# Braze documentation — project dictionary for cspell.
#
# How to maintain (see also cspell.json at repo root):
# 1. Canonical editorial terms: _docs/_contributing/style_guide/writing_style_guide.md (#glossary)
# 2. Company glossary export (partner names, acronyms, product terms): align with internal
#    “BRAZE CONTENT AND COPY STYLE GUIDE – GLOSSARY” when it is updated.
# 3. When cspell flags a word that is correct per those sources, add it here (one entry per
#    line, sorted alphabetically). Multi-word names are allowed on a single line.
# 4. If CI reports an unknown word: fix a real typo in the Markdown, OR add the token here.
# 5. Do not add misspellings to silence the checker. Skip common English words already in en_US.
#    Exception: Shoptify is listed because it appears on purpose in Do/Don't examples (versus
#    Shopify) in writing_style_guide.md and localized mirrors—do not replace with Shopify here.
#
# Branded capitalization (Canvas, Segment, Branch, etc.):
# - cspell’s job is “is this token spelled like a known word?”, not “is this the correct
#   capital letter for the Braze product sense?”. By default, dictionary matching is
#   case-insensitive, so listing “Canvas” does not stop lowercase “canvas” from being treated
#   as a valid spelling of the same token—it only avoids false “unknown word” hits when you
#   use the product name.
# - For “same letters, different meaning” pairs (for example Segment the company vs segment
#   the audience), spellcheck cannot enforce title case. Use the style guide, review, or a
#   dedicated prose linter (for example Vale) if you need capitalization rules in CI.
#
# Liquid / Jekyll / Kramdown tokens are mostly stripped by cspell.json patterns.
# Colloquial spellings that drop final -g before an apostrophe (for example Fishin', runnin’)
# are skipped by a dedicated ignoreRegExpList entry in cspell.json, not by listing each word here.
#
# Bulk update: ~714 tokens from 2026-04-06 full-repo cspell sweep were merged after excluding
# obvious typos, lorem ipsum, and test strings.
#
# Also listed here (not typos): example Apple Team IDs, Liquid/base64 table fragments, fuzzy SMS
# opt-out samples, Transifex example resource slugs, Inbox Monster partner phrasing (“scaries”),
# Braze Pilot demo usernames, and the Makhuwa meetto language name.
