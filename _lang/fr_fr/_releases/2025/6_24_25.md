# Publication du 24 juin 2025 {#june-24-2025-release}

## BrazeAI Decisioning Studio™

[BrazeAI Decisioning Studio™](https://www.braze.com/product/brazeai-decisioning-studio/) remplace les tests A/B par une décision automatisée par IA qui personnalise tout et maximise n'importe quel indicateur : générez du chiffre d'affaires, pas des clics. Avec BrazeAI Decisioning Studio™, vous pouvez optimiser n'importe quel indicateur clé de performance. Consultez notre section dédiée [BrazeAI Decisioning Studio™]({{site.baseurl}}/user_guide/brazeai/decisioning_studio/) pour découvrir des exemples de cas d'utilisation et les principales fonctionnalités.

## Flexibilité des données {#data-flexibility}

### Provisionnement SAML juste-à-temps {#saml-just-in-time-provisioning}

{% multi_lang_include release_type.md release="General availability" %}

Utilisez le [provisionnement SAML juste-à-temps]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/saml_just_in_time_provisioning/) pour permettre aux nouveaux utilisateurs de l'entreprise de créer un compte Braze lors de leur première connexion. Cela évite aux administrateurs de devoir créer manuellement un compte pour un nouvel utilisateur, de choisir ses autorisations, de l'affecter à un espace de travail et d'attendre qu'il active son compte.

### Filtres par sélection {#filters-per-selection}

Vous pouvez désormais ajouter jusqu'à 10 filtres par [sélection]({{site.baseurl}}/user_guide/data/activation/catalogs/selections/).

### Stockage du catalogue {#catalog-storage}

La taille de stockage pour la version gratuite des [catalogues]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog/#catalog-storage) est de 100&nbsp;Mo maximum. Vous pouvez avoir un nombre illimité d'éléments tant qu'ils ne dépassent pas 100&nbsp;Mo.

### Nombre de lignes synchronisées avec l'ingestion de données cloud {#number-of-rows-synced-with-cloud-data-ingestion}

Par défaut, pour l'ingestion de données cloud, chaque exécution peut synchroniser jusqu'à 500 millions de lignes. Toute synchronisation comportant plus de 500 millions de nouvelles lignes sera interrompue.

Consultez les [limitations du produit d'ingestion de données cloud]({{site.baseurl}}/user_guide/data/cloud_ingestion/overview/#product-limitations) pour plus de détails.

## Canaux robustes {#robust-channels}

### Tests d'accessibilité dans Inbox Vision {#accessibility-testing-in-inbox-vision}

{% multi_lang_include release_type.md release="General availability" %}

Utilisez les [tests d'accessibilité]({{site.baseurl}}/user_guide/message_building_by_channel/email/inbox_vision/#accessibility-testing) dans Inbox Vision pour mettre en évidence les problèmes d'accessibilité que peut présenter votre e-mail.

Les tests d'accessibilité analysent le contenu de vos e-mails en fonction de certaines exigences des [Directives pour l'accessibilité des contenus web](https://www.w3.org/WAI/standards-guidelines/wcag/) (WCAG) 2.2 AA. Cela peut fournir des informations sur les éléments qui ne respectent pas les normes d'accessibilité.

### Suivi des clics pour WhatsApp {#click-tracking-for-whatsapp}

{% multi_lang_include release_type.md release="General availability" %}

Vous pouvez activer le [suivi des clics]({{site.baseurl}}/user_guide/channels/whatsapp/message_features_and_optimization/click_tracking/) dans les messages de réponse et les modèles de messages pour consulter les données relatives aux clics dans vos rapports de performance WhatsApp et segmenter les utilisateurs en fonction de qui a cliqué sur quoi.

### Vidéos pour WhatsApp {#videos-for-whatsapp}

{% multi_lang_include release_type.md release="General availability" %}

Vous pouvez [intégrer des vidéos]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/create/#supported-whatsapp-features) dans le corps du texte des messages WhatsApp sortants. Ces fichiers doivent être hébergés via une URL ou dans la [bibliothèque multimédia de Braze]({{site.baseurl}}/user_guide/messaging/design_and_edit/media_library/image_specifications/).

## Nouveaux partenariats Braze {#new-braze-partnerships}

### Stripe – eCommerce

L'intégration entre Braze et [Stripe]({{site.baseurl}}/partners/stripe/) vous permet de déclencher des messages dans Braze sur la base d'événements Stripe tels que le démarrage d'un essai, l'activation d'un abonnement, l'annulation d'un abonnement, et bien plus encore.
