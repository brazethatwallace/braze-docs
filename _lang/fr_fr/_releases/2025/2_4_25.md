# Version du 4 février 2025 {#february-4-2025-release}

## Améliorations de la documentation Braze {#braze-docs-improvements}

### Refonte Données et Analytique {#data-and-analytics-revamp}
Pour vous aider à trouver plus facilement ce que vous cherchez, nous avons séparé les articles précédemment regroupés sous « Data & Analytics » en deux sections : [Données]({{site.baseurl}}/user_guide/data) et [Analytique]({{site.baseurl}}/user_guide/analytics).

### Guide du développeur {#developer-guide}
Nous avons effectué un grand nettoyage de l'ensemble de la documentation du [Guide du développeur Braze]({{site.baseurl}}/developer_guide/home), qui comprenait notamment la fusion de guides pratiques répartis sur plusieurs pages en une seule page.

Il existe également une nouvelle [page de référence SDK]({{site.baseurl}}/developer_guide/references) qui répertorie l'ensemble de la documentation de référence et des dépôts pour chaque SDK Braze.

#### SDK Braze pour Unreal Engine {#unreal-engine-braze-sdk}
Nous avons migré et réécrit tout le contenu du README du dépôt GitHub du SDK Braze pour Unreal Engine dans sa [section dédiée sur la documentation Braze]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=unreal%20engine).

## Flexibilité des données {#data-flexibility}

### Tableau de bord d'utilisation de l'API {#api-usage-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

Le [tableau de bord d'utilisation de l'API]({{site.baseurl}}/user_guide/analytics/dashboards/api_usage) vous permet de surveiller le trafic entrant de votre REST API vers Braze afin de comprendre les tendances d'utilisation de nos REST API et de résoudre les problèmes éventuels.

### Ajout de tags aux attributs personnalisés {#adding-tags-to-custom-attributes}

{% multi_lang_include release_type.md release="General availability" %}

Vous pouvez [ajouter des tags à un attribut personnalisé]({{site.baseurl}}/user_guide/data/activation/attributes/custom_attributes#add-tags) après sa création si vous disposez de la permission « Manage Events, Attributes, Purchases ». Les tags peuvent ensuite être utilisés pour filtrer la liste des attributs.

### Endpoints de sélections de catalogue et de champs de catalogue asynchrones {#catalog-selections-and-async-catalog-fields-endpoints}

{% multi_lang_include release_type.md release="General availability" %}

Les endpoints suivants sont désormais en disponibilité générale :
* [POST : Create Catalog Fields]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/post_create_catalog_fields)
* [DELETE : Delete Catalog Field]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/delete_catalog_field)
* [DELETE : Delete Catalog Selection]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/delete_catalog_selection)
* [POST : Create Catalog Selection]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/post_create_catalog_selections)

### Utilisation d'une adresse e-mail pour déclencher des Campaigns ou des Canvas {#using-an-email-address-to-trigger-campaigns-or-canvases}

{% multi_lang_include release_type.md release="General availability" %}

Vous pouvez désormais spécifier un destinataire par adresse e-mail pour déclencher vos [Campaigns]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/target_users) et [Canvas]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas#step-13-set-your-target-entry-audience).

### Utilisation d'un numéro de téléphone pour identifier un utilisateur via l'API {#using-a-phone-number-to-identify-a-user-via-the-api}

{% multi_lang_include release_type.md release="General availability" %}

Vous pouvez désormais utiliser un numéro de téléphone, en plus d'un alias et d'une adresse e-mail, pour identifier un utilisateur via l'[endpoint `/users/identify` de l'API]({{site.baseurl}}/api/endpoints/user_data/post_user_identify).

### Obtenir une trace SAML {#getting-a-saml-trace}
Nous avons ajouté des [étapes expliquant comment obtenir une trace SAML]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/saml_sso_setup#obtaining-a-saml-trace), ce qui vous aide à résoudre plus efficacement les problèmes liés à l'authentification unique (SSO) SAML avec le support.

### Centres de données régionaux {#region-specific-data-centers}
Braze se développant pour desservir de nouvelles zones géographiques, nous avons ajouté un [article sur les centres de données Braze]({{site.baseurl}}/user_guide/data/infrastructure/data_centers) pour clarifier notre approche opérationnelle.

## Libérer la créativité {#unlocking-creativity}

### Notifications de baisse de prix et notifications de retour en stock {#price-drop-notifications-and-back-in-stock-notifications}

{% multi_lang_include release_type.md release="General availability" %}

Vous pouvez désormais informer les clients lorsqu'un article est de nouveau en stock en configurant des [notifications de retour en stock]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/back_in_stock_notifications) via un Canvas et un catalogue.

Vous pouvez également créer des [notifications de baisse de prix]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/price_drop_notifications) pour informer les clients lorsque le prix d'un article a diminué, en configurant des notifications de baisse de prix dans un catalogue et un Canvas.

### Aperçu pour les sélections {#preview-for-selection}

{% multi_lang_include release_type.md release="General availability" %}

Après avoir créé une sélection, vous pouvez [visualiser ce qu'une sélection renverrait]({{site.baseurl}}/user_guide/data/activation/catalogs/selections#test-and-preview) pour un utilisateur aléatoire ou un utilisateur spécifique.

### Modélisation d'éléments de catalogue incluant du Liquid {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="General availability" %}

Vous pouvez [modéliser des éléments de catalogue qui incluent du Liquid]({{site.baseurl}}/user_guide/data/activation/catalogs/using_catalogs#using-liquid).

### Modèles Canvas {#canvas-templates}
Nous avons ajouté de nouveaux modèles Canvas pour l'[onboarding des utilisateurs avec un sondage de préférences]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/preference_survey) et la [création d'une inscription par e-mail avec double abonnement]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/email_signup).

### Gestion des prospects avec Salesforce Sales Cloud pour le B2B {#managing-leads-with-salesforce-sales-cloud-for-b2b}
L'une des façons dont les marketeurs B2B peuvent utiliser Braze est via une intégration avec Salesforce Sales Cloud. Découvrez comment implémenter ce [cas d'usage]({{site.baseurl}}/user_guide/get_started/b2b_use_cases/b2b_salesforce_sales_cloud).

## Canaux robustes {#robust-channels}

### Listes de suppression {#suppression-lists}

{% multi_lang_include release_type.md release="Beta" %}

Les [listes de suppression]({{site.baseurl}}/user_guide/audience/suppression_lists) spécifient des groupes d'utilisateurs qui ne recevront jamais de messages. Les administrateurs peuvent créer des listes de suppression avec des filtres de Segment pour affiner un groupe d'utilisateurs de la même manière que pour la segmentation.

## Nouveaux partenariats Braze {#new-braze-partnerships}

### Constructor - Contenu dynamique {#constructor-dynamic-content}
[Constructor]({{site.baseurl}}/partners/ecommerce/product_search_recommendations/constructor) est une plateforme de recherche et de découverte de produits qui utilise l'IA et le machine learning pour offrir des expériences personnalisées de recherche, de recommandations et de navigation pour les sites d'e-commerce et de vente au détail.

### Trustpilot - Contenu dynamique {#trustpilot-dynamic-content}
[Trustpilot]({{site.baseurl}}/partners/trustpilot) est une plateforme d'avis en ligne qui permet à vos clients de partager leurs retours et vous permet de gérer et de répondre aux avis.
