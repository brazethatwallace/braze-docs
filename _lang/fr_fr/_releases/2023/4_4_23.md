# Version du 4 avril 2023 {#april-4-2023-release}

## Fil d'Ariane de la documentation {#documentation-breadcrumbs}
Vous remarquerez peut-être que le site Braze Docs dispose désormais d'un fil d'Ariane en haut de chaque article pour vous indiquer où vous vous trouvez sur le site. Il s'agit simplement d'une option supplémentaire pour faciliter votre navigation !

![Un fil d'Ariane de navigation depuis User Guide > Message Building by Channel > In-App Messages > Templates > Simple Survey]({% image_buster /assets/img/doc-breadcrumbs.png %}){: style="max-width:55%"}

## Créer des catalogues dans le navigateur {#creating-catalogs-in-browser}
Vous pouvez utiliser des catalogues pour référencer des données non-utilisateurs dans vos Campaigns Braze via Liquid. Braze vous permet désormais de créer un catalogue directement dans votre navigateur au lieu d'importer un fichier CSV. Reportez-vous à la section [Création d'un catalogue]({{site.baseurl}}/user_guide/data/activation/catalogs/create) pour plus d'informations.

## Requête SQL personnalisée dans le générateur de requêtes {#custom-sql-in-query-builder}
Avec le générateur de requêtes, vous pouvez générer des rapports en utilisant les données Braze dans Snowflake. Désormais, vous pouvez [utiliser le langage SQL personnalisé]({{site.baseurl}}/user_guide/data_and_analytics/query_builder#custom-sql) pour obtenir de nouvelles informations.

{% alert important %}
L'éditeur SQL est en accès anticipé. Si vous souhaitez participer à l'accès anticipé, contactez votre gestionnaire du succès des clients.
{% endalert %}

## FAQ sur les feature flags {#feature-flag-faq}
Nous avons répondu à quelques [questions fréquemment posées concernant les feature flags]({{site.baseurl}}/developer_guide/feature_flags/faq).

## Étiquette Liquid « message extras » pour Currents {#message-extras-liquid-tag-for-currents}
Grâce à l'[étiquette Liquid `message_extras`]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/advanced_filters/message_extras), vous pouvez annoter vos événements d'envoi avec des données dynamiques issues du contenu connecté, des attributs personnalisés (tels que la langue, le pays) et des propriétés d'entrée dans Canvas. Cette étiquette Liquid ajoute des paires clé-valeur à l'événement d'envoi correspondant dans Currents.

{% alert important %}
Cette étiquette Liquid est actuellement en version bêta pour les événements d'envoi d'e-mails, de SMS et de notifications push. Contactez votre gestionnaire du succès des clients Braze si vous souhaitez participer à la bêta.
{% endalert %}

## Remplissage de l'historique Shopify {#shopify-historical-backfill}
Le [remplissage de l'historique Shopify]({{site.baseurl}}/partners/ecommerce/shopify/shopify_data_features#historical-backfill) permet à Braze d'importer tous les clients, commandes et événements d'achat des 90 derniers jours précédant votre connexion à l'intégration Shopify.

## WhatsApp
WhatsApp est une plateforme de messagerie pair-à-pair populaire utilisée dans le monde entier, qui propose une messagerie conversationnelle pour les entreprises. Le [canal de messagerie WhatsApp]({{site.baseurl}}/user_guide/channels/whatsapp) offre un moyen direct d'interagir avec les utilisateurs sur la plateforme WhatsApp par le biais de Campaigns, d'abonnements et de désabonnements, de réponses rapides, et plus encore.

### Objet API WhatsApp {#whatsapp-api-object}
Dans le cadre de la prise en charge de WhatsApp par Braze, l'objet `whats_app` vous permet de modifier ou de créer des messages WhatsApp via nos [endpoints de messagerie]({{site.baseurl}}/api/endpoints/messaging). Consultez la [documentation de l'objet `whats_app`]({{site.baseurl}}/api/objects_filters/messaging/whats_app_object) pour les spécifications complètes.
