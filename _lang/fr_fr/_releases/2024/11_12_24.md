{% multi_lang_include release_type.md release="General availability" %}

## Mises à jour du SDK {#sdk-updates}

Les mises à jour du SDK suivantes ont été publiées. Les mises à jour majeures sont répertoriées ci-dessous ; vous pouvez trouver toutes les autres mises à jour en consultant les journaux des modifications du SDK correspondants.

- [Expo Plugin 3.0.0](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
    - Cette version nécessite la version 13.1.0 du SDK Braze React Native.
    - Remplace l'appel à la méthode iOS BrazeAppDelegate de BrazeReactUtils.populateInitialUrl par BrazeReactUtils.populateInitialPayload.
        - Cette mise à jour résout un problème où les événements d'ouverture push ne se déclenchaient pas lors d'un clic sur une notification alors que l'application était dans un état terminé.
        - Pour tirer pleinement parti de cette mise à jour, remplacez tous les appels de Braze.getInitialURL par Braze.getInitialPushPayload dans votre code JavaScript. L'URL initiale est désormais accessible via la propriété url du payload push initial.
- [Braze Segment Swift Plugin 5.0.0](https://github.com/braze-inc/braze-segment-swift/blob/main/CHANGELOG.md)
    - Met à jour les bindings du SDK Swift de Braze afin qu'ils requièrent les versions à partir de la dénomination SemVer 11.1.1+.
    - Cela permet la compatibilité avec toute version du SDK de Braze à partir de la 11.1.1 jusqu'à la 12.0.0 exclue.
    - Consultez l'entrée du journal des modifications de la version 11.1.1 pour plus d'informations sur les changements potentiellement incompatibles.
