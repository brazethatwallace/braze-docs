# Version du 17 septembre 2024 {#september-17-2024-release}

## Flexibilité des données {#data-flexibility}

### Ingestion de données cloud Braze pour S3 {#braze-cloud-data-ingestion-for-s3}

Vous pouvez utiliser l'[Ingestion de données cloud (CDI) pour S3]({{site.baseurl}}/user_guide/data_and_analytics/cloud_ingestion/file_storage_integrations/#aws-definitions) pour intégrer directement un ou plusieurs compartiments S3 de votre compte AWS à Braze. Lorsque de nouveaux fichiers sont publiés sur S3, un message est envoyé à SQS et l'Ingestion de données cloud Braze prend en charge ces nouveaux fichiers.

### Utilisateurs actifs par mois CY 24-25 {#monthly-active-users-cy-24-25}

Pour les clients qui ont acheté la formule Utilisateurs actifs par mois - CY 24-25, Braze gère différentes limites de débit sur son endpoint `/users/track`. Pour plus de détails, reportez-vous à [POST : Suivre les utilisateurs]({{site.baseurl}}/api/endpoints/user_data/post_user_track/#monthly-active-users-cy-24-25).

## Libérer la créativité {#unlocking-creativity}

### Modélisation d'articles de catalogue incluant du Liquid {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="Early access" %}

Utilisez l'indicateur `:rerender` dans une étiquette Liquid pour [afficher le contenu Liquid d'un article de catalogue]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog/#using-liquid). Par exemple, si vous affichez le contenu Liquid suivant :

{% raw %}
```liquid
Hi ${first_name}
{% catalog_items Messages greet_msg :rerender %}
{{ items[0].Welcome_Message }}
```
{% endraw %}

Le résultat s'affichera comme suit :

{% raw %}
```
Hi Peter,
Welcome to our store, Peter!
```
{% endraw %}

## Canaux robustes {#robust-channels}

### Messages de réponse WhatsApp {#whatsapp-response-messages}

{% multi_lang_include release_type.md release="General availability" %}

Vous pouvez utiliser les [messages de réponse]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/create/#response-messages) pour répondre aux messages WhatsApp entrants de vos utilisateurs. Ces messages sont créés in-app sur Braze pendant votre expérience de composition et peuvent être modifiés à tout moment. Vous pouvez utiliser Liquid pour faire correspondre la langue du message de réponse aux utilisateurs appropriés.

### Modèles de Canvas {#canvas-templates}

{% multi_lang_include release_type.md release="General availability" %}

Créez des [modèles de Canvas]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/) pour affiner votre envoi de messages en créant un cadre cohérent qui peut être facilement personnalisé pour s'adapter à vos objectifs spécifiques sur l'ensemble de vos Canvas.

### Pages d'accueil {#landing-pages}

{% multi_lang_include release_type.md release="Beta" %}

Les [pages d'accueil]({{site.baseurl}}/user_guide/messaging/landing_pages/) Braze sont des pages web autonomes qui peuvent piloter votre stratégie d'acquisition et d'engagement des utilisateurs.

### Changements depuis la dernière consultation {#changes-since-last-viewed}

Vous pouvez consulter le nombre de mises à jour de vos [Canvas]({{site.baseurl}}/user_guide/engagement_tools/canvas/testing_canvases/measuring_and_testing_with_canvas_analytics/#changes-since-last-viewed), campagnes et [segments]({{site.baseurl}}/user_guide/engagement_tools/segments/managing_segments/#changes-since-last-viewed) effectuées par d'autres membres de votre équipe en vous référant à l'indicateur *Changements depuis la dernière consultation* sur les pages d'aperçu respectives (comme la page d'aperçu d'une [campagne e-mail]({{site.baseurl}}/user_guide/message_building_by_channel/email/reporting_and_analytics/email_reporting/#changes-since-last-viewed)).

### Résolution des problèmes liés aux requêtes webhook et de Contenu connecté {#troubleshooting-webhook-and-connected-content-requests}

La page [Résoudre les problèmes liés aux requêtes webhook et de Contenu connecté]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content/troubleshooting_webhooks_and_connected_content/) explique comment résoudre les codes d'erreur de webhook et de Contenu connecté, notamment la nature des erreurs et les étapes pour les résoudre.

## Nouveaux partenariats Braze {#new-braze-partnerships}

### Inbox Monster - Analytique {#inbox-monster-analytics}

[Inbox Monster]({{site.baseurl}}/partners/data_and_analytics/analytics/inbox_monster/) est une plateforme de signaux de boîte de réception qui aide les marques d'entreprise à réussir chaque envoi. Il s'agit d'une suite intégrée de solutions pour la livrabilité, le rendu créatif et la surveillance des SMS, qui permet aux équipes modernes de gestion de la relation client (CRM) d'être plus efficaces et de mettre fin aux angoisses liées à l'envoi.

### SessionM - Fidélisation {#sessionm-loyalty}

[SessionM]({{site.baseurl}}/partners/data_and_analytics/loyalty/sessionm/) est une plateforme d'engagement client et de fidélisation qui offre des fonctionnalités de gestion de campagnes et des solutions de gestion de la fidélisation pour aider les marketeurs à mener des actions ciblées afin d'augmenter l'engagement et le bénéfice.

## IA et automatisation par apprentissage automatique {#ai-and-ml-automation}

### Recommandations d'articles tendance {#trending-item-recommendations}

Outre le modèle « AI Personalized », la fonctionnalité de [recommandations produit basées sur l'IA]({{site.baseurl}}/user_guide/sage_ai/recommendations/about_item_recommendations/#trending) comprend également un modèle de recommandation « Trending », qui met en avant les articles ayant eu l'élan le plus positif en termes d'interactions récentes avec les utilisateurs.

## Paramètres {#settings}

### Rôles {#roles}

{% multi_lang_include release_type.md release="General availability" %}

Les [rôles]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/user_permissions/#creating-a-role) permettent une meilleure structuration en regroupant vos autorisations personnalisées individuelles avec les contrôles d'accès à l'espace de travail. Ceci est particulièrement utile si vous avez plusieurs marques ou espaces de travail régionaux dans un seul tableau de bord. Grâce aux rôles, vous pouvez ajouter les utilisateurs du tableau de bord aux bons espaces de travail et leur accorder directement les autorisations associées.

### Rapport sur les événements de sécurité {#security-event-report}

Nous avons ajouté une liste complète des [événements de sécurité]({{site.baseurl}}/user_guide/administrative/app_settings/company_settings/security_settings/#downloading-a-security-event-report) qui peuvent apparaître dans votre rapport de sécurité téléchargé.

### Rapport sur l'utilisation des messages {#message-usage-report}

{% multi_lang_include release_type.md release="Early access" %}

Le [tableau de bord d'utilisation des crédits]({{site.baseurl}}/credits_usage_dashboard/) fournit en libre-service des informations sur votre utilisation des crédits pour une vue d'ensemble de l'utilisation historique et actuelle par rapport aux attributions contractuelles. Ces informations peuvent réduire votre confusion et vous aider à effectuer des ajustements pour prévenir les risques de dépassement.

## SDK

### Initialisation différée pour le SDK Braze Swift {#delayed-initialization-for-the-braze-swift-sdk}

Configurez l'[initialisation différée]({{site.baseurl}}/developer_guide/sdk_initalization/?sdktab=swift) pour initialiser votre SDK Braze Swift de manière asynchrone tout en veillant à ce que la gestion des notifications push soit préservée. Cela peut être utile lorsque vous devez configurer d'autres services avant d'initialiser le SDK, par exemple pour récupérer des données de configuration depuis un serveur ou attendre le consentement de l'utilisateur.
