# Version du 5 mars 2024 {#march-5-2024-release}

## Politique de consentement des utilisateurs de l'UE de Google {#google-eu-user-consent-policy}

Google met à jour sa [politique de consentement des utilisateurs de l'UE](https://www.google.com/about/company/user-consent-policy/) en réponse aux modifications apportées au [Digital Markets Act (DMA)](https://ads-developers.googleblog.com/2023/10/updates-to-customer-match-conversion.html), en vigueur depuis le 6 mars 2024. Ce changement exige que les annonceurs divulguent certaines informations à leurs utilisateurs finaux de l'EEE et du Royaume-Uni, et qu'ils obtiennent les consentements nécessaires de leur part. Dans le cadre de ce changement à venir, vous pouvez [collecter les deux signaux de consentement dans Braze en tant qu'attributs personnalisés]({{site.baseurl}}/partners/canvas_steps/google_audience_sync#collecting-consent-for-eea-and-uk-end-users). Braze synchronisera les données de ces attributs personnalisés avec les champs de consentement appropriés dans Google.

## Flexibilité des données {#data-flexibility}

### Fusionner les utilisateurs en double {#merge-duplicate-users}

{% multi_lang_include release_type.md release="Early access" %}

Dans le tableau de bord de Braze, vous pouvez désormais [rechercher et fusionner les utilisateurs en double]({{site.baseurl}}/user_guide/audience/manage_audience/merge_duplicate_users) pour maximiser l'efficacité de vos Campaigns et Canvas. Vous pouvez fusionner les profils utilisateur individuellement ou effectuer une fusion en masse, qui fusionne tous les profils avec des identifiants correspondants dans le profil utilisateur le plus récemment mis à jour.

### Rechercher du contenu archivé {#search-for-archived-content}

Dans le tableau de bord de Braze, vous pouvez désormais inclure [du contenu archivé dans vos résultats de recherche]({{site.baseurl}}/user_guide/administrative/access_braze/global_search#filter-for-archived-content) en sélectionnant **Show Archived Content**.

### Prise en charge de l'archivage des messages pour AWS S3 et Google Cloud Storage {#message-archiving-support-for-aws-s3-and-google-cloud-storage}

Vous pouvez utiliser [l'archivage des messages]({{site.baseurl}}/user_guide/data/distribution/export_braze_data/message_archiving) pour enregistrer une copie de vos messages envoyés aux utilisateurs à des fins d'archivage ou de conformité dans votre compartiment AWS S3, votre conteneur Azure Blob Storage ou votre compartiment Google Cloud Storage.

### Référence des tables SQL {#sql-table-reference}

Consultez la [référence des tables SQL]({{site.baseurl}}/user_guide/audience/segments/segment_extension/sql_segments/sql_segments_tables) pour voir les tables et colonnes disponibles pour les requêtes dans le Query Builder ou lors de la génération d'extensions de segments SQL.

## Libérer la créativité {#unlocking-creativity}

### Contrôle du ton pour la rédaction assistée par IA {#tone-control-for-ai-copywriting}

Vous pouvez désormais choisir un [ton de message]({{site.baseurl}}/user_guide/brazeai/generative_ai/ai_copywriting#steps) pour déterminer le style du texte généré avec l'assistant de rédaction IA.

## Canaux robustes {#robust-channels}

### Création de cartes {#card-creation}

Vous pouvez choisir le moment où Braze évalue l'éligibilité de l'audience et la personnalisation pour les nouvelles campagnes de Content Cards et les étapes Canvas en spécifiant quand la carte est [créée]({{site.baseurl}}/user_guide/channels/content_cards/create_a_content_card/card_creation).

### Aperçu des parcours utilisateurs {#preview-user-paths}

{% multi_lang_include release_type.md release="General availability" %}

Découvrez le parcours Canvas que vous avez créé pour vos utilisateurs, y compris un aperçu du timing et des messages qu'ils recevront. Ces [tests]({{site.baseurl}}/preview_user_paths) servent d'assurance qualité pour vérifier que vos messages sont envoyés à la bonne audience, le tout avant d'envoyer le Canvas.

### Campaigns push rapides {#quick-push-campaigns}

{% multi_lang_include release_type.md release="General availability" %}

Lors de la création d'une campagne de notification push dans Braze, vous pouvez sélectionner plusieurs plateformes et appareils pour rédiger un seul message pour toutes les plateformes dans une expérience d'édition unique appelée [push rapide]({{site.baseurl}}/user_guide/channels/push/create_a_push_message/multiple_platform_push). Cette fonctionnalité est uniquement disponible pour les Campaigns.

### En-tête de désabonnement de liste personnalisé {#custom-list-unsubscribe-header}

{% multi_lang_include release_type.md release="General availability" %}

L'ajout d'un [en-tête de désabonnement de liste personnalisé]({{site.baseurl}}/user_guide/administrative/app_settings/email_settings#custom-list-unsubscribe-header) à vos e-mails permet à vos destinataires de se désabonner. De cette façon, vous pouvez ajouter votre propre endpoint de désabonnement en un clic configuré et un « mailto: » optionnel. Braze nécessite une entrée d'URL pour prendre en charge un en-tête de désabonnement de liste personnalisé, car le désabonnement en un clic HTTP est une exigence de Yahoo et Gmail pour les expéditeurs en masse.

### Pages multiples pour les messages in-app {#multiple-pages-for-in-app-messages}

{% multi_lang_include release_type.md release="Early access" %}

[L'ajout de pages à votre message in-app]({{site.baseurl}}/user_guide/message_building_by_channel/in-app_messages/drag_and_drop/create#multi-page) vous permet de guider les utilisateurs à travers un flux séquentiel, comme un flux d'onboarding ou un parcours de bienvenue. Vous pouvez gérer les pages depuis la section **Pages** de l'onglet **Créer**.

### Randomiser les chemins pour un chemin d'expérience {#randomize-paths-for-an-experiment-path}

Pour toujours [randomiser l'attribution des chemins]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step) dans une étape de chemin d'expérience, sélectionnez **Randomized Paths in Experiment Paths** dans l'étape. Cette option n'est pas disponible lors de l'utilisation des chemins gagnants ou personnalisés.

### Formulaire de capture d'e-mail {#email-capture-form}

Les [messages de capture d'e-mail]({{site.baseurl}}/user_guide/channels/in_app_messages/message_types/email_capture_form) vous permettent d'inviter facilement les utilisateurs de votre site à soumettre leur adresse e-mail, qui sera ensuite disponible dans leur profil utilisateur pour être utilisée dans toutes vos campagnes de communication.
