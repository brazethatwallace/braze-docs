# Janvier 2019 {#january-2019}

Bienvenue dans une nouvelle année !

## Durée de vie des notifications push (TTL) {#push-time-to-live-ttl}

Dans votre compte, sous **Gérer les paramètres**, cliquez sur l'onglet [Paramètres TTL des notifications push]({{site.baseurl}}/user_guide/administer/global/workspace_settings/push_settings/) pour gérer la durée des tentatives de réexpédition lorsqu'un appareil est hors ligne.

## Liste d'autorisation d'IP pour le contenu connecté {#connected-content-ip-whitelisting}

Braze a le plaisir d'annoncer que, grâce à plusieurs mises à niveau d'infrastructure effectuées par nos équipes internes, nous pouvons désormais proposer une liste d'autorisation d'adresses IP pour le contenu connecté sur tous les clusters. À l'avenir, nous prévoyons d'ajouter des IP supplémentaires pour les clusters hors UE.
