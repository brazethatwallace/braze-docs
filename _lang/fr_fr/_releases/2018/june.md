# Juin 2018 {#june-2018}

## Réutilisation du mot de passe {#password-reusability}

Les administrateurs peuvent désormais déterminer le nombre minimum de nouveaux mots de passe uniques que les autres utilisateurs de leur entreprise doivent utiliser avant de pouvoir réutiliser un ancien mot de passe. Ce paramètre est configurable depuis le panneau [Règles d'authentification]({{site.baseurl}}/user_guide/onboarding/platform_administrative_features/#authentication-rules) dans les **Paramètres de l'entreprise**, sous l'onglet **Paramètres de sécurité**.

## Suivi des désinstallations pour les étapes Canvas {#uninstall-tracking-for-canvas-steps}

Les désinstallations par étape Canvas sont désormais suivies et consultables en tant que statistique.
