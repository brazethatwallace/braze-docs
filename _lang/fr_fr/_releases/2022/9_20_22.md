# Version du 20 septembre 2022 {#september-20-2022-release}

## Guide API {#api-guide}
Consultez le [Guide API de Braze]({{site.baseurl}}/api/home) pour rechercher des endpoints par type d'endpoint, ce qui vous aidera à affiner votre recherche dans le glossaire.

## Variantes personnalisées {#personalized-variants}
Utilisez les [variantes personnalisées]({{site.baseurl}}/user_guide/messaging/ab_testing/optimizations) pour envoyer à chaque utilisateur de votre Segment cible la variante avec laquelle il est le plus susceptible d'interagir.

## Tester les Canvas {#testing-canvases}
Après avoir créé votre Canvas, plusieurs vérifications peuvent être nécessaires avant le lancement, en fonction de détails tels que la taille de votre audience ou le nombre de filtres de segmentation. Consultez [Envoyer des Canvas de test]({{site.baseurl}}/user_guide/messaging/canvas/testing_canvases/sending_test_canvases) pour obtenir des conseils.

## Liquid 5
Pour les utilisateurs existants de l'entreprise, Liquid 5 est disponible de manière générale. Découvrez les [nouveautés de Liquid 5]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid#liquid-5-support).

## Nouveaux partenariats Braze {#new-braze-partnerships}

### Shopify
L'intégration de Braze et [Shopify]({{site.baseurl}}/partners/shopify) vous permet de mettre à jour des profils utilisateur existants ou d'en créer de nouveaux dans Braze pour les prospects, les inscriptions et les enregistrements de comptes capturés dans votre boutique Shopify.

## Mises à jour du SDK {#sdk-updates}

Les dernières mises à jour du SDK ont été publiées. Les mises à jour avec rupture de compatibilité sont répertoriées dans la section des mises à jour du SDK ; toutes les autres mises à jour sont disponibles dans les journaux des modifications des SDK correspondants.

- [Android SDK 23.1.0-23.12](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [React Native SDK v1.38.0–v1.38.1](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - Mise à jour du pont Android natif vers le Braze Android SDK 23.0.1.
  - Mise à jour du pont iOS natif vers le Braze iOS SDK 4.5.0.
  - Le Braze React Native Android SDK nécessite désormais Kotlin directement pour la compilation.
- [Braze Expo Plugin 0.4.0](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - Renommage de la propriété `fcmSenderID` en `firebaseCloudMessagingSenderId`.
- [Unity 3.9.0](https://github.com/Appboy/appboy-unity-sdk/blob/master/CHANGELOG.md)
  - Mise à jour du plugin Android pour utiliser le Braze Android SDK 23.1.0.
  - Ajout de la possibilité de demander les autorisations de notification push sur les appareils Android 13+ via `Appboy.AppboyBinding.PromptUserForPushPermissions(false)`.
- [Swift SDK 5.3.0-5.4.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#540)
