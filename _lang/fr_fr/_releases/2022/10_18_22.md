# Version du 18 octobre 2022 {#october-18-2022-release}

## Historique d'envoi de messages du profil utilisateur {#user-profile-messaging-history}

L'onglet **Historique des messages** du profil utilisateur montre les événements récents liés aux messages (environ 40) pour un utilisateur individuel au cours des 30 derniers jours. Ces événements comprennent les messages que l'utilisateur a envoyés, reçus, avec lesquels il a interagi, etc. Pour en savoir plus, reportez-vous à la section [Profils utilisateurs]({{site.baseurl}}/user_guide/engagement_tools/segments/user_profiles#messaging-history-tab).

## Content Blocks pour l'éditeur par glisser-déposer {#content-blocks-for-drag-drop-editor}

Les [Content Blocks]({{site.baseurl}}/user_guide/messaging/design_and_edit/content_blocks) utilisés exclusivement dans l'éditeur par glisser-déposer ont des fonctionnalités similaires à celles des Content Blocks utilisés sur les différents canaux. Ils servent d'emplacement centralisé pour la conservation d'informations qui peuvent être référencées dans diverses campagnes par e-mail. Il peut s'agir de regrouper des en-têtes d'e-mails, des encarts promotionnels et plus encore, le tout sur une seule ligne réutilisable.

## ScriptTag Shopify {#shopify-scripttag}

L'[intégration Braze et Shopify]({{site.baseurl}}/partners/shopify) vous permet désormais d'intégrer notre SDK Web via ScriptTag sur votre boutique Shopify. L'implémentation de notre SDK Web via ScriptTag permet de suivre les éléments suivants :
- Suivi des utilisateurs anonymes pour suivre l'activité des visiteurs dans votre boutique
- Suivi des utilisateurs actifs par mois, étant donné que le SDK Web est capable de suivre les données de session des visiteurs de votre boutique
- Option pour collecter les données d'activité des utilisateurs Shopify sur site, qui compteront dans votre consommation de points de données
- Option pour activer l'envoi de messages dans le navigateur comme canal sur votre boutique Shopify

## Désabonnements approximatifs par SMS {#sms-fuzzy-opt-outs}

Le [désabonnement approximatif]({{site.baseurl}}/user_guide/message_building_by_channel/sms/keywords/fuzzy_opt_out#fuzzy-opt-out) tente de reconnaître les cas où un message SMS entrant ne correspond pas à un mot-clé de désabonnement, mais indique une intention de se désabonner. Si le désabonnement approximatif est activé et qu'une réponse de mot-clé entrante est considérée comme « approximative », Braze répondra automatiquement en demandant à l'utilisateur de confirmer son intention.
