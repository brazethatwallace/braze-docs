# Version du 15 novembre 2022 {#november-15-2022-release}

## Nouvel éditeur par glisser-déposer pour les messages in-app {#new-drag-drop-editor-for-in-app-messages}

Avec le nouvel [éditeur par glisser-déposer pour les messages in-app]({{site.baseurl}}/user_guide/channels/in_app_messages/drag_and_drop/), vous pouvez créer des messages in-app entièrement personnalisés sans avoir besoin de connaître le langage HTML. L'éditeur par glisser-déposer sera déployé pour tous les clients au cours des prochains mois. Si vous souhaitez demander l'accès plus tôt, contactez votre gestionnaire de la satisfaction client.

## Mises à jour de l'éditeur par glisser-déposer pour les e-mails {#updates-to-drag-drop-editor-for-email}

### Nouveaux blocs éditeur {#new-editor-blocks}

Deux nouveaux blocs éditeur ont été ajoutés à l'éditeur par glisser-déposer pour les e-mails : les [blocs de paragraphes]({{site.baseurl}}/user_guide/message_building_by_channel/email/drag_and_drop/dnd_editor_blocks/#paragraph) et les [blocs de listes]({{site.baseurl}}/user_guide/message_building_by_channel/email/drag_and_drop/dnd_editor_blocks/#list).

{% alert important %}
Le bloc de texte existant est désormais obsolète, mais tous les e-mails existants contenant un bloc de texte continueront d'être pris en charge.
{% endalert %}

### Aperçu en mode sombre {#dark-mode-preview}

Lorsque vous [prévisualisez et testez vos e-mails]({{site.baseurl}}/user_guide/message_building_by_channel/email/html_editor/#step-3b-preview-and-test-your-message) dans l'éditeur par glisser-déposer, vous pouvez désormais activer l'option **Dark Mode Preview** pour voir à quoi ressemble votre e-mail pour les utilisateurs en mode sombre.

## Accès anticipé à Winning Path {#winning-path-early-access}

Disponible dans le cadre des Chemins d'expérience dans Canvas, [Winning Path]({{site.baseurl}}/user_guide/engagement_tools/canvas/canvas_components/experiment_step/#step-2-turn-on-winning-path-optional) vous permet d'automatiser vos tests A/B. Lorsque Winning Path est activé, après une période définie, tous les utilisateurs suivants seront dirigés vers le chemin ayant le taux de conversion le plus élevé.

Cette fonctionnalité est actuellement disponible en accès anticipé. Si vous souhaitez participer à l'accès anticipé, contactez votre gestionnaire de la satisfaction client.

## Messages in-app et Content Cards sur tvOS {#in-app-messages-and-content-cards-on-tvos}

Ce nouvel article couvre les spécificités de l'intégration des [messages in-app et des Content Cards sur tvOS]({{site.baseurl}}/developer_guide/in_app_messages/?sdktab=tvos), disponibles via le SDK Swift de Braze.

## Nouveau cas d'utilisation Liquid {#new-liquid-use-case}

Nous avons ajouté un nouveau cas d'utilisation à la [bibliothèque de cas d'utilisation Liquid]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/liquid/liquid_use_cases/#misc-personalize-content) expliquant comment utiliser l'état d'abonnement d'un client pour personnaliser le contenu des messages. Avec ce cas d'utilisation, les clients abonnés à un groupe d'abonnement spécifique recevront un message exclusif pour les groupes d'abonnement par e-mail et par SMS.
