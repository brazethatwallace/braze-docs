# Version du 5 avril 2022 {#april-5-2022-release}

## Filtrer par attribution de Campaign ou de Canvas {#filter-by-campaign-or-canvas-attribution}
Vous pouvez désormais filtrer les utilisateurs qui ont répondu à une Campaign SMS ou une étape du Canvas spécifique, par catégorie de mot-clé ou par étiquette. Pour plus d'informations, consultez la section [Reciblage SMS]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/user_retargeting/).

## Tableau de bord des performances des e-mails {#email-performance-dashboard}
Le [tableau de bord des performances des e-mails]({{site.baseurl}}/user_guide/analytics/dashboards/) vous permet de consulter les indicateurs de performance agrégés pour l'ensemble de votre canal e-mail, qu'il s'agisse de Campaigns ou de Canvas, pour la plage de dates sélectionnée.

Pour plus d'informations sur les tableaux de bord analytiques disponibles dans Braze, consultez la section [Vos tableaux de bord analytiques]({{site.baseurl}}/user_guide/analytics/dashboards/home/).

## Paramètres de style globaux {#global-style-settings}

Découvrez les [paramètres de style globaux]({{site.baseurl}}/user_guide/channels/email/customize/email_global_style_settings/) pour l'éditeur par glisser-déposer ! Vous pouvez désormais personnaliser facilement l'apparence de vos Campaigns et Canvas d'e-mail en ajoutant un thème par défaut, en définissant le style de texte de base, et bien plus encore.

## Webhooks Braze à Braze {#braze-to-braze-webhooks}
Avec un webhook Braze à Braze, vous pouvez utiliser des webhooks pour communiquer avec la REST API de Braze, et faire tout ce que notre API vous permet de faire. Il s'agit essentiellement d'un webhook qui communique de Braze vers Braze. Pour plus d'informations, consultez notre article sur les [webhooks Braze à Braze]({{site.baseurl}}/user_guide/channels/webhooks/use_case_create_a_braze_to_braze_webhook/).

## Obsolescences {#deprecations}

### SDK Windows {#windows-sdk}
Depuis le 24 mars 2022, le [SDK Windows de Braze]({{site.baseurl}}/developer_guide/sdk_integration/initialization/?sdktab=web/) est obsolète, et aucune nouvelle application Windows ne peut être créée dans le tableau de bord de Braze.

### Intégration push Baidu {#baidu-push-integration}
Depuis le 24 mars 2022, l'[intégration Baidu Push de Braze]({{site.baseurl}}/developer_guide/platform_integration_guides/android/push_notifications/?tab=android) est obsolète, et aucune nouvelle application Baidu ne peut être créée dans le tableau de bord de Braze.

## Nouveaux partenariats Braze {#new-braze-partnerships}

### Tealium pour Currents {#tealium-for-currents}

L'intégration de Braze et [Tealium]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/tealium/tealium_for_currents/) vous permet de contrôler de façon fluide le flux d'informations entre les deux systèmes. Désormais, avec Currents, vous pouvez également connecter des données à Tealium afin de les exploiter dans l'ensemble de vos outils de croissance.
