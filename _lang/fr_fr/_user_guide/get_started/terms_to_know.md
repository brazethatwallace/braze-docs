glossary_top_header: "Termes à connaître"
glossary_top_text: "Ces termes devraient vous aider à renforcer vos relations avec vos clients et vos utilisateurs grâce à Braze. Prenez le temps de les lire avant de commencer votre onboarding."
page_type: glossary
description: "Ce glossaire couvre les termes importants à connaître lorsque vous suivez le processus d'onboarding de Braze."

glossaries:
  - name: Utilisateur actif
    description: "Pour le ciblage des Campaigns, Braze définit un <a href=\"/docs/user_guide/messaging/campaigns/ideas_and_strategies/active_user_campaigns\">utilisateur actif</a> pour une période donnée comme toute personne ayant eu une session au cours de cette période (les utilisateurs mis à jour via l'API comptent également pour cette période). Pour l'<a href=\"/docs/user_archival#active-users\">archivage utilisateur</a> et les statistiques d'accessibilité, Braze utilise une définition plus large qui inclut également les mises à jour de profil, les messages envoyés à l'utilisateur et les interactions avec les messages."
  - name: Alloys
    description: "Les Alloys sont nos <a href=\"/docs/partners/home\">partenaires technologiques</a>."
  - name: Utilisateurs anonymes
    description: "Lorsqu'un profil utilisateur est reconnu via le SDK, un profil utilisateur anonyme est créé avec l'<a href=\"/docs/api/basics#user-ids\">identifiant utilisateur Braze</a> associé."
  - name: Campagnes API
    description: "Les <a href=\"/docs/api/api_campaigns\">campagnes API</a> utilisent le tableau de bord de Braze pour générer un <code>campaign_id</code> (et des identifiants de variante) tandis que vous fournissez le contenu, l'audience, la planification et les ressources via les <a href=\"/docs/api/endpoints/messaging\">API de messagerie</a>. Elles diffèrent des <a href=\"/docs/user_guide/messaging/campaigns/schedule_your_campaign/api_triggered_delivery\">Campaigns déclenchées par API</a>, où vous déclenchez via l'API une Campaign entièrement configurée depuis le tableau de bord."
  - name: Interface de programmation d'applications (API)
    description: "L'<a href=\"/docs/api/basics#api-overview\">API de Braze</a> fournit un service Web qui vous permet d'enregistrer les actions de vos utilisateurs directement via HTTP, plutôt que par le biais des SDK mobiles. Cela vous permet, par exemple, de transmettre à Braze des données utilisateur qui ne sont pas suivies dans votre application ou votre site Web."
  - name: Instance d'application
    description: "Les instances d'application désignent les différents sites et applications rassemblés dans un espace de travail."
  - name: Braze (le produit)
    description: "Parfois appelé tableau de bord, ce produit contrôle toutes les données et interactions au cœur de la plateforme Braze. Les clients de Braze l'utilisent pour gérer les notifications, configurer des Campaigns de communication ciblées et afficher des analyses. Les développeurs l'utilisent pour gérer les paramètres d'intégration des applications, tels que les clés API et les identifiants de notifications push."
  - name: Équipe
    description: "Les administrateurs de Braze peuvent répartir un sous-ensemble d'utilisateurs du tableau de bord en <a href=\"/docs/user_guide/administer/global/user_management/teams\">équipes</a> avec différents rôles et autorisations. Cela permet aux administrateurs de Braze de limiter l'accès à certaines fonctionnalités en fonction de l'appartenance à un groupe."
  - name: Campaign
    description: "Les Campaigns sont des méthodes d'envoi de messages personnalisées permettant d'apporter une réponse personnalisée à vos clients. Vous pouvez <a href=\"/docs/user_guide/messaging/campaigns\">créer des Campaigns</a> en utilisant différents canaux de communication pour envoyer vos messages uniques."
  - name: Canvas
    description: "<a href=\"/docs/user_guide/messaging/canvas\">Canvas</a> est une interface unifiée où les marketeurs peuvent implémenter des Campaigns avec plusieurs messages et étapes pour former un parcours cohérent. Canvas vous permet de comparer et d'optimiser ces expériences à l'aide d'analyses complètes pour l'ensemble de l'expérience utilisateur."
  - name: Contenu connecté
    description: "Le <a href=\"/docs/user_guide/messaging/design_and_edit/personalize/connected_content\">contenu connecté</a> développe la personnalisation marketing pour stimuler l'engagement client et les conversions. Vous pouvez insérer toute information accessible via l'API directement dans les messages que vous envoyez aux utilisateurs. Le contenu connecté permet d'extraire du contenu directement à partir de votre serveur Web ou des API accessibles au public."
  - name: Content Cards
    description: "Les <a href=\"/docs/user_guide/channels/content_cards\">Content Cards</a> vous permettent d'envoyer un flux dynamique et hautement ciblé de contenus riches à vos clients, directement dans les applications qu'ils aiment, sans interrompre leur expérience. Les Content Cards peuvent être envoyées aux utilisateurs iOS, Android et Web."
  - name: Événement de conversion
    description: "Un <a href=\"/docs/user_guide/messaging/messaging_fundamentals/conversion_events\">événement de conversion</a> est un indicateur de réussite qui enregistre si un destinataire a effectué une action à forte valeur dans une fenêtre de conversion après avoir reçu votre message (ou après être entré dans un Canvas ou un groupe de contrôle, selon le canal et la configuration). Utilisez les événements de conversion pour mesurer les performances des Campaigns et des Canvas au-delà des simples envois."
  - name: Currents
    description: "<a href=\"/docs/user_guide/data/distribution/braze_currents\">Currents</a>, notre exportation de flux de données, est inclus dans certains forfaits Braze. Braze Currents vous permet de vous intégrer via Data Storage à l'aide de fichiers plats, ou avec nos partenaires Behavioral Analytics et Customer Data, en utilisant des payloads JSON en batch vers un endpoint désigné."
  - name: Attributs personnalisés
    description: "Les <a href=\"/docs/user_guide/data/activation/attributes/custom_attributes\">attributs personnalisés</a> sont une collection de caractéristiques uniques de vos utilisateurs. Ils sont les plus appropriés pour stocker des attributs sur vos utilisateurs ou des informations sur les actions à faible valeur dans votre application. Vous pouvez attribuer des attributs personnalisés aux utilisateurs dans le tableau de bord. Vous pouvez filtrer et segmenter vos utilisateurs selon ces attributs pour les Campaigns <a href=\"/docs/developer_guide/analytics/setting_user_attributes?sdktab=swift\">Swift</a> et <a href=\"/docs/developer_guide/analytics/setting_user_attributes?sdktab=android\">Android</a>."
  - name: Événements personnalisés
    description: "Les <a href=\"/docs/user_guide/data/activation/events/custom_events\">événements personnalisés</a> sont des actions effectuées par vos utilisateurs ; ils sont particulièrement adaptés au suivi des interactions de grande valeur entre les utilisateurs et votre application."
  - name: Point de donnée
    description: "Un point de donnée est comptabilisé lorsqu'un <a href=\"/docs/user_guide/data/activation/attributes/custom_attributes\">attribut personnalisé</a> est défini ou mis à jour (même si vous le mettez à jour avec la même valeur), lorsqu'un <a href=\"/docs/user_guide/data/activation/events/custom_events\">événement personnalisé</a> ou un événement d'achat est enregistré, lorsqu'une donnée standard (par exemple, <code>email</code>, <code>first_name</code>, <code>last_name</code>, <code>country</code> ou <code>home_city</code>) est enregistrée, lorsqu'une session commence et lorsqu'elle se termine."
  - name: Création de liens profonds
    description: "Les <a href=\"/docs/user_guide/messaging/design_and_edit/personalize/actions_and_media_urls\">liens profonds</a> sont utilisés pour orienter les clients vers leur prochaine action ou interaction. Grâce aux liens profonds, vous pouvez connecter un message à un contenu ciblé au sein d'un site Web ou d'une application mobile."
  - name: Utilisateurs dormants
    description: "Un utilisateur est considéré comme <a href=\"/docs/user_archival#dormant-users\">dormant</a> lorsqu'il n'a eu aucune activité qualifiante au cours des douze derniers mois : il n'a utilisé aucune application ni aucun site Web dans l'espace de travail, n'a reçu aucun message de l'espace de travail et n'a pas été mis à jour depuis plus de douze mois. Par défaut, Braze utilise une fenêtre de douze mois pour l'archivage des utilisateurs dormants ; les paramètres de votre entreprise peuvent modifier le nombre de jours."
  - name: Endpoint
    description: "Une extrémité d'un canal de communication, également connue sous le nom d'<a href=\"/docs/api/endpoints\">endpoint</a> API, est utilisée dans l'API de communication de Braze pour l'envoi et la planification des messages."
  - name: Événement d'exception
    description: "Dans Canvas, les <a href=\"/docs/user_guide/messaging/canvas/create_a_canvas/exit_criteria#exception-events\">événements d'exception</a> sont des actions spécifiques qui retirent un utilisateur du parcours lorsqu'elles se produisent (par exemple, passer une commande). Ils permettent de garder les messages de suivi pertinents une fois que l'utilisateur a atteint votre objectif. Consultez les <a href=\"/docs/user_guide/messaging/canvas/create_a_canvas/exit_criteria\">critères de sortie</a> pour comprendre comment les sorties sont évaluées et planifiées."
  - name: ID externe
    description: "L'<code>external_id</code> est l'identifiant utilisateur principal d'un profil utilisateur Braze. Il relie la même personne à travers les canaux et les appareils lorsque vous attribuez des identifiants depuis vos propres systèmes. Les profils anonymes peuvent ne pas avoir d'<code>external_id</code> tant que vous n'avez pas identifié l'utilisateur. Pour en savoir plus, consultez <a href=\"/docs/user_guide/get_started/users_and_segments\">Utilisateurs et segments</a> et <a href=\"/docs/api/basics#user-ids\">ID utilisateur</a>."
  - name: Limite de fréquence
    description: "La <a href=\"/docs/user_guide/messaging/messaging_fundamentals/frequency_capping\">limite de fréquence</a> vous permet de gérer la communication sans surcharger votre audience. Il s'agit d'une limite automatisée des messages visant à empêcher les utilisateurs de recevoir trop de communications dans un court laps de temps."
  - name: HIPAA
    description: "HIPAA est l'acronyme de Health Insurance Portability and Accountability Act (loi sur la portabilité et la responsabilité en matière d'assurance maladie). Braze est <a href=\"/docs/developer_guide/disclosures/security_qualifications#hipaa\">conforme à la loi HIPAA</a>. Les exigences HIPAA impliquent la sécurité administrative, physique et technique."
  - name: Message in-app
    description: "Les <a href=\"/docs/user_guide/channels/in_app_messages\">messages in-app</a> sont des messages mobiles qui apparaissent dans votre application. Ils vous aident à fournir du contenu à votre utilisateur sans interrompre sa journée avec une notification push. Des messages in-app personnalisés et adaptés améliorent l'expérience utilisateur et aident votre audience à tirer le meilleur parti de votre application."
  - name: Utilisateurs inactifs
    description: "Un utilisateur est considéré comme <a href=\"/docs/user_archival#inactive-users\">inactif</a> lorsqu'il n'est plus joignable sur les principaux canaux de communication (par exemple, e-mail, SMS, push, WhatsApp et LINE selon votre configuration), n'a utilisé aucune application ni aucun site Web dans l'espace de travail depuis plus de six mois, n'a reçu aucun message de l'espace de travail depuis plus de six mois et n'a pas été mis à jour depuis plus de six mois. Les utilisateurs inactifs sont candidats à l'archivage, tout comme les utilisateurs dormants. Par défaut, Braze utilise une fenêtre de six mois pour l'archivage des utilisateurs inactifs ; les paramètres de votre entreprise peuvent modifier le nombre de jours."
  - name: Réchauffement d'adresses IP
    description: "Le <a href=\"/docs/user_guide/channels/email/email_setup/ip_warming\">réchauffement d'adresses IP</a> consiste à augmenter progressivement la quantité de courrier envoyé à partir d'une adresse IP dédiée. Cela permet d'établir une réputation auprès des fournisseurs de services Internet et de minimiser la probabilité que vos messages soient signalés."
  - name: Paires clé-valeur
    description: "Les <a href=\"/docs/user_guide/messaging/design_and_edit/personalize/sources/key_value_pairs\">paires clé-valeur</a> sont des données liées où la clé est un identifiant unique et la valeur est le contenu. Elles peuvent être utilisées pour envoyer des payloads de données supplémentaires aux appareils des utilisateurs."
  - name: Liquid
    description: "Liquid est un langage de template couramment utilisé et orienté client, créé par Shopify et écrit en Ruby. <a href=\"/docs/user_guide/messaging/design_and_edit/personalize/liquid\">Liquid</a> est utilisé pour charger et extraire du contenu dynamique. Liquid vous permet d'utiliser des objets, des balises et des filtres pour <a href=\"/docs/user_guide/messaging/design_and_edit/personalize/liquid/supported_personalization_tags\">ajouter une personnalisation</a>."
  - name: Canal de communication
    description: "Les <a href=\"/docs/user_guide/channels\">canaux de communication</a> vous permettent de communiquer virtuellement avec vos clients via des notifications push sur leur téléphone ou navigateur Web, des e-mails, des messages in-app et bien plus encore !"
  - name: Utilisateur actif par mois (MAU)
    description: "Il s'agit des utilisateurs qui ont eu une session au cours des 30 derniers jours."
  - name: Communication multicanale
    description: "Envoyer un message à un utilisateur sur différents supports, comme une combinaison d'e-mails, de notifications push Web et de notifications push mobiles. Il est préférable d'utiliser les <a href=\"/docs/developer_guide/getting_started/platform_overview#multichannel-messaging\">canaux de communication</a> de manière conjointe et régulière afin de réengager les utilisateurs perdus, fidéliser les utilisateurs actifs et dynamiser les ambassadeurs de votre marque."
  - name: Test multivarié
    description: "Le <a href=\"/docs/user_guide/messaging/ab_testing\">test A/B</a> compare un ensemble restreint de versions de messages ; le <a href=\"/docs/user_guide/messaging/ab_testing/create_tests\">test multivarié</a> compare plusieurs variables simultanément pour déterminer quelle combinaison obtient les meilleurs résultats. Vous pouvez configurer les deux depuis le tableau de bord pour les types de Campaigns pris en charge."
  - name: Nouvel utilisateur
    description: "Braze considère un nouvel utilisateur comme toute personne qui a récemment installé votre application. Un nouvel utilisateur peut également être défini comme un utilisateur avec un ID utilisateur qui n'a pas été identifié auparavant dans Braze."
  - name: Personnalisation
    description: "Utiliser la technologie pour prendre en compte les préférences et les tendances individuelles de chaque utilisateur lors de la communication avec eux. L'<a href=\"/docs/user_guide/messaging/design_and_edit/personalize\">envoi de messages personnalisés</a> aide à créer des expériences client précieuses en s'adaptant à leurs préférences."
  - name: Notification push
    description: "Une <a href=\"/docs/user_guide/channels/push\">notification push</a> est une notification qui s'affiche depuis une application mobile. Les notifications push s'affichent souvent sous forme de boîtes de dialogue contextuelles et de bannières pour iOS et Android."
  - name: Jeton de notification push
    description: "Un jeton de notification push est une clé unique, créée et attribuée par Apple ou Google pour créer une connexion entre une application et un appareil iOS, Android ou Web. La <a href=\"/docs/api/objects_filters/user_attributes_object#migrate-push-tokens\">migration des jetons de notification push</a> consiste à importer ces clés déjà générées dans Braze."
  - name: Durée de vie des notifications push (TTL)
    description: "Également connue sous le nom de <a href=\"/docs/user_guide/administer/global/workspace_settings/push_settings\">TTL des notifications push</a>, la durée de vie désigne la période pendant laquelle les Campaigns continueront à tenter d'être livrées à un utilisateur hors ligne."
  - name: Condition de concurrence
    description: "Une <a href=\"/docs/user_guide/messaging/ab_testing/concepts/race_conditions\">condition de concurrence</a> est un concept d'ingénierie logicielle qui décrit une situation indésirable survenant lorsqu'un système essaie d'effectuer plusieurs opérations simultanément, mais en raison de la nature du système, les opérations doivent être effectuées dans la séquence correcte pour aboutir correctement. <br><br>Dans la plateforme Braze, segmenter une Campaign déclenchée sur la base des données utilisateur enregistrées au moment de l'événement peut entraîner une condition de concurrence. Cela se produit lorsqu'un changement dans l'attribut utilisateur sur lequel la Campaign est segmentée n'a pas encore été traité pour l'utilisateur au moment où l'appartenance au segment est déterminée et que la Campaign est envoyée, ce qui peut conduire à la non-réception de la Campaign par l'utilisateur."
  - name: Limitation du débit
    description: "La <a href=\"/docs/user_guide/messaging/messaging_fundamentals/frequency_capping\">limitation du débit</a> contrôle la vitesse à laquelle les messages quittent Braze (par exemple, la vitesse de distribution par minute ou les limites centrées sur l'utilisateur à l'aide de filtres de segment). Elle fonctionne conjointement avec la limite de fréquence sur la même page, qui limite le nombre de messages qu'un utilisateur reçoit dans une fenêtre de temps."
  - name: Segmentation
    description: "La <a href=\"/docs/user_guide/audience/segments\">segmentation</a> du tableau de bord vous permet de créer des groupes ou des extensions d'utilisateurs en fonction de filtres puissants portant sur leur comportement in-app, leurs données démographiques et plus encore."
  - name: Kit de développement logiciel (SDK)
    description: "Les <a href=\"/docs/developer_guide/getting_started/sdk_overview\">SDK</a> sont intégrés à vos applications mobiles, sites Web et expériences connectées, et fournissent des outils de marketing, de messagerie et d'analyse. Braze publie des guides d'intégration SDK pour des plateformes telles que <a href=\"/docs/developer_guide/sdk_integration?sdktab=swift\">Swift</a> et <a href=\"/docs/developer_guide/sdk_integration?sdktab=android\">Android</a> ; pour le Web et les autres plateformes, suivez les parcours d'intégration liés depuis l'aperçu du SDK."
  - name: Groupes d'abonnement
    description: "Les <a href=\"/docs/user_guide/channels/email/subscriptions#subscription-groups\">groupes d'abonnement</a> se superposent aux états d'abonnement globaux afin de vous permettre d'offrir des choix d'abonnement granulaires (par exemple, newsletters versus promotions). Des modèles similaires existent pour des canaux tels que le SMS et WhatsApp ; ciblez toujours un groupe d'abonnement lorsque votre canal l'exige."
  - name: Temporisation
    description: "La temporisation désigne le processus d'identification des utilisateurs désengagés et de cessation de l'envoi actif de messages à ces utilisateurs sans qu'ils aient à prendre de mesures. Créer des politiques de temporisation pour vos messages <a href=\"/docs/user_guide/channels/email/best_practices/sunset_policies\">e-mail</a> et de <a href=\"/docs/user_guide/channels/push/best_practices#implement-a-sunset-policy-for-unresponsive-users\">notification push</a> peut aider à réduire les impacts sur vos taux d'ouverture."
  - name: Étiquette
    description: "Les <a href=\"/docs/user_guide/administer/global/workspace_settings/tags\">étiquettes</a> sont un outil qui vous aide à catégoriser, organiser et trier votre engagement dans une ou plusieurs Campaigns."
  - name: Alias d'utilisateur
    description: "Les <a href=\"/docs/user_guide/data/unification/user_data/user_profile_lifecycle/anonymous_users#assigning-user-aliases\">alias d'utilisateur</a> sont des identifiants alternatifs que vous pouvez attribuer à des profils anonymes avant qu'un <code>external_id</code> n'existe, afin de pouvoir référencer la même personne sur différents appareils ou canaux jusqu'à ce qu'elle se connecte."
  - name: Archivage utilisateur
    description: "L'<a href=\"/docs/user_archival\">archivage utilisateur</a> désigne les utilisateurs qui ont été archivés. Chez Braze, cela inclut les utilisateurs inactifs et dormants. L'archivage évalue les règles d'inactivité et de dormance dans les services Braze (consultez la page Archivage utilisateur pour la planification, l'éligibilité de l'espace de travail comme les seuils de nombre d'utilisateurs, et la personnalisation des fenêtres via les paramètres de l'entreprise ou Canvas)."
  - name: Profil utilisateur
    description: "Un <a href=\"/docs/user_guide/audience/manage_audience/user_profiles\">profil utilisateur</a> est l'enregistrement central de chaque personne dans Braze, comprenant les identifiants, les attributs, les événements, les achats, les appareils, l'historique d'engagement et l'historique des messages. Les profils alimentent la segmentation, la personnalisation et les workflows de conformité sur l'ensemble des canaux."
  - name: Webhook
    description: "Les <a href=\"/docs/user_guide/channels/webhooks\">webhooks</a> vous permettent de déclencher des actions hors application telles que la livraison de SMS. Vous pouvez utiliser des webhooks pour fournir à d'autres systèmes et applications des informations en temps réel. La flexibilité de cette fonctionnalité vous permet d'envoyer des informations à n'importe quel endpoint."
  - name: Espace de travail
    description: "Un <a href=\"/docs/user_guide/get_started/workspaces\">espace de travail</a> est le conteneur dans lequel Braze stocke les données et où votre équipe crée des Campaigns, des Canvas et des segments. Chaque espace de travail contient une ou plusieurs <a href=\"/docs/user_guide/get_started/workspaces#understanding-workspaces\">instances d'application</a> (les applications et sites individuels qui envoient des données dans cet espace de travail)."
