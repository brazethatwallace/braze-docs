## Onboarding {#onboarding}

Imaginons que votre restaurant souhaite accompagner les nouveaux utilisateurs pour qu'ils effectuent leur première réservation. Comme ce Canvas est uniquement destiné à l'onboarding, le moment idéal pour le lancer serait au début de session pour tous les nouveaux clients. Pour atteindre rapidement et efficacement votre audience de convives, vous pouvez utiliser le canal de communication SMS.

![Capture d'écran liée à l'onboarding.]({% image_buster /assets/img_archive/canvas_outline_onboarding.png %}){: style="max-width:90%;"}

### Montée en gamme {#upsell}

Encourager la montée en gamme de vos abonnements est également possible en créant et en envoyant des Canvas efficaces. Par exemple, si vous souhaitez inciter les utilisateurs actifs de la version gratuite de votre application à passer à un forfait supérieur, vous pouvez créer un Canvas basé sur une action qui se déclenche lorsqu'un client atteint l'événement personnalisé « 3 heures de streaming ». À l'aide d'une étape de message, vous pouvez inviter ces clients à s'inscrire à vos abonnements premium.

### Paniers abandonnés {#abandoned-carts}

Les entreprises de vente au détail ont souvent besoin de rappeler à leurs clients qu'ils ont des achats en attente. Avec un Canvas basé sur une action, vous pouvez envoyer un rappel à tous les clients enregistrés pour les inciter à finaliser les articles dans leur panier abandonné. Vous pouvez également tester la réceptivité de vos clients à vos messages en variant les délais d'envoi.

![Capture d'écran liée aux paniers abandonnés.]({% image_buster /assets/img_archive/canvas_outline_cart.png %}){: style="max-width:90%;"}

### Ressources pour les clients {#customer-resources}

Vous pouvez utiliser Canvas pour informer vos clients sur les ressources disponibles. Par exemple, pour une compagnie aérienne, vous pouvez créer un Canvas qui prépare les clients ayant réservé un voyage dans trois jours en programmant un e-mail hebdomadaire contenant les informations de leur vol et une FAQ sur l'aéroport concerné.
