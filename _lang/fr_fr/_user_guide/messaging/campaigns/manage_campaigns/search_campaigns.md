# Rechercher des campagnes {#search-for-campaigns}

> À mesure que vous créez des campagnes dans votre espace de travail, vous pouvez ajuster les filtres et les colonnes de la liste des campagnes pour trier et organiser ces campagnes. En combinant ces méthodes de recherche, vous pouvez affiner vos résultats, surtout lorsque votre liste de campagnes s'allonge.

Il existe plusieurs façons de rechercher des campagnes sur la page de liste des campagnes en sélectionnant :

- État
- Étiquettes
- Filtres
- Colonnes

Vous pouvez utiliser la barre de recherche pour saisir des mots-clés et des expressions liés au nom de votre campagne. Pour effectuer une recherche exacte, utilisez des guillemets ("") autour de votre expression de recherche. Par exemple, pour rechercher spécifiquement des campagnes de test webhook, saisissez `"webhook test"` dans la barre de recherche.

## Sélectionner un état {#selecting-a-status}

Par défaut, la liste des campagnes affiche vos campagnes actives et inactives. Vous pouvez sélectionner le menu déroulant pour afficher les campagnes selon leur état (actif, brouillon, archivé, arrêté et inactif).

Par exemple, si vous souhaitez examiner vos brouillons de campagne, sélectionnez **État** > **Brouillon** pour filtrer votre liste de campagnes.

### Rechercher par étiquettes {#searching-by-tags}

Rechercher vos campagnes par [étiquettes]({{site.baseurl}}/user_guide/administer/global/workspace_settings/tags) peut affiner davantage vos résultats. Par exemple, si vous cherchez toutes les campagnes que vous avez créées pour cibler de nouveaux clients, des acheteurs fréquents ou des clients inactifs, vous pourriez rechercher ces campagnes par leur étiquette commune **Ciblage par type de client**.

### Ajuster les filtres {#adjusting-filters}

Utilisez les filtres pour regrouper les résultats selon les détails de campagne suivants :

- Type de campagne
- Qui a créé la campagne
- Qui a modifié la campagne en dernier
- Planification d'entrée
- Segment cible
- Équipes
- Campagnes dont les données d'interaction ont expiré

Vous pouvez également effectuer une recherche en sélectionnant la plage de dates de création ou de dernière modification de la campagne. Cela peut être particulièrement utile si vous recherchez des campagnes utilisées lors d'une période promotionnelle.

### Organiser les colonnes {#organizing-columns}

Lorsque vous sélectionnez **Colonnes**, vous pouvez ajuster les informations de la page de liste des campagnes pour afficher les détails pertinents en cochant les cases correspondantes. Par exemple, si vous souhaitez configurer la liste des campagnes pour afficher uniquement les campagnes webhook basées sur une action de votre équipe marketing, vous pouvez sélectionner **Type de campagne**, **Planification d'entrée** et **Équipes** comme colonnes.
