# Calendrier de contenu {#content-calendar}

> Le calendrier de contenu offre un aperçu général de vos prochaines campagnes planifiées.

Vous pouvez analyser les données d'envoi de messages, ainsi que consulter et gérer vos campagnes planifiées. Pour ouvrir le calendrier, sélectionnez **Contenu** > **Calendrier de contenu**.

## Analyse des messages {#messaging-analytics}

La section d'analyse des messages contient deux rapports pour vos Campaigns planifiées récentes et à venir :

- **Types de messages à venir :** Le nombre de Campaigns de notification push, d'e-mail et de messages in-app planifiées dans les 14 prochains jours.
- **Messages envoyés :** Le nombre de messages envoyés et ouverts au cours des 14 derniers jours.

Consultez l'analyse des messages pour un jour spécifique dans un rapport en plaçant votre curseur sur ce jour.

![Les graphiques « Types de messages à venir » et « Messages envoyés » dans la section Analyse des messages.]({% image_buster /assets/img/campaign_calendar/content_calendar_messaging_analytics.png %})

Pour télécharger une copie de vos données, sélectionnez <i class="fa-solid fa-bars" style="color: #2e7487;" aria-hidden="true" aria-label="Menu contextuel du graphique"></i> **Menu contextuel du graphique**, puis choisissez le format de fichier souhaité.

## Calendrier d'envoi {#send-calendar}

Le calendrier d'envoi affiche les Campaigns planifiées pour le mois en cours. Les Canvas, les Campaigns basées sur une action et les Campaigns déclenchées par API ne sont pas inclus.

Les Campaigns sont identifiées par un code couleur selon leur type dans la **Légende** :

- Le bleu indique les Campaigns multicanales.
- Le violet indique les Campaigns multivariées.
- Le gris indique les Campaigns désactivées.

{% alert note %}
Les In-App Messages sont toujours basés sur une action, ils n'apparaissent donc pas dans le calendrier d'envoi.
{% endalert %}

Changez de mois en sélectionnant <i class="fa-solid fa-chevron-left" style="color: #2e7487;" aria-hidden="true"></i> **Voir le mois précédent** ou <i class="fa-solid fa-chevron-right" style="color: #2e7487;" aria-hidden="true"></i> **Voir le mois suivant**. Pour revenir au mois en cours, sélectionnez **Today**.

![Le calendrier d'envoi affichant toutes les Campaigns planifiées pour le mois en cours.]({% image_buster /assets/img/campaign_calendar/content_calendar_sends.png %})

Consultez ou modifiez vos Campaigns en sélectionnant la Campaign dans le calendrier. Pour plus d'informations, consultez [Gérer les Campaigns]({{site.baseurl}}/user_guide/messaging/campaigns/manage_campaigns).
