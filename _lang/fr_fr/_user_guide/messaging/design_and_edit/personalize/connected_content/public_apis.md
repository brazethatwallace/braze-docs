# Utiliser des API publiques pour le Contenu connecté {#use-public-apis-for-connected-content}

> Il existe une grande variété d'API publiquement disponibles pouvant être utilisées pour le Contenu connecté. Les API publiques vous permettent d'insérer des données personnalisées dans vos messages. Cette page compile une liste d'API publiques qui pourraient être utilisées pour le Contenu connecté. Cependant, il en existe bien d'autres, offrant un large éventail d'utilisations potentielles du Contenu connecté.

Contactez-nous à [success@braze.com](mailto:success@braze.com) pour nous faire savoir si vous avez une API à partager !

{% alert note %}
Les API publiques peuvent être soumises à des restrictions d'utilisation et à des limites de débit. Assurez-vous de lire la documentation des API et de contacter les fournisseurs d'API concernant l'utilisation que vous prévoyez d'en faire.
{% endalert %}

|	 API 	| Description |
| --------- | --- |
| [OpenWeatherMap](http://openweathermap.org/api) | Fournit des données météorologiques actuelles, des prévisions à 5 et 16 jours, ainsi que des données historiques. |
| [NYT Article Search](https://developer.nytimes.com/docs/articlesearch-product/1/overview) | Fournit des données d'articles du NYT, incluant le titre, le sujet, l'URL, la date, le résumé, etc. |
| [The Guardian API](http://open-platform.theguardian.com/documentation/) | Fournit des données d'articles du Guardian, incluant le titre, le sujet, l'URL, la date, le résumé, etc. |
