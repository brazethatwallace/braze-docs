guide_top_text: "Le Contenu connecté de Braze étend la personnalisation marketing pour renforcer l'engagement client et les conversions. Cette fonctionnalité vous permet d'insérer toute information accessible via API directement dans les messages que vous envoyez aux utilisateurs. Le Contenu connecté permet de récupérer du contenu directement depuis votre serveur web ou depuis des API accessibles publiquement. Vous pouvez également utiliser nos capacités de Contenu connecté avec nos partenaires technologiques, comme <b><a href='/docs/partners/data_augmentation/contextual_location/accuweather'>AccuWeather</a></b> et <b><a href='/docs/partners/channel_extensions/localization/transifex'>Transifex</a></b>.<br><br>En plus des articles listés ci-dessous, nous vous recommandons de consulter notre cours d'apprentissage <b><a href='https://learning.braze.com/connected-content'>Contenu connecté</a></b> sur Braze Learning."
