# BrazeAI Decisioning Studio™ Go

> Découvrez comment configurer et intégrer BrazeAI Decisioning Studio™ Go dans Braze.

{% alert important %}
Mi-2026, une nouvelle version de Decisioning Studio™ Go sera disponible en libre-service depuis le tableau de bord de Braze. L'article suivant s'applique à la version héritée, qui sera à terme abandonnée.
{% endalert %}

## À propos de Decisioning Studio Go {#about-decisioning-studio-go}

Decisioning Studio Go comprend une configuration créative en libre-service avec une banque d'actions limitée, des fonctionnalités client basées uniquement sur l'engagement, une optimisation sur les clics, et n'est compatible qu'avec les plateformes d'engagement client (CEP) suivantes :

* Braze
* Salesforce Marketing Cloud

Pour en savoir plus sur les différences entre Decisioning Studio Go et Decisioning Studio Pro, consultez [Decisioning Studio Go par rapport à Decisioning Studio Pro]({{site.baseurl}}/user_guide/brazeai/decisioning_studio/#decisioning-studio-go-vs-decisioning-studio-pro).
