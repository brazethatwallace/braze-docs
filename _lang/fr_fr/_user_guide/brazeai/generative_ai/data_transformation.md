# Générer du code de transformation des données {#generate-data-transformation-code}

> Générez du code de transformation dans l'éditeur de Transformation des données à l'aide d'Operator. Décrivez comment mapper un payload de webhook entrant vers des requêtes valides de l'API Braze, et Operator rédige le code pour que vous puissiez le vérifier.
