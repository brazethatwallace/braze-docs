# Vérification du contenu avec Operator {#content-review-with-operator}

> Détectez les fautes d'orthographe, les problèmes de grammaire, le ton inapproprié ou le langage offensant dans le contenu de vos messages avant l'envoi.

{% multi_lang_include brazeai/generative_ai/unification_note.md %}

## Comment y accéder {#how-to-access}

Dans l'onglet **Test** pour les SMS, les notifications push Android, les notifications push iOS et les messages in-app traditionnels, sélectionnez **Review with Operator** pour vérifier votre contenu avant l'envoi. Operator détecte les fautes d'orthographe et de grammaire, le ton inapproprié ou hors marque, le langage offensant, ainsi que le code résiduel ou le Liquid non rendu. Chaque problème est signalé avec le texte concerné et une suggestion de correction, ou bien le contenu est confirmé comme étant conforme.


Pour plus d'informations, y compris les fonctionnalités prises en charge, les bonnes pratiques et des exemples de prompts, consultez [Vérifier la qualité du contenu dans les capacités d'Operator]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#review-content-quality).
