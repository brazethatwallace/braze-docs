# Résolution des problèmes de BrazeAI Operator {#troubleshooting-brazeai-operator}

> Problèmes courants et solutions pour BrazeAI Operator<sup>TM</sup>.

## Problèmes courants {#common-issues}

| Problème | Résolution des problèmes |
| --- | --- |
| Pas de réponse | Essayez d'actualiser la page et de rouvrir le panneau Operator. |
| Réponses hors sujet | Reformulez la question de manière plus spécifique. Mentionnez la fonctionnalité ou le flux de travail concerné. |
| Messages d'erreur | Si Operator ne peut pas diffuser le contenu, une invite « Réessayer » peut apparaître. Operator peut être temporairement indisponible ou la connexion a été interrompue. Réessayez après quelques minutes. |
| Limite quotidienne atteinte | La limite d'utilisation quotidienne à l'échelle de l'entreprise a été atteinte. Toutes les actions d'Operator sont comptabilisées dans cette limite. Attendez que la limite se réinitialise (toutes les 24 heures). Vous pouvez toujours soumettre un ticket d'assistance via le formulaire web. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Problèmes courants" }

Pour savoir ce qu'Operator peut et ne peut pas faire dans le tableau de bord, consultez [Limitations]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#limitations).
