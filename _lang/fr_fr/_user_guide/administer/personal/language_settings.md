# Paramètres de langue {#language-settings}

> Cet article décrit comment changer la langue d'affichage du tableau de bord de Braze.

## Modifier les paramètres de langue de votre tableau de bord {#change-your-dashboard-language-settings}

Le tableau de bord de Braze est disponible en [plusieurs langues](#supported-languages). Vous pouvez changer la langue d'affichage à tout moment selon vos préférences.

1. Dans l'en-tête global, sélectionnez <i class="fa-solid fa-globe" aria-label="Sélectionnez votre langue"></i>.
2. Choisissez votre langue dans la liste.

![Anglais sélectionné pour la langue du tableau de bord de Braze.]({% image_buster /assets/img_archive/language_dashboard.png %}){: style="max-width:40%"}

Le rechargement du tableau de bord peut prendre quelques instants.

### Langues prises en charge {#supported-languages}

Vous pouvez choisir parmi les langues prises en charge suivantes :

- Allemand (Deutsch)
- Anglais (English)
- Espagnol (Espa&ntilde;ol)
- Français
- Japonais (日本語)
- Coréen (한국어)
- Portugais (Brasil)
