# Anthropic

> [Anthropic](https://www.anthropic.com/) est une entreprise de sécurité et de recherche en intelligence artificielle qui développe Claude, un assistant d'intelligence artificielle de nouvelle génération conçu pour être utile, honnête et sûr pour un large éventail de tâches langagières.

{% multi_lang_include alerts/important_alerts.md alert='Braze Agents' %}

_Cette intégration est maintenue par Anthropic._

## À propos de l'intégration {#about-the-integration}

L'intégration de Braze et Anthropic vous permet de connecter votre clé API Anthropic à Braze afin d'utiliser les modèles Claude lorsque vous créez des agents d'intelligence artificielle personnalisés. Grâce à cette intégration, vos agents peuvent générer des textes personnalisés, prendre des décisions en temps réel ou mettre à jour les champs du Catalogue en utilisant les modèles Claude d'Anthropic.

## Conditions préalables {#prerequisites}

| Exigences | Description |
|---|---|
| Compte Anthropic avec clé API | Un compte Anthropic avec une clé API. Pour obtenir de l'aide, contactez votre administrateur ou l'[assistance Anthropic](https://support.anthropic.com/). |
| Instance de Braze | Vous pouvez trouver votre instance Braze sur la [page d'aperçu de l'API]({{site.baseurl}}/api/basics/#endpoints) ou auprès de votre gestionnaire d'onboarding Braze. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Conditions préalables" }

## Intégration {#integration}

Pour connecter votre clé API Anthropic à Braze :

1. Accédez à **Intégrations partenaires** > **Partenaires technologiques** dans le tableau de bord de Braze et recherchez Anthropic.
2. Saisissez votre clé API Anthropic.
3. Sélectionnez **Enregistrer**.

Après l'enregistrement, vous pouvez sélectionner les modèles Claude lors de la [création d'un agent personnalisé]({{site.baseurl}}/user_guide/brazeai/agents/creating_agents/) dans la Console des agents.

Contactez l'[assistance Anthropic](https://support.anthropic.com/) pour tout problème ou toute question concernant votre intégration.
