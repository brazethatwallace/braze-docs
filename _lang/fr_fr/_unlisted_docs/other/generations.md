# Générations de messages in-app {#in-app-messages-generations}

Braze dispose actuellement de trois générations de messages in-app. Chacune offre son propre niveau de prise en charge. Pour profiter des fonctionnalités les plus récentes de nos messages in-app, nous vous recommandons de mettre à jour vers les dernières versions des SDK [web]({{site.baseurl}}/developer_guide/platform_integration_guides/web/initial_sdk_setup/#upgrading-the-sdk), iOS et Android.

Ce tableau met en évidence les fonctionnalités et les types de messages actuellement disponibles, ainsi que la génération dans laquelle ils ont été introduits. Il indique également explicitement ce qui n'est pas pris en charge dans une génération donnée.

| Génération | Nouvelles fonctionnalités | Fonctionnalités non prises en charge |
|---|---|---|
| **Génération 1** | • Types de messages déclenchés in-app : plein écran, fenêtre modale et contextuel | Messages HTML personnalisés <br> • Formulaire de capture d'e-mail web <br> • Fenêtre modale web avec CSS personnalisé |
| **Génération 2** | • Contrôles d'alignement du texte <br> • Superposition derrière la fenêtre modale <br> • Zone de sécurité d'image dans la fenêtre de prévisualisation | Bordure de bouton |
| **Génération 3** | • Bordure de bouton <br> • Apparence affinée pour tous les types de messages <br> • Concept de générations 1, 2 et 3 <br> • Nouvelle ressource de fermeture X <br> • Accessibilité améliorée sur le web <br> • Prise en charge améliorée sur les appareils à encoche | (La dernière génération offre toujours une prise en charge complète des fonctionnalités !) |
