# Éditeur HTML mis à jour pour les e-mails {#updated-html-editor-for-email}

> L'éditeur HTML mis à jour pour les e-mails propose une série d'améliorations de l'interface utilisateur, notamment une meilleure expérience d'édition de code.

## Avantages {#benefits}

L'éditeur HTML mis à jour offre une expérience cohérente avec nos éditeurs dans les autres canaux de communication. Vous pouvez passer de façon fluide d'un éditeur à l'autre (HTML, classique, texte brut et AMP) grâce à la navigation en haut de l'éditeur. Ces options étaient auparavant masquées dans un menu déroulant dans l'ancien éditeur HTML.

Les avantages incluent également une prise en charge améliorée de la syntaxe Liquid et la [prise en charge des paramètres multilingues](https://www.braze.com/docs/user_guide/administrative/app_settings/multi_language_settings).

La gestion des liens est également prise en charge dans l'éditeur HTML mis à jour, même si vous n'avez pas activé l'[aliasage de lien](https://www.braze.com/docs/user_guide/message_building_by_channel/email/templates/link_aliasing/).
