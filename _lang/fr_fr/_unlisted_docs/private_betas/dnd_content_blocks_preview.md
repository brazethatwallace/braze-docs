# Prévisualiser les Content Blocks de l'éditeur par glisser-déposer {#preview-drag-and-drop-editor-content-blocks}

Après avoir créé vos [Content Blocks pour vos campagnes d'e-mail par glisser-déposer]({{site.baseurl}}/user_guide/message_building_by_channel/email/drag_and_drop/dnd_content_blocks/), vous pouvez consulter votre bibliothèque de Content Blocks dans l'éditeur par glisser-déposer.

{% alert important %}
Cette fonctionnalité de prévisualisation des Content Blocks par glisser-déposer est actuellement en accès anticipé. Contactez votre gestionnaire de compte Braze si vous souhaitez participer à l'accès anticipé.
{% endalert %}

Pour prévisualiser vos Content Blocks, accédez à la section **Contenu** > **Conception et création**. Sélectionnez l'onglet **Lignes**, puis sélectionnez **Content Blocks** dans le menu déroulant. Vous pouvez alors voir vos Content Blocks par glisser-déposer s'afficher tels qu'ils apparaîtraient dans votre campagne d'e-mail.

{% alert note %}
Seuls les Content Blocks utilisés exclusivement dans l'éditeur par glisser-déposer sont visibles sous l'onglet **Lignes**.
{% endalert %}

Une fois que vous avez glissé-déposé le Content Block dans votre campagne d'e-mail, vous pouvez apporter des modifications à l'ensemble du contenu du Content Block. Notez que si un Content Block contient du Liquid, vous verrez le Liquid dans la section **Prévisualisation et test**.
