# 임시 커스텀 이벤트 {#ephemeral-custom-events}

- 임시 커스텀 이벤트에는 구매 이벤트 또는 세션 시작 및 세션 종료(Braze 설명서에 설명된 대로)가 포함되지 않습니다.
- Braze는 SDK 구현당 최대 12개의 배치/이벤트 이름에 대해 커스텀 이벤트를 데이터 포인트로 Braze에 전송하거나 저장하지 않습니다.
- 임시 이벤트 솔루션은 Braze의 프로덕션 iOS 및 Android SDK에 통합되어 있으며, Braze가 임시 커스텀 이벤트 솔루션을 활성화한 플랫폼에 대한 향후 모든 Braze 프로덕션 SDK에도 통합됩니다. 이를 통해 고객은 해당 프로덕션 SDK를 사용할 수 있으며, 향후 기능 및 버그 수정과 동기화가 유지됩니다. 또한 고객은 별도의 커스텀 프로세스 없이 향후 SDK 업데이트를 활용할 수 있습니다.
