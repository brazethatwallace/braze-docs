# 인앱 메시지 세대 {#in-app-messages-generations}

Braze는 현재 세 가지 세대의 인앱 메시지를 제공하고 있습니다. 각 세대는 고유한 수준의 지원을 제공합니다. 인앱 메시지의 최신 기능을 활용하려면 최신 [웹]({{site.baseurl}}/developer_guide/platform_integration_guides/web/initial_sdk_setup/#upgrading-the-sdk), iOS 및 Android SDK로 업그레이드하는 것을 권장합니다.

이 차트는 현재 사용 가능한 기능과 메시지 유형, 그리고 각 세대에서 도입된 시기를 보여줍니다. 또한 특정 세대에서 지원되지 않는 기능도 명시적으로 표시합니다.

| 세대 | 새로운 기능 | 지원되지 않는 기능 |
|---|---|---|
| **1세대** | • 인앱 트리거 전체화면, 모달, 슬라이드업 메시지 유형 | 커스텀 HTML 메시지 <br> • 웹 이메일 캡처 양식 <br> • 커스텀 CSS가 포함된 웹 모달 |
| **2세대** | • 텍스트 정렬 제어 <br> • 모달 뒤 오버레이 <br> • 미리보기 기간의 이미지 안전 영역 | 버튼 테두리 |
| **3세대** | • 버튼 테두리 <br> • 모든 메시지 유형에 대한 개선된 디자인 <br> • 1, 2, 3세대 개념 <br> • 새로운 닫기 X 자산 <br> • 웹 접근성 개선 <br> • 노치 기기 지원 개선 | (최신 세대는 항상 전체 기능을 지원합니다!) |
