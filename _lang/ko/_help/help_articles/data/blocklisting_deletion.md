# 차단 목록과 삭제의 차이점 {#difference-between-blocklisting-and-deleting}

Braze에서 커스텀 데이터를 차단 목록에 추가하는 것과 삭제하는 것의 차이를 이해하기 위해 각 동작의 결과를 검토해 보세요:

- **차단 목록:** 커스텀 속성, 이벤트 또는 구매가 차단 목록에 있는 경우 해당 데이터는 고객 프로필에 남아 있지만, Braze는 해당 오브젝트에 대한 새로운 데이터를 더 이상 처리하지 않습니다.
- **삭제:** 커스텀 속성, 이벤트 또는 구매가 삭제되면 Braze는 고객 프로필에서 해당 데이터를 제거합니다. 삭제된 커스텀 속성과 이벤트는 7일 동안 `Trashed` 상태로 이동하며, 이 기간 동안 복원할 수 있습니다. 7일이 지나면 Braze가 영구적으로 삭제합니다. 또한 삭제해도 새로운 수신 데이터가 차단되지 않으므로, 삭제하기 전에 SDK, API 또는 CSV 가져오기를 통해 해당 데이터가 더 이상 전송되지 않는지 확인하세요.

## 어떻게 해야 하나요? {#which-should-i-do}

차단 목록을 적용하려면 Braze가 차단 목록 정보를 각 사용자의 기기로 전송해야 하며, 이는 데이터 집약적인 작업으로 가능하면 피하는 것이 좋습니다. 또한 목록이 너무 크면(속성, 이벤트 또는 구매가 100개 이상) 앱 속도가 느려질 수 있습니다.

더 이상 Braze에 속성을 전송할 계획이 없다면 삭제 방식을 사용하는 것이 좋습니다.

어떤 방식을 선택하든, 제거한 커스텀 속성, 이벤트 및 구매는 더 이상 **워크스페이스 관리** 페이지에 표시되지 않으며, Segment 필터에서도 제거됩니다. 커스텀 데이터를 삭제하면 Braze는 프로필에서 해당 사용자 수준 데이터를 제거합니다.
