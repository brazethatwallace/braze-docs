- RCS 과금은 두 가지 메시지 유형을 기준으로 합니다(미국의 경우 세부 구분이 있습니다):
    - **기본 RCS:** 텍스트 전용, 최대 160자
    - **단일 RCS:** 리치 콘텐츠를 포함하는 메시지 또는 160자를 초과하는 텍스트 전용 메시지
    - **리치 RCS(미국 전용):** 텍스트 전용이며, 제한된 제안/버튼(quickReply, dialPhone, 웹뷰 없는 openURL)을 포함할 수 있고, 160 UTF-8 바이트 단위로 분할됩니다
    - **리치 미디어 RCS(미국 전용):** 미디어가 포함되거나 더 풍부한 제안/버튼(웹뷰, 위치, 캘린더 등)이 포함된 텍스트이며, 하나의 메시지로 집계됩니다
