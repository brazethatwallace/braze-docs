- **화면 녹화:** 오류가 발생하기 전에 수행한 단계를 녹화한 것으로, 페이지 전환도 포함합니다.
- **타임스탬프 및 시간대:** 오류가 발생한 정확한 시간과 사용자의 시간대입니다.
- **브라우저 및 버전:** 사용 중인 브라우저(예: Chrome 120, Safari 17)와 다른 브라우저에서 오류를 재현해 보았는지 여부입니다.

- **재현 단계:** 오류를 트리거하는 작업에 대한 명확한 설명으로, 관련된 특정 캔버스 단계 또는 구성을 포함합니다.

- **재현 단계:** 오류를 트리거하는 작업에 대한 명확한 설명으로, 관련된 특정 Campaign 또는 Canvas 설정을 포함합니다.

- **네트워크 로그(선택 사항):** 브라우저 개발자 도구(**네트워크** 탭)를 열고 오류를 재현한 다음, 네트워크 로그를 HTTP Archive(HAR) 로그 파일로 내보냅니다. 이를 통해 지원 팀이 어떤 API 호출에서 시간 초과가 발생하는지 파악하는 데 도움이 됩니다.
