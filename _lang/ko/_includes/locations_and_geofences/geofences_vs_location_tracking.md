Braze에서 지오펜스와 위치 추적은 서로 다른 목적을 가지고 있습니다.

| | 위치 추적 | 지오펜스 |
|---|---|---|
| 목적 | 사용자가 있었던 위치를 기반으로 세분화 | 사용자가 특정 영역에 진입하거나 이탈할 때 메시징 트리거 |
| 일반적인 사용 | `Most Recent Location` 및 관련 필터 | 지오펜스 진입 또는 이탈 시 실시간 Campaign |
| 위치가 평가되는 시점 | 앱이 열려 있을 때(세션 시작 시) 업데이트되며, 사용자의 마지막으로 알려진 위치를 반영합니다 | 위치 권한이 허용된 경우 앱이 백그라운드에 있거나 종료된 상태를 포함하여 OS에서 모니터링합니다 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Location tracking compared to geofences" }

- **위치 추적:** 각 사용자의 가장 최근 위치를 수집하여 프로필에 저장합니다. 이 데이터를 과거 기반 세분화에 사용합니다. 예를 들어, `Most Recent Location` 필터는 사용자가 실시간으로 어디에 있는지가 아니라 마지막으로 앱을 열었던 위치를 기반으로 사용자를 타겟팅합니다.
- **지오펜스:** 위도, 경도, 반경을 기준으로 가상 경계를 정의합니다. 사용자가 경계에 진입하거나 이탈하면 Braze가 Campaign 발송과 같은 동작을 트리거할 수 있습니다. 지오펜스는 기본 위치 추적 외에 추가적인 SDK 설정이 필요합니다.

두 기능 모두 사용자가 위치 권한을 부여해야 합니다. 사용자가 위치 추적을 거부하면 이전에 저장된 위치 데이터는 프로필에서 자동으로 제거되지 않지만, 새로운 위치 데이터는 수집되지 않습니다.
