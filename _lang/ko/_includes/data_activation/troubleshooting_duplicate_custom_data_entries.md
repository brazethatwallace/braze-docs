동일한 이름으로 보이는 커스텀 데이터 항목이 두 개 표시되는 경우, 하나의 항목에 보이지 않는 선행 또는 후행 공백이 포함되어 있을 수 있습니다.

이 문제를 해결하려면 다음을 수행합니다.

1. **데이터 설정** > **커스텀 속성** 또는 **커스텀 이벤트**로 이동한 다음, 동일한 이름으로 보이는 두 항목을 찾습니다.
2. 이름 중 하나에 숨겨진 공백이 포함되어 있는지 확인합니다.
    1. 각 이름을 마우스 오른쪽 버튼으로 클릭하고 **검사**를 선택합니다.
    2. 브라우저 개발자 도구에서 HTML 텍스트 값을 확인합니다.
    3. 값을 비교합니다(예: `email`과 ` email`).
    4. 필요한 경우 [Chrome DevTools로 페이지 및 스타일 검사 및 편집](https://developer.chrome.com/docs/devtools/inspect-mode)을 참조합니다.
3. 표준 키로 유지할 이름을 결정하고, 해당 철자와 대소문자를 정확히 통일합니다.
4. 하나의 항목에 선행 또는 후행 공백이 포함되어 있고 대시보드에서 직접 생성된 경우, 해당 항목 사용을 중단하고 표준 키로 전환합니다.
    - 대시보드 워크플로, CSV 가져오기 및 내부 런북을 표준 키를 사용하도록 업데이트합니다.
    - 해당 항목을 폐기할 준비가 되면 잘못된 항목에 대해 [커스텀 데이터 차단 목록]({{site.baseurl}}/user_guide/data/activation/custom_data/blocklist_custom_data)을 설정합니다.
5. 수집 경로를 확인합니다.
    - API 및 SDK 페이로드는 선행 및 후행 공백을 자동으로 제거합니다.
    - 대시보드에서 생성된 이름은 자동으로 공백을 제거하지 않으므로, 수동 입력 시 주의와 관리가 필요합니다.
