- **에이전트 만들기** 버튼 드롭다운을 통해 Operator에서 사전 설정된 사용 사례를 구성할 수 있습니다.
- 에이전트 목록에서 기존 에이전트를 복제할 수 있습니다.
- 생성 중에 에이전트를 초안으로 저장하고 나중에 구성을 완료할 수 있습니다.
- Canvas 에이전트에 대체 출력 값을 설정하여 에이전트 오류 발생 시 출력 변수가 null로 설정되는 것을 방지할 수 있습니다.
- 카탈로그 에이전트 필드에 필수 입력 필드를 설정하여 필수 입력 필드 값이 비어 있거나 누락된 경우 에이전트가 실행되지 않도록 할 수 있습니다.
- 에이전트 열의 모든 빈 셀에 대해 에이전트를 다시 실행하여 전체 열을 다시 실행하지 않고도 누락된 값을 채울 수 있습니다.
