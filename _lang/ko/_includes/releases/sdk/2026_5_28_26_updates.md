- [Flutter SDK 19.0.0](https://pub.dev/packages/braze_plugin/changelog#1900)
    - 지원되는 최소 Dart 버전은 `2.17.0`입니다.
    - SDK 로깅이 이제 Dart 레이어에서 제어됩니다.
    - 네이티브 SDK 바인딩을 업데이트했으며, 네이티브 Android 브리지를 [Braze Android SDK 41.1.1에서 42.2.0으로](https://github.com/braze-inc/braze-android-sdk/compare/v41.1.1...v42.2.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed) 업데이트했습니다.
    - 크래시를 수정했습니다.
- [Cordova 16.0.1](https://github.com/braze-inc/braze-cordova-sdk/releases/tag/16.0.1)
    - `SwiftDelegate` 템플릿과 함께 `cordova-ios` 8을 사용할 때 iOS 초기화 문제를 수정했습니다.
- [Unity SDK 11.0.0](https://github.com/braze-inc/braze-unity-sdk/blob/master/CHANGELOG.md)
    - 네이티브 SDK 바인딩을 업데이트했으며, 네이티브 iOS 브리지를 Braze [Swift SDK 13.2.0에서 14.1.0으로](https://github.com/braze-inc/braze-swift-sdk/compare/13.2.0...14.1.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed) 업데이트했습니다.
    - 네이티브 Android 브리지를 [Braze Android SDK 36.0.0에서 42.2.0으로](https://github.com/braze-inc/braze-android-sdk/compare/v36.0.0...v42.2.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed) 업데이트했습니다.
        - 최소 필수 Android SDK 버전은 23입니다. 자세한 내용은 [Braze Android SDK 버전 정보](https://github.com/braze-inc/braze-android-sdk?tab=readme-ov-file#version-information)를 참조하세요.
    - 최소 필수 Unity 버전을 Unity 6([6000.0.66f2](https://unity.com/releases/editor/whats-new/6000.0.66f2) 이상)으로 업데이트했습니다.
    - News Feed를 제거했습니다.
        - `RequestFeedRefresh()`, `RequestFeedRefreshFromCache()`, `LogFeedDisplayed()`, `LogCardImpression(string)`, `LogCardClicked(string)`를 제거했습니다.
    - 사소한 버그를 수정했습니다.
- [React Native 20.1.0](https://github.com/braze-inc/braze-react-native-sdk/releases/tag/20.1.0)
    - Android SDK 바인딩을 업데이트했습니다.
    - 푸시 알림 딥링킹 문제를 수정했습니다.
- [Segment Swift 8.0.0](https://github.com/braze-inc/braze-segment-swift/blob/main/CHANGELOG.md#800)
    - Braze Swift SDK 바인딩을 `14.0.0+` SemVer 범위의 릴리스를 요구하도록 업데이트했습니다.
        - 이를 통해 `14.0.0`부터 `15.0.0` 미만까지 모든 Braze SDK 버전과 호환됩니다.
        - 잠재적인 호환성 변경 사항에 대한 자세한 내용은 [`14.0.0` 체인지로그 항목](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1400)을 참조하세요.
    - SDK 인증 지원을 추가했습니다.
