2025년 7월 1일부터 WhatsApp은 메시지당 과금 방식을 적용합니다. 메시지 요금은 수신자 전화번호의 국가 코드와 발송하는 메시지 유형에 따라 결정됩니다. 메시지 유형은 WhatsApp Manager에서 승인을 위해 제출하는 [메시지 템플릿](https://developers.facebook.com/docs/whatsapp/message-templates/guidelines/)에 의해 결정됩니다.

{% alert note %}
플랫폼에서 비즈니스가 시작하는 모든 대화는 승인된 템플릿 메시지로 시작해야 합니다.
{% endalert %}

{% if include.content == "h2" %}##{% else include.content == "h3" %}###{% endif %} 메시지 템플릿 정의

WhatsApp Manager에서 승인을 위해 제출할 수 있는 메시지 템플릿은 다음과 같습니다.

| 템플릿 | 정의 |
|----------|------------|
| **마케팅 템플릿** | 이 템플릿을 사용하면 인지도 향상부터 매출 촉진, 고객 리타겟팅까지 다양한 목표를 달성할 수 있습니다. 예를 들어 신제품, 서비스 또는 기능 공지, 타겟 프로모션이나 혜택, 장바구니 유기 리마인더 등이 있습니다. |
| **유틸리티 템플릿** | 이 템플릿을 사용하면 사용자 동작이나 요청에 대한 후속 조치를 취할 수 있으며, 일반적으로 사용자 동작에 의해 트리거되는 메시지입니다. 예를 들어 옵트인 확인, 주문 또는 배송 관리(배송 업데이트 등), 계정 업데이트 또는 알림(결제 리마인더 등), 피드백 설문조사 등이 있습니다.<br><br>2025년 7월 1일부터:<br>• 유틸리티 템플릿은 설득 의도 없이 비프로모션 성격이어야 합니다.<br>• 유틸리티 템플릿은 (1) 사용자에게 특정되거나 사용자가 요청한 것이거나 (2) 사용자에게 필수적이거나 중요한 것이어야 합니다. |
| **인증 템플릿** | 이 템플릿을 사용하면 고객 여정의 다양한 단계(계정 인증, 계정 복구, 무결성 확인 등)에서 사용자의 신원을 확인할 수 있습니다.<br><br>인증 대화는 사안별로만 지원되며, Braze는 특정 SLA를 보장할 수 없습니다. 또한 Braze는 PIN 생성을 지원하지 않습니다. |

{% if include.content == "h2" %}##{% else include.content == "h3" %}###{% endif %} 무료 메시지 유형

WhatsApp 메시지가 무료로 제공되는 몇 가지 시나리오는 다음과 같습니다.

| 메시지 | 세부 정보 |
|-------|-------|
| 모든 서비스 대화 | _2024년 11월 1일부터 적용_<br><br>사용자가 브랜드에 메시지를 보내면(24시간 고객 서비스 기간 시작) 템플릿이 아닌 응답 메시지에는 요금이 부과되지 않습니다. 참고: 브랜드가 사용자에게 템플릿으로 응답하는 경우에는 템플릿 유형에 따라 요금이 부과됩니다. |
| 24시간 고객 서비스 기간 내에 발송된 유틸리티 템플릿 | _2025년 7월 1일부터 적용_<br><br>최종 사용자가 브랜드에 메시지를 보내면 24시간 고객 서비스 기간이 생성됩니다. 브랜드가 유틸리티 템플릿으로 응답하면 무료입니다. 24시간 고객 서비스 기간 외에 발송된 유틸리티 템플릿(예: 계정 리마인더 및 주문 상태 업데이트를 위해 브랜드가 사전에 발송하는 유틸리티 템플릿)에는 여전히 요금이 부과됩니다. |
| 무료 진입점 대화 | 무료 진입점 대화는 1) 사용자가 Click to WhatsApp 광고 또는 Facebook 페이지 행동 유도 버튼을 통해 브랜드에 메시지를 보내고 2) 브랜드가 24시간 이내에 응답하면 시작됩니다. 무료 진입점 대화는 브랜드가 응답하는 즉시 시작되며 72시간 동안 지속됩니다. 72시간 기간 내에 브랜드는 사용자에게 메시지 템플릿을 무료로 발송할 수 있습니다. 단, 브랜드는 24시간 고객 서비스 기간이 열려 있는 경우에만 템플릿이 아닌 메시지를 발송할 수 있습니다. |
| 응답 메시지 | 응답 메시징을 통해 브랜드는 사용자 메시지에 대한 응답으로 템플릿이 아닌 메시지를 발송할 수 있습니다. 응답 메시지는 사용자가 WhatsApp에서 브랜드에 메시지를 보내는 경우처럼 24시간 고객 서비스 기간이 열려 있을 때 발송할 수 있습니다.<br><br>대화를 시작하는 템플릿 메시지에는 여전히 요금이 부과되지만, 이후의 응답 메시지는 무료입니다. |
