# 2022년 2월 8일 릴리스 {#february-8-2022-release}

## Canvas 작업 경로 {#canvas-action-paths}

[작업 경로]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/action_paths)를 사용하면 사용자의 행동에 따라 사용자를 분류할 수 있습니다. 작업 경로를 사용하면 다음과 같은 작업이 가능합니다.
- 특정 행동을 기반으로 사용자 경로를 커스터마이즈할 수 있습니다.
- 평가 기간 동안의 행동에 따라 다음 경로의 우선순위를 정하기 위해 일정 기간 동안 사용자를 보류할 수 있습니다.

작업 경로에 대한 액세스는 모든 Braze 인스턴스에 점진적으로 적용될 예정입니다. 자세한 내용은 Braze 계정 매니저에게 문의하세요.

## API 엔드포인트 참조 페이지 {#api-endpoint-reference-page}

사용 가능한 모든 Braze 엔드포인트에 대한 빠른 참조 페이지를 찾고 계신가요? [API 엔드포인트 색인]({{site.baseurl}}/api/endpoints)을 방문하세요.

## Transifex v2 및 v2.5 API 지원 중단 {#transifex-v2-and-v25-api-deprecation}
2022년 4월 7일부터 [Transifex]({{site.baseurl}}/partners/message_personalization/localization/transifex)는 버전 3으로의 전환을 위해 API 버전 2 및 2.5에 대한 지원을 중단할 예정입니다. 이 날짜 이후에는 v2 및 v2.5가 더 이상 작동하지 않으며 관련 요청이 실패합니다. 이 파트너 통합 사용자는 해당 날짜 이전에 API 버전을 업데이트하시기 바랍니다.

## 사용 가능한 커스텀 속성 데이터 유형 {#available-custom-attribute-data-types}
곧 출시됩니다! 커스텀 속성에 대한 오브젝트 및 오브젝트 배열 데이터 유형 지원은 2022년 봄에 제공될 예정입니다.
