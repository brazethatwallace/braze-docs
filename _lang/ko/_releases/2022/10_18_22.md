# 2022년 10월 18일 릴리스 {#october-18-2022-release}

## 고객 프로필 메시징 기록 {#user-profile-messaging-history}

고객 프로필의 **메시지 기록** 탭은 지난 30일간 개별 사용자의 최근 메시징 관련 이벤트(약 40건)를 보여줍니다. 이러한 이벤트에는 사용자가 발송받았거나, 수신했거나, 상호작용한 메시지 등이 포함됩니다. 자세한 내용은 [고객 프로필]({{site.baseurl}}/user_guide/engagement_tools/segments/user_profiles#messaging-history-tab)을 참조하세요.

## 드래그 앤 드롭 편집기용 Content Blocks {#content-blocks-for-drag-drop-editor}

드래그 앤 드롭 편집기에서 독점적으로 사용되는 [Content Blocks]({{site.baseurl}}/user_guide/messaging/design_and_edit/content_blocks)는 다양한 채널에서 사용되는 Content Blocks와 기능적으로 유사합니다. 다양한 이메일 Campaign에서 참조할 수 있는 정보를 보관하는 중앙 집중식 위치입니다. 이메일 헤더, 프로모션 콜아웃 등을 하나의 재사용 가능한 행으로 그룹화하는 데 활용할 수 있습니다.

## Shopify ScriptTag

[Braze와 Shopify 통합]({{site.baseurl}}/partners/shopify)을 통해 이제 ScriptTag를 사용하여 Shopify 스토어에 웹 SDK 통합을 임베딩할 수 있습니다. ScriptTag를 통해 웹 SDK를 임베딩하면 다음을 추적할 수 있습니다:
- 익명 사용자 추적을 통해 스토어에서 게스트 활동을 추적합니다
- 웹 SDK가 스토어 방문자의 세션 데이터를 추적할 수 있으므로 월간 활성 사용자를 추적합니다
- Shopify 온사이트 활동 사용자를 수집하는 옵션으로, 데이터 포인트 소비에 포함됩니다
- Shopify 스토어에서 채널로 브라우저 내 메시징을 활성화하는 옵션

## SCIM 엔드포인트 {#scim-endpoint}

다음 Braze SCIM 엔드포인트를 사용하여 자동 사용자 프로비저닝을 관리합니다:
- [DELETE: 대시보드 사용자 계정 삭제]({{site.baseurl}}/api/endpoints/scim/delete_existing_dashboard_user)
- [GET: 기존 대시보드 사용자 계정 조회]({{site.baseurl}}/api/endpoints/scim/get_see_user_account_information)
- [POST: 새 대시보드 사용자 계정 생성]({{site.baseurl}}/api/endpoints/scim/post_create_user_account)
- [PUT: 대시보드 사용자 계정 업데이트]({{site.baseurl}}/api/endpoints/scim/put_update_existing_user_account)

## 단문 메시지 서비스 퍼지 수신 거부 {#sms-fuzzy-opt-outs}

[퍼지 수신 거부]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/keyword_processing/fuzzy_opt_out)는 수신 단문 메시지 서비스 메시지가 수신 거부 키워드와 일치하지 않지만 수신 거부 의도를 나타내는 경우를 인식하려고 시도합니다. 퍼지 수신 거부가 활성화되어 있고 수신 키워드 응답이 "퍼지"로 판정되면, Braze는 자동으로 사용자에게 의도를 확인하는 응답을 보냅니다.

## SDK 업데이트 {#sdk-updates}

최신 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 SDK 업데이트 섹션에 나열되어 있으며, 그 외 모든 업데이트는 해당 SDK 체인지로그에서 확인할 수 있습니다.

- [Android SDK 23.2.0-23.2.1](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2321)
- [iOS Objective-C SDK 4.5.1](https://github.com/Appboy/appboy-ios-sdk/blob/master/CHANGELOG.md#451)
- [iOS Swift SDK 5.5.0S-SDK 5.5.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#550)
- [Cordova SDK 2.31.0](https://github.com/Appboy/appboy-cordova-sdk/blob/master/CHANGELOG.md#2310)
  - [Braze Android SDK 23.0.1](https://github.com/braze-inc/braze-android-sdk/releases/tag/v23.0.1)로 업데이트되었습니다.
- [Unity 3.10.0](https://github.com/Appboy/appboy-unity-sdk/blob/master/CHANGELOG.md#3100)
- [React SDK v1.39.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md#1400)
  - 네이티브 Android SDK가 23.2.0으로 업데이트되었습니다.
  - `kotlin_versio`n gradle 템플릿 변수의 이름이 `kotlinVersion`으로 변경되었습니다.
- [Flutter SDK 2.6.0](https://pub.dev/packages/braze_plugin/changelog#260)
  - 네이티브 Android 브리지는 Braze Android SDK 23.2.0을 사용합니다.
  - 네이티브 iOS 브리지는 Braze iOS SDK 4.5.1을 사용합니다.
  - iOS 레이어에서 `process(inAppMessage)`의 이름이 `processInAppMessage(inAppMessage)`로 변경되었습니다.
- [Segment iOS 4.6.0](https://github.com/Appboy/appboy-segment-ios/blob/master/CHANGELOG.md#460)
  - Braze [iOS SDK 4.5.1+](https://github.com/Appboy/appboy-ios-sdk/blob/master/CHANGELOG.md#451)로 업데이트되었습니다.
