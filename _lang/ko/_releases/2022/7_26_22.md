# 2022년 7월 26일 릴리스 {#july-26-2022-release}

## Canvas Flow
최신 버전의 Canvas 제품인 [Canvas Flow]({{site.baseurl}}/user_guide/engagement_tools/canvas/create_a_canvas/create_a_canvas#editing-a-step)가 릴리스되었습니다. Canvas Flow를 사용하면 가벼운 [Canvas 구성요소]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/about), [영구 진입 속성정보]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas/context_and_event_properties/canvas_persistent_entry_properties), [출시 후 편집]({{site.baseurl}}/post-launch_edits)에 액세스할 수 있습니다.

![경량 구성요소와 분기 흐름을 보여주는 Canvas Flow 시각적 개요.]({% image_buster /assets/img/canvas_flow.png %})

## 오브젝트 배열 {#array-of-objects}
관련 속성을 그룹화하려면 [오브젝트 배열]({{site.baseurl}}/user_guide/data_and_analytics/custom_data/custom_attributes/array_of_objects#array-of-objects)을 사용하세요. 예를 들어, 한 사용자에게 속하는 반려동물 오브젝트, 노래 오브젝트, 계정 오브젝트 그룹이 있을 수 있습니다. 이러한 오브젝트 배열은 Liquid로 메시징을 개인화하거나, 오브젝트 내의 요소가 기준에 맞는 경우 오디언스 세그먼트를 생성하는 데 사용할 수 있습니다.

## 업데이트된 파트너 통합 {#updated-partner-integrations}
[Amplitude Recommend]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/amplitude/amplitude_audiences) 및 [mParticle]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/mparticle/mparticle)의 통합 단계가 업데이트되었습니다. 이러한 파트너를 활용하고 있다면, 최신 설정을 따르고 있는지 확인하기 위해 해당 설명서를 방문하세요.

## Shopify 요구 사항 {#shopify-requirements}
- [필수 조건]({{site.baseurl}}/partners/message_orchestration/channel_extensions/ecommerce/shopify/shopify#prerequisites)에 나열된 필수 사용자 권한이 업데이트되었습니다.
- `price`, `total_price`, `total_discounts`, `amount` 속성정보를 포함하는 예시 Shopify [페이로드]({{site.baseurl}}/partners/message_orchestration/channel_extensions/ecommerce/shopify/shopify#supported-shopify-events)가 이러한 속성정보를 문자열 대신 숫자로 형식화하도록 업데이트되었습니다.

## 예측 업데이트 {#prediction-updates}
고객이탈 예측 및 구매 예측의 최대 시간 기간이 14일에서 60일로 증가했습니다.

## SDK 업데이트 {#sdk-updates}
다음 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 아래에 나열되어 있으며, 그 외의 모든 업데이트는 해당 SDK 체인지로그를 확인하시기 바랍니다.
- [웹 SDK 4.1.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md#410)
- [Cordova SDK 2.30.1](https://github.com/Appboy/appboy-cordova-sdk/blob/master/CHANGELOG.md#2301)
- [Unity SDK 3.8.1](https://github.com/Appboy/appboy-unity-sdk/blob/master/CHANGELOG.md#381)
- [Swift SDK 5.0.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#501)
- [Roku SDK 0.1.2](https://github.com/braze-inc/braze-roku-sdk/blob/main/CHANGELOG.md#012)
- [React Native SDK 1.37.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md#1370)
  - Braze React Native SDK는 이제 기본 오브젝트를 ES 모듈로 내보냅니다. 현재 `require()`를 사용하여 SDK를 가져오고 있다면, 이제 표준 ES 모듈로 가져와야 합니다(예: import Braze from "`@braze/react-native-sdk`").
- [Android SDK 22.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2200)
  - `Appboy.java`가 이제 `Braze.kt`로 변경되었습니다. Kotlin 클라이언트는 필요한 경우 Braze 싱글톤에서 Kotlin 속성 사용을 지원하도록 코드를 업데이트해야 합니다.
    - `Braze.registerPushToken()`/`Braze.getRegisteredPushToken()`이 이제 `Braze.setRegisteredPushToken()/Braze.getRegisteredPushToken()`으로 변경되었습니다. Kotlin을 사용하는 경우 `Braze.registeredPushToken` 속성을 사용하세요.
    - `Braze.getDeviceId`가 이제 Kotlin에서 `Braze.deviceId`로 변경되었습니다.
    - `Braze.enableMockNetworkAppboyRequestsAndDropEventsMode`가 이제 `Braze.enableMockNetworkRequestsAndDropEventsMode()`로 변경되었습니다.
    - `Appboy.java`가 제거되었습니다. 예를 들어, `Appboy.getInstance()`와 같은 호출은 앞으로 `Braze.getInstance()`로 변경해야 합니다.
    - `setCustomAppboyNotificationFactory()`가 `setCustomBrazeNotificationFactory()` / `customBrazeNotificationFactory`로 교체되었습니다.
    - `enableMockAppboyNetworkRequestsAndDropEventsMode`가 `enableMockNetworkRequestsAndDropEventsMode`로 이름이 변경되었습니다.
  - `com.appboy.IBrazeEndpointProvider`가 `com.braze.IBrazeEndpointProvider`로 이동되었습니다.
  - `com.braze.events.IEventSubscriber`가 `com.braze.events.IEventSubscriber`로 이름이 변경되었습니다.
  - `Appboy.registerAppboyPushMessages()` / `Appboy.getAppboyPushMessageRegistrationId()`가 제거되었습니다. `getRegisteredPushToken()` / `setRegisteredPushToken()`으로 교체되었습니다.
  - `IAppboyNotificationFactory`가 `IBrazeNotificationFactory`로 교체되었습니다.
  - `com.appboy.ui.inappmessage.listeners.IHtmlInAppMessageActionListener`가 제거되었습니다. 대신 `com.braze.ui.inappmessage.listeners.IHtmlInAppMessageActionListener`를 사용하세요.
