# 2022년 1월 11일 릴리스 {#january-11-2022-release}

새해를 맞이한 것을 환영합니다!

## Canvas 실험 경로 단계 {#canvas-experiment-paths-step}
새로운 Canvas 실험 경로 단계는 사용자 여정의 어느 지점에서든 여러 Canvas 경로를 서로 및 대조군과 비교하여 경로 성과를 추적하는 데 도움이 됩니다. 이제 여기서 수집된 분석을 활용하여 어떤 경로가 가장 효과적인지 추가로 결정할 수 있습니다. [실험 경로 단계]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step/)를 만드는 방법에 대해 자세히 알아보세요.

## 유효하지 않은 전화번호 처리 {#handling-invalid-phone-numbers}
사용자가 유효하지 않은 전화번호를 입력한 시나리오를 경험하셨을 수 있습니다. 여기 해결 방법이 있습니다! Braze는 이러한 유효하지 않은 전화번호를 표시하고 해당 번호로 추가 통신을 시도하지 않습니다. Braze가 [유효하지 않은 전화번호를 처리하는 방법]({{site.baseurl}}/user_guide/message_building_by_channel/sms/phone_numbers/user_phone_numbers/#handling-invalid-phone-numbers/)에 대해 자세히 알아보세요.

## 새로운 SMS 엔드포인트 {#new-sms-endpoints}
이제 새로운 [Braze SMS 엔드포인트]({{site.baseurl}}/api/endpoints/sms/)를 사용하여 유효하지 않은 전화번호를 관리할 수 있습니다! 이번 업데이트에는 다음이 포함됩니다:
- [GET: 유효하지 않은 전화번호 쿼리 또는 목록 엔드포인트]({{site.baseurl}}/api/endpoints/sms/get_query_invalid_numbers/)는 Braze에서 "유효하지 않음"으로 간주되는 전화번호 목록을 반환합니다.
- [POST: 유효하지 않은 전화번호 제거 엔드포인트]({{site.baseurl}}/api/endpoints/sms/post_remove_invalid_numbers/)를 사용하면 Braze의 유효하지 않은 목록에서 "유효하지 않은" 전화번호를 제거할 수 있습니다.

## 사용량 제한 {#rate-limits}
모든 [Braze 엔드포인트 문서]({{site.baseurl}}/api/basics/#nav_top_endpoints)에 API 사용량 제한이 포함되었습니다. 이제 요청 유형별로 사용량 제한을 쉽게 확인할 수 있습니다. 사용량 제한에 대한 자세한 내용은 [API 사용량 제한]({{site.baseurl}}/api/api_limits/) 문서를 확인하세요.

## 새로운 REST 엔드포인트 {#new-rest-endpoint}
Braze는 [새로운 EU-02 REST 엔드포인트]({{site.baseurl}}/api/basics/#api-definitions)를 추가했습니다.

## 이메일 소개 {#about-email}
이메일 메시지는 고객과 소통하는 훌륭한 방법입니다. 이메일 메시지를 커스터마이즈하고 활용하는 방법에 대한 간단한 소개는 [이메일 소개]({{site.baseurl}}/user_guide/channels/email/) 문서를 확인하세요.

## 인앱 메시지 소개 {#about-in-app-messages}
인앱 메시지는 앱 내에서 활동하는 사용자에게 풍부한 콘텐츠를 제공합니다. 개인화된 인사말이나 기능 채택을 위한 인앱 메시지를 만들어 활성 고객과 쉽게 소통할 수 있습니다. 장점과 메시지 유형에 대해 알아보려면 [인앱 메시지 소개]({{site.baseurl}}/in-app_messages/) 문서를 확인하세요.
