# 2022년 12월 13일 릴리스 {#december-13-2022-release}

## News Feed 지원 중단 {#news-feed-is-deprecated}
News Feed는 지원이 중단될 예정입니다. Braze는 News Feed 도구를 사용하는 고객에게 Content Cards 메시징 채널로 전환할 것을 권장합니다. Content Cards는 더 유연하고, 커스터마이징이 가능하며, 안정적입니다. 자세한 내용은 [마이그레이션 가이드]({{site.baseurl}}/user_guide/channels/content_cards)를 참조하세요.

## 새로운 API 엔드포인트: 카탈로그 {#new-api-endpoints-catalogs}
[Braze API 카탈로그 엔드포인트]({{site.baseurl}}/api/endpoints/catalogs)를 사용하여 [카탈로그]({{site.baseurl}}/user_guide/data/activation/catalogs) 및 카탈로그 항목 세부 정보를 추가, 편집, 관리할 수 있습니다. 비동기 카탈로그 엔드포인트를 사용하여 카탈로그를 대량으로 변경할 수 있습니다.

## 이메일 드래그 앤 드롭 편집기의 링크에 대한 HTML 속성 {#html-attributes-for-links-in-the-drag-drop-editor-for-email}
이제 이메일 드래그 앤 드롭 편집기에서 `Image`, `Button` 또는 `Text` 편집기 블록 내의 모든 URL에 [HTML 속성을 추가]({{site.baseurl}}/user_guide/message_building_by_channel/email/drag_and_drop/#creative-details/)할 수 있습니다. 커스텀 속성을 사용하면 이메일의 HTML 태그에 추가 정보를 쉽게 첨부할 수 있습니다. 이 기능은 메시지 개인화, 세분화 및 스타일링에 특히 유용합니다.

## 히트맵 표시 토글 {#show-heatmap-toggle}
이제 [히트맵 표시 토글]({{site.baseurl}}/user_guide/message_building_by_channel/email/reporting_and_analytics/email_reporting#heatmaps)을 사용하여 이메일 Campaign의 전체 기간 동안 클릭의 전체 빈도와 위치를 보여주는 **메시지 분석**의 시각적 보기를 표시할 수 있습니다. 또한 향후 참조를 위해 히트맵 사본을 다운로드할 수도 있습니다.

## 업데이트된 이메일 설정 {#updated-email-settings}
이전 **일반 이메일 설정** 섹션이 **발송 구성**과 **구독 페이지 및 푸터**라는 두 개의 새로운 섹션으로 분리되었습니다. 개별 설정에 대한 자세한 내용은 [이메일 설정]({{site.baseurl}}/user_guide/administrative/app_settings/email_settings#sending-configuration)을 확인하세요.

## 미디어 라이브러리를 위한 AI 이미지 생성 {#generate-ai-images-for-your-media-library}
DALL·E 2를 사용하여 미디어 라이브러리용 이미지를 생성할 수 있습니다. DALL·E 2는 자연어 설명을 통해 사실적인 이미지와 아트를 생성할 수 있는 OpenAI의 인공지능 시스템입니다. [AI를 사용한 이미지 생성]({{site.baseurl}}/user_guide/engagement_tools/templates_and_media/media_library#generate-ai)에 대해 자세히 알아보세요.

## 중첩 커스텀 속성 개선 사항 {#enhancements-to-nested-custom-attributes}
중첩 커스텀 속성을 사용하여 커스텀 속성의 새로운 데이터 유형으로 객체를 전송할 수 있습니다.
- [중첩 커스텀 속성 객체가 변경될 때 트리거]({{site.baseurl}}/user_guide/data_and_analytics/custom_data/custom_attributes/nested_custom_attribute_support#trigger-nested-custom-attribute-changes)할 수 있습니다.
- 이제 [커스텀 속성 객체와 Liquid를 사용하여 메시지를 개인화]({{site.baseurl}}/user_guide/data_and_analytics/custom_data/custom_attributes/nested_custom_attribute_support#personalization)할 수도 있습니다.

## 새 비디오 블록 {#new-video-block}
이메일용 드래그 앤 드롭 편집기에 [비디오]({{site.baseurl}}/user_guide/message_building_by_channel/email/drag_and_drop/dnd_editor_blocks#video)를 위한 새 콘텐츠 블록이 추가되었습니다.

## IDFV(Identifier for Vendor) 선택적 수집 - Swift {#optional-identifier-for-vendor-collection-swift}
이전 버전의 Braze iOS Swift SDK에서는 IDFV(Identifier for Vendor) 필드가 사용자의 기기 ID로 자동 수집되었습니다. Swift SDK v5.7.0부터 IDFV 필드를 선택적으로 비활성화할 수 있으며, 대신 Braze가 랜덤 UUID를 기기 ID로 설정합니다. 자세한 내용은 [IDFV 수집]({{site.baseurl}}/developer_guide/analytics/managing_data_collection/?sdktab=swift)을 참조하세요.

## Snowflake 리더 계정 {#snowflake-reader-accounts}
Snowflake 리더 계정은 Snowflake 계정이나 Snowflake와의 고객 관계 없이도 [Snowflake 데이터 공유]({{site.baseurl}}/partners/snowflake)와 동일한 데이터 및 기능에 액세스할 수 있도록 해줍니다. 리더 계정을 사용하면 Braze가 계정을 생성하고 데이터를 공유하며, 로그인하여 데이터에 액세스할 수 있는 자격 증명을 제공합니다. 이를 통해 모든 데이터 공유 및 사용 요금 청구는 전적으로 Braze에서 처리됩니다.

자세한 내용은 고객 성공 매니저에게 문의하세요.

## 업데이트된 Shopify 통합 {#updated-shopify-integration}
[Shopify 통합]({{site.baseurl}}/partners/shopify)을 통해 이제 Shopify 스토어에서 이메일 및 SMS 옵트인을 수집하고 Braze의 구독 그룹에 할당할 수 있습니다.

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### Ada - 설문조사 {#ada-surveys}
[Ada]({{site.baseurl}}/partners/home)와 Braze 통합을 통해 자동화된 Ada 대화에서 수집한 데이터로 사용자 프로필을 보강할 수 있습니다. Ada 채팅 중 수집한 정보를 기반으로 커스텀 속성을 설정하고, Ada 대화의 특정 시점에서 Braze에 커스텀 이벤트를 기록할 수 있습니다. Ada 챗봇을 Braze에 연결하면 소비자가 브랜드에 대해 어떤 질문을 하는지 파악하거나, 능동적으로 대화를 시작하여 소비자의 관심사와 선호도를 더 잘 이해할 수 있는 질문을 던져 소비자에 대해 더 깊이 알 수 있습니다.

### B.Layer - 메시지 템플릿 {#blayer-message-templates}
[B.Layer]({{site.baseurl}}/partners/message_orchestration/templates/blayer)와 Braze 통합을 통해 B.Layer 인앱 메시지 빌더를 활용하여 브랜드에 맞는 인앱 메시지를 구축하고, zip 파일 또는 인라인 HTML로 Braze에 내보낼 수 있습니다. 이 통합은 추가 개발자 리소스가 필요하지 않으므로 시간과 비용을 절약할 수 있습니다.

### Contentsquare - 분석 {#contentsquare-analytics}
[Contentsquare]({{site.baseurl}}/partners/data_and_analytics/analytics/contentsquare)와 Braze 통합을 통해 라이브 시그널(사기, 불만 시그널 등)을 Braze의 커스텀 이벤트로 전송할 수 있습니다. Contentsquare의 경험 인사이트를 활용하여 고객의 디지털 경험과 행동 패턴을 기반으로 메시지를 타겟팅함으로써 캠페인의 관련성과 전환율을 향상시킬 수 있습니다.

[Dynamic Yield]({{site.baseurl}}/partners/dynamic_yield)와 Braze 파트너십을 통해 Dynamic Yield의 추천 및 세분화 엔진을 활용하여 Braze 메시지에 삽입할 수 있는 Experience Block을 생성할 수 있습니다. Experience Block은 다음으로 구성될 수 있습니다:
{% multi_lang_include partners/message_personalization/dynamic_yield_experience_blocks.md %}

### Octolis - 분석 {#octolis-analytics}
[Octolis]({{site.baseurl}}/partners/data_and_analytics/analytics/contentsquare)와 Braze 통합은 원시 데이터 소스와 Braze 사이의 미들웨어 역할을 하여 온라인과 오프라인의 다양한 소스에서 데이터를 검색하고 통합할 수 있도록 합니다.

### Jacquard - A/B 테스트 {#jacquard-ab-testing}
[Jacquard React]({{site.baseurl}}/partners/message_personalization/dynamic_content/content_optimization_testing/jacquard)는 Jacquard X를 기반으로 Braze Currents와 연결된 콘텐츠를 활용하여 웹훅을 통해 구독자의 클릭 추적 정보를 수집합니다. 그런 다음 Jacquard는 해당 이벤트를 언어 배리언트에 연결하여 실시간 언어 최적화를 수행합니다.

### Sheetlabs - 동적 콘텐츠 {#sheetlabs-dynamic-content}
[Sheetlabs]({{site.baseurl}}/partners/message_personalization/dynamic_content/personalization_engines/sheetlabs)와 Braze 통합을 통해 [연결된 콘텐츠]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content)를 활용하여 Braze 마케팅 Campaigns에 Sheetlabs API를 포함할 수 있습니다. 이 통합은 일반적으로 Google 스프레드시트(마케팅 팀이 직접 업데이트하는)와 Braze 템플릿 사이의 연결을 제공하는 데 사용됩니다. 이를 통해 번역이나 더 많은 커스텀 속성 세트와 같이 Braze 템플릿으로 더 많은 것을 달성할 수 있습니다.

### Tellius - 분석 {#tellius-analytics}
[Tellius]({{site.baseurl}}/partners/data_and_analytics/business_intelligence/tellius)와 Braze 통합을 통해 사용자는 BI 엔지니어에 의존하지 않고도 데이터를 활용하여 대시보드를 구축하고 인사이트를 생성하여 더 나은 마케팅 의사결정을 내릴 수 있습니다.

### ThoughtSpot - 분석 {#thoughtspot-analytics}
[ThoughtSpot]({{site.baseurl}}/partners/data_and_analytics/business_intelligence/thoughtspot)와 Braze 통합은 ThoughtSpot TML Block을 활용하여 사내 사용자가 사전 구축된 워크시트 및 모델 템플릿으로 사용자 행동 분석을 가속화할 수 있도록 합니다. 이 통합을 통해 사용자는 Braze 인터랙션 데이터를 무제한으로 검색하고 유용한 인사이트를 발견할 수 있습니다.

### Wunderkind - 분석 {#wunderkind-analytics}
[Wunderkind]({{site.baseurl}}/partners/ecommerce/analytics_workflow/wunderkind)와 Braze 통합을 통해 성과 향상을 분석하고 더 많은 익명 사용자를 식별하여 Braze를 통해 전송되는 일대일 메시지와 Braze에 직접 추가되는 연락처를 대폭 확장할 수 있습니다.

## SDK 업데이트 {#sdk-updates}
최신 SDK 업데이트가 출시되었습니다. 주요 변경 사항은 SDK 업데이트 섹션에 나열되어 있으며, 그 외의 업데이트는 해당 SDK 체인지로그에서 확인할 수 있습니다.

- [iOS Swift SDK 5.6.3-5.7.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
- [Flutter SDK 3.0.0](https://pub.dev/packages/braze_plugin/changelog)
    - 네이티브 iOS 브리지는 이제 [새로운 Braze Swift SDK, 버전 5.6.4](https://github.com/braze-inc/braze-swift-sdk)를 사용합니다. 최소 iOS 배포 대상은 10.0입니다.
    - 마이그레이션 중에 다음 변경 사항으로 프로젝트를 업데이트하세요:
        - Braze를 초기화하려면 [다음 통합 단계에 따라 구성 객체를 생성하세요](https://braze-inc.github.io/braze-swift-sdk/tutorials/braze/a2-configure-braze). 그런 다음 이 코드를 추가하여 설정을 완료하세요: `let braze = BrazePlugin.initBraze(configuration)`
        - `SDWebImage`를 종속성으로 계속 사용하려면 프로젝트의 `/ios/Podfile`에 다음 줄을 추가하세요: `pod 'SDWebImage', :modular_headers => true`. 그런 다음 [이 설정 안내](https://braze-inc.github.io/braze-swift-sdk/tutorials/braze/c3-gif-support)를 따르세요.
        - 인앱 메시지 및 콘텐츠 카드 데이터 수신과 같은 기타 변경 사항에 대한 안내는 샘플 [`AppDelegate.swift`](https://github.com/braze-inc/braze-flutter-sdk/blob/master/example/ios/Runner/AppDelegate.swift)를 참조하세요.
- [React Native SDK v1.41.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
- [Web SDK 4.5.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)

### 새 SDK 라이브러리: Segment Kotlin SDK {#new-sdk-library-segment-kotlin-sdk}
Segment가 Segment Kotlin이라는 새로운 Kotlin 중심 접근 방식으로 라이브러리를 업데이트했습니다. Braze는 이 새로운 라이브러리 패러다임과 함께 작동하는 자체 라이브러리를 출시했습니다. [GitHub에서 초기 릴리스를 확인하세요.](https://github.com/braze-inc/braze-segment-kotlin)
