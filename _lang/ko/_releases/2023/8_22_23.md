# 2023년 8월 22일 릴리스 {#august-22-2023-release}

## Shopify 카탈로그 {#shopify-catalogs}

Shopify 카탈로그를 사용하면 Shopify 스토어의 제품을 Braze 카탈로그로 가져올 수 있으며, 제품 데이터를 자동으로 불러와 메시지의 개인화를 한층 강화할 수 있습니다. 유기한 장바구니, 주문 확인 등에 최신 제품 세부 정보와 정보를 활용할 수 있습니다.

## 이메일로 사용자 병합 {#merging-users-by-email}

이제 `/users/merge` 엔드포인트를 사용하여 [이메일로 사용자를 병합]({{site.baseurl}}/api/endpoints/user_data/post_users_merge#merging-users-by-email-or-phone-number)할 수 있습니다.

{% multi_lang_include alerts/early_access_beta_alert.md feature='The ability to merge users by email and use the `/users/merge` endpoint with mismatched identifiers' %}

## WhatsApp 모범 사례 {#best-practices-for-whatsapp}

WhatsApp 메시지를 보내기 전에 높은 전화 품질 등급을 유지하고, 차단 및 신고를 방지하며, 사용자 옵트인 및 옵트아웃을 관리하기 위한 권장 [모범 사례]({{site.baseurl}}/user_guide/channels/whatsapp/best_practices)를 참조할 수 있습니다.

## 도메인 평판 {#domain-reputation}

전달 가능성 센터에서 이제 [도메인 평판]({{site.baseurl}}/user_guide/analytics/dashboards/deliverability_center#domain-reputation)을 확인하고 모니터링하여 스팸 폴더로 필터링되는 것을 방지할 수 있습니다.

## 커스터마이제이션 가이드 {#customization-guides}

개발자 포털의 재구성을 소개하게 되어 기쁩니다. 이제 [Content Cards]({{site.baseurl}}/developer_guide/content_cards)를 시작으로 SDK의 커스터마이제이션 옵션이 전용 커스터마이제이션 가이드에 통합되었습니다. 이 변경을 통해 자세한 지침에 보다 쉽게 액세스할 수 있으며, 특정 요구 사항에 맞게 경험을 맞춤 설정하는 것이 더 간편해집니다.

## Canvas에서의 카드 생성 {#card-creation-in-canvas}

새로운 콘텐츠 카드 캠페인 및 캔버스 단계에서 카드가 생성되는 시점을 지정하여 Braze가 오디언스 자격 및 개인화를 평가하는 시점을 선택할 수 있습니다.

{% multi_lang_include alerts/early_access_beta_alert.md feature="Control over card creation in Canvas steps" %}

## 워크스페이스에 복사하기 {#copying-to-workspaces}

[워크스페이스 간 Campaign 복사]({{site.baseurl}}/copying_to_workspaces)를 사용하면 다른 워크스페이스에 있는 Campaign의 사본으로 시작하여 메시지 작성을 빠르게 진행할 수 있습니다. 이 사본은 편집하고 시작할 때까지 초안 상태로 유지되므로, 성공적인 메시징 전략을 보존하고 이를 기반으로 발전시킬 수 있습니다.

{% multi_lang_include alerts/early_access_beta_alert.md feature='Copying campaigns across workspaces' %}

## Push Max

[Push Max]({{site.baseurl}}/user_guide/channels/push/platform_specific_resources/android/push_max)는 실패한 푸시 알림을 추적하고 사용자가 푸시를 받을 가능성이 더 높은 시점에 푸시를 다시 발송함으로써 Android 푸시 알림의 효과를 증대시켜 줍니다. Push Max에 대해 알아보고 이 기능을 사용하여 [중국 OEM 기기]({{site.baseurl}}/user_guide/channels/push/best_practices/chinese_push_deliverability)에서 Android 푸시 알림의 전달 가능성을 잠재적으로 향상시킬 수 있는 방법을 알아보세요.

{% multi_lang_include alerts/early_access_beta_alert.md feature='Push Max' %}

## SDK 업데이트 {#sdk-updates}

최신 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 SDK 업데이트 섹션에 나열되어 있으며, 그 외 모든 업데이트는 해당 SDK 체인지로그에서 확인할 수 있습니다.

- [Xamarin SDK 2.0.0-2.0.1](https://github.com/braze-inc/braze-xamarin-sdk/blob/master/CHANGELOG.md)
    - Braze Android SDK 26.3.2를 사용하도록 Android 바인딩을 업데이트했습니다.
- [Flutter SDK 6.0.1](https://pub.dev/packages/braze_plugin/changelog)
    - 네이티브 Android 브릿지를 Braze Android SDK 26.1.0에서 26.1.1로 업데이트했습니다.
- [Android SDK 27.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [SWIFT SDK 6.5.0-6.6.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - HTML 인앱 메시지에서 커스텀 이벤트 및 구매 속성정보가 `1`과 `0` 값을 항상 각각 `true`와 `false`로 변환하던 문제를 수정했습니다. 이제 이러한 속성정보 값은 HTML에서 원래 형식을 유지합니다.
- [React Native SDK 6.0.0-6.0.2](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
    - 네이티브 Android 브릿지를 Braze Android SDK 26.3.1에서 26.3.2로 업데이트했습니다.
- [Cordova SDK 6.0.0-6.0.1](https://github.com/braze-inc/braze-cordova-sdk/blob/master/CHANGELOG.md)
    - 네이티브 Android 버전을 Braze Android SDK 26.3.1에서 26.3.2로 업데이트했습니다.
- [Expo Plugin 1.1.2](https://github.com/braze-inc/braze-expo-plugin/blob/1.1.2/CHANGELOG.md)
- [Unity 4.3.0](https://github.com/braze-inc/braze-unity-sdk/blob/master/CHANGELOG.md)
- [Segment Kotlin 1.4.1](https://github.com/braze-inc/braze-segment-kotlin/blob/main/CHANGELOG.md)
- [Segment-Android 15.0.1](https://github.com/Appboy/appboy-segment-android/blob/master/CHANGELOG.md)
