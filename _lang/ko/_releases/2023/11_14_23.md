# 2023년 11월 14일 릴리스 {#november-14-2023-release}

## Braze 시작하기 {#getting-started-with-braze}

흥미로운 소식입니다! Braze [마케터]({{site.baseurl}}/user_guide/get_started)와 [개발자]({{site.baseurl}}/developer_guide/getting_started)를 위해 특별히 맞춤화된 두 개의 시작하기 섹션을 소개합니다. 이 섹션은 필요한 모든 도구와 안내를 제공하여 Braze를 빠르게 시작하는 데 도움이 되도록 설계되었습니다. 지금 바로 들어가서 탐색을 시작하세요.

## 새로운 Braze 대시보드 인스턴스 {#new-braze-dashboard-instance}

Braze는 대시보드 및 REST 엔드포인트에 대한 다양한 인스턴스를 관리합니다. 새 대시보드 인스턴스 `US-07`이 추가되었습니다. 자세한 내용은 [API 개요]({{site.baseurl}}/api/basics)를 참조하세요.

## 강력한 채널 {#robust-channels}

### 인앱 메시지를 위한 커스텀 드래그 앤 드롭 템플릿 {#custom-drag-and-drop-templates-for-in-app-messages}

{% multi_lang_include release_type.md release="General availability" %}

이제 [인앱 메시지용 커스텀 드래그 앤 드롭 템플릿]({{site.baseurl}}/user_guide/channels/in_app_messages/drag_and_drop)을 사용하여 드래그 앤 드롭 편집기에서 인앱 메시지 디자인을 시작할 수 있습니다.

### SMS 더블 옵트인 {#sms-double-opt-in}

{% multi_lang_include release_type.md release="General availability" %}

[SMS 더블 옵트인]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/keyword_processing/double_opt_in)을 사용하면 사용자가 SMS 메시지를 수신하기 전에 옵트인 의사를 명시적으로 확인하도록 요구할 수 있습니다. 이를 통해 SMS에 참여할 가능성이 높거나 이미 참여 중인 사용자에게 집중할 수 있습니다.

### 이메일 보고를 위한 예상 실제 열람율 {#estimated-real-open-rate-for-email-reporting}

{% multi_lang_include release_type.md release="General availability" %}

[예상 실제 열람율]({{site.baseurl}}/user_guide/message_building_by_channel/email/reporting_and_analytics/email_reporting#estimated-real-open-rate)은 Braze에서 개발한 독자적인 분석 모델을 사용하여 기계 열람이 존재하지 않는 것처럼 Campaign의 고유 열람율 추정치를 재구성합니다. Braze는 각 Campaign의 클릭 데이터를 사용하여 실제 사용자가 메시지를 열어본 비율을 추론합니다. 이는 Apple의 MPP를 비롯한 다양한 기계 열람 메커니즘을 보완합니다.

### Canvas를 위한 개인화된 경로 {#personalized-paths-for-canvas}

{% multi_lang_include release_type.md release="Beta" %}

[개인화된 경로]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step/personalized_paths)를 사용하면 Campaigns의 개인화된 배리언트와 유사하게 전환 가능성에 따라 개별 사용자의 전체 Canvas 여정을 개인화할 수 있습니다. 실험 경로 단계와 함께 개인화된 경로를 사용하여 일부 사용자를 지연 그룹에 유지하면서 Braze가 나머지 경로를 서로 테스트합니다.

## 데이터 유연성 {#data-flexibility}

### Braze 대시보드 검색 {#searching-your-braze-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

[검색창]({{site.baseurl}}/user_guide/administer/personal/the_braze_dashboard)을 사용하여 Braze 대시보드 내에서 작업 및 기타 정보를 찾을 수 있습니다. 검색창은 Braze 대시보드 상단에 있습니다.

### 커스텀 속성 및 이벤트 차단 목록 {#blocklisting-custom-attributes-and-events}

{% multi_lang_include release_type.md release="General availability" %}

이제 한 번에 최대 10개의 커스텀 속성 또는 이벤트를 차단 목록에 추가할 수 있습니다. 자세한 내용은 [커스텀 이벤트 및 속성 관리]({{site.baseurl}}/user_guide/data/activation/custom_data/managing_custom_data)를 참조하세요.

### 새 도움말 문서: 유니버설 링크 및 앱 링크 {#new-help-article-universal-links-and-app-links}

Apple 유니버설 링크와 Android 앱 링크는 웹 콘텐츠와 모바일 앱 간의 원활한 전환을 제공하기 위해 고안된 메커니즘입니다. 유니버설 링크는 iOS에만 해당되지만, Android 앱 링크는 Android 애플리케이션에서 동일한 목적을 수행합니다.

이 주제에 대한 자세한 내용은 [유니버설 링크 및 앱 링크]({{site.baseurl}}/user_guide/channels/email/customize/universal_links_and_app_links) 전용 문서를 참조하세요.

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### Olo - 채널 확장 {#olo-channel-extensions}

Braze와 [Olo]({{site.baseurl}}/partners/ecommerce/ordering_payments_subscription/olo)의 통합을 통해 Braze에서 사용자 프로필을 업데이트하여 Olo 사용자 프로필과 일관성을 유지할 수 있습니다. 또한 Olo 이벤트를 기반으로 Braze에서 적절한 메시지를 보낼 수도 있습니다.

### Typeform - 고객 데이터 플랫폼 {#typeform-customer-data-platform}

Braze와 [Typeform]({{site.baseurl}}/partners/additional_channels_and_extensions/extensions/surveys/typeform)의 통합을 통해 Typeform 응답에서 수집된 데이터로 Braze의 사용자 프로필을 업데이트하고, 사용자의 Typeform 참여에 따라 Braze에서 메시지를 트리거하고, 사용자의 Typeform 응답을 기반으로 Braze 메시지를 개인화할 수 있습니다.

## SDK 업데이트 {#sdk-updates}

다음 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 아래에 나열되어 있으며, 그 외의 모든 업데이트는 해당 SDK 체인지로그에서 확인할 수 있습니다.

- [웹 SDK v4.10.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [웹 SDK v5.0.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [Android SDK 29.0.1](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [Swift SDK 7.1.0-7.2.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - `Braze.Configuration.DeviceProperty.pushDisplayOptions`는 더 이상 사용되지 않습니다. 이 값을 제공해도 더 이상 효과가 없습니다.
- [React Native SDK 8.0.0-8.1.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
    - 네이티브 Android 브릿지를 Braze Android SDK 27.0.1에서 29.0.0으로 업데이트합니다.
    - 네이티브 iOS 브릿지를 Braze Swift SDK 6.6.0에서 7.0.0으로 업데이트합니다.
    - `Banner` Content Cards 유형의 이름을 ImageOnly로 변경합니다:
        - `BannerContentCard`에서 `ImageOnlyContentCard`로
        - `ContentCardTypes.BANNER`에서 `ContentCardTypes.IMAGE_ONLY`로
    - Android에서 프로젝트의 XML 파일에 Content Cards용 `banner`라는 단어가 포함되어 있으면 `image_only`로 대체해야 합니다.
    - `Braze.getFeatureFlag(id)`는 이제 피처 플래그가 존재하지 않으면 `null`을 반환합니다.
    - `Braze.Events.FEATURE_FLAGS_UPDATED`는 새로고침 요청이 성공 또는 실패로 완료된 경우와 현재 세션에서 이전에 캐시된 데이터가 있는 경우 최초 구독 시에만 트리거됩니다.
