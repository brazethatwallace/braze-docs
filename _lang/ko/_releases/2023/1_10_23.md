# 2023년 1월 10일 릴리스 {#january-10-2023-release}

## Canvas Flow용 사용자 업데이트 구성요소 {#user-update-component-for-canvas-flow}

[사용자 업데이트]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/user_update) 구성요소를 사용하면 JSON 작성기에서 사용자의 속성, 이벤트 및 구매를 업데이트할 수 있으므로 API 키와 같은 민감한 정보를 포함할 필요가 없습니다.

## API를 통해 구독 그룹 설정하기 {#setting-subscription-groups-via-api}

[`/users/track` 엔드포인트]({{site.baseurl}}/api/endpoints/user_data/post_user_track)를 통해 새 사용자를 생성할 때 사용자 속성 오브젝트 내에서 구독 그룹을 설정할 수 있으며, 이를 통해 한 번의 API 호출로 사용자를 생성하고 구독 그룹 상태를 설정할 수 있습니다.

## 전환 대시보드 얼리 액세스 {#conversions-dashboard-early-access}

[전환 대시보드]({{site.baseurl}}/user_guide/analytics/dashboards/conversions)를 사용하면 다양한 기여도 방법을 활용하여 Campaign(캠페인), Canvas 및 채널 전반의 전환을 분석할 수 있습니다. 다음과 같은 기여도 방법을 구체적으로 추적할 수 있습니다:

- **열람 전환:** 사용자가 메시지를 연 후 발생한 전환
- **클릭 전환:** 사용자가 메시지를 클릭한 후 발생한 전환
- **수신 전환:** 사용자가 메시지를 수신한 후 발생한 전환
- **라스트 클릭 전환:** 사용자가 메시지를 클릭한 후 발생한 전환(해당 메시지가 사용자가 가장 최근에 클릭한 메시지인 경우) (이 기능은 현재 일부 얼리 액세스 고객을 대상으로 테스트 중입니다)

이 기능은 현재 얼리 액세스 중입니다. 얼리 액세스에 참여하고 싶으시다면 고객 성공 매니저에게 문의하세요.

## Braze 커런츠용 Canvas 종료 이벤트 {#canvas-exit-events-for-braze-currents}

이제 사용자가 이벤트를 수행하거나 오디언스를 매칭하여 Canvas에서 나가는 시점을 추적할 수 있습니다. 자세한 내용은 Currents 이벤트 용어집의 [메시지 인게이지먼트 이벤트]({{site.baseurl}}/user_guide/data/distribution/braze_currents/event_glossary/message_engagement_events) 섹션을 참조하세요.

## SDK 업데이트 {#sdk-updates}

다음 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 아래에 나열되어 있으며, 그 외의 모든 업데이트는 해당 SDK 체인지로그를 확인하시기 바랍니다.

- [웹 SDK 4.5.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [AppboyKit iOS SDK 4.5.2](https://github.com/Appboy/appboy-ios-sdk/releases/tag/4.5.2)
- [Swift SDK 5.8.0-5.8.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#580)
  - 같은 이름의 모듈을 섀도잉하지 않도록 `BrazeLocation` 클래스의 이름을 `BrazeLocationProvider`로 변경했습니다.
- [Flutter SDK 3.0.1](https://pub.dev/packages/braze_plugin/changelog)
- [Android SDK 24.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
  - 위치 및 지오펜스 기능이 `com.braze:android-sdk-location`이라는 새 모듈로 이전되었습니다.
  - Appboy 클래스와 파일이 Braze로 일괄 이전되었습니다.
  - Content Cards를 정렬할 때 마지막 업데이트 시간 대신 생성 시간을 사용하도록 `DefaultContentCardsUpdateHandler`의 기본 동작을 변경했습니다.
  - BrazeUser.setFacebookData() 및 BrazeUser.setTwitterData()를 제거했습니다.
