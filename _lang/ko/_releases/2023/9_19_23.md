# 2023년 9월 19일 릴리스 {#september-19-2023-release}

## 클라우드 데이터 수집을 위한 BigQuery {#bigquery-for-cloud-data-ingestion}

이제 서버리스 엔터프라이즈 데이터 웨어하우스인 [BigQuery](https://cloud.google.com/bigquery)를 사용하여 클라우드 데이터 수집 통합을 생성할 수 있습니다. 자세한 내용은 [클라우드 데이터 수집 통합]({{site.baseurl}}/user_guide/data_and_analytics/cloud_ingestion/integrations/?tab=bigquery)을 참조하세요.

## Braze 데이터 변환 {#braze-data-transformation}

[Braze 데이터 변환]({{site.baseurl}}/user_guide/data/unification/data_transformation)을 사용하면 웹훅 통합을 구축하고 관리하여 외부 플랫폼에서 Braze 사용자 프로필로의 데이터 흐름을 자동화할 수 있습니다. 이렇게 새로 통합된 사용자 데이터를 활용하면 더욱 정교한 마케팅 사용 사례를 구현할 수 있습니다.

## Canvas에서 댓글 달기 {#commenting-in-canvas}

[Canvas에서의 댓글]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas/canvas_comments)은 마케팅 팀이 Canvases의 세부 사항을 파악하고 논의하며 검토할 수 있는 훌륭한 협업 공간이 될 수 있습니다. Canvas를 구성하면서 동료의 추가 피드백이 필요한 영역을 파악하기 위해 댓글을 작성하고 관리할 수 있습니다.

## 전달 가능성 센터 {#deliverability-center}

[전달 가능성 센터]({{site.baseurl}}/user_guide/analytics/dashboards/deliverability_center)는 Gmail Postmaster Tools 사용을 지원하여 발송된 이메일에 대한 데이터를 추적하고 발송 도메인에 대한 데이터를 수집함으로써, 이메일 성능에 대한 더 깊은 인사이트를 제공합니다.

이메일 전달 가능성은 Campaign 성공의 핵심입니다. Braze 대시보드의 전달 가능성 센터를 사용하면 IP 평판이나 전달 오류별로 도메인을 조회하여 이메일 전달 가능성과 관련된 잠재적인 문제를 발견하고 해결할 수 있습니다.

## 인앱 메시지용 드래그 앤 드롭 편집기 {#drag-and-drop-editor-for-in-app-messages}

[인앱 메시지용 드래그 앤 드롭 편집기]({{site.baseurl}}/user_guide/channels/in_app_messages/drag_and_drop)에 다음과 같은 추가 기능이 도입되었습니다.

- 메시지를 닫지 않는 텍스트 링크
- 푸시 프라이머를 요청하는 버튼 동작
- 커스텀 코드 편집기 블록

드래그 앤 드롭 편집기에서 사용할 수 있는 모든 기능을 활용하려면 SDK를 권장 SDK 버전으로 업데이트하세요.

### 커스텀 템플릿 저장 (얼리 액세스) {#save-custom-templates-early-access}

인앱 메시지용 드래그 앤 드롭 편집기에서, 얼리 액세스 참가자는 편집기를 종료한 후 사용할 수 있는 **템플릿으로 저장** 버튼을 사용하여 커스텀 인앱 메시지 템플릿을 만들고 저장할 수 있습니다. 템플릿으로 저장하려면 먼저 Campaign을 시작하거나 초안으로 저장해야 합니다.

**템플릿** > **인앱 메시지 템플릿**으로 이동하여 인앱 메시지 템플릿을 만들고 저장할 수도 있습니다.

## 인앱 메시지에서 다크 모드 비활성화 {#disabling-dark-mode-for-in-app-messages}

개발자는 사용자 기기에서 다크 모드가 켜져 있을 때 인앱 메시지가 다크 모드 스타일을 적용하지 않도록 설정할 수 있습니다. 이를 구현하는 방법에 대한 단계는 플랫폼별 다음 설명서를 참조하세요.

- [Swift]({{site.baseurl}}/developer_guide/platform_integration_guides/swift/in-app_messaging/customization/setting_delegates#disabling-dark-mode)
- [OBJECTIVE-C]({{site.baseurl}}/developer_guide/platform_integration_guides/ios/in-app_messaging/customization/handling_in_app_display#disabling-dark-mode)

## 메시지 아카이빙을 위한 새 필드 {#new-fields-for-message-archiving}

[메시지 아카이빙]({{site.baseurl}}/user_guide/data/distribution/export_braze_data/message_archiving)을 사용하면 아카이빙 또는 규정 준수 목적으로 사용자에게 발송된 메시지의 사본을 S3 버킷에 저장할 수 있습니다. 메시지가 발송될 때마다 S3 버킷으로 전달되는 JSON 페이로드에 다음 필드가 추가되었습니다:

- `user_id`
- `campaign_name`
- `canvas_name`
- `canvas_step_name`

## 새로운 Liquid 개인화 태그 {#new-liquid-personalization-tags}

인앱 메시지의 경우, Liquid 내에서 다음과 같은 앱 속성을 사용할 수 있습니다. 값은 앱이 메시징을 요청하는 데 사용하는 SDK API 키를 기반으로 합니다:

- {% raw %}`{{app.${api_id}}}`{% endraw %}
- {% raw %}`{{app.${name}}}`{% endraw %}

자세한 내용은 [지원되는 개인화 태그]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/supported_personalization_tags#targeted-app-information)를 참조하세요.

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### Antavo Loyalty Cloud – 채널 확장 {#antavo-loyalty-cloud-channel-extensions}

[Antavo]({{site.baseurl}}/partners/data_and_analytics/loyalty/antavo)와 Braze 통합을 통해 로열티 프로그램 관련 데이터를 활용하여 개인화된 Campaign을 구축하고 고객 경험을 향상시킬 수 있습니다. Antavo는 두 플랫폼 간의 로열티 데이터 동기화를 지원하며, 이는 Antavo에서 Braze로의 단방향 데이터 동기화만 가능합니다.

### Ketch – 고객 데이터 플랫폼 {#ketch-customer-data-platform}

Braze와 [Ketch]({{site.baseurl}}/partners/data_and_analytics/data_privacy/ketch) 통합을 통해 Ketch 환경설정 센터에서 고객 커뮤니케이션 환경설정을 제어하고, 이러한 변경 사항을 Braze에 자동으로 전파할 수 있습니다.

### Redpoint – 고객 데이터 플랫폼 {#redpoint-customer-data-platform}

Redpoint는 마케터에게 완전히 통합된 캠페인 오케스트레이션 플랫폼을 제공하는 기술 플랫폼입니다. Braze와 [Redpoint]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/redpoint) 통합을 통해 Redpoint 고객 데이터 플랫폼 데이터를 기반으로 Braze Segments를 생성할 수 있습니다.

### Simon Data – 고객 데이터 플랫폼 {#simon-data-customer-data-platform}

Braze와 [Simon Data]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/simonai) 통합을 사용하여 정교한 오디언스를 생성하고 코드 없이 실시간으로 Braze에 동기화하여 오케스트레이션할 수 있습니다. 이 통합을 통해 Simon의 캠페인 우선순위 지정 및 ID 매칭 기능, 복잡한 집계 지원 등을 활용하여 다운스트림에서 Braze Campaign의 효과를 높일 수 있습니다.

## SDK 업데이트 {#sdk-updates}

최신 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 SDK 업데이트 섹션에 나열되어 있으며, 그 외 모든 업데이트는 해당 SDK 체인지로그에서 확인할 수 있습니다.

- [Swift SDK 6.6.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#661)
- [Web SDK 4.9.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md#490)
- [Android SDK 28.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2800)
    - 최소 SDK 버전이 21(Lollipop)로 업데이트되었습니다.
    - 기능 플래그 함수가 수정되었습니다.
    - `Braze.getFeatureFlag(id)`는 이제 기능 플래그가 존재하지 않을 경우 null을 반환합니다.
    - `Braze.subscribeToFeatureFlagsUpdates()`는 새로고침 요청이 완료될 때만 콜백되며, 이전에 캐시된 데이터가 있는 경우 초기에도 콜백됩니다. 또한 새로고침 실패 시에도 캐시된 기능 플래그와 함께 호출됩니다.
        - 앱 시작 시 캐시된 값을 즉시 가져오려면 `Braze.getFeatureFlag(id)`를 사용하세요.
    - `DefaultInAppMessageViewWrapper.createButtonClickListener()`가 `DefaultInAppMessageViewWrapper.createButtonClickListeners()`로 리팩토링되었습니다.
- [React Native SDK 7.0.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md#700)
    - 네이티브 Android 브리지가 [Braze Android SDK 26.3.2에서 27.0.1](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2701)로 업데이트되었습니다.
- [Cordova SDK 7.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2800)
    - 네이티브 Android 브리지가 [Braze Android SDK 26.3.2에서 27.0.1](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2701)로 업데이트되었습니다.
- [Roku SDK 2.0.0](https://github.com/braze-inc/braze-roku-sdk/blob/main/CHANGELOG.md#200)
    - `getFeatureFlag`는 플래그가 존재하지 않을 경우 invalid를 반환합니다.
    - `BrazeTask`는 이제 `BrazeFeatureFlagsUpdated`를 관찰하여 기능 플래그 새로고침의 성공 또는 실패를 확인합니다. 데이터 값이 항상 다르지는 않을 수 있습니다.
