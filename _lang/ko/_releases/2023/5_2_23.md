# 2023년 5월 2일 릴리스 {#may-2-2023-release}

## 새롭게 디자인된 Braze UI/UX {#redesigned-braze-uiux}

_2023년 5월 16일부터 일반 사용 가능_

새롭게 디자인된 UI/UX 및 정보 아키텍처로 시간을 절약하고 필요한 정보를 정확하게 찾아보세요. 플랫폼 전반을 빠르게 탐색하고, 작업을 완료하고, 새로운 기능을 쉽게 발견하세요. 여러분과 여러분의 팀이 보다 쉽게 전환할 수 있도록 전용 [탐색 가이드]({{site.baseurl}}/user_guide/administer/personal/the_braze_dashboard)를 통해 변경된 사항과 향후 예상되는 사항을 알아보세요.

## 쿼리 빌더 {#query-builder}

[쿼리 빌더]({{site.baseurl}}/user_guide/analytics/reports/query_builder)를 사용하면 Snowflake에서 Braze 데이터를 사용하여 보고서를 생성할 수 있습니다. 쿼리 빌더에는 미리 작성된 SQL 쿼리 템플릿이 제공되어 쉽게 시작할 수 있으며, 커스텀 SQL 쿼리를 직접 작성하여 더 많은 인사이트를 얻을 수도 있습니다.

## Canvas 버전 기록 {#canvas-version-history}

[버전 기록]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/canvas_version_history)을 통해 Canvas의 이전 버전에 대한 분석 및 사용자 여정을 보고 액세스할 수 있습니다. Canvas 버전 기록을 참조하면 Canvas의 진화 과정을 기록하는 데 특히 유용할 수 있습니다.

## SQL Segments의 증분 새로고침 {#incremental-refresh-for-sql-segments}

이제 최근 2일 분량의 데이터만 새로고침하는 증분 새로고침을 사용하는 [SQL 세그먼트 확장]({{site.baseurl}}/user_guide/audience/segments/segment_extension/sql_segments)을 만들 수 있습니다. 이 방식은 비용 효율성이 더 높고, 세그먼트 멤버십이 새로고침될 때마다 SQL Segment 크레딧을 더 적게 사용합니다. 전체 새로고침 확장과 달리, 증분 새로고침 확장은 멤버십을 매일 자동으로 갱신하도록 설정할 수 있습니다.

## 이메일 전달 가능성 센터 {#deliverability-center-for-email}

[전달 가능성 센터]({{site.baseurl}}/user_guide/data_and_analytics/analytics/deliverability_center#deliverability-center)는 Gmail Postmaster Tools를 사용하여 발송된 이메일 데이터를 추적하고 발송 도메인에 대한 데이터를 수집할 수 있도록 지원하여 이메일 성능에 대한 더 많은 인사이트를 제공합니다.

{% alert important %}
전달 가능성 센터는 현재 얼리 액세스 중입니다. 얼리 액세스에 참여하려면 Braze 고객 성공 매니저에게 문의하세요.
{% endalert %}

## 카탈로그 제한 사항 업데이트 {#update-for-catalog-limitations}

2023년 5월 1일부로 [카탈로그 저장 한도]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog#limits)에 대한 업데이트가 있었습니다. 카탈로그 저장소 업그레이드를 요청하려면 Braze 계정 매니저에게 문의하세요.

## 새로운 API 및 SDK 엔드포인트 문서 {#new-api-and-sdk-endpoints-article}

Braze는 "클러스터"라고 부르는 대시보드, SDK 및 REST 엔드포인트에 대한 다양한 인스턴스를 관리합니다. 사용 가능한 Braze 인스턴스에 대한 대시보드 URL, API 엔드포인트 및 SDK 엔드포인트 목록은 [API 및 SDK 엔드포인트]({{site.baseurl}}/user_guide/administer/personal/sdk_endpoints)를 확인하세요.

[Liquid에 대해 자주 묻는 질문]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/faq)에 대한 답변을 준비했습니다.

## iOS SDK 지원 중단 - Swift {#ios-sdk-deprecation-swift}

Braze의 레거시 iOS SDK는 새로운 Swift SDK로 대체되어 지원이 중단됩니다. 이를 통해 향상된 성능, 새로운 기능, [새로운 설명서]({{site.baseurl}}/developer_guide/platform_integration_guides/swift/initial_sdk_setup/overview)를 포함한 많은 개선 사항이 제공됩니다!

업그레이드를 원하시나요? 자세한 내용은 [마이그레이션 가이드](https://braze-inc.github.io/braze-swift-sdk/documentation/braze/appboy-migration-guide/)를 확인하세요.
