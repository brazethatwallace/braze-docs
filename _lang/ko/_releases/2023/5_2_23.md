# 2023년 5월 2일 릴리스 {#may-2-2023-release}

## 새롭게 디자인된 Braze UI/UX {#redesigned-braze-uiux}

_2023년 5월 16일에 정식 출시_

새롭게 디자인된 UI/UX와 정보 구조로 시간을 절약하고 필요한 것을 정확히 찾을 수 있습니다. 플랫폼 전체를 빠르게 탐색하고, 작업을 완료하며, 새로운 기능을 손쉽게 발견할 수 있습니다. 이 전환을 더 쉽게 진행할 수 있도록, 전용 [탐색 가이드]({{site.baseurl}}/user_guide/administer/personal/the_braze_dashboard)에서 변경된 사항과 앞으로 기대할 수 있는 내용을 확인해 보세요.

## 쿼리 빌더 {#query-builder}

[쿼리 빌더]({{site.baseurl}}/user_guide/analytics/reports/query_builder)를 사용하면 Snowflake의 Braze 데이터를 활용하여 보고서를 생성할 수 있습니다. 쿼리 빌더에는 바로 사용할 수 있는 사전 구축된 SQL 쿼리 템플릿이 제공되며, 직접 커스텀 SQL 쿼리를 작성하여 더 깊은 인사이트를 확보할 수도 있습니다.

## Canvas 버전 기록 {#canvas-version-history}

[버전 기록]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/canvas_version_history)을 사용하면 이전 버전의 Canvas에 대한 분석 및 사용자 여정을 확인하고 액세스할 수 있습니다. Canvas 버전 기록을 참조하면 Canvas의 변화 과정을 기록으로 유지하는 데 특히 유용합니다.

## SQL Segments의 증분 새로고침 {#incremental-refresh-for-sql-segments}

이제 증분 새로고침을 사용하는 [SQL 세그먼트 확장]({{site.baseurl}}/user_guide/audience/segments/segment_extension/sql_segments)을 생성할 수 있습니다. 증분 새로고침은 최근 2일간의 데이터만 새로고침합니다. 이 방식은 비용 효율적이며 Segment 멤버십이 새로고침될 때마다 사용하는 SQL Segment 크레딧이 줄어듭니다. 전체 새로고침 확장과 달리, 증분 새로고침 확장은 매일 자동으로 멤버십을 재생성하도록 설정할 수 있습니다.

## 이메일 전달 가능성 센터 {#deliverability-center-for-email}

[전달 가능성 센터]({{site.baseurl}}/user_guide/data_and_analytics/analytics/deliverability_center#deliverability-center)는 Gmail Postmaster Tools를 활용하여 발송된 이메일에 대한 데이터를 추적하고 발송 도메인에 대한 데이터를 수집할 수 있도록 지원함으로써 이메일 성능에 대한 더 많은 인사이트를 제공합니다.

{% alert important %}
전달 가능성 센터는 현재 얼리 액세스 단계에 있습니다. 얼리 액세스 참여에 관심이 있으시면 Braze 고객 성공 매니저에게 문의해 주세요.
{% endalert %}

## 카탈로그 제한 사항 업데이트 {#update-for-catalog-limitations}

2023년 5월 1일부로 [카탈로그 저장 용량 제한]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog#limits)이 업데이트되었습니다. 카탈로그 저장 용량 업그레이드를 요청하려면 Braze 계정 매니저에게 문의하세요.

## 새로운 API 및 SDK 엔드포인트 문서 {#new-api-and-sdk-endpoints-article}

Braze는 대시보드, SDK, REST 엔드포인트를 위한 다양한 인스턴스를 관리하며, 이를 "클러스터"라고 부릅니다. 사용 가능한 Braze 인스턴스의 대시보드 URL, API 엔드포인트, SDK 엔드포인트 목록은 [API 및 SDK 엔드포인트]({{site.baseurl}}/user_guide/administer/personal/sdk_endpoints)를 확인하세요.

## iOS SDK 지원 종료 - Swift {#ios-sdk-deprecation-swift}

Braze의 레거시 iOS SDK는 새로운 Swift SDK로 대체되면서 지원이 종료됩니다. 이를 통해 향상된 성능, 새로운 기능, 그리고 [새로운 설명서]({{site.baseurl}}/developer_guide/sdk_integration?sdktab=swift)를 포함한 다양한 개선 사항이 제공됩니다!

업그레이드를 고려하고 계신가요? 자세한 내용은 [마이그레이션 가이드](https://braze-inc.github.io/braze-swift-sdk/documentation/braze/appboy-migration-guide/)를 확인해 보세요.
