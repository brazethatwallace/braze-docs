# 2023년 2월 7일 릴리스 {#february-7-2023-release}

## 접근 가능한 메시지 만들기 {#building-accessible-messages}

의도하지 않았더라도 장애를 가진 사람들을 배제하는 마케팅 콘텐츠는 수백만 명이 브랜드와 상호작용하지 못하게 만들 수 있습니다. 마케팅에서의 접근성이란 모든 사람이 마케팅을 쉽게 경험하고, 커뮤니케이션을 수신하고 이해하며, 제품, 서비스 또는 브랜드에 투자하거나 팬이 될 수 있는 기회를 갖도록 하는 것을 의미합니다. 자세한 안내는 [Braze에서 접근 가능한 메시지 만들기]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/accessibility)를 참조하세요.

## 쿼리 빌더 얼리 액세스 {#query-builder-early-access}

[쿼리 빌더]({{site.baseurl}}/user_guide/analytics/reports/query_builder)를 사용하면 Snowflake의 Braze 데이터를 활용하여 보고서를 생성할 수 있습니다. 쿼리 빌더에는 미리 작성된 SQL 쿼리 템플릿이 포함되어 있어 쉽게 시작할 수 있습니다. 현재는 템플릿 쿼리만 허용됩니다. 커스텀 SQL 쿼리 지원은 추후 제공될 예정입니다.

이 기능은 현재 얼리 액세스 단계에 있습니다. 얼리 액세스에 참여하고 싶으시다면, 고객 성공 매니저에게 문의하세요.

## 기능 플래그 베타 {#feature-flags-beta}

[기능 플래그]({{site.baseurl}}/developer_guide/feature_flags)를 사용하면 선택한 사용자에 대해 기능을 원격으로 활성화하거나 비활성화할 수 있습니다. 추가 코드 배포나 앱 스토어 업데이트 없이 프로덕션 환경에서 기능을 켜거나 끌 수 있습니다. 이를 통해 새로운 기능을 안심하고 안전하게 롤아웃할 수 있습니다.

이 기능은 현재 베타 버전입니다. 베타 참여에 관심이 있으시면 고객 성공 매니저에게 문의하세요.

## 새로운 Currents 이벤트 {#new-currents-events}

다음 Currents 이벤트가 최근 릴리스되어 [메시지 인게이지먼트 이벤트]({{site.baseurl}}/user_guide/data/distribution/braze_currents/event_glossary/message_engagement_events) 및 [고객 행동 및 사용자 이벤트]({{site.baseurl}}/user_guide/data/distribution/braze_currents/event_glossary/customer_behavior_events) 용어집에 추가되었습니다.

메시지 중단 이벤트:
- `users.messages.contentcard.abort`
- `users.messages.email.abort`
- `users.messages.inappmessage.abort`
- `users.messages.pushnotification.abort`
- `users.messages.sms.abort`
- `users.messages.webhook.abort`

단문 메시지 서비스 짧은 링크 클릭 이벤트:
- `users.messages.sms.ShortLinkClick`

글로벌 상태 변경 구독 이벤트:
- `users.behaviors.subscription.GlobalStateChange`

구독 그룹 상태 변경 이벤트:
- `users.behaviors.subscriptiongroup.StateChange`

Canvas 종료 이벤트:
- `users.canvas.exit.PerformedEvent`
- `users.canvas.exit.MatchedAudience`

## 개인화된 배리언트 {#personalized-variant}

A/B 테스트를 보낼 때 사용자에게 개인화된 배리언트를 전송하여 참여할 가능성이 가장 높은 배리언트를 보낼 수 있습니다. 개인화된 배리언트가 어떻게 선택되는지, 그리고 Campaigns에서 이를 활용하는 방법에 대한 자세한 내용은 [다변량 분석]({{site.baseurl}}/user_guide/engagement_tools/testing/multivariant_testing/multivariate_analytics#personalized-variant)을 참조하세요.

## SQL 세그먼트 확장 얼리 액세스 {#sql-segment-extensions-early-access}

[세그먼트 확장]({{site.baseurl}}/sql_segments)을 사용하면 Snowflake 데이터의 Snowflake SQL 쿼리를 활용하여 세그먼트 확장을 생성할 수 있습니다. SQL은 다른 세분화 기능으로는 달성할 수 없는 방식으로 데이터 간의 관계를 설명할 수 있는 유연성을 제공하므로, 새로운 Segment 사용 사례를 활용하는 데 도움이 됩니다.

## Canvas 출시 전후 체크리스트 {#pre-and-post-launch-checklist-for-canvas}

Canvas를 출시하기 전과 후에 확인해야 할 여러 세부 사항이 있습니다:
- 메시징과 발송 시간이 오디언스의 선호도에 맞는지 확인하세요
- 시간대, 진입 설정 등의 차이를 고려하세요
- 출시 후 이러한 시나리오에 따라 불일치가 발생할 경우 Canvas를 검토하고 조정하세요

이 [체크리스트]({{site.baseurl}}/user_guide/messaging/canvas/ideas_and_strategies/pre_post_launch_checklist)를 가이드로 활용하여 사용 사례에 맞게 이러한 영역을 세밀하게 조정하고 Canvas의 성공에 기여하세요.

## 새로운 API 엔드포인트: 사용자 별칭 업데이트 {#new-api-endpoint-update-user-alias}

[사용자 별칭 업데이트 엔드포인트]({{site.baseurl}}/api/endpoints/user_data/post_users_alias_update)를 사용하여 기존 사용자 별칭을 업데이트합니다.

## SDK 업데이트 {#sdk-updates}

최신 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 SDK 업데이트 섹션에 나열되어 있으며, 그 외 모든 업데이트는 해당 SDK 체인지로그에서 확인할 수 있습니다.

- [웹 SDK 4.6.0-4.6.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md#461)
- [Android SDK 24.1.0-24.2.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2420)
- [AppboyKit iOS SDK 4.5.3](https://github.com/Appboy/appboy-ios-sdk/releases/tag/4.5.3)
- [SWIFT SDK 5.9.0-5.9.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#591)
  - 최소 배포 대상이 iOS 11.0 및 tvOS 11.0으로 상향되었습니다.
  - Xcode 버전이 14.1(14B47b)로 상향되었습니다.
- [Flutter SDK 3.1.0](https://pub.dev/packages/braze_plugin/changelog)
  - 네이티브 Android 브릿지가 Braze Android SDK 24.2.0을 사용합니다.
  - 네이티브 iOS 브릿지가 Braze iOS SDK 5.9.0을 사용합니다.
  - 최소 iOS 배포 대상은 11.0입니다.
- [Cordova SDK 2.33.0](https://github.com/Appboy/appboy-cordova-sdk/blob/2.33.0/CHANGELOG.md#2330)
  - iOS 플러그인이 새로운 Braze SWIFT SDK(5.8.1)를 사용하도록 마이그레이션되었습니다.
  - News Feed UI는 더 이상 iOS에서 지원되지 않습니다.
