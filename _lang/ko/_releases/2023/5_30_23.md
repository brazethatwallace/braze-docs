# 2023년 5월 30일 릴리스 {#may-30-2023-release}

## Braze 내비게이션 개편 {#redesigned-braze-navigation}

Braze 내비게이션이 업데이트되어 콘텐츠를 더 빠르고 효율적으로 만들고 액세스할 수 있게 되었습니다. 이제 기능들이 Braze에서의 마케터 워크플로에 익숙하고 관련성 높은 직관적인 카테고리로 구성되어 있습니다. 앞으로 몇 달간 기존 내비게이션과 새로운 내비게이션 경험을 자유롭게 전환할 수 있습니다. 변경 사항에 대한 자세한 내용은 [Braze 내비게이션]({{site.baseurl}}/user_guide/administer/personal/the_braze_dashboard)을 참조하세요.

## 새로운 Currents 이벤트 {#new-currents-events}

다음 WhatsApp Currents 이벤트가 최근 출시되어 [메시지 인게이지먼트 이벤트]({{site.baseurl}}/user_guide/data/distribution/braze_currents/event_glossary/message_engagement_events) 용어집에 추가되었습니다:

메시지 중단 이벤트:
- `users.messages.whatsapp.Send`
- `users.messages.whatsapp.Abort`
- `users.messages.whatsapp.Delivery`
- `users.messages.whatsapp.Failure`
- `users.messages.whatsapp.Read`
- `users.messages.whatsapp.InboundReceive`

## 브라우저 내 카탈로그 편집 및 카탈로그 셀렉션 {#in-browser-catalog-editing-and-catalog-selections}

카탈로그는 이제 브라우저 내 편집과 [셀렉션]({{site.baseurl}}/user_guide/data/activation/catalogs/selections)을 지원합니다. 셀렉션은 Campaign의 각 사용자에게 메시지를 개인화하는 데 사용할 수 있는 데이터 그룹입니다. [카탈로그]({{site.baseurl}}/user_guide/data/activation/catalogs)를 생성한 후, Braze Campaigns에 셀렉션을 통합하여 이 데이터를 추가로 참조할 수 있습니다.

`message_extras` Liquid 태그를 사용하면 연결된 콘텐츠, 카탈로그, 커스텀 속성(예: 언어, 국가), Canvas 진입 속성정보 또는 기타 데이터 소스의 동적 데이터로 전송 이벤트에 주석을 달고, 추가 데이터를 Currents 또는 Snowflake 데이터 공유로 다시 전송할 수 있습니다.

## Currents 및 Snowflake 데이터 공유 message_extras Liquid 태그 {#currents-and-snowflake-data-sharing-message_extras-liquid-tag}

[`message_extras` Liquid 태그]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/advanced_filters/message_extras)를 사용하면 연결된 콘텐츠, 카탈로그, 커스텀 속성(예: 언어, 국가), Canvas 진입 속성정보 또는 기타 데이터 소스의 동적 데이터로 전송 이벤트에 주석을 달고, 추가 데이터를 Currents 또는 Snowflake 데이터 공유로 다시 전송할 수 있습니다.

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### Tangerine - 현지화 {#tangerine-localization}
Braze와 [Tangerine]({{site.baseurl}}/partners/ecommerce/analytics_workflow/tangerine) 통합을 통해 Braze의 원시 Campaign 및 노출 횟수 데이터를 Snowflake Secure Data Sharing을 통해 Store360에 통합할 수 있습니다. 이제 브랜드는 이러한 Campaign이 오프라인 매장 방문 및 매장 내 인게이지먼트에 미치는 영향을 측정할 수 있습니다.

### Personalize.AI - 동적 콘텐츠 {#personalizeai-dynamic-content}
Braze와 [Personalize.AI]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize) 통합을 통해 Personalize.AI의 데이터를 Braze 플랫폼으로 내보내 메시지 개인화 및 타겟팅에 활용할 수 있습니다.

### Regal - 메시징 {#regal-messaging}
[Regal]({{site.baseurl}}/partners/additional_channels_and_extensions/additional_channels/instant_chat/regal)과 Braze를 통합하면 모든 고객 터치포인트에서 보다 일관되고 개인화된 경험을 만들 수 있습니다.
- Regal에서의 전화 대화 내용을 기반으로 Braze에서 최적의 다음 이메일 또는 푸시 알림을 전송합니다.
- 고가치 고객이 Braze의 마케팅 이메일을 클릭했지만 전환하지 않은 경우 Regal에서 전화를 트리거합니다.

### Sendbird - 메시징 {#sendbird-messaging}
Braze와 [Sendbird]({{site.baseurl}}/partners/additional_channels_and_extensions/additional_channels/instant_chat/sendbird) 통합을 통해 회사 사용자는 다음을 수행할 수 있습니다.
{% multi_lang_include partners/instant_chat/sendbird_integration_bullets.md %}

### Fresh Relevance - 동적 콘텐츠 {#fresh-relevance-dynamic-content}
Braze와 [Fresh Relevance]({{site.baseurl}}/partners/home) 통합을 통해 고객이 탐색한 제품이나 동일 카테고리 내 항목을 기반으로 한 제품 추천 등 개인화된 콘텐츠를 트리거 이메일에 포함할 수 있습니다. 가격 인하, 재입고, 다단계 탐색, 장바구니 이탈 메시지 등 고급 트리거 이메일 Campaign을 전송할 수도 있습니다!

### Smartling - 현지화 {#smartling-localization}
Braze와 [Smartling]({{site.baseurl}}/partners/message_personalization/localization/smartling) 통합을 통해 이메일 템플릿과 Content Blocks를 번역할 수 있습니다. Smartling은 번역 과정에서 언어 전문가에게 시각적 컨텍스트를 제공하여 오류를 줄이고 품질을 유지합니다.

### SalesWings - 분석 {#saleswings-analytics}
Braze와 [SalesWings]({{site.baseurl}}/partners/data_and_infrastructure_agility/analytics/saleswings#saleswings) 통합을 통해 두 플랫폼 간에 유연하게 데이터를 동기화하고, 리드 스코어링 및 리드 등급 기능으로 리드를 평가할 수 있습니다.

### Kognitiv Inspire - 로열티 {#kognitiv-inspire-loyalty}
Braze와 [Kognitiv]({{site.baseurl}}/partners/data_and_analytics/loyalty/kognitiv) 통합을 통해 로열티 전략을 구현하고 평가할 수 있으며, 혁신적인 기능과 맞춤형 회원 커뮤니케이션을 제공하여 프로그램 효과를 높일 수 있습니다.

### OneTrust - 데이터 프라이버시 {#onetrust-data-privacy}
Braze와 [OneTrust]({{site.baseurl}}/partners/data_and_analytics/data_privacy/onetrust) 통합을 통해 OneTrust 워크플로 빌더를 사용하여 제품에 대한 보안 워크플로를 생성할 수 있습니다.

### Stylitics - 동적 콘텐츠 {#stylitics-dynamic-content}
Braze와 [Stylitics]({{site.baseurl}}/partners/message_personalization/dynamic_content/visual_and_interactive_content/stylitics) 통합을 통해 기존 이메일 Campaign에 매력적이고 관련성 높은 번들 콘텐츠를 추가하여 개인화된 고객 경험을 만들 수 있습니다.

## SDK 업데이트 {#sdk-updates}

최신 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 SDK 업데이트 섹션에 나열되어 있으며, 그 외 모든 업데이트는 해당 SDK 체인지로그에서 확인할 수 있습니다.

- [SWIFT SDK 6.1.0-6.2.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#620)
- [웹 SDK 4.7.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md#471)
- [React Native SDK 5.0.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md#500)
  - 네이티브 iOS 브리지를 Braze SWIFT SDK 5.13.0에서 6.2.0으로 업데이트했습니다.
  - 버전 2.0.0부터 no-op이었던 `setSDKFlavor` 및 `setMetadata`를 제거했습니다.
  - iOS에서는 SDK 초기화 시 `Braze.Configuration` 객체를 사용하여 이러한 필드를 설정해야 합니다.
  - Android에서는 braze.xml 파일을 통해 이러한 필드를 설정해야 합니다.
- [Cordova SDK 4.0.0-5.0.0](https://github.com/braze-inc/braze-cordova-sdk/blob/master/CHANGELOG.md#500)
  - **Cordova SDK 4.0.0**
		- Appboy 인스턴스의 이름을 Braze로 변경했습니다.
			- 프로젝트가 새로운 명명 규칙으로 올바르게 마이그레이션되었는지 확인하려면 프로젝트에서 다음 인스턴스를 확인하고 교체하세요:
				- 플러그인 이름이 `cordova-plonugin-appboy`에서 `cordova-plugin-braze`로 변경되었습니다.
					- Cordova 플러그인을 실행하고 `cordova-plugin-appboy`를 제거한 다음 [README](https://github.com/braze-inc/braze-cordova-sdk/blob/master/README.md)의 지침에 따라 플러그인을 다시 추가하세요.
				- 이 GitHub 리포지토리가 https://github.com/braze-inc/braze-cordova-sdk URL로 이동되었습니다.
				- 프로젝트의 config.xml 파일에서 각 구성 속성 키에 대해 com.appboy 인스턴스를 com.braze로 변경하세요.
				- JavaScript 클래스 인터페이스 `AppboyPlugin`의 이름이 `BrazePlugin`으로 변경되었습니다.
		- Braze Android SDK 25.0.0으로 업데이트했습니다.
		- Braze SWIFT SDK 5.13.0으로 업데이트했습니다.
			- 이 업데이트는 Content Cards 클릭 로깅 시 버전 2.33.0에서 도입된 iOS 동작을 수정합니다. `logContentCardClicked`를 호출하면 이제 클릭 이벤트를 전송하고 관련 URL 필드로 리디렉션하는 대신 측정기준용 클릭 이벤트만 전송합니다.
  - **Cordova SDK 5.0.0**
		- 다음 기능 플래그 메서드가 콜백 매개변수를 사용하는 대신 프로미스를 반환하도록 업데이트되었습니다.
			- `getAllFeatureFlags()`
			- `getFeatureFlag(id)`
			- `getFeatureFlagBooleanProperty(id, key)`
			- `getFeatureFlagStringProperty(id, key)`
			- `getFeatureFlagNumberProperty(id, key)`
- [Unreal SDK 2.5.0](https://github.com/braze-inc/braze-unreal-sdk/blob/master/CHANGELOG.md#250)
- [Unity SDK 4.1.0](https://github.com/braze-inc/braze-unity-sdk/blob/master/CHANGELOG.md#410)
