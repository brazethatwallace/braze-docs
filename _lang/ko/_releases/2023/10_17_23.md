# 2023년 10월 17일 릴리스 {#october-17-2023-release}

## 워크스페이스로 복사하기 {#copying-to-workspaces}

[워크스페이스 간 Campaign 복사]({{site.baseurl}}/user_guide/messaging/governance/copy_across_workspaces)를 사용하면 다른 워크스페이스에 있는 Campaign의 사본으로 시작하여 메시지 작성을 빠르게 진행할 수 있습니다. 이 사본은 편집하고 실행할 때까지 초안 상태로 유지되므로, 성공적인 메시징 전략을 보존하고 이를 기반으로 발전시킬 수 있습니다.

## Currents 커넥터 테스트 {#test-currents-connectors}

[Currents 커넥터 테스트]({{site.baseurl}}/user_guide/data_and_analytics/braze_currents/setting_up_currents#test-currents-connectors)는 다양한 대상을 테스트하고 시도해 볼 수 있는 기존 커넥터의 무료 버전입니다. Currents 테스트의 특징은 다음과 같습니다:

- 구축할 수 있는 Currents 테스트 커넥터 수에 제한이 없습니다.
- 30일 롤링 기간당 총 최대 10,000개의 이벤트를 집계할 수 있습니다. 이 이벤트 합계는 대시보드에서 매시간 업데이트됩니다.

## 기능 플래그 {#feature-flags}

[기능 플래그]({{site.baseurl}}/developer_guide/feature_flags)를 사용하면 특정 사용자 또는 무작위로 선택한 사용자에 대해 원격으로 기능을 활성화하거나 비활성화할 수 있습니다. 중요한 점은, 추가적인 코드 배포나 앱 스토어 업데이트 없이도 프로덕션 환경에서 기능을 켜고 끌 수 있다는 것입니다. 이를 통해 새로운 기능을 안심하고 안전하게 출시할 수 있습니다.

## 기능 플래그 실험 {#feature-flag-experiments}

[기능 플래그 실험]({{site.baseurl}}/developer_guide/feature_flags/experiments)을 통해 애플리케이션의 변경 사항을 A/B 테스트하여 전환율을 최적화할 수 있습니다. 마케터는 기능 플래그를 사용하여 새로운 기능이 전환율에 긍정적 또는 부정적 영향을 미치는지, 또는 어떤 기능 플래그 속성 조합이 가장 최적인지 판단할 수 있습니다.

## 사용자 프로필 병합 {#merging-user-profiles}

**사용자 검색** 페이지에서 검색 결과가 여러 사용자 프로필을 반환하는 경우, **중복 항목 병합** 버튼을 클릭하여 [사용자 프로필을 병합]({{site.baseurl}}/user_guide/audience/manage_audience/merge_duplicate_users)할 수 있습니다. 유지할 사용자 프로필을 선택할 수 있으며, 해당 프로필은 그대로 유지되면서 병합된 프로필의 속성을 가져옵니다.

## Segment별 성과 데이터 {#performance-data-by-segment}

이제 쿼리 빌더 보고서 템플릿을 사용하여 Campaigns, Canvas, 배리언트 및 단계에 대한 [성과 데이터를 Segment별로 분석]({{site.baseurl}}/user_guide/data_and_analytics/reporting/viewing_and_understanding_segment_data#performance-data-by-segment)할 수 있습니다.

## 사용자 프로필 업데이트 {#updating-user-profiles}

이제 [`/users/track` 엔드포인트]({{site.baseurl}}/api/endpoints/user_data/post_user_track)를 사용하여 전화번호 또는 이메일로 사용자 프로필을 업데이트할 수 있습니다.

## SDK 업데이트 {#sdk-updates}

최신 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 SDK 업데이트 섹션에 나열되어 있으며, 그 외 모든 업데이트는 해당 SDK 체인지로그에서 확인할 수 있습니다.

- [Braze Segment Swift 플러그인 v2.1.0](https://github.com/braze-inc/braze-segment-swift/blob/main/CHANGELOG.md)
- [웹 SDK v4.10.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [웹 SDK v5.0.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
    - [`subscribeToFeatureFlagsUpdates()`](https://js.appboycdn.com/web-sdk/latest/doc/modules/braze.html#subscribetofeatureflagsupdates) 콜백이 이제 새로고침 성공/실패와 관계없이 항상 호출됩니다. 업데이트 수신에 실패한 경우, 현재 캐시된 기능 플래그와 함께 콜백이 호출됩니다.
    - [`getFeatureFlag()`](https://js.appboycdn.com/web-sdk/latest/doc/modules/braze.html#getfeatureflag) 메서드는 이제 기능 플래그가 존재하지 않거나 기능 플래그가 비활성화된 경우 null을 반환합니다.
    - 이전에 4.0.4에서 사용 중단된 `logContentCardsDisplayed()` 메서드를 제거했습니다.
    - 사용 중단된 초기화 옵션 `enableHtmlInAppMessages`를 제거했습니다. 이 옵션은 `allowUserSuppliedJavascript` 옵션으로 대체해야 합니다.
    - 이전에 4.9.0에서 [`ImageOnly`](https://js.appboycdn.com/web-sdk/latest/doc/classes/braze.imageonly.html)로 대체되어 사용 중단된 Banner 클래스를 제거했습니다.
    - `Banner` 클래스 제거의 일환으로 `ab-banner` CSS 클래스명을 제거했습니다. CSS 커스터마이징은 대신 `ab-image-only` 클래스를 대상으로 해야 합니다.
    - SDK는 더 이상 런타임 오류를 발생시키지 않습니다. 초기화 전에 Braze 메서드를 호출하면 대신 콘솔에 경고가 기록됩니다.
    - SDK는 더 이상 커스텀 HTML 인앱 메시지에 기본값 Braze 인앱 메시지 스타일을 추가하지 않습니다. 이 스타일은 이전에 레거시 인앱 메시지 유형에서 사용되었습니다.
- [Android SDK 29.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
    - `BannerImageCard`, `BannerImageCardView`, `BannerImageContentCardView`의 이름을 `ImageOnlyCard`, `ImageOnlyCardView`, `ImageOnlyContentCardView`로 변경했습니다.
    - Banner 카드에 사용된 모든 스타일이 Image Only 카드로 업데이트되었습니다. `banner`라는 단어가 포함된 모든 키를 `image_only`로 대체해야 합니다.
    - 이제 기기 브랜드 정보가 전송됩니다. 이를 차단하려면 데이터 수집 차단을 참조하세요.
- [Flutter SDK 7.0.0](https://pub.dev/packages/braze_plugin/changelog)
    - 네이티브 Android 브릿지를 [Braze Android SDK 26.1.1에서 27.0.1로](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2701) 업데이트합니다.
    - Gradle 8 지원을 추가합니다.
- [Swift SDK 7.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - `useUUIDAsDeviceId` 구성이 이제 기본값으로 활성화됩니다.
        - 영향에 대한 자세한 내용은 [IDFV 수집 - Swift]({{site.baseurl}}/developer_guide/analytics/managing_data_collection/?sdktab=swift)를 참조하세요.
    - 배너 콘텐츠 카드 유형 및 해당 UI 요소의 이름이 `ImageOnly`로 변경되었습니다. 모든 멤버 메서드와 프로퍼티는 동일하게 유지됩니다.
        - `Braze.ContentCard.Banner` → `Braze.ContentCard.ImageOnly`
        - `BrazeContentCardUI.BannerCell` → `BrazeContentCardUI.ImageOnlyCell`
    - BrazeUI의 일부 텍스트 레이아웃 로직을 새로운 Braze.ModalTextView 클래스로 리팩토링했습니다.
    - 기능 플래그 메서드의 동작을 업데이트했습니다.
        - `FeatureFlags.featureFlag(id:)`는 이제 존재하지 않는 ID에 대해 nil을 반환합니다.
        - `FeatureFlags.subscribeToUpdates(:)`는 새로고침 요청이 성공 또는 실패로 완료될 때 콜백을 트리거합니다.
            - 이전에 캐시된 데이터가 존재하는 경우, 초기 구독 시 콜백이 즉시 트리거됩니다.
- [AppboyKit iOS SDK 4.6.0](https://github.com/Appboy/appboy-ios-sdk/releases/tag/4.6.0)
    - 이 릴리스는 Xcode `14.x`가 필요합니다.
    - iOS 9 및 iOS 10에 대한 지원을 중단합니다.
    - Carthage를 통해 가져올 때 사용되던 구형 `.framework` 에셋에 대한 지원을 제거하고 최신 `.xcframework` 에셋으로 대체합니다.
        - 적절한 Braze 에셋을 가져오려면 `carthage update --use-xcframeworks` 명령어를 사용하세요.
        - `appboy_ios_sdk_full.json` 대신 `appboy_ios_sdk.json` 사용에 대한 지원을 제거합니다.
