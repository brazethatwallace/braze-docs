# 2018년 2월 {#february-2018}

## iOS 푸시 배지 카운트 {#ios-push-badge-count}

이제 Braze의 푸시 작성기에서 [배지 카운트를 업데이트]({{site.baseurl}}/help/best_practices/utilizing_badge_count#utilizing-badge-count)할 수 있습니다.
각 푸시 메시지에 대해 해당 알림이 트리거하는 배지 카운트를 지정할 수 있습니다.

## 이메일 주소를 사용하여 API를 통해 사용자 내보내기 {#exporting-users-via-api-using-email-addresses}

이제 이메일 주소를 지정하여 [API를 통해 고객 프로필 데이터를 내보낼]({{site.baseurl}}/developer_guide/rest_api/export#user-export) 수 있습니다.
이 내보내기에는 해당 이메일 주소와 연결된 모든 프로필이 포함됩니다.

## 이메일 템플릿 API {#email-template-apis}

이제 [API를 통해 이메일 템플릿을 생성하고 업데이트]({{site.baseurl}}/developer_guide/rest_api/email_templates#email-templates)할 수 있습니다. 각 템플릿에는 다른 API 호출에서 참조할 수 있는 **email_template_id**가 있습니다.

## REST API 키 권한 {#rest-api-keys-permissions}

이제 [여러 REST API 키를 생성]({{site.baseurl}}/api/basics#creating-rest-api-keys)하고 각 키에 대한 액세스 권한을 구성할 수 있습니다. 각 키는 특정 엔드포인트에 대한 액세스를 부여하도록 구성할 수 있습니다.

또한 지정된 REST API 키에 대해 REST API 요청을 수행할 수 있도록 허용된 [IP 주소 및 서브넷의 화이트리스트]({{site.baseurl}}/developer_guide/rest_api/basics#api-ip-whitelisting)를 지정할 수 있습니다.
