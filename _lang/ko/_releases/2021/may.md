# 2021년 5월 {#may-2021}

## 전환 상관관계 {#conversion-correlation}

이 가이드에서는 **Campaign 분석** 페이지의 [전환 상관관계]({{site.baseurl}}/user_guide/messaging/ab_testing/concepts/conversion_correlation/) 분석에 대해 설명하며, 이를 통해 어떤 사용자 속성과 동작이 Campaign에 대해 설정한 결과에 도움이 되거나 해가 되는지에 대한 인사이트를 얻을 수 있습니다. 분석의 개요, 확인 대상, 사용 가능한 시기, Braze가 유의성을 확인하는 방법에 대해 설명합니다.

## 글로벌 컨트롤 그룹 보고서 {#global-control-group-report}

시간 경과에 따른 메시징 활동의 전반적인 영향을 더 잘 분석할 수 있도록 [글로벌 컨트롤 그룹]({{site.baseurl}}/user_guide/audience/global_control_group/) 보고서의 측정기준을 업데이트했습니다. 주요 변경 사항으로는 **사용자당 이벤트** 및 **예상 그룹 규모**를 추가하고, 처리 그룹과 대조군 간의 총 이벤트 차이를 반영하도록 **증분 상승률** 계산을 조정한 것이 있습니다.

## 보고서 개요 {#reports-overview}

Campaign 또는 Canvas 분석을 어디서부터 시작해야 할지 모르시겠나요? [보고서 개요]({{site.baseurl}}/user_guide/analytics/reports/)에서는 일반적인 마케팅 전략 질문에 답하는 데 사용할 수 있는 보고서 및 분석에 대한 지침을 제공합니다.

## 새로운 US-05 클러스터 {#new-us-05-cluster}

Braze는 새로운 미국 클러스터인 US-05를 지원합니다. 자세한 내용은 대시보드 및 REST [엔드포인트]({{site.baseurl}}/api/basics/#endpoints) 목록을 참조하세요.

## Braze UI 업데이트 {#braze-ui-updates}

2021년 5월, Braze 대시보드에서 다음과 같은 라벨과 용어가 업데이트되었습니다.

- App Usage --> Overview
- App Settings --> Settings
- Manage App Group --> Manage Settings
- Money Spent In-App --> Money Spent
- App Usage (User Profile) --> Sessions Overview
- Import a CSV of user information to add and/or update users in this App Group --> Import a CSV of user information to add or update users
