# 2020년 2월 {#february-2020}

## 리텐션 보고서 {#retention-reports}

Braze는 이제 Campaign을 위한 [리텐션 보고서]({{site.baseurl}}/user_guide/analytics/reports/retention_reports/)를 제공하게 되어 기쁩니다. 이 기능은 특정 Campaign에서 메시지를 수신한 사용자의 리텐션을 측정하는 데 도움이 됩니다. 리텐션 보고서는 대시보드 내 **Campaign Analytics** 페이지에서 편리하게 확인할 수 있습니다.

![전체 보고서]({% image_buster /assets/img/retention_report_full_report.png %})

{% alert important %}
2020년 1월 13일 현재 이 기능은 EU 지역에 배포된 클라이언트나 HIPAA(미국의료정보보호법) 준수 클러스터에서는 아직 사용할 수 없습니다. 전체 플랫폼에 기능을 지속적으로 배포하면서 해당 지역에서도 이 보고서를 사용할 수 있도록 할 예정입니다.
{% endalert %}
