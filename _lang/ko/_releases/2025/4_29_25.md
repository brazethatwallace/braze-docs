# 2025년 4월 29일 릴리스 {#april-29-2025-release}

## Braze 접근 문제 해결 {#troubleshooting-braze-access}

[Braze 접근 문제 해결]({{site.baseurl}}/user_guide/administer/personal/accessing_your_account)에서는 계정이 잠기거나 Braze 대시보드가 예상대로 작동하지 않는 경우 등 Braze에 접근할 때 발생할 수 있는 문제를 해결하는 방법을 안내합니다.

## 데이터 유연성 {#data-flexibility}

### Currents 자주 묻는 질문 {#currents-frequently-asked-questions}

Currents에 대한 자주 묻는 질문의 답변은 새로운 [자주 묻는 질문]({{site.baseurl}}/user_guide/data/distribution/braze_currents/faq) 페이지에서 확인할 수 있습니다.

### 익명 사용자 {#anonymous-users}

[익명 사용자]({{site.baseurl}}/user_guide/data/unification/user_data/user_profile_lifecycle/anonymous_users)의 "작동 방식" 및 "사용자 별칭 할당" 섹션에 익명 사용자의 작동 방식과 사용자 별칭을 할당하는 이유에 대한 새로운 세부 정보가 추가되었습니다.

### Campaign 초안 {#campaign-drafts}

[초안 저장]({{site.baseurl}}/user_guide/engagement_tools/campaigns/managing_campaigns/change_your_campaign_after_launch#campaign-drafts)을 사용하면 활성 Campaign에 대규모 변경을 수행할 수 있습니다. 초안을 만들면 다음 실행 전에 계획된 변경 사항을 사전에 검토할 수 있습니다.

### 사용자 식별 및 병합 {#identifying-and-merging-users}

사용자를 [식별]({{site.baseurl}}/api/endpoints/user_data/post_user_identify)하거나 [병합]({{site.baseurl}}/api/endpoints/user_data/post_users_merge)할 때, 이제 `prioritization` 배열에서 `least_recently_updated` 파라미터를 사용하여 가장 최근에 업데이트되지 않은 사용자를 우선시할 수 있습니다.

### 예약된 사용자 병합 {#scheduled-user-merging}

[예약된 병합]({{site.baseurl}}/user_guide/engagement_tools/segments/user_profiles/duplicate_users#scheduled-merging)을 사용하면 사전 구성된 규칙을 활용하여 매일 고객 프로필 병합을 자동화할 수 있습니다. Braze는 예약된 병합이 실행되기 24시간 전에 워크스페이스 관리자에게 알림을 보내어 구성을 검토할 수 있는 시간을 제공합니다.

### 수신자 객체 {#recipient-object}

이제 [수신자 객체]({{site.baseurl}}/api/objects_filters/recipient_object)에 `braze_id`를 포함할 수 있으며, 이를 통해 엔드포인트에서 정보를 요청하거나 기록할 수 있습니다.

### 새로운 데이터 센터 {#new-data-centers}

Braze는 US-10과 ID-01, 두 개의 새로운 [데이터 센터]({{site.baseurl}}/user_guide/data/infrastructure/data_centers)를 출시했습니다. Braze 계정을 설정할 때 지역별 데이터 센터에 가입할 수 있습니다.

## 창의성 발휘하기 {#unlocking-creativity}

### 랜딩 페이지 템플릿 {#landing-page-templates}

[랜딩 페이지 템플릿]({{site.baseurl}}/user_guide/engagement_tools/landing_pages/creating_pages#using-landing-page-templates)을 사용하여 다음 캠페인을 위한 템플릿을 만들 수 있습니다. 이러한 템플릿은 랜딩 페이지 편집기와 대시보드의 **템플릿** 섹션 모두에서 액세스하고 관리할 수 있습니다.

### 랜딩 페이지 양식 필드 {#landing-page-form-field}

랜딩 페이지를 커스터마이징할 때 양식 필드를 [필수 또는 선택 사항]({{site.baseurl}}/user_guide/engagement_tools/landing_pages/creating_pages#step-3-customize-the-page)으로 설정할 수 있습니다. 필수 필드는 양식을 제출하기 전에 반드시 입력해야 합니다. 선택 필드는 사용자가 비워두거나 선택하지 않을 수 있습니다.

### Canvas 사전 구축 템플릿 {#canvas-pre-built-templates}

BRAZE 캔버스는 이커머스 마케터를 위해 특별히 설계된 여러 [사전 구축 템플릿]({{site.baseurl}}/user_guide/messaging/canvas/ideas_and_strategies/ecommerce_use_cases)을 제공하여 핵심 전략을 더 쉽게 구현할 수 있도록 도와줍니다. 이 페이지에서는 고객 여정을 강화하는 데 활용할 수 있는 주요 템플릿을 소개합니다.

## 강력한 채널 {#robust-channels}

### WhatsApp 비디오 {#whatsapp-videos}

{% multi_lang_include release_type.md release="Early access" %}

[WhatsApp 비디오 파일]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#outbound-messages)을 이제 URL 또는 Braze 미디어 라이브러리를 통해 호스팅할 수 있습니다.

### WhatsApp 목록 메시지 {#whatsapp-list-messages}

[목록 메시지]({{site.baseurl}}/user_guide/channels/whatsapp/message_processing/messaging_users#list-messages)는 클릭 가능한 옵션 목록이 포함된 본문 메시지로 표시됩니다. 각 목록에는 여러 섹션이 포함될 수 있으며, 각 목록에는 최대 10개의 행을 포함할 수 있습니다.

### 미리보기 링크 복사 {#copy-preview-link}

HTML 및 드래그 앤 드롭 [이메일 메시지]({{site.baseurl}}/user_guide/message_building_by_channel/email/drag_and_drop#step-3-add-your-sending-information), [이메일 템플릿]({{site.baseurl}}/user_guide/message_building_by_channel/email/templates/email_template#step-5-preview-and-test-your-message), [Content Blocks]({{site.baseurl}}/user_guide/messaging/design_and_edit/content_blocks)에서 **미리보기 링크 복사**를 사용하여 임의의 사용자에게 콘텐츠가 어떻게 표시되는지 보여주는 공유 가능한 링크를 생성할 수 있습니다.

### 푸시 등록 다이어그램 {#push-registration-diagram}

사용자 가이드의 푸시 알림 설명서를 개선하고, [더 큰 규모에서 푸시 등록이 어떻게 이루어지는지]({{site.baseurl}}/user_guide/message_building_by_channel/push/push_registration#what-does-this-look-like-on-a-broader-scale) 시각화하는 데 도움이 되는 새로운 다이어그램을 추가했습니다.

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### 업데이트된 파트너 카테고리 {#updated-partner-categories}

탐색 환경을 개선하기 위해 [기술 파트너 섹션]({{site.baseurl}}/partners/home)의 카테고리와 하위 카테고리를 업데이트했습니다.

### Shopify (새 버전) - 이커머스 {#shopify-new-version-ecommerce}

Shopify 통합의 새 버전이 4월부터 Shopify 스토어 유형과 초기 통합 설정에 사용된 외부 ID에 따라 단계적으로 출시됩니다.

**이전 버전의 통합은 2025년 8월 28일에 지원이 중단됩니다. 2025년 8월 28일 이전에 새 버전의 통합으로 업데이트해야 합니다.**

신규 Braze 고객: 2025년 4월부터 Braze는 신규 온보딩 고객을 대상으로 새로운 Shopify 커넥터를 점진적으로 출시하고 기존 고객을 업그레이드할 예정입니다. 새로운 표준 통합에 대해 자세히 알아보려면 [Shopify 표준 통합]({{site.baseurl}}/shopify_standard_integration)을 참조하세요.

### Just Words - 동적 콘텐츠 {#just-words-dynamic-content}

[Just Words]({{site.baseurl}}/partners/just_words)는 라이프사이클 마케팅 채널에서 대규모로 메시징을 초개인화하여, 수백 가지 변형을 동적으로 테스트하고 성과가 낮은 콘텐츠를 자동으로 새로고침할 수 있도록 지원합니다.

### Tapcart - 이커머스 {#tapcart-ecommerce}

[Tapcart]({{site.baseurl}}/partners/ecommerce/tapcart)는 Shopify 기반 브랜드를 위한 선도적인 모바일 커머스 플랫폼으로, 판매자가 고객이 선호하는 개인화된 매력적인 쇼핑 경험을 제공하는 커스텀 모바일 앱을 만들 수 있도록 지원합니다.

## SDK 업데이트 {#sdk-updates}

최신 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 SDK 업데이트 섹션에 나열되어 있으며, 그 외 모든 업데이트는 해당 SDK 체인지로그에서 확인할 수 있습니다.

- [Braze Unity SDK 8.0.0](https://github.com/braze-inc/braze-unity-sdk/blob/master/CHANGELOG.md#710)
    - 네이티브 iOS 브릿지를 [Braze Swift SDK 10.3.0에서 11.9.0으로](https://github.com/braze-inc/braze-swift-sdk/compare/10.3.0...11.9.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed) 업데이트했습니다.
    - 네이티브 Android 브릿지를 [Braze Android SDK 32.1.0에서 35.0.0으로](https://github.com/braze-inc/braze-android-sdk/compare/v32.1.0...v35.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed) 업데이트했습니다.
        - 최소 필수 Android SDK 버전은 25입니다. [최소 Android SDK 버전 세부 정보](https://github.com/braze-inc/braze-android-sdk?tab=readme-ov-file#version-information)를 참조하세요.
- [Braze Segment Kotlin 3.0.0](https://github.com/braze-inc/braze-segment-kotlin/blob/main/CHANGELOG.md)
    - Braze Android SDK를 [32.1.0에서 35.0.0으로](https://github.com/braze-inc/braze-android-sdk/compare/v32.1.0...v35.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed) 업데이트했습니다.
        - 최소 필수 Android SDK 버전은 25입니다. [최소 Android SDK 버전 세부 정보](https://github.com/braze-inc/braze-android-sdk?tab=readme-ov-file#version-information)를 참조하세요.
- [Braze Swift SDK 12.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1200)
    - 배포되는 정적 XCFramework가 이제 외부 리소스 번들에 의존하지 않고 리소스를 직접 포함합니다.
        - 정적 XCFramework를 수동으로 통합할 때, 타겟의 *General settings*에 있는 *Frameworks, Libraries, and Embedded Content* 섹션에서 각 XCFramework에 대해 *Embed & Sign* 옵션을 선택해야 합니다.
        - 스위프트 패키지 매니저 또는 CocoaPods 통합에는 변경 사항이 필요하지 않습니다.
- [Braze Segment Swift 6.0.0](https://github.com/braze-inc/braze-segment-swift/blob/main/CHANGELOG.md)
    - Braze Swift SDK 바인딩을 `12.0.0`+ SemVer 기준 릴리스를 요구하도록 업데이트했습니다.
        - 이를 통해 `12.0.0`부터 `13.0.0` 미만까지 모든 Braze SDK 버전과 호환됩니다.
        - 잠재적인 주요 변경 사항에 대한 자세한 내용은 [`12.0.0`](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1200) 체인지로그 항목을 참조하세요.
