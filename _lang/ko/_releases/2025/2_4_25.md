# 2025년 2월 4일 릴리스 {#february-4-2025-release}

## Braze 문서 개선 사항 {#braze-docs-improvements}

### 데이터 및 분석 개편 {#data-and-analytics-revamp}
원하는 정보를 더 쉽게 찾을 수 있도록, 기존에 "데이터 및 분석" 아래에 중첩되어 있던 문서를 [데이터]({{site.baseurl}}/user_guide/data)와 [분석]({{site.baseurl}}/user_guide/analytics)으로 분리했습니다.

### 개발자 가이드 {#developer-guide}
[Braze 개발자 가이드]({{site.baseurl}}/developer_guide/home) 전반에 걸쳐 대규모 정리를 수행했으며, 여러 페이지에 분산되어 있던 사용법 문서를 단일 페이지로 통합했습니다.

또한 각 Braze SDK의 레퍼런스 문서와 리포지토리를 모두 나열하는 새로운 [SDK 레퍼런스 페이지]({{site.baseurl}}/developer_guide/references)가 추가되었습니다.

#### 언리얼 엔진 Braze SDK {#unreal-engine-braze-sdk}
언리얼 엔진 Braze SDK GitHub 리포지토리 README의 모든 콘텐츠를 [Braze 문서의 전용 섹션]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=unreal%20engine)으로 마이그레이션하고 다시 작성했습니다.

## 데이터 유연성 {#data-flexibility}

### API 사용량 대시보드 {#api-usage-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

[API 사용량 대시보드]({{site.baseurl}}/user_guide/analytics/dashboards/api_usage)를 통해 Braze로 유입되는 REST API 트래픽을 모니터링하여 REST API 사용 추이를 파악하고 잠재적인 문제를 해결할 수 있습니다.

### 커스텀 속성에 태그 추가 {#adding-tags-to-custom-attributes}

{% multi_lang_include release_type.md release="General availability" %}

"이벤트, 속성, 구매 관리" 권한이 있는 경우 커스텀 속성을 생성한 후 [커스텀 속성에 태그를 추가]({{site.baseurl}}/user_guide/data/activation/attributes/custom_attributes#add-tags)할 수 있습니다. 태그는 속성 목록을 필터링하는 데 사용할 수 있습니다.

### 카탈로그 선택 항목 및 비동기 카탈로그 필드 엔드포인트 {#catalog-selections-and-async-catalog-fields-endpoints}

{% multi_lang_include release_type.md release="General availability" %}

다음 엔드포인트가 이제 정식 출시되었습니다:
* [POST: 카탈로그 필드 생성]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/post_create_catalog_fields)
* [DELETE: 카탈로그 필드 삭제]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/delete_catalog_field)
* [DELETE: 카탈로그 선택 항목 삭제]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/delete_catalog_selection)
* [POST: 카탈로그 선택 항목 생성]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/post_create_catalog_selections)

### 이메일 주소를 사용하여 Campaigns 또는 Canvases 트리거 {#using-an-email-address-to-trigger-campaigns-or-canvases}

{% multi_lang_include release_type.md release="General availability" %}

이제 이메일 주소로 수신자를 지정하여 [Campaigns]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/target_users) 및 [Canvases]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas#step-13-set-your-target-entry-audience)를 트리거할 수 있습니다.

### 전화번호를 사용하여 API를 통해 사용자 식별 {#using-a-phone-number-to-identify-a-user-via-the-api}

{% multi_lang_include release_type.md release="General availability" %}

이제 별칭 및 이메일 주소 외에 전화번호를 사용하여 [`/users/identify` API 엔드포인트]({{site.baseurl}}/api/endpoints/user_data/post_user_identify)를 통해 사용자를 식별할 수 있습니다.

### SAML 추적 가져오기 {#getting-a-saml-trace}
[SAML 추적을 가져오는 방법에 대한 단계]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/saml_sso_setup#obtaining-a-saml-trace)를 추가하여 지원팀과 함께 SAML SSO 관련 문제를 보다 효율적으로 해결할 수 있도록 했습니다.

### 지역별 데이터 센터 {#region-specific-data-centers}
Braze가 새로운 지역에 서비스를 확장함에 따라, 운영 방식을 보다 명확히 설명하기 위해 [Braze 데이터 센터에 대한 문서]({{site.baseurl}}/user_guide/data/infrastructure/data_centers)를 추가했습니다.

## 창의성 잠금 해제 {#unlocking-creativity}

### 가격 인하 알림 및 재입고 알림 {#price-drop-notifications-and-back-in-stock-notifications}

{% multi_lang_include release_type.md release="General availability" %}

이제 Canvas와 카탈로그를 통해 [재입고 알림]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/back_in_stock_notifications)을 설정하여 아이템이 재입고되었을 때 고객에게 알릴 수 있습니다.

또한 카탈로그와 Canvas에서 가격 인하 알림을 설정하여 아이템 가격이 인하되었을 때 고객에게 알리는 [가격 인하 알림]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/price_drop_notifications)을 생성할 수 있습니다.

### 셀렉션 미리보기 {#preview-for-selection}

{% multi_lang_include release_type.md release="General availability" %}

셀렉션을 생성한 후, 랜덤 사용자 또는 특정 사용자에 대해 [셀렉션이 반환하는 결과를 확인]({{site.baseurl}}/user_guide/data/activation/catalogs/selections#test-and-preview)할 수 있습니다.

### Liquid를 포함하는 카탈로그 항목 템플릿 만들기 {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="General availability" %}

[Liquid를 포함하는 카탈로그 항목을 템플릿으로 만들]({{site.baseurl}}/user_guide/data/activation/catalogs/using_catalogs#using-liquid) 수 있습니다.

### Canvas 템플릿 {#canvas-templates}
[선호도 설문조사를 통한 사용자 온보딩]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/preference_survey) 및 [이중 옵트인으로 이메일 가입 생성]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/email_signup)을 위한 새로운 Canvas 템플릿을 추가했습니다.

### B2B를 위한 Salesforce Sales Cloud 리드 관리 {#managing-leads-with-salesforce-sales-cloud-for-b2b}
B2B 마케터가 Braze를 활용할 수 있는 한 가지 방법은 Salesforce Sales Cloud와의 통합입니다. 이 [사용 사례]({{site.baseurl}}/user_guide/get_started/b2b_use_cases/b2b_salesforce_sales_cloud)를 구현하는 방법에 대해 자세히 알아보세요.

## 강력한 채널 {#robust-channels}

### 수신 거부 목록 {#suppression-lists}

{% multi_lang_include release_type.md release="Beta" %}

[수신 거부 목록]({{site.baseurl}}/user_guide/audience/suppression_lists)은 메시지를 절대 수신하지 않을 사용자 그룹을 지정합니다. 관리자는 세분화와 동일한 방식으로 Segment 필터를 사용하여 사용자 그룹을 좁히는 수신 거부 목록을 만들 수 있습니다.

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### Constructor - 동적 콘텐츠 {#constructor-dynamic-content}
[Constructor]({{site.baseurl}}/partners/ecommerce/product_search_recommendations/constructor)는 인공지능과 머신 러닝을 활용하여 이커머스 및 소매 웹사이트에 개인화된 검색, 추천, 브라우징 경험을 제공하는 검색 및 제품 디스커버리 플랫폼입니다.

### Trustpilot - 동적 콘텐츠 {#trustpilot-dynamic-content}
[Trustpilot]({{site.baseurl}}/partners/trustpilot)은 고객이 피드백을 공유하고 리뷰를 관리하고 응답할 수 있는 온라인 리뷰 플랫폼입니다.

## SDK 업데이트 {#sdk-updates}

최신 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 SDK 업데이트 섹션에 나열되어 있으며, 그 외 모든 업데이트는 해당 SDK 체인지로그에서 확인할 수 있습니다.

- [Braze Android SDK 34.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#3400)
    - 최소 SDK 버전이 21(Lollipop)에서 25(Nougat)로 업데이트되었습니다.
