# 2025년 7월 22일 릴리스 {#july-22-2025-release}

## Amazon S3를 사용한 보안 이벤트 내보내기 {#security-events-export-with-amazon-s3}

[보안 이벤트를 Amazon S3로 자동 내보내기]({{site.baseurl}}/user_guide/administer/global/admin_settings/security_settings/security_export_s3)할 수 있습니다. Amazon S3는 클라우드 스토리지 제공업체로, 매일 UTC 자정에 실행되는 작업을 통해 내보내기가 수행됩니다. 설정이 완료되면 대시보드에서 보안 이벤트를 수동으로 내보낼 필요가 없습니다.

## 데이터 유연성 {#data-flexibility}

### CSV 가져오기 {#csv-import}

{% multi_lang_include release_type.md release="General availability" %}

CSV 가져오기를 사용하여 `first_name`, `last_destination_searched`, `trip_booked`와 같은 사용자 속성 및 커스텀 이벤트를 Braze에 기록하고 업데이트할 수 있습니다. 시작하려면 [CSV 가져오기]({{site.baseurl}}/user_guide/audience/manage_audience/import_users/csv_import)를 참조하세요.

### API 사용량 알림 {#api-usage-alerts}

{% multi_lang_include release_type.md release="General availability" %}

API 사용량 알림은 API 사용 현황에 대한 중요한 가시성을 제공하여 예상치 못한 트래픽을 사전에 감지할 수 있도록 합니다. 주요 API 요청 볼륨을 추적하는 알림을 설정하면 실시간 알림을 받고 마케팅 캠페인에 영향을 미치기 전에 문제를 해결할 수 있습니다.

### 워크스페이스 API 사용량 제한 {#workspace-api-rate-limits}

워크스페이스 API 사용량 제한을 사용하면 워크스페이스가 `/users/track` 또는 SDK 데이터와 같은 특정 수집 엔드포인트에 대해 수행할 수 있는 최대 API 요청 수를 설정할 수 있습니다. 또한 워크스페이스 그룹에 사용량 제한을 적용할 수도 있으며, 이 경우 해당 그룹의 모든 워크스페이스가 제한을 공유합니다.

### Campaign 분석의 기본 시간 범위 {#default-time-range-for-campaign-analytics}

기본적으로 [**Campaign 분석**]({{site.baseurl}}/user_guide/analytics/reports/campaign_analytics)의 시간 범위는 현재 시각으로부터 최근 90일을 표시합니다. 즉, Campaign이 90일 이전에 시작된 경우 해당 시간 범위에 대한 분석이 "0"으로 표시됩니다. 이전 Campaign의 모든 분석을 보려면 보고 시간 범위를 조정하세요.

### Canvas 실험 경로 단계의 업데이트된 동작 {#updated-behavior-for-canvas-experiment-paths-step}

Canvas에 활성 또는 진행 중인 우승 경로 또는 개인화된 경로 [실험]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step)이 있고 활성 Canvas를 업데이트하는 경우, 실험 경로 단계 자체를 업데이트했는지 여부와 관계없이 진행 중인 실험이 종료되며 실험 단계에서 우승 경로 또는 개인화된 경로를 결정하지 않습니다. 실험을 다시 시작하려면 기존 실험 경로를 연결 해제하고 새 실험 경로를 시작하거나, Canvas를 복제하여 새 Canvas를 시작할 수 있습니다. 그렇지 않으면 사용자는 최적화 방법이 선택되지 않은 것처럼 실험 경로를 통해 이동합니다.

자세한 내용은 [시작 후 Canvases 편집]({{site.baseurl}}/post-launch_edits)을 참조하세요.

### `/users/export/ids` 엔드포인트에 대한 더 빠른 사용량 제한 제공 {#faster-rate-limit-available-for-usersexportids-endpoint}

다음 요구 사항을 충족하면 [`/users/export/ids` 엔드포인트의 사용량 제한]({{site.baseurl}}/api/endpoints/export/user_data/post_users_identifier#rate-limit)을 초당 40개 요청으로 늘릴 수 있습니다:

- 워크스페이스에 기본 사용량 제한(분당 250개 요청)이 활성화되어 있어야 합니다. 기존에 설정된 사용량 제한을 제거하는 데 추가 지원이 필요하면 Braze 계정 매니저에게 문의하세요.
- 요청에 수신하려는 모든 필드를 나열하는 fields_to_export 매개변수가 포함되어야 합니다.

## 강력한 채널 {#robust-channels}

### 이메일 봇 필터링 {#bot-filtering-for-emails}

{% multi_lang_include release_type.md release="General availability" %}

[이메일 환경설정]({{site.baseurl}}/user_guide/administer/global/workspace_settings/email_preferences)에서 봇 필터링을 설정하여 의심되는 모든 기계 또는 봇 클릭을 제외하세요. 이메일에서 "봇 클릭"이란 자동화된 프로그램에 의해 생성된 이메일 내 하이퍼링크 클릭을 의미합니다. 이러한 봇 클릭을 필터링함으로써 참여도가 높은 수신자에게 의도적으로 메시지를 트리거하고 전달할 수 있습니다.

### 드래그 앤 드롭 제품 블록 {#drag-and-drop-product-blocks}

{% multi_lang_include release_type.md release="Early access" %}

[드래그 앤 드롭 에디터]({{site.baseurl}}/dnd_product_blocks)를 사용하면 커스텀 Liquid 코드를 작성할 필요 없이 메시지에 제품 블록을 빠르게 추가하고 구성하여 원활한 제품 쇼케이스를 만들 수 있습니다. 드래그 앤 드롭 제품 블록 기능은 현재 이메일에서만 사용할 수 있습니다.

### 랜딩 페이지 및 인앱 메시지용 스팬 텍스트 {#span-text-for-landing-pages-and-in-app-messages}

스팬 텍스트를 사용하면 [랜딩 페이지]({{site.baseurl}}/user_guide/engagement_tools/landing_pages/creating_pages#step-3-customize-the-page) 및 [인앱 메시지]({{site.baseurl}}/user_guide/channels/in_app_messages/customize/style_settings#blocks)에서 커스텀 코드 없이 텍스트 블록에 특정 스타일을 적용할 수 있습니다. 스타일을 적용할 텍스트를 강조 표시한 다음 **Wrap with span for style**을 선택하세요.

### WhatsApp 광고 클릭 {#ad-click-to-whatsapp}

[WhatsApp으로 연결되는 광고]({{site.baseurl}}/whatsapp_use_cases)는 Facebook, Instagram 또는 기타 플랫폼의 Meta 광고를 통해 신규 및 기존 고객 모두를 유입시키는 효율적인 방법입니다. 이러한 광고를 사용하여 제품과 서비스를 홍보하는 동시에 사용자에게 WhatsApp 채널의 존재를 알릴 수 있습니다.

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### Shopify Visitory API — 이커머스 {#shopify-visitory-api-ecommerce}

Braze는 인브라우저 메시지를 통해 이메일 주소, 전화번호 등 방문자 정보를 수집합니다. 이 정보는 Shopify로 전송됩니다. 이 데이터는 판매자가 스토어 방문자를 인식하고 보다 개인화된 쇼핑 경험을 제공하는 데 도움이 됩니다.

### Okendo — 이커머스 {#okendo-ecommerce}

Braze와 [Okendo]({{site.baseurl}}/partners/okendo) 통합은 리뷰, 로열티, 추천, 설문조사, 퀴즈를 포함한 Okendo 플랫폼의 여러 제품에 걸쳐 작동합니다. Okendo는 커스텀 이벤트와 사용자 속성을 Braze로 전송하며, 이를 통해 메시지를 개인화하고 트리거할 수 있습니다.

### Lemnisk — 고객 데이터 플랫폼 {#lemnisk-customer-data-platform}

Braze와 [Lemnisk]({{site.baseurl}}/partners/lemnisk) 통합을 통해 브랜드와 기업은 Braze의 잠재력을 최대한 활용할 수 있습니다. Lemnisk는 CDP 기반 인텔리전스 레이어로서 여러 플랫폼에 분산된 사용자 데이터를 실시간으로 통합하고, 수집된 사용자 정보와 행동 데이터를 실시간으로 Braze에 전송합니다.

## SDK 업데이트 {#sdk-updates}

최신 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 SDK 업데이트 섹션에 나열되어 있으며, 그 외 모든 업데이트는 해당 SDK 체인지로그에서 확인할 수 있습니다.

- [웹 SDK 6.0.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
    - `Banner.html` 속성, `logBannerClick`, `logBannerImpressions` 메서드가 제거되었습니다. 대신 노출 횟수 및 클릭 추적을 자동으로 처리하는 [`insertBanner`](https://js.appboycdn.com/web-sdk/latest/doc/modules/braze.html#insertbanner)를 사용하세요.
    - 레거시 News Feed 기능에 대한 지원이 제거되었습니다. 여기에는 Feed 클래스 및 관련 메서드의 제거가 포함됩니다.
    - 레거시 뉴스피드 카드에서 사용하던 created 및 categories 필드가 [`Card`](https://js.appboycdn.com/web-sdk/latest/doc/classes/braze.card.html) 서브클래스에서 제거되었습니다.
    - linkText 필드도 [`ImageOnly`](https://js.appboycdn.com/web-sdk/latest/doc/classes/braze.imageonly.html) Card 서브클래스 및 해당 생성자에서 제거되었습니다.
    - SDK가 초기화되지 않았을 때 특정 SDK 메서드가 명시적으로 undefined를 반환한다는 점을 명확히 하기 위해 정의를 명확히 하고 타입을 업데이트했습니다. 이로써 타이핑이 실제 런타임 동작과 일치하게 되었습니다. 이전의 불완전한 타이핑에 의존하던 프로젝트에서는 새로운 TypeScript 오류가 발생할 수 있습니다.
    - `cropType`이 `CENTER_CROP`인 인앱 메시지(예: 기본적으로 `FullScreenMessage`)의 이미지가 접근성 향상을 위해 `<span>` 대신 `<img>` 태그로 렌더링됩니다. 이로 인해 `.ab-center-cropped-img` 클래스 또는 그 하위 요소에 대한 기존 CSS 커스터마이징이 깨질 수 있습니다.
- [Cordova SDK 13.0.0](https://github.com/braze-inc/braze-cordova-sdk/blob/master/CHANGELOG.md#1300)
    - `enableSdk` 메서드의 내부 iOS 구현이 Swift SDK에서 더 이상 사용되지 않는 `_requestEnableSDKOnNextAppRun` 대신 setEnabled:를 사용하도록 업데이트되었습니다.
        - 이 메서드를 호출할 때 더 이상 앱을 다시 실행할 필요가 없습니다. 이제 이 메서드가 실행되는 즉시 SDK가 활성화됩니다.
    - 네이티브 Android 브릿지가 [Braze Android SDK 36.0.0에서 37.0.0으로](https://github.com/braze-inc/braze-android-sdk/compare/v36.0.0...v37.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed) 업데이트되었습니다.
- [Android SDK 37.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [Swift SDK 12.0.1-12.1.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
