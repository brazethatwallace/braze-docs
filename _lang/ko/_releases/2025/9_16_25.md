# 2025년 9월 16일 릴리스 {#september-16-2025-release}

## 데이터 유연성 {#data-flexibility}

### Braze 데이터 플랫폼 {#braze-data-platform}

Braze 데이터 플랫폼은 고객 생애주기 전반에 걸쳐 개인화되고 영향력 있는 경험을 만들 수 있도록 지원하는 포괄적이고 구성 가능한 데이터 기능 및 파트너 통합의 집합입니다. 데이터와 관련된 세 가지 작업에 대해 자세히 알아보세요:

- [데이터 통합]({{site.baseurl}}/user_guide/data/unification)
- [데이터 활성화]({{site.baseurl}}/user_guide/data/activation)
- [데이터 배포]({{site.baseurl}}/user_guide/data/distribution)

### 커스텀 배너 속성 {#custom-banner-properties}

{% multi_lang_include release_type.md release="Early access" %}

배너 Campaign의 커스텀 속성을 사용하여 SDK를 통해 키-값 데이터를 검색하고 앱의 동작이나 외관을 수정할 수 있습니다. 자세히 알아보려면 [커스텀 배너 속성]({{site.baseurl}}/developer_guide/banners/placements#custom-properties)을 참조하세요.

### 토큰 인증 {#token-authentication}

{% multi_lang_include release_type.md release="General availability" %}

Braze 연결된 콘텐츠를 사용할 때 특정 API에 사용자 이름과 비밀번호 대신 토큰이 필요할 수 있습니다. Braze는 [토큰 인증 헤더 값]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/connected_content/making_an_api_call#using-token-authentication)을 포함하는 자격 증명을 저장할 수 있습니다.

### 프로모션 코드 {#promotion-codes}

사용자 업데이트 단계를 통해 프로모션 코드를 고객 프로필에 저장할 수 있습니다. 자세한 내용은 [고객 프로필에 프로모션 코드 저장]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/sources/promotion_codes#save-to-profile)을 참조하세요.

## 창의력 발휘 {#unlocking-creativity}

### Braze Pilot

[Braze Pilot]({{site.baseurl}}/user_guide/get_started/braze_pilot)은 공개적으로 사용 가능한 Android 및 iOS용 앱으로, Braze 대시보드에서 휴대폰으로 메시지를 발송할 수 있습니다. 앱 다운로드, Braze 대시보드 연결 초기화, 설정 완료에 대한 안내는 [Braze Pilot 시작하기]({{site.baseurl}}/user_guide/get_started/braze_pilot/getting_started)를 참조하세요.

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### Blings - 시각적 및 인터랙티브 콘텐츠 {#blings-visual-and-interactive-content}

[Blings]({{site.baseurl}}/partners/blings)는 차세대 개인화된 비디오 플랫폼으로, 채널 전반에 걸쳐 실시간, 인터랙티브, 데이터 중심의 비디오 경험을 대규모로 제공할 수 있도록 지원합니다.

### 타사 도구를 활용한 Shopify 표준 통합 {#shopify-standard-integration-with-third-party-tool}

Shopify 온라인 스토어의 경우 Braze의 표준 통합 방법을 사용하여 사이트에서 Braze SDK를 지원하는 것을 권장합니다.

하지만 Google Tag Manager와 같은 타사 도구를 사용하는 것을 선호하실 수도 있으므로 그 방법에 대한 가이드를 준비했습니다. 시작하려면 [Shopify: 타사 태깅]({{site.baseurl}}/shopify_standard_integration_third_party_tagging)을 참조하세요.

## SDK 업데이트 {#sdk-updates}

다음 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 아래에 나열되어 있으며, 그 외의 모든 업데이트는 해당 SDK 체인지로그를 확인하시면 됩니다.

- [Braze Flutter SDK 15.0.0](https://github.com/braze-inc/braze-flutter-sdk/blob/main/CHANGELOG.md#1500)
    - 네이티브 Android 브릿지를 Braze Android SDK `36.0.0`에서 `39.0.0`으로 업데이트합니다.
    - 네이티브 iOS 브릿지를 Braze Swift SDK `12.0.0`에서 `13.2.0`으로 업데이트합니다. 여기에는 Xcode 26 지원이 포함됩니다.

- [Braze Swift SDK 7.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1300)
  - Braze Swift SDK 바인딩이 `13.0.0+` SemVer 범위의 릴리스를 요구하도록 업데이트합니다. 이를 통해 `13.0.0`부터 `14.0.0` 미만까지의 모든 Braze SDK 버전과 호환됩니다.
