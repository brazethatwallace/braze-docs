# 2025년 3월 4일 릴리스 {#march-4-2025-release}

## 개발자 가이드 정리 {#developer-guide-detangle}

여러 SDK에서 공유되는 동일한 콘텐츠가 문서 사이트의 새로운 SDK 탭 기능을 사용하여 통합되기 시작했습니다. 이번 달에는 [SDK 통합]({{site.baseurl}}/developer_guide/sdk_integration), [SDK 초기화]({{site.baseurl}}/developer_guide/sdk_initialization), [Content Cards]({{site.baseurl}}/developer_guide/content_cards)가 결합되었습니다. 앞으로 몇 달 동안 더 많은 업데이트를 기대해 주세요.

## 데이터 유연성 {#data-flexibility}

### 고객 프로필을 위한 Braze ID {#braze-ids-for-user-profiles}

이제 고객 프로필에 [Braze ID]({{site.baseurl}}/user_guide/engagement_tools/segments/user_profiles#user-profiles)가 포함됩니다. 고객 프로필을 검색할 때 이를 사용할 수 있습니다.

### 지연(Deferrals)

Braze는 소프트 바운스에 대한 정의를 업데이트했으며, [지연(deferrals)]({{site.baseurl}}/user_guide/message_building_by_channel/email/reporting_and_analytics/email_reporting#email-performance)이라는 새로운 이벤트를 전송하고 있습니다. 이는 이메일이 즉시 전달되지 않았지만, Braze가 이 일시적인 전달 실패 후 최대 72시간 동안 이메일을 재시도하여 해당 Campaign에 대한 시도가 중단되기 전에 성공적인 전달 가능성을 극대화하는 것을 의미합니다.

### Snowflake 엔티티 관계 {#snowflake-entity-relationships}

Snowflake와 Braze 엔티티 관계에 대한 [원시 테이블 스키마](/docs/assets/download_file/data-sharing-raw-table-schemas.txt)를 새로운 [사용자 친화적인 문서 페이지]({{site.baseurl}}/partners/data_and_analytics/data_warehouses/snowflake/entity_relationships)에 매핑했습니다. 각 채널에 속하는 `USER_MESSAGES` 테이블의 세부 사항과 각 테이블의 기본 키, 외래 키 및 네이티브 키에 대한 설명이 포함되어 있습니다.

### 외부 ID에 대한 아이덴티티 관리 {#identity-management-for-external-ids}

이메일 주소 또는 해시된 이메일 주소를 Braze 외부 ID로 사용하면 데이터 소스 전반에 걸쳐 아이덴티티 관리를 단순화할 수 있지만, 사용자 개인 정보 및 데이터 보안에 대한 [잠재적 위험]({{site.baseurl}}/user_guide/data/user_data_collection/user_profile_lifecycle#identified-user-profiles)을 고려하는 것이 중요합니다.

### Canvas 컨텍스트 단계 {#context-steps-for-canvas}

{% multi_lang_include release_type.md release="Early access" %}

사용자가 Canvas를 이동하는 동안 해당 사용자의 컨텍스트(또는 사용자 행동에 대한 인사이트)를 나타내는 변수 집합을 생성하거나 업데이트하려면 [컨텍스트 단계]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/context)를 사용하세요.

### 개인화된 지연 {#personalized-delay}

{% multi_lang_include release_type.md release="Early access" %}

지연 단계에서 **Personalize delay** 토글을 선택하여 사용자에 대한 [개인화된 지연]({{site.baseurl}}/user_guide/engagement_tools/canvas/canvas_components/delay_step#personalized-delays)을 설정할 수 있습니다. 컨텍스트 단계와 함께 사용하여 지연할 컨텍스트 변수를 선택할 수 있습니다.

Canvas 사용자 여정에서 지연 단계를 설정할 때 이제 최대 2년까지 지연을 생성할 수 있습니다.

### 자동 동기화 되돌리기 {#reverting-automatic-synchronization}

[이메일 메시지 작성]({{site.baseurl}}/user_guide/message_building_by_channel/email/html_editor#step-3-compose-your-email) 시, 일반 텍스트 탭에서 Regenerate from HTML 아이콘을 선택하여 자동 동기화로 되돌릴 수 있으며, 이 아이콘은 일반 텍스트가 동기화되지 않을 때만 나타납니다.

![Braze에서 자동 동기화를 위한 되돌리기 버튼.]({% image_buster /assets/img/release_notes/2025_05_04/regenerate_from_html.png %})

## 강력한 채널 {#robust-channels}

### Android 라이브 업데이트 {#android-live-updates}

라이브 업데이트는 [Android 16](https://android-developers.googleblog.com/2025/01/first-beta-android16.html)까지 공식적으로 제공되지 않지만, [Android용 라이브 업데이트]({{site.baseurl}}/developer_guide/push_notifications/live_notifications/?sdktab=android&tab=local) 페이지에서 동작을 에뮬레이트하는 방법을 확인할 수 있으므로, [Swift Braze SDK의 라이브 활동]({{site.baseurl}}/developer_guide/push_notifications/live_notifications/?sdktab=swift)과 유사한 인터랙티브 잠금 화면 알림을 표시할 수 있습니다. 공식 라이브 업데이트와 달리, 이 기능은 이전 Android 버전에서도 구현할 수 있습니다.

### 워크스페이스 간 기능 플래그가 있는 Campaign 복사 {#copying-campaigns-with-feature-flags-across-workspaces}

이제 [워크스페이스 간 기능 플래그가 있는 Campaign을 복사]({{site.baseurl}}/user_guide/engagement_tools/campaigns/managing_campaigns/copying_to_workspace#copying-campaigns-with-feature-flags)할 수 있습니다. 이를 위해서는 대상 워크스페이스에 원래 Campaign에서 참조된 기능 플래그와 일치하는 ID로 구성된 기능 플래그 실험이 설정되어 있어야 합니다.

### 새로운 WhatsApp 메시지 유형 지원 {#new-whatsapp-message-types-supported}

WhatsApp 메시지는 이제 [비디오, 오디오 및 문서 아웃바운드 메시지]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/create#outbound-messages)를 지원합니다. 얼리 액세스 참여에 관심이 있으시면 Braze 계정 매니저에게 문의하세요.

### 오른쪽에서 왼쪽으로 읽는 메시지 {#right-to-left-messages}

[오른쪽에서 왼쪽으로 읽는 메시지 만들기]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/localization/right_to_left_messages)는 오른쪽에서 왼쪽으로 읽는 언어로 메시지를 작성하는 모범 사례를 다루어, 메시지가 가능한 한 정확하게 표시되도록 합니다.

## AI 및 ML 자동화 {#ai-and-ml-automation}

### 항목 추천 {#item-recommendations}

[메시징에서 항목 추천 사용하기]({{site.baseurl}}/user_guide/brazeai/item_recommendations/using_recommendations)는 `product_recommendation` Liquid 오브젝트를 다루며, 이 지식을 실제로 적용하는 데 도움이 되는 튜토리얼을 포함합니다.

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### Email Love - 채널 확장 {#email-love-channel-extensions}

Braze와 [Email Love]({{site.baseurl}}/partners/message_orchestration) 파트너십은 Email Love의 Export to Braze 기능과 Braze API를 활용하여 이메일 템플릿을 Braze에 원활하게 업로드합니다.

### VWO - A/B 테스트 {#vwo-ab-testing}

Braze와 [VWO]({{site.baseurl}}/partners/data_and_analytics/ab_testing/vwo) 통합을 통해 VWO 실험 데이터를 활용하여 타겟 세그먼트를 만들고 개인화된 Campaign을 전달할 수 있습니다.

## SDK 업데이트 {#sdk-updates}

다음 SDK 업데이트가 릴리스되었습니다. 주요 업데이트는 아래에 나열되어 있으며, 그 외의 모든 업데이트는 해당 SDK 체인지로그를 확인하시면 됩니다.

- [React Native](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
    - React Native 최소 요구 버전을 [0.71.0](https://reactnative.dev/blog/2023/01/12/version-071)으로 올렸습니다. 자세한 내용은 React Working Group의 [릴리스 지원 정책](https://github.com/reactwg/react-native-releases#releases-support-policy)을 참조하세요.
    - 최소 요구 iOS 버전을 12.0으로 올렸습니다.
    - 네이티브 iOS 버전 바인딩을 [Braze Swift SDK 7.5.0에서 8.1.0](https://github.com/braze-inc/braze-swift-sdk/compare/7.5.0...8.1.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed)으로 업데이트했습니다.
    - 네이티브 Android 버전 바인딩을 [Braze Android SDK 29.0.1에서 30.1.1](https://github.com/braze-inc/braze-android-sdk/compare/v29.0.1...v30.1.1#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed)로 업데이트했습니다.
