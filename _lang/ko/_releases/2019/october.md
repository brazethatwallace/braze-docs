# 2019년 10월 {#october-2019}

## 향상된 캔버스 배리언트 분석 {#improved-canvas-variant-analytics}

Canvas에 각 배리언트의 성과를 확인할 수 있는 새롭고 개선된 분석 기능이 추가되었습니다. 특히 전환 이벤트 및 신뢰도와 관련된 새로운 측정기준과 셀 복사, API ID, 결과의 `.csv` 다운로드와 같은 새로운 기능이 있습니다. [향상된 캔버스 배리언트 분석]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/change_your_canvas_after_launch/#canvas-details)에 대해 자세히 알아보세요.

## SMS

이제 Braze에서 Campaigns, Canvas, [Currents]({{site.baseurl}}/user_guide/data/distribution/braze_currents/event_glossary/message_engagement_events/)를 통해 SMS를 제공합니다! 시작하려면 [설정 가이드]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/)를 확인하고, 자세한 내용은 [SMS 발송 가이드]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/)를 참조하세요!

## Content Blocks 개선 사항 {#content-block-improvements}

이제 콘텐츠 블록의 API ID가 대시보드의 선택한 콘텐츠 블록 페이지에 표시됩니다. 또한 Content Blocks가 사용되는 위치도 표시됩니다.

## API를 통한 별칭 전용 사용자 생성 및 식별 {#alias-only-user-creation-and-identification-via-the-api}

이제 속성 오브젝트의 모든 필드와 함께 [API 요청을 사용]({{site.baseurl}}/api/endpoints/user_data/#user-attributes-object-specification)하면 지정된 고객 프로필에 해당 이름의 속성을 지정된 값으로 생성하거나 업데이트할 수 있습니다.
