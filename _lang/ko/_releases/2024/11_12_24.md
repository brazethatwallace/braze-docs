## 강력한 채널 {#robust-channels}

### LINE

{% multi_lang_include release_type.md release="General availability" %}

Braze의 LINE 통합이 정식 출시되었습니다! LINE은 일본에서 가장 인기 있는 메시징 앱으로, 월간 활성 사용자가 9,500만 명이 넘습니다. 메시징 외에도 LINE은 사용자에게 소셜 미디어, 게임, 쇼핑 및 결제를 위한 "올인원" 플랫폼을 제공합니다.

시작하려면 [LINE 설명서]({{site.baseurl}}/user_guide/channels/line)를 참조하세요.

### LinkedIn Audience Sync

{% multi_lang_include release_type.md release="Beta" %}

이제 최고의 소셜 및 광고 기술로 캠페인의 도달 범위를 확장하는 데 도움이 되는 도구인 [Braze Audience Sync]({{site.baseurl}}/partners/canvas_audience_sync)와 함께 LinkedIn을 사용할 수 있습니다. 베타에 참여하려면 Braze 성공 매니저에게 문의하세요.

선도적인 글로벌 엽서 앱인 [MyPostcard](https://www.mypostcard.com/)를 사용하면 다이렉트 메일 캠페인을 쉽게 실행하여 고객과 원활하고 수익성 있는 방식으로 소통할 수 있습니다. 시작하려면 [MyPostcard와 Braze 통합하기]({{site.baseurl}}/partners/additional_channels_and_extensions/additional_channels/direct_mail/mypostcard)를 참조하세요.

## SDK 업데이트 {#sdk-updates}

다음 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 아래에 나열되어 있으며, 그 외의 모든 업데이트는 해당 SDK 체인지로그를 확인하시면 됩니다.

- [Expo Plugin 3.0.0](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
    - 이 버전은 Braze React Native SDK 13.1.0이 필요합니다.
    - iOS BrazeAppDelegate 메서드 호출에서 BrazeReactUtils.populateInitialUrl을 BrazeReactUtils.populateInitialPayload로 대체합니다.
        - 이 업데이트는 애플리케이션이 종료된 상태에서 알림을 클릭했을 때 푸시 열람 이벤트가 트리거되지 않던 문제를 해결합니다.
        - 이 업데이트를 완전히 활용하려면 JavaScript 코드에서 Braze.getInitialURL 호출을 모두 Braze.getInitialPushPayload로 대체하세요. 이제 초기 URL은 초기 푸시 페이로드의 url 속성을 통해 액세스할 수 있습니다.
- [Braze Segment Swift Plugin 5.0.0](https://github.com/braze-inc/braze-segment-swift/blob/main/CHANGELOG.md)
    - 11.1.1+ SemVer 명칭의 릴리스를 요구하도록 Braze Swift SDK 바인딩을 업데이트합니다.
    - 이를 통해 11.1.1부터 12.0.0 미만까지 모든 버전의 Braze SDK와 호환됩니다.
    - 잠재적인 주요 변경 사항에 대한 자세한 내용은 11.1.1의 체인지로그 항목을 참조하세요.
