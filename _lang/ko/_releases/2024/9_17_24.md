# 2024년 9월 17일 릴리스 {#september-17-2024-release}

## 데이터 유연성 {#data-flexibility}

### S3용 Braze 클라우드 데이터 수집 {#braze-cloud-data-ingestion-for-s3}

[S3용 클라우드 데이터 수집(CDI)]({{site.baseurl}}/user_guide/data_and_analytics/cloud_ingestion/file_storage_integrations#aws-definitions)을 사용하여 AWS 계정에 있는 하나 이상의 S3 버킷을 Braze와 직접 통합할 수 있습니다. 새 파일이 S3에 게시되면 SQS에 메시지가 전송되고, Braze 클라우드 데이터 수집이 해당 새 파일을 가져옵니다.

### 월간 활성 사용자 CY 24-25 {#monthly-active-users-cy-24-25}

월간 활성 사용자 - CY 24-25를 구매한 고객의 경우, Braze는 `/users/track` 엔드포인트에 대해 별도의 사용량 제한을 관리합니다. 자세한 내용은 [POST: 사용자 추적]({{site.baseurl}}/api/endpoints/user_data/post_user_track#monthly-active-users-cy-24-25-universal-mau-web-mau-and-mobile-mau)을 참조하세요.

## 창의성 발휘하기 {#unlocking-creativity}

### Liquid를 포함한 카탈로그 항목 템플릿 작성 {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="Early access" %}

Liquid 태그에서 `:rerender` 플래그를 사용하여 [카탈로그 항목의 Liquid 콘텐츠를 렌더링]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog#using-liquid)할 수 있습니다. 예를 들어 다음 Liquid 콘텐츠를 렌더링하면:

{% raw %}
```liquid
Hi ${first_name}
{% catalog_items Messages greet_msg :rerender %}
{{ items[0].Welcome_Message }}
```
{% endraw %}

다음과 같이 표시됩니다:

{% raw %}
```
Hi Peter,
Welcome to our store, Peter!
```
{% endraw %}

## 견고한 채널 {#robust-channels}

### WhatsApp 응답 메시지 {#whatsapp-response-messages}

{% multi_lang_include release_type.md release="General availability" %}

[응답 메시지]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#response-messages)를 사용하여 사용자로부터 수신된 WhatsApp 메시지에 답장할 수 있습니다. 이러한 메시지는 작성 과정에서 Braze 내에서 인앱으로 구축되며 언제든지 편집할 수 있습니다. Liquid를 사용하여 응답 메시지 언어를 적절한 사용자에게 맞출 수 있습니다.

### Canvas 템플릿 {#canvas-templates}

{% multi_lang_include release_type.md release="General availability" %}

[Canvas 템플릿]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates)을 만들어 Canvases 전반에서 특정 목표에 맞게 쉽게 커스텀할 수 있는 일관된 프레임워크를 구축하여 메시징을 개선하세요.

### 랜딩 페이지 {#landing-pages}

{% multi_lang_include release_type.md release="Beta" %}

Braze [랜딩 페이지]({{site.baseurl}}/user_guide/messaging/landing_pages)는 사용자 확보 및 인게이지먼트 전략을 추진할 수 있는 독립형 웹페이지입니다.

### 마지막 조회 이후 변경 사항 {#changes-since-last-viewed}

팀 내 다른 구성원이 [Canvases]({{site.baseurl}}/user_guide/engagement_tools/canvas/testing_canvases/measuring_and_testing_with_canvas_analytics#changes-since-last-viewed), Campaigns 및 [Segments]({{site.baseurl}}/user_guide/engagement_tools/segments/managing_segments#changes-since-last-viewed)에 대해 업데이트한 횟수를 해당 개요 페이지(예: [이메일 Campaign]({{site.baseurl}}/user_guide/channels/email/reporting#changes-since-last-viewed) 개요 페이지)에서 *마지막 조회 이후 변경 사항* 지표를 참조하여 확인할 수 있습니다.

### 웹훅 및 연결된 콘텐츠 요청 문제 해결 {#troubleshooting-webhook-and-connected-content-requests}

[웹훅 및 연결된 콘텐츠 요청 문제 해결]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content/troubleshooting_webhooks_and_connected_content)에서는 웹훅 및 연결된 콘텐츠 오류 코드에 대한 문제 해결 방법을 다루며, 오류의 의미와 이를 해결하기 위한 단계를 설명합니다.

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### Inbox Monster - 분석 {#inbox-monster-analytics}

[Inbox Monster]({{site.baseurl}}/partners/data_and_analytics/analytics/inbox_monster)는 기업 브랜드가 모든 발송을 성공적으로 전달할 수 있도록 돕는 받은편지함 신호 플랫폼입니다. 전달 가능성, 크리에이티브 렌더링, 단문 메시지 서비스 모니터링을 위한 통합 솔루션 스위트로, 현대적인 고객 관계 관리(CRM) 팀의 역량을 강화하고 발송에 대한 불안을 해소해 줍니다.

### SessionM - 로열티 {#sessionm-loyalty}

[SessionM]({{site.baseurl}}/partners/data_and_analytics/loyalty/sessionm)은 Campaign 관리 기능과 로열티 관리 솔루션을 제공하는 고객 참여 및 로열티 플랫폼으로, 마케터가 타겟팅된 아웃리치를 통해 인게이지먼트와 수익성을 높일 수 있도록 지원합니다.

## AI 및 ML 자동화 {#ai-and-ml-automation}

### 인기 아이템 추천 {#trending-item-recommendations}

"AI 개인화" 모델 외에도, [AI 아이템 추천]({{site.baseurl}}/user_guide/sage_ai/recommendations/about_item_recommendations#trending) 기능에는 "인기" 추천 모델도 포함되어 있습니다. 이 모델은 최근 사용자 상호작용에서 가장 긍정적인 모멘텀을 보인 아이템을 추천합니다.

## 설정 {#settings}

### 역할 {#roles}

{% multi_lang_include release_type.md release="General availability" %}

[역할]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/user_permissions#creating-a-role)을 사용하면 개별 커스텀 권한을 워크스페이스 액세스 제어와 함께 묶어 더 체계적으로 관리할 수 있습니다. 이 기능은 하나의 대시보드에 여러 브랜드 또는 지역별 워크스페이스가 있는 경우 특히 유용합니다. 역할을 사용하면 대시보드 사용자를 적절한 워크스페이스에 추가하고 관련 권한을 직접 부여할 수 있습니다.

### 보안 이벤트 보고서 {#security-event-report}

다운로드한 보안 보고서 이벤트에 표시될 수 있는 [보안 이벤트]({{site.baseurl}}/user_guide/administrative/app_settings/company_settings/security_settings#downloading-a-security-event-report)의 전체 목록이 추가되었습니다.

### 메시지 사용량 보고서 {#message-usage-report}

{% multi_lang_include release_type.md release="Early access" %}

[크레딧 사용량 대시보드]({{site.baseurl}}/credits_usage_dashboard)는 크레딧 사용량에 대한 셀프서비스 인사이트를 제공하여 계약 할당량 대비 과거 및 현재 사용량을 종합적으로 확인할 수 있도록 합니다. 이러한 인사이트는 혼란을 줄이고 초과량 위험을 방지하기 위한 조정에 도움을 줄 수 있습니다.
