# 2024년 2월 6일 릴리스 {#february-6-2024-release}

## Braze 개인정보 보호 매니페스트 {#braze-privacy-manifest}

Braze는 자체 개인정보 보호 매니페스트와 함께, 선언된 추적 데이터를 전용 `-tracking` 엔드포인트로 자동 재라우팅하는 새로운 유연한 API를 출시했습니다. 자세한 내용은 [Braze 개인정보 보호 매니페스트]({{site.baseurl}}/developer_guide/analytics/managing_data_collection/?sdktab=swift#swift_privacy-manifest)를 참조하세요.

## Google EU 사용자 동의 정책 {#google-eu-user-consent-policy}

Google은 2024년 3월 6일에 발효되는 [디지털 시장법(DMA)](https://ads-developers.googleblog.com/2023/10/updates-to-customer-match-conversion.html)의 변경 사항에 따라 [EU 사용자 동의 정책](https://www.google.com/about/company/user-consent-policy/)을 업데이트하고 있습니다. 이 새로운 변경 사항에 따라 광고주는 EEA 및 영국 최종 사용자에게 특정 정보를 공개하고, 해당 사용자로부터 필요한 동의를 받아야 합니다. 이 변경 사항의 일환으로, [Braze에서 두 가지 동의 신호를 커스텀 속성으로 수집]({{site.baseurl}}/partners/canvas_steps/google_audience_sync#collecting-consent-for-eea-and-uk-end-users)할 수 있습니다. Braze는 이러한 커스텀 속성의 데이터를 Google의 적절한 동의 필드에 동기화합니다.

카탈로그에 대한 Braze CDI 지원이 이제 [Databricks 소스]({{site.baseurl}}/user_guide/data_and_analytics/cloud_ingestion/sync_catalogs_data#step-2-integrate-cloud-data-ingestion-with-catalog-data)에서 사용 가능합니다.

## 강력한 채널 {#robust-channels}

### 커스텀 코드 블록 {#custom-code-blocks}

{% multi_lang_include release_type.md release="General availability" %}

[커스텀 코드 블록]({{site.baseurl}}/user_guide/message_building_by_channel/in-app_messages/drag_and_drop/editor_blocks#custom-code)을 사용하면 인앱 메시지의 HTML, CSS 및 JavaScript를 추가, 편집 또는 삭제할 수 있습니다.

### 푸시 알림 페이로드 크기 줄이기 {#reduce-payload-size-of-push-notifications}

새로운 도움말 문서 [푸시 알림 페이로드 크기 줄이기]({{site.baseurl}}/user_guide/channels/push/best_practices#reduce-push-notification-payload-size)에서는 푸시 페이로드 크기 제한으로 인해 Campaign이나 캔버스 단계를 시작할 수 없는 경우 푸시 알림의 페이로드 크기를 줄이기 위한 몇 가지 팁을 제공합니다.

### Campaign 또는 Canvas에 BCC or 배너 콘텐츠 카드 주소 추가 {#add-bcc-addresses-to-your-campaign-or-canvas}

{% multi_lang_include release_type.md release="General availability" %}

이메일 메시지에 [BCC or 배너 콘텐츠 카드 주소]({{site.baseurl}}/user_guide/administrative/app_settings/email_settings/?tab=bcc%20address#outbound-email-settings)를 추가할 수 있습니다. 이렇게 하면 사용자가 수신하는 메시지와 동일한 사본이 BCC or 배너 콘텐츠 카드 받은편지함으로 전송됩니다. 이를 통해 규정 준수 요건이나 고객 지원 문제를 위해 사용자에게 보낸 메시지의 사본을 유지할 수 있습니다.

### 이메일 원클릭 수신 거부 링크 {#one-click-unsubscribe-links-for-emails}

[리스트 수신 거부 헤더]({{site.baseurl}}/user_guide/administrative/app_settings/email_settings#list-unsubscribe-header)를 사용하면 수신자가 메시지 본문이 아닌 메일함 UI 내에 표시되는 **수신 거부** 버튼을 통해 마케팅 이메일 수신을 원클릭으로 거부할 수 있습니다.

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### Criteo - Canvas 오디언스 동기화 {#criteo-canvas-audience-sync}

[Braze 오디언스 동기화 to Criteo]({{site.baseurl}}/partners/canvas_audience_sync/criteo_audience_sync)를 사용하면, 브랜드는 자체 Braze 통합에서 사용자 데이터를 Criteo 고객 목록에 추가하여 행동 트리거, 세분화 등을 기반으로 광고를 전달할 수 있습니다. BRAZE 캔버스에서 사용자 데이터를 기반으로 메시지(푸시, 이메일, 단문 메시지 서비스, 웹훅 등)를 트리거하는 데 일반적으로 사용하는 모든 기준을 Criteo 고객 목록의 해당 사용자에게 광고를 트리거하는 데에도 사용할 수 있습니다.

### Movable Ink - 동적 콘텐츠 {#movable-ink-dynamic-content}

[Movable Ink]({{site.baseurl}}/partners/message_personalization/dynamic_content/visual_and_interactive_content/movable_ink) 고객 데이터 API 통합을 사용하면 마케터가 Braze에 저장된 고객 이벤트 데이터를 활성화하여 Movable Ink 내에서 개인화된 콘텐츠를 생성할 수 있습니다.

### Scuba Analytics - 분석 {#scuba-analytics-analytics}

[Scuba Analytics]({{site.baseurl}}/partners/data_and_analytics)는 고속 시계열 데이터를 위해 설계된 풀스택 머신 러닝 기반 데이터 협업 플랫폼입니다. Scuba를 사용하면 사용자(액터라고도 함)를 선택적으로 내보내고 Braze 플랫폼에 로드할 수 있습니다. Scuba에서는 커스텀 액터 속성을 사용하여 행동 트렌드를 분석하고, 다양한 플랫폼에서 데이터를 활성화하며, 머신 러닝을 통해 예측 모델링을 수행할 수 있습니다.

## SDK 업데이트 {#sdk-updates}

최신 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 SDK 업데이트 섹션에 나열되어 있으며, 그 외 모든 업데이트는 해당 SDK 체인지로그에서 확인할 수 있습니다.

- [Expo Plugin 2.0.0](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
    - [Expo SDK 50 요구 사항](https://expo.dev/changelog/2024/01-18-sdk-50)에 따라 iOS 최소 플랫폼 버전을 `13.4`로 올렸습니다.
    - 이 버전은 Expo SDK 50을 완전히 지원하려면 Braze React Native SDK [8.3.0+](https://github.com/braze-inc/braze-react-native-sdk/releases/tag/8.3.0) 버전이 필요합니다.
- [React Native SDK 8.3.0](https://github.com/braze-inc/braze-react-native-sdk/blob/8.3.0/CHANGELOG.md)
- [Unity SDK 5.1.0](https://github.com/braze-inc/braze-unity-sdk/blob/master/CHANGELOG.md)
- [Android SDK 30.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
    - In-App Messages에 사용되는 WebView가 `WebViewAssetLoader`를 사용하도록 업데이트되었습니다.
        - `InAppMessageHtmlBaseView` 및 `BrazeWebViewActivity`에서 `WebSettings.allowFileAccess`가 이제 false로 설정됩니다.
        - 자체 `InAppMessageWebViewClient` 또는 `InAppMessageHtmlBaseView`를 사용하는 경우, 원본 클래스와 비교하여 구현이 에셋을 올바르게 로드하고 있는지 확인하세요.
        - 커스텀 클래스를 사용하지 않는 경우, 이전과 동일하게 작동합니다.
- [Braze Swift SDK 6.6.2](https://github.com/braze-inc/braze-swift-sdk/blob/6.6.2/CHANGELOG.md)
- [Braze Swift SDK 7.6.0](https://github.com/braze-inc/braze-swift-sdk/releases/tag/7.6.0)
- [Xamarin SDK 버전 3.0.0](https://github.com/braze-inc/braze-xamarin-sdk/blob/master/CHANGELOG.md)
    - NuGet 패키지 이름이 `AppboyPlatformXamariniOSBinding`에서 [`BrazePlatform.BrazeiOSBinding`](https://www.nuget.org/packages/BrazePlatform.BrazeiOSBinding/)으로 변경되었습니다.
        - 업데이트된 패키지를 사용하려면, `AppboyPlatformXamariniOSBinding;`을 사용하는 모든 인스턴스를 다음으로 교체하세요: using Braze;
    - 이 버전은 .NET 6 이상을 사용해야 하며 Xamarin 프레임워크를 사용하는 프로젝트에 대한 지원이 제거되었습니다. Xamarin 지원 종료에 관한 [Microsoft의 정책](https://dotnet.microsoft.com/en-us/platform/support/policy/xamarin)을 참조하세요.
    - Android 바인딩을 [Braze Android SDK 26.3.2에서 29.0.1로](https://github.com/braze-inc/braze-android-sdk/compare/v26.3.1...v29.0.1#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed) 업데이트했습니다.
- [Xamarin SDK 4.0.0](https://github.com/braze-inc/braze-xamarin-sdk/blob/master/CHANGELOG.md)
    - 이 버전은 iOS 바인딩을 [Braze Swift SDK](https://github.com/braze-inc/braze-swift-sdk/)를 사용하도록 업데이트합니다. 대부분의 iOS 퍼블릭 API가 변경되었으므로, 대체 사용에 관한 안내는 [마이그레이션 가이드](https://braze-inc.github.io/braze-swift-sdk/documentation/braze/appboy-migration-guide/)(Swift)를 참조하세요. 기존 퍼블릭 API를 계속 사용할 수 있도록 호환성 바인딩을 제공합니다.
        - iOS 바인딩은 이제 여러 모듈로 구성됩니다:
            - **BrazeKit:** 분석 및 푸시 알림을 지원하는 메인 SDK 라이브러리(nuget: [Braze.iOS.BrazeKit](https://www.nuget.org/packages/Braze.iOS.BrazeKit)).
            - BrazeUI: In-App Messages 및 Content Cards를 위한 Braze 제공 사용자 인터페이스 라이브러리(nuget: [Braze.iOS.BrazeUI](https://www.nuget.org/packages/Braze.iOS.BrazeUI)).
            - BrazeLocation: 위치 분석 및 지오펜스 모니터링을 지원하는 위치 라이브러리(nuget: [Braze.iOS.BrazeLocation](https://www.nuget.org/packages/Braze.iOS.BrazeLocation)).
            - BrazeKitCompat: 4.0.0 이전 API를 지원하는 호환성 라이브러리(nuget: [Braze.iOS.BrazeKitCompat](https://www.nuget.org/packages/Braze.iOS.BrazeKitCompat)).
            - BrazeUICompat: 4.0.0 이전 UI API를 지원하는 호환성 라이브러리(nuget: [Braze.iOS.BrazeUICompat](https://www.nuget.org/packages/Braze.iOS.BrazeUICompat)).
        - 새로운 통합에 대해서는 BrazeiOSMauiSampleApp을, 호환성 모듈 사용에 대해서는 BrazeiOSMauiCompatSampleApp을 참조하세요.
    - iOS 바인딩을 [Braze Swift SDK 7.6.0](https://github.com/braze-inc/braze-swift-sdk/releases/tag/7.6.0)으로 업데이트했습니다.
    - iOS 바인딩은 Xcode 15와의 호환성을 위해 .NET 7 사용이 필요합니다.
