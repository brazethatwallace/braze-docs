# 2024년 10월 15일 릴리스 {#october-15-2024-release}

## 데이터 유연성 {#data-flexibility}

### Campaigns 및 Canvases {#campaigns-and-canvases}

Campaigns 및 Canvases를 생성할 때, [정확한 통계 계산]({{site.baseurl}}/user_guide/engagement_tools/segments/creating_a_segment#statistics-for-segment-size)을 선택하면 기본값 추정 대신 타겟 오디언스에서 도달 가능한 정확한 사용자 수를 계산할 수 있습니다.

### API Android 객체 {#api-android-objects}

[`android_priority` 파라미터]({{site.baseurl}}/api/objects_filters/messaging/android_object#additional-parameter-details)는 FCM 발신자 우선순위를 지정하기 위해 "normal" 또는 "high" 값을 허용합니다. 기본적으로 알림 메시지는 높은 우선순위로 전송되고, 데이터 메시지는 일반 우선순위로 전송됩니다.

서로 다른 값이 전송에 어떤 영향을 미치는지에 대한 자세한 내용은 [Android 메시지 우선순위](https://firebase.google.com/docs/cloud-messaging/android/message-priority/)를 참조하세요.

### SDK

앱에서 자세한 로깅을 활성화하지 않고도 SDK 기반 채널의 문제를 해결하려면 [Braze SDK 내장 디버거]({{site.baseurl}}/developer_guide/sdk_integration/debugging)를 사용하세요.

### 라이브 액티비티 {#live-activities}

Swift 라이브 액티비티의 [자주 묻는 질문]({{site.baseurl}}/developer_guide/live_notifications/live_activities)에 몇 가지 새로운 질문과 답변을 추가했습니다.

### 커스텀 이벤트 {#custom-events}

배열 또는 객체 값을 포함하는 [이벤트 속성정보 객체]({{site.baseurl}}/user_guide/data/activation/events/custom_events/custom_event_properties)는 이제 최대 100&nbsp;KB의 이벤트 속성정보 페이로드를 가질 수 있습니다.

### 무작위 버킷 번호 {#random-bucket-numbers}

Campaigns에서 A/B 테스트를 수행하거나 특정 사용자 그룹을 타겟팅하려면 [무작위 버킷 번호를 사용한 무작위 오디언스 재진입]({{site.baseurl}}/user_guide/engagement_tools/testing/random_bucket_numbers#random-audience-re-entry-using-random-bucket-numbers)을 활용하세요.

### 세그먼트 확장 {#segment-extensions}

확장이 새로고침될 빈도(매일, 매주 또는 매월)와 새로고침이 발생할 특정 시간을 선택하여 [반복 스케줄에 따라 세그먼트 확장을 새로고침]({{site.baseurl}}/user_guide/engagement_tools/segments/segment_extension#setting-up-a-recurring-refresh)할 수 있습니다.

## 견고한 채널 {#robust-channels}

### 단문 메시지 서비스

단문 메시지 서비스 메시지에서 UTM 매개변수를 사용하여 Google Analytics와 같은 서드파티 분석 도구에서 캠페인 성과를 추적하는 방법을 보여주는 [UTM 매개변수 추가]({{site.baseurl}}/user_guide/message_building_by_channel/sms/campaign/link_shortening#using-link-shortening)를 추가했습니다.

### 랜딩 페이지 {#landing-pages}

[자체 도메인을 연결]({{site.baseurl}}/user_guide/messaging/landing_pages/customize_the_url)하여 Braze 워크스페이스에 브랜드에 맞는 랜딩 페이지 URL을 커스터마이즈할 수 있습니다.

### LINE과 Braze {#line-and-braze}

{% multi_lang_include release_type.md release="Beta" %}

새로운 설명서를 추가했습니다:

- [LINE 메시지 유형]({{site.baseurl}}/line/create/message_types)은 작성할 수 있는 LINE 메시지 유형과 그 특징 및 제한 사항을 다루며, LINE 베타 컬렉션의 일부입니다.
- [사용자 계정 연동]({{site.baseurl}}/line/line_setup#user-account-linking)을 통해 사용자가 LINE 계정을 앱의 사용자 계정에 연결할 수 있습니다. 그런 다음 Braze에서 {% raw %}`{{line_id}}`{% endraw %}와 같은 Liquid를 사용하여 사용자의 LINE ID를 웹사이트 또는 앱에 전달하는 개인화된 URL을 생성할 수 있으며, 이를 통해 알려진 사용자와 연결할 수 있습니다.

### WhatsApp과 Braze {#whatsapp-and-braze}

[WhatsApp Business 계정(WABA)]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/overview#step-2-whatsapp-setup)을 이제 여러 비즈니스 솔루션 제공업체와 공유할 수 있습니다.

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### Future Anthem - 동적 콘텐츠 {#future-anthem-dynamic-content}

Braze와 [Future Anthem]({{site.baseurl}}/partners/future_anthem) 파트너십은 Amplifier AI를 활용하여 콘텐츠 개인화, 실시간 경험, 동적 오디언스를 제공합니다. Amplifier AI는 스포츠, 카지노, 복권 분야 전반에서 작동하며, 좋아하는 게임, 인게이지먼트 점수, 예상 다음 베팅 등과 같은 업계별 플레이어 속성으로 Braze 플레이어 프로필을 강화할 수 있습니다.

## SDK 업데이트 {#sdk-updates}

최신 SDK 업데이트가 출시되었습니다. 주요 변경 사항은 SDK 업데이트 섹션에 나열되어 있으며, 그 외 모든 업데이트는 해당 SDK 체인지로그에서 확인할 수 있습니다.

- [SWIFT SDK 10.3.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1110)
- [SWIFT SDK 11.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1110)
    - [Swift 6 엄격한 동시성 검사](https://developer.apple.com/documentation/swift/adoptingswift6) 지원이 추가되었습니다.
        - 관련 공개 Braze 클래스 및 데이터 타입이 이제 `Sendable` 프로토콜을 준수하며, 동시성 컨텍스트 간에 안전하게 사용할 수 있습니다.
        - 메인 스레드 전용 API는 이제 `@MainActor` 속성으로 표시됩니다.
        - 컴파일러가 생성하는 경고를 최소화하면서 이러한 기능을 활용하려면 Xcode 16.0 이상을 사용하는 것을 권장합니다. 이전 버전의 Xcode도 계속 사용할 수 있지만 일부 기능에서 경고가 발생할 수 있습니다.
    - 푸시 알림 지원을 수동으로 통합하는 경우, 경고를 방지하기 위해 `UNUserNotificationCenterDelegate` 적합성에 `@preconcurrency` 속성을 사용하도록 업데이트해야 할 수 있습니다.
        - 프로토콜 적합성에 `@preconcurrency` 속성을 적용하는 것은 Xcode 16.0 이상에서만 가능합니다. [SWIFT SDK 수동 푸시 알림 통합 샘플](https://github.com/braze-inc/braze-swift-sdk/tree/main/Examples/Swift/Sources/PushNotifications-Manual)을 참조하세요.
- [React Native SDK 13.0.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md#1300)
    - 네이티브 Android 버전 바인딩이 [Braze Android SDK 31.1.0에서 32.1.0](https://github.com/braze-inc/braze-android-sdk/compare/v31.1.0...v32.1.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed)으로 업데이트되었습니다.
    - 네이티브 iOS 버전 바인딩이 [Braze SWIFT SDK 10.3.0에서 11.0.0](https://github.com/braze-inc/braze-swift-sdk/compare/10.3.0...11.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed)으로 업데이트되었습니다.
- [Flutter SDK 11.1.0](https://pub.dev/packages/braze_plugin/changelog#1110)
- [SWIFT SDK 11.1.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1110)

    - Kotlin이 1.8에서 Kotlin 2.0으로 업데이트되었습니다.
