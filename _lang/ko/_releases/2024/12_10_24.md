# 2024년 12월 10일 릴리스 {#december-10-2024-release}

## IP 주소 기반 SDK 사용자 위치 {#sdk-user-location-by-ip-address}

2024년 11월 26일부터 Braze는 첫 번째 SDK 세션 시작 시 IP 주소를 사용하여 지리적 위치 국가에서 사용자 위치를 감지합니다. Braze는 IP 주소를 사용하여 SDK를 통해 생성된 사용자 프로필의 국가 값을 설정하며, IP 기반 국가 설정은 첫 번째 세션 중 및 이후에 사용할 수 있습니다. 자세한 내용은 [위치 추적]({{site.baseurl}}/user_guide/audience/locations_and_geofences/location_tracking/)을 참조하세요.

## 고급 액세스 설정 {#elevated-access-setting}

[고급 액세스]({{site.baseurl}}/user_guide/administrative/app_settings/company_settings/security_settings/#elevated-access)는 Braze 대시보드에서 민감한 작업에 대한 추가 보안 계층을 제공합니다. 활성화되면 사용자는 Segment를 내보내거나 API 키를 보기 전에 계정을 다시 인증해야 합니다. 고급 액세스를 사용하려면 **설정** > **관리자 설정** > **보안 설정**으로 이동하여 토글을 켜세요.

## 개인 식별 정보(PII) 보기 권한 {#permission-for-viewing-personally-identifiable-information-pii}

관리자의 경우, Liquid 변수를 사용하여 사용자 속성에 액세스하는 메시지 미리보기에서 회사가 대시보드에 정의한 대로 [사용자가 PII를 볼 수 있도록 허용]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/user_permissions/#list-of-permissions)할 수 있습니다.

워크스페이스의 경우, 사용자가 대시보드에서 회사가 정의한 대로 PII를 볼 수 있도록 허용하거나, 사용자 프로필을 보되 회사가 PII로 식별한 필드를 편집하지 못하도록 할 수 있습니다.

## 데이터 유연성 {#data-flexibility}

### 데이터 레이크 스키마 {#data-lake-schemas}

원시 테이블 스키마에 다음 스키마가 추가되었습니다:
- `USERS_CANVASSTEP_PROGRESSION_SHARED`: Canvas에서 사용자의 진행 이벤트
- `CHANGELOGS_GLOBALCONTROLGROUP_SHARED`: 현재 및 이전 전역 제어 그룹에 포함된 무작위 버킷 번호 식별
- `USERS_MESSAGES_FEATUREFLAG_IMPRESSION_SHARED`: 사용자가 피처 플래그를 볼 때의 노출 이벤트

### 계정 기반 세분화 {#account-based-segmentation}

B2B 데이터 모델을 설정하는 방식에 따라 두 가지 방법으로 [B2B(기업 간) 계정 기반 세분화]({{site.baseurl}}/user_guide/get_started/b2b_use_cases/account_based_segmentation/)를 수행할 수 있습니다:

- 비즈니스 오브젝트에 카탈로그를 사용하는 경우
- 비즈니스 오브젝트에 연결된 소스를 사용하는 경우

### 세분화 필터 {#segmentation-filters}

세분화 필터의 전체 목록과 설명은 [세분화 필터]({{site.baseurl}}/user_guide/audience/segments/segmentation_filters/)를 참조하세요.

#### 사용자 프로필 생성 시점 {#user-profile-created-at}

사용자 프로필이 생성된 시점을 기준으로 사용자를 세분화합니다. 사용자가 CSV 또는 API를 통해 추가된 경우 이 필터는 추가된 날짜를 반영합니다. 사용자가 CSV 또는 API로 추가되지 않았고 SDK에서 첫 번째 세션이 추적된 경우 이 필터는 해당 첫 번째 세션의 날짜를 반영합니다.

#### 발신 전화번호 {#sending-phone-number}

e.164 전화번호 필드로 사용자를 세분화합니다. 이 필터와 함께 정규표현식을 사용하여 특정 국가 코드가 포함된 전화번호를 기준으로 세분화할 수 있습니다.

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### Narvar - 전자상거래 {#narvar-ecommerce}

Braze와 [Narvar](https://corp.narvar.com/)의 통합을 통해 브랜드는 Narvar의 알림 이벤트를 활용하여 Braze에서 직접 메시지를 트리거함으로써 고객에게 적시에 업데이트 정보를 제공할 수 있습니다.

### Currents용 Zeotap - 고객 데이터 플랫폼 {#zeotap-for-currents-customer-data-platform}

Braze와 [Zeotap](https://zeotap.com/)의 통합을 통해 Zeotap 고객 Segment를 Braze 사용자 프로필에 동기화하여 Campaigns의 규모와 도달 범위를 확장할 수 있습니다. [Currents]({{site.baseurl}}/user_guide/data/distribution/braze_currents/)를 사용하면 데이터를 Zeotap에 연결하여 전체 성장 스택에서 실행 가능하게 만들 수도 있습니다.

### Notify - 동적 콘텐츠 {#notify-dynamic-content}

Braze와 [Notify](https://notifyai.io/)의 통합을 통해 마케터는 다양한 플랫폼에서 효과적으로 참여를 유도할 수 있습니다. 기존 마케팅 방식에 의존하는 대신, Braze API로 트리거되는 Campaign은 Notify의 기능을 활용하여 이메일, SMS, 푸시 알림 등 여러 채널을 통해 개인화된 메시지를 전달할 수 있습니다.

### Contentful - 동적 콘텐츠 {#contentful-dynamic-content}

Braze와 [Contentful](https://www.contentful.com/)의 통합을 통해 연결된 콘텐츠를 동적으로 사용하여 Contentful의 콘텐츠를 Braze Campaigns로 가져올 수 있습니다.

### Outgrow - 리드 캡처 {#outgrow-leads-capture}

Braze와 [Outgrow](https://outgrow.co/)의 통합을 통해 Outgrow의 사용자 데이터를 자동으로 Braze로 전송하여 고도로 개인화된 타겟팅 Campaigns를 진행할 수 있습니다.
