# 2024년 8월 20일 릴리스 {#august-20-2024-release}

## 새로운 사용 사례 {#new-use-cases}

### 카탈로그 {#catalogs}

모든 유형의 데이터를 카탈로그로 가져올 수 있습니다. 일반적으로 데이터는 제품, 할인, 프로모션, 이벤트 등과 같은 오퍼링에 대한 메타데이터입니다. [사용 사례]({{site.baseurl}}/user_guide/data/activation/catalogs/)를 읽고 이 데이터를 사용하여 관련성이 높은 메시지로 사용자를 타겟팅하는 방법을 알아보세요.

### Intelligence Suite

Intelligence Suite는 사용자 기록과 Campaign 및 Canvas 성과를 분석하는 강력한 기능을 제공하며, 참여, 조회수 및 전환을 높이기 위해 자동으로 조정합니다. 이러한 기능이 다양한 산업에 어떻게 도움이 되는지 몇 가지 예를 보려면 [활용 사례]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/)를 확인하세요.

## 홈 대시보드 업데이트 {#home-dashboard-update}

최근에 편집하거나 생성한 파일에 쉽게 액세스하여 Braze 대시보드에서 [중단한 부분부터 다시 시작]({{site.baseurl}}/user_guide/data_and_analytics/analytics/home_dashboard/#pick-up-where-you-left-off)할 수 있습니다. 이 섹션은 Braze 대시보드의 **홈** 페이지 상단에 나타납니다.

## 데이터 유연성 {#data-flexibility}

### 데이터 변환 템플릿 및 새 대상 {#data-transformation-templates-and-new-destination}

{% multi_lang_include release_type.md release="General availability" %}

기본 코드 대신 특정 외부 플랫폼에서 시작하는 데 도움이 되는 전용 [템플릿 라이브러리]({{site.baseurl}}/user_guide/data_and_analytics/data_transformation/creating_a_transformation/#step-2-create-a-transformation)를 사용하여 데이터 변환을 구축하세요. 이제 소스 플랫폼의 웹훅을 변환하여 사용자에게 즉시 메시지를 보낼 수 있도록 **POST: API를 통해서만 즉시 메시지 전송**을 대상으로 선택할 수 있습니다.

### 사용자 일괄 병합 {#merge-users-in-bulk}

{% multi_lang_include release_type.md release="General availability" %}

중복된 고객 프로필이 있는 경우 이러한 사용자를 [일괄 병합]({{site.baseurl}}/user_guide/engagement_tools/segments/user_profiles/duplicate_users/#bulk-merging)하여 데이터를 간소화할 수 있습니다.

### 커스텀 속성 내보내기 {#export-custom-attributes}

{% multi_lang_include release_type.md release="General availability" %}

**커스텀 속성** 페이지에서 **모두 내보내기**를 선택하여 [커스텀 속성 목록을 CSV 파일로 내보낼]({{site.baseurl}}/user_guide/data_and_analytics/custom_data/custom_attributes/#exporting-data) 수 있습니다. CSV 파일이 생성되고 다운로드 링크가 이메일로 전송됩니다.

### Currents IP 허용 목록 {#currents-ip-allowlisting}

Braze는 [허용 목록]({{site.baseurl}}/user_guide/data/distribution/braze_currents/setting_up_currents/)에 옵트인한 모든 API 키에 자동으로 동적으로 추가되는 나열된 IP에서 Currents 데이터를 전송합니다.

## 강력한 채널 {#robust-channels}

### 새로운 Segment 빌더 경험 {#new-segment-builder-experience}

{% multi_lang_include release_type.md release="General availability" %}

[업데이트된 경험]({{site.baseurl}}/user_guide/audience/segments/creating_a_segment/)을 사용하여 Segment를 구축하세요. Segments는 데이터가 변경됨에 따라 실시간으로 업데이트되며, 타겟팅 및 메시징 목적에 맞게 필요한 만큼의 Segments를 생성할 수 있습니다.

### Segments별 측정기준 {#metrics-by-segments}

Campaigns, Canvas, 배리언트 및 단계의 성과 측정기준을 Segments별로 분류하려면 [쿼리 빌더]({{site.baseurl}}/user_guide/analytics/reports/query_builder/) 보고서 템플릿을 사용하세요.

### 전화번호 획득 {#phone-number-acquisition}

WhatsApp 메시징 채널을 사용하려면 WhatsApp의 [Cloud API](https://developers.facebook.com/docs/whatsapp/cloud-api/phone-numbers) 또는 [On-Premises API](https://developers.facebook.com/docs/whatsapp/on-premises/phone-numbers) 요구 사항을 충족하는 전화번호가 필요합니다.

전화번호는 직접 획득해야 하며, Braze는 번호를 제공하지 않습니다. 비즈니스 전화 제공업체를 통해 SIM 카드가 있는 물리적 전화를 구입하거나 당사의 파트너 중 하나를 사용할 수 있습니다: Twilio 또는 Infobip. **Twilio 또는 Infobip 계정이 있어야 하며, 이 작업은 Braze를 통해 수행할 수 없습니다.**

## 새로운 Braze 파트너십 {#new-braze-partnerships}

### Zendesk Chat - 인스턴트 채팅 {#zendesk-chat-instant-chat}

Braze와 [Zendesk Chat]({{site.baseurl}}/partners/zendesk_chat/) 통합은 각 플랫폼의 웹훅을 사용하여 양방향 SMS 대화를 설정합니다. 사용자가 지원을 요청하면 Zendesk에 티켓이 생성됩니다. 상담원 응답은 API 트리거 SMS Campaign을 통해 Braze로 전달되고, 사용자 답장은 다시 Zendesk로 전송됩니다.

## SDK 업데이트 {#sdk-updates}

다음 SDK 업데이트가 릴리스되었습니다. 주요 변경 사항은 아래에 나열되어 있으며, 그 외의 모든 업데이트는 해당 SDK 체인지로그를 확인하면 확인할 수 있습니다.

- [Android SDK 32.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [Swift SDK 10.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - [`Braze.Notifications.subscribeToUpdates(payloadTypes:_:)`](https://braze-inc.github.io/braze-swift-sdk/documentation/brazekit/braze/notifications-swift.class/subscribetoupdates(payloadtypes:_:))를 사용하여 푸시 이벤트를 구독할 때 다음과 같은 변경 사항이 적용되었습니다:
        - 이제 `update` 클로저는 기본적으로 "Push Opened" 및 "Push Received" 이벤트 모두에 의해 트리거됩니다. 이전에는 "Push Opened" 이벤트에 의해서만 트리거되었습니다.
            - "Push Opened" 이벤트만 계속 구독하려면 `payloadTypes` 매개변수에 `[.opened]`를 전달하세요. 또는 `update` 클로저를 구현하여 `Braze.Notifications.Payload`의 `type`이 `.opened`인지 확인하세요.
        - `content-available: true`로 푸시 알림을 받을 때 [`Braze.Notifications.Payload.type`](https://braze-inc.github.io/braze-swift-sdk/documentation/brazekit/braze/notifications-swift.class/payload/type)은 이제 `.opened` 대신 `.received`가 됩니다.
    - 더 이상 사용되지 않는 다음 API를 사용 불가로 표시합니다:
        - `Braze.Configuration.Api.Flavor`
        - `Braze.Configuration.Api.flavor`
        - `Braze.Configuration.Api.SdkMetadata`
        - `Braze.Configuration.Api.addSdkMetadata(_:)`
        - `Braze.ContentCard.ClickAction.uri(_:useWebview:)`
        - `Braze.ContentCard.ClickAction.uri`
        - `Braze.InAppMessage.ClickAction.uri(_:useWebview:)`
        - `Braze.InAppMessage.ClickAction.uri`
        - `Braze.InAppMessage.ModalImage.imageUri`
        - `Braze.InAppMessage.Full.imageUri`
        - `Braze.InAppMessage.FullImage.imageUri`
        - `Braze.InAppMessage.Themes.default`
        - `Braze.deviceId(queue:completion:)`
        - `Braze._objc_deviceId(completion:)`
        - `Braze.deviceId()`
        - `Braze.User.setCustomAttributeArray(key:array:fileID:line:)`
        - `Braze.User.addToCustomAttributeArray(key:value:fileID:line:)`
        - `Braze.User.removeFromCustomAttributeArray(key:value:fileID:line:)`
        - `Braze.User._objc_addToCustomAttributeArray(key:value:)`
        - `Braze.User._objc_removeFromCustomAttributeArray(key:value:)`
        - `gifViewProvider`
        - `GifViewProvider.default`
    - 더 이상 사용되지 않는 API를 제거합니다:
        - `Braze.Configuration.DeviceProperty.pushDisplayOptions`
        - `Braze.InAppMessageRaw.Context.Error.extraProcessClickAction`
    - 더 이상 사용되지 않는 `BrazeLocation` 클래스를 제거하고 `BrazeLocationProvider`로 대체합니다.
- [Xamarin SDK 버전 6.0.0](https://github.com/braze-inc/braze-xamarin-sdk/blob/master/CHANGELOG.md)
    - .NET 7.0의 지원이 종료됨에 따라 iOS 및 Android 바인딩에 대한 .NET 8.0 지원이 추가되었습니다.
        - 이로 인해 .NET 7.0에 대한 지원이 제거됩니다.
    - Android 바인딩을 [Braze Android 30.4.0에서 32.0.0으로](https://github.com/braze-inc/braze-android-sdk/compare/v30.4.0...v32.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed) 업데이트했습니다.
    - iOS 바인딩을 [Braze Swift SDK 9.0.0에서 10.0.0으로](https://github.com/braze-inc/braze-swift-sdk/compare/9.0.0...10.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed) 업데이트했습니다.
        - 푸시 알림 이벤트를 구독할 때 iOS에서 "Push Opened" 이벤트에 대해서만 트리거되는 것이 아니라 "Push Received" 및 "Push Opened" 이벤트 모두에 대해 구독이 트리거됩니다.
- [React Native SDK 12.0.0](https://github.com/braze-inc/braze-react-native-sdk/blob/12.0.0/CHANGELOG.md)
    - 네이티브 iOS 버전 바인딩을 [Braze Swift SDK 9.0.0에서 10.0.0으로](https://github.com/braze-inc/braze-swift-sdk/compare/9.0.0...10.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed) 업데이트합니다.
        - 푸시 알림 이벤트를 구독하면 iOS에서 `push_opened` 이벤트에 대해서만 트리거되는 것이 아니라 `push_received` 및 `push_opened` 이벤트 모두에 대해 구독이 트리거됩니다.
