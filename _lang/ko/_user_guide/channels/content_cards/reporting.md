# 콘텐츠 카드 보고서 {#content-card-reporting}

> 이 참조 문서에서는 Braze 대시보드에서 제공하는 다양한 콘텐츠 카드 보고서 측정기준 및 분석 옵션에 대한 개요를 설명합니다.

## 발송이 기록되는 시점 {#when-sends-are-logged}

콘텐츠 카드의 _발송됨_ 이벤트 타이밍은 전달 유형과 **카드 생성** 설정에 따라 달라집니다.

### 스케줄 전달 {#scheduled-delivery}

스케줄된 콘텐츠 카드의 경우, _발송됨_ 이벤트 타이밍은 **카드 생성** 설정에 따라 달라집니다.

- **캠페인 시작 시:** 발송은 스케줄된 발송 시간에 기록되며, 이때 카드가 사용자의 피드에 기록됩니다. 사용자가 앱을 열었는지 또는 카드를 확인했는지 여부와 관계없이 발생합니다.
- **첫 노출 시:** 발송은 스케줄된 발송 시간 이후 앱이 카드를 처음 요청할 때 기록되며, 이때 카드가 온디맨드로 생성됩니다.

캠페인이 **첫 노출 시**(권장)를 사용하도록 구성된 경우, 캠페인 분석의 _발송됨_ 수는 개별 앱이 카드를 요청함에 따라 점진적으로 증가합니다. 카드가 만료되기 전에 앱이 카드를 요청하지 않으면(예: 사용자가 앱을 열지 않은 경우) 발송이 기록되지 않으며 카드가 전달되지 않습니다. 캠페인이 **캠페인 시작 시**를 사용하도록 구성된 경우, 캠페인 분석의 _발송됨_ 수는 스케줄된 시간에 급증합니다.

### 실행 기반 전달 {#action-based-delivery}

실행 기반 콘텐츠 카드의 경우, 발송은 사용자가 트리거 동작을 수행한 직후 카드가 피드에 기록될 때 로깅됩니다. 사용자가 카드를 확인했는지 여부와 관계없이 발생합니다.

### 수신된 Campaigns 및 리타겟팅 필터 {#campaigns-received-and-retargeting-filters}

전달 유형이나 **카드 생성** 설정에 관계없이, 콘텐츠 카드 Campaign은 사용자가 앱에서 실제로 카드를 확인한 후에만 사용자 프로필의 **수신된 Campaigns** 아래에 표시됩니다. **마지막으로 메시지를 수신한 시점** 및 **마지막으로 Campaign을 수신한 시점** 리타겟팅 필터도 같은 이유로 확인 시점에 업데이트됩니다.
