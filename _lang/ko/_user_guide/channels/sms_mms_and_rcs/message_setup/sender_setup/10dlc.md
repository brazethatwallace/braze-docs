# Application-to-Person 10자리 긴 코드 {#application-to-person-10-digit-long-codes}

> A2P 10DLC는 미국에서 비즈니스가 표준 10자리 긴 코드(10DLC) 전화번호를 통해 Application-to-Person(A2P) 유형의 메시지를 보낼 수 있도록 하는 시스템입니다. 이러한 등록된 긴 코드는 표준 긴 코드보다 더 높은 처리량, 더 나은 전달 가능성, 그리고 향상된 규정 준수를 제공합니다.

{% alert important %}
현재 미국 고객에게 발송하기 위해 미국 긴 코드를 보유하고 있거나 사용 중인 모든 고객은 10DLC에 긴 코드를 등록해야 합니다. 등록하지 않으면 모든 메시지가 심하게 필터링됩니다. 이 신청 절차는 4~6주가 소요됩니다.
{% endalert %}

## 왜 필요한가요 {#why-its-necessary}

10DLC 서비스는 긴 코드를 사용한 A2P 메시징을 전문적으로 지원하기 위해 만들어졌습니다. 역사적으로 긴 코드는 Person-to-Person(P2P) 메시징을 위한 것이었지만, 마케팅 목적으로 사용되면서 비즈니스가 제한된 처리량과 강화된 필터링으로 인해 제약을 받게 되었습니다.

10DLC는 다음을 제공하여 이러한 문제를 완화하는 데 도움을 줍니다:
- **더 높은 처리량**: 10DLC 번호는 일반 긴 코드보다 더 많은 양의 메시지를 지원합니다.
- **더 나은 전달 가능성**: 10DLC 번호는 A2P 트래픽용으로 지정되어 있으므로, 이 번호로 발송된 메시지는 일반 로컬 긴 코드로 발송된 메시지보다 수신자에게 도달할 가능성이 높고, 통신사에 의해 필터링되거나 거부될 가능성이 낮습니다.
- **향상된 규정 준수**: 상업적 문자 메시지에 로컬 긴 코드를 사용하는 것은 [CTIA](https://api.ctia.org/wp-content/uploads/2019/07/190719-CTIA-Messaging-Principles-and-Best-Practices-FINAL.pdf) 가이드라인에 위배됩니다. 10DLC 번호는 대량 메시징용으로 지정되어 있으며, 브랜드가 짧은 코드에 의존하지 않고도 업계 규정을 준수할 수 있도록 합니다.
- **예산 친화적**: 10DLC는 단문 메시지 서비스 발송을 시작하거나 소량으로 단문 메시지 서비스를 발송하려는 회사에 훌륭한 옵션입니다. 하루 100,000건 이상의 대량 메시지를 발송하는 브랜드의 경우, 짧은 코드 사용을 권장합니다.

2019년부터 통신사들은 상업적 메시징에 10DLC를 채택하기 시작했으며, 현재 Verizon과 AT&T가 10DLC를 지원하고 있고, 모든 주요 통신사가 곧 뒤따를 것으로 예상됩니다. 단기적으로는 불편을 초래할 수 있지만, 장기적으로 고객은 소비자를 원치 않는 메시지로부터 보호하면서 더 나은 전달 가능성을 누릴 수 있습니다.

## 알아야 할 사항 {#what-you-need-to-know}

### 접근 {#access}

A2P 10DLC에 긴 코드를 등록하는 데 4~6주가 소요됩니다.

### 비용 {#costs}

A2P 10DLC 등록에는 여러 유형의 수수료가 포함될 수 있습니다:

| 수수료 유형 | 설명 |
| -------- | ---------- |
| 등록 수수료 | 모든 주요 미국 네트워크에 브랜드와 사용 사례를 등록할 때 적용되는 소액 수수료입니다. |
| 2차 심사 수수료 | 브랜드는 [브랜드 신뢰 점수](#trust-score)에 이의를 제기하고 전체 처리량을 개선하기 위해 2차 심사 프로세스를 요청할 수 있으며, 이 프로세스에는 수수료가 부과됩니다. |
| 통신사 수수료 | 10DLC 등록 후 사용자에게 발송되는 아웃바운드 단문 메시지 서비스 및 MMS 메시지에 대해 통신사가 부과하는 수수료입니다. 2021년 10월 1일부터 미등록 트래픽(표준 긴 코드)에 대한 통신사 수수료가 등록된 트래픽(10DLC)보다 높아집니다. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Costs" }

업데이트된 [수수료 추정치](https://support.twilio.com/hc/en-us/articles/1260803965530-What-pricing-and-fees-are-associated-with-the-A2P-10DLC-service-)를 확인하려면 Twilio 10DLC 문서를 방문하세요.

### 처리량 {#throughput}

10DLC의 메시지 처리량은 브랜드 신뢰 점수, 일일 메시지 한도, 메시징 사용 사례 등 여러 요인에 따라 달라집니다.

#### 브랜드 신뢰 점수 {#trust-score}

Campaign Registry(TCR)는 회사와 관련된 특정 기준을 검토하기 위해 평판 알고리즘을 사용하고 각 브랜드의 메시징 처리량을 결정하는 신뢰 점수를 부여하는 서드파티 기관입니다. 이 신뢰 점수는 고객이 미국 10DLC 메시징에 등록할 때 부여됩니다. 신뢰 점수가 높을수록 더 나은 초당 메시지 수(MPS)를 경험하게 됩니다.

|     | 신뢰 점수 | AT&T | T-Mobile | Verizon |
| --- | ----------- | ---- | -------- | ------- |
| 높음 | 75-100 | 75 MPS | 75 MPS | 75 MPS |
| 중간 | 50-74 | 40 MPS | 40 MPS | 40 MPS |
| 낮음 | 1-49 | 4 MPS | 4 MPS | 4 MPS |
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3  .reset-td-br-4 aria-label="Brand trust score #trust-score" }

{% alert tip %}
Russell 3000 지수에 등재된 회사는 10DLC 등록 및 검토 후 높은 처리량과 브랜드 신뢰 점수를 부여받습니다.
{% endalert %}

#### 일일 메시지 한도 {#daily-message-limits}

일일 한도는 브랜드 신뢰 점수에 따라 2,000건에서 200,000건까지 다양하며, 모든 긴 코드에 걸쳐 적용됩니다. 높은 브랜드 신뢰 점수는 초당 60건의 메시지 처리량을 제공하지만, 통신사가 설정한 일일 메시지 한도는 여전히 적용됩니다. 이는 브랜드의 일일 피크 메시지가 부과된 일일 한도보다 높은 경우 짧은 코드가 더 나은 옵션이 될 수 있음을 의미합니다.

#### 메시징 사용 사례 {#messaging-use-cases}

처리량은 선택한 메시징 사용 사례 유형에 따라서도 영향을 받습니다. 대부분의 고객은 표준 마케팅 또는 혼합 마케팅 사용 사례에 해당합니다. 그 외 덜 일반적인 사용 사례는 다른 처리량 값의 영향을 받을 수 있습니다.

사용 사례에 따라 최대 처리량을 달성하는 데 필요한 신뢰 점수가 달라집니다. 다음 표는 표준 사용 사례와 일반적인 사용 사례 신뢰 점수 범위를 나열합니다. 긴급 서비스나 자선 단체와 같은 특수 사용 사례의 경우 [Twilio 문서](https://support.twilio.com/hc/en-us/articles/1260803225669-Message-throughput-MPS-and-Trust-Scores-for-A2P-10DLC-in-the-US)를 참조하세요.

| 표준 사용 사례 | 설명 |
| ------------------ | ----------- |
| 마케팅 | 세일 및 한정 기간 제안과 같은 프로모션 콘텐츠입니다. |
| 혼합 | 고객 관리 등 여러 사용 사례를 포함하는 Campaign입니다. |
| 고등 교육 | 고등 교육 기관을 위한 Campaign입니다. |
| 설문조사 및 투표 | 고객 설문조사와 같은 비정치적 설문조사 및 투표입니다. |
| 공익 광고 | 특정 주제에 대한 인식을 높이기 위한 공익 광고입니다. |
| 고객 관리 | 고객지원, 계정 관리 및 기타 고객 상호작용입니다. |
| 배송 알림 | 배송 메시지의 상태입니다. |
| 계정 알림 | 계정 상태에 대한 알림입니다. |
| 2FA | OTP와 같은 계정 인증 또는 확인입니다. |
| 보안 경고 | 시스템 침해에 대한 알림입니다. |
| 사기 경고 | 잠재적 사기 활동에 대한 메시지입니다. |

## 다음 단계 {#next-steps}

아직 10DLC에 등록하지 않은 고객은 고객 성공 매니저와 협력하여 긴 코드를 등록해야 합니다. **고객이 긴 코드를 등록하지 않으면, 2021년 10월 1일부터 긴 코드를 사용하는 모든 A2P 발신자의 메시지가 심하게 필터링됩니다.** 10DLC 등록을 시작하려면 고객 성공 매니저에게 문의하세요.
