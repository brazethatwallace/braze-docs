# 단문 메시지 서비스 및 RCS 요금 계산기 {#sms-and-rcs-billing-calculators}

> Braze에서 단문 메시지 서비스 메시지는 메시지 세그먼트 단위로 요금이 부과되며, RCS 메시지는 메시지 단위로 요금이 부과됩니다. 단문 메시지 서비스 세그먼트의 정의와 다양한 RCS 요금 유형을 이해하면 요금 청구 방식을 파악하고 예상치 못한 초과 요금을 방지하는 데 도움이 됩니다.

## 단문 메시지 서비스 메시지 카피 및 세그먼트 계산기 {#sms-message-copy-and-segment-calculator}

단문 메시지 서비스 메시지는 메시지 세그먼트 단위로 과금됩니다. 단문 메시지 서비스 메시지가 어떻게 분할되는지 이해하는 것은 요금 청구를 파악하는 데 핵심적입니다.

### 단문 메시지 서비스 세그먼트란 무엇인가요? {#what-is-an-sms-segment}

단문 메시지 서비스(단문 메시지 서비스)는 기기 간에 짧은 텍스트 메시지를 주고받을 수 있게 해주는 표준화된 커뮤니케이션 프로토콜입니다. 다른 시그널링 프로토콜 사이에 "끼워 넣기" 위해 설계되었기 때문에 단문 메시지 서비스 메시지 길이는 160개의 7비트 문자, 즉 1,120비트 또는 140바이트로 제한됩니다. 단문 메시지 서비스 메시지 세그먼트는 이동통신사가 문자 메시지를 측정하는 데 사용하는 문자 묶음 단위입니다. 메시지는 메시지 세그먼트 단위로 과금되므로, 단문 메시지 서비스를 활용하는 클라이언트는 메시지 분할 방식의 세부 사항을 이해하면 큰 도움이 됩니다.

Braze를 사용하여 단문 메시지 서비스 Campaign 또는 Canvas를 만들 때, 메시지 작성기에서 작성한 메시지는 사용자의 휴대전화에 전달될 때 보게 될 내용을 나타내지만, **메시지가 어떻게 세그먼트로 분할되고 최종적으로 어떻게 과금되는지를 나타내는 것은 아닙니다**. 전송되는 세그먼트 수를 파악하고, 발생할 수 있는 잠재적 초과량을 인지하는 것은 사용자의 책임이지만, 이를 보다 쉽게 할 수 있도록 몇 가지 리소스를 제공합니다. 자체 [세그먼트 계산기](#segment-calculator)를 확인해 보세요.

#### 세그먼트 분할 방식 {#segment-breakdown}

**독립형 단문 메시지 서비스 세그먼트**의 문자 제한은 인코딩 유형에 따라 160자([GSM-7](https://en.wikipedia.org/wiki/GSM_03.38) 인코딩) 또는 70자([UCS-2](https://en.wikipedia.org/wiki/Universal_Coded_Character_Set) 인코딩)입니다. 그러나 대부분의 휴대전화와 네트워크는 연결(concatenation)을 지원하여 GSM-7의 경우 최대 1,530자, UCS-2의 경우 최대 670자까지 긴 형식의 단문 메시지 서비스 메시지를 보낼 수 있습니다. 따라서 메시지에 여러 세그먼트가 포함되더라도, 이러한 연결 제한을 초과하지 않으면 하나의 메시지로 표시되고 그에 맞게 보고됩니다.

중요한 점은 **첫 번째 세그먼트의 문자 제한을 초과하면, 추가 문자로 인해 전체 메시지가 새로운 문자 제한에 따라 분할 및 세그먼트화된다**는 것입니다:
- **GSM-7 인코딩**
    - 160자 제한을 초과하는 메시지는 153자 세그먼트로 분할되어 개별적으로 전송된 후, 수신자의 기기에서 재조립됩니다. 예를 들어, 161자 메시지는 153자짜리 메시지 하나와 8자짜리 메시지 하나, 총 두 개의 메시지로 전송됩니다.
- **UCS-2 인코딩**
    - 단문 메시지 서비스 메시지에 이모지, 중국어, 한국어, 일본어 스크립트 등 비 GSM 문자를 포함하면, 해당 메시지는 UCS-2 인코딩으로 전송해야 합니다. 초기 세그먼트 제한인 70자를 초과하는 메시지는 전체 메시지가 67자 메시지 세그먼트로 연결됩니다. 예를 들어, 71자 메시지는 67자짜리 메시지 하나와 4자짜리 메시지 하나, 총 두 개의 메시지로 전송됩니다.

인코딩 유형에 관계없이, Braze에서 전송하는 각 단문 메시지 서비스 메시지는 최대 10개 세그먼트로 제한되며 [Liquid 템플릿]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/using_liquid), [연결된 콘텐츠]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content), 이모지, 링크와 호환됩니다.

### 카피 작성 시 유의 사항 {#things-to-keep-in-mind-as-you-create-your-copy}

- **세그먼트당 문자 제한**
    - [GSM-7](https://en.wikipedia.org/wiki/GSM_03.38)은 단일 단문 메시지 서비스 세그먼트에 대해 160자 제한이 있습니다. 160자를 초과하는 메시지는 모두 153자 제한으로 세그먼트화됩니다.
    - [UCS-2](https://en.wikipedia.org/wiki/Universal_Coded_Character_Set)는 메시지 세그먼트당 70자 제한이 있습니다. 70자를 초과하는 메시지는 모두 67자 제한으로 세그먼트화됩니다.<br><br>
- **메시지당 세그먼트 제한**
    - 매체의 제한으로 인해 전송할 수 있는 세그먼트의 최대 수가 있습니다. 단일 Braze 단문 메시지 서비스 메시지에서 최대 **10개 세그먼트**까지 전송할 수 있습니다.
    - 이 10개 세그먼트는 1,530자(GSM-7 인코딩) 또는 670자(UCS-2 인코딩)로 제한됩니다.<br><br>
- **Liquid 템플릿, 연결된 콘텐츠, 이모지, 링크와 호환**
    - Liquid 템플릿 및 연결된 콘텐츠는 인코딩 유형의 문자 제한을 초과할 위험이 있습니다. [truncate words 필터](https://help.shopify.com/en/themes/liquid/filters/string-filters#truncatewords)를 사용하여 Liquid가 메시지에 가져올 수 있는 단어 수를 제한할 수 있습니다.
    - 이모지는 모든 이모지에 걸쳐 표준 문자 수가 없으므로, 메시지가 올바르게 세그먼트화되고 표시되는지 반드시 테스트하세요.
    - 링크는 많은 문자를 사용할 수 있어 의도한 것보다 더 많은 메시지 세그먼트를 생성할 수 있습니다. 링크 단축기를 사용할 수 있지만, 짧은 코드와 함께 사용하는 것이 가장 좋습니다. 자세한 내용은 [단문 메시지 서비스 FAQ]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/faqs)를 참조하세요.<br><br>
- **테스트**
    - 단문 메시지 서비스 메시지를 발송하기 전에 항상 테스트하세요. 특히 Liquid 및 연결된 콘텐츠를 사용할 때는 메시지 또는 카피 제한을 초과하면 추가 요금이 발생할 수 있습니다. 테스트 메시지도 메시지 제한에 포함된다는 점에 유의하세요.<br><br>
- **자동 응답 메시지**
    - 이중 옵트인 확인 및 HELP 키워드에 대한 응답 등 Braze에서 전송하는 자동 응답 메시지는 과금 대상 세그먼트에 포함되는 단문 메시지 서비스 전송입니다. 과금 대상 세그먼트 수는 카피의 길이와 문자 인코딩에 따라 달라집니다.

## RCS 메시지 과금 {#rcs-message-billing}

RCS 메시지는 콘텐츠와 메시지가 전달되는 국가에 따라 과금됩니다. 비용을 정확하게 예측하려면 다양한 메시지 유형과 과금 방식을 이해하는 것이 중요합니다.

### RCS 과금 유형 {#rcs-billing-types}

Braze 플랫폼은 글로벌 모델과 미국 모델이라는 두 가지 주요 과금 모델을 지원합니다.

#### 글로벌 모델(미국 외 시장) {#global-model-non-us-markets}

메시지는 메시지 단위로 과금되며 Basic 또는 Single로 분류됩니다.

{% tabs local %}
{% tab Basic %}

Basic RCS 메시지는 160자 이내의 텍스트 전용 메시지이며 단일 메시지로 과금됩니다.

{% alert note %}
버튼이나 리치 요소를 추가하면 메시지 유형이 Single RCS 메시지로 변경됩니다.
{% endalert %}

{% endtab %}
{% tab Single %}

Single RCS 메시지는 160자를 초과하거나 버튼 또는 미디어와 같은 리치 요소를 포함하는 메시지입니다. 메시지 길이에 관계없이 단일 메시지로 과금됩니다.

{% alert note %}
텍스트 메시지와 별도의 미디어 파일을 전송하면 두 개의 별도 메시지로 과금됩니다.
{% endalert %}

{% endtab %}
{% endtabs %}

#### 미국 모델 {#united-states-model}

메시지는 Rich 또는 Rich Media로 분류됩니다.

{% tabs local %}
{% tab Rich 메시지 %}

Rich 메시지는 버튼이 있거나 없는 텍스트 전용 메시지입니다. 메시지 세그먼트 단위로 과금되며, 각 세그먼트는 160 UTF-8 바이트로 제한됩니다. 즉, **세그먼트당 문자 수는 고정되어 있지 않습니다**. 160자의 일반 영어 문자로만 구성된 메시지는 하나의 세그먼트이지만, 긴 텍스트와 이모지가 포함된 메시지는 여러 세그먼트가 될 수 있습니다.

{% endtab %}
{% tab Rich Media 메시지 %}

Rich Media 메시지는 미디어 파일(이미지, 비디오) 또는 리치 카드를 포함하며 단일 메시지로 과금됩니다.

{% endtab %}
{% endtabs %}

### 메시지 작성기 및 크레딧 사용량 대시보드 {#message-composer-and-credits-usage-dashboard}

메시지를 작성할 때 메시지 작성기에서 과금 유형을 레이블(Basic RCS, Single RCS, Rich 또는 Rich Media)을 통해 실시간으로 표시하여 발송 전에 비용을 추적할 수 있도록 도와줍니다.

[크레딧 사용량 대시보드]({{site.baseurl}}/credits_usage_dashboard)에서는 이러한 과금 유형을 반영하고 미국 메시지에 사용된 세그먼트 수를 제공하여 메시지 크레딧 소비에 대한 투명한 보기를 제공합니다.
