# CSS 인라이닝

> CSS 인라이닝은 CSS 스타일 시트의 스타일을 HTML 이메일 본문으로 이동시키는 이메일 전처리 방식입니다. "인라이닝"이라는 용어는 스타일이 개별 HTML 요소에 "인라인"으로 적용된다는 사실에서 유래합니다.

일부 이메일 클라이언트의 경우, CSS 인라이닝을 사용하면 이메일 렌더링 방식이 개선되고 이메일이 기대한 대로 표시되는지 확인하는 데 도움이 됩니다. 이미 대부분의 CSS가 인라인 처리되어 있거나 HTML과 CSS가 대부분의 메일 클라이언트 요구 사항과 호환된다고 확신하는 경우, 이 기능을 켤 필요가 없을 수 있습니다. 동적으로 삽입된 스타일이 기존 인라인 스타일과 충돌하여 예상한 미리보기 및 이메일 렌더링이 변경될 수 있습니다.

## CSS 인라이닝 사용하기

HTML 편집기의 **발송 정보** 탭에서 **인라인 CSS 활성화** 토글을 사용하여 이메일 메시지별로 CSS 인라이닝을 켜거나 끌 수 있습니다.

![HTML 작성기에서 CSS 인라이닝을 관리하는 체크박스.]({% image_buster /assets/img_archive/css-inline2.png %}){: style="max-width:40%;"}

### 기본 인라이닝 상태

**설정** > **이메일 환경설정**에서 전역적으로 기본 켜기 또는 끄기 상태를 설정할 수 있습니다. **CSS 인라이닝** 설정을 찾으세요. 이 설정은 모든 새 이메일 메시지가 시작할 때 적용되는 기본값을 결정합니다. 이 설정을 변경해도 기존 이메일 메시지에는 영향을 미치지 않습니다. 이메일 메시지를 작성하는 동안 언제든지 이 기본값을 재정의할 수 있습니다.
