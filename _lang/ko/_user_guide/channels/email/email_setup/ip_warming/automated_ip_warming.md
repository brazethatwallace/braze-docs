# 자동화된 IP 워밍 {#automated-ip-warming}

> 자동화된 IP 워밍을 사용하여 새로운 전용 IP에서 이메일 발송량을 점진적으로 늘려 받은편지함 제공자와의 발송자 평판을 구축하세요. 자주 묻는 질문은 [자동화된 IP 워밍 FAQ]({{site.baseurl}}/user_guide/channels/email/email_setup/ip_warming/faq)를 참조하세요.

## 작동 방식 {#how-it-works}

자동 IP 워밍을 사용하면 일일 발송량을 점진적으로 늘려 받은편지함 공급자가 발송 패턴을 학습하고 신뢰할 수 있도록 할 수 있습니다. 워크스페이스에 도메인을 추가할 때, 홈 대시보드의 **Pick up where you left off** 섹션에서 **Automated IP Warming** 타일을 선택할 수 있습니다. 이 타일은 워크스페이스가 신규 발신자 온보딩 기간에 있는 동안 60일간 표시되며, 하나 이상의 플랜을 완료하면 숨겨집니다.

각 자동 IP 워밍 플랜은 하나의 발신 주소에 연결됩니다. 해당 발신 주소는 발송 서브도메인과 IP 풀에 매핑됩니다. 풀에 여러 전용 IP가 포함되어 있는 경우, Braze는 하나의 플랜에서 이를 함께 워밍합니다.

Braze는 가장 참여도가 높은 구독자에게 먼저 발송하여, 모범 사례에 맞는 속도로 일일 발송량을 늘립니다. 그런 다음 Braze는 인게이지먼트 및 전달 가능성 신호를 추적합니다. 문제가 감지되면 시스템이 자동으로 스케줄을 조정합니다.

하나 이상의 플랜을 완료한 후에는 **Settings** > **Email Preferences** > **Automated IP warming**에서 완료된 플랜을 확인할 수 있습니다.

## 전제 조건 {#prerequisites}

자동 IP 워밍을 수행하려면 다음이 필요합니다:

- 인증된 서브도메인 및 활성 IP 주소
- 플랜을 보고 설정하기 위한 권한:
    - "View Email Settings" — IP 워밍 플랜 및 홈 대시보드 위젯을 보기 위함
    - "View Email Templates" — 이메일 템플릿을 선택하기 위함
    - "View Segments" — Segments를 선택하기 위함
- 플랜을 실행하기 위한 권한:
    - "Edit Email Settings"
    - "Edit Campaigns"
    - "Launch Campaigns"
    - "Approve Campaigns"

{% alert note %}
Campaign 승인 워크플로가 켜져 있는 경우, Braze는 자동 IP 워밍에 의해 생성된 Campaigns를 자동으로 승인합니다.
{% endalert %}

## 자동화된 IP 워밍 계획 설정 {#set-up-an-automated-ip-warming-plan}

### 1단계: 스케줄 설정 {#step-1-set-a-schedule}

1. 고유한 **계획 이름**을 입력합니다. 계획 이름에는 문자, 숫자, 하이픈, 밑줄만 사용할 수 있으며, 워크스페이스 내에서 고유해야 합니다. 계획을 실행하려면 먼저 계획 이름이 필요합니다.
2. **발송 정보** 섹션에서 IP 주소를 워밍할 **발신 주소**를 선택합니다. Braze는 해당 발신 주소에 대한 연결된 **IP 풀**과 **풀 내 IP 주소** 수를 표시합니다.
3. **현재 일일 발송량**과 **목표 발송량**을 입력합니다. Braze는 선택한 풀의 IP당 최대 200만 건의 발송을 목표 발송량으로 권장합니다. 현재 일일 발송량이 0인 경우, 스케줄 첫날은 IP당 최대 50건, 총 500건으로 제한되어 시작합니다.
4. 자동화된 IP 워밍의 시작 날짜를 선택합니다. 이 날짜는 계획이 실행된 후 최소 하루 뒤여야 합니다.
5. 발송 시간을 입력합니다. 메시지는 워크스페이스 시간대(또는 워크스페이스에 재정의가 없는 경우 회사 시간대)로 발송됩니다.
6. **다음: Segments**를 선택하여 설정을 계속합니다.

![스케줄 세부 정보 예시.]({% image_buster /assets/img/automated_ip_warming_schedule.png %})

### 2단계: Segments 선택 및 순위 지정 {#step-2-select-and-rank-segments}

1. 다음으로, 타겟팅할 Segments를 선택합니다. IP 워밍 중에 Braze는 인게이지먼트가 가장 높은 사용자에게 먼저 발송을 시작하고, 시간이 지남에 따라 발송량을 점진적으로 늘리면서 인게이지먼트가 낮은 Segments를 서서히 추가합니다.
2. 그런 다음, 드래그 앤 드롭으로 Segments를 높은 인게이지먼트부터 낮은 인게이지먼트 순으로 정렬합니다. 높은 인게이지먼트에는 이메일을 지속적으로 열람하고 클릭하는 수신자가 포함됩니다. 낮은 인게이지먼트에는 이메일 참여가 일관되지 않거나 오랫동안 이메일에 참여하지 않은 수신자가 포함됩니다.
3. **다음: 메시지**를 선택하여 설정을 계속합니다.

{% alert important %}
선택한 모든 Segments의 이메일 발송 가능한 총 사용자 수가 **목표 발송량** 이상인지 확인합니다. 오디언스가 목표 발송량보다 적은 경우, 일부 사용자가 같은 날 두 개 이상의 이메일 템플릿을 수신할 수 있습니다. 자세한 내용은 [오디언스 규모 및 사용자당 다중 발송](#audience-size-and-multiple-sends-per-user)을 참조하세요.
{% endalert %}

![자동화된 IP 워밍을 위해 선택된 두 개의 타겟 Segments.]({% image_buster /assets/img/automated_ip_warming_segment.png %})

### 3단계: 발송할 메시지 선택 {#step-3-select-the-messages-to-send}

1. **이메일 템플릿 선택**을 선택합니다.
2. 발송할 메시지의 이메일 템플릿을 선택합니다. IP 워밍 중에 발송하는 콘텐츠는 열람과 클릭을 유도하는 것이어야 합니다. 과거에 좋은 반응을 얻었던 콘텐츠를 선택하는 것을 권장합니다. 예를 들어, 프로모션 혜택을 활용하여 즉각적인 참여와 구매를 유도할 수 있습니다.
3. **템플릿 선택**을 선택합니다. Braze는 실행하기 전에 필요한 템플릿 수를 계산합니다. 시스템이 전달 가능성 문제에 대해 중단 없이 조정할 수 있도록 최소 필요 수보다 더 많은 템플릿을 제공하는 것을 권장합니다.
4. 필요한 수의 템플릿을 추가한 후 **다음: 요약**을 선택합니다.

{% alert important %}
IP 워밍 도구에서 생성된 Campaigns에 대한 변경 사항(예약 날짜, Segment, 발송량 변경 등)은 IP 워밍 **요약** 페이지에 반영되지 않습니다.
{% endalert %}

### 4단계: 전환 이벤트 선택 {#step-4-select-conversion-events}

추적할 전환 이벤트를 최대 4개까지 정의할 수 있습니다. 이 전환 이벤트는 자동화된 IP 워밍 계획이 실행된 후에는 업데이트할 수 없습니다.

- 세션 시작
- 주문 완료
- 커스텀 이벤트 수행
- 앱 업그레이드
- 이메일 열람
- 이메일 클릭

다음으로 전환 마감 기한을 선택합니다. 이는 사용자가 Campaign에 진입한 시점과 전환 이벤트 사이에 경과할 수 있는 최대 시간입니다.

![전환 이벤트 선택과 전환 마감 기한을 보여주는 전환 설정.]({% image_buster /assets/img/automated_ip_warming_conversions.png %})

### 5단계: 검토 및 실행 {#step-5-review-and-launch}

IP 워밍 계획의 세부 정보를 검토합니다. 그런 다음 **실행**을 선택합니다.

## 다중 IP 워밍 {#multiple-ip-warming}

두 개 이상의 발신 주소 또는 IP 풀을 워밍해야 할 때 다중 자동 IP 워밍 계획을 사용하세요.

| 시나리오 | 권장 사항 |
| --- | --- |
| 하나의 IP 풀에 여러 전용 IP가 있는 경우 | 하나의 계획을 만들고 해당 풀의 발신 주소를 선택합니다 |
| 여러 IP 풀 또는 발신 주소가 있는 경우 | 각 발신 주소마다 별도의 계획을 만듭니다 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="다중 IP 워밍 시나리오" }

### 하나의 풀에서 여러 IP 워밍하기 {#warm-multiple-ips-in-one-pool}

[1단계: 스케줄 설정](#step-1-set-a-schedule)에서 발신 주소를 선택하면 Braze가 연결된 IP 풀과 풀 내 IP 주소를 표시합니다. Braze는 IP 수를 기반으로 발송량 증가 스케줄을 구성하고 목표 발송량을 제안합니다.

**현재 일일 발송량**이 0인 경우, 첫 번째 예약일은 풀 내 IP당 최대 50건의 발송으로 시작하며 총 500건으로 제한됩니다. Braze는 풀 내 IP당 최대 200만 건의 **목표 발송량**을 제안합니다.

### 여러 IP 풀 워밍하기 {#warm-multiple-ip-pools}

두 개 이상의 발신 주소 또는 IP 풀을 워밍하려면:

1. **설정** > **이메일 환경설정** > **자동 IP 워밍**으로 이동합니다.
2. **새 IP 워밍 계획**을 선택합니다.
3. 고유한 **계획 이름**을 입력합니다.
4. 해당 발신 주소에 대한 설정을 완료합니다.
5. 워밍이 필요한 추가 발신 주소 또는 IP 풀에 대해 위 과정을 반복합니다.

**자동 IP 워밍** 테이블에서 각 계획을 추적할 수 있습니다. 각 계획에는 자체 스케줄, Segments, 템플릿, Campaigns, 추적기가 있습니다. 계획은 **초안**, **진행 중**, **완료** 또는 **중단** 상태일 수 있습니다.

{% alert important %}
자동 IP 워밍 계획이 활성 상태인 동안 동일한 발신 주소 또는 IP 풀에서 대량의 비워밍 Campaigns를 발송하지 마세요. 워밍 중 추가 발송은 전달 가능성 신호에 영향을 미치고 문제를 분리하기 어렵게 만들 수 있습니다.
{% endalert %}

## 활성 IP 워밍 기간 중 {#during-active-ip-warming}

IP 워밍 Campaign은 유효 시간대 기준 당일 및 다음 날 자정에 생성됩니다(발송 0~1일 전). 플랜을 실행하면 예정된 Campaign도 즉시 생성됩니다. 이러한 Campaign에는 다음 형식으로 자동 이름이 지정됩니다: `IP Warming Day [X] - [Date] - [Template Name]`

목표 일일 발송량에 도달하면, 발송자 평판을 보호하기 위해 해당 일의 발송이 중단됩니다.

Braze는 12~20시간 전에 발송된 Campaign의 전달 가능성을 평가합니다. 다음 임계값 중 하나라도 초과되면, Braze는 발송량을 늘리는 대신 다음 발송일의 발송량을 유지합니다:

- 전달률 90% 미만
- 열람율 10% 미만
- 반송률 5% 초과
- 스팸 신고율 0.04% 초과

발송량이 유지될 때 어떤 일이 발생하는지 알아보려면 [발송량이 유지되면 어떻게 되나요?]({{site.baseurl}}/user_guide/channels/email/email_setup/ip_warming/faq#what-happens-when-volume-is-held)를 참조하세요.

## 오디언스 규모와 사용자당 다중 발송 {#audience-size-and-multiple-sends-per-user}

각 날의 발송 목표를 달성하기 위해 Braze는 선택한 이메일 템플릿을 순환합니다. 플랜 내에서 Braze는 이미 특정 템플릿을 수신한 사용자를 제외하지만, 다른 템플릿을 수신한 사용자는 여전히 대상에 포함됩니다. 해당 날의 스케줄에 사용 가능한 오디언스가 소진되면, 플랜은 템플릿을 다시 순환하므로 일부 사용자는 같은 날에 두 번째 템플릿을 수신할 수 있습니다.

선택한 Segments 전체에서 이메일 발송 가능한 사용자의 총 수가 **목표 발송량**보다 적은 경우, 일일 발송량이 최대치에 달하는 플랜의 마지막 날 또는 마지막 며칠 동안 이 결과는 불가피합니다. 예를 들어, Segments에 이메일 발송 가능한 사용자가 400,000명이고 목표 발송량이 600,000인 경우, 마지막 날에 약 200,000명의 사용자가 두 개의 템플릿을 수신하고 나머지 200,000명의 사용자는 하나를 수신합니다.

오디언스가 목표 발송량보다 큰 경우에도 사용자는 서로 다른 날에 다른 템플릿을 수신할 수 있습니다. Braze는 각 날의 오디언스를 템플릿에 분배할 때 사용자가 이전에 어떤 템플릿을 수신했는지 고려하지 않으므로, 하나의 템플릿을 수신한 사용자가 플랜의 이후 시점에 다른 템플릿에 선택될 수 있습니다.

Braze는 목표 발송량이 사용 가능한 오디언스보다 클 때 플랜 실행을 차단하지 않습니다. 각 사용자가 발송일당 하나의 템플릿만 수신하도록 하려면, 실행 전에 다음 중 하나를 수행하세요.

- Segments를 추가하여 이메일 발송 가능한 사용자의 총 수가 목표 발송량 이상이 되도록 합니다.
- **목표 발송량**을 이메일 발송 가능한 사용자의 총 수 이하로 줄입니다.

## IP 워밍 계획 중지 {#stop-an-ip-warmup-plan}

IP 워밍 계획을 중지하면 이후 Campaign 생성을 방지할 수 있습니다. 계획을 중지하면 연결된 모든 Campaign도 비활성화됩니다. 계획을 중지한 후에는 다시 재개할 수 없습니다. 중단한 지점부터 이어서 진행하려면 새 계획을 설정하세요:

- 중지된 계획의 기존 데이터를 다운로드하여 기록으로 보관합니다
- **현재 일일 발송량**을 가장 최근 발송량으로 업데이트합니다
- 이전 IP 워밍에서 사용한 동일한 Segment를 사용할 계획이라면, 이전 Campaign을 이미 수신한 사용자를 제외하는 필터를 Segment에 추가합니다

## IP 워밍 완료 시점 {#when-an-ip-warming-completes}

IP 워밍은 워크스페이스 시간대(또는 워크스페이스에 별도 설정이 없는 경우 회사 시간대)의 자정에 IP 워밍 마지막 날이 종료되면 완료로 표시됩니다. 예를 들어, 플랜의 마지막 Campaign이 오후 8시에 발송되면 4시간 후 자정에 플랜이 완료로 표시됩니다.

완료된 플랜은 **설정** > **이메일 환경설정** > **자동 IP 워밍**에서 계속 확인할 수 있습니다. 또한 트래커는 플랜 종료 후 90일 동안 홈 대시보드에 유지됩니다. 90일이 지나면 홈 대시보드 트래커가 제거됩니다.

데이터를 다운로드하면 다음과 같은 표준 이메일 측정기준이 포함됩니다:

- *발송 수*
- *전달 수*
- *반송 수*
- *스팸 신고*
- *총 열람 수*
- *고유 열람*
- *클릭 수*
- *수신 거부*

하루에 발송량 요건을 충족하기 위해 여러 Campaign이 사용된 경우, 일별 보기에서 이 데이터가 집계됩니다.
