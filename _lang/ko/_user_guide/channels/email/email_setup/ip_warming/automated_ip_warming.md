# 자동화된 IP 워밍 {#automated-ip-warming}

> 자동화된 IP 워밍을 사용하여 새로운 전용 IP에서 이메일 발송량을 점진적으로 늘려 받은편지함 제공자와의 발송자 평판을 구축하세요.

## 작동 방식 {#how-it-works}

자동 IP 워밍을 사용하면 일일 발송량을 점진적으로 늘릴 수 있어, 받은편지함 공급자가 발송 패턴을 학습하고 신뢰할 수 있게 됩니다. 워크스페이스에 도메인을 추가할 때, 홈 대시보드의 **Pick up where you left off** 섹션에서 **Automated IP Warming** 타일을 선택할 수 있습니다. 이 타일은 워크스페이스가 신규 발신자 온보딩 기간에 있는 동안 60일간 표시됩니다.

각 자동 IP 워밍 플랜은 하나의 발신 주소에 연결됩니다. 해당 발신 주소는 발송 서브도메인과 IP 풀에 매핑됩니다. 풀에 여러 전용 IP가 포함된 경우, Braze는 하나의 플랜에서 이를 함께 워밍합니다.

Braze는 가장 참여도가 높은 구독자에게 먼저 발송하여, 모범 사례에 맞는 속도로 일일 발송량을 늘립니다. 그런 다음 Braze는 인게이지먼트 및 전달 가능성 신호를 추적합니다. Braze가 문제를 감지하면 시스템이 자동으로 스케줄을 조정합니다.

하나 이상의 플랜을 완료한 후에는 **Settings** > **Email Preferences** > **Automated IP warming**에서 완료된 플랜을 확인할 수 있습니다.

{% alert note %}
대시보드에 단일 플랜 환경만 표시되는 경우, 워크스페이스에서 아직 다중 IP 워밍 플랜에 접근할 수 없을 수 있습니다. 이용 가능 여부는 Braze 계정 팀에 문의하세요.
{% endalert %}

## 전제 조건 {#prerequisites}

자동 IP 워밍을 수행하려면 다음이 필요합니다:

- 인증된 하위 도메인 및 활성 IP 주소
- IP 워밍업을 조회하고 시작할 수 있는 권한
    - IP 워밍 섹션을 조회하기 위한 "View Usage Data"
    - IP 워밍용 이메일 템플릿을 조회하고 선택하기 위한 "View Email Templates"
    - IP 워밍업을 시작하기 위한 "Manage Email Settings"
- "Access Campaigns"
- Campaigns에 대한 승인 워크플로가 켜져 있는 경우 "Approve and Deny Campaigns"
    - Braze는 자동 IP 워밍에서 생성된 Campaigns를 자동으로 승인합니다.

{% alert important %}
이 기능은 이메일 인프라에 따라 지원되지 않을 수 있습니다.
{% endalert %}

## 자동 IP 워밍 플랜 설정하기 {#set-up-an-automated-ip-warming-plan}

### 1단계: 스케줄 설정 {#step-1-set-a-schedule}

1. 워크스페이스에서 여러 IP 워밍 플랜을 지원하는 경우, 고유한 **플랜 이름**을 입력합니다. 플랜 이름에는 문자, 숫자, 하이픈, 밑줄만 사용할 수 있으며, 워크스페이스 내에서 고유해야 합니다. 플랜을 시작하려면 플랜 이름이 필요합니다.
2. **발송 정보** 섹션에서 IP 주소를 워밍할 **발신 주소**를 선택합니다. Braze는 해당 발신 주소에 연결된 **IP 풀**과 풀 내 **IP 주소 수**를 표시합니다.
3. **현재 일일 발송량**과 **목표 발송량**을 입력합니다. Braze는 선택한 풀의 IP당 최대 200만 건의 발송량을 목표로 권장합니다. 현재 일일 발송량이 0인 경우, 스케줄 첫날은 IP당 최대 50건으로 시작하며 총 500건으로 제한됩니다.
4. 자동 IP 워밍의 시작 날짜를 선택합니다. 이 날짜는 플랜이 시작된 후 최소 하루 이후여야 합니다.
5. 발송 시간을 입력합니다. 메시지는 회사의 시간대에 맞춰 발송됩니다.
6. **다음: Segments**를 선택하여 설정을 계속합니다.

![스케줄 세부 정보 예시.]({% image_buster /assets/img/automated_ip_warming_schedule.png %})

### 2단계: Segment 선택 및 순위 지정 {#step-2-select-and-rank-segments}

1. 다음으로, 타겟팅할 Segment를 선택합니다. IP 워밍 중에 Braze는 인게이지먼트가 가장 높은 사용자부터 발송을 시작하고, 시간이 지남에 따라 발송량을 점진적으로 늘리면서 인게이지먼트가 낮은 Segment를 서서히 추가합니다.
2. 그런 다음, Segment를 드래그 앤 드롭하여 인게이지먼트가 높은 순서에서 낮은 순서로 순위를 지정합니다. 높은 인게이지먼트에는 이메일을 꾸준히 열람하고 클릭하는 수신자가 포함됩니다. 낮은 인게이지먼트에는 이메일 인게이지먼트가 일관되지 않거나 오랫동안 이메일에 참여하지 않은 수신자가 포함됩니다.
3. **다음: 메시지**를 선택하여 설정을 계속합니다.

![자동 IP 워밍을 위해 타겟팅할 두 개의 Segment가 선택된 화면.]({% image_buster /assets/img/automated_ip_warming_segment.png %})

### 3단계: 발송할 메시지 선택 {#step-3-select-the-messages-to-send}

1. **이메일 템플릿 선택**을 선택합니다.
2. 발송할 메시지의 이메일 템플릿을 선택합니다. IP 워밍 중에 발송하는 콘텐츠는 열람과 클릭을 유도하는 것이어야 합니다. 과거에 좋은 반응을 얻었던 콘텐츠를 선택하는 것을 권장합니다. 예를 들어, 프로모션 혜택을 활용하여 즉각적인 참여와 구매를 유도할 수 있습니다.
3. **템플릿 선택**을 선택합니다. Braze는 시작하기 전에 필요한 템플릿 수를 계산합니다. 시스템이 전달 가능성 문제에 대응하면서도 중단 없이 조정할 수 있도록 최소 필요 수보다 더 많은 템플릿을 제공하는 것을 권장합니다.
4. 필요한 수의 템플릿을 추가한 후, **다음: 요약**을 선택합니다.

{% alert important %}
IP 워밍 도구에서 생성된 Campaigns에 대한 변경 사항(예: 예약 날짜, Segment, 발송량 변경)은 IP 워밍 **요약** 페이지에 반영되지 않습니다.
{% endalert %}

### 4단계: 전환 이벤트 선택 {#step-4-select-conversion-events}

추적할 전환 이벤트를 최대 4개까지 정의할 수 있습니다. 이러한 전환 이벤트는 자동 IP 워밍 플랜이 시작된 후에는 업데이트할 수 없습니다.

- 세션 시작
- 주문 완료
- 커스텀 이벤트 수행
- 앱 업그레이드
- 이메일 열람
- 이메일 클릭

다음으로, 전환 기한을 선택합니다. 전환 기한은 사용자가 Campaign에 진입한 시점과 전환 이벤트 사이에 경과할 수 있는 최대 시간입니다.

![전환 이벤트 선택 및 전환 기한이 표시된 전환 설정 화면.]({% image_buster /assets/img/automated_ip_warming_conversions.png %})

### 5단계: 검토 및 시작 {#step-5-review-and-launch}

IP 워밍 플랜의 세부 정보를 검토합니다. 그런 다음, **시작**을 선택합니다.

## 다중 IP 워밍 {#multiple-ip-warming}

여러 발신 주소 또는 IP 풀을 워밍해야 할 때 다중 자동 IP 워밍 플랜을 사용하세요.

| 시나리오 | 권장 사항 |
| --- | --- |
| 하나의 IP 풀에 여러 전용 IP가 있는 경우 | 하나의 플랜을 생성하고 해당 풀의 발신 주소를 선택합니다 |
| 여러 IP 풀 또는 발신 주소가 있는 경우 | 각 발신 주소별로 별도의 플랜을 생성합니다 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="다중 IP 워밍 시나리오" }

### 하나의 풀에서 여러 IP 워밍하기 {#warm-multiple-ips-in-one-pool}

[1단계: 스케줄 설정](#step-1-set-a-schedule)에서 발신 주소를 선택하면, Braze가 연결된 IP 풀과 풀 내 IP 주소를 표시합니다. Braze는 IP 수를 기반으로 램프 스케줄을 구성하고 목표 발송량을 제안합니다.

**현재 일일 발송량**이 0인 경우, 첫 번째 예약일은 풀 내 IP당 최대 50건의 발송으로 시작하며, 총 500건으로 제한됩니다. Braze는 풀 내 IP당 최대 200만 건의 **목표 발송량**을 제안합니다.

### 여러 IP 풀 워밍하기 {#warm-multiple-ip-pools}

둘 이상의 발신 주소 또는 IP 풀을 워밍하려면:

1. **설정** > **이메일 환경설정** > **자동 IP 워밍**으로 이동합니다.
2. **새 IP 워밍 플랜**을 선택합니다.
3. 고유한 **플랜 이름**을 입력합니다.
4. 해당 발신 주소에 대한 설정을 완료합니다.
5. 워밍이 필요한 각 추가 발신 주소 또는 IP 풀에 대해 반복합니다.

**자동 IP 워밍** 테이블에서 각 플랜을 추적할 수 있습니다. 각 플랜에는 고유한 스케줄, Segments, 템플릿, Campaigns 및 트래커가 있습니다. 플랜은 **초안**, **진행 중**, **완료** 또는 **중지됨** 상태일 수 있습니다.

{% alert important %}
자동 IP 워밍 플랜이 활성화된 동안에는 동일한 발신 주소 또는 IP 풀에서 대규모 비워밍 Campaigns를 발송하지 마세요. 워밍 중 추가 발송은 전달 가능성 신호에 영향을 미칠 수 있으며, 문제를 분리하기 어렵게 만들 수 있습니다.
{% endalert %}

## 활성 IP 워밍 중 {#during-active-ip-warming}

IP 워밍 Campaign은 1~2일 전에 미리 생성됩니다. 단, 다음 날 바로 IP 워밍을 시작하는 경우는 예외입니다. 이러한 Campaign은 다음 형식으로 자동 명명됩니다: `IP Warming Day [X] - [Date] - [Template Name]`

목표 일일 발송량에 도달하면, 시스템은 발송자 평판을 보호하기 위해 해당 일의 발송을 중단합니다.

시스템은 다음 업계 벤치마크를 기준으로 상태를 모니터링합니다:

- 전달율이 90% 이하로 하락
- 열람율이 10% 미만
- 반송률이 5% 초과
- 스팸 신고율이 0.04% 초과

통계가 벤치마크 기준에 미달하는 경우, 시스템은 발송자 평판에 대한 리스크를 완화하기 위해 발송량을 늘리지 않고 다음 날 발송량을 유지합니다.

## IP 워밍 플랜 중지 {#stop-an-ip-warmup-plan}

Braze에서는 IP 워밍과 향후 Campaign 생성을 중지할 수 있지만, Campaign이 이미 활성 상태이거나 향후 24~48시간 내에 스케줄되어 있는 경우에는 해당 Campaign을 수동으로 중지해야 할 수 있습니다. IP 워밍 플랜을 중지하면 관련된 모든 Campaign도 함께 중지됩니다.

단, 중지된 IP 워밍은 다시 재개할 수 없습니다. 대신 중단한 지점부터 이어서 진행할 수 있도록 새 플랜을 설정해야 합니다. 방법은 다음과 같습니다.

- 중지된 플랜의 기존 데이터를 다운로드하여 기록으로 보관합니다.
- **현재 일일 발송량**을 가장 최근 발송량으로 업데이트합니다.
- 이전 IP 워밍에서 사용한 것과 동일한 Segment를 사용할 계획이라면, 이전 Campaign을 이미 수신한 사용자를 제외하는 필터를 Segment에 추가합니다.

## IP 워밍이 완료되는 시점 {#when-an-ip-warmup-completes}

IP 워밍은 IP 워밍의 마지막 날이 회사 시간대 기준 자정에 종료되면 완료로 표시됩니다. 예를 들어, IP 워밍 계획에서 마지막으로 발송된 Campaign이 오후 8시에 발송되면, 4시간 후에 계획이 완료로 표시됩니다.

완료된 계획은 **설정** > **이메일 환경설정** > **자동 IP 워밍**에서 계속 확인할 수 있습니다. 워크스페이스에서 단일 계획 환경을 사용하는 경우, 계획이 종료된 후 90일 동안 홈 대시보드에 트래커가 유지됩니다. 90일이 지나면 홈 대시보드 트래커가 제거됩니다.

데이터를 다운로드하면 다음과 같은 표준 이메일 측정기준이 포함됩니다:

- *발송*
- *전달*
- *반송*
- *스팸 신고*
- *총 열람*
- *고유 열람*
- *클릭*
- *탈퇴*

하루에 발송량 요건을 충족하기 위해 여러 Campaign이 사용된 경우, 일별 보기에서 이들이 합산되어 표시됩니다.
