# 동의 및 주소 수집 {#consent-and-address-collection}

> 첫 이메일을 발송하기 전에 먼저 고객의 허락을 받는 것이 중요합니다. 이는 기본적인 예의이며 열람율에도 큰 도움이 됩니다!

## 구독자 상태 {#subscriber-states}

사용자의 이메일 구독 상태는 **옵트인함**, **가입됨**, **탈퇴됨** 세 가지가 있습니다. 사용자의 구독 상태를 변경하려면 [구독 변경]({{site.baseurl}}/user_guide/channels/email/subscriptions#changing-email-subscriptions) 문서를 확인하거나 [구독 API]({{site.baseurl}}/api/endpoints/subscription_groups/post_update_user_subscription_group_status)를 사용하세요.

| 구독자 상태 | 설명 |
|---|---|
| 옵트인함 | 이러한 고객은 확인 이메일의 링크를 클릭하고 메시지 수신에 적극적으로 동의한 것입니다. |
| 가입됨 | 기본적으로 사용자는 프로필에 유효한 이메일 주소가 저장되어 있는 한 이메일을 구독하게 됩니다. 사용자는 탈퇴하거나 옵트인할 때까지 구독 상태를 유지합니다. |
| 탈퇴됨 | 수신 거부로 표시되려면 고객이 명시적으로 이메일 수신을 거부했거나 이메일을 스팸으로 표시한 경우입니다. |

## 주소 수집 방법 {#address-collection-methods}

메시지를 보내기 전에 사용자의 허락을 받는 것 외에도, 이메일 주소를 수집하는 여러 방법이 있으며 이는 전달 가능성에 영향을 미칠 수 있습니다.

### 구매한 주소 목록 {#purchased-address-lists}

구매하거나 대여한 목록으로 이메일을 발송하는 것은 Braze 계약 위반입니다! 이메일을 구매하면 완전히 원치 않는 메시지를 보내는 것이며, 전달 가능성 문제에 노출될 위험이 있습니다.

### 공동 등록 {#co-registration}

공동 등록은 사용자 정보를 수집하기 위한 회사 간의 계약을 의미합니다. 이는 위험한 수집 방법입니다. 때로는 고객이 알지 못하거나 허락하지 않은 상태에서 제3자로부터 이메일을 수신하도록 사용자를 옵트인시킵니다. 이 방법을 사용하려면 수집 시점에서 명확한 고지 사항과 탈퇴할 수 있는 기능을 반드시 제공해야 합니다.

### 사전 선택 또는 강제 옵트인 {#pre-selected-or-forced-opt-in}

사전 선택 옵트인은 이메일 가입 체크박스가 이미 선택된 상태로 표시되는 이메일 등록 방법입니다. 체크박스를 선택된 상태로 두면 가입자는 옵트인하여 이메일 수신에 동의하게 됩니다. 이 방법은 사람들을 짜증나게 하는 경향이 있습니다(캐나다로 발송되거나 캐나다 내에서 발송되는 메일의 경우 불법이기도 합니다). 상당한 규모의 이메일 목록을 확보할 수 있지만, 이 사용자들이 실제로 마케팅 이메일을 원하는지 확신할 수 없습니다.

### 단일 옵트인 {#single-opt-in}

단일 옵트인은 가입자가 구독 양식을 통해 가입하면 즉시 이메일 목록에 추가되는 방식입니다. 이 방법에서는 사용자가 수집 필드에 이메일 주소를 입력하거나 트랜잭션의 일부로 체크박스를 선택하는 등 한 단계만 거치면 구독됩니다.

### 확인된 옵트인 {#confirmed-opt-in}

확인된 옵트인은 사용자가 이메일 커뮤니케이션을 요청하는 체크박스를 선택하면 확인 메시지가 발송되는 방식입니다. 이 방법을 통해 사용자는 콘텐츠의 유형과 빈도를 선택할 수 있어 인게이지먼트가 향상됩니다.

가장 참여도가 높은 사용자만 타겟팅하고 있는지 확인하려면 이중 확인 옵트인 방법을 사용할 수도 있습니다. 이 방식은 사용자가 확인 이메일의 버튼이나 링크를 클릭해야 이메일 목록에 추가되는 추가 단계가 포함됩니다.
