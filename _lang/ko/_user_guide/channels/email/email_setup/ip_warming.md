# IP 워밍 {#ip-warming}

> IP 워밍은 이메일 받은편지함 제공자가 전용 IP 주소에서 메시징을 수신하는 데 익숙해지도록 하는 관행입니다. 이것은 모든 이메일 서비스 공급자(ESP)와 함께 이메일을 보내는 데 있어 매우 중요한 부분이며, Braze에서 메시지가 대상 받은편지함에 일관되게 높은 비율로 도달하는지 확인하는 표준 관행입니다. [자동화된 IP 워밍]({{site.baseurl}}/user_guide/channels/email/email_setup/ip_warming/automated_ip_warming)을 사용하는 경우, [자동화된 IP 워밍 FAQ]({{site.baseurl}}/user_guide/channels/email/email_setup/ip_warming/faq)를 참조하세요.

IP 워밍은 인터넷 서비스 공급자(ISP)와 긍정적인 평판을 쌓는 데 도움을 주기 위해 설계되었습니다. 새로운 IP 주소가 이메일을 보내는 데 사용될 때마다 ISP는 해당 이메일이 사용자에게 스팸을 보내는 데 사용되지 않는지 프로그래밍 방식으로 모니터링합니다. IP와 도메인 평판을 신용 점수처럼 생각해 보세요. ISP는 이 평판을 사용하여 메일이 받은편지함에 도착할지 스팸 폴더에 도착할지를 결정합니다. 신용 점수와 마찬가지로 긍정적인 평판을 쌓는 데는 시간이 걸리며, 나빠진 평판을 다시 쌓는 데는 더 오랜 시간이 걸립니다.

## 이메일 전달 및 전달 가능성 {#email-delivery-and-deliverability}

**전달(Delivery)**은 수락되었으며 하드 바운스가 발생하지 않은 이메일의 비율입니다. **전달 가능성(Deliverability)**은 메일이 스팸이 아닌 받은편지함에 도달하는지를 의미하며, 받은편지함 제공자는 이를 단일 측정기준으로 제공하지 않습니다.

건강한 전달률은 일반적으로 약 99%의 전달률과 약 1% 이하의 반송률입니다. 수치상으로는 양호해 보이더라도 문제가 숨어 있을 수 있습니다(예: 특정 도메인에서 다수의 바운스가 발생하거나, 메일이 전달되었지만 스팸으로 필터링되는 경우). 전달률뿐만 아니라 열람 및 클릭도 함께 모니터링하세요. 보고된 스팸 신고율이 낮더라도 심층 검토가 필요할 수 있습니다.

### IP 워밍 전 권장 사항 {#recommendations-before-ip-warming}

IP 워밍을 시작하기 전에 다음을 수행하세요:

1. **Settings** > **Email Preferences**에서 기본 발송 도메인을 설정하고, [커스텀 푸터]({{site.baseurl}}/user_guide/channels/email/customize/custom_email_footer)에 유효한 수신 거부 링크를 추가하고, [list-unsubscribe 헤더]({{site.baseurl}}/user_guide/administer/global/workspace_settings/email_preferences#list-unsubscribe)를 활성화하며, 필요한 경우 커스텀 수신 거부/옵트인 페이지를 구성하세요.
2. 이메일에 대한 [최대 게재빈도 설정]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/frequency_capping)을 구성하세요.
3. **Content** > **Email**로 이동하여 필요한 템플릿을 생성하세요.

## IP 워밍 시간이 없으면 어떻게 하나요? {#what-if-i-dont-have-time-to-warm-ips}

**IP 워밍은 필수입니다.** IP를 적절히 워밍하지 않고 이메일 패턴이 의심을 유발하면, 이메일 전달 속도가 크게 제한되거나 느려질 수 있습니다. 또한 ISP에 의해 도메인이나 IP가 차단될 수 있으며, 이 경우 이메일이 사용자의 받은편지함 대신 스팸 폴더로 직접 전달될 수 있습니다. 따라서 IP를 올바르게 워밍하는 것이 중요합니다.

ISP는 스팸 의심이 발생하면 사용자를 보호하기 위해 이메일 전달을 제한합니다. 예를 들어, 100,000명의 사용자에게 발송하는 경우 ISP는 첫 한 시간 동안 그중 5,000명에게만 이메일을 전달할 수 있습니다. 그런 다음 ISP는 열람율, 클릭률, 탈퇴, 스팸 신고 등의 인게이지먼트 지표를 모니터링합니다. 상당수의 스팸 신고가 발생하면, 나머지 발송분을 사용자의 받은편지함에 전달하는 대신 스팸 폴더로 분류할 수 있습니다.

인게이지먼트가 보통 수준이면, ISP는 해당 이메일이 스팸인지 여부를 더 확실히 판단하기 위해 추가 인게이지먼트 데이터를 수집하면서 이메일 전달을 계속 제한할 수 있습니다. 이메일의 인게이지먼트 측정기준이 매우 높으면, 해당 이메일에 대한 제한을 완전히 해제할 수 있습니다. ISP는 이 데이터를 사용하여 이메일이 자동으로 스팸으로 필터링되는지 여부를 결정하는 이메일 평판을 구축합니다.

ISP에 의해 도메인이나 IP가 차단된 경우, [메시지 활동 로그]({{site.baseurl}}/user_guide/administer/global/workspace_settings/logs_and_alerts/message_activity_log)의 메시지 로그에 해당 ISP에 이의를 제기하고 차단 목록에서 해제받기 위해 방문해야 할 웹사이트에 대한 정보가 포함되어 있습니다.

## IP 워밍 스케줄 {#ip-warming-schedules}

전달 가능성을 높이기 위해 IP 워밍 스케줄을 엄격히 준수할 것을 강력히 권장합니다. 또한 일관된 확장이 전달 측정기준을 개선하므로 날짜를 건너뛰지 않는 것이 중요합니다. 기존 이메일 발송 이력과 전달 가능성 측정기준을 기반으로 스케줄을 선택하세요.

{% endalert %}

대부분의 경우 최대 발송량이 아닌 평균 일일 발송량까지 워밍하세요. ISP는 주로 이전 몇 주간의 발송 행동을 기반으로 평판을 평가하므로, 몇 달에 한 번만 최대 발송량에 도달하는 경우(예: 시즌 기간 중 700만 건), 발송일에 가까워질 때 해당 최대 발송량을 향해 점진적으로 늘릴 수 있습니다. 그러나 1~2주마다 최대 발송량에 도달하는 경우에는 처음부터 해당 최대 발송량까지 워밍하세요.

IP 워밍이 완료되고 원하는 일일 발송량에 도달한 후에는 매일 해당 발송량을 유지하는 것을 목표로 해야 합니다. 약간의 변동은 예상되지만, 원하는 발송량에 도달한 후 일주일에 한 번만 대량 발송을 하면 전달 측정기준과 발송자 평판에 부정적인 영향을 미칠 수 있습니다.

{% alert important %}
대부분의 ISP는 평판 데이터를 30일 동안만 저장합니다. 한 달 동안 메시지를 발송하지 않으면 IP 워밍 프로세스를 다시 수행해야 합니다.
{% endalert %}

### IP 주소 {#ip-addresses}

3개월 동안 사용하지 않으면 Braze는 IP 주소를 회수하여 재할당할 수 있습니다. IP 주소의 이전 이력에 관계없이, 대부분의 ISP가 평판 데이터를 30일 동안만 저장하므로 새로 할당된 모든 IP에 대해 전체 IP 워밍을 수행하는 것이 권장됩니다. 대부분의 ISP에서 이는 3개월의 비활성 기간이 사실상 평판을 초기화한다는 것을 의미합니다. 특정 IP 주소의 이력에 대해 추가 질문이 있으시면 [Braze 지원팀]({{site.baseurl}}/user_guide/administer/personal/braze_support)에 문의하세요.

## 워밍 중 발송량 제한 방법 {#how-to-limit-sends-during-warming}

내장된 사용자 제한 기능은 IP 주소 워밍에 유용한 도구입니다. Campaign 생성 시 원하는 메시징 Segments를 선택한 후, [타겟 사용자]({{site.baseurl}}/user_guide/channels/email/html_editor#step-4-build-the-remainder-of-your-campaign-or-canvas) 단계에서 **Advanced Options** 드롭다운을 선택하여 사용자를 제한할 수 있습니다. 워밍 스케줄이 진행됨에 따라 이 제한을 점진적으로 높여 발송하는 이메일 양을 늘릴 수 있습니다.

## 서브도메인 세분화 {#subdomain-segmentation}

많은 ISP와 이메일 액세스 공급자는 더 이상 IP 주소 평판만으로 필터링하지 않습니다. 이러한 필터링 기술은 이제 도메인 기반 평판도 고려합니다. 즉, 필터는 발신자의 도메인과 관련된 모든 데이터를 살펴보며 IP 주소만을 단독으로 평가하지 않습니다. 이러한 이유로, 이메일 IP 워밍 외에도 마케팅, 트랜잭션, 기업 메일에 대해 별도의 도메인 또는 서브도메인을 사용하는 것을 권장합니다.

{% alert important %}
서브도메인 세분화는 대량 발송자에게 특히 중요합니다. 대량 발송자는 계정을 설정할 때 Braze 담당자와 협력하여 이 관행을 준수하고 있는지 확인해야 합니다.
{% endalert %}

도메인을 세분화하여 기업 메일은 최상위 도메인을 통해 발송하고, 마케팅 및 트랜잭션 메일은 서로 다른 도메인 또는 서브도메인을 통해 발송하는 것을 권장합니다.

## 모범 사례 {#best-practices}

다음 모범 사례를 따르면 IP 워밍을 수행하지 않았을 때 발생하는 모든 부정적인 결과를 방지할 수 있습니다:

### 소량의 이메일 발송부터 시작하기 {#start-with-small-sending-volumes-of-email}

매일 발송하는 양을 가능한 한 점진적으로 늘리세요. 갑작스럽고 대량의 이메일 캠페인은 ISP로부터 가장 많은 의심을 받습니다. 따라서 소량의 이메일 발송부터 시작하여 최종적으로 발송하려는 이메일 양까지 점진적으로 확대해야 합니다. 각 ISP에서 개별적으로 IP를 워밍하고 있다는 점을 기억하세요. ISP는 서로 평판 데이터를 공유하지 않습니다. 워밍 발송량을 설정할 때, 특정 ISP에서 발송량을 너무 빠르게 늘리지 않도록 주의하세요. 발송량에 관계없이 안전을 위해 IP 워밍을 수행하는 것을 권장합니다. [IP 워밍 스케줄](#ip-warming-schedules)을 참조하세요.

### 매력적인 초기 콘텐츠 준비하기 {#have-engaging-introductory-content}

첫 번째 콘텐츠가 높은 참여도를 유도하고 사용자가 이메일을 클릭, 열람, 참여할 가능성을 극대화하는지 확인하세요. IP 워밍 시에는 무차별적인 대량 발송보다 항상 잘 타겟팅된 이메일을 선호하세요.

### 일관된 발송 주기 설정하기 {#set-a-consistent-sending-cadence}

IP 워밍이 완료되면 발송 주기를 설정하고, 이메일을 하루 또는 며칠에 걸쳐 분산 발송하세요. 가능한 한 일관된 스케줄을 유지하면 IP 쿨다운을 방지할 수 있습니다. IP 쿨다운은 발송량이 며칠 이상 중단되거나 크게 감소할 때 발생할 수 있습니다.

특정 시간에 대량 발송하는 대신, [IP 워밍 스케줄](#ip-warming-schedules)을 참조하여 더 긴 기간에 걸쳐 발송을 분산하세요.

### 이메일 목록 정리하기 {#clean-your-email-lists}

이메일 목록이 깨끗하고 오래되었거나 인증되지 않은 이메일이 포함되어 있지 않은지 확인하세요. [CASL 및 CAN-SPAM 규정을 준수]({{site.baseurl}}/user_guide/administer/global/privacy/spam_regulations)하는 것이 이상적입니다.

### 발송자 평판 모니터링하기 {#monitor-your-sender-reputation}

IP 워밍 과정을 진행할 때, 발송자 평판을 주의 깊게 모니터링하세요. 다음 측정기준을 특히 주시해야 합니다:
- **반송률:** Campaign의 반송률이 3~5%를 초과하는 경우, [Keep It Clean: The Importance of Email List Hygiene](https://www.braze.com/blog/email-list-hygiene/) 문서의 가이드라인에 따라 목록의 청결도를 평가해야 합니다. 또한 참여하지 않거나 휴면 상태인 이메일 주소로의 발송을 중단하기 위해 [일몰 정책]({{site.baseurl}}/user_guide/channels/email/best_practices/sunset_policies)을 구현하는 것을 고려하세요.
- **스팸 신고:** Campaign의 스팸 신고율이 0.08%를 초과하는 경우, 발송하는 콘텐츠를 재평가하고, 관심 있는 오디언스를 대상으로 하는지 확인하며, 이메일이 수신자의 관심을 끌 수 있도록 적절하게 작성되었는지 확인하세요.
- **열람율:** 열람율은 받은편지함 배치의 유용한 지표입니다. 고유 열람율이 25%를 초과하면 높은 받은편지함 배치율을 경험하고 있을 가능성이 높으며, 이는 긍정적인 발송자 평판을 나타냅니다.

{% alert tip %}
Braze는 IP 워밍에 [Intelligent Timing]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_timing)을 사용하지 않는 것을 권장합니다. IP 워밍 캠페인은 처음 발송하는 캠페인 중 하나이므로, Braze가 사용자에 대한 충분한 정보를 확보하지 못해 최적의 발송 시간을 계산할 수 없습니다. 이 경우 Intelligent Timing이 적용된 모든 메시지는 대체 시간으로 기본 설정되어 결국 같은 시간에 발송됩니다.
{% endalert %}

{% alert tip %}
IP 워밍 중에는 도메인과 IP가 아직 긍정적인 평판을 확립하지 못했기 때문에 메일이 스팸 폴더로 전달되는 것은 정상적인 현상입니다. 메일이 스팸 폴더에 도착하는 경우, 메일 관리자가 Braze 발송 도메인과 IP를 회사의 허용 목록에 추가해야 할 수 있습니다.
{% endalert %}
