# 브랜드 가이드라인 {#brand-guidelines}

> 맞춤형 브랜드 가이드라인을 사용하여 인공지능이 생성한 카피의 스타일을 브랜드의 목소리, 어조, 개성에 맞게 조정하세요.

**콘텐츠** > **브랜드 가이드라인**에서 브랜드 가이드라인을 만들고 관리할 수 있습니다.

## 브랜드 가이드라인 만들기 {#creating-brand-guidelines}

### 1단계: 브랜드 가이드라인 생성하기 {#step-1-create-a-brand-guideline}

**브랜드 가이드라인** 페이지에서 **새로 만들기**를 선택합니다. 이 브랜드 가이드라인을 워크스페이스의 기본값으로 설정하려면 **기본 브랜드 가이드라인으로 사용**을 선택하세요. 워크스페이스당 기본값은 하나만 설정할 수 있습니다.

### 2단계: 브랜드 개성 설명하기 {#step-2-describe-your-brand-personality}

**브랜드 개성**에서 브랜드를 고유하게 만드는 요소에 대해 생각해 보세요. 브랜드를 정의하는 특성, 가치, 목소리, 아키타입 등을 포함하세요. 이 필드는 10,000자 이하로 유지합니다. LLM으로 이 텍스트를 생성하는 경우, 출력이 필드에 맞도록 프롬프트에 해당 글자 수 제한을 포함하세요.

고려할 만한 특성은 다음과 같습니다:

| 특성       | 정의                                                                       | 예시                                                       |
|--------------------------|--------------------------------------------------------------------------------------|--------------------------------------------------------------------|
| 평판               | 시장에서 브랜드가 어떻게 인식되기를 원하는지.                               | 우리는 업계에서 가장 신뢰할 수 있고 고객 중심적인 브랜드로 알려져 있습니다. |
| 성격적 특성       | 브랜드의 성격을 설명하는 인간적인 특성.                     | 우리 브랜드는 친근하고, 접근하기 쉬우며, 항상 밝습니다.          |
| 가치                   | 브랜드의 행동과 결정을 이끄는 핵심 가치.                           | 우리는 지속 가능성, 투명성, 커뮤니티를 중시합니다.            |
| 차별화          | 경쟁사와 구별되는 고유한 특성.                         | 우리는 한 발 더 나아가는 개인화된 고객 서비스를 제공하여 차별화합니다. |
| 브랜드 보이스              | 브랜드가 사용하는 커뮤니케이션의 톤과 스타일.                                 | 우리의 목소리는 캐주얼하면서도 유익하며, 지나치게 격식을 차리지 않으면서 명확성을 보장합니다. |
| 브랜드 아키타입          | 브랜드의 페르소나를 대표하는 아키타입(영웅, 창조자 등).    | 우리는 항상 새로운 도전과 모험을 추구하는 "탐험가" 아키타입을 구현합니다. |
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3 aria-label="2단계: 브랜드 개성 설명하기" }

### 3단계: 피해야 할 표현 정의하기 (선택 사항) {#step-3-define-language-that-should-be-avoided-optional}

**제외 사항**에서 브랜드에 맞지 않는 표현이나 스타일을 나열합니다. 예를 들어 "비꼼", "부정적인 태도", "거만한" 톤을 피하고 싶을 수 있습니다. 이 필드는 300자 이하로 유지합니다.

![이름, 설명, 개성, 제외 사항 및 톤을 입력할 수 있는 필드가 있는 '브랜드 가이드라인 만들기' 창.]({% image_buster /assets/img/guidelines_create.png %})

### 4단계: 가이드라인 테스트하기 {#step-4-test-your-guidelines}

가이드라인이 어떻게 작동하는지 테스트합니다. **가이드라인 테스트하기**를 펼쳐 예시 카피를 생성하고 필요에 따라 조정하세요.

### 5단계: 가이드라인 저장하기 {#step-5-save-your-guidelines}

가이드라인이 만족스러우면 **브랜드 가이드라인 저장**을 선택합니다. 가이드라인은 나중에 사용할 수 있도록 워크스페이스에 저장됩니다.

{% alert important %}
카피가 어떤 언어로 작성되어 있는지에 관계없이 출력 언어를 변경할 수 있지만, Braze와 OpenAI 모두 번역 품질을 보장하지 않습니다. 번역을 사용하기 전에 항상 테스트하고 확인하세요.
{% endalert %}

## 브랜드 가이드라인 관리 {#managing-brand-guidelines}

**Brand Guidelines** 페이지에서 브랜드 가이드라인을 선택하여 편집할 수 있습니다. 브랜드 가이드라인을 보관하면 비활성 상태가 되어 메시지 작성기에서 사용할 수 없게 됩니다. 다시 활성 상태로 만들어 선택할 수 있게 하려면, 보관된 브랜드 가이드라인을 필터링한 후 보관을 해제하면 됩니다.

## 브랜드 가이드라인 사용하기 {#using-brand-guidelines}

Operator 채팅 패널에서 <i class="fa-regular fa-plus"></i>&nbsp;**Operator에 대한 컨텍스트 추가**를 선택한 다음, **Brand guidelines** 아래에서 하나 이상의 가이드라인을 선택합니다. Operator는 선택한 가이드라인을 생성된 카피, 템플릿, 이미지에 적용합니다. 기본값으로는 아무것도 선택되어 있지 않습니다.

![Operator 채팅 패널에서 브랜드 가이드라인 선택하기.]({% image_buster /assets/img/operator/operator_brand_guidelines.png %})

에이전트를 구성할 때, [컨텍스트 추가]({{site.baseurl}}/user_guide/brazeai/agents/creating_agents#add-resources)에서 브랜드 가이드라인을 선택하면 에이전트가 해당 보이스와 스타일을 따릅니다. Agent Console은 워크스페이스 기본값을 자동으로 선택합니다.
