# 이해관계자와 메시지 미리보기 공유하기 {#share-a-message-preview-with-stakeholders}

> 공유 가능한 미리보기를 사용하면 메시지 또는 콘텐츠의 미리보기 링크를 생성하여 Braze 대시보드에 액세스할 수 없는 이해관계자, 법무팀, 컴플라이언스팀 등 검토자와 공유할 수 있습니다. 수신자는 Braze에 로그인하지 않고도 브라우저에서 미리보기를 확인할 수 있습니다.

## 지원되는 채널 {#supported-channels}

다음 채널 및 콘텐츠 유형에 대해 공유 가능한 미리보기 링크를 생성할 수 있습니다.

- 배너
- Content Blocks
- Content Cards
- 이메일 및 이메일 푸터
- 랜딩 페이지
- LINE
- 푸시 알림
- 구독 페이지
- 단문 메시지 서비스 및 RCS
- WhatsApp

{% alert note %}
공유 가능한 미리보기는 점진적으로 출시되고 있으며, 워크스페이스의 모든 채널에서 아직 사용할 수 없을 수 있습니다. 이 섹션에 나열된 채널에 대한 옵션이 보이지 않으면 Braze 계정 매니저에게 문의하세요.
{% endalert %}

## 공유 가능한 미리보기 작동 방식 {#how-shareable-preview-works}

다음 동작은 지원되는 모든 채널에서 동일합니다.

### 링크 생성하기 {#generating-a-link}

메시지 또는 콘텐츠를 작성하는 동안 **미리보기 링크 복사**를 선택하여 공유 가능한 링크를 생성합니다. Braze가 자동으로 링크를 클립보드에 복사합니다.

- 링크는 생성 시점의 메시지를 정적인 읽기 전용 스냅샷으로 엽니다. 편집을 계속해도 자동으로 업데이트되지 않습니다. 최신 변경 사항을 반영하려면 새 링크를 생성하세요.
- 메시지에 테스트 사용자, 커스텀 고객 프로필 또는 랜덤 사용자를 기반으로 확인되는 Liquid 또는 연결된 콘텐츠와 같은 개인화가 포함된 경우, 미리보기는 **미리보기 및 테스트**에서 보이는 것과 동일한 개인화를 반영합니다.
- **링크 재생성**을 선택하면 새로운 만료일이 적용된 새 스냅샷이 생성됩니다. 이전 링크는 무효화되지 않습니다. 두 링크 모두 각각의 만료일까지 독립적으로 작동합니다.

### 링크 보기 {#viewing-the-link}

링크가 있는 사람은 누구나 미리보기를 볼 수 있습니다. Braze 로그인이나 대시보드 권한은 필요하지 않습니다.

{% alert important %}
링크를 다른 공유 문서와 동일하게 취급하세요. 액세스 권한을 부여하려는 사람에게만 전송하고, 공개된 곳에 게시하지 마세요.
{% endalert %}

### 링크 만료 {#link-expiration}

- 모든 공유 가능한 미리보기 링크는 생성 후 7일이 지나면 만료됩니다.
- 링크가 만료되면 더 이상 열리지 않습니다. 작성기에서 새 링크를 생성하여 새로운 링크를 받으세요.
- 만료 전에 링크를 수동으로 취소하거나 비활성화할 수 있는 방법은 없습니다. 링크를 재생성해도 이전 링크는 취소되지 않으며, 각 링크는 자체 7일 일정에 따라 만료됩니다.

## 채널별 차이점 {#per-channel-nuances}

핵심 경험은 모든 곳에서 동일하지만, 일부 채널에는 알아두면 좋은 작은 차이점이 있습니다.

{% alert note %}
공유 가능한 미리보기는 인앱 메시지에는 사용할 수 없습니다.
{% endalert %}

| 채널 | 차이점 |
|---|---|
| 이메일 | 미리보기에는 메시지 본문 외에 수신자, 발신자, 제목란 필드가 포함됩니다. <br><br>커스텀 사용자로 개인화하는 경우, API 트리거 속성정보 또는 이벤트 속성정보로 입력한 값은 **미리보기 및 테스트**에서 올바르게 표시되더라도 미리보기에 나타나지 않을 수 있습니다. 커스텀 속성, 테스트 사용자, 랜덤 사용자는 영향을 받지 않습니다. |
| 배너 (드래그 앤 드롭 편집기) | 미리보기는 가장 최근 편집이 아닌, 작성기에서 마지막으로 **미리보기** 탭을 열었을 때의 콘텐츠를 반영합니다. <br><br>링크를 생성하거나 재생성하기 전에 **미리보기**를 다시 열어 최신 상태인지 확인하세요. |
| 단문 메시지 서비스 및 RCS | 둘 다 동일한 공유 가능한 미리보기 기능으로 관리되지만, 각각 독립적인 링크를 생성합니다. |
| WhatsApp | 공유 가능한 미리보기는 WhatsApp 템플릿 메시지와 WhatsApp 응답 메시지 모두에 대해 별도로 사용할 수 있습니다. |
| Content Blocks, 이메일 푸터, 구독 페이지 | 특정 Campaign 또는 Canvas에서 사용되는 것과 관계없이 독립적인 콘텐츠의 미리보기를 생성합니다. |
| 랜딩 페이지 | 랜딩 페이지의 미리보기는 다른 채널과 다르게 동작합니다. 자세한 내용은 [페이지 미리보기]({{site.baseurl}}/user_guide/messaging/landing_pages/create_landing_pages#step-5-preview-the-page)를 참조하세요. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="채널별 차이점" }

## 자주 묻는 질문 {#frequently-asked-questions}

{% details 수신자가 미리보기를 보려면 Braze 계정이 필요한가요? %}
아니요. 링크가 있는 사람은 누구나 로그인 없이 브라우저에서 미리보기를 볼 수 있습니다.
{% enddetails %}

{% details 메시지를 계속 편집하면 미리보기가 업데이트되나요? %}
아니요. 공유 가능한 미리보기 링크는 생성 시점의 스냅샷입니다. **링크 재생성**을 선택하여 최신 변경 사항을 반영하고 새 링크를 받으세요.
{% enddetails %}

{% details 링크는 얼마나 오래 활성 상태를 유지하나요? %}
생성 시점으로부터 7일입니다. 링크를 재생성하면 새 링크는 이전 링크와 별도로 자체 7일 만료 기간을 갖습니다.
{% enddetails %}

{% details 링크를 조기에 취소할 수 있나요? %}
아니요, 링크를 취소할 수 없습니다. 링크를 재생성해도 이전 링크는 무효화되지 않습니다. 모든 링크는 7일 후 만료될 때까지 작동합니다.
{% enddetails %}
