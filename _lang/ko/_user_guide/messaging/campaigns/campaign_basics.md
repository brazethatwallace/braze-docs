# 캠페인 기본 사항 {#campaigns-basics}

> 이 참조 문서에서는 첫 번째 캠페인을 설정할 때 스스로에게 물어봐야 할 다양한 질문을 다루며 캠페인의 기본 사항을 설명합니다.

## 캠페인 구조 이해하기 {#understanding-campaign-structure}

캠페인 설정의 세부 사항을 살펴보기 전에, 다양한 메시징 채널에서 캠페인이 어떻게 작동하는지 이해하기 위한 핵심 사항을 알아보겠습니다.

캠페인은 채널(일반적으로 메시징 채널이라고 함)을 통해 사용자에게 연결하는 단일 메시지 단계입니다. 이러한 메시징 채널에는 Content Cards, 이메일, 인앱 메시지, 푸시, SMS 및 MMS, 웹훅이 포함됩니다. 고객이 어디에 있는지 파악하면 적절한 메시징 채널을 활용하여 소통할 수 있습니다.

## 고객 여정 구축하기 {#building-the-customer-journey}

캠페인은 메시징 채널에 따라 고유하게 구축할 수 있으므로, 다음 5가지 W 시각화를 활용하여 고객 참여 전략과 목표를 파악하고 구체화할 수 있습니다.

### "무엇을": 캠페인 이름 짓기 {#the-what-name-your-campaign}

*사용자가 무엇을 하거나 이해하도록 도우려고 하나요?*

이름의 힘을 과소평가하지 마세요. Braze는 협업을 위해 만들어졌으므로, 팀과 목표를 어떻게 소통할지 정리하기에 좋은 시점입니다. 고객 여정에 대해 더 알아보려면 [사용자 라이프사이클 매핑](https://learning.braze.com/mapping-customer-lifecycles) Braze 학습 과정을 확인하세요!

### "언제": 시작 조건 만들기 {#the-when-create-starting-conditions}

*고객이 이 캠페인을 언제 접하게 되나요?*

사용자가 캠페인에 진입하는 방법은 세 가지입니다: 설정된 날짜와 시간에(스케줄), 특정 동작을 수행할 때(동작 기반), 또는 API 호출을 트리거하는 행동을 할 때(API 트리거)입니다.

스케줄 전달은 캠페인을 특정 시간에 발송하도록 조정하며, 선택적으로 지정된 주기로 발송할 수 있습니다. 동작 기반 캠페인은 특정 고객 행동이 실시간으로 발생할 때 반응합니다. 여기에는 구매하거나 다른 캠페인과 상호작용하는 것이 포함될 수 있습니다. API 트리거 캠페인은 플랫폼에서 주요 고객 동작을 정의하여, 해당 동작이 달성되면 Braze에 API 호출을 트리거하고 캠페인을 발송하도록 설정할 수 있습니다.

### "누구에게": 진입 오디언스 선택하기 {#the-who-select-an-entry-audience}

*누구에게 도달하려고 하나요?*

사전 정의된 [Segments]({{site.baseurl}}/user_guide/audience/segments/)를 사용하여 인구통계학적, 행동적 또는 기술적 특성과 동작을 기반으로 사용자를 타겟팅할 수 있습니다. 캠페인을 구축할 때 필터를 추가하여 Segment를 더 세밀하게 조정하세요. 이러한 타겟 오디언스 기준에 부합하는 사용자만 여정에 진입할 수 있습니다. 사용 가능한 필터 유형에 대한 간략한 요약은 아래 표를 확인하세요.

| 필터 | 설명 |
|---|---|
| 커스텀 데이터 | 정의한 이벤트와 속성을 기반으로 사용자를 세그먼트합니다. 제품에 특화된 기능을 사용할 수 있습니다. |
| 사용자 활동 | 동작과 구매를 기반으로 고객을 세그먼트합니다. |
| 리타겟팅 | 이전 캠페인을 발송받았거나, 수신했거나, 상호작용한 고객을 세그먼트합니다. |
| 마케팅 활동 | 마지막 참여 또는 수신한 캠페인과 같은 범용 행동을 기반으로 고객을 세그먼트합니다. |
| 사용자 속성 | 고정적인 속성과 특성을 기반으로 고객을 세그먼트합니다. |
| 설치 경로 | 최초 소스, 광고 그룹, 캠페인 또는 광고를 기반으로 고객을 세그먼트합니다. |

### "왜": 전환 이벤트 식별하기 {#the-why-identify-conversion-events}

*이 캠페인을 왜 구축하나요?*

명확한 목표를 염두에 두는 것은 항상 중요하며, 캠페인은 세션 참여, 구매, 커스텀 이벤트와 같은 KPI에 대한 성과를 파악하는 데 도움이 됩니다. 하나 이상의 [전환 이벤트]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/conversion_events/)를 선택하면 캠페인 성과를 이해할 수 있습니다.

### "어디서": 오디언스 찾기 {#the-where-find-my-audience}

*오디언스에게 가장 효과적으로 도달할 수 있는 곳은 어디인가요?*

여기서 사용자 여정에 가장 적합한 메시징 채널을 결정합니다. 이상적으로는 사용자가 가장 활발하게 활동하는 곳에서 도달하는 것이 좋습니다.

### "어떻게": 경험 구축하기 {#the-how-build-the-experience}

*5가지 W를 파악한 후 캠페인을 어떻게 구축하나요?*

캠페인 구축에 익숙해지면 배리언트와 A/B 테스트 설정을 고려해 보세요. 캠페인은 대조군과 함께 최대 8개의 배리언트를 지원합니다. 캠페인 분석을 활용하여 세그먼트된 오디언스부터 실제 메시지 콘텐츠까지 다양한 요소를 조정하면서 정보에 기반한 결정을 내리세요.
