# 시작 후 캠페인 편집 {#edit-your-campaign-after-launch}

> 이 문서에서는 캠페인 시작 후 특정 측면을 편집했을 때의 결과에 대한 개요를 제공합니다.

## 캠페인 중지 {#stopping-your-campaign}

캠페인을 중지하려면 **캠페인 세부 정보** 페이지를 열고 **캠페인 중지**를 선택합니다. 캠페인이 중지되면:

- 발송 예정이었던 메시지가 취소됩니다.
- 초기 테스트가 이미 발송된 A/B 테스트는 영구적으로 취소됩니다.
- 이미 발송된 메시지에 대한 이벤트(예: 오픈 클릭)는 계속 추적됩니다.

캠페인을 다시 시작하려면 **재개**를 선택합니다. 캠페인은 메시지와 A/B 테스트 발송을 계속하지만, 누락된 메시지는 다시 발송되거나 다시 스케줄되지 않습니다.

### 발송 중 캠페인 중지 {#stopping-your-campaign-during-sending}

오디언스 규모가 크고 사용량 제한이 있는 캠페인의 경우, Braze는 메시지 배치를 분할하여 서로 다른 시간에 발송하도록 스케줄합니다. 캠페인이 중지되면 발송이 즉시 취소되지 않습니다. 대신, 실행이 시작되어 캠페인이 중지되었음을 감지할 때 취소됩니다.

예를 들어, 사용량 제한이 적용된 이메일 캠페인을 시작하고 몇 시간 동안 일시 중지한 후 다시 재개하면, 일시 중지된 시간 동안 발송 예정이었던 모든 메시지는 취소되어 발송되지 않습니다. 캠페인이 재개된 후 스케줄된 나머지 메시지는 계속 발송됩니다. 캠페인에 재자격이 활성화되어 있는 경우, 캠페인이 중지되기 전에 이미 대기줄에 있던 메시지 외에도 사용자가 다시 캠페인을 수신할 자격을 얻을 수 있습니다.

## 트리거된 캠페인 {#triggered-campaigns}

실행 기반 전달 캠페인 및 API 트리거 전달 캠페인에 대한 모든 변경 사항은 이후 발송에 즉시 적용됩니다.

이러한 캠페인이 트리거되었지만 아직 발송되지 않은 경우(예: 1일 지연이 설정된 실행 기반 전달 캠페인이 1일 지연 기간 중에 편집된 경우), 스케줄된 캠페인에 대한 다음 안내를 참조하세요.

### 스케줄된 캠페인 {#scheduled-campaigns}

시작 후 캠페인을 변경해야 하는 경우, 변경 사항이 원하는 효과를 가져오는지 확인하기 위해 캠페인을 편집할 때 다음 항목을 참고하세요.

### 메시지 콘텐츠 {#message-content}

메시지 콘텐츠 변경 사항(제목, 본문, 이미지 포함)은 저장 즉시 이후 모든 메시지 발송에 적용됩니다. 이미 발송된 메시지의 콘텐츠는 변경할 수 없습니다.

### 스케줄 및 오디언스 {#scheduling-and-audience}

캠페인의 예정된 발송 시간이나 오디언스를 편집하면 해당 변경 사항이 실제 캠페인에 즉시 반영됩니다.

#### 고려 사항 {#considerations}

캠페인이 Intelligent Timing 또는 현지 시간대 전달을 사용하는 경우, 원래 발송 시간으로부터 24시간 이내에 편집하면 예정된 발송 시간 변경이 반영되지 않습니다. 그 이유는 다음과 같습니다:

- **Intelligent Timing:** Braze는 사모아 시간 자정에 최적의 발송 시간 계산을 시작합니다. 이 시간이 이미 지났다면 메시지 처리가 시작된 것입니다. 자세한 내용은 [Intelligent Timing]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_timing/)을 참조하세요.
- **현지 시간대 전달:** 24시간 이내로 스케줄된 현지 시간대 캠페인을 편집해도 메시지의 스케줄은 변경되지 않습니다. 자세한 내용은 [현지 시간대 캠페인은 어떻게 스케줄하나요?]({{site.baseurl}}/user_guide/messaging/campaigns/faq/#how-do-i-schedule-a-local-time-zone-campaign)를 참조하세요.

### 발송 속도 {#send-rate}

발송 사용량 제한을 사용하는 경우, Braze는 분 단위 시간 슬롯으로 메시지를 "스케줄"합니다. 따라서 메시지 발송 속도를 변경하려면 즉시 변경을 위해 다음 프로세스를 따르세요.

#### 전달 속도 사용량 제한이 적용된 캠페인 일시 중지 {#pausing-campaigns-with-delivery-speed-rate-limiting}

[전달 속도 사용량 제한]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/frequency_capping/#delivery-speed-rate-limiting)을 사용하는 캠페인을 일시 중지하면, Braze는 분 단위 슬롯에 걸쳐 발송을 분배합니다. **재개**를 선택해도 캠페인이 일시 중지된 동안 취소된 슬롯의 메시지는 다시 발송되지 않으며, 캠페인이 재개되었을 때 모든 메시지가 반드시 발송되는 것은 아닙니다.

캠페인이 일시 중지되어 일부 사용자가 메시지를 수신하지 못한 경우, **재개**에 의존하여 누락된 메시지를 전달하는 대신 캠페인을 복제하고 해당 사용자만 타겟으로 지정하세요.

## 즉시 변경하기 {#making-immediate-changes}

변경 사항을 즉시 적용해야 하는 경우 다음을 수행하세요:

1. 해당 캠페인을 중지합니다.
2. 캠페인을 복제합니다.
3. 복제된 캠페인에서 편집합니다.

{% alert important %}
이렇게 하면 원래 캠페인을 이미 수신한 사용자의 자격이 초기화되므로, 원래 캠페인을 수신하지 않은 사용자를 대상으로 복제된 캠페인을 필터링해야 할 수 있습니다.
{% endalert %}

## 활성 캠페인의 임시저장본 저장 {#campaign-drafts}

임시저장본은 활성 캠페인에 대규모 변경을 할 때 유용합니다. 임시저장본을 생성하면 다음 시작 전에 계획된 변경 사항을 미리 검토할 수 있습니다.

{% alert note %}
캠페인에는 한 번에 하나의 임시저장본만 있을 수 있습니다. 또한 임시저장된 변경 사항이 아직 시작되지 않았으므로 분석을 사용할 수 없습니다.
{% endalert %}

임시저장본을 생성하려면 다음을 수행하세요:

1. 활성 캠페인으로 이동합니다.
2. 변경 사항을 적용합니다.
3. **임시저장**을 선택합니다. 임시저장본을 생성한 후에는 임시저장본을 시작하거나 삭제할 때까지 활성 캠페인을 편집할 수 없습니다.

![활성 캠페인을 볼 수 있는 옵션이 있는 활성 캠페인의 임시저장본.]({% image_buster /assets/img/campaign_draft.png %})

임시저장본을 편집하는 동안 캠페인 임시저장본의 헤더 또는 캠페인 분석의 푸터에서 활성 캠페인을 참조할 수도 있습니다.

활성 캠페인으로 돌아가려면 분석 보기 또는 활성 캠페인 보기에서 **임시저장본 편집**을 선택합니다.

### 인앱 메시지 우선순위 지정 {#in-app-message-prioritization}

인앱 메시지 우선순위는 **상세 우선순위 지정**을 선택하고 다른 Campaign(캠페인) 또는 Canvases와의 관계에서 우선순위를 지정하면 임시저장본이 시작되기 전에 즉시 업데이트됩니다.
