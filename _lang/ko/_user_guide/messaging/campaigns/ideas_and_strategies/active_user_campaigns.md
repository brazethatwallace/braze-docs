# 활성 사용자 캠페인 {#active-user-campaigns}

> 활성 사용자를 파악하여 맞춤형 캠페인을 만들고 플랫폼을 자주 이용하는 사용자에게 보상을 제공하세요.

이미 활성 상태인 앱 사용자에게 다가가는 것은 꾸준한 앱 사용자층을 구축하는 데 강력한 도구가 될 수 있습니다. 핵심 사용자에게 약간의 개인화된 인정을 보여주면 그들을 앱의 열렬한 지지자로 만들 수 있습니다.

이메일 마케팅 전략과 추천 생애주기 캠페인에 대한 [Braze 학습 과정](https://learning.braze.com/quick-overview-segment-and-campaign-setup)도 확인해 보세요!

## 활성 사용자 이해하기 {#understanding-active-users}

Braze는 특정 기간의 "활성 사용자"를 해당 기간 동안 세션이 있는 모든 사용자로 정의합니다.

사용자의 연결이 끊기면 세션 데이터를 로컬에 캐시하고 네트워크 연결이 복구되면 업로드합니다. 이러한 세션도 활성 사용자 수에 반영됩니다. 또한 앱에 등록 프로세스가 있는 경우, Braze는 등록 여부에 관계없이 모든 사용자를 활성 사용자로 집계합니다.

사용자 ID를 설정하여 새 사용자가 로그인할 때 사용자를 식별하면 별도의 활성 사용자로 집계됩니다. API를 통해 업데이트된 사용자도 업데이트된 기간의 활성 사용자로 집계됩니다.

## 1단계: 상위 사용자 파악하기 {#step-1-identifying-your-top-users}

다양한 필터를 사용하여 가장 충성도 높고 꾸준한 사용자 기반을 포함하는 사용자 Segment를 만드세요. 다음 샘플 Segment는 상위 사용자를 정의합니다.

![상위 사용자 오디언스를 정의하는 Braze Segment 필터 샘플.]({% image_buster /assets/img_archive/define_top_users.png %} "Define your top users")

또한 이 Segment를 계속 업데이트할 필요가 없습니다. 캠페인 조건에 해당하거나 벗어나는 사용자는 자동으로 타겟팅되거나 제외됩니다.

{% alert note %}
위의 예시는 일반적인 앱 사용량을 기준으로 사용자를 세그먼트합니다. 대부분의 경우 상위 사용자 Segment를 정의하는 데 필요한 전체 필터 모음은 앱의 특성에 따라 크게 달라집니다.
{% endalert %}

## 2단계: 상위 사용자에게 연락하기 {#step-2-contact-your-top-users}

### 사용자에게 감사함을 전달하기 {#make-your-users-feel-appreciated}

앱에 대한 충성도와 헌신에 감사를 표하여 사용자가 소중하게 느끼도록 하세요. 사용자에게 앱을 계속 방문할 더 많은 이유를 제공하여 추가 활동을 장려하세요. 이는 상위 사용자만을 위한 특별 혜택이나 보너스 형태가 될 수 있습니다.

예상치 못한 보상은 처음부터 약속한 것보다 지속적인 사용자 행동을 유도하는 데 더 효과적일 수 있습니다!

![작성 단계의 캠페인으로, "다시 한번 저희와 함께 쇼핑해 주셔서 감사합니다! 감사의 마음을 담아 다음 구매 시 무료 배송을 드립니다"라는 iOS 리치 알림이 표시됩니다.]({% image_buster /assets/img/congratulations_push.jpg %})

### 결과 추적하기 {#keep-track-of-your-results}

열람 수를 추적하여 적절한 사용자 그룹에 최적의 메시지 유형으로 타겟팅하고 있는지 확인하세요. 또한 푸시 수신 거부를 추적하고 이러한 중요한 사용자를 잃지 않도록 주의하세요.
