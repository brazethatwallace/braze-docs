# 전환 이벤트 {#conversion-events}

> 전환 이벤트는 메시지 수신자가 인게이지먼트를 받은 후 정해진 시간 내에 높은 가치의 행동을 수행하는지 추적하는 성공 측정기준의 한 유형입니다. 이러한 이벤트를 사용하여 관련성 있고 유용한 정보를 수집하고, 나중에 Campaign(캠페인)이나 Canvas에 대한 인사이트를 얻는 데 활용할 수 있습니다.

## 작동 방식 {#how-it-works}

활성 사용자를 타겟팅하는 개인화된 휴일 Campaign의 경우, 2~3일 이내의 **세션 시작** 전환 이벤트가 적절할 수 있습니다. 이를 통해 메시지 수신에 따른 사용자 인게이지먼트를 파악할 수 있기 때문입니다. **주문하기**, **앱 업그레이드** 또는 커스텀 이벤트 중 하나를 전환 이벤트로 선택할 수도 있습니다.

### 전환 추적은 언제 시작되나요? {#when-does-conversion-tracking-begin}

{% tabs %}
{% tab Campaign %}

전환 추적은 사용자가 Campaign을 수신하거나 Campaign의 대조군에 배정될 때 시작됩니다. 메시지 수신과 배리언트 배정은 보통 동시에 이루어집니다. 인앱 메시지 Campaign의 경우, Braze가 노출을 기록할 때 전환 추적이 시작됩니다.

{% endtab %}
{% tab Canvas %}

전환 추적은 사용자가 Canvas에 진입할 때 시작됩니다. 캔버스 단계의 경우, 사용자가 해당 단계에서 활성 상태인 동안 전환이 귀속됩니다. 사용자가 다음 단계로 진행하면 이전 단계의 전환 추적이 중지되고 다음 단계의 전환 추적이 시작됩니다.

사용자가 지연 단계 또는 기타 비메시지 단계에 있는 동안 발생한 전환은 다른 메시지 단계를 수신할 때까지 마지막으로 수신한 메시지 단계에 귀속됩니다. 사용자가 경로의 마지막 메시지 단계를 수신한 후에도, 추가 메시지 단계가 없더라도 전환 기한(Canvas 진입 시점부터 계산)까지 전환이 기록될 수 있습니다.

{% endtab %}
{% endtabs %}

{% alert tip %}
전환에 대해 더 알아보려면 Campaign 설정에 관한 [Braze 학습 과정](https://learning.braze.com/campaign-setup-delivery-targeting-conversions)을 확인하세요.
{% endalert %}

### 전환 추적 규칙 {#conversion-tracking-rules}

전환 이벤트는 사용자 행동을 인게이지먼트 시점에 귀속시킵니다. 일반적으로 전환 기간이 열려 있는 동안, 사용자는 해당 Campaign 또는 Canvas의 전환 이벤트당 최대 한 번 전환됩니다. 기한 전에 동일한 전환 행동을 두 번 이상 수행하더라도(예: 두 번 구매) Braze는 해당 이벤트에 대해 한 번의 전환만 집계합니다. 멀티채널 Campaign은 각 메시징 채널별로 별도의 전환 기회를 기록할 수 있으며, 이로 인해 전환 수를 고유 수신자와 비교할 때 전환율이 100%를 초과할 수 있습니다(아래 항목에서 설명).

Braze가 다중 전환을 처리하는 방식에 대해 다음 사항을 참고하세요.

- **단일 채널 Campaign:** 전환은 기기 단위가 아닌 사용자 단위로 발생합니다. 단일 채널 내에서 사용자는 메시지가 여러 기기로 전송되더라도 전환 이벤트당 한 번만 전환됩니다. 예를 들어, Campaign에 "구매 완료"로 설정된 전환 이벤트가 하나 있고 사용자가 전환 기한 내에 두 번의 별도 구매를 한 경우, Braze는 한 번의 전환만 집계합니다. 그러나 [재자격]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/re_eligibility)이 활성화된 경우, Campaign을 여러 번 수신한 사용자는 각 발송마다 다시 전환할 수 있습니다. 재자격이 있는 Campaign에서 전환 메커니즘은 Campaign 발송당 사용자당 한 번이며, 사용자가 동일한 Campaign을 여러 번 수신하고 전환할 때 더 높은 전환 수가 발생할 수 있습니다.
- **멀티채널 Campaign:** 멀티채널 Campaign의 경우, 각 채널에 고유한 전환 기회가 있습니다. 사용자는 해당 채널에서 메시지를 수신한 후 채널당 한 번 전환할 수 있습니다. 즉, 사용자가 여러 채널(예: 이메일과 푸시 모두)에서 메시지를 수신하고 전환 행동을 수행하면, Braze는 각 채널에 대해 한 번의 전환을 집계하므로 전환율이 100%를 초과할 수 있습니다.
- **Canvas 메시지 단계:** Braze는 전환 기한 내에 발생한 전환을 사용자가 마지막으로 수신한 Canvas 메시지 단계에 귀속시킵니다. 다음 메시지 단계를 수신하면 귀속이 해당 단계로 이동합니다. Braze는 각 메시지 개별이 아닌 사용자가 Canvas에 진입한 시점부터 해당 기간을 측정합니다. 메시지 단계 사이의 지연 중에 발생한 전환은 사용자가 진행할 때까지 이전 메시지 단계의 귀속으로 집계되며, 마지막 메시지 단계 이후의 전환도 Canvas 전환 기한까지 집계됩니다.
- **과거 이벤트 보존:** Campaign 및 Canvas 대시보드의 전환 추적은 현재 고객 프로필이 아닌 과거 행동을 측정합니다. 사용자가 지정된 기간 내에 전환 규칙을 충족하면, Braze는 분석에 한 번의 전환을 기록하며, 이후 해당 사용자의 프로필이 일상적인 데이터 정리 또는 GDPR 준수 과정에서 삭제, 병합 또는 보관되더라도 이를 제거하지 않습니다. 실시간 Segment 수는 동적 Segments가 데이터베이스에 현재 존재하는 활성 프로필만 필터링하기 때문에 영구 대시보드 이벤트 로그보다 자연스럽게 낮을 수 있습니다.
- 사용자가 수신한 두 개의 별도 Campaign 또는 Canvases의 전환 기한 내에 하나의 전환 이벤트를 수행하면, 전환은 양쪽 모두에 등록됩니다.
- 사용자가 메시지를 열람하거나 클릭하지 않았더라도, 기간 내에 특정 전환 이벤트를 수행했다면 전환된 것으로 집계됩니다.

### 주요 전환 이벤트 {#primary-conversion-event}

주요 전환 이벤트는 Campaign 또는 Canvas 생성 시 추가하는 첫 번째 이벤트입니다. 이 이벤트는 인게이지먼트와 리포팅에 가장 큰 영향을 미칩니다. Braze는 주요 전환 이벤트를 다음과 같이 사용합니다.

- [다변량]({{site.baseurl}}/user_guide/messaging/ab_testing/optimizations#winning-variant) Campaign 또는 Canvases에서 우승 메시지 배리언트를 계산합니다.
- Campaign 또는 Canvas의 매출이 계산되는 기간을 결정합니다.
- [지능형 선택]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_selection)을 사용하는 Campaign 및 Canvases의 메시지 배분을 조정합니다.

주요 전환 이벤트 수는 발생한 전환 이벤트의 횟수입니다. 멀티채널 Campaign의 경우, Braze는 채널별로 전환을 집계하므로([전환 추적 규칙](#conversion-tracking-rules)에서 설명) 전환 수가 고유 사용자 수를 초과하여 전환율이 100%를 넘을 수 있습니다. Braze는 이 수를 고유 수신자 수로 나누어 주요 전환 이벤트 비율을 계산합니다. Braze는 채널에 따라 메시지가 전송되거나 표시될 때 사용자를 수신자로 간주합니다. 예를 들어, 푸시 또는 이메일의 경우 Braze가 메시지를 전송한 후 사용자가 수신자가 됩니다. 인앱 메시지 또는 Content Cards의 경우, 사용자가 메시지를 조회해야 수신자로 간주됩니다.

{% alert note %}
Liquid `abort` 태그를 사용하여 메시지를 중단하면, Braze는 배리언트를 거치는 사용자에 대해서만 메시지를 중단합니다. 대조군의 사용자에게 보내는 메시지는 중단되지 않으므로, 배리언트와 대조군 간에 전환 비율이 왜곡될 수 있습니다. 해결 방법으로, [세분화]({{site.baseurl}}/user_guide/audience/segments/creating_a_segment)를 사용하여 Campaign 및 Canvas 진입 시 사용자를 타겟팅하세요.
{% endalert %}

## 전환 추적이 포함된 Campaign 만들기 {#creating-a-campaign-with-conversion-tracking}

### 1단계: Campaign 설정하기 {#step-1-set-up-your-campaign}

원하는 메시징 채널에 맞게 [Campaign을 생성]({{site.baseurl}}/user_guide/messaging/campaigns/creating_campaign)합니다. Campaign의 메시지와 스케줄을 설정한 후, 추적을 위해 최대 4개의 전환 이벤트를 추가할 수 있습니다.

필요한 만큼 전환 이벤트를 사용하세요. 두 번째 또는 세 번째 전환 이벤트를 추가하면 리포팅이 크게 풍부해집니다. 예를 들어, 휴면 사용자를 타겟팅하는 Campaign의 경우, 주요 **세션 시작** 전환 이벤트와 함께 보조 전환 이벤트를 추가하면 Campaign이 사용자를 앱으로 다시 유도하는 데 얼마나 효과적인지 파악하는 데 도움이 됩니다.

### 2단계: 전환 이벤트 추가하기 {#step-2-add-the-conversion-events}

먼저, 사용하려는 이벤트의 일반 유형을 선택합니다.

| 전환 이벤트 유형 | 설명 |
|-------------------------|----------------------------|
| **세션 시작** | 사용자가 지정한 앱 중 하나를 열면 전환한 것으로 집계됩니다(기본값은 워크스페이스의 모든 앱). |
| **구매** | 사용자가 [구매 이벤트]({{site.baseurl}}/api/objects_filters/purchase_object)를 기록하면 전환한 것으로 집계됩니다. 기본적으로 모든 구매를 추적하며, 특정 제품을 지정할 수도 있습니다. |
| **주문 완료** | 사용자가 [주문 완료 이커머스 권장 이벤트]({{site.baseurl}}/user_guide/data/activation/events/recommended_events/ecommerce_events#ecommerce-recommended-events?tab=ecommerce.order_placed)를 트리거하면 전환한 것으로 집계됩니다. 기본적으로 모든 주문을 추적하며, 특정 제품으로 필터링할 수도 있습니다.<br><br>"주문 완료" 이벤트는 현재 얼리 액세스 중입니다. 이 얼리 액세스에 참여하고 싶으시면 Braze 계정 매니저에게 문의하세요. |
| **커스텀 이벤트 수행** | 사용자가 기존 커스텀 이벤트 중 하나를 수행하면 전환한 것으로 집계됩니다(기본값 없음, 이벤트를 지정해야 합니다). |
| **앱 업그레이드** | 사용자가 지정한 앱 중 하나에서 앱 버전을 업그레이드하면 전환한 것으로 집계됩니다(기본값은 워크스페이스의 모든 앱). Braze는 변경이 업그레이드인지 판단하기 위해 최선의 수치 비교를 수행합니다. 숫자가 아닌 버전은 버전이 변경되면 전환으로 집계됩니다. |
| **이메일 열람** | 사용자가 이메일을 열면 전환한 것으로 집계됩니다(이메일 Campaign 전용). |
| **이메일 클릭** | 사용자가 이메일 내 링크를 클릭하면 전환한 것으로 집계됩니다(이메일 Campaign 전용). |
{: .reset-td-br-1 .reset-td-br-2 aria-label="2단계: 전환 이벤트 추가하기" }

{% alert important %}
**전환 이벤트에서 중첩 속성은 지원되지 않습니다**. 전환 이벤트에서 중첩 속성을 사용할 수 없습니다. 예를 들어, `product_code` 또는 `product_name`이 `products` 배열 내의 중첩 속성인 경우(예: `products[].product_code`), 전환 이벤트에서 특정 제품 구매 여부를 확인하는 데 사용할 수 없습니다.
{% endalert %}

전환 기한을 설정합니다. 이는 Braze가 전환으로 간주하기까지 경과할 수 있는 최대 시간입니다. 사용자가 지정된 행동을 수행하면 Braze가 전환을 집계하는 최대 30일까지의 기간을 설정할 수 있습니다.

![전환 이벤트 유형으로 "구매"를 선택하여 구매한 사용자의 전환을 기록하는 예시. 전환 기한은 12시간으로 설정되어 있습니다.]({% image_buster /assets/img_archive/conversion_event_selection.png %})

전환 이벤트를 선택한 후, Campaign 생성 프로세스를 계속 진행하고 Campaign 전송을 시작합니다.

### 3단계: 결과 확인하기 {#step-3-view-your-results}

**세부 정보** 페이지로 이동하여 생성한 Campaign과 관련된 각 전환 이벤트의 세부 정보를 확인합니다. 선택한 전환 이벤트에 관계없이, 주요 전환 이벤트 기간 동안 이 특정 Campaign과 특정 배리언트에 귀속된 총 매출도 확인할 수 있습니다.

{% alert note %}
Campaign 생성 시 전환 이벤트를 선택하지 않으면 기본값은 3일로 설정됩니다.
{% endalert %}

또한, 다변량 메시지의 경우 대조군과 각 배리언트의 전환 수 및 전환율을 확인할 수 있습니다.

![3시간 이내 구매, 2시간 이내 구매, 30분 이내 세션 시작, 25분 이내 세션 시작을 기준으로 전환을 추적하는 4개의 전환 이벤트.]({% image_buster /assets/img_archive/conversion_event_details.png %})

## 캔버스 단계와 배리언트 전환율 비교 {#canvas-step-versus-variant-conversion-rates}

Canvas 배리언트의 총 전환 수가 개별 단계의 전환 수 합계보다 높은 경우가 흔합니다. 이는 배리언트 수준과 단계 수준에서 전환이 다르게 추적되기 때문입니다.

- 배리언트 전환은 사용자가 배리언트에 진입하는 즉시 집계됩니다.
- 단계 전환은 해당 단계의 메시지가 사용자에게 전송된 후에만 집계됩니다.

즉, Canvas에 진입한 후 단계를 수신하기 전에 전환 이벤트를 수행한 사용자는 배리언트 합계에는 포함되지만 어떤 단계에도 포함되지 않습니다.

다음과 같은 시나리오에서도 이러한 차이가 발생할 수 있습니다.

- **사용자가 단계를 수신하기 전에 Canvas를 이탈하는 경우.** 사용자가 Canvas에 진입했지만 메시지가 전송되기 전에 이탈한 경우(예: 필터 또는 오디언스 불일치로 인해), 해당 사용자가 수행한 전환은 배리언트 수준에서는 집계되지만 단계 수준에서는 집계되지 않습니다.
- **단계가 일부 사용자만 타겟팅하는 경우.** 단계가 특정 플랫폼(예: 모바일)에만 전송되도록 구성된 경우, 다른 플랫폼(예: 웹)의 사용자도 Canvas에 진입하여 전환할 수 있습니다. 이러한 사용자는 해당 단계의 메시지를 수신하지 않으므로 전환이 단계 수준에서는 집계되지 않고 배리언트 수준에서만 집계됩니다.
