# 종료 기준 {#exit-criteria}

> Canvas 진입 규칙에 예외 이벤트를 직접 추가하면 사용자가 특정 동작을 수행할 때 여정에서 제거할 수 있습니다.
> Braze는 이벤트가 발생하는 즉시 종료를 기록합니다.
> 사용자가 Canvas를 완전히 떠나는 속도는 현재 진행 중인 단계에 따라 달라지며, 특히 지연 단계에서 차이가 있습니다.
> 자세한 내용은 [사용자가 종료하는 방법](#how-users-exit)을 참조하세요.

## 사용자가 이탈하는 방식 {#how-users-exit}

사용자가 이탈 이벤트를 수행하면, Braze는 즉시 해당 사용자를 Canvas에서 이탈 대상으로 표시합니다. 이후 해당 사용자는 이후 단계로 진행되지 않습니다.

지연 단계에 있는 경우, 지연 기간이 끝날 때까지 해당 단계에 남아 있습니다. 지연이 완료되더라도 이후 단계로 진행되지 않으며, Canvas에서 완전히 이탈하게 됩니다. Canvas 데이터를 확인하는 위치에 따라, 이탈 이벤트가 발생한 시점과 지연 단계가 완료되어 사용자가 Canvas에서 완전히 이탈한 시점 모두에서 이탈 관련 활동이 표시될 수 있습니다.

예를 들어, 사용자가 30일 지연 단계에 있고 지연 단계 첫째 날에 이탈 이벤트를 수행한 경우, 즉시 이탈 대상으로 표시되지만 지연 단계가 종료될 때까지(29일 후) Canvas에서 완전히 이탈하지는 않습니다.

시간 기반 이탈 기준을 사용하는 또 다른 예를 살펴보겠습니다. 사용자가 7월 1일 오전 12시에 24시간으로 설정된 지연 단계에 진입합니다. 이 지연 기간 중 오전 3시에 "마지막 주문이 1시간 이내"라는 이탈 이벤트를 수행합니다. 이 사용자는 지연 단계 기간이 종료되는 7월 2일 오전 12시에 이탈 기준에 대해 평가됩니다. 7월 1일 오전 3시 주문 이후 21시간이 경과했으므로, 7월 2일 지연 단계를 이탈하는 시점 기준 1시간 이내에 주문을 하지 않았기 때문에 Canvas에서 이탈하지 않습니다. 이는 Canvas 분석의 "Total Exits by Exit Criteria"에 영향을 미치며, 이 값은 사용자가 Canvas에서 완전히 이탈한 후에만 업데이트됩니다.

## 종료 기준 설정하기 {#setting-up-exit-criteria}

Canvas 빌더의 **타겟 오디언스** 단계에서 Canvas를 종료할 사용자를 식별하기 위한 종료 기준을 설정할 수 있습니다.

종료 기준에는 예외 이벤트가 포함되며, 이는 사용자가 Canvas를 종료하게 만들 수 있는 특정 액션입니다.

![제품을 둘러봤지만 장바구니에 추가하거나 주문하지 않은 사용자에게 재참여를 유도하기 위해 설정된 종료 기준.]({% image_buster /assets/img/exit_criteria.png %}){: style="max-width:90%;"}

### 예외 이벤트 선택하기 {#exception-events}

사용자가 예외 이벤트를 수행하면, Braze는 [사용자가 종료하는 방식](#how-users-exit)에 따라 해당 사용자를 종료 대상으로 표시합니다. 예외 이벤트는 지연 단계와 같은 캔버스 단계에서 대기 중인 경우를 포함하여, 사용자가 Canvas 내에 있는 동안 적용됩니다.

새 제품을 홍보하기 위한 Canvas가 설정되어 있다고 가정해 보겠습니다. 이 경우 해당 제품의 주문이 예외 이벤트가 됩니다. 이렇게 하면 사용자가 주문을 완료한 후에는 이미 구매한 제품에 대한 메시지를 더 이상 받지 않게 됩니다. 예외 이벤트는 메시징을 관련성 있고 개인화된 상태로 유지합니다.

추가 예외 이벤트에는 다음이 포함됩니다:

- 주문하기
- 세션 시작하기
- 커스텀 이벤트 수행하기
- 전환 이벤트 수행하기
- 이메일 주소 추가하기
- 커스텀 속성 값 변경하기
- 가입 상태 업데이트하기
- 구독 그룹 상태 업데이트하기
- Campaign과 상호작용하기
- 위치 입력하기
- 지오펜스 트리거하기
- 단문 메시지 서비스 인바운드 메시지 보내기
- WhatsApp 인바운드 메시지 보내기
- LINE 인바운드 메시지 보내기
- 장바구니 업데이트 이벤트 수행하기

#### 스케줄된 단계 {#scheduled-steps}

사용자를 특정 시간까지 지연 단계에 머물게 하지 않는 캔버스 단계의 경우, 사용자는 일반적으로 현재 단계가 완료되는 즉시 Canvas를 떠납니다. 해당 단계에 남아 있는 지연 타이머가 없기 때문에 완료가 예외 이벤트 직후에 이루어지는 경우가 많습니다. 이는 예외 이벤트로 종료 대상으로 표시된 후에도 지연이 끝날 때까지 사용자가 머무르는 지연 단계와 다릅니다([사용자가 종료하는 방식](#how-users-exit) 참조).

#### 트리거된 단계 {#triggered-steps}

캔버스 단계가 이벤트에 의해 트리거된 경우, 해당 트리거에서 대기줄에 추가된 마지막 스케줄된 전송이 취소되지만, 사용자는 윈도우 기간 동안 Canvas 내에 남아 있습니다. 즉, 윈도우 내에서 트리거 이벤트를 다시 수행하면 해당 단계를 여전히 받을 수 있습니다. 윈도우가 지나면 사용자는 Canvas를 종료합니다.

### Segments와 필터 사용하기 {#using-segments-and-filters}

종료 기준에 Segments와 필터를 추가할 수도 있습니다. 이는 해당 Segment 및 필터 조건에 일치하는 사용자가 Canvas를 종료하고 더 이상 메시지를 받지 않는다는 것을 의미합니다.

예를 들어, Canvas의 첫 번째 단계가 5일 지연이 있는 지연 단계인 경우, 종료 기준은 해당 단계가 완료될 때 평가됩니다. 사용자가 지연 단계에 있는 동안 종료 기준을 충족하면 즉시 종료 대상으로 표시되지만, 5일이 끝나는 시점에 Canvas를 완전히 떠나게 됩니다(지연 이후의 단계로는 진행되지 않습니다).

{% alert note %}
배열 속성은 현재 예외 이벤트의 종료 기준으로 지원되지 않습니다.
{% endalert %}

### 동일한 종료 이벤트와 전환 이벤트 사용하기 {#having-the-same-exit-event-and-conversion-event}

종료 이벤트와 전환 이벤트가 동일한 경우, 전환 이벤트와 종료 이벤트 모두 집계됩니다. 예를 들어, Canvas에 지연 단계가 있고 사용자가 해당 지연 단계에 있는 동안 종료 기준을 수행하면, 사용자가 지연 단계를 나가는 즉시 종료 이벤트가 증가합니다. 전환 이벤트도 고객 프로필에 해당 이벤트가 기록되는 즉시 증가합니다.

전환은 Canvas가 종료된 후에도 추적되지만, 종료 이벤트는 사용자가 Canvas를 나간 후에는 추적되지 않습니다. 전환 윈도우는 Canvas의 최대 기간 이후 3일까지 연장됩니다. 즉, 종료 이벤트 추적이 중단된 후에도 전환은 계속 추적됩니다.

전환 윈도우의 최소 시간은 5분입니다. 전환 이벤트와 종료 이벤트의 동등성을 최대한 확보하려면 전환 윈도우를 5분으로 설정하세요. 또한 전환 윈도우를 Canvas의 가장 긴 경로와 최소한 일치하도록 설정하는 것을 권장합니다.

분석이 어떻게 계산되는지에 대한 다음 예시를 살펴보세요:

1. 10명의 사용자가 Canvas를 통과합니다.
2. 3명의 사용자가 5분 이내에 전환 이벤트를 수행합니다(종료 이벤트 수는 3이고, 전환 이벤트 수는 3입니다).
3. 또 다른 5명의 사용자가 5분 후에 Canvas를 종료하지만, 2일 후에 전환 이벤트를 수행합니다(종료 이벤트 수는 동일하게 유지되지만, 전환 이벤트는 8로 증가합니다).
4. 마지막 2명의 사용자가 5분 후에 Canvas를 종료하지만, 전환 이벤트를 수행하지 않거나 3일 5분 후에 수행합니다(종료 이벤트 또는 전환 이벤트 측정기준에 포함되지 않습니다).

## 예시 {#example}

배낭 공급 회사에서 아직 주문을 하지 않은 사용자를 타겟팅하고 싶다고 가정해 보겠습니다. 종료 기준을 설정하려면 다음과 같이 합니다:

1. **Place an Order**를 예외 이벤트로 선택합니다.
2. **Add Trigger**를 선택합니다.
3. **Segments**에서 **Used in last day**를 선택하면, Canvas가 시작될 때 오디언스에서 구매한 적이 있는 사용자가 제외됩니다.
4. **Filters**에서 **Purchase behavior** > **Number of purchases** > **Purchased product**를 선택합니다.
5. 필터 그룹을 `backpack-example exactly 1`로 설정합니다. 이렇게 하면 배낭 제품을 구매한 사용자가 Canvas에서 종료됩니다.

![예외 이벤트가 'Makes Any Purchase'로 설정된 종료 기준 설정 화면. 사용자가 구매를 하면 이 Canvas에서 종료됩니다.]({% image_buster /assets/img_archive/exit_criteria_example.png %}){: style="max-width:80%;"}
