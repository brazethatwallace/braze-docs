# 행동 경로 {#action-paths}

> Canvas의 행동 경로를 사용하면 사용자의 행동을 기반으로 사용자를 분류할 수 있습니다.

![Canvas 사용자 여정의 행동 경로 단계.]({% image_buster /assets/img/canvas_actionpath.png %}){: style="float:right;max-width:40%;margin-left:15px;"}

행동 경로를 사용하면 다음을 수행할 수 있습니다:

* 사용자 참여 이벤트 및 커스텀 이벤트를 포함한 특정 행동을 기반으로 사용자 경로를 커스텀할 수 있습니다
* 평가 기간 동안의 행동을 기반으로 다음 경로의 우선순위를 지정하기 위해 사용자를 일정 기간 동안 대기시킬 수 있습니다

## 행동 경로 생성 {#creating-an-action-path}

행동 경로를 생성하려면 Canvas에 구성요소를 추가합니다. 사이드바에서 구성요소를 드래그 앤 드롭하거나, 단계 하단의 <i class="fas fa-plus-circle"></i> 플러스 버튼을 선택한 후 **행동 경로**를 선택합니다.

### 동작 설정 {#action-settings}

**동작 설정**에서 **평가 기간**을 설정하여 사용자가 해당 단계에 머무는 시간을 결정합니다. 기본적으로 사용자는 1일 이내에 평가되지만, Canvas에 따라 초, 분, 시간, 일, 주 단위로 이 기간을 조정할 수 있습니다. 행동 경로의 최대 평가 기간은 31일입니다.

**동작 설정** 내에서 **순위 순서에 따라 사용자 진행** 토글을 켜서 구성요소의 순위 순서를 활성화할 수도 있습니다.

![평가 기간이 1일인 동작 설정.]({% image_buster /assets/img/actionpath_settings.png %})

기본적으로 **순위**는 꺼져 있습니다. 사용자가 행동 경로에 진입하여 어떤 행동 그룹에 연결된 트리거 이벤트를 수행하면, 단계에 진입한 후 수행한 **첫 번째 적격 행동**을 기반으로 해당 행동 그룹을 통해 즉시 진행됩니다. 사용자가 다른 행동 그룹에 해당하는 두 번째 행동을 수행하더라도 경로가 변경되지 않습니다. 첫 번째 행동이 경로를 결정합니다. 사용자가 트리거 이벤트를 수행하지 않으면, 평가 기간이 끝날 때 기본 **다른 모든 사용자** 그룹을 통해 진행됩니다.

**순위 순서에 따라 사용자 진행**이 켜져 있으면 **순위**가 활성화됩니다. 따라서 모든 사용자는 평가 기간이 끝날 때까지 대기합니다. 평가 기간이 끝나면, 사용자는 평가 기간 종료 시점에 자격이 있는 가장 높은 우선순위의 행동 그룹을 통해 진행됩니다. 평가 기간 동안 어떤 행동도 수행하지 않은 사용자는 기본 **다른 모든 사용자** 그룹을 통해 진행됩니다.

{% alert tip %}
수행한 행동이 아닌 현재 속성이나 Segment 멤버십을 기반으로 사용자를 라우팅하려면 [오디언스 경로]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/audience_paths/)를 대신 사용하세요.
{% endalert %}

중첩 고객 속성 오브젝트가 변경될 때 행동 경로를 트리거할 수 있지만, 중첩 고객 속성의 배열이나 오브젝트 배열 데이터 유형의 변경에 대해서는 트리거할 수 없습니다.

#### 인앱 메시지 {#in-app-messages}

행동 그룹 트리거가 세션 시작이고 다음 단계가 인앱 메시지인 경우, 사용자가 인앱 메시지를 받으려면 두 번의 세션 시작이 필요합니다. 첫 번째 세션은 행동 경로 내의 행동 그룹에 사용자를 할당하고, 두 번째 세션은 인앱 메시지를 트리거합니다.

#### 순위 상태 예시 {#ranking-status-example}

평가 기간이 1일이고 두 개의 행동 그룹(그룹 1과 그룹 2)이 있는 행동 경로가 있다고 가정해 보겠습니다. 그룹 1에는 "세션 시작" 트리거 이벤트가 있고, 그룹 2에는 "구매하기"가 있습니다. **순위**가 켜져 있으면, 행동 경로의 모든 사용자는 1일 동안 "대기"합니다. 하루가 끝날 때 사용자가 세션을 시작하고 구매도 했다면, 가장 높은 순위의 경로로 진행됩니다. 이 경우 사용자는 그룹 1로 진행됩니다.

위의 예시에서 **순위**가 꺼져 있고 사용자가 트리거 이벤트("세션 시작" 또는 "구매하기") 중 하나를 수행하면, 해당 사용자는 트리거 동작을 기반으로 관련 행동 그룹으로 진행됩니다.

Canvas 진입 등록정보는 이벤트 등록정보와 다릅니다. Canvas 진입 등록정보는 Canvas를 트리거한 이벤트의 등록정보입니다. 이러한 등록정보는 원래 Canvas 워크플로를 사용할 때 Canvas의 첫 번째 전체 단계에서만 사용할 수 있습니다. Canvas를 사용할 때 영구 진입 등록정보가 활성화되어 Canvas 전체에서 진입 등록정보를 재사용할 수 있습니다. 반대로, 이벤트 등록정보는 사용자가 워크플로를 진행하면서 발생하는 이벤트 또는 행동에서 비롯됩니다.

### 행동 그룹 {#action-groups}

트리거 하나 또는 여러 개를 추가하여 행동 그룹을 정의합니다. 여기에서 다음과 같은 다양한 트리거를 선택할 수 있습니다:

- 구매하기
- 세션 시작
- [커스텀 이벤트]({{site.baseurl}}/user_guide/data/activation/events/custom_events/) 수행
- 전환 이벤트 수행
- 이메일 주소 추가
- 커스텀 속성 값 변경
  - 여기에는 처음으로 고객 프로필에 값이 있는 새 속성을 추가하는 경우(이전에 해당 속성이 없었던 경우)도 포함됩니다.
  - 속성 트리거는 배열 속성에는 사용할 수 없습니다.
- 구독 상태 또는 구독 그룹 상태 업데이트
- Campaign 또는 콘텐츠 카드와 상호작용
- 위치 진입
- 지오펜스 트리거
- SMS 또는 WhatsApp 인바운드 메시지 전송

#### 이메일 주소 추가 트리거 {#add-an-email-address-trigger}

**이메일 주소 추가** 행동 그룹 트리거는 행동 경로의 **평가 기간** 동안 고객 프로필에 이메일 주소가 추가되거나 업데이트될 때 실행됩니다. 이 동작은 다른 프로필 업데이트 트리거와 동일합니다. 트리거의 필터를 포함하여 구성에 따라 프로필 변경이 적격한 경우 사용자가 행동 그룹을 통해 진행됩니다.

![구매를 수행하는 사용자를 위한 "그룹 1"이라는 행동 그룹.]({% image_buster /assets/img/actionpath_group.png %})

각 행동 그룹 설정에서 **이 그룹이 Canvas를 종료하도록 설정** 체크박스를 선택하는 옵션도 있습니다. 이는 이 그룹의 사용자가 평가 기간이 끝날 때 Canvas를 종료한다는 의미입니다.

### 재진입이 가능한 Canvases {#canvases-with-re-eligibility}

사용자가 행동 경로에 여러 번 진입하여 동시에 행동 경로에 여러 항목이 있는 경우, 예상되는 동작은 **순위** 상태에 따라 달라집니다.

| 순위 상태 | 행동 경로 동작 |
|---|--------------|
| **꺼짐** | 사용자는 행동 경로에 두 번 이상 진입할 수 있습니다. 이러한 항목은 트리거 동작 또는 이벤트가 기록될 때까지 행동 경로에 유지됩니다. 트리거 이벤트가 항목의 등록정보 필터를 충족하지 않는 경우(예: [컨텍스트 변수]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas/context_variables/)가 트리거의 등록정보 필터와 일치하지 않는 경우), 해당 항목은 행동 경로에 남아 있습니다. <br><br>트리거 이벤트가 둘 이상의 항목을 충족하는 경우, Braze는 이러한 항목만 중복 제거하고 가장 먼저 일치하는 항목을 관련 행동 그룹을 통해 즉시 진행시킵니다. |
| **켜짐** | 모든 항목은 해당 평가 기간이 끝날 때 진행됩니다. 중복 제거는 발생하지 않습니다. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="재진입이 가능한 Canvases" }

순위는 [시작 후에는 편집할 수 없습니다]({{site.baseurl}}/post-launch_edits/).
