# 캔버스 분석 {#canvas-analytics}

> 구축하고 있는 것이 실질적인 변화를 만들어내고 있는지 알아야 합니다. 캔버스 분석을 통해 구축한 경험이 목표에 어떤 영향을 미치고 있는지 전체적인 그림을 파악할 수 있습니다.

캔버스를 구축하고 라이브로 설정한 후, **Canvas** 페이지로 이동하여 캔버스를 선택하면 세부 정보 페이지가 열립니다. 여기에서 캔버스의 성과를 측정하고 테스트할 수 있습니다.

## Canvas 개요 {#canvas-overview}

**Canvas 세부 정보** 페이지 상단에는 Canvas의 주요 통계가 표시됩니다. 여기에는 Canvas 내에서 발송된 메시지 수, 고객이 Canvas에 진입한 총 횟수, 전환한 사용자 수와 총 전환율, Canvas에서 발생한 매출, 그리고 예상 총 오디언스가 포함됩니다.

이 영역은 Canvas가 목표 대비 어떻게 성과를 내고 있는지 전체적으로 파악하기에 좋은 곳입니다. Canvas의 성과가 예상 범위를 벗어날 경우 사전에 알림을 받으려면 [Canvas 임계값 알림]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/canvas_threshold_alerts)을 참조하세요.

### 도달 가능한 사용자 및 정확한 통계 {#reachable-users-and-exact-statistics}

Canvas에 연결된 오디언스에 대해 **[정확한 통계 계산]({{site.baseurl}}/user_guide/audience/segments/creating_a_segment#single-user-segments)**이 실행 중일 때, Braze는 **도달 가능한 사용자** 영역에 반올림된 추정치를 잠시 표시할 수 있습니다. 계산이 완료되면 정확한 합계가 추정치를 대체합니다. 채널별 전체 분석을 보려면 **추가 통계 보기**를 선택하세요. Canvas 빌더에서는 **대상 집단** 아래에 동일한 흐름을 설명하고 있습니다. [대상 집단 계산]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas#calculating-target-population)을 참조하세요.

![발송된 메시지, 전환율, 총 진입 수, 총 매출, 총 이탈 수, 예상 오디언스 등 주요 통계와 채널 및 통계 필터가 표시된 Canvas 세부 정보 페이지.]({% image_buster /assets/img_archive/Journey_5.png %})

{% alert tip %}
Canvas 활동을 기반으로 생성한 Segment에서 Canvas 분석 결과에 비해 도달 가능한 사용자가 예상보다 적게 표시되는 경우, 일반적으로 두 가지 원인이 있습니다.

- **추정 샘플링:** Segment 통계는 정확한 수치가 아닌 95% 신뢰 구간 ±1%의 무작위 샘플 기반 추정치를 표시할 수 있습니다.
- **기준에 더 이상 부합하지 않는 사용자:** Canvas 분석에서 집계된 일부 사용자가 더 이상 해당 Segment에 해당하지 않을 수 있습니다. 예를 들어, Canvas가 실행된 이후 탈퇴했거나 프로필 데이터가 변경된 경우입니다. 탈퇴 수가 많은지 확인하려면 Canvas의 **과거 성과**를 확인하세요.
{% endalert %}

### 마지막 조회 이후 변경 사항 {#changes-since-last-viewed}

팀의 다른 구성원이 Canvas에 적용한 업데이트 수는 Canvas 개요 페이지의 *마지막 조회 이후 변경 사항* 측정기준으로 추적됩니다. **마지막 조회 이후 변경 사항**을 선택하면 Canvas 이름, 스케줄, 태그, 메시지, 오디언스, 승인 상태 또는 팀 접근 설정에 대한 업데이트 체인지로그를 확인할 수 있습니다. 각 업데이트에 대해 누가 언제 업데이트를 수행했는지 확인할 수 있습니다. 이 체인지로그를 사용하여 Canvases의 변경 사항을 감사할 수 있습니다.

## 성능 시각화 {#performance-visualization}

**Canvas 세부 정보** 페이지를 아래로 스크롤하면 각 구성 요소의 성능을 확인할 수 있습니다. 예를 들어 얼마나 많은 사용자가 진입했는지, 다음 단계로 진행했는지, Canvas에서 이탈했는지 등을 볼 수 있습니다. 특정 캔버스 단계 또는 구성 요소를 선택하면 해당 여정 부분에 패널이 집중되어 측정기준을 더 자세히 검토할 수 있습니다.

{% alert note %}
Canvas Flow의 경우, 사용자는 사용자 여정의 마지막 단계에 진입하여 메시지 페이로드를 수신한 후 Canvas에서 이탈합니다.
{% endalert %}

측정기준에는 노출 횟수, 고유 수신자, 전환 수, 발생 매출도 포함됩니다. 구성 요소를 클릭하면 데이터를 더 세분화하고 채널별 성능을 확인할 수 있습니다.

![Canvas 구성 요소의 성능 세부 정보를 보여주는 두 가지 예시. 왼쪽은 하나의 Canvas 구성 요소가 포함된 사용자 경로의 성능 세부 정보를 보여줍니다. 오른쪽은 확장된 Canvas 구성 요소와 인앱 메시지 노출 횟수를 표시하는 중첩 단계의 성능 세부 정보를 보여줍니다.]({% image_buster /assets/img_archive/Journey_6.png %})

## 배리언트별 성능 분석 {#performance-breakdown-by-variant}

**Canvas 세부 정보** 페이지 하단에서 **배리언트 분석**을 클릭하면 **Canvas 분석** Modal이 열립니다. 이 Modal에는 세 개의 탭이 있습니다:

- 배리언트 분석
- Canvas 퍼널 보고서
- Canvas 유지 보고서

### 배리언트 분석 {#analyze-variants}

**배리언트 분석** 탭에서는 배리언트 및 대조군별 성능 분석을 확인할 수 있습니다(두 개 이상의 배리언트가 있는 경우). Canvas API 식별자를 복사하거나, 측정기준의 CSV 파일을 다운로드하거나, 셀을 복사할 수도 있습니다. **배리언트 분석** 탭에는 각 배리언트를 여러 수준에서 분석한 테이블이 포함되어 있습니다.

효과적인 배리언트를 빠르게 파악하고 적절한 케이던스, 콘텐츠, 트리거, 타이밍 등을 식별할 수 있습니다.

![배리언트 분석 탭이 선택된 Canvas 분석 Modal로, 경로 1과 경로 2의 항목, 발송, 매출, 전환율, 변화율, 신뢰도 측정기준을 비교하는 테이블을 보여줍니다.]({% image_buster /assets/img_archive/analyze_variants.png %})

기본 측정기준은 다음과 같습니다:

- **배리언트 API 식별자:** API 호출에 사용할 수 있는 배리언트의 API 식별자입니다.
- **총 항목:** Canvas 배리언트에 진입한 총 사용자 수입니다.
- **총 발송:** Canvas 배리언트에서 발송된 총 메시지 수입니다.
- **총 단계:** Canvas 배리언트의 총 단계 수입니다.
- **총 매출:** 설정된 주요 전환 기간 내 Canvas 수신자로부터 발생한 총 매출(달러)입니다. *총 매출*은 해당 기간 동안 해당 배리언트를 수신한 사용자에게 기여된 구매의 합계입니다. 구매가 해당 기간의 기여도 규칙에 해당하는 한, 사용자가 설정된 주요 전환 이벤트를 수행하지 않더라도 *총 매출*에 포함됩니다.

{% alert note %}
전환과 마찬가지로, 매출은 기술적으로 Canvas 수준에서 추적되지만 사용자가 메시지를 수신한 가장 최근 구성 요소 및 가장 최근 배리언트에 기여됩니다(아직 메시지를 수신하지 않은 경우 진입한 배리언트에 기여됩니다).<br><br>
예를 들어, 사용자가 두 단계를 완료한 후 구매하면 해당 매출은 두 번째 구성 요소와 진입한 배리언트에 기여됩니다. Canvas에 진입했지만 첫 번째 Canvas 구성 요소를 수신하기 전에 구매한 경우, 해당 매출은 진입한 배리언트에 기여되지만 어떤 구성 요소에도 기여되지 않습니다.
{% endalert %}

그 외에도 다음을 포함한 [전환 이벤트]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/conversion_events)의 더 상세한 분석을 확인할 수 있습니다:

- 각 전환 이벤트의 전환 합계 및 전환율
- 대조군 대비 상승률
- 각 전환 이벤트의 통계적 신뢰도

### 전환 추적 방식 {#how-conversions-are-tracked}

사용자는 Canvas 진입당 전환 이벤트별로 한 번만 전환할 수 있습니다. 전환은 해당 진입에서 사용자가 수신한 가장 최근 메시지에 할당됩니다. Canvas 요약에는 해당 경로의 사용자가 수행한 모든 전환이 반영되며, 메시지 수신 여부와 관계없이 표시됩니다. 이후 각 단계에서는 해당 단계가 사용자가 수신한 가장 최근 단계였을 때 발생한 전환만 표시됩니다.

다음 예시를 살펴보겠습니다: Canvas에 10개의 푸시 알림이 있고 전환 이벤트가 "앱 열기"(또는 "세션 시작")인 경우입니다.
- 사용자 A는 진입 후 첫 번째 메시지를 수신하기 전에 앱을 엽니다.
- 사용자 B는 각 푸시 알림 후에 앱을 엽니다.

Canvas 요약에는 두 건의 전환이 표시되고, 개별 단계에서는 첫 번째 단계에 한 건의 전환이 표시되며 이후 모든 단계에는 전환이 표시되지 않습니다. 전환 이벤트 발생 시 방해금지 시간이 활성화되어 있으면 동일한 규칙이 적용됩니다.

이제 방해금지 시간이 설정된 Canvas에서 다음 이벤트가 발생하는 경우를 살펴보겠습니다:

1. 사용자 A가 Canvas에 진입합니다.
2. 첫 번째 단계가 설정된 방해금지 시간 내의 지연 단계이므로 메시지가 억제됩니다.
3. 사용자 A가 전환 이벤트를 수행합니다.

사용자 A는 전체 캔버스 배리언트에서는 전환으로 집계되지만, 해당 단계를 수신하지 않았으므로 단계에서는 전환으로 집계되지 않습니다.

마지막 예시로, 재진입이 활성화된 Canvas가 있다고 가정해 보겠습니다. 재진입 가능한 사용자가 첫 번째 진입과 두 번째 진입에서 전환 이벤트를 수행하면 두 건의 전환이 집계됩니다.

### 퍼널 보고서 {#funnel-report}

퍼널 보고서는 고객이 Canvas를 수신한 후 거치는 여정을 분석할 수 있는 시각적 보고서를 제공합니다. Canvas에 대조군이나 여러 배리언트가 사용되는 경우, 다양한 배리언트가 전환 퍼널에 미치는 영향을 더 세분화된 수준에서 파악하고 이 데이터를 기반으로 최적화할 수 있습니다. 퍼널 보고서에 대한 자세한 내용은 [퍼널 보고서]({{site.baseurl}}/user_guide/analytics/reports/funnel_reports)를 참조하세요.

### 유지 보고서 {#retention-report}

사용자 유지는 모든 마케터에게 가장 중요한 측정기준 중 하나입니다. 참여하는 사용자가 계속 돌아오도록 하는 것은 비즈니스가 건강하다는 것을 나타냅니다. Braze에서는 **Canvas 분석** 페이지에서 바로 사용자 유지를 측정할 수 있습니다. 유지 보고서를 읽고 해석하는 방법에 대한 자세한 내용은 [유지 보고서]({{site.baseurl}}/user_guide/analytics/reports/retention_reports)를 확인하세요.
