# Canvas에서 사용자 경로 미리보기 {#preview-user-paths-in-canvas}

> 사용자를 위해 만든 Canvas 여정을 직접 경험해 보세요. 사용자가 받는 타이밍과 메시지를 미리 볼 수 있습니다. 이러한 테스트 실행은 Canvas를 발송하기 전에 메시지가 올바른 오디언스에게 전송되는지 확인하는 품질 보증 역할을 합니다.

## 테스트 실행 생성 {#creating-a-test-run}

사용자 여정을 미리 보려면 다음 단계를 따르세요:

1. Canvas 빌더로 이동합니다. 저장하지 않은 변경 사항을 저장하고 오류를 해결합니다.
2. 바닥글에서 **Test Canvas**를 선택합니다.
3. 테스트 사용자를 선택합니다.
4. (선택 사항) 테스트 수신자를 선택합니다.
5. **Run Test**를 선택합니다.

Canvas를 편집할 권한이 없어도 미리보기를 실행할 수 있지만, 저장하지 않은 변경 사항이 있는 경우 해당 변경 사항이 포함된 상태로 미리보기가 실행됩니다.

### 지원되는 단계 {#supported-steps}

다음 단계가 지원됩니다:
- 메시지
- 오디언스 경로
- 결정 분할
- 지연
- 행동 경로
- 실험 경로
- 에이전트
- 사용자 업데이트(UI 편집기에서만 지원되며, JSON 편집기를 사용하는 단계는 건너뜁니다)

테스트가 위에 나열되지 않은 단계 유형과 겹치는 경우, 지원되지 않는 단계는 건너뛰고 테스트 사용자는 다음 지원되는 단계로 계속 진행합니다.

### 에이전트 단계 {#agent-steps}

테스트 실행이 [에이전트 단계]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/agent_step)에 도달하면, Braze는 일시 중지하고 **에이전트 "{agentName}"을(를) 실행하시겠습니까?**라고 묻습니다. 계속 진행할 방법을 선택하세요:

- **예:** 텍스트 필드에 선택적으로 컨텍스트를 추가한 다음(테스트 사용자의 프로필 및 여정에 이미 있는 Canvas 컨텍스트 외에), **Simulate response**를 선택하여 에이전트를 호출합니다. 장바구니 내용이나 인바운드 메시지 텍스트를 설명하는 등 일반 언어로 샘플 값을 입력하여 에이전트가 프로덕션에서 수신할 런타임 컨텍스트를 모방할 수 있습니다.
- **아니요:** Braze는 에이전트를 호출하지 않습니다. 이 단계는 [Agent Console]({{site.baseurl}}/user_guide/brazeai/agents/creating_agents#configure-fallback-values)의 **Output** 섹션에서 구성된 에이전트의 **대체 출력**을 사용합니다.

**예**와 **Simulate response**를 선택하면, 에이전트가 미리보기 사용자에 대해 실행되고 출력을 에이전트 단계의 출력 변수에 저장한 후 테스트가 여정을 따라 계속됩니다. **Simulate response**의 호출은 에이전트의 일일 호출 한도에 포함되며 **Agent Console** > **Logs**에 표시됩니다.

전체 Canvas 경로를 실행하지 않고 에이전트 단계를 개별적으로 테스트하려면 Canvas 빌더의 단계 내 미리보기를 사용하세요. 설정 세부 사항은 에이전트 단계의 [에이전트 테스트]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/agent_step#step-5-test-the-agent)를 참조하세요.

에이전트 단계가 업스트림 [컨텍스트 단계]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/context)의 데이터에 의존하는 경우, **Test Canvas**를 실행하여 경로를 따라 컨텍스트 변수가 채워지도록 하세요. 시드 그룹은 시드 수신자에 대해 컨텍스트 단계나 컨텍스트 변수를 평가하지 않습니다.

### 캔버스 단계 세부 정보 {#canvas-step-details}

진입 기준에 대한 자세한 내용을 보려면 **See more**를 선택합니다. 세분화가 있는 단계는 충족된 기준 또는 충족되지 않은 기준을 보여줍니다. 메시지는 전달 검증 및 채널 적격성에 대해서도 이를 보여줍니다. 메시지 단계는 어떤 채널이 발송되었고 어떤 채널이 발송되지 않았는지를 보여줍니다.

### Liquid

Braze는 실제 테스트 메시지를 발송하지 않더라도 테스트 실행 중에 Liquid 로직을 처리합니다. 즉, [메시지 중단 로직]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/aborting_messages)과 기타 Liquid 로직이 반영되어 Canvas 사용자 여정에 영향을 미칠 수 있습니다.

미리보기가 중단하지 않고 사용자 여정의 마지막 단계를 발송하는 경우, 미리보기는 Canvas 진입 시간을 기준으로 사용자가 실제로 해당 단계에 있을 시간이 아닌 현재 시간을 Liquid 평가를 위한 테스트 시간으로 사용할 수 있습니다.

## 타이밍 미리보기 {#previews-for-timing}

스케줄된 Canvas의 경우, 테스트 사용자는 다음 스케줄된 진입 시간에 진입합니다. 시작 날짜가 있는 액션 기반 Canvas의 경우, 테스트 사용자는 시작 날짜와 시간에 진입합니다.

기본 시작 시간이 여전히 적용되지만, 진입 시간은 모든 경우에 구성할 수 있으므로 과거 또는 미래의 날짜를 시뮬레이션할 수 있습니다. 그러나 Canvas의 시작 날짜 이전이나 종료 날짜 이후에는 테스트할 수 없습니다.

메시지 및 지연 단계에서는 지연을 다시 구성할 필요 없이 사용자가 진행하거나 메시지를 받는 시간을 보여줍니다. 단계에서 Intelligent Timing 사용 여부는 표시되지만, 이 사용자 경로 미리보기에서는 테스트 사용자에 대한 예상 시간을 계산하지 않습니다.

"커스텀 속성 값 변경"과 같은 액션 트리거가 있는 Canvas의 경우, Braze는 **Canvas 테스트 실행에서만** 트리거에 있는 사용자의 속성을 일시적으로 빈 값으로 설정하여 변경을 시뮬레이션합니다(이는 고객 프로필에 영향을 주지 않습니다). 이는 속성이 현재 값에서 변경되는 것을 테스트하기 위한 것입니다.

## 사용자 진입 및 종료 시점 {#when-users-enter-and-exit}

테스트 사용자는 실제로 적격하지 않더라도 미리보기에 진입합니다. 적격하지 않은 경우, 기준을 충족하지 못한 이유를 확인할 수 있습니다. 테스트 사용자가 미리보기에 진입하면, 테스트 사용자가 타겟 오디언스 기준을 충족하고 액션 트리거 기준을 수행한 것으로 가정합니다. 예를 들어, 진입 기준에 커스텀 이벤트를 사용하는 Canvas의 경우, 테스트 사용자가 진입 기준에서 예상대로 커스텀 이벤트를 수행한 것으로 가정합니다. 그러나 동일한 커스텀 이벤트가 Canvas의 다른 곳(예: 종료 기준)에서 사용되는 경우, 이것이 사용자 경로에 어떤 영향을 미칠 수 있는지 고려하세요.

테스트 사용자가 Canvas에 진입할 수 있도록 가정된 이벤트, API 트리거, 커스텀 속성 및 Canvas 진입 속성정보는 실제 고객 프로필에 업데이트되지 않으며 테스트 실행 이후에 유지되지 않습니다. 예를 들어, 테스트 중에 커스텀 속성이 Canvas 트리거로 사용되는 경우, 트리거 기준은 사용자가 커스텀 속성 변경을 트리거한 **것처럼** 사용자의 미리보기에 적용됩니다.

### 고려 사항 {#consideration}

종료 기준에 해당하는 동작(이벤트 속성정보 포함)이 있는 행동 경로를 테스트하면 종료 기준이 트리거되고 테스트 실행이 종료됩니다. 종료 기준에 해당하는 메시지 단계를 테스트하면 종료 기준이 트리거되고 테스트 실행이 종료됩니다.

현재로서는 행동 경로 내에서 종료 기준을 트리거할 특정 이벤트나 속성정보를 선택할 수 없습니다(경로 전체만 가능). 사용자가 여러 종료 기준을 잠재적으로 충족할 수 있는 경우, 처리되는 첫 번째 기준 중 사용자가 충족하는 기준이 결과로 표시됩니다.

## 실험 경로 및 캔버스 배리언트 {#experiment-paths-and-canvas-variants}

- 최상위 배리언트가 있는 Canvas의 경우, 테스트 시작 시 배리언트를 선택합니다.
- 실험 경로의 경우, 테스트 사용자가 해당 단계에 도달했을 때 사용자가 진행할 배리언트를 선택합니다.
- 개인화된 경로 또는 위닝 배리언트를 사용하는 실험 경로의 경우, 테스트 사용자가 메시지 단계에서 대기하는 지연 기간이 있지만, Braze는 사용자가 선택한 배리언트를 즉시 진행한 것으로 가정하므로 이 지연은 고려되지 않습니다.

## 테스트 발송 {#test-sends}

테스트 실행이 진행되는 동안 내부 테스트 그룹이나 개별 사용자에게 테스트 메시지를 보내도록 선택할 수 있습니다. 즉, 사용자가 테스트 경로에서 만나는 메시지만 발송됩니다. 수신자는 기본적으로 자신의 속성이 포함된 메시지를 받지만, 테스트 사용자의 속성으로 이를 재정의할 수 있습니다.

경로를 미리보지 않고 Canvas의 모든 테스트 메시지를 한 번에 보내려면 **Test Sends** 탭에서 **Send All Test Messages**를 선택하면 됩니다.

## 반응성 {#responsiveness}

캔버스 단계는 사용자 경로를 미리볼 때 타이밍에 반응합니다. 사용자 업데이트 단계를 통해 이루어진 업데이트는 이후 단계에 반영되지만 실제 고객 프로필에는 적용되지 않습니다. 사용자가 배리언트에 진입한 효과는 미리보기의 이후 단계에 반영됩니다.

마찬가지로, 필터는 테스트 사용자가 Canvas의 다른 단계와 상호작용한 결과로 발생한 동작을 인식합니다. 예를 들어, 이 미리보기 모드는 사용자가 Canvas에서 이전에 "발송된" 메시지 단계를 만났음을 인식하고, 테스트 사용자가 행동 경로를 통해 진행하기 위해 "동작을 수행했음"을 인식합니다.

반응성 동작에 대한 자세한 내용은 [종료 기준]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas/exit_criteria)을 참조하세요.

## 연결된 콘텐츠 {#connected-content}

연결된 콘텐츠가 Canvas에 포함되어 있으면 실행됩니다. 즉, 연결된 콘텐츠 호출이 있는 Canvas나 연결된 콘텐츠를 포함하는 Content Blocks가 있는 Canvas를 테스트하면, Canvas가 연결된 콘텐츠 호출을 보낼 수 있으며, 이는 다른 Campaigns이나 Canvases에서 참조하는 데이터를 수정할 수 있습니다.

사용자 경로를 미리볼 때, 고객 프로필이나 다른 Canvases 또는 Campaigns에서 참조하는 데이터를 변경하는 연결된 콘텐츠를 제거하는 것을 고려하세요.

## 웹훅 {#webhooks}

웹훅은 테스트 메시지가 발송될 때 실행되지만, 테스트 실행 중에는 실행되지 않습니다. 연결된 콘텐츠와 마찬가지로, 고객 프로필이나 다른 Canvases 또는 Campaigns에서 참조하는 데이터를 변경하는 웹훅을 제거하는 것을 고려하세요.

## 컨텍스트 변수 및 시드 그룹 {#context-variables-and-seed-groups}

이메일을 메시징 채널로 사용하는 메시지 단계의 경우, 시드 그룹은 사용자가 Canvas에서 이 단계에 도달하면 이메일의 시드 사본을 발송합니다. 이러한 시드 사본은 시드 그룹 수신자 자체의 Canvas 여정의 일부로 발송되지 않으므로, Braze는 해당 수신자에 대해 [컨텍스트 단계]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/context)를 실행하거나 컨텍스트 변수를 평가하지 않습니다. 이메일 콘텐츠가 컨텍스트 변수를 참조하는 경우, 시드 그룹 수신자는 해당 데이터가 채워지지 않은 시드 사본을 받습니다. 컨텍스트 변수 데이터에 의존하는 메시지를 테스트하려면 시드 그룹 대신 테스트 발송이 포함된 **Test Canvas** 미리보기를 사용하세요.

## 사용 사례 {#use-case}

이 시나리오에서 Canvas는 앱에서 세션이 없는 사용자를 타겟으로 설정되어 있습니다. 이 여정에는 환영 이메일이 포함된 메시지 단계, 1일로 설정된 지연 단계, 그리고 두 경로로 분할되는 오디언스 경로 단계가 포함됩니다: 세션이 1회 이상인 사용자와 다른 모든 사용자. 사용자가 어떤 오디언스 경로에 해당하는지에 따라 후속 메시지 단계가 발송됩니다.
