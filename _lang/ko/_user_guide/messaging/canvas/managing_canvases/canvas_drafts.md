# 캔버스 임시저장본 저장

> 캔버스를 생성하고 시작한 후에도 활성 캔버스를 편집하고 임시저장본으로 저장할 수 있어, 다시 시작하기 전에 변경 사항을 사전에 검토할 수 있습니다.

대규모 변경이 필요한 활성 캔버스가 있는 경우, 이 기능을 사용하여 활성 캔버스에서 변경 사항을 시작하기 **전에** 구축, 저장 및 품질 검사를 수행할 수 있습니다.

다른 캔버스와 마찬가지로, 한 번에 한 명의 사용자만 임시저장본을 편집할 수 있으며, 캔버스당 하나의 임시저장본만 존재할 수 있습니다. 임시저장본의 변경 사항은 아직 시작되지 않았기 때문에 분석 데이터가 없습니다.

## 임시저장본 생성

임시저장본을 생성하려면:

1. 활성 캔버스로 이동합니다.
2. 캔버스 하단의 **임시저장** 버튼을 선택합니다.

캔버스의 임시저장본이 존재하는 동안에는 활성 캔버스를 편집할 수 없습니다. 캔버스를 업데이트하여 변경 사항을 적용하거나 임시저장본을 삭제할 수 있습니다.

## 활성 임시저장본 참조

활성 캔버스를 참조하려면 분석 보기의 하단 또는 임시저장본의 캔버스 헤더에서 **활성 캔버스 보기**를 선택합니다. 활성 캔버스로 돌아가려면 분석 보기 또는 활성 캔버스 보기에서 **임시저장본 편집**을 선택합니다.

임시저장본이 생성되기 전에 이미 시작된 단계만 참조할 수 있습니다. 즉, 임시저장본이 생성된 **이후에** 만든 단계나 채널은 임시저장본에서 참조할 수 없습니다.

{% alert note %}
콘텐츠 블록이 캔버스 임시저장본에서 참조되는 경우, 해당 캔버스는 콘텐츠 블록 포함 횟수에 포함됩니다. 그러나 콘텐츠 블록이 **활성** 캔버스의 임시저장본에서 참조되는 경우, 해당 캔버스는 콘텐츠 블록 포함 횟수에 포함되지 않습니다.
{% endalert %}

### 인앱 메시지 우선순위

활성 캔버스의 임시저장본에서 캔버스 빌더 내 인앱 메시지 우선순위는 사용자가 우선순위를 변경하면 즉시 업데이트됩니다. 즉, 캔버스 수준의 인앱 메시지 우선순위는 임시저장본이 존재하더라도 활성 캔버스에 즉시 적용됩니다.

그러나 단계 수준의 인앱 메시지 우선순위 변경은 임시저장본으로 저장되며 캔버스가 업데이트될 때 적용됩니다. 예를 들어, 메시지 단계에서 우선순위 정렬기는 단계 설정이 단계 수준에서 적용되므로 사용자가 임시저장본을 시작할 때 업데이트됩니다.
