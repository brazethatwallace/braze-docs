# 캔버스 버전 기록 {#canvas-version-history}

> 버전 기록을 사용하면 캔버스의 이전 버전에 대한 Canvas 분석 및 사용자 여정을 확인하고 액세스할 수 있습니다.

캔버스 버전 기록을 참조하면 캔버스의 변화 과정을 기록으로 유지하는 데 특히 유용합니다. 예를 들어, 대규모 변경을 수행한 경우 이전 캔버스 버전을 참조하여 워크플로가 어떻게 발전해 왔는지 더 잘 이해할 수 있습니다.

{% alert tip %}
워크스페이스에 있는 Canvases의 전체 목록을 확인하려면(예: 감사 목적) [Canvas 목록 내보내기 엔드포인트]({{site.baseurl}}/api/endpoints/export/canvas/get_canvases)를 사용하고 결과를 페이지네이션하세요.
{% endalert %}

## 버전 관리 {#managing-versions}

![버전 관리와 관련된 스크린샷.]({% image_buster /assets/img_archive/canvas_version_history.png %}){: style="float:right;max-width:35%;margin-left:15px;"}

새 버전을 생성하려면 **캔버스 업데이트**를 클릭합니다. 이렇게 하면 캔버스의 이전 설정을 덮어쓰지 않고 변경할 수 있습니다. 새 캔버스 버전이 생성되면 이미 캔버스에 있는 사용자는 새 버전의 워크플로를 따라 진행합니다. 캔버스에 진입하는 사용자도 새 버전으로 진입합니다.

버전 기록에 액세스하려면 캔버스 상단의 캔버스 세부 정보로 이동하여 **# Versions**를 선택합니다. 여기에서 **버전 기록** 사이드바에 액세스할 수 있습니다. 사이드바에서 캔버스 버전을 선택하여 캔버스 세부 정보를 확인하고 비교할 수 있습니다. 캔버스 분석과 캔버스 설정 간에 전환하려면 하단 도구 모음에서 **분석 보기** 또는 **Canvas 보기**를 클릭합니다.

{% alert note %}
**버전 기록**에 나열된 Canvases는 보기 전용입니다.
{% endalert %}

버전이 활성 상태인 동안 변경된 사항 목록을 보려면 버전 기록 사이드바에서 **변경 사항 보기**를 선택합니다. 캔버스 체인지로그에서 버전과 관련된 모든 변경 사항을 확인할 수도 있습니다.

캔버스를 시작한 후 두 번째 버전을 생성하기 전에 편집을 하지 않은 경우, 캔버스의 첫 번째 버전에 대한 **변경 사항 보기**에 변경 사항이 표시되지 않습니다.

버전 기록 수가 늘어나면 사이드바에서 각 버전의 이름을 변경하여 체계적으로 관리할 수 있습니다. 기본값으로 버전 이름은 이전에 생성된 버전 수를 기반으로 숫자로 생성됩니다. 더 이상 활성 상태가 아닌 버전의 이름을 변경하면 캔버스 체인지로그에는 표시되지만, 버전 기록 보기 내의 해당 버전 체인지로그에는 표시되지 않습니다.

![두 개의 새 캔버스 버전이 생성되었음을 보여주는 캔버스 체인지로그 예시.]({% image_buster /assets/img_archive/canvas_version_history_changelog.png %}){: style="max-width:85%" }

### 버전 삭제 {#discarding-versions}

캔버스당 최대 10개의 버전을 생성할 수 있습니다. 이 한도에 도달하면 버전을 삭제하여 새 버전을 위한 공간을 확보할 수 있습니다. 버전은 캔버스를 업데이트할 때가 아니라 **삭제**를 클릭할 때 삭제됩니다. 버전 삭제는 특정 버전의 체인지로그가 아닌 전체 캔버스 체인지로그에 반영됩니다.

버전을 삭제하면 캔버스 설정은 즉시 손실되지만, 삭제된 버전과 관련된 분석은 유지됩니다.

## 분석 보기 {#viewing-analytics}

버전 기록 내에서 캔버스 수준 및 단계 수준의 분석을 확인할 수 있습니다. 캔버스 버전 보기에서 데이터는 해당 버전의 기간만이 아닌 전체 날짜 범위에 대해 채워집니다. 그러나 단계 수준에서는 해당 버전이 활성 상태인 동안 존재했던 단계에 대한 분석만 표시됩니다. 이러한 분석은 회사의 시간대에 해당하는 캘린더 일 기준으로 채워지므로, 버전이 생성된 정확한 시각에 특정되지 않습니다.
