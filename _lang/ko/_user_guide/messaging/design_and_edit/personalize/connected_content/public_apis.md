# 연결된 콘텐츠를 위한 공개 API 사용 {#use-public-apis-for-connected-content}

> 연결된 콘텐츠에 사용할 수 있는 다양한 공개 API가 있습니다. 공개 API를 사용하면 메시지에 커스텀 데이터를 삽입할 수 있습니다. 이 페이지에서는 연결된 콘텐츠에 사용할 수 있는 공개 API 목록을 정리합니다. 하지만 이 외에도 다양한 연결된 콘텐츠 활용 가능성을 제공하는 더 많은 API가 있습니다.

공유하고 싶은 API가 있으시면 [success@braze.com](mailto:success@braze.com)으로 문의해 주세요!

{% alert note %}
공개 API에는 사용 제한 및 사용량 제한이 적용될 수 있습니다. API 설명서를 꼼꼼히 읽고, 의도한 사용 방법에 대해 API 제공업체에 문의하세요.
{% endalert %}
