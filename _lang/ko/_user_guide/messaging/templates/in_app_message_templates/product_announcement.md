# 제품 공지 {#product-announcement}

> 인앱 메시지 드래그 앤 드롭 에디터를 사용하여 신제품 출시에 대한 인지도를 높이세요.

{% multi_lang_include drag_and_drop/templates.md section='SDK requirements' %}

## 제품 공지 만들기 {#creating-a-product-announcement}

### 1단계: 템플릿 선택 {#step-1-choose-your-template}

드래그 앤 드롭 인앱 메시지를 만들 때 템플릿으로 **Product announcement**를 선택한 다음 **Build message**를 선택합니다. 이 템플릿은 모바일 앱과 웹 브라우저 모두에서 지원됩니다.

![제품 공지 템플릿이 적용된 인앱 메시지 에디터.]({% image_buster /assets/img/drag_and_drop/templates/product_announcement.png %})

### 2단계: 메시지 스타일 설정 {#step-2-set-up-your-message-styles}

{% multi_lang_include drag_and_drop/templates.md section='message style' %}

### 3단계: 버튼 구성요소 커스터마이즈 {#step-3-customize-your-button-component}

제품 공지를 만들기 시작하려면 에디터에서 버튼 구성요소를 선택합니다. 그런 다음 사이드 메뉴를 사용하여 사용자가 버튼을 선택했을 때 이동할 위치를 설정합니다. 기본값으로 템플릿은 메시지를 닫지만, 앱 내 특정 페이지(예: 공지에 소개된 제품 페이지)로 이동하도록 설정할 수 있습니다.

![버튼 요소를 커스터마이즈하기 위한 사이드 메뉴가 있는 인앱 메시지 에디터.]({% image_buster /assets/img/drag_and_drop/templates/product_announcement_button.png %})

**Pages** 섹션에서 제품 공지에 추가 메시지를 넣은 다음 순차적으로 연결할 수도 있습니다. 예를 들어, 제품의 기능을 간략히 설명하는 일련의 메시지를 구성하고 마지막에 사용자를 제품 페이지로 이동시키는 버튼으로 마무리할 수 있습니다. 자세한 방법은 [페이지 연결하기]({{site.baseurl}}/user_guide/channels/in_app_messages/drag_and_drop/?tab=adding%20pages#step-3a-connect-pages-together)에서 확인하세요.

### 4단계: 메시지 스타일링 {#step-4-style-your-message}

드래그 앤 드롭 [인앱 메시지 구성요소]({{site.baseurl}}/user_guide/channels/in_app_messages/customize/style_settings/#message-components)를 사용하여 제품 공지의 디자인과 느낌을 커스터마이즈하세요.
