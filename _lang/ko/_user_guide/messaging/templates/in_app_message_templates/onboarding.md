# 온보딩 플로우 {#onboarding-flow}

> **온보딩 플로우** 인앱 메시지 템플릿을 사용하여 Campaign 전략에 활용할 사용자 속성, 인사이트, 선호도를 수집하세요.

{% multi_lang_include drag_and_drop/templates.md section='SDK requirements' %}

## 온보딩 플로우 생성하기 {#creating-an-onboarding-flow}

### 1단계: 템플릿 선택 {#step-1-choose-your-template}

드래그 앤 드롭 인앱 메시지를 생성할 때 템플릿으로 **Onboarding flow**를 선택한 다음 **Build message**를 선택합니다. 이 템플릿은 모바일 앱과 웹 브라우저 모두에서 지원됩니다.

![온보딩 플로우 템플릿이 적용된 인앱 메시지 편집기.]({% image_buster /assets/img/drag_and_drop/templates/onboarding_editor.png %})

### 2단계: 메시지 스타일 설정 {#step-2-set-up-your-message-styles}

{% multi_lang_include drag_and_drop/templates.md section='message style' %}

### 3단계: 온보딩 플로우 순서 커스터마이즈 {#step-3-customize-the-order-of-your-onboarding-flow}

온보딩 플로우 구축을 시작하려면 **Pages** 섹션을 사용하여 플로우에 메시지를 추가하거나 삭제합니다. 원하는 수의 메시지를 설정한 후 각 페이지의 버튼을 선택합니다. 그런 다음 사이드 메뉴를 사용하여 사용자가 버튼을 선택했을 때 이동할 위치를 설정합니다. 플로우를 종료하거나 다음 메시지로 이동하도록 지정할 수 있습니다.

사용자가 플로우를 올바르게 진행할 수 있도록 메시지가 순차적으로 연결되어 있는지 확인하세요. 자세한 방법은 [페이지 연결하기]({{site.baseurl}}/user_guide/channels/in_app_messages/drag_and_drop/?tab=adding%20pages#step-3a-connect-pages-together)를 참조하세요.

### 4단계: 메시지 스타일 지정 {#step-4-style-your-message}

드래그 앤 드롭 [인앱 메시지 구성요소]({{site.baseurl}}/user_guide/channels/in_app_messages/customize/style_settings/#message-components)를 사용하여 온보딩 플로우의 디자인과 느낌을 커스터마이즈하세요.
