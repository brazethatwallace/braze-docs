# Braze Canvas 템플릿 사용 {#use-braze-canvas-templates}

> Braze에는 일반적인 사용 사례에 대한 모범 사례로 참조하고 사용할 수 있는 Canvas 템플릿이 준비되어 있습니다. 이러한 템플릿은 편집할 수 없지만, **콘텐츠** > **Canvas** > **Braze 템플릿**에서 확인하거나 Canvases에서 사용할 수 있습니다.

![Canvas 템플릿 섹션의 Braze 템플릿으로, 13개의 사용 가능한 템플릿이 표시되어 있습니다.]({% image_buster /assets/img/braze_canvas_templates.png %})

다음 사용 가능한 템플릿 중에서 선택하여 Canvas로 참조하거나 사용하세요.

## 표준 Canvas 템플릿 {#standard-canvas-templates}

{% tabs %}
{% tab Abandoned Intent %}

### 유기한 장바구니 {#abandoned-intent}

실시간으로 사용자와 소통하여 구매를 완료하도록 유도합니다.

이 템플릿을 사용할 때 다음 사항을 고려하세요:

- 진입 스케줄은 API 트리거 방식입니다. 사용자가 장바구니를 유기했을 때 [`/canvas/trigger/send` 엔드포인트]({{site.baseurl}}/api/endpoints/messaging/send_messages/post_send_triggered_canvases/)를 사용하여 사용자를 진입시키거나, 설정에 맞는 경우 **커스텀 이벤트 수행** 또는 **장바구니 업데이트 이벤트 수행**과 같은 트리거를 사용하는 행동 기반 스케줄로 전환하세요.
- 기본 전환은 **구매 완료(레거시)**를 추적합니다. 필요에 따라 전환 이벤트와 **구매 완료?** 행동 경로 단계를 특정 제품에 맞게 조정하세요.
- **구매 완료?** 행동 경로 단계에서 구매를 완료하면 사용자가 Canvas에서 퇴장합니다. 이 템플릿은 별도의 구매 후 여정이 있다고 가정합니다.
- Canvas에는 **항목별 리마인더** 이메일, 지연 단계, 이메일과 SMS를 위한 인텔리전트 채널 분할, Content Cards가 포함된 채널 메시지(이메일, SMS, 인앱 메시지), 그리고 오디언스 싱크 단계가 포함되어 있습니다. 파트너 및 오디언스와 함께 **광고 리타겟팅**을 구성하세요.

단계별 안내는 [유기한 장바구니]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/abandoned_cart/)를 참조하세요.

{% endtab %}
{% tab Back In Stock %}

### 재입고 {#back-in-stock}

개인화된 메시징을 통해 상품이 재입고되었음을 사용자에게 알려 구매를 유도합니다. 이 템플릿을 사용할 때 다음 사항을 고려하세요:

- **진입 스케줄**에서 사용할 카탈로그를 선택하세요. 이를 통해 제품, 할인, 프로모션 등의 데이터에 접근하여 사용자를 더 효과적으로 타겟팅할 수 있습니다.
- **타겟 오디언스**에서 특정 상품에 관심을 표시한 사용자를 타겟팅할 세그먼트를 추가하세요.
- Canvas 전체의 메시지 단계에서 카탈로그를 참조하도록 Liquid를 업데이트하세요.

{% endtab %}
{% tab Feature Adoption %}

### 기능 도입 {#feature-adoption}

적시에 개인화된 메시지를 전달하여 혜택과 사용 팁을 강조합니다. 이 템플릿을 사용할 때 다음 사항을 고려하세요:

- 이미 기능을 도입한 사용자를 제외하세요. 예를 들어, **타겟 오디언스**에서 이미 발생한 "기능 활성화"와 같은 커스텀 이벤트에 대한 필터를 추가하세요.
- 실험 경로 단계를 사용하려면 전환 이벤트를 정의하세요. 이 이벤트는 기능 도입을 나타내는 이벤트여야 합니다.
- 템플릿의 행동 경로 단계에 "기능 활성화" 및 "투어 완료"에 대한 커스텀 이벤트를 설정하세요.
- "피드백 설문조사"라는 이름의 메시지 단계에서 피드백의 감성을 캡처하기 위한 커스텀 속성을 설정하세요.

{% endtab %}
{% tab Lapsed User %}

### 이탈 사용자 {#lapsed-user}

과거 참여 이력을 기반으로 인센티브를 제공하여 사용자를 앱으로 다시 불러옵니다. 이 템플릿을 사용할 때 다음 사항을 고려하세요:

- **기본 설정**에서 전환을 추적할 특정 앱을 선택하세요.
- Canvas 편집기에서 행동 경로 단계에 특정 앱을 추가하세요.
- 사용 사례에 맞는 파트너 및 오디언스로 오디언스 싱크 단계를 구성하세요.

{% endtab %}
{% tab Onboarding %}

### 온보딩 {#onboarding}

초기 도입을 촉진하고 사용자와 지속적인 관계를 구축하는 온보딩 여정을 만드세요. 이 템플릿을 사용할 때 다음 사항을 고려하세요:

- "오디언스 분할"이라는 이름의 오디언스 경로 단계에서 참여 사용자를 위한 주요 동작을 커스터마이즈하는 것을 고려하세요. 템플릿에서 세그먼트 필터는 "환영 이메일 단계에서 이메일을 클릭함"입니다.

{% endtab %}
{% tab Post-Purchase Feedback %}

### 구매 후 피드백 {#post-purchase-feedback}

개인화된 경험을 오케스트레이션하여 피드백에 응답하고 사용자와의 관계를 구축합니다. 이 템플릿을 사용할 때 다음 사항을 고려하세요:

- Canvas 편집기의 첫 번째 단계에서:
    - 선택한 설문조사 옵션에 따라 피드백의 감성을 나타내는 인앱 메시지의 커스텀 속성을 지정하세요.
    - 선택된 옵션을 캡처하기 위해 각 행동 유도 버튼의 링크에 속성을 지정하세요. 이러한 속성은 후속 오디언스 경로에서 참조됩니다.
- 이 템플릿의 첫 번째 단계에서 가져온 속성으로 오디언스 경로를 커스터마이즈하세요.
- "광고 리타겟팅"이라는 이름의 오디언스 싱크 단계를 설정하세요.

{% endtab %}
