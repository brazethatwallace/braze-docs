# 랜딩 페이지 설문조사 {#landing-page-surveys}

> Braze 설문조사는 랜딩 페이지에서 피드백을 수집하여 분석하고 후속 메시징에 활용할 수 있습니다. 베타 기간 동안 설문조사는 [랜딩 페이지 드래그 앤 드롭 편집기]({{site.baseurl}}/user_guide/messaging/landing_pages/create_landing_pages/)에서 작성합니다.
