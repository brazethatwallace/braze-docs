# KakaoTalk 클릭 추적

> 이 페이지에서는 KakaoTalk 메시지에서 클릭 추적을 켜는 방법, 단축 링크를 테스트하는 방법, 추적 링크에 커스텀 도메인을 사용하는 방법 등을 다룹니다.

KakaoTalk 클릭 추적이 켜져 있으면 Braze가 자동으로 URL을 단축하고, 추적 메커니즘을 추가하며, 실시간으로 클릭을 기록합니다. 이 데이터를 활용하면 클릭 동작을 기반으로 사용자를 세분화하거나 특정 클릭에 대한 응답으로 메시지를 트리거하는 등 보다 타겟팅된 세분화 및 리타겟팅 전략을 수립할 수 있습니다.

KakaoTalk 클릭 추적은 텍스트, 이미지, 리스트 아이템 메시지에 사용할 수 있습니다. 버튼 내 링크와 이미지 클릭 시 동작을 지원합니다. Liquid 및 커스텀 도메인을 사용하여 URL을 개인화할 수도 있습니다.

## 작동 방식

메시지 작성기의 **링크 옵션** 섹션에서 KakaoTalk 클릭 추적 설정을 관리할 수 있습니다. 켜져 있으면 기본 Braze 도메인(`https://brz.ai`) 또는 구독 그룹에 지정된 커스텀 도메인을 사용하여 URL이 단축되고 사용자별로 개인화됩니다.

`http://` 또는 `https://`로 시작하는 모든 URL이 단축됩니다. 하나의 메시지에 최대 25개의 URL을 포함할 수 있습니다. Liquid 개인화(예: 사용자 수준 추적 또는 UTM 매개변수)가 포함된 단축 URL은 2개월 동안 유효합니다.

## 클릭 추적 설정

### 텍스트 메시지

텍스트 메시지에 대한 클릭 추적을 설정하려면:

1. **텍스트** 메시지를 작성하고 텍스트 필드 또는 버튼에 URL을 추가합니다.
2. 메시지 작성기의 **링크 옵션** 섹션에서 **클릭 추적**이 체크되어 있는지 확인합니다. 모든 새 메시지에는 기본적으로 클릭 추적이 켜져 있습니다.

![링크 옵션 섹션에서 클릭 추적이 체크된 KakaoTalk 텍스트 메시지 작성기.]({% image_buster /assets/img/kakaotalk/kakaotalk_text.png %})

### 이미지 메시지

이미지 메시지에 대한 클릭 추적을 설정하려면:

1. **이미지** 메시지를 작성하고 클릭 시 동작을 URL 열기로 설정합니다.
2. URL 필드에 URL을 입력합니다.
3. 메시지 작성기의 **링크 옵션** 섹션에서 **클릭 추적**이 체크되어 있는지 확인합니다.

### 리스트 아이템 메시지

리스트 아이템 메시지에 대한 클릭 추적을 설정하려면:

1. **리스트 아이템** 메시지를 작성하고 아이템의 **웹사이트 URL** 필드에 URL을 추가합니다.
2. 메시지 작성기의 **링크 옵션** 섹션에서 **클릭 추적**이 체크되어 있는지 확인합니다.

## 커스텀 도메인

KakaoTalk 클릭 추적을 사용하면 자체 도메인을 사용하여 단축 URL의 외관을 개인화할 수 있어 일관된 브랜드 이미지를 전달하는 데 도움이 됩니다. 자세한 내용은 [커스텀 도메인]({{site.baseurl}}/user_guide/message_building_by_channel/sms_mms_rcs/link_shortening/custom_domains)을 참조하세요.

## URL의 Liquid 개인화

Braze 메시지 작성기 내에서 URL을 동적으로 구성할 수 있어 URL에 동적 UTM 매개변수를 추가하거나 사용자에게 고유한 링크(예: 유기한 장바구니로 이동하거나 재입고된 특정 제품으로 이동)를 보낼 수 있습니다.

지원되는 모든 Liquid 개인화 태그를 사용하여 URL을 동적으로 생성할 수 있습니다.

{% raw %}
```
https://example.com/?campaign_utm={{campaign.${api_id}}}&user_attribute={{custom_attribute.${attribute1}}}
```
{% endraw %}

다음 예시와 같이 커스텀 정의된 Liquid 변수도 단축할 수 있습니다:

{% raw %}
```liquid
{% assign url_var = {{event_properties.${url_slug}}} %}
https://example.com/{{url_var}}
```
{% endraw %}

Braze는 API 트리거 등록정보에 포함된 URL을 포함하여 Liquid로 렌더링된 URL을 단축합니다. 예를 들어, {% raw %}`{{api_trigger_properties.${url_value}}}`{% endraw %}가 유효한 URL을 나타내는 경우 Braze는 KakaoTalk 메시지를 보내기 전에 해당 URL을 단축하고 추적합니다.

## 테스트

캠페인 또는 Canvas를 시작하기 전에 먼저 메시지를 미리보기하고 테스트하는 것이 좋습니다. 이를 위해 **테스트** 탭으로 이동하여 콘텐츠 테스트 그룹 또는 개별 사용자에게 KakaoTalk 메시지를 미리보기하고 보냅니다.

미리보기는 관련 개인화 및 단축 URL로 업데이트됩니다.

{% alert important %}
활성 Canvas 내에서 초안이 생성된 경우 단축 URL이 생성되지 않습니다. 실제 단축 URL은 Canvas 초안이 활성화될 때 생성됩니다.
{% endalert %}

## 보고

KakaoTalk 성과 테이블에는 배리언트별 클릭 이벤트 수와 관련 클릭률을 보여주는 **총 클릭 수** 열이 포함되어 있습니다. KakaoTalk 측정기준에 대한 자세한 내용은 [KakaoTalk 보고]({{site.baseurl}}/kakaotalk_reporting/)를 참조하세요.

클릭 데이터는 분석 대시보드에 자동으로 보고됩니다.

## 사용자 리타겟팅

다음 세분화 필터 및 트리거를 사용하여 KakaoTalk 메시지에서 URL을 클릭한 사용자를 리타겟할 수 있습니다:

- 동작 기반 트리거
    - 캠페인과 상호작용
    - 단계와 상호작용

- 세분화 필터
    - 캠페인 클릭/열기
    - 태그가 있는 캠페인 또는 Canvas 클릭/열기
    - 단계 클릭/열기

## 자주 묻는 질문

### 테스트 발송 시 받는 링크가 실제 URL인가요?

네, 테스트 발송 시 실제 URL이 생성됩니다. 다만, 시작된 캠페인에서 전송되는 정확한 URL은 테스트 발송에서 전송된 URL과 다를 수 있습니다.

### URL이 단축되기 전에 UTM 매개변수를 추가할 수 있나요?

네, 정적 및 동적 매개변수 모두 추가할 수 있습니다.

### 단축 URL은 얼마나 오래 유효한가요?

개인화된 URL은 URL 등록 시점부터 2개월 동안 유효합니다.

### URL을 단축하려면 Braze SDK를 설치해야 하나요?

아니요, 클릭 추적은 SDK 통합 없이도 작동합니다.

### 어떤 개별 사용자가 URL을 클릭했는지 알 수 있나요?

네. 클릭 추적이 켜져 있으면 [KakaoTalk 리타겟팅 필터](#retargeting-users)를 사용하여 URL을 클릭한 사용자를 리타겟할 수 있습니다.

### 클릭 추적이 딥링크 또는 유니버설 링크에서도 작동하나요?

클릭 추적은 웹 URL에 적용됩니다. 딥링크의 경우 KakaoTalk 버튼의 클릭 시 동작 유형으로 딥링크를 직접 설정할 수 있으며, 이 경우 URL 단축이나 클릭 추적을 거치지 않습니다. Branch나 Appsflyer와 같은 제공업체의 유니버설 링크를 사용하려는 경우 단축은 가능하지만, 발생할 수 있는 문제(예: 기여도 손상 또는 리디렉션 실패)에 대해 Braze는 문제 해결을 지원할 수 없습니다.
