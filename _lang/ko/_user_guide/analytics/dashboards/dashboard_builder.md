# 대시보드 빌더 {#dashboard-builder}

> 대시보드 빌더를 사용하여 보고서 빌더 또는 쿼리 빌더에서 생성한 보고서를 활용해 대시보드와 시각화를 만들 수 있습니다.

대시보드 빌더를 사용하면 처음부터 또는 Braze에서 제공하는 대시보드를 기반으로 커스텀 분석 대시보드를 작성하고 시각화할 수 있습니다. 코드 없는 데이터 소스(보고서 빌더) 또는 SQL 데이터 소스(쿼리 빌더)를 사용하여 대시보드를 구동하거나, Braze에서 제공하는 다양한 대시보드 중 하나에서 시작할 수 있습니다.

## 커스텀 대시보드 생성 {#creating-a-custom-dashboard}

1. **Analytics** > **대시보드 빌더**로 이동합니다.
2. **대시보드 생성**을 선택합니다.
3. 보고서를 구동할 데이터 소스를 선택합니다:
- 보고서 빌더에서 구축한 **보고서**
- 쿼리 빌더에서 생성한 **커스텀 쿼리**<br><br>![대시보드의 데이터 소스를 선택하는 창.]({% image_buster /assets/img/select_data_source.png %})<br><br>

이제 데이터 소스에 맞는 각 단계를 따르세요:

{% tabs %}
{% tab Reports %}

{: start="4"}
4. **+ 타일 추가**를 선택한 다음 [보고서 빌더(신규)]({{site.baseurl}}/user_guide/analytics/reports/report_builder/)에서 생성한 보고서 중 하나를 선택합니다.

{% alert important %}
보고서 빌더 보고서가 대시보드 빌더 타일에 추가된 후에는 타일이 원본 보고서와 연결되지 않습니다. 보고서 빌더에서 원본 보고서를 편집한 경우, 기존 대시보드 타일을 삭제하고 업데이트된 보고서를 데이터 소스로 사용하여 새 타일을 생성해야 합니다.
{% endalert %}

{: start="5"}
5. 연필 아이콘을 선택하여 타일에 표시되는 제목과 차트 유형을 변경합니다.
    - 기본 시각화 아래에서 다양한 차트 유형 간에 토글할 수 있습니다. 현재 옵션에는 막대 차트(가로 또는 세로)와 꺾은선 차트(보고서 빌더 설정에서 **날짜**를 드릴다운 옵션으로 선택한 경우에만 사용 가능)가 포함됩니다.<br><br>![다양한 차트 유형에 대한 토글.]({% image_buster /assets/img/report_builder_types.png %})<br><br>
    - 측정기준 드롭다운을 사용하여 시각화에 포함할 측정기준을 선택합니다. 기본적으로 보고서의 첫 번째 열이 기본 표시 측정기준이 됩니다.
6. 시각화를 원하는 대로 변경한 후 **저장**을 선택합니다.
7. 나중에 대시보드를 쉽게 찾을 수 있도록 이름, 설명, 태그를 추가합니다.
{% endtab %}
{% tab Custom Queries %}
{: start="4"}
4. **+ 타일 추가**를 선택한 다음 쿼리 빌더에서 실행한 쿼리를 선택합니다.
5. 타일에 쿼리 결과가 표시되는 방식을 편집하려면 연필 아이콘을 선택하여 제목과 차트 유형을 변경합니다.
    - 기본 시각화 아래에서 다양한 차트 유형 간에 토글할 수 있습니다. 현재 옵션에는 테이블, 막대 차트(가로 또는 세로), 꺾은선 차트가 포함됩니다.<br><br>![다양한 차트 유형에 대한 토글.]({% image_buster /assets/img/query_builder_types.png %})<br><br>
        - 차트 옵션 중 하나를 선택한 경우, **X축** 드롭다운을 사용하여 쿼리 결과에서 X축으로 사용할 단일 열을 선택합니다.
        - **Y축** 드롭다운을 사용하여 시각화에 포함할 측정기준을 선택합니다. 기본적으로 쿼리 결과의 모든 열이 표시되므로, 보고 싶지 않은 열은 선택을 해제합니다.<br><br>![다양한 차트 유형에 대한 토글.]({% image_buster /assets/img/query_builder_axis.png %})<br><br>
        - (선택 사항) **그룹화** 드롭다운을 사용하여 쿼리 결과를 그룹화할 수 있습니다. 예를 들어, Campaign ID가 열 결과에 있고 해당 값을 가진 모든 행을 합산하려면 **그룹화** 드롭다운을 사용합니다.
        - (선택 사항) 표시되는 데이터를 편집하려면 시각화에 연결된 쿼리를 선택하고 [쿼리 빌더]({{site.baseurl}}/user_guide/analytics/reports/query_builder/)에서 편집합니다.
6. 시각화를 원하는 대로 변경한 후 **저장**을 선택합니다.
7. 나중에 대시보드를 쉽게 찾을 수 있도록 이름, 설명, 태그를 추가합니다.
{% endtab %}
{% endtabs %}

8. 원하는 대시보드를 만들 때까지 해당 방법에 맞게 4~7단계를 반복합니다.
9. **대시보드 보기** > **대시보드 실행**을 선택합니다.

대시보드 보고서 생성이 완료되기까지 몇 분이 걸릴 수 있습니다.

{% alert note %}
대시보드에 최대 10개의 타일을 추가할 수 있습니다.
{% endalert %}

## 대시보드 타일 관리 {#managing-dashboard-tiles}

### 타일 삭제 {#delete-tiles}

타일 하단의 **타일 삭제**를 선택하여 대시보드 타일을 삭제합니다. **이 동작은 되돌릴 수 없습니다.**

### 타일 복제 {#duplicate-tiles}

타일 하단의 **타일 복제**를 선택하여 타일의 사본을 만듭니다.

### 타일 크기 및 위치 조정 {#adjust-tile-size-and-position}

타일의 오른쪽 하단 모서리를 드래그하여 타일 크기를 조정하고, 타일의 오른쪽 상단 모서리에 있는 핸들을 드래그하여 대시보드에서 타일 위치를 조정합니다.

## 대시보드 실행 {#running-a-dashboard}

1. **Analytics** > **대시보드 빌더**로 이동합니다. 홈 페이지에는 워크스페이스 내의 모든 기존 대시보드가 나열되며, Braze에서 생성한 대시보드가 상단에 표시됩니다. 이러한 대시보드는 제목에 "(Braze)"로 표시됩니다.
2. 관심 있는 대시보드를 선택합니다.
3. **대시보드 실행**을 선택하여 해당 대시보드를 로드합니다.

### 사용 가능한 대시보드 {#available-dashboards}

Braze는 라스트 터치 기여도를 사용한 매출 분석과 같은 자주 사용되는 활용 사례를 위해 사전 구축된 대시보드를 제공합니다. 대시보드 편집 기능은 아직 사용할 수 없습니다. 향후 특정 대시보드를 보고 싶으시면 고객 성공 매니저에게 문의하세요.

#### 매출 - 라스트 터치 기여도 {#revenue-last-touch-attribution}

**매출 - 라스트 터치 기여도** 대시보드는 Campaign, Canvases, 채널 전반의 매출을 검토합니다. 모든 매출 데이터는 기여도 기간 동안 마지막으로 터치된 메시지에 귀속됩니다.

터치에는 _이메일 클릭_(링크 클릭), _콘텐츠 카드 클릭_, _인앱 메시지 클릭_(닫기 버튼 제외), _푸시 열기_, _SMS 단축 링크 클릭_, _WhatsApp 읽음_, _웹훅 전송_이 포함됩니다.

| 측정기준 | 정의 |
| --- | --- |
| 총 라스트 터치 매출 | 선택한 날짜 범위 및 기여도 기간 내에 라스트 터치 이벤트가 있는 모든 Campaign 및 Canvas 매출 이벤트의 합계입니다. |
| 총 구매 전환 | 적격한 라스트 터치 이벤트가 있는 모든 Campaign 및 Canvas 매출 이벤트의 수입니다. |
| 평균 전환 소요 일수 | 적격한 라스트 터치 이벤트가 있는 모든 Campaign 및 Canvas 구매 이벤트 간의 평균 시간입니다. |
| 수신자당 매출 | 적격한 매출 이벤트의 매출 합계를 날짜 범위 내에 메시지를 수신한 고유 사용자 수로 나눈 값입니다. |
| 고유 구매자 | 적격한 매출 이벤트가 있는 고유 사용자 수입니다. |
| 국가별 매출 | 라스트 터치 이벤트가 있는 모든 Campaign 및 Canvas 매출 이벤트의 합계로, 국가별로 그룹화됩니다. |
| Campaign별 매출 | 적격한 라스트 터치 이벤트가 있는 모든 Campaign 및 Canvas 매출 이벤트의 합계로, Campaign별로 그룹화됩니다. |
| 캠페인 배리언트별 매출 | 적격한 라스트 터치 이벤트가 있는 모든 Campaign 및 Canvas 매출 이벤트의 합계로, 캠페인 배리언트별로 그룹화됩니다. |
| Canvas별 매출 | 적격한 라스트 터치 이벤트가 있는 모든 Campaign 및 Canvas 매출 이벤트의 합계로, Canvas별로 그룹화됩니다. |
| 캔버스 배리언트별 매출 | 적격한 라스트 터치 이벤트가 있는 모든 Campaign 및 Canvas 매출 이벤트의 합계로, 캔버스 배리언트별로 그룹화됩니다. |
| 제품별 구매 | 제품별로 그룹화된 모든 구매 수입니다. |
| 채널별 매출 | 적격한 라스트 터치 이벤트가 있는 모든 Campaign 및 Canvas 매출 이벤트의 합계로, 채널별로 그룹화됩니다. |
| 매출 시계열 | 적격한 라스트 터치 이벤트가 있는 모든 Campaign 및 Canvas 매출 이벤트의 합계로, UTC 기준 일별로 그룹화됩니다. |

#### 세션 분석 {#session-analytics}

| 측정기준 | 정의 |
|---|---|
| 일별 세션 수(시계열) | 선택한 날짜 범위 내에서 일별로 그룹화된 고유 세션 수로, 시계열로 표시됩니다. |
