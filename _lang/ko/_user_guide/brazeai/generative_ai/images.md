# BrazeAI로 이미지 생성하기 {#generate-images-with-brazeai}

> {% multi_lang_include brazeai/generative_ai/about_images.md %}

## 미디어 라이브러리 소개 {#about-the-media-library}

미디어 라이브러리를 사용하면 자산을 하나의 중앙 위치에서 관리할 수 있습니다. Braze 미디어 라이브러리에 액세스하려면 **콘텐츠** > **미디어 라이브러리**로 이동하세요. 자세한 내용은 [미디어 라이브러리]({{site.baseurl}}/user_guide/messaging/design_and_edit/media_library/)를 참조하세요.

## 이미지 생성하기 {#generating-an-image}

1. 미디어 라이브러리로 이동한 다음 <i class="fas fa-wand-magic-sparkles"></i> **AI Image Generator**를 선택합니다.
2. 생성하려는 이미지에 대한 설명을 300자 이내로 입력하세요. 설명이 자세할수록 더 좋은 결과를 얻을 수 있습니다. 이 기능은 텍스트 입력만 지원하며, 참조용으로 이미지를 업로드하는 것은 지원되지 않습니다.
3. **Generate Images**를 선택합니다. 이미지가 생성되기까지 약 1분 정도 걸릴 수 있습니다.
4. 미디어 라이브러리에 추가하려는 이미지에서 <i class="fas fa-download" title="미디어 라이브러리에 이미지 추가"></i>를 선택합니다.
