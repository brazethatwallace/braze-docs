# 카피 생성 {#generate-copy}

> Operator를 사용하여 SMS, 푸시, Canvas 메시지용 마케팅 카피를 생성하세요. 제품이나 Campaign을 설명하고, 필요한 경우 톤을 포함하면 Operator가 카피 초안을 작성하여 검토 후 메시지 작성기에 바로 삽입할 수 있습니다.
