# Decisioning Studio Go 예제 {#examples-for-decisioning-studio-go}

> Decisioning Studio Go는 에이전트가 인게이지먼트로부터 학습할 시간이 있고, 콘텐츠에 의미 있는 개인화를 위한 충분한 배리언트 옵션이 포함된 반복적인 이메일 프로그램에 가장 적합합니다. 이 페이지에서는 일반적인 이메일 사용 사례를 적합도 수준별로 분류하고, 각각에 대한 예제와 가이드를 제공합니다.

Decisioning Studio Go의 작동 방식에 대한 개요는 [BrazeAI Decisioning Studio Go]({{site.baseurl}}/user_guide/brazeai/decisioning_studio/decisioning_studio_go)를 참조하세요.

이 가이드의 각 예제에는 다음 적합도 수준 중 하나가 표시됩니다.

| 적합도 수준 | 설명 |
|---|---|
| **최적** | 에이전트가 학습할 충분한 시간이 있고, 오디언스가 리프트를 보여줄 만큼 안정적이며, 개인화가 인게이지먼트에 의미 있는 영향을 줄 수 있습니다. 여기서 시작하세요. |
| **지원됨** | 예제가 잘 작동할 수 있지만, 성공 여부는 타이밍, 오디언스 규모 또는 시퀀싱에 따라 달라집니다. 적용하기 전에 고려 사항을 검토하세요. |
| **권장하지 않음** | 예제가 에이전트의 학습 방식과 충돌합니다. 다른 프로그램 유형을 선택하거나, 고객 성공 매니저 또는 솔루션 컨설턴트에게 다른 설정에 대해 문의하세요. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="적합도 수준" }

{% alert note %}
모든 적합도 수준에서 에이전트는 오디언스가 알고리즘이 패턴을 감지할 수 있을 만큼 충분한 인게이지먼트 신호를 생성할 때 가장 잘 학습합니다. 일반적인 기준으로, 수만 명 이상의 사용자를 대상으로 하고 일관된 주간 발송량을 유지하세요. 에이전트는 더 작은 오디언스에서도 실행할 수 있지만, 학습 기간이 길어지고 리프트의 신뢰도가 낮아질 수 있습니다. 고객 성공 매니저 또는 솔루션 컨설턴트가 특정 오디언스의 규모가 적절한지 확인하는 데 도움을 줄 수 있습니다.
{% endalert %}

## 최적 적합 사례 {#best-fit}

### 상시 캘린더 기반 Campaigns {#always-on-calendared-campaigns}

| 주제 | 세부 사항 |
|---|---|
| 어떤 모습인가요 | 수개월 이상 운영되며 시간이 지남에 따라 콘텐츠를 교체하는 마케팅 캘린더입니다. 예를 들어 리워드 회원 캘린더, 콘텐츠 드롭 스케줄, 라이프스타일 또는 영감 캘린더 등이 있습니다. |
| 왜 적합한가요 | 장기 프로그램은 에이전트가 각 사용자에게 효과적인 것을 학습할 충분한 시간을 제공합니다. 오디언스가 안정적이고, 콘텐츠가 정기적으로 갱신되며, 클릭은 보통 인게이지먼트의 의미 있는 지표입니다. |
| 무엇을 준비해야 하나요 | 로테이션에 사용할 수 있는 여러 기본 크리에이티브 또는 배리언트 세트를 준비합니다. 에이전트가 각 사용자에게 적합한 버전을 선택하지만, 제공하는 옵션에 충분한 다양성이 필요합니다. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="상시 캘린더 기반 Campaigns" }

### 에버그린 프로그램 {#evergreen-programs}

| 주제 | 세부 사항 |
|---|---|
| 어떤 모습인가요 | 특정 날짜나 이벤트에 묶이지 않는 지속적인 Campaigns입니다. 윈백, 재참여 프로그램, 휴면 계정 넛지, 마일스톤 축하 등이 해당됩니다. |
| 왜 적합한가요 | 캘린더 기반 Campaigns와 마찬가지로 오디언스는 동적이지만 프로그램은 무기한 운영됩니다. 에이전트에게 학습 시간이 있고, 콘텐츠에 유연성이 있으며, 클릭은 에이전트가 최적화할 수 있는 선행 지표입니다. |
| 무엇을 준비해야 하나요 | 다양한 동기에 맞게 메시지를 구성할 수 있는 제목란과 CTA의 배리언트 옵션을 준비합니다. 이미지 배리언트가 있으면 도움이 됩니다. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="에버그린 프로그램" }

## 지원되는 사용 사례 {#supported-use-cases}

### 다중 이메일 프로모션 {#multi-email-promotions}

| 주제 | 세부 사항 |
|---|---|
| 어떤 형태인지 | 동일한 프로모션 테마 아래 수 주에 걸쳐 발송되는 일련의 이메일입니다. 예를 들어 개학 시리즈나 여러 주에 걸친 카테고리 프로모션이 있습니다. |
| 효과적인 이유 | 프로모션이 최소 수 주 이상 충분히 길게 운영되면, 에이전트가 프로모션 기간 내에 학습할 수 있는 충분한 시간을 확보합니다. 클릭률은 일반적으로 프로모션 인게이지먼트의 강력한 선행 지표입니다. |
| 고려 사항 | 프로모션 기간이 짧으면 프로그램이 종료되기 전에 에이전트가 학습하기에 충분한 데이터 일수를 확보하지 못할 수 있습니다. 일반적인 가이드라인으로, 에이전트가 강력한 추천을 개발하려면 최소 10일의 Campaign 데이터가 필요합니다. 프로모션이 그보다 짧다면 에버그린 프로그램이 학습을 대신 수행할 수 있는지 검토한 후, 학습한 내용을 다음 프로모션에 적용하는 것을 고려하세요. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="다중 이메일 프로모션" }

### 액션 또는 이벤트 기반 여정 {#action-or-event-driven-journeys}

| 주제 | 세부 사항 |
|---|---|
| 어떤 형태인지 | 고객 액션(장바구니 유기, 탐색 이탈, 구매 후 후속 조치 등)에 의해 트리거되는 단일 이메일 또는 이메일 시퀀스입니다. |
| 효과적인 이유 | 트리거가 깔끔한 진입 지점을 만들어 줍니다. 여정이 반복적이고 오디언스 볼륨이 일정하면, 에이전트가 어떤 콘텐츠가 어떤 사용자에게 효과적인지 학습할 수 있습니다. |
| 고려 사항 | 타이밍이 중요합니다. 트리거 이벤트 후 몇 분 이내에 이메일을 발송해야 하는 경우, 고객 성공 매니저 또는 솔루션 컨설턴트와 협의하여 에이전트의 발송 스케줄이 호환되는지 확인하세요. 사용자가 특정 순서로 이메일을 받아야 하는 경우(이메일 A를 이메일 B보다 먼저), 오디언스 이동을 직접 오케스트레이션해야 합니다. 에이전트는 다중 이메일 여정에서 단일 사용자에 대한 발송 순서를 조율하지 않습니다. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="액션 또는 이벤트 기반 여정" }

## 비추천 {#not-recommended}

### 드립 시퀀스 {#drip-sequences}

| 주제 | 세부 정보 |
|---|---|
| 어떤 형태인지 | 다중 이메일 시퀀스—예를 들어 온보딩 튜토리얼—에서 사용자가 이메일 A, 이메일 B, 이메일 C를 순서대로 수신해야 하는 경우입니다. |
| 적합하지 않은 이유 | 에이전트는 각 사용자에게 클릭을 유도할 가능성이 높은 콘텐츠를 선택합니다. 시퀀스 요구 사항을 모델링하지 않습니다. 특정 순서를 강제해야 하는 경우, 각 이메일 발송 후 사용자를 Segment에서 Segment로 이동시키는 등 오디언스를 직접 조율해야 하며, 이는 에이전트 사용의 이점을 대부분 줄이게 됩니다. 또한 에이전트는 이메일 B를 보내기 전에 이메일 A가 성공했는지 독립적으로 확인할 수 없습니다. |
| 대신 사용할 방법 | [Canvas]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas)를 사용하여 드립을 조율하세요. 드립 내에서 AI 최적화를 원한다면, 고객 성공 매니저 또는 솔루션 컨설턴트에게 [Decisioning Studio Pro]({{site.baseurl}}/user_guide/brazeai/decisioning_studio/get_started)가 더 적합한지 문의하세요. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="드립 시퀀스" }

### 일회성 이메일 대량 발송 {#one-time-email-blasts}

| 주제 | 세부 정보 |
|---|---|
| 어떤 형태인지 | 단일 이메일을 한 번에 대량 발송하는 경우—블랙 프라이데이 안내, 신제품 출시, 또는 일회성 기업 커뮤니케이션 등입니다. |
| 적합하지 않은 이유 | 에이전트는 학습할 시간이 필요합니다. 단일 발송은 Campaign이 종료되기 전에 의사 결정을 개선할 기회를 제공하지 않습니다. 더 나은 선택을 할 수 있을 만큼 충분한 인게이지먼트 신호가 모이는 시점에는 이미 프로그램이 끝나 있습니다. |
| 대신 사용할 방법 | 유사한 콘텐츠를 가진 상시 프로그램이 있다면—예를 들어, 연중 운영되는 제품 안내 프로그램—Decisioning Studio Go를 활용하고 학습한 내용을 일회성 발송에 적용하세요. 일회성 발송의 경우, A/B 테스트를 위해 [BrazeAI<sup>TM</sup>로 최적화]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/variant_selection)를 사용하세요. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="일회성 이메일 대량 발송" }

## 한눈에 보기 {#at-a-glance}

| 시나리오 | 적합도 | 주요 고려 사항 |
|---|---|---|
| 상시 운영 캘린더 기반 캠페인 | 최적 | 시간이 지남에 따라 교체할 수 있도록 여러 기본 크리에이티브 또는 배리언트 세트를 제공하세요. |
| 에버그린 프로그램(윈백, 재참여) | 최적 | 동일한 메시지를 다양한 동기에 맞게 구성하는 배리언트 옵션을 제공하세요. |
| 다중 이메일 프로모션 | 지원됨 | 최소 10일 이상의 Campaign 운영 기간을 확보하세요. 프로모션 기간이 짧으면 학습이 제한됩니다. |
| 액션 또는 이벤트 기반 여정 | 지원됨 | 발송 타이밍 요건을 확인하세요. 시퀀스 적용은 사용자가 직접 관리해야 합니다. |
| 드립 시퀀스(온보딩 튜토리얼) | 권장하지 않음 | 시퀀싱에는 Canvas를 사용하세요. 드립 내 최적화에 대해서는 Decisioning Studio Pro를 검토하세요. |
| 일회성 이메일 발송 | 권장하지 않음 | 대신 BrazeAI<sup>TM</sup>를 활용한 최적화로 A/B 테스트를 진행하세요. |

## 다음 단계 {#next-steps}

프로그램이 적합한지 확실하지 않다면 Braze 고객 성공 매니저 또는 솔루션 컨설턴트에게 문의하세요. 다음과 같은 강력한 신호가 있습니다:

- 오디언스가 한 달 이상의 기간 동안 최소 주 1회 이상 정기적으로 이메일을 수신합니다.
- 오디언스가 일관된 인게이지먼트 신호를 생성할 수 있을 만큼 충분히 큽니다(수만 명의 사용자가 유용한 시작 목표입니다).
- 제공할 수 있는 의미 있는 배리언트 옵션이 최소 두세 가지 있습니다(제목란, CTA, 또는 메시지를 다르게 구성하는 이미지 등).
- 클릭이 이 프로그램의 비즈니스 가치를 나타내는 선행 지표이며, 단순한 허영 지표가 아닙니다.
- 해당 Segment가 동일한 사용자의 인게이지먼트를 놓고 경쟁하는 다른 Canvas 또는 Campaign에서 적극적으로 사용되고 있지 않습니다.
