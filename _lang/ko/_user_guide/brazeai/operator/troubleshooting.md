# BrazeAI Operator 문제 해결 {#troubleshooting-brazeai-operator}

> BrazeAI Operator<sup>TM</sup>에 대한 일반적인 문제 및 해결책.

## 일반적인 문제 {#common-issues}

| 문제 | 문제 해결 |
| --- | --- |
| 응답 없음 | 페이지를 새로고침하고 Operator 패널을 다시 열어 보세요. |
| 주제와 관련 없는 답변 | 질문을 더 구체적으로 다시 작성하세요. 질문하려는 기능이나 워크플로를 명시하세요. |
| 오류 메시지 | Operator가 콘텐츠를 스트리밍할 수 없는 경우 "다시 시도" 프롬프트가 나타날 수 있습니다. Operator가 일시적으로 사용할 수 없거나 연결이 중단된 것일 수 있습니다. 몇 분 후에 다시 시도하세요. |
| 일일 한도 도달 | 회사 전체의 일일 사용 한도에 도달했습니다. 모든 Operator 작업이 이 한도에 포함됩니다. 한도가 초기화될 때까지 기다리세요(24시간마다 초기화). 웹 양식을 통해 고객지원 티켓을 제출할 수 있습니다. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="일반적인 문제" }

Operator가 대시보드에서 할 수 있는 것과 할 수 없는 것에 대해서는 [제한 사항]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#limitations)을 참조하세요.
