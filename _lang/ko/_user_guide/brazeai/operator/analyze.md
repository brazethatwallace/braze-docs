# Operator 분석 {#operator-analyze}

> Operator 분석은 BrazeAI Operator<sup>TM</sup>에서 자연어 성과 질문에 답변합니다. 응답에는 차트, 비교, 간단한 인사이트가 포함됩니다. 대시보드를 구축하거나 전체 보고서를 먼저 가져올 필요가 없습니다.

{% alert important %}
Operator 분석은 현재 베타 버전입니다. 기능과 지원되는 분석은 계속 발전하고 있습니다. 계정 액세스를 요청하려면 고객 성공 매니저에게 문의하세요.
{% endalert %}

## Operator 분석을 사용하는 이유 {#why-use-operator-analyze}

대부분의 성과 관련 질문은 여전히 도구를 전환하거나, 뷰를 구축하거나, 다른 사람을 기다려야 합니다. 예를 들어 "지난주 성과는 어땠나요", "벤치마크 대비 잘하고 있나요", "어떤 Campaign이 가장 좋은 결과를 내고 있나요?" 같은 질문이 있습니다.

Operator 분석은 참여 측정기준, *기여 매출*, 업계 벤치마크를 다룹니다. 이는 보고서나 대시보드에서 가져오는 것과 동일한 데이터입니다. Operator 패널에서 자유롭게 질문하세요. 차트, 순위 비교 또는 테이블과 함께 1~5개의 유용한 인사이트를 받을 수 있습니다.

## Operator 분석에 접근하기 {#access-operator-analyze}

Operator 분석은 Operator 대화 패널에서 실행됩니다.

1. Braze 대시보드의 아무 페이지에서 고객 프로필 옆에 있는 **BrazeAI Operator<sup>TM</sup>**를 선택합니다.
2. 채널 참여 또는 벤치마크 비교에 대해 질문합니다([질문 예시](#example-questions) 참조).
3. Operator가 답변을 반환하며, 도움이 되는 경우 차트 또는 테이블과 간단한 인사이트 목록을 함께 제공합니다.

Operator 채팅 패널에 대한 자세한 내용은 [BrazeAI Operator]({{site.baseurl}}/user_guide/brazeai/operator/)를 참조하세요.

## 시각화 {#visualizations}

Operator는 데이터가 뒷받침될 때 차트를 추가합니다. **꺾은선형 차트**는 시계열에, **막대 차트**는 카테고리 비교에, **테이블**은 기타 경우에 적합합니다. 테이블은 백분율을 소수점 둘째 자리까지 표시하고 큰 숫자에는 쉼표를 사용합니다.

응답에 여러 측정기준이 포함된 경우, Operator는 원시 수치보다 참여율(*열람률*, *클릭률*, *푸시 열람률*)을 우선합니다.

## 지원되는 채널 및 측정기준 {#supported-channels-and-metrics}

*기여 매출*과 *전환*은 [질문 예시](#example-questions)의 **매출 및 전환** 탭에 표시된 것과 동일한 Campaign, Canvas, 채널, 프로그램 집계를 사용합니다.

| 채널 | 측정기준 | 업계 벤치마크 |
| --- | --- | --- |
| 이메일 | *발송*, *전달*, *고유 열람*, *고유 클릭*, *탈퇴* | 예 |
| 푸시 (iOS, Android, 웹) | *발송*, *전달*, *열람* | 예 |
| SMS | *발송*, *전달*, *링크 클릭* | 예 |
| In-App Messages | *노출 횟수*, *클릭 수* | 예 |
| Content Cards | *발송*, *노출 횟수*, *클릭 수* | 예 |
| WhatsApp | *발송*, *전달*, *읽음*, *클릭 수* | 아직 미지원 |
| RCS | *발송*, *전달*, *읽음*, *클릭 수* (텍스트 URL, 버튼, 동작, 답장 동작, 답장 버튼 하위 유형 포함) | 아직 미지원 |
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3 aria-label="지원되는 채널, 측정기준, 벤치마크 제공 여부" }

{% alert tip %}
Operator는 비율에 고유 수치를 사용합니다(예: *이메일 열람률*의 경우 *고유 열람*을 *전달*로 나눔). 수치가 대시보드와 다른 경우, 기여도 기간, 시간 범위, 정의를 비교하세요. Operator는 각 응답에 세 가지를 모두 표시합니다.
{% endalert %}

## 기간 및 기여도 기간 {#time-periods-and-attribution-windows}

### 회계연도 vs. 역년 {#fiscal-year-vs-calendar-year}

Operator 분석은 기본적으로 2월 1일부터 1월 31일까지인 **Braze 회계연도**를 사용합니다.

| 회계 분기 | 월 |
| --- | --- |
| FQ1 | 2월 – 4월 |
| FQ2 | 5월 – 7월 |
| FQ3 | 8월 – 10월 |
| FQ4 | 11월 – 1월 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Braze 회계 분기 및 해당 월" }

역년 관련 질문에는 "CY", "calendar year" 또는 "standard year"를 포함하세요. 모호한 "last year" 프롬프트의 경우 Operator가 어떤 캘린더를 의미하는지 확인합니다.

`Q4 2025` 또는 `2025-03-01 to 2025-05-31`과 같은 ISO 형식 범위도 사용할 수 있습니다.

### 기여도 기간 {#attribution-windows}

Operator 분석의 기본값은 **7일**입니다. 질문에 기간을 명시하면 재정의할 수 있습니다:

* **1일** — 빠른 참여 확인용
* **3일** — 단기 Campaign용
* **7일** — 일반 개요 및 Campaign 분석용 (기본값)
* **30일** — 전략적 또는 장기적 관점용
* **모든 기간** — 1일 / 3일 / 7일 / 30일 나란히 비교

기간별 결과가 50% 이상 차이나면 Operator가 네 가지를 모두 나란히 표시합니다.

## 데이터 최신성 {#data-freshness}

데이터는 매일 새로고침됩니다. 당일 활동은 다음 새로고침 후에 표시됩니다. 각 응답에는 데이터셋의 최신 날짜가 명시됩니다. 해당 날짜가 오래된 것으로 보이면 고객 성공 매니저에게 문의하세요.

## 범위 밖 항목 {#whats-out-of-scope}

* **제품 수준 성과 분석.** *기여 매출*과 참여는 Campaign, Canvas, 채널 또는 프로그램 수준으로 집계됩니다. 제품이나 SKU별로 분류되지 않습니다. 제품 또는 SKU 수준 질문은 지원되지 않습니다. 해당 분석이 필요하면 고객 성공 매니저에게 문의하세요.
* **WhatsApp 및 RCS의 업계 벤치마크.** 두 채널의 참여 측정기준은 지원됩니다. 벤치마크는 아직 제공되지 않습니다.

범위 밖 질문에는 직접적인 답변, 가능한 경우 대안 제안, 또는 고객 성공 매니저 안내가 제공됩니다.

## 더 나은 결과를 위한 팁 {#tips-for-better-results}

* **시간 범위:** 정확성이 필요할 때는 "last quarter" 같은 모호한 표현보다 명시적인 범위("FY26 Q2", "지난 90일")를 사용하세요.
* **측정기준:** 관심 있는 비율(*열람률*, *클릭률*, *클릭 대비 열람률*)을 명시하세요. Operator가 사용한 공식을 보고합니다.
* **후속 질문:** 결과를 상세히 분석하거나, 기간을 변경하거나, 채널을 전환하세요. Operator는 스레드 전체에서 컨텍스트를 유지합니다.
* **채널 표현:** WhatsApp과 RCS는 *읽음률*(*열람률*이 아님)을 사용합니다. SMS는 *링크 클릭률*을 사용합니다.
* **복합 질문:** 벤치마크와 트렌드를 하나의 프롬프트로 함께 질문할 수 있습니다.
