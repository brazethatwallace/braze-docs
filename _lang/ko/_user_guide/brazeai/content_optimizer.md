# 콘텐츠 최적화 프로그램 {#content-optimizer}

> 콘텐츠 최적화 프로그램은 AI를 사용하여 대량의 콘텐츠 배리언트를 자동으로 생성하고 평가함으로써 대규모로 메시지 콘텐츠를 테스트하고 최적화하는 데 도움을 줍니다.

{% alert important %}
콘텐츠 최적화 프로그램은 현재 베타 버전이며 이메일, 푸시 알림, 단문 메시지 서비스/MMS/RCS 메시지 채널에서만 사용할 수 있습니다. 시작하는 데 도움이 필요하면 고객 성공 매니저에게 문의하세요.
{% endalert %}

## 콘텐츠 옵티마이저 소개 {#about-content-optimizer}

콘텐츠 옵티마이저는 캔버스 단계에서 실행됩니다. 테스트할 메시지 구성요소를 정의하고, 생성형 AI 또는 수동 입력을 사용해 배리언트를 생성하며, 사용자에게 전송되는 콘텐츠 조합을 자동으로 최적화할 수 있도록 도와줍니다. 이 기능을 통해 다음을 수행할 수 있습니다:

- 이메일의 제목란, 본문 헤더, 본문 콘텐츠 또는 기본 CTA를 최적화합니다.
- 푸시 알림의 제목과 메시지를 최적화합니다.
- 단문 메시지 서비스, MMS, RCS 메시지의 훅, 본문, CTA를 최적화합니다.
- 수동 A/B 테스트 설정 없이 메시지 성능을 지속적으로 개선합니다.
- AI를 활용한 아이디어 발상으로 대량의 콘텐츠 배리언트를 빠르게 테스트합니다.
- 성과가 낮은 콘텐츠를 자동으로 단계적으로 제거하고 우수한 콘텐츠를 확대합니다.

[콘텐츠 옵티마이저 단계]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/content_optimizer_step)를 만드는 방법을 알아보세요.

### OpenAI와 콘텐츠 옵티마이저 {#openai-and-content-optimizer}

콘텐츠 옵티마이저는 AI 생성 배리언트 제안을 명시적으로 요청할 때만 OpenAI를 사용합니다. 각 사용자가 수신할 배리언트를 선택하거나 전송 트래픽을 할당하는 데는 OpenAI를 사용하지 않습니다.

- **OpenAI 사용:** 콘텐츠 구성요소에 대해 **AI 제안 생성**을 선택하면, Braze는 시드 배리언트, 지침, 선택적 [브랜드 가이드라인]({{site.baseurl}}/user_guide/administer/global/workspace_settings/brand_guidelines), 그리고 (충분한 전송 데이터가 있는 실행 중인 단계의 경우) 집계된 성능 컨텍스트를 OpenAI에 전송하여 배리언트 아이디어를 생성합니다.
- **밴딧 최적화:** Braze의 자체 멀티암드 밴딧 알고리즘이 트래픽 할당, 전송 시점의 배리언트 선택, 성능 기반 최적화를 처리합니다. [작동 방식](#how-it-works)을 참조하세요.
- **수동 입력:** OpenAI에 콘텐츠를 전송하지 않고 직접 배리언트를 입력하여 정의할 수 있습니다.

## 작동 방식 {#how-it-works}

Braze의 밴딧 알고리즘이 이 섹션에서 설명하는 최적화를 처리합니다.

콘텐츠 최적화 프로그램은 비상황별 [다중 슬롯머신(multi-armed bandit)](https://en.wikipedia.org/wiki/Multi-armed_bandit) 알고리즘을 사용하여 고성과 배리언트에 더 많은 발송을 할당하고 저성과 배리언트에 대한 할당을 줄입니다. 시간이 지남에 따라 최소한의 수동 개입으로 메시지 콘텐츠가 지속적으로 개선됩니다.

Braze의 독자적인 밴딧 최적화 알고리즘은 콘텐츠 최적화 프로그램 단계의 조합적 특성에 맞게 특별히 설계되었습니다. 각 메시지가 여러 구성요소로 이루어져 있으므로, 밴딧은 각 구성요소(예: 제목란, 본문, CTA)의 성과뿐만 아니라 메시지로 결합될 때의 상호작용도 동시에 학습합니다. 더 구체적으로, 특정 조합이 발송되면 동일한 구성요소를 공유하는 모든 조합이 해당 발송 데이터의 혜택을 받습니다. 이를 통해 밴딧은 표준 밴딧 알고리즘에 비해 동일한 양의 데이터에서 훨씬 더 빠르게 학습할 수 있습니다.

단계가 처음 시작되면 콘텐츠 최적화 프로그램은 초기 성과 데이터를 수집하기 위해 배리언트를 무작위로 발송합니다. 이 초기 탐색 기간이 지나면 알고리즘은 고성과 콘텐츠 조합으로 트래픽을 이동시키기 시작하고 저성과 옵션에 대한 할당을 점차 줄입니다. 탐색 기간 동안 트래픽은 알고리즘이 상대적 성과를 학습할 수 있도록 사용 가능한 배리언트에 전반적으로 분배됩니다.

콘텐츠 최적화 프로그램은 Canvas의 메시지 단계와 유사하며, 방해금지 시간, [Intelligent Timing]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_timing), 이벤트 로깅과 같은 기능을 갖추고 있습니다. 기본 메시지를 생성하고 최적화할 콘텐츠 구성요소(예: 제목란, 본문 텍스트 또는 콜투액션)를 정의하여 콘텐츠 최적화 프로그램 단계를 구성할 수 있습니다. 각 구성요소의 배리언트는 인공지능으로 생성하거나 수동으로 입력할 수 있으며, 구성요소를 메시지 콘텐츠에 매핑하려면 기본 메시지에 Liquid 태그를 추가해야 합니다.

각 사용자는 콘텐츠 최적화 프로그램 단계에 진입할 때마다 하나의 메시지를 받습니다. 재진입은 이전 배리언트에 대한 기억 없이 새로운 진입으로 처리됩니다.

자체 분석 도구에서 다운스트림 행동을 어트리뷰션하려면, 각 사용자가 수신한 조합을 기록하는 Liquid 태그를 메시지에 추가하세요. 자세한 내용은 [조합 토큰]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/content_optimizer_step#combination-token)을 참고하세요.

## Canvas 항목 설정 {#canvas-entry-setup}

최상의 결과를 얻으려면, 반복 실행되거나 항상 활성화된 Canvases에서 일정한 일일 볼륨으로 사용자가 점진적이고 정기적으로 단계에 진입하는 경우에 Content Optimizer를 사용하세요. 모든 사용자가 한꺼번에 단계에 진입하면, Content Optimizer가 초기 결과에서 학습할 시간이 부족합니다. 이 경우 해당 단계는 실시간 최적화 엔진이 아닌 정적 A/B 테스트처럼 동작하게 됩니다.

Content Optimizer에 가장 적합한 환경은 일일 반복 항목 Canvases와 비교적 일정한 일일 사용자 진입이 있는 이벤트 트리거 및 API 트리거 Canvases입니다. 단일 발송 Canvases나 "급증형" 항목 Canvases(예: 월간 반복)에서 Content Optimizer를 사용하는 경우, [항목 제어]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas#selecting-entry-controls)를 활용하여 여러 날에 걸쳐 사용자 진입을 분산시키는 것을 고려하세요.

### 주요 개념 {#key-concepts}

| 용어                    | 설명 |
|-------------------------|-------------|
| 기본 메시지   | 모든 전송 설정을 포함하여 배리언트가 구축되는 기본 메시지 템플릿입니다. |
| 콘텐츠 구성 요소  | 테스트 및 최적화할 수 있는 메시지 내 요소입니다(예: 제목란 또는 기본 CTA). 마케터는 구성 요소가 표시되어야 하는 위치에 관련 Liquid 태그를 메시지에 삽입해야 합니다. |
| 콘텐츠 배리언트    | 콘텐츠 구성 요소가 가질 수 있는 다양한 값입니다. |
| 콘텐츠 조합 | 콘텐츠 배리언트를 조합하여 생성된 고유 메시지입니다. |
| 최적화 이벤트       | Content Optimizer가 성능을 평가하고 시간이 지남에 따라 콘텐츠 조합에 트래픽을 할당하는 방법을 결정합니다(예: 이메일의 클릭 또는 열람). 단계 내 모든 콘텐츠 구성 요소에 적용됩니다. Content Optimizer는 이 이벤트에서 지속적으로 학습하여 성능이 더 높은 콘텐츠 조합으로 자동으로 전달을 전환합니다. |

## 고려 사항 {#considerations}

- 콘텐츠 옵티마이저는 현재 베타 버전이며, 이메일, 푸시 알림, 단문 메시지 서비스/MMS/RCS 메시지 채널에서만 사용할 수 있습니다.
- 이메일의 경우, 콘텐츠 옵티마이저는 단계당 최대 125개의 조합을 생성할 수 있습니다:
   - 단계당 최대 3개의 구성 요소
   - 각 구성 요소당 최대 5개의 배리언트
- 푸시 알림의 경우, 콘텐츠 옵티마이저는 단계당 최대 25개의 조합을 생성할 수 있습니다:
   - 단계당 최대 2개의 구성 요소
   - 각 구성 요소당 최대 5개의 배리언트
- 단문 메시지 서비스, MMS, RCS 메시지의 경우, 콘텐츠 옵티마이저는 단계당 최대 25개의 조합을 생성할 수 있습니다:
   - 단계당 최대 2개의 구성 요소
   - 각 구성 요소당 최대 5개의 배리언트
- 항목당 사용자 한 명에게 하나의 메시지만 전송됩니다. 재진입 시 이전 전송에 대한 기록은 유지되지 않습니다.
- 마케터는 정의된 콘텐츠 구성 요소 배리언트가 렌더링될 위치에 메시지 작성기에서 각 구성 요소에 대한 Liquid 태그를 수동으로 삽입해야 합니다.
