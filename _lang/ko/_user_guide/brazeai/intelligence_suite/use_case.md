# 사용 사례: 과거 앱 행동을 적절한 채널의 개인화된 오퍼로 전환하기 {#use-case-turn-past-app-behavior-into-personalized-offers-on-the-right-channel}

> 이 예시는 가상의 브랜드가 Intelligent Timing을 활용하여 과거 앱 및 메시지 참여 데이터를 기반으로 통합 Canvas에서 개인화된 프로모션을 전송하는 방법을 보여줍니다.

마빈이 한정 메뉴를 자주 운영하는 패스트푸드 레스토랑 SandwichEmperor의 마케팅 매니저라고 가정해 봅시다. 마빈의 팀은 새로운 한정 메뉴 아이템인 Super Sub를 홍보하기 위해 앱에서 프로모션 메시지를 전달하는 업무를 담당하고 있습니다.

지금까지 한정 메뉴 아이템에 대한 모든 메시지는 사일로로 관리되었습니다: 서로 다른 카피 테스트와 앵글이 별도의 발송으로 전달되었고—한정 프로모션이 앱 내 사용자들 사이에서 가장 인기 있는 시점을 완전히 이해하지 못한 채 더 높은 참여를 유도하기 위해 다양한 메시징 앵글을 시도했습니다.

새로운 Super Sub 프로모션을 위해 마빈은 시간이 지남에 따라 학습하는 하나의 통합 Canvas를 원합니다—발송 시간이나 단일 우승 메시지를 추측하는 대신 Braze가 이미 수집하는 행동(세션, 열기, 클릭)을 활용합니다.

Intelligent Timing을 사용하면 마빈은 과거 상호작용의 통계 분석(예: 세션 패턴 및 채널 참여)을 기반으로 각 사용자가 참여할 가능성이 더 높은 시점에 메시지 단계를 전달할 수 있습니다.

이 안내는 마빈이 어떻게 다음을 수행하는지 설명합니다:

- 푸시, 이메일, SMS를 메시지 단계에 포함한 하나의 Canvas 구축
- 해당 단계에 Intelligent Timing을 적용하여 사용자 및 채널별 추론된 참여 패턴에 맞춰 전달

## 1단계: 성공 측정기준 정의 및 Canvas 구축 {#step-1-define-the-success-metric-and-build-the-canvas}

마빈은 Super Sub에 대한 "성공"이 무엇을 의미하는지 결정합니다(예: 주문 또는 누군가가 Super Sub 구매를 완료하거나 앱에서 추가할 때 트리거되는 커스텀 이벤트).

다음으로, 마빈은 오퍼가 진행되는 동안 새로운 사용자가 일정한 스케줄로 진입할 수 있는 Canvas를 생성합니다.

1. Braze 대시보드에서 마빈은 **메시징** > **Canvas**로 이동합니다.
2. 그는 Canvas를 생성하고 "한정 메뉴 - Super Sub"라고 이름을 지정합니다.
3. 그런 다음 Canvas에 하나의 전환 이벤트와 다른 배리언트를 추가합니다.
4. 나머지 Canvas 세부 정보를 완료하고 이제 Canvas 빌더에서 사용자 여정을 매핑할 준비가 되었습니다.

## 2단계: 전달 설정 구성 {#step-2-set-up-delivery-settings}

메시지 단계의 **전달 설정** 탭에서 마빈은 Intelligent Timing을 사용하여 사용자의 앱 및 각 메시징 채널과의 과거 상호작용을 분석한 다음, 각 사용자에게 Super Sub를 홍보할 최적의 시간을 자동으로 선택할 계획입니다. 이는 일부 사용자는 오후에, 다른 사용자는 저녁에 프로모션을 받을 수 있음을 의미합니다.

그는 분석할 과거 상호작용이 충분하지 않은 사용자를 위해 **모든 사용자 중 앱을 가장 많이 사용하는 시간**을 선택합니다.

## 3단계: 지연 및 Intelligent Timing을 메시지 단계에 추가 {#step-3-add-delays-and-intelligent-timing-to-message-steps}

Intelligent Timing을 사용하는 메시지 단계의 경우, 마빈은 Canvas 가이드를 따릅니다: 진입(또는 이전 단계)과 Intelligent Timing이 적용된 메시지 단계 사이에 최소 2일의 캘린더 일수 지연 단계를 배치합니다. Intelligent Timing을 사용할 때 캘린더 일수 지연을 선호하는데, 이렇게 하면 각 사용자의 최적 시간에 의도한 날짜에 전달이 이루어지기 때문입니다.

각 푸시 알림, 이메일, SMS 메시지 단계에서 그는 **전달 설정**을 열고 **Intelligent Timing 사용**을 선택합니다. 최적 시간을 위한 충분한 참여 이력이 없는 사용자를 위해 대체 시간을 설정합니다. 여러 채널이 포함된 메시지 단계는 채널별로 다른 시간에 전송하거나 전송을 시도할 수 있으며, 이는 일부 고객이 아침에는 이메일에, 저녁에는 푸시에 더 많이 참여하는 방식과 일치합니다.

## 4단계: 모니터링 및 최적화 {#step-4-monitor-and-optimize}

마빈은 메시지 단계(및 배리언트가 사용하는 후속 단계)에서 푸시, 이메일, SMS에 걸쳐 Super Sub 프로모션 자산을 조율하고 Canvas를 시작합니다.

시작 후, 그는 Canvas 분석 및 전환 수를 관찰하고 Intelligent Timing이 지속적인 참여 패턴을 기반으로 각 사용자에 대해 각 채널이 발송되는 시점을 계속 최적화하고 있다고 결론짓습니다. 그 결과, 마빈은 SandwichEmperor가 한정 오퍼 성과를 지난번에 어떤 일회성 프로모션 메시지가 이겼는지가 아니라, 언제 그리고 어떤 여정이 효과적인지에 연결하는 데 성공적으로 기여했습니다.
