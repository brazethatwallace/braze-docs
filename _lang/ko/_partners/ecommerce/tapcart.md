# Tapcart

> [Tapcart](https://www.tapcart.com/)는 Shopify 기반 브랜드를 위한 선도적인 모바일 커머스 플랫폼으로, 판매자가 고객이 좋아하는 개인화된 매력적인 쇼핑 경험을 제공하는 커스텀 모바일 앱을 만들 수 있도록 지원합니다.

_이 통합은 Tapcart에서 유지 관리합니다._

## 필수 조건 {#prerequisites}

| 요구 사항              | 설명                                                                                                                                         |
|--------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| Tapcart Enterprise 계정 | 이 통합은 **Tapcart Enterprise 고객**만 사용할 수 있습니다.                                                                              |
| Braze 앱 API 키         | [Braze 앱 식별자 API 키](https://www.braze.com/docs/api/identifier_types)가 필요합니다. 각 플랫폼(예: iOS 또는 Android)에는 고유한 앱 식별자가 있습니다. Braze 대시보드에서 **설정** > **API 키** > **앱 식별자**로 이동하세요. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Prerequisites" }

## 통합 소개 {#about-the-integration}

Tapcart와 Braze를 통합하는 방법을 알아보려면 Tapcart 웹사이트에서 [Tapcart 통합 가이드](https://help.tapcart.com/hc/en-us/articles/36413383526675-Braze-Integration)를 직접 확인하세요. 통합 후 Braze에서 다음 Tapcart 기능을 활용할 수 있습니다:

- 기본 SDK 통합
- iOS 및 Android 푸시 알림
- 리치 푸시 메시지
- 사용자 여정 추적 및 세분화

현재 지원되지 않는 기능은 다음과 같습니다: Push Stories, 웹 푸시, 인앱 메시지 커스터마이징.
