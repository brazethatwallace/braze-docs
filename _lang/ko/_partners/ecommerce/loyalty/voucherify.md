# Voucherify

> [Voucherify](https://www.voucherify.io/)는 프로모션, 쿠폰, 로열티 프로그램, 추천, 개인화된 인센티브를 관리할 수 있는 인센티브 최적화 엔진입니다. Braze와 함께 사용하면 Campaigns 및 Canvases 내에서 동적 인센티브를 제공하고, 인센티브 동작을 트리거하며, 커스텀 백엔드 시스템을 구축하지 않고도 시스템 간에 프로모션 데이터를 동기화할 수 있습니다.

## 필수 조건 {#prerequisites}

Braze에서 Voucherify를 사용하려면 다음이 필요합니다:

- Voucherify 계정
- Braze 계정
- Voucherify API 자격 증명
- Braze 연결된 콘텐츠, 커스텀 속성 또는 둘 다에 대한 액세스

## 통합 개요 {#integration-overview}

Voucherify를 Braze와 통합하여 다음을 수행할 수 있습니다:

- 연결된 콘텐츠를 사용하여 실시간으로 인센티브 가져오기
- Braze에서 인센티브 동작 트리거
- 세분화를 위해 Braze로 이벤트 전송
- Braze 고객 프로필에 인센티브 데이터 저장
- 개인 바우처 코드와 함께 Braze로 커스텀 속성 전송

## 통합 리소스 {#integration-resources}

다음 리소스를 사용하여 통합을 설정하고 관리하세요:

- [Braze – Voucherify 개요](https://docs.voucherify.io/integrations/braze-overview): 통합 및 지원되는 사용 사례에 대한 개요입니다.
- [Braze로 이벤트 스트리밍](https://docs.voucherify.io/integrations/stream-events-to-braze): Voucherify 이벤트(예: 사용 내역)를 Braze로 전송합니다.
- [Braze에서 Voucherify로 데이터 전송](https://docs.voucherify.io/integrations/send-data-from-braze): Braze Campaigns에서 Voucherify 동작을 트리거합니다.
- [Braze 연결된 콘텐츠 개요](https://docs.voucherify.io/integrations/braze-connected-content-overview): Braze 메시지에 인센티브를 동적으로 가져옵니다.
- [Braze 커스텀 속성으로 배포](https://docs.voucherify.io/integrations/braze-custom-attributes): Braze 고객 프로필에 Voucherify 데이터를 저장합니다.
- [Braze로 쿠폰 내보내기](https://docs.voucherify.io/integrations/braze-promotion-codes): Braze Campaigns에서 사용할 프로모션 코드를 동기화합니다.

## 추가 리소스 {#additional-resources}

- [Braze를 떠나지 않고 로열티 빠르게 구축하기](https://www.voucherify.io/blog/speedrunning-loyalty-without-leaving-braze): Voucherify를 사용하여 인센티브 및 검증 로직을 지원하면서 Braze에서 빠르고 실험 중심의 로열티 프로그램을 운영하는 방법을 알아보세요.
- [인센티브 성숙도 스코어카드](https://scorecard.voucherify.io/braze): 인센티브 전략을 평가하고 최적화 기회를 파악하세요.
