# Blings

> [Blings](https://www.blings.io/)는 차세대 개인화된 비디오 플랫폼으로, 채널 전반에 걸쳐 실시간 인터랙티브 데이터 중심 비디오 경험을 대규모로 제공할 수 있도록 지원합니다.

_이 통합은 Blings에서 유지 관리합니다._

## 통합 {#integration}

### 1단계: Blings HTML 스니펫 가져오기 {#step-1-obtain-your-blings-html-snippet}

{% tabs %}
{% tab Blings business and free plans %}

#### Blings 비즈니스 및 무료 요금제 {#blings-business-and-free-plans}

Blings 앱에서 HTML 스니펫을 직접 찾아 복사하세요.

1. 선택한 MP5 프로젝트의 **Connect** 탭으로 이동합니다.
2. Blings **Connect** 페이지에서 해당 변수에 Braze Liquid 태그를 추가합니다. 태그는 HTML 스니펫의 값을 동적으로 채웁니다.

![Blings HTML 스니펫.]({% image_buster /assets/img/blings/blings_connect_audience.png %}){: style="max-width:70%;"}

{% endtab %}
{% tab Blings Enterprise plan %}

#### Blings 엔터프라이즈 요금제 {#blings-enterprise-plan}

Blings 담당자에게 HTML 스니펫을 요청하세요.

{% endtab %}
{% endtabs %}

### 2단계: Braze Campaign 생성 {#step-2-create-a-braze-campaign}

Braze에서 새 이메일 또는 인앱 메시지 Campaign을 생성하고 Blings HTML 스니펫을 삽입합니다. 편집기 미리보기에서 개인화된 필드와 Creative Suite 동적 콘텐츠가 올바르게 표시되는지 확인합니다.

### 3단계: 테스트 및 시작 {#step-3-test-and-launch}

Braze에서 Campaign을 미리 보고 개인화된 필드가 올바르게 채워지는지 확인합니다. 그런 다음 MP5 Campaign을 대규모로 배포하세요.

![Blings Braze 미리보기.]({% image_buster /assets/img/blings/blings_braze_preview.png %}){: style="max-width:70%;"}

## 고객지원 받기 {#getting-support}

궁금한 점이 있거나 스니펫을 요청하려면 [support@blings.io](mailto:support@blings.io)로 Blings에 문의하거나 [Blings 도움말 센터](https://blings.gitbook.io/blings-knowledge-base/documentation)를 참조하세요.
