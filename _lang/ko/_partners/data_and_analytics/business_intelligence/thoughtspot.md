# ThoughtSpot

> [ThoughtSpot](https://www.thoughtspot.com/)은 최신 분석 클라우드로, 최신 데이터 스택에 실시간 분석을 제공하는 차세대 분석 플랫폼입니다. 동료, 파트너, 고객이 데이터를 유용한 인사이트로 전환할 수 있도록 지원합니다.

Braze와 ThoughtSpot 통합은 ThoughtSpot TML 블록을 활용하여 회사 사용자가 미리 구축된 워크시트 및 모델 템플릿으로 사용자 행동 분석을 가속화할 수 있도록 합니다. 이 통합을 통해 사용자는 Braze 상호작용 데이터를 무제한으로 검색하고 유용한 인사이트를 발견할 수 있습니다.

## 필수 조건 {#prerequisites}

Braze에서 ThoughtSpot을 사용하려면 ThoughtSpot이 실시간 쿼리를 수행할 수 있도록 먼저 데이터를 클라우드 데이터 웨어하우스로 전송해야 합니다.

| 요구 사항 | 설명 |
| ----------- | ----------- |
| ThoughtSpot 계정 | 이 파트너십을 활용하려면 ThoughtSpot 계정이 필요합니다. |
| 클라우드 데이터 웨어하우스 | Braze 데이터는 Braze Currents를 사용하여 클라우드 데이터 웨어하우스에 저장됩니다. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Prerequisites" }

## TML 블록 {#tml-blocks}

회사 사용자는 모든 디지털 상호작용 데이터에 쉽게 접근하고 검색할 수 있습니다. 미리 구축된 시각화 및 워크시트를 통해 사용자가 분석을 빠르게 설정할 수 있도록 템플릿을 제공합니다. 검색, 드릴다운, SpotIQ를 사용하여 웹사이트의 유입 및 사용자 행동을 분석하세요.

## 통합 {#integration}

### 1단계: ThoughtSpot 연결 {#step-1-connect-thoughtspot}

ThoughtSpot 인스턴스에 로그인하고 Braze Currents를 사용하여 가져온 각 테이블에 대해 Embrace 연결을 생성합니다.

#### 2단계: TML 가져오기 {#step-2-import-tml}

ThoughtSpot에서 워크시트 및 라이브보드의 압축 파일을 가져오고 오류 없이 가져오기가 완료되었는지 확인합니다.

가져오기가 완료되면 라이브보드를 검색하고 커스터마이즈할 수 있습니다.
