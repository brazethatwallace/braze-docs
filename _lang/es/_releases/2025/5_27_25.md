# Versión del 27 de mayo de 2025 {#may-27-2025-release}

## Flexibilidad de los datos {#data-flexibility}

### Copiar Canvas entre espacios de trabajo {#copying-canvases-across-workspaces}

{% multi_lang_include release_type.md release="General availability" %}

Ahora puedes copiar Canvas entre espacios de trabajo. Esto te permite agilizar la composición de tus mensajes comenzando con una copia de un Canvas en un espacio de trabajo diferente. Para obtener más información sobre lo que se copia, consulta [Copiar Campaigns y Canvas entre espacios de trabajo]({{site.baseurl}}/copying_to_workspaces).

### Reglas de mensajería para el flujo de trabajo de aprobación {#messaging-rules-for-approval-workflow}

{% multi_lang_include release_type.md release="General availability" %}

Utiliza las [reglas de mensajería]({{site.baseurl}}/user_guide/messaging/governance/approvals/messaging_rules) en tu flujo de trabajo de aprobación para limitar el número de usuarios alcanzables antes de que se requiera una aprobación adicional; de esta forma, puedes revisar tus Campaigns y Canvas antes de dirigirte a una audiencia más amplia.

### Diagramas de relación de entidades para Snowflake y Braze {#entity-relationship-diagrams-for-snowflake-and-braze}

A principios de este año, creamos tablas de relación de entidades para los datos compartidos entre Snowflake y Braze. Este mes, añadimos [nuevos diagramas interactivos]({{site.baseurl}}/partners/data_and_analytics/data_warehouses/snowflake/entity_relationships) donde puedes desplazarte, arrastrar y ampliar los detalles de cada tabla, lo que te da una mejor idea de cómo interactúan tus datos con Braze.

## Desbloquear la creatividad {#unlocking-creativity}

### Eventos recomendados {#recommended-events}

{% multi_lang_include release_type.md release="Early access" %}

Los [eventos recomendados]({{site.baseurl}}/user_guide/data/activation/events/recommended_events) se asignan a los ejemplos de comercio electrónico más comunes. Al usar eventos recomendados, puedes desbloquear plantillas de Canvas prediseñadas, paneles de informes que se asignan al ciclo de vida del cliente, y más.

## Canales robustos {#robust-channels}

### Canal de Banners {#banners-channel}

{% multi_lang_include release_type.md release="General availability" %}

Con [Banners]({{site.baseurl}}/user_guide/channels/banners), puedes crear mensajes personalizados para tus usuarios, a la vez que amplías el alcance de tus otros canales, como el correo electrónico o las notificaciones push. Puedes integrar Banners directamente en tu aplicación o sitio web, lo que te permite interactuar con los usuarios a través de una experiencia que resulta natural.

### Canal de Rich Communication Services (RCS) {#rich-communication-services-rcs-channel}

{% multi_lang_include release_type.md release="General availability" %}

[Rich Communication Services (RCS)]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs) mejora los servicio de mensajes cortos tradicionales permitiendo a las marcas entregar mensajes que no solo son informativos, sino también mucho más atractivos. Ahora compatible tanto con Android como con iOS, RCS ofrece características como contenido multimedia de alta calidad, botones interactivos y perfiles de remitente con marca directamente en las aplicaciones de mensajería preinstaladas de los usuarios, eliminando la necesidad de descargar una aplicación independiente.

### Página de configuración de push {#push-settings-page}

{% multi_lang_include release_type.md release="General availability" %}

Usa la página [**Configuración de push**]({{site.baseurl}}/user_guide/administer/global/workspace_settings/push_settings) para configurar los ajustes clave de tus notificaciones push, incluido el TTL or tiempo de vida or tiempo de vida de la notificación push (TTL or tiempo de vida) y la prioridad FCM predeterminada para Campaigns de Android. Estos ajustes ayudan a optimizar la entrega y la eficacia de tus notificaciones push, asegurando una mejor experiencia para tus usuarios.

### Códigos promocionales para campañas de mensajes dentro de la aplicación {#promotion-codes-for-in-app-message-campaigns}

{% multi_lang_include release_type.md release="Early access" %}

Puedes usar [códigos promocionales]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/sources/promotion_codes) en campañas de mensajes dentro de la aplicación insertando un [fragmento de código de lista de códigos promocionales]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/sources/promotion_codes/create#create) en el cuerpo del mensaje de tu campaña de mensajes dentro de la aplicación.

### Gestión de errores de webhook y límites de velocidad {#handling-webhook-errors-and-rate-limiting}

[Acerca de los webhooks]({{site.baseurl}}/user_guide/message_building_by_channel/webhooks/understanding_webhooks#webhook-error-handling-and-rate-limiting) tiene una nueva sección que describe cómo Braze gestiona los errores de webhook y los límites de velocidad.

### Configuraciones regionales para mensajes dentro de la aplicación {#in-app-message-locales}

Después de [añadir configuraciones regionales]({{site.baseurl}}/locales_in_messages) a tu espacio de trabajo, puedes dirigirte a usuarios en diferentes idiomas, todo dentro de un único mensaje dentro de la aplicación.

### Amazon SES como proveedor de envío de correo electrónico (ESP) {#amazon-ses-as-an-email-sending-provider-esp}

Ahora puedes usar Amazon SES como ESP, de manera similar a cómo usarías SendGrid y SparkPost. Consulta [SSL en Braze]({{site.baseurl}}/user_guide/channels/email/email_setup/ssl#what-is-a-cdn-and-why-do-i-need-it) y [Universal Links y App Links]({{site.baseurl}}/user_guide/channels/email/customize/universal_links_and_app_links#turning-off-click-tracking-on-a-link-to-link-basis) para conocer los matices en la configuración de SSL y el seguimiento de clics enlace por enlace.

## Nuevas asociaciones de Braze {#new-braze-partnerships}

### Eagle Eye - Fidelización {#eagle-eye-loyalty}

La integración bidireccional entre Braze y [Eagle Eye]({{site.baseurl}}/partners/eagle_eye) te permite activar datos de fidelización y promocionales directamente en Braze, lo que permite a los especialistas en marketing personalizar la interacción con los clientes utilizando datos en tiempo real como saldos de puntos, promociones y actividades de recompensas.

### Eppo - Pruebas A/B {#eppo-ab-testing}

La integración entre Braze y [Eppo]({{site.baseurl}}/partners/eppo) te permite configurar pruebas A/B en Braze y analizar los resultados en Eppo para descubrir información y vincular el rendimiento de los mensajes con métricas empresariales a largo plazo como los ingresos o la retención.

### Mention Me - Referidos {#mention-me-referrals}

Juntos, [Mention Me](https://www.mention-me.com/) y Braze pueden ser tu puerta de entrada para atraer clientes premium y fomentar una fidelización de marca inquebrantable. Al integrar fácilmente datos de referidos de primera parte en Braze, puedes ofrecer experiencias omnicanal altamente personalizadas dirigidas a los fans de tu marca. Para comenzar, consulta [Partners tecnológicos: Mention Me]({{site.baseurl}}/partners/mention_me).

### Shopify - eCommerce

[Conecta múltiples dominios de tiendas Shopify]({{site.baseurl}}/shopify_connecting_multiple_stores) a un único espacio de trabajo para tener una visión integral de tus clientes en todos los mercados. Crea y lanza programas de automatización y journeys en un solo espacio de trabajo sin duplicar esfuerzos entre tiendas regionales.

## Actualizaciones del SDK or kit de desarrollo de software {#sdk-updates}

Se han publicado las últimas actualizaciones del SDK or kit de desarrollo de software. Las actualizaciones de última hora se enumeran en la sección de actualizaciones del SDK or kit de desarrollo de software; todas las demás actualizaciones se pueden encontrar en los registros de cambios del SDK or kit de desarrollo de software correspondientes.

- [Android SDK or kit de desarrollo de software 36.0.0](https://pub.dev/packages/braze_plugin/changelog)
    - Esta versión revierte el aumento de la versión mínima del Android SDK or kit de desarrollo de software del SDK or kit de desarrollo de software de Android de Braze de API 21 a API 25 introducido en la versión 34.0.0. Esto permite que el SDK or kit de desarrollo de software pueda compilarse nuevamente en aplicaciones que soportan desde API 21. Ten en cuenta que, aunque estamos reintroduciendo la capacidad de compilación, no estamos reintroduciendo el soporte formal para versiones < API 25, y no podemos garantizar que el SDK or kit de desarrollo de software funcione según lo previsto en dispositivos que ejecuten esas versiones.
    - Si tu aplicación soporta esas versiones, deberías:
        - Validar que tu integración del SDK or kit de desarrollo de software funcione según lo previsto en dispositivos físicos (no solo emuladores) para esas versiones de API.
        - Si no puedes validar el comportamiento esperado, debes llamar a [disableSDK](https://braze-inc.github.io/braze-android-sdk/kdoc/braze-android-sdk/com.braze/-braze/-companion/disable-sdk.html), o no inicializar el SDK or kit de desarrollo de software en esas versiones. De lo contrario, podrías causar efectos secundarios no deseados o un rendimiento degradado en los dispositivos de tus usuarios finales.
    - Se corrigió un problema en el que los mensajes dentro de la aplicación causaban una lectura en el hilo principal.
    `BrazeInAppMessageManager.displayInAppMessage` es ahora una función suspend de Kotlin.
        - Si no llamas a esta función directamente, no necesitas realizar ningún cambio.
    - AndroidX Compose BOM se actualizó a 2025.04.01 para gestionar las actualizaciones en las API de Jetpack Compose.
- [React Native SDK or kit de desarrollo de software 15.0.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
    - Actualiza el puente nativo de Android del SDK or kit de desarrollo de software de Android de Braze 35.0.0 a 36.0.0.
    - Actualiza las vinculaciones de la versión nativa de iOS del SDK or kit de desarrollo de software Swift de Braze 11.9.0 a 12.0.0.
    - Actualiza la representación de unidad de PushNotificationEvent.timestamp a milisegundos en iOS.
        - Anteriormente, este valor se representaba en segundos en iOS. Ahora coincidirá con la implementación existente de Android.
