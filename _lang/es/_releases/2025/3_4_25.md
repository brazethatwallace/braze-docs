# Lanzamiento del 4 de marzo de 2025 {#march-4-2025-release}

## Simplificación de la guía para desarrolladores {#developer-guide-detangle}

El contenido idéntico que se comparte entre varios SDK or kit de desarrollo de software se está empezando a unificar mediante la nueva función de pestañas de SDK or kit de desarrollo de software del sitio de documentación. Este mes se combinaron la [integración de SDK or kit de desarrollo de software]({{site.baseurl}}/developer_guide/sdk_integration), la [inicialización de SDK or kit de desarrollo de software]({{site.baseurl}}/developer_guide/sdk_integration) y las [Content Cards]({{site.baseurl}}/developer_guide/content_cards). Mantente atento a más actualizaciones en los próximos meses.

## Flexibilidad de datos {#data-flexibility}

### ID de Braze para perfiles de usuario {#braze-ids-for-user-profiles}

Un perfil de usuario ahora incluye un [ID de Braze]({{site.baseurl}}/user_guide/audience/manage_audience/user_profiles). Puedes usarlo para buscar perfiles de usuario.

### Aplazamientos {#deferrals}

Braze ha actualizado nuestra definición de lo que es un rebote blando y está enviando un nuevo evento llamado [aplazamientos]({{site.baseurl}}/user_guide/channels/email/reporting#email-performance), que se produce cuando un correo electrónico no se entregó de forma inmediata, pero Braze reintentará el envío del correo electrónico durante un máximo de 72 horas tras este fallo de entrega temporal para maximizar las posibilidades de una entrega exitosa antes de que se detengan los intentos para esa Campaign específica.

### Relaciones de entidades en Snowflake {#snowflake-entity-relationships}

Hemos mapeado los [esquemas de tablas sin procesar](/docs/assets/download_file/data-sharing-raw-table-schemas.txt) para las relaciones de entidades de Snowflake y Braze a una nueva [página de documentación fácil de usar]({{site.baseurl}}/partners/data_and_analytics/data_warehouses/snowflake/entity_relationships). Incluye un desglose de las tablas `USER_MESSAGES` pertenecientes a cada canal, así como descripciones de las claves primarias, foráneas y nativas de cada tabla.

### Gestión de identidad para ID externos {#identity-management-for-external-ids}

Usar una dirección de correo electrónico o una dirección de correo electrónico con hash como tu ID externo de Braze puede simplificar la gestión de identidad en tus orígenes de datos; sin embargo, es importante tener en cuenta los [posibles riesgos]({{site.baseurl}}/user_guide/data/user_data_collection/user_profile_lifecycle#identified-user-profiles) para la privacidad de los usuarios y la seguridad de los datos.

### Pasos de contexto para Canvas {#context-steps-for-canvas}

{% multi_lang_include release_type.md release="Early access" %}

Usa los [pasos de contexto]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/context) para crear o actualizar un conjunto de variables que representen el contexto de un usuario (o información sobre el comportamiento de ese usuario) a medida que avanza por un Canvas.

### Retraso personalizado {#personalized-delay}

{% multi_lang_include release_type.md release="Early access" %}

Puedes configurar un [retraso personalizado]({{site.baseurl}}/user_guide/engagement_tools/canvas/canvas_components/delay_step#personalized-delays) para tus usuarios seleccionando el conmutador **Personalizar retraso** en tu paso de retraso. Puedes usar esto junto con un paso de contexto para seleccionar una variable de contexto como criterio de retraso.

Al configurar un paso de retraso en el recorrido de usuario de tu Canvas, ahora puedes crear un retraso de hasta 2 años.

### Revertir la sincronización automática {#reverting-automatic-synchronization}

Al [redactar un mensaje de correo electrónico]({{site.baseurl}}/user_guide/message_building_by_channel/email/html_editor#step-3-compose-your-email), puedes volver a la sincronización automática en la pestaña de texto sin formato seleccionando el icono Regenerar desde HTML, que solo aparece si el texto sin formato no se está sincronizando.

## Canales robustos {#robust-channels}

### Actualizaciones en vivo de Android {#android-live-updates}

Aunque las Actualizaciones en vivo no estarán disponibles oficialmente hasta
[Android 16](https://android-developers.googleblog.com/2025/01/first-beta-android16.html), nuestra página de [Actualizaciones en vivo para Android]({{site.baseurl}}/developer_guide/push_notifications/live_notifications/?sdktab=android&tab=local) te muestra cómo emular su comportamiento, para que puedas mostrar notificaciones interactivas en la pantalla de bloqueo de forma similar a las [Actividades en vivo del SDK or kit de desarrollo de software Swift de Braze]({{site.baseurl}}/developer_guide/push_notifications/live_notifications/?sdktab=swift). A diferencia de las Actualizaciones en vivo oficiales, esta funcionalidad se puede implementar en versiones anteriores de Android.

### Copiar Campaigns con conmutadores de características entre espacios de trabajo {#copying-campaigns-with-feature-flags-across-workspaces}

Ahora puedes [copiar Campaigns con conmutadores de características entre espacios de trabajo]({{site.baseurl}}/user_guide/engagement_tools/campaigns/managing_campaigns/copying_to_workspace#copying-campaigns-with-feature-flags). Para hacerlo, asegúrate de que el espacio de trabajo de destino tenga un experimento de conmutador de características configurado con un ID que coincida con el conmutador de características referenciado en la Campaign original.

### Nuevos tipos de mensajes de WhatsApp compatibles {#new-whatsapp-message-types-supported}

Los mensajes de WhatsApp ahora admiten [mensajes salientes de video, audio y documentos]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#outbound-messages). Ponte en contacto con tu director de cuentas de Braze si estás interesado en participar en el acceso anticipado.

### Mensajes de derecha a izquierda {#right-to-left-messages}

[Crear mensajes de derecha a izquierda]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/localization/right_to_left_messages) cubre las mejores prácticas para elaborar mensajes en idiomas que se leen de derecha a izquierda, de modo que tus mensajes se muestren con la mayor precisión posible.

### Recomendaciones de artículos {#item-recommendations}

## Nuevos partners de Braze {#new-braze-partnerships}

### Email Love - Extensiones de canal {#email-love-channel-extensions}

La integración de Braze y [Email Love]({{site.baseurl}}/partners/message_orchestration) aprovecha la característica Exportar a Braze de Email Love y la API de Braze para cargar tus plantillas de correo electrónico en Braze fácilmente.

### VWO - Pruebas A/B {#vwo-ab-testing}

La integración de Braze y [VWO]({{site.baseurl}}/partners/data_and_analytics/ab_testing/vwo) te permite aprovechar los datos de experimentos de VWO para crear Segments segmentados y entregar Campaigns personalizadas.
