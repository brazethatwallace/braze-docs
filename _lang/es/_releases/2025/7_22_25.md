# Versión del 22 de julio de 2025 {#july-22-2025-release}

## Exportación de eventos de seguridad con Amazon S3 {#security-events-export-with-amazon-s3}

Puedes [exportar automáticamente eventos de seguridad a Amazon S3]({{site.baseurl}}/user_guide/administer/global/admin_settings/security_settings/security_export_s3), un proveedor de almacenamiento en el cloud, con un trabajo diario que se ejecuta a medianoche UTC. Una vez configurado, no necesitas exportar manualmente los eventos de seguridad desde el panel.

## Flexibilidad de datos {#data-flexibility}

### Importación de CSV {#csv-import}

{% multi_lang_include release_type.md release="General availability" %}

Puedes usar la importación de CSV para registrar y actualizar atributos de usuario y eventos personalizados en Braze como `first_name`, `last_destination_searched` y `trip_booked`. Para empezar, consulta [Importación de CSV]({{site.baseurl}}/user_guide/audience/manage_audience/import_users/csv_import).

### Alertas de uso de API {#api-usage-alerts}

{% multi_lang_include release_type.md release="General availability" %}

Las alertas de uso de API proporcionan visibilidad crítica sobre tu uso de la API, lo que te permite detectar proactivamente tráfico inesperado. Al configurar estas alertas para rastrear volúmenes clave de solicitudes de API, puedes recibir notificaciones en tiempo real y abordar problemas antes de que afecten tus Campaigns de marketing.

### Límites de velocidad de API del espacio de trabajo {#workspace-api-rate-limits}

Con los límites de velocidad de API del espacio de trabajo, puedes establecer un número máximo de solicitudes de API que un espacio de trabajo puede realizar a un endpoint de ingesta específico, como `/users/track` o datos del SDK or kit de desarrollo de software. También puedes aplicar límites de velocidad a un grupo de espacios de trabajo, lo que significa que el límite se comparte entre todos los espacios de trabajo de ese grupo.

### Intervalo de tiempo predeterminado para análisis de Campaign {#default-time-range-for-campaign-analytics}

De forma predeterminada, el intervalo de tiempo para [**Análisis de Campaign**]({{site.baseurl}}/user_guide/analytics/reports/campaign_analytics) mostrará los últimos 90 días desde la hora actual. Esto significa que si la Campaign se lanzó hace más de 90 días, los análisis se mostrarán como "0" para el intervalo de tiempo dado. Para ver todos los análisis de Campaigns anteriores, ajusta el intervalo de tiempo del informe.

### Comportamiento actualizado para el paso de recorrido de experimentos en Canvas {#updated-behavior-for-canvas-experiment-paths-step}

Si tu Canvas tiene un recorrido ganador o un recorrido personalizado activo o en curso en un [experimento]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step) y actualizas el Canvas activo, independientemente de si actualizas el paso de recorrido de experimentos en sí, el experimento en curso finalizará y el paso de experimento no determinará un recorrido ganador ni recorridos personalizados. Para reiniciar el experimento, puedes desconectar el recorrido de experimentos existente y lanzar uno nuevo, o duplicar el Canvas y lanzar un nuevo Canvas. De lo contrario, los usuarios fluirán a través del recorrido de experimentos como si no se hubiera seleccionado ningún método de optimización.

Para más información, consulta [Editar Canvas después del lanzamiento]({{site.baseurl}}/post-launch_edits).

### Límite de velocidad más rápido disponible para el endpoint `/users/export/ids` {#faster-rate-limit-available-for-usersexportids-endpoint}

También puedes aumentar el [límite de velocidad del endpoint /users/export/ids]({{site.baseurl}}/api/endpoints/export/user_data/post_users_identifier#rate-limit) a 40 solicitudes por segundo cumpliendo los siguientes requisitos:

- Tu espacio de trabajo tiene habilitado el límite de velocidad predeterminado (250 solicitudes por minuto). Contacta a tu director de cuentas de Braze para obtener ayuda adicional con la eliminación de cualquier límite de velocidad preexistente que puedas tener.
- Tu solicitud incluye el parámetro fields_to_export para listar todos los campos que deseas recibir.

## Desbloqueando la creatividad {#unlocking-creativity}

### Páginas de destino {#landing-pages}

Puedes hacer que tu página de destino sea [receptiva al tamaño del dispositivo del usuario]({{site.baseurl}}/user_guide/messaging/landing_pages/create_landing_pages#step-3-customize-the-page) apilando columnas verticalmente en pantallas más pequeñas. ## Canales robustos {#robust-channels}

### Filtrado de bots para correos electrónicos {#bot-filtering-for-emails}

{% multi_lang_include release_type.md release="General availability" %}

Configura el filtrado de bots en tus [Preferencias de correo electrónico]({{site.baseurl}}/user_guide/administer/global/workspace_settings/email_preferences) para excluir todos los clics sospechosos de máquinas o bots. Un "clic de bot" en un correo electrónico se refiere a un clic en los hipervínculos dentro de un correo electrónico generado por un programa automatizado. Al filtrar estos clics de bots, puedes desencadenar y entregar mensajes de forma intencionada a los destinatarios que están participando activamente.

### Bloques de productos de arrastrar y soltar {#drag-and-drop-product-blocks}

{% multi_lang_include release_type.md release="Early access" %}

El [editor de arrastrar y soltar]({{site.baseurl}}/dnd_product_blocks) te permite añadir y configurar rápidamente bloques de productos en tus mensajes para presentaciones de productos fluidas, sin necesidad de crear código Liquid personalizado. La característica de bloques de productos de arrastrar y soltar solo está disponible actualmente para correo electrónico.

### Texto span para páginas de destino y mensajes dentro de la aplicación {#span-text-for-landing-pages-and-in-app-messages}

El texto span te permite aplicar estilos específicos a bloques de texto sin código personalizado para tus [páginas de destino]({{site.baseurl}}/user_guide/engagement_tools/landing_pages/creating_pages#step-3-customize-the-page) y [mensajes dentro de la aplicación]({{site.baseurl}}/user_guide/channels/in_app_messages/customize/style_settings#blocks). Para ello, resalta el texto al que quieras dar estilo y luego selecciona **Wrap with span for style**.

### Clic en anuncio a WhatsApp {#ad-click-to-whatsapp}

Los [anuncios que hacen clic a WhatsApp]({{site.baseurl}}/whatsapp_use_cases) son una forma eficiente de atraer tanto a clientes nuevos como existentes desde los anuncios de Meta en Facebook, Instagram u otras plataformas. Usa estos anuncios para promocionar tus productos y servicios mientras haces que los usuarios conozcan tu presencia en WhatsApp.

## Nuevas integraciones de Braze {#new-braze-partnerships}

### Shopify Visitory API — eCommerce

Braze recopila información de los visitantes, como direcciones de correo electrónico y números de teléfono, a través de mensajes en el explorador. Esta información se envía luego a Shopify. Estos datos ayudan a los comerciantes a reconocer a los visitantes de su tienda y a crear una experiencia de compra más personalizada.

### Okendo — eCommerce

La integración de Braze y [Okendo]({{site.baseurl}}/partners/okendo) funciona en múltiples productos de la plataforma de Okendo, incluyendo Reviews, Loyalty, Referrals, Surveys y Quizzes. Okendo envía eventos personalizados y atributos de usuario a Braze, que pueden utilizarse para personalizar y desencadenar mensajes.

### Lemnisk — CDP or plataforma de datos de los clientes or plataforma de datos de los clientes {#lemnisk-customer-data-platform}

La integración de Braze y [Lemnisk]({{site.baseurl}}/partners/lemnisk) permite a las marcas y empresas aprovechar todo el potencial de Braze al actuar como una capa de inteligencia basada en CDP or plataforma de datos de los clientes que unifica los datos de usuario en todas las plataformas en tiempo real, y envía la información y los comportamientos recopilados del usuario a Braze en tiempo real.

## Actualizaciones del SDK or kit de desarrollo de software {#sdk-updates}

Se han publicado las últimas actualizaciones del SDK or kit de desarrollo de software. Las actualizaciones de última hora se enumeran en la sección de actualizaciones del SDK or kit de desarrollo de software; todas las demás actualizaciones se pueden encontrar en los registros de cambios del SDK or kit de desarrollo de software correspondientes.

- [Web SDK or kit de desarrollo de software 6.0.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
    - Se eliminaron la propiedad `Banner.html`, y los métodos `logBannerClick` y `logBannerImpressions`. En su lugar, usa [`insertBanner`](https://js.appboycdn.com/web-sdk/latest/doc/modules/braze.html#insertbanner), que gestiona automáticamente el seguimiento de impresiones y clics.
    - Se eliminó la compatibilidad con la característica heredada de News Feed. Esto incluye la eliminación de la clase Feed y sus métodos asociados.
    - Los campos created y categories que utilizaban las tarjetas heredadas de News Feed se han eliminado de las subclases de [`Card`](https://js.appboycdn.com/web-sdk/latest/doc/classes/braze.card.html).
    - El campo linkText también se eliminó de la subclase Card [`ImageOnly`](https://js.appboycdn.com/web-sdk/latest/doc/classes/braze.imageonly.html) y de su constructor.
    - Se clarificaron las definiciones y se actualizaron los tipos para indicar que ciertos métodos del SDK or kit de desarrollo de software devuelven explícitamente undefined cuando el SDK or kit de desarrollo de software no está inicializado, alineando las tipificaciones con el comportamiento real en tiempo de ejecución. Esto podría introducir nuevos errores de TypeScript en proyectos que dependían de las tipificaciones anteriores (incompletas).
    - Las imágenes de los mensajes dentro de la aplicación con `cropType` de `CENTER_CROP` (como `FullScreenMessage` de forma predeterminada) ahora se renderizan mediante una etiqueta `<img>` en lugar de `<span>` para mejorar la accesibilidad. Esto puede afectar a las personalizaciones CSS existentes para la clase `.ab-center-cropped-img` o sus elementos hijos.
- [Cordova SDK or kit de desarrollo de software 13.0.0](https://github.com/braze-inc/braze-cordova-sdk/blob/master/CHANGELOG.md#1300)
    - Se actualizó la implementación interna de iOS del método `enableSdk` para usar setEnabled: en lugar de `_requestEnableSDKOnNextAppRun`, que fue descontinuado en el Swift SDK or kit de desarrollo de software.
        - Llamar a este método ya no requiere reiniciar la aplicación para que surta efecto. El SDK or kit de desarrollo de software ahora se habilitará tan pronto como se ejecute este método.
    - Se actualizó el puente nativo de Android [de Braze Android SDK or kit de desarrollo de software 36.0.0 a 37.0.0](https://github.com/braze-inc/braze-android-sdk/compare/v36.0.0...v37.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
- [Android SDK or kit de desarrollo de software 37.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [Swift SDK or kit de desarrollo de software 12.0.1-12.1.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
