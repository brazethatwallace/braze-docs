# Versión del 19 de agosto de 2025 {#august-19-2025-release}

## Estandarización de la coherencia de zona horaria en Canvas Context {#time-zone-consistency-standardization-to-canvas-context}

{% multi_lang_include release_type.md release="Early access" %}

Si participas en el [acceso anticipado al paso Canvas Context]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/context), todas las marcas de tiempo con un tipo de fecha y hora de las propiedades de evento desencadenante en Canvas basados en acciones siempre se normalizarán a [UTC](https://en.wikipedia.org/wiki/Coordinated_Universal_Time). Para obtener más información, consulta [Estandarización de la coherencia de zona horaria]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/context#time-zone-consistency-standardization).

## Flexibilidad de datos {#data-flexibility}

### Dominios personalizados de autoservicio {#self-serve-custom-domains}

{% multi_lang_include release_type.md release="General access" %}

Los [dominios personalizados de autoservicio]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/custom_domains) te permiten configurar y gestionar tus propios dominios personalizados para servicio de mensajes cortos, RCS y WhatsApp, directamente desde tu panel de Braze. Puedes añadir, supervisar y gestionar fácilmente hasta 10 dominios personalizados en un solo lugar.

### Estadísticas de embudo de Segment {#segment-funnel-statistics}

Selecciona [Ver estadísticas de embudo]({{site.baseurl}}/user_guide/engagement_tools/segments/creating_a_segment#viewing-funnel-statistics) para mostrar las estadísticas de ese grupo de filtros y ver cómo cada filtro añadido afecta las estadísticas de tu Segment. Verás un recuento estimado y un porcentaje de los usuarios que son alcanzados por todos los filtros hasta ese punto. Una vez que se muestran las estadísticas de un grupo de filtros, se actualizan automáticamente cada vez que cambias los filtros.

### Nuevos campos de respuesta para el endpoint `/campaigns/details` para notificaciones push {#new-response-fields-for-campaignsdetails-endpoint-for-push-notifications}

La respuesta `messages` para notificaciones push ahora incluye dos nuevos campos:

- `image_url`: una URL de imagen para una imagen de notificación de Android, una imagen de notificación de iOS o una imagen de icono de notificación push web.
- `large_image_url`: una URL de imagen de notificación web para acciones de notificación push web de Android Chrome y Windows.

### Definición de campos PII {#defining-pii-fields}

Seleccionar y [definir ciertos campos como campos PII]({{site.baseurl}}/user_guide/administer/global/admin_settings/security_settings#view-pii) solo afecta a lo que los usuarios pueden ver en el panel de Braze y no afecta a cómo se gestionan los datos del usuario final en dichos campos PII.

Consulta con tu equipo legal para alinear la configuración de tu panel con las regulaciones y políticas de privacidad aplicables a tu empresa, incluidas las relacionadas con la [retención de datos]({{site.baseurl}}/api/data_retention).

### Compartir un enlace de descarga del generador de informes {#sharing-a-report-builder-download-link}

Puedes [compartir un enlace del panel]({{site.baseurl}}/user_guide/analytics/reporting/report_builder#sharing-a-report) al informe seleccionando **Compartir** y luego **Compartir un enlace** o **Enviar o programar un correo electrónico**.

Hemos añadido una [sección de mejores prácticas]({{site.baseurl}}) para ayudarte a configurar de forma cuidadosa tu mensaje de exclusión aproximada y crear una experiencia clara, conforme y positiva para tus suscriptores.

### WhatsApp Flows

{% multi_lang_include release_type.md release="Early access" %}

[WhatsApp Flows]({{site.baseurl}}/whatsapp_flows) es una mejora del canal de WhatsApp existente, que te permite crear experiencias de mensajería interactivas y dinámicas.

### Preguntas entrantes sobre productos en WhatsApp {#whatsapp-inbound-product-questions}

Los usuarios pueden responder a tu mensaje de producto o catálogo con [preguntas sobre productos]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/product_messages#receiving-inbound-product-questions). Estas llegan como mensajes entrantes, que luego pueden clasificarse con un paso de ruta de acción.

Además, Braze extrae el ID del producto y el ID del catálogo de estas preguntas, por lo que si deseas automatizar las respuestas o enviar las preguntas a otro equipo (como atención al cliente), puedes incluir esos detalles.

## Actualizaciones del SDK or kit de desarrollo de software {#sdk-updates}

Se han publicado las últimas actualizaciones del SDK or kit de desarrollo de software. Las actualizaciones de última hora se enumeran en la sección de actualizaciones del SDK or kit de desarrollo de software; todas las demás actualizaciones se pueden encontrar en los registros de cambios del SDK or kit de desarrollo de software correspondientes.

- [Swift SDK or kit de desarrollo de software 13.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - Amplía la funcionalidad de `BrazeSDKAuthDelegate.braze(_:sdkAuthenticationFailedWithError:)` para que se active ante errores de autenticación "Optional".
        - El método delegado `BrazeSDKAuthDelegate.braze(_:sdkAuthenticationFailedWithError:)` ahora se activará tanto para errores de autenticación "Required" como "Optional".
        - Si deseas manejar únicamente los errores de autenticación del SDK or kit de desarrollo de software "Required", añade una comprobación que asegure que `BrazeSDKAuthError.optional` sea false dentro de tu implementación de este método delegado.
    - Corrige el uso de `Braze.Configuration.sdkAuthentication` para que surta efecto cuando está habilitado.
        - Anteriormente, el valor de esta configuración no era consumido por el SDK or kit de desarrollo de software y el token siempre se adjuntaba a las solicitudes si estaba presente.
        - Ahora, el SDK or kit de desarrollo de software solo adjuntará el token de autenticación del SDK or kit de desarrollo de software a las solicitudes de red salientes cuando esta configuración esté habilitada.
    - Los setters de todas las propiedades de `Braze.FeatureFlag` y todas las propiedades de `Braze.Banner` se han establecido como `private`. Las propiedades de estas clases son ahora de solo lectura.
    - Elimina la propiedad `Braze.Banner.id`, que fue descontinuada en la versión `11.4.0`.
        - En su lugar, usa `Braze.Banner.trackingId` para leer el ID de seguimiento de Campaign de un banner.
- [React Native SDK or kit de desarrollo de software 16.0.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
    - Actualiza los enlaces de versión del SDK or kit de desarrollo de software nativo de Android de [Braze Android SDK or kit de desarrollo de software 36.0.0 a 37.0.0](https://github.com/braze-inc/braze-android-sdk/compare/v36.0.0...v37.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
    - Actualiza los enlaces de versión del SDK or kit de desarrollo de software nativo de Swift de [Braze Swift SDK or kit de desarrollo de software 12.0.0 a 13.0.0](https://github.com/braze-inc/braze-swift-sdk/compare/12.0.0...13.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
        - El evento `sdkAuthenticationError` ahora se activará tanto para errores de autenticación "Required" como "Optional".
- [Xamarin SDK or kit de desarrollo de software 7.0.0](https://github.com/braze-inc/braze-xamarin-sdk/blob/7.0.0/CHANGELOG.md)
    - Se añadió compatibilidad con .NET 9.0 para los enlaces de iOS y Android.
        - Esto elimina la compatibilidad con .NET 8.0.
        - Esto requiere una [versión mínima de iOS 12.2](https://learn.microsoft.com/en-us/dotnet/maui/whats-new/dotnet-9?view=net-maui-9.0).
    - Se actualizó el enlace de Android de [Braze Android 32.0.0 a 37.0.0](https://github.com/braze-inc/braze-android-sdk/compare/v32.0.0...v37.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
    - Se actualizó el enlace de iOS de [Braze Swift SDK or kit de desarrollo de software 10.0.0 a 12.1.0](https://github.com/braze-inc/braze-swift-sdk/compare/10.0.0...12.1.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
    - Esta versión contiene API para la característica Banners, pero actualmente no es completamente compatible con este SDK or kit de desarrollo de software. Si deseas usar Banners en tu aplicación .NET MAUI, contacta con tu administrador de soporte al cliente antes de integrarla en tu aplicación.
- [Cordova SDK or kit de desarrollo de software 13.0.0](https://github.com/braze-inc/braze-cordova-sdk/blob/master/CHANGELOG.md#1300)
    - Se actualizó la implementación interna de iOS del método `enableSdk` para usar `setEnabled`: en lugar de `_requestEnableSDKOnNextAppRun`, que fue descontinuado en el Swift SDK or kit de desarrollo de software.
    - Llamar a este método ya no requiere que la aplicación se reinicie para que surta efecto. El SDK or kit de desarrollo de software ahora se habilitará tan pronto como se ejecute este método.
    - Se actualizó el puente nativo de Android de [Braze Android SDK or kit de desarrollo de software `36.0.0` a `37.0.0`](https://github.com/braze-inc/braze-android-sdk/compare/v36.0.0...v37.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
