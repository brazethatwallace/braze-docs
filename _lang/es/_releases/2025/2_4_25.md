# Lanzamiento del 4 de febrero de 2025 {#february-4-2025-release}

## Mejoras en la documentación de Braze {#braze-docs-improvements}

### Renovación de Datos y Análisis {#data-and-analytics-revamp}
Para facilitarte encontrar lo que buscas, separamos los artículos que antes estaban anidados en "Datos y análisis" en [Datos]({{site.baseurl}}/user_guide/data) y [Análisis]({{site.baseurl}}/user_guide/analytics).

### Guía del desarrollador {#developer-guide}
Hemos realizado una gran limpieza de toda la documentación en la [Guía del desarrollador de Braze]({{site.baseurl}}/developer_guide/home), que incluyó la fusión de guías prácticas repartidas en varias páginas en una sola página.

También hay una nueva [página de referencia del SDK]({{site.baseurl}}/developer_guide/references) que enumera toda la documentación de referencia y los repositorios para cada SDK de Braze.

#### SDK de Braze para Unreal Engine {#unreal-engine-braze-sdk}
Migramos y reescribimos todo el contenido del README del repositorio de GitHub del SDK de Braze para Unreal Engine en su [sección dedicada en la documentación de Braze]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=unreal%20engine).

## Flexibilidad de datos {#data-flexibility}

### Panel de uso de API {#api-usage-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

El [panel de uso de API]({{site.baseurl}}/user_guide/analytics/dashboards/api_usage) te permite supervisar el tráfico entrante de REST API en Braze para comprender las tendencias en tu uso de nuestras REST API y solucionar cualquier problema potencial.

### Añadir etiquetas a atributos personalizados {#adding-tags-to-custom-attributes}

{% multi_lang_include release_type.md release="General availability" %}

Puedes [añadir etiquetas a un atributo personalizado]({{site.baseurl}}/user_guide/data/activation/attributes/custom_attributes#add-tags) después de crearlo si tienes el permiso "Manage Events, Attributes, Purchases". Las etiquetas pueden usarse para filtrar la lista de atributos.

### Endpoints de selecciones de catálogo y campos de catálogo asíncronos {#catalog-selections-and-async-catalog-fields-endpoints}

{% multi_lang_include release_type.md release="General availability" %}

Los siguientes endpoints ya están disponibles de forma general:
* [POST: Create Catalog Fields]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/post_create_catalog_fields)
* [DELETE: Delete Catalog Field]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/delete_catalog_field)
* [DELETE: Delete Catalog Selection]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/delete_catalog_selection)
* [POST: Create Catalog Selection]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/post_create_catalog_selections)

### Usar una dirección de correo electrónico para desencadenar Campaigns o Canvas {#using-an-email-address-to-trigger-campaigns-or-canvases}

{% multi_lang_include release_type.md release="General availability" %}

Ahora puedes especificar un destinatario por dirección de correo electrónico para desencadenar tus [Campaigns]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/target_users) y [Canvas]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas#step-13-set-your-target-entry-audience).

### Usar un número de teléfono para identificar a un usuario a través de la API {#using-a-phone-number-to-identify-a-user-via-the-api}

{% multi_lang_include release_type.md release="General availability" %}

Ahora puedes usar un número de teléfono, además de un alias y una dirección de correo electrónico, para identificar a un usuario a través del [endpoint de API `/users/identify`]({{site.baseurl}}/api/endpoints/user_data/post_user_identify).

### Obtener un rastreo de SAML {#getting-a-saml-trace}
Añadimos [pasos sobre cómo obtener un rastreo de SAML]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/saml_sso_setup#obtaining-a-saml-trace), que te ayudan a resolver problemas de SAML inicio de sesión único con el equipo de soporte de forma más eficiente.

### Centros de datos específicos por región {#region-specific-data-centers}
A medida que Braze crece para dar servicio a nuevas áreas, hemos añadido un [artículo sobre los centros de datos de Braze]({{site.baseurl}}/user_guide/data/infrastructure/data_centers) para aclarar nuestro enfoque operativo.

## Desbloqueando la creatividad {#unlocking-creativity}

### Notificaciones de bajada de precio y notificaciones de vuelta en existencias {#price-drop-notifications-and-back-in-stock-notifications}

{% multi_lang_include release_type.md release="General availability" %}

Ahora puedes notificar a los clientes cuando un artículo vuelve a estar en existencias configurando [notificaciones de vuelta en existencias]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/back_in_stock_notifications) a través de un Canvas y un catálogo.

También puedes crear [notificaciones de bajada de precio]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/price_drop_notifications) para notificar a los clientes cuando el precio de un artículo ha disminuido, configurando notificaciones de bajada de precio en un catálogo y Canvas.

### Vista previa para selección {#preview-for-selection}

{% multi_lang_include release_type.md release="General availability" %}

Después de crear una selección, puedes [ver lo que devolvería una selección]({{site.baseurl}}/user_guide/data/activation/catalogs/selections#test-and-preview) para un usuario aleatorio o un usuario específico.

### Plantillas de elementos del catálogo que incluyen Liquid {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="General availability" %}

Puedes [crear plantillas de elementos del catálogo que incluyan Liquid]({{site.baseurl}}/user_guide/data/activation/catalogs/using_catalogs#using-liquid).

### Plantillas de Canvas {#canvas-templates}
Hemos añadido nuevas plantillas de Canvas para [incorporar usuarios con un cuestionario de preferencias]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/preference_survey) y [crear un registro de correo electrónico con doble adhesión voluntaria]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/email_signup).

### Gestión de leads con Salesforce Sales Cloud para B2B {#managing-leads-with-salesforce-sales-cloud-for-b2b}
Una forma en que los especialistas en marketing B2B pueden usar Braze es a través de una integración con Salesforce Sales Cloud. Lee más sobre cómo implementar este [caso de uso]({{site.baseurl}}/user_guide/get_started/b2b_use_cases/b2b_salesforce_sales_cloud).

## Canales robustos {#robust-channels}

### Listas de supresión {#suppression-lists}

{% multi_lang_include release_type.md release="Beta" %}

Las [listas de supresión]({{site.baseurl}}/user_guide/audience/suppression_lists) especifican grupos de usuarios que nunca recibirán mensajes. Los administradores pueden crear listas de supresión con filtros de Segment para delimitar un grupo de usuarios de la misma forma que lo harían para la segmentación.

## Nuevas asociaciones de Braze {#new-braze-partnerships}

### Constructor - Contenido dinámico {#constructor-dynamic-content}
[Constructor]({{site.baseurl}}/partners/ecommerce/product_search_recommendations/constructor) es una plataforma de búsqueda y descubrimiento de productos que utiliza IA y aprendizaje automático para ofrecer experiencias personalizadas de búsqueda, recomendaciones y navegación para sitios web de comercio electrónico y comercio minorista.

### Trustpilot - Contenido dinámico {#trustpilot-dynamic-content}
[Trustpilot]({{site.baseurl}}/partners/trustpilot) es una plataforma de reseñas en línea que permite a tus clientes compartir comentarios y te permite gestionar y responder a las reseñas.
