# Lanzamiento del 3 de mayo de 2022 {#may-3-2022-release}

## Aprobación de Campaign {#campaign-approval}

La aprobación de Campaign agrega un proceso de revisión a tu flujo de trabajo antes de lanzar una Campaign. Ahora, puedes asegurarte de que cada confirmación esté aprobada para poder lanzar la Campaign. Para obtener más información sobre el proceso de aprobación, consulta [Aprobación de Campaign]({{site.baseurl}}/user_guide/messaging/governance/approvals).

## Paso de mensaje en Canvas {#canvas-message-step}

Los pasos de mensaje te permiten añadir un mensaje independiente donde quieras en tu flujo de Canvas. Visita nuestro artículo sobre el [paso de mensaje]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/message_step) para obtener más información.

## Asistente de redacción con IA {#ai-copywriting-assistant}

El [asistente de redacción con IA]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#generate-copy) de Braze envía un nombre o una descripción breve del producto a la herramienta de generación de texto GPT3 de OpenAI para generar textos de marketing similares a los escritos por personas y utilizarlos en tu mensajería. Esta funcionalidad está disponible de forma predeterminada en la mayoría de los creadores de mensajes del panel de Braze.

## Guía de pruebas unitarias de notificaciones push en iOS {#ios-push-notification-unit-testing-guide}

Se ha añadido una [guía de pruebas unitarias de iOS para notificaciones push]({{site.baseurl}}/developer_guide/platforms/legacy_sdks/ios/push_notifications/unit_tests) a la guía del desarrollador. Esta guía proporcionará pruebas unitarias que verificarán si tu app delegate está correctamente configurado.

## Cuestionario de privacidad de Google {#google-privacy-questionnaire}

A partir de abril de 2022, los desarrolladores de Android deben completar el [formulario de seguridad de datos][4] de Google Play para divulgar las prácticas de privacidad y seguridad. Esta [guía del cuestionario de privacidad de Google Play]({{site.baseurl}}/developer_guide/analytics/managing_data_collection?sdktab=android#android_privacy-questionnaire) proporciona instrucciones sobre cómo completar este nuevo formulario con información sobre cómo Braze maneja los datos de tu aplicación.

## RelayState SAML inicio de sesión único

Se han actualizado las instrucciones de configuración inicial de inicio de sesión único para recomendar el uso de una clave de API `RelayState`. Para obtener más información, consulta la [configuración de SAML inicio de sesión único]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/saml_sso_setup) y los artículos correspondientes de [OneLogin]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/onelogin), [Okta]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/okta) y [Azure Active Directory]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/microsoft_entra_sso).

## Actualizaciones de la integración de Talon.One {#talonone-integration-updates}

Nuestro artículo sobre la asociación con [Talon.One]({{site.baseurl}}/partners/data_and_analytics/loyalty/talonone) ahora tiene pasos de integración, endpoints y ejemplos actualizados. Si estás aprovechando la asociación con Talon.One, te recomendamos actualizar tu integración en consecuencia.

## Lanzamiento de Braze Web SDK or kit de desarrollo de software V4 {#braze-web-sdk-v4-released}

El equipo de SDKs de Braze ha lanzado Web SDK or kit de desarrollo de software v4. Para consultar una lista de cambios importantes, actualizaciones y novedades, visita nuestro [registro de cambios](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md) del Web SDK or kit de desarrollo de software. Se ha creado una [guía de actualización](https://github.com/braze-inc/braze-web-sdk/blob/master/UPGRADE_GUIDE.md) para quienes estén actualizando de V3 a V4.

## Obsolescencia de Grouparoo {#grouparoo-deprecation}

El soporte para Grouparoo se ha descontinuado a partir de abril de 2022.
