# Lanzamiento del 26 de julio de 2022 {#july-26-2022-release}

## Canvas Flow
Se ha lanzado la última versión del producto Canvas, [Canvas Flow]({{site.baseurl}}/user_guide/engagement_tools/canvas/create_a_canvas/create_a_canvas#editing-a-step). Con Canvas Flow tienes acceso a [componentes de Canvas]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/about) ligeros, [propiedades de entrada persistentes]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas/context_and_event_properties/canvas_persistent_entry_properties) y [edición posterior al lanzamiento]({{site.baseurl}}/post-launch_edits).

![Resumen visual de Canvas Flow mostrando componentes ligeros y flujo de ramificación.]({% image_buster /assets/img/canvas_flow.png %})

## Arreglo de objetos {#array-of-objects}
Usa un [arreglo de objetos]({{site.baseurl}}/user_guide/data/activation/attributes/array_of_objects) para agrupar atributos relacionados. Por ejemplo, puedes tener un grupo de objetos de mascotas, objetos de canciones y objetos de cuentas que pertenecen a un mismo usuario. Estos arreglos de objetos se pueden usar para personalizar tu mensajería con Liquid, o para crear Segments de audiencia si algún elemento dentro de un objeto coincide con los criterios.

## Integraciones de partners actualizadas {#updated-partner-integrations}
[Amplitude Recommend]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/amplitude/amplitude_audiences) y [mParticle]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/mparticle/mparticle) ahora tienen pasos de integración actualizados. Si aprovechas estos partners, visita su documentación para asegurarte de haber seguido la configuración más reciente.

## Requisitos de Shopify {#shopify-requirements}
- Los permisos de usuario requeridos que se enumeran en los [requisitos previos]({{site.baseurl}}/partners/message_orchestration/channel_extensions/ecommerce/shopify/shopify#prerequisites) se han actualizado.
- Las [cargas útiles]({{site.baseurl}}/partners/message_orchestration/channel_extensions/ecommerce/shopify/shopify#supported-shopify-events) de ejemplo de Shopify que incluyen las propiedades `price`, `total_price`, `total_discounts` y `amount` se han actualizado para dar formato a estas propiedades como números en lugar de cadenas.

## Actualizaciones de predicciones {#prediction-updates}
El periodo máximo para predicciones de cancelación y predicciones de compra ha aumentado de 14 días a 60 días.

## Actualizaciones del SDK {#sdk-updates}
Se han publicado las siguientes actualizaciones del SDK. Los cambios de última hora se enumeran en esta sección; todas las demás actualizaciones se pueden encontrar consultando los registros de cambios del SDK correspondientes.
- [SDK Web 4.1.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md#410)
- [SDK de Cordova 2.30.1](https://github.com/Appboy/appboy-cordova-sdk/blob/master/CHANGELOG.md#2301)
- [SDK de Unity 3.8.1](https://github.com/Appboy/appboy-unity-sdk/blob/master/CHANGELOG.md#381)
- [SDK de SWIFT 5.0.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#501)
- [SDK de Roku 0.1.2](https://github.com/braze-inc/braze-roku-sdk/blob/main/CHANGELOG.md#012)
- [SDK de React Native 1.37.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md#1370)
  - El SDK de Braze para React Native ahora exporta su objeto predeterminado como un módulo ES. Si actualmente importas el SDK usando `require()`, ahora deberás importarlo como un módulo ES estándar (por ejemplo, import Braze from "`@braze/react-native-sdk`").
- [SDK de Android 22.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2200)
  - `Appboy.java` es ahora `Braze.kt`. Los clientes de Kotlin deberán actualizar su código para soportar el uso de las propiedades de Kotlin en el singleton de Braze cuando sea necesario.
    - `Braze.registerPushToken()`/`Braze.getRegisteredPushToken()` es ahora `Braze.setRegisteredPushToken()/Braze.getRegisteredPushToken()`. Si usas Kotlin, utiliza la propiedad `Braze.registeredPushToken`.
    - `Braze.getDeviceId` es ahora simplemente `Braze.deviceId` para Kotlin.
    - `Braze.enableMockNetworkAppboyRequestsAndDropEventsMode` es ahora `Braze.enableMockNetworkRequestsAndDropEventsMode()`.
    - `Appboy.java` ha sido eliminado. Por ejemplo, las llamadas como `Appboy.getInstance()` deberán ser `Braze.getInstance()` de ahora en adelante.
    - Se reemplazó `setCustomAppboyNotificationFactory()` por `setCustomBrazeNotificationFactory()` / `customBrazeNotificationFactory`.
    - Se renombró `enableMockAppboyNetworkRequestsAndDropEventsMode` a `enableMockNetworkRequestsAndDropEventsMode`.
  - Se movió `com.appboy.IBrazeEndpointProvider` a `com.braze.IBrazeEndpointProvider`.
  - Se renombró `com.braze.events.IEventSubscriber` a `com.braze.events.IEventSubscriber`.
  - Se eliminó `Appboy.registerAppboyPushMessages()` / `Appboy.getAppboyPushMessageRegistrationId()`. Se reemplazó por `getRegisteredPushToken()` / `setRegisteredPushToken()`.
  - Se reemplazó `IAppboyNotificationFactory` por `IBrazeNotificationFactory`.
  - Se eliminó `com.appboy.ui.inappmessage.listeners.IHtmlInAppMessageActionListener`. Usa `com.braze.ui.inappmessage.listeners.IHtmlInAppMessageActionListener` en su lugar.
