# Lanzamiento del 13 de diciembre de 2022 {#december-13-2022-release}

## News Feed está obsoleto {#news-feed-is-deprecated}
News Feed está siendo obsoleto. Braze recomienda que los clientes que utilizan nuestra herramienta News Feed migren a nuestro canal de mensajería Content Cards, ya que es más flexible, personalizable y fiable. Consulta la [guía de migración]({{site.baseurl}}/user_guide/channels/content_cards) para obtener más información.

## Nuevos endpoints de API: Catálogos {#new-api-endpoints-catalogs}
Usa los [endpoints de API de catálogos de Braze]({{site.baseurl}}/api/endpoints/catalogs) para añadir, editar y gestionar tus [catálogos]({{site.baseurl}}/user_guide/data/activation/catalogs) y los detalles de los elementos del catálogo. Puedes usar los endpoints de catálogo asíncronos para realizar cambios masivos en tu catálogo.

## Atributos HTML para enlaces en el editor de arrastrar y soltar para correo electrónico {#html-attributes-for-links-in-the-drag-drop-editor-for-email}
Ahora puedes [añadir atributos HTML]({{site.baseurl}}/user_guide/message_building_by_channel/email/drag_and_drop/#creative-details/) a cualquier URL dentro de los bloques de editor `Image`, `Button` o `Text` en el editor de arrastrar y soltar para correo electrónico. Con atributos personalizados, puedes agregar fácilmente información adicional a las etiquetas HTML en los correos electrónicos. Esto puede ser especialmente útil para la personalización de mensajes, la segmentación y el estilo.

## Alternar Mostrar mapa de calor {#show-heatmap-toggle}
Ahora puedes usar la [opción Mostrar mapa de calor]({{site.baseurl}}/user_guide/channels/email/reporting#heatmaps) para acceder a una vista visual de tus **análisis de mensajes** que muestra la frecuencia general y la ubicación de los clics a lo largo de la vida útil de la Campaign de correo electrónico. También puedes descargar una copia de tus mapas de calor para consultarlos en el futuro.

## Configuración de correo electrónico actualizada {#updated-email-settings}
La sección anterior **Configuración general de correo electrónico** se ha dividido en dos nuevas secciones: **Configuración de envío** y **Páginas de suscripción y pies de página.** Para obtener más información sobre las configuraciones individuales, consulta [Configuración de correo electrónico]({{site.baseurl}}/user_guide/administrative/app_settings/email_settings#sending-configuration).

## Genera imágenes con IA para tu biblioteca de medios {#generate-ai-images-for-your-media-library}
Puedes generar imágenes para tu biblioteca de medios utilizando DALL·E 2, un sistema de IA de OpenAI que puede crear imágenes realistas y arte a partir de una descripción en lenguaje natural. Lee más sobre [Generar una imagen usando IA]({{site.baseurl}}/user_guide/engagement_tools/templates_and_media/media_library#generate-ai).

## Mejoras en los atributos personalizados anidados {#enhancements-to-nested-custom-attributes}
Puedes usar atributos personalizados anidados para enviar objetos como un nuevo tipo de datos para atus atributos personalizados.
- Puedes [desencadenar acciones cuando un objeto de atributo personalizado anidado cambia]({{site.baseurl}}/user_guide/data_and_analytics/custom_data/custom_attributes/nested_custom_attribute_support#trigger-nested-custom-attribute-changes).
- También puedes [personalizar tus mensajes usando un objeto de atributo personalizado y Liquid]({{site.baseurl}}/user_guide/data_and_analytics/custom_data/custom_attributes/nested_custom_attribute_support#personalization).

## Nuevo bloque de video {#new-video-block}
Se ha añadido un nuevo bloque de contenido para [Video]({{site.baseurl}}/user_guide/message_building_by_channel/email/drag_and_drop/dnd_editor_blocks#video) al editor de arrastrar y soltar para correo electrónico.

## Identificador opcional para el proveedor (Vendor) - Swift {#optional-identifier-for-vendor-collection-swift}
En versiones anteriores de Braze iOS Swift SDK or kit de desarrollo de software, el campo IDFV (Identifier for Vendor) se recopilaba automáticamente como el ID de dispositivo del usuario. A partir de Swift SDK or kit de desarrollo de software v5.7.0, el campo IDFV puede desactivarse opcionalmente y, en su lugar, Braze establecerá un UUID aleatorio como ID de dispositivo. Para más información, consulta [Recopilar IDFV]({{site.baseurl}}/developer_guide/analytics/managing_data_collection/?sdktab=swift).

## Cuentas de lectura de Snowflake {#snowflake-reader-accounts}
Las cuentas de lectura de Snowflake ofrecen a los usuarios acceso a los mismos datos y funcionalidades que [Snowflake Data Sharing]({{site.baseurl}}/partners/snowflake), todo sin necesidad de una cuenta de Snowflake ni una relación de cliente con Snowflake. Con las cuentas de lectura, Braze creará y compartirá tus datos en una cuenta y te proporcionará credenciales para iniciar sesión y acceder a tus datos. Esto hará que toda la facturación de uso y compartición de datos sea gestionada íntegramente por Braze.

Para obtener más información, ponte en contacto con tu CSM or administrador de éxito de cliente or administrador de éxito de cliente.

## Integración de Shopify actualizada {#updated-shopify-integration}
La [integración de Shopify]({{site.baseurl}}/partners/shopify) ahora te permite recopilar adhesiones voluntarias de correo electrónico y servicio de mensajes cortos desde tu tienda de Shopify y asignarlas a un grupo de suscripción en Braze.

## Nuevas asociaciones con Braze {#new-braze-partnerships}

### Ada - Cuestionarios {#ada-surveys}
La integración de [Ada]({{site.baseurl}}/partners/home) y Braze te permite enriquecer los perfiles de usuario con datos recopilados de tus conversaciones automatizadas de Ada. Puedes establecer atributos de usuario personalizados basados en la información que recopilas durante un chat de Ada y registrar eventos personalizados en Braze en puntos específicos de una conversación de Ada. Al conectar tu chatbot de Ada con Braze, puedes aprender más sobre tus consumidores en función de las preguntas que hacen sobre tu marca o iniciando conversaciones con ellos de forma proactiva, haciéndoles preguntas que te permitan conocer más sobre sus intereses y preferencias.

### B.Layer - Plantillas de mensajes {#blayer-message-templates}
La integración de [B.Layer]({{site.baseurl}}/partners/message_orchestration/templates/blayer) y Braze te permite aprovechar el constructor de mensajes dentro de la aplicación de B.Layer para ayudarte a crear mensajes dentro de la aplicación alineados con tu marca que pueden exportarse como un archivo zip o HTML en línea a Braze. Esta integración no requiere recursos de desarrollo adicionales, lo que te ahorra tiempo y presupuesto.

### Contentsquare - Análisis {#contentsquare-analytics}
La integración de [Contentsquare]({{site.baseurl}}/partners/data_and_analytics/analytics/contentsquare) y Braze te permite enviar Live Signals (fraude, señales de frustración, etc.) como eventos personalizados en Braze. Aprovecha la información sobre la experiencia de Contentsquare para mejorar la relevancia y las tasas de conversión de tus campañas segmentando los mensajes en función de la experiencia digital y el lenguaje corporal de tus clientes.

### Dynamic Yield - Contenido dinámico {#dynamic-yield-dynamic-content}
La asociación entre [Dynamic Yield]({{site.baseurl}}/partners/dynamic_yield) y Braze te permite aprovechar el motor de recomendaciones y segmentación de Dynamic Yield para crear bloques de experiencia que pueden integrarse en los mensajes de Braze. Los bloques de experiencia pueden estar compuestos por:
{% multi_lang_include partners/message_personalization/dynamic_yield_experience_blocks.md %}

### Octolis - Análisis {#octolis-analytics}
La integración de [Octolis]({{site.baseurl}}/partners/data_and_analytics/analytics/contentsquare) y Braze actúa como middleware entre tus orígenes de datos sin procesar y Braze, lo que te permite recuperar y unificar datos de diversas fuentes, tanto en línea como fuera de línea.

### Jacquard - Pruebas A/B {#jacquard-ab-testing}
[Jacquard React]({{site.baseurl}}/partners/message_personalization/dynamic_content/content_optimization_testing/jacquard), impulsado por Jacquard X, aprovecha Braze Currents y contenido conectado para recopilar información de seguimiento de clics de tus suscriptores a través de webhooks. Después, Jacquard vincula esos eventos con tus variantes de lenguaje para la optimización del lenguaje en tiempo real.

### Sheetlabs - Contenido dinámico {#sheetlabs-dynamic-content}
La integración de [Sheetlabs]({{site.baseurl}}/partners/message_personalization/dynamic_content/personalization_engines/sheetlabs) y Braze te permite aprovechar el [contenido conectado]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content) para incluir las API de Sheetlabs dentro de tus Campaigns de marketing en Braze. Esto se utiliza comúnmente para proporcionar un puente entre una hoja de cálculo de Google (que el equipo de marketing actualiza directamente) y las plantillas de Braze. Esto te permite lograr más con las plantillas de Braze, como traducciones o conjuntos más grandes de atributos personalizados.

### Tellius - Análisis {#tellius-analytics}
La integración de [Tellius]({{site.baseurl}}/partners/data_and_analytics/business_intelligence/tellius) y Braze permite a los usuarios aprovechar los datos, sin depender de ingenieros de BI, para crear paneles y generar análisis que faciliten mejores decisiones de marketing.

### ThoughtSpot - Análisis {#thoughtspot-analytics}
La integración de [ThoughtSpot]({{site.baseurl}}/partners/data_and_analytics/business_intelligence/thoughtspot) y Braze aprovecha los bloques TML de ThoughtSpot, que permiten a los usuarios de la empresa acelerar sus análisis de comportamiento de usuario con plantillas predefinidas de hojas de trabajo y modelos. Esta integración permite a los usuarios buscar de forma ilimitada en sus datos de interacción de Braze y descubrir análisis accionables.

### Wunderkind - Análisis {#wunderkind-analytics}
La integración de [Wunderkind]({{site.baseurl}}/partners/ecommerce/analytics_workflow/wunderkind) y Braze te permite analizar el aumento del rendimiento e identificar más usuarios anónimos, escalando significativamente los mensajes uno a uno enviados a través de Braze y los contactos añadidos directamente a Braze.

## Actualizaciones del SDK or kit de desarrollo de software {#sdk-updates}
Se han publicado las últimas actualizaciones del SDK or kit de desarrollo de software. Los cambios de última hora se enumeran en la sección de actualizaciones del SDK or kit de desarrollo de software; todas las demás actualizaciones se pueden encontrar en los registros de cambios del SDK or kit de desarrollo de software correspondientes.

- [iOS Swift SDK or kit de desarrollo de software 5.6.3-5.7.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
- [Flutter SDK or kit de desarrollo de software 3.0.0](https://pub.dev/packages/braze_plugin/changelog)
    - El puente nativo de iOS ahora utiliza el [nuevo Braze Swift SDK or kit de desarrollo de software, versión 5.6.4](https://github.com/braze-inc/braze-swift-sdk). El objetivo mínimo de despliegue en iOS es 10.0.
    - Durante la migración, actualiza tu proyecto con los siguientes cambios:
        - Para inicializar Braze, [sigue estos pasos de integración para crear un objeto de configuración](https://braze-inc.github.io/braze-swift-sdk/tutorials/braze/a2-configure-braze). Luego, añade este código para completar la configuración: `let braze = BrazePlugin.initBraze(configuration)`
        - Para seguir usando `SDWebImage` como dependencia, añade esta línea al `/ios/Podfile` de tu proyecto: `pod 'SDWebImage', :modular_headers => true`. Luego, sigue [estas instrucciones de configuración](https://braze-inc.github.io/braze-swift-sdk/tutorials/braze/c3-gif-support).
        - Para orientación sobre otros cambios, como la recepción de datos de mensajes dentro de la aplicación y Content Cards, consulta nuestro ejemplo de [`AppDelegate.swift`](https://github.com/braze-inc/braze-flutter-sdk/blob/master/example/ios/Runner/AppDelegate.swift).
- [React Native SDK or kit de desarrollo de software v1.41.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
- [Web SDK or kit de desarrollo de software 4.5.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
