# Lanzamiento del 8 de marzo de 2022 {#march-8-2022-release}

## Mensajes dentro de la aplicación para Roku {#in-app-messages-for-roku}

¡Braze ahora permite enviar mensajes dentro de la aplicación a tus usuarios en sus dispositivos Roku! Ten en cuenta que esto requiere una configuración adicional del SDK or kit de desarrollo de software y no está disponible de forma predeterminada. Para obtener más información sobre la integración de mensajes dentro de la aplicación para Roku, consulta [Mensajes dentro de la aplicación de Roku]({{site.baseurl}}/developer_guide/in_app_messages/?sdktab=roku).

## Modo de filtro completo para predicciones de cancelación y predicciones de compra {#full-filter-mode-for-churn-predictions-and-purchase-predictions}

Para crear una nueva predicción de forma inmediata, solo se admite de forma predeterminada un subconjunto de filtros de segmentación de Braze. Ahora puedes habilitar el modo de filtro completo para activar todos los filtros de segmentación; sin embargo, este modo te limita a una ventana al crear la predicción. Para más información, consulta los siguientes artículos:

- [Crear una predicción de cancelación]({{site.baseurl}}/user_guide/predictive_suite/predictive_churn/creating_a_churn_prediction/#full-filter-mode)
- [Crear una predicción de compra]({{site.baseurl}}/user_guide/predictive_suite/predictive_purchases/creating_a_purchase_prediction/#full-filter-mode)

## Opción de reorientación para respuestas con palabras clave {#retargeting-option-for-keyword-responses}

Al ver los análisis de una campaña de servicio de mensajes cortos, ahora puedes crear cómodamente un segmento para reorientar basándote en los usuarios que respondieron con una categoría de palabras clave específica. Para más información, consulta [Respuestas con palabras clave]({{site.baseurl}}/user_guide/message_building_by_channel/sms/sms_campaign_analytics/#keyword-responses) en los informes de servicio de mensajes cortos.

## Mejores prácticas de recopilación de datos {#data-collection-best-practices}

¿Te has preguntado cuándo y cómo debes recopilar datos de usuario cuando manejas tanto usuarios conocidos como desconocidos? Sabemos que el ciclo de vida de un perfil de usuario en Braze puede ser un poco confuso, así que hemos reunido algunas [mejores prácticas de recopilación de datos]({{site.baseurl}}/user_guide/data/unification/user_data/best_practices/) para ayudar a aclarar los diferentes métodos y mejores prácticas para recopilar datos de usuario nuevos y existentes.

## Obsolescencia de la API de Transifex {#transifex-api-deprecation}

A partir del 7 de abril de 2022, Transifex dejará obsoletas sus versiones 2 y 2.5 de la API para dar paso a la versión 3. Después de esta fecha, las versiones 2 y 2.5 dejarán de estar operativas y las solicitudes correspondientes fallarán. Si aprovechas la API de Transifex, actualiza en consecuencia tus llamadas a contenido conectado. Para más información, consulta [Transifex]({{site.baseurl}}/partners/message_personalization/localization/transifex/).

## Nuevas asociaciones de Braze {#new-braze-partnerships}

### Toovio - CDP or plataforma de datos de los clientes or plataforma de datos de los clientes {#toovio-customer-data-platform}

La asociación entre Braze y [Toovio]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/toovio/) proporciona la activación de mensajes casi en tiempo real, las herramientas para impulsar el rendimiento incremental y el acceso a las herramientas avanzadas de medición de campañas de Toovio.

### Snowplow - Análisis {#snowplow-analytics}

La integración de Braze y [Snowplow]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/snowplow/) permite a los usuarios reenviar eventos de Snowplow a Braze mediante el etiquetado del lado del servidor de Google Tag Administrador. La etiqueta de Braze de Snowplow te permite enviar eventos a Braze y ofrece flexibilidad y control adicionales:

- Visibilidad total de todas las transformaciones de los datos
- Capacidad para evolucionar en sofisticación con el tiempo
- Todos los datos permanecen en tu nube privada hasta que decidas reenviarlos
- Facilidad de configuración gracias a las numerosas bibliotecas de etiquetas y a la conocida interfaz de usuario de Google Tag Administrador

Aprovecha los ricos datos de comportamiento de Snowplow para impulsar potentes interacciones centradas en el cliente en Braze y entregar mensajes personalizados en tiempo real.

### Clarisights - Análisis {#clarisights-analytics}

La integración de Braze y [Clarisights]({{site.baseurl}}/partners/data_and_analytics/business_intelligence/clarisights/) te permite importar datos de Campaigns y Canvas de Braze para lograr una interfaz de informes unificada de rendimiento y marketing de CRM or administración de las relaciones con el cliente/retención.

### Wyng - Contenido dinámico {#wyng-dynamic-content}

La integración de Braze y [Wyng]({{site.baseurl}}/partners/wyng/) te permite aprovechar las experiencias de Wyng para ofrecer personalización en Campaigns y Canvas de Braze. Wyng también incluye un portal de preferencias del cliente para que los usuarios puedan controlar los datos y preferencias que comparten con una marca.

### Grouparoo - Automatización del flujo de trabajo {#grouparoo-workflow-automation}

La integración de Braze y [Grouparoo]({{site.baseurl}}/releases/deprecations/grouparoo/) sincroniza los datos del almacén con Braze. Las programaciones de sincronización automática mantienen las comunicaciones con los clientes al día con información actualizada.

### Lexer - CDP or plataforma de datos de los clientes or plataforma de datos de los clientes {#lexer-customer-data-platform}

La integración de Braze y [Lexer]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/lexer/) te permite sincronizar datos entre las dos plataformas. Utiliza tus datos de Lexer para crear segmentos valiosos en Braze o importa los que ya tienes a Lexer para obtener información.

### Knak - Orquestación del correo electrónico {#knak-email-orchestration}

La integración de Braze y [Knak]({{site.baseurl}}/partners/knak/) te permite crear correos electrónicos totalmente adaptables en cuestión de minutos u horas, en lugar de días o semanas, y exportarlos como plantillas de Braze listas para usar. Knak está pensado para los especialistas en marketing que quieren mejorar la creación de correos electrónicos para campañas gestionadas en Braze, sin necesidad de agencias externas ni de código manual.
