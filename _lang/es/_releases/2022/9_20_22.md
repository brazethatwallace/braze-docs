# Lanzamiento del 20 de septiembre de 2022 {#september-20-2022-release}

## Guía de API {#api-guide}
Consulta la [Guía de API de Braze]({{site.baseurl}}/api/home) para buscar endpoints según los tipos de endpoint, lo que te ayudará a acotar el glosario.

## Variantes personalizadas {#personalized-variants}
Usa [Variantes personalizadas]({{site.baseurl}}/user_guide/messaging/ab_testing/optimizations) para enviar a cada usuario de tu segmento objetivo la variante con la que es más probable que interactúe.

## Pruebas de Canvas {#testing-canvases}
Después de crear tu Canvas, hay varias comprobaciones que puedes realizar antes del lanzamiento, dependiendo de detalles como el tamaño de tu audiencia o la cantidad de filtros de segmentación. Consulta [Enviar Canvas de prueba]({{site.baseurl}}/user_guide/messaging/canvas/testing_canvases/sending_test_canvases) para obtener consejos.

## Liquid 5
Para los usuarios actuales de la empresa, Liquid 5 está disponible de forma general. Obtén más información sobre las [novedades de Liquid 5]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid#liquid-5-support).

## Nuevas asociaciones de Braze {#new-braze-partnerships}

### Shopify
La integración de Braze y [Shopify]({{site.baseurl}}/partners/shopify) te permite actualizar perfiles de usuario existentes o crear nuevos en Braze para leads, registros y creaciones de cuentas capturados en tu tienda de Shopify.

## Actualizaciones del SDK {#sdk-updates}

Se han publicado las últimas actualizaciones del SDK. Las actualizaciones de última hora se enumeran en la sección de actualizaciones del SDK; todas las demás actualizaciones se pueden encontrar en los registros de cambios correspondientes de cada SDK.

- [Android SDK 23.1.0-23.12](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [React Native SDK v1.38.0–v1.38.1](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - Se actualizó el puente nativo de Android a Braze Android SDK 23.0.1.
  - Se actualizó el puente nativo de iOS a Braze iOS SDK 4.5.0.
  - Braze React Native Android SDK ahora requiere Kotlin directamente para la compilación.
- [Braze Expo Plugin 0.4.0](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - Se renombró la propiedad `fcmSenderID` a `firebaseCloudMessagingSenderId`.
- [Unity 3.9.0](https://github.com/Appboy/appboy-unity-sdk/blob/master/CHANGELOG.md)
  - Se actualizó el plugin de Android para usar Braze Android SDK 23.1.0.
  - Se añadió la posibilidad de solicitar permisos de notificación push en dispositivos Android 13+ mediante `Appboy.AppboyBinding.PromptUserForPushPermissions(false)`.
- [SWIFT SDK 5.3.0-5.4.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#540)
