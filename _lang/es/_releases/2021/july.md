# Julio de 2021 {#july-2021}

## Mensaje dentro de la aplicación de cuestionario simple {#simple-survey-in-app-message}

Utiliza la [plantilla de mensaje dentro de la aplicación de cuestionario simple]({{site.baseurl}}/user_guide/channels/in_app_messages/message_types/simple_survey) para recopilar atributos, información y preferencias de los usuarios que impulsen tu estrategia de campaña. Por ejemplo, puedes preguntar a los usuarios cómo les gustaría utilizar tu aplicación, conocer mejor sus preferencias personales o incluso preguntarles por su satisfacción con una característica concreta. Esta plantilla de cuestionario es compatible tanto con aplicaciones móviles como con navegadores web.

## Biblioteca de ejemplos de Liquid {#liquid-use-case-library}

¿Te preguntas cómo hacer esa cosa con Liquid? ¿Buscas inspiración? Echa un vistazo a nuestra [biblioteca de ejemplos de Liquid]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/liquid_use_cases) para ver una colección de ejemplos que van desde aniversarios y cumpleaños hasta segmentación por plataforma y mucho más.

## Seguimiento por correo electrónico {#email-tracking}

Ahora se puede desactivar el seguimiento de píxeles de apertura y de clics por perfil de usuario. Esta flexibilidad ayuda a los clientes a cumplir las leyes de privacidad regionales, en las que un perfil de usuario individual puede indicar que ya no desea ser objeto de seguimiento. Consulta [Seguimiento de píxeles de apertura y de clics]({{site.baseurl}}/user_guide/channels/email/email_setup/open_pixel_and_click_tracking) para obtener más información.

## Endpoints de la API del perfil de usuario de Amplitude {#amplitude-user-profile-api-endpoints}

La API de perfil de usuario de Amplitude sirve perfiles de usuario de Amplitude. Esto incluye propiedades del usuario, propiedades computadas del usuario, una lista de ID de cohortes que incluyen al usuario y recomendaciones. Consulta [los endpoints de la API del perfil de usuario de Amplitude]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/amplitude/amplitude_user_profile_api) para obtener más información.

## Endpoint de detalles de Campaign {#campaign-details-endpoint}

El [endpoint `/campaigns/details`]({{site.baseurl}}/api/endpoints/export/campaigns/get_campaign_details) ha añadido una respuesta `message` dedicada para el canal de mensajes dentro de la aplicación. Puedes encontrar la documentación al respecto en [Mensajes por canal]({{site.baseurl}}/api/endpoints/export/campaigns/get_campaign_details#messages-by-channel).
