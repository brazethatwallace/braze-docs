# Versión del 17 de septiembre de 2024 {#september-17-2024-release}

## Flexibilidad de datos {#data-flexibility}

### Braze Cloud Data Ingestion para S3 {#braze-cloud-data-ingestion-for-s3}

Puedes usar [Cloud Data Ingestion (CDI) para S3]({{site.baseurl}}/user_guide/data_and_analytics/cloud_ingestion/file_storage_integrations#aws-definitions) para integrar directamente uno o más contenedores de S3 en tu cuenta de AWS con Braze. Cuando se publican nuevos archivos en S3, se envía un mensaje a SQS y Braze Cloud Data Ingestion incorpora esos nuevos archivos.

### MAU or usuarios activos al mes or usuarios activos al mes CY 24-25 {#monthly-active-users-cy-24-25}

Para los clientes que han adquirido Monthly Active Users - CY 24-25, Braze gestiona diferentes límites de velocidad en su endpoint `/users/track`. Para más detalles, consulta [POST: Rastrear usuarios]({{site.baseurl}}/api/endpoints/user_data/post_user_track#monthly-active-users-cy-24-25-universal-mau-web-mau-and-mobile-mau).

## Desbloqueo de la creatividad {#unlocking-creativity}

### Creación de plantillas de elementos del catálogo con Liquid {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="Early access" %}

Usa la marca `:rerender` en una etiqueta de Liquid para [representar el contenido Liquid de un elemento del catálogo]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog#using-liquid). Por ejemplo, si representas el siguiente contenido Liquid:

{% raw %}
```liquid
Hi ${first_name}
{% catalog_items Messages greet_msg :rerender %}
{{ items[0].Welcome_Message }}
```
{% endraw %}

Esto se mostrará de la siguiente manera:

{% raw %}
```
Hi Peter,
Welcome to our store, Peter!
```
{% endraw %}

### Mensajes de respuesta de WhatsApp {#whatsapp-response-messages}

{% multi_lang_include release_type.md release="General availability" %}

Puedes usar [mensajes de respuesta]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#response-messages) para responder a los mensajes entrantes de WhatsApp de tus usuarios. ## Nuevas integraciones de Braze {#new-braze-partnerships}

### Inbox Monster - Análisis {#inbox-monster-analytics}

[Inbox Monster]({{site.baseurl}}/partners/data_and_analytics/analytics/inbox_monster) es una plataforma de señales de bandeja de entrada que ayuda a las marcas empresariales a que cada envío llegue a su destino. Es una línea de productos integrada de soluciones para la capacidad de entrega, la representación creativa y la monitorización de servicio de mensajes cortos, que empodera a los equipos modernos de CRM or administración de las relaciones con el cliente or administración de las relaciones con el cliente (CRM or administración de las relaciones con el cliente) y acaba con el miedo a los envíos.

### SessionM - Fidelización {#sessionm-loyalty}

[SessionM]({{site.baseurl}}/partners/data_and_analytics/loyalty/sessionm) es una plataforma de interacción con los clientes y fidelización que proporciona características de gestión de Campaigns y soluciones de gestión de fidelización para ayudar a los especialistas en marketing a impulsar comunicaciones dirigidas que aumenten la participación y la rentabilidad.

## Automatización de IA y ML {#ai-and-ml-automation}

### Recomendaciones de artículos en tendencia {#trending-item-recommendations}

Además del modelo "Personalizado con IA", la característica de [recomendaciones de artículos con IA]({{site.baseurl}}/user_guide/sage_ai/recommendations/about_item_recommendations#trending) también incluye un modelo de recomendación para "Tendencias", que destaca artículos que tuvieron el mayor impulso positivo en cuanto a interacciones recientes de los usuarios.

## Configuración {#settings}

### Roles

{% multi_lang_include release_type.md release="General availability" %}

Los [roles]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/user_permissions#creating-a-role) permiten una mayor estructura al agrupar tus permisos personalizados individuales con controles de acceso al espacio de trabajo. Esto es especialmente útil si tienes muchas marcas o espacios de trabajo regionales en un solo panel. Con los roles, puedes añadir usuarios del panel a los espacios de trabajo apropiados y otorgarles directamente los permisos asociados.

### Informe de eventos de seguridad {#security-event-report}

Añadimos una lista completa de los [eventos de seguridad]({{site.baseurl}}/user_guide/administrative/app_settings/company_settings/security_settings#downloading-a-security-event-report) que pueden aparecer en tu informe de eventos de seguridad descargado.

### Informe de uso de mensajes {#message-usage-report}

{% multi_lang_include release_type.md release="Early access" %}

El [panel de uso de créditos]({{site.baseurl}}/credits_usage_dashboard) proporciona información de autoservicio sobre tu uso de créditos para una vista completa del uso histórico y actual en comparación con las asignaciones contractuales. Estos datos pueden reducir tu confusión y ayudarte a realizar ajustes para prevenir riesgos de excedentes.

## SDK or kit de desarrollo de software

### Inicialización retardada para el SDK or kit de desarrollo de software Swift de Braze {#delayed-initialization-for-the-braze-swift-sdk}

Configura la [inicialización retardada]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=swift#step-2-set-up-delayed-initialization-optional) para inicializar tu SDK or kit de desarrollo de software Swift de Braze de forma asíncrona, garantizando al mismo tiempo que se conserva la gestión de las notificaciones push. Esto puede ser útil cuando necesites configurar otros servicios antes de inicializar el SDK or kit de desarrollo de software, como obtener datos de configuración de un servidor o esperar el consentimiento del usuario.
