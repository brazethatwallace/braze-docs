# Versión del 17 de septiembre de 2024 {#september-17-2024-release}

## Flexibilidad de los datos {#data-flexibility}

### Ingesta de datos de Cloud de Braze para S3 {#braze-cloud-data-ingestion-for-s3}

Puedes utilizar la [Ingesta de datos de Cloud (CDI) para S3]({{site.baseurl}}/user_guide/data_and_analytics/cloud_ingestion/file_storage_integrations/#aws-definitions) para integrar directamente uno o varios contenedores de S3 de tu cuenta de AWS con Braze. Cuando se publican nuevos archivos en S3, se envía un mensaje a SQS, y la Ingesta de datos de Cloud de Braze recoge esos nuevos archivos.

### Usuarios activos al mes CY 24-25 {#monthly-active-users-cy-24-25}

Para los clientes que hayan comprado Usuarios activos al mes - CY 24-25, Braze gestiona diferentes límites de velocidad en su punto de conexión `/users/track`. Para más detalles, consulta [POST: Seguimiento de usuarios]({{site.baseurl}}/api/endpoints/user_data/post_user_track/#monthly-active-users-cy-24-25).

## Desbloquear la creatividad {#unlocking-creativity}

### Elementos del catálogo con plantillas, incluido Liquid {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="Early access" %}

Utiliza la marca `:rerender` en una etiqueta de Liquid para [mostrar el contenido Liquid de un elemento del catálogo]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog/#using-liquid). Por ejemplo, si generas el siguiente contenido Liquid:

{% raw %}
```liquid
Hi ${first_name}
{% catalog_items Messages greet_msg :rerender %}
{{ items[0].Welcome_Message }}
```
{% endraw %}

Se mostrará de la siguiente manera:

{% raw %}
```
Hi Peter,
Welcome to our store, Peter!
```
{% endraw %}

## Canales robustos {#robust-channels}

### Mensajes de respuesta de WhatsApp {#whatsapp-response-messages}

{% multi_lang_include release_type.md release="General availability" %}

Puedes utilizar [mensajes de respuesta]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/create/#response-messages) para responder a los mensajes entrantes de WhatsApp de tus usuarios. Estos mensajes se crean dentro de la aplicación en Braze durante tu experiencia de composición y pueden editarse en cualquier momento. Puedes utilizar Liquid para adaptar el idioma del mensaje de respuesta a los usuarios adecuados.

### Plantillas de Canvas {#canvas-templates}

{% multi_lang_include release_type.md release="General availability" %}

Crea [plantillas de Canvas]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/) para perfeccionar tu mensajería creando un marco coherente que pueda personalizarse fácilmente para adaptarse a tus objetivos específicos en todos tus Canvas.

### Páginas de inicio {#landing-pages}

{% multi_lang_include release_type.md release="Beta" %}

Las [páginas de inicio]({{site.baseurl}}/user_guide/messaging/landing_pages/) de Braze son páginas web independientes que pueden impulsar tu estrategia de captación e interacción de usuarios.

### Cambios desde la última visita {#changes-since-last-viewed}

Puedes ver el número de actualizaciones de tus [Canvas]({{site.baseurl}}/user_guide/engagement_tools/canvas/testing_canvases/measuring_and_testing_with_canvas_analytics/#changes-since-last-viewed), Campaigns y [Segments]({{site.baseurl}}/user_guide/engagement_tools/segments/managing_segments/#changes-since-last-viewed) realizadas por otros miembros de tu equipo consultando la métrica *Cambios desde la última visita* en las respectivas páginas de resumen (como la página de resumen de una [Campaign de correo electrónico]({{site.baseurl}}/user_guide/message_building_by_channel/email/reporting_and_analytics/email_reporting/#changes-since-last-viewed)).

### Solución de problemas de solicitudes de webhook y contenido conectado {#troubleshooting-webhook-and-connected-content-requests}

[Solución de problemas de solicitudes de webhook y contenido conectado]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content/troubleshooting_webhooks_and_connected_content/) explica cómo solucionar los códigos de error de webhook y contenido conectado, incluyendo cuáles son los errores y los pasos para resolverlos.

## Nuevas asociaciones de Braze {#new-braze-partnerships}

### Inbox Monster - Análisis {#inbox-monster-analytics}

[Inbox Monster]({{site.baseurl}}/partners/data_and_analytics/analytics/inbox_monster/) es una plataforma de señales de buzón de entrada que ayuda a las marcas empresariales a aterrizar cada envío. Es una línea de productos integrada de soluciones de capacidad de entrega, renderización creativa y monitorización de SMS, que capacita a los equipos modernos de administración de las relaciones con el cliente (CRM) y acaba con los sustos de los envíos.

### SessionM - Fidelización {#sessionm-loyalty}

[SessionM]({{site.baseurl}}/partners/data_and_analytics/loyalty/sessionm/) es una plataforma de interacción con los clientes y fidelización que proporciona características de gestión de campañas y soluciones de gestión de la fidelización para ayudar a los especialistas en marketing a impulsar el alcance específico para aumentar la interacción y la ganancia.

## Automatización de IA y ML {#ai-and-ml-automation}

### Recomendaciones de elementos en tendencia {#trending-item-recommendations}

Además del modelo "AI Personalizado", la característica de [recomendaciones de elementos de IA]({{site.baseurl}}/user_guide/sage_ai/recommendations/about_item_recommendations/#trending) también incluye un modelo de recomendación de "Tendencias", que presenta los elementos que tuvieron el impulso más positivo en lo que respecta a las interacciones recientes de los usuarios.

## Configuración {#settings}

### Roles

{% multi_lang_include release_type.md release="General availability" %}

[Los roles]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/user_permissions/#creating-a-role) permiten una mayor estructuración al agrupar tus permisos personalizados individuales con controles de acceso al espacio de trabajo. Esto es especialmente útil si tienes muchas marcas o espacios de trabajo regionales en un mismo dashboard. Con los roles, puedes añadir usuarios del dashboard a los espacios de trabajo adecuados y concederles directamente los permisos asociados.

### Informe de eventos de seguridad {#security-event-report}

Hemos añadido una lista completa de los [eventos de seguridad]({{site.baseurl}}/user_guide/administrative/app_settings/company_settings/security_settings/#downloading-a-security-event-report) que pueden aparecer en tu informe de eventos de seguridad descargado.

### Informe de uso de mensajes {#message-usage-report}

{% multi_lang_include release_type.md release="Early access" %}

El [panel de uso de créditos]({{site.baseurl}}/credits_usage_dashboard/) proporciona información de autoservicio sobre tu uso de créditos para obtener una visión completa del uso histórico y actual comparado con las asignaciones del contrato. Esta información puede reducir tu confusión y ayudarte a hacer ajustes para evitar riesgos de excedente.

## SDK

### Inicialización retardada para el SDK Swift de Braze {#delayed-initialization-for-the-braze-swift-sdk}

Configura la [inicialización retardada]({{site.baseurl}}/developer_guide/sdk_initalization/?sdktab=swift) para inicializar tu SDK Swift de Braze de forma asíncrona, garantizando al mismo tiempo que se conserva la gestión de las notificaciones push. Esto puede ser útil cuando necesites configurar otros servicios antes de inicializar el SDK, como obtener datos de configuración de un servidor o esperar el consentimiento del usuario.
