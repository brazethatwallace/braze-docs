# Versión del 20 de agosto de 2024 {#august-20-2024-release}

## Nuevos ejemplos {#new-use-cases}

### Catálogos {#catalogs}

Puedes incorporar cualquier tipo de datos en un catálogo. Normalmente, los datos son metadatos sobre ofertas, como productos, descuentos, promociones, eventos y similares. Lee nuestros [ejemplos]({{site.baseurl}}/user_guide/data/activation/catalogs) y aprende cómo puedes usar estos datos para dirigirte a los usuarios con mensajes altamente relevantes.

### Suite de inteligencia {#intelligence-suite}

La suite de inteligencia ofrece características potentes para analizar el historial de los usuarios y el rendimiento de Campaigns y Canvas, y luego realizar ajustes automáticos para aumentar la participación, las visualizaciones y las conversiones. Para ver algunos ejemplos de cómo estas características pueden beneficiar a diferentes industrias, consulta nuestros [ejemplos]({{site.baseurl}}/user_guide/brazeai/intelligence_suite).

## Actualización del panel de inicio {#home-dashboard-update}

Puedes [retomar donde lo dejaste]({{site.baseurl}}/user_guide/data_and_analytics/analytics/home_dashboard#pick-up-where-you-left-off) en el panel de Braze con acceso fácil a los archivos que editaste o creaste recientemente. Esta sección aparece en la parte superior de la página **Inicio** del panel de Braze.

## Flexibilidad de datos {#data-flexibility}

### Plantillas de Transformación de datos y nuevo destino {#data-transformation-templates-and-new-destination}

{% multi_lang_include release_type.md release="General availability" %}

Crea tu Transformación de datos utilizando nuestra [biblioteca de plantillas]({{site.baseurl}}/user_guide/data/unification/data_transformation/creating_a_transformation#step-2-create-a-transformation) dedicada para ayudarte a empezar con ciertas plataformas externas, en lugar de código predeterminado. Ahora puedes seleccionar **POST: Send messages immediately via API Only** como tu destino para transformar webhooks de una plataforma de origen y enviar mensajes inmediatos a tus usuarios.

### Fusionar usuarios de forma masiva {#merge-users-in-bulk}

{% multi_lang_include release_type.md release="General availability" %}

Si encuentras perfiles de usuario duplicados, puedes [fusionarlos de forma masiva]({{site.baseurl}}/user_guide/audience/manage_audience/merge_duplicate_users#bulk-merging) para ayudar a optimizar tus datos.

### Exportar atributos personalizados {#export-custom-attributes}

{% multi_lang_include release_type.md release="General availability" %}

Puedes [exportar la lista de atributos personalizados]({{site.baseurl}}/user_guide/data_and_analytics/custom_data/custom_attributes#exporting-data) como un archivo CSV seleccionando **Exportar todo** en la página de **Atributos personalizados**. Se generará el archivo CSV y se te enviará un enlace de descarga por correo electrónico.

### Lista de IP permitidas de Currents {#currents-ip-allowlisting}

Braze enviará datos de Currents desde las IP enumeradas, que se añaden automática y dinámicamente a cualquier clave de API que haya sido incluida en la [lista de permitidos]({{site.baseurl}}/user_guide/data/distribution/braze_currents/setting_up_currents).

## Canales robustos {#robust-channels}

### Nueva experiencia del constructor de segmentos {#new-segment-builder-experience}

{% multi_lang_include release_type.md release="General availability" %}

Crea un segmento utilizando nuestra [experiencia actualizada]({{site.baseurl}}/user_guide/audience/segments/creating_a_segment). Los segmentos se actualizan en tiempo real a medida que cambian los datos, y puedes crear tantos segmentos como necesites para tus propósitos de segmentación y mensajería.

### Métricas por segmentos {#metrics-by-segments}

Utiliza las plantillas de informe del [Generador de consultas]({{site.baseurl}}/user_guide/analytics/reports/query_builder) para desglosar las métricas de rendimiento de Campaigns, Canvas, variantes y pasos por segmentos.

### Adquisición de número de teléfono {#phone-number-acquisition}

Para utilizar el canal de mensajería de WhatsApp, necesitarás un número de teléfono que cumpla con los requisitos de WhatsApp para su [API en la nube](https://developers.facebook.com/docs/whatsapp/cloud-api/phone-numbers) o [API local](https://developers.facebook.com/docs/whatsapp/on-premises/phone-numbers).

Debes adquirir tu número de teléfono por tu cuenta, ya que Braze no proporcionará el número por ti. Puedes comprar un teléfono físico con una tarjeta SIM a través de tu proveedor de telefonía empresarial o utilizar uno de nuestros partners: Twilio o Infobip. **Debes tener tu propia cuenta de Twilio o Infobip, ya que esto no se puede hacer a través de Braze.**

## Nuevas alianzas de Braze {#new-braze-partnerships}

### Zendesk Chat - Chat instantáneo {#zendesk-chat-instant-chat}

La integración de Braze y [Zendesk Chat]({{site.baseurl}}/partners/zendesk_chat) utiliza webhooks de cada plataforma para configurar una conversación servicio de mensajes cortos bidireccional. Cuando un usuario solicita soporte, se crea un ticket en Zendesk. Las respuestas del agente se reenvían a Braze a través de una Campaign de servicio de mensajes cortos activada por API, y las respuestas del usuario se envían de vuelta a Zendesk.
