# Versión del 10 de enero de 2023 {#january-10-2023-release}

## Componente de actualización de usuario para Canvas Flow {#user-update-component-for-canvas-flow}

El componente [Actualización de usuario]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/user_update) te permite actualizar los atributos, eventos y compras de un usuario en un creador JSON, por lo que no es necesario incluir información sensible como claves de API.

## Configuración de grupos de suscripción mediante API {#setting-subscription-groups-via-api}

Al crear nuevos usuarios a través del [endpoint `/users/track`]({{site.baseurl}}/api/endpoints/user_data/post_user_track), puedes establecer grupos de suscripción dentro del objeto de atributos de usuario, lo que te permite crear un usuario y establecer el estado del grupo de suscripción en una sola llamada a la API.

## Acceso anticipado al panel de conversiones {#conversions-dashboard-early-access}

El [panel de conversiones]({{site.baseurl}}/user_guide/analytics/dashboards/conversions) te permite analizar las conversiones entre campañas, Canvas y canales, utilizando diferentes métodos de atribución. Puedes hacer un seguimiento específico de estos métodos de atribución:

- **Conversiones abiertas:** conversiones que se produjeron después de que un usuario abriera el mensaje
- **Conversiones por clic:** conversiones que se produjeron después de que un usuario hiciera clic en el mensaje
- **Conversiones recibidas:** conversiones que se produjeron después de que un usuario recibiera el mensaje
- **Conversiones de último clic:** conversiones que se produjeron después de que un usuario hiciera clic en el mensaje si el mensaje era el más reciente en el que el usuario había hecho clic (esta característica se está probando actualmente en un pequeño subconjunto de clientes de acceso anticipado)

Esta característica está actualmente en acceso anticipado. Si estás interesado en participar en el acceso anticipado, ponte en contacto con tu administrador de éxito de cliente.

## Eventos de salida de Canvas para Braze Currents {#canvas-exit-events-for-braze-currents}

Ahora puedes hacer un seguimiento de cuándo tus usuarios salen de un Canvas, ya sea realizando un evento o coincidiendo con una audiencia. Consulta la sección [Eventos de interacción con mensajes]({{site.baseurl}}/user_guide/data/distribution/braze_currents/event_glossary/message_engagement_events) en el glosario de eventos de Currents para obtener más información.

## Actualizaciones del SDK {#sdk-updates}

Se han publicado las últimas actualizaciones del SDK. Las actualizaciones de ruptura se enumeran en la sección de actualizaciones del SDK; todas las demás actualizaciones se pueden encontrar consultando los correspondientes registros de cambios del SDK.

- [Web SDK 4.5.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [AppboyKit iOS SDK 4.5.2](https://github.com/Appboy/appboy-ios-sdk/releases/tag/4.5.2)
- [Swift SDK 5.8.0-5.8.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#580)
  - Cambia el nombre de la clase `BrazeLocation` a `BrazeLocationProvider` para evitar el sombreado del módulo del mismo nombre.
- [Flutter SDK 3.0.1](https://pub.dev/packages/braze_plugin/changelog)
- [Android SDK 24.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
  - La funcionalidad de ubicación y geovalla se trasladó a un nuevo módulo llamado `com.braze:android-sdk-location`.
  - Las clases y archivos de Appboy se han trasladado en su totalidad a Braze.
  - Se cambió el comportamiento predeterminado de `DefaultContentCardsUpdateHandler` para utilizar la hora de creación en lugar de la hora de la última actualización al ordenar las Content Cards.
  - Se eliminaron BrazeUser.setFacebookData() y BrazeUser.setTwitterData().
