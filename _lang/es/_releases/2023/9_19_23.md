# Versión del 19 de septiembre de 2023 {#september-19-2023-release}

## BigQuery para la ingesta de datos en la nube {#bigquery-for-cloud-data-ingestion}

Ahora puedes crear integraciones de ingesta de datos en la nube con [BigQuery](https://cloud.google.com/bigquery), un almacén de datos empresarial sin servidor. Para obtener más información, consulta [Integraciones de ingesta de datos en la nube]({{site.baseurl}}/user_guide/data_and_analytics/cloud_ingestion/integrations/?tab=bigquery).

## Braze Data Transformation

[Braze Data Transformation]({{site.baseurl}}/user_guide/data/unification/data_transformation) te permite crear y gestionar integraciones de webhook para automatizar el flujo de datos desde plataformas externas hacia los perfiles de usuario de Braze. Estos datos de usuario recién integrados pueden potenciar casos de uso de marketing aún más sofisticados.

## Comentarios en Canvas {#commenting-in-canvas}

Los [comentarios en Canvas]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas/canvas_comments) pueden ser un excelente espacio colaborativo para que tu equipo de marketing identifique, analice y revise los detalles más específicos de tus Canvas. A medida que construyes un Canvas, puedes crear y gestionar comentarios para identificar aquellas áreas que puedan requerir retroalimentación adicional de tus colegas.

## Centro de capacidad de entrega {#deliverability-center}

El [Centro de capacidad de entrega]({{site.baseurl}}/user_guide/analytics/dashboards/deliverability_center) proporciona más información sobre el rendimiento de tu correo electrónico al permitir el uso de Gmail Postmaster Tools para rastrear datos sobre los correos electrónicos enviados y recopilar datos sobre tu dominio de envío.

La capacidad de entrega del correo electrónico es el pilar del éxito de una Campaign. Utilizando el Centro de capacidad de entrega en el panel de Braze, puedes ver tus dominios por reputación de IP o errores de entrega para descubrir y solucionar cualquier problema potencial con la capacidad de entrega del correo electrónico.

## Editor de arrastrar y soltar para mensajes dentro de la aplicación {#drag-and-drop-editor-for-in-app-messages}

Estas características adicionales se han añadido al [editor de arrastrar y soltar para mensajes dentro de la aplicación]({{site.baseurl}}/user_guide/channels/in_app_messages/drag_and_drop):

- Enlaces de texto que no descartan el mensaje
- Acción de botón para solicitar la solicitud de push
- Bloque de editor de código personalizado

Para aprovechar todas las características disponibles en el editor de arrastrar y soltar, actualiza tus SDK or kit de desarrollo de software a las versiones de SDK or kit de desarrollo de software recomendadas.

### Guardar plantillas personalizadas (acceso anticipado) {#save-custom-templates-early-access}

En el editor de arrastrar y soltar para mensajes dentro de la aplicación, los participantes del acceso anticipado pueden crear y guardar plantillas de mensajes dentro de la aplicación personalizadas utilizando el botón **Guardar como plantilla**, disponible después de salir del editor. Antes de poder guardarla como plantilla, primero debes lanzar la campaña O guardarla como borrador.

También puedes crear y guardar plantillas de mensajes dentro de la aplicación navegando a **Plantillas** > **Plantillas de In-App Messages**.

## Deshabilitar el modo oscuro para los mensajes dentro de la aplicación {#disabling-dark-mode-for-in-app-messages}

Los desarrolladores pueden evitar que los mensajes dentro de la aplicación adopten el estilo del modo oscuro cuando el dispositivo del usuario tiene el modo oscuro activado. Para conocer los pasos sobre cómo implementar esto, consulta la siguiente documentación por plataforma:

- [Swift]({{site.baseurl}}/developer_guide/platform_integration_guides/swift/in-app_messaging/customization/setting_delegates#disabling-dark-mode)
- [Objective-C]({{site.baseurl}}/developer_guide/platform_integration_guides/ios/in-app_messaging/customization/handling_in_app_display#disabling-dark-mode)

## Nuevos campos para el archivado de mensajes {#new-fields-for-message-archiving}

El [archivado de mensajes]({{site.baseurl}}/user_guide/data/distribution/export_braze_data/message_archiving) te permite guardar una copia de los mensajes enviados a los usuarios con fines de archivo o cumplimiento en tu contenedor de S3. Los siguientes campos se han añadido a la carga útil JSON entregada a tu contenedor de S3 cada vez que se envía un mensaje:

- `user_id`
- `campaign_name`
- `canvas_name`
- `canvas_step_name`

## Nuevas etiquetas de personalización de Liquid {#new-liquid-personalization-tags}

Para mensajes dentro de la aplicación, puedes utilizar los siguientes atributos de aplicación dentro de Liquid. Los valores se basan en la clave de API de SDK or kit de desarrollo de software que tus aplicaciones utilizan para solicitar mensajería:

- {% raw %}`{{app.${api_id}}}`{% endraw %}
- {% raw %}`{{app.${name}}}`{% endraw %}

Para más información, consulta [Etiquetas de personalización compatibles]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/supported_personalization_tags#targeted-app-information).

## Nuevas asociaciones de Braze {#new-braze-partnerships}

### Antavo Loyalty Cloud – Extensiones de canal {#antavo-loyalty-cloud-channel-extensions}

La integración de [Antavo]({{site.baseurl}}/partners/data_and_analytics/loyalty/antavo) y Braze te permite utilizar datos relacionados con el programa de fidelización para crear campañas personalizadas que mejoren la experiencia del cliente. Antavo admite la sincronización de datos de fidelización entre las dos plataformas; se trata de una sincronización de datos unidireccional, solo de Antavo a Braze.

### Ketch – CDP or plataforma de datos de los clientes or plataforma de datos de los clientes {#ketch-customer-data-platform}

La integración de Braze y [Ketch]({{site.baseurl}}/partners/data_and_analytics/data_privacy/ketch) te permite controlar las preferencias de comunicación de los clientes dentro del centro de preferencias de Ketch y propagar automáticamente estos cambios a Braze.

### Redpoint – CDP or plataforma de datos de los clientes or plataforma de datos de los clientes {#redpoint-customer-data-platform}

Redpoint es una plataforma tecnológica que proporciona a los especialistas en marketing una plataforma de orquestación de campañas totalmente integrada. La integración de Braze y [Redpoint]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/redpoint) te permite crear Segments de Braze basados en los datos de tu CDP or plataforma de datos de los clientes de Redpoint.

### Simon Data – CDP or plataforma de datos de los clientes or plataforma de datos de los clientes {#simon-data-customer-data-platform}

Utiliza la integración de Braze y [Simon Data]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/simonai) para crear y sincronizar audiencias sofisticadas en Braze para su orquestación en tiempo real y sin código. Con esta integración, puedes aprovechar lo mejor de las capacidades de priorización de campañas y coincidencia de identidades de Simon, el soporte de agregaciones complejas y mucho más para potenciar tus Campaigns de Braze en los siguientes pasos del flujo.

## Actualizaciones del SDK or kit de desarrollo de software {#sdk-updates}

Se han publicado las últimas actualizaciones del SDK or kit de desarrollo de software. Las actualizaciones de última hora se enumeran en la sección de actualizaciones del SDK or kit de desarrollo de software; todas las demás actualizaciones se encuentran en los registros de cambios del SDK or kit de desarrollo de software correspondientes.

- [Swift SDK or kit de desarrollo de software 6.6.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#661)
- [Web SDK or kit de desarrollo de software 4.9.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md#490)
- [Android SDK or kit de desarrollo de software 28.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2800)
    - Se actualizó la versión mínima del SDK or kit de desarrollo de software a 21 (Lollipop).
    - Se han modificado las funciones de los conmutadores de características.
    - `Braze.getFeatureFlag(id)` ahora devolverá null si el conmutador de características no existe.
    - `Braze.subscribeToFeatureFlagsUpdates()` solo realizará la devolución de llamada cuando se complete una solicitud de actualización, e inicialmente si existen datos previamente almacenados en caché. También se llamará con los conmutadores de características en caché para cualquier error de actualización.
        - Si deseas el valor en caché inmediatamente al iniciar la aplicación, utiliza `Braze.getFeatureFlag(id)`.
    - Se refactorizó `DefaultInAppMessageViewWrapper.createButtonClickListener()` a `DefaultInAppMessageViewWrapper.createButtonClickListeners()`.
- [React Native SDK or kit de desarrollo de software 7.0.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md#700)
    - Actualiza el puente nativo de Android de [Braze Android SDK or kit de desarrollo de software 26.3.2 a 27.0.1](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2701).
- [Cordova SDK or kit de desarrollo de software 7.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2800)
    - Actualiza el puente nativo de Android de [Braze Android SDK or kit de desarrollo de software 26.3.2 a 27.0.1](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2701).
- [SDK or kit de desarrollo de software de Roku 2.0.0](https://github.com/braze-inc/braze-roku-sdk/blob/main/CHANGELOG.md#200)
    - `getFeatureFlag` devolverá un valor no válido cuando el conmutador de características no exista.
    - `BrazeTask` ahora observa `BrazeFeatureFlagsUpdated` para saber cuándo las actualizaciones de los conmutadores de características tienen éxito o fallan. Los valores de los datos pueden no ser siempre diferentes.
