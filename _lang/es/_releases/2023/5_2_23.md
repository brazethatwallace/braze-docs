# Versión del 2 de mayo de 2023 {#may-2-2023-release}

## Rediseño de la UI/UX de Braze {#redesigned-braze-uiux}

_Disponible de forma general el 16 de mayo de 2023_

Ahorra tiempo y encuentra exactamente lo que necesitas con el nuevo diseño de la interfaz de usuario y la arquitectura de la información. Navega rápidamente por la plataforma, completa tareas y descubre nuevas características con facilidad. Para que esta transición te resulte más fácil a ti y a tu equipo, consulta nuestra [guía de navegación]({{site.baseurl}}/user_guide/administer/personal/the_braze_dashboard) dedicada para saber qué ha cambiado y qué puedes esperar a continuación.

## Generador de consultas {#query-builder}

Con el [generador de consultas]({{site.baseurl}}/user_guide/analytics/reports/query_builder), puedes generar informes utilizando los datos de Braze en Snowflake. El generador de consultas incluye plantillas de consultas SQL predefinidas para que puedas empezar, o puedes escribir tus propias consultas SQL personalizadas para obtener aún más información.

## Historial de versiones de Canvas {#canvas-version-history}

El [historial de versiones]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/canvas_version_history) te permite ver y acceder a los análisis de Canvas y a los recorridos de usuario de cualquier versión anterior de tu Canvas. Consultar el historial de versiones de tu Canvas puede ser especialmente útil para mantener un registro de la evolución de un Canvas.

## Actualización incremental para segmentos SQL {#incremental-refresh-for-sql-segments}

Ahora puedes crear [extensiones de segmento SQL]({{site.baseurl}}/user_guide/audience/segments/segment_extension/sql_segments) que utilicen la actualización incremental, que solo actualiza los datos de los 2 últimos días. Es más rentable y consume menos créditos de segmento SQL cada vez que se actualiza la pertenencia a un segmento. A diferencia de las extensiones de actualización completa, puedes configurar las extensiones de actualización incremental para que regeneren automáticamente la membresía a diario.

## Centro de capacidad de entrega de correo electrónico {#deliverability-center-for-email}

El [Centro de capacidad de entrega]({{site.baseurl}}/user_guide/data_and_analytics/analytics/deliverability_center#deliverability-center) proporciona más información sobre el rendimiento de tu correo electrónico al admitir el uso de Gmail Postmaster Tools para realizar un seguimiento de los datos de los correos electrónicos enviados y recopilar datos sobre tu dominio de envío.

{% alert important %}
El Centro de capacidad de entrega está actualmente en período de acceso anticipado. Ponte en contacto con tu administrador de éxito de cliente de Braze si estás interesado en participar en el acceso anticipado.
{% endalert %}

## Actualización de las limitaciones del catálogo {#update-for-catalog-limitations}

A partir del 1 de mayo de 2023, se actualizaron los [límites de almacenamiento de los catálogos]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog#limits). Para solicitar una mejora del almacenamiento de catálogos, ponte en contacto con tu director de cuentas de Braze.

## Nuevo artículo sobre endpoints de API y SDK {#new-api-and-sdk-endpoints-article}

Braze gestiona varias instancias diferentes para nuestro panel, SDK y endpoints REST, que llamamos "clústeres". Consulta [Endpoints de API y SDK]({{site.baseurl}}/user_guide/administer/personal/sdk_endpoints) para ver una lista de URL del panel, endpoints de API y endpoints de SDK para las instancias de Braze disponibles.

## Obsolescencia del SDK para iOS - Swift {#ios-sdk-deprecation-swift}

El SDK heredado de Braze para iOS está quedando obsoleto en favor del nuevo SDK Swift. Esto aporta un mayor rendimiento, nuevas características y muchas mejoras, ¡incluida [una nueva documentación]({{site.baseurl}}/developer_guide/platform_integration_guides/swift/initial_sdk_setup/overview)!

¿Quieres actualizar? Consulta nuestra [guía de migración](https://braze-inc.github.io/braze-swift-sdk/documentation/braze/appboy-migration-guide/) para más detalles.
