# Versión del 2 de mayo de 2023 {#may-2-2023-release}

## Rediseño de la UI/UX de Braze {#redesigned-braze-uiux}

_Disponible de forma general el 16 de mayo de 2023_

Ahorra tiempo y encuentra exactamente lo que necesitas con la UI/UX y la arquitectura de información recientemente rediseñadas. Navega rápidamente por la plataforma, completa tareas y descubre nuevas características con facilidad. Para facilitar esta transición para ti y tu equipo, consulta nuestra [guía de navegación]({{site.baseurl}}/user_guide/administer/personal/the_braze_dashboard) dedicada para conocer qué ha cambiado y qué puedes esperar a continuación.

## Generador de consultas {#query-builder}

Con el [generador de consultas]({{site.baseurl}}/user_guide/analytics/reports/query_builder), puedes generar informes utilizando datos de Braze en Snowflake. El generador de consultas incluye plantillas de consultas SQL prediseñadas para que puedas empezar rápidamente, o puedes escribir tus propias consultas SQL personalizadas para obtener información aún más detallada.

## Historial de versiones de Canvas {#canvas-version-history}

El [historial de versiones]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/canvas_version_history) te permite ver y acceder a los análisis de Canvas y los recorridos de usuario de cualquier versión anterior de tu Canvas. Consultar el historial de versiones de tu Canvas puede ser especialmente útil para mantener un registro de la evolución de un Canvas.

## Actualización incremental para SQL Segments {#incremental-refresh-for-sql-segments}

Ahora puedes crear [extensiones de segmento SQL]({{site.baseurl}}/user_guide/audience/segments/segment_extension/sql_segments) que utilicen actualización incremental, la cual solo actualiza los datos de los últimos 2 días. Esto es más rentable y consume menos créditos de segmento SQL cada vez que se actualiza la membresía del segmento. A diferencia de las extensiones con actualización completa, puedes configurar las extensiones con actualización incremental para que regeneren automáticamente la membresía de forma diaria.

## Centro de capacidad de entrega para correo electrónico {#deliverability-center-for-email}

El [Centro de capacidad de entrega]({{site.baseurl}}/user_guide/analytics/dashboards/deliverability_center) proporciona más información sobre el rendimiento de tu correo electrónico al admitir el uso de Gmail Postmaster Tools para rastrear datos de correos electrónicos enviados y recopilar datos sobre tu dominio de envío.

{% alert important %}
El Centro de capacidad de entrega se encuentra actualmente en acceso anticipado. Ponte en contacto con tu CSM or administrador de éxito de cliente or administrador de éxito de cliente de Braze si te interesa participar en el acceso anticipado.
{% endalert %}

## Obsolescencia del SDK or kit de desarrollo de software de iOS - Swift {#ios-sdk-deprecation-swift}

El SDK or kit de desarrollo de software heredado de iOS de Braze se está descontinuando en favor del nuevo SDK or kit de desarrollo de software de Swift. Esto aporta un rendimiento mejorado, nuevas características y muchas mejoras, incluida [nueva documentación]({{site.baseurl}}/developer_guide/sdk_integration?sdktab=swift).

¿Quieres actualizar? Consulta nuestra [guía de migración](https://braze-inc.github.io/braze-swift-sdk/documentation/braze/appboy-migration-guide/) para más detalles.
