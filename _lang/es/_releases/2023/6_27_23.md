# Versión del 27 de junio de 2023 {#june-27-2023-release}

## Centro de preferencias de correo electrónico con arrastrar y soltar {#drag-and-drop-email-preference-center}

Configurar un centro de preferencias proporciona un lugar centralizado para que tus usuarios editen y gestionen sus preferencias de notificación para tu mensajería de correo electrónico. Con el editor de arrastrar y soltar, ahora puedes crear y personalizar un centro de preferencias para ayudar a gestionar qué usuarios reciben ciertos tipos de comunicación. Consulta [Crear un centro de preferencias de correo electrónico con arrastrar y soltar]({{site.baseurl}}/user_guide/audience/subscription_preferences/preference_center/dnd_preference_center) para obtener más información.

## Guardar borradores para Canvas {#saving-drafts-for-canvas}

A medida que creas y lanzas Canvas, también puedes realizar ediciones en un Canvas activo y guardarlas como borrador, lo que te permite probar tus cambios antes de otro lanzamiento. Si tienes un Canvas activo que requiere cambios a gran escala, puedes usar esta característica para crear borradores separados para estas ediciones. Consulta [Guardar borradores para Canvas]({{site.baseurl}}/save_as_draft) para obtener más información.

## Recorrido ganador con entrada única {#winning-path-with-one-time-entry}

Al usar [recorridos ganadores]({{site.baseurl}}/user_guide/engagement_tools/canvas/canvas_components/experiment_step/winning_path#one-time-entry) en un Canvas en el que los usuarios solo pueden entrar una vez, ahora se incluye automáticamente un grupo de retraso. Esto significa que ya no necesitas realizar una solución alternativa para los Canvas de entrada única a fin de usar recorridos ganadores en tus recorridos de experimentos.

## Límites de velocidad para la actualización de Content Cards {#refreshing-content-card-rate-limits}

Para los clientes incorporados después del 14 de junio de 2023, el límite de velocidad predeterminado para llamar manualmente a `requestContentCardsRefresh()` es de 3 llamadas cada 10 minutos por dispositivo, a fin de prevenir la degradación del rendimiento y errores. Para obtener más información sobre la actualización de Content Cards, consulta la documentación correspondiente para [iOS]({{site.baseurl}}/developer_guide/content_cards/customizing_cards/feed#refreshing-the-feed), [Android]({{site.baseurl}}/developer_guide/content_cards/customizing_cards/feed#refreshing-the-feed) y [Web]({{site.baseurl}}/developer_guide/content_cards/customizing_cards/feed#refreshing-the-feed).

## Sincronización de audiencia con Facebook {#audience-sync-to-facebook}

Si utilizas [Sincronización de audiencia con Facebook]({{site.baseurl}}/partners/canvas_audience_sync/facebook_audience_sync), ten en cuenta que a partir de julio de 2023, Meta está implementando las cuentas de trabajo de Meta para un pequeño grupo de empresas interesadas en adoptar este nuevo tipo de cuenta. Si tienes una cuenta de empresa integrada con Braze, asegúrate de desconectar y volver a conectar la [página del partner de Facebook]({{site.baseurl}}/partners/canvas_audience_sync/facebook_audience_sync#step-1-connect-to-facebook) con tu cuenta de empresa para preservar esta implementación y no interrumpir ningún Canvas activo.

## Ingesta de datos en la nube para Databricks {#cloud-data-ingestion-for-databricks}

La ingesta de datos en la nube de Braze para Databricks permite a los clientes sincronizar directamente datos de usuario (atributos, eventos, compras), así como eliminaciones de usuarios, desde Databricks a Braze. Una vez sincronizados con Braze, estos datos se pueden utilizar como cualquier otro dato en la plataforma de Braze. Esta característica es una extensión de nuestro producto de [ingesta de datos en la nube]({{site.baseurl}}/user_guide/data/unification/cloud_ingestion/integrations) y actualmente se encuentra en acceso anticipado.

## Portal de privacidad {#privacy-portal}

El nuevo [Portal de privacidad de Braze]({{site.baseurl}}/user_guide/privacy_portal) proporciona información útil sobre cómo Braze puede ayudarte a ser un buen custodio de los datos de tus clientes y, lo que es más importante, permitirte tomar medidas para cumplir con las normas de protección de datos relevantes para tu negocio. Hemos reunido información y enlaces a documentación que pueden ayudarte en tu uso de los servicios de Braze en cumplimiento con las leyes y regulaciones de protección de datos aplicables.
