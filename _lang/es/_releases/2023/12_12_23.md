# Versión del 12 de diciembre de 2023 {#december-12-2023-release}

## Actualizaciones en la integración push de Android {#updates-to-android-push-integration}

El 20 de junio de 2023, Google dejó obsoleta su API Cloud Messaging para enviar notificaciones push a aplicaciones Android. La [integración push estándar de Android]({{site.baseurl}}/developer_guide/push_notifications?sdktab=android) ahora te muestra cómo configurar la API Firebase Cloud Messaging de Google en su lugar.

Para más información sobre la obsolescencia de la API Cloud Messaging de Google, consulta las [preguntas frecuentes de Firebase](https://firebase.google.com/support/faq#fcm-23-deprecation).

## Canales robustos {#robust-channels}

### Mensajes de respuesta de WhatsApp {#whatsapp-response-messaging}

{% multi_lang_include release_type.md release="General availability" %}

Al [crear un mensaje de WhatsApp]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/create#response-messages) en una campaña o Canvas, puedes crear mensajes de respuesta para contestar a los mensajes de WhatsApp de los usuarios dentro de un período de 24 horas. Los mensajes de respuesta pueden ser especialmente útiles en Canvas que fomentan las interacciones entre tu marca y sus usuarios, como las campañas de adhesión voluntaria.

### Limitación de frecuencia de WhatsApp {#whatsapp-frequency-capping}

{% multi_lang_include release_type.md release="General availability" %}

Ahora puedes configurar [reglas de limitación de frecuencia]({{site.baseurl}}/user_guide/engagement_tools/campaigns/building_campaigns/rate-limiting#frequency-capping) para WhatsApp. La limitación de frecuencia se aplica a nivel de envío de la campaña o del componente de Canvas, y se puede configurar para cada espacio de trabajo desde **Configuración** > **Reglas de limitación de frecuencia**.

## Flexibilidad de datos {#data-flexibility}

### Panel de conversiones {#conversions-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

El [panel de conversiones]({{site.baseurl}}/user_guide/analytics/dashboards/conversions) te permite analizar conversiones en Campaigns, Canvas y canales, usando diferentes métodos de atribución. Al medir tus conversiones, puedes especificar el período de tiempo, el evento de conversión y la ventana de conversión.

### Informes de Email Insights {#email-insights-reports}

{% multi_lang_include release_type.md release="General availability" %}

Hay una nueva pestaña, Email Insights, ubicada dentro del [panel de rendimiento de correo electrónico]({{site.baseurl}}/user_guide/data_and_analytics/analytics/email_performance_dashboard#email-insights-dashboard) que contiene dos nuevos informes:

- **Engagement by Mailbox Providers:** Muestra el número de clics y aperturas por proveedor de buzón de correo. Puedes seleccionar un proveedor de buzón de correo y desglosar en dominios de recepción específicos.
- **Engagement by Day of Week:** Muestra cuándo los usuarios interactúan con sus correos electrónicos.

### Actualización del gráfico de series temporales de grupos de suscripción {#update-to-subscription-group-timeseries-graph}

{% multi_lang_include release_type.md release="General availability" %}

El gráfico **Subscription Group Timeseries** que aparece en la página **Subscription Groups** ahora muestra el recuento de suscripciones por usuario en lugar de por correo electrónico o número de teléfono. Esto se alinea mejor con la forma en que Braze calcula las estadísticas en otras áreas del panel.

## Automatización de IA y ML {#ai-ml-automation}

### Recomendaciones de artículos con IA {#ai-item-recommendations}

{% multi_lang_include release_type.md release="General availability" %}

[Recomendaciones de artículos con IA]({{site.baseurl}}/user_guide/brazeai/item_recommendations/creating_recommendations/ai) es una herramienta de recomendación de productos basada en aprendizaje profundo que utiliza el comportamiento de compra colectivo de los usuarios para recomendar artículos. Puedes usar las recomendaciones de artículos con IA para calcular los productos más populares o crear recomendaciones de IA personalizadas para un catálogo específico. Después de crear tu recomendación, puedes usar la personalización para insertar esos productos en tus mensajes.

## Nuevas asociaciones de Braze {#new-braze-partnerships}

### Facebook Lead Ads a través de Zapier – Captura de leads {#facebook-lead-ads-via-zapier-leads-capture}

Con la [integración de Facebook Lead Ads a través de Zapier]({{site.baseurl}}/partners/data_and_analytics/leads_capture/facebook_via_zapier), puedes importar tus leads de Facebook a Braze y hacer seguimiento de un evento personalizado cuando se capturan leads.

### SmarterSends – Plantillas de mensajes {#smartersends-message-templates}

La asociación entre Braze y [SmarterSends]({{site.baseurl}}/partners/message_orchestration/templates/smartersends) te permite combinar el poder de Braze con el contenido hiperlocalizado que poseen tus usuarios distribuidos para potenciar tus Campaigns de marketing.

### Recurly – Pagos {#recurly-payments}

La integración de [Recurly]({{site.baseurl}}/partners/ecommerce/ordering_payments_subscription/recurly) y Braze simplifica el proceso de compartir datos de suscripción con Braze, permitiendo una comunicación dirigida con los clientes.

## Actualizaciones del SDK or kit de desarrollo de software {#sdk-updates}

Se han publicado las últimas actualizaciones del SDK or kit de desarrollo de software. Las actualizaciones de última hora se enumeran en la sección de actualizaciones del SDK or kit de desarrollo de software; todas las demás actualizaciones se pueden encontrar en los registros de cambios del SDK or kit de desarrollo de software correspondientes.

- [Flutter SDK or kit de desarrollo de software 8.0.0-8.1.0](https://pub.dev/packages/braze_plugin/changelog)
  - Actualiza el puente nativo de Android del SDK or kit de desarrollo de software de Braze para Android 27.0.1 a 29.0.1.
  - Actualiza el puente nativo de iOS del SDK or kit de desarrollo de software de Braze en SWIFT 6.6.1 a 7.2.0.
  - Modifica el comportamiento de los métodos de conmutadores de características.
    - `BrazePlugin.getFeatureFlagByID(String id)` ahora devolverá `null` si el conmutador de características no existe.
    - `BrazePlugin.subscribeToFeatureFlags(void Function(List<BrazeFeatureFlag>) onEvent))` solo se activará en las siguientes situaciones:
      - Cuando una solicitud de actualización se completa con éxito o fallo.
      - Tras la suscripción inicial, si había datos previamente almacenados en caché de la sesión actual.
  - La versión mínima compatible del SDK or kit de desarrollo de software de Android es la 21.
