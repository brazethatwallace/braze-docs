Usa **Paneles** para monitorear el rendimiento de un vistazo, **Informes** para un análisis más profundo de Campaigns y Canvas, y **Seguimiento** para configurar cómo Braze captura las acciones de los usuarios. Si no tienes claro qué significa una métrica específica, consulta el **Glosario de métricas**.

## Preguntas frecuentes {#frequently-asked-questions}

### ¿Qué paneles de análisis están disponibles en Braze? {#what-analytics-dashboards-are-available-in-braze}

Braze incluye paneles prediseñados y personalizables para el rendimiento de Campaigns, Canvas y canales. Consulta [Paneles]({{site.baseurl}}/user_guide/analytics/dashboards) para ver las vistas disponibles y los pasos de configuración.

### ¿Cómo exporto los datos de análisis de Braze? {#how-do-i-export-braze-analytics-data}

Usa los informes del panel, las exportaciones programadas o [Currents]({{site.baseurl}}/user_guide/data/distribution/braze_currents) para transmitir datos de eventos a tu almacén de datos o herramientas de BI.

### ¿Dónde puedo encontrar las definiciones de las métricas de Braze? {#where-can-i-find-definitions-for-braze-metrics}

Consulta el [Glosario de métricas]({{site.baseurl}}/user_guide/analytics/metrics_glossary) para conocer las definiciones de las métricas comunes de Campaigns y participación.
