# Solución de problemas de BrazeAI Operator {#troubleshooting-brazeai-operator}

> Problemas comunes y soluciones para BrazeAI Operator<sup>TM</sup>.

## Problemas comunes {#common-issues}

| Problema | Solución de problemas |
| --- | --- |
| Sin respuesta | Intenta actualizar la página y volver a abrir el panel de Operator. |
| Respuestas fuera de tema | Reformula la pregunta de forma más específica. Menciona la característica o el flujo de trabajo sobre el que preguntas. |
| Mensajes de error | Si Operator no puede transmitir contenido, puede aparecer un mensaje de "Intentar de nuevo". Es posible que Operator no esté disponible temporalmente o que la conexión se haya interrumpido. Vuelve a intentarlo después de unos minutos. |
| Límite diario alcanzado | Se ha alcanzado el límite de uso diario de toda la empresa. Todas las acciones de Operator cuentan para este límite. Espera a que el límite se restablezca (cada 24 horas). Aún puedes enviar un ticket de soporte a través del formulario web. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Problemas comunes" }

Para saber qué puede y qué no puede hacer Operator en el panel, consulta [Limitaciones]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#limitations).
