# Enviar tickets de soporte con BrazeAI Operator {#file-support-tickets-with-brazeai-operator}

> Aprende a enviar tickets de soporte directamente desde BrazeAI Operator<sup>TM</sup> sin salir del panel de Braze.

## Cómo enviar un ticket {#how-to-file-a-ticket}

1. Haz una pregunta a Operator y luego selecciona <i class="fa-regular fa-circle-question"></i> **File a support ticket** (o pide a Operator que envíe uno).
2. Completa el título y la descripción del problema.
3. Revisa los archivos adjuntos y el contexto sugeridos para incluir.
4. Revisa y selecciona **Submit**.

Enviar un ticket a través de Operator cuenta para el límite de uso diario de toda la empresa, y es un uso más ligero que crear o editar objetos como Campaigns y Segments. Si ya se alcanzó el límite, Operator te dirige a **File a support ticket** a través del formulario web. Para más información, consulta [Limitaciones]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#limitations).

## Contexto incluido automáticamente {#auto-included-context}

Al crear un ticket desde Operator, se incluye automáticamente el siguiente contexto:

- Mensajes recientes de la sesión de chat de Operator
- Contexto de la página activa cuando se abrió Operator
- Nombre del espacio de trabajo
- Registros relevantes y detalles de la sesión

Puedes agregar contexto adicional de forma manual usando el campo de texto o adjuntando archivos.

## Consejos para una resolución más rápida {#tips-for-faster-resolution}

- Añade una descripción detallada de los pasos para reproducir el problema.
- Incluye los mensajes de error relevantes o el comportamiento inesperado.
- Revisa los archivos adjuntos sugeridos automáticamente antes de enviar.
