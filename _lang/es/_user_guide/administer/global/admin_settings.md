guide_top_text: "La configuración de administrador se aplica a toda tu empresa y afecta a todos los espacios de trabajo y usuarios. Usa esta configuración para administrar la información de contacto de la empresa, configurar las preferencias de notificación, aplicar políticas de seguridad como reglas de autenticación y listas de IP permitidas, y controlar el acceso OAuth para el servidor MCP de Braze.<br><br>Para administrar esta configuración, ve a <b>Configuración</b> > <b>Configuración de administrador</b>. La mayoría de las características solo están disponibles para los administradores de cuentas de Braze. Para la configuración específica del espacio de trabajo, consulta <a href='/docs/user_guide/administer/global/workspace_settings'>Configuración del espacio de trabajo</a>."
