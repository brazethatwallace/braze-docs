Usa el registro de eventos de usuario para buscar eventos de usuarios individuales cuando estés solucionando problemas de integración o depurando el comportamiento de una campaign. Consulta el registro de exportaciones para ver el estado de las exportaciones de datos de segmentos y campaigns, y revisa el registro de actividad de mensajes para obtener detalles sobre la entrega de mensajes, incluidos los intentos de envío, las confirmaciones y los errores."
