# Archivar Campaigns y Canvas {#archive-campaigns-and-canvases}

> Archivar tus Campaigns y Canvas es una forma eficaz de organizar tu espacio de trabajo. A medida que sigas creando más mensajes, archivar puede ayudarte a mantener el enfoque en los esfuerzos de mensajería activos y relevantes.

{% alert important %}
No puedes eliminar Campaigns y Canvas desde el dashboard, pero puedes archivarlos.
{% endalert %}

## Archivar {#archiving}

Cuando archivas una campaña o un Canvas, no se entregarán más mensajes y tus mensajes dentro de la aplicación no se mostrarán. Aún podrás ver los resultados después de archivar, pero no podrás editar la campaña o el Canvas. Para hacerlo, primero tendrás que [desarchivarlo](#unarchiving-campaigns-and-canvases).

{% alert note %}
**Archivar** no elimina tu campaña o Canvas. Braze detiene la entrega, oculta el mensaje de las listas del día a día y lo conserva para informes e historial del espacio de trabajo.
{% endalert %}

{% tabs local %}
{% tab campaign %}
Para archivar una campaña:

1. Ve a **Mensajería** > **Campaigns**.
2. Pasa el cursor sobre la fila de la campaña y selecciona el menú <i class="fas fa-ellipsis-vertical"></i>.
3. Selecciona **Archivar**.
{% endtab %}

{% tab canvas %}
Para archivar un Canvas:

1. Ve a **Mensajería** > **Canvas**.
2. Pasa el cursor sobre la fila del Canvas y selecciona el menú <i class="fas fa-ellipsis-vertical"></i>.
3. Selecciona **Archivar**.
{% endtab %}
{% endtabs %}

## Desarchivar {#unarchiving}

Cuando desarchivas una campaña o un Canvas, no se pondrá en vivo&mdash;su estado solo cambiará a **Activos**. Después de desarchivar, puedes editar y revisar cómo está configurado el mensaje sin que se envíe ningún mensaje.

Para reanudar la campaña o el Canvas y comenzar a enviar mensajes, selecciona el menú <i class="fas fa-ellipsis-vertical"></i> de la fila correspondiente y selecciona **Reanudar**.
