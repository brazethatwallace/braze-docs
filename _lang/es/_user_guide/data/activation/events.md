guide_top_text: "Los eventos rastrean el comportamiento de los usuarios y almacenan esa información en sus <a href='/docs/user_guide/data/unification/user_data/user_profile_lifecycle'>perfiles de usuario</a>. <br><br>Usa eventos estándar para acciones rastreadas automáticamente por el <a href='/docs/user_guide/data/unification/user_data/sdk_data_collection'>SDK or kit de desarrollo de software de Braze</a>, como lanzamientos de aplicaciones e inicios de sesión. Para rastrear acciones únicas de los usuarios, como iniciar un tutorial o añadir un artículo a la lista de deseos, puedes definir eventos personalizados. Para industrias comunes como el comercio electrónico, los eventos recomendados proporcionan esquemas predefinidos y estructuras de datos con mejores prácticas para ayudarte a empezar más rápido. También puedes registrar transacciones con datos de ingresos usando eventos de compra. <br><br>En conjunto, estos eventos te permiten analizar tendencias a lo largo del tiempo y desencadenar interacciones oportunas y relevantes."
