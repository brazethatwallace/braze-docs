# Localización {#localization}

> Obtén información sobre la localización y los idiomas compatibles con el SDK or kit de desarrollo de software de Braze, para que puedas conectar con tus usuarios en todo el mundo. Para obtener orientación sobre cómo configurar mensajes localizados, consulta [Localización]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/localization) en nuestra sección Fundamentos de la mensajería.

## Acerca de la localización {#about-localization}

Además del inglés, Braze admite varios idiomas para los mensajes del SDK or kit de desarrollo de software que se muestran en tu aplicación.

Cuando el idioma del teléfono de un usuario está configurado en uno de los idiomas compatibles, los mensajes del SDK or kit de desarrollo de software que se incluyen de forma predeterminada para el canal de mensajería se traducirán a ese idioma. Por ejemplo, si tu aplicación muestra un mensaje sobre problemas de conectividad, se traducirá al idioma elegido por el usuario.
