- [Android SDK 42.3.0](https://github.com/braze-inc/braze-android-sdk/releases/tag/v42.3.0)
    - `BannerView`: los campos de `BannerDismissSnapshot` pasados a `onDismissCallback` ahora no son nulos. Si el SDK no puede resolver `placementId`, `stableKey` o `trackingId`, la devolución de llamada se omite y se registra una advertencia.
- [Web SDK 6.8.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
    - Añade compatibilidad con los nuevos métodos de eventos de eCommerce.
- [Swift SDK 14.2.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1421)
- [Swift SDK 15.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - Banners: `onDismiss` ahora recibe `Braze/BannerDismissalEvent` en lugar de `Braze/Banner`.
    - Eleva la versión de Xcode a 26.0 (17A324).
    - Eleva el objetivo de despliegue mínimo de Mac Catalyst de iOS 13 (macOS 10.15 Catalina) a iOS 16 (macOS 13 Ventura).
        - Los usuarios de Mac Catalyst en macOS 12 Monterey o versiones anteriores ya no son compatibles.
    - Elimina la capacidad de controlar si el SDK impide mostrar mensajes dentro de la aplicación a diferentes usuarios en ciertos casos extremos.
        - Elimina la opción de configurar a través de `Braze.Configuration.preventInAppMessageDisplayForDifferentUser`.
        - El SDK ahora siempre se comportará como si esta opción de configuración estuviera establecida en true.
    - Actualiza el init de `Braze.WebViewBridge.ScriptMessageHandler` y `Braze.WebViewBridge.SchemeHandler` para que el parámetro `channel` no sea opcional.
- [Android SDK 42.3.1](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#4231)
    - Añade compatibilidad con los nuevos métodos de eventos de eCommerce.
    - Añade métodos de descarte de Banner para implementaciones de interfaz de usuario personalizadas.
    - Incluye correcciones de errores de mensajes dentro de la aplicación en HTML.
- [Swift SDK 15.0.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1501)
- [React Native 21.0.0](https://www.npmjs.com/package/@braze/react-native-sdk/v/21.0.0)
    - Actualiza los enlaces de versión nativos de los SDK de Swift y Android.
    - Actualiza los enlaces de versión nativos del SDK de Swift [de Braze Swift SDK 14.0.4 a 15.0.1](https://github.com/braze-inc/braze-swift-sdk/compare/14.0.4...15.0.1#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
    - Corrige la documentación JSDoc de Content Cards.
        - Eleva la versión de Xcode a 26.0 (17A324).
- [Swift SDK 15.1.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - Añade compatibilidad con los nuevos métodos de eventos de eCommerce.
    - Añade métodos de descarte de Banner para implementaciones de interfaz de usuario personalizadas.
    - Añade implementaciones de ejemplo para crear interfaces de usuario personalizadas con Banners.
    - Añade observabilidad pass-through de Live Activities, lo que permite rastrear errores y eventos de actualización con mayor precisión y granularidad.
    - Añade getters asíncronos basados en devoluciones de llamada para Content Cards y marca como obsoletos los getters anteriores.
    - Mejora la estabilidad de la gestión de estado.

        - Esto permite la compatibilidad con cualquier versión de Braze SDK desde `15.0.0` hasta, pero sin incluir, `16.0.0`.
        - Eleva la versión de Xcode a 26.0 (17A324).
        - Consulta la entrada del registro de cambios de [`15.0.0`](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1500) para obtener más información sobre posibles cambios de ruptura.
