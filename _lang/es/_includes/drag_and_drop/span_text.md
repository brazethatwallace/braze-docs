Para aplicar un estilo específico a bloques de texto sin código personalizado, resalta el texto al que quieras aplicar estilo y selecciona **Wrap with span for style**.

![Cuadro de texto con diferentes secciones de texto estilizadas, como distintos tamaños y colores de letra, y una sección resaltada que muestra una barra de herramientas con la opción "Wrap with span for style".]({% image_buster /assets/img/landing_pages/wrap_with_span.png %}){: style="max-width:50%;"}

Ajusta las propiedades de span para actualizar el estilo de tu texto, que incluyen:

- Familia tipográfica, peso, tamaño
- Altura de línea
- Espaciado de letras
- Alineación y color del texto
- Relleno de bloque
