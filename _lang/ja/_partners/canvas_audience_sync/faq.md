# よくある質問 {#frequently-asked-questions}

> この記事では、オーディエンス同期に関するよくある質問への回答を提供します。

### オーディエンス同期パートナーのダッシュボードにオーディエンスが反映されるまでどのくらいの時間がかかりますか？ {#how-long-does-it-take-for-my-audiences-to-populate-in-my-audience-sync-partner-dashboard}

オーディエンスの反映にかかる時間は、パートナーによって異なります。すべてのネットワークがBrazeからのリクエストを処理し、ユーザーのマッチングを試みます。このプロセスには通常6〜48時間かかります。

各オーディエンス同期パートナーのドキュメントのトラブルシューティングセクションで、具体的な時間範囲を確認できます。

### オーディエンス同期ではどのようなファーストパーティデータを使用できますか？ {#what-type-of-first-party-data-can-i-use-in-my-audience-sync}

各パートナーで使用される具体的なフィールドは、パートナーの要件によって異なる場合があります。

たとえば、Facebookへのオーディエンス同期を設定する場合、メール、電話番号、名、姓など、さまざまなファーストパーティフィールドを使用できますが、Snapchatでは、メール、電話番号、またはモバイル広告主IDのいずれかのみを選択できます。

同期するために選択できるユーザーフィールドは、Brazeの標準属性項目とモバイル広告IDに対応していることに注意してください。SDKやAPIを通じてこのデータを適切に渡す必要があります。

### オーディエンス同期の各パートナーにデータが送信される際、どのような処理が行われますか？ {#what-happens-when-my-data-is-being-processed-to-send-to-each-audience-sync-partner}

オーディエンス同期の送信先に送信するデータとして選択されたデータは正規化されます。各パートナーは、API要件に基づいてデータ正規化の仕様が異なる場合があるため、各パートナー固有のエンドポイントで詳細を確認してください。

さらにBrazeは、オーディエンス同期パートナーとユーザーを同期する前にすべてのデータをハッシュ化し、すべてのPIIがSHA256を使用してハッシュ化されるようにします。

### パートナーによっては1つのステップで複数の識別子を選択できるのに、他のパートナーでは1つの識別子しか選択できないのはなぜですか？ {#why-can-i-select-multiple-identifiers-in-one-step-for-some-partners-but-can-only-select-one-identifier-for-others}

これはパートナー連携の方法によって決定されるものであり、Brazeがコントロールしているものではありません。一部のパートナー（Metaなど）では複数の識別子の同期が可能ですが、他のパートナー（Googleなど）では特定の時点でユーザーと同期できる識別子は1つのみです。

### 連携を再接続するにはどうすればよいですか？ {#how-do-i-reconnect-my-integration}

連携を接続した以前のユーザーがもう貴社にいない場合は、**Change Account**を選択して、新しいユーザーで連携を更新する必要があります。次に、**Confirm**を選択し、新しいユーザーと接続します。前のユーザーから新しいユーザーへの移行中に同期を行うと、アクティブなキャンバスが中断される可能性があるため、キャンバスへのスケジュールされたユーザーのエントリ前など、アクティブな同期が行われていないときにユーザーを変更することをお勧めします。

再接続するユーザーには、ユーザーをパートナーに正常に同期させるために、すべてのオーディエンスに対する読み取りと書き込みの両方のアクセス権が必要です。連携を再接続するユーザーが、同じ広告アカウントとオーディエンスにアクセスできることを確認してください。既存のキャンバスステップを編集する必要はありません。

### オーディエンス同期を作成・管理する際に発生しうる一般的なエラーとは何ですか？ {#what-are-common-errors-that-can-occur-when-creating-and-managing-my-audience-syncs}

| エラー | 理由 | 解決策 |
| --- | --- | --- |
| 無効なトークン | これは、特定の広告ネットワークにログインするためのパスワードを変更した場合や、認証情報の有効期限が切れた場合に発生する可能性があります。 | 各パートナーのページにアクセスし、アカウントの切断と再接続を行います。 |
| オーディエンスのサイズが小さすぎる | これは、オーディエンスからユーザーを削除するオーディエンス同期ステップを作成した場合に発生することがあります。オーディエンスのサイズがゼロに近づくと、ネットワークによりオーディエンスのサイズが小さすぎて配信できないというフラグが設定されることがあります。 | オーディエンスのサイズが完全に枯渇しない形で定期的にユーザーを追加および削除するオーディエンス同期戦略を検討していることを確認してください。 |
| オーディエンスが存在しない | オーディエンス同期ステップが、存在しないオーディエンスを使用しています。これは、オーディエンスにアクセスするために必要な権限を持っていない場合にも発生することがあります。 | オーディエンス同期設定でアクティブなオーディエンスを追加するか、新しいオーディエンスを作成してください。 |
| 広告アカウントへのアクセス試行 | このエラーは、広告アカウント、選択したオーディエンス、またはその両方に対する権限がない場合に発生します。 | 広告アカウントの管理者と協力して、適切なアクセス権と権限を取得してください。 |
| 無効な設定 | これは、キャンバスで特定のオーディエンス同期の送信先（広告アカウント、オーディエンス、一致させるユーザーフィールドを含む）を設定していない場合に発生する可能性があります。 | 起動する前に、各パートナーの設定を完了してください。 |
| サービス利用規約 | Facebookなどの一部のオーディエンス同期の送信先では、広告ネットワークによりオーディエンス同期機能を使用するために特定のサービス利用規約に同意することが義務付けられています。このエラーは、該当する利用規約に同意していない場合に発生します。 | 各パートナーの必要な利用規約に同意したことを確認してください。特にFacebookについては、[Facebookのトラブルシューティング]({{site.baseurl}}/partners/canvas_steps/facebook_audience_sync/#troubleshooting)を確認してください。 |
