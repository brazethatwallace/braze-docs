# Stylitics

> [Stylitics](https://stylitics.com/)は、小売業者が視覚コンテンツを大規模に自動化および配信するためのクラウドベースのSaaSプラットフォームです。Styliticsのバンドルは、製品を文脈に応じて提示することでインスピレーションを与え、購入の自信を高め、エンゲージメントを増加させ、最終的には平均注文額とコンバージョン率を向上させます。

_この統合はStyliticsによって管理されています。_

## 統合について {#about-the-integration}

BrazeとStyliticsの統合により、既存のメールキャンペーンを、魅力的で関連性の高いバンドルコンテンツで強化し、パーソナライズされた顧客体験を創出できます。

## ユースケース {#use-cases}

以下に、一般的なトリガーメールプログラムの例をいくつか示します。

- 閲覧放棄メール
- 配送確認メール
- 購入後メール

## 統合 {#integration}

Styliticsは、この統合のためのバンドルデータを提供します。お客様のメールサービスプロバイダー（ESP）は、Styliticsバンドルを含むメールテンプレートを作成または更新できます。Styliticsがメールのレイアウトやデザインを変更することはできません。

1. バンドルをメールに統合します。ESPが位置とカスタマイズを決定します。
2. ESPが、Styliticsコンテンツを組み込むためにトリガーメールのコードを更新します。
3. ESPが、更新されたトリガーシリーズをテスト、プレビュー、および開始します。

Styliticsはアイテムのバンドルデータのみを提供します。お客様とESPの間でユーザーデータを保持し、ユーザーに送信するStyliticsバンドルデータを組み込むことができます。

## データ交換 {#data-exchange}

次の3つのアプローチにより、トリガーメールにStyliticsバンドルを含めることができます。

### 1\.APIアプローチ（推奨） {#1-api-approach-recommended}

お客様またはESPが、アイテムごとにAPI呼び出しを実行して、バンドルデータをメールに取り込みます。Styliticsでは、すぐに使用できるStylitics APIを使用してAPI呼び出しを実行することを推奨しています。

{% alert note %}
Styliticsが実行するA/Bテストを行う場合、ユーザーがメールでクリックするStyliticsアイテムのPDP URLに、`styliticsCID`および`styliticsoverride`パラメーターを追加する必要があります。
<br><br>
たとえば {% raw %}`&styliticsoverride=001?styliticsCID=email[clientname]`{% endraw %} などです。
{% endalert %}

### 2\.フラットファイルアプローチ {#2-flat-file-approach}
お客様またはESPが、フラットファイル内のアイテムのバンドルデータを参照して、メールにバンドルデータを取り込むことができます。Styliticsはバンドルデータを CSV、TXT、または XML 形式でフラット化し、毎日送信できます。また、ESPのニーズに合わせてファイル形式を調整することもできます。このファイルの作成には2～3週間かかる点にご注意ください。

#### 要件 {#requirements}
- **ロケーション**：Styliticsがファイルを Stylitics SFTPにドロップしてお客様が毎日取り込むか、またはお客様がStyliticsにSFTP認証情報を送信してファイルをドロップすることができます。
- **時間**：Styliticsは毎朝ファイルをドロップします。特定の時間にファイルが必要な場合は、Styliticsにお知らせください。
- **ファイルキー**：お客様とStyliticsは、ESPがデータを参照できるように、ファイルのキーとなるアイテムデータ文字列について合意する必要があります。SKU、`item_group_id`、または`item_number`が一般的に使用されます。

### 3\.Webサイトデータ抽出アプローチ {#3-website-data-extraction-approach}
ベンダーは、サイトのフロントエンドをスクレイピングしてStyliticsのコンテンツを取得し、バンドルデータをメールに挿入できます。Styliticsからの追加作業は必要ありません。

## メールテンプレートのベストプラクティス {#email-template-best-practices}

お客様とESPが、Styliticsデータとバンドルを挿入するためのHTMLメールテンプレートを作成します。以下にいくつかのベストプラクティスと推奨事項を示します。
- ユーザーが購入または反応した最も高額なアイテムまたは最初の定価アイテムについて、2～4個のバンドルをメールに表示します
- 複数の`item_numbers`を呼び出して、最初のいくつかのバンドルレスポンスを表示します
- アイテムに対してバンドルが利用できない場合のフォールバックオプションを用意してください
	- Styliticsバンドルが配置されているセクションを非表示にします
	- ユーザーが閲覧した次のアイテムのバンドルを表示します
- バンドル画像と製品タイトルおよびサムネイル画像のリストを表示して、ユーザーが明確にクリックスルーできるようにします

{% alert note %}
メールではJavaScriptがサポートされていないため、StyliticsウィジェットのJavaScriptをメールに挿入することはできません。
{% endalert %}

## 分析 {#analytics}

Styliticsは、このタイプのメールプログラムのバンドルデータを提供します。そのため、お客様、ESP、およびStyliticsの間でオープンなデータ共有をお願いしています。可能であれば、効果を把握しプログラムを改善するために、以下の指標をご提供いただけますと幸いです。
- 送信メール数
- 開封メール数
- ビューとエンゲージメント
- クリックスルー率
- バッグに追加
- 購入

## 次のステップ {#next-steps}

メールプログラムの次のステップとタイムラインを調整するために、Styliticsのアカウントマネージャーにご連絡ください。次のステップには以下が含まれます。
- 使用するメールを決定する
- データ交換についてAPIオプションまたはフラットファイルオプションを検討するため、StyliticsをESPに紹介する
- ESPと連携してモックアップを作成する
- 分析について合意する
- ローンチのタイムラインについて合意する
