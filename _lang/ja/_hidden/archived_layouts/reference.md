### コードサンプル {#code-sample}

技術的な概念を説明している場合は、ここに記載し、コードサンプルを示してください。

```html
<!DOCTYPE html>
<html>
<head>
<title>Page Title</title>
</head>
<body>

<h1>My First Heading</h1>
<p>My first paragraph.</p>

</body>
</html>
```

ユーザーがコードサンプルから調整する必要があるパラメーターや要素を定義してください。多くのユーザーはコピーして貼り付けるだけです。

| 変数 | 説明 |
| -------- | ----------- |
| Page Title | ページのタイトルは何でも構いません。これは必須です。 |
| My First Heading | 大文字で記載することをお勧めします。これはオプションです。 |
