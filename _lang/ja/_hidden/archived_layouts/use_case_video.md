## キャンペーン/キャンバスの作り方 {#how-to-build-this-campaigncanvas}

この部分を書くときは、やるべきことを戦略とステップに分けて説明します。以下のようにステップに名前を付けると分かりやすくなります。手順を明示的に記述しないでください（つまり、このボタンをクリックする、あのボタンをクリックする、など）。代わりに、ユースケースの目標を達成するためのステップを記述することで、指示し導いてください。

### ステップ1: 離脱ユーザー向けにキャンバスを設定する（オーディエンスに関するアドバイス） {#step-1-set-up-your-canvas-for-lapsing-users-advise-on-audience}

オーディエンスについて話すときに、セグメントやフィルターの使用方法を指示する必要はありません。代わりに、オーディエンスを離脱ユーザーに絞り込み、他のユーザーに送信されないようにする方法と、それがなぜ重要なのかを説明します。たとえば、「数日間アプリを使用していないユーザーや、メールを開封していないユーザーを選択するなど、いくつかの方法で離脱ユーザーを絞り込むことができます。あまりにも長い間アプリから離れていて、データポイントの価値がないかもしれないユーザーを除外したい場合は、必ずフィルターを適用してください。」


### コードサンプル {#code-sample}

技術的な概念を説明する場合は、ここに記載し、コードサンプルを示してください。

```html
<!DOCTYPE html>
<html>
<head>
<title>Page Title</title>
</head>
<body>

<h1>My First Heading</h1>
<p>My first paragraph.</p>

</body>
</html>
```

ユーザーがコードサンプルから調整する必要があるパラメーターや要素を定義してください。多くのユーザーはコピーして貼り付けるだけです。

| 変数 | 説明 |
| -------- | ----------- |
| Page Title | ページのタイトルは何でも構いません。これは必須です。 |
| My First Heading | 大文字で記載することをお勧めします。これはオプションです。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Code Sample" }


### ステップ2: 適切なタイミングでメッセージを送信する {#step-2-send-your-message-at-the-right-time}

重要な場合は、メッセージを送信するタイミングについて説明します。重要でない場合もあります！少なくとも、ローカルタイムで送信できることを伝えてください。あるいは、この特定の状況をAPIでトリガーする方法や、キャンバスを使用していてアクションに基づいてステップをトリガーする方がよい場合（メールを開封してから少なくとも1日間クリックしないなど）についても説明してください。

### ステップ3: メッセージを構築する {#step-3-building-your-message}

ここでベストプラクティスについてアドバイスできます。いくつかのことをリストアップするだけだとしても、これを行うことを強くお勧めします。画像も追加するとよいでしょう。

### ステップ4: その他 {#step-4-anything-else}
