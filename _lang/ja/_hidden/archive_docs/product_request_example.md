# 製品リクエスト例 {#product-request-example}

ここでは、顧客が提出した優れた製品リクエストの例を示します。要望を明確に定義し、その機能のユースケースを詳細に説明しています。

## スカイスキャナーからのリクエスト例 {#example-request-from-skyscanner}

### どのような問題を解決しようとしていますか？ {#what-problem-are-you-trying-to-solve}
スカイスキャナーは、フリークエンシーキャップのコンテキストにおいて、特定のタグを他のタグよりも優先して指定できるようにしたいと考えています。

### 具体的なユースケースは何ですか？ {#what-are-some-specific-use-cases}
_ここでは、キャンペーンやキャンバスへのリンクが説明と同様に役立ちます_

ユーザーの行動に基づいて、より多くのトリガーキャンペーンを展開していくにつれて、一部のメールが互いに重複してしまい、1日1通を上限としているため、1日の早い時間にスケジュールされたメールが午後のメールよりも優先される可能性があります。これは理想的ではありません。例えば、ファネルの最下層に関するメール（リターゲティング）は、TOFU（ニュースレターなど）のメールよりも多くの結果をもたらすため、優先順位を付けられるようにしたいと考えています。

例えば、フリークエンシーキャップは最大1日とし、リダイレクトリターゲティングでタグ付けされたすべてのキャンペーンとキャンバスをP0、すべてのインスピレーションをP3、検索のすべてのリターゲティングをP2、XsellをP1などと定義できるようにしたいと考えています。

例を挙げると、結果としてタグを優先順位の順に定義することになります。

### 他に何かインサイトはありますか？ {#do-you-have-any-additional-insight}
_「これが私たちにできることです」というだけでなく、あなたやあなたのチームにとってより広くどのようなメリットがありますか。_

これにより、メールやキャンペーンをエコシステムとして作成し、ユーザーにとって包括的な体験となるように織り込むことができます。TOFUが優先されないように送信時間を調整する手間も省けます。
