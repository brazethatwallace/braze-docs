# CampaignおよびCanvasの再エントリ資格 {#re-eligibility-for-campaigns-and-canvas}

> 定期的またはトリガーベースのCampaignやCanvasをスケジュールする際、ユーザーに再エントリ資格を付与するオプションがあります。再エントリ資格とは、ユーザーがトリガーに基づいてCampaignやCanvasに複数回エントリできることを意味します。

## 仕組み {#how-it-works}

デフォルトでは、Brazeはユーザーに対してメッセージを1回のみ送信します。これは、ユーザーが複数回再適格となった場合でも同様で、再エントリ資格は別途オンにする必要があります。オンにすると、適格なメンバーはCampaignまたはCanvasの最初のインスタンスを受信した後、再度メッセージを受信できるようになります。ユーザーが最終的に再エントリ資格を得るまでのタイムラインを指定できます。

## 再エントリ資格をオンにする {#turning-on-re-eligibility}

{% tabs local %}
{% tab campaign %}
Campaignの再エントリ資格をオンにするには、**配信コントロール**セクションの**ユーザーがCampaignを再度受信できるようにする**チェックボックスを選択します。Campaignの再エントリ資格の最大期間は720日です。

再エントリ資格がオンになっているトリガーCampaignでは、（トリガーイベントを完了したにもかかわらず）[実際にはCampaignメッセージを受信しなかった]({{site.baseurl}}/user_guide/messaging/campaigns/schedule_your_campaign/triggered_delivery#why-did-a-user-not-receive-my-triggered-campaign)ユーザーは、次にトリガーイベントを完了した際に自動的にメッセージの対象となります。これは、再エントリ資格がCampaignエントリではなくメッセージの受信に基づいているためです。トリガーCampaignでユーザーに再エントリ資格を付与することで、ユーザーは（単にトリガーするだけでなく）実際にメッセージを複数回受信できるようになります。

{% alert note %}
「受信」には、共有チャネル識別子を通じたアトリビューションが含まれます。メッセージが配信、開封、またはクリックされると、Brazeは同じメールアドレスまたは電話番号を共有するすべてのプロファイルのデータを更新します。そのため、直接メッセージが送信されていないユーザーでも受信済みとしてマークされ、再エントリ資格を得られない場合があります。
{% endalert %}

また、再エントリ資格を0分に設定してメッセージを即座に送信しようとする場合、ユーザーがCampaignまたはCanvasの以前のバージョンをどのように受信したかに関係なく、常にすぐにスケジュールを試みます。

### APIトリガーCampaignの再エントリ資格 {#re-eligibility-with-api-triggered-campaigns}

ユーザーがAPIトリガーCampaignを受信する回数は、再エントリ資格の設定で制限できます。つまり、APIトリガーが何回発火されたかに関係なく、ユーザーはCampaignを1回のみ、または指定された期間内に1回のみ受信します。

たとえば、APIトリガーCampaignを使用して、ユーザーが最近閲覧したアイテムに関するCampaignを送信しているとします。この場合、APIトリガーを各アイテムに対して発火しつつ、閲覧したアイテム数に関係なく、Campaignの送信を1日あたり最大1メッセージに制限できます。一方、APIトリガーCampaignがトランザクション型の場合は、ユーザーがトランザクションを行うたびにCampaignを受信できるよう、遅延を0分に設定する必要があります。
{% endtab %}

{% tab canvas %}

Canvasの再エントリ資格をオンにするには、**エントリコントロール**セクションの**ユーザーがこのCanvasに再エントリできるようにする**を選択します。Canvasの最大期間後、または指定された期間後にユーザーが再エントリできるようにするかを選択できます。

Canvasバリアントの再エントリ資格は、メッセージの受信ではなくCanvasエントリに紐づいています。Canvasにエントリしてメッセージを受信しなかったユーザーは、再エントリ資格がオンになっていない限り、Canvasに再エントリすることはできません。

再エントリ資格が0秒に設定されている場合、ユーザーは最初にCanvasを退出する必要なく再エントリできます。つまり、ユーザーは同じCanvasに再度エントリできます。別の例として、Canvasの期間が7日間に設定され、再エントリ資格の期間が3日間に設定されている場合、ユーザーは最初のジャーニーを完了する前にCanvasに再エントリできます。

追加のフィルターを設定して、ユーザーが同じステップやメッセージを複数回受信することを防ぐことができます。ただし、ユーザーが2回目にCanvasに再エントリした場合、1回目のCanvas内で以前受信したステップはユーザーに表示されません。つまり、ユーザーは同じメッセージを再度受信する可能性があります。これを防ぐには、Canvasの再エントリを防止するか、再エントリ資格をCanvasの最大期間に設定します。

また、[ユーザーの更新ステップ]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/user_update)を使用して、ステップを受信したユーザーにカスタム属性としてログを記録させ、Canvasジャーニー中にそのステップを受信済みのユーザーをフィルタリングすることもできます。

### 例 {#example}

たとえば、メールアドレスを持たないユーザーが、ユーザージャーニーに1つのステップを含む日次定期Canvasにエントリしたとします。このステップにはメールメッセージのみが含まれているため、ユーザーはエンゲージメントを受け取りません。このユーザーは、Canvasに再エントリ資格がオンになっていない限り、再度Canvasにエントリすることはできません。

再エントリ資格のないアクティブな定期またはトリガーCanvasがあり、ユーザーがCanvasからメッセージを受信するまで再エントリできるようにしたい場合は、Canvasからメッセージを受信済みの顧客を除外するフィルターをエントリ条件に追加して、ユーザーにエントリの再エントリ資格を付与することを検討できます。

Canvasの再エントリ資格がCanvasの期間よりも短く設定されている場合、ユーザーがCanvasに複数回エントリする可能性があり、特に長い遅延を伴うアプリ内メッセージを使用するCanvasでは誤解を招く動作につながることがあります。複数のCanvasアプリ内メッセージが同じセッション開始によってトリガーされる可能性があるため、特定のコンポーネントが他のコンポーネントよりも速くレンダリングされた場合、ユーザーは同じメッセージを繰り返し受信する体験をする可能性があります。
{% endtab %}
{% endtabs %}

## 再エントリ資格の遅延計算 {#re-eligibility-delay-calculations}

CampaignとCanvasの両方の再エントリ資格は、カレンダー日ではなく秒単位で計算されます。つまり、1日はユーザーがメッセージを受信した時点から24時間（86,400秒）としてカウントされ、翌日の午前0時ではありません。同様に、1か月は正確に2,592,000秒としてカウントされ、約30日に相当します。

### 例

次のシナリオを考えてみましょう。

* Campaignは毎月15日に送信するよう設定されており、再エントリ資格は30日に設定されています。
* 2月15日から3月15日までは30日未満です。

これは、2月15日にCampaignを受信したユーザーは、3月15日に送信されるCampaignの対象にならないことを意味します。（共有チャネル識別子により、ユーザーが「受信済み」としてマークされる場合があります。たとえば、メッセージを受信、開封、またはクリックした人とメールアドレスや電話番号を共有している場合です。）Campaignが毎日午前8時に送信するよう設定されており、再エントリ資格が1日の場合、メッセージの送信に遅延が発生すると、午前8時30分にCampaignを受信したユーザーは翌日の午前8時にはまだ再エントリ資格を得ていません。

## Content Cardsの再エントリ資格 {#re-eligibility-for-content-cards}

Content Cards CampaignまたはCanvasステップで再エントリ資格が有効になっている場合、同じCampaignからの以前のカードがまだフィードに残っている状態で、ユーザーが別のカードを受信する可能性があり、重複カードのように見えることがあります。重複を減らすには、再エントリ資格をオフにするか、最初のカードがユーザーが次の送信対象となる前に[フィードから期限切れになる]({{site.baseurl}}/user_guide/channels/content_cards/create_a_content_card#the-30-day-expiration-and-re-eligibility)よう、再エントリ資格の期間を長くしてください。

## バナーの再エントリ資格 {#re-eligibility-for-banners}

バナーCampaignで再エントリ資格が有効になっている場合、バナーを閉じたユーザーは、閉じた時点から始まる設定可能なクールダウン期間の後に再度対象となることができます。再エントリ資格がオンになっていない場合、閉じたユーザーは対象外のままです。再エントリ資格を設定するには、[再エントリ資格の設定]({{site.baseurl}}/user_guide/channels/banners/create_a_banner#re-eligibility)を参照してください。Canvasのバナーステップでは、代わりにCanvasの再エントリ設定が使用されます。

## 多変量テスト {#multivariate-testing}

多変量テストでは、Brazeは以下のルールを使用して、すべてのCampaign、トリガーアプリ内メッセージ、およびCanvasのバリアント再エントリ資格を決定します。

- バリアントの割合が変更されていない場合、各ユーザーは再エントリ資格を得るたびに、常にCampaign、トリガーアプリ内メッセージ、またはCanvasエントリの同じバリアントにエントリします。
- バリアントの割合が変更された場合、ユーザーは他のバリアントに再配分される可能性があります。
- コントロールグループは、バリアントの割合が変更されていない限り一貫性を保ちます。以前にメッセージを受信したユーザーが後の送信でコントロールグループにエントリすることはなく、コントロールグループのユーザーがメッセージを受信することもありません。
