# クワイエットアワー {#quiet-hours}

> クワイエットアワーは、指定した時間枠内にメッセージが送信されるのを防ぎます。夜間や早朝など、ユーザーにとって不都合な時間帯に連絡することを避けつつ、その時間枠外の最適な時間に送信するために使用できます。

クワイエットアワーは、CampaignまたはCanvasレベルで設定します。

## クワイエットアワーの仕組み {#how-quiet-hours-work}

クワイエットアワーが有効で、制限された時間枠内にメッセージが送信される予定の場合、Brazeはメッセージを保留し、クワイエットアワー終了後の次に利用可能な時間に配信します。

たとえば、クワイエットアワーが午後10時から午前6時までに設定されていて、メッセージが午前5時30分にスケジュールされている場合、Brazeは代わりに午前6時に配信します。

{% alert note %}
クワイエットアワーは各ユーザーのローカルタイムゾーンで適用されます。
{% endalert %}

## クワイエットアワーとインテリジェントタイミング {#quiet-hours-and-intelligent-timing}

クワイエットアワーとインテリジェントタイミングは独立して動作します。クワイエットアワーを有効にするためにインテリジェントタイミングをオンにする必要はなく、その逆も同様です。一般的に、ポリシー、コンプライアンス、またはその他の要件によりインテリジェントタイミングと併用する必要がある場合を除き、両方を同時に使用するのではなく、どちらか一方を選択することをお勧めします。

- **インテリジェントタイミングなしの場合:** クワイエットアワーは、スケジュールされた送信時間に対する送信禁止時間枠として機能します。スケジュールされた時間がクワイエットアワー内に該当する場合、メッセージは保留され、時間枠が終了した時点で送信されます。
- **インテリジェントタイミングありの場合:** Brazeは引き続き各ユーザーの最適な送信時間を計算します。その時間がクワイエットアワー内に該当する場合、メッセージは保留され、代わりにクワイエット時間枠の最も近い端で配信されます。

インテリジェントタイミングCampaignでのクワイエットアワーの設定について詳しくは、[インテリジェントタイミング]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_timing)を参照してください。

## 考慮事項 {#things-to-consider}

- **クワイエットアワー終了時にメッセージが同時に送信されます。** 大規模なオーディエンスのメッセージがクワイエットアワー中に保留されている場合、時間枠が終了した時点でそれらのメッセージがすべて一斉に送信されます。時間に敏感なCampaignでは、これが配信タイミングにどのように影響するかを考慮してください。
- **クワイエットアワーはメッセージの中止とは異なります。** メッセージを中止すると、メッセージは完全に破棄されます。クワイエットアワーはメッセージを保留し、後で配信します。
- **クワイエットアワーはフリークエンシーキャップやレート制限とは別のものです。** これらの配信コントロールはそれぞれ独立して適用されます。フリークエンシーキャップとレート制限をクリアしたメッセージでも、クワイエットアワーによって保留される場合があります。また、クワイエットアワーによって保留されたメッセージは、最終的に送信される際にレート制限に対して評価されます。詳しくは、[レート制限とフリークエンシーキャップ]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/frequency_capping)を参照してください。
