# クワイエットアワー {#quiet-hours}

> クワイエットアワーは、指定した時間枠内にメッセージが送信されるのを防ぎます。夜間や早朝など、ユーザーにとって不都合な時間帯に連絡することを避けつつ、その時間枠外の最適な時間に送信するために使用できます。

クワイエットアワーは、キャンペーンまたはキャンバスレベルで設定します。また、ワークスペース全体のメッセージングチャネルのデフォルトとして[ワークスペースクワイエットアワー]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/quiet_hours/workspace_quiet_hours)を設定することもできます（早期アクセス）。

## 静寂時間の仕組み {#how-quiet-hours-work}

静寂時間が有効になっている場合、制限されたウィンドウ中にメッセージが送信されるはずだったとき、Brazeはメッセージを保留し、静寂時間の終了後に次の利用可能な時間に配信します。

たとえば、静寂時間が午後10時から午前6時までで、メッセージが午前5時30分にスケジュールされている場合、Brazeは代わりに午前6時に配信します。

{% alert note %}
静寂時間は各ユーザーのローカルタイムゾーンで適用されます。
{% endalert %}

## サイレント時間帯とインテリジェントタイミング {#quiet-hours-and-intelligent-timing}

サイレント時間帯とインテリジェントタイミングは独立して動作します。サイレント時間帯を有効にするためにインテリジェントタイミングをオンにする必要はなく、その逆も同様です。一般的に、ポリシー、コンプライアンス、またはその他の要件によりインテリジェントタイミングと併せてサイレント時間帯が必要な場合を除き、両方を同時に使用するのではなく、どちらか一方を選択することをお勧めします。

- **インテリジェントタイミングなしの場合：** サイレント時間帯は、スケジュールされた送信時刻に対する送信禁止ウィンドウとして機能します。スケジュールされた時刻がサイレント時間帯内に該当する場合、メッセージは保留され、ウィンドウが終了した時点で送信されます。
- **インテリジェントタイミングありの場合：** Brazeは引き続き各ユーザーの最適な送信時刻を計算します。その時刻がサイレント時間帯内に該当する場合、メッセージは保留され、代わりにサイレント時間帯の最も近い境界で配信されます。

インテリジェントタイミングキャンペーン内でのサイレント時間帯の設定について詳しくは、[インテリジェントタイミング]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_timing)を参照してください。

## 考慮すべきポイント {#things-to-consider}

- **サイレント時間の終了時にメッセージが一斉に送信されます。**大規模なオーディエンスのメッセージがサイレント時間中に保留されている場合、ウィンドウが終了した時点でそれらのメッセージがすべて一度に送信されます。時間的制約のあるキャンペーンでは、これが配信タイミングにどのように影響するかを考慮してください。
- **サイレント時間はメッセージの中止とは異なります。**メッセージを中止すると、そのメッセージは完全に破棄されます。サイレント時間はメッセージを保留し、後で配信します。
- **サイレント時間はフリークエンシーキャップやレート制限とは別の機能です。**これらの配信コントロールはそれぞれ独立して適用されます。フリークエンシーキャップとレート制限をクリアしたメッセージでも、サイレント時間によって保留される場合があります。また、サイレント時間によって保留されたメッセージは、最終的に送信される際にレート制限に対して評価されます。詳細については、[レート制限とフリークエンシーキャップ]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/frequency_capping)を参照してください。
