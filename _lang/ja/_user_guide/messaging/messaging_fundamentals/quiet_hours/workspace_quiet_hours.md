# ワークスペースの配信停止時間 {#workspace-quiet-hours}

> ワークスペースの配信停止時間を使用すると、ワークスペース全体でメッセージングチャネルにデフォルトの配信停止時間ウィンドウを設定できます。そのチャネルで送信するすべてのキャンペーンとキャンバスが自動的にこのウィンドウを遵守するため、キャンペーンやキャンバスごとに個別に配信停止時間を設定する必要がありません。

ワークスペースの配信停止時間は、キャンペーンおよびキャンバスレベルの配信停止時間とは別のものです。キャンペーンおよびキャンバスレベルの配信停止時間は、設定した場合に引き続き適用されます。ワークスペースの配信停止時間はデフォルトのケースに使用してください（例：すべてのSMS送信に対するコンプライアンス要件）。例外的なケースにはキャンペーンおよびキャンバスレベルの配信停止時間を使用してください。

{% alert important %}
ワークスペースの配信停止時間は現在、早期アクセスで利用可能です。一般提供前に設定オプションが変更される場合があります。アクセスをリクエストするには、Brazeアカウントチームにお問い合わせください。
{% endalert %}

## 仕組み {#how-it-works}

- **チャネルごとに1つのウィンドウ：** 各チャネルは、開始時刻と終了時刻で定義される1つのワークスペース配信停止時間ウィンドウをサポートします。
- **ローカルタイムゾーン：** キャンペーンおよびキャンバスレベルの配信停止時間と同様に、ワークスペースの配信停止時間は会社のタイムゾーンではなく、各受信者のローカルタイムゾーンで適用されます。
- **後で配信するために保留：** ウィンドウ中に送信されるはずだったメッセージは保留され、後で配信されるか、キャンペーンタイプに応じて中止されます。[保留されたメッセージの処理](#what-happens-to-a-held-message)を参照してください。配信停止時間はメッセージの内容を変更しません。タイミングにのみ影響します。
- **最大ウィンドウ長：** 配信停止時間ウィンドウは20時間を超えることはできません。この制限は、チャネルでのすべての送信を誤って一時停止することを防ぐために存在します（例：開始時刻と終了時刻を同じ値に設定した場合）。

### サポートされるチャネル {#supported-channels}

以下のチャネルに対してワークスペースの配信停止時間ウィンドウを設定できます。

- Content Cards
- メール
- KakaoTalk
- LINE
- プッシュ
   - これはワークスペース内のすべてのプッシュプラットフォームに適用されます。個別のプラットフォーム（例：iOSとAndroid）に異なる配信停止時間を設定するオプションはありません。
- SMS/MMS/RCS
- Webhook
- WhatsApp

## 前提条件 {#prerequisites}

ワークスペースの配信停止時間を作成または更新するには、「Edit Quiet Hours」権限が必要です。

| 権限 | アクセス |
|---|---|
| Edit Quiet Hours | ワークスペースの配信停止時間を作成および更新します。 |
| View Quiet Hours | ワークスペースの配信停止時間の設定を編集せずに表示します。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="配信停止時間の権限" }

既存のキャンペーンおよびキャンバスの編集権限には影響しません。これらの権限を持つユーザーは、引き続きキャンペーンまたはキャンバスレベルで配信停止時間を編集できます。

## ワークスペースの配信停止時間を設定する {#set-up-workspace-quiet-hours}

### ワークスペースウィンドウを設定する {#configure-the-workspace-window}

1. **設定** > **配信停止時間**に移動します。
2. **配信停止時間を追加**を選択します。
3. チャネルを選択し、開始時刻と終了時刻を入力します。1つのチャネルに設定できるワークスペース配信停止時間ウィンドウは一度に1つだけです。
4. （オプション）別のチャネルを追加するには、**配信停止時間を追加**を再度選択します。
5. 変更を保存します。

![SMSとメールの配信停止時間ウィンドウが表示されたワークスペース設定ページ。各ウィンドウには開始時刻と終了時刻があり、配信停止時間を追加するオプションがあります。]({% image_buster /assets/img/quiet_hours/workspace_quiet_hours_settings.png %}){: style="max-width:90%;"}

ワークスペースの配信停止時間の更新は変更ログに記録されます。この設定はチャネル上のすべてのキャンペーンとキャンバスに影響するため、誰がいつ変更したかが記録されます。

### キャンペーンまたはキャンバスで適用またはオーバーライドする {#apply-or-override-in-a-campaign-or-canvas}

保存後、ワークスペースの配信停止時間ウィンドウは、ウィンドウが設定されている各チャネルのキャンペーンおよびキャンバスエディターに表示されます。ワークスペースのデフォルトをそのまま使用するか、オプトアウトしてキャンペーンまたはキャンバス固有のウィンドウを代わりに適用できます。これはワークスペースレベルのフリークエンシーキャップからオプトアウトする方法と同じです。

1. **このキャンペーンに配信停止時間を適用する**（またはキャンバスの同等のオプション）を選択します。
2. **ワークスペースの配信停止時間を使用する**を選択してワークスペースのデフォルトを適用するか、**カスタム配信停止時間を使用する**を選択してキャンペーンまたはキャンバス固有のウィンドウを設定します。
3. 使用中のチャネルのワークスペースウィンドウを確認するには、**配信停止時間を表示**を選択します。

![キャンペーンの配信停止時間セクション。「このキャンペーンに配信停止時間を適用する」が選択され、「ワークスペースの配信停止時間を使用する」が選択されており、メールのワークスペースウィンドウ（午後8:00〜午前8:00）が展開表示されています。]({% image_buster /assets/img/quiet_hours/campaign_workspace_quiet_hours.png %}){: style="max-width:70%;"}

## 優先順位：ワークスペースとキャンペーンまたはキャンバスの配信停止時間 {#precedence-workspace-versus-campaign-or-canvas-quiet-hours}

特定のキャンペーンまたはキャンバスに対して、一度に有効になる配信停止時間の設定は1つだけです（ワークスペースの配信停止時間、キャンペーンまたはキャンバス固有のウィンドウ、またはなし）。キャンペーンまたはキャンバスレベルの配信停止時間ウィンドウは、常にワークスペースのデフォルトよりも優先されます。

配信停止時間の適用方法は、キャンペーンまたはキャンバスが作成された時期にも依存します。

- **既存のキャンペーンとキャンバス**（ワークスペースの配信停止時間を有効にする前に作成されたもの）：キャンペーンまたはキャンバスに独自の配信停止時間ウィンドウがない場合、そのチャネルのワークスペース配信停止時間ウィンドウが自動的に適用されます。すでにキャンペーンまたはキャンバスレベルのウィンドウがある場合は、そのウィンドウが引き続き適用されます。
- **新しいキャンペーンとキャンバス：** キャンペーンまたはキャンバスを作成する際に、ワークスペースの配信停止時間のデフォルトを使用するか、カスタムのキャンペーンまたはキャンバスレベルのウィンドウを設定するか、配信停止時間を完全にオプトアウトするかを選択できます。

| 設定の状態 | 適用される配信停止時間 |
|---|---|
| キャンペーンまたはキャンバスに独自の配信停止時間ウィンドウがある | キャンペーンまたはキャンバスレベルのウィンドウが適用されます。そのキャンペーンまたはキャンバスではワークスペースの配信停止時間は無視されます。 |
| キャンペーンまたはキャンバスに独自の配信停止時間ウィンドウがなく、使用するチャネルにワークスペースの配信停止時間ウィンドウが存在する | ワークスペースの配信停止時間ウィンドウが自動的に適用されます。これには、配信停止時間を設定したことがない既存のキャンペーンとキャンバスも含まれます。 |
| キャンペーンまたはキャンバスがオプトアウトしている | 配信停止時間は適用されません。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="配信停止時間の優先順位" }

### 保留されたメッセージの処理 {#what-happens-to-a-held-message}

配信停止時間ウィンドウ内に該当するメッセージの処理は、キャンペーンまたはキャンバスの配信タイプによって異なります。

- **アクションベースのキャンペーンとキャンバス：** フォールバックは**メッセージを中止する**または**次に利用可能な時間に送信する**のいずれかで、キャンペーンおよびキャンバスレベルの配信停止時間と同じオプションです。
- **固定送信時刻のスケジュールされたキャンペーン：** フォールバックは**メッセージを中止する**です。Brazeは固定時刻の送信を次に利用可能なスロットまで遅延させません。配信停止時間の終了後に大量のメッセージが圧縮された送信ウィンドウに集中する可能性があるためです。
- **インテリジェントタイミングを使用するキャンペーン：** 別途のフォールバックは不要です。Brazeは各ユーザーに対して計算する最適な送信時刻にワークスペースの配信停止時間ウィンドウをすでに考慮しているため、メッセージはそもそもウィンドウ内にスケジュールされません。
- **APIトリガーキャンペーンとAPIキャンペーン：** フォールバックはデフォルトで**メッセージを中止する**です。

### APIトリガーキャンペーンとAPIキャンペーン {#api-triggered-and-api-campaigns}

配信停止時間は、APIトリガーキャンペーンとAPIキャンペーンでは異なる動作をします。

#### APIトリガーキャンペーン {#api-triggered-campaigns}

APIトリガーキャンペーンは、ダッシュボードの他のキャンペーンと同じ配信停止時間オプションに従います。ワークスペースの配信停止時間のデフォルトを使用するか、カスタムのキャンペーンレベルのウィンドウを設定するか、キャンペーン設定で配信停止時間をオプトアウトできます。APIトリガー送信用の`ignore_workspace_quiet_hours` APIパラメーターはありません。

`at_optimal_time`を使用するスケジュールされたAPIトリガー送信の場合、ワークスペースの配信停止時間は[インテリジェントタイミング]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_timing)と同様に、最適な送信時刻にすでに考慮されています。

#### APIキャンペーン {#api-campaigns}

APIキャンペーンはキャンペーンレベルの配信停止時間を使用できません。ワークスペースの配信停止時間ウィンドウのみが適用されます。そのウィンドウ中に送信するには、APIリクエストにオプションの`ignore_workspace_quiet_hours`パラメーターを含めてください。

### 除外対象 {#exclusions}

以下は、チャネルに関係なく、ワークスペースの配信停止時間によって保留されることはありません。

- トランザクションメッセージおよびSLA対象メッセージ
- SMS自動応答（例：`STOP`や`HELP`キーワードの返信）
- テスト送信およびシードグループ送信

## その他の考慮事項 {#other-considerations}

- **会社時間でのスケジュール送信：** ワークスペースの配信停止時間は各受信者のローカルタイムゾーンに基づいていますが、スケジュールされたキャンペーンの送信時刻は会社のタイムゾーンで設定されている場合があります。このずれにより、会社時間では問題ないように見える送信時刻でも、一部の受信者にとっては配信停止時間内に該当する可能性があります。送信前にキャンペーンエディターに表示されるワークスペースの配信停止時間の詳細を確認してください。
- **配信停止時間終了後の配信：** ウィンドウ中に大量のオーディエンスが保留された場合、ウィンドウが閉じると同時にそれらのメッセージが一斉に送信可能になる場合があります。チャネルのオーディエンスが広く、配信停止時間ウィンドウが長い場合は、この点を考慮して計画してください。
- **フリークエンシーキャップおよびレート制限とは独立：** ワークスペースの配信停止時間は、フリークエンシーキャップおよびレート制限とは独立して適用されます。これらのコントロールをクリアしたメッセージでも配信停止時間によって保留される場合があり、配信停止時間によって保留されたメッセージは送信準備が整った時点でレート制限に対して評価されます。
- **インテリジェントタイミングは、マルチチャネルのアクションベースキャンペーンではワークスペースの配信停止時間をオーバーライドします。送信時刻を制限するには、代わりにカスタム配信停止時間を設定してください。

## 関連設定 {#related-settings}

- [配信停止時間]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/quiet_hours)：この機能の既存のキャンペーンおよびキャンバスごとのバージョンです。ワークスペースの配信停止時間はこれを置き換えるものではなく、キャンペーンまたはキャンバスが独自のウィンドウを設定していない場合に適用されるデフォルトを設定します。
- [インテリジェントタイミング]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_timing)：ユーザーごとに最適な送信時刻を計算します。ワークスペースの配信停止時間と併用する場合、配信停止時間はその計算に考慮されます。
- [レート制限とフリークエンシーキャップ]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/frequency_capping)：配信停止時間とは独立して適用される別の配信コントロールです。
