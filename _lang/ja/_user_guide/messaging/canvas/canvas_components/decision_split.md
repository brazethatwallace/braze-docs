# 条件分岐 {#decision-split}

> キャンバスの条件分岐コンポーネントを使用すると、ユーザーにパーソナライズされたリアルタイムの体験を提供できます。

![プッシュが有効なユーザーと有効でないユーザーを対象とした「プッシュ有効？」という名前の条件分岐ステップ。]({% image_buster /assets/img/decision-split-1.png %}){: style="float:right;max-width:40%;margin-left:15px;margin-top:15px;margin-bottom:15px;"}

このコンポーネントを使用すると、ユーザーがクエリに一致するかどうかに基づいてキャンバスの分岐を作成できます。

## 条件分岐を作成する {#create-a-decision-split}

ワークフローで条件分岐を作成するには、キャンバスにステップを追加します。次に、サイドバーからコンポーネントをドラッグ＆ドロップするか、ステップの下部にある<i class="fas fa-plus-circle"></i>プラスボタンを選択して**条件分岐**を選択します。

### 分岐を定義する {#define-your-split}

ユーザーをどのように分岐させますか？[セグメント]({{site.baseurl}}/user_guide/audience/segments)とフィルターを使用して条件を設定できます。基本的には、ユーザーを評価して一方のステップまたはもう一方のステップに振り分ける`true`または`false`のクエリを作成します。少なくとも1つのセグメントまたは1つのフィルターを使用する必要があります。セグメントとフィルターの両方を使用する必要はありません。

![「フォアグラウンドプッシュが有効」が true に設定されたフィルターを持つ条件分岐ステップ。]({% image_buster /assets/img/define-split-2.png %})

{% alert note %}
デフォルトでは、条件分岐ステップのセグメントとフィルターは、ディレイを追加しない限り、前のステップを受信した直後にチェックされます。
{% endalert %}

#### 再エントリが有効なキャンバスでのリターゲティングフィルター {#retargeting-filters-in-canvases-with-re-entry}

条件分岐ステップのリターゲティングフィルター（`Clicked/Opened Step In This キャンバス`など）は、以前のエントリを含む、ユーザーのすべてのキャンバスエントリにわたるエンゲージメントを評価します。たとえば、ユーザーが以前のエントリ中にあるステップに対してインタラクションを行った場合、条件分岐はそのユーザーがキャンバスに再エントリした際にそのインタラクションを認識します。

再エントリが有効なキャンバスでは、現在のキャンバスエントリ中のエンゲージメントのみを時間枠内で評価する必要がある場合、**ステップとのインタラクション**トリガーを使用した[アクションパス]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/action_paths)ステップを使用してください。アクションパスは、ステップの評価ウィンドウ中に発生したインタラクションのみをカウントします。

## 条件分岐を使用する {#use-your-split}

条件分岐を使用すると、ユーザーのセグメントや属性に基づいて、さらにはユーザーがメッセージを受信するために特定のメッセージングチャネルを使用しているかどうかに基づいて、パスを区別できます。

例えば、オンボーディングフローを作成するとします。まず、サインアップ時にウェルカムメールを送信します。次に、2日後にプッシュメッセージを送信しますが、プッシュが有効なユーザーにのみ送信します。その後、サインアップから3日後にすべてのユーザーに別のメールを送信します。また、条件分岐を使用して、プッシュが有効になっていないユーザーにアプリ内メッセージを送信し、プッシュを有効にするよう促すこともできます。

いずれかのパスの後にステップがない場合、そのパスに進んだユーザーはキャンバスを退出します。

![「プッシュ有効？」という名前の条件分岐ステップ。プッシュが有効でないユーザーと有効なユーザーに分かれています。プッシュが有効でないユーザーは、3日間の遅延の後にメールメッセージを受信します。プッシュが有効なユーザーは、1日間の遅延の後にプッシュ通知を受信し、さらに2日間の遅延の後に、プッシュが有効でないユーザーと同じメールメッセージを受信します。]({% image_buster /assets/img/use-split-onboarding-3.png %}){: style="max-width:60%"}

## 分析 {#analytics}

このステップの分析の説明については、以下の表を参照してください。

| 指標 | 説明 |
|---|---|
| _エントリ済み_ | ステップにエントリした合計回数です。キャンバスに再エントリ資格があり、ユーザーが条件分岐ステップに2回エントリした場合、2つのエントリが記録されます。 |
| _はい_ | 指定された条件を満たし、「はい」のパスに進んだエントリの数です。 |
| _いいえ_ | 指定された条件を満たさず、「いいえ」のパスに進んだエントリの数です。 |
