# ディレイ

> ディレイコンポーネントを使用すると、Canvasにスタンドアロンのディレイを追加できます。関連するメッセージを追加せずに、Canvasにディレイを追加できます。

ディレイを使用すると、Canvasをよりすっきりと見せることができます。また、このコンポーネントを使用して、正確な日付まで、特定の日まで、または特定の曜日まで別のステップを遅延させることもできます。ディレイコンポーネントは、最大1つの後続ステップに接続できます。<br> ![1日のディレイがCanvasの最初のステップとして設定されたディレイステップ。]({% image_buster /assets/img/canvas_delay.png %}){: style="float:right;max-width:35%;margin-left:15px;"}

## ディレイの作成

ディレイを作成するには、Canvasにステップを追加します。サイドバーからディレイコンポーネントをドラッグ＆ドロップするか、ステップの下部にある<i class="fas fa-plus-circle"></i>プラスボタンを選択して**ディレイ**を選択します。

### 延長ディレイ

ディレイステップは最大2年間（730日）まで延長できます。例えば、アプリの新規ユーザーをオンボーディングしている場合、セッションを開始していないユーザーに対してメッセージステップを送信する前に、2か月間の延長ディレイを追加できます。

## 時間ディレイのタイプ

Canvasの次のメッセージまでのディレイのタイプを選択できます。指定された期間が経過するまでユーザーを待機させるディレイを設定するか、特定の日時までユーザーを待機させることができます。

時間ディレイがある場合、一部のユーザーはディレイ後にのみCanvasの次のステップに進むことが想定されます。ディレイ中のユーザーは「_次のステップに進んだ_」指標に追加されません。詳細については、[ディレイ分析](#delay-analytics)を参照してください。

{% tabs %}
{% tab 期間 %}

**期間**を選択すると、秒、分、時間、日、または週の設定された数だけ、特定の時間にユーザーを遅延させることができます。例えば、ユーザーを4時間または1日遅延させることができます。

「日」と「暦日」の計算方法の違いに注意してください。

- 「日」は24時間であり、ユーザーがディレイステップに入った時点から計算されます。
- 「暦日」は次の指定された時間までの待機時間を定義し、24時間未満になる場合があります。会社の時間またはユーザーのローカルタイムゾーンで遅延させることを選択できます。時間が指定されていない場合、ユーザーは会社の時間で翌日の深夜まで遅延されます。

**特定の時間に**を選択して、ユーザーがCanvasで進むタイミングを指定することもできます。このオプションは、ユーザーがディレイステップに入った時間を考慮します。この時間が設定で構成された時間を超えている場合、ディレイにさらに時間が追加されます。

例として、今日が12月11日で、ディレイステップが**期間**1週間、午前8時（UTC）に設定されているとします。ユーザーが12月4日にディレイステップに入った場合、午前8時（UTC）より前にディレイステップに入っていれば、今日ディレイステップから解放されてジャーニーを続行します。この時間以降にディレイステップに入った場合、ユーザーは翌日（この時間の次の発生時）まで遅延されます。

{% endtab %}
{% tab カレンダー日付 %}

**カレンダー日付**を選択すると、特定の日時までユーザーをステップに保持できます。

### 考慮事項

#### 過去の日付のステップやメッセージはユーザーに届きません

選択した日時がユーザーがディレイステップに進む時点ですでに過ぎている場合、ユーザーはCanvasを退出します。Canvasの開始と「正確な日まで待機」ステップに選択された日付の間には、最大31日の間隔を設けることができます。

{% alert important %}
[Canvas Contextの早期アクセス]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/context)に参加している場合、最大2年間のディレイを設定できます。
{% endalert %}

例えば、以下のシナリオではユーザーはステップやメッセージを受信しません：

- メッセージが5月3日午後9時に送信されるようにスケジュールされているが、ディレイステップが5月3日午前9時に期限切れになる場合。
- Canvasステップがユーザーのローカルタイムゾーンの特定の時間まで遅延するが、ユーザープロファイルにタイムゾーンが設定されていない場合。この場合、ディレイはこれらのユーザーに対して会社のタイムゾーンをデフォルトとして使用しますが、指定された時間がすでに過ぎています。

#### 後続のディレイステップが前のディレイステップのタイムライン内にある場合、ユーザーは退出します

Canvasに2つのディレイステップがあり、最初のディレイステップが2番目のディレイステップよりも長い場合、ユーザーもCanvasを退出します。

例えば、Canvasに以下のステップがあるとします：
- ステップ 1：メッセージステップ
- ステップ 2：12月13日午後10時までのディレイステップ
- ステップ 3：メッセージステップ
- ステップ 4：12月13日午後7時までのディレイステップ
- ステップ 5：メッセージステップ

ステップ 4に入ったユーザーは、ステップ 4のディレイがステップ 2のタイムフレームの一部であるため、ステップ 5を受信する前にCanvasを退出します。

{% endtab %}
{% tab 曜日 %}

**曜日**を選択すると、特定の曜日の特定の時間までユーザーをステップに保持できます。例えば、会社のタイムゾーンで次の木曜日の午後4時までユーザーを遅延させることができます。

これを正しく設定するには、ユーザーが選択した曜日（例：木曜日）に指定された時間以降にCanvasに入った場合の動作も選択する必要があります。同じ日にユーザーを進めるか、翌週まで保持するかを選択できます。
{% endtab %}
{% endtabs %}

## ディレイステップの使用

6月10日だとしましょう。6月11日に、ユーザーがCanvasに入り、今後のプロモーションに関するメッセージを受信するようにしたいとします。次に、6月17日午後3時（ローカルタイム）までユーザーをCanvasに保持したいとします。6月17日午後3時（ローカルタイム）に、プロモーションに関するリマインダーメッセージをユーザーに送信したいとします。

Canvasステップのシーケンスは以下のようになります：

1. まず、6月11日にユーザーがCanvasに入った直後に送信されるメッセージステップを追加します。
2. 6月17日午後1時（ローカルタイム）までユーザーを保持するディレイステップを作成します。
3. ディレイステップを、メッセージを即座に送信する別のメッセージステップにリンクします。

### Canvasの最後のディレイコンポーネント {#delay-as-last-step}

Canvasにディレイコンポーネントを追加し、後続のステップがない場合、最後のステップに到達したユーザーは自動的にCanvasから進められます。これは、ディレイステップの時間にまだ達していない場合でも同様です。つまり、すでにディレイステップに到達したユーザーは、このステップの後に追加されたメッセージを受信しません。ただし、ユーザーがまだディレイステップに到達しておらず、メッセージが追加された場合、そのメッセージを受信します。

### パーソナライズされたディレイ

{% multi_lang_include alerts/early_access_beta_alert.md feature='The personalized delays and extended delays feature' %}

**ディレイをパーソナライズ**トグルを選択して、ユーザー向けのパーソナライズされたディレイを設定します。これを[Contextステップ]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/context)と組み合わせて使用し、遅延に使用するコンテキスト変数を選択できます。これにより、選択した属性またはプロパティで設定された時刻が上書きされます。これは、日数または週数のオフセットを適用し、ユーザーを特定の時間に進めたい場合に便利です。タイムゾーンは属性またはプロパティから取得され、利用できない場合はフォールバックが使用されます。

#### 「特定の時間に」のタイムゾーン動作

**特定の時間に**オプションでパーソナライズされたディレイを設定する場合、タイムゾーンの動作は属性またはコンテキスト変数のデータタイプによって異なります：

- **タイムゾーン情報を含む文字列データタイプ：** 属性またはコンテキスト変数がタイムゾーン情報を含む文字列データタイプの場合、文字列で指定されたタイムゾーンに準拠します。例えば、`2025-06-10T10:00:00-08:00`はUTC-8を使用します。
- **タイムゾーン情報を含まない文字列データタイプ：** 属性またはコンテキスト変数がタイムゾーン情報を含まない文字列データタイプの場合、フォールバックタイムゾーンに準拠します。例えば、`2025-06-10`はフォールバックタイムゾーンを使用します。
- **時間データタイプ：** 属性またはコンテキスト変数が時間データタイプの場合、UTCに準拠します。これは、時間データタイプがデータベースに保存される際に常にUTCに変換されるため、変数が時間データタイプに設定されている場合、「特定の時間に」は常にUTCを参照します。例えば、`2025-06-10T10:00:00-08:00`はUTC+0を使用します。

{% alert note %}
文字列データタイプの場合、カスタム属性またはコンテキスト変数に特定の時間もタイムゾーンも含まれない可能性があります。時間データタイプの場合は、時間とタイムゾーンを指定する必要があります。ただし、カスタム属性またはコンテキスト変数が「無関係な」文字列（「product_name」など）の場合、ユーザーはCanvasを退出します。
{% endalert %}

#### ユースケース

顧客に30日後に歯磨き粉の購入をリマインドしたいとしましょう。Contextステップとディレイステップの組み合わせを使用して、遅延に使用するコンテキスト変数を選択できます。この場合、Contextステップには以下のフィールドがあります：

- **コンテキスト変数名：** product_reminder_interval
- **データタイプ：** 時間
- **値：** {% raw %}`{{custom_attribute.${Order_filled_time}}}`{% endraw %}

![「product_reminder_interval」とその値。]({% image_buster /assets/img/context_step1.png %})

次に、30日後に顧客にリマインドしたいため、ディレイオプションとして**特定の日まで**を選択し、**ディレイをパーソナライズ**を選択してContextステップの情報を使用します。これにより、ユーザーは選択したコンテキスト変数まで遅延されます。

## ディレイ分析 {#delay-analytics}

ディレイコンポーネントには、アクティブまたは以前アクティブだったCanvasの分析ビューで以下の指標が利用できます。

| 指標 | 説明 |
|---|---|
| _入場_ | ステップに入った回数を反映します。Canvasに再エントリー資格があり、ユーザーがディレイステップに2回入った場合、2つのエントリーが記録されます。 |
| _次のステップに進んだ_ | Canvasの次のステップに進んだエントリー数を反映します。 |
| _Canvasを退出_ | Canvasを退出し、次のステップに進まなかったエントリー数を反映します。 |
| _パーソナライゼーション失敗_ | ユーザー向けのパーソナライズされたメッセージまたはコンテンツが以下の理由で配信できなかった回数を反映します：<br> {::nomarkdown}<ul><li>ディレイ値が過去の日付である</li><li>ディレイ値が2年以上先の未来である</li><li><b>期間後</b>の値が数値ではない</li><li><b>特定の日まで</b>の値が日付または日付形式の文字列ではない</li></ul>{:/} <br>詳細については、[パーソナライゼーション失敗エラー](#personaliztion-failed-errors)を参照してください。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="ディレイ分析" }

これらの分析の時系列は、展開されたコンポーネントビューで利用できます。

## トラブルシューティング

### パーソナライゼーション失敗エラー {#personaliztion-failed-errors}

ユーザーがパーソナライズされたディレイをトリガーしていない場合、ディレイステップの資格を得るために設定したContextステップが期待どおりに機能していない可能性があります。[コンテキスト変数が無効]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/context#troubleshooting)な場合、ユーザーはContextステップによるコンテキストの設定なしにCanvasを続行します。これにより、パーソナライズされたディレイなど、Canvasの後続のステップの資格を得られなくなる可能性があります。

### Canvasが停止されたときにディレイステップにいるユーザー

[Canvasを停止]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/change_your_canvas_after_launch#stopping-canvases)すると、すでにディレイステップで待機しているユーザーはすぐには退出しません。Brazeはディレイの完了を引き続きスケジュールしますが、Canvasが停止している間は**それ以降のメッセージは送信されません**。

Canvasを再有効化した時点でユーザーのディレイがまだ経過していない場合、スケジュールどおりに次のステップに進むことができます。Canvasが停止している間にディレイの時間枠がすでに過ぎていた場合、それらのユーザーは次のステップを受信する代わりにCanvasを退出します。例については、[Canvasを停止するとどうなりますか？]({{site.baseurl}}/user_guide/messaging/canvas/faqs#what-happens-when-you-stop-a-canvas)および[Canvasの停止]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/change_your_canvas_after_launch#stopping-canvases)を参照してください。
