# オーディエンスパス {#audience-paths}

> キャンバスのオーディエンスパスを使用すると、各ユーザーを条件に一致する最初のパスに送ることで、大規模にユーザーを直感的にフィルタリングおよびセグメンテーションできます。

このキャンバスコンポーネントは、オーディエンスベースのフルステップを過剰に作成する必要性を置き換え、8つのフルコンポーネントが必要だったものを1つにまとめることができます。これにより、ユーザーターゲティングが簡素化され、キャンバスから不要な煩雑さと複雑さが解消されます。

## 仕組み {#how-it-works}

![エンゲージしたユーザーとその他全員の2つのグループがあるオーディエンスパス。]({% image_buster /assets/img/audience_path/audience_path.png %}){: style="float:right;max-width:45%;margin-left:15px;margin-top:15px;"}

ユーザーは条件に一致する最初のBranchに進むため、最も重要なパスを最初に配置してください。これにより、ユーザーがどこに進み、どのメッセージを受け取るかについてのあいまいさが軽減されます。なお、この順序は[ローンチ後に編集できません]({{site.baseurl}}/post-launch_edits)。

オーディエンスパスを使用すると、以下のことが可能です:

- オーディエンス条件に基づいて、ユーザーを異なるキャンバスパスに振り分けます。
- 最も重要なオーディエンスグループを最初に配置します。ユーザーは条件に一致する最初のパスに進みます。
- 大規模にユーザーを正確にターゲティングします。
  - オーディエンスパスのステップごとに最大8つのオーディエンスグループ（デフォルトの2つと追加の6つ）を作成できますが、複数のオーディエンスパスのステップを接続して、ユーザーをさらに分類することもできます。

1つのオーディエンスパスのステップ内では、ユーザーはオーディエンスグループに対して順番に評価され、条件に一致する最初のパスに進みます。キャンバス内で複数のオーディエンスパスのステップを接続した場合、ユーザーは新しいオーディエンスパスのステップに到達するたびに再度評価されます。

### ユーザーの評価方法 {#how-users-are-evaluated}

![メッセージステップの後に24時間の遅延があり、その後にオーディエンスパスが続くキャンバス。]({% image_buster /assets/img/audience_path/audience_path5.png %}){: style="float:right;max-width:40%;margin-left:15px;"}

ユーザーは、キャンバスにエントリした時点ではなく、**オーディエンスパスのステップに到達した時点で**フィルターおよびセグメントのメンバーシップに対して評価されます。評価後、ユーザーは一致するパスに即座に進みます。ユーザーがオーディエンスグループに配置されると、その後にユーザープロファイルが変更されても、そのグループに留まります。

<div style="clear: both;"></div>

{% alert important %}
オーディエンスパスは、評価時のユーザーの現在の属性、フィルター、セグメントのメンバーシップに基づいて評価されます。キャンバスのエントリをトリガーした特定のイベントに基づいて評価されるわけではありません。ユーザーが実行したアクション（カスタムイベントなど）に基づいてルーティングするには、代わりに[アクションパス]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/action_paths)を使用してください。
{% endalert %}

ユーザーがパスを進んだ後は、オーディエンスグループに対して再評価されません。後続のメッセージが遅延ステップ、サイレント時間帯、インテリジェントタイミング、レート制限、またはローカルタイムゾーン配信によって遅延される場合、そのメッセージが送信される前にユーザーのプロファイルが変更される可能性があります。

メッセージステップが送信される前にユーザーがセグメントとフィルターの条件を満たしているかどうかを確認するには、メッセージステップの[配信バリデーション]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/message_step#delivery-validations)で**メッセージ送信時にオーディエンスを検証**を有効にしてください。配信バリデーションは、そのメッセージステップに追加したセグメントとフィルターのみをチェックするため、オーディエンスパスの条件は再利用されません。アプリ内メッセージの場合、配信バリデーションはメッセージが表示される時点ではなく、ユーザーがメッセージステップにエントリした時点でチェックされます。

### ユーザー評価のための時間の確保 {#allowing-time-for-user-evaluations}

評価は即座に行われるため、パスの条件が前のステップとのユーザーインタラクションに依存する場合は、オーディエンスパスの前に遅延を追加することが重要です。

たとえば、ユーザーにメッセージAが送信され、次のステップがそのメッセージとインタラクションしたかどうかを評価するオーディエンスパスの場合、すべてのユーザーはメッセージとインタラクションしていないユーザー向けのステップに進みます。これは、ユーザーがメッセージとインタラクションする時間なく、即座にオーディエンスパスのステップに進んだためです。つまり、ユーザーはメッセージ送信後ほぼ即座に、そのメッセージとのインタラクションについて評価されます。

送信済みメッセージとインタラクションする時間をユーザーに与えるには、メッセージステップとオーディエンスパスの間に遅延を追加してください。たとえば、24時間の遅延を設定すると、評価前にメッセージAとインタラクションするための24時間がユーザーに与えられます。

## オーディエンスパスの作成 {#creating-an-audience-path}

オーディエンスパスステップを追加するには、以下の手順を実行します。

1. キャンバスにステップを追加します。
2. サイドバーからコンポーネントをドラッグ＆ドロップするか、ステップの下部にある<i class="fas fa-plus-circle"></i> **追加**を選択し、**オーディエンスパス**を選択します。

デフォルトのオーディエンスパスコンポーネントには、**グループ1**と**その他全員**の2つのデフォルトオーディエンスグループが含まれています。**その他全員**グループには、定義されたオーディエンスグループに該当しないすべてのユーザーが含まれます。このグループは常に順序の最後に配置されます。

### オーディエンスグループの定義 {#defining-audience-groups}

以下のスクリーンショットは、展開されたオーディエンスパスステップのレイアウトを示しています。ここでは、最大8つのオーディエンスグループ（1つのプリセットと7つのカスタマイズ可能なグループ）を定義できます。オーディエンスグループを定義するには、オーディエンスパスエディターからグループ名を選択します。オーディエンスグループの名前を変更したり、グループに適用するフィルターやセグメントを選択したり、グループを追加または削除したりできます。たとえば、オンボーディングメッセージングをユーザーグループにターゲティングしたい場合、「メールをクリックした」や「アプリ内メッセージをクリックした」などのリターゲティングフィルターを選択できます。

![「アジア料理が好き」、「ラテン料理が好き」、「ヨーロッパ料理が好き」、「その他全員」のグループを持つ展開されたオーディエンスパス。]({% image_buster /assets/img/audience_path/audience_path3.png %})

オーディエンスパスステップが完了すると、各オーディエンスグループに個別のブランチが作成されます。オーディエンスパスを引き続き使用してオーディエンスをさらにフィルタリングするか、標準のキャンバスステップでキャンバスジャーニーを続行できます。

![エンゲージメントに基づく異なるグループを持つ2つのオーディエンスパス。]({% image_buster /assets/img/audience_path/audience_path4.png %}){: style="max-width:50%"}

#### コンテキスト変数での比較フィルターの使用 {#using-comparison-filters-with-context-variables}

日付を保持するコンテキスト変数で分割する場合は、[日付コンテキスト変数の年間日数および時間フィルター]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/sources/context_variables#day-of-year-and-time-filters-for-date-context-variables)を参照して、正しい比較タイプを選択してください。

### オーディエンスグループのテスト {#testing-audience-groups}

オーディエンスにセグメントとフィルターを追加した後、[ユーザーを検索]({{site.baseurl}}/user_guide/audience/segments/creating_a_segment)してオーディエンス基準に一致するかどうかを確認することで、オーディエンスグループが期待どおりに設定されているかをテストできます。

## オーディエンスパスの使用 {#using-audience-paths}

オーディエンスパスの真の力は、最も重視するパスを**先頭**に配置することにあります。この機能は戦略的に使用する必要はありませんが、スペシャル商品や限定リリースなど、特定の商品をユーザーにプッシュしたいと考えるマーケターもいるでしょう。

それらのセグメントをリストの先頭に配置することで、特定のフィルターやセグメントに該当するユーザーをターゲティングしながら、その特定の基準に当てはまらないユーザーもターゲティングできます。これらすべてを1つのキャンバスステップで実現できます。

![「Likes Big Brand Shoes」、「Likes Big Brand」、「Everyone Else」のグループを含むオーディエンスパス。]({% image_buster /assets/img/audience_path/audience_path2.png %}){: style="float:right;max-width:50%;margin-left:15px;margin-bottom:15px;"}

例えば、あるユーザーグループに新商品の広告を送信したいとします。オーディエンスパスで、それらの商品に該当するフィルターを**先頭**に配置することから始めます。「Big Brand」という企業向けのマーケティングキャンペーンを作成していて、新しい小売ブランドがリリースされたばかりの場合、「Likes Big Brand Shoes」や「Likes Big Brand Bags」のようなフィルターを選択し、どのフィルターグループに該当するかに基づいて異なるメールメッセージを送信できます。

ユーザーがこのオーディエンスパスコンポーネントに入ると、まずオーディエンスグループ1「Likes Big Brand Shoes」（リストの最初のパス）で評価されます。該当する場合、キャンバスで定義された次のコンポーネントに進みます。「Like Big Brand Shoes」に該当しない場合、次のオーディエンスグループであるオーディエンスグループ2「Likes Big Brand Bags」で評価され、基準を満たしている場合は次のステップに進みます。最後に、前のグループに該当しなかったユーザーは「Everybody Else」グループに分類され、そのパスに定義された次のキャンバスステップに進みます。

このステップのパフォーマンスは、[キャンバス分析]({{site.baseurl}}/user_guide/messaging/canvas/testing_canvases/measuring_and_testing_with_canvas_analytics#performance-visualization)を使用して確認することもできます。

### ランダムバケット番号によるオーディエンスパスのセグメンテーション {#segmenting-audience-paths-with-random-bucket-numbers}

キャンバスで[レート制限]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/frequency_capping)（キャンバスを受信するユーザーの総数を制限するなど）を使用している場合、Brazeではオーディエンスパスのセグメンテーションにランダムバケット番号を使用しないことを推奨しています。

[ランダムバケット番号]({{site.baseurl}}/user_guide/messaging/ab_testing/concepts/random_bucket_numbers)は、ランダムなユーザーの均等分布セグメントを作成するために使用できるユーザー属性です。Brazeはキャンバスエントリのセグメンテーションフェーズでランダムバケット番号を使用してユーザーをグループ化し、各グループは個別に処理されます。どのグループが先に処理を完了するかによって、レート制限によりエントリ時にキャップされるユーザーが発生する場合があり、オーディエンスパスステップに到達した際にユーザーの分布が不均等になる可能性があります。

このシナリオでは、代わりに[実験パス]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step)の使用を試してください。

### オーディエンスパスでのインテリジェントチャネルフィルターの使用 {#using-intelligent-channel-filter-with-audience-paths}

オーディエンスパスステップとインテリジェントチャネルフィルターを組み合わせることで、各ユーザーの好みや行動に合わせてメッセージング体験をカスタマイズできます。これにより、ユーザーは適切なチャネルを通じて最も関連性の高いメッセージを受け取ることができます。

例えば、オーディエンスパスステップで、メール、モバイルプッシュ、Everyone Elseの3つのオーディエンスを作成できます。メールオーディエンスには、フィルター`Intelligent Channel is Email`を追加します。モバイルプッシュオーディエンスには、フィルター`Intelligent Channel is Mobile Push`を追加します。その後、各オーディエンスパスにメッセージステップを追加して、パーソナライズされた関連性の高いメッセージを配信できます。

{% alert tip %}
これらのビルド済みテンプレートをカスタマイズする方法の例については、[Brazeキャンバステンプレート]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates)をご覧ください。
{% endalert %}
