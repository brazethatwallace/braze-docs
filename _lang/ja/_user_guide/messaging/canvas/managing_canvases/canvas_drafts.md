# キャンバスの下書きを保存

> キャンバスを作成して起動した後、アクティブなキャンバスを編集して下書きとして保存できます。これにより、次の起動前に変更内容を検証できます。

大規模な変更が必要なアクティブなキャンバスがある場合、この機能を使用して、アクティブなキャンバスで変更を起動する**前に**、変更内容の構築、保存、品質チェックを行うことができます。

他のキャンバスと同様に、一度に下書きを編集できるのは1人のユーザーのみで、キャンバスが持てる下書きも一度に1つだけです。下書きの変更はまだ起動されていないため、これらの下書きには分析データがありません。

## 下書きの作成

下書きを作成するには:

1. アクティブなキャンバスに移動します。
2. キャンバスのフッターにある**下書きとして保存**ボタンを選択します。

キャンバスの下書きが存在する間は、アクティブなキャンバスを編集できません。キャンバスを更新して変更を適用するか、下書きを破棄できます。

## アクティブな下書きの参照

アクティブなキャンバスを参照するには、分析ビューのフッターまたは下書きのキャンバスヘッダーから**アクティブなキャンバスを表示**を選択します。アクティブなキャンバスに戻るには、分析ビューまたはアクティブなキャンバスビューから**下書きを編集**を選択します。

参照できるのは、下書きが作成される前にすでに起動されたステップのみです。つまり、下書きが作成された**後に**ステップやチャネルを作成した場合、そのステップやチャネルは下書き内で参照できません。

{% alert note %}
コンテンツブロックがキャンバスの下書きで参照されている場合、そのキャンバスはコンテンツブロックの参照カウントに含まれます。ただし、コンテンツブロックが**アクティブな**キャンバスの下書きで参照されている場合、そのキャンバスはコンテンツブロックの参照カウントに含まれません。
{% endalert %}

### アプリ内メッセージの優先順位

アクティブなキャンバスの下書きでは、キャンバスビルダー内のアプリ内メッセージの優先順位は、ユーザーが優先順位を変更するとすぐに更新されます。つまり、キャンバスレベルのアプリ内メッセージの優先順位は、下書きが存在する場合でも、アクティブなキャンバスにすぐに適用されます。

ただし、ステップレベルのアプリ内メッセージの優先順位の変更は下書きとして保存され、キャンバスが更新されたときに適用されます。たとえば、メッセージステップでは、ステップ設定がステップレベルで適用されるため、ユーザーが下書きを起動したときに優先順位ソーターが更新されます。
