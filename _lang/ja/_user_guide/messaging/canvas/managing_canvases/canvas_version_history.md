# キャンバスのバージョン履歴 {#canvas-version-history}

> バージョン履歴を使用すると、Canvasの以前のバージョンのCanvas分析やユーザージャーニーを表示してアクセスできます。

Canvasのバージョン履歴を参照することは、Canvasの変遷の記録を維持するうえで特に役立ちます。たとえば、大規模な変更を行った場合、以前のCanvasバージョンを参照して、ワークフローがどのように進化してきたかをより深く理解できます。

{% alert tip %}
ワークスペース内のCanvasesの完全なリストを取得するには（たとえば監査のため）、[Canvas一覧エクスポートエンドポイント]({{site.baseurl}}/api/endpoints/export/canvas/get_canvases)を使用し、結果をページネーションしてください。
{% endalert %}

## バージョンの管理 {#managing-versions}

![バージョン管理に関するスクリーンショット。]({% image_buster /assets/img_archive/canvas_version_history.png %}){: style="float:right;max-width:35%;margin-left:15px;"}

新しいバージョンを作成するには、**キャンバスを更新**をクリックします。これにより、Canvasの以前の設定を上書きせずに変更を加えることができます。新しいCanvasバージョンが作成されると、すでにCanvasに入っているユーザーは新しいバージョンのワークフローに沿って進みます。Canvasに入るユーザーも新しいバージョンに入ります。

バージョン履歴にアクセスするには、Canvasの上部にあるCanvasの詳細に移動し、**# バージョン**を選択します。ここで、**バージョン履歴**サイドバーにアクセスできます。サイドバーでCanvasバージョンのいずれかを選択すると、Canvasの詳細を表示して比較できます。Canvas分析とCanvasの設定を切り替えるには、下部のツールバーで**分析を表示**または**キャンバスを表示**をクリックします。

{% alert note %}
**バージョン履歴**に表示されるCanvasesは閲覧専用です。
{% endalert %}

バージョンがアクティブだった間に行われた変更のリストを表示するには、バージョン履歴サイドバーで**変更を表示**を選択します。バージョンに関連するすべての変更は、Canvasの変更ログでも確認できます。

Canvasの起動から2番目のバージョンの作成までの間に編集を行わなかった場合、最初のバージョンの**変更を表示**には変更が表示されません。

バージョン履歴の数が増えるにつれて、サイドバーで各バージョンの名前を変更して整理することもできます。デフォルトでは、バージョン名は以前に作成されたバージョンの数に基づく番号として生成されます。アクティブでなくなったバージョンの名前を変更した場合、その変更はCanvasの変更ログに表示されますが、バージョン履歴ビュー内のそのバージョンの変更ログには表示されません。

![2つの新しいCanvasバージョンが作成されたことを示すCanvasの変更ログの例。]({% image_buster /assets/img_archive/canvas_version_history_changelog.png %}){: style="max-width:85%" }

### バージョンの破棄 {#discarding-versions}

Canvasごとに最大10個のバージョンを作成できます。この上限に達した場合、バージョンを破棄して新しいバージョンのためのスペースを確保できます。バージョンはCanvasを更新したときではなく、**破棄**をクリックしたときに破棄されます。バージョンの破棄は、特定のバージョンの変更ログではなく、Canvas全体の変更ログに反映されます。

バージョンを破棄すると、Canvasの設定はすぐに失われますが、破棄されたバージョンに関連する分析は保持されます。

## 分析の表示 {#viewing-analytics}

バージョン履歴では、Canvasレベルおよびステップレベルの分析を表示できます。Canvasバージョンビューでは、そのバージョンの期間だけでなく、全期間のデータが表示されます。ただし、ステップレベルでは、そのバージョンがアクティブだった間に存在していたステップの分析のみが表示されます。これらの分析は会社のタイムゾーンに対応するカレンダー日を使用して表示されるため、バージョンが作成された正確な時刻に固有のものではありません。
