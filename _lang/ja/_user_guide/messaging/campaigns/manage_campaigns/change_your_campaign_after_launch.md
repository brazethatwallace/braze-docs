# 起動後のキャンペーン編集 {#edit-your-campaign-after-launch}

> この記事では、起動後のキャンペーンの特定の側面を編集した場合の結果について概要を説明します。

## 編集前にキャンペーンを停止すべき理由 {#risks-of-editing-live}

{% alert important %}
Brazeでは、ライブ状態のまま編集するのではなく、変更を加える前にキャンペーンを停止することを推奨しています。ライブキャンペーンを停止せずに編集すると、ユーザーがメッセージを2回受信するなど、予期しない動作が発生する可能性があります。
{% endalert %}

キャンペーンが起動されると、対象となるすべてのユーザーがメッセージ受信のキューに入ります。ただし、ユーザーがキャンペーンを受信済みとしてマークされるのは、キューに入った時点ではなく、メッセージが実際に配信された時点です。ライブキャンペーンを停止せずに編集すると、元のキューがまだ処理されている間に、Brazeが対象ユーザーを更新版のキューに再登録します。元のメッセージをまだ受信していないユーザーは両方のキューに入ることになり、以下のような結果が生じる可能性があります。

- 再適格性がオフになっていても、ユーザーがキャンペーンを2回受信する（元のバージョンと更新バージョン）。
- 最初のキューにいるユーザーに元のバージョンのキャンペーンが引き続き配信される。
- キャンペーン分析でオーディエンス数が予期しない値になる。

これは、大規模なオーディエンスをターゲットとし、即時送信がスケジュールされているCampaignsで最も発生しやすくなります。一度に大量のユーザーキューが処理されるためです。アクションベースのCampaignsでは、トリガーが段階的に発生する（サインアップイベントなど）ため、任意の時点でキューに入るユーザー数が少なく、リスクは低くなります。

安全に変更を加えるには、まずキャンペーンを停止してから、停止したキャンペーンを編集するか、変更を加えた[複製](#making-immediate-changes)を作成してください。

## キャンペーンの停止 {#stopping-your-campaign}

キャンペーンを停止するには、**Campaign Details**ページを開き、**キャンペーンを停止**を選択します。キャンペーンが停止されると、以下のようになります。

- 送信がスケジュールされていたメッセージはキャンセルされます。
- 初回テストがすでに送信されているA/Bテストは永久にキャンセルされます。
- すでに送信されたメッセージのイベント（開封やクリック数など）は引き続き追跡されます。

キャンペーンを再開するには、**Resume**を選択します。キャンペーンはメッセージの送信とA/Bテストを続行しますが、送信されなかったメッセージは再送信や再スケジュールされません。

### 送信中のキャンペーンの停止 {#stopping-your-campaign-during-sending}

大規模なオーディエンスとレート制限を持つCampaignsの場合、Brazeはメッセージのバッチを分割し、異なる時間に送信するようスケジュールします。キャンペーンが停止されても、送信はすぐにはキャンセルされません。代わりに、バッチの実行が開始され、キャンペーンが停止されたことが検出された時点でキャンセルされます。

例えば、レート制限付きのメールキャンペーンを開始し、数時間一時停止してから再開した場合、一時停止中に送信がスケジュールされていたすべてのメッセージはキャンセルされ、送信されません。キャンペーンの再開後にスケジュールされた残りのメッセージは引き続き送信されます。キャンペーンで再適格性が有効になっている場合、ユーザーはキャンペーンの停止前にすでにキューに入っていたメッセージに加えて、再度キャンペーンを受信する資格を得ることができます。

## トリガーキャンペーン {#triggered-campaigns}

アクションベースの配信キャンペーンおよびAPIトリガー配信キャンペーンへのすべての変更は、以降の送信に対して即座に反映されます。

これらのキャンペーンがトリガーされたがまだ送信されていない場合（例えば、1日の遅延が設定されたアクションベースの配信キャンペーンが、その1日の遅延期間中に編集された場合）は、スケジュールされたキャンペーンに関する以下のガイダンスを参照してください。

### スケジュールされたキャンペーン {#scheduled-campaigns}

起動後のキャンペーンに変更を加える必要がある場合は、変更が意図した効果を持つことを確認するために、キャンペーンを編集する際に以下の項目に注意してください。

### メッセージコンテンツ {#message-content}

メッセージコンテンツの変更（タイトル、本文、画像を含む）は、保存後すぐに以降のすべてのメッセージ送信に反映されます。すでに送信されたメッセージのコンテンツを変更することはできません。

### スケジュールとオーディエンス {#scheduling-and-audience}

キャンペーンのスケジュールされた送信時間やオーディエンスを編集すると、それらの変更は実際のキャンペーンに即座に反映されます。

#### 考慮事項 {#considerations}

キャンペーンがインテリジェントタイミングまたはローカルタイムゾーン配信を使用している場合、元の送信時間から24時間以内に編集が行われると、スケジュールされた送信時間の編集は反映されません。これは以下の理由によります。

- **インテリジェントタイミング:** Brazeはサモア時間の午前0時に最適な送信時間の計算を開始します。この時間がすでに過ぎている場合、メッセージの処理が開始されています。詳細については、[インテリジェントタイミング]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_timing)を参照してください。
- **ローカルタイムゾーン配信:** 24時間以内にスケジュールされたローカルタイムゾーンキャンペーンを編集しても、メッセージのスケジュールは変更されません。詳細については、[ローカルタイムゾーンキャンペーンのスケジュール方法]({{site.baseurl}}/user_guide/messaging/campaigns/faq#how-do-i-schedule-a-local-time-zone-campaign)を参照してください。

### 送信レート {#send-rate}

レート制限を使用している場合、Brazeは分単位のタイムスロットでメッセージを「スケジュール」します。そのため、メッセージの送信レートを変更したい場合は、即座に変更を反映するために以下のプロセスに従ってください。

#### 配信速度レート制限を使用したキャンペーンの一時停止 {#pausing-campaigns-with-delivery-speed-rate-limiting}

[配信速度レート制限]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/frequency_capping#delivery-speed-rate-limiting)を使用しているキャンペーンを一時停止すると、Brazeは分単位のスロットに送信を分散します。**Resume**を選択しても、キャンペーンが一時停止されている間にキャンセルされたスロットのメッセージは再送信されず、キャンペーンの再開時にすべてのメッセージが送信されるとは限りません。

キャンペーンの一時停止によりメッセージを受信しなかったユーザーがいる場合は、**Resume**で未送信メッセージを配信しようとするのではなく、キャンペーンを複製してそれらのユーザーのみをターゲットにしてください。

## 即座に変更を反映する {#making-immediate-changes}

変更を即座に反映する必要がある場合は、以下の手順を実行してください。

1. 対象のキャンペーンを停止します。
2. キャンペーンを複製します。
3. 複製したキャンペーンで編集を行います。

{% alert important %}
この操作により、元のキャンペーンをすでに受信したユーザーの適格性がリセットされます。そのため、元のキャンペーンを受信していないユーザーで複製キャンペーンをフィルタリングする必要がある場合があります。
{% endalert %}

## アクティブなキャンペーンの下書きを保存する {#campaign-drafts}

下書きは、アクティブなキャンペーンに大規模な変更を加える場合に便利です。下書きを作成することで、次回の起動前に計画した変更を試すことができます。

{% alert note %}
キャンペーンには一度に1つの下書きしか作成できません。また、下書きの変更はまだ起動されていないため、分析は利用できません。
{% endalert %}

下書きを作成するには、以下の手順を実行してください。

1. アクティブなキャンペーンに移動します。
2. 変更を加えます。
3. **下書きとして保存**を選択します。下書きを作成した後は、下書きを起動するか破棄するまで、アクティブなキャンペーンを編集できないことに注意してください。

![アクティブなキャンペーンを表示するオプションが付いた、アクティブなキャンペーンの下書き。]({% image_buster /assets/img/campaign_draft.png %})

下書きを編集している間、キャンペーンの下書きのヘッダーまたはキャンペーン分析のフッターからアクティブなキャンペーンを参照することもできます。

アクティブなキャンペーンに戻るには、分析ビューまたはアクティブなキャンペーンビューから**下書きを編集**を選択します。

### アプリ内メッセージの優先順位付け {#in-app-message-prioritization}

アプリ内メッセージの優先順位は、**正確な優先度を設定**を選択し、他のCampaignsやCanvasesとの関係で優先順位を指定すると、（下書きの起動前に）即座に更新されます。
