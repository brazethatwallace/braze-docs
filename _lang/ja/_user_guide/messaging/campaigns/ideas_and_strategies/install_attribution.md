# ユーザーインストールの理解

> インストールアトリビューショントラッキングは、ユーザーとの初期関係を改善するための優れた方法です。ユーザーがどのように、どこで、そしてさらに重要なことに、なぜアプリをインストールしたかを知ることで、ユーザーがどのような人物であるか、またアプリをどのように紹介すべきかをより深く理解できます。

Braze はインストールアトリビューショントラッキングを提供していませんが、Branch や AppsFlyer などの[サービス]({{site.baseurl}}/partners/message_orchestration/)と連携して、インストールデータをシームレスに提供できます。

## ユーザーのセグメント化

ユーザーがアプリをインストールしたら、以下の[インストールアトリビューションフィルター]({{site.baseurl}}/user_guide/audience/segments/segmentation_filters#install-attribution)に基づいてセグメント化を開始できます。たとえば、旅行アプリでは、ビーチバケーションのお得な情報に関する広告から来たユーザーを「ビーチ好き」セグメントに追加できます。同様に、音楽アプリでは、インストールにつながった広告に表示されていた音楽のジャンルに基づいてユーザーをセグメント化できます。

## ベストプラクティス

### パーソナライズされたオンボーディング

ユーザーに関する情報が増えたことで、オンボーディングプロセスをパーソナライズできます。メッセージ内の画像をユーザーの好みに合わせて変更するといったシンプルなものから、インストールにつながる可能性のある各広告に対してユニークなユーザーオンボーディングを作成するといった複雑なものまで対応できます。ユーザーの動作を考慮した包括的なメッセージシーケンスをスケールアウトするには、[キャンバス]({{site.baseurl}}/developer_guide/rest_api/messaging/#canvas)に関するドキュメントを参照してください。

### 広告からのデータの参照

ユーザーは、プロモーションオファーやプレゼントに惹かれてアプリをインストールする場合があります。インストールアトリビューションデータを使用すると、これらのプロモーションによってインストールしたユーザーのみに、割引コードやオファーを含むキャンペーンを送信できます。同様に、広告に特定の製品に関する情報（動画アプリの特定の映画や e コマースアプリのセールなど）が含まれている場合、ユーザーをアプリの適切なページに誘導するキャンペーンを送信できます。

## 広告効果の評価

インストールアトリビューションデータは、さまざまなマーケティングキャンペーンの効果を評価する上で貴重です。どの広告やキャンペーンが最も多くのインストールにつながっているか、またどれが遅れをとっているかを確認することで、最も効果的な広告にリソースを集中させることができます。
