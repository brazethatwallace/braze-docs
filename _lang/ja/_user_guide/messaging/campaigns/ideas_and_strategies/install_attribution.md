# ユーザーインストールの理解 {#understanding-user-installs}

> インストールアトリビューショントラッキングは、ユーザーとの初期関係を改善するための優れた方法です。ユーザーがどのように、どこで、そしてさらに重要なことに、なぜアプリをインストールしたかを知ることで、ユーザーがどのような人物であるか、またアプリをどのように紹介すべきかをより深く理解できます。

Brazeはインストールアトリビューショントラッキングを提供していませんが、BranchやAppsFlyerなどの[サービス]({{site.baseurl}}/partners/message_orchestration)と連携して、インストールデータをシームレスに提供できます。

## ユーザーをセグメントする {#segment-your-users}

ユーザーがアプリをインストールすると、以下の[インストールアトリビューションフィルター]({{site.baseurl}}/user_guide/audience/segments/segmentation_filters#install-attribution)に基づいてセグメンテーションを開始できます。例えば、旅行アプリでは、ビーチバケーションのお得情報に関する広告から流入したユーザーを「Beach Lovers」セグメントに追加できます。同様に、音楽アプリでは、インストールにつながった広告に表示されていた音楽のジャンルに基づいてユーザーをセグメントできます。

## ベストプラクティス {#best-practices}

### パーソナライズされたオンボーディング {#personalized-onboarding}

ユーザーに関する情報が増えたので、オンボーディングプロセスをパーソナライズできます。メッセージ内の画像をユーザーの好みに合わせて変更するといったシンプルな方法から、インストールにつながる可能性のある各広告に対して独自のユーザーオンボーディングを作成するといった複雑な方法まで、さまざまなアプローチがあります。ユーザーの行動を考慮した包括的なメッセージシーケンスをスケールアウトするには、[キャンバス]({{site.baseurl}}/api/endpoints/messaging/send_messages/post_send_triggered_canvases)に関するドキュメントを参照してください。

### 広告からのデータの参照 {#reference-data-from-the-ad}

ユーザーは、プロモーションオファーやプレゼントに惹かれてアプリをインストールすることがあります。インストールアトリビューションデータを使用すると、これらのプロモーションによってインストールしたユーザーのみに、割引コードやオファーを含むキャンペーンを送信できます。同様に、広告に特定の商品に関する情報（動画アプリの特定の映画やeコマースアプリのセール情報など）が含まれている場合、ユーザーをアプリの適切なページに誘導するキャンペーンを送信できます。

## 広告効果の評価 {#evaluate-advertising-efforts}

インストールアトリビューションデータは、さまざまなマーケティングキャンペーンの効果を評価する際に役立ちます。どの広告やキャンペーンが最も多くのインストールにつながっているか、またどれが伸び悩んでいるかを確認することで、最も効果的な広告にリソースを集中させることができます。
