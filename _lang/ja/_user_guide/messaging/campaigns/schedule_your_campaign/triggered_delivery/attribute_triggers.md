# 属性トリガー

> 属性トリガーを使用すると、ユーザーのサブスクリプション状態やカスタム属性の値が変更されたときに、アクションベースのメッセージを送信できます。

属性トリガーは、以下のシナリオで利用できます。

- サブスクリプション状態の更新。
- ブール値、整数、文字列、または日付のカスタム属性値が任意の値に変更された場合。
- ブール値、整数、または文字列のカスタム属性値が特定の値に変更された場合。

属性トリガーの使用を開始するには、キャンペーンまたはキャンバスコンポーネントを作成し、配信方法として**アクションベースの配信**を選択します。次に、使用したい属性トリガーを選択します。

![トリガーを選択するドロップダウンが表示された「アクションベースの配信」セクション。]({% image_buster /assets/img_archive/trigger_attribute.png %})

### サブスクリプションステータスの更新

`Update Subscription Status` トリガーを使用して、サブスクリプションステータスが更新されたユーザーをターゲットにします。

たとえば、メールまたはプッシュのサブスクリプションステータスがオプトインに変更されたユーザーをターゲットにして、オプトインへの感謝を伝えることができます。また、ユーザーがメールの配信停止を行った際に Webhook をシステムに送信し、内部システムが最新のサブスクリプションステータス情報を保持できるようにすることも可能です。

{% alert important %}
このトリガーは、新しいユーザーがデフォルトのメールグローバル状態 `subscribed` で作成され、その後に状態を `subscribed` に更新するリクエストが行われた場合には適用されません。サブスクリプションステータスが変更されていないためです。
{% endalert %}

### サブスクリプショングループステータスの更新

`Update Subscription Group Status` トリガーを使用して、メール、SMS、または WhatsApp のサブスクリプショングループステータスが更新されたユーザーをターゲットにします。

たとえば、プログラムにオプトインしたユーザーにウェルカム SMS メッセージを送信できます。また、更新のソースを指定して、メッセージが送信されるタイミングをより細かく制御することもできます。

利用可能な更新ソースはチャネルによって異なります。
- キャンバスのユーザーの更新ステップ
- CSV インポート
- List-Unsubscribe
- ユーザー設定センター
- REST API
- SDK
- Shopify（メール、SMS）
- 受信メッセージ（SMS）

たとえば、受信メッセージからではなく REST API からの更新時にのみウェルカム SMS を送信したい場合があります。Braze は特定の受信 SMS に対して自動的に応答するためです。

### カスタム属性値の変更

属性変更の場合、トリガーが最初に評価され、次にオーディエンス条件が評価されます。これは、オーディエンス条件が最初に評価されてからトリガーが評価されるデフォルトの動作とは異なります。競合を避けるため、トリガーとして使用する属性がオーディエンスの条件に使用する属性と同じにならないようにしてください。

#### 任意の新しい値オプション

`Change Custom Attribute Value` トリガーと `any new value` オプションを使用して、ブール値、整数、文字列、または日付の値が任意の新しい値に変更されたときにユーザーをターゲットにします。

たとえば、報酬ポイント数が変更されたときにユーザーをターゲットにして、現在のポイント数を知らせることができます。この例では、ユーザーが85の報酬ポイントを持っており、報酬ポイント属性が任意の新しい値に変更されたときにトリガーするキャンペーンを設定したとします。このユーザーの報酬ポイント属性値が任意の新しい値（83、84、86など）に変更されると、キャンペーンがトリガーされます。

次のユースケースとして、ティア更新通知を考えてみましょう。報酬ティアが変更された場合にユーザーに通知したい場合があります。このユースケースを実現するには、`Change Custom Attribute Value` でトリガーするキャンペーンを設定し、カスタム属性の報酬ティアが任意の新しい値に変更されたときにトリガーするように設定します。

{% alert important %}
属性トリガーは現在、配列属性には対応していません。
{% endalert %}

![「AA_current_rewards_tier」が任意の値に変更されたときの「Change Custom Attribute Value」トリガー。]({% image_buster /assets/img_archive/any_value.png %})

また、Liquid を使用してメッセージ本文に顧客の新しい報酬ティアをパーソナライズし、変更に関する詳細情報を提供することもできます。

{% raw %}
```liquid
Your rewards tier was just changed to {{custom_attribute.${AA_current_rewards_tier}}}
```
{% endraw %}

#### 特定の値

`Change Custom Attribute Value` トリガーと `specific value` オプションを使用して、ブール値、整数、または文字列のカスタム属性が特定の値に変更されたときにユーザーをターゲットにします。

たとえば、報酬ティアが最上位ティアに変更されたときにユーザーをターゲットにします。この例では、最上位の報酬ティアが Super VIP だとします。ユーザーの報酬ティアカスタム属性が `Super VIP` に変更されたときにトリガーするキャンペーンを設定し、Super VIP になったことを祝福できます。

![「AA_current_rewards_tier」が特定の値「super vip」に変更されたときの「Change Custom Attribute Value」トリガー。]({% image_buster /assets/img_archive/super_vip.png %})

{% alert important %}
- 特定のカスタム属性値に対する属性トリガーは、配列および日付のカスタム属性には対応していません。
- カスタム属性値変更トリガーは、カスタム属性値が null に更新された場合にはトリガーされません。
- カスタム属性値変更トリガーは、カスタム属性の値が変更された場合にのみトリガーされます。カスタム属性の現在の値が Braze に再送信された場合（例：お気に入りの色属性の値が赤で、再度赤の値を Braze に送信した場合）、カスタム属性値変更トリガーは発生しません。
- カスタム属性値変更トリガーは、新しく作成されたユーザーにも適用されます。
{% endalert %}
