# 属性トリガー {#attribute-triggers}

> 属性トリガーを使用すると、ユーザーのサブスクリプション状態やカスタム属性の値が変更されたときに、アクションベースのメッセージを送信できます。

属性トリガーは、以下のシナリオで利用できます。

- サブスクリプション状態の更新。
- ブール値、数値、文字列、または日時型のカスタム属性値が任意の値に変更された場合。
- ブール値、数値、または文字列のカスタム属性値が特定の値に変更された場合。

{% alert important %}
ダッシュボードでは、整数の属性は**数値**型を使用し、日付やタイムスタンプは**日時**型を使用します（UIでは「integer」や「date」とは表示されません）。**日時**型の属性は、**任意の新しい値**オプションを使用した**カスタム属性値の変更**のみをサポートしており、**特定の値**オプションはサポートしていません。
{% endalert %}

属性トリガーの使用を開始するには、CampaignまたはCanvasコンポーネントを作成し、配信方法として**アクションベースの配信**を選択します。次に、使用したい属性トリガーを選択します。

![トリガーを選択するドロップダウンが表示された「アクションベースの配信」セクション。]({% image_buster /assets/img_archive/trigger_attribute.png %})

## サブスクリプションステータスの更新 {#update-subscription-status}

`Update Subscription Status` トリガーを使用して、サブスクリプションステータスが更新されたユーザーをターゲットにします。

たとえば、メールまたはプッシュのサブスクリプションステータスがオプトインに変更されたユーザーをターゲットにして、オプトインへの感謝を伝えることができます。また、ユーザーがメールの配信停止を行った際にWebhookをシステムに送信し、内部システムが最新のサブスクリプションステータス情報を保持できるようにすることも可能です。

{% alert important %}
このトリガーは、新しいユーザーがデフォルトのメールグローバル状態 `subscribed` で作成され、その後に状態を `subscribed` に更新するリクエストが行われた場合には適用されません。サブスクリプションステータスが変更されていないためです。
{% endalert %}

## サブスクリプショングループステータスの更新 {#update-subscription-group-status}

`Update Subscription Group Status` トリガーを使用して、メール、SMS、またはWhatsAppのサブスクリプショングループステータスが更新されたユーザーをターゲットにします。

たとえば、プログラムにオプトインしたユーザーにウェルカムSMSメッセージを送信できます。また、更新のソースを指定して、メッセージが送信されるタイミングをより細かく制御することもできます。

利用可能な更新ソースはチャネルによって異なります。
- Canvasのユーザーの更新ステップ
- CSVインポート
- List-Unsubscribe
- ユーザー設定センター
- REST API
- SDK
- Shopify（メール、SMS）
- 受信メッセージ（SMS）

たとえば、受信メッセージからではなくREST APIからの更新時にのみウェルカムSMSを送信したい場合があります。Brazeは特定の受信SMSに対して自動的に応答するためです。

## カスタム属性値の変更 {#change-custom-attribute-value}

属性変更の場合、トリガーが最初に評価され、次にオーディエンス条件が評価されます。これは、オーディエンス条件が最初に評価されてからトリガーが評価されるデフォルトの動作とは異なります。競合を避けるため、トリガーとして使用する属性がオーディエンスの条件に使用する属性と同じにならないようにしてください。

### 任意の新しい値オプション {#any-new-value-option}

`Change Custom Attribute Value` トリガーと `any new value` オプションを使用して、ブール値、数値、文字列、または日時型の値が任意の新しい値に変更されたときにユーザーをターゲットにします。

たとえば、報酬ポイント数が変更されたときにユーザーをターゲットにして、現在のポイント数を知らせることができます。この例では、ユーザーが85の報酬ポイントを持っており、報酬ポイント属性が任意の新しい値に変更されたときにトリガーするCampaignを設定したとします。このユーザーの報酬ポイント属性値が任意の新しい値（83、84、86など）に変更されると、Campaignがトリガーされます。

次のユースケースとして、ティア更新通知を考えてみましょう。報酬ティアが変更された場合にユーザーに通知したい場合があります。このユースケースを実現するには、`Change Custom Attribute Value` でトリガーするCampaignを設定し、カスタム属性の報酬ティアが任意の新しい値に変更されたときにトリガーするように設定します。

{% alert important %}
属性トリガーは現在、配列属性には対応していません。
{% endalert %}

![「AA_current_rewards_tier」が任意の値に変更されたときの「Change Custom Attribute Value」トリガー。]({% image_buster /assets/img_archive/any_value.png %})

また、Liquidを使用してメッセージ本文に顧客の新しい報酬ティアをパーソナライズし、変更に関する詳細情報を提供することもできます。

{% raw %}
```liquid
Your rewards tier was just changed to {{custom_attribute.${AA_current_rewards_tier}}}
```
{% endraw %}

### 特定の値 {#specific-value}

`Change Custom Attribute Value` トリガーと `specific value` オプションを使用して、ブール値、数値、または文字列のカスタム属性が特定の値に変更されたときにユーザーをターゲットにします。

たとえば、報酬ティアが最上位ティアに変更されたときにユーザーをターゲットにします。この例では、最上位の報酬ティアがSuper VIPだとします。ユーザーの報酬ティアカスタム属性が `Super VIP` に変更されたときにトリガーするCampaignを設定し、Super VIPになったことを祝福できます。

![「AA_current_rewards_tier」が特定の値「super vip」に変更されたときの「Change Custom Attribute Value」トリガー。]({% image_buster /assets/img_archive/super_vip.png %})

{% alert important %}
- 特定のカスタム属性値に対する属性トリガーは、配列および日時型のカスタム属性には対応していません。
- カスタム属性値変更トリガーは、カスタム属性値がnullに更新された場合にはトリガーされません。
- カスタム属性値変更トリガーは、カスタム属性の値が変更された場合にのみトリガーされます。カスタム属性の現在の値がBrazeに再送信された場合（例：お気に入りの色属性の値が赤で、再度赤の値をBrazeに送信した場合）、カスタム属性値変更トリガーは発生しません。
- カスタム属性値変更トリガーは、新しく作成されたユーザーにも適用されます。
{% endalert %}
