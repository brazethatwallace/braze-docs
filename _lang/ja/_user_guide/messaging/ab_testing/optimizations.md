# ABテストの最適化 {#optimize-ab-tests}

> 多変量テストやABテストを作成する際に、バリアント最適化を使用する方法について説明します。

## プッシュ {#push}

プッシュの[ABテストを作成する]({{site.baseurl}}/user_guide/messaging/ab_testing/create_tests)場合、最適化オプションとして[BrazeAI<sup>TM</sup> バリアントセレクション]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/variant_selection)を使用できます。この機能を使用すると、単発送信または繰り返しのABテストで自動的に実験を実行し、最適なエンゲージメント結果に向けて最適化できます。

## メール、Webhook、SMS、WhatsApp {#email-webhook-sms-and-whatsapp}

メール、Webhook、SMS、WhatsApp キャンペーンで1回送信するようにスケジュールされた[ABテストを作成する]({{site.baseurl}}/user_guide/messaging/ab_testing/create_tests)場合、2つの最適化オプションから選択できます。**勝者バリアント**と**パーソナライズ済みバリアント**です。

![ターゲットオーディエンスを選択する際のABテストセクションに表示される最適化オプション。次の3つのオプションが表示されます：最適化なし、勝者バリアント、およびパーソナライズ済みバリアント。パーソナライズ済みバリアントが選択されています。]({% image_buster /assets/img_archive/ab_personalized_variant.png %})

どちらのオプションも、ターゲットセグメントの一定の割合に初期テストを送信することで機能します。テスト終了後、オーディエンスの残りのユーザーには、最もパフォーマンスの高いバリアント（勝者バリアント）またはエンゲージする可能性が最も高いバリアント（パーソナライズ済みバリアント）のいずれかが送信されます。

{% alert tip %}
最適化は、キャンペーン作成の**ターゲットオーディエンス**ステップの**ABテスト**にあります。
{% endalert %}

## 勝者バリアント {#winning-variant}

勝者バリアントの送信は、標準的なABテストと似ています。このグループのユーザーは、初期テストが完了すると勝者バリアントを受け取ります。

1. **勝者バリアント**を選択し、キャンペーンオーディエンスの何パーセントを勝者バリアントグループに割り当てるかを指定します。
2. 以下の追加設定を行います。

| フィールド | 説明 |
| --- | --- |
| 勝者バリアントを判別 | 最適化する指標です。メールの場合は*ユニーク開封数*または*クリック数*、プッシュの場合は*開封数*、すべてのチャネルの場合は*1次コンバージョン率*のいずれかを選択します。*開封数*または*クリック数*を選択して勝者を決定しても、キャンペーンの[コンバージョンイベント]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/conversion_events)の選択には影響しません。<br><br>コントロールグループを使用している場合、コントロールグループのユーザーは*開封*や*クリック*を実行できないため、コントロールグループのパフォーマンスは `0` であることが保証されます。その結果、コントロールグループはABテストに勝つことができません。ただし、コントロールグループを使用して、メッセージを受信しないユーザーの他の指標を追跡することもできます。 |
| 勝者バリアントの送信時間 | 勝者バリアントが送信される日時です。 |
| 勝者バリアントを決定できない場合 | 統計的に有意な差でどのバリアントも勝てない場合の動作です。最もパフォーマンスの高いバリアントをそのまま送信するか、テストを終了してそれ以上のメッセージを送信しないかを選択します。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="勝者バリアント" }

{% alert note %}
勝者バリアントとパーソナライズ済みバリアントの場合、Brazeは2回目の送信時に適格性チェックを再度実行します。最初の送信時にターゲットセグメントに含まれていなかった（またはリーチできなかった）ユーザーは後から参加できます。セグメントを離脱したユーザーはフォローアップを受け取れなくなる場合があります。意図したオーディエンスが両方の送信時に適格であるように、セグメントとスケジュールを計画してください。
{% endalert %}

## パーソナライズ済みバリアント {#personalized-variant}

パーソナライズ済みバリアントを使用すると、ターゲットセグメントの各ユーザーに、最もエンゲージする可能性の高いバリアントを送信できます。

各ユーザーに最適なバリアントを決定するために、Brazeはまずターゲットオーディエンスの一部に初期テストを送信し、ユーザー特性とメッセージの好みの間の関連性を調べます。初期テストで各バリアントに対するユーザーの反応に基づいて、これらの特性を使用して残りのユーザーがどのバリアントを受け取るかを決定します。関連性が見つからずパーソナライゼーションができない場合は、勝者バリアントが自動的に残りのユーザーに送信されます。パーソナライズ済みバリアントの決定方法の詳細については、[多変量テストとABテストの分析]({{site.baseurl}}/user_guide/messaging/ab_testing/analytics#personalized-variant)を参照してください。

1. **パーソナライズ済みバリアント**を選択し、キャンペーンオーディエンスの何パーセントをパーソナライズ済みバリアントグループに割り当てるかを指定します。
2. 以下の追加設定を行います。

| フィールド | 説明 |
| --- | --- |
| パーソナライズ済みバリアントを判別 | 最適化する指標です。メールの場合は*ユニーク開封数*または*クリック数*、プッシュの場合は*開封数*、すべてのチャネルの場合は*1次コンバージョン率*のいずれかを選択します。*開封数*または*クリック数*を選択して勝者を決定しても、キャンペーンの[コンバージョンイベント]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/conversion_events)の選択には影響しません。<br><br>コントロールグループを使用している場合、コントロールグループのユーザーは*開封*や*クリック*を実行できないため、コントロールグループのパフォーマンスは `0` であることが保証されます。その結果、コントロールグループはABテストに勝つことができません。ただし、コントロールグループを使用して、メッセージを受信しないユーザーの他の指標を追跡することもできます。 |
| パーソナライズ済みバリアントの送信時間 | パーソナライズ済みバリアントが送信される日時です。 |
| パーソナライズ済みバリアントを決定できない場合 | パーソナライズ済みバリアントが見つからない場合の動作です。代わりに勝者バリアントを送信するか、テストを終了してそれ以上のメッセージを送信しないかを選択します。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="パーソナライズ済みバリアント" }
