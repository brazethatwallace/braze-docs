# 勝者バリアントまたはパーソナライズバリアントで AB テストを最適化する

> 多変量テストや AB テストを作成する際に、勝者バリアントやパーソナライズバリアントを使用する方法を説明します。

1回限りの送信がスケジュールされたメール、プッシュ、Webhook、SMS、WhatsApp キャンペーンの [AB テストを作成する]({{site.baseurl}}/user_guide/messaging/ab_testing/create_tests/)際に、最適化を選択できます。最適化オプションは2つあります: **勝者バリアント**と**パーソナライズバリアント**です。

![ターゲットオーディエンスを選択する際の AB テストセクションに表示される最適化オプション。3つのオプションが表示されています: 最適化なし、勝者バリアント、パーソナライズバリアント。パーソナライズバリアントが選択されています。]({% image_buster /assets/img_archive/ab_personalized_variant.png %})

どちらのオプションも、まずターゲットセグメントの一定割合に初期テストを送信します。テスト終了後、オーディエンスの残りのユーザーには、最もパフォーマンスの高いバリアント（勝者バリアント）またはそのユーザーが最もエンゲージする可能性の高いバリアント（パーソナライズバリアント）が送信されます。

{% alert tip %}
最適化は、キャンペーン作成の**ターゲットオーディエンス**ステップの **AB テスト**の下にあります。
{% endalert %}

## 勝者バリアント

勝者バリアントの送信は、標準的な AB テストと同様です。このグループのユーザーは、初期テストが完了すると勝者バリアントを受け取ります。

1. **勝者バリアント**を選択し、キャンペーンオーディエンスの何パーセントを勝者バリアントグループに割り当てるかを指定します。
2. 以下の追加設定を構成します。

| フィールド | 説明 |
| --- | --- | 
| 勝者バリアントの決定 | 最適化する指標です。メールの場合は*ユニーク開封数*または*クリック数*、プッシュの場合は*開封数*、すべてのチャネルの場合は*1次コンバージョン率*から選択します。勝者を決定するために*開封数*または*クリック数*を選択しても、キャンペーンの[コンバージョンイベント]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/conversion_events/)の選択には影響しません。<br><br>コントロールグループを使用している場合、コントロールグループのユーザーは*開封*や*クリック*を実行できないため、コントロールグループのパフォーマンスは `0` になることに注意してください。その結果、コントロールグループが AB テストに勝つことはありません。ただし、メッセージを受信しないユーザーの他の指標を追跡するために、コントロールグループを使用することは可能です。 |
| 勝者バリアントの送信時間 | 勝者バリアントが送信される日時です。 |
| 勝者バリアントを決定できない場合 | 統計的に有意な差でどのバリアントも勝てない場合の動作です。最もパフォーマンスの高いバリアントをそのまま送信するか、テストを終了してそれ以上のメッセージを送信しないかを選択します。 |
{: .reset-td-br-1 .reset-td-br-2 role="presentation" }

## パーソナライズバリアント

パーソナライズバリアントを使用すると、ターゲットセグメントの各ユーザーに、最もエンゲージする可能性の高いバリアントを送信できます。

各ユーザーに最適なバリアントを決定するために、Braze はまずターゲットオーディエンスの一部に初期テストを送信し、ユーザー特性とメッセージの好みの間の関連性を調べます。初期テストで各バリアントに対するユーザーの反応に基づいて、これらの特性を使用して残りのユーザーがどのバリアントを受け取るかを決定します。関連性が見つからずパーソナライゼーションができない場合は、勝者バリアントが自動的に残りのユーザーに送信されます。パーソナライズバリアントの決定方法の詳細については、[多変量テストと AB テストの分析]({{site.baseurl}}/user_guide/messaging/ab_testing/analytics#personalized-variant)を参照してください。

1. **パーソナライズバリアント**を選択し、キャンペーンオーディエンスの何パーセントをパーソナライズバリアントグループに割り当てるかを指定します。
2. 以下の追加設定を構成します。

| フィールド | 説明 |
| --- | --- | 
| パーソナライズバリアントの決定 | 最適化する指標です。メールの場合は*ユニーク開封数*または*クリック数*、プッシュの場合は*開封数*、すべてのチャネルの場合は*1次コンバージョン率*から選択します。勝者を決定するために*開封数*または*クリック数*を選択しても、キャンペーンの[コンバージョンイベント]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/conversion_events/)の選択には影響しません。<br><br>コントロールグループを使用している場合、コントロールグループのユーザーは*開封*や*クリック*を実行できないため、コントロールグループのパフォーマンスは `0` になることに注意してください。その結果、コントロールグループが AB テストに勝つことはありません。ただし、メッセージを受信しないユーザーの他の指標を追跡するために、コントロールグループを使用することは可能です。 |
| パーソナライズバリアントの送信時間 | パーソナライズバリアントが送信される日時です。 |
| パーソナライズバリアントを決定できない場合 | パーソナライズバリアントが見つからない場合の動作です。代わりに勝者バリアントを送信するか、テストを終了してそれ以上のメッセージを送信しないかを選択します。 |
