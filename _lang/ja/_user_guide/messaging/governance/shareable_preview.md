# メッセージプレビューを関係者と共有する {#share-a-message-preview-with-stakeholders}

> 共有可能なプレビューを使用すると、メッセージやコンテンツのプレビューリンクを生成し、Brazeダッシュボードにアクセスできないレビュー担当者（関係者、法務チーム、コンプライアンスチームなど）と共有できます。受信者はBrazeにログインせずにブラウザでプレビューを表示できます。

## サポートされているチャネル {#supported-channels}

以下のチャネルおよびコンテンツタイプに対して、共有可能なプレビューリンクを生成できます。

- バナー
- Content Blocks
- Content Cards
- メールおよびメールフッター
- ランディングページ
- LINE
- プッシュ通知
- 購読ページ
- SMSおよびRCS
- WhatsApp

{% alert note %}
共有可能なプレビューは段階的にロールアウトされており、ワークスペースのすべてのチャネルでまだ利用できない場合があります。このセクションに記載されているチャネルのオプションが表示されない場合は、Brazeアカウントマネージャーにお問い合わせください。
{% endalert %}

## 共有可能なプレビューの仕組み {#how-shareable-preview-works}

以下の動作は、サポートされているすべてのチャネルで共通です。

### リンクの生成 {#generating-a-link}

メッセージやコンテンツを作成中に、**プレビューリンクをコピー**を選択して共有可能なリンクを生成します。Brazeは自動的にリンクをクリップボードにコピーします。

- リンクは、生成した時点でのメッセージの静的な読み取り専用スナップショットを開きます。編集を続けても自動的には更新されません。最新の変更を反映するには、新しいリンクを生成してください。
- メッセージにパーソナライゼーション（テストユーザー、カスタムユーザープロファイル、またはランダムユーザーに対して解決されるLiquidやConnected Contentなど）が含まれている場合、プレビューには**プレビューとテスト**で表示されるものと同じパーソナライゼーションが反映されます。
- **リンクを再生成**を選択すると、独自の新しい有効期限を持つ新しいスナップショットが作成されます。これにより以前のリンクが無効になることはありません。両方のリンクは、それぞれの有効期限が切れるまで独立して機能し続けます。

### リンクの表示 {#viewing-the-link}

リンクを持っている人は誰でもプレビューを表示できます。Brazeへのログインやダッシュボードの権限は必要ありません。

{% alert important %}
リンクは他の共有ドキュメントと同様に扱ってください。アクセスを許可する予定の人にのみ送信し、公開の場所に投稿しないようにしてください。
{% endalert %}

### リンクの有効期限 {#link-expiration}

- すべての共有可能なプレビューリンクは、生成から7日後に期限切れになります。
- リンクの有効期限が切れると、開けなくなります。コンポーザーから新しいリンクを生成してください。
- 有効期限が切れる前にリンクを手動で取り消したり無効にしたりする方法はありません。リンクを再生成しても以前のリンクは取り消されません。各リンクはそれぞれの7日間のスケジュールで期限切れになります。

## チャネルごとの注意点 {#per-channel-nuances}

基本的な体験はどこでも同じですが、いくつかのチャネルには知っておくべき小さな違いがあります。

{% alert note %}
共有可能なプレビューはアプリ内メッセージでは利用できません。
{% endalert %}

| チャネル | 違い |
|---|---|
| メール | プレビューには、メッセージ本文に加えて、メッセージの宛先、差出人、件名フィールドが含まれます。<br><br>カスタムユーザーとしてパーソナライズしている場合、APIトリガープロパティやイベントプロパティとして入力された値は、**プレビューとテスト**では正しく表示されていても、プレビューに表示されないことがあります。カスタム属性、テストユーザー、ランダムユーザーは影響を受けません。 |
| バナー（ドラッグ＆ドロップエディター） | プレビューは、最新の編集ではなく、コンポーザーで最後に**プレビュー**タブを開いた時点のコンテンツを反映します。<br><br>リンクを生成または再生成する前に、**プレビュー**を再度開いて最新の状態であることを確認してください。 |
| SMSおよびRCS | これらは同じ共有可能なプレビュー機能で管理されますが、それぞれ独立したリンクが生成されます。 |
| WhatsApp | 共有可能なプレビューは、WhatsAppテンプレートメッセージとWhatsApp応答メッセージの両方で個別に利用できます。 |
| Content Blocks、メールフッター、購読ページ | これらは、特定のキャンペーンやキャンバスとは独立した、スタンドアロンコンテンツのプレビューを生成します。 |
| ランディングページ | ランディングページのプレビュー動作は、他のチャネルとは異なります。詳細については、[ページをプレビューする]({{site.baseurl}}/user_guide/messaging/landing_pages/create_landing_pages#step-5-preview-the-page)を参照してください。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="チャネルごとの注意点" }

## よくある質問 {#frequently-asked-questions}

{% details 受信者がプレビューを表示するにはBrazeアカウントが必要ですか？ %}
いいえ。リンクを持っている人は誰でも、ログインせずにブラウザでプレビューを表示できます。
{% enddetails %}

{% details メッセージの編集を続けるとプレビューは更新されますか？ %}
いいえ。共有可能なプレビューリンクは、作成時点のスナップショットです。最新の変更を反映して新しいリンクを取得するには、**リンクを再生成**を選択してください。
{% enddetails %}

{% details リンクはどのくらいの期間有効ですか？ %}
生成から7日間です。リンクを再生成すると、新しいリンクには以前のリンクとは別の独自の7日間の有効期限が設定されます。
{% enddetails %}

{% details リンクを早期に取り消すことはできますか？ %}
いいえ、リンクを取り消すことはできません。リンクを再生成しても以前のリンクは無効になりません。すべてのリンクは7日後に期限切れになるまで機能します。
{% enddetails %}
