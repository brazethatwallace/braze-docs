# CampaignsとCanvasesの複製 {#duplicate-campaigns-and-canvases}

> 既存のCampaignsやCanvasesを複製して、成功した戦略を継続的にIterateし、発展させることができます。CampaignsやCanvasesを複製することで、配信の詳細やオーディエンスSegmentsの再設定にかかる時間を最小限に抑えることができます。

## 複製する {#duplicating}

CampaignまたはCanvasを複製すると、新しいメッセージには自動的に`"Copy of [Original Name]"`というタイトルが付けられ、その編集ページに移動します。これらの複製は、編集して起動するまで下書きのままになります。

{% alert tip %}
ワークスペース間で[Campaignをコピー]({{site.baseurl}}/user_guide/messaging/governance/copy_across_workspaces/)することもできます。コピーは編集して起動するまで下書きのままになります。
{% endalert %}

{% tabs %}
{% tab campaign %}
Campaignを複製するには:

1. **Messaging** > **Campaigns** に移動します。
2. Campaignにカーソルを合わせ、<i class="fas fa-gear"></i> **More actions** を選択します。
3. **Duplicate** を選択します。
{% endtab %}

{% tab canvas %}
Canvasを複製するには:

1. **Messaging** > **Canvas** に移動します。
2. Canvasの行にカーソルを合わせ、<i class="fas fa-ellipsis-vertical"></i> **More actions** を選択します。
3. **Duplicate** を選択します。

{% endtab %}
{% endtabs %}
