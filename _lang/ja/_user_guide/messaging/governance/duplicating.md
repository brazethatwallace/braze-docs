# キャンペーンとキャンバスの複製 {#duplicate-campaigns-and-canvases}

> 既存のキャンペーンやキャンバスを複製して、成功した戦略を継続的にIterateし、発展させることができます。キャンペーンやキャンバスを複製することで、配信の詳細やオーディエンスセグメントの再設定にかかる時間を最小限に抑えることができます。

## 複製する {#duplicating}

キャンペーンまたはキャンバスを複製すると、新しいメッセージには自動的に`"Copy of [Original Name]"`というタイトルが付けられ、その編集ページに移動します。これらの複製は、編集して起動するまで下書きのままになります。

{% alert tip %}
ワークスペース間で[キャンペーンをコピー]({{site.baseurl}}/user_guide/messaging/governance/copy_across_workspaces/)することもできます。コピーは編集して起動するまで下書きのままになります。
{% endalert %}

{% tabs %}
{% tab campaign %}
キャンペーンを複製するには:

1. **Messaging** > **キャンペーン** に移動します。
2. キャンペーンにカーソルを合わせ、<i class="fas fa-gear"></i> **More actions** を選択します。
3. **Duplicate** を選択します。
{% endtab %}

{% tab canvas %}
キャンバスを複製するには:

1. **Messaging** > **キャンバス** に移動します。
2. キャンバスの行にカーソルを合わせ、<i class="fas fa-ellipsis-vertical"></i> **More actions** を選択します。
3. **Duplicate** を選択します。

{% endtab %}
{% endtabs %}
