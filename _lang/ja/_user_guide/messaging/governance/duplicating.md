# キャンペーンとキャンバスの複製 {#duplicate-campaigns-and-canvases}

> 既存のキャンペーンやキャンバスを複製して、成功した戦略を継続的にIterateし、発展させることができます。キャンペーンやキャンバスを複製することで、配信の詳細やオーディエンスセグメントの再設定にかかる時間を最小限に抑えることができます。

## 複製する {#duplicating}

キャンペーンまたはキャンバスを複製すると、新しいメッセージには自動的に`"Copy of [Original Name]"`というタイトルが付けられ、その編集ページに移動します。これらの複製は、編集して起動するまで下書きのままになります。

{% alert tip %}
ワークスペース間で[キャンペーン、キャンバス、ランディングページをコピー]({{site.baseurl}}/user_guide/messaging/governance/copy_across_workspaces)することもできます。コピーは、編集してキャンペーンやキャンバスを起動するか、ランディングページを公開するまで下書きのままになります。
{% endalert %}

{% tabs %}
{% tab キャンペーン %}
キャンペーンを複製するには:

1. **メッセージング** > **キャンペーン** に移動します。
2. キャンペーンにカーソルを合わせ、<i class="fas fa-gear"></i> **その他のアクション**を選択します。
3. **複製**を選択します。
{% endtab %}

{% tab キャンバス %}
キャンバスを複製するには:

1. **メッセージング** > **キャンバス** に移動します。
2. キャンバスの行にカーソルを合わせ、<i class="fas fa-ellipsis-vertical"></i> **その他のアクション**を選択します。
3. **複製**を選択します。

{% endtab %}
{% endtabs %}
