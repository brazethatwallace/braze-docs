# プロモーションコードの作成 {#create-promotion-codes}

> CampaignsやCanvasesでプロモーションコードを作成する方法を説明します。

## プロモーションコードリストの作成 {#create}

### ステップ 1:新しいリストを作成する {#step-1-create-a-new-list}

ダッシュボードで**データ設定** > **プロモーションコード**に移動し、**プロモーションコードリストを作成**を選択します。

![プロモーションコードを作成するボタン。]({% image_buster /assets/img/promocodes/promocode1.png %})

### ステップ 2:詳細を入力する {#step-2-enter-the-details}

1. プロモーションコードリストに名前を付け、オプションで説明を追加します。
2. 次に、プロモーションコードのコードスニペットを作成します。

コードスニペットを作成する際に考慮すべき点は以下のとおりです。

- コードスニペットは保存後に編集できません。
- スニペットは大文字と小文字が区別されます。たとえば、システムは「Birthday_promo」と「birthday_promo」を2つの異なるスニペットとして認識します。
- Liquidでスニペット名を使用して、このプロモーションコードのセットを参照します。
- コードスニペットが別のリストで既に使用されていないことを確認してください。

![コードスニペット「spring25」を持つ「SpringSale2025」という名前のプロモーションコードリスト。]({% image_buster /assets/img/promocodes/promocode3.png %}){: style="max-width:80%"}

### ステップ 3:プロモーションコードのオプションを選択する {#step-3-choose-promotion-code-options}

各プロモーションコードリストには、作成時に設定される対応する有効期限の日時があります。有効期限の最大長は、リストを作成または編集した日から6か月です。

その期間内であれば、有効期限を繰り返し変更・更新できます。この有効期限は、このリストに追加されたすべてのコードに適用されます。有効期限が切れると、コードはBrazeシステムから削除され、そのリストのコードスニペットを呼び出すメッセージは送信されません。

![残りのすべてのコードが2025年4月30日午前12時に期限切れになるリスト有効期限設定。]({% image_buster /assets/img/promocodes/promocode4.png %}){: style="max-width:80%"}

また、オプションでカスタマイズ可能なしきい値アラートを設定することもできます。設定すると、リストで利用可能なプロモーションコードが少なくなった場合、またはプロモーションコードリストの有効期限が近づいた場合に、指定された受信者にメールで通知されます。受信者には1日1回通知されます。

![プロモーションコードリストの有効期限が5日後に切れる場合に「marketing@abc.com」に通知するしきい値アラートの例。]({% image_buster /assets/img/promocodes/promocode5.png %}){: style="max-width:80%"}

### ステップ 4:プロモーションコードをアップロードする {#step-4-upload-promotion-codes}

Brazeはコードの作成や引き換えを管理しないため、プロモーションコードをCSVファイルに生成してBrazeにアップロードする必要があります。

CSVファイルが以下のガイドラインに従っていることを確認してください。

- プロモーションコードの列が含まれていること。
- 1行に1つのプロモーションコードが記載されていること。

[Voucherify]({{site.baseurl}}/partners/ecommerce/loyalty/voucherify)または[Talon.One]({{site.baseurl}}/partners/ecommerce/loyalty/talonone)との組み込み連携を使用して、プロモーションコードを作成およびエクスポートできます。

{% alert important %}
最大ファイルサイズは100&nbsp;MBで、最大リストサイズは2,000万の未使用コードです。間違ったファイルをアップロードした場合は、新しいファイルをアップロードして前のファイルを置き換えてください。
{% endalert %}

1. アップロードが完了したら、**リストを保存**を選択して、入力したすべての詳細とコードを保存します。

![正常にアップロードされた「springsale」という名前のCSVファイル。]({% image_buster /assets/img/promocodes/promocode7.png %})

{:start="2"}
2. 保存を選択すると、**インポート履歴**に新しい行が表示されます。
3. インポートが完了したかどうかを確認するためにテーブルを更新するには、テーブルの上部にある <span style="font-size: 14px;margin-bottom: .5rem;height: 16px;width: 16px;" class="fas fa-sync" ></span> **同期**を選択します。

![アップロード中のプロモーションコード。]({% image_buster /assets/img/promocodes/promocode8.png %})

{% alert note %}
大きなファイルのインポートには数分かかります。待っている間、ページを離れてインポートの進行中に他の作業を行うことができます。インポートが完了すると、テーブルのステータスが**完了**に変わります。
{% endalert %}

## プロモーションコードリストの更新 {#updating-a-promotion-code-list}

リストを更新するには、既存のリストの1つを選択します。名前、説明、リストの有効期限、しきい値アラートを変更できます。また、新しいファイルをアップロードして**リストを更新**を選択することで、リストにコードを追加することもできます。リスト内のすべてのコードは、インポート日に関係なく同じ有効期限を持ちます。

{% alert important %}
プロモーションコードは削除できません。
{% endalert %}

### 誤ったプロモーションコードリストの修正 {#modifying-an-incorrect-promotion-code-list}

誤ったプロモーションコードを含むCSVファイルをアップロードして**リストを保存**を選択した場合、以下のいずれかの方法で解決できます。

- リスト全体を廃止する：現在のプロモーションコードリストをすべてのCampaigns、Canvases、またはテンプレートでの使用を停止します。次に、正しいコードを含むCSVファイルをアップロードして、メッセージングで使用します。
- 誤ったコードを使い切る：誤ったプロモーションコードリストからプレースホルダーにプロモーションコードを送信するCampaignを作成し、誤ったコードがすべて使用されるまで続けます。その後、正しいプロモーションコードを同じリストにアップロードします。
