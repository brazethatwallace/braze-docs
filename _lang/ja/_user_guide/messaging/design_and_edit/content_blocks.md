# コンテンツブロック {#content-blocks}

> コンテンツブロックを使用すると、再利用可能なクロスチャネルのコンテンツを一元管理できます。キャンペーン全体で統一された外観を作成したり、異なるチャネルを通じて同じオファーコードを配信したり、大規模な一貫性のあるメッセージングのために事前定義されたアセットを構築したりできます。また、[APIを使用して]({{site.baseurl}}/api/endpoints/templates)コンテンツブロックを作成・管理することもできます。

### コンテンツブロックの仕様 {#content-block-specifications}

| コンテンツブロックの属性 | 仕様 |
|---|---|
| 名前 | 最大100文字の必須フィールドです。コンテンツブロック名には、英字（A-Z）、数字（0-9）、ダッシュ（`-`）、アンダースコア（`_`）のみを使用できます。スペースやその他の特殊文字は使用できず、自動的に変換されます（例：スペースはアンダースコアに置き換えられます）。コンテンツブロックの保存後に名前を変更することはできません。また、アーカイブ済みであっても、以前のコンテンツブロックの名前を再利用することはできません。 |
| 説明 | （オプション）最大250文字です。他のBrazeユーザーがその用途や使用場所を把握できるように、コンテンツブロックの説明を記載してください。 |
| コンテンツサイズ | 最大50 KBです。 |
| 配置 | Content Blocksはメールフッター内では使用できませんが、メールで使用するために[フッターを含むコンテンツブロックを作成する](#email-footers)ことができます。 |
| 作成 | HTMLエディターまたはドラッグ＆ドロップエディターです。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="コンテンツブロックの仕様" }

{% alert tip %}
Content Blocksを作成する際、改行を追加してHTMLとLiquidを視覚化すると便利です。これらの改行を送信時にそのまま残すと、余分なスペースが生じ、ブロックのレンダリングに影響を与える可能性があります。これを避けるには、ブロックで**Capture**タグと**&#124; strip**フィルターを使用してください。
{% raw %}
```
{% capture your_variable %}
{{content_blocks.${your_content_block}}}
{% endcapture %}{{your_variable | strip}}
```
{% endraw %}
{% endalert %}

## Content Blocksを使用する {#use-content-blocks}

Content Blocksを作成したら、エディターまたはLiquidを使用してメッセージに挿入できます。

### ドラッグ＆ドロップエディターを使用する {#using-the-editor}

ドラッグ＆ドロップエディターでContent Blocksを追加するには：

1. エディターの**行**タブに移動し、**Content Blocks**を選択します。
2. Content Blocksをメールエディターにドラッグ＆ドロップします。
3. （オプション）ナビゲーションメニューのボタンを選択して、Content Blocksの幅を調整します。メールのグローバルスタイル設定で指定されていない場合、デフォルトの幅は100%です。指定されている場合は、グローバル設定が適用されます。<br><br>![幅を編集するオプション付きの両方向矢印。]({% image_buster /assets/img_archive/content_block_width_updated.png %}){: style="max-width:30%;" }<br><br>

{% alert note %}
ドラッグ＆ドロップで追加されたContent Blocksは、元のContent Blocksに**リンクされていません**。元のContent Blocksに加えた変更を表示するには、再度メールエディターにドラッグしてください。
{% endalert %}

ドラッグ＆ドロップエディターでは、複数のContent Blocksを1つの行ブロックに追加すると、位置ずれが発生する場合があります。行レベルでコンテンツの配置を維持するには、別々の行ブロックを使用してみてください。

### Liquidを使用する {#using-liquid}

Liquidを使用してContent Blocksを挿入するには：

1. **Content Blocksの詳細**セクションから**Content Block Liquidタグ**をコピーします。
2. Content Block Liquidタグをメッセージに挿入します。Liquidの入力を開始すると、タグが自動入力されます。

ドラッグ＆ドロップエディターでは、**パーソナライゼーション**パネルからContent Blocksを追加することもできます：

1. メールキャンペーンに移動し、**メール本文を編集**を選択します。
2. <i class="fas fa-plus"></i> **パーソナライゼーション**をクリックします。
3. **パーソナライゼーションタイプ**ドロップダウンで**Content Blocks**を選択します。
4. **属性**フィールドでContent Blocksの名前を選択します。
5. Liquidスニペットをコピーしてテキストエディターブロックに貼り付けます。<br>![オプション付きのパーソナライゼーション追加タブ。]({% image_buster /assets/img_archive/dnd_content_block_personalization.png %}){: style="max-width:30%;"}

{% alert important %}
Liquidで挿入されたContent Blocksは、元のContent Blocksに**リンクされており**、テンプレートへの変更が反映されます。
{% endalert %}

## Content Blocksのプレビュー {#preview-content-blocks}

アクティブなキャンペーンまたはキャンバスにContent Blocksを追加した後、Content Blocksライブラリからプレビューできます。コンテンツブロックにカーソルを合わせ、<i class="fa fa-eye preview-icon"></i> **プレビュー**アイコンを選択します。

このプレビューには、コンテンツブロックに関する情報が含まれます。例えば、作成者、タグ、作成日、最終編集日、説明、エディタータイプ、使用数の詳細（そのコンテンツブロックを使用しているメッセージやContent Blocksのクリック可能なリスト）、およびコンテンツブロックの実際のプレビューなどです。

{% alert note %}
コンテンツブロックがどこで使用されているかを監査する際は、リンクされた各メッセージまたはステップを個別に確認して、そのステータスを確認してください。
{% endalert %}

## コンテンツブロックのネスト {#nest-content-blocks}

コンテンツブロックはネストできますが、1回のみです。コンテンツブロックAをコンテンツブロックBにネストすることはできますが、そのコンテンツブロックBをコンテンツブロックCにネストすることはできません。

{% alert warning %}
3階層目のコンテンツブロックのネストを妨げるものはありませんが、2階層目以降のネストではコンテンツが展開されません。コンテンツとLiquidスニペットはメッセージから削除されます。
{% endalert %}

ネストされたコンテンツブロック内のリンクは、親メッセージの合計リンク数にカウントされます。ローカライゼーション用の国別URLなど、多数の条件付きリンクを含む単一のコンテンツブロックを使用すると、親メッセージに大量のリンクが蓄積され、キャンバスの保存が遅くなったり、保存できなくなったりする場合があります。大規模なローカライゼーションには、単一のコンテンツブロック内の条件付きリンクよりも、[多言語メッセージ]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/localization/locales_in_messages)の方が適しています。

## Content Blocksの更新とコピー {#update-and-copy-content-blocks}

Liquidを使用してContent Blocksが挿入されているすべてのメッセージで、Content Blocksを更新すると、その更新が反映されます。ドラッグ＆ドロップエディターの**行**の下にある**Content Blocks**ドロップダウンを使用してインポートされたContent Blocksは、すべてのメッセージで更新されるわけではありません。

単一のメッセージのContent Blocksを更新したい場合、または他のメッセージで使用するためにコピーを作成したい場合は、元のメッセージからHTMLを新しいメッセージにコピーするか、元のContent Blocksを編集して（すでにメッセージで使用されている必要があります）保存します。新しいContent Blocksとして保存できるプロンプトが表示されます。

Content Blocksに編集を加えた後、**Launch Content Block**を選択して、更新されたContent Blocksを保存して公開できます。または、**その他** > **複製**を選択して、Content Blocksの複製を作成できます。

![「Welcome to our newsletter」と表示されたContent Blocks]({% image_buster /assets/img/copy-content-block.png %})

## コンテンツブロックでメールフッターを使用する {#email-footers}

コンテンツブロックはメールフッター内では使用できませんが、メールで使用するためのフッターコンテンツを含むコンテンツブロックを作成できます。手順は以下の通りです：

1. **設定** > **メール設定** > **カスタムフッター**に移動し、フッターを作成します。
2. **コンテンツブロックライブラリ**でフッターをコンテンツブロックに追加します。
3. そのコンテンツブロックをメールテンプレートまたはメッセージに追加します。

## 注意事項 {#things-to-know}

- ドラッグ＆ドロップメールでHTMLコンテンツブロックを使用したり、HTMLメールでドラッグ＆ドロップのContent Blocksを使用したりすると、予期しないレンダリングの問題が発生する場合があります。これは、ドラッグ＆ドロップエディターがコンテンツを動的にレンダリングするHTMLとCSSを生成するのに対し、HTMLエディターはより静的であるためです。
- Liquidを使用してドラッグ＆ドロップのコンテンツブロックを挿入する場合、Brazeはブロックの HTML `<head>` からスタイルを含めません。モバイル固有のCSSなどのレスポンシブスタイルが期待どおりにレンダリングされない場合があります。ブロックがレスポンシブCSSに依存している場合は、そのCSSをコンテンツブロックを含むメッセージまたはテンプレートに追加してください。
- キャンバスエントリプロパティはキャンバスでのみサポートされています。キャンバスエントリプロパティを含むコンテンツブロックをキャンペーンで参照しても、値は反映されません。
- 複数のContent Blocksを含むメッセージが期待どおりにレンダリングされない場合（LiquidタグやHTMLが処理されずにテキストとして表示されるなど）、いずれかのContent Blocksの閉じられていないタグやその他のエラーが原因であることが多いです。原因を特定するには：
    1. 影響を受けているメッセージからContent Blocksを1つずつ削除します。
    2. 各削除後にメッセージが正しくレンダリングされるか確認します。
    3. 問題が解消される直前に削除したコンテンツブロックが原因です。
- `<code>` HTMLタグは、コンテンツブロックに設定されたフォントスタイルに関係なく、ほとんどのメールクライアントでデフォルトで等幅フォントでレンダリングされます。等幅表示を意図しない限り、テキストを `<code>` タグで囲むことは避けてください。
- Liquidを使用してカスタムHTMLメールテンプレートにコンテンツブロックを挿入すると、親テンプレートのCSSルールがコンテンツブロック内で定義されたスタイルを上書きする場合があります。詳細については、[カスタムHTMLテンプレートのContent Blocks]({{site.baseurl}}/user_guide/channels/email/html_editor/css_inline#content-blocks-in-custom-html-templates)を参照してください。

## Content Blocksのアーカイブ {#archive-content-blocks}

![展開された設定ドロップダウンメニューに、アーカイブ、複製、ワークスペースにコピーの3つのオプションが表示されています。]({% image_buster /assets/img/template_archive_cog.png %}){: style="max-width:20%;float:right;margin-left:15px;" }

コンテンツブロックの使用が完了したら、**テンプレート**ページからアーカイブできます。アーカイブされたContent Blocksは読み取り専用のため、編集する前にアーカイブを解除してください。メッセージで使用中のContent Blocksはアーカイブできません。

### ベストプラクティス {#best-practices}

- ブロックが少数のメールでのみ使用されている場合は、古いブロックをアーカイブし、アーカイブされていない新しいブロックでライブメッセージを更新することをお勧めします。
- ブロックにタイプミスがあるだけ、または軽微な変更が必要な場合は、ブロックをアーカイブすることはお勧めしません。代わりに、ブロックを更新して送信しましょう！
- このリストの最初の提案では合理的に管理できないほど多くのメッセージでブロックが使用されている場合は、ブロックからすべてのコンテンツを削除することをお勧めします。これにより、古い情報がメッセージに含まれることを防ぎます。
- 誤ってコンテンツブロックをアーカイブした場合は、アーカイブを解除できます。
