# ランディングページアンケート {#landing-page-surveys}

> Brazeアンケートは、ランディングページでフィードバックを収集し、分析してフォローアップメッセージングに活用できます。ベータ期間中、アンケートは[ランディングページのドラッグアンドドロップエディター]({{site.baseurl}}/user_guide/messaging/landing_pages/create_landing_pages/)で作成します。
