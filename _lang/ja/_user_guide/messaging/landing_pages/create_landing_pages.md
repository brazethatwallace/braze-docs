# ランディングページの作成 {#create-landing-pages}

> ドラッグ＆ドロップエディターを使用してランディングページを作成およびカスタマイズし、Brazeで直接オーディエンスを拡大し、ユーザーの設定を収集する方法を学びましょう。

## 前提条件 {#prerequisites}

ランディングページビルダーにアクセスするには、[特定の権限]({{site.baseurl}}/user_guide/messaging/landing_pages#prerequisites)が必要です。アクセスできない場合は、Braze管理者にお問い合わせください。

## ランディングページを作成する {#create-a-landing-page}

ランディングページは、共有可能なURLを持つ公開済みのWebページで、顧客がアクセスできます。

{% alert note %}
ランディングページテンプレートは、公開URLを持たない未公開のデザイン出発点であり、顧客と共有することはできません。テンプレートからページを作成するには、[テンプレートの使用](#using-templates)を参照してください。
{% endalert %}

### ステップ1:新しい下書きを作成する {#step-1-create-a-new-draft}

**メッセージング** > **ランディングページ**に移動し、**ランディングページを作成**を選択します。既存のランディングページの名前を選択して複製したり、変更を加えたりすることもできます。

### ステップ2:ページの詳細を入力する {#step-2-enter-the-page-details}

ランディングページの整理、ブランディング、共有に役立つ内部向けおよび公開向けの詳細を追加します。

#### 一般的な詳細 {#general-details}

ランディングページの名前と説明を入力します。これらの詳細は、内部ワークスペースでページを検索するために使用されます。顧客には表示されません。

#### サイトの詳細 {#site-details}

メタタグを設定して、ブラウザータブでのページの表示をカスタマイズし、検索エンジンの結果を最適化します。これらは顧客に表示されます。

以下のベストプラクティスに従うことをお勧めします。

| フィールド | 説明 | 推奨事項 |
| --- | --- | --- |
| サイトタイトル | ブラウザータブに表示されるタイトル。 | 60文字以内で入力してください。 |
| メタディスクリプション | 検索結果に表示されるテキストスニペット。 | 140～160文字で入力してください。 |
| ファビコン | ブラウザータブのサイトタイトルの横に表示されるアイコン。 | アスペクト比は1:1で、サポートされているファイル形式はPNG、JPEG、またはICOです。 |
| ページURL | ランディングページへのURLパスです。この値は、メッセージに埋め込んでフォーム送信時にユーザーを自動的に識別する[ランディングページLiquidタグ]({{site.baseurl}}/user_guide/messaging/landing_pages/tracking_users)を使用する際にも参照されます。 | この値はワークスペース全体で一意である必要があります。 |
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3 aria-label="サイトの詳細" }

### ステップ3:ページをカスタマイズする {#step-3-customize-the-page}

まだの場合は、**下書きとして保存**を選択します。ページのカスタマイズを開始するには、**ランディングページを編集**を選択します。ドラッグ＆ドロップエディターにはデフォルトテンプレートがプリロードされており、ユースケースに合わせてカスタマイズできます。

![ドラッグ＆ドロップエディターで作成中のランディングページの例。]({% image_buster /assets/img/landing_pages/template.png %})

エディターでは、ランディングページの構成に2種類のコンポーネントを使用します。基本ブロックとフォームブロックです。すべてのブロックは行内に配置する必要があります。各ブロックとプロパティの詳細なリファレンスについては、[エディターブロック（ランディングページ）]({{site.baseurl}}/user_guide/messaging/design_and_edit/editor_blocks?sdktab=landing%20pages)を参照してください。

![「行」と「フォームブロック」を含む「ビルド」セクション。]({% image_buster /assets/img/landing_pages/dnd.png %}){: style="max-width:35%;"}

{% tabs %}
{% tab 基本ブロック %}

これらのブロックを使用して、ランディングページにコンテンツを追加したりレイアウトをカスタマイズしたりできます。

| ブロックタイプ | 説明 |
|-------------|-------------|
| タイトル | コンテンツに見出しやタイトルを追加するためのテキストブロック。セクションの構造化と可読性の向上に役立ちます。 |
| 段落 | 長い説明や追加のコンテキスト用のテキストブロック。リッチテキストフォーマットをサポートしています。 |
| ボタン | リンクを開いたりフォームを送信したりなど、指定したアクションにユーザーを誘導するクリック可能な要素。 |
| ラジオボタン | ユーザーが1つを選択する必要があるオプションのリストを追加します。送信時に、関連するカスタム属性がユーザープロファイルに記録されます。 |
| 画像 | 画像を表示するためのブロック。画像をアップロードするか、外部ソースを参照するURLを指定できます。 |
| リンク | ユーザーがクリックして指定のURLに移動できるハイパーリンク。テキスト内に埋め込むことも、独立して使用することもできます。 |
| スペーサー | 要素間に垂直方向のスペースを追加し、レイアウトと可読性を向上させるための非表示ブロック。 |
| カスタムコード | カスタムHTML、CSS、またはJavaScriptを挿入して実行し、高度なカスタマイズを行えるブロック。このブロックからBraze SDKとのインターフェイスについては、[ランディングページ用JavaScriptブリッジ]({{site.baseurl}}/user_guide/messaging/landing_pages/javascript_bridge)および[カスタムフォームブロックの作成]({{site.baseurl}}/user_guide/messaging/landing_pages/custom_form_blocks)を参照してください。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="ステップ3: ページをカスタマイズする" }

#### スパンテキスト {#span-text}

カスタムコードを使わずにテキストブロックに特定のスタイルを適用するには、スタイルを適用したいテキストをハイライトし、**スタイル用のスパンでラップ**を選択します。

![異なるフォントサイズや色など、さまざまなスタイルのテキストセクションがあるテキストボックス。ハイライトされたセクションに「スタイル用のスパンでラップ」オプションを含むツールバーが表示されています。]({% image_buster /assets/img/landing_pages/wrap_with_span.png %}){: style="max-width:50%;"}

スパンプロパティを調整してテキストスタイルを更新できます。以下の項目が含まれます。

- フォントファミリー、ウェイト、サイズ
- 行の高さ
- 文字間隔
- テキストの配置と色
- ブロックのパディング

![更新するさまざまなオプションがあるスパンプロパティパネル。]({% image_buster /assets/img/landing_pages/span_properties.png %}){: style="max-width:35%;"}

これらのブロックを使用して、ユーザーが送信したデータをBrazeのプロファイルにリンクするフォームを作成できます。フォームブロックを使用する場合は、確認状態用の追加のランディングページも作成する必要があることに注意してください。

![新規顧客を登録し、メールに割引コードを送信するフォームブロック。]({% image_buster /assets/img/landing_pages/form.png %}){: style="max-width:70%;"}

{% alert tip %}
フォームブロックを行に直接配置する代わりに、[マルチステップフォーム]({{site.baseurl}}/user_guide/messaging/landing_pages/create_landing_pages/multi_step_forms)を使用して長いフォームを複数のステップに分割し、各ステップに独自のフィールドと組み込みの確認ステップを設定できます。
{% endalert %}

| ブロックタイプ | 説明 |
|---------------|-------------|
| メールキャプチャ | メールアドレス用のフォームフィールド。送信時に、そのユーザーのBrazeプロファイルにメールアドレスが追加されます。 |
| 電話番号キャプチャ | 電話番号用のフォームフィールド。送信時に、ユーザーはSMSまたはWhatsApp購読グループに購読登録されます。 |
| 入力フィールド | 標準属性項目（名前や姓など）または任意のカスタム属性文字列をサポートするフォームフィールド。 |
| ドロップダウン | ユーザーが定義済みのリストから項目を選択できます。リストには任意のカスタム属性文字列を追加できます。 |
| チェックボックス | ユーザーがチェックを入れると、ブロックの属性が`true`に設定されます。チェックが入っていない場合、属性は`false`に設定されます。 |
| チェックボックスグループ | ユーザーが複数の選択肢から選択できます。値は定義された配列カスタム属性に設定または追加されます。 |
| 購読を管理 | メール、SMS、またはWhatsApp購読グループのチェックリスト。ユーザーはフォーム送信時に参加するグループを選択します。各ブロックは1つのチャネル用です。詳細については、[購読を管理ブロック]({{site.baseurl}}/user_guide/messaging/landing_pages/manage_subscriptions)を参照してください。 |

{% endalert %}

#### ページコンテナスタイル {#page-container-styles}

**ページコンテナ**タブから、ランディングページ内のすべての関連コンポーネントブロックに適用されるスタイルを設定できます。これらのスタイルは、特定のブロックでオーバーライドする場合を除き、ページ全体に適用されます。

ブロックレベルでスタイルをカスタマイズする前に、ページコンテナレベルのスタイルを設定することをお勧めします。ページ全体の背景画像を追加することもできます。

![背景画像、色、ボーダーの詳細、コンテンツスタイリングをカスタマイズするオプションがある「ページコンテナ」セクション。]({% image_buster /assets/img/landing_pages/page_container.png %}){: style="max-width:40%;"}

#### ユーザーデバイスへのレスポンシブ対応 {#responsive-to-user-devices}

小さい画面でカラムを縦に積み重ねることで、ランディングページをユーザーのデバイスサイズにレスポンシブ対応させることができます。この機能を有効にするには、レスポンシブにしたい行にカラムを追加し、**カラムのカスタマイズ**セクションで**小さい画面では縦に積み重ねる**をオンに切り替えます。

有効にすると、小さい画面で複数カラムコンテンツの縦方向の順序を制御するために、カラムの積み重ね順序を逆にすることもできます。これにより、カスタムコードなしでモバイルでのページの見た目と使い勝手が向上します。

![「カラムのカスタマイズ」セクションの「小さい画面では縦に積み重ねる」トグル。]({% image_buster /assets/img/landing_pages/device_responsive_toggle.png %}){: style="max-width:50%;"}

#### デバイスごとに行やブロックを非表示にする {#hide-rows-and-blocks-by-device}

デスクトップまたはタブレットおよびモバイルデバイスで行やブロックを非表示にできます。キャンバス上の行またはブロックを選択します。プロパティパネルで**非表示にする**を選択し、**デスクトップ**または**タブレットおよびそれ以下のデバイス**を選択します。

非表示の行やブロックは、そのデバイスタイプではドラッグ＆ドロップエディターのプレビューおよびライブランディングページに表示されません。

#### 任意フィールドと必須フィールド {#optional-and-required-fields}

特定のフォームフィールドを必須にするか任意にするかを選択できます。必須フィールドは、フォームを送信する前に入力する必要があります。任意フィールドは、ユーザーが空白または未選択のままにできます。

{% alert note %}
ラジオボタンは常に必須であり、任意に設定することはできません。任意の単一選択フィールドが必要な場合は、代わりにドロップダウンの使用を検討してください。
{% endalert %}

たとえば、フォーム送信前に同意の取得を強制するには、**必須フィールド入力**をオンにして、適切な免責事項テキストと共にチェックボックスを必須に設定できます。

![「必須入力フィールド」トグルが選択されたチェックボックスフォームフィールド。]({% image_buster /assets/img/landing_pages/lp-optional-required.png %}){: style="max-width:50%;"}

### ステップ4:確認ページを作成する（任意） {#step-4-create-a-confirmation-page-optional}

ランディングページにフォームが含まれていない場合は、次のステップに進んでください。

{% alert note %}
フォームに[マルチステップフォーム]({{site.baseurl}}/user_guide/messaging/landing_pages/create_landing_pages/multi_step_forms)を使用している場合は、このステップをスキップしてください。マルチステップフォームには組み込みのロックされた確認ステップが含まれているため、別の確認ページは不要です。
{% endalert %}

ランディングページに[フォーム](#form-blocks)が含まれている場合、確認エクスペリエンスとして機能する2つ目のランディングページを任意で作成できます。このページでは、ユーザーに感謝を伝えたり、フォーム送信後の次のステップを提供したりします。

1. フォームの**送信**ボタンを選択します
2. ユーザーがフォームを送信したときに確認ページを含めるかどうかを選択します
    - **Web URLを開く**のクリック時動作を使用して、ユーザーを確認ページに誘導します
    - **なし**のクリック時動作を使用すると、ユーザーはランディングページに留まります

確認ページを含めない場合、ユーザーはフォームが正常に送信されたことを知ることができない場合があります。ジャーニーを完了するために、常に確認エクスペリエンスを含めてください。

{% alert note %}
確認ページが新しいタブで開く場合、元のランディングページに戻って更新された情報で再送信したユーザーは、前回の送信を上書きする可能性があり、データの不整合が生じる場合があります。
{% endalert %}

### ステップ5:ページをプレビューする {#step-5-preview-the-page}

エディターの**プレビュー**タブでランディングページをプレビューできます。ランディングページを下書きとして保存した後、**ランディングページ**に移動し、ランディングページの横にある**URLをコピー**を選択してURLにアクセスできます。

![メニューが開かれ「URLをコピー」オプションが表示されているランディングページ。]({% image_buster /assets/img/landing_pages/copy-url.png %})

#### プレビューリンクを共有する {#sharing-a-preview-link}

エディターで**プレビューリンクをコピー**を選択して、ダッシュボードにアクセスできないレビュアーとページを共有することもできます。

- ランディングページがLiquidを使用していない場合、このリンクは**URLをコピー**のダイレクトURLと同じで、プレビューモードで開かれます。
- ランディングページがLiquidを使用しており、ランディングページProのエンタイトルメントがある場合、リンクはリンク生成時のスナップショットではなく、最新の変更を反映してオンデマンドでライブページをレンダリングします。コンテンツはユーザーごとにパーソナライズされます。プレビューにはBrazeファビコンが表示され、変更することはできません。

他のチャネルのプレビューリンクについては、[共有可能なプレビュー]({{site.baseurl}}/user_guide/messaging/governance/shareable_preview)を参照してください。

### ステップ6:公開する {#step-6-publish}

公開する前に、以下を確認してください。

- プランの公開ランディングページの上限を超えていないこと
- 各フォームベースのページが**Web URLを開く**アクションを使用して[確認ページ](#step-4-create-a-confirmation-page-optional)にリンクされているか、組み込みの確認ステップを持つ[マルチステップフォーム]({{site.baseurl}}/user_guide/messaging/landing_pages/create_landing_pages/multi_step_forms)を使用していること
- すべての必須ページフィールド（URLパスやタイトルなど）が完了していること

準備ができたら、**ランディングページを公開**を選択します。

{% alert note %}
iOSおよびSafari（Safariの組み込みコントロールやサードパーティの拡張機能を含む）の積極的なポップアップブロッカーや広告ブロッカーは、フォームの**送信**ボタンが別のURLも開く場合（同じタブまたは新しいタブのいずれか）、ランディングページの動作に悪影響を与える可能性があります。
{% endalert %}

## テンプレートを使用する {#use-templates}

ランディングページテンプレートは、ランディングページをより速く構築するための再利用可能なデザインの出発点です。テンプレートにはパブリックURLがなく、顧客がアクセスすることはできません。テンプレートからライブランディングページを作成するには、新しいランディングページを作成する際にテンプレートを選択し、必要に応じてカスタマイズしてから公開します。

テンプレートは、ランディングページエディターと**ランディングページテンプレート**ページ（**コンテンツ** > **ランディングページ**）の両方からアクセスおよび管理できます。ランディングページテンプレートには名前が必要で、説明は任意です。

## テンプレートを管理する {#manage-templates}

ランディングページテンプレートをプレビュー、アーカイブ、または編集できます。自分のランディングページテンプレート（**Your Templates** にあります）は複製できますが、Brazeテンプレートは複製できません。ランディングページを編集する際に、ランディングページをテンプレートとして保存したり、テンプレートに変更を加えたり、ランディングページのコンテンツを削除したりできます。

![ランディングページの保存、変更、削除のオプションが表示されたドロップダウン。]({% image_buster /assets/img/landing_pages/manage-lp-template.png %}){: style="max-width:60%;"}

## 分析の表示 {#view-analytics}

ランディングページの効果を分析するには、**メッセージング** > **ランディングページ**に移動し、公開済みのランディングページを選択します。ここでは、ランディングページのページビュー数、ページクリック数、ページ送信数、送信率を追跡できます。

![ランディングページの分析セクション。]({% image_buster /assets/img/landing_pages/analytics.png %})

## フォーム送信エラーの処理 {#handling-form-submission-errors}

ユーザーが必須項目が未入力またはサポートされていない入力でフォームを送信しようとすると、一般的なエラーメッセージが表示され、送信できません。

一般的な原因：

- 必須フィールドが空白のまま
- テキスト入力に特殊文字が使用されている
- 必須チェックボックスが選択されていない

ユーザーに表示されるエラーメッセージはカスタマイズできません。公開前にランディングページをプレビューして、フィールドの動作を確認してください。
