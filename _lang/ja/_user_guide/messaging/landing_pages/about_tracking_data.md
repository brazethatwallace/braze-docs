# ランディングページのトラッキングデータについて {#about-landing-page-tracking-data}

> Brazeのランディングページにおけるトラッキングおよび匿名化データについて説明します。

## トラッキング方法 {#tracking-methods}

### Web SDK {#web-sdk}

Braze Web SDKは、ユーザーがランディングページでフォームを送信した際に初期化されます。フォーム送信前には、個人データは収集されず、SDKはユーザーを能動的に追跡しません。初期化が完了した後も、SDKはブラウザにデータを保存しません（Cookie、ローカルストレージなどを含む）。

Braze Web SDKは、ユーザーがBrazeメッセージ内の{% raw %}`{% landing_page_url %}`{% endraw %} Liquidタグによって生成されたリンクからランディングページに遷移した際に、即座に初期化されます。

フォームが送信されると、SDKは以下のデータを収集します。

- フォーム送信イベント（イベント名と送信時刻）
- チームがフォームで指定したデータ（名前、メール、電話番号など）
- セッション開始時刻
- デバイスID（デバイスに対して生成されるユニークなIDですが、保存はされません）
- IPアドレスから判定された国

### 匿名化データ {#anonymized-data}

ユーザーがフォームを送信する前に、ランディングページで追跡されるデータは、匿名化された識別不可能な情報のみで構成されます。これは、ランディングページが受け取るページビュー数（インプレッション）やクリック数などの標準的なWebサイト集計指標で構成されます。

このデータは識別可能なユーザーに紐づけられていないため、個々のユーザーの行動をリターゲティングしたり追跡したりするために使用することはできません。

## 重複ユーザープロファイルの統合 {#merging-duplicate-user-profiles}

Brazeは、ランディングページフォームが送信された際に、メールや電話番号などの属性に基づいてユーザーを自動的に統合することはありません。既存のユーザープロファイルと一致するメールまたは電話番号でフォームが送信された場合、Brazeは別のユーザープロファイルを作成します。

重複ユーザープロファイルを統合するには、以下の方法があります。

- ランディングページフォームが送信された際に[`/users/merge`エンドポイント]({{site.baseurl}}/api/endpoints/user_data/post_users_merge)をトリガーして、新しいプロファイルを既存のプロファイルと統合します。
- [一括統合]({{site.baseurl}}/user_guide/audience/manage_audience/merge_duplicate_users#bulk-merging)をスケジュールして、一致する識別子に基づいて重複プロファイルを定期的に統合します。
