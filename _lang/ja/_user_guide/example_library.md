## ここにあるもの {#what-you-find-here}

各サンプルでは、実用的なパターンを紹介します。達成したい目標、構築前に検討すべき点、Brazeでの設定方法を解説しています。サンプルはトピックごとに整理されているため、目指す成果に合ったパターンを見つけることができます。

これらの記事は、機能リファレンス記事を補完するものです。サンプルで使用されているチャネル、キャンバスコンポーネント、またはデータツールの詳細な製品情報が必要な場合は、そのページにある関連記事のリンクを参照してください。

## これらの例の使い方 {#how-to-use-these-examples}

1. **目標から始める：** 達成したい成果を明確にします（例えば、プレビューでパーソナライズされたLiquidを検証する、複数ステップのジャーニーを構築するなど）。
2. **パターンを応用する：** 各例を出発点として活用します。自社のイベント、属性、セグメント、クリエイティブに置き換えてください。
3. **ワークスペースで確認する：** 起動する前に、データの可用性、チャネルの設定、権限などの前提条件を確認してください。
4. **関連リソースで理解を深める：** Brazeの機能についてより詳しいリファレンスガイダンスが必要な場合は、各例のページにある関連記事を活用してください。
