## ここで見つかるもの {#what-you-find-here}

各サンプルでは、実践的なパターンを解説しています。解決する目標、構築前に検討すべきこと、Brazeでの設定方法を順を追って説明します。サンプルはトピック別に整理されているため、目指す成果に合ったパターンを見つけることができます。

これらの記事は、機能リファレンス記事を補完するものです。サンプルで使用されているチャネル、キャンバスコンポーネント、またはデータツールの詳細な製品情報が必要な場合は、そのページの関連記事リンクをご参照ください。

## これらのサンプルの使い方 {#how-to-use-these-examples}

1. **目標から始める：** 達成したい成果を特定します（例：プレビューでパーソナライズされたLiquidを検証する、マルチステップジャーニーをオーケストレーションするなど）。
2. **パターンを応用する：** 各サンプルを出発点として活用してください。イベント、属性、セグメント、クリエイティブを自分のものに置き換えます。
3. **ワークスペースで確認する：** 開始前に、データの可用性、チャネルの設定、権限などの前提条件を確認してください。
4. **おすすめリソースで理解を深める：** Brazeの機能についてより詳しいリファレンスガイダンスが必要な場合は、各サンプルページの関連記事をご活用ください。
