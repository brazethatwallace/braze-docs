# ユースケース：より賢いターゲティングでサブスクリプションのアップグレードを予測する {#use-case-predict-subscription-upgrades-with-smarter-targeting}

> この例は、架空のブランドがBraze予測イベントを活用し、自社にとって重要な成果（プロ会員へのアップグレードなど）を定義し、結果を改善するターゲット戦略を構築する方法を示しています。

ジョーダンは、無料版と有料版がある健康・フィットネスアプリ「Steppington」のライフサイクルストラテジストだとしましょう。ジョーダンのチームは、無料ユーザー群全員に割引メッセージを大量に送りつけることなく、プロプランへのアップグレードを増やすことを目標としています。現在、無料プランのユーザー全員に、7日後に「プロ版を50%オフで試す」プロモーションを送っています。一部のコンバージョンは促進されますが（7日間で約5%）、過剰なアプローチも招いてしまいます。これには、元々アップグレードする可能性が高かったユーザーへの不要な割引も含まれます。

ターゲティングを改善し、メッセージングの疲弊を軽減するため、ジョーダンは予測イベントを使用して、ユーザーが今後7日以内にプロにアップグレードする可能性をモデル化します。彼はカスタムイベント`upgraded_to_pro`を定義し、それを使って予測モデルをトレーニングし、ユーザーをスマートで行動指向のグループにセグメント化します。

このチュートリアルでは、ジョーダンが以下をどのように作成したかを説明します。

- 7日以内の`upgraded_to_pro`に対する予測モデル
- コンバージョン率を向上させつつ、送信するメッセージの総数を減らすのに役立つセグメント

## ステップ 1：アップグレードの予測モデルを作成する {#step-1-create-a-predictive-model-for-upgrades}

ジョーダンはまず、アップグレード戦略において最も重要な成果を定義します。それはユーザーが無料プランからプロプランに移行することです。「登録からの経過時間」のような一般的なトリガーに頼るのではなく、実際にコンバージョンする可能性が高いユーザーを予測したいと考えています。こうすることで、チームは単なる推測ではなく、実際のシグナルに基づいて行動できます。

1. Brazeダッシュボードで、ジョーダンは**Analytics** > **予測イベント**に移動します。
2. 彼は[新しいイベント予測を作成し]({{site.baseurl}}/user_guide/brazeai/predictive_suite/predictive_events/creating_an_event_prediction)、「7日でプロ版にアップグレード」と名付けます。
3. ターゲットイベントとして、彼は自身のカスタムイベント`upgraded_to_pro`を選択します。
4. ジョーダンは予測期間を7日に設定し、更新スケジュールを設定し、予測を作成します。

![予測の定義、時間枠、オーディエンス、更新スケジュールを示す予測設定画面。]({% image_buster /assets/img/ai_use_cases/prediction_settings.png %})

## ステップ 2：ユーザーをアップグレード確率に基づいてセグメント化する {#step-2-segment-users-based-on-upgrade-probability}

トレーニングが完了すると、Brazeは対象となる各ユーザーに[イベント発生確率スコア]({{site.baseurl}}/user_guide/brazeai/predictive_suite/predictive_events/analytics#purchase_score)（0〜100）を割り当てます。ジョーダンはこのスコアを使って、実行可能なセグメントを作成します。一つは割引を必要としない可能性が高い購入意欲の高いユーザー向け、もう一つはサポートなしではコンバージョンに至らない可能性が高いユーザー向けです。

1. ジョーダンはBrazeのセグメントに移動します。
2. 彼は[イベント発生確率スコアフィルター]({{site.baseurl}}/user_guide/audience/segments/segmentation_filters#event-likelihood-score)を使って2つの[セグメント]({{site.baseurl}}/user_guide/audience/segments/creating_a_segment)を作成し、自身が作成した予測を選択します。2つのセグメントは次の通りです。
  - **アップグレードする可能性が高い：** スコアが70超
  - **アップグレードするには後押しが必要：** スコアが40超かつ70未満

{% alert tip %}
予測フィルターは、他のユーザー属性や行動と組み合わせることができます。ジョーダンは、ユーザーの興味に基づいてこれらのセグメントをさらに精緻化する計画です。例えば、フィットネストラッキング機能を頻繁に利用するユーザーを優先するといった具合です。これにより、4つのサブグループをより正確にターゲティングでき、コンテンツやメッセージングを各ユーザーのニーズに合わせることができます。
{% endalert %}

![イベント発生確率スコア用の2つのフィルターを備えたセグメントビルダー。]({% image_buster /assets/img/ai_use_cases/event_likelihood_score.png %})

## ステップ 3：意図レベルに応じてメッセージングをパーソナライズする {#step-3-personalize-messaging-by-intent-level}

ジョーダンは、アップグレードの意思を示す明確なシグナルと、ユーザー行動に基づく精緻化されたサブグループを手にしています。そこで彼は、各ユーザーのニーズに応じて適応するメッセージング戦略を構築します。画一的な一斉送信はもう終わりです。

彼はこのキャンペーンの主要チャネルとしてメールを選びます。なぜでしょうか？ジョーダンは、購入意欲の高いユーザーに対してプロ版の価値を説明し、躊躇しているユーザーに対して説得力のある提案をしたいと考えています。どちらの場合も、十分なスペースと視覚的要素、そして強力なCTAが必要です。メールはユーザーにプレッシャーをかけずにそれをうまく行う柔軟性を与え、クリック行動を通じてパフォーマンスをトラッキングできるようにします。

ジョーダンは、先ほど構築したセグメントに基づいて体験を分割する[キャンバスを作成]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas)します。彼はオーディエンスパスステップを追加してターゲットを絞ります。

- 高い意欲、フィットネス重視のユーザー
- 高い意欲、その他のユーザー
- 低い意欲、フィットネス重視のユーザー
- 低い意欲、その他のユーザー

![各意図タイプごとに4つのパスがあるキャンバスオーディエンスパス。]({% image_buster /assets/img/ai_use_cases/canvas_paths_by_intent.png %})

彼はまた、キャンバスのコンバージョンイベントをカスタムイベント`upgraded_to_pro`に設定します。これにより、Brazeはユーザーがフローを進むにつれてアップグレードコンバージョンを自動的にトラッキングします。

### パスごとのメッセージ例 {#example-messages-per-path}

{% tabs %}
{% tab 高い意欲、フィットネス %}

これらのユーザーは既にアクティブで、フィットネストラッキング機能に深くエンゲージしています。追加のインセンティブがなくてもアップグレードする可能性が高いため、メッセージは既存の習慣を基盤とした深いインサイトと高度なツールの活用に焦点を当てています。

- **件名：** フィットネス目標をさらに高めよう
- **ヘッダー：** あなたの進歩にはプロ版がふさわしい
- **本文：** あなたはもうしっかりした習慣を身につけています。プロ版なら、さらに深く掘り下げられます。筋肉群ごとの進捗をトラッキングし、週ごとのパフォーマンス目標を設定し、自分の動きに合わせた高度な分析機能を利用できます。
- **CTA：** 無料のプロ版トライアルを始める

{% endtab %}
{% tab 高い意欲、その他 %}
これらのユーザーは、プロ機能の閲覧や頻繁なアプリ利用といった強いエンゲージメントの兆候を示していますが、特にフィットネストラッキングに焦点を当てているわけではありません。このメッセージは、コーチングやパーソナライゼーションといったより広範なプロの利点を強調し、ユーザーを後押しして契約へと導きます。

- **件名：** もうすぐです——プロ版はいつでも準備できています
- **ヘッダー：** もっと多くの運動方法を解き放とう
- **本文：** あなたはプロ版が提供するものを探ってきました。今こそ、あなた独自の目標に合わせて設計されたカスタムプラン、1対1のコーチングコンテンツ、ガイド付きプログラムを利用するチャンスです。その目標が筋力、バランス、継続性のいずれであっても構いません。
- **CTA：** 無料のプロ版トライアルを始める

{% endtab %}
{% tab 低い意欲、フィットネス %}
これらのユーザーはフィットネス機能を試してはいますが、アップグレードに向けた具体的なステップを踏んでいません。このメッセージは、彼らのフィットネスへの関心に寄り添いながら、期間限定オファーで障壁を減らします。これにより、プロ版が日常のトレーニングをレベルアップさせる低リスクな方法だと理解してもらえます。

- **件名：** もっと賢くトレーニングする準備はできていますか？プロ版を50%オフで試そう
- **ヘッダー：** トレーニングのアップグレードが待っています
- **本文：** プロ版は、強力なスタートに必要なすべてを提供します。分かりやすいトレーニング計画、専門家のアドバイス、そして実際の進捗トラッキングです。今すぐ50%オフで試せます。いつでもキャンセルできます。
- **CTA：** プロ版を50%オフで手に入れる

{% endtab %}
{% tab 低い意欲、その他 %}

これらのユーザーは全体的にエンゲージメントが低い状態です。強い動機がなければアップグレードしない可能性が高いため、メッセージはシンプルで、メリットを前面に出すアプローチを取ります。割引を提示し、柔らかい言葉遣いでプレッシャーをかけずに検討を促します。

- **件名：** プロ版が50%オフ——今週末だけ
- **ヘッダー：** 準備ができたら、いつでもどうぞ
- **本文：** 初めてのパーソナライズされたフィットネスプランを作成し、進捗をトラッキングし、限定ワークアウトにアクセスできます。すべてが半額です。プロ版をお得に試して、いつでもキャンセルできます。
- **CTA：** プロ版を50%オフで手に入れる

{% endtab %}
{% endtabs %}

## ステップ 4：結果を測定し、戦略を最適化する {#step-4-measure-results-and-optimize-your-strategy}

キャンペーン実施後、ジョーダンは[キャンバス Analytics]({{site.baseurl}}/user_guide/messaging/canvas/testing_canvases/measuring_and_testing_with_canvas_analytics)でパフォーマンスを確認し、パーソナライズされたパスがどの程度効果的だったかを把握します。同時に、予測意図と行動シグナルを組み合わせることでアップグレード率が向上したかどうかも確認します。

パス別のメールパフォーマンス：

- **高い意欲、フィットネス**
   - *開封率：* 34%
   - *クリック率：* 20%
   - *コンバージョン率：* 13%
   - 割引なし
- **高い意欲、その他**
   - *開封率：* 30%
   - *クリック率：* 17%
   - *コンバージョン率：* 11%
   - 割引なし
- **低い意欲、フィットネス**
   - *開封率：* 27%
   - *クリック率：* 12%
   - *コンバージョン率：* 8%
   - 50%オフの特典を含む
- **低い意欲、その他**
   - *開封率：* 23%
   - *クリック率：* 9%
   - *コンバージョン率：* 6%
   - 50%オフの特典を含む

チームの以前の画一的なキャンペーン（7日後の一律割引でコンバージョン率はわずか5%、過剰なメッセージングを招いた）と比べ、ターゲットを絞ったアプローチでは全グループで意味のある向上が見られ、効率性が改善され、不要な割引も減りました。

[ファネルレポート]({{site.baseurl}}/user_guide/analytics/reports/funnel_reports)でも、主要なステップにおける離脱率が明らかに減少していることが示されています。特に、パーソナライズされたメッセージングを受け取った購入意欲の低いユーザーにおいて顕著です。より多くのユーザーが開封し、クリックし、アップグレードしています。これは意図ベースのターゲティングの価値を証明しています。

ジョーダンはこれらのインサイトを次のように活用します。

- 件名とCTAの表現に関するA/Bテストを検討する
- 中程度の購入意欲を持つユーザーに対する割引の適用基準を見直す
- コンテンツ閲覧やアプリ機能の使用といった追加の行動に基づいて、セグメントの精緻化を続ける

予測イベントと階層的セグメンテーションにより、ジョーダンのチームはユーザーの意図と行動に基づいてメッセージングを適応させる、スケーラブルな戦略を手に入れました。これによりアップグレードを促進しつつ、ブランドの信頼を維持しています。
