# コンテンツオプティマイザー {#content-optimizer}

> コンテンツオプティマイザーは、AIを活用して大量のコンテンツバリアントを自動生成・評価し、メッセージコンテンツを大規模にテスト・最適化します。

{% alert important %}
コンテンツオプティマイザーは現在ベータ版であり、メール、プッシュ通知、SMS/MMS/RCSメッセージのチャネルでのみ利用可能です。利用開始に関するサポートが必要な場合は、カスタマーサクセスマネージャーにお問い合わせください。
{% endalert %}

## Content Optimizerについて {#about-content-optimizer}

Content Optimizerはキャンバスステップ内で実行されます。テストするメッセージコンポーネントの定義、生成AIまたは手動入力によるバリアントの生成、そしてユーザーに送信するコンテンツの組み合わせの自動最適化を支援します。この機能を使用すると、以下のことが可能です。

- メールの件名、本文ヘッダー、本文コンテンツ、またはプライマリCTAを最適化します。
- プッシュ通知のタイトルとメッセージを最適化します。
- SMS、MMS、RCSメッセージのフック、本文、CTAを最適化します。
- 手動のA/Bテスト設定なしで、メッセージのパフォーマンスを継続的に改善します。
- AIを活用したアイデア出しにより、大量のコンテンツバリアントを素早くテストします。
- パフォーマンスの低いコンテンツを自動的にフェーズアウトし、勝者をスケールアップします。

[Content Optimizerステップ]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/content_optimizer_step)の作成方法をご覧ください。

### OpenAIとContent Optimizer {#openai-and-content-optimizer}

Content OptimizerはAI生成のバリアント候補を明示的にリクエストした場合にのみOpenAIを使用します。どのバリアントを各ユーザーに送信するか、または送信トラフィックの配分にはOpenAIを使用しません。

- **OpenAIを使用する場合：** コンテンツコンポーネントに対して**AI候補を生成**を選択すると、Brazeはシードバリアント、指示、オプションの[ブランド・ガイドライン]({{site.baseurl}}/user_guide/administer/global/workspace_settings/brand_guidelines)、および（十分な送信データがあるローンチ済みステップの場合）集計されたパフォーマンスコンテキストをOpenAIに送信し、バリアントのアイデアを生成します。
- **バンディット最適化：** Braze独自のマルチアームバンディットアルゴリズムが、トラフィック配分、送信時のバリアント選択、およびパフォーマンスに基づく最適化を処理します。[仕組み](#how-it-works)を参照してください。
- **手動入力：** OpenAIにコンテンツを送信せず、自分でバリアントを入力して定義できます。

| テーマ別コンテンツの組み合わせ | 高パフォーマンスの組み合わせの発見 | テーマに沿った件名、本文、CTAのコンポーネントを組み合わせ、最適な全体的な組み合わせを見つけます。 |

## 仕組み {#how-it-works}

このセクションで説明する最適化は、Brazeのバンディットアルゴリズムが処理します。

コンテンツオプティマイザーは、非文脈的な[マルチアームドバンディット](https://en.wikipedia.org/wiki/Multi-armed_bandit)アルゴリズムを使用して、高パフォーマンスのバリアントへの配信を増やし、低パフォーマンスのバリアントへの配信を減らします。時間の経過とともに、手動での介入を最小限に抑えながら、メッセージコンテンツの継続的な改善が実現されます。

Braze独自のバンディット最適化アルゴリズムは、コンテンツオプティマイザーステップの組み合わせ的性質に特化して構築されています。各メッセージは複数のコンポーネントで構成されているため、バンディットは各コンポーネント（件名、本文、CTAなど）のパフォーマンスと、それらを組み合わせてメッセージにした際の相互作用を同時に学習します。より具体的には、ある組み合わせが送信されると、同じコンポーネントを共有するすべての組み合わせがその送信データの恩恵を受けます。これにより、標準的なバンディットアルゴリズムと比較して、同じ量のデータでバンディットがはるかに速く学習できるようになります。

ステップが最初に起動すると、コンテンツオプティマイザーは初期のパフォーマンスデータを収集するために、バリアントをランダムに送信します。この初期の探索期間の後、アルゴリズムはパフォーマンスの高いコンテンツの組み合わせへトラフィックをシフトし始め、パフォーマンスの低い選択肢への割り当てを徐々に減らしていきます。探索期間中は、アルゴリズムが相対的なパフォーマンスから学習できるよう、トラフィックは一般的に利用可能なバリアント全体に分散されます。

コンテンツオプティマイザーは、キャンバスのメッセージステップに似ており、サイレント時間帯、[インテリジェントタイミング]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_timing)、イベントログ記録などの機能を備えています。コンテンツオプティマイザーステップを設定するには、ベースメッセージを作成し、最適化するコンテンツコンポーネント（件名、本文テキスト、行動喚起など）を定義します。各コンポーネントのバリアントはAIで生成するか手動で入力でき、ベースメッセージにLiquidタグを追加してコンポーネントをメッセージコンテンツにマッピングする必要があります。

各ユーザーは、コンテンツオプティマイザーステップへのエントリごとに1通のメッセージを受け取ります。再エントリは新規として扱われ、以前のバリアントに関する記憶は保持されません。

## キャンバスのエントリ設定 {#canvas-entry-setup}

最良の結果を得るには、定期的に実行されるキャンバスや常時稼働のキャンバスなど、ユーザーが徐々にかつ定期的にステップに入るキャンバスでContent Optimizerを使用してください。日次のボリュームが安定していることが重要です。すべてのユーザーが一度にステップに入る場合、Content Optimizerは初期の結果から学習する時間がありません。その場合、ステップはライブ最適化エンジンではなく、静的なA/Bテストのように動作します。

Content Optimizerに最適なのは、日次で定期的にエントリするキャンバス、およびイベントトリガーやAPIトリガーのキャンバスで、日次のユーザーエントリが比較的安定しているものです。単発送信のキャンバスや、エントリが急増する「スパイク型」のキャンバス（月次の定期実行など）でContent Optimizerを使用する場合は、[エントリコントロール]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas#selecting-entry-controls)を使用して、数日間にわたってユーザーエントリを分散させることを検討してください。

### 主要な概念 {#key-concepts}

| 用語                    | 説明 |
|-------------------------|-------------|
| ベースメッセージ   | すべての送信設定を含む、バリアントのもととなるメインのメッセージテンプレートです。 |
| コンテンツコンポーネント  | メッセージ内の要素（件名やプライマリCTAなど）で、テストや最適化が可能です。マーケターは、コンポーネントを表示させたい場所にメッセージ内で関連するLiquidタグを挿入する必要があります。 |
| コンテンツバリアント    | コンテンツコンポーネントが取りうるさまざまな値です。 |
| コンテンツの組み合わせ | コンテンツバリアントを組み合わせて作成されるユニークなメッセージです。 |
| 最適化イベント       | Content Optimizerがパフォーマンスを評価し、時間の経過とともにコンテンツの組み合わせにトラフィックを配分する方法を決定します（メールのクリックや開封など）。ステップ内のすべてのコンテンツコンポーネントに適用されます。Content Optimizerはこのイベントから継続的に学習し、より高いパフォーマンスのコンテンツの組み合わせに自動的に配信を移行します。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="主要な概念" }

## 考慮事項 {#considerations}

- コンテンツオプティマイザーは現在ベータ版であり、メール、プッシュ通知、SMS/MMS/RCSメッセージのチャネルでのみ利用できます。
- メールの場合、コンテンツオプティマイザーはステップごとに最大125の組み合わせを生成できます。
   - ステップごとに最大3つのコンポーネント
   - 各コンポーネントごとに最大5つのバリアント
- プッシュ通知の場合、コンテンツオプティマイザーはステップごとに最大25の組み合わせを生成できます。
   - ステップごとに最大2つのコンポーネント
   - 各コンポーネントごとに最大5つのバリアント
- SMS、MMS、RCSメッセージの場合、コンテンツオプティマイザーはステップごとに最大25の組み合わせを生成できます。
   - ステップごとに最大2つのコンポーネント
   - 各コンポーネントごとに最大5つのバリアント
- エントリごとにユーザーあたり1つのメッセージのみが送信されます。再エントリ時に過去の送信履歴は保持されません。
- マーケターは、定義したコンテンツコンポーネントのバリアントがレンダリングされるべき箇所に、メッセージ作成画面で各コンポーネントのLiquidタグを手動で挿入する必要があります。
