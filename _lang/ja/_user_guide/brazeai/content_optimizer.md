# コンテンツオプティマイザー {#content-optimizer}

> コンテンツオプティマイザーは、AIを活用して大量のコンテンツバリアントを自動生成・評価し、メッセージコンテンツを大規模にテスト・最適化するエージェントです。

{% alert important %}
コンテンツオプティマイザーは現在ベータ版であり、メール、プッシュ通知、SMS/MMS/RCSメッセージのチャネルでのみ利用可能です。利用開始に関するサポートが必要な場合は、カスタマーサクセスマネージャーにお問い合わせください。
{% endalert %}

## コンテンツオプティマイザーについて {#about-content-optimizer}

コンテンツオプティマイザーは、キャンバスステップ内で動作するエージェントです。テスト対象のメッセージコンポーネントを定義し、生成AIや手動入力でバリアントを生成し、ユーザーに送信するコンテンツの組み合わせを自動的に最適化します。この機能により、以下のことが可能になります。

- メールの件名、本文ヘッダー、本文コンテンツ、または主要なCTAを最適化する。
- プッシュ通知のタイトルとメッセージを最適化する。
- SMS、MMS、RCSメッセージのフック、本文、CTAを最適化する。
- 手動でのA/Bテスト設定なしに、メッセージのパフォーマンスを継続的に改善する。
- AIを活用したアイデア創出により、大量のコンテンツバリアントを迅速にテストする。
- パフォーマンスの低いコンテンツを自動的に段階的に廃止し、成果の高いコンテンツを拡大する。

[コンテンツオプティマイザーステップ]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/content_optimizer_step/)の作成方法をご覧ください。

## ユースケース {#use-cases}

### メール {#email}

| 最適化のユースケース | 目標 | 説明 |
| --- | --- | --- |
| 件名のバリエーション | 開封率の向上 | トーン、緊急性、パーソナライゼーション、絵文字の使用をテストします。 |
| ヘッダーのメッセージングスタイル | エンゲージメントの向上 | 本文ヘッダーにおける感情に訴えるメッセージング、価値を重視したメッセージング、明確なメッセージングを比較します。 |
| 本文コンテンツの形式 | 読みやすさとエンゲージメントの向上 | ストーリーテリングと機能リスト、箇条書きと段落、コンテンツの長さをテストします。 |
| CTAのコピーとトーン | クリックスルーの向上 | アクションを促す表現、利益を強調する表現、一人称のCTA表現を比較します。 |
| テーマ別コンテンツの組み合わせ | パフォーマンスの高い組み合わせの発見 | テーマに沿った件名、本文、CTAのコンポーネントを組み合わせて、最適な全体的組み合わせを見つけます。 |

## 仕組み {#how-it-works}

コンテンツオプティマイザーは、非文脈的な[マルチアームドバンディット](https://en.wikipedia.org/wiki/Multi-armed_bandit)アルゴリズムを使用して、高パフォーマンスのバリアントへの配信を増やし、低パフォーマンスのバリアントへの配信を減らします。時間の経過とともに、手動での介入を最小限に抑えながら、メッセージコンテンツの継続的な改善が実現されます。

Brazeの独自バンディット最適化アルゴリズムは、コンテンツオプティマイザーステップの組み合わせ的性質に特化して構築されています。各メッセージは複数のコンポーネントで構成されているため、バンディットは各コンポーネント（件名、本文、CTAなど）のパフォーマンスと、それらを組み合わせてメッセージにした際の相互作用を同時に学習します。より具体的には、ある組み合わせが送信されると、同じコンポーネントを共有するすべての組み合わせがその送信データの恩恵を受けます。これにより、標準的なバンディットアルゴリズムと比較して、同じ量のデータでバンディットがはるかに速く学習できるようになります。

ステップが最初に起動すると、コンテンツオプティマイザーは初期のパフォーマンスデータを収集するために、バリアントをランダムに送信します。この初期の探索期間の後、アルゴリズムはパフォーマンスの高いコンテンツの組み合わせへトラフィックをシフトし始め、パフォーマンスの低い選択肢への割り当てを徐々に減らしていきます。探索期間中は、アルゴリズムが相対的なパフォーマンスから学習できるよう、トラフィックは一般的に利用可能なバリアント全体に分散されます。

コンテンツオプティマイザーは、キャンバスのメッセージステップに似ており、サイレント時間帯、[インテリジェントタイミング]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_timing/)、イベントログ記録などの機能を備えています。コンテンツオプティマイザーステップを設定するには、ベースメッセージを作成し、最適化するコンテンツコンポーネント（件名、本文テキスト、行動喚起など）を定義します。各コンポーネントのバリアントはAIで生成するか手動で入力でき、ベースメッセージにLiquidタグを追加してコンポーネントをメッセージコンテンツにマッピングする必要があります。

各ユーザーは、コンテンツオプティマイザーステップへのエントリごとに1通のメッセージを受け取ります。再エントリは新規として扱われ、以前のバリアントに関する記憶は保持されません。

## キャンバスのエントリ設定 {#canvas-entry-setup}

最良の結果を得るには、ユーザーが段階的かつ定期的にステップに入るキャンバスでコンテンツオプティマイザーを使用してください。例えば、毎日一定のボリュームがある定期的なキャンバスや常時稼働のキャンバスが該当します。すべてのユーザーが一斉にステップに入ると、エージェントは初期の結果から学習する時間がなくなります。その場合、ステップはライブ最適化エンジンというよりも、静的なA/Bテストに近い動作をします。

コンテンツオプティマイザーに最適なのは、毎日の定期エントリキャンバス、およびイベントトリガーやAPIトリガーで比較的安定した日次ユーザーエントリがあるキャンバスです。単発送信キャンバスやエントリが集中する「スパイク型」キャンバス（月次の定期送信など）でコンテンツオプティマイザーを使用する場合は、[エントリコントロール]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas/#selecting-entry-controls)を使用して、ユーザーのエントリを複数日にわたって分散させることを検討してください。

### 主要な概念 {#key-concepts}

| 用語                    | 説明 |
|-------------------------|-------------|
| ベースメッセージ   | すべての送信設定を含む、バリアントの基盤となるメインメッセージテンプレートです。 |
| コンテンツコンポーネント  | メッセージ内の要素（件名や主要なCTAなど）で、テストや最適化が可能です。マーケターは、コンポーネントを表示すべき箇所に関連するLiquidタグをメッセージに挿入する必要があります。 |
| コンテンツバリアント    | コンテンツコンポーネントが取り得るさまざまな値です。 |
| コンテンツの組み合わせ | コンテンツバリアントを組み合わせて作成されるユニークなメッセージです。 |
| 最適化イベント       | コンテンツオプティマイザーがパフォーマンスを評価し、時間の経過とともにコンテンツの組み合わせにトラフィックを割り当てる方法を決定します（メールのクリック数や開封数など）。ステップ内のすべてのコンテンツコンポーネントに適用されます。コンテンツオプティマイザーはこのイベントから継続的に学習し、パフォーマンスの高いコンテンツの組み合わせに向けて配信を自動的にシフトします。 |

## 考慮事項 {#considerations}

- コンテンツオプティマイザーは現在ベータ版であり、メール、プッシュ通知、SMS/MMS/RCSメッセージのチャネルでのみ利用可能です。
- メールの場合、エージェントは1ステップあたり最大125通りの組み合わせを生成できます。
   - 1ステップあたり最大3つのコンポーネント
   - 各コンポーネントにつき最大5つのバリアント
- プッシュ通知の場合、エージェントは1ステップあたり最大25通りの組み合わせを生成できます。
   - 1ステップあたり最大2つのコンポーネント
   - 各コンポーネントにつき最大5つのバリアント
- SMS、MMS、RCSメッセージの場合、エージェントは1ステップあたり最大25通りの組み合わせを生成できます。
   - 1ステップあたり最大2つのコンポーネント
   - 各コンポーネントにつき最大5つのバリアント
- ユーザーごとにエントリあたり1通のメッセージのみ送信されます。再エントリ時の過去の送信記録は保持されません。
- マーケターは、定義されたコンテンツコンポーネントのバリアントを表示すべきメッセージ作成画面内の各コンポーネントに、手動でLiquidタグを挿入する必要があります。
