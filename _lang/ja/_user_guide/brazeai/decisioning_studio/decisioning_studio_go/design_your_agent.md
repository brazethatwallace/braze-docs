# エージェントの設計 {#design-your-agent}

> この記事では、Decisioning Studio Goエージェントの設計方法について説明します。オーディエンスの定義、ディメンションの選択、Go固有の機能と制限事項の理解を含みます。

意思決定エージェントに関する基礎概念（成功指標、ディメンション、アクションバンク、制約など）については、[意思決定エージェントの設計]({{site.baseurl}}/user_guide/brazeai/decisioning_studio/design_agents)を参照してください。

## GoとProの機能比較 {#go-versus-pro-capabilities}

Decisioning Studio Goは、Decisioning Studio Proと比較して機能が簡素化されたセルフサービスプラットフォームです。これらの違いを理解することで、Goの範囲内で効果的なエージェントを設計できます。

| 機能 | Decisioning Studio Go | Decisioning Studio Pro |
|-----------|----------------------|------------------------|
| **成功指標** | クリックのみ | あらゆるビジネス指標（収益、コンバージョン、またはARPU） |
| **ディメンション** | 限定アクションバンク | 無制限のディメンション |
| **サポートされるCEP** | Braze、SFMC | あらゆるCEP（ネイティブおよびカスタム） |
| **顧客データ** | エンゲージメントのみ | すべての1Pデータ |
| **設定** | セルフサービス | AI意思決定サービスサポート |
| **実験グループ** | Go + ランダムコントロール + オプションのBAU | 完全にカスタマイズ可能 |
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3 aria-label="GoとProの機能比較" }

## Goエージェントの設計 {#design-your-go-agent}

Decisioning Studio Goエージェントを設計する際には、以下の領域で判断を行います。

### ステップ 1: オーディエンスを定義する {#step-1-define-your-audience}

オーディエンスとは、エージェントがエンゲージする顧客の集合です。Goでは、オーディエンスはCEP内で定義されます。

{% tabs %}
{% tab Braze %}

**Brazeでオーディエンスを定義する：**

1. Brazeで、エージェントがターゲットとする顧客を定義するセグメントを作成します。
2. Decisioning Studio Goポータルで実験設定を行う際、このセグメントをターゲットオーディエンスとして選択します。

{% alert tip %}
Decisioning Studio Goの実験用に専用のセグメントを作成することを検討してください。テストを分離し、測定可能な状態に保つことができます。
{% endalert %}

{% endtab %}
{% tab Salesforce Marketing Cloud %}

**SFMCでオーディエンスを定義する：**

1. ターゲットオーディエンスを含むData Extensionを設定します。
2. このData Extensionが最新の顧客データで毎日更新されるようにします。
3. 実験設定時に、Decisioning Studio GoポータルでこのData Extensionを参照します。

{% endtab %}
{% endtabs %}

### ステップ 2: ディメンションを選択する {#step-2-select-your-dimensions}

ディメンションとは、エージェントがカスタマーエクスペリエンスをパーソナライズするために操作できる「レバー」です。件名やヒーロー画像といったクリエイティブディメンションや、メールの頻度や送信時間帯といった送信タイプのディメンションが含まれます。

{% alert note %}
利用可能な具体的なディメンションは、CEPとキャンペーンの設定方法によって異なります。CEPで設定したテンプレートとコンテンツを使って作業してください。
{% endalert %}

### ステップ 3: アクションバンクを設定する {#step-3-configure-your-action-bank}

アクションバンクは、各ディメンションにおいてエージェントが選択できる具体的なオプションを定義します。例えば以下のとおりです。

- **メールテンプレート：** エージェントが使用できるテンプレートを選択します（これらはまずCEPで設定しておく必要があります）
- **件名：** エージェントがテストできる件名のバリアントを定義します
- **送信時間：** エージェントが選択できる時間枠を指定します

### ステップ 4: 実験グループを設定する {#step-4-set-up-experiment-groups}

Decisioning Studio Goは自動的に実験グループを作成し、パフォーマンスを測定します。

| グループ | 説明 |
|-------|-------------|
| **Decisioning Studio Go** | AIによって最適化されたおすすめを受け取る顧客 |
| **ランダムコントロール** | ランダムに選択されたオプションを受け取る顧客（ベースライン比較） |
| **通常運用（オプション）** | 既存のキャンペーンを受け取る顧客（現在のパフォーマンスと比較する場合） |
{: .reset-td-br-1 .reset-td-br-2 aria-label="ステップ 4: 実験グループを設定する" }

{% alert important %}
正確な比較のためには、顧客が複数の実験グループに属さないようにし、顧客が偏りなくランダムにグループに割り当てられるようにしてください。
{% endalert %}

## 考慮すべき制限事項 {#limitations-to-consider}

Goエージェントを設計する際には、以下の制限事項を念頭に置いてください。

- **クリックのみ：** Goはクリックスルー率を最適化します。収益やコンバージョン、その他のビジネス指標を最適化する必要がある場合は、Decisioning Studio Proを検討してください。
- **限定されたディメンション：** Goはあらかじめ定義された一連のディメンションをサポートしています。カスタムディメンションや複雑なパーソナライゼーションが必要な場合は、Decisioning Studio Proを検討してください。
- **限定されたCEPサポート：** GoはBrazeとSalesforce Marketing Cloudとのみ連携します。他のプラットフォームについては、Decisioning Studio Proを検討してください。

## ベストプラクティス {#best-practices}

- **まずは狭い範囲から始める：** 2〜3個のテンプレートや件名のバリアントから始めてください。エージェントが学習するための十分な選択肢を得つつ、実験を管理可能な状態に保つことができます。
- **時間をかける：** エージェントは学習するのに十分なデータが必要です。パフォーマンスについて結論を出す前に、少なくとも2〜4週間は待ってください。
- **コンテンツを多様に保つ：** 選択肢が意味のある違いを持つようにしてください。些細な差異をテストしても、重要なインサイトは得られない可能性があります。
- **定期的にモニタリングする：** Decisioning Studio Goポータルを確認し、実験の進捗状況とエンゲージメント指標をモニタリングしてください。
