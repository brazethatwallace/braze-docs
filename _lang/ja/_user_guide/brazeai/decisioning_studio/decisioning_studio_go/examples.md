# Decisioning Studio Goの例 {#examples-for-decisioning-studio-go}

> Decisioning Studio Goは、エージェントがエンゲージメントから学習する時間があり、コンテンツに意味のあるパーソナライゼーションを行うのに十分なバリアントオプションが含まれている、定期的なメールプログラムに最適です。このページでは、一般的なメールのユースケースを適合度別にグループ化し、それぞれの例とガイダンスを紹介します。

Decisioning Studio Goの仕組みの概要については、[BrazeAI Decisioning Studio Go]({{site.baseurl}}/user_guide/brazeai/decisioning_studio/decisioning_studio_go)を参照してください。

このガイドの各例には、以下のいずれかの適合度が付けられています。

| 適合度 | 説明 |
|---|---|
| **最適** | エージェントが学習するのに十分な時間があり、オーディエンスがリフトを示すのに十分安定しており、パーソナライゼーションがエンゲージメントに意味のある影響を与えることができます。ここから始めてください。 |
| **対応可能** | この例はうまく機能する可能性がありますが、成功はタイミング、オーディエンスサイズ、またはシーケンスに依存します。コミットする前に考慮事項を確認してください。 |
| **非推奨** | この例はエージェントの学習方法と相反します。別のプログラムタイプを選択するか、カスタマーサクセスマネージャーまたはソリューションコンサルタントに別の設定について相談してください。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="適合度" }

{% alert note %}
すべての適合度において、エージェントはオーディエンスがアルゴリズムでパターンを検出するのに十分なエンゲージメントシグナルを生成する場合に最もよく学習します。目安として、数万人以上のユーザーをターゲットにし、毎週一貫した送信量を維持してください。エージェントはより小さなオーディエンスでも実行できますが、学習期間が長くなり、リフトの信頼性が低くなることが予想されます。カスタマーサクセスマネージャーまたはソリューションコンサルタントが、特定のオーディエンスのサイズが適切かどうかの確認をお手伝いします。
{% endalert %}

## 最適なユースケース {#best-fit}

### 常時配信カレンダーキャンペーン {#always-on-calendared-campaigns}

| トピック | 詳細 |
|---|---|
| どのようなものか | 数か月以上にわたって運用されるマーケティングカレンダーで、時間の経過とともにコンテンツが入れ替わります。例えば、リワード会員カレンダー、コンテンツドロップスケジュール、ライフスタイルやインスピレーションカレンダーなどです。 |
| なぜ適しているか | 長期運用のプログラムでは、エージェントがさまざまなユーザーに対して何が効果的かを学習する時間があります。オーディエンスは安定しており、コンテンツは定期的に更新され、クリックは通常エンゲージメントの有意な指標となります。 |
| 必要なもの | ローテーションに使用できる複数のベースクリエイティブまたはバリアントセット。エージェントは各ユーザーに最適なバージョンを選択しますが、提供するオプションに十分なバリエーションが必要です。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="常時配信カレンダーキャンペーン" }

### エバーグリーンプログラム {#evergreen-programs}

| トピック | 詳細 |
|---|---|
| どのようなものか | 特定の日付やイベントに紐づかない継続的なキャンペーンです。ウィンバック、再エンゲージメントプログラム、休止状態アカウントへのナッジ、マイルストーンのお祝いなどがあります。 |
| なぜ適しているか | カレンダーキャンペーンと同様に、オーディエンスはダイナミックですが、プログラムは無期限に継続します。エージェントには学習する時間があり、コンテンツには柔軟性があり、クリックはエージェントが最適化に活用できる先行指標です。 |
| 必要なもの | さまざまな動機に合わせてメッセージを構成する件名やCTAのバリアントオプション。画像バリアントがあればさらに効果的です。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="エバーグリーンプログラム" }

## サポートされるユースケース {#supported-use-cases}

### マルチメールプロモーション {#multi-email-promotions}

| トピック | 詳細 |
|---|---|
| どのようなものか | 同じプロモーションテーマのもとで数週間にわたって送信される一連のメール。たとえば、新学期シリーズや数週間にわたるカテゴリプロモーションなどです。 |
| なぜ効果的か | プロモーションが十分に長い期間（少なくとも数週間）にわたって実施される場合、エージェントにはプロモーション内で学習するための時間があります。クリックスルーは通常、プロモーションエンゲージメントの強力な先行指標です。 |
| 考慮事項 | 短期のプロモーションでは、プログラムが終了する前にエージェントが学習するための十分なデータ日数がない場合があります。一般的なガイドラインとして、エージェントが強力なレコメンデーションを開発するには、少なくとも10キャンペーン日が必要です。プロモーションがそれより短い場合は、代わりにエバーグリーンプログラムで学習を蓄積し、そこで得た知見を次のプロモーションに活用することを検討してください。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="マルチメールプロモーション" }

### アクションまたはイベントドリブンジャーニー {#action-or-event-driven-journeys}

| トピック | 詳細 |
|---|---|
| どのようなものか | 顧客のアクションによってトリガーされる単一のメールまたはシーケンス。カート放棄、閲覧放棄、購入後のフォローアップなどがあります。 |
| なぜ効果的か | トリガーにより明確なエントリポイントが作成されます。ジャーニーが繰り返し発生し、オーディエンスボリュームが一定であれば、エージェントはどのコンテンツがどのユーザーに効果的かを学習できます。 |
| 考慮事項 | タイミングが重要です。トリガーイベントから数分以内にメールを送信する必要がある場合は、カスタマーサクセスマネージャーまたはソリューションコンサルタントに連絡して、エージェントの送信スケジュールに互換性があることを確認してください。ユーザーが特定の順序でメールを受信する必要がある場合（メールAの後にメールB）、オーディエンスの移動は自分でオーケストレーションする必要があります。エージェントは、マルチメールジャーニー全体で単一ユーザーへの送信をシーケンス化することはしません。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="アクションまたはイベントドリブンジャーニー" }

## 推奨されないケース {#not-recommended}

### ドリップシーケンス {#drip-sequences}

| トピック | 詳細 |
|---|---|
| どのようなものか | 複数メールのシーケンス（例：オンボーディングチュートリアル）で、ユーザーがメールA、メールB、メールCの順番で受信する必要があるもの。 |
| 適さない理由 | エージェントは、各ユーザーに対してクリックを促す可能性が高いものに基づいて送信内容を選択します。シーケンスの要件をモデル化することはできません。特定の順序を強制する必要がある場合は、オーディエンスを自分で調整する必要があり（各メール送信後にユーザーをセグメントからセグメントに移動させる）、エージェントを使用するメリットの大部分が失われます。また、エージェントはメールBを送信する前にメールAが成功したかどうかを独自に確認することもできません。 |
| 代わりにすべきこと | [キャンバス]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas)を使用してドリップを調整します。ドリップ内でAI最適化が必要な場合は、[Decisioning Studio Pro]({{site.baseurl}}/user_guide/brazeai/decisioning_studio/get_started)がより適しているかどうか、カスタマーサクセスマネージャーまたはソリューションコンサルタントにご相談ください。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="ドリップシーケンス" }

### 一斉メール配信 {#one-time-email-blasts}

| トピック | 詳細 |
|---|---|
| どのようなものか | 一度に一斉送信される単一のメール（ブラックフライデーの告知、新製品のローンチ、一回限りの企業コミュニケーションなど）。 |
| 適さない理由 | エージェントには学習するための時間が必要です。一度きりの送信では、キャンペーンが終了する前に意思決定を改善する機会がありません。より良い選択を行うための十分なエンゲージメントシグナルが得られる頃には、プログラムは終了しています。 |
| 代わりにすべきこと | 類似のコンテンツを持つ常時稼働のプログラムがある場合（例：通年の製品告知プログラム）は、そこでDecisioning Studio Goを使用し、学んだことを一回限りの送信に活用します。一回限りの送信には、ABテスト用の[BrazeAI<sup>TM</sup>で最適化]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/variant_selection)を使用してください。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="一斉メール配信" }

## 概要 {#at-a-glance}

| シナリオ | 適合度 | 主な考慮事項 |
|---|---|---|
| 常時稼働のカレンダーベースキャンペーン | 最適 | 時間の経過とともにリフレッシュできるよう、複数のベースクリエイティブまたはバリアントセットを用意してください。 |
| エバーグリーンプログラム（ウィンバック、再エンゲージメント） | 最適 | 同じメッセージを異なるモチベーションに合わせてフレーミングするバリアントオプションを用意してください。 |
| 複数メールのプロモーション | 対応可能 | 少なくとも10キャンペーン日分の期間を確保してください。短いプロモーションでは学習が制限されます。 |
| アクションまたはイベント駆動型ジャーニー | 対応可能 | 送信タイミングの要件を確認してください。シーケンスの制御はお客様の責任となります。 |
| ドリップシーケンス（オンボーディングチュートリアル） | 非推奨 | シーケンスにはキャンバスを使用してください。ドリップ内の最適化にはDecisioning Studio Proの活用を再検討してください。 |
| 単発メール配信 | 非推奨 | 代わりにBrazeAI<sup>TM</sup>による最適化をABテストに使用してください。 |
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3 aria-label="シナリオ別の適合度まとめ表" }

## 次のステップ {#next-steps}

プログラムが適しているかどうか不明な場合は、Brazeのカスタマーサクセスマネージャーまたはソリューションコンサルタントにお問い合わせください。適合の強いシグナルには以下が含まれます：

- オーディエンスが定期的にメールを受信している—少なくとも週1回—1か月以上の期間にわたっていること。
- オーディエンスが一貫したエンゲージメントシグナルを生成するのに十分な規模であること（数万人のユーザーが有用な出発点です）。
- 提供できる意味のあるバリアントオプションが少なくとも2〜3つあること（件名、CTA、またはメッセージの見せ方を変える画像など）。
- クリックスルーがこのプログラムにとってビジネス価値の先行指標であり、単なる虚栄の指標ではないこと。
- セグメントが、同じユーザーのエンゲージメントを競合する別のキャンバスやキャンペーンで積極的に使用されていないこと。
