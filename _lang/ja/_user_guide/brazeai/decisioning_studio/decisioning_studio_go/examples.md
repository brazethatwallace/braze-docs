# Decisioning Studio Goの例 {#examples-for-decisioning-studio-go}

> Decisioning Studio Goは、エージェントがエンゲージメントから学習する時間があり、コンテンツに意味のあるパーソナライゼーションを行うのに十分なバリアントオプションが含まれている、定期的なメールプログラムに最適です。このページでは、一般的なメールのユースケースを適合度別にグループ化し、それぞれの例とガイダンスを紹介します。

Decisioning Studio Goの仕組みの概要については、[BrazeAI Decisioning Studio Go]({{site.baseurl}}/user_guide/brazeai/decisioning_studio/decisioning_studio_go)を参照してください。

このガイドの各例には、以下のいずれかの適合度が付けられています。

| 適合度 | 説明 |
|---|---|
| **最適** | エージェントが学習するのに十分な時間があり、オーディエンスがリフトを示すのに十分安定しており、パーソナライゼーションがエンゲージメントに意味のある影響を与えることができます。ここから始めてください。 |
| **対応可能** | この例はうまく機能する可能性がありますが、成功はタイミング、オーディエンスサイズ、またはシーケンスに依存します。コミットする前に考慮事項を確認してください。 |
| **非推奨** | この例はエージェントの学習方法と相反します。別のプログラムタイプを選択するか、カスタマーサクセスマネージャーまたはソリューションコンサルタントに別の設定について相談してください。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="適合度" }

{% alert note %}
すべての適合度において、エージェントはオーディエンスがアルゴリズムでパターンを検出するのに十分なエンゲージメントシグナルを生成する場合に最もよく学習します。目安として、数万人以上のユーザーをターゲットにし、毎週一貫した送信量を維持してください。エージェントはより小さなオーディエンスでも実行できますが、学習期間が長くなり、リフトの信頼性が低くなることが予想されます。カスタマーサクセスマネージャーまたはソリューションコンサルタントが、特定のオーディエンスのサイズが適切かどうかの確認をお手伝いします。
{% endalert %}

## 最適 {#best-fit}

### 常時稼働のカレンダーキャンペーン {#always-on-calendared-campaigns}

| トピック | 詳細 |
|---|---|
| どのようなものか | 数か月以上にわたって実行され、コンテンツが随時入れ替えられるマーケティングカレンダーです。例えば、報酬メンバーカレンダー、コンテンツドロップスケジュール、ライフスタイルやインスピレーションカレンダーなどがあります。 |
| なぜ適しているか | 長期間のプログラムにより、エージェントはさまざまなユーザーに何が効果的かを学習する時間を得られます。オーディエンスは安定しており、コンテンツは定期的に更新され、クリックは通常エンゲージメントの意味のある指標となります。 |
| 用意するもの | ローテーションに使用できる複数のベースクリエイティブまたはバリアントセット。エージェントは各ユーザーに最適なバージョンを選択しますが、提供するオプションに十分な多様性が必要です。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="常時稼働のカレンダーキャンペーン" }

### エバーグリーンプログラム {#evergreen-programs}

| トピック | 詳細 |
|---|---|
| どのようなものか | 特定の日付やイベントに紐づかない継続的なキャンペーンです。ウィンバック、再エンゲージメントプログラム、休止状態アカウントへのナッジ、マイルストーンのお祝いなどがあります。 |
| なぜ適しているか | カレンダーキャンペーンと同様に、オーディエンスはダイナミックですがプログラムは無期限に実行されます。エージェントは学習する時間があり、コンテンツには柔軟性があり、クリックはエージェントが最適化できる先行指標です。 |
| 用意するもの | さまざまな動機に合わせてメッセージを構成する件名とCTAのバリアントオプション。画像バリアントがあれば役立ちます。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="エバーグリーンプログラム" }

## 対応可能なユースケース {#supported-use-cases}

### 複数メールのプロモーション {#multi-email-promotions}

| トピック | 詳細 |
|---|---|
| どのようなものか | 同じプロモーションテーマのもとで数週間にわたって送信される一連のメールです。例えば、新学期シリーズや数週間にわたるカテゴリプロモーションなどがあります。 |
| なぜ機能するか | プロモーションが十分に長く（少なくとも数週間）実行される場合、エージェントはプロモーション内で学習する余地があります。クリックスルーは通常、プロモーションエンゲージメントの強力な先行指標です。 |
| 考慮事項 | 短いプロモーションの場合、プログラムが終了する前にエージェントが学習するのに十分なデータ日数がない可能性があります。一般的なガイドラインとして、エージェントが強力なレコメンデーションを開発するには少なくとも10キャンペーン日が必要です。プロモーションがそれより短い場合、エバーグリーンプログラムで学習を蓄積し、その学びを次のプロモーションに適用することを検討してください。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="複数メールのプロモーション" }

### アクションまたはイベント駆動型ジャーニー {#action-or-event-driven-journeys}

| トピック | 詳細 |
|---|---|
| どのようなものか | 顧客のアクションによってトリガーされる単一のメールまたはシーケンスです。カート放棄、閲覧放棄、購入後のフォローアップなどがあります。 |
| なぜ機能するか | トリガーはクリーンなエントリポイントを作成します。ジャーニーが繰り返し発生し、オーディエンスのボリュームが一貫している場合、エージェントはどのコンテンツがどのユーザーに効果的かを学習できます。 |
| 考慮事項 | タイミングが重要です。トリガーイベントから数分以内にメールを送信する必要がある場合は、カスタマーサクセスマネージャーまたはソリューションコンサルタントに相談して、エージェントの送信スケジュールに互換性があるか確認してください。ユーザーが特定の順序でメールを受信する必要がある場合（メールAの後にメールB）、オーディエンスの移動を自分で管理する必要があります。エージェントは複数メールのジャーニーにおいて単一ユーザーの送信をシーケンス化しません。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="アクションまたはイベント駆動型ジャーニー" }

## 非推奨 {#not-recommended}

### ドリップシーケンス {#drip-sequences}

| トピック | 詳細 |
|---|---|
| どのようなものか | 複数メールのシーケンスです。例えば、オンボーディングチュートリアルで、ユーザーがメールA、次にメールB、次にメールCの順序で受信する必要があるものです。 |
| なぜ適さないか | エージェントは、各ユーザーにクリックを促す可能性が高いものに基づいて送信内容を選択します。シーケンス要件をモデル化しません。特定の順序を強制する必要がある場合、オーディエンスを自分で管理する必要があり（各メール後にセグメントからセグメントへユーザーを移動）、エージェントを使用するメリットの大部分が失われます。また、エージェントはメールBを送信する前にメールAが成功したことを独立して確認することもできません。 |
| 代わりにすべきこと | [キャンバス]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas)を使用してドリップを管理してください。ドリップ内でAI最適化を行いたい場合は、[Decisioning Studio Pro]({{site.baseurl}}/user_guide/brazeai/decisioning_studio/get_started)がより適しているかどうか、カスタマーサクセスマネージャーまたはソリューションコンサルタントに相談してください。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="ドリップシーケンス" }

### 一斉送信メール {#one-time-email-blasts}

| トピック | 詳細 |
|---|---|
| どのようなものか | 一度に送信される単一のメールです。ブラックフライデーのお知らせ、新製品のローンチ、一回限りの企業コミュニケーションなどがあります。 |
| なぜ適さないか | エージェントには学習する時間が必要です。単一の送信では、キャンペーンが終了する前に判断を改善する機会がありません。より良い選択を行うのに十分なエンゲージメントシグナルを得る頃には、プログラムは終了しています。 |
| 代わりにすべきこと | 類似のコンテンツを持つエバーグリーンプログラムがある場合（例えば、年間を通じた製品アナウンスプログラム）、そこでDecisioning Studio Goを使用し、学んだことを一回限りの送信に適用してください。本当に一回限りの一斉送信の場合は、[ABテスト]({{site.baseurl}}/user_guide/messaging/ab_testing)または[インテリジェントセレクション]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_selection)がより適しています。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="一斉送信メール" }

## 一覧 {#at-a-glance}

| シナリオ | 適合度 | 主な考慮事項 |
|---|---|---|
| 常時稼働のカレンダーキャンペーン | 最適 | 時間の経過とともに更新できる複数のベースクリエイティブまたはバリアントセットを用意してください。 |
| エバーグリーンプログラム（ウィンバック、再エンゲージメント） | 最適 | さまざまな動機に合わせて同じメッセージを構成するバリアントオプションを用意してください。 |
| 複数メールのプロモーション | 対応可能 | 少なくとも10キャンペーン日の余地を目指してください。短いプロモーションは学習を制限します。 |
| アクションまたはイベント駆動型ジャーニー | 対応可能 | 送信タイミングの要件を確認してください。シーケンスの強制はお客様の責任です。 |
| ドリップシーケンス（オンボーディングチュートリアル） | 非推奨 | シーケンス管理にはキャンバスを使用してください。ドリップ内の最適化にはDecisioning Studio Proを再検討してください。 |
| 一斉送信メール | 非推奨 | 代わりにABテストまたはインテリジェントセレクションを使用してください。 |
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3 aria-label="例のサマリーテーブル" }

## 次のステップ {#next-steps}

お客様のプログラムが適しているかどうか不明な場合は、Brazeのカスタマーサクセスマネージャーまたはソリューションコンサルタントにお問い合わせください。適合の強いシグナルには以下が含まれます。

- オーディエンスが1か月以上の期間にわたって、少なくとも毎週メールを受信していること。
- 一貫したエンゲージメントシグナルを生成するのに十分な規模のオーディエンスであること（数万人のユーザーが有用な出発点です）。
- 少なくとも2〜3の意味のあるバリアントオプションを提供できること（件名、CTA、またはメッセージを異なる形で構成する画像）。
- クリックがこのプログラムのビジネス価値の先行指標であり、単なるバニティメトリクスではないこと。
- セグメントが、同じユーザーのエンゲージメントを競合する別のキャンバスやキャンペーンで積極的に使用されていないこと。
