# よくある質問 {#frequently-asked-questions}

## 一般 {#general}

### Decisioning Studio Goとは何ですか？ {#what-is-decisioning-studio-go}

Decisioning Studio Goは、Brazeダッシュボードに組み込まれたAI意思決定エージェントです。クリエイティブバリアント、送信タイミング、曜日などのオプションメニューをキュレートすると、エージェントがクリックを最適化するために各ユーザーに最適な組み合わせを選択します。データサイエンティストやカスタムインテグレーションを必要とせずに、1対1のパーソナライゼーションを実現します。最初のリリースではメールをサポートしており、追加チャネルは個別のベータ版で順次対応し、各チャネルは独自のエージェントによって処理されます。

### ABテストとの違いは何ですか？ {#how-is-this-different-from-ab-testing}

ABテストは、オーディエンス全体またはセグメント内で平均的に最もパフォーマンスの高いバリアントを見つけ、そのグループ全員にその1つのバリアントを展開します。Decisioning Studio Goは、各ユーザーが過去にエンゲージした内容に基づいて、個々のユーザーに最適なバリアントを選択します。同じ送信で異なるユーザーが異なるバリアントを受信できます。グループに1つの勝者バリアントを展開する代わりに、Decisioning Studio Goは個人レベルでコンテンツをパーソナライズします。

### Decisioning Studio Proとの違いは何ですか？ {#how-is-this-different-from-decisioning-studio-pro}

Goはセルフサーブティアです。大がかりな実装なしに1対1のメールパーソナライゼーションを実現したいマーケター向けの最適な出発点です。クリックを最適化し、Braze内で直接設定したオプションで動作します。

Proはサービス全般を取り扱うティアです。あらゆるビジネス指標に対して最適化し、あらゆるファーストパーティデータソースに接続し、複数チャネルをサポートし、Braze AI Decisioning Servicesチームによる専任サポートが付属します。

### これはどのような種類のAIですか？生成AIですか？ {#what-kind-of-ai-is-this-is-it-generative}

いいえ。各ユーザーに何を送信するかを決定するエージェントは意思決定エージェントであり、生成エージェントではありません。コンテンツを自動生成することはありません。オプションを提供すると、エージェントが各ユーザーに最適なオプションを学習します。

Decisioning Studio Goは強化学習に基づいて構築されています。エージェントは各送信を学習の機会として扱い、承認されたオプションの組み合わせを試し、各ユーザーがエンゲージしたかどうかを観察し、誰に何が効果的かの理解を更新します。時間の経過とともに、メニューの中からクリックを促す可能性が最も高いオプションを各ユーザーにマッチングする精度がますます向上します。

## オーディエンスとコントロールグループ {#audiences-and-control-groups}

### Decisioning Studioグループとランダムコントロールグループの違いは何ですか？ {#whats-the-difference-between-the-decisioning-studio-group-and-the-random-control-group}

Decisioning Studioグループは、AIで最適化されたメールコンテンツを受信します。エージェントが各ユーザーに最適なバリアントを選択します。ランダムコントロールグループは、最適化なしで同じオプションのランダムな組み合わせを受信します。両方のグループは設定した制約を遵守します（例えば、15日以内に件名を繰り返さないと設定した場合、そのルールはランダムコントロールにも適用されます）。2つのグループを比較することで、エージェントのリフトを正確に測定できます。

### ランダムコントロールはメールを受信しないユーザーのホールドアウトグループですか？ {#is-the-random-control-a-holdout-group-of-users-who-receive-no-email}

いいえ。ランダムコントロールのユーザーもメールを受信します。設定したオプションからランダムに選択された組み合わせが、スケジュール内のランダムに選択された日に送信されます。これにより、「メールなし」ではなく、「AIでパーソナライズされたコンテンツ」と「同じコンテンツをランダムに送信した場合」を比較できます。

### ランダムコントロールが必須なのはなぜですか？ {#why-is-the-random-control-required}

理由は2つあります。第一に、エージェントがランダムベースラインをどれだけ上回っているかをリアルタイムで継続的に測定できます。第二に、エージェントはランダムコントロールの行動を学習シグナルの一部として使用します。ランダムコントロールの最小サイズは5%です。これは、エージェントが確実に学習し、パフォーマンス測定が有意義であるために必要な最低限の値です。

### 別のキャンバスやキャンペーンで既に使用されているセグメントを使用できますか？ {#can-i-use-a-segment-thats-already-used-in-another-canvas-or-campaign}

使用できますが、強く推奨されず、警告が表示されます。同じユーザーがDecisioning Studio Goと他のキャンバスやキャンペーンから同時にメッセージを受信すると、他のメッセージがエージェントでは考慮できない形でエンゲージメントに影響を与えます。最もクリーンな設定は、エージェント専用のセグメントを使用することです。

## 設定 {#configuration}

### 何をパーソナライズできますか？ {#what-can-i-personalize}

各ベースクリエイティブ内で、Liquidタグを使用して件名、CTA、画像をパーソナライゼーションポイントとしてマークできます。エージェントは、各コンポーネントに対して提供したバリアントの中から、ユーザーごとに選択します。複数のベースクリエイティブを用意することもでき、エージェントはどのベースクリエイティブを使用するかも選択します。

### パーソナライズされたコンポーネントにContent Blocksを使用できますか？ {#can-i-use-content-blocks-for-the-personalized-components}

いいえ。現時点では、Content Blocksはクリエイティブコンポーネントの置換ポイントとして機能しません。パーソナライズされた件名、CTA、画像は、コンテンツブロック内ではなく、メール本文に直接配置してください。

### クリック可能な要素のない画像ベースのテンプレートを使用できますか？ {#can-i-use-image-based-templates-with-no-clickable-elements}

画像ベースのテンプレートはサポートされていますが、エージェントが最適化できる範囲が制限されます。メール全体が1つの画像の場合、エージェントはどの画像を送信するかを決定できますが、メール内の件名、CTA、レイアウトを最適化することはできません。複数のパーソナライゼーションポイントを持つHTMLベースのテンプレートを使用すると、より大きなリフトが得られます。

### コンバージョンイベントを変更できますか？ {#can-i-change-the-conversion-event}

セルフサーブティアでは、サポートされるコンバージョンイベントはクリックです。Decisioning Studio Proでは、任意のカスタムビジネス指標に対して最適化できます。

### 送信頻度はどのように機能しますか？ {#how-does-send-frequency-work}

週3回の送信など、単一の頻度を選択します。エージェントは頻度間の選択は行いません。その頻度の範囲内で、許可した曜日の中からどの日に送信するか、またユーザーのローカルタイムゾーンでのサイレントアワー内のどの時間に送信するかを選択します。

### フリークエンシーキャップはどのように機能しますか？ {#how-do-frequency-caps-work}

設定時に、ワークスペースのフリークエンシーキャップルールをエージェントに適用し、エージェントの送信を各ユーザーのグローバルフリークエンシーキャップにカウントするかどうかを選択できます。ワークスペースでのフリークエンシーキャップの設定状況に基づいて、プログラムに適したアプローチを決定するために、カスタマーサクセスマネージャーまたはソリューションコンサルタントにご相談ください。

### エージェントは複数のチャネルで送信できますか？ {#can-the-agent-send-across-multiple-channels}

各エージェントはシングルチャネルであり、現在サポートされているチャネルはメールです。異なるプログラム用に複数のエージェントを並行して実行できますが、各エージェントは1つのチャネルを処理します。

## テストとローンチ {#testing-and-launch}

### 本番稼働前にどのようにテストしますか？ {#how-do-i-test-before-going-live}

Braze Composerのネイティブテスト送信機能を使用します。テスト送信では、選択した特定のバリアントの組み合わせが表示されます。これはメール自体の校正用であり、エージェントが実際のユーザーに何を送信するかを予測するものではありません。Composerのダイナミックプレビューでも、異なるバリアントの組み合わせがどのようにレンダリングされるかを確認できます。

### ローンチ直後に何が起こりますか？ {#what-happens-right-after-i-launch}

エージェントはトレーニング期間に入ります。メールは待機期間なしに初日から送信されますが、エージェントが組み合わせを探索している間はパフォーマンスが変動する可能性があります。レポートでは、エージェントがまだトレーニング中なのか、アクティブなパーソナライゼーションに移行したのかが示されるため、常にどの段階にあるかを把握できます。

### ローンチ後にエージェントを編集できますか？ {#can-i-edit-the-agent-after-launch}

はい。オーディエンス、スケジュール、クリエイティブ、制約はすべてローンチ後に更新できます。変更を反映するには、プロモートする必要があります。

### ローンチ後にコンテンツオプションを更新するとどうなりますか？ {#what-if-i-update-content-options-after-launch}

最初の設定時と同じ方法で、バリアントの追加、削除、変更ができます。変更を反映するにはプロモートする必要があります。新しいバリアントを追加しても、既存のバリアントに対するエージェントのトレーニングはリセットされません。

## レポートと結果 {#reporting-and-results}

### Decisioning Studio Goのレポートは、Brazeの他のメール分析と一致しますか？ {#does-decisioning-studio-go-reporting-match-what-i-see-in-my-email-analytics-elsewhere-in-braze}

数値が異なる場合があります。Decisioning Studioは標準のメールレポートよりも積極的なクリックフィルタリングを適用するため、合計値が低くなることがあります。Decisioning Studioグループとランダムコントロール間の相対的な比較は、クリックフィルタリングが各グループに均等に適用されるため、Decisioning Studioレポート内で一貫しています。

### エージェントはどの指標を最適化しますか？ {#what-metrics-does-the-agent-optimize-for}

ユーザーあたりの1日のユニーククリック数です。エージェントの目標は、生のクリック量ではなく、クリックするユニークユーザー数を最大化することです。

### どの組み合わせが最もパフォーマンスが高いかを確認できますか？ {#can-i-see-which-combinations-are-performing-best}

はい。レポートには、エージェントが送信する件名、CTA、画像などの個々の要素の分布が含まれます。

### エージェントが送信するコンテンツの責任は誰にありますか？ {#whos-accountable-for-the-content-the-agent-sends}

お客様ご自身です。エージェントは、バリアントとして追加したコンテンツのみを送信します。エージェントは各ユーザーの組み合わせを決定しますが、すべての個々の要素はお客様が提供したバリアントから取得されます。

## サポート {#support}

### エージェントに関するサポートはどこで受けられますか？ {#where-do-i-get-help-with-my-agent}

設定、パフォーマンスレビュー、プログラム設計に関するサポートについては、Brazeのカスタマーサクセスマネージャーまたはソリューションコンサルタントにお問い合わせください。
