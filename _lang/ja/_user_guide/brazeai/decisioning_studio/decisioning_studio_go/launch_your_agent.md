# エージェントを起動する {#launch-your-agent}

> データソースを接続し、オーケストレーションを設定し、エージェントを設計したら、起動の準備は完了です。この記事では、エージェントのアクティブ化とオプションのBAUレポートの設定について説明します。

## 起動ステップ {#launch-steps}

Decisioning Studio Goポータルですべての設定ステップを完了した後：

1. エージェントの設定を確認し、すべての設定が正しいことを確かめます。
2. CEP統合がアクティブであり、オーケストレーションの準備が整っていることを確認します。
3. Decisioning Studio Goポータルで**Launch**（または同等のアクション）を選択して、エージェントをアクティブ化します。

起動すると、エージェントは以下を行います：
- CEPからオーディエンスデータの受信を開始します
- 各顧客向けにパーソナライズされたおすすめを提案し始めます
- 設定済みのCEPを通じて送信をオーケストレーションします
- エンゲージメントデータを収集し、時間をかけて学習・改善します

## BAUレポートを設定する {#set-up-bau-reporting}

デフォルトでは、Decisioning Studio Goポータルのレポートは、Decisioning Studio Goグループとランダムコントロールグループを比較します。既存の通常業務（BAU）キャンペーンと比較したい場合は、BAUレポートを設定することで、3つのグループすべてを一箇所で確認できます。

### BAUレポートの利点 {#benefits-of-bau-reporting}

BAUレポートを設定する主な利点は、Decisioning Studio Goの無効クリックフィルタリングを適用できることです。3つの実験グループすべてに適用することで、以下のノイズを除去し、最も正確かつ公平な（同条件での）クリックパフォーマンス比較が可能になります：
- 機械によるクリックの疑いがあるもの
- 配信停止リンクへのクリック

### BAUレポートの要件 {#requirements-for-bau-reporting}

BAUレポートを設定する前に、BAU処理グループ、Decisioning Studio Goグループ、およびランダムコントロールグループの間で同条件での比較が確実に行われるようにしてください：

- **重複なし：** 実験期間中、どの受信者も複数のグループに属することはできません
- **無作為割当：** 受信者は偏りなくグループに無作為に割り当てられます
- **同等の選択肢：** BAUグループが利用できるあらゆる選択肢（クリエイティブ、頻度、時間、インセンティブ、またはオファー）は、Decisioning Studio Goグループとランダムコントロールグループにも利用可能です

{% alert warning %}
同条件での比較という実験設計がなければ、BAUレポートは混乱を招いたり誤解を生じさせたりする可能性があります。
{% endalert %}

### 必要な情報 {#required-information}

実験設計を検証した後、BAUレポートを設定するために以下の詳細を収集します：

**CEPからのキャンペーン ID：**

| CEP | 受け入れ可能な種類 |
|-----|---------------|
| **Braze** | キャンペーンおよびキャンバス |
| **Salesforce Marketing Cloud** | ジャーニーのみ |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Required information" }

**CEPからのオーディエンスID：**

| CEP | 受け入れ可能な種類 |
|-----|---------------|
| **Braze** | セグメントのみ |
| **Salesforce Marketing Cloud** | Data Extensionsのみ |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Required information" }

BAUオーディエンスをトラッキングする既存のオーディエンスがない場合は、作成する必要があります。

### 考慮事項 {#considerations}

- **クリックKPIのみ：** Decisioning Studio Go全般と同様に、BAUレポートはクリックKPIのみをカバーし、コンバージョンKPIは対象外です。
- **キャンバスの制限事項：** 現在、特定のキャンバスステップIDへのフィルタリングはサポートしていません。すべてのキャンバスステップからのイベントがBAUデータに含まれます。特定のキャンバスステップのみを含めるべき場合、BAUとの比較が無効になる可能性があります。

### BAUレポートを設定する

Decisioning Studio Goポータルの指示に従ってください。以下が必要です：
- すべてのコミュニケーションがBAUコミュニケーションであるキャンペーン IDが1つ以上
- BAUオーディエンス内の受信者を毎日トラッキングする1つのオーディエンスID

## エージェントを監視する {#monitor-your-agent}

起動後、Decisioning Studio Goポータルでエージェントのパフォーマンスを監視します：

- **エンゲージメント指標：** 実験グループ間のクリック率をトラッキングします
- **学習の進捗状況：** エージェントのおすすめが時間とともにどのように変化するかを観察します
- **グループ比較：** Decisioning Studio Goのパフォーマンスを、ランダムコントロールおよびBAU（設定されている場合）と比較します

{% alert tip %}
パフォーマンスに関する結論を出す前に、少なくとも2〜4週間のデータ収集期間を設けてください。エージェントが効果的に学習し最適化するには、十分なインタラクションが必要です。
{% endalert %}

## トラブルシューティング {#troubleshooting}

エージェントが期待どおりのパフォーマンスを発揮していない場合：

1. **オーケストレーションを確認する：** CEP統合がアクティブであること、キャンペーンとジャーニーが実行中であること、グローバルキャップや類似のルールがオーケストレーションを妨げていないことを確認します。
2. **データフローを確認する：** オーディエンスデータとエンゲージメントデータが正しく収集されていることを確認します。
3. **実験グループを確認する：** 適切な無作為割当を確保し、グループ間の重複がないようにします。
4. **サポートに連絡する：** さらにサポートが必要な場合は、Brazeサポートにお問い合わせください。
