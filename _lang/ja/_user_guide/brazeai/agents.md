# エージェントコンソールのBrazeエージェント {#braze-agents-in-agent-console}

> Brazeエージェントは、Braze内で作成できるAI搭載のヘルパーです。エージェントはコンテンツを生成し、インテリジェントな判断を下し、データを充実させることで、よりパーソナライズされた顧客体験を提供できるようにします。

{% alert important %}
Brazeエージェントにアクセスして利用するには、メッセージクレジットまたはアクションクレジットが必要です。現在アクションクレジットをお持ちでなく、Brazeエージェントを利用したい場合は、次のステップについてアカウントマネージャーにお問い合わせください。
{% endalert %}

## Brazeエージェントを使う理由 {#why-use-braze-agents}

Brazeエージェントは、追加の作業なしで、よりスマートでパーソナライズされた体験をチームが提供できるよう支援します。エージェントは自律的に動作し、単にプロンプトに応答するだけでなく、コンテキストを理解し、意思決定を行い、目標に向けてアクションを起こします。

実際には、エージェントは件名や製品内テキストなどのメッセージコピーを自動生成できるため、すべての顧客がパーソナライズされたコミュニケーションを受け取ることができます。また、リアルタイムで適応し、好みや行動、その他のデータに基づいてユーザーを異なるキャンバスパスに誘導することもできます。

メッセージングにとどまらず、エージェントは製品やプロファイルのフィールド値を計算・生成することでカタログを充実させ、データを常に最新かつダイナミックな状態に保ちます。反復的または複雑なタスクを引き受けることで、チームは手動設定ではなく戦略と創造性に集中できるようになります。Brazeエージェントはバックグラウンドプロセスというよりも協力者のように機能し、問題解決とスケールでのインパクト提供を支援します。

### Brazeエージェントと他のBrazeAI機能の使い分け {#when-to-use-braze-agents-versus-other-brazeai-features}

ユーザーの特定のコンテキストを使用して、コンテンツをその場でパーソナライズする場合にエージェントを使用します。例えば、あるユーザーのお気に入りのアイスクリームの味がチョコレートで、お気に入りのトッピングがグミベアであることをエージェントが知っている場合、そのユーザーがキャンバスを通過する際に、その組み合わせに特化したプッシュコピーを作成できます。

ただし、エージェントは試行錯誤を通じて学習することはなく、測定・最大化すべき最終的なマーケティング目標を認識していません。コンバージョンを促進するコピーを一般的に書くよう指示したとしても、エージェントが書いたコピーのコンバージョンへの影響を「モニタリング」し、そのデータを将来のエージェント呼び出しにフィードバックする仕組みはありません。これは報酬ベースのAI意思決定ではなく、「雰囲気」による意思決定と考えることができます。

一方、他のBrazeAIツールは、測定対象の指標を最大化するように設計されています。例えば、エージェントはユーザーの特性が特定のイベントを起こす可能性や特定の製品を好む傾向にどう影響するかを定性的に評価するのが非常に得意です。しかし、エージェントは試行錯誤を通じて学習しないため、予測の精度を測定する方法も、時間の経過とともにシグナルを改善する方法も持っていません。そのため、予測精度の正確さと時間経過に伴う改善度で評価した場合、予測スイートはエージェントステップを上回るパフォーマンスを発揮します。

## 機能 {#features}

Brazeエージェントの機能には以下が含まれます。

- **柔軟な設定：** Brazeが提供するLLMを使用するか、独自の[AIモデルプロバイダー]({{site.baseurl}}/partners/ai_model_providers)（OpenAI、Anthropic、Google Gemini、Databricks Mosaicなど）を接続できます。
- **シームレスな統合：** エージェントをキャンバスステップやカタログフィールドに直接デプロイできます。
- **テスト、ログ記録、バージョン履歴：** 起動前にサンプル入力でテストしてエージェントの出力をプレビューできます。エージェントが実行されるたびに、その実行の入力と出力を含むログを確認できます。**バージョン履歴**タブを使用して、過去のバージョンやインストラクション変更のインライン差分を確認できます。
- **使用量コントロール：** 日次制限によりパフォーマンスとコストを管理できます。

## Brazeエージェントについて {#about-braze-agents}

エージェントは、動作を定義するインストラクション（システムプロンプト）で構成されます。エージェントが実行されると、インストラクションと明示的に渡されたデータを使用して応答を生成します。エージェントは、設定したデータ以外のユーザーデータにはアクセスできません。アクセスできるのは、Liquid変数、エージェントコンテキストの選択、キャンバスコンテキスト変数、コンテキストステップの値のみです。エージェントはプロファイルを検索したり、データが不足している場合に警告を出したりすることはありません。詳細については、[エージェントが受け取るデータ]({{site.baseurl}}/user_guide/brazeai/agents/reference#what-data-agents-receive)を参照してください。

## 制限事項 {#limitations}

以下の制限が適用されます。

- 各エージェントにはデフォルトで1日あたり250,000回の実行制限が設定されており、最大で1日あたり1,000,000回まで増やすことができます。この制限の引き上げをご希望の場合は、カスタマーサクセスマネージャーにお問い合わせください。
- エージェントコンソールには、各エージェントの**日次アクションクレジットコスト上限**が表示されます。これは、モデルの1回あたりの実行クレジット比率と日次実行制限に基づく、1日あたりの推定最大クレジット数です。詳細については、[日次実行およびクレジット制限]({{site.baseurl}}/user_guide/brazeai/agents/reference#daily-invocation-and-credit-limits)を参照してください。
- デフォルトでは、各実行は20秒以内に完了する必要があります。20秒を超えると、エージェントは使用箇所で`null`応答を返します。
    - エージェントが頻繁にタイムアウトする場合は、Brazeのアカウントマネージャーに連絡してこの制限の引き上げをご依頼ください。
- 入力データはリクエストあたり25KBに制限されています。長い入力は切り詰められます。

## ベストプラクティス {#best-practices}

エージェントが最大の投資対効果（ROI）を生み出せる高価値のユースケースをターゲットにし、反応する可能性の高いオーディエンスを選択してください。小規模でも高い機会を持つオーディエンスは、機会の低い大規模なオーディエンスを上回ることが多いです。例えば、ユーザー群全体にエージェント生成のコピーを送信するのではなく、最近検索したがコンバージョンしなかったユーザーをリターゲティングする方が効果的です。

スケールする前にROIを検証するには、[実験パス]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step)ステップを使用して、オーディエンスの一部のみをエージェントステップに通してください。デプロイに関する詳細なガイダンスについては、[カスタムエージェントをデプロイする]({{site.baseurl}}/user_guide/brazeai/agents/deploying_agents)を参照してください。

## エラーハンドリング {#error-handling}

キャンバスステップエージェントまたはカタログエージェントの実行中に、接続されたモデルがLLMプロバイダーから[レート制限エラー]({{site.baseurl}}/user_guide/brazeai/agents/reference#rate-limit-errors)を返した場合、Brazeはエクスポネンシャルバックオフを使用してリクエストを継続的に再試行します。

その他の障害（タイムアウトや無効なAPIキーなど）の場合、エージェントコンソールで[フォールバック値が設定]({{site.baseurl}}/user_guide/brazeai/agents/creating_agents#configure-fallback-values)されていない限り、キャンバスステップエージェントの出力は`null`に設定されます（キャンバスステップエージェントのみ）。カタログエージェントはレート制限以外の障害を再試行しません。エージェントが日次実行制限に達した場合、Brazeは設定されたフォールバック値が存在すればそれを適用し、存在しない場合は出力を`null`に設定します。

多くのユーザーが同時にエージェントステップに入ると、[実行フロー制御]({{site.baseurl}}/user_guide/brazeai/agents/reference#invocation-flow-controls)により処理に時間がかかる場合があります。実行が失敗した場合でもユーザーが出力を受け取れるよう、エージェントコンソールでキャンバスステップエージェントのフォールバック値を設定するか、下流のメッセージステップで[Liquidのデフォルト値]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/setting_default_values)を使用してください。

## データはどのように利用され、Braze提供のLLMに送信されますか？ {#how-is-my-data-used-and-sent-to-braze-provided-llms}

Brazeが提供するLLMを活用しているとBrazeが識別したBraze AI機能を通じてAI出力（以下「出力」）を生成するために、Brazeはお客様のシステムプロンプトまたはその他の入力（該当する場合、以下「入力」）をBraze提供のLLMに送信します。該当するBraze提供のLLMに送信されたデータは、Braze提供のLLMのトレーニングや改善には使用されません。お客様とBrazeの間では、出力はお客様の知的財産です。Brazeは当該出力について著作権の所有権を主張しません。Brazeは、出力を含むAI生成コンテンツ全般に関して、いかなる種類の保証も行いません。

Brazeエージェント向けにBrazeが提供するLLMは「Auto」として識別され、Google Geminiモデルを使用しています。GoogleはBrazeを通じて送信された入力と出力を55日間保持し、その後データは削除されます。
