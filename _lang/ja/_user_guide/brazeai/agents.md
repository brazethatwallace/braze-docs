# エージェントコンソールのBrazeエージェント {#braze-agents-in-agent-console}

> Brazeエージェントは、Braze内で作成できるAI搭載のヘルパーです。エージェントはコンテンツを生成し、インテリジェントな判断を下し、データを充実させることで、よりパーソナライズされた顧客体験を提供できるようにします。

{% alert important %}
Brazeエージェントにアクセスして利用するには、メッセージクレジットまたはアクションクレジットが必要です。現在アクションクレジットをお持ちでなく、Brazeエージェントを利用したい場合は、次のステップについてアカウントマネージャーにお問い合わせください。
{% endalert %}

## なぜBrazeエージェントを使うのか？ {#why-use-braze-agents}

Brazeエージェントは、余分な作業を増やすことなく、よりスマートでパーソナライズされた体験をチームが提供できるよう支援します。プロンプトに応答するだけでなく、コンテキストを理解し、意思決定を行い、目標に向かってアクションを実行する自律的なエージェントとして機能します。

実際には、エージェントは件名やアプリ内テキストなどのメッセージコピーを自動的に作成できるため、すべての顧客が自分向けにカスタマイズされたと感じるコミュニケーションを受け取ることができます。また、好み、行動、その他のデータに基づいて、リアルタイムで異なるキャンバスパスにユーザーをルーティングすることもできます。

メッセージングにとどまらず、エージェントは製品やプロファイルのフィールド値を計算・生成することでカタログをエンリッチし、データを最新かつダイナミックな状態に保つことができます。反復的または複雑なタスクを引き受けることで、チームが手動設定ではなく戦略やクリエイティビティに集中できるようにします。Brazeエージェントはバックグラウンドプロセスというより、問題解決を支援し、大規模にインパクトを提供するコラボレーターのように機能します。

### Brazeエージェントと他のBrazeAI機能の使い分け {#when-to-use-braze-agents-versus-other-brazeai-features}

エージェントは、ユーザー固有のコンテキストを使用してコンテンツをリアルタイムでパーソナライズする場合に使用します。たとえば、エージェントが特定のユーザーのお気に入りのアイスクリームフレーバーがチョコレートで、お気に入りのトッピングがグミベアであることを知っている場合、そのユーザーがキャンバスを通過する際に、その組み合わせに特化したプッシュコピーを作成できます。

ただし、エージェントは試行錯誤を通じて学習するわけではなく、測定して最大化しようとする最終的なマーケティング目標を認識していません。コンバージョンを促進するコピーを書くよう一般的に指示したとしても、エージェントにはそのエージェント的な記述のコンバージョンへの影響を「モニタリング」し、そのデータを将来のエージェント呼び出しに統合するメカニズムがありません。これは報酬ベースのAI意思決定ではなく、「感覚的な」意思決定と考えることができます。

一方、他のBrazeAIツールは、測定している指標を最大化するように設計されています。たとえば、エージェントはユーザーの特性が特定のイベントを行う可能性や特定の製品を好む傾向にどのように影響するかを定性的に評価することに非常に優れています。しかし、エージェントは試行錯誤を通じて学習しないため、可能性の予測精度を測定し、時間の経過とともにシグナルを改善する方法を持っていません。そのため、予測の精度と時間の経過に伴う改善という観点では、予測スイートの使用がエージェントステップよりも優れたパフォーマンスを発揮します。

## 機能 {#features}

Brazeエージェントの機能には以下が含まれます。

- **柔軟な設定：** Brazeが提供するLLMを使用するか、独自の[AIモデルプロバイダー]({{site.baseurl}}/partners/ai_model_providers)（OpenAI、Anthropic、Google Gemini、Databricks Mosaicなど）を接続できます。
- **シームレスなインテグレーション：** キャンバスステップまたはカタログフィールドにエージェントを直接デプロイできます。
- **テスト、ログ、バージョン履歴：** ローンチ前にサンプル入力でテストして、エージェントの出力をプレビューできます。エージェントが実行されるたびに、その入力と出力を含むログを確認できます。**バージョン履歴**タブを使用して、過去のバージョンやインストラクション変更のインラインdiffを確認できます。
- **使用量の管理：** 1日あたりの制限により、パフォーマンスとコストを管理できます。

## Brazeエージェントについて {#about-braze-agents}

エージェントは、動作を定義するインストラクション（システムプロンプト）を設定して構成します。エージェントが実行されると、インストラクションと明示的に渡されたデータを使用してレスポンスを生成します。エージェントは、設定されたもの以外のユーザーデータにはアクセスできません。アクセスできるのは、Liquid変数、エージェントコンテキストの選択、キャンバスコンテキスト変数、およびコンテキストステップの値のみです。エージェントはプロファイルを検索したり、データが欠落している場合に警告を出したりしません。詳細については、[エージェントが受け取るデータ]({{site.baseurl}}/user_guide/brazeai/agents/reference#what-data-agents-receive)を参照してください。

## 制限事項 {#limitations}

以下の制限事項が適用されます。

- 各エージェントには、デフォルトで1日あたり250,000回の実行制限があり、最大1,000,000回/日まで増加できます。この制限の引き上げにご興味がある場合は、カスタマーサクセスマネージャーにお問い合わせください。
- エージェントコンソールには、各エージェントの**1日あたりのアクションクレジットコスト制限**が表示されます。これは、モデルの1回あたりのクレジット比率と1日あたりの実行制限に基づいて推定される1日の最大クレジット数です。[1日あたりの呼び出しとクレジットの制限]({{site.baseurl}}/user_guide/brazeai/agents/reference#daily-invocation-and-credit-limits)を参照してください。
- デフォルトでは、各実行は20秒以内に完了する必要があります。20秒を超えると、エージェントは使用箇所で`null`レスポンスを返します。
    - エージェントが一貫してタイムアウトする場合は、Brazeアカウントマネージャーに連絡してこの制限の引き上げを依頼してください。
- 入力データは1リクエストあたり25 KBに制限されています。より長い入力は切り捨てられます。

## ベストプラクティス {#best-practices}

エージェントが最大の投資対効果（ROI）を発揮できる価値の高いユースケースをターゲットにし、反応する可能性が高いオーディエンスを選びましょう。小規模でも機会の大きいオーディエンスは、機会の少ない大規模なオーディエンスよりも高い成果を上げることがよくあります。たとえば、エージェントが生成したコピーをユーザー群全体に送信するのではなく、最近検索したがコンバージョンに至らなかったユーザーをリターゲティングする方が効果的です。

スケーリング前にROIを検証するには、[実験パス]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step)ステップを使用して、オーディエンスの一部のみをエージェントステップに通します。小規模なテストで良好な結果が確認できたら、エージェントをターゲットオーディエンス全体にスケーリングし、送信中に呼び出しが制限されないよう[1日あたりの呼び出し制限]({{site.baseurl}}/user_guide/brazeai/agents/reference#daily-invocation-and-credit-limits)を引き上げてください。フルオーディエンスにスケーリングする前に、推定クレジット消費量に問題がないことを確認してください。デプロイに関する詳細なガイダンスについては、[カスタムエージェントをデプロイする]({{site.baseurl}}/user_guide/brazeai/agents/deploying_agents)を参照してください。

## エラーハンドリング {#error-handling}

接続されたモデルがキャンバスステップエージェントまたはカタログエージェントの呼び出し中にLLMプロバイダーから[レートリミットエラー]({{site.baseurl}}/user_guide/brazeai/agents/reference#rate-limit-errors)を返した場合、Brazeは指数バックオフを使用してリクエストを継続的にリトライします。

その他の障害（タイムアウトや無効なAPIキーなど）の場合、エージェントコンソールで[フォールバック値が設定]({{site.baseurl}}/user_guide/brazeai/agents/creating_agents#configure-fallback-values)されていない限り、キャンバスステップエージェントの出力は`null`に設定されます（キャンバスステップエージェントのみ）。カタログエージェントは、レートリミット以外の障害をリトライしません。エージェントが1日あたりの呼び出し制限に達した場合、Brazeは設定済みのフォールバック値が存在すればそれを適用し、存在しない場合は出力を`null`に設定します。

レートリミットエラー、モデルの利用不可、および1日あたりの呼び出し制限による障害はBrazeクレジットを消費しません。タイムアウトはクレジットを消費します。[クレジットが消費されるタイミング]({{site.baseurl}}/user_guide/brazeai/agents/reference#when-credits-are-consumed)を参照してください。

多くのユーザーが同時にエージェントステップに入ると、[呼び出しフローコントロール]({{site.baseurl}}/user_guide/brazeai/agents/reference#invocation-flow-controls)により処理に時間がかかる場合があります。呼び出しが失敗してもユーザーが出力を受け取れるように、エージェントコンソールでキャンバスステップエージェントのフォールバック値を設定するか、下流のメッセージステップで[デフォルトのLiquid値]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/setting_default_values)を使用してください。

## データはどのように使用され、Braze提供のLLMに送信されますか？ {#how-is-my-data-used-and-sent-to-braze-provided-llms}

Braze提供のLLMを活用していると特定されたBraze AI機能を通じてAI出力（以下「出力」）を生成するために、Brazeはお客様のシステムプロンプトまたはその他の該当する入力（以下「入力」）をBraze提供のLLMに送信します。該当するBraze提供のLLMに送信されたデータは、Braze提供のLLMのトレーニングや改善には使用されません。お客様とBrazeの間において、出力はお客様の知的財産です。Brazeは当該出力に対して著作権の所有権を主張しません。Brazeは、出力を含むAI生成コンテンツ全般に関して、いかなる種類の保証も行いません。

「Auto」と識別されるBrazeエージェント向けのBraze提供のLLMは、Google Geminiモデルを使用しています。Googleは、Brazeを通じて送信された入力と出力を55日間保持し、その後データは削除されます。
