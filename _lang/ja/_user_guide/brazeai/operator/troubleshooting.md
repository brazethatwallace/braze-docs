# BrazeAI Operatorのトラブルシューティング {#troubleshooting-brazeai-operator}

> BrazeAI Operator<sup>TM</sup>のよくある問題とソリューションです。

## よくある問題 {#common-issues}

| 問題 | トラブルシューティング |
| --- | --- |
| 応答がない | ページを更新して、オペレーターパネルを再度開いてみてください。 |
| 的外れな回答 | 質問をより具体的に言い換えてください。質問対象の機能やワークフローについて明示してください。 |
| エラーメッセージ | オペレーターがコンテンツをストリーミングできない場合、「もう一度試す」というプロンプトが表示されることがあります。オペレーターが一時的に利用できないか、接続が中断された可能性があります。数分後に再試行してください。 |
| 1日の使用上限を超過 | 会社全体での使用上限に達しました。上限がリセットされるまでお待ちください（24時間ごとにリセットされます）。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="よくある問題" }

ダッシュボード全体でオペレーターができることとできないことについては、[制限事項]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#limitations)を参照してください。
