# BrazeAI Operatorのトラブルシューティング {#troubleshooting-brazeai-operator}

> BrazeAI Operator<sup>TM</sup>のよくある問題とソリューションです。

## よくある問題 {#common-issues}

| 問題 | トラブルシューティング |
| --- | --- |
| 応答がない | ページを更新し、オペレーターパネルを再度開いてみてください。 |
| 的外れな回答 | 質問をより具体的に言い換えてください。質問している機能やワークフローについて言及してください。 |
| エラーメッセージ | オペレーターがコンテンツをストリーミングできない場合、「再試行」プロンプトが表示されることがあります。オペレーターが一時的に利用できないか、接続が中断された可能性があります。数分後に再試行してください。 |
| 1日の上限に達した | 会社全体の1日の使用上限に達しました。すべてのオペレーターアクションがこの上限にカウントされます。上限がリセットされるまでお待ちください（24時間ごと）。Webフォームからサポートチケットを提出することは引き続き可能です。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="よくある問題" }

ダッシュボード全体でオペレーターができることとできないことについては、[制限事項]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#limitations)を参照してください。
