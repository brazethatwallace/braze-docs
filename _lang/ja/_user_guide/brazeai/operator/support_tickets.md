# BrazeAI Operatorでサポートチケットを提出する {#file-support-tickets-with-brazeai-operator}

> Brazeダッシュボードを離れることなく、BrazeAI Operator<sup>TM</sup>から直接サポートチケットを提出する方法を説明します。

## チケットの提出方法 {#how-to-file-a-ticket}

1. オペレーターに質問し、<i class="fa-regular fa-circle-question"></i> **サポートチケットを提出** を選択します（またはオペレーターにチケットの提出を依頼します）。
2. 問題のタイトルと説明を入力します。
3. 推奨される添付ファイルと含めるコンテキストを確認します。
4. 内容を確認し、**送信** を選択します。

オペレーターを通じてチケットを提出すると、会社全体の1日あたりの使用制限にカウントされますが、キャンペーンやセグメントなどのオブジェクトの作成や編集よりも軽い使用量です。制限にすでに達している場合でも、オペレーターはWebフォームを通じて **サポートチケットを提出** するよう案内します。詳細については、[制限事項]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#limitations)を参照してください。

## 自動的に含まれるコンテキスト {#auto-included-context}

オペレーターからチケットを提出する際、以下のコンテキストが自動的に含まれます。

- オペレーターのチャットセッションからの最近のメッセージ
- オペレーターを開いた時点でのアクティブページのページコンテキスト
- ワークスペース名
- 関連するログとセッションの詳細

テキストフィールドを使用するか、ファイルを添付することで、手動でコンテキストを追加できます。

## 迅速な解決のためのヒント {#tips-for-faster-resolution}

- 問題を再現するためのステップを詳細に記述してください。
- 関連するエラーメッセージや予期しない動作を含めてください。
- 送信前に自動提案された添付ファイルを確認してください。
