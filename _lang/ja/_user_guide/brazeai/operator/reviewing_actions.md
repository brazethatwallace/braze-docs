# BrazeAI Operatorのアクションの確認 {#reviewing-brazeai-operator-actions}

> BrazeAI Operator<sup>TM</sup>がダッシュボードで変更を提案した際に、アクションを確認・承認する方法について説明します。

![確認用のアクションカード案を提示するオペレーター。]({% image_buster /assets/img/operator/suggested_actions.png %}){: style="max-width:40%; border:none; float:right; margin-left:15px;"}

## アクションカードの仕組み {#how-action-cards-work}

オペレーターがダッシュボードで変更を提案する際（フォームフィールドの入力、設定の更新、画像の生成など）、各変更をレビュー用のアクションカードとして提示します。

1. **オペレーターが計画を要約します：** オペレーターはアクションカードを表示する前に、実行する予定の内容を説明します。
2. **個別のアクションカードが表示されます：** 提案された各変更は、オペレーターがダッシュボードで変更または実行しようとしている内容を示す個別のカードとして提示されます。既存の値に対する変更の場合、以前の値と提案された値が比較のために並べて表示されます。
3. **レビューと承認：** 各カードをレビューし、承認または却下します。
4. **アクションの実行：** 承認されたアクションはBrazeで実行されます。却下されたアクションは適用されません。

承認後にアクションが失敗した場合、オペレーターが失敗の詳細を通知します。

### 利用可能な範囲 {#availability}

オペレーターは、メッセージ作成画面、一覧ページや概要ページ、設定、その他操作可能なサーフェスなど、対応するダッシュボードページでアクションカードを提案できます。代表的な対応範囲については、[オペレーターでできること]({{site.baseurl}}/user_guide/brazeai/operator/capabilities)を参照してください。対応するメッセージチャネルとエディターについては、[メッセージの生成]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#generate-messages)を参照してください。

対応範囲は定期的に拡大されています。オペレーターが現在のページで操作できない場合は、UIで実行するステップの一覧が提供されます。

## プランを変更する {#modify-a-plan}

オペレーターのプランを変更するには、まず保留中のアクションを承認または却下します。次に、新しいチャットメッセージで希望する変更内容を記述します。

承認済みのアクションはオペレーターを通じて元に戻すことはできません。オペレーターに新しい変更内容を記述するか、ダッシュボードで手動で変更を行ってください。

## アクションの自動承認 {#auto-approve-actions}

**アクションの自動承認**トグルは、オペレーターのチャットパネルにあります。

- **オン：** オペレーターが提案したアクションは、リクエストを完了するための[別のページへの移動]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#navigate-the-dashboard)を含め、手動承認を必要とせずに即座に実行されます。画像の生成やワークスペースレベルの設定の変更など、安全性の観点から明示的な承認が必要なアクションもあります。
- **オフ（デフォルト）：** ページナビゲーションを含むすべての提案されたアクションは、上記の手動レビュープロセスに従います。オペレーターは移動を提案し、実行する前にあなたの承認を待ちます。

![オペレーターのチャットパネルにおける自動承認トグルと確認モーダル。]({% image_buster /assets/img/operator/auto-approval_toggle.png %}){: style="max-width:50%;"}

自動承認は、ページを更新したり、新しいタブを開いたり、ログアウトして再度ログインしたりするとリセットされます。ダッシュボード内でページ間を移動してもリセットされません。自動承認はいつでもオフにできます。

オペレーターのアクセス制限やチームの使用状況の監査については、[データプライバシーとセキュリティ]({{site.baseurl}}/user_guide/brazeai/operator/data_privacy_security)を参照してください。
