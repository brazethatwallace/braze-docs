# オペレーター分析 {#operator-analyze}

> オペレーター分析は、BrazeAI Operator<sup>TM</sup>で自然言語のパフォーマンスに関する質問に回答します。回答にはチャート、比較、簡潔なインサイトが含まれます。ダッシュボードを構築したり、完全なレポートを先に取得したりする必要はありません。

{% alert important %}
オペレーター分析は現在ベータ版です。機能とサポートされる分析は進化し続けています。アカウントへのアクセスをリクエストするには、カスタマーサクセスマネージャーにお問い合わせください。
{% endalert %}

## Operator Analyzeを使用する理由 {#why-use-operator-analyze}

ほとんどのパフォーマンスに関する質問には、ツールの切り替え、ビューの作成、または他の誰かの対応を待つことが依然として必要です。たとえば、「先週の結果はどうだったか」「ベンチマークに対して順調に推移しているか」「最も強力な成果を出しているキャンペーンはどれか」などが挙げられます。

Operator Analyzeは、エンゲージメント指標、*Attributed Revenue*、業界ベンチマークをカバーしています。これは、レポートやダッシュボードに取り込むのと同じデータです。Operatorパネルから自分の言葉で質問してください。チャート、ランク付けされた比較、またはテーブルに加え、1〜5件の実用的なインサイトが返されます。

## Operator Analyzeへのアクセス {#access-operator-analyze}

Operator Analyzeは、Operatorの会話パネルで実行されます。

1. Brazeダッシュボードの任意のページで、ユーザープロファイルの横にある**BrazeAI<sup>TM</sup> Operator**を選択します。
2. チャネルエンゲージメントやベンチマーク比較について質問します（[質問の例](#example-questions)を参照してください）。
3. Operatorが回答を返し、必要に応じてチャートやテーブル、および簡単なインサイトのリストを表示します。

Operatorのチャットパネルの詳細については、[BrazeAI Operator]({{site.baseurl}}/user_guide/brazeai/operator)を参照してください。

## ビジュアライゼーション {#visualizations}

オペレーターは、データがサポートしている場合にチャートを追加します。**折れ線グラフ**は時系列データに、**棒グラフ**はカテゴリー比較に、**テーブル**はその他のケースに適しています。テーブルではパーセンテージを小数点以下2桁まで表示し、大きな数値にはカンマを使用します。

レスポンスに複数の指標が含まれる場合、オペレーターは生のカウントよりもエンゲージメント率（*開封率*、*クリック率*、*プッシュ開封率*）を優先します。

## サポート対象のチャネルと指標 {#supported-channels-and-metrics}

*アトリビューション収益*と*コンバージョン*は、**収益とコンバージョン**タブの[質問の例](#example-questions)に示されているものと同じキャンペーン、キャンバス、チャネル、およびプログラムの集計を使用します。

| チャネル | 指標 | 業界ベンチマーク |
| --- | --- | --- |
| メール | *送信数*、*配信数*、*ユニーク開封数*、*ユニーククリック数*、*購読解除数* | あり |
| プッシュ（iOS、Android、Web） | *送信数*、*配信数*、*開封数* | あり |
| SMS | *送信数*、*配信数*、*リンククリック数* | あり |
| In-App Messages | *インプレッション数*、*クリック数* | あり |
| Content Cards | *送信数*、*インプレッション数*、*クリック数* | あり |
| WhatsApp | *送信数*、*配信数*、*既読数*、*クリック数* | 未対応 |
| RCS | *送信数*、*配信数*、*既読数*、*クリック数*（テキストURL、ボタン、アクション、返信アクション、返信ボタンのサブタイプを含む） | 未対応 |
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3 aria-label="サポート対象のチャネル、指標、ベンチマークの利用可否" }

{% alert tip %}
オペレーターは率の計算にユニーク数を使用します（例：*メール開封率*の場合、*ユニーク開封数*を*配信数*で除算します）。ダッシュボードと数値が異なる場合は、アトリビューションウィンドウ、期間、定義を比較してください。オペレーターは各レスポンスにこれら3つの情報をすべて記載します。
{% endalert %}

## 期間とアトリビューションウィンドウ {#time-periods-and-attribution-windows}

### 会計年度とカレンダー年度 {#fiscal-year-vs-calendar-year}

Operator Analyzeはデフォルトで**Brazeの会計年度**を使用します。会計年度は2月1日から1月31日までです。

| 会計四半期 | 月 |
| --- | --- |
| FQ1 | 2月～4月 |
| FQ2 | 5月～7月 |
| FQ3 | 8月～10月 |
| FQ4 | 11月～1月 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Brazeの会計四半期とカレンダー月" }

カレンダー年度に関する質問の場合は、「CY」、「calendar year」、または「standard year」を含めてください。「last year」のようなあいまいな表現の場合、Operatorはどちらのカレンダーを意味するか確認を求めます。

`Q4 2025` や `2025-03-01 to 2025-05-31` のようなISO形式の範囲も使用できます。

### アトリビューションウィンドウ {#attribution-windows}

Operator Analyzeのデフォルトは**7日間**です。別のウィンドウを使用するには、質問にウィンドウを指定してください。

* **1日間** — 短期的なエンゲージメント確認用
* **3日間** — 短期サイクルのキャンペーン用
* **7日間** — 一般的な概要やキャンペーンの分析用（デフォルト）
* **30日間** — 戦略的または長期的な分析用
* **全ウィンドウ** — 1日/3日/7日/30日の並列比較用

ウィンドウ間で結果が50%以上異なる場合、Operatorは4つすべてを並べて表示します。

## データの鮮度 {#data-freshness}

データは毎日更新されます。当日のアクティビティは、次回の更新後に表示されます。各レスポンスには、データセット内の最新の日付が記載されています。その日付が古いと思われる場合は、カスタマーサクセスマネージャーにお問い合わせください。

## 対象範囲外 {#whats-out-of-scope}

* **プロダクトレベルのパフォーマンス内訳。***アトリビューション収益*およびエンゲージメントは、キャンペーン、キャンバス、チャネル、またはプログラムレベルにロールアップされます。プロダクトやSKU単位での内訳は表示されません。プロダクトまたはSKUレベルの質問はサポートされていません。それらの分析については、カスタマーサクセスマネージャーにお問い合わせください。
* **WhatsAppとRCSの業界ベンチマーク。**両チャネルのエンゲージメント指標はサポートされています。ベンチマークはまだ利用できません。

対象範囲外の質問には、直接的な回答、可能な場合は代替案の提案、またはカスタマーサクセスマネージャーへの案内が提供されます。

## より良い結果を得るためのヒント {#tips-for-better-results}

* **時間範囲:** 精度が必要な場合は、「前四半期」のような曖昧な表現ではなく、明示的な範囲（「FY26 Q2」、「過去90日間」）を使用してください。
* **指標:** 関心のある指標を具体的に名前で指定してください（*開封率*、*クリックスルー率*、*クリック・トゥ・オープン率*）。オペレーターは使用した計算式をレポートします。
* **フォローアップ:** 結果を掘り下げたり、期間を変更したり、チャネルを切り替えたりできます。オペレーターはスレッド全体のコンテキストを保持します。
* **チャネルの表現:** WhatsAppとRCSは*既読率*（*開封率*ではありません）を使用します。SMSは*リンククリック率*を使用します。
* **複合的なリクエスト:** ベンチマークとトレンドを1つのプロンプトにまとめることもサポートされています。
