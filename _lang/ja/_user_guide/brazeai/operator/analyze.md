# Operator Analyze {#operator-analyze}

> Operator Analyzeは、BrazeAI Operator<sup>TM</sup>で自然言語のパフォーマンスに関する質問に回答します。回答にはチャート、比較、簡潔なインサイトが含まれます。ダッシュボードを構築したり、完全なレポートを先に取得したりする必要はありません。

{% alert important %}
Operator Analyzeは現在ベータ版です。機能とサポートされる分析は進化し続けています。アカウントへのアクセスをリクエストするには、カスタマーサクセスマネージャーにお問い合わせください。
{% endalert %}

## Operator Analyzeを使用する理由 {#why-use-operator-analyze}

ほとんどのパフォーマンスに関する質問では、ツールの切り替え、ビューの構築、または他の人の対応を待つ必要があります。例えば「先週の結果はどうだったか」「ベンチマークに対してどうか」「どのキャンペーンが最も強い成果を出しているか」などです。

Operator Analyzeは、エンゲージメント指標、*アトリビューション収益*、業界ベンチマークをカバーします。これは、レポートやダッシュボードに取り込むのと同じデータです。Operatorパネルから自分の言葉で質問してください。チャート、ランク付き比較、またはテーブルに加えて、1〜5件の実用的なインサイトが得られます。

## Operator Analyzeにアクセスする {#access-operator-analyze}

Operator AnalyzeはOperatorの会話パネルで実行されます。

1. Brazeダッシュボードの任意のページで、ユーザープロファイルの横にある**BrazeAI Operator<sup>TM</sup>**を選択します。
2. チャネルエンゲージメントやベンチマーク比較について質問します（[質問の例](#example-questions)を参照）。
3. Operatorが回答を返し、必要に応じてチャートまたはテーブルと簡潔なインサイトのリストを表示します。

Operatorチャットパネルの詳細については、[BrazeAI Operator]({{site.baseurl}}/user_guide/brazeai/operator/)を参照してください。

## ビジュアライゼーション {#visualizations}

Operatorはデータがサポートする場合にチャートを追加します。**折れ線グラフ**は時系列に適しており、**棒グラフ**はカテゴリ比較に適しており、**テーブル**はその他のケースをカバーします。テーブルではパーセンテージを小数点以下2桁まで表示し、大きな数値にはカンマを使用します。

回答に複数の指標が含まれる場合、Operatorは生のカウントよりもエンゲージメント率（*開封率*、*クリック率*、*プッシュ開封率*）を優先します。

## サポートされるチャネルと指標 {#supported-channels-and-metrics}

*アトリビューション収益*と*コンバージョン*は、[質問の例](#example-questions)の**収益とコンバージョン**タブに表示されるのと同じキャンペーン、キャンバス、チャネル、プログラムの集計を使用します。

| チャネル | 指標 | 業界ベンチマーク |
| --- | --- | --- |
| メール | *送信数*、*配信数*、*ユニーク開封数*、*ユニーククリック数*、*配信停止数* | あり |
| プッシュ（iOS、Android、Web） | *送信数*、*配信数*、*開封数* | あり |
| SMS | *送信数*、*配信数*、*リンククリック数* | あり |
| In-App Messages | *インプレッション数*、*クリック数* | あり |
| Content Cards | *送信数*、*インプレッション数*、*クリック数* | あり |
| WhatsApp | *送信数*、*配信数*、*既読数*、*クリック数* | 未対応 |
| RCS | *送信数*、*配信数*、*既読数*、*クリック数*（テキストURL、ボタン、アクション、返信アクション、返信ボタンのサブタイプを含む） | 未対応 |
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3 aria-label="Supported channels, metrics, and benchmark availability" }

{% alert tip %}
Operatorは率の計算にユニークカウントを使用します（例：*メール開封率*の場合、*ユニーク開封数*を*配信数*で割ります）。数値がダッシュボードと異なる場合は、アトリビューションウィンドウ、時間範囲、定義を比較してください。Operatorは各回答で3つすべてを記載します。
{% endalert %}

## 期間とアトリビューションウィンドウ {#time-periods-and-attribution-windows}

### 会計年度とカレンダー年度 {#fiscal-year-vs-calendar-year}

Operator Analyzeのデフォルトは**Brazeの会計年度**で、2月1日から1月31日までです。

| 会計四半期 | 月 |
| --- | --- |
| FQ1 | 2月〜4月 |
| FQ2 | 5月〜7月 |
| FQ3 | 8月〜10月 |
| FQ4 | 11月〜1月 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Braze fiscal quarters and calendar months" }

カレンダー年度の質問には、「CY」、「calendar year」、または「standard year」を含めてください。曖昧な「last year」の場合、Operatorはどのカレンダーを意味するか確認します。

`Q4 2025`や`2025-03-01 to 2025-05-31`のようなISO形式の範囲も使用できます。

### アトリビューションウィンドウ {#attribution-windows}

Operator Analyzeのデフォルトは**7日間**です。質問でウィンドウを指定してオーバーライドできます：

* **1日** — 迅速なエンゲージメントチェック向け
* **3日** — 短期サイクルのキャンペーン向け
* **7日** — 一般的な概要とキャンペーンの確認向け（デフォルト）
* **30日** — 戦略的または長期的なビュー向け
* **全ウィンドウ** — 1日/3日/7日/30日の並列比較

ウィンドウ間で結果が50%以上異なる場合、Operatorは4つすべてを並べて表示します。

## データの鮮度 {#data-freshness}

データは毎日更新されます。当日のアクティビティは次回の更新後に表示されます。各回答にはデータセットの最新日付が記載されます。その日付が古く見える場合は、カスタマーサクセスマネージャーにお問い合わせください。

## 対象外の範囲 {#whats-out-of-scope}

* **製品レベルのパフォーマンス内訳。** *アトリビューション収益*とエンゲージメントは、キャンペーン、キャンバス、チャネル、またはプログラムレベルにロールアップされます。製品やSKUへの分解はできません。製品レベルまたはSKUレベルの質問はサポートされていません。それらの分析については、カスタマーサクセスマネージャーにお問い合わせください。
* **WhatsAppとRCSの業界ベンチマーク。** 両チャネルのエンゲージメント指標はサポートされています。ベンチマークはまだ利用できません。

対象外の質問には、直接的な回答、可能な場合は代替案の提案、またはカスタマーサクセスマネージャーへの案内が提供されます。

## より良い結果を得るためのヒント {#tips-for-better-results}

* **時間範囲：** 精度が必要な場合は、「last quarter」のような曖昧なフレーズよりも、明示的な範囲（「FY26 Q2」、「過去90日間」）を使用してください。
* **指標：** 関心のある率を指定してください（*開封率*、*クリックスルー率*、*クリック対開封率*）。Operatorは使用した計算式を報告します。
* **フォローアップ：** 結果を掘り下げたり、ウィンドウを変更したり、チャネルを切り替えたりできます。Operatorはスレッド全体でコンテキストを保持します。
* **チャネルの表現：** WhatsAppとRCSは*既読率*（*開封率*ではなく）を使用します。SMSは*リンククリック率*を使用します。
* **複合的な質問：** ベンチマークとトレンドを1つのプロンプトで組み合わせることがサポートされています。
