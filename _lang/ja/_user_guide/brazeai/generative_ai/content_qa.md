# オペレーターによるコンテンツレビュー {#content-review-with-operator}

> 送信前にメッセージコンテンツのスペルミス、文法の問題、不適切なトーン、不快な言葉遣いをキャッチできます。

{% multi_lang_include brazeai/generative_ai/unification_note.md %}

## アクセス方法 {#how-to-access}

SMS、Androidプッシュ、iOSプッシュ、および従来のアプリ内メッセージの**テスト**タブで、**Review with Operator**を選択して、送信前にコンテンツをレビューします。オペレーターは、スペルや文法のエラー、ブランドにそぐわない不適切なトーン、不快な言葉遣い、不要なコードや未レンダリングのLiquidをチェックします。各問題について該当するテキストと修正案をフラグ表示するか、コンテンツに問題がないことを確認します。


サポートされている機能、ベストプラクティス、プロンプトの例など、詳細については[オペレーターの機能のコンテンツ品質レビュー]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#review-content-quality)を参照してください。
