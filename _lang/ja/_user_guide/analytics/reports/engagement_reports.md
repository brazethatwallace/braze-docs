# エンゲージメントレポート {#engagement-reports}

> エンゲージメントレポートを使用すると、キャンペーンやキャンバスの特定のメッセージからエンゲージメント統計を取得し、希望の時間にメールで受け取ることができます。

{% alert note %}
エンゲージメントレポートを実行するには、「Export User Data」権限が必要です。
{% endalert %}

エンゲージメントレポートでは、メールレポートに含めるキャンペーンやキャンバスを手動で選択するか、ルールを指定して関連するキャンペーンやキャンバスを自動的に選択できます。

選択したキャンペーンやキャンバスの数に関係なく、最大2つのCSVファイルが生成されます。1つはすべてのキャンペーンデータ用、もう1つはすべてのキャンバスデータ用です。これらのCSVファイルには、レポートメール内に埋め込まれたリンクからアクセスできます。エンゲージメントレポートはBrazeダッシュボードには保存されません。

一部のデータは、個々のキャンペーンバリアントやキャンバスステップレベルではなく、キャンペーンまたはキャンバスレベルで集計されます。[起動後にキャンバスステップを削除]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/change_your_canvas_after_launch#canvas-details)すると、エンゲージメントレポートからもデータが削除されます。

{% alert tip %}
レポートを再実行して、更新された統計を生成できます。
{% endalert %}

## 新しいレポートの作成 {#creating-a-new-report}

### ステップ1：レポートを作成する {#step-1-create-a-report}

ダッシュボードアカウントで、**Analytics** > **エンゲージメントレポート**に移動します。**+ 新しいレポートを作成**を選択します。

### ステップ2：メッセージを追加する {#step-2-add-messages}

レポートにまとめたいキャンペーンとキャンバスメッセージを追加します。メッセージの選択方法は2つあります。

- キャンペーンとキャンバスを手動で選択する
- 特定のルールに基づいてキャンペーンとキャンバスを自動的に選択する

![エンゲージメントレポートのメッセージ選択画面]({% image_buster /assets/img_archive/engagement_report_add_messages.png %})

#### キャンペーンまたはキャンバスを手動で選択する {#manually-select-campaigns-or-canvases}

このオプションでは、レポートに含めたいキャンペーンやキャンバスを自由に選択できます。

#### キャンペーンまたはキャンバスを自動的に選択する {#automatically-select-campaigns-or-canvases}

このオプションでは、特定の[タグ]({{site.baseurl}}/user_guide/administer/global/workspace_settings/tags)を含むすべてのメッセージを自動的に含めることができます。リストされたタグのいずれか1つ、またはすべてを持つメッセージをターゲットにできます。このオプションは、定期的なレポートを設定し、エンゲージメントメッセージに定期的にタグを付けている場合に便利です。

{% alert important %}
レポートを生成するには、タグが少なくとも1つのキャンペーンまたはキャンバスに一致する必要があります。**特定のルールに基づいてキャンペーンとキャンバスを自動的に選択する**を使用してエラーが表示された場合は、少なくとも1つのキャンペーンまたはキャンバスがタグやその他のフィルターに一致していることを確認してください（例えば、リストされたすべてのタグを必須にしている場合、一致するすべてのメッセージがすべてのタグを持っている必要があります）。
{% endalert %}

### ステップ3：統計を追加する {#add-statistics-to-your-reports}

**統計を追加**ステップでは、選択したキャンペーンまたはキャンバスの種類に応じた統計が表示されます。例えば、メールメッセージを選択した場合、関連するメール統計のみが表示されます。メールとプッシュの組み合わせを選択した場合、それら2つのチャネルの統計を確認できます。

![エンゲージメントレポートの統計追加画面]({% image_buster /assets/img_archive/engagement_report_add_stats.png %})

エンゲージメントレポートはキャンペーンまたはキャンバスごとにデータを集計し、ワークスペースレベルでは集計しません。すべてのアクティブなキャンペーンとキャンバスにわたる合計送信数やインプレッション数（ワークスペース全体のチャネルごとの送信数やインプレッション数など）を監視するには、[レポートビルダー]({{site.baseurl}}/report_builder)を使用してください。

{% alert note %}
*Sends to Carrier*は非推奨ですが、すでに使用しているユーザーに対しては引き続きサポートされます。
{% endalert %}

| チャネル | 利用可能な統計 |
| ------| --------------|
| メール | Sends、Opens、Unique Opens、Clicks、Unique Clicks、Click to Open、Unsubscribes、Bounces、Delivered、Reported Spam |
| プッシュ  | Sends、Opens、Influenced Opens、Bounces、Body Clicks |
| Webプッシュ | Sends、Opens、Bounces、Body Clicks |
| アプリ内メッセージ | Impressions、Clicks、First Button Clicks、Second Button Clicks |
| Webhook  |  Sends、Errors |
| SMS | Sends、Sends to Carrier、Confirmed Deliveries、Delivery Failures、Rejections |
{: .reset-td-br-1 .reset-td-br-2 aria-label="ステップ3：統計を追加する #add-statistics-to-your-reports" }

### ステップ4：レポート設定を完了する {#step-4-complete-report-setup}

レポートに名前を付け、レポートのフォーマットを選択し、受信者を選択します。デフォルトでは、エンゲージメントレポートはカンマ区切り（各データがカンマで区切られる）のZIPファイルとして送信されます。

以下の圧縮形式と区切り文字のオプションから選択できます。

- **圧縮形式：** ZIP、非圧縮、またはgzip
- **区切り文字：** カンマ（`,`）、コロン（`:`）、セミコロン（`;`）、またはパイプ（`|`）

{% alert note %}
統計はレポートで指定された日付範囲のみ収集されます。正確な開封率とクリック率の統計を受け取るには、キャンペーンとキャンバスの送信イベントが実行された時期を含む日付範囲を選択してください。
{% endalert %}

#### 期間を選択する {#select-time-frame}

デフォルトでは、表示されるデータ範囲は会社のタイムゾーンに基づいており、選択された最も古いメッセージから現在の日付までとなります。日付ドロップダウンを選択してカスタム範囲選択を使用するか、次のラジオボタンを選択して利用可能なドロップダウンオプションで日付範囲を定義することで、これをカスタマイズできます。

#### データ表示を選択する {#select-data-display}

デフォルトでは、エンゲージメントレポートに表示されるデータは日次（1日単位）です。異なる間隔でこのデータを表示するには、レポートのデータを集計する明示的な日数または週数を選択します。日次の指標を表示する代わりに、週次、月次、四半期ごと、または同様の単位でエンゲージメントを確認できます。時間ベースの集計では不十分な場合は、キャンペーンまたはキャンバスレベルでデータをエクスポートすることもできます。

![エンゲージメントレポートのデータカバレッジ画面]({% image_buster /assets/img_archive/engagement_report_datacoverage.png %})

##### キャンペーンまたはキャンバス全体でデータを表示する {#show-data-by-entire-campaign-or-canvas}

**キャンペーンまたはキャンバス全体でデータを表示する**を選択すると、Brazeはレポートの期間全体にわたって1,825日（5年）のチャンク単位で指標を集計します。

期間が複数のチャンクにまたがる場合、同じキャンペーンまたはキャンバスに対して日付列に異なる日付を持つ複数の行が表示されることがあります。一部の行には、期間の後半に記録された指標のみが含まれる場合があります（例えば、購読解除）。また、日付がワークスペースで送信を開始するよりも何年も前になることがありますが、これはエクスポートのチャンク境界を反映しているためであり、最初の送信日のみを反映しているわけではありません。

日付列を選択したキャンペーンとキャンバスの実際の送信時期に合わせるには、レポートの[**期間を選択する**の開始日](#select-time-frame)を、ファイルに含めたい最も早い日付（通常はそれらのメッセージが送信を開始した時期）に設定してください。最も古い選択メッセージまで遡るデフォルトの範囲のままにしないでください。

エクスポートされたCSVでは、最初の列が日付です。

- **キャンペーンまたはキャンバス全体でデータを表示する：** 日付はレポートの日付範囲の開始日またはその範囲内のチャンク境界であり、キャンペーンまたはキャンバスの開始日ではありません。
- **X日またはX週ごとにデータを表示する：** 各行の日付は、その集計ウィンドウ内でイベントが発生した時期を反映しています。

#### レポートをスケジュールする {#schedule-your-report}

レポートのスケジュール設定には2つのオプションがあります。

- **すぐに送信する：** レポートが起動された後、Brazeはこのレポートをすぐに送信します。
- **指定した時間に送信する：** このオプションでは、レポートを受信する頻度を柔軟に選択できます。設定した日数、週数、または月数ごとにレポートを送信するよう選択できます。また、レポートの送信を停止する時期を定義することもできます。

![エンゲージメントレポートのスケジュール設定画面]({% image_buster /assets/img_archive/engagement_report_reportschedule.png %}){: style="max-width:65%;" }

### ステップ5：確認して起動する {#step-5-review-and-launch}

レポート設定の最終ステップでは、設定したオプションの閲覧専用の概要が表示されます。レポートを確認し、問題がなければ**レポートを起動**を選択します。

### ステップ6：メールを確認する {#step-6-check-your-email}

選択した時間またはスケジュールに応じて、レポートへのリンクが記載されたメールが届きます。**これらのリンクはレポート送信後1時間で期限切れになります。** 提供されたリンクを選択すると、CSVファイルを含むZIPファイルが自動的にダウンロードされます（すべてのキャンペーンに対して1つのファイル）。

レポートには、設定プロセスの[統計を追加する](#add-statistics-to-your-reports)セクションで選択したすべての統計が含まれます。

## トラブルシューティング {#troubleshooting}

### エンゲージメントレポートの指標がメールパフォーマンスダッシュボードと異なる {#engagement-report-metrics-differ-from-the-email-performance-dashboard}

エンゲージメントレポートと[メールパフォーマンスダッシュボード]({{site.baseurl}}/user_guide/analytics/dashboards/channel_performance)は、同じメール指標の定義を使用しています。どちらも開封とクリックを各イベントが**発生した**日に帰属させ、*ユニーク開封数*と*ユニーククリック数*を1日あたりの7日間ユニークカウントとして計算し、選択した日付範囲全体で合計します。定義については、[メール指標]({{site.baseurl}}/user_guide/channels/email/reporting/analytics_glossary)およびチャネルパフォーマンスダッシュボードページの[指標の計算方法]({{site.baseurl}}/user_guide/analytics/dashboards/channel_performance#how-metrics-are-calculated)を参照してください。

同じキャンペーンと期間で合計が異なる場合は、以下を確認してください。

| 確認項目 | 重要な理由 |
| --- | --- |
| 日付範囲とタイムゾーン | 両方の画面で同じタイムゾーンの同じ暦日をカバーしている必要があります。 |
| キャンペーンまたはキャンバスの選択 | メールパフォーマンスダッシュボードはワークスペース全体のメールアクティビティを集計します。エンゲージメントレポートには、選択したキャンペーンまたはキャンバスのみが含まれます。 |
| 日別行とレポート合計 | **Data Display**がエクスポートを日別行に分割している場合、それらの行を合計して同じ範囲のダッシュボード合計と比較してください。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="エンゲージメントレポートのメール指標がメールパフォーマンスダッシュボードと異なる場合の確認事項" }

エンゲージメントレポートの数値をメールパフォーマンスダッシュボードではなく**キャンペーン**または**キャンバス**の分析と比較した場合、差異がより多く発生します。キャンペーンおよびキャンバスのページでは、送信日の指標（例：送信日に帰属する送信数やコンバージョン数）がイベント日の開封数やクリック数と並んで表示されることがあります。[エンゲージメントレポートがキャンバスまたはキャンペーンの指標と一致しない](#engagement-report-doesnt-match-metrics-from-the-canvas-or-campaign)を参照してください。

### エンゲージメントレポートがキャンバスまたはキャンペーンの指標と一致しない {#engagement-report-doesnt-match-metrics-from-the-canvas-or-campaign}

#### 時間範囲の不一致 {#mismatched-time-range}

エンゲージメントレポートの日付がキャンバスまたはキャンペーンの分析の日付と一致していることを確認してください（例：両方とも12月1日〜15日をカバーしている）。キャンバスが1回しか送信していない場合でも同様です。エンゲージメントレポートの設定で**Data Display**を確認し、正しいキャンバスまたはキャンペーンを表示していることを確認してください。**Data Display**がデータを*X*日ごとに表示するように設定されている場合、各ステップの指標が記録された日付ごとに1行が表示されます。

スプレッドシートで合計が正しくない場合は、エクスポートの余分なフィルターをクリアしてください。日別行を合計して、同じ時間範囲のキャンバスまたはキャンペーンの合計と照合できます。

{% alert note %}
日別、週別、またはその他の定期的なバケットではなく、キャンペーンまたはキャンバス全体で行を集計したい場合は、**Data Display**を**Show Data by Entire キャンペーン or キャンバス**に設定してください。CSVで行数や日付が正しくない場合は、[Show Data by Entire キャンペーン or キャンバス](#show-data-by-entire-campaign-or-canvas)を参照してください。
{% endalert %}

#### HTMLアプリ内メッセージでのボタンクリックの重複 {#duplicate-button-clicks-in-html-in-app-messages}

HTMLアプリ内メッセージを使用していて、エンゲージメントレポートで**Body clicks**が高く表示される場合、クリックログが2回発生している可能性があります。例えば、汎用のボディクリックに対して`brazeBridge.logClick()`を呼び出し、同じインタラクションで`brazeBridge.logClick('body click')`（または別のID）も呼び出している場合です。マークアップで`brazeBridge.logClick(`を検索し、コントロールごとに1つのパターンに統一してください。推奨される使用方法については、[ボタントラッキング]({{site.baseurl}}/user_guide/channels/in_app_messages/message_types/custom_html#button-tracking-improvements)を参照してください。

#### メール送信されたエンゲージメントレポートのリンク切れ {#broken-links-in-emailed-engagement-reports}

スケジュールされたエンゲージメントレポートのメール内のリンクがメールクライアントで正しく開かない場合は、以下のステップを試してください。

1. レポートをGmailの受信トレイに転送し、Google Chromeでリンクを開きます。
2. エンゲージメントレポートの設定で、**Report Schedule**が期待どおりに送信されるように設定されていることを確認します（例：遅延スケジュールではなく、レポート生成直後に送信される設定）。
