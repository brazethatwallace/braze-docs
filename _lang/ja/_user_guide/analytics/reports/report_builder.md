# レポートビルダー {#report-builder}

> このページでは、レポートビルダーを使用してBrazeデータに基づく詳細なレポートを作成・表示する方法と、レポートをダッシュボードに追加する方法について説明します。

以下の動画では、レポートビルダーでレポートを作成しカスタマイズする方法の概要を紹介しています。

{% multi_lang_include video.html id="oi66kwwldv" source="wistia" %}

## レポートテンプレートの使用 {#using-a-report-template}

1. **Analytics** > **レポートビルダー（新）**に移動します。
2. **新しいレポートを作成**ボタンの横にある**その他のオプション**の矢印を選択し、**レポートテンプレートを使用**を選択します。<br><br>![「新しいレポートを作成」ボタンのドロップダウン。カスタムレポートの作成またはテンプレートの使用オプションが表示されています。]({% image_buster /assets/img/report_builder_2/create_new_report.png %}){: style="max-width:40%;"}<br><br>
3. Brazeテンプレートライブラリからレポートテンプレートを1つ選択します。
    - **行項目**と**タグ**のドロップダウンを使用して、ユースケースに関連するレポートを見つけます。<br><br>![「Brazeレポートテンプレート」ウィンドウ。選択可能なBrazeテンプレートの一覧が表示されています。]({% image_buster /assets/img/report_builder_2/report_templates.png %}){: style="max-width:90%;"}<br><br>
4. [レポートの作成](#creating-a-report)のステップ3以降に従って、ユースケースに合わせてレポートをさらにカスタマイズします。

## レポートの作成 {#creating-a-report}

1. **Analytics** > **レポートビルダー（New）**に移動します。
2. **新しいレポートを作成**を選択します。
3. **Rows**ドロップダウンで、レポート対象を選択します：
    - キャンペーン
    - キャンバス
    - キャンペーンとキャンバス
    - チャネル
    - タグ

    **Rows**の選択は[表示できる指標](#metrics-availability)に影響します。例えば、多変量指標は、**キャンバス**、または**バリアント**ドリルダウンを使用した**キャンペーン**でレポートする場合にのみ表示できます。**キャンペーンとキャンバス**でレポートする場合、それらのキャンペーンやキャンバスに多変量テストがある場合でも、これらの指標を表示することはできません。

![レポートの行とグループを選択するためのフィールドがある「行と列」セクション。]({% image_buster /assets/img/report_builder_2/rows_and_columns.png %}){: style="width:90%;"}

{: start="4"}
4. （オプション）**Add drilldown**を選択して、データをより詳細なビューに分解します：
    - チャネル
    - 日付
        - データをより小さな時間範囲に分割する場合に使用します。例えば、キャンペーンの日別パフォーマンスに興味がある場合は、以下の設定を選択します：
            - **Rows**：キャンペーン
            - **Grouping：**日付
            - **Interval：**日
    - バリアント
    - キャンペーンとキャンバス

{% alert tip %}
ドリルダウンオプションのさまざまな設定を試して、[データを分解する多くの方法](#metrics-availability)を確認してみてください。
{% endalert %}

{: start="5"}
5. **Columns**セクションで、**Customize Metrics**を選択します。

![複数の指標を選択するオプションがある「Customize Metrics」セクション。]({% image_buster /assets/img/report_builder_2/customize_metrics.png %}){: style="width:90%;"}

{: start="6"}
6. カテゴリ別に指標を参照し、対応するチェックボックスを選択してレポートに指標を追加します。
    - ドットアイコンを上下にドラッグして、指標と列の順序を並べ替えます。
7. **Report content**で、レポートにデータを含める日付範囲を設定します。
8. 次に、ステップ3での選択内容に応じて、キャンペーン、キャンバス、またはその両方を手動または自動でレポートに追加します。
    - **手動で追加：** **Last Sent**の日付やタグ、チャネルのフィルターを使用するか、キャンペーンまたはキャンバスの名前を検索して、レポートに含めるキャンペーンまたはキャンバスを個別に選択します。<br><br>![選択可能なキャンペーンのリストがある「キャンペーンとキャンバスを手動で追加」セクション。]({% image_buster /assets/img/report_builder_2/manually_add.png %}){: style="width:90%;"}<br><br>
    - **自動で追加：** レポートに含めるキャンペーンまたはキャンバスのルールを設定します。このページでは、少なくとも1つのフィールドを選択する必要があります。
        - この画面で設定した条件を満たすキャンペーンまたはキャンバスが追加されると、今後のレポート実行時に自動的に含まれます。
        - **Channel**ドロップダウンにはバナーのオプションがないため、チャネルルールを使用してバナーキャンペーンまたはキャンバスを自動的に追加することはできません。ただし、レポートの指標にバナーのKPIを含めることは可能です。<br><br>![レポートに追加するキャンペーンとキャンバスのルールを設定するフィールドがある「キャンペーンとキャンバスを自動で追加」セクション。]({% image_buster /assets/img/report_builder_2/automatically_add.png %}){: style="width:90%;"}<br><br>
9. **Save & Run**を選択してレポートを実行します。

{% alert note %}
設定段階で選択した日付範囲やキャンペーンまたはキャンバスの数によっては、レポートの実行に数分かかる場合があります。
{% endalert %}

## 指標の利用可能性 {#metrics-availability}

**行**の選択により、選択できる指標が変わります。

{% alert tip %}
キャンバスのバリアントやステップについてレポートを作成したい場合は、行に**キャンバス**を選択し、フィールドを空のままにするか、ドリルダウンとして**日付**を選択します。レポートを実行すると、結果ページに**キャンバスビュー**ドロップダウンが表示され、キャンバスのみの指標を表示したり、バリアント、ステップ、またはメッセージごとに指標をグループ化したりできます。<br><br> レポートを編集する際、プレビューテーブルには最大50行が表示されます。すべての行を表示するには、レポートを実行して結果ページでページネーション（1ページあたり100行）を使用するか、完全なデータセットをCSVとしてエクスポートしてください。

![「キャンバスビュー」ドロップダウンの展開表示]({% image_buster /assets/img/report_builder_2/canvas_view_dropdown.png %}){: style="width:40%;"}
{% endalert %}

| 指標 | 説明 |
| --- | --- |
| コンバージョン指標 | キャンペーン、キャンバス、キャンペーンとキャンバス、で利用可能です。 |
| エントリ | キャンペーン、キャンバス、キャンペーンとキャンバス、タグで利用可能です。 |
| 最終送信日 | キャンペーン、キャンバス、キャンペーンとキャンバス、で利用可能です。スケジュールされたキャンペーンのみ表示されます。アクションベースまたはAPIトリガーのキャンペーンでは表示されません。 |
| 送信数 | 関連する各チャネルで利用可能です。 |
| 送信済みメッセージ | キャンペーン、キャンバス、キャンペーンとキャンバス、タグで利用可能です。 |
| 件名 | **バリアント**ドリルダウンのメールキャンペーン、キャンバス、および**バリアント**ドリルダウンのキャンバスで利用可能です。 |
| 合計収益 | キャンペーン、キャンバス、キャンペーンとキャンバス、タグで利用可能です。**チャネル**ドリルダウンでは利用できません。 |
| ユニークインプレッション | キャンペーン、キャンバス、キャンペーンとキャンバス、タグで利用可能です。 |
| ユニーク受信者 | キャンペーン、キャンバス、キャンペーンとキャンバス、タグで利用可能です。**チャネル**ドリルダウンでは利用できません。 |

### 削除されたメッセージバリアント {#deleted-message-variants}

レポートをキャンペーンまたはキャンバスで分類した場合、削除されたメッセージバリアントの統計は表示されません。ただし、チャネルレベルの合計には、バリアントが削除されたかどうかに関係なく、すべての統計が含まれます。例えば、メールの*送信数*にはすべてのメール送信が含まれますが、それらの統計をキャンペーンで分類すると、削除されたメッセージバリアントの送信がフィルタリングされるため、数値が低くなる場合があります。

同じレポートで、メッセージバリアントが送信後に削除された場合、*ユニーク受信者*が*ユニークインプレッション*より高くなることがあります。キャンペーンレベルの*ユニーク受信者*には、削除されたバリアントを受信したユーザーが引き続き含まれる一方で、*ユニークインプレッション*はメッセージレベルの集計において削除されたバリアントの統計を除外します。

## レポートの共有 {#sharing-a-report}

レポートのダッシュボードリンクを共有するには、**共有**を選択し、以下のいずれかのオプションを選択します。
- **リンクを共有：**リンクをコピーして共有します。
- **メールを送信またはスケジュール：**ダウンロードリンクを含むメールを即時または指定した時間に送信します。ダウンロードリンクは1時間後に期限切れになります。**メール受信者**ドロップダウンに表示される社内ユーザーから受信者を選択するか、他のメールアドレスを入力できます。

{% alert note %}
**メール受信者**ドロップダウンにはBrazeの社内ユーザーのみが表示され、メールアドレスはレポートスケジュール間で保存されます。外部のメールアドレスは、新しいレポートスケジュールを作成するたびに手動で入力する必要があります。パートナーの連絡先など、外部の受信者に頻繁にレポートを送信する場合は、適切な権限を持つ社内ユーザーとして追加することを検討してください。そうすることで、そのアドレスがドロップダウンに表示されるようになります。
{% endalert %}

![レポートのフォーマット、受信者、送信タイミングを選択するフィールドを含む「メールをスケジュール」ウィンドウ]({% image_buster /assets/img/report_builder_2/schedule_an_email.png %}){: style="max-width:70%;"}

- **CSVをダウンロード：**レポートのCSVをダウンロードします。

## レポートをダッシュボードに追加する {#adding-a-report-to-a-dashboard}

1. レポートテーブルの上部にあるドットアイコンを選択します。
2. **ダッシュボードに追加**を選択します。
3. 新しいダッシュボードを作成するか、既存のダッシュボードに追加するかを選択します。<br><br>![新しいダッシュボードに追加するか既存のダッシュボードに追加するかを選択するオプションが表示されたウィンドウ。]({% image_buster /assets/img/report_builder_2/add_to_dashboard.png %}){: style="width:90%;"}<br><br>
4. ダッシュボードの構築について詳しくは、[ダッシュボードビルダー]({{site.baseurl}}/user_guide/analytics/dashboards/dashboard_builder)のステップに従ってください。

## チームの権限 {#team-permissions}

レポートビルダーのレポートは、キャンペーンやキャンバスのような[チーム割り当て]({{site.baseurl}}/user_guide/administer/global/user_management/teams)をサポートしていません。レポートを作成する際に、保存したレポートを特定のチームに制限することはできません。

チームレベルの[「ダッシュボードレポートの表示」]({{site.baseurl}}/user_guide/administer/global/user_management/permissions)権限（ワークスペースレベルではなく）を持つユーザーは引き続きレポートビルダーを使用できますが、レポートの表示は制限されます。

- これらのユーザーは、選択されたすべてのキャンペーンとキャンバスが自分のチームに割り当てられているレポートのみを表示できます。
- **チャネル**を行として使用するレポートは非表示になります。
- 自動選択を使用してキャンペーンやキャンバスを追加するレポートは非表示になります。これは、レポート実行時に追加される可能性のあるメッセージに対して、Brazeがチームアクセスを検証できないためです。

[レポートビルダー（レガシー）]({{site.baseurl}}/report_builder_legacy)では、レポートに追加できるキャンペーンやキャンバスをチームごとにスコープしますが、保存されたレポートはレポートビルダー（新）と同じ方法でリストからフィルタリングされません。権限の設定については、[ユーザー権限の設定]({{site.baseurl}}/user_guide/administer/global/user_management/permissions)および[チーム]({{site.baseurl}}/user_guide/administer/global/user_management/teams)を参照してください。

## トラブルシューティング {#troubleshooting}

### キャンペーンまたはキャンバスの送信がレポートに表示されない {#report-shows-no-sends-for-a-campaign-or-canvas}

キャンペーンまたはキャンバスは、**最終送信日**が設定した**最終送信日**の範囲内にある場合にレポートに表示されます。**送信数**やその他の指標は、**データの表示期間**の日付範囲内のアクティビティに対してのみ入力されます。**データの表示期間**中にメッセージが送信されなかった場合、その行にはキャンペーンまたはキャンバスが送信数ゼロで表示されることがあります。

例えば、**最終送信日**が2025年1月1日〜2025年4月14日に設定されているためキャンペーンが含まれているが、**データの表示期間**が2024年12月1日〜2025年1月14日の場合を考えます。そのキャンペーンが12月や1月に送信がなかった場合でも、送信指標なしでテーブルに表示されます。

### ダウンロードリンクの有効期限が切れている {#download-link-has-expired}

レポートのダウンロードリンクは1時間後に有効期限が切れます。リンクの有効期限が切れた場合は、新しいレポートを生成し、1時間以内にダウンロードしてください。有効期限を延長する方法はありません。

[Amazon S3バケット]({{site.baseurl}}/partners/data_and_analytics/cloud_storage/amazon_s3)が**パートナー連携**に接続されている場合は、S3バケットを直接参照して古いレポートのデータを取得できる場合があります。
