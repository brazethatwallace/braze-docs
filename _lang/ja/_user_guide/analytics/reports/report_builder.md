# レポートビルダー {#report-builder}

> このページでは、レポートビルダーを使用してBrazeデータに基づく詳細なレポートを作成・表示する方法と、レポートをダッシュボードに追加する方法について説明します。

以下の動画では、レポートビルダーでレポートを作成しカスタマイズする方法の概要を紹介しています。

{% multi_lang_include video.html id="oi66kwwldv" source="wistia" %}

## レポートテンプレートの使用 {#using-a-report-template}

1. **Analytics** > **レポートビルダー（新）**に移動します。
2. **新しいレポートを作成**ボタンの横にある**その他のオプション**の矢印を選択し、**レポートテンプレートを使用**を選択します。<br><br>![「新しいレポートを作成」ボタンのドロップダウン。カスタムレポートの作成またはテンプレートの使用オプションが表示されています。]({% image_buster /assets/img/report_builder_2/create_new_report.png %}){: style="max-width:40%;"}<br><br>
3. Brazeテンプレートライブラリからレポートテンプレートを1つ選択します。
    - **行アイテム**と**タグ**のドロップダウンを使用して、ユースケースに関連するレポートを検索します。<br><br>![「Brazeレポートテンプレート」ウィンドウ。選択可能なBrazeテンプレートの一覧が表示されています。]({% image_buster /assets/img/report_builder_2/report_templates.png %}){: style="max-width:90%;"}<br><br>
4. [レポートの作成](#creating-a-report)のステップ3以降に従って、ユースケースに合わせてレポートをさらにカスタマイズします。

## レポートの作成 {#creating-a-report}

1. **Analytics** > **レポートビルダー（新）**に移動します。
2. **新しいレポートを作成**を選択します。
3. **行**ドロップダウンで、レポートする対象を選択します：
    - キャンペーン
    - キャンバス
    - キャンペーンとキャンバス
    - チャネル
    - タグ

    **行**の選択は、[表示できる指標](#metrics-availability)に影響します。例えば、多変量の指標を表示できるのは、**キャンバス**、または**バリアント**のドリルダウンを含む**キャンペーン**でレポートする場合のみです。**キャンペーンとキャンバス**でレポートする場合は、それらのキャンペーンやキャンバスに多変量テストがあっても、これらの指標を表示することはできません。

![レポートの行とグループを選択するフィールドを含む「行と列」セクション。]({% image_buster /assets/img/report_builder_2/rows_and_columns.png %}){: style="width:90%;"}

{: start="4"}
4. （オプション）**ドリルダウンを追加**を選択して、データをより詳細なビューに分割します：
    - チャネル
    - 日付
        - データをより小さな時間範囲に分割するために使用します。例えば、キャンペーンが日ごとにどのようなパフォーマンスだったかを知りたい場合は、以下の設定を選択します：
            - **行：** キャンペーン
            - **グループ：** 日付
            - **間隔：** 日
    - バリアント
    - キャンペーンとキャンバス

{% alert tip %}
さまざまなドリルダウンオプションの設定を試して、[データを分割する多くの方法](#metrics-availability)を探索してください。
{% endalert %}

{: start="5"}
5. **列**セクションで、**指標をカスタマイズ**を選択します。

![複数の指標を選択するオプションを含む「指標をカスタマイズ」セクション。]({% image_buster /assets/img/report_builder_2/customize_metrics.png %}){: style="width:90%;"}

{: start="6"}
6. カテゴリ別に指標を参照し、対応するチェックボックスを選択してレポートに指標を追加します。
    - **一般**の下で、**タグ**を選択して、レポートの各行にあるキャンペーンまたはキャンバスに適用されたタグを含めます。
    - ドットアイコンを上下にドラッグして、指標と列を並べ替えます。
7. **レポートコンテンツ**で、レポートにデータを含める日付範囲を設定します。
8. 次に、ステップ3での選択に応じて、キャンペーン、キャンバス、またはその両方を手動または自動でレポートに追加します。
    - **手動で追加：** **最終送信日**やタグまたはチャネルのフィルターを使用するか、キャンペーンまたはキャンバスの名前を検索して、レポートに含める各キャンペーンまたはキャンバスを選択します。<br><br>![選択可能なキャンペーンのリストを含む「キャンペーンとキャンバスを手動で追加」セクション。]({% image_buster /assets/img/report_builder_2/manually_add.png %}){: style="width:90%;"}<br><br>
    - **自動で追加：** レポートに含めるキャンペーンまたはキャンバスのルールを設定します。このページでは少なくとも1つのフィールドを選択する必要があります。
        - この画面で設定した条件を満たす追加のキャンペーンまたはキャンバスは、レポートの今後の実行時に自動的に追加されます。
        - バナーは**チャネル**ドロップダウンのオプションにないため、チャネルルールを使用してバナーのキャンペーンやキャンバスを自動追加することはできません。バナーのKPIをレポートの指標に含めることは可能です。<br><br>![レポートに追加するキャンペーンとキャンバスのルールを設定するフィールドを含む「キャンペーンとキャンバスを自動的に追加」セクション。]({% image_buster /assets/img/report_builder_2/automatically_add.png %}){: style="width:90%;"}<br><br>
9. **保存して実行**を選択してレポートを実行します。

{% alert note %}
設定段階で選択した日付範囲やキャンペーンまたはキャンバスの数によっては、レポートの実行に数分かかる場合があります。
{% endalert %}

## 指標の利用可能性 {#metrics-availability}

**行**の選択によって、選択できる指標が異なります。

{% alert tip %}
キャンバスのバリアントやステップについてレポートしたい場合は、行として**キャンバス**を選択し、フィールドを空のままにするか、ドリルダウンとして**日付**を選択します。レポートを実行すると、結果ページに**キャンバスビュー**ドロップダウンが表示され、キャンバスのみの指標を表示したり、バリアント、ステップ、またはメッセージごとに指標をグループ化したりできます。<br><br>レポートを編集する際、プレビューテーブルには最大50行が表示されます。レポートを実行すると、結果ページでページネーション付き（1ページあたり100行）のすべての行を表示できるほか、完全なデータセットをCSVとしてエクスポートすることもできます。

![開いた「キャンバスビュー」ドロップダウン]({% image_buster /assets/img/report_builder_2/canvas_view_dropdown.png %}){: style="width:40%;"}
{% endalert %}

| 指標 | 説明 |
| --- | --- |
| コンバージョン指標 | キャンペーン、キャンバス、キャンペーンとキャンバス、で利用可能です。 |
| エントリ | キャンペーン、キャンバス、キャンペーンとキャンバス、タグで利用可能です。 |
| 最終送信日 | キャンペーン、キャンバス、キャンペーンとキャンバスで利用可能です。スケジュールされたキャンペーンのみに表示されます。アクションベースまたはAPIトリガーのキャンペーンでは表示されません。 |
| タグ | キャンペーン、キャンバス、キャンペーンとキャンバスで利用可能です。各キャンペーンまたはキャンバスに適用されたタグを一覧表示します。メッセージに複数のタグがある場合、セミコロン区切りのリストとして表示されます。 |
| 送信数 | 関連する各チャネルで利用可能です。 |
| 送信済みメッセージ | キャンペーン、キャンバス、キャンペーンとキャンバス、タグで利用可能です。 |
| 件名 | **バリアント**ドリルダウン付きのメールキャンペーン、キャンバス、および**バリアント**ドリルダウン付きのキャンバスで利用可能です。 |
| 合計収益 | キャンペーン、キャンバス、キャンペーンとキャンバス、タグで利用可能です。**チャネル**ドリルダウンでは利用できません。 |
| ユニークインプレッション | キャンペーン、キャンバス、キャンペーンとキャンバス、タグで利用可能です。 |
| ユニーク受信者 | キャンペーン、キャンバス、キャンペーンとキャンバス、タグで利用可能です。**チャネル**ドリルダウンでは利用できません。 |

### 削除されたメッセージバリアント {#deleted-message-variants}

キャンペーンまたはキャンバスごとにレポートを分類した場合、削除されたメッセージバリアントの統計は表示されません。ただし、チャネルレベルの合計には、バリアントが削除されたかどうかに関係なく、すべての統計が含まれます。例えば、メールの*送信数*にはすべてのメール送信が含まれますが、それらの統計をキャンペーンごとに分類すると、削除されたメッセージバリアントの送信数がフィルターされるため、数値が低くなる場合があります。

同じレポートで、メッセージバリアントが送信後に削除された場合、*ユニーク受信者*が*ユニークインプレッション*よりも多くなることがあります。キャンペーンレベルの*ユニーク受信者*には、削除されたバリアントを受け取ったユーザーが引き続き含まれる一方、*ユニークインプレッション*ではメッセージレベルの集計で削除されたバリアントの統計が除外されます。

## レポートの共有 {#sharing-a-report}

レポートのダッシュボードリンクを共有するには、**共有**を選択し、以下のいずれかのオプションを選択します。
- **リンクを共有：**リンクをコピーして共有します。
- **メールを送信またはスケジュール：**ダウンロードリンクを含むメールを即時または指定した時間に送信します。ダウンロードリンクは1時間後に期限切れになります。**メール受信者**ドロップダウンに表示される会社のユーザーから受信者を選択するか、他のメールアドレスを入力できます。

{% alert note %}
**メール受信者**ドロップダウンにはBrazeの会社ユーザーのみが表示され、レポートスケジュール全体でメールアドレスが保存されます。外部のメールアドレスは、新しいレポートスケジュールを作成するたびに手動で入力する必要があります。パートナーの連絡先など、外部の受信者に頻繁にレポートを送信する場合は、適切な権限を持つ会社ユーザーとして追加することを検討してください。そうすることで、そのアドレスがドロップダウンに表示されるようになります。
{% endalert %}

![レポートの形式、受信者、送信タイミングを選択するフィールドが含まれる「メールをスケジュール」ウィンドウ。]({% image_buster /assets/img/report_builder_2/schedule_an_email.png %}){: style="max-width:70%;"}

- **CSVをダウンロード：**レポートのCSVをダウンロードします。

## レポートをダッシュボードに追加する {#adding-a-report-to-a-dashboard}

1. レポートテーブルの上部にあるドットアイコンを選択します。
2. **ダッシュボードに追加**を選択します。
3. 新しいダッシュボードを作成するか、既存のダッシュボードに追加するかを選択します。<br><br>![新しいダッシュボードに追加するか、既存のダッシュボードに追加するかを選択するオプションが表示されたウィンドウ。]({% image_buster /assets/img/report_builder_2/add_to_dashboard.png %}){: style="width:90%;"}<br><br>
4. ダッシュボードの構築について詳しくは、[ダッシュボードビルダー]({{site.baseurl}}/user_guide/analytics/dashboards/dashboard_builder)のステップに従ってください。

## チームの権限 {#team-permissions}

レポートビルダーのレポートは、キャンペーンやキャンバスのような[チーム割り当て]({{site.baseurl}}/user_guide/administer/global/user_management/teams)をサポートしていません。レポートを作成する際に、保存したレポートを特定のチームに制限することはできません。

チームレベルの[「ダッシュボードレポートの表示」]({{site.baseurl}}/user_guide/administer/global/user_management/permissions)権限（ワークスペースレベルではなく）を持つユーザーは引き続きレポートビルダーを使用できますが、レポートの表示は制限されます。

- これらのユーザーは、選択されたすべてのキャンペーンとキャンバスが自分のチームに割り当てられているレポートのみを表示できます。
- **チャネル**を行として使用するレポートは非表示になります。
- 自動選択を使用してキャンペーンやキャンバスを追加するレポートは非表示になります。これは、レポート実行時に追加される可能性のあるメッセージに対して、Brazeがチームアクセスを検証できないためです。

[レポートビルダー（レガシー）]({{site.baseurl}}/report_builder_legacy)では、レポートに追加できるキャンペーンやキャンバスをチームごとにスコープしますが、保存されたレポートはレポートビルダー（新）と同じ方法でリストからフィルタリングされません。権限の設定については、[ユーザー権限の設定]({{site.baseurl}}/user_guide/administer/global/user_management/permissions)および[チーム]({{site.baseurl}}/user_guide/administer/global/user_management/teams)を参照してください。

## トラブルシューティング {#troubleshooting}

### レポートにキャンペーンまたはキャンバスの送信が表示されない {#report-shows-no-sends-for-a-campaign-or-canvas}

キャンペーンまたはキャンバスは、**最終送信**日が設定した**最終送信**ウィンドウの範囲内にある場合にレポートに表示されます。**送信数**やその他の指標は、**データの表示期間**の日付範囲内のアクティビティに対してのみ入力されます。**データの表示期間**中にメッセージが送信されなかった場合でも、そのキャンペーンまたはキャンバスは送信数ゼロとして行に表示されることがあります。

例えば、**最終送信**が2025年1月1日～2025年4月14日に設定されているためキャンペーンが含まれているものの、**データの表示期間**が2024年12月1日～2025年1月14日の場合を考えます。そのキャンペーンが12月または1月に送信を行っていなかった場合でも、テーブルには送信指標なしで表示されます。

### ダウンロードリンクの有効期限切れ {#download-link-has-expired}

レポートのダウンロードリンクは1時間で有効期限が切れます。リンクの有効期限が切れた場合は、新しいレポートを生成し、1時間以内にダウンロードしてください。有効期限を延長する方法はありません。

[Amazon S3バケット]({{site.baseurl}}/partners/data_and_analytics/cloud_storage/amazon_s3)を**パートナー連携**で接続している場合は、S3バケットを直接参照することで、過去のレポートからデータを取得できる場合があります。
