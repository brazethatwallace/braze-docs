# レポートビルダー（レガシー） {#report-builder-legacy}

> レポートビルダーを使用すると、複数のキャンペーンまたはキャンバスの結果を1つのビューで比較できるため、どのエンゲージメント戦略が主要な指標に最も影響を与えたかを簡単に判断できます。キャンペーンとキャンバスの両方について、データをエクスポートし、レポートを保存して将来表示することができます。<br><br>レポートに含まれる指標の説明リストについては、[レポート指標用語集]({{site.baseurl}}/user_guide/analytics/metrics_glossary)を参照してください。

![キャンペーンの比較例]({% image_buster /assets/img/campaign_comparison/campaign_main.png %}){: style="max-width:80%;"}

このレポートを使用して、主要なエンゲージメントに関する質問に答えることができます。例えば：

- 特定のタグやチャネルで最もパフォーマンスが高かったキャンペーンまたはキャンバスはどれですか？
- 多変量キャンペーンのどのバリアントがコントロールに対して最も大きな向上をもたらしましたか？
- どの季節のプロモーションキャンペーンがより高い購入率につながりましたか？夏のセール、秋のセール、それとも冬のセールですか？
- このキャンバス内のどのプッシュ通知が最も高い開封率を記録しましたか？
- このキャンバスグループのどのステップが最も多くのコンバージョンを獲得しましたか？
- ウェルカムメールのバージョン1とバージョン2では、どちらがより高いエンゲージメントとコンバージョンにつながりましたか？変更は効果がありましたか？
- 異なる配信方法（例えば、3つのスケジュールされたプッシュ、3つのアクションベースのプッシュ、3つのAPIトリガーのプッシュ）は、開封率、コンバージョン率、または購入率にどのような影響を与えますか？
- 離脱ユーザーメッセージの継続的な改善は、時間の経過とともにKPIにプラスの影響を与えましたか？

{% alert tip %}
比較したいキャンペーンやキャンバスのコンバージョンA、Bなどに同じコンバージョンイベントを使用するようにしてください。そうすることで、レポートビルダーのレポートでこれらのコンバージョンを揃えることができます。
{% endalert %}

## レポートの実行 {#running-a-report}

### ステップ 1:新しいレポートを作成する {#step-1-create-a-new-report}

ダッシュボード内で、**Analytics** > **レポートビルダー**に移動します。

**新しいレポートを作成**を選択し、キャンペーン比較レポートまたはキャンバス比較レポートのいずれかを選択します。

キャンペーンのレポートを実行する場合、**手動**または**自動**レポートのいずれかを選択できます。レポートにはキャンペーンまたはキャンバスのいずれかを含めることができますが、両方を一緒に含めることはできません。過去12か月以内に最後にメッセージを送信したキャンペーンおよびキャンバスがレポートの対象となります。

![キャンペーンダッシュボード]({% image_buster /assets/img/campaign_comparison/create_report.png %}){: style="max-width:80%;"}

以下は、これら2つのオプションの違いです：

| **アクション** | **手動** | **自動** |
| ---- | ---------- | ------------- |
| **レポートの構築** | フィルターを使用してキャンペーンリストを絞り込み、特定のキャンペーンにチェックを入れることができます。 | フィルターオプションを使用してキャンペーンリストを絞り込むことでレポートを構築します。 |
| **レポートの保存と表示** | レポートを保存できます。次回表示する際には、以前追加したのと同じキャンペーンを表示できます。これらのキャンペーンは引き続き「最終送信」フィルターに該当するためです。 | レポートを保存できます。次回表示する際には、現在フィルターに一致するすべてのキャンペーンを含むようにレポートが自動的に更新されます。 |
| **レポートの編集** | **レポートを編集**を選択して、レポートからキャンペーンを追加または削除できます。 | フィルター条件を調整してレポートを編集できます。 |
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3 aria-label="ステップ 1: 新しいレポートを作成する" }

{% alert note %}
**手動**と**自動**の両方のレポートには、最大250件のキャンペーンを含めることができます。
{% endalert %}

キャンバスレポートは手動キャンペーンレポートと同様に機能し、キャンバスの選択とレポートの更新も手動で行う必要があります。1つのレポートに最大5つのキャンバスを含めることができます。

### ステップ 2:指標を選択する {#step-2-choose-your-metrics}

レポートを作成すると、各行にキャンペーンが含まれた空のテーブルが表示されます。**列を編集**を選択して追加したい指標を選ぶと、テーブルにデータが入力されます。

![キャンペーンオプション]({% image_buster /assets/img/campaign_comparison/campaign_comparison_columns.png %}){: style="max-width:80%;"}

選択した指標でテーブルにデータが入力されます。これらの指標の定義については、[レポート指標用語集]({{site.baseurl}}/user_guide/analytics/metrics_glossary)を参照してください。一部の指標はキャンペーン比較レポートでのみ利用可能です。

また、任意の割合または数値指標の**平均**と、任意の数値指標の**合計**の計算を切り替えることもできます。

### ステップ 3:期間を選択する {#step-3-choose-a-time-period}

特定の期間を選択して、レポートのデータを表示できます。特定のキャンペーン、キャンバス、キャンバスバリアント、またはキャンバスコンポーネントに選択した期間のデータがない場合、その行の結果は空白になります。

![キャンペーン数値指標]({% image_buster /assets/img/campaign_comparison/metric.png %}){: style="max-width:60%;"}

### ステップ 4:レポートに名前を付けて保存する {#step-4-name-and-save-your-report}

保存する前にレポートに名前を付けてください。名前を付けずにレポートを保存した場合、Brazeはデフォルト名「キャンペーン Comparison Report」を適用します。

![キャンペーンメモ]({% image_buster /assets/img/campaign_comparison/comparison_name.png %}){: style="max-width:60%;"}

準備ができたら、**保存**を選択します。保存されたレポートは、後から**レポートビルダー**ページで表示できます。

## 多変量キャンペーンを含むキャンペーン比較レポート {#campaign-comparison-report-with-multivariate-campaigns}

多変量キャンペーンの場合、キャンペーン名の横にある矢印をクリックすると、バリアントとコントロールグループごとに分類された指標を表示できます。バリアントを含む行にはそのバリアントのパフォーマンス結果が含まれ、コントロールを含む行にはコンバージョンイベントの結果のみが含まれます。

![キャンペーンメモ]({% image_buster /assets/img/campaign_comparison/compare_note.png %}){: style="float:right;max-width:15%;margin-left:15px;"}

キャンペーン全体の行に入力される指標はバリアントのパフォーマンスを反映しますが、コントロールのパフォーマンスは含まれません。例えば、キャンペーン全体の1次コンバージョンイベントAは、バリアントの1次コンバージョンイベントAの合計であり、コントロールの1次コンバージョンイベントAは含まれません。

{% alert important %}
多変量キャンペーンからバリアントを削除した場合、そのバリアントのデータは将来のレポートで使用できなくなります。
{% endalert %}

## キャンバス比較レポートの内訳 {#canvas-comparison-report-breakdown}

キャンバスレポート内では、バリアント、ステップ、またはメッセージごとにキャンバスを分類して表示できます。

### バリアント {#variant}

**バリアントごとの内訳**を選択すると、キャンバス全体の概要統計と、各バリアントの統計を表示できます。キャンバス名の横にある矢印を選択すると展開できます。

![バリアント]({% image_buster /assets/img/campaign_comparison/campaign_comparison1.png %}){: style="max-width:90%;"}

### ステップ {#steps}

**ステップごとの内訳**を選択すると、ステップレベルの指標を表示でき、レポートの各行にステップの行が含まれます。

![ステップ]({% image_buster /assets/img/campaign_comparison/campaign_comparison2.png %}){: style="max-width:90%;"}

### メッセージ {#message}

ステップレベルの内訳と同様に、**メッセージごとの内訳**を選択すると、各行にステップの名前が表示されます。ただし、**列を編集**内では、メールのクリック数やプッシュの開封数などのチャネル固有の統計といったメッセージレベルの指標にアクセスできます。

![レポート]({% image_buster /assets/img/campaign_comparison/campaign_comparison3.png %}){: style="max-width:90%;"}

Brazeダッシュボード内では、キャンバスレポートの最初の50行をプレビューできます。CSVをエクスポートすると、完全なレポートにアクセスできます。

## 保存されたレポートへのアクセス {#accessing-saved-reports}

保存された**手動レポート**にアクセスすると、以前追加したのと同じキャンペーンを表示できます。これらのキャンペーンは引き続き「最終送信」フィルターに該当するためです。

保存された**自動レポート**にアクセスすると、現在フィルターに一致するすべてのキャンペーンを含むようにレポートが自動的に更新されます。例えば、レポートが「プロモーション」タグでキャンペーンをフィルタリングしている場合、このレポートを表示するたびに、このレポートを作成した後に作成されたキャンペーンであっても、「プロモーション」タグが付いたすべてのキャンペーンを表示できます。

## レポートの編集 {#editing-reports}

**手動レポート**では、**編集**を選択してレポートを編集できます。そこから、レポートに含めるキャンペーンを選択または選択解除できます。

**自動レポート**では、フィルターを切り替えてレポートの結果を絞り込みます。

## レポートのエクスポート {#exporting-reports}

**エクスポート**を選択して、レポートをCSVにダウンロードすることもできます。

レポートに多変量キャンペーンが含まれている場合、エクスポートには2つのCSVファイルが含まれます：

- 各キャンペーンのトップレベル指標のみを含むファイル
- バリアントレベルの指標を含むファイル

バリアント指標を含むファイルには、名前の先頭に`variant_`が付加されます。自動レポートを初めてエクスポートする際、複数ファイルのダウンロードを許可するかどうかを尋ねるポップアップが表示されます。**許可**をクリックしてください。

![キャンペーンダウンロード]({% image_buster /assets/img/campaign_comparison/download.png %}){: style="max-width:60%;"}

### キャンバス比較レポートのエクスポート {#exporting-canvas-comparison-reports}

CSVエクスポートは、**エクスポート**を選択した時点で表示していた内訳ビューを反映します。例えば、ステップレベルの内訳ビューを表示していた場合、エクスポートにはステップ指標のデータが含まれます。別の内訳からデータをエクスポートするには、まずその内訳に移動してから、そこで**エクスポート**を選択する必要があります。

バリアント内訳のキャンバスレポートをダウンロードすると、2つのCSVファイルが届きます：

- 各キャンバスのトップレベル指標のみを含むファイル
- バリアントレベルの指標を含むファイル

## チャートの構築 {#building-charts}

チャートを使用して、レポート内の選択した指標を視覚化できます。チャートは、キャンペーンを含み、列に少なくとも1つの指標が追加されているレポートで利用可能です。

![「送信メッセージ」指標が選択されたキャンペーンパフォーマンスチャート]({% image_buster /assets/img/campaign_comparison/report_builder_charts.png %})

デフォルトでは、各レポートのチャートはレポートの最初の列の指標を表示します。グラフに表示する別の指標を選択するには、ドロップダウンから指標を選択してください。レポートテーブル内の任意の指標をチャートに表示できます。

最大3つの指標をグラフ化できます。すべての指標の単位は同じである必要があります。例えば、最初のドロップダウンで割合を選択した場合、2番目のドロップダウンでも割合のみが選択可能になります。

チャートに指標が1つだけ含まれている場合、選択した指標に基づいて降順で最大30件のキャンペーンが表示されます。例えば、チャートの指標がメールのクリック数の場合、最もクリック数の多い30件のメールキャンペーンが、多い順に表示されます。レポートに30件以上のキャンペーンが含まれている場合、上位30件のみがチャートに表示されます。複数の指標を選択した場合、グラフには最初に選択した指標に基づく上位5件のキャンペーンのみが表示されます。

チャートは現在、レポートを保存する際に保存されません。
