# ダッシュボードビルダー {#dashboard-builder}

> ダッシュボードビルダーを使用して、レポートビルダーまたはクエリビルダーで作成したレポートからダッシュボードやビジュアライゼーションを作成できます。

ダッシュボードビルダーでは、カスタム分析ダッシュボードをゼロから作成・可視化したり、Brazeが提供するダッシュボードをベースにしたりできます。ノーコードのデータソース（レポートビルダー）またはSQLデータソース（クエリビルダー）を使用してダッシュボードを構築するか、Brazeが提供する多数のダッシュボードから開始できます。

## カスタムダッシュボードの作成 {#creating-a-custom-dashboard}

1. **Analytics** > **ダッシュボードビルダー**に移動します。
2. **Create Dashboard**を選択します。
3. レポートを構築するデータソースを選択します：
- レポートビルダーで作成した**Reports**
- クエリビルダーで作成した**Custom Queries**<br><br>![ダッシュボードのデータソースを選択する画面。]({% image_buster /assets/img/select_data_source.png %})<br><br>

次に、データソースに応じた手順に従ってください：

{% tabs %}
{% tab レポート %}

{: start="4"}
4. **+ Add Tile**を選択し、[レポートビルダー（新）]({{site.baseurl}}/user_guide/analytics/reports/report_builder/)で作成したレポートの1つを選択します。

{% alert important %}
レポートビルダーのレポートをダッシュボードビルダーのタイルに追加した後、そのタイルは元のレポートとは接続されません。レポートビルダーで元のレポートを編集した場合は、既存のダッシュボードタイルを削除し、更新されたレポートをデータソースとして使用して新しいタイルを作成する必要があります。
{% endalert %}

{: start="5"}
5. 鉛筆アイコンを選択して、タイルのタイトルとチャートタイプの表示方法を変更します。
    - デフォルトのビジュアライゼーションの下にある異なるチャートタイプを切り替えることができます。現在のオプションには、棒グラフ（水平または垂直）と折れ線グラフ（レポートビルダーの設定でドリルダウンオプションとして**Date**を選択した場合のみ利用可能）があります。<br><br>![異なるチャートタイプの切り替え。]({% image_buster /assets/img/report_builder_types.png %})<br><br>
    - 指標ドロップダウンを使用して、ビジュアライゼーションに含める指標を選択します。デフォルトでは、レポートの最初の列がデフォルトの表示指標になります。
6. ビジュアライゼーションを好みに合わせて変更したら、**Save**を選択します。
7. 名前、説明、タグを追加して、後でダッシュボードを見つけやすくします。
{% endtab %}
{% tab カスタムクエリ %}
{: start="4"}
4. **+ Add Tile**を選択し、クエリビルダーで実行したクエリを選択します。
5. タイルでのクエリ結果の表示方法を編集するには、鉛筆アイコンを選択してタイトルとチャートタイプを変更します。
    - デフォルトのビジュアライゼーションの下にある異なるチャートタイプを切り替えることができます。現在のオプションには、テーブル、棒グラフ（水平または垂直）、折れ線グラフがあります。<br><br>![異なるチャートタイプの切り替え。]({% image_buster /assets/img/query_builder_types.png %})<br><br>
        - チャートオプションのいずれかを選択した場合は、**X-axis**ドロップダウンを使用して、クエリ結果からX軸として使用する単一の列を選択します。
        - **Y-axis**ドロップダウンを使用して、ビジュアライゼーションに含める指標を選択します。デフォルトでは、クエリ結果のすべての列が表示されるため、表示する必要のない列の選択を解除してください。<br><br>![異なるチャートタイプの切り替え。]({% image_buster /assets/img/query_builder_axis.png %})<br><br>
        - （オプション）**Grouping**ドロップダウンを使用して、クエリ結果をグループ化できます。たとえば、列の結果としてキャンペーン IDがあり、その値を持つすべての行を合計したい場合は、**Grouping**ドロップダウンを使用します。
        - （オプション）表示されているデータを編集するには、ビジュアルに関連付けられたクエリを選択し、[クエリビルダー]({{site.baseurl}}/user_guide/analytics/reports/query_builder/)で編集を行います。
6. ビジュアライゼーションを好みに合わせて変更したら、**Save**を選択します。
7. 名前、説明、タグを追加して、後でダッシュボードを見つけやすくします。
{% endtab %}
{% endtabs %}

{: start="8"}
8. 目的のダッシュボードが完成するまで、それぞれの方法に応じてステップ4〜7を繰り返します。
9. **View Dashboard** > **Run Dashboard**を選択します。

ダッシュボードのレポート生成が完了するまで数分かかる場合があります。

{% alert note %}
ダッシュボードには最大10個のタイルを追加できます。
{% endalert %}

## ダッシュボードタイルの管理 {#managing-dashboard-tiles}

### タイルの削除 {#delete-tiles}

タイルの下部にある**Delete Tile**を選択して、ダッシュボードタイルを削除します。**この操作は元に戻せません。**

### タイルの複製 {#duplicate-tiles}

タイルの下部にある**Duplicate Tile**を選択して、タイルのコピーを作成します。

### タイルのサイズと位置の調整 {#adjust-tile-size-and-position}

タイルの右下隅をドラッグしてタイルのサイズを調整し、タイルの右上隅にあるハンドルをドラッグしてダッシュボード上のタイルの位置を調整します。

## ダッシュボードの実行 {#running-a-dashboard}

1. **Analytics** > **ダッシュボードビルダー**に移動します。ホームページには、ワークスペース内の既存のすべてのダッシュボードが一覧表示され、Brazeが作成したダッシュボードが上部に表示されます。これらはタイトルに「(Braze)」と表示されます。
2. 対象のダッシュボードを選択します。
3. **Run Dashboard**を選択して、そのダッシュボードを読み込みます。

### 利用可能なダッシュボード {#available-dashboards}

Brazeは、ラストタッチアトリビューションを使用した収益分析など、よく使われるユースケース向けに事前構築されたダッシュボードを提供しています。ダッシュボードの編集機能はまだ利用できません。今後特定のダッシュボードをご希望の場合は、カスタマーサクセスマネージャーにお問い合わせください。

#### 収益 - ラストタッチアトリビューション {#revenue-last-touch-attribution}

**収益 - ラストタッチアトリビューション**ダッシュボードでは、キャンペーン、キャンバス、チャネル全体の収益を確認できます。すべての収益データは、アトリビューション時間枠内で最後にタッチされたメッセージに帰属されます。

タッチには、_メールクリック_（リンククリック）、_コンテンツカードクリック_、_アプリ内メッセージクリック_（閉じるボタンを除く）、_プッシュ開封_、_SMSショートリンククリック_、_WhatsApp既読_、_Webhook送信_が含まれます。

| 指標 | 定義 |
| --- | --- |
| ラストタッチ収益合計 | 選択した日付範囲とアトリビューション時間枠内にラストタッチイベントがあるすべてのキャンペーンおよびキャンバスの収益イベントの合計。 |
| 購入コンバージョン合計 | 対象となるラストタッチイベントがあるすべてのキャンペーンおよびキャンバスの収益イベントの件数。 |
| コンバージョンまでの平均日数 | 対象となるラストタッチイベントがあるすべてのキャンペーンおよびキャンバスの購入イベント間の平均時間。 |
| 受信者あたりの収益 | 対象となる収益イベントからの収益合計を、日付範囲内にメッセージを受信したユニークユーザー数で割った値。 |
| ユニーク購入者数 | 対象となる収益イベントがあるユニークユーザーの数。 |
| 国別収益 | ラストタッチイベントがあるすべてのキャンペーンおよびキャンバスの収益イベントの合計（国別にグループ化）。 |
| キャンペーン別収益 | 対象となるラストタッチイベントがあるすべてのキャンペーンおよびキャンバスの収益イベントの合計（キャンペーン別にグループ化）。 |
| キャンペーンバリアント別収益 | 対象となるラストタッチイベントがあるすべてのキャンペーンおよびキャンバスの収益イベントの合計（キャンペーンバリアント別にグループ化）。 |
| キャンバス別収益 | 対象となるラストタッチイベントがあるすべてのキャンペーンおよびキャンバスの収益イベントの合計（キャンバス別にグループ化）。 |
| キャンバスバリアント別収益 | 対象となるラストタッチイベントがあるすべてのキャンペーンおよびキャンバスの収益イベントの合計（キャンバスバリアント別にグループ化）。 |
| 製品別購入数 | 製品別にグループ化されたすべての購入の件数。 |
| チャネル別収益 | 対象となるラストタッチイベントがあるすべてのキャンペーンおよびキャンバスの収益イベントの合計（チャネル別にグループ化）。 |
| 収益時系列 | 対象となるラストタッチイベントがあるすべてのキャンペーンおよびキャンバスの収益イベントの合計（UTC日別にグループ化）。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Revenue - Last Touch Attribution" }

#### セッション分析 {#session-analytics}

| 指標 | 定義 |
|---|---|
| 日別セッション数（時系列） | 選択した日付範囲内のユニークセッション数を日別にグループ化し、時系列として表示します。 |
| ユーザーあたりの平均セッション数 | 選択した日付範囲内のセッション合計をユニークユーザー数で割って算出した、ユーザーあたりの平均セッション数。 |
| セッションにコンバージョンしたキャンペーン | キャンペーンコンバージョンと同時に発生したユニークセッション数（キャンペーン ID別にグループ化し、セッション数でランキング）。 |
| セッションにコンバージョンしたキャンバス | キャンバスコンバージョンと同時に発生したユニークセッション数（キャンバス ID別にグループ化し、セッション数でランキング）。 |
| ユーザーあたりの合計セッション数 | 選択した日付範囲内のセッション数合計が多い上位1,000ユーザーのリスト。 |
