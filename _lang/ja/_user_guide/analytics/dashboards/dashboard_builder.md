# ダッシュボードビルダー {#dashboard-builder}

> ダッシュボードビルダーを使用して、レポートビルダーまたはクエリビルダーで作成したレポートからダッシュボードやビジュアライゼーションを作成できます。

ダッシュボードビルダーでは、カスタム分析ダッシュボードをゼロから作成・可視化したり、Brazeが提供するダッシュボードをベースにしたりできます。ノーコードのデータソース（レポートビルダー）またはSQLデータソース（クエリビルダー）を使用してダッシュボードを構築するか、Brazeが提供する多数のダッシュボードから開始できます。

## カスタムダッシュボードの作成 {#creating-a-custom-dashboard}

1. **Analytics** > **ダッシュボードビルダー**に移動します。
2. **Create Dashboard**を選択します。
3. レポートを作成するデータソースを選択します。
- レポートビルダーで作成した**レポート**
- クエリビルダーで作成した**カスタムクエリ**<br><br>![ダッシュボードのデータソースを選択するウィンドウ。]({% image_buster /assets/img/select_data_source.png %})<br><br>

次に、データソースに応じたそれぞれの手順に従います。

{% tabs %}
{% tab レポート %}

{: start="4"}
4. **+ Add Tile**を選択し、[レポートビルダー（新）]({{site.baseurl}}/user_guide/analytics/reports/report_builder)で作成したレポートのいずれかを選択します。

{% alert important %}
レポートビルダーのレポートをダッシュボードビルダーのタイルに追加した後、そのタイルは元のレポートとは連動しません。レポートビルダーで元のレポートを編集した場合、既存のダッシュボードタイルを削除し、更新されたレポートをデータソースとして新しいタイルを作成する必要があります。
{% endalert %}

{: start="5"}
5. 鉛筆アイコンを選択して、タイル内のタイトルとチャートタイプの表示を変更します。
    - チャートタイプのコントロールで異なるチャートタイプを切り替えることができます。現在のオプションには、棒グラフ（横向きまたは縦向き）と折れ線グラフ（レポートビルダーの設定でドリルダウンオプションとして**Date**を選択した場合のみ利用可能）があります。<br><br>![異なるチャートタイプの切り替えコントロール。]({% image_buster /assets/img/report_builder_types.png %})<br><br>
    - 指標ドロップダウンを使用して、ビジュアライゼーションに含める指標を選択します。デフォルトでは、レポートの最初の列が表示される指標になります。
6. ビジュアライゼーションを好みに合わせて変更したら、**Save**を選択します。
7. ダッシュボードを後で見つけやすくするために、名前、説明、タグを追加します。
{% endtab %}
{% tab カスタムクエリ %}
{: start="4"}
4. **+ Add Tile**を選択し、クエリビルダーで実行したクエリを選択します。
5. タイル内のクエリ結果の表示方法を編集するには、鉛筆アイコンを選択してタイトルとチャートタイプを変更します。
    - チャートタイプのコントロールで異なるチャートタイプを切り替えることができます。現在のオプションには、テーブル、棒グラフ（横向きまたは縦向き）、折れ線グラフがあります。<br><br>![異なるチャートタイプの切り替えコントロール。]({% image_buster /assets/img/query_builder_types.png %})<br><br>
        - チャートオプションのいずれかを選択した場合、**X-axis**ドロップダウンを使用して、クエリ結果からX軸として使用する列を1つ選択します。
        - **Y-axis**ドロップダウンを使用して、ビジュアライゼーションに含める指標を選択します。デフォルトでは、クエリ結果のすべての列が表示されるため、表示する必要のない列の選択を解除します。<br><br>![異なるチャートタイプの切り替えコントロール。]({% image_buster /assets/img/query_builder_axis.png %})<br><br>
        - （オプション）**Grouping**ドロップダウンを使用して、クエリ結果をグループ化できます。たとえば、列の結果にキャンペーンIDがあり、その値を持つすべての行を合計したい場合は、**Grouping**ドロップダウンを使用します。
        - （オプション）表示されているデータを編集するには、ビジュアルに関連付けられているクエリを選択し、[クエリビルダー]({{site.baseurl}}/user_guide/analytics/reports/query_builder)で編集します。
6. ビジュアライゼーションを好みに合わせて変更したら、**Save**を選択します。
7. ダッシュボードを後で見つけやすくするために、名前、説明、タグを追加します。
{% endtab %}
{% endtabs %}

{: start="8"}
8. 目的のダッシュボードが完成するまで、それぞれの方法でステップ4～7を繰り返します。
9. **View Dashboard** > **Run Dashboard**を選択します。

ダッシュボードのレポート生成が完了するまで、数分かかる場合があります。

{% alert note %}
ダッシュボードには最大10個のタイルを追加できます。
{% endalert %}

## ダッシュボードタイルの管理 {#managing-dashboard-tiles}

### タイルの削除 {#delete-tiles}

ダッシュボードタイルを削除するには、タイルの下部にある**Delete Tile**を選択します。**この操作は元に戻すことができません。**

### タイルの複製 {#duplicate-tiles}

タイルのコピーを作成するには、タイルの下部にある**Duplicate Tile**を選択します。

### タイルのサイズと位置の調整 {#adjust-tile-size-and-position}

タイルのサイズを調整するには、リサイズハンドルをドラッグします。ダッシュボード上のタイルの位置を調整するには、タイルハンドルをドラッグします。

## ダッシュボードの実行 {#running-a-dashboard}

1. **Analytics** > **ダッシュボードビルダー**に移動します。ホームページには、ワークスペース内の既存のダッシュボードがすべて一覧表示され、Brazeが作成したダッシュボードが上部に表示されます。これらはタイトルに「(Braze)」と表示されます。
2. 関心のあるダッシュボードを選択します。
3. **Run Dashboard**を選択して、そのダッシュボードを読み込みます。

#### Revenue - Last Touch Attribution {#revenue---last-touch-attribution}

**Revenue - Last Touch Attribution**ダッシュボードは、キャンペーン、キャンバス、チャネル全体の収益をレビューします。すべての収益データは、アトリビューションウィンドウ内で最後にタッチされたメッセージに帰属します。

タッチには、_メールクリック_（リンククリック）、_Content Cardsクリック_、_アプリ内メッセージクリック_（閉じるボタンを除く）、_プッシュ開封_、_SMSショートリンククリック_、_WhatsApp既読_、_Webhook送信_が含まれます。

| 指標 | 定義 |
| --- | --- |
| ラストタッチ収益合計 | 選択した日付範囲とアトリビューションウィンドウ内にラストタッチイベントがある、すべてのキャンペーンおよびキャンバスの収益イベントの合計。 |
| 購入コンバージョン合計 | 条件を満たすラストタッチイベントがある、すべてのキャンペーンおよびキャンバスの収益イベントの件数。 |
| コンバージョンまでの平均日数 | 条件を満たすラストタッチイベントがある、すべてのキャンペーンおよびキャンバスの購入イベント間の平均時間。 |
| 受信者あたりの収益 | 条件を満たす収益イベントからの収益の合計を、日付範囲内にメッセージを受信したユニークユーザー数で割った値。 |
| ユニーク購入者数 | 条件を満たす収益イベントがあるユニークユーザーの数。 |
| 国別収益 | ラストタッチイベントがある、すべてのキャンペーンおよびキャンバスの収益イベントの合計（国別）。 |
| キャンペーン別収益 | 条件を満たすラストタッチイベントがある、すべてのキャンペーンおよびキャンバスの収益イベントの合計（キャンペーン別）。 |
| キャンペーンバリアント別収益 | 条件を満たすラストタッチイベントがある、すべてのキャンペーンおよびキャンバスの収益イベントの合計（キャンペーンバリアント別）。 |
| キャンバス別収益 | 条件を満たすラストタッチイベントがある、すべてのキャンペーンおよびキャンバスの収益イベントの合計（キャンバス別）。 |
| キャンバスバリアント別収益 | 条件を満たすラストタッチイベントがある、すべてのキャンペーンおよびキャンバスの収益イベントの合計（キャンバスバリアント別）。 |
| 商品別購入数 | 商品別にグループ化されたすべての購入の件数。 |
| チャネル別収益 | 条件を満たすラストタッチイベントがある、すべてのキャンペーンおよびキャンバスの収益イベントの合計（チャネル別）。 |
| 収益の時系列 | 条件を満たすラストタッチイベントがある、すべてのキャンペーンおよびキャンバスの収益イベントの合計（UTC日別）。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Revenue - Last Touch Attribution" }

#### Session Analytics {#session-analytics}

| 指標 | 定義 |
|---|---|
| 日別セッション数（時系列） | 選択した日付範囲内の日別ユニークセッション数を時系列で表示します。 |
| ユーザーあたりの平均セッション数 | 選択した日付範囲内のセッション合計をユニークユーザー数で割って算出した、ユーザーあたりの平均セッション数。 |
| セッションにコンバージョンしたキャンペーン | キャンペーンコンバージョンと同時に発生したユニークセッションの件数（キャンペーンID別にグループ化し、セッション数順にランキング）。 |
| セッションにコンバージョンしたキャンバス | キャンバスコンバージョンと同時に発生したユニークセッションの件数（キャンバスID別にグループ化し、セッション数順にランキング）。 |
| ユーザーあたりの合計セッション数 | 選択した日付範囲内のセッション数が多い上位1,000人のユーザーリスト。 |
