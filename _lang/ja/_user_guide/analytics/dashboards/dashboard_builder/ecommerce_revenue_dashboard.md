# e コマース収益ダッシュボード

> **e コマース収益 - ラストタッチアトリビューション**ダッシュボードは、[e コマース推奨イベント]({{site.baseurl}}/ecommerce_events/)を使用して、キャンペーンとキャンバスのラストタッチアトリビューション収益を追跡します。このダッシュボードを使用して、どのメッセージが収益を促進しているかを把握し、e コマースの全体的なパフォーマンスを経時的にモニタリングできます。

{% alert note %}
e コマース推奨イベントは現在、早期アクセス段階です。この早期アクセスへの参加に興味がある場合は、Braze カスタマーサクセスマネージャーにお問い合わせください。<br><br>新しい [Shopify コネクター]({{site.baseurl}}/partners/ecommerce/shopify/multiple_stores/?tab=shopify%20connector)を使用している場合、これらの推奨イベントは統合を通じて自動的に利用可能になります。それ以外の場合は、このダッシュボードにデータが表示される前にこれらのイベントを実装する必要があります。
{% endalert %}

e コマース収益ダッシュボードを表示するには、**分析** > **ダッシュボードビルダー**に移動し、**e コマース収益 - ラストタッチアトリビューション**を選択します。このダッシュボードは、選択したコンバージョン時間枠内で、ユーザーが注文を行う前に最後にインタラクションしたキャンペーンまたはキャンバスに帰属する収益をレポートします。

## 利用可能な指標

| 指標 | 定義 |
| --- | --- |
| e コマース収益 | 選択した日付範囲とコンバージョン時間枠に基づくラストタッチアトリビューション収益の合計。 |
| 1日あたりの注文数 | 1日あたりに行われた個別注文の平均数。 |
| 1日あたりの平均 e コマース収益 | 選択した期間における1日あたりの平均アトリビューション収益。 |
| e コマース収益の推移 | 選択した日付範囲におけるアトリビューション収益の時系列。 |
| キャンペーン別 e コマース収益 | キャンペーン別に分類されたアトリビューション収益。 |
| キャンバス別 e コマース収益 | キャンバス別に分類されたアトリビューション収益。 |
{: .reset-td-br-1 .reset-td-br-2 role="presentation"}

## アトリビューションモデル

**e コマース収益 - ラストタッチアトリビューション**ダッシュボードは、ラストタッチアトリビューションを使用します。これは、ユーザーが注文を行う前に最後にエンゲージした Braze キャンペーンまたはキャンバスに収益が帰属されることを意味します。

以下のメッセージインタラクションが、アトリビューションのタッチイベントとして認定されます。

- メールクリック
- プッシュ開封
- コンテンツカードクリック
- アプリ内メッセージクリック
- SMS ショートリンククリック
- WhatsApp ショートリンククリック

{% alert important %}
メッセージインタラクションは、選択したコンバージョン時間枠内に発生している必要があります。コンバージョン時間枠内に対象となるメッセージインタラクションがない注文は帰属されません。
{% endalert %}

## 含まれるデータ

**e コマース収益 - ラストタッチアトリビューション**ダッシュボードは、e コマース推奨イベントからデータを取得します。

- `ecommerce.product_viewed`
- `ecommerce.cart_updated`
- `ecommerce.checkout_started`
- `ecommerce.order_placed`
- `ecommerce.order_refunded`
- `ecommerce.order_cancelled`

{% alert note %}
**e コマース収益 - ラストタッチアトリビューション**ダッシュボードにデータを表示するには、`ecommerce.order_placed` イベントの `total_value`、`product.price`、および `product.quantity` が `0` 以上である必要があります。
{% endalert %}

収益と注文数は Braze の標準化された計算方法を使用します。

| 指標 | 計算方法 |
| --- | --- |
| 合計収益 | 注文金額の合計 − 返金金額の合計 |
| 合計注文数 | 個別注文数 − キャンセルされた個別注文数 |
{: .reset-td-br-1 .reset-td-br-2 role="presentation"}

### 除外されるデータ

レガシー購入イベントを使用して記録された購入は含まれません。**e コマース収益 - ラストタッチアトリビューション**ダッシュボードは現在、生涯価値やキャンペーンまたはキャンバス内の収益レポートなど、レガシー購入イベントに関連する機能をサポートしていません。


## 通貨の取り扱い

すべての収益は USD で表示されます。USD 以外の通貨は、イベントが報告された日の為替レートを使用して USD に変換されます。変換を防ぐには、イベント送信時に通貨を `USD` にハードコードしてください。
