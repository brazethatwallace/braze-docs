# eコマース収益ダッシュボード {#ecommerce-revenue-dashboard}

> **eコマース収益 - ラストタッチアトリビューション**ダッシュボードは、[eコマース推奨イベント]({{site.baseurl}}/ecommerce_events/)を使用して、キャンペーンとキャンバスのラストタッチアトリビューション収益を追跡します。このダッシュボードを使用して、どのメッセージが収益を促進しているかを把握し、eコマースの全体的なパフォーマンスを経時的にモニタリングできます。

{% alert note %}
新しい[Shopifyコネクター]({{site.baseurl}}/partners/ecommerce/shopify/multiple_stores/?tab=shopify%20connector)を使用している場合、eコマース推奨イベントは統合を通じて自動的に利用可能になります。それ以外の場合は、このダッシュボードにデータが表示される前にこれらのイベントを実装する必要があります。
{% endalert %}

eコマース収益ダッシュボードを表示するには、**Analytics** > **ダッシュボードビルダー**に移動し、**eコマース収益 - ラストタッチアトリビューション**を選択します。このダッシュボードは、選択したコンバージョン時間枠内で、ユーザーが注文を行う前に最後にインタラクションしたキャンペーンまたはキャンバスに帰属する収益をレポートします。

## アトリビューションモデル {#attribution-model}

**eコマース収益 - ラストタッチアトリビューション**ダッシュボードは、ラストタッチアトリビューションを使用します。これは、ユーザーが注文を行う前に最後にエンゲージしたBrazeのキャンペーンまたはキャンバスに収益が帰属されることを意味します。

以下のメッセージインタラクションが、アトリビューションのタッチイベントとして認定されます。

- メールクリック
- プッシュ開封
- コンテンツカードクリック
- アプリ内メッセージクリック
- SMSショートリンククリック
- WhatsAppショートリンククリック

{% alert important %}
メッセージインタラクションは、選択したコンバージョン時間枠内に発生している必要があります。コンバージョン時間枠内に対象となるメッセージインタラクションがない注文は帰属されません。
{% endalert %}

## 含まれるデータ {#included-data}

**eコマース収益 - ラストタッチアトリビューション**ダッシュボードは、eコマース推奨イベントからデータを取得します。

- `ecommerce.product_viewed`
- `ecommerce.cart_updated`
- `ecommerce.checkout_started`
- `ecommerce.order_placed`
- `ecommerce.order_refunded`
- `ecommerce.order_cancelled`

{% alert note %}
**eコマース収益 - ラストタッチアトリビューション**ダッシュボードにデータを表示するには、`ecommerce.order_placed`イベントの`total_value`、`product.price`、および`product.quantity`が`0`以上である必要があります。
{% endalert %}

収益と注文数はBrazeの標準化された計算方法を使用します。

| 指標 | 計算方法 |
| --- | --- |
| 合計収益 | 注文金額の合計 − 返金金額の合計 |
| 合計注文数 | 個別注文数 − キャンセルされた個別注文数 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Included data" }

### 除外されるデータ {#excluded-data}

レガシー購入イベントを使用して記録された購入は含まれません。**eコマース収益 - ラストタッチアトリビューション**ダッシュボードは現在、生涯価値やキャンペーンまたはキャンバス内の収益レポートなど、レガシー購入イベントに関連する機能をサポートしていません。

## 通貨の取り扱い {#currency-handling}

すべての収益はUSDで表示されます。USD以外の通貨は、イベントが報告された日の為替レートを使用してUSDに変換されます。変換を防ぐには、イベント送信時に通貨を`USD`にハードコードしてください。
