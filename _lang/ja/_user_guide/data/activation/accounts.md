# アカウントオブジェクト {#account-objects}

> アカウントオブジェクトを使用して、アカウントデータによるセグメンテーションとメッセージングのパーソナライゼーションを行います。

{% alert important %}
アカウントは早期アクセス段階です。機能の進化に伴い、これらの手順は変更される場合があります。
{% endalert %}

アカウントオブジェクトを使用すると、以下のことができます。

- アカウント条件でセグメントを構築する
- Liquidを通じてアカウント属性でメッセージをパーソナライズする
- アカウントレコードを一元管理する

アカウントオブジェクトは、ユーザープロファイルに接続されたワークスペースレベルのデータモデルです。アカウントレコードは、1つの特定のアカウントとそれに関連するフィールドデータです。
企業属性などのアカウントコンテキストがターゲティングやメッセージングのパーソナライゼーションに役立つ場合に、アカウントオブジェクトを使用します。
また、アカウント階層（親アカウントと子アカウントなど）をモデル化し、1つのユーザープロファイルを複数のアカウントにリンクすることもできます。

## アカウントオブジェクトを使用する理由 {#why-use-account-objects}

一部のユースケースでは、キャンペーンやキャンバスが個々のユーザーに送信される場合でも、アカウントレベルのコンテキストが必要です。

アカウントオブジェクトを使用すると、アカウントデータを一度保存し、Braze全体でセグメンテーションとパーソナライゼーションに再利用できます。

これにより、以下のことが可能になります。

- アカウント属性でセグメンテーションする
- 共有アカウントコンテキスト（会社名や業種など）でメッセージをパーソナライズする
- アカウント間の関係をモデル化し、1つのユーザープロファイルを複数のアカウントに接続する

このアプローチにより、同じアカウント属性を多数のユーザープロファイルに複製する必要がなくなります。

## 前提条件 {#prerequisites}

開始する前に：

- ワークスペースでアカウントの早期アクセスが有効になっている必要があります。Brazeアカウントチームにお問い合わせください。
- Brazeにユーザーが既に存在している必要があります。
- アカウントが有効になると、**データ設定** > **アカウント**に表示されます。アカウントを初めて使用する場合は、画面上の初期化手順に従ってください。

## アカウントデータモデル {#account-data-model}

各アカウントにはexternal ID（`id`）と名前（`name`）が必要です。

このセクションのアカウントフィールドは、アカウントオブジェクトスキーマを定義します。これらのフィールドは、Brazeに保存するすべての個別アカウントレコードに適用されます。

Brazeにはデフォルトで標準フィールドを持つアカウントオブジェクトが含まれています。ユースケースに基づいてカスタムフィールドを追加・削除できます。

| フィールド名 | フィールドタイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string | はい | アカウントのシステムID（例：CRM ID）。ワークスペース内で一意である必要があります。 |
| `name` | string | はい | アカウント名。 |
| `type` | string | いいえ | アカウントタイプ（顧客、パートナー、リセラーなど）。 |
| `annual_revenue` | number | いいえ | アカウントの年間収益。 |
| `industry` | string | いいえ | アカウントの業種。 |
| `number_of_employees` | number | いいえ | 従業員数。 |
| `address` | string | いいえ | 住所。 |
| `city` | string | いいえ | 市区町村。 |
| `state` | string | いいえ | 都道府県。 |
| `postal_code` | string | いいえ | 郵便番号。 |
| `country` | string | いいえ | 国。 |
| `notes` | string | いいえ | 追加メモ。 |
| `website` | string | いいえ | WebサイトURL。 |
| `main_phone` | string | いいえ | 主要電話番号。 |
| `created_date` | time | いいえ | アカウント作成タイムスタンプ。 |
| `sic_code` | string | いいえ | 標準産業分類コード。 |
| カスタムフィールド | custom | いいえ | ユーザーが定義・管理するフィールド。 |

## データ統合オプション {#data-integration-options}

アカウントレコードは以下の方法で管理できます。

- アカウントレコード用のREST APIエンドポイント
- **データ設定** > **アカウント**でのブラウザ内編集（個別レコード用）

## はじめに {#get-started}

### ステップ1：アカウントを有効にする {#step-1-enable-accounts}

アカウントは会社レベルで有効化されます。早期アクセス期間中は、Brazeアカウントチームが一度限りの有効化を行います。

アカウントが有効になったら、**データ設定** > **アカウント**に移動し、プロンプトが表示された場合は一度限りの初期化フローを完了してください。

### ステップ2：アカウントレコードを追加する {#step-2-add-account-records}

REST APIまたはブラウザ内編集を通じてアカウントレコードを追加または更新します。

### ステップ3：アカウント条件の計算フィルターを作成する {#step-3-create-a-calculated-filter-for-account-criteria}

アカウントデータでセグメンテーションを行う前に、アカウント条件を定義する計算フィルターを作成します。詳細については、[計算フィルターの仕組み]({{site.baseurl}}/user_guide/audience/segments/calculated_filters#how-it-works)を参照してください。

### ステップ4：セグメントビルダーで計算フィルターを使用する {#step-4-use-the-calculated-filter-in-segment-builder}

セグメントビルダーで、作成した計算フィルターを選択し、キャンペーンやキャンバスのターゲティングをサポートする追加のユーザー属性フィルターを追加します。

## アカウントベースのセグメントを構築する {#build-account-based-segments}

アカウントレコードと計算フィルターの準備ができたら：

1. [セグメントビルダー]({{site.baseurl}}/user_guide/audience/segments/creating_a_segment)に移動します。
2. アカウント条件用に事前設定した計算フィルターを追加します。
3. 追加のユーザー属性フィルターを追加します。
4. セグメントを保存します。

例：

- **計算フィルター：** アカウントの`industry`が`healthcare`と完全一致
- **ユーザー属性フィルター：** `days_since_last_login`が`30`未満

## Liquidでパーソナライズする {#personalize-with-liquid}

`{% raw %}{% data_object account %}{% endraw %}` Liquidタグを使用して、ユーザーのアカウントデータを`data_objects`配列に読み込みます。

{% alert note %}
**プレビューとテスト**を使用する場合は、パーソナライゼーションが正しく解決されるように、アカウントデータを含むセグメントを使用してください。
{% endalert %}

{% raw %}
```liquid
{% data_object account %}
Hi {{${first_name}}},
We'd love to invite you and your peers at {{ data_objects[0].name }}.
```
{% endraw %}

一致するすべてのアカウントを反復処理するには：

{% raw %}
```liquid
{% data_object account %}
{% for acct in data_objects %}
- {{ acct.name }}
{% endfor %}
```
{% endraw %}

## APIの基本 {#api-basics}

早期アクセス期間中は、REST APIを使用してアカウントレコードを管理できます。

{% alert note %}
アカウントのエンドポイントの詳細は、早期アクセスのオンボーディング時に提供されます。アクセスやオンボーディングの詳細が必要な場合は、Brazeアカウントチームにお問い合わせください。
{% endalert %}

認証とREST APIエンドポイントの基本については、[Braze APIの概要]({{site.baseurl}}/api/basics)を参照してください。

## よくある質問 {#frequently-asked-questions}

### アカウントにカスタムフィールドを追加できますか？ {#can-i-add-custom-fields-to-accounts}

はい。ワークスペースでカスタムアカウントフィールドを定義・管理できます。フィールドの要件については、[アカウントデータモデル](#account-data-model)を参照してください。

### アカウントは有料アドオンですか？ {#is-accounts-a-paid-add-on}

いいえ。アカウントは有料アドオンではなく、すべてのプランで利用可能です。早期アクセス期間中は、Brazeアカウントチームがワークスペースで有効化する必要があります。
