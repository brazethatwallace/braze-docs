# 収集のユースケース {#collection-use-case}

> この記事では、ライドシェアアプリがどのようなユーザーデータを収集するかを決定する方法について、ユーザーデータ収集のユースケースを取り上げています。

例えば、StyleRydeというタクシーやライドシェアアプリが、収集するユーザーデータを決めたいとします。以下の質問とブレーンストーミングのプロセスは、マーケティングチームと開発チームが従うべき優れたモデルです。この演習が終わるころには、両チームとも、目標を達成するためにどのようなカスタムイベントや属性を収集するのが理にかなっているかについて、しっかりと理解しているはずです。

## ケースの質問1：目標は何ですか？ {#case-question-1-what-is-the-goal}

StyleRydeの目標はシンプルです。ユーザーがアプリを通じてタクシーの配車を依頼できるようにすることです。

## ケース質問2：アプリインストール後、目標に到達するためのステップは？ {#case-question-2-what-are-the-steps-to-reach-that-goal-after-app-installation}

1. StyleRydeは、ユーザーに登録プロセスを開始し、個人情報を入力してもらう必要があります。
2. StyleRydeは、SMSで受け取ったコードをアプリに入力して、ユーザーに登録プロセスを完了・認証してもらう必要があります。
3. StyleRydeは、ユーザーにタクシーの配車を試みてもらう必要があります。
4. StyleRydeは、ユーザーがタクシーを配車する際に利用可能である必要があります。

これらのアクションは、以下のカスタムイベントとしてタグ付けできます。

- Began Registration
- Completed Registration
- Successful Taxi Hails
- Unsuccessful Taxi Hails

イベントを実装した後、StyleRydeは以下のようなキャンペーンを実行できます。

1. Began Registrationを行ったが、一定期間内にCompleted Registrationに至っていないユーザーにメッセージを送信します。
2. Completed Registrationを達成したユーザーにお祝いのメッセージを送信します。
3. Unsuccessful Taxi Hailsが発生し、一定時間内にSuccessful Taxi Hailが続かなかったユーザーにお詫びとプロモーションクレジットを送信します。
4. Successful Taxi Hailsの回数が多いパワーユーザーに、ロイヤルティへの感謝としてプロモーションを送信します。

## ケース質問3：メッセージングに活用できる他のユーザー情報にはどのようなものがありますか？ {#case-question-3-what-other-user-information-could-we-collect-and-use-to-inform-our-messaging}

- ユーザーがプロモーションクレジットを持っているかどうか
- ユーザーがドライバーに付ける平均評価
- ユーザー固有のプロモコード

これらの特性は、以下のカスタム属性としてタグ付けできます。

- プロモーションクレジット残高（小数型）
- ドライバー平均評価（整数型）
- 固有プロモコード（文字列型）

これらの属性を使用すると、次のようなキャンペーンをユーザーに送信できます。

1. 7日間アプリを使用しておらず、アカウントにプロモーションクレジットがあるユーザーに、アプリに戻ってクレジットを使用するようリマインドする。
2. メッセージテンプレートと[パーソナライゼーション機能]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize)を使用して、固有のプロモーションコード属性をユーザー向けのメッセージングにドラッグする。

{% alert important %}
Brazeは、セッション数が5,000,000を超える、異なるカスタムイベント名が20,000を超える、または購入における異なる製品名が20,000を超えるユーザープロファイル（「ダミーユーザー」）をブロックします。これらは通常、誤った連携の結果であるためです。プロファイルがブロックされると、Brazeはそのプロファイルへのすべての受信データ（SDKおよびREST APIの両方から）の取り込みを停止します。正規のユーザーにこの問題が発生した場合は、Brazeアカウントマネージャーにお問い合わせください。
{% endalert %}
