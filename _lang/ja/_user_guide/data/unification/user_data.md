{% alert important %}
Brazeは、セッション数が500万を超えるユーザー（「ダミーユーザー」）を禁止またはブロックし、SDKイベントの取り込みを停止します。これは通常、誤った連携の結果であるためです。正当なユーザーでこのような事態が発生した場合は、Brazeアカウントマネージャーにご連絡ください。
{% endalert %}
