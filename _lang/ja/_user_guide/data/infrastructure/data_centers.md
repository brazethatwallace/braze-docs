# データセンター {#data-centers}

> Brazeのデータセンターは、ユーザーデータが処理および保管される場所に関するオプションを提供するように構築されています。これにより、データ主権、柔軟性、および管理に関連するリスクを効果的に管理できます。

## 仕組み {#how-it-works}

Brazeは、世界中のさまざまな地域にある複数のデータセンターを運営しています。これらのデータセンターにより、当社のサービスの信頼性と拡張性が確保されています。この地理的な分散は、データがサーバーとユーザーの間を移動するのにかかる時間であるレイテンシーを最小限に抑えるのに役立ちます。

また、ユーザーがアプリまたはWebサイトとやり取りすると、そのリクエストが最も近いデータセンターに送信されるため、パフォーマンスが最適化され、読み込み時間が短縮されます。最寄りのデータセンターに接続することで、ユーザーは高速な読み込み時間を体験できます。これは、リアルタイムのメッセージングとユーザーエンゲージメントにとって特に重要です。

たとえば、ユーザーにプッシュ通知を送信するモバイルアプリがあるとしましょう。メルボルンのユーザーが通知を受け取った場合、その通知の送信リクエストはオーストラリアの最も近いデータセンターにルーティングされます。プロモーションイベント中にモバイルアプリのユーザーが急増した場合でも、Brazeには増大する需要に対応できる複数のデータセンターを備えたスケーラブルなインフラがあります。

## 地域固有のデータセンターへの登録 {#signing-up-for-region-specific-data-centers}

Brazeアカウントを設定する際に、地域固有のデータセンターにサインアップできます。ユーザーの地理的地域に基づいて最適なデータセンターに関する情報と推奨事項については、アカウントマネージャーにお問い合わせください。
