# はじめに: ユーザーとセグメント {#get-started-users-and-segments}

> パーソナライズされたターゲットを絞ったマーケティングキャンペーンを送信するためには、ユーザーを理解し、効果的にターゲティングすることが不可欠です。この記事では、ユーザーとセグメントの概要を示し、その意義と、オーディエンスをエンゲージするためにどのように活用できるかについて概説します。

## ユーザー {#users}

Brazeでは、オーディエンスに関する情報がユーザープロファイルに保存されます。[ユーザープロファイル]({{site.baseurl}}/user_guide/audience/manage_audience/user_profiles)は、エンドユーザーを表す情報と属性の包括的なコレクションです。ユーザーの行動、好み、デモグラフィックの詳細に関連するデータを保存・管理するための中央リポジトリとして機能します。

### ユーザープロファイルの構成要素 {#parts-of-a-user-profile}

ユーザープロファイルを理解することで、オーディエンスに関するインサイトを得て、パーソナライズされたターゲットレベルでエンゲージメントを図ることができます。ユーザープロファイルには多くの情報が含まれていますが、ここでは主要な構成要素をいくつか紹介します。

- **ユーザー識別子:** 各ユーザープロファイルは、`external_id` と呼ばれるユーザーIDによって一意に識別されます。この識別子により、Brazeはさまざまなチャネルやデバイスにわたってユーザーデータをトラッキングし、関連付けることができ、各ユーザーとブランドとのインタラクションの統合ビューを提供します。[匿名ユーザープロファイル]({{site.baseurl}}/user_guide/data/unification/user_data/user_profile_lifecycle/anonymous_users)（ログインせずにWebサイトやアプリケーションにアクセスするユーザー）には `external_id` がありませんが、代替の識別子として[ユーザーエイリアス]({{site.baseurl}}/user_guide/data/unification/user_data/user_profile_lifecycle/anonymous_users#assigning-user-aliases)を割り当てることができます。
- [属性](#attributes)**:** ユーザーの名前、年齢、所在地、その他のデモグラフィック情報など、ユーザーに関する具体的な情報です。これらの属性を使用して、オーディエンスをセグメント化し、メッセージングをパーソナライズできます。
- [イベント](#events)**:** 購入、リンクのクリック、アプリの起動など、ユーザーが行うアクションです。Brazeはこれらのイベントをトラッキングし、ユーザーの行動とエンゲージメントの理解に役立てます。属性と同様に、イベントもセグメンテーションとパーソナライズに使用できます。
- **購入:** このセクションでは、ユーザーの購入履歴が記録されます。ユーザーの購買習慣や好みを理解するために不可欠です。
- **デバイス:** このセクションでは、ユーザーがブランドとやり取りするために使用したデバイスが一覧表示されます。モバイルデバイス、Webブラウザー、コネクテッドデバイス（ウェアラブルやスマートTVなど）が含まれます。
- **エンゲージメント:** このセクションには、送信したメッセージに対するユーザーのインタラクション、所属するセグメント、購読ステータスなどの情報が含まれます。
- **メッセージ履歴:** 各メッセージングチャネル（メールやプッシュなど）からユーザーに送信されたすべてのメッセージの記録です。

{% alert tip %}
BrazeプラットフォームのSDKは、27種類の属性とイベントを自動的に収集します。これらの標準イベントと標準属性を使用することで、SDKを統合するとすぐにセグメントを構築できます。
{% endalert %}

### 属性 {#attributes}

属性は、ユーザーに関連付けられた特定の特性やプロパティです。これらの属性により、ユーザーの固有の特徴や興味に基づいてセグメント化やターゲティングを行うことができます。Brazeには、標準属性とカスタム属性の2種類の属性があります。

#### 標準属性 {#standard-attributes}

標準属性は、SDKをアプリに統合した後にBrazeでトラッキングできる定義済みの属性です。ほとんどのアプリにとって有用な、デモグラフィックやデバイスデータなどの一般的なユーザー情報です。例としては以下があります。

- 名
- 姓
- メール
- 性別
- 生年月日
- 国
- 市区町村
- 最後に使用したアプリ
- 言語
- タイムゾーン

#### カスタム属性 {#custom-attributes}

[カスタム属性]({{site.baseurl}}/user_guide/data/activation/attributes/custom_attributes)は、特定のビジネスニーズに基づいて定義する属性です。アプリやビジネスに固有の情報をトラッキングできます。

例えば、音楽ストリーミングアプリでは、次のようなカスタム属性をトラッキングする場合があります。

- お気に入りのジャンル
- 再生した曲数
- プレミアム会員（はい/いいえ）
- お気に入りのアーティスト

一方、小売アプリでは、次のようなカスタム属性をトラッキングする場合があります。

- 希望する服のサイズ
- お気に入りのブランド
- 購入回数
- ロイヤルティプログラムメンバー（はい/いいえ）

カスタム属性を使用すると、ビジネスに最も関連性の高いデータを柔軟に収集・分析できます。ただし、追加の設定が必要です。

標準属性とカスタム属性の両方を使用して、オーディエンスのセグメント化やマーケティングメッセージのパーソナライズを行うことができます。例えば、特定の市区町村（標準属性）にいて、10回以上購入した（カスタム属性）ユーザーに特別オファーを送信できます。

### イベント {#events}

イベントは、アプリやWebサイト内でユーザーが実行する特定のアクションや行動を表します。イベントの例としては、アプリの起動、購入、コンテンツの閲覧、その他のアクションがあります。これらのイベントをトラッキングして分析することで、ユーザーの行動やエンゲージメントパターンに関するインサイトを得ることができます。

#### 標準イベント {#standard-events}

[標準イベント]({{site.baseurl}}/user_guide/data/activation/events)は、SDKがアプリやサイトに統合された後にBrazeが自動的にトラッキングする定義済みのイベントです。標準イベントの例としては以下があります。

- **セッション開始:** ユーザーがアプリを開いたときにトリガーされるイベントです。
- **セッション終了:** ユーザーがアプリを閉じたときにトリガーされるイベントです。
- **購入:** ユーザーがアプリ内で購入を行ったときにトリガーされるイベントです。
- **プッシュ通知クリック:** ユーザーがプッシュ通知をクリックしたときにトリガーされるイベントです。

#### カスタムイベント {#custom-events}

[カスタムイベント]({{site.baseurl}}/user_guide/data/activation/events/custom_events)は、アプリやサイト内でトラッキングしたい特定のアクションに基づいて定義するイベントです。例えば、音楽ストリーミングアプリでは、次のようなカスタムイベントをトラッキングする場合があります。

- 曲の再生
- プレイリストの作成
- 広告のスキップ

一方、フィットネスアプリでは、次のようなカスタムイベントをトラッキングする場合があります。

- ワークアウト開始
- ワークアウト完了
- 自己ベスト記録

カスタムイベントを使用すると、アプリやビジネスに最も関連性の高いアクションを柔軟にトラッキングできます。ただし、カスタム属性と同様に、追加の設定が必要です。

### データポイント {#data-points}

Brazeはデータポイントを使用して、ビジネスにとって最もインパクトのある情報を定義するお手伝いをします。データポイントはBrazeの運用における重要な要素であり、課金、価格設定、そして最も重要なこととして、マーケティングキャンペーンのパーソナライズと最適化に使用されます。

データポイントは、ユーザーのプロファイルデータが更新されたとき、または特定のアクションを実行したときに消費されます。これらのアクションには、セッションの開始、セッションの終了、カスタムイベントの記録、購入の実行が含まれます。Brazeが収集するすべてのデータがデータポイントとしてカウントされるわけではないことに注意してください。例えば、プッシュトークン、デバイス情報、メールの開封やプッシュ通知のクリックなどのすべてのキャンペーンエンゲージメントトラッキングイベントなど、Brazeサービスによってデフォルトで収集されるデータやイベントは、データポイントとしてカウントされません。

データポイントとしてトラッキングする情報を慎重に検討することで、ユーザー体験に最も大きなインパクトを与えるデータをターゲットにすることができます。Brazeのアカウントマネージャーが、お客様のニーズに合ったデータのベストプラクティスをご案内します。

[データポイント]({{site.baseurl}}/user_guide/data/infrastructure/data_points)の詳細については、専用の記事をご覧ください。

## セグメント {#segments}

[セグメンテーション]({{site.baseurl}}/user_guide/audience/segments)を使用すると、ユーザーのデモグラフィック、行動、ソーシャル、技術的な特性やアクション（つまり、属性やイベント）に基づいてユーザーをターゲティングできます。セグメンテーションとメッセージングオートメーションをクリエイティブかつインテリジェントに活用することで、ユーザーをカスタマーライフサイクルジャーニーに沿ってシームレスに導くことができます。

セグメントを扱う際のヒント：

- Brazeのセグメントはダイナミックです。ユーザーは常に条件を満たしたり外れたりするため、セグメントに出入りし続けます。送信時点でセグメントの条件に合致するユーザーが、そのキャンペーンやキャンバスの受信者となります。
    - セグメントを静的にしたい場合は、セグメントエクステンションを使用できます。セグメントエクステンション（[再生成をオフ]({{site.baseurl}}/user_guide/audience/segments/segment_extension#step-4-designate-refresh-settings-optional)にした状態）は、特定の時点でのオーディエンスのスナップショットを表します。
- フィルターは1つに限定されません。複数のフィルターを重ねることで、きめ細かく精密なセグメントを作成できます。
- ユーザーのアクションやインアクション（非アクション）を活用して、ユーザーがエンゲージメントしたいポイントでどのようにリーチすればよいかを理解できます。これらのアクションには、カスタムイベント、既存のキャンペーンやキャンバスとのエンゲージメント、さらにはキャンバス内の特定のメッセージも含まれます。

### ユースケース {#use-case}

オンラインの衣料品ストアを運営しており、カートにアイテムを追加したが購入を完了していないユーザーに対して、一連のメールを送信するメッセージングフローを設定しているとします。この放棄カートフローには、最初のリマインダーメール、割引を提供するフォローアップメール、最後のリマインダーメールが含まれる場合があります。

![ユースケースに関連するスクリーンショット。]({% image_buster /assets/img/getting_started/segment_example.png %}){: style="max-width:70%" }

カスタムイベント「カートにアイテムを追加」をトリガーしたが、カスタムイベント「購入完了」をトリガーしていないユーザーのセグメントを作成できます。さらに、このセグメント内で、最初のリマインダーメールを開封した（特定のメッセージとのエンゲージメント）が、まだ購入していないユーザーを特定できます。

![カスタムイベント「カートにアイテムを追加」をトリガーしたが、カスタムイベント「購入完了」をトリガーしていないユーザーのセグメントを作成できます。さらに、このセグメント内で、最初のリマインダーメールを開封した（特定のメッセージとのエンゲージメント）が、まだ購入していないユーザーを特定できます。]({% image_buster /assets/img/getting_started/segment_example_breakdown.png %})

このセグメントに対して、より積極的なキャンペーンを展開し、これらのユーザーを購入者に転換することを試みることができます。たとえば、特別オファーやカート内のアイテムに基づいたパーソナライズされたレコメンデーションを送信できます。

これは、ユーザーのアクションやインアクション、カスタムイベント、エンゲージメントデータを活用してセグメントを作成し、Brazeでマーケティング戦略をカスタマイズする方法の一例にすぎません。
