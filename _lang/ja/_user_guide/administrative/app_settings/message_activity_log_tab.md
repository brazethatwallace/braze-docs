# メッセージアクティビティログ {#dev-console-troubleshooting}

> [**メッセージアクティビティログ**] では、キャンペーンや送信に関連するメッセージ (特にエラーメッセージ) を確認できます。

API キャンペーンのトランザクションの確認、失敗したメッセージの詳細のトラブルシューティング、および通知配信を改善したり既存の技術的な問題を解決したりする方法に関するインサイトの収集ができます。

ログにアクセスするには、[**設定**] > [**メッセージアクティビティログ**] に移動します。

![メッセージアクティビティログ]({% image_buster /assets/img_archive/message_activity_log.png %})

{% alert tip %}
この記事に加えて、「[Quality Assurance and Debugging Tools](https://learning.braze.com/quality-assurance-and-debugging-tools-in-the-dashboard/)」のBrazeラーニングコースも確認することをお勧めします。このコースでは、メッセージアクティビティログを使用して独自のトラブルシューティングとデバッグを実行する方法を説明しています。
{% endalert %}

**メッセージアクティビティログ**に記録された次の内容を基準にしてフィルターを適用できます。

- プッシュ通知のエラー
- メッセージ中止のエラー
- Webhook エラー
- メールエラー
- API メッセージレコード
- コネクテッドコンテンツのエラー
- REST API 接続オーディエンスのエラー
- ユーザーエイリアシングのエラー
- AB テストのエラー
- SMS/MMS エラー
- WhatsApp エラー
- ライブアクティビティのエラー
- 不正なユーザートリガーエラー
- Braze エージェントの[日次呼び出し制限]({{site.baseurl}}/user_guide/brazeai/agents/deploying_agents/#monitor-your-agent)エラー
- Braze エージェントの利用不可[モデル]({{site.baseurl}}/user_guide/brazeai/agents/reference/#models)エラー

これらのメッセージの送信元として、Braze システム、お客様のアプリやプラットフォーム、またはサードパーティのパートナーがあります。このため、このログに表示されるメッセージの数が膨大になる可能性があります。

## ログメッセージについて

メッセージの意味を判断する際に、各メッセージの語句とそれに対応する列に注意を払うと、コンテキストの手がかりを使用してトラブルシューティングを行う際に役立ちます。 

例えば、ログエントリのメッセージが「empty-cart_app」と表示されていて、その意味がわからない場合、左側の [**タイプ**] 列を確認します。「メッセージ中止のエラー」と表示された場合、メッセージは Liquid を使用して[メッセージ中止]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/liquid/aborting_messages/#aborting-messages)として書き込まれたものであり、メッセージが中止された理由は、メッセージの対象受信者のアプリのカートが空だったためだと確実に推測できます。

### 一般的なメッセージ

表示されるメッセージには一般的なタイプや、さらに問題の診断と修正に役立つトラブルシューティングのリンクを提供するものもあります。

以下のメッセージは例示用であり、ログの [**メッセージ**] 列に表示される内容と正確には一致しない場合があります。

| メッセージタイプ | 潜在的なメッセージ | 説明 |
|---|---|---|
| ソフトバウンス | メールアドレス same@example.com がソフトバウンスしました。 | メールアドレスは有効で、メールメッセージは受信者のメールサーバーに届きましたが、「一時的な」問題で拒否されました。<br><br>ソフトバウンスの一般的な理由として、次のものがあります。{::nomarkdown} <ul> <li> メールボックスがいっぱいです (ユーザーの割り当てを超えている) </li> <li> サーバーがダウンしていました </li> <li> メッセージが大きすぎて受信者の受信トレイに収まりません </li>  </ul> {:/} メールがソフトバウンスした場合、通常72時間以内に再送信を試みますが、再送信の試行回数は受信者によって異なります。 |
| ハードバウンス | お試しになったメールアカウントは存在しません。受信者のメールアドレスにタイプミスや不要なスペースがないか再確認してください。 | あなたのメッセージはこの人の受信トレイに届きませんでした。届くべき受信トレイが存在しなかったためです。さらに詳しく調べたい場合、このようなメッセージには [**詳細を表示**] 列にリンクが含まれていることがあり、メッセージの本来の受信者のプロファイルを確認できます。|
| ブロック | スパムメッセージはスパム対策ポリシーのため拒否されます。 | あなたのメッセージはスパムとして分類されました。このメールエラーは、メールがドロップされたことを示すイベントをメールサービスプロバイダー (ESP) から受信した場合に、そのユーザーについてログに記録されます。その対象受信者だけの問題かもしれませんが、このメッセージを頻繁に見かける場合は、送信習慣やメッセージの内容を見直すことをお勧めします。また、[IP のウォームアップ]({{site.baseurl}}/user_guide/message_building_by_channel/email/email_setup/ip_warming/)を実行したか確認してください。まだの場合は、Braze に連絡してアドバイスを受けてください。|
| 中止されたメッセージエラー | empty-cart_web | カート付きのアプリがある場合、または Liquid で中止メッセージを含む送信を作成する場合は、送信が中止された場合に返されるメッセージをカスタマイズできます。この場合、返されるメッセージは empty-cart_web です。|

### メッセージがリストされない理由

メッセージアクティビティログのメッセージは、Braze、お客様のアプリやプラットフォーム、サードパーティパートナーなど、さまざまなソースから送信されます。つまり、このログには膨大な数のメッセージが表示される可能性があり、想像できるように、すべてを一覧表示することはできません。

例えば、上の表に示したメッセージに加えて、次のような「ブロック」メッセージが考えられます。

- 残念ながら、[_IP_ADDRESS_] からのメッセージは送信されませんでした。インターネットサービスプロバイダーのネットワークの一部がブロックリストに含まれているため、インターネットサービスプロバイダーに問い合わせてください。
- ローカルポリシーにより、メッセージが拒否されました。
- メッセージは、受信者によってスパムとしてブロックされました。
- サービスは利用できません。クライアントホスト [_IP_ADDRESS_] は Spamhaus によってブロックされています。

## ストレージリテンション期間

過去60時間のエラーは、メッセージアクティビティログで確認できます。60時間以上経過したログは消去され、アクセスできなくなります。

### エラーログの保存数

保存されるログの数は、いくつかの条件に影響されます。例えば、スケジュールされたキャンペーンが何千人ものユーザーに送信された場合、メッセージアクティビティログにはすべてのエラーではなく、エラーのサンプルが表示される可能性があります。以下は、保存されるログの数に影響を与える条件の概要です。
- 以下のエラータイプについては、同一キャンペーンまたはキャンバスステップ内で、固定された1時間以内に発生した同一エラータイプのエラーログを最大20件保存します。
    - コネクテッドコンテンツのエラー
    - 中止メッセージのエラー
    - Webhook エラー
    - SMS 拒否エラー
    - SMS 配信失敗エラー
    - WhatsApp の障害エラー
    - AB テストのエラー
- 以下のエラータイプについては、同一のキャンペーンまたはキャンバスステップとアプリの組み合わせにおいて、同一エラータイプのプッシュ通知エラーログを最大20件保存します。
    - 無効なプッシュ認証情報
    - 無効なプッシュトークン
    - プッシュ認証情報なし
    - トークンエラー
    - クォータ超過
    - 再試行タイムアウト
    - 無効なペイロード
    - 予期しないエラー
- 以下のエラータイプについては、同一アプリ内で固定された1時間以内に発生した同一エラータイプのエラーログを最大100件保存します。
    - ライブアクティビティエラー（プッシュ認証情報なし）
    - ライブアクティビティエラー（無効なプッシュ認証情報）
    - その他のライブアクティビティのエラー
    - APNs フィードバック削除トークンエラー
- 以下のエラータイプについては、同一キャンペーンまたはキャンバスステップ内で、固定された1時間以内に発生した同一エラータイプのエラーログを最大100件保存します。
    - メールソフトバウンスエラー
    - メールハードバウンスエラー
    - メールブロックエラー
- 同一ワークスペースにおいて、固定された1時間以内に最大100件のユーザーエイリアシングエラーログが保存されます。

## テスト送信

**メッセージアクティビティログ**には、以下のメッセージングチャネルのテストログが表示されます。

- SMS
- WhatsApp
- LINE
- KakaoTalk
- Webhook

以下のチャネルではテスト送信ログは利用できません：メール、コンテンツカード、アプリ内メッセージ、プッシュ通知。

テスト送信ログには「[TEST SEND]」という接頭辞が付きます。ただし、すべてのテスト送信ログに接頭辞が付くとは限りません（例えば、コネクテッドコンテンツのエラーには接頭辞が付きません）。
