# SMS、MMS、RCSのベストプラクティス {#best-practices-for-sms-mms-and-rcs}

> BrazeでのSMS、MMS、RCSのベストプラクティスについて、オプトアウト監視やトラフィックパンピングに関する推奨事項を含めて詳しく説明します。

## オプトアウト監視の推奨事項 {#opt-out-monitoring-recommendations}

コミュニケーションのオプトアウトを求める受信者のリクエストに応じることは、法律で義務付けられています。SMSの受信者からのチャネルのオプトアウトリクエストに従わない場合、罰金を含む罰則が科されたり、訴訟に発展する可能性があります。Brazeには、堅牢なSMSおよびMMSのオプトイン・オプトアウト管理を可能にする機能と、リクエストが正しく処理されるよう支援する仕組みが備わっています。

当社との購読契約に基づき、お客様は当社のサービスの利用において適用法を遵守する責任を負います。そのため、SMSの設定を正しく構成し、その設定を徹底的にテストし、オプトアウトのコンプライアンスを監視するための対策を講じ、オプトアウトリクエストへの不遵守が確認された場合は速やかに対処することを強くお勧めします。

BrazeでSMSおよびMMSのオプトインとオプトアウトを管理するための設定を行う際は、以下のリソースリストを参照してください。
* [SMS購読グループ]({{site.baseurl}}/sms_rcs_subscription_groups)：購読グループとオプトイン・オプトアウトの方法およびステータス。
* [購読グループREST API]({{site.baseurl}}/api/endpoints/subscription_groups)：メッセージへの直接応答以外のソースから受信したオプトインおよびオプトアウトの処理方法。
* [キーワード処理]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/keyword_processing)：Brazeがキーワードの処理と管理にどのようにアプローチするかの説明。
* [SMSダブルオプトイン]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/keyword_processing/double_opt_in)：SMSメッセージを受信する前に、ユーザーがオプトインの意思を明示的に確認することを求めます。SMSダブルオプトインは一部の国で義務付けられているため、Brazeではこの設定を推奨しています。
* [SMSメッセージ送信]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_setup/sms_sending)：BrazeにおけるSMS送信の基本（購読グループの重要性、SMSセグメントおよびメッセージ本文の要件など）。

### 考慮事項 {#considerations}

SMSおよびMMSが複数のインスタンスにまたがって設定されている場合、設定ミスによりキャンペーンやキャンバスのオプトアウトが誤ったワークスペースに送信される可能性があります。

* Brazeにはこのようなケースを特定するための監視機能が備わっています。この動作が検出された場合、Brazeはそのオプトアウトを正しいインスタンスに適用し、その期間中に発生したものをバックフィルします。
* お客様には、Brazeにある各購読グループのオプトアウトをテストすることを強くお勧めします。メッセージ送信前にこの問題を特定する方が、問題が確認された後に対処するよりも望ましいです。

Brazeは、ユーザープロファイル（`user_id`）レベルと電話番号（`channel_id`）レベルの両方でSMS/MMSの購読を管理しています。電話番号がオプトインまたはオプトアウトされると、その更新はその番号を共有するすべてのプロファイルに適用されます。ユーザーがある電話番号でオプトインした後に電話番号を変更した場合、新しい電話番号はそのユーザーの購読グループステータスを引き継ぎます。したがって、ユーザーがオプトアウトした後に新しい電話番号でアプリやWebサイトに再度アクセスした場合でも、不要なメッセージを受信することはありません。

## 電話番号リストの衛生管理に関する推奨事項 {#phone-number-list-hygiene-recommendations}

電話番号リストの衛生管理を維持することで、有効な同意と到達可能性データを長期にわたって保つことができます。Brazeは、コンプライアンスリスクの軽減、同意に基づくメッセージング慣行のサポート、および元のユーザーに属さなくなった可能性のある番号への送信の回避を支援するために、一部の電話番号を無効としてマークします。

電話番号が通常無効としてマークされる理由については、[無効な電話番号の処理]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_setup/user_phone_numbers#handling-invalid-phone-numbers)を参照してください。

無効な電話番号を削除するために、以下のワークフローを推奨します。

1. [`/sms/invalid_phone_numbers`エンドポイント]({{site.baseurl}}/api/endpoints/sms/get_query_invalid_numbers)を通じて、影響を受ける電話番号を特定します。
2. 無効化された電話番号と、プロバイダーエラーを受けた電話番号を区別します。
3. 無効化された電話番号については、ユーザーに電話番号を再確認します。ユーザーが電話番号を確認した後、[`/sms/invalid_phone_numbers/remove`エンドポイント]({{site.baseurl}}/api/endpoints/sms/post_remove_invalid_numbers)を通じて、無効リストから電話番号を削除します。

## トラフィックポンピングに関する推奨事項 {#traffic-pumping-recommendations}

### トラフィックポンピングとは {#what-is-traffic-pumping}

トラフィックポンピングとは、悪意のある第三者がオンラインフォームを利用して大量のSMSメッセージ（オプトインメッセージやワンタイムパスワードなど）の送信をトリガーする不正行為の一種です。悪意のある第三者は、これらのメッセージの送信先としてプレミアムレート番号を設定し、そのプレミアムレート番号を設定した携帯電話事業者からの収益分配を請求することで、不正な収益を得ます。

### トラフィックポンピングを見分ける方法 {#how-to-spot-traffic-pumping}

* この種の詐欺に利用されるプレミアムレート番号は、常にではありませんが、通常の送信対象地域外の国で設定されることが多くあります。
* オンラインフォームからのメッセージ送信に異常なスパイクが見られる場合、トラフィックポンピングの可能性があります。
    * [キャンペーンアラート]({{site.baseurl}}/user_guide/messaging/campaigns/manage_campaigns/campaign_alerts)を設定して、不自然に多くのメッセージが送信された場合に上限設定と通知を行うことを推奨します。
* オンラインフォームが不完全な状態で送信される場合、プログラムによるフォームの自動入力が行われている可能性があります。
* オンラインフォームを構築する際は、フォームが完全に入力されることを保証するルールを設定し、CAPTCHAなどのツールを使用してリスクを最小限に抑えることを推奨します。

### トラフィックポンピングの影響 {#impact-of-traffic-pumping}

お客様は送信するトラフィックを監視する責任があり、アカウントを通じて送信されたすべてのSMSに対して請求されます。BrazeとCustomerの間では、Customerがトラフィックポンピングを検出し防止するためにより適切な立場にある当事者です。

## 複数国でのSMS送信 {#multi-country-sms-sending}

一部のブランドでは、異なる国の電話番号を持つユーザーグループにメッセージを送信したい場合があります。特定の国の電話番号にSMSメッセージを送信するには、同じ国のロングコードまたはショートコードを使用することがベストプラクティスです。実際、ショートコードはそのショートコードが作成された国と同じ国の電話番号にのみSMSを送信できます。

この制限を克服するために、購読グループの[設定プロセス]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_setup/subscription_groups)では、複数の異なる国のロングコードとショートコードを保持するようにグループを設定できます。設定が完了すると、キャンペーンの開始時にターゲットユーザーの電話番号と同じ国番号を持つ送信用電話番号が自動的に使用されます。異なる国番号の電話番号を持つユーザーごとに個別のキャンペーンを作成する必要がなくなり、1つのキャンペーンまたは1つのキャンバスコンポーネントを使用して関連するユーザーをターゲットにできます。

![SMSペイロードは、ターゲットユーザーの電話番号と同じ国番号を使用して送信されます。]({% image_buster /assets/img/sms/multi_country_subgroups.png %})

### 送信に関する一般的なベストプラクティス {#general-sending-best-practices}

1. **許可を得る。** SMSをビジネスとして使用する上で最も重要なルールの1つは、顧客に連絡する前にまず許可を得ることです。これを怠ると、ブランドのイメージが損なわれ、多額の法的費用が発生する可能性があります。
2. **ユースケースに適した番号を選ぶ。** SMSメッセージの送受信が可能な電話番号には、ロングコード、ショートコード、英数字の送信者IDの3つの主要な種類があり、それぞれの機能と地域ごとの利用可能性は異なります。バニティコードの方がビジネスに適しているかどうか、事前に検討しましょう。
3. **タイミングに注意する。** 顧客は自分宛てに直接送られたメッセージに対してより反応しやすいことを覚えておきましょう。受信者の名を使用したり、顧客の関心を反映した会話調のメッセージにしたりと、少しのパーソナライゼーションが大きな効果を生みます。
4. **双方向の会話をする。** SMSは顧客とのエンゲージメントに非常に効果的なチャネルであるため、メッセージへの返信を予測し、効果的に対応することが重要です。消費者の85%は情報を受け取るだけでなく、企業に返信したり会話に参加したりすることも望んでいます。
5. **効果を測定する。** 適切なタイミングで、最適な頻度で、最も効果的なコールトゥアクションを使って顧客にリーチできていますか？適切なトラッキングツールを使用することで、ROIを証明する直接的かつ測定可能な指標を得ることができます。

## 大量送信 {#high-volume-sending}

大量送信を予定していますか？スムーズに送信するためのベストプラクティスをご紹介します。

- ターゲットオーディエンスのサイズに基づいて、キャンペーンやキャンバスの配信速度レート制限を必要に応じて調整してください。これにより、必要な送信量を確保し、Twilioが想定・処理できるレートでBrazeがメッセージを送信できるようになります。
- 160文字の制限を守り、特殊文字がダブルカウントされることに注意してください（例：バックスラッシュ `\`、キャレット `^`、チルダ `~`）。

## 静寂時間帯の推奨事項 {#quiet-hours-recommendations}

{% alert warning %}
**Brazeネイティブの静寂時間帯は、デバイスレベルでの配信時間を保証するものではありません。**メッセージが送信されると、キャリアに引き渡されます。キャリアがメッセージを受け取った後、ユーザーのデバイスに配信される正確なタイミングについてBrazeは制御できません。<br><br>例えば、メッセージが午後8時59分にキャリアに引き渡された場合、午後9時2分までデバイスに届かない場合があります。リスクを軽減するために、以下のLiquidベースの静寂時間帯メソッドの使用を推奨します。この方法では、引き渡し前にBrazeエンジンレベルでメッセージを抑制します。
{% endalert %}

### Brazeネイティブの静寂時間帯 {#braze-native-quiet-hours}

地域の規制やベストプラクティスを遵守するため、すべてのSMSキャンペーンとキャンバスで[静寂時間帯]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_timing#quiet-hours)を有効にすることを強く推奨します。

### Content Blocksによる追加のセーフガード {#additional-safeguard-through-content-blocks}

Content Blocks内にLiquidベースのチェックを追加できます。これにより、ネイティブ設定と併用できる信頼性の高いスケーラブルなセーフガードが提供されます。

#### 設定 {#setup}

以下のスニペットをSMSメッセージ本文の先頭に含めてください。この例では、ユーザーの[ローカルタイムゾーン]({{site.baseurl}}/user_guide/messaging/campaigns/faq#what-does-local-time-zone-delivery-offer)で午前9時から午後9時の時間枠外の場合に送信を中止します。

{% raw %}
```liquid
{% assign time = 'now' | time_zone: ${time_zone} %}
{% assign hour = time | date: '%H' | plus: 0 %}
{% if hour >= 21 or hour < 9 %}
  {% abort_message("Outside allowed time window") %}
{% endif %}
```
{% endraw %}

#### 考慮事項

- {% raw %}`time_zone: ${time_zone}`{% endraw %}を使用すると、固定のグローバル時間ではなく、各ユーザーのローカルタイムに対して時間枠を評価できます。詳細については[キャンペーンFAQ]({{site.baseurl}}/user_guide/messaging/campaigns/faq#what-does-local-time-zone-delivery-offer)を参照してください。
- {% raw %}`abort_message()`{% endraw %}によって抑制されたメッセージは、翌日に再スケジュールされることはなく、キャンセルされます。
- {% raw %}デフォルトでは、中止されたメッセージは標準のキャンペーンレポートに表示されません。ただし、Liquidが`{% abort_message %}`で送信を中止すると、Brazeはそれをメッセージアクティビティログにメッセージエラーとして記録します（デフォルトでは`{% abort_message %}`が呼び出されたと表示されます）。文字列を渡すと、その理由がログに表示されます（例：`{% abort_message('language was nil') %}`）{% endraw %}。ダッシュボードでこれらの抑制を確認するには、カスタマーサクセスマネージャーに連絡して[メッセージング診断ダッシュボード]({{site.baseurl}}/user_guide/analytics/dashboards/dashboard_builder/diagnostics_dashboard)へのアクセスを依頼してください。
