# SMS、MMS、RCSのベストプラクティス {#best-practices-for-sms-mms-and-rcs}

> BrazeでのSMS、MMS、RCSのベストプラクティスについて、オプトアウト監視やトラフィックパンピングに関する推奨事項を含めて詳しく説明します。

## オプトアウト監視の推奨事項 {#opt-out-monitoring-recommendations}

通信のオプトアウトを求める受信者のリクエストに従うことは、法律で義務付けられています。SMS受信者からのチャネルオプトアウトリクエストに従わない場合、罰金を含む罰則が科される可能性があり、訴訟につながることもあります。Brazeには、堅牢なSMSおよびMMSのオプトイン/オプトアウト管理を可能にする機能と、リクエストが正しく処理されるようにするためのメカニズムが備わっています。

当社との購読契約に基づき、お客様はサービスの利用において適用法を遵守する責任を単独で負います。したがって、SMSの設定を正しく構成し、その設定を十分にテストし、オプトアウトコンプライアンスを監視するための措置を講じ、オプトアウトリクエストへの非準拠が確認された場合は速やかに対処することを強くお勧めします。

BrazeでSMSおよびMMSのオプトインとオプトアウトを管理するための設定を行う際は、以下のリソースリストを参照してください。
* [SMS購読グループ]({{site.baseurl}}/sms_rcs_subscription_groups): 購読グループとオプトイン/オプトアウトの方法およびステータス。
* [購読グループREST API]({{site.baseurl}}/api/endpoints/subscription_groups): メッセージへの直接返信以外のソースから受信したオプトインおよびオプトアウトを処理する方法。
* [キーワード処理]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/keyword_processing): Brazeがキーワード処理と管理にどのようにアプローチするかの説明。
* [SMSダブルオプトイン]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/keyword_processing/double_opt_in): ユーザーがSMSメッセージを受信する前に、オプトインの意思を明示的に確認することを要求します。SMSダブルオプトインは一部の国で義務付けられているため、Brazeではこの設定を推奨しています。
* [SMSメッセージ送信]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_setup/sms_sending): BrazeでのSMS送信の基本（購読グループの重要性、SMSセグメントとメッセージ本文の要件など）。

### 考慮事項 {#considerations}

SMSとMMSが複数のインスタンスにわたって設定されている場合、設定ミスにより、キャンペーンやキャンバスのオプトアウトが誤ったワークスペースに送信されることがあります。

* Brazeにはこのようなインスタンスを特定するための監視機能があります。この動作が検出された場合、Brazeはオプトアウトを正しいインスタンスにリダイレクトし、その期間中に発生したオプトアウトをバックフィルします。
* お客様には、Brazeで保有するすべての購読グループについてオプトアウトをテストすることを強くお勧めします。メッセージを送信する前にこの問題を特定する方が、問題が発覚した後に対処するよりもはるかに効果的です。

Brazeは、ユーザープロファイル（`user_id`）レベルと電話番号（`channel_id`）レベルの両方でSMS/MMS購読を管理しています。電話番号がオプトインまたはオプトアウトされると、その更新はその番号を共有するすべてのプロファイルに適用されます。エンドユーザーが特定の電話番号でオプトインした後に電話番号を変更した場合、新しい電話番号はそのユーザーの購読グループステータスを引き継ぎます。したがって、エンドユーザーがオプトアウトした後に新しい電話番号でアプリやWebサイトに再度アクセスした場合、不要なメッセージを受信することはありません。

## 電話番号リストの衛生管理に関する推奨事項 {#phone-number-list-hygiene-recommendations}

電話番号リストの衛生管理を維持することで、有効な同意データと到達可能性データを長期にわたって保持できます。Brazeは、コンプライアンスリスクの軽減、同意ベースのメッセージング慣行のサポート、および元のユーザーに属さなくなった可能性のある番号への送信を回避するために、一部の電話番号を無効としてマークします。

電話番号が無効としてマークされる一般的な理由については、[無効な電話番号の処理]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_setup/user_phone_numbers#handling-invalid-phone-numbers)を参照してください。

無効な電話番号を削除するために、以下のワークフローを推奨します。

1. [`/sms/invalid_phone_numbers`エンドポイント]({{site.baseurl}}/api/endpoints/sms/get_query_invalid_numbers)を通じて、影響を受ける電話番号を特定します。
2. 無効化された電話番号とプロバイダーエラーを受信した電話番号を区別します。
3. 無効化された電話番号については、ユーザーに電話番号を再確認します。ユーザーが電話番号を確認した後、[`/sms/invalid_phone_numbers/remove`エンドポイント]({{site.baseurl}}/api/endpoints/sms/post_remove_invalid_numbers)を通じて無効リストから電話番号を削除します。

## トラフィックパンピングの推奨事項 {#traffic-pumping-recommendations}

### トラフィックパンピングとは {#what-is-traffic-pumping}

トラフィックパンピングは、悪意のある行為者がオンラインフォームを使用してSMSメッセージを大量に送信させる（例：オプトインメッセージやワンタイムパスワード）詐欺の一形態です。悪意のある行為者は、これらのメッセージの送信先としてプレミアムレート電話番号を設定し、プレミアムレート番号が設定されたモバイルオペレーターとの収益分配を請求することで、不正な収益を生み出します。

### トラフィックパンピングの見分け方 {#how-to-spot-traffic-pumping}

* この種の詐欺を支えるプレミアムレート番号は、常にではありませんが、通常の送信地域以外の国に設定されていることが多いです。
* オンラインフォームからのメッセージ送信の異常な急増は、トラフィックパンピングを示している可能性があります。
    * [キャンペーンアラート]({{site.baseurl}}/user_guide/messaging/campaigns/manage_campaigns/campaign_alerts)を設定して、信じがたいほど大量のメッセージが送信された場合に上限を設けて通知することをお勧めします。
* 不完全なオンラインフォームは、プログラムによるフォーム入力を示している可能性があります。
* オンラインフォームを構築する際は、フォームが完全に入力されるようルールを設定し、CAPTCHAなどのツールを使用してリスクを最小限に抑えることをお勧めします。

### トラフィックパンピングの影響 {#impact-of-traffic-pumping}

お客様は送信するトラフィックを監視する責任があり、アカウントを通じて送信されたすべてのSMSに対して請求されます。Brazeとお客様の間では、トラフィックパンピングを検出し防止するのに適した立場にあるのはお客様です。

## 複数国へのSMS送信 {#multi-country-sms-sending}

一部のブランドでは、異なる国の電話番号を持つユーザーグループに送信したい場合があります。特定の国の電話番号にSMSメッセージを送信するには、同じ国のロングコードまたはショートコードを使用することがベストプラクティスです。実際、ショートコードは、そのショートコードが作成された国と同じ国の電話番号にのみSMSを送信できます。

この制限を克服するために、購読グループの[設定プロセス]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_setup/subscription_groups)で、複数の異なる国のロングコードとショートコードを保持するグループを設定できます。設定が完了すると、キャンペーンの起動時にターゲットユーザーの電話番号と同じ国コードを持つ送信電話番号が自動的に使用されます。異なる国コードの電話番号を持つユーザー向けに個別のキャンペーンを作成する必要がなくなり、1つのキャンペーンを起動するか、1つのキャンバスコンポーネントを使用して関連するユーザーをターゲティングできます。

![SMSペイロードは、ターゲットユーザーの電話番号と同じ国コードを使用して送信されます。]({% image_buster /assets/img/sms/multi_country_subgroups.png %})

### 一般的な送信のベストプラクティス {#general-sending-best-practices}

1. **許可を得る。** SMSをビジネスとして使用する上で最も重要なルールの1つは、まず顧客から連絡の許可を得ることです。これを怠ると、ブランドイメージが損なわれ、多額の法的費用が発生する可能性があります。
2. **ユースケースに適した番号を選択する。** SMSメッセージの送受信が可能な電話番号には、ロングコード、ショートコード、英数字送信者IDの3つの主要なタイプがあり、それぞれの機能と地域での利用可能性は異なります。バニティコードの方がビジネスに適しているかどうかを事前に検討してください。
3. **タイミングに注意する。** 顧客は、自分に直接宛てられた内容に対してより反応しやすいことを覚えておいてください。受信者の名を使用したり、顧客の関心を反映した会話的なタッチを加えるなど、少しのパーソナライゼーションが大きな効果を生みます。
4. **双方向の会話に取り組む。** SMSは顧客とのエンゲージメントに非常に効果的なチャネルであるため、メッセージへの返信を予測し、効果的に対応することが重要です。消費者の85%は、情報を受け取るだけでなく、企業に返信したり会話に参加したりすることを望んでいます。
5. **効果を測定する。** 適切なタイミングで、最適な頻度で、最も効果的な行動喚起を使用して顧客にリーチできていますか？適切なトラッキングツールを使用することで、ROIを証明する直接的で測定可能な指標を得ることができます。

## 大量送信 {#high-volume-sending}

大量送信を計画していますか？スムーズに実行するためのベストプラクティスをご紹介します。

- ターゲットオーディエンスのサイズに基づいて、キャンペーンやキャンバスの配信速度レート制限を必要に応じて調整してください。これにより、必要な送信量に到達し、BrazeがTwilioの想定する処理可能なレートでメッセージを送信できるようになります。
- 160文字の制限を守り、特殊文字がダブルカウントされることに注意してください（例：フォワードスラッシュ `\`、キャレット `^`、チルダ `~`）。

## サイレントアワーの推奨事項 {#quiet-hours-recommendations}

{% alert warning %}
**Brazeネイティブのサイレントアワーは、デバイスレベルの配信時間を保証するものではありません。** メッセージが送信されると、キャリアに引き渡されます。キャリアがメッセージを受け入れた後、Brazeはユーザーのデバイスに配信される正確なタイミングを制御できません。<br><br>例えば、メッセージが午後8時59分にキャリアに引き渡された場合、デバイスに届くのは午後9時02分になる可能性があります。リスクを軽減するために、以下のLiquidベースのサイレントアワー方式の使用をお勧めします。この方式では、引き渡し前にBrazeエンジンレベルでメッセージを抑制します。
{% endalert %}

### Brazeネイティブのサイレントアワー {#braze-native-quiet-hours}

すべてのSMSキャンペーンおよびキャンバスで[サイレントアワー]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_timing#quiet-hours)を有効にすることを強くお勧めします。これにより、地域の規制やベストプラクティスへの準拠に役立ちます。

### Content Blocksによる追加のセーフガード {#additional-safeguard-through-content-blocks}

コンテンツブロック内にLiquidベースのチェックを追加できます。これにより、ネイティブ設定と連携する信頼性の高いスケーラブルなセーフガードが提供されます。

#### セットアップ {#setup}

SMSメッセージ本文の先頭に以下のスニペットを含めてください。この例では、ユーザーの[ローカルタイムゾーン]({{site.baseurl}}/user_guide/messaging/campaigns/faq#what-does-local-time-zone-delivery-offer)で午前9時〜午後9時の時間枠外の場合に送信を中止します。

{% raw %}
```liquid
{% assign time = 'now' | time_zone: ${time_zone} %}
{% assign hour = time | date: '%H' | plus: 0 %}
{% if hour >= 21 or hour < 9 %}
  {% abort_message("Outside allowed time window") %}
{% endif %}
```
{% endraw %}

#### 考慮事項

- {% raw %}`time_zone: ${time_zone}`{% endraw %}により、固定のグローバル時間ではなく、各ユーザーのローカルタイムに対して時間枠が評価されます。詳しくは[キャンペーンFAQ]({{site.baseurl}}/user_guide/messaging/campaigns/faq#what-does-local-time-zone-delivery-offer)を参照してください。
- {% raw %}`abort_message()`{% endraw %}によって抑制されたメッセージは、翌日に再スケジュールされることはなく、キャンセルされます。
- {% raw %}デフォルトでは、中止されたメッセージは標準のキャンペーンレポートには表示されません。ただし、Liquidが`{% abort_message %}`で送信を中止した場合、Brazeはメッセージアクティビティログにメッセージエラーとして記録します（デフォルトでは`{% abort_message %}`が呼び出されたと表示されます）。文字列を渡すと、その理由がログに表示されます（例：`{% abort_message('language was nil') %}`）{% endraw %}。ダッシュボードでこれらの抑制を確認するには、カスタマーサクセスマネージャーに連絡して[メッセージング診断ダッシュボード]({{site.baseurl}}/user_guide/analytics/dashboards/dashboard_builder/diagnostics_dashboard)へのアクセスを依頼してください。
