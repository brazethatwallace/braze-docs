## MMS固有の要件 {#mms-specific-requirements}

### MMS送信者の要件 {#mms-sender-requirements}

> MMSとSMSはどちらもBrazeのSMSチャネルに紐づいています。アカウントでMMSにアクセスするには、まだSMSを購入していない場合はSMSの購入が必要です。既存のSMS顧客は、MMSを購入後にアクセスできます。

MMSは現在、米国ショートコード（5〜6桁の番号）、米国およびカナダのロングコード（10桁の番号）、米国およびカナダの顧客番号でサポートされています。MMSは、特定のサービスプロバイダーによりトールフリー番号でもサポートされています。

米国およびカナダ以外の番号へのMMS送信も可能ですが、MMSメッセージはメディアアセットへのリンクを含むSMSメッセージに変換されます。

### MMSショートコード {#mms-short-codes}

一部のユーザーはMMSショートコードを実装または使用しない場合がありますが、後日必要になった際に利用可能です。

BrazeがMMSをサポートする前にショートコードを取得したユーザーについて、米国ショートコードを持つ既存の顧客はすべて、即座にMMSを有効化する資格があります。この状況に該当し、MMSの有効化を希望される場合は、カスタマーサクセスマネージャーにお問い合わせください。

{% alert important %}
以前MMSが有効化されていなかったショートコードでMMSを有効化する場合、承認プロセスでショートコードの再承認が必要になることがあり、数週間かかる可能性があります。MMSの有効化を決定する際には、このタイミングを考慮することが重要です。
{% endalert %}

#### MMSショートコードのベストプラクティス {#mms-short-code-best-practices}

- Brazeでは、トランザクションメッセージングとプロモーションメッセージングを、それぞれ異なるショートコードで分離することを強く推奨しています。MMSはSMSチャネルに紐づいており、SMSチャネルは厳しく規制されているため、チャネルの不正使用により金銭的なペナルティを課されたり、ショートコードが停止（不可逆）されたりする可能性があります。トランザクションメッセージングとプロモーションメッセージングを異なるショートコードに紐づけることで、トランザクションメッセージングを保護できます。
- 顧客がすでにプロモーションメッセージング専用のショートコードを持っており、それがMMS対応である場合、MMS用に別のショートコードは必要ありません。

### MMSロングコード {#mms-long-codes}

顧客はロングコードでMMSを送信できます。これを行うには、ロングコードがMMS対応であることを確認する必要があります。これは初期設定時、またはアカウント内から後で行うことができます。

MMSメッセージは英数字の送信者IDでは送信できません。

### MMSメッセージの制限とスループット {#mms-message-limits-and-throughput}

MMSのスループットは、ロングコードを通じて1秒あたり1セグメントです。

キャリアは独自のファイルサイズ制限を設けており、これがMMS送信の成否を決定します。これらの制限は地域やキャリアによって異なる場合があるため、Brazeではメッセージ本文を含めてマルチメディアアセットを600&nbsp;KB以下にすることを推奨しています。また、ユーザーのキャリア全体でメディアが配信可能であることをテストで確認することも推奨しています。

#### キャリアのファイルサイズ制限 {#carrier-file-size-limits}

| ファイル&nbsp;サイズ | キャリアの処理 |
| --- | --- |
| 300&nbsp;KB | すべてのキャリアがこのサイズのMMSメッセージを確実に処理できます。 |
| 600&nbsp;KB | これはほとんどのキャリアにおけるMMSの標準最大ファイルサイズとされています。 |
| 1&nbsp;MB | ほとんどの米国およびカナダのキャリアがこのサイズのMMSメッセージを処理できますが、キャリアによって異なる場合があります。一部のキャリアではこれより大きなファイルサイズを許可する場合があります。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="キャリアのファイルサイズ制限" }

#### 対応ファイルタイプ {#accepted-file-types}

BrazeはJPEG、GIF、PNG、VCFファイルに対応しており、MMSメッセージに1つのマルチメディアアセットを添付できます。
