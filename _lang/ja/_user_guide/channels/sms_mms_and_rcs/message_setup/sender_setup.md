## MMS固有の要件 {#mms-specific-requirements}

### MMS送信者の要件 {#mms-sender-requirements}

> MMSとSMSはどちらもBrazeのSMSチャネルに紐づいています。アカウントでMMSにアクセスするには、まだSMSを購入していない方はSMSの購入が必要です。既存のSMSをご利用のお客様は、MMSを購入後にアクセスできます。

MMSは現在、米国のショートコード（5〜6桁の番号）、米国およびカナダのロングコード（10桁の番号）、米国およびカナダの顧客番号でサポートされています。MMSは、特定のサービスプロバイダーによりトールフリー番号でもサポートされています。

米国およびカナダ以外の番号へのMMS送信は可能ですが、MMSメッセージはメディアアセットへのリンクを含むSMSメッセージに変換されます。

### MMSショートコード {#mms-short-codes}

一部のユーザーはMMSショートコードを実装または使用しない場合がありますが、後日必要になった場合に利用可能です。

BrazeがMMSをサポートする前にショートコードを取得したユーザーについて、米国のショートコードを持つ既存のお客様はすべて、即座にMMSを有効化する資格があります。この状況に該当し、MMSの有効化をご希望の場合は、カスタマーサクセスマネージャーにお問い合わせください。

{% alert important %}
以前MMSが有効化されていなかったショートコードでMMSを有効化する場合、ショートコードの再承認プロセスが必要になることがあり、数週間かかる場合があります。MMSの有効化を決定する際には、このタイミングを考慮することが重要です。
{% endalert %}

#### MMSショートコードのベストプラクティス {#mms-short-code-best-practices}

- Brazeでは、トランザクションメッセージングとプロモーションメッセージングを分離し、それぞれ異なるショートコードを使用することを強くお勧めします。MMSはSMSチャネルに紐づいており、SMSチャネルは厳しく規制されているため、チャネルの不正使用により金銭的なペナルティを課せられたり、ショートコードが停止されたりする可能性があります（停止は取り消し不可能です）。トランザクションメッセージングとプロモーションメッセージングを異なるショートコードに紐づけることで、トランザクションメッセージングを保護できます。
- プロモーションメッセージング専用のショートコードをすでにお持ちで、それがMMS対応の場合、MMS用に別のショートコードは必要ありません。

### MMSロングコード {#mms-long-codes}

お客様はロングコードでMMSを送信できます。これを行うには、ロングコードがMMS対応であることを確認する必要があります。これは初期設定時、またはアカウント内から後で行うことができます。

MMSメッセージは英数字の送信者IDでは送信できません。

### MMSメッセージの制限とスループット {#mms-message-limits-and-throughput}

MMSのスループットは、ロングコードを通じて1秒あたり1セグメントです。

キャリアは独自のファイルサイズ制限を設けており、これがMMS送信の成否を決定します。これらの制限は地域やキャリアによって異なる場合があるため、Brazeではメッセージ本文を含めてマルチメディアアセットを600&nbsp;KB以下にすることをお勧めします。BrazeのSMSまたはMMSコンポーザーでは、1&nbsp;MBを超えるアップロードはブロックされます。エラーメッセージでは、600&nbsp;KB以下のファイルをアップロードすることを推奨しています。また、ユーザーのキャリア全体でメディアが配信可能であることをテストで確認することもお勧めします。

#### キャリアのファイルサイズ制限 {#carrier-file-size-limits}

| ファイル&nbsp;サイズ | キャリアの処理 |
| --- | --- |
| 300&nbsp;KB | すべてのキャリアがこのサイズのMMSメッセージを確実に処理できます。 |
| 600&nbsp;KB | ほとんどのキャリアにおけるMMSの標準的な最大ファイルサイズとされています。 |
| 1&nbsp;MB | ほとんどの米国およびカナダのキャリアはこのサイズのMMSメッセージを処理できますが、キャリアによって異なる場合があります。一部のキャリアでは、これより大きなファイルサイズを許可する場合があります。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="キャリアのファイルサイズ制限" }

#### 対応ファイル形式 {#accepted-file-types}

BrazeはJPEG、GIF、PNG、VCFファイルに対応しており、MMSメッセージに1つのマルチメディアアセットを添付できます。
