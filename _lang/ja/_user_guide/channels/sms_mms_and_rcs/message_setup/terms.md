glossaries:
  - name: SMS (Short Message Service)
    description: 1980年に作られたメッセージングチャネルで、最も古いテキストメッセージ技術の1つです。また、すべてのテキストメッセージチャネルの中で最も広く普及し、最も頻繁に使用されているチャネルの1つでもあります。このチャネルは、ユーザーや顧客の個人の電話番号を利用して連絡するため、他のほとんどのメッセージングチャネルよりも直接的にユーザーにリーチする方法です。そのため、SMSには他のメッセージングチャネルよりも多くのルールや規制があります。
  - name: Short Code
    description: これは覚えやすい5〜6桁の数字の配列で、送信者がロングナンバーよりも多くのメッセージをより安定したレートで送信できるようにします（1秒あたり1メッセージ）。<br><br>ショートコードまたはロングコードのいずれかが必要です。
  - name: Long Code
    description: これは標準的な10桁の電話番号（ほとんどの国で）で、送信者が1秒あたり1メッセージのレートでメッセージを送信できるようにします。<br><br>ショートコードまたはロングコードのいずれかが必要です。
  - name: Encoding
    description: あらゆるものをコード化された形式に変換することです。SMSコンテンツはGSM-7またはUCS-2のいずれかでエンコードできます。
  - name: GSM-7 Encoding (Global System for Mobile Communications)
    description: GSM-7は、ほとんどのSMSメッセージングで最も一般的に使用されるエンコーディング標準です。ギリシャ語と英語のアルファベットの大部分、およびいくつかの追加文字を使用します。GSM-7エンコーディングと使用可能な文字セットの詳細については、<a href='https://en.wikipedia.org/wiki/GSM_03.38#GSM_7-bit_default_alphabet_and_extension_table_of_3GPP_TS_23.038_.2F_GSM_03.38' title="GSM 7ビットデフォルトアルファベットと拡張テーブル">Wikipedia</a> を参照してください。中国語、韓国語、日本語などの言語は、16ビットのUCS-2文字エンコーディングを使用して転送する必要があります。<br> <br> このタイプのエンコーディングのセグメントあたりの文字数制限は128文字と推定できます。
  - name: UCS-2 Encoding (Universal Coded Character Set)
    description: UCS-2エンコーディングは、特にメッセージをGSM-7でエンコードできない場合や、言語のレンダリングに128文字以上が必要な場合のフォールバックエンコーディング標準です。UCS-2は「文字」ではなく<a href='https://en.wikipedia.org/wiki/Code_point'>コードポイント</a> で測定する方が適切です。いずれにしても、このタイプのエンコーディングのセグメントあたりの文字数制限は67文字と推定できます。
  - name: Subscription Groups for SMS
    description: サブスクリプショングループは、特定のサブスクリプションレベルのユーザーや顧客をターゲットにできるBrazeのツールです。SMS用サブスクリプショングループはメッセージサービスに基づいて内部的に構築され、ワークスペース間で共有することはできません。
  - name: Message セグメント
    description: メッセージセグメントとは、定義された文字数（GSM-7エンコーディングの場合は160文字、UCS-2エンコーディングの場合は67文字）までの文字のグループで、1回のSMS送信で送られます。GSM-7エンコーディングで161文字のSMSを送信すると、2つのメッセージセグメントが送信されたことがわかります。複数のメッセージセグメントを送信すると、追加料金が発生する場合があります。
  - name: Message Service
    description: BrazeでSMSメッセージを送信するために使用されるロングコード、ショートコード、英数字IDのコレクションです。
  - name: Keyword
    description: "事前に定義されたSMSプログラムとやり取りしたり、特定のプログラムまたはコード上のすべてのプログラムからのオプトアウトをリクエストしたりするために、ショートコードまたはロングコードに送信される短い単語です。例えば、<code>STOP</code>。キーワードは<br> - 英数字であること<br> - スペースを含まないこと<br> - 10文字未満であること<br> <br>が必要です。特定のキーワードとショートコードの組み合わせは、一度に1つのアクティブなプログラムでのみ使用できます。別のプログラムで既に使用されているキーワードを入力すると、バリデーションエラーが表示されます。<br> <br> すべてのSMSコンテンツプロバイダーが準拠しなければならない必須キーワードカテゴリが2つあります：<code>STOP</code>と<code>HELP</code>。"
  - name: Mandatory Keyword HELP
    description: SMS キャンペーン マネージャープラットフォームで作成される各プログラムについて、このキーワードのコンテンツを提供する必要があり、SMSトラフィックが送受信される国または地域ごとのベストプラクティスとキャリアコンプライアンスに準拠する必要があります。ほとんどの場合、このコンテンツにはSMSプログラムの簡単な説明とオプトアウト方法が含まれている必要があります。
  - name: Global STOP Keywords
    description: バリエーションには<code>STOP</code>、<code>END</code>、<code>QUIT</code>、<code>UNSUBSCRIBE</code>、<code>CANCEL</code>、<code>STOPALL</code>があります。これらは<code>Global-Stop-Keywords</code>と呼ばれます。これらのキーワードのいずれかがショートコードまたはロングコードにテキスト送信されると、その携帯電話番号（発信元の携帯電話番号）は、そのコードに関連付けられたすべてのアクティブなSMSプログラムからオプトアウトされます。
  - name: Vanity Code
    description: バニティショートコードは、ブランドが特別に選択した5〜6桁の電話番号です。バニティショートコードはブランド化されており、消費者にとって覚えやすいものです。
  - name: Shared Short Code
    description: 共有ショートコードを使用する場合、どのビジネスや組織が送信したかに関係なく、すべてのテキストメッセージは消費者のモバイルデバイスに同じ5〜6桁の電話番号から届きます。共有ショートコードは比較的低コストですぐに利用できますが、ビジネスに専用のショートコードがないことを意味し、他のビジネスが共有ショートコードで正しいプロトコルに従うことに依存します。
  - name: Alphanumeric Sender ID
    description: 英数字送信者IDを使用すると、サポートされている国への一方向メッセージを送信する際に、英数字を使用して会社名やブランドを送信者IDとして設定できます。
  - name: Toll-Free Number
    description: フリーダイヤル番号（トールフリー番号）は、発信元の電話加入者に料金が発生するのではなく、着信するすべての通話に対して課金される電話番号です。米国とカナダのフリーダイヤル番号はSMS対応で、加入者は送受信テキストに対して課金されます。<br><br>フリーダイヤルメッセージングは、カスタマーサポートや営業など、送信者と受信者の両方がテキストで会話するような、個人間のユースケースに最適です。
  - name: One-Way Messaging
    description: 一方向メッセージングでは、テキストメッセージを送信して顧客とコミュニケーションできます。一方向メッセージングは、ロングコードやショートコードが利用できない市場で英数字送信者IDを実装する場合に便利です。
  - name: Two-Way Messaging
    description: 双方向メッセージングでは、テキストメッセージの送受信の両方を行うことで会話を続けることができます。
  - name: MMS (Multimedia Message Service)
    description: MMSは、マルチメディアアセット（JPEG、GIF、PNG）を含むメッセージを携帯電話に送信するために使用されます。SMSと同様に、MMSは顧客と即座にコミュニケーションできる緊急性の高いメッセージングチャネルです。MMSは、テキストのみのSMSにメディアを追加する機能を提供することで、SMSの機能を拡張します。
  - name: RCS (Rich Communication Services)
    description: リッチコミュニケーションサービス（RCS）は、従来のSMSを強化し、ブランドが情報提供だけでなく、はるかに魅力的なメッセージを配信できるようにします。RCSは、高品質メディア、インタラクティブボタン、ブランド化された送信者プロファイルなどの機能を、ユーザーのプリインストールされたメッセージングアプリに直接提供します。
  - name: RCS-Verified Sender
    description: RCSメッセージの送信エンティティ、つまり受信者がデバイス上でメッセージの送信元を識別するために表示されるものです。RCS認証済み送信者には、会社名、キャプション、ビジュアルブランディング、認証バッジが含まれます。必要なRCS送信者登録情報をBrazeに提供すると、Brazeが登録とサブスクリプショングループのセットアップを行います。
  - name: SMS Fallback
    description: RCSメッセージを配信できない場合（例えば、その地域でのキャリアサポートがない場合）、サブスクリプショングループ内にSMSコードが存在する場合、BrazeはSMSを通じてメッセージの配信を試みます。
  - name: Basic RCS
    description: 160文字までのテキストのみのRCSメッセージです。単一メッセージとして課金されます。このカテゴリはグローバルモデルでのみ使用されます。
  - name: Single RCS
    description: 160文字を超えるテキストのみのRCSメッセージ、またはボタンやメディアなどのリッチ要素を含むRCSメッセージです。単一メッセージとして課金されます。このカテゴリはグローバルモデルでのみ使用されます。
  - name: Rich RCS
    description: テキストのみのRCSメッセージで、限定的なサジェスチョンやボタンの有無を問いません。セグメント（160 UTF-8バイト）ごとに課金されます。このカテゴリは米国モデルでのみ使用されます。
  - name: Rich Media RCS
    description: メディアファイル（画像、動画）またはリッチカードを含むRCSメッセージです。メッセージの長さに関係なく、単一メッセージとして課金されます。このカテゴリは米国モデルでのみ使用されます。
