# 不明な電話番号の処理 - 新規ユーザー {#handle-unknown-phone-numbers-new-users}

> SMS、MMS、RCSをBrazeで運用開始した後、不明なユーザーからメッセージを受信することがあります。以下のステップでは、未確認のユーザーと電話番号がどのように処理されるかを説明します。

## 不明な番号に対するオプトイン/オプトアウトおよびカスタムキーワードのワークフロー {#opt-inout-and-custom-keyword-workflow-for-unknown-numbers}

Brazeは不明な番号を自動的に以下の3つの方法のいずれかで処理します。

1. オプトインキーワードがテキスト送信された場合:
  * Brazeは匿名プロファイルを作成します
  * システムが電話番号属性を設定します
  * Brazeが受信したオプトインキーワードに基づいて、対応するサブスクリプショングループにユーザーを登録します。<br><br>
2. オプトアウトキーワードがテキスト送信された場合:
  * Brazeは匿名プロファイルを作成します
  * システムが電話番号属性を設定します
  * Brazeが受信したオプトアウトキーワードに基づいて、対応するサブスクリプショングループからユーザーの配信停止を行います。<br><br>
3. その他のカスタムキーワードがテキスト送信された場合:
  * Brazeはそのテキストメッセージを無視し、何も処理を行いません。
