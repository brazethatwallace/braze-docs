# ダブルオプトイン {#double-opt-in}

> ダブルオプトイン機能では、SMS、MMS、またはRCSメッセージを受信する前に、ユーザーがオプトインの意思を明示的に確認する必要があります。これにより、エンゲージメントの高いユーザーにメッセージングを集中させ、コンプライアンスのベストプラクティスをサポートします。

ダブルオプトインが有効になっている場合、キャンペーンやキャンバスからメッセージを送信する前に、ユーザーに明示的な同意を求めるメッセージが送信されます。

1991年電話消費者保護法（TCPA）の明示的な要件ではありませんが、Brazeでは、ユーザーがSMS、MMS、またはRCSプログラムに参加することを認識し、同意していることを確認するためにダブルオプトインを設定することを推奨しています。コンプライアンスの詳細については、[SMS、MMS、RCSに関する法律、規制、不正利用防止]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/compliance_and_delivery/laws_and_regulations)をご覧ください。

## ダブルオプトインワークフロー {#double-opt-in-workflows}

ダブルオプトインを使用すると、インバウンドおよびアウトバウンドのオプトインキャンペーンを通じて、明示的な同意を取得できます。

### アウトバウンド {#outbound}

ユーザーが電話番号を提供すると、同意を求めるメッセージが送信されます。

![アウトバウンドSMSメッセージのスクリーンショット。ブランドが「Welcome to BRAND text updates! 1 msg a week for the latest offers. Reply Y to opt-in.」とテキストを送信し、ユーザーが「Y」と返信し、ブランドが「Thanks! You're now opted-in to BRAND alerts. Here is a promo code SMS10 for 10% off your first purchase!」と応答しています。]({% image_buster /assets/img/double_opt_in_outbound.png %}){:style="max-width:40%;"}

### インバウンド {#inbound}

ユーザーがオプトインキーワードを含むメッセージを送信すると、同意を求めるメッセージが送信されます。

![インバウンドSMSメッセージのスクリーンショット。ユーザーが「JOIN」と送信し、「Reply Y to confirm you want to JOIN our SMS program. 3msg/week, text STOP at any time to STOP」という応答を受け取り、「Y」と返信しています。]({% image_buster /assets/img/double_opt_in_inbound.png %}){:style="max-width:40%;"}

## ダブルオプトインの有効化 {#enabling-double-opt-in}

ダブルオプトインを有効にするには、該当する購読グループの**グローバルキーワード**テーブルに移動し、**オプトインキーワードカテゴリ**の**編集**をクリックします。次に、オプトイン方法（**オプトイン**または**ダブルオプトイン**）を選択します。**ダブルオプトイン**を選択すると、ページが展開され、追加の[設定可能なフィールド](#configurable-fields)が表示されます。

![オプトイン方法セクションには、オプトインとダブルオプトインの2つのオプトイン方法があります。]({% image_buster /assets/img/double_opt_in_method.png %}){:style="max-width:50%;"}

### 設定可能なフィールド {#configurable-fields}

| カテゴリ | フィールド | 説明
| ----------- |----------- |----------------
| オプトインプロンプト | キーワード | ユーザーがオプトインの意思を示すためにテキスト送信できるキーワードです。`START`は必須キーワードです。このオプトインプロンプトは、[購読ソース](#subscription-sources)セクションに記載されているソースによってユーザーの購読ステータスが更新された場合にも送信されます。
| | 返信メッセージ | ユーザーがオプトインキーワードをテキスト送信した後に受け取る最初の応答です（例：「この番号からのメッセージ受信を確認するにはYと返信してください。メッセージおよびデータ料金が適用される場合があります。」）
| ダブルオプトイン確認 | キーワード | ユーザーがオプトインの意思を確認するために返信できるキーワードです。少なくとも1つのキーワードが必要です。これらのキーワードは**オプトインプロンプト返信メッセージ**フィールドで指定する必要があります。
| | 返信メッセージ | ユーザーがオプトインを明示的に確認し、メッセージ送信可能になった後に受け取る確認応答です。ユーザーの購読グループステータスは`Subscribed`に設定されます。
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3 aria-label="設定可能なフィールド" }

ユーザーがオプトインプロンプトを受け取った場合、オプトインの意思を確認するまでに30日間の猶予があります。30日間の期間を過ぎた後にユーザーが購読を希望する場合は、オプトインキーワードをテキスト送信してダブルオプトインワークフローを再度開始する必要があります。

![設定可能なフィールドには、オプトインプロンプトとダブルオプトイン確認の2つのセクションがあり、それぞれにキーワードと返信メッセージのフィールドがあります。]({% image_buster /assets/img/double_opt_in_fields.png %})

## 購読グループのステータス {#subscription-group-status}

ユーザーの[購読グループのステータス]({{site.baseurl}}/sms_rcs_subscription_groups)が`Subscribed`に更新されるのは、ダブルオプトインワークフローを完了した後のみです。ユーザーがワークフローを開始しても完了しなかった場合、ステータスは`Unsubscribed`のままとなり、その購読グループからメッセージを送信することはできません。

また、ユーザーは[他のソースから購読]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_setup/subscription_groups)している場合（例：REST API、SDK）にも、ダブルオプトインワークフローに入ることができます。

## 購読ソース {#subscription-sources}

ユーザーは、インバウンドメッセージ以外の購読更新を通じてもダブルオプトインワークフローに入ることができます。これらのソースには、REST API、SDK、ユーザー設定センターからの更新が含まれます。ユーザーがこれらのソースを通じてダブルオプトインワークフローに入ると、**オプトインプロンプト返信メッセージ**を受け取ります。

{% alert important %}
インバウンドメッセージ以外のソースからダブルオプトインワークフローに登録されたユーザーは、このワークフローに登録された回数に関係なく、24時間のローリング期間中に最大1回のオプトインプロンプト返信メッセージを受け取ります。
{% endalert %}

各購読ソースには、以下の表に記載されているように、異なる登録動作があります。

ソース    | ダブルオプトイン登録動作
----------- | -----------
SDK | Braze SDKを通じて購読登録されたユーザーは、自動的にダブルオプトインワークフローに入ります。
REST API | `/subscription/status/set`、`/v2/subscription/status/set`、または`/users/track`を通じて購読ステータスが設定され、オプションパラメーター`use_double_opt_in_logic`が`true`として渡された場合、ユーザーはワークフローに登録されます（例：[{"subscription_group_id" : "subscription_group_identifier", "subscription_state" : "subscribed", "use_double_opt_in_logic": true}]）。このパラメーターが省略された場合、ユーザーはダブルオプトインワークフローに登録されません。<br><br>REST APIで`use_double_opt_in_logic`を使用する場合、指定された電話番号に関連付けられたユーザープロファイルが存在しないと、購読ステータスは更新されず、ユーザーはダブルオプトインワークフローに入ることができません。
Shopify | Shopify連携によって購読ステータスが設定された場合、ユーザーはダブルオプトインワークフローに登録されません。
ユーザーインポート | ユーザーインポートによって購読ステータスが設定された場合、ユーザーはダブルオプトインワークフローに登録されません。
[ユーザー設定センター]({{site.baseurl}}/user_guide/audience/subscription_preferences/preference_center) | ユーザー設定センターを通じて購読登録されたユーザーは、自動的にダブルオプトインワークフローに入ります。
ユーザー更新ステップ | ユーザー更新ステップを通じて購読ステータスが設定され、オプションパラメーター`use_double_opt_in_logic`が`true`として渡された場合、ユーザーはダブルオプトインワークフローに登録されます。このパラメーターが省略された場合、ユーザーはダブルオプトインワークフローに登録されません。
{: .reset-td-br-1 .reset-td-br-2 aria-label="購読ソース" }

## 多言語サポート {#multi-language-support}
受信メッセージの場合、ダブルオプトインは購読グループで定義されたすべての言語でサポートされています。つまり、自動応答をさまざまな言語で定義でき、一致するキーワードを受信した際に、Brazeが特定の言語に関連付けられた自動応答を送信します。

受信メッセージ以外の購読更新（SDK、REST API、Shopifyなど）を通じてダブルオプトインワークフローに入ったユーザーには、英語のキーワードのみが送信されます。
