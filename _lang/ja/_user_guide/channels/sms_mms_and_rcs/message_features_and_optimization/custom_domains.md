# セルフサービスカスタムドメイン {#self-serve-custom-domains}

> このページでは、Brazeダッシュボードで独自のカスタムドメインを設定する方法について説明します。カスタムドメインを使用すると、一般的な短縮リンクやBrazeドメイン（`brz.ai`）の代わりに、ブランドのアイデンティティを反映したブランド付き短縮リンクを使用できます。これにより、ユーザーの信頼性が向上し、SMSリンクでのキャンペーンエンゲージメントが改善されます。

セルフサービスカスタムドメインを使用すると、SMS、RCS、WhatsApp用の独自のカスタムドメインをBrazeダッシュボードから直接設定・管理できます。最大10個のカスタムドメインを1か所で簡単に追加、監視、管理できます。

## セルフサービスカスタムドメインのメリット {#benefits-of-self-serve-custom-domains}

- **設定の効率化：** **会社の設定**ページでドメインを設定でき、セットアップ時間を短縮できます。
- **透明性の向上：** ダッシュボードのバナーを通じて、ドメインの設定ステータスに関するリアルタイムの更新を受け取れます。
- **プロアクティブな通知：** カスタムドメインが接続された場合や設定エラーが発生した場合に、即座にアラートを受け取れます。

## ドメインの要件 {#domain-requirements}

- ドメインはお客様自身で取得、所有、管理する必要があります。これはGoDaddy、Amazon Route 53、Google Domainsなどのドメインレジストラを通じて行えます。
- この機能に使用するドメインは以下の条件を満たす必要があります：
  - ユニークであること（Webサイトのドメインとは異なるもの）
  - Webコンテンツのホスティングに使用できないこと
    - ユニークなサブドメインを使用することもできます。たとえば、ドメイン`braze.com`には`sms.braze.com`や`whatsapp.braze.com`などのサブドメインを設定できます。

## カスタムドメインの委任 {#delegating-your-custom-domain}

リンク短縮およびクリックトラッキングサービスとの適切なルーティングとインフラの互換性を確保するため、カスタムドメインをBrazeに委任していただく必要があります。ドメインをBrazeに委任すると、サービスの中断を防ぐために証明書の更新が自動的に処理されます。

## カスタムドメインの追加 {#adding-a-custom-domain}

1. Brazeで、**会社の設定** > **SMS/RCSおよびメッセージングアプリドメイン**に移動します。
![複数のドメインが一覧表示された「SMS/RCSおよびメッセージングアプリドメイン」ページ。]({% image_buster /assets/img/main_page.png %})

{: start="2"}
2. **ドメインを追加**を選択して、新しいカスタムドメインの設定を開始します。
3. 購入したカスタムドメインをアプリ内の入力欄に入力します。既存のバリデーションロジックにより適切なフォーマットが検証されます。入力後、**次へ**を選択し、**送信**を選択します。

![「SMS/RCSおよびメッセージングアプリドメイン」ページの「ドメインを追加」ボタン。]({% image_buster /assets/img/custom_domain_button.png %}){: style="max-width:70%;"}

{: start="4"}
4. 技術チーム（エンジニアリングやITなど）に、表示されるCloudflare DNSレコードの詳細でDNS設定を更新してもらいます。技術チームは45日以内にこれらの詳細でDNSレコードを更新する必要があります。
  - DNSレコードの更新に追加の時間が必要な場合は、プロセスを再開して、ドメイン用の新しいDNSレコードセットを生成できます。

Brazeは約30分ごとにDNS設定をポーリングして更新を確認します。

![ドメインの設定を完了するための3つのステップが表示された「DNSレコード」セクション。]({% image_buster /assets/img/dns_record.png %})

{% alert note %}
ドメインの進行状況は自動的に保存されます。途中で終了する必要がある場合は、**SMS/RCSおよびメッセージングアプリドメイン**ページで保留中のドメインエントリを選択して、後から再開できます。
{% endalert %}

### 継続的な管理と使用 {#ongoing-management-and-usage}

ドメインが検証されると、カスタムドメインは**SMS/RCSおよびメッセージングアプリドメイン**ページのテーブルにステータスインジケーター付きで表示されます。接続済みのドメインは、複数のサブスクリプショングループ、ワークスペース、およびSMS、RCS、WhatsAppチャネルですぐに使用できます。

![カスタムドメインとステータスの一覧。]({% image_buster /assets/img/custom_domain_statuses.png %}){: style="max-width:60%;"}

ライブモニタリングにより、アクティブなドメインに問題がある場合はBrazeダッシュボードでアラートが表示されるため、カスタムリンクを引き続き使用できます。問題が発生した場合は、アプリ内のエラー詳細を参照するか、Braze[サポート]({{site.baseurl}}/braze_support)にお問い合わせください。

## サブスクリプショングループへのカスタムドメインの割り当て {#assigning-custom-domains-to-subscription-groups}

設定が完了すると、カスタムドメインを1つまたは複数のSMS、RCS、WhatsAppサブスクリプショングループに割り当てることができます。

1. **オーディエンス** > **購読グループ管理**に移動します。
2. 一覧からサブスクリプショングループを見つけて選択します。
3. **購読グループの詳細**で、**リンク短縮ドメイン**ドロップダウンからカスタムドメインを選択します。

リンク短縮をオンにして送信されたキャンペーンは、SMS、RCS、またはWhatsAppサブスクリプショングループに関連付けられた割り当て済みドメインを使用します。

![短縮リンクドメインが「メッセージ」ボックスのドメインとは異なるSMSメッセージ作成画面のプレビュー。]({% image_buster /assets/img/custom_domain2.png %})

## よくある質問 {#frequently-asked-questions}

### 委任されたドメインを複数のサブスクリプショングループで共有できますか？ {#can-delegated-domains-be-shared-across-multiple-subscription-groups}

はい。1つのドメインを複数のサブスクリプショングループで使用できます。そのためには、関連付ける各サブスクリプショングループでそのドメインを選択してください。

### 委任されたドメインを複数のワークスペースで共有できますか？ {#can-delegated-domains-be-shared-across-multiple-workspaces}

はい。ワークスペースが同じ会社内に含まれている場合、ドメインを複数のワークスペースのサブスクリプショングループに関連付けることができます。

### カスタムドメインはいくつ追加できますか？ {#how-many-custom-domains-can-i-add}

ダッシュボードごとに最大10個のカスタムドメインを追加できます。

### 45日以内にDNSレコードを更新しなかった場合はどうなりますか？ {#what-happens-if-i-dont-update-my-dns-records-within-45-days}

Cloudflare DNSレコードの詳細は45日後に期限切れになりますが、同じドメインでセットアッププロセスを再開でき、Brazeが新しいDNSレコードセットを生成してセットアップ期間を延長します。

### DNS更新プロセス中にエラーが発生した場合、通知されますか？ {#will-i-be-notified-if-there-is-an-error-during-the-dns-update-process}

はい。エラーが発生した場合、Brazeダッシュボードに問題の詳細と解決手順を記載したバナーが表示されます。

### カスタムドメインを複数のチャネルで使用できますか？ {#can-i-use-a-custom-domain-across-multiple-channels}

はい。カスタムドメインが検証された後、ダッシュボード内のすべてのワークスペースにわたるすべてのSMS、RCS、WhatsAppサブスクリプショングループで使用できます。

### 質問がある場合やさらにサポートが必要な場合はどうすればよいですか？ {#what-if-i-have-questions-or-need-further-support}

カスタムドメインの設定と管理に関する詳細なガイダンス（トラブルシューティング手順や技術要件を含む）については、[サポートにお問い合わせ]({{site.baseurl}}/braze_support)ください。
