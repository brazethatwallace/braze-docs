# セルフサービスカスタムドメイン {#self-serve-custom-domains}

> このページでは、Brazeダッシュボードで独自のカスタムドメインを設定する方法について説明します。カスタムドメインを使用すると、一般的な短縮リンクやBrazeドメイン（`brz.ai`）の代わりに、ブランドのアイデンティティを反映したブランド付き短縮リンクを使用できます。これにより、ユーザーの信頼性が向上し、SMSリンクでのキャンペーンエンゲージメントが改善されます。

セルフサービスカスタムドメインを使用すると、SMS、RCS、WhatsApp用の独自のカスタムドメインをBrazeダッシュボードから直接設定・管理できます。最大10個のカスタムドメインを1か所で簡単に追加、監視、管理できます。

## セルフサービスカスタムドメインのメリット {#benefits-of-self-serve-custom-domains}

- **設定の効率化：**「**会社の設定**」ページでドメインを設定でき、セットアップ時間を短縮できます。
- **透明性の向上：**ダッシュボードのバナーを通じて、ドメインの設定ステータスをリアルタイムで確認できます。
- **プロアクティブな通知：**カスタムドメインが接続されたとき、または設定エラーが発生したときに、即座にアラートを受け取ることができます。

## ドメインの要件 {#domain-requirements}

- ドメインは、お客様自身で取得、所有、管理する必要があります。これは、GoDaddy、Amazon Route 53、Cloudflareなどのドメインレジストラを通じて行うことができます。
- この機能に使用するドメインは、以下の条件を満たす必要があります。
  - 一意であること（Webサイトのドメインとは異なるもの）
  - Webコンテンツのホスティングに使用できないこと
    - 一意のサブドメインを使用することもできます。たとえば、ドメイン `braze.com` には `sms.braze.com` や `whatsapp.braze.com` などのサブドメインを設定できます。

## カスタムドメインの委任 {#delegating-your-custom-domain}

カスタムドメインをBrazeに委任していただく必要があります。これにより、リンク短縮およびクリックトラッキングサービスとの適切なルーティングとインフラの互換性を確保できます。ドメインをBrazeに委任すると、サービスの中断を防ぐために証明書の更新が自動的に処理されます。

{% alert important %}
DNSレコードが45日以内に更新されない場合、設定トークンの有効期限が切れます。**SMS/RCS and Messaging Apps Domains** からドメインの設定を再開して、新しいDNSレコードを生成してください。
{% endalert %}

## カスタムドメインの追加 {#adding-a-custom-domain}

1. Brazeで、**会社設定** > **SMS/RCSおよびメッセージングアプリドメイン**に移動します。
![複数のドメインが一覧表示された「SMS/RCSおよびメッセージングアプリドメイン」ページ。]({% image_buster /assets/img/main_page.png %})

{: start="2"}
2. **ドメインを追加**を選択して、新しいカスタムドメインの設定を開始します。
3. 購入したカスタムドメインをアプリ内の入力フィールドに入力します。既存のバリデーションロジックにより適切なフォーマットが検証されます。入力後、**次へ**を選択してから**送信**を選択します。

![「SMS/RCSおよびメッセージングアプリドメイン」ページの「ドメインを追加」ボタン。]({% image_buster /assets/img/custom_domain_button.png %}){: style="max-width:70%;"}

{: start="4"}
4. 技術チーム（開発やITなど）に、表示されるCloudflare DNSレコードの詳細でDNS設定を更新してもらいます。技術チームは45日以内にこれらの詳細でDNSレコードを更新する必要があります。
  - DNSレコードの更新に追加の時間が必要な場合は、プロセスを再開して、ドメイン用の新しいDNSレコードセットを生成できます。

BrazeはDNS設定を約30分ごとにポーリングして更新を確認します。

![ドメインの設定を完了するための3つのステップが表示された「DNSレコード」セクション。]({% image_buster /assets/img/dns_record.png %})

{% alert note %}
ドメインの進捗状況は自動的に保存されます。途中で終了する必要がある場合は、**SMS/RCSおよびメッセージングアプリドメイン**ページで保留中のドメインエントリを選択して後から再開できます。
{% endalert %}

### 継続的な管理と使用 {#ongoing-management-and-usage}

ドメインが検証されると、カスタムドメインは**SMS/RCSおよびメッセージングアプリドメイン**ページのテーブルにステータスインジケーターとともに表示されます。接続されたドメインは、複数の購読グループ、ワークスペース、およびSMS、RCS、WhatsAppチャネルにわたってすぐに使用できます。

![カスタムドメインとステータスの一覧。]({% image_buster /assets/img/custom_domain_statuses.png %}){: style="max-width:60%;"}

ライブ監視により、アクティブなドメインに問題が発生した場合はBrazeダッシュボードでアラートが通知されるため、カスタムリンクを引き続き使用できます。問題が発生した場合は、アプリ内のエラーの詳細を参照するか、Braze[サポート]({{site.baseurl}}/user_guide/administer/personal/braze_support)にお問い合わせください。

## 購読グループへのカスタムドメインの割り当て {#assigning-custom-domains-to-subscription-groups}

カスタムドメインは設定後、1つまたは複数のSMS、RCS、WhatsApp購読グループに割り当てることができます。

1. **オーディエンス** > **購読グループ管理**に移動します。
2. リストから購読グループを見つけて選択します。
3. **購読グループの詳細**で、**リンク短縮ドメイン**ドロップダウンからカスタムドメインを選択します。

リンク短縮を有効にして送信されたキャンペーンでは、SMS、RCS、またはWhatsApp購読グループに関連付けられた割り当て済みドメインが使用されます。

![「メッセージ」ボックスのドメインとは異なる短縮リンクドメインが表示されたSMSメッセージ作成画面のプレビュー。]({% image_buster /assets/img/custom_domain2.png %})

## よくある質問 {#frequently-asked-questions}

### 委任したドメインを複数の購読グループで共有できますか？ {#can-delegated-domains-be-shared-across-multiple-subscription-groups}

はい。1つのドメインを複数の購読グループで使用できます。関連付ける各購読グループにそのドメインを選択してください。

### 委任したドメインを複数のワークスペースで共有できますか？ {#can-delegated-domains-be-shared-across-multiple-workspaces}

はい。ワークスペースが同じ会社に含まれている場合、ドメインを複数のワークスペースの購読グループに関連付けることができます。

### カスタムドメインはいくつ追加できますか？ {#how-many-custom-domains-can-i-add}

ダッシュボードごとに最大10個のカスタムドメインを追加できます。リクエストに応じて、Brazeがお客様の会社に対してより高い上限を設定することも可能です。

**Pending**または**Error**ステータスのドメインもこの上限にカウントされます。**SMS/RCS and Messaging Apps Domains**ページでそれらを削除するか、エラーを解決してください。

購読グループで**Link Shortening Domain**として割り当てられているドメインは削除できません。まず各購読グループでドメインの割り当てを変更してから、そのドメインを削除してください。

### 45日以内にDNSレコードを更新しなかった場合はどうなりますか？ {#what-happens-if-i-dont-update-my-dns-records-within-45-days}

CloudflareのDNSレコードの詳細は45日後に期限切れになりますが、同じドメインで設定プロセスを再開でき、Brazeが新しいDNSレコードのセットを生成して設定期間を延長します。

### DNS更新プロセス中にエラーが発生した場合、通知されますか？ {#am-i-notified-if-there-is-an-error-during-the-dns-update-process}

はい。エラーが発生した場合、Brazeダッシュボードに問題の詳細と解決手順を示すバナーが表示されます。

### カスタムドメインを複数のチャネルで使用できますか？ {#can-i-use-a-custom-domain-across-multiple-channels}

はい。カスタムドメインが検証された後、ダッシュボード内のすべてのワークスペースにわたって、すべてのSMS、RCS、WhatsApp購読グループで使用できます。

### 質問がある場合やさらにサポートが必要な場合はどうすればよいですか？ {#what-if-i-have-questions-or-need-further-support}

トラブルシューティング手順や技術要件を含む、カスタムドメインの設定と管理に関する詳細なガイダンスについては、[サポートにお問い合わせ]({{site.baseurl}}/user_guide/administer/personal/braze_support)ください。
