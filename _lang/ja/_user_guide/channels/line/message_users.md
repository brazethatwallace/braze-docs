# LINEユーザーへのメッセージ送信 {#message-line-users}

> LINEは双方向のコミュニケーションチャネルです。ユーザーにメッセージを送信するだけでなく、テンプレート化されたキャンペーンやキャンバスを使用してユーザーと会話することができます。この記事では、受信メッセージのトリガーワードの設定方法や認識されない応答の処理方法など、ユーザーへのメッセージ送信の詳細について説明します。

LINEのトリガーワードを使用するなど、LINEを通じてユーザーと会話するさまざまな方法があります。また、コールトゥアクション（CTA）を使用して、LINEメッセージングへのユーザーエンゲージメントを促進することもできます。

## アクションベースのトリガー {#action-based-triggers}

トリガーワードを含む受信LINEメッセージ（ユーザーから送信されたメッセージ）を受け取ったときに、開始、分岐、およびジャーニー途中の変更を行うキャンペーンやキャンバスを作成できます。ユーザーが送信すると予想される内容に一致するトリガーワードを選択してください。

アクションベースの配信キャンペーンをスケジュールする際にトリガーワードを設定します。

### 要件 {#requirements}

Brazeでは受信トリガーワードの大文字化は必須ではありませんが、キャンペーンやキャンバスを構築する際には、トリガーワードの各文字を大文字にする必要があります。たとえば、トリガーワードが「JOIN2023」の場合、受信メッセージが「jOin2023」であっても、キャンバスやキャンペーンはトリガーされます。

トリガーワードが指定されていない場合、キャンペーンやキャンバスは*すべて*の受信LINEメッセージに対して実行されます。これには、アクティブなキャンペーンやキャンバスでフレーズが一致したメッセージも含まれ、その場合ユーザーは2つのLINEメッセージを受信します。

## 認識されない応答 {#unrecognized-responses}

インタラクティブなキャンバスには、認識されない応答に対するトリガーオプションを含める必要があります。これにより、利用可能なプロンプト（またはトリガーワード）をユーザーに通知し、チャネルに対する期待値を設定できます。

### 認識されない応答のトリガーを作成する {#creating-a-trigger-for-unrecognized-responses}

カスタムフィルターフレーズのアクショングループを作成した後、アクションパスに**Send LINE message**用の別のアクショングループを追加し、**Where the message body**にチェックを入れないでください。これにより、「else」句と同様に、認識されないすべてのユーザー応答がキャッチされます。

このメッセージでは、このチャネルは人間によって監視されていないことをユーザーに通知するLINEメッセージを送信し、必要に応じてサポートチャネルに誘導してください。
