# LINEメッセージタイプ {#line-message-types}

> この記事では、作成できるLINEメッセージタイプについて、その特徴と制限事項を含めて説明します。

LINEメッセージを作成する際、メッセージタイプをコンポーザーにドラッグ＆ドロップしてカスタマイズできます。

![テキスト、画像、リッチメッセージ、カードベースメッセージなど、コンポーザーエディターにドラッグできるメッセージタイプが表示されたメッセージタイプパネル。]({% image_buster /assets/img/line/line_message_types.png %}){: style="max-width:40%;"}

## テキスト {#text}

LINEテキストメッセージには最大5,000文字を含めることができ、絵文字やLiquidパーソナライゼーションを使用できます。

ユースケース:
- 在庫一掃セールの期間限定プロモーションを告知する
- ユニークなプロモーションカード付きのパーソナライズされた誕生日メッセージを送信する
- 今後のイベントに関する最新情報を素早く共有する

![ブラックフライデーパーティーを忘れないようにリマインドし、深夜までに最大80%オフになる可能性を伝えるテキストメッセージ。]({% image_buster /assets/img/line/line_text_message.png %}){: style="max-width:40%;"}

## 画像 {#image}

LINE画像メッセージは、[メディアライブラリ]({{site.baseurl}}/user_guide/messaging/design_and_edit/media_library)、URL、またはLiquidを通じて追加できます。これらの画像はスタンドアロンであり、クリック可能なリンクは含まれません。

ユースケース:
- 旅行先を紹介して、ユーザーに航空券の購入を検討してもらう
- シーズン末のプロモーションをハイライトして、来年の冬服をお得に買いだめするよう促す
- 店舗全体の年次セールへのビジュアルカウントダウンを開始する

![トースターのセールを宣伝する画像メッセージ。]({% image_buster /assets/img/line/line_image_message.png %}){: style="max-width:40%;"}

### URL画像 {#url-image}

URL画像は、以下を組み込むユースケースに使用します:
- 画像ソース属性にLiquidを含めることで、Liquidダイナミック画像を使用できます。例えば、画像URLとして {% raw %} `https://example.com/images/?imageBanner={{first_name}}` {% endraw %} を挿入すると、画像にユーザーの名を含めることができます
- [コネクテッドコンテンツ]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content)を使用して、Webサーバーまたは公開アクセス可能なAPIから画像を直接取得する
- [Brazeカタログ]({{site.baseurl}}/user_guide/data/activation/catalogs)を使用して、インポートされたCSVファイルやAPIエンドポイントから画像にアクセスする

| **仕様** | **推奨プロパティ** |
|--------------------------|----------------------------|
| 画像ファイルURL長 | 最大2,000文字  |
| 画像形式          | PNG、JPEG             |
| ファイルサイズ     |  最大10&nbsp;MB |
{: .reset-td-br-1 .reset-td-br-2 aria-label="URL画像" }

## リッチメッセージ（イメージマップ） {#rich-messages-image-map}

LINEリッチメッセージは、画像上の特定の領域を選択すると開かれる1つ以上のリンクを含む画像です。リッチメッセージテンプレートを選択して、リンクが画像上にどのようにマッピングされるかを選択します。

ユースケース:
- 新着ハンドバッグのグリッドを表示し、各バッグの商品ページへのリンクを設定する
- インタラクティブなメニューを表示し、アイテムを選択してコンボ注文を開始する
- 複数のプロモーションを並べて、ユーザーがグリッドの四角を選択して選べるようにする

![白黒のグリッド写真が表示された6マスのリッチメッセージ。ユーザーがタップするとランダムなオファーを受け取れます。]({% image_buster /assets/img/line/line_rich_message.png %})

### イメージマップ {#image-map}

| **仕様** | **推奨プロパティ** |
|--------------------------|----------------------------|
| 画像ファイルURL長 | 最大2,000文字  |
| 画像形式          | PNG（透過可）、JPEG             |
| アスペクト比          | 1:1（幅:高さ）
| ファイルサイズ     |  最大10&nbsp;MB |
{: .reset-td-br-1 .reset-td-br-2 aria-label="イメージマップ" }

### URIリンク {#uri-link}

| **仕様** | **推奨プロパティ** |
|--------------------------|----------------------------|
| 文字数      | 最大1,000 |
| スキーム              | HTTP、HTTPS、LINE、tel |
{: .reset-td-br-1 .reset-td-br-2 aria-label="URIリンク" }

### テキスト

テキストリッチメッセージには最大400文字を含めることができます。

## カードベース（カルーセル） {#card-based-carousel}

LINEカードベースメッセージでは、ユーザーがカルーセルのように複数のメッセージをスクロールし、カードまたはカードのボタンを選択して最も関連性の高いメッセージに対してアクションを実行できます。

ユースケース:
- 特定のメニューアイテムのプロモーションを表示する
- 今シーズンのベストセラージャケットをハイライトする
- キットに含まれる調理器具やガジェットのサンプルを紹介する

![コンポーザーエディターでサンドイッチを宣伝する少なくとも2枚のカードを含むカードベースメッセージ。]({% image_buster /assets/img/line/line_card_message.png %})

### メッセージ {#message}

| **仕様** | **推奨プロパティ** |
|--------------------------|----------------------------|
| カラム数                  | 最大10 |
| アスペクト比             | 長方形: 1.51:1 <br> 正方形: 1:1  |
| タイトル                    | 最大40文字
{: .reset-td-br-1 .reset-td-br-2 aria-label="メッセージ" }


### 画像

| **仕様** | **推奨プロパティ** |
|--------------------------|----------------------------|
| 画像URL                 | 最大2,000文字 |
| 画像形式              | JPEGまたはPNG |
| 幅                     | 1,024ピクセル  |
| ファイルサイズ                 | 1 MB |
{: .reset-td-br-1 .reset-td-br-2 aria-label="画像" }


### テキスト

| **仕様** | **推奨プロパティ** |
|-------------------------|----------------------------|
| 文字数              | 最大120（画像またはタイトルなし） <br> 最大60（画像またはタイトル付きメッセージ）  |
| アクション                 | 最大3 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="テキスト" }
