# WhatsApp カルーセルテンプレート {#whatsapp-carousel-templates}

> WhatsApp カルーセルテンプレートを使用すると、ユーザーがスワイプして閲覧できるインタラクティブなマルチカードメッセージを作成できます。各カルーセルには、画像や動画を含む最大10枚のカードと、エンゲージメント用のカスタマイズ可能なボタンを含めることができます。この機能は、製品やサービス、または複数ステップのコンテンツを視覚的に魅力的な形式で紹介するのに最適です。

## カルーセルテンプレートの作成 {#create-a-carousel-template}

WhatsAppテンプレートビルダーを使用して、Braze内でカルーセルテンプレートを作成できます。テンプレートを作成する際、BrazeはMetaの基準を満たすようにコンテンツを検証します。

Brazeでテンプレートを作成する際には、以下のいずれかを使用できます。
- メッセージ送信時に使用する予定のLiquid。Brazeはこれを今後の参照用に保存します。
- {% raw %}`{{1}}`{% endraw %} のような汎用変数。

{% alert note %}
{% raw %}`{% %}`{% endraw %} Liquidタグは、Metaのコンテンツ基準を満たさないため、テンプレートビルダーではサポートされていません。
{% endalert %}

テンプレートが送信されると、WABAのテンプレートリストに表示され、24時間以内に審査されます。ただし、審査は通常数分以内に完了します。

### ステップ1:テンプレートビルダーにアクセスする {#step-1-access-the-template-builder}

1. Brazeで**テンプレート**に移動します。
2. 利用可能なオプションから**WhatsAppテンプレート**を選択します。

![テンプレートナビゲーションメニューのWhatsAppテンプレート。]({% image_buster /assets/img/whatsapp/templates/whatsapp_templates.png %}){: style="max-width:70%;"}

{: start="3"}
3. **カルーセルテンプレートを作成**を選択します。

![カルーセルテンプレートを作成するボタン。]({% image_buster /assets/img/whatsapp/templates/create_carousel_template.png %})

### ステップ2:テンプレート設定を構成する {#step-2-configure-template-settings}

必須フィールドを入力します。

| フィールド | 説明 |
| --- | --- |
| WhatsApp Businessアカウント | このテンプレートが保存されるWABAを選択します。このWABA内のすべての購読グループと電話番号がテンプレートにアクセスできることに注意してください。 |
| テンプレート言語 | テンプレートの言語を選択します。Metaはテンプレートを単一言語に制限しているため、オーディエンスに表示される言語を選択してください。 |
| テンプレート名 | 後でこのテンプレートを識別するのに役立つ説明的な名前を入力します。テンプレート名にはスペースを含めることができません。アンダースコアを使用するか、スペースを完全に削除してください（`carousel_example` や `carouselexample` など）。 |
| カテゴリ | 自動的に**マーケティング**に設定されます。すべてのカルーセルメッセージはマーケティングメッセージとして分類されます。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="ステップ2:テンプレート設定を構成する" }

![WhatsApp Businessアカウントが選択され、テンプレート言語が英語、テンプレート名が「welcome_message」のWhatsAppテンプレート詳細パネル。]({% image_buster /assets/img/whatsapp/templates/whatsapp_template_details.png %}){: style="max-width:70%"}

### ステップ3:本文コンテンツを追加する {#step-3-add-body-content}

すべてのカルーセルメッセージは本文コンテンツから始まる必要があります。これはカルーセルカードの前に表示されるテキストです。

パーソナライゼーション用のLiquid変数（{% raw %}`{{first_name}}`{% endraw %} など）を含めることができます。これにより、ダイナミックなコンテンツで埋めたり、キャンペーンでテンプレートを使用する際に後から変更したりできる空の変数スロットが作成されます。変数は本文コンテンツの先頭または末尾に配置することはできません。

### ステップ4:カルーセル設定を構成する {#step-4-configure-carousel-settings}

個別のカードを作成する前に、カルーセル設定でカルーセル全体の構造を定義します。これらの設定はすべてのカードに適用され、テンプレート送信後は変更できません。

#### メディアタイプ {#media-type}

メディアタイプを選択します：**画像**または**動画**。これはすべてのカードに使用されます。

![画像または動画のメディアタイプを選択するオプションがある作成画面。]({% image_buster /assets/img/whatsapp/templates/media_types.png %})

#### ボタン設定 {#button-configuration}

ボタンタイプを選択します：**クイック返信**、**電話番号**、または**Webサイトにアクセス**。この設定はすべてのカードに使用されます。次に、カードごとに最大2つのボタンを選択します。

### ステップ5:カルーセルカードを作成する {#step-5-create-carousel-cards}

これで個別のカルーセルカードを作成できます。すべてのカードは同じ形状と構造を維持します。最大10枚のカードを追加できますが、少なくとも2枚のカードを追加する必要があります。

{% alert important %}
Metaに審査用としてテンプレートを送信した後は、カード枚数を変更できません。
{% endalert %}

1. 選択したメディアタイプに応じて、画像または動画をアップロードします。
2. カードテキストまたは説明を追加します。
3. ボタンテキストとアクションを設定します。
4. 必要に応じてLiquid変数を追加します。**+** プラスボタンがある場所に追加できます。

#### カードを複製する {#duplicate-a-card}

既存のカードをコピーするには、複製したいカードの3点メニューを選択し、**カードを複製**を選択します。Brazeはカードのメディア、テキスト、ボタン設定を、カルーセルの末尾に追加される新しいカードにコピーします。

カードは2〜10枚の範囲で追加できます。**カードを複製**は、カルーセルに既に10枚のカードがある場合、またはMetaにテンプレートを送信した後（カード枚数が固定されている場合）は使用できません。

{% alert tip %}
Liquid変数を戦略的に使用して、割引率、商品名、ユーザー固有のオファーなどのコンテンツをパーソナライズしましょう。変数はカードテキスト、ボタンテキスト、URLに追加できます。
{% endalert %}

![栄養豊富な食品を宣伝するカルーセルカードの例がある作成画面。]({% image_buster /assets/img/whatsapp/templates/example_carousel_cards.png %})

### ステップ6:プレビューして送信する {#step-6-preview-and-submit}

1. **プレビュー**セクションを使用して、カルーセルがユーザーにどのように表示されるかを確認します。
2. **Metaに審査用として送信**を選択すると、Brazeがテンプレートを承認のためにMetaに送信します。
3. 承認は通常数分で完了しますが、最大24時間かかる場合があります。
4. WhatsAppテンプレートページの**テンプレート**リスト、またはキャンバスやキャンペーンのセレクターでテンプレートのステータスを確認します。

{% alert note %}
テスト送信は、Metaがテンプレートを承認した後にのみ利用可能です。テンプレートのステータスは作成中は**下書き**として表示され、Metaが審査を完了すると**承認済み**に変わります。
{% endalert %}

## カルーセルテンプレートを使用する {#use-carousel-templates}

カルーセルテンプレートがMetaによって承認された後、キャンペーンやキャンバスで使用できます。プロセスはどちらのメッセージタイプでも同様です。

### ステップ1:WhatsAppメッセージを作成する {#step-1-create-a-whatsapp-message}

1. Brazeで、**キャンペーン**または**キャンバス**に移動し、WhatsAppメッセージを作成します。
2. テンプレートのWhatsApp Businessアカウント（WABA）に対応する購読グループを選択します。

{% alert important %}
複数のWhatsApp Businessアカウントがある場合は、テンプレートが作成されたWABAと同じWABAの購読グループを選択してください。テンプレートはWABA間では共有されませんが、同じWABA内のすべての購読グループと電話番号間では共有されます。
{% endalert %}

### ステップ2:カルーセルテンプレートを選択する {#step-2-select-your-carousel-template}

1. テンプレートを名前で検索します（「carousel_example」など）。
2. テンプレートのステータスが**承認済み**であることを確認します。
3. テンプレートを選択してメッセージ作成画面に読み込みます。

### ステップ3:ダイナミックなコンテンツをカスタマイズする {#step-3-customize-dynamic-content}

テンプレートを読み込むと、ロックされたコンテンツと編集可能なコンテンツが含まれています。

{% tabs local %}
{% tab ロックされたコンテンツ %}


- 静的テキスト（変数なしで送信されたコンテンツ）はロックされており、編集できません。
- カルーセルカードの数は固定されています。
- メディアタイプとボタンの設定は変更できません。

{% endtab %}
{% tab 編集可能なコンテンツ %}


{% raw %}
- 変数を含むフィールドは、異なるLiquidで変更できます。
- テンプレートをLiquid付きで送信した場合（例：`{{first_name}}`）、Brazeは自動的にそのLiquidを保持して表示します。
- Liquidを別の変数に変更できます（例：`{{first_name}}`から`{{last_name}}`に切り替える）。
- 変数を含む画像は、LiquidのURLを使用してダイナミックにすることができます。
- 送信済みのメディアを使用する代わりに、Brazeメディアライブラリから新しい画像をアップロードできます。
{% endraw %}

#### 例 {#example}

{% raw %}例えば、テンプレートに割引率の変数`{{discount_percentage}}`が含まれているとします。キャンペーンでは、これをそのまま使用するか、`{{custom_attributes.vip_discount}}`に変更できます。{% endraw %} Metaは変数スロットが埋められていることのみを要求しており、使用する具体的なLiquidは柔軟に変更できます。

{% endtab %}
{% endtabs %}

### ステップ4:キャンペーンまたはキャンバスを開始する {#step-4-launch-your-campaign-or-canvas}

メッセージ作成が完了したら、テストを含むキャンペーンまたはキャンバスの開始ワークフローに進みます。カルーセルテンプレートは他のWhatsAppメッセージテンプレートと同様に機能します。

## ベストプラクティス {#best-practices}

### コンテンツガイドライン {#content-guidelines}

- **本文コンテンツの配置：**変数は本文コンテンツの末尾に配置できません。各変数の後に少なくとも1つの単語または句読点を追加してください。
- **統一されたカード構造：**すべてのカードは同じ形状、メディアタイプ、ボタン設定を持つ必要があります。それに合わせてコンテンツを計画してください。
- **最適なカード数：**最大10枚のカードを作成できますが、ユーザーエクスペリエンスを考慮してください。カードが多すぎると圧倒される可能性があります。ほとんどのユースケースでは3〜5枚が適切です。
- **デフォルト値：**Liquid変数を使用する場合は、正確なプレビューのために必ずデフォルト値を指定してください。これにより、特定のユーザープロファイルデータが欠落している場合でもメッセージが適切に表示されることを確認できます。

### WhatsApp Businessアカウントと購読グループ {#whatsapp-business-accounts-and-subscription-groups}

- **テンプレート共有の理解：**テンプレートは同じWhatsApp Businessアカウント（WABA）内のすべての購読グループで共有されますが、異なるWABA間では共有されません。複数のWABAを管理している場合は、それに応じて計画してください。
- **WABAごとの整理：**複数のWABAがある場合は、キャンペーンでテンプレートを選択する際の混乱を避けるために、ビジネスアカウントごとにテンプレートを整理することを検討してください。

### テストと承認 {#testing-and-approval}

- **送信前のプレビュー：**Metaに承認申請する前に、必ずテンプレートをプレビューしてエラーがないか確認してください。
- **承認時間の計画：**承認には通常数分しかかかりませんが、キャンペーンの開始を計画する際には遅延の可能性も考慮してください。
- **徹底的なテスト：**承認後、実際のユーザーデータを使用してカルーセルをテストし、すべての変数が正しく入力され、ユーザーエクスペリエンスがシームレスであることを確認してください。

## トラブルシューティング {#troubleshooting}

| 問題 | ソリューション |
| --- | --- |
| テンプレートがキャンペーンに表示されない | 選択した購読グループがテンプレートと同じWABAに属していることを確認してください。また、テンプレートのステータスが**承認済み**であり、**Draft**や**Pending**ステータスのままでないことを確認してください。 |
| 本文の末尾に変数を配置できない | 変数をテキストの前方に移動し、変数の後に少なくとも1文字またはひとつの句読点を追加してください。これはWhatsAppテンプレートに関するMetaの要件です。 |
| テストで変数が反映されない | Liquid構文が正しいこと、およびユーザープロファイルに属性が存在することを確認してください。変数名にタイプミスがないか確認し、適切な箇所にデフォルト値が設定されていることを確認してください。 |
| テンプレート名にスペースが含まれている | テンプレート名にスペースを含めることはできません。代わりにアンダースコアを使用するか（`template_name`）、スペースを完全に削除してください（`templatename`）。 |
| カードの数を変更できない | カードの数はテンプレート作成時に固定され、送信後に変更することはできません。異なる数のカードが必要な場合は、新しいテンプレートを作成する必要があります。 |
