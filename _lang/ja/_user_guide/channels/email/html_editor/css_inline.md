# CSSインライン化

> CSSインライン化は、CSSスタイルシートのスタイルをHTMLメールの本文に移動するメール前処理の一形態です。「インライン化」という用語は、スタイルが個々のHTML要素に「インライン」で適用されることを指します。

一部のメールクライアントでは、CSSインライン化によりメールのレンダリングが改善され、メールが期待どおりに表示されることを確認するのに役立ちます。すでにCSSの大部分がインライン化されている場合や、HTMLとCSSがほとんどのメールクライアントの要件に対応していると確信している場合は、この機能をオンにする必要はないかもしれません。ダイナミックに埋め込まれたスタイルが既存のインラインスタイルと競合し、期待されるプレビューやメールのレンダリングが変わる可能性があります。

## CSSインライン化の使用

CSSインライン化のオン・オフは、HTMLエディターの**送信情報**タブにある**インラインCSSを有効にする**トグルを使用して、任意のメールメッセージで制御できます。

![HTMLコンポーザーでCSSインライン化を管理するチェックボックス。]({% image_buster /assets/img_archive/css-inline2.png %}){: style="max-width:40%;"}

### デフォルトのインライン化状態

**設定** > **メール設定**から、グローバルにデフォルトのオン・オフ状態を設定できます。**CSSインライン化**の設定を見つけてください。この設定は、すべての新しいメールメッセージが開始時に持つデフォルト値を決定します。この設定を変更しても、既存のメールメッセージには影響しません。また、メールメッセージの作成中にいつでもこのデフォルトを上書きできます。
