# Gmailプロモーションタブ {#gmail-promotions-tab}

> [Gmailモバイルのプロモーションタブ](https://developers.google.com/gmail/promotab/)を使用すると、マーケターは件名やプリヘッダーの情報だけでなく、「カード」の注釈を使用してより多くの情報を送信できます。Brazeには、メールキャンペーンからカードを作成するためのツールが組み込まれています。

## 前提条件 {#prerequisites}

まず、お客様のドメインとサブドメインをGoogleのプロモーションタブのアウトリーチチーム（<a href="mailto:p-promo-outreach@google.com">p-promo-outreach@google.com</a>）に転送して、Gmailの許可リストに追加してもらいます。これにより、Gmailプロモーションタブの商品カルーセルなど、リッチな画像を表示する機能を使用できます。

## Brazeでカードを構築する {#build-the-card-with-braze}

次のステップに従い、メールキャンペーンのGmailプロモーションカードを構築します。エディターの**コンテンツ**セクションから移動すると、**Gmailプロモーション**タブのフィールドと情報がリセットされます。プロモーションカードの設定を完了し、HTMLコードを失わないように生成されたHTMLをコピーしてください。

### ステップ1:メールキャンペーンを作成する {#step-1-create-an-email-campaign}

まず、[メールキャンペーンを作成]({{site.baseurl}}/user_guide/channels/email/html_editor)し、編集環境として**HTMLコードエディター**を選択します。

### ステップ2:Gmailプロモーションカードに詳細を追加する {#step-2-add-details-to-gmail-promotion-card}

次に、HTMLエディターの**コンテンツ**セクションに移動し、**Gmailプロモーション**タブを選択します。**基本情報**のフィールドに記入し、**HTMLコードを生成**を選択します。これにより、**HTMLコードを`<Head>`にコピー＆ペースト**セクションにGmailプロモーションタブカードのスクリプトが生成されます。

![カードの作成方法の例。]({% image_buster /assets/img/create-gmail-promo.png %})

### ステップ3:Gmailプロモーションカードをカスタマイズする {#step-3-customize-your-gmail-promotion-card}

Gmailプロモーションカードに割引オファー、ディールカード、プロモーションカード、またはすべてのオプションを含めるかどうかを選択します。

{% tabs %}
{% tab 割引オファー %}

割引オファーを設定すると、割引の有効期間を指定できます。

1. **割引オファー**のトグルを選択します。
2. **オファー**には、割引の簡単な概要を入力します。例えば「20％オフ」などです。
3. **コード**には、ユーザーがチェックアウト時に適用する必要のあるプロモーションコードを追加します。
4. 次に、割引オファーの開始日時を選択します。
5. 割引オファーを特定の時間に終了するか、終了しないかを決定します。

![割引オファーのオファー値、コード、開始日時を指定するオプション。]({% image_buster /assets/img/gmail_promo_discount_details.png %}){: style="max-width:70%;"}

{% endtab %}
{% tab ディールカード %}

ディールカードを使用すると、メール本文の上部に主要なディール情報を直接表示できます。これにより、受信者はオファーの詳細をすばやく理解し、アクションを起こすことができます。例えば、ディールカードを使用して期間限定オファーを宣伝し、ユーザーがメール内で詳細を探す手間を減らすことができます。

1. **ディールカード**のトグルを選択します。
2. **オファー**には、割引の簡単な概要を入力します。例えば「全靴20%オフ」などです。
3. （オプション）**コード**には、ユーザーがチェックアウト時に適用する必要のあるプロモーションコードを追加します。
4. 以下のURLのうち少なくとも1つを入力します。
-  **オファーページURL:** 特定のオファーランディングページのURLです。「今すぐ購入」（または類似の）ボタンが作成されます。ディールカードにはこのURLを提供することをお勧めします。
- **マーチャントホームページURL:** メインホームページのURLです。特定のオファーページURLが利用できない場合にのみ、このフィールドを使用してください。
5. （オプション）オファーの開始日を追加します。
6. オファーを特定の時間に終了するか、終了しないかを決定します。

![ディールカードのオファー値、コード、開始日時を指定するオプション。]({% image_buster /assets/img/gmail_promo_deal_cards.png %}){: style="max-width:70%;"}

{% endtab %}
{% tab プロモーションカード %}

商品カルーセルのプロモーションカードは、オファーに画像を提供するのに役立ちます。商品カルーセルの変数をカスタマイズし、最大10枚の画像プレビューを含めることもできます。各画像はユニークである必要があります。

1. **プロモーションカード**のトグルを選択します。
2. **プロモーションカードを追加**を選択します。商品カルーセルの各画像には固有のURLが必要で、同じアスペクト比（4:5、1:1、1.91:1）を使用する必要があります。
3. 画像URLを含めます。
4. **ターゲットURL**に、プロモーションのリンクを追加します。

{% alert tip %}
商品画像をメディアライブラリにアップロードし、URLをコピーして適切なフィールドに貼り付けることをお勧めします。静的画像形式（PNGおよびJPEG）のみが受け入れられます。一部の画像形式（GIF）はアップロードされますが、期待どおりに表示されません。
{% endalert %}

{: start="5"}
5. 見出し、通貨、価格、割引値を追加してプロモーションカードをカスタマイズします。

| カスタマイズ可能なプロパティ | 説明 |
|---|---|
| 見出し | （オプション）プロモーションの1〜2文の説明です。プレビュー画像の下に表示されます。 |
| 通貨 | （オプション）価格の通貨です。 |
| 価格 | プロモーションの価格です。 |
| 割引値 | 元の価格からの割引額です。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="ステップ3:Gmailプロモーションカードをカスタマイズする" }

### ステップ4:HTMLコードを生成して貼り付ける {#step-4-generate-and-paste-html-code}

Gmailプロモーションカードを作成したら、**HTMLコードを生成**を選択します。スクリプトをコピーして、メールのHTMLの`<head>`要素に貼り付けます。

{% alert tip %}
ドラッグ＆ドロップエディターの場合は、生成されたHTMLコードを**送信設定**の[カスタムヘッドタグ]({{site.baseurl}}/user_guide/channels/email/drag_and_drop#custom-head-tags)セクションにコピーして貼り付けます。
{% endalert %}

{% alert warning %}
プロモーションスクリプトは、メールがGmailのプロモーションタブに配信された場合にのみ表示されます。現在、Gmailはアルゴリズムを使用してメールの配信先を決定しています。ただし、ユーザーがメールをプロモーションとしてマークした場合、Gmailのアルゴリズムは無視され、以降メールは自動的にプロモーションタブに配信されます。
{% endalert %}

### ステップ5:Gmailのプレビューツールを使用してテストする {#step-5-test-using-gmails-preview-tool}

少量送信のアノテーションをテストするには、まずGmailの[プレビューツール](https://developers.google.com/workspace/gmail/promotab/preview)を使用してアノテーションを検証する必要があります。このステップをスキップすると、商品カルーセルと単一画像プレビューは、より大量の送信時にのみトリガーされます。

## Gmailカードの測定 {#measure-gmail-cards}

Gmailはこれらのカードに関する分析を返さず、Brazeのようなメールサービスプロバイダー（ESP）はヘッダーセクション（プロモーションカードや商品カルーセルを含む）のリンクに独自のリンクトラッキングを挿入できません。ただし、設定時にURLにUTMパラメーターやユニークコードを追加できます。これらのパラメーターにより、トラッキングがESPによって挿入されるのではなくURL自体の一部であるため、独自のWebサイト分析やコンバージョントラッキングを使用してエンゲージメントを追跡できます。ESPレベルのクリックトラッキングは、これらのリンクでは利用できません。

### 画像を組み込む {#incorporate-images}

Gmailでは、メールメッセージに関連する強力な画像を使用した方がより良い結果が得られています。Gmailは、このスペースがメールマーケティングに不可欠なビジュアル言語をプレビューに取り入れるために設計されているため、テキストのみのデザインの使用を推奨していません。テキストが途切れた画像を使用したり、複数のキャンペーンで同じ画像を繰り返し使用したりしないでください。

### オファーを説明する {#describe-offers}

Gmailは、「1つ買うと1つ無料」や「すべてのショーツとシャツが割引」などの文章やフレーズの使用を推奨していません。これらはクリップされたり、目を引かなくなったり、件名と競合したりする可能性があるためです。このスペースは、メッセージングで顧客をエンゲージするためにのみ使用してください。「今すぐこのメールを開く」や「ここをクリックしてお得な情報を入手」などの表現は避けてください。件名を繰り返すことも避けるのがベストです。

## ベストプラクティス {#best-practices}

一般的に、[Gmailのプロモーションタブのベストプラクティス](https://developers.google.com/gmail/promotab/best-practices)に従ってください。

カードを作成する際は、以下の質問を検討してください。

- アノテーションスクリプトは有効ですか？[Googleでプレビュー](https://developers.google.com/workspace/gmail/promotab/preview)してください。
- Gmailの**Show original**で、生のメッセージにスクリプトが表示されますか？
- メールは**Promotions**に配信されていますか？カードはそこでのみ適用されます。
- デスクトップとモバイルの両方でテストしましたか？

{% alert tip %}
スクリプト内のLiquidはサポートされていますが、エラーを避けるために徹底的にテストすることをお勧めします。
{% endalert %}

### アノテーションをプレビューする {#preview-your-annotation}

[プレビューツール](https://developers.google.com/workspace/gmail/promotab/preview)を使用してアノテーションをプレビューします。テストメールを自分に送信してもアノテーションには機能しません。アノテーションは、メールが相当数の受信者に送信される場合にのみレンダリングされるためです。最終メール（画像URLを含む）を少なくとも100人のGmail受信者に送信してください。

アノテーション付きのメールを送信するためにGoogle Workspaceを使用しないでください。許可リストに登録されたメールドメインのみを使用して、大規模な受信者グループにアノテーションを送信してください。

### 画像ガイドラインに準拠する {#adhere-to-image-guidelines}

画像が以下のガイドラインに準拠していることを確認してください。
- 高品質で高解像度の画像を使用してください。
- すべてのアノテーション画像は同じアスペクト比を使用してください。サポートされているアスペクト比は4:5、1:1、1.91:1です。
- 正しい画像サイズを使用してください。最小は256x256、最大は4096x4096ピクセルです。

Gmailは以下を避けることを推奨しています。
- 画像内でテキストを過度に使用すること
- アイコンのみの画像を使用すること
- 丸いマスクの画像を使用すること
- パーソナライズされた画像URLを使用すること

### DMARCに登録する {#register-with-dmarc}

アノテーションが正しくレンダリングされるようにするには、送信ドメインがDMARCに登録されており、すべてのポリシーが有効になっていることを確認してください。

## よくある質問 {#frequently-asked-questions}

### 送信者ロゴを追加するにはどうすればよいですか？ {#how-do-i-add-a-sender-logo}

[Googleアノテーション](https://developers.google.com/workspace/gmail/promotab/overview)を使用して、Gmailアプリにロゴとプロモーションカードを追加します。レンダリングはBrazeではなくGmailによって制御されます。

### プロモーションメッセージがエンドユーザーの受信トレイにプロモーションカードや商品カルーセルを表示しないのはなぜですか？ {#why-is-my-promotional-message-not-displaying-the-promotion-card-or-product-carousel-in-the-end-users-inbox}

商品カルーセルがGmailのプロモーションタブに表示されるかどうかを決定する要因は多数あります。

アノテーション内のすべての画像は品質フィルターを通過する必要があります。商品カルーセルが表示されるためには、アノテーション内のすべての画像が推奨される画像アスペクト比であり、高品質で高解像度のクローズアップ商品画像である必要があります。画像にはテキストがほとんどまたはまったく含まれていない必要があります。品質フィルターは不適切なコンテンツもフィルタリングするため、画像はファミリー、ユーザー、子供に適したものである必要があります。

さらに、Gmailにはユーザーのプロモーションタブに表示される商品カルーセルの数に密度制限があります。例えば、ユーザーがプロモーションメールで商品カルーセルを使用する多くのブランドを購読している場合、Gmailは最終的に表示される商品カルーセルの数に制限を設けます。

Googleのプライバシーおよび安全規制により、アノテーション付きのメールはアノテーションが機能するために広く送信される必要があります。Googleのシステムが「大量送信」として検出するために、キャンペーンを開始して少なくとも100人の受信者に送信することをお勧めします。画像URLは受信者間で異なってはいけません。

### プロモーションカードや商品カルーセルのクリックはどのように追跡されますか？ {#how-are-clicks-on-a-promotion-card-or-product-carousel-tracked}

Brazeやその他のESPは、ヘッダーセクションのリンクにリンクトラッキングを挿入できません。つまり、プロモーションカードや商品カルーセルのクリックは追跡できません。

### 商品カルーセルを受け取ったユーザー数を確認する方法はありますか？ {#is-there-a-way-to-see-how-many-users-received-a-product-carousel}

Gmailがカードをいつ誰に表示するかを決定するため、すべての受信者が商品カルーセルを見るという保証はありません。

### Gmailのプロモーションタブにアノテーションが表示されないのはなぜですか？ {#why-dont-i-see-annotations-in-my-gmail-promotions-tab}

アノテーションはGoogle Workspaceではサポートされていません。アノテーションをプレビューするには、Gmailで個人用メールアドレスを作成してください。

アノテーションは**メイン**タブやGmailモバイルアプリの他のタブではレンダリングされません。ユーザーがメールを開封した後や、`DiscountOffer`アノテーションタイプを使用していて日時がすでに期限切れの場合、アノテーションは表示されません。

{% alert tip %}
その他のトラブルシューティングについては、[Googleのメールプロモーションのトラブルシューティングガイド](https://developers.google.com/workspace/gmail/promotab/troubleshooting)を参照してください。
{% endalert %}
