# 自動 IP ウォームアップ

> 自動 IP ウォームアップを使用して、新しい IP アドレスからのメール送信量を段階的に増やし、受信トレイプロバイダーとの送信者レピュテーションを構築します。

{% multi_lang_include early_access_beta_alert.md feature='Automated IP warming' %}

## 仕組み

自動 IP ウォームアップを使用すると、1日の送信量を段階的に増やすことができ、受信トレイプロバイダーがお客様の送信パターンを学習し信頼できるようになります。ワークスペースにドメインを追加すると、ホームダッシュボードの **Pick up where you left off** セクションで **Automated IP Warming** タイルを選択できます。このタイルは60日間表示されます。

Braze はまずエンゲージメントが最も高いサブスクライバーに送信し、ベストプラクティスに合ったペースで1日の送信量を増やしていきます。その後、Braze はエンゲージメントと配信到達性のシグナルを追跡します。問題が検出された場合、システムはスケジュールを自動的に調整します。

{% alert note %}
IP ウォームアップは1回のみ実行できます。
{% endalert %}

## 前提条件

自動 IP ウォームアップを実行するには、以下が必要です。

- 検証済みのサブドメインとアクティブな IP アドレス
- IP ウォームアップの表示と起動の権限
    - IP ウォームアップセクションを表示するための「View Usage Data」
    - IP ウォームアップ用のメールテンプレートを表示・選択するための「View Email Templates」
    - IP ウォームアップを起動するための「Manage Email Settings」
- 「Access Campaigns」
- キャンペーンの承認ワークフローが有効になっている場合は「Approve and Deny Campaigns」
    - Braze は自動 IP ウォームアップから作成されたキャンペーンを自動的に承認します。

## 自動 IP ウォームアッププランの設定

### ステップ 1: スケジュールの設定

1. **Sending information** セクションで、IP アドレスをウォームアップする **From address** を選択します。
2. 現在の1日の送信量とターゲット送信量を入力します。
3. 自動 IP ウォームアップの開始日を選択します。この日付はプランの起動日から少なくとも1日後である必要があります。
4. 送信時刻を入力します。メッセージは会社のタイムゾーンで送信されます。
5. **Next: Segments** を選択してセットアップを続行します。

![スケジュール詳細の例。]({% image_buster /assets/img/automated_ip_warming_schedule.png %})

### ステップ 2: セグメントの選択とランク付け

1. 次に、ターゲットとするセグメントを選択します。IP ウォームアップ中、Braze はエンゲージメントが最も高いユーザーから送信を開始し、時間の経過とともに送信量を段階的に増やしながら、エンゲージメントの低いセグメントを徐々に追加していきます。
2. セグメントをドラッグ＆ドロップして、エンゲージメントの高い順から低い順にランク付けします。高エンゲージメントには、メールを一貫して開封しクリックする受信者が含まれます。低エンゲージメントには、メールへのエンゲージメントが不安定な受信者や、長期間メールに反応していない受信者が含まれます。
3. **Next: Messages** を選択してセットアップを続行します。

![自動 IP ウォームアップのターゲットとして選択された2つのセグメント。]({% image_buster /assets/img/automated_ip_warming_segment.png %})

### ステップ 3: 送信するメッセージの選択

1. **Select email templates** を選択します。
2. 送信するメッセージのメールテンプレートを選択します。IP ウォームアップ中に送信するコンテンツは、開封やクリックを促すものにしてください。過去に好評だったコンテンツを選択することをお勧めします。たとえば、即座のエンゲージメントと購入を促すプロモーションオファーを使用できます。
3. **Select templates** を選択します。Braze は起動前に必要なテンプレート数を計算します。配信到達性の問題が発生しても停止せずにシステムが調整できるよう、最低必要数よりも多くのテンプレートを用意することをお勧めします。
4. 必要な数のテンプレートを追加したら、**Next: Summary** を選択します。

{% alert important %}
IP ウォームアップツールから作成されたキャンペーンに加えた変更（スケジュール日、セグメント、ボリュームの変更など）は、IP ウォームアップの **Summary** ページには反映されません。
{% endalert %}

### ステップ 4: コンバージョンイベントの選択

追跡する以下のコンバージョンイベントを最大4つ定義できます。これらのコンバージョンイベントは、自動 IP ウォームアッププランの起動後に更新することはできません。

- セッションを開始
- 注文する
- カスタムイベントを実行
- アプリをアップグレード
- メールを開封
- メールをクリック

次に、コンバージョン期限を選択します。これは、ユーザーがキャンペーンに入ってからコンバージョンイベントが発生するまでの最大時間です。

![コンバージョンイベントの選択とコンバージョン期限を示すコンバージョン設定。]({% image_buster /assets/img/automated_ip_warming_conversions.png %})

### ステップ 5: 確認と起動

IP ウォームアッププランの詳細を確認します。次に、**Launch** を選択します。

## アクティブな IP ウォームアップ中

IP ウォームアップキャンペーンは1〜2日前に作成されます（翌日に IP ウォームアップを起動する場合を除く）。これらのキャンペーンは次の形式で自動的に命名されます: `IP Warming Day [X] - [Date] - [Template Name]`。

ターゲットの1日の送信目標に達すると、レピュテーションを保護するためにシステムはその日の送信を停止します。

システムは以下の業界ベンチマークに基づいてヘルスを監視します。

- 配信率が90%以下に低下
- 開封率が10%未満
- バウンスが5%超
- スパム苦情率が0.04%超

統計がベンチマークを下回った場合、送信者レピュテーションへのリスクを軽減するため、システムはボリュームを増やすのではなく、翌日のボリュームを維持します。

## IP ウォームアッププランの停止

Braze では IP ウォームアップと今後のキャンペーン作成を停止できますが、キャンペーンがすでにアクティブであるか、今後24〜48時間以内にスケジュールされている場合は、特定のキャンペーンを手動で停止する必要がある場合があります。IP ウォームアッププランを停止すると、関連するすべてのキャンペーンも停止されます。

ただし、停止した IP ウォームアップは再開できません。代わりに、中断したところから再開するために新しいプランを設定する必要があります。

- 新しい IP ウォームアップを開始すると以前のトラッカーが削除されるため、停止したプランの既存データをダウンロードして記録として保管してください
- **Current daily send volume** を最新のボリュームに更新します
- 前回の IP ウォームアップと同じセグメントを使用する場合は、以前のキャンペーンをすでに受信したユーザーを除外するフィルターをセグメントに追加します

## IP ウォームアップが完了した場合

IP ウォームアップは、IP ウォームアップの最終日が会社のタイムゾーンの深夜0時に終了した時点で完了としてマークされます。たとえば、IP ウォームアッププランで送信された最後のキャンペーンが午後8時に送信された場合、プランは4時間後に完了としてマークされます。

トラッカーはプラン終了後90日間ホームページに表示されます。90日後、トラッカーは削除されます。データのダウンロードには、以下の標準メール指標が含まれます。

- _Sent_
- _Delivered_
- _Bounces_
- _Spam reports_
- _Total opens_
- _Unique opens_
- _Clicked_
- _Unsubscribed_

ボリューム要件を満たすために1日に複数のキャンペーンが使用された場合、日次ビューで集計されます。
