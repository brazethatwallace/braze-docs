# 自動 IP ウォームアップ

> 自動 IP ウォームアップを使用すると、新しい IP アドレスからのメール送信量を徐々に増やし、受信トレイプロバイダーにおける送信者の評価を構築できます。

{% multi_lang_include alerts/early_access_beta_alert.md feature='Automated IP warming' %}

## 仕組み

自動 IP ウォームアップを使用すると、1日あたりの送信量を徐々に増やすことができ、受信トレイプロバイダーが送信パターンを学習し信頼するようになります。ワークスペースにドメインを追加すると、ホームダッシュボードの**「作業を再開する」**セクションで**「自動 IP ウォームアップ」**タイルを選択できます。このタイルは60日間表示されます。

Braze は最もエンゲージメントの高いサブスクライバーから優先的に送信するため、日々の送信量がベストプラクティスに沿ったペースで増加します。その後、Braze はエンゲージメントと配信可能性のシグナルを追跡します。Braze が問題を検知した場合、システムは自動的にスケジュールを調整します。

{% alert note %}
IP ウォームアップは一度だけ実行できます。
{% endalert %}

## 前提条件

自動 IP ウォームアップを行うには、以下が必要です。

- 検証済みサブドメインと有効な IP アドレス
- IP ウォームアップの表示と起動の権限
    - 「使用状況データを見る」で IP ウォームアップセクションを確認できます
    - 「メールテンプレートを表示」で IP ウォームアップ用のメールテンプレートを表示・選択できます
    - 「メール設定の管理」で IP ウォームアップを起動できます
- 「キャンペーンへのアクセス」
- キャンペーンの承認ワークフローが有効になっている場合は「キャンペーンの承認と却下」
    - Braze は自動 IP ウォームアップから作成されたキャンペーンを自動的に承認します。

## 自動 IP ウォームアッププランを設定する

### ステップ 1: スケジュールを設定する

1. **送信情報**セクションで、IP アドレスをウォームアップする**送信元アドレス**を選択します。
2. 現在の日次送信量と目標送信量を入力します。
3. 自動 IP ウォームアップの開始日を選択します。この日付はプランの起動日から少なくとも1日後である必要があります。
4. 送信時間を入力します。メッセージは会社のタイムゾーンで送信されます。
5. **次へ: セグメント** を選択して設定を続けます。

![スケジュールの詳細例。]({% image_buster /assets/img/automated_ip_warming_schedule.png %})

### ステップ 2: セグメント を選択し、順位付けする

1. 次に、ターゲットとする セグメント を選択します。IP ウォームアップ期間中、Braze は最もエンゲージメントの高いユーザーへの送信から開始し、時間の経過とともに送信量を徐々に増やしながら、エンゲージメントの低い セグメント を段階的に追加していきます。
2. セグメント をドラッグ＆ドロップして、エンゲージメントの高い順から低い順にランク付けします。高エンゲージメントには、メールを一貫して開封しクリックする受信者が含まれます。低エンゲージメントには、メールへのエンゲージメントが不安定な受信者や、長期間メールに反応していない受信者が含まれます。
3. **次へ: メッセージ**を選択して設定を続けます。

![自動 IP ウォームアップのターゲットとして選択された2つの セグメント。]({% image_buster /assets/img/automated_ip_warming_segment.png %})

### ステップ 3: 送信するメッセージを選択する

1. **メールテンプレートを選択**を選択します。
2. 送信するメッセージのメールテンプレートを選択します。IP ウォームアップ中に送信するコンテンツは、開封やクリックを促すものにしてください。過去に好評だったコンテンツを選択することをお勧めします。たとえば、即座のエンゲージメントと購入を促すプロモーションオファーを使用できます。
3. **テンプレートを選択**を選択します。Braze は起動前に必要なテンプレート数を計算します。配信可能性の問題が発生してもシステムが停止せずに調整できるよう、最低必要数よりも多くのテンプレートを用意することをお勧めします。
4. 必要な数のテンプレートを追加したら、**次へ: サマリー**を選択します。

{% alert important %}
IP ウォームアップツールから作成された キャンペーン に加えた変更（スケジュール日、セグメント、ボリュームの変更など）は、IP ウォームアップの**サマリー**ページには反映されません。
{% endalert %}

### ステップ 4: コンバージョンイベントを選択する

追跡する以下のコンバージョンイベントを最大4つ定義できます。これらのコンバージョンイベントは、自動 IP ウォームアッププランの起動後に更新することはできません。

- セッションを開始
- 注文する
- カスタムイベントを実行
- アプリをアップグレード
- メールを開封
- メールをクリック

次に、コンバージョン期限を選択します。これは、ユーザーが キャンペーン に入ってからコンバージョンイベントが発生するまでの最大時間です。

![コンバージョンイベントの選択とコンバージョン期限を示すコンバージョン設定。]({% image_buster /assets/img/automated_ip_warming_conversions.png %})

### ステップ 5: 確認と起動

IP ウォームアッププランの詳細を確認します。次に、**起動**を選択します。

## アクティブな IP ウォームアップ中

IP ウォームアップ キャンペーン は1〜2日前に作成されます（翌日に IP ウォームアップを起動する場合を除く）。これらの キャンペーン は次の形式で自動的に命名されます: `IP Warming Day [X] - [Date] - [Template Name]`。

ターゲットの日次送信目標に達すると、レピュテーションを保護するためにシステムはその日の送信を停止します。

システムは以下の業界ベンチマークに基づいてヘルスを監視します。

- 配信率が90%以下に低下
- 開封率が10%未満
- バウンスが5%超
- スパム苦情率が0.04%超

統計がベンチマークを下回った場合、送信者レピュテーションへのリスクを軽減するため、システムはボリュームを増やすのではなく、翌日のボリュームを維持します。

## IP ウォームアッププランの停止

Braze では IP ウォームアップと今後の キャンペーン 作成を停止できますが、キャンペーン がすでにアクティブであるか、今後24〜48時間以内にスケジュールされている場合は、特定の キャンペーン を手動で停止する必要がある場合があります。IP ウォームアッププランを停止すると、関連するすべての キャンペーン も停止されます。

ただし、停止した IP ウォームアップは再開できません。代わりに、中断したところから再開するために新しいプランを設定する必要があります。

- 新しい IP ウォームアップを開始すると以前のトラッカーが削除されるため、停止したプランの既存データをダウンロードして記録として保管してください
- **現在の日次送信量**を最新のボリュームに更新します
- 前回の IP ウォームアップと同じ セグメント を使用する場合は、以前の キャンペーン をすでに受信したユーザーを除外するフィルターを セグメント に追加します

## IP ウォームアップが完了した場合

IP ウォームアップは、IP ウォームアップの最終日が会社のタイムゾーンの深夜0時に終了した時点で完了としてマークされます。たとえば、IP ウォームアッププランで送信された最後の キャンペーン が午後8時に送信された場合、プランは4時間後に完了としてマークされます。

トラッカーはプラン終了後90日間ホームページに表示されます。90日後、トラッカーは削除されます。データのダウンロードには、以下の標準メール指標が含まれます。

- _Sent_
- _Delivered_
- _Bounces_
- _Spam reports_
- _Total opens_
- _Unique opens_
- _Clicked_
- _Unsubscribed_

ボリューム要件を満たすために1日に複数の キャンペーン が使用された場合、日次ビューで集計されます。
