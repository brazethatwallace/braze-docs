# 自動 IP ウォームアップ {#automated-ip-warming}

> 自動 IP ウォームアップを使用すると、新しい専用 IP からのメール送信量を徐々に増やし、受信トレイプロバイダーにおける送信者の評価を構築できます。よくある質問については、[自動 IP ウォームアップ FAQ]({{site.baseurl}}/user_guide/channels/email/email_setup/ip_warming/faq) を参照してください。

## 仕組み {#how-it-works}

自動 IP ウォームアップを使用すると、1日あたりの送信量を段階的に増やし、受信トレイプロバイダーがあなたの送信パターンを学習して信頼できるようにすることができます。ワークスペースにドメインを追加すると、ホームダッシュボードの**Pick up where you left off**セクションにある**Automated IP Warming**タイルを選択できます。このタイルは、ワークスペースが新規送信者のオンボーディング期間中である60日間表示され、少なくとも1つのプランを完了すると非表示になります。

各自動 IP ウォームアッププランは、1つの差出人アドレスに紐づけられます。その差出人アドレスは、送信サブドメインと IP プールにマッピングされます。プールに複数の専用 IP が含まれている場合、Brazeはそれらを1つのプランでまとめてウォームアップします。

Brazeは最もエンゲージメントの高いサブスクライバーから優先的に送信するため、ベストプラクティスに沿ったペースで1日の送信量を増やすことができます。その後、Brazeはエンゲージメントと配信到達性のシグナルを追跡します。Brazeが問題を検出した場合、システムはスケジュールを自動的に調整します。

少なくとも1つのプランを完了すると、**Settings** > **Email Preferences** > **Automated IP warming**で完了済みのプランを確認できます。

## 前提条件 {#prerequisites}

自動IPウォームアップを実行するには、以下が必要です。

- 検証済みのサブドメインとアクティブなIPアドレス
- プランの表示と設定に必要な権限:
    - 「View Email Settings」: IPウォームアップのプランとホームダッシュボードウィジェットを表示
    - 「View Email Templates」: メールテンプレートを選択
    - 「View セグメント」: セグメントを選択
- プランの起動に必要な権限:
    - 「Edit Email Settings」
    - 「Edit キャンペーン」
    - 「Launch キャンペーン」
    - 「Approve キャンペーン」

{% alert note %}
キャンペーン承認ワークフローが有効になっている場合、Brazeは自動IPウォームアップによって作成されたキャンペーンを自動的に承認します。
{% endalert %}

## 自動 IP ウォームアッププランの設定 {#set-up-an-automated-ip-warming-plan}

### ステップ1:スケジュールを設定する {#step-1-set-a-schedule}

1. 一意の**プラン名**を入力します。プラン名には文字、数字、ハイフン、アンダースコアのみ使用でき、ワークスペース内で一意である必要があります。プラン名は起動前に必須です。
2. **送信情報**セクションで、IP アドレスをウォームアップする**差出人アドレス**を選択します。Brazeは関連する**IP プール**と、その差出人アドレスの**プール内の IP アドレス数**を表示します。
3. **現在の1日あたりの送信量**と**目標送信量**を入力します。Brazeは、選択したプール内の IP あたり最大200万件の送信を目標送信量として推奨しています。現在の1日あたりの送信量が0の場合、スケジュールの初日は IP あたり最大50件、合計500件を上限として開始します。
4. 自動 IP ウォームアップの開始日を選択します。この日付はプランの起動日から少なくとも1日後でなければなりません。
5. 送信時刻を入力します。メッセージはワークスペースのタイムゾーン（ワークスペースに上書き設定がない場合は会社のタイムゾーン）で送信されます。
6. **次へ：セグメント**を選択して設定を続けます。

![スケジュール詳細の例。]({% image_buster /assets/img/automated_ip_warming_schedule.png %})

### ステップ2:セグメントを選択してランク付けする {#step-2-select-and-rank-segments}

1. 次に、ターゲットとするセグメントを選択します。IP ウォームアップ中、Brazeはエンゲージメントが最も高いユーザーから送信を開始し、時間の経過とともに送信量を徐々に増やしながら、エンゲージメントの低いセグメントを段階的に追加していきます。
2. セグメントをドラッグ＆ドロップして、エンゲージメントの高い順から低い順にランク付けします。高エンゲージメントには、メールを一貫して開封しクリックする受信者が含まれます。低エンゲージメントには、メールへのエンゲージメントが不安定な受信者や、長期間メールに反応していない受信者が含まれます。
3. **次へ：メッセージ**を選択して設定を続けます。

{% alert important %}
選択したすべてのセグメントのメール送信可能なユーザーの合計数が**目標送信量**以上であることを確認してください。オーディエンスが目標送信量より少ない場合、一部のユーザーは同じ日に複数のメールテンプレートを受信する可能性があります。詳細については、[オーディエンスサイズとユーザーあたりの複数送信](#audience-size-and-multiple-sends-per-user)を参照してください。
{% endalert %}

![自動 IP ウォームアップのターゲットとして選択された2つのセグメント。]({% image_buster /assets/img/automated_ip_warming_segment.png %})

### ステップ3:送信するメッセージを選択する {#step-3-select-the-messages-to-send}

1. **メールテンプレートを選択**を選択します。
2. 送信するメッセージのメールテンプレートを選択します。IP ウォームアップ中に送信するコンテンツは、開封とクリックを促すものにする必要があります。過去に良い反応があったコンテンツを選択することをお勧めします。たとえば、即座のエンゲージメントと購入を促すプロモーションオファーを使用できます。
3. **テンプレートを選択**を選択します。Brazeは起動前に必要なテンプレート数を計算します。配信到達性の問題が発生しても停止せずにシステムが調整できるよう、最小必要数よりも多くのテンプレートを用意することをお勧めします。
4. 必要な数のテンプレートを追加したら、**次へ：サマリー**を選択します。

{% alert important %}
IP ウォームアップツールから作成されたキャンペーンに加えた変更（スケジュール日、セグメント、ボリュームの変更など）は、IP ウォームアップの**サマリー**ページには反映されません。
{% endalert %}

### ステップ4:コンバージョンイベントを選択する {#step-4-select-conversion-events}

トラッキングするコンバージョンイベントを最大4つ定義できます。これらのコンバージョンイベントは、自動 IP ウォームアッププランの起動後に更新することはできません。

- セッションを開始する
- 注文する
- カスタムイベントを実行する
- アプリをアップグレードする
- メールを開封する
- メールをクリックする

次に、コンバージョン期限を選択します。これは、ユーザーがキャンペーンにエントリーしてからコンバージョンイベントが発生するまでの最大時間です。

![コンバージョンイベントの選択とコンバージョン期限を示すコンバージョン設定。]({% image_buster /assets/img/automated_ip_warming_conversions.png %})

### ステップ5:確認して起動する {#step-5-review-and-launch}

IP ウォームアッププランの詳細を確認します。次に、**起動**を選択します。

## 複数IPのIPウォームアップ {#multiple-ip-warming}

複数の差出人アドレスまたはIPプールをウォームアップする必要がある場合は、複数の自動IPウォームアッププランを使用します。

| シナリオ | 推奨事項 |
| --- | --- |
| 1つのIPプールに複数の専用IP | 1つのプランを作成し、そのプールの差出人アドレスを選択します |
| 複数のIPプールまたは差出人アドレス | 差出人アドレスごとに個別のプランを作成します |
{: .reset-td-br-1 .reset-td-br-2 aria-label="複数のIPウォームアップシナリオ" }

### 1つのプールで複数のIPをウォームアップする {#warm-multiple-ips-in-one-pool}

[ステップ1：スケジュールを設定する](#step-1-set-a-schedule)で差出人アドレスを選択すると、Brazeは関連するIPプールとプール内のIPアドレスを表示します。Brazeはランプスケジュールを作成する際にIP数を使用し、目標送信量を提案します。

**現在の1日あたりの送信量**が0の場合、最初のスケジュール日はプール内のIPあたり最大50送信、合計で500を上限として開始されます。Brazeはプール内のIPあたり最大200万送信の**目標送信量**を提案します。

### 複数のIPプールをウォームアップする {#warm-multiple-ip-pools}

複数の差出人アドレスまたはIPプールをウォームアップするには：

1. **設定** > **メール設定** > **自動IPウォームアップ**に移動します。
2. **新規IPウォームアッププラン**を選択します。
3. 一意の**プラン名**を入力します。
4. その差出人アドレスの設定を完了します。
5. ウォームアップが必要な追加の差出人アドレスまたはIPプールごとに繰り返します。

各プランは**自動IPウォームアップ**テーブルから追跡できます。各プランには独自のスケジュール、セグメント、テンプレート、キャンペーン、トラッカーがあります。プランのステータスは**下書き**、**進行中**、**完了**、または**停止**のいずれかになります。

{% alert important %}
自動IPウォームアッププランがアクティブな間は、同じ差出人アドレスまたはIPプールから大量の非ウォームアップキャンペーンを送信しないでください。ウォームアップ中の追加送信は配信到達性のシグナルに影響を与え、問題の切り分けを困難にする可能性があります。
{% endalert %}

## アクティブなIPウォームアップ中 {#during-active-ip-warming}

IPウォームアップキャンペーンは、有効なタイムゾーンで当日および翌日の深夜0時に作成されます（送信の0〜1日前）。プランを開始すると、今後のキャンペーンもすぐに作成されます。これらのキャンペーンには、`IP Warming Day [X] - [Date] - [Template Name]` という形式で自動的に名前が付けられます。

1日の目標送信数に達すると、レピュテーションを保護するためにその日の送信が停止されます。

Brazeは、12〜20時間前に送信されたキャンペーンの配信到達性を評価します。以下のしきい値のいずれかを超えた場合、Brazeは次の送信日のボリュームを増加させず、保留します。

- 配信率が90%未満
- 開封率が10%未満
- バウンス率が5%超
- スパム苦情率が0.04%超

ボリュームが保留された場合の動作については、[ボリュームが保留されるとどうなりますか?]({{site.baseurl}}/user_guide/channels/email/email_setup/ip_warming/faq#what-happens-when-volume-is-held)を参照してください。

## オーディエンスサイズとユーザーあたりの複数送信 {#audience-size-and-multiple-sends-per-user}

各日の送信目標を達成するために、Brazeは選択されたメールテンプレートを順番に使用します。プラン内では、すでに特定のテンプレートを受信したユーザーは除外されますが、別のテンプレートを受信したユーザーは引き続き対象となります。その日のスケジュールに対応するオーディエンスが不足すると、プランはテンプレートを再び循環するため、同じ日に2つ目のテンプレートを受信するユーザーが発生します。

選択したセグメント全体でメール送信可能なユーザーの合計数が**目標送信数**より少ない場合、日次ボリュームが最大になるプランの最終日にこの結果は避けられません。たとえば、セグメントにメール送信可能なユーザーが400,000人含まれており、目標送信数が600,000の場合、最終日に約200,000人のユーザーが2つのテンプレートを受信し、残りの200,000人のユーザーは1つのテンプレートを受信します。

オーディエンスが目標送信数より大きい場合でも、ユーザーが異なる日に異なるテンプレートを受信することがあります。Brazeは、各日のオーディエンスをテンプレートに分割する際に、ユーザーが以前にどのテンプレートを受信したかを考慮しないため、あるテンプレートを受信したユーザーがプランの後半で別のテンプレートに選択される可能性があります。

目標送信数が利用可能なオーディエンスを超えている場合でも、Brazeはプランの開始を妨げません。送信日ごとに各ユーザーを1つのテンプレートに制限するには、開始前に以下のいずれかを行ってください:

- メール送信可能なユーザーの合計数が目標送信数以上になるようにセグメントを追加します。
- メール送信可能なユーザーの合計数を超えないように**目標送信数**を下げます。

## IP ウォームアッププランを停止する {#stop-an-ip-warmup-plan}

IP ウォームアッププランを停止すると、今後のキャンペーンの作成を防止できます。プランを停止すると、関連するすべてのキャンペーンも無効になります。プランを停止した後は再開できません。中断した箇所から再開するには、新しいプランを設定してください。その際の手順は以下のとおりです。

- 停止したプランの既存データをダウンロードして記録として保管します
- **現在の1日あたりの送信量**を直近の送信量に更新します
- 前回の IP ウォームアップと同じセグメントを使用する予定がある場合は、以前のキャンペーンをすでに受信したユーザーを除外するフィルターをセグメントに追加します

## IP ウォームアップが完了した場合 {#when-an-ip-warming-completes}

IP ウォームアップは、IP ウォームアップの最終日がワークスペースのタイムゾーン（またはワークスペースに上書き設定がない場合は会社のタイムゾーン）の午前0時に終了した時点で完了とマークされます。たとえば、プラン内の最後のキャンペーンが午後8時に送信された場合、そのプランは4時間後の午前0時に完了とマークされます。

完了したプランは、**設定** > **メール設定** > **自動 IP ウォームアップ**から引き続き利用できます。トラッカーもプラン終了後90日間はホームダッシュボードに表示されます。90日後、ホームダッシュボードのトラッカーは削除されます。

データのダウンロードには、次の標準的なメール指標が含まれます。

- _送信数_
- _配信数_
- _バウンス数_
- _スパムレポート数_
- _総開封数_
- _ユニーク開封数_
- _クリック数_
- _購読解除数_

1日に複数のキャンペーンがボリューム要件を満たすために使用された場合、それらは日次ビューで集計されます。
