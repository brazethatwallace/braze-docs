# 自動 IP ウォームアップ {#automated-ip-warming}

> 自動 IP ウォームアップを使用すると、新しい専用 IP からのメール送信量を徐々に増やし、受信トレイプロバイダーにおける送信者の評価を構築できます。

## 仕組み {#how-it-works}

自動 IP ウォームアップを使用すると、1日の送信量を段階的に増やすことができ、受信トレイプロバイダーがお客様の送信パターンを学習し信頼できるようになります。ワークスペースにドメインを追加すると、ホームダッシュボードの**Pick up where you left off**セクションにある**Automated IP Warming**タイルを選択できます。このタイルは、ワークスペースが新規送信者のオンボーディング期間中である60日間表示されます。

各自動 IP ウォームアップのプランは、1つの差出人アドレスに紐づけられています。その差出人アドレスは、送信サブドメインとIPプールにマッピングされます。プールに複数の専用IPが含まれている場合、Brazeはそれらを1つのプランでまとめてウォームアップします。

Brazeは最もエンゲージメントの高いサブスクライバーから優先的に送信するため、ベストプラクティスに沿ったペースで1日の送信量を増やすことができます。その後、Brazeはエンゲージメントと配信到達性のシグナルを追跡します。問題が検出された場合、システムがスケジュールを自動的に調整します。

少なくとも1つのプランを完了すると、**設定** > **メール設定** > **Automated IP warming**で完了したプランを確認できます。

{% alert note %}
ダッシュボードにプランが1つしか表示されない場合、お客様のワークスペースではまだ複数の IP ウォームアッププランにアクセスできない可能性があります。利用可能かどうかについては、Brazeアカウントチームにお問い合わせください。
{% endalert %}

## 前提条件 {#prerequisites}

自動 IP ウォームアップを実行するには、以下が必要です。

- 検証済みのサブドメインとアクティブな IP アドレス
- IP ウォームアップの表示と起動に必要な権限
    - IP ウォームアップセクションを表示するための「View Usage Data」
    - IP ウォームアップ用のメールテンプレートを表示・選択するための「View Email Templates」
    - IP ウォームアップを起動するための「Manage Email Settings」
- 「Access キャンペーン」
- キャンペーンの承認ワークフローが有効になっている場合は「Approve and Deny キャンペーン」
    - Brazeは、自動 IP ウォームアップから作成されたキャンペーンを自動的に承認します。

{% alert important %}
この機能は、メールインフラによってはサポートされない場合があります。
{% endalert %}

## 自動 IP ウォームアッププランの設定 {#set-up-an-automated-ip-warming-plan}

### ステップ1: スケジュールを設定する {#step-1-set-a-schedule}

1. ワークスペースが複数の IP ウォームアッププランをサポートしている場合は、一意の**プラン名**を入力します。プラン名には英字、数字、ハイフン、アンダースコアのみを使用でき、ワークスペース内で一意である必要があります。プラン名は起動前に必須です。
2. **送信情報**セクションで、IP アドレスをウォームアップする**差出人アドレス**を選択します。Brazeは、その差出人アドレスに関連付けられた**IP プール**と**プール内の IP アドレス**の数を表示します。
3. **現在の1日あたりの送信量**と**目標送信量**を入力します。Brazeは、選択したプール内の IP あたり最大200万送信の目標送信量を推奨しています。現在の1日あたりの送信量が0の場合、スケジュールの初日は IP あたり最大50送信、合計500送信を上限として開始されます。
4. 自動 IP ウォームアップの開始日を選択します。この日付は、プランの起動日から少なくとも1日後である必要があります。
5. 送信時刻を入力します。メッセージは会社のタイムゾーンで送信されます。
6. **次へ: セグメント**を選択して設定を続行します。

![スケジュール詳細の例。]({% image_buster /assets/img/automated_ip_warming_schedule.png %})

### ステップ2: セグメントを選択してランク付けする {#step-2-select-and-rank-segments}

1. 次に、ターゲットとするセグメントを選択します。IP ウォームアップ中、Brazeはエンゲージメントが最も高いユーザーへの送信から開始し、時間の経過とともに送信量を徐々に増やしながら、エンゲージメントの低いセグメントを少しずつ追加していきます。
2. セグメントをドラッグ＆ドロップして、エンゲージメントの高い順から低い順にランク付けします。高エンゲージメントには、メールを一貫して開封しクリックする受信者が含まれます。低エンゲージメントには、メールへのエンゲージメントが不安定な受信者や、長期間メールに反応していない受信者が含まれます。
3. **次へ: メッセージ**を選択して設定を続行します。

![自動 IP ウォームアップのターゲットとして選択された2つのセグメント。]({% image_buster /assets/img/automated_ip_warming_segment.png %})

### ステップ3: 送信するメッセージを選択する {#step-3-select-the-messages-to-send}

1. **メールテンプレートを選択**を選択します。
2. 送信するメッセージのメールテンプレートを選択します。IP ウォームアップ中に送信するコンテンツは、開封やクリックを促すものにしてください。過去に好評だったコンテンツを選択することをお勧めします。たとえば、プロモーションオファーを使用して、即座のエンゲージメントや購入を促進できます。
3. **テンプレートを選択**を選択します。Brazeは、起動前に必要なテンプレート数を計算します。配信性の問題が発生しても停止せずにシステムが調整できるよう、最低必要数よりも多くのテンプレートを用意することをお勧めします。
4. 必要な数のテンプレートを追加したら、**次へ: サマリー**を選択します。

{% alert important %}
IP ウォームアップツールから作成されたキャンペーンに加えた変更（スケジュール日、セグメント、ボリュームの変更など）は、IP ウォームアップの**サマリー**ページには反映されません。
{% endalert %}

### ステップ4: コンバージョンイベントを選択する {#step-4-select-conversion-events}

追跡する以下のコンバージョンイベントを最大4つ定義できます。これらのコンバージョンイベントは、自動 IP ウォームアッププランの起動後に更新することはできません。

- セッションを開始
- 注文する
- カスタムイベントを実行
- アプリをアップグレード
- メールを開封
- メールをクリック

次に、コンバージョン期限を選択します。これは、ユーザーがキャンペーンに入ってからコンバージョンイベントが発生するまでの最大時間です。

![コンバージョンイベントの選択とコンバージョン期限を示すコンバージョン設定。]({% image_buster /assets/img/automated_ip_warming_conversions.png %})

### ステップ5: 確認して起動する {#step-5-review-and-launch}

IP ウォームアッププランの詳細を確認します。次に、**起動**を選択します。

## 複数のIPウォームアップ {#multiple-ip-warming}

複数の差出人アドレスまたはIPプールをウォームアップする必要がある場合は、複数の自動IPウォームアッププランを使用します。

| シナリオ | 推奨事項 |
| --- | --- |
| 1つのIPプールに複数の専用IP | 1つのプランを作成し、そのプールの差出人アドレスを選択します |
| 複数のIPプールまたは差出人アドレス | 差出人アドレスごとに個別のプランを作成します |
{: .reset-td-br-1 .reset-td-br-2 aria-label="複数のIPウォームアップシナリオ" }

### 1つのプールで複数のIPをウォームアップする {#warm-multiple-ips-in-one-pool}

[ステップ1：スケジュールを設定する](#step-1-set-a-schedule)で差出人アドレスを選択すると、Brazeは関連するIPプールとプール内のIPアドレスを表示します。Brazeはランプスケジュールを構築する際にIP数を使用し、目標送信量を提案します。

**現在の1日あたりの送信量**が0の場合、最初のスケジュール日はプール内のIPあたり最大50送信から開始され、合計500件が上限となります。Brazeはプール内のIPあたり最大200万送信の**目標送信量**を提案します。

### 複数のIPプールをウォームアップする {#warm-multiple-ip-pools}

複数の差出人アドレスまたはIPプールをウォームアップするには：

1. **設定** > **メール設定** > **自動IPウォームアップ**に移動します。
2. **新しいIPウォームアッププラン**を選択します。
3. 一意の**プラン名**を入力します。
4. その差出人アドレスの設定を完了します。
5. ウォームアップが必要な追加の差出人アドレスまたはIPプールごとに繰り返します。

各プランは**自動IPウォームアップ**テーブルから追跡できます。各プランには独自のスケジュール、セグメント、テンプレート、キャンペーン、およびトラッカーがあります。プランのステータスは**下書き**、**進行中**、**完了**、または**停止**のいずれかです。

{% alert important %}
自動IPウォームアッププランがアクティブな間は、同じ差出人アドレスまたはIPプールから大量の非ウォームアップキャンペーンを送信しないでください。ウォームアップ中の追加送信は配信シグナルに影響を与え、問題の切り分けが困難になる可能性があります。
{% endalert %}

## アクティブな IP ウォームアップ中 {#during-active-ip-warming}

IP ウォームアップキャンペーンは、翌日に IP ウォームアップを開始する場合を除き、1〜2日前に作成されます。これらのキャンペーンは、`IP Warming Day [X] - [Date] - [Template Name]` の形式で自動的に命名されます。

目標とする1日の送信数に達すると、送信者レピュテーションを保護するために、システムはその日の送信を停止します。

システムは、以下の業界ベンチマークに基づいてメール送信の健全性を監視します。

- 配信率が90%以下に低下
- 開封率が10%未満
- バウンス率が5%超
- スパム苦情率が0.04%超

統計がベンチマークを下回っている場合、システムは送信者レピュテーションへのリスクを軽減するために、送信量を増やすのではなく、翌日の送信量を据え置きます。

## IP ウォームアッププランの停止 {#stop-an-ip-warmup-plan}

Brazeでは、IP ウォームアップと今後のキャンペーンの作成を停止できますが、キャンペーンがすでにアクティブであるか、今後24〜48時間以内にスケジュールされている場合は、特定のキャンペーンを手動で停止する必要がある場合があります。IP ウォームアッププランを停止すると、関連するすべてのキャンペーンも停止されます。

ただし、停止した IP ウォームアップは再開できません。代わりに、中断したところから再開するために新しいプランを設定する必要があります。その際、以下の手順を行います。

- 停止したプランの既存データをダウンロードして記録として保管する
- **現在の1日あたりの送信量**を直近の送信量に更新する
- 前回の IP ウォームアップと同じセグメントを使用する場合は、以前のキャンペーンをすでに受信したユーザーを除外するフィルターをセグメントに追加する

## IPウォームアップが完了した場合 {#when-an-ip-warmup-completes}

IPウォームアップは、IPウォームアップの最終日が会社のタイムゾーンの深夜0時に終了した時点で完了とマークされます。たとえば、IPウォームアッププランで送信された最後のキャンペーンが午後8時に送信された場合、そのプランは4時間後に完了とマークされます。

完了したプランは、**設定** > **メール設定** > **自動IPウォームアップ**から引き続き利用できます。ワークスペースがシングルプランエクスペリエンスを使用している場合、トラッカーはプラン終了後90日間ホームダッシュボードにも表示されます。90日後、ホームダッシュボードのトラッカーは削除されます。

データのダウンロードには、以下の標準的なメール指標が含まれます。

- _送信数_
- _配信数_
- _バウンス数_
- _スパムレポート数_
- _合計開封数_
- _ユニーク開封数_
- _クリック数_
- _購読解除数_

1日に複数のキャンペーンを使用してボリューム要件を満たした場合、これらは日次ビューで集計されます。
