# メール一覧をBraze に読み込む {#importing-email-lists}

> メール送信を成功させるための重要なステップとして、質の高いメールリストを確保することがあります。適切なメールリスト管理によって配信到達性が向上し、より正確でクリーンなキャンペーン成果を得ることができます。

## インポート前の注意事項

{% multi_lang_include alerts/important_alerts.md alert='Email via SMS' %}

### メールリストを検証する

メールリストを Braze にインポートする前に、リストに本物のメールアドレスだけが含まれていることを確認してください。バウンス率が高いと、メール送信者の評判が下がります。

メールリストのクリーニングサービスを利用すると、メールアドレスが正しい構文に従っているか、メールアドレスの物理的な特性を持っているかを判定し、メールドメインを検証し、メールサーバーに接続してそのメールアドレスが存在するかどうかを認証することができます。

### メールアドレスがすでにユーザーに関連付けられているかどうかを調べる

API または SDK でユーザーを作成する前に、[`/users/export/ids`]({{site.baseurl}}/api/endpoints/export/user_data/post_users_identifier/) エンドポイントを呼び出し、ユーザーの `email_address` を指定します。ユーザープロファイルを返した場合、その Braze ユーザーはすでにそのメールアドレスに関連付けられています。

新規ユーザーを作成する際には、固有のメールアドレスを使用し、同じメールアドレスを持つユーザーを渡すことやインポートすることがないようにすることを強くお勧めします。そうしないと、メッセージ送信、ターゲティング、レポート、その他の機能に影響を与える、意図しない結果を招く可能性があります。

たとえば、重複したプロファイルがあるが、特定のカスタム属性やイベントが1つのプロファイルにしか存在しないとします。複数の条件で キャンペーン や キャンバス をトリガーしようとすると、ユーザープロファイルが2つあるため、Braze が対象ユーザーとして識別できません。また、キャンペーン が2人のユーザーによって共有されているメールアドレスをターゲットにしている場合、**ユーザーを検索**ページには、両方のユーザープロファイルが キャンペーン を受け取ったものとして表示されます。

### エンゲージメントの高いユーザーを特定する

最もエンゲージメントの高いユーザーを特定するためには、まず、長期間にわたって離脱しているユーザーを排除します。メール送信者としての評判が損なわれないよう、6か月以上メールのエンゲージメントがないユーザーにはメールを送信しないのがベストプラクティスです。メールリストをインポートする際は、過去6か月以内にメールを開封したユーザーだけを含めるようにしてください。

長期的には、[サンセットポリシー]({{site.baseurl}}/user_guide/channels/email/best_practices/sunset_policies/)の導入も検討してください。

### 抑制リストを避ける

既存のメールプロバイダーから移行する場合は、抑制リストからユーザーをインポートしないように注意してください。抑制リストには、配信停止した、メールをスパムとしてマークした、またはハードバウンスしたメールアドレスが含まれています。

## インポート方法

メールリストの準備ができたら、Braze REST API や CSVファイルなど、Braze にユーザーをインポートするいくつかの方法があります。詳しくは[ユーザーインポート]({{site.baseurl}}/user_guide/audience/manage_audience/import_users/)の記事をご覧ください。
