# 認証済みドメイン {#verified-domains}

> 認証済みドメインを使用すると、特定のサブドメインの管理をBrazeに委任し、メール設定とHTTPSトラッキングを自動化できます。DNSドメイン委任により、Brazeはメール送信とクリックトラッキングに必要なDNSレコードを管理します。たとえば、サブドメインが「mail.example.com」の場合、それをBrazeに委任して送信ドメインとトラッキングドメインを設定できます。

{% alert important %}
認証済みドメインは現在、Amazon SESのみをサポートしています。SendGridまたはSparkPostを使用している場合、この機能は利用できません。<br><br>認証済みドメインはメールのみでサポートされています。{% multi_lang_include product_feedback_cta.md context="gap" feature="verified domains for channels other than email" %}
{% endalert %}

## メリット {#benefits}

- オンボーディングの高速化：これらのステップを自動化することで、メールのオンボーディング時間を短縮できます。
- 調整作業の削減：ドメイン設定タスクのためにBrazeサポートと連携する必要がなくなり、完全なセルフサービス体験に近づきます。
- SSL管理の自動化：BrazeがSSL証明書の作成と更新を処理するため、一般的な障害ポイントと手動のオーバーヘッドが排除されます。SSLでリンクを保護することは標準的なベストプラクティスです。受信者はセキュアなリンクをより信頼しやすく、追加の認証レイヤーがデータの保護に役立ちます。
- 設定エラーの削減：ガイド付きのオンボーディングフローと自動検証により、エラーが発生しやすい手動のDNS設定が置き換えられるため、レコードの誤設定やメール設定の破損が起こりにくくなります。
- プロアクティブな監視：Brazeは障害が表面化するのを待つのではなく、DNSレコードを監視し、問題を検出した場合に通知します。

## 考慮事項 {#considerations}

開始する前に、以下の点に留意してください。

- 専用のサブドメインを選択してください。ドメイン委任が完了すると、BrazeはそのサブドメインのすべてのDNSレコードを管理します。Brazeでは、ブランドの親ドメインではなくサブドメインを委任することを推奨しています。親ドメインを委任すると、その可視性とコントロールが失われるためです。親ドメインを使用する場合は、他で使用されていないものを使用してください。
- NS（ネームサーバー）委任が必要です。これにより、BrazeはSPF、DKIM、HTTPSトラッキングなどのサブドメインのDNSレコードを、個別に手動設定することなく管理できます。

{% alert note %}
CNAME委任はサポートされていません。{% multi_lang_include product_feedback_cta.md context="gap" feature="CNAME delegation for verified domains" %}
{% endalert %}

- 最低3レベルの送信サブドメインを計画してください。Brazeは委任されたドメインの下にサブドメインを作成するため（「mail.example.com」など）、送信ドメインは少なくとも3レベルの深さが必要です。例として「e.mail.example.com」があります。
- BrazeがDNSレコードを管理します。委任が完了すると、Brazeは委任されたサブドメインのDNSレコードに責任を持ちます。これらのレコードを自分で変更しないでください。メール送信に問題が発生する可能性があります。
- 認証済みドメインを設定するには、「Edit Domain Settings」権限が必要です。

## ステップ1：認証済みドメインを追加する {#step-1-add-the-verified-domain}

1. **設定** > **認証済みドメイン** > **認証済みドメインを追加**に移動します。
2. サブドメインとルート名を入力します。たとえば、サブドメイン「mail.example.com」をBrazeに委任する場合、ルート名は「example.com」、サブドメインは「mail」です。
3. 選択したサブドメインが他で使用されておらず、競合するDNSレコードがないことを確認します。
4. **追加**を選択して、TXTレコードとNSレコードを受け取ります。

## ステップ2：DNSレコードを設定する {#step-2-configure-dns-records}

認証済みドメインを送信した後、BrazeはDNSプロバイダーに追加する必要のあるDNSレコードを生成します。このステップでは、ITチームまたはDNSチームとの調整が必要になる場合があります。レコードが期限切れになるまでに検証を完了するための猶予は30日間です。期限を過ぎた場合は、再度設定を行う必要があります。

{% alert tip %}
`dig`コマンドを使用して4つのNSレコードすべてが明示的に存在することを確認し、設定完了とみなす前にダッシュボードでドメインが検証されていることを確認してください。DNS検証は30日後に期限切れになります。
{% endalert %}

## ステップ3：ドメインを検証する {#step-3-verify-the-domain}

DNSレコードが伝播された後、Brazeは24時間以内にレコードが存在し、正しく設定されていることを検証します。検証が成功すると、以下のようになります。

- ドメインのステータスが**検証済み**に更新されます。
- Brazeからドメインの準備が完了したことを通知するメールが送信されます。
- **認証済みドメイン**リストにドメインがアクティブとして表示されます。

サブドメインの委任が正常に完了したら、**カスタムドメインを追加**に移動して、送信ドメインやトラッキングドメインなどのメールドメインを作成します。その後、**送信者の検証**ページに移動して設定を完了します。詳細な手順については、[メールセルフサービス]({{site.baseurl}}/user_guide/channels/email/email_setup/setting_up_ips_and_domains/email_self_serve)を参照してください。
