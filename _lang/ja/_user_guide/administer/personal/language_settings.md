# 言語設定 {#language-settings}

> この記事では、Brazeダッシュボードの表示言語を変更する方法について説明します。

## ダッシュボードの言語設定を変更する {#change-your-dashboard-language-settings}

Brazeダッシュボードは[複数の言語](#supported-languages)で利用できます。表示言語はいつでもお好みの言語に変更できます。

1. グローバルヘッダーで、<i class="fa-solid fa-globe" aria-label="言語を選択"></i>を選択します。
2. リストから言語を選択します。

![Brazeダッシュボードの言語として英語が選択されている状態。]({% image_buster /assets/img_archive/language_dashboard.png %}){: style="max-width:40%"}

ダッシュボードの再読み込みに少し時間がかかる場合があります。

### サポートされている言語 {#supported-languages}

以下のサポートされている言語から選択できます。

- ドイツ語 (Deutsch)
- 英語 (English)
- スペイン語 (Espa&ntilde;ol)
- フランス語 (Français)
- 日本語 (日本語)
- 韓国語 (한국어)
- ポルトガル語 (Brasil)
