# 製品ポータル {#product-portal}

> 製品ポータルでは、Brazeの製品ロードマップにアクセスし、アイデアを送信できます。最近リリースされた機能、現在開発中の新機能、構築を検討中のアイデアについてインサイトを得ることができます。ポータルでは、機能の重要度をランク付けして投票したり、フィードバックやリクエストのコメントを残したりできます。

製品ポータルは、**コミュニティ** > **製品ロードマップ**からアクセスできます。

![Brazeダッシュボードのリソースメニュー]({% image_buster /assets/img/portal.png %}){: style="max-width:40%;"}

## ポータルの内容 {#whats-in-the-portal}

| セクション | 説明 |
| --- | --- |
| 最近リリースされた機能 | 四半期ごとにリリースされた新機能 |
| 計画中の機能 | 構築にコミットし、四半期内に開発を開始する機能。<br>これらの機能がリリースされる確定した期限はありません。 |
| 検討中 | 製品チームがフィードバックを求めている、構築を検討中の機能。<br>これらはアイデアであり、この機能を構築する保証はありません。 |
| アイデアの送信 | 10の製品カテゴリーがあり、一般的な改善に投票したり、特定の機能リクエストやアイデアをコメントしたりできます。<br>製品チームがリクエストを受け取り確認しますが、アイデアの送信は構築を保証するものではありません。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="ポータルの内容" }

## 会話に参加する方法 {#how-you-can-join-the-conversation}

| オプション | 説明 |
| --- | --- |
| 機能の重要度をランク付けする | **Nice to Have**、**Important**、または**Critical**を選択して、機能の重要度をランク付けします。 |
| 機能にコメントする | 機能をランク付けした後、フィードバックのコメントを残すことができます。 |
| プロダクトマネージャーの質問に回答する | 機能カードの「How Customers Can Help」を探して、製品チームからの質問に回答してください。 |
| アイデアを送信する | ポータルの**アイデアの送信**ページに移動し、10枚のカードから1つを選択して重要度をランク付けします。コメント欄にアイデアやリクエストを記入してください！<br><br>送信されたアイデアは、製品チームのメンバーが確認します。リクエストのステータスに関する更新情報を提供することはできません。アイデアが「検討中」や「計画中の機能」セクションに追加されていないか、定期的に確認してください。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="会話に参加する方法" }

## Brazeにおける製品フィードバック {#product-feedback-at-braze}

Brazeは、さまざまな情報ソースに基づいて製品ロードマップを構築しています。顧客、市場、事業を展開するテクノロジー環境、製品ビジョンとイノベーション戦略などからデータを取得しています。顧客のインプットとフィードバックは重要なコンポーネントですが、あくまで一つのコンポーネントにすぎません。

優先順位とタイムラインは、チームが入手できる最新情報に基づいて変更される可能性があります（実際に変更されます）。これを踏まえ、製品チームが顧客と市場の意見を把握できるよう、製品フィードバックはタイムリーに送信することを常にお勧めします。

- **製品フィードバックの送信は**、製品チームがフィードバックを確認し検討することを保証します。
- **製品フィードバックの送信は**、対応を保証するものではありません。Brazeは、すべての製品フィードバックに対応することはできませんし、そうすることを望んでもいません。

## 製品フィードバック送信のヒント {#tips-for-submitting-product-feedback}

情報とコンテキストは多ければ多いほど良いです！CampaignsやCanvases、Segmentsへのリンクなど、説明に役立つものをすべて含めてください。製品フィードバックは以下の質問に基づいて構成されています。

- どのような問題を解決しようとしていますか？
- 具体的なユースケースは何ですか？
- 追加のインサイトはありますか？（例：これがあなたやチームにどのようなメリットをもたらすか）
- 現在の回避策はありますか？（これは優先順位付けのプロセスのためではなく、ソリューション発見の作業に役立つ可能性があります）

適切に書かれた製品リクエストの例については、この[製品リクエストの例]({{site.baseurl}}/product_request/)を参照してください。
