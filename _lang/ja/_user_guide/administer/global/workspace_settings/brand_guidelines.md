# ブランド・ガイドライン {#brand-guidelines}

> カスタマイズされたブランドガイドラインで、AIが生成するコピーのスタイルをブランドのボイス、トーン、パーソナリティに合わせて調整できます。

ブランドガイドラインの作成と管理は、**コンテンツ** > **ブランドガイドライン**で行います。

## ブランド・ガイドラインの作成 {#creating-brand-guidelines}

### ステップ1:ブランド・ガイドラインを作成する {#step-1-create-a-brand-guideline}

**ブランド・ガイドライン**ページで、**新規作成**を選択します。このブランド・ガイドラインをワークスペースのデフォルトにしたい場合は、**デフォルトのブランド・ガイドラインとして使用**を選択します。ワークスペースごとにデフォルトは1つ設定できます。

### ステップ2:ブランドパーソナリティを記述する {#step-2-describe-your-brand-personality}

**ブランドパーソナリティ**では、あなたのブランドを独自にしているものについて考えてください。ブランドを定義する特性、価値観、声、アーキタイプを含めてください。このフィールドは10,000文字以内に収めてください。LLMでこのテキストを生成する場合は、出力がフィールドに収まるようプロンプトにその文字数制限を含めてください。

考慮すべき特性をいくつか紹介します。

| 特性 | 定義 | 例 |
|--------------------------|--------------------------------------------------------------------------------------|--------------------------------------------------------------------|
| 評判 | 市場でブランドがどのように認識されたいか。 | 私たちは業界で最も信頼性が高く、顧客重視のブランドとして知られています。 |
| パーソナリティ特性 | ブランドの性格を表す人間的な特徴。 | 私たちのブランドはフレンドリーで親しみやすく、常に前向きです。 |
| 価値観 | ブランドのアクションと意思決定を導くコアバリュー。 | 私たちはサステナビリティ、透明性、コミュニティを大切にしています。 |
| 差別化 | 競合他社との差別化を図るユニークな特質。 | 私たちは、期待以上のパーソナライズされたカスタマーサービスを提供することで際立っています。 |
| ブランドボイス | ブランドが使用するコミュニケーションのトーンとスタイル。 | 私たちの声はカジュアルでありながら情報的で、堅くなりすぎずに明確さを確保しています。 |
| ブランドアーキタイプ | ブランドのペルソナを表すアーキタイプ（ヒーロー、クリエイターなど）。 | 私たちは「探検家」のアーキタイプを体現し、常に新しい挑戦と冒険を求めています。 |
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3 aria-label="ステップ2:ブランドパーソナリティを記述する" }

### ステップ3:避けるべき表現を定義する（オプション） {#step-3-define-language-that-should-be-avoided-optional}

**除外事項**には、ブランドに合わない表現やスタイルを記載します。たとえば、「皮肉」、「ネガティブな態度」、「見下した」トーンを避けたい場合などです。このフィールドは300文字以内に収めてください。

![名前、説明、パーソナリティ、除外事項、トーンを入力するフィールドを含む「ブランド・ガイドラインの作成」ウィンドウ。]({% image_buster /assets/img/guidelines_create.png %})

### ステップ4:ガイドラインをテストする {#step-4-test-your-guidelines}

ガイドラインをテストして、どのように機能するか確認します。**ガイドラインをテスト**を展開して、サンプルコピーを生成し、必要に応じて調整します。

### ステップ5:ガイドラインを保存する {#step-5-save-your-guidelines}

ガイドラインに満足したら、**ブランド・ガイドラインを保存**を選択します。ガイドラインは今後の使用のためにワークスペースに保存されます。

{% alert important %}
コピーの言語に関係なく出力言語を変更できますが、BrazeもOpenAIも翻訳の品質を保証するものではありません。使用する前に、必ず翻訳をテストし確認してください。
{% endalert %}

## ブランド・ガイドラインの管理 {#managing-brand-guidelines}

ブランド・ガイドラインを編集するには、**ブランド・ガイドライン**ページでブランド・ガイドラインを選択します。ブランド・ガイドラインをアーカイブすると、非アクティブになり、メッセージ作成画面で使用できなくなります。再びアクティブにして選択可能にするには、アーカイブされたブランド・ガイドラインをフィルターで検索し、アーカイブを解除します。

## ブランド・ガイドラインの使用 {#using-brand-guidelines}

メッセージを作成する際に、オペレーターを開いて[コピーを生成]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#generate-copy)し、**ブランド・ガイドラインを適用**ドロップダウンでブランド・ガイドラインを選択します。特定のブランド・ガイドラインをデフォルトに指定すると、Brazeはドロップダウンで自動的にそれを選択しますが、別のガイドラインを選択することもできます。
