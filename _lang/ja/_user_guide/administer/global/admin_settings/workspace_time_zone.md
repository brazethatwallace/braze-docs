# ワークスペースのタイムゾーン {#workspace-time-zones}

> ワークスペースのタイムゾーンを使用すると、管理者が個々のワークスペースに対して特定のタイムゾーンを定義できます。これにより、スケジュールされたキャンペーンやキャンバス（ローカルタイムやインテリジェントタイミングを使用しないもの）は、会社全体のタイムゾーンではなく、ワークスペースで指定されたタイムゾーンに基づいて送信されます。

{% alert important %}
メッセージ送信のためのワークスペースのタイムゾーンは段階的にロールアウトされています。ダッシュボードにこれらの設定がまだ表示されない場合があります。
{% endalert %}

デフォルトでは、新しいワークスペースは会社のタイムゾーン設定を継承します。管理者は、ワークスペースのタイムゾーンを使用して、1つ以上のワークスペースに対してこのデフォルト設定を上書きできます。ワークスペースのタイムゾーンが設定されると、そのワークスペース内のスケジュールされたキャンペーンとキャンバスは、送信時刻を決定する際にその新しいタイムゾーンを参照します。

例えば、ワークスペースのタイムゾーンがPSTに設定されている場合、そのワークスペース内のキャンペーンがPST午後3時に送信されるようにスケジュールされていると、実際に配信されるのはPST午後3時となります。たとえ会社の全体的なタイムゾーンが異なっていても（例えばESTの場合、PSTの午後3時はESTの午後6時になります）、これは当てはまります。

## ワークスペースのタイムゾーンを管理する {#manage-workspace-time-zones}

管理者であれば、**設定** > **管理者設定** > **ワークスペースのタイムゾーン**からワークスペースのタイムゾーンにアクセスし管理できます。

ここでは、すべてのワークスペースの一覧、それぞれの設定タイムゾーン、そしてタイムゾーンが最後に編集された日時を確認できます。検索バーを使って、名前で特定のワークスペースを探すことができます。

### タイムゾーンの設定 {#setting-a-time-zone}

{% alert note %}
タイムゾーンの更新が反映されるまで、数分かかる場合があります。
{% endalert %}

{% tabs %}
{% tab 単一ワークスペース %}
1. リストから目的のワークスペースを探します。
2. ワークスペース名の横にある**編集**アイコンを選択します。

![ワークスペース名の横にある「編集」ボタン。]({% image_buster /assets/img/workspaces/time_zones/single_edit_icon.png %})

{: start="3"}
3. ドロップダウンメニューで、そのワークスペースに適用したいタイムゾーンを選択します。
4. **保存**を選択します。

{% endtab %}
{% tab 複数ワークスペース %}

以下の手順で、複数のワークスペースに特定のタイムゾーンを一度に適用できます。

1. 更新したいすべてのワークスペースの横にあるチェックボックスを選択します。
2. **タイムゾーンを編集**を選択します。
3. ドロップダウンメニューから、選択したすべてのワークスペースに適用するタイムゾーンを選択します。

![複数のワークスペースが選択された「ワークスペースのタイムゾーン」ページと「タイムゾーンを編集」ボタン。]({% image_buster /assets/img/workspaces/time_zones/bulk_edit_workspace_time_zone.png %})

{: start="4"}
4. **保存**を選択します。

{% endtab %}
{% endtabs %}

## キャンペーンとキャンバスへの影響 {#impact-on-campaigns-and-canvases}

{% alert important %}
タイムゾーンの変更について、各ワークスペース内の関連チームや関係者に通知し、キャンペーンスケジュールに関する混乱を避けてください。
{% endalert %}

- **ローカルタイムおよびインテリジェントタイミングのキャンペーン:** ユーザーのローカルタイムまたは[インテリジェントタイミング]({{site.baseurl}}/user_guide/messaging/campaigns/schedule_your_campaign/scheduled_delivery#option-3-intelligent-timing)を使用して配信するキャンペーンやキャンバスは、これまでどおり機能し、ワークスペースのタイムゾーンの影響を受けません。
- **スケジュールされたキャンペーンとキャンバス:** ユーザーのローカルタイムやインテリジェントタイミングを使用しないスケジュールされたキャンペーンやキャンバスは、ワークスペースで選択されたタイムゾーンに基づいて送信されるようになります。
- **タイムゾーン変更前にスケジュールされたキャンペーン:** ワークスペースのタイムゾーンを変更する前にキャンペーンやキャンバスをスケジュールしていた場合、Brazeは元の送信時刻を保持し、再スケジュールは行いません。例えば、キャンペーンがPST午後7時に送信されるように設定されていて、ワークスペースのタイムゾーンがESTに変更された場合、キャンペーンは引き続きPST午後7時に送信されます（これはEST午後10時に相当します）。システムは引き続き元の時刻を参照しますが、新しいワークスペースのタイムゾーンを通じて解釈します。

## 日付ベースのオーディエンスフィルターへの影響 {#impact-on-date-based-audience-filters}

ワークスペースのタイムゾーンが更新されると、日付のみの条件を使用するオーディエンスフィルター（特定の時刻が指定されていないもの）は、新しいタイムゾーンの境界に基づいて再評価されます。

「最後にカスタムイベントXを実行した日時が〜以降」などのフィルターでは、Brazeはワークスペースのタイムゾーンを使用してカレンダー日の開始と終了を決定します。この設定を変更すると、その特定の日付の午後11時59分のカットオフポイントがシフトします。

### 例 {#example}

ワークスペースのタイムゾーンを東部時間（EST）から太平洋時間（PST）に更新します。

- **以前のカットオフ時刻:** EST午後11時59分
- **新しいカットオフ時刻:** PST午後11時59分（これはEST翌日午前2時59分に相当します）

この変更後、2026年3月6日PST午後10時（EST 2026年3月7日午前1時）にカスタムイベントを実行したユーザーは、その日付のPSTカレンダー境界内に該当するため、オーディエンスに含まれるようになります。

## パフォーマンスデータへの影響 {#impact-on-performance-data}

ワークスペースのタイムゾーンを更新すると、パフォーマンスデータの集計方法やダッシュボードでの表示方法に影響します。*デイリーアクティブユーザー*（DAU）などのデータの分析はワークスペースのタイムゾーンに依存して24時間の開始と終了を定義するため、この設定を変更するとレポートの時間枠がシフトします。

タイムゾーンを変更すると、過去のデータに変動や「シフト」が見られる場合があります。これは、午前12時から午後11時59分までの時間枠がUTCに対して移動したために発生します。

ワークスペースのタイムゾーンをUTCからPST（UTC-8）に変更する場合の例を考えてみましょう。

- **変更前:** レポートの「1日」はUTC午前12時からUTC午後11時59分までで計測されます。
- **変更後:** レポートの「1日」はPST午前12時からPST午後11時59分までで計測されるようになります。

その結果、1月1日UTC午前1時に発生したイベントは、以前は1月1日の統計としてカウントされていました。PSTへの変更後、同じイベント（12月31日PST午後5時に発生）は、更新されたレポートでは前日の指標に帰属されることになります。
