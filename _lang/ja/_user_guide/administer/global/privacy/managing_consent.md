# 同意の管理 {#manage-consent}

> このリファレンス記事では、Brazeを使用してユーザーからの同意を管理する方法のヒントを紹介します。

Brazeでは、法令の解釈に関する具体的な助言や、同意管理の取り扱いに関するガイダンスを提供することができません。これは、お客様の法務チームによる法律の解釈に依存するためです。しかし、サブスクリプションと同意の管理をサポートするさまざまなツールを提供しています。

お客様のアプローチは、法務チームによる法律の解釈に基づいて求められる厳格さによって決まります。以下に、検討すべきオプションを最も厳しいものから順にいくつか紹介します。

- **チーム:** 真のガバナンスを実現するために、[Brazeのチーム]({{site.baseurl}}/user_guide/administer/global/user_management/teams)を使用します。これには、すべてのユーザープロファイルに同意ステータス、同意日、またはその両方を示すカスタム属性を追加することが含まれます。次に、すべてのキャンペーンとキャンバスを指定のチームに移行し、ダッシュボードのユーザー権限を適宜調整する必要があります。
- **ユーザープロファイル属性:** すべてのユーザープロファイルに同意属性を追加します。この属性は、ユーザーが同意したかどうかを示します。その後、同意したユーザーのセグメント（例: `consent = true`）をすべてのキャンペーンとキャンバスに含めることができます。
- **チャネル固有のサブスクリプショングループ:** 特定のチャネル（プッシュ通知、メールなど）のサブスクリプショングループを操作して、同意を管理します。まず、これらのチャネルからユーザーを配信停止としてマークし、ユーザーが同意した後にのみ購読中としてマークします。

{% alert important %}
法務チームに相談して、組織の同意管理要件へのコンプライアンスに適したアプローチを決定してください。
{% endalert %}
