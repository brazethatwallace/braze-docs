Brazeダッシュボードで、**データ設定** > **データ変換** に移動します。

**変換を作成** を選択して変換に名前を付け、編集エクスペリエンスを選択します。

![編集エクスペリエンスとして「テンプレートを使用」または「ゼロから作成」を選択するオプションが表示された変換の詳細。]({% image_buster /assets/img/data_transformation/data_transformation10.png %}){: style="max-width:80%;"}

**テンプレートを使用** を選択すると、データ変換のユースケースを含むテンプレートライブラリーを参照できます。または、**ゼロから作成** を選択してデフォルトのコードテンプレートを読み込みます。

ゼロから作成する場合は、変換の送信先を選択します。テンプレートライブラリーからコードテンプレートを挿入することもできます。

{% details 送信先の詳細 %}
* **POST: ユーザーを追跡:** ソースプラットフォームからのwebhookを、属性、イベント、購入などのユーザープロファイル更新に変換します。
* **PUT: 複数のカタログアイテムを更新:** ソースプラットフォームからのwebhookをカタログアイテムの更新に変換します。
* **DELETE: 複数のカタログアイテムを削除:** ソースプラットフォームからのwebhookをカタログアイテムの削除に変換します。
* **PATCH: 複数のカタログアイテムを編集:** ソースプラットフォームからのwebhookをカタログアイテムの編集に変換します。
* **POST: API経由でメッセージを即時送信:** ソースプラットフォームからのwebhookを変換し、指定したユーザーに即座にメッセージを送信します。
{% enddetails %}

{% alert note %}
追加のテンプレートや送信先をリクエストしたい場合は、[製品フィードバック]({{site.baseurl}}/user_guide/administrative/access_braze/portal)をお寄せください。
{% endalert %}
