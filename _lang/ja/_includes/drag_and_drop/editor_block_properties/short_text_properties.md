| プロパティ | 説明 |
| --- | --- |
| 必須入力フィールド | フォームを送信する前にフィールドへの入力が必要かどうかを示します。 |
| 最大文字数 | ユーザーが入力できる文字数を制限します（文字列カスタム属性の上限は255文字です）。 |
| プレースホルダーテキスト | ユーザーが入力するまでフィールド内に表示されるテキストです。 |
| 属性 | 送信された値を**名**、**姓**、または**カスタム属性**としてユーザープロファイルに保存します。 |
| カスタム属性名 | 送信された値を受け取る文字列カスタム属性を選択します（**属性**が**カスタム属性**に設定されている場合に使用できます）。 |
| フォントファミリー | 入力テキストの書体です。 |
| フォントウェイト | 入力テキストの太さ（ライト、ノーマル、ボールドなど）です。 |
| フォントサイズ | 入力テキストのサイズです。 |
| 行の高さ | テキスト行間の垂直方向の間隔です。 |
| 文字間隔 | 文字間の水平方向の間隔です。 |
| カラー | フィールドに入力されたテキストの色です。 |
| テキスト配置 | フィールド内の入力テキストの水平方向の配置です。 |
| パディング | ブロック周囲の間隔です。 |
