| プロパティ | 説明 |
| --- | --- |
| 必須入力フィールド | フォームを送信する前にユーザーがオプションを選択する必要があるかどうかを示します。 |
| プレースホルダーテキスト | ユーザーがオプションを選択するまでドロップダウンに表示されるテキストです。 |
| カスタム属性名 | 選択された値を受け取るカスタムユーザー属性を選択します。 |
| オプション合計 | オプションのリストです。各オプションには**オプションラベル**（ユーザーに表示される内容）と**属性値**（保存される内容）があります。 |
| フォントファミリー | ドロップダウンテキストの書体です。 |
| フォントウェイト | テキストの太さ（ライト、ノーマル、ボールドなど）です。 |
| フォントサイズ | テキストのサイズです。 |
| 行の高さ | 垂直方向の行間隔です。 |
| テキストカラー | ドロップダウンテキストの色です。 |
| 文字間隔 | 文字間の水平方向のスペースです。 |
| 配置 | ドロップダウンの水平方向の配置（左揃えまたは中央揃え）です。 |
| パディング | ブロック周囲のスペースです。 |
