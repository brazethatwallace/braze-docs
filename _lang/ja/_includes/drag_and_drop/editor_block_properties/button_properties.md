| プロパティ | 説明 |
| --- | --- |
| ボタンの幅 | ボタンの幅を自動または手動に変更します。 |
| フォントファミリー | テキストのフォントスタイルです。 |
| フォントウェイト | テキストの太さを決定します。 |
| フォントサイズ | テキストのサイズを決定します。 |
| 文字間隔 | 各文字間の距離を変更します。 |
| ボタンの配置 | ボタンを左揃え、中央揃え、または右揃えに移動します。 |
| ボタンのテキスト色 | ボタン上のテキストの色を変更します。 |
| バックグラウンドの色 | ボタンのバックグラウンドの色を変更します。 |
| ボーダースタイル | ボタンのボーダーのスタイルを決定します。 |
| ボーダーの角丸 | 角の丸みを決定します。 |
