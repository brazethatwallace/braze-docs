| プロパティ | 説明 |
| --- | --- |
| カスタム属性名 | フォームが送信されたときに、ユーザーが選択したオプションを保存するカスタムユーザー属性を選択します。 |
| 選択肢の合計 | オプションのリストです。各オプションには**ラベルテキスト**（ユーザーに表示される内容）と**属性値**（保存される内容）があります。最低2つ、最大15個の選択肢を追加できます。 |
| フォントファミリー | ラジオグループテキストの書体です。 |
| フォントウェイト | テキストの太さ（ライト、ノーマル、ボールドなど）です。 |
| フォントサイズ | テキストのサイズです。 |
| 行の高さ | テキスト行間の垂直方向の間隔です。 |
| テキストカラー | オプションラベルテキストの色です。 |
| 文字間隔 | 文字間の水平方向の間隔です。 |
| 配置 | ブロック内の選択肢の水平方向の配置です。 |
| アクセントカラー | ラジオボタンコントロールに使用される色（選択済み状態のインジケーターなど）です。 |
| パディング | ブロック周囲の間隔です。 |
