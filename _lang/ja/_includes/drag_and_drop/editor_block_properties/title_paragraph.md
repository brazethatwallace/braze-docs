| プロパティ | 説明 |
| --- | --- |

| フォントウェイト | テキストの太さを決定します。 |
| フォントサイズ | テキストのサイズを決定します。 |
| 行の高さ | テキストの行間の距離を変更します。 |
| 文字間隔 | 各文字間の距離を変更します。 |
| テキストの配置 | テキストを左揃え、中央揃え、右揃え、または両端揃えに移動します。 |
| テキストの色 | テキストの色を変更します。 |
