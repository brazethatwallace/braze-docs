| プロパティ | 説明 |
| --- | --- |
| 必須入力フィールド | 送信前にユーザーが最低限のオプション数を選択する必要があるかどうかを設定します。 |
| 最小選択数 | フィールドが必須の場合に、ユーザーが選択しなければならないオプションの最小数です。 |
| 最大選択数 | ユーザーが選択できるオプションの最大数です。 |
| カスタム属性名 | 選択済みの値を書き込む配列カスタム属性を選択します。 |
| アクション | 送信時に**Sets items**（配列を置換）するか、**Adds items**（配列に追加）するかを設定します。 |
| 選択肢の合計 | オプションのリストです。各オプションには**Label text**（ユーザーに表示されるテキスト）と**Attribute value**（保存される値）があります。 |
| フォントファミリー | オプションラベルの書体です。 |
| フォントウェイト | オプションラベルテキストの太さ（ライト、ノーマル、ボールドなど）です。 |
| フォントサイズ | オプションラベルテキストのサイズです。 |
| 行の高さ | テキスト行間の垂直方向の間隔です。 |
| テキストカラー | オプションラベルテキストの色です。 |
| 文字間隔 | 文字間の水平方向の間隔です。 |
| 配置 | グループの水平方向の配置（左揃えまたは中央揃え）です。 |
| アクセントカラー | チェックボックスコントロールの色です。 |
| パディング | ブロック周囲の余白です。 |
