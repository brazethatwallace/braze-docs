| プロパティ | 説明 |
| --- | --- |
| 必須入力フィールド | フォームを送信する前にこのフィールドへの入力が必須かどうかを指定します。 |
| 最小文字数 | ユーザーが入力する必要がある最小文字数です。 |
| 最大文字数 | ユーザーが入力できる最大文字数です。 |
| 文字数カウントを非表示 | テキストエリアの下に表示されるリアルタイムの文字数カウンターの表示・非表示を切り替えます。 |
| プレースホルダーテキスト | ユーザーが入力するまで、空のテキストエリア内に表示されるテキストです。 |
| 高さ（テキストの行数） | テキストエリアの高さを行数で指定します。 |
| フォントファミリー | テキストエリアのテキストに使用する書体です。 |
| フォントウェイト | テキストの太さ（ライト、ノーマル、ボールドなど）です。 |
| フォントサイズ | テキストのサイズです。 |
| 行の高さ | テキスト行間の垂直方向の間隔です。 |
| テキストの色 | テキストの色です。 |
| 文字間隔 | 文字間の水平方向の間隔です。 |
