# クレジット使用量ダッシュボード {#credits-usage-dashboard}

> クレジット使用量ダッシュボードは、クレジット使用量に関するセルフサービスのインサイトを提供し、契約割り当てと比較した過去および現在の使用量を包括的に確認できます。これらのインサイトにより、混乱を軽減し、超過料金のリスクを防ぐための調整を行うことができます。

**クレジット使用量**ダッシュボードは2つのセクションに分かれています。
- [クレジット使用量の概要](#credits-usage-overview)
- [チャネルタブ](#credits-features)

ダッシュボードにアクセスするには、**設定** > **請求** > **クレジット使用量**に移動します。

## クレジット使用量の概要 {#credits-usage-overview}

**メッセージクレジット使用量の概要**では、クレジットを使用するすべてのチャネルにわたる使用量の概要を確認できます。クレジット割り当て全体に対するペースを確認したり、有効な契約や契約期間の詳細を確認したりできます。

このページは、クレジット契約を結んでいる場合に表示されます。クレジットを使用するチャネルは、**クレジット使用量**に表示されます。

{% alert note %}
WhatsAppを購入しているもののクレジット契約を結んでいない場合でも、WhatsAppのクレジット消費量は表示されます。これは、レガシーWhatsApp契約がそのように請求されるためです。これはレガシーSMSとは異なり、SMSはクレジット契約を結んでいる場合にのみクレジットを消費します。
{% endalert %}

クレジット使用量の概要データは、**クレジット契約の概要**に表示される契約期間に限定されます。**クレジット期間**の範囲外の日付でフィルターすることはできません。


### 契約期間全体のクレジット使用量 {#credits-usage-over-contract}

**契約期間全体のメッセージクレジット使用量**グラフには、選択した期間の使用量が表示されます。このチャートの粒度は、選択した時間枠によって異なります。チャートメニューのメニューを選択して、エクスポートオプションを表示します。

![契約期間全体のクレジット使用量グラフ。]({% image_buster /assets/img/app_settings/credit_usage_over_contract1.png %})

## 概要タブ {#overview-tab}

**使用量の概要**タブには、貴社に該当するチャネル全体のクレジット使用量が表示されます。たとえば、WhatsAppを利用していない場合、そのタブは表示されません。

## 知っておくべきこと {#things-to-know}

{% alert important %}
**クレジット使用量**ダッシュボードに表示されるデータは契約レベルのものであり、個別のダッシュボードの会社やワークスペースに限定されません。このデータは、ダッシュボード内のすべてのワークスペース、さらに複数のダッシュボードをお持ちの場合はすべてのダッシュボードの使用量を反映します。
{% endalert %}

- 基礎となるデータは日次で提供され、データテーブルは米国東部時間の午前3時、午前9時、午後12時、午後6時に更新されます。**クレジット使用量**ダッシュボードの更新には24時間以上かかる場合があります。
- 新しい契約期間が開始された場合、更新された契約情報およびメッセージクレジット情報が表示されるまで最大24時間かかることがあります。そのデータが読み込まれるまで、ダッシュボードには完全な概要やチャネル使用量の詳細ではなく、**Credit Ratios**タブのみが表示される場合があります。
- Brazeは標準的な四捨五入の方法に従い、数値は最も近い小数第1位に切り上げられます。

### 日付範囲の選択 {#date-range-selection}

**クレジット使用量**ダッシュボードでは、選択した範囲の終了日が結果から除外されます。たとえば、10月1日〜31日を選択した場合、10月31日の使用統計は除外されます。目的の期間の最終日を含めるには、範囲を1日延長してください。たとえば、10月全体を含めるには、10月1日〜11月1日を選択してください。

### サードパーティプロバイダーとの比較 {#comparing-with-third-party-providers}

Brazeのクレジット使用量データをサードパーティプロバイダー（Infobipなど）と比較する場合は、以下の点に留意してください。

- **メッセージセグメントとメッセージ**: BrazeはSMSメッセージをセグメント単位でカウントします。長さなどの理由で複数のセグメントに分割される単一のSMSメッセージは、Brazeでは複数のセグメントとしてカウントされます。詳細については、[SMSおよびRCS課金計算ツール]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/billing_calculator)を参照してください。
- **クレジットベースと非クレジットベースのメッセージ**: ダッシュボードにはクレジットベースのメッセージと非クレジットベースのメッセージの両方が含まれます。サードパーティプロバイダーはクレジットベースのメッセージのみをカウントする場合があり、合計に差異が生じる可能性があります。
- **インバウンドとアウトバウンド**: 同じメッセージタイプを比較していることを確認してください。サードパーティのダッシュボードでは、インバウンドとアウトバウンドの両方のメッセージが合計に含まれる場合がありますが、Brazeでは方向でフィルターできます。
- **日付範囲の整合性**: ダッシュボードは終了日を除外するため、日単位の比較は長い日付範囲よりも正確に一致する場合があります。特定の期間のデータを比較する場合は、比較期間の最終日を含めるためにBrazeの日付範囲を1日延長してください。
