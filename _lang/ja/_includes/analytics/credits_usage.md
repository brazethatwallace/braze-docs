# クレジット使用量ダッシュボード {#credits-usage-dashboard}

> クレジット使用量ダッシュボードは、クレジット使用量に関するセルフサービスのインサイトを提供し、契約割り当てと比較した過去および現在の使用量を包括的に確認できます。これらのインサイトにより、混乱を軽減し、超過料金のリスクを防ぐための調整を行うことができます。

**クレジット使用量**ダッシュボードは2つのセクションに分かれています。
- [クレジット使用量の概要](#credits-usage-overview)
- [チャネルタブ](#credits-features)

ダッシュボードにアクセスするには、**設定** > **請求** > **クレジット使用量**に移動します。

## クレジット使用量の概要 {#credits-usage-overview}

**メッセージクレジット使用量の概要**では、クレジットを使用するすべてのチャネルにわたる使用量の概要を確認できます。全体的なクレジット割り当てに対するペースを確認し、有効な契約と契約期間の詳細を確認できます。

このページは、クレジット契約を利用している場合に表示されます。クレジットを使用するチャネルは**クレジット使用量**に表示されます。

{% alert note %}
WhatsAppを購入したがクレジット契約を利用していない場合でも、WhatsAppのクレジット消費量は表示されます。これは、レガシーWhatsApp契約がそのように請求されるためです。これは、クレジット契約を利用している場合にのみクレジットを消費するレガシーSMSとは異なります。
{% endalert %}

クレジット使用量の概要データは契約期間に限定されており、**クレジット契約の概要**に表示されます。**クレジット期間**の範囲外の日付でフィルタリングすることはできません。


### 契約期間中のクレジット使用量 {#credits-usage-over-contract}

**契約期間中のメッセージクレジット使用量**グラフには、選択した期間の使用量が表示されます。このグラフの粒度は、選択した時間枠によって異なります。グラフメニューのメニューを選択すると、エクスポートオプションが表示されます。

![契約期間中のクレジット使用量グラフ。]({% image_buster /assets/img/app_settings/credit_usage_over_contract1.png %})

## 注意事項 {#things-to-know}

{% alert important %}
**クレジット使用量**ダッシュボードに表示されるデータは契約レベルのものであり、個々のダッシュボード会社やワークスペースに限定されていません。このデータは、ダッシュボード内のすべてのワークスペース、および（複数のダッシュボードがある場合は）すべてのダッシュボードの使用量を反映しています。
{% endalert %}

- 基礎となるデータは日次で提供され、データテーブルは米国東部時間の午前3時、午前9時、午後12時、午後6時に更新されます。**クレジット使用量**ダッシュボードの更新には24時間以上かかる場合があります。
- 新しい契約期間が開始されると、更新された契約およびメッセージクレジット情報が表示されるまで最大24時間かかることがあります。データが読み込まれるまで、ダッシュボードには完全な概要やチャネル使用量の詳細ではなく、**クレジット比率**タブのみが表示される場合があります。
- Brazeは標準的な四捨五入の方法に従い、数値は最も近い小数第1位に切り上げられます。

### 日付範囲の選択 {#date-range-selection}

**クレジット使用量**ダッシュボードでは、選択した範囲の終了日が結果から除外されます。たとえば、10月1日〜31日を選択した場合、10月31日の使用統計は除外されます。希望する期間の最終日を含めるには、範囲を1日延長してください。たとえば、10月全体を含めるには、10月1日〜11月1日を選択します。

### サードパーティプロバイダーとの比較 {#comparing-with-third-party-providers}

Brazeのクレジット使用量データをサードパーティプロバイダー（Infobipなど）と比較する際は、以下の点に留意してください。

- **メッセージセグメントとメッセージ**: BrazeはSMSメッセージをセグメント単位でカウントします。1つのSMSメッセージが複数のセグメントに分割される場合（たとえば、長さが原因で）、Brazeでは複数のセグメントとしてカウントされます。詳細については、[SMSおよびRCS課金計算ツール]({{site.baseurl}}/user_guide/message_building_by_channel/sms_mms_rcs/segments)を参照してください。
- **クレジットベースと非クレジットベースのメッセージ**: ダッシュボードにはクレジットベースと非クレジットベースの両方のメッセージが含まれます。サードパーティプロバイダーはクレジットベースのメッセージのみをカウントする場合があり、合計に差異が生じることがあります。
- **受信と送信**: 同じメッセージタイプを比較していることを確認してください。一部のサードパーティダッシュボードでは受信メッセージと送信メッセージの両方が合計に含まれますが、Brazeでは方向でフィルタリングできます。
- **日付範囲の整合**: ダッシュボードでは終了日が除外されるため、日単位の比較は長い日付範囲よりも正確に一致する場合があります。特定の期間のデータを比較する場合は、比較期間の最終日を含めるためにBrazeの日付範囲を1日延長してください。
