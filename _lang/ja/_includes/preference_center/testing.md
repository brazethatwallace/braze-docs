## ユーザー設定センターのテスト {#testing-preference-centers}

ユーザー設定センターのリンクは、送信時にユーザーごとに生成され、ライブのキャンペーンまたはキャンバス送信に紐づけられます。テスト送信やエディターのプレビューでは、購読の変更を保存することはできません。これは想定された動作です。

### 表示される内容 {#what-youll-see}

- **テスト送信：** ユーザー設定センターのLiquidタグが有効なリンクに解決されない場合があります。ページが読み込まれた場合でも、**設定を保存**ボタンは無効になっており、購読の変更は保存されません。
- **ドラッグ＆ドロップエディターのプレビュータブ：** レイアウトとスタイリングをプレビューできますが、エディターからユーザー設定の保存をテストすることはできません。

### エンドツーエンドのテスト方法 {#how-to-test-end-to-end}

本番送信の前にユーザー設定センターのリンクとボタンが正しく動作することを確認するには、以下の手順を実行してください。

1. ユーザー設定センターのLiquidタグを含むキャンペーンまたはキャンバスのメールステップを作成します。
2. テストユーザーまたは小規模な内部セグメントのみをターゲットに設定します。
3. メッセージを送信し、（**テスト送信**ではなく）実際の受信トレイからメールを開きます。
4. ユーザー設定センターのリンクを選択し、購読グループを更新して、**設定を保存**を選択します。
5. Brazeダッシュボードでユーザーのプロファイルに変更が反映されていることを確認します。

{% if include.section == "api" %}
APIで構築されたユーザー設定センターの代替手段として、[ユーザー設定センターURL生成エンドポイント]({{site.baseurl}}/api/endpoints/preference_center/get_create_url_preference_center)を使用して、テスト送信以外で特定のユーザーの有効なURLを取得できます。
{% endif %}

その他のテスト送信の制限事項については、[テストメッセージの送信]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/sending_test_messages#limitations)を参照してください。

### プレビュー、テスト送信、ライブ送信 {#preview-test-send-and-live-send}

| 方法 | レイアウトのプレビュー | 購読変更の保存 |
| --- | --- | --- |
| ドラッグ＆ドロップエディターの**プレビュー**タブ | 可 | 不可 |
| キャンペーンまたはキャンバスの**テスト送信** | 部分的（メールは届きます） | 不可 |
| テストユーザーまたはセグメントへのライブ送信 | 可 | 可 |
| [ユーザー設定センターURL生成]({{site.baseurl}}/api/endpoints/preference_center/get_create_url_preference_center) API | 可 | 可 |
