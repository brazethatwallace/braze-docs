2025年7月1日より、WhatsAppはメッセージ単位で課金されるようになりました。メッセージ料金は、受信者の電話番号の国コードと送信するメッセージタイプの両方に基づいて決まります。メッセージタイプは、WhatsApp マネージャーで承認申請する[メッセージテンプレート](https://developers.facebook.com/docs/whatsapp/message-templates/guidelines/)によって決定されます。

{% alert note %}
プラットフォーム上のすべてのビジネス主導の会話は、承認済みのテンプレートメッセージから開始する必要があります。
{% endalert %}

{% if include.content == "h2" %}##{% else include.content == "h3" %}###{% endif %} メッセージテンプレートの定義

以下は、WhatsApp マネージャーで承認申請できるメッセージテンプレートです。

| テンプレート | 定義 |
|----------|------------|
| **マーケティングテンプレート** | このテンプレートを使用すると、認知度の向上から販売促進、顧客のリターゲティングまで、幅広い目標を達成できます。例としては、新製品・サービス・機能のお知らせ、ターゲットを絞ったプロモーションやオファー、カート放棄のリマインダーなどがあります。 |
| **ユーティリティテンプレート** | このテンプレートを使用すると、ユーザーのアクションやリクエストに対するフォローアップが可能です。これらのメッセージは通常、ユーザーのアクションによってトリガーされます。例としては、オプトインの確認、注文や配信の管理（配信状況の更新など）、アカウントの更新やアラート（支払いリマインダーなど）、フィードバックアンケートなどがあります。<br><br>2025年7月1日より：<br>• ユーティリティテンプレートは、説得的な意図のない非プロモーション的なものでなければなりません。<br>• ユーティリティテンプレートは、（1）ユーザーに固有のもの、またはユーザーがリクエストしたもの、あるいは（2）ユーザーにとって不可欠または重要なものでなければなりません。 |
| **認証テンプレート** | このテンプレートを使用すると、カスタマージャーニーのさまざまなステップ（アカウント認証、アカウント復旧、整合性チャレンジなど）でユーザーの本人確認を行うことができます。<br><br>認証の会話はケースバイケースでのみサポートされ、Brazeは特定のSLAを保証することはできません。また、BrazeはPIN生成をサポートしていません。 |

{% if include.content == "h2" %}##{% else include.content == "h3" %}###{% endif %} 無料メッセージの種類

WhatsAppメッセージが無料になるいくつかのシナリオを以下に示します。

| メッセージ | 詳細 |
|-------|-------|
| すべてのサービス会話 | _2024年11月1日より_<br><br>ユーザーがブランドにメッセージを送信すると（24時間のカスタマーサービス時間枠が開始されます）、テンプレートを使用しない応答メッセージには課金されません。注：ただし、ブランドがテンプレートを使用してユーザーに応答した場合は、テンプレートタイプに基づいて課金されます。 |
| 24時間のカスタマーサービス時間枠中に送信されたユーティリティテンプレート | _2025年7月1日より_<br><br>エンドユーザーがブランドにメッセージを送信すると、24時間のカスタマーサービス時間枠が作成されます。ブランドがユーティリティテンプレートで返信した場合、無料になります。24時間のカスタマーサービス時間枠外で送信されたユーティリティテンプレート（例：アカウントリマインダーや注文ステータスの更新のためにブランドが事前に送信するユーティリティテンプレート）には引き続き課金されます。 |
| 無料エントリポイント会話 | 無料エントリポイント会話は、次の条件を満たした場合に開始されます。1）ユーザーがClick to WhatsApp広告またはFacebookページのCall-to-Actionボタンを通じてブランドにメッセージを送信し、2）ブランドが24時間以内に応答した場合です。無料エントリポイント会話はブランドが応答した時点で開始され、72時間継続します。72時間の時間枠内では、ブランドはユーザーにメッセージテンプレートを無料で送信できます。ただし、テンプレートを使用しないメッセージは、24時間のカスタマーサービス時間枠が開いている場合にのみ送信できます。 |
| 応答メッセージ | 応答メッセージングにより、ブランドはユーザーのメッセージに対してテンプレートを使用しないメッセージを送信できます。応答メッセージは、ユーザーがWhatsAppでブランドにメッセージを送信した場合など、24時間のカスタマーサービス時間枠が開いているときに送信できます。<br><br>会話を開始するテンプレートメッセージには引き続き課金されますが、その後の応答メッセージは無料になることにご留意ください。 |
