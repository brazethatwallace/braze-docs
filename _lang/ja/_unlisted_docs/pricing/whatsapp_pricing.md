# WhatsApp料金の更新 {#whatsapp-pricing-updates}

## 2025年10月のWhatsApp料金変更の追加情報 {#additional-whatsapp-pricing-changes-in-october-2025}
*最終更新日：2025年9月3日*

### 一部地域での料金変更 {#pricing-changes-in-some-regions}

**10月1日**より、Metaは特定のマーケットで料金を更新します。

- **ユーティリティメッセージおよび認証メッセージ：** アルゼンチン、エジプト、メキシコ、北米において、料金の競争力を維持するため料金が引き下げられます。
- **マーケティングメッセージ：** メキシコにおいて、導入促進と健全なメッセージングエコシステムの育成を継続するため料金が引き下げられます。

| --- | --- |

| アルゼンチン - ユーティリティ                       | -10.04%  |

| エジプト - 認証 - 国際    | -0.58%   |
| エジプト - ユーティリティ                           | -30.43%  |
| メキシコ - マーケティング                        | -30.08%  |
| 北米 - 認証            | -70.39%  |

## 2025年7月のWhatsApp追加料金変更 {#additional-whatsapp-pricing-changes-in-july-2025}
*最終更新日：2025年6月12日*

以前発表された7月の料金更新に加えて、Metaは2025年7月1日に発効するいくつかの追加更新を展開しています。

以前発表された変更の概要は以下のとおりです：
- WhatsAppの料金体系は「会話ごと」のモデルから「メッセージごと」のモデルに移行します。**「メッセージごと」の料金は、現行の「会話ごと」の料金と同じになります。**
- ユーザーのメッセージに応答して送信されるユーティリティテンプレート（つまり、オープンな[カスタマーサービスウィンドウ](https://developers.facebook.com/docs/whatsapp/cloud-api/guides/send-messages#customer-service-windows)内で送信されるもの）は無料になります。

*これらの変更の詳細については、この記事の後半にある3月12日付の以前の投稿をご覧ください。*

7月1日の追加変更（Metaが5月15日に発表）：
- Metaは、代替チャネルと同等の料金設定を確保するための継続的な取り組みの一環として、複数の市場でユーティリティおよび認証の料金を更新しています。
    - ユーティリティおよび認証メッセージングの料金は、インドネシアを除くすべての市場で引き下げられます。インドネシアでは、ユーティリティの料金は引き上げられ、認証の料金は引き下げられます。
- Metaは、ユーザーのエンゲージメントとセンチメントに基づいてユーティリティの定義を見直しており、特定のユースケースをユーティリティカテゴリーに追加または除外しています。Metaの新しい[ユーティリティテンプレートの定義](https://developers.facebook.com/docs/whatsapp/pricing/updates-to-pricing#updates-to-template-category-guidelines)をご覧ください。

ほとんどの顧客にとって、これらの更新は7月1日に自動的に適用されます。

## 2025年7月に予定されているWhatsApp料金変更 {#upcoming-whatsapp-pricing-changes-in-july-2025}

*最終更新日：2025年3月12日（初回掲載日：2024年12月13日）*

WhatsAppは2025年7月1日より、料金体系にさらに2つの変更を加えます。Brazeも同日に料金を更新し、これらの変更を反映します。変更の概要と対応するためのベストプラクティスを以下のセクションにまとめています。

### 変更1：WhatsAppの料金体系が「会話単位」から「メッセージ単位」モデルに移行します。 {#update-1-whatsapp-pricing-will-shift-to-a-per-message-model-instead-of-a-per-conversation-model}

**「メッセージ単位」の料金は、現在の「会話単位」の料金と同じです。**

#### なぜこの変更が行われるのですか？ {#why-are-they-making-this-change}

Metaは、ブランドが投資対効果（ROI）の計算を簡素化できるよう、「メッセージ単位」モデルへの移行を進めています。この変更により、メッセージ単位で料金が設定されている他のチャネルとの直接的なROI比較も容易になります。

#### 現在のWhatsApp利用にどのような影響がありますか？ {#how-will-this-affect-my-current-whatsapp-usage}

- 24時間ウィンドウ内で1つのメッセージテンプレートで送信されている現在の会話には影響がありません。
- **24時間ウィンドウ内で_同じ種類_のメッセージテンプレートを2つ以上送信している現在の会話はコストが増加します。** 例えば、24時間以内にマーケティングテンプレートを2つ送信すると、メッセージテンプレートごとに課金されるため、コストは2倍になります。

| シナリオ例 | 2025年4月以前の料金 | 2025年4月以降の料金 |
| --- | --- | --- |
| ブランドが24時間ウィンドウ内でマーケティングテンプレートメッセージを1つ送信 | マーケティング会話1件分の課金 | マーケティングメッセージ1件分の課金 |
| ブランドが24時間ウィンドウ内でマーケティングテンプレートメッセージを2つ送信 | マーケティング会話1件分の課金 | マーケティングメッセージ2件分の課金 |
| ブランドが24時間ウィンドウ内でユーティリティテンプレートメッセージを1つ送信 | ユーティリティ会話1件分の課金 | ユーティリティメッセージ1件分の課金 |
| ブランドが24時間ウィンドウ内でユーティリティテンプレートメッセージを2つ送信 | ユーティリティ会話1件分の課金 | ユーティリティメッセージ2件分の課金 |
| ブランドが24時間ウィンドウ内でマーケティングテンプレートメッセージ1つとユーティリティテンプレートメッセージ1つを送信 | マーケティング会話1件分とユーティリティ会話1件分の課金 | マーケティングメッセージ1件分とユーティリティメッセージ1件分の課金 |
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3 role="presentation"}

この変更はマーケティング、ユーティリティ、認証テンプレートに適用されます。サービス会話は2024年11月1日以降、無料です。

*注：この変更は当初4月1日、その後5月1日に予定されていましたが、現在は**7月1日**に変更されています。*

### 変更2：24時間カスタマーサービスウィンドウ中に送信されたユーティリティテンプレートが無料になります。 {#update-2-utility-templates-sent-during-a-24-hour-customer-service-window-will-be-free-of-charge}

#### どのように機能しますか？ {#how-does-this-work}

エンドユーザーがブランドにメッセージを送信すると、[24時間カスタマーサービスウィンドウ](https://developers.facebook.com/docs/whatsapp/cloud-api/guides/send-messages#customer-service-windows)が作成されます。ブランドがユーティリティテンプレートで返信した場合、その返信は無料になります。

24時間カスタマーサービスウィンドウ外で送信されたユーティリティテンプレート（例えば、アカウントリマインダーや注文ステータス更新などのためにブランドが主体的に送信するユーティリティテンプレート）は引き続き課金されます。

これらの変更に対応し、WhatsAppマーケティング予算を最大化するために、以下のベストプラクティスをお勧めします：

- 24時間以内に同じ種類のメッセージテンプレートを複数送信すること（ユーザーの応答がない場合）を制限してください。これにより、以前の「会話単位」モデルよりも多く課金されることはありません。これは顧客に質の高い体験を提供し、メッセージ疲れを軽減するためのベストプラクティスでもあります。
- エンドユーザーのメッセージに返信する際は、[レスポンスメッセージング]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#response-messages)を使用してください。レスポンスメッセージングは無料です。

| シナリオ例 | 2025年4月以前の料金 | 2025年4月以降の料金 |
| --- | --- | --- |
| - ブランドがマーケティングテンプレートを送信 <br>- ユーザーが返信 <br>- ブランドがレスポンスメッセージで返信 | マーケティング会話1件分の課金 | マーケティングメッセージ1件分の課金 |
| - ユーザーがブランドにメッセージを送信 <br>- ブランドがレスポンスメッセージで返信 | 無料 <br> _サービス会話として分類_ | 無料 <br> _サービス会話として分類_ |
{: .reset-td-br-1 .reset-td-br-2 .reset-td-br-3 role="presentation"}

これらの変更に対応し、WhatsAppマーケティング予算を最大化するために、以下のベストプラクティスをお勧めします：

- 24時間以内に同じ種類のメッセージテンプレートを複数送信すること（ユーザーの応答がない場合）を制限してください。これにより、以前の「会話単位」モデルよりも多く課金されることを防げます。これは顧客に質の高い体験を提供し、メッセージ疲れを軽減するためのベストプラクティスでもあります。
- エンドユーザーのメッセージに返信する際は、[レスポンスメッセージング]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#response-messages)を使用してください。レスポンスメッセージングは無料です。

*注：この変更は当初4月1日に予定されていましたが、**現在は7月1日**に変更されています。*

## 2024年8月〜11月のWhatsApp料金変更 {#whatsapp-pricing-changes-from-august-2024-november-2024}

*最終更新日：2024年10月29日*

### ユーティリティ会話 {#utility-conversations}

2024年8月1日、Metaはブランドがプラットフォーム上で購入後のカスタマージャーニーをより促進することを奨励するため、ユーティリティ会話の料金を引き下げました。このコスト削減は、メッセージクレジットまたはWhatsAppクレジットのエンタイトルメントに同等の割合で反映されています。この更新はMetaと同日（8月1日）に発効しました。

#### ユーティリティ会話とは？ {#what-are-utility-conversations}

ユーティリティ会話は、特定の顧客のアクションやリクエストに対するフォローアップを可能にします。例としては、オプトイン確認、注文の更新と確認、アカウントの更新やアラート（支払いリマインダーなど）、フィードバックアンケートなどがあります。

#### この更新をどのように活用できますか？ {#how-can-you-benefit-from-this-update}

WhatsAppをトランザクションメッセージングに活用することをお勧めします。また、ブランドにとって合理的であれば（各チャネルでのオーディエンスのリーチとエンゲージメントに基づいて）、トランザクションSMSメッセージの一部をWhatsAppに移行することも検討できます。たとえば、WhatsAppが広く利用されているアジア、ラテンアメリカ、ヨーロッパの顧客にとっては、これが良い選択肢となる可能性があります。

### マーケティング会話 {#marketing-conversations}

2024年10月1日、Metaは現在の需要を反映して、英国のマーケティング会話の料金を25%引き下げました。このコスト削減は、メッセージクレジットまたはWhatsAppクレジットのエンタイトルメントに同等の割合で反映されています。この更新はMetaと同日（10月1日）に発効しました。

#### マーケティング会話とは？ {#what-are-marketing-conversations}

マーケティング会話は、認知度の向上から売上促進、顧客のリターゲティングまで、幅広い目標の達成を可能にします。例としては、新製品の発表、ターゲットプロモーション/オファー、カート放棄キャンペーンなどがあります。

### サービス会話 {#service-conversations}

2024年11月1日より、すべてのサービス会話が無料となります。サービス会話はメッセージクレジットまたはWhatsAppクレジットのエンタイトルメントを消費しなくなります。この変更はMetaと同日（11月1日）に発効します。

#### サービス会話とは？ {#what-are-service-conversations}

サービス会話は、顧客からの問い合わせに対応することを可能にします。これには、エンドユーザーが会話を開始し、ブランドがテンプレートメッセージではなく[レスポンスメッセージ]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#response-messages)で返信する会話が含まれます。

#### この更新をどのように活用できますか？

以前は「サービス」として課金されていた一部の会話が無料になります。これには以下が含まれます：

- エンドユーザーが認識されないメッセージを送信し、ブランドが[レスポンスメッセージング]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#response-messages)を使用して汎用メッセージで返信する[未認識レスポンスキャンペーン]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#response-messages)。たとえば、エンドユーザーがキーワードなしでメッセージを送信し、ブランドが「お客様のメッセージを認識できません。カスタマーサポートまでお問い合わせください。」と返信する場合です。
- エンドユーザーがプロモーションされたキーワードをブランドに送信し、ブランドが[レスポンスメッセージ]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#response-messages)を使用して返信する会話。一般的な例としては、WhatsAppメッセージングへのオプトインや特定のプロモーションへの参加があります。
