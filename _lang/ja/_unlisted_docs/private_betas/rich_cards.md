# RCS メッセージの作成 {#creating-an-rcs-message}

> RCS キャンペーンは、顧客に直接リーチし、プログラムで会話するのに最適です。Liquidやその他のダイナミックコンテンツを使用して、ユーザーとのパーソナルな体験を作り出し、ブランドとの控えめなユーザー体験を促進・向上させる環境を構築できます。

## RCS メッセージの作成

### ステップ1:メッセージの作成場所を選択する {#step-1-choose-where-to-build-your-message}

メッセージをキャンペーンとキャンバスのどちらで送信するか迷っていますか？キャンペーンはシンプルな単発のメッセージングに適しており、キャンバスはマルチステップのユーザージャーニーに適しています。

{% tabs %}
{% tab キャンペーン %}
1. **メッセージング** > **キャンペーン** に移動し、**キャンペーンを作成** を選択します。
2. **SMS/MMS/RCS** を選択します。複数のチャネルをターゲットにするキャンペーンの場合は、**マルチチャネル** を選択します。
3. キャンペーンにわかりやすく意味のある名前を付けます。
4. 必要に応じて、[チーム]({{site.baseurl}}/user_guide/administer/global/user_management/teams)と[タグ]({{site.baseurl}}/user_guide/administer/global/workspace_settings/tags)を追加します。
   * タグを使用すると、キャンペーンの検索やレポートの作成が容易になります。たとえば、[レポートビルダー]({{site.baseurl}}/user_guide/analytics/reports/report_builder)を使用する場合、特定のタグでフィルタリングできます。

{: start="5"}
5. キャンペーンに必要な数のバリアントを追加して名前を付けます。追加した各バリアントに対して、異なるプラットフォーム、メッセージタイプ、レイアウトを選択できます。このトピックの詳細については、[多変量テストとABテスト]({{site.baseurl}}/user_guide/messaging/ab_testing)を参照してください。
- **SMS と RCS のバリアントテスト**: Brazeでは、1つのキャンペーン内に SMS と RCS の両方のバリアントを含めることができ、それぞれのパフォーマンスを比較できます。SMS と RCS のバリアントは、メッセージ作成の最初のステップで追加できます。

{: start="6"}
6. RCS に対応した[購読グループ]({{site.baseurl}}/sms_rcs_subscription_groups)を選択します。購読グループを選択すると、Brazeは自動的にセグメンテーションフィルターを追加し、購読しているユーザーのみがキャンペーンを受信するようにします。その購読グループに属するロングコードとショートコードのみが、ターゲットユーザーへの SMS 送信に使用されます。
- **SMS フォールバック**: Brazeでは、RCS 送信者を含むすべての購読グループに、フォールバック用の SMS コードを少なくとも1つ含めることを強く推奨します。これは、RCS メッセージの配信に失敗した場合の到達性にとって重要です。失敗の理由として、ユーザーデバイスの非互換性や、特定の国・地域でのキャリアカバレッジの不完全さなどが挙げられます。SMS フォールバックを有効にすることで、メッセージは確実にユーザーに届き、接点を逃すことがなくなります。

{: start="7"}
7. SMS と RCS のどちらかを選択します。RCS メッセージを作成する前に、送信するチャネルを選択してください。一般的には、RCS は SMS に比べてユーザーエンゲージメントの面で大きなメリットがあるため、可能な限り RCS の使用を推奨します。ただし、最大限の柔軟性とコントロールを確保するために、SMS での送信オプションも常に提供しています。

![RCS または SMS/MMS メッセージタイプを選択するオプション。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_message_type.png %}){: style="max-width:65%;"}

{% alert tip %}
キャンペーン内のすべてのメッセージが類似または同じ内容になる場合は、追加のバリアントを追加する前にメッセージを作成してください。その後、**バリアントを追加** ドロップダウンから **バリアントからコピー** を選択できます。
{% endalert %}

{% endtab %}
{% tab キャンバス %}
1. キャンバスコンポーザーを使用して[キャンバスを作成]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas)します。
2. キャンバスの設定が完了したら、キャンバスビルダーで **SMS/MMS/RCS** メッセージステップを追加します。
3. ステップにわかりやすく意味のある名前を付けます。
4. RCS に対応した[購読グループ]({{site.baseurl}}/sms_rcs_subscription_groups)を選択します。購読グループを選択すると、Brazeは自動的にセグメンテーションフィルターを追加し、購読しているユーザーのみがキャンペーンを受信するようにします。その購読グループに属するロングコードとショートコードのみが、ターゲットユーザーへの送信に使用されます。

{: start="5"}
5. SMS と RCS のどちらかを選択します。RCS メッセージを作成する前に、送信するチャネルを選択してください。一般的には、RCS は SMS に比べてユーザーエンゲージメントの面で大きなメリットがあるため、可能な限り RCS の使用を推奨します。ただし、最大限の柔軟性とコントロールを確保するために、SMS での送信オプションも常に提供しています。

### ステップ2:RCS メッセージタイプを選択する {#step-2-select-your-rcs-message-type}

キャンペーンおよびキャンバスの作成時に、3つの RCS メッセージタイプ（テキスト、メディア、リッチカード）から選択して、目標に最適なメッセージを構成できます。

![テキスト、メディア、またはカードのメッセージタイプから選択するオプション。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_text_media.png %}){: style="max-width:65%;"}

{% tabs local %}
{% tab テキスト %}
その名の通り、RCS テキストメッセージはテキストをメディアとして重視しています。160文字以内で入力すると、テキストのみ（「基本」）メッセージとして課金されます。160文字を超えるか、リッチ要素を使用した場合、リッチ（「シングル」）RCS メッセージとして課金されます（文字数上限は3072文字に増加します）。

#### 機能 {#features}

- テキストメッセージタイプには、すべての SMS 機能が含まれます。URL クリックトラッキングには、ユーザーレベルのレポート粒度を提供する高度なトラッキングのみが利用可能です。
- さらに、ランディングページへのアクセスや注文の完了など、高エンゲージメントのユーザーアクションを促進する**提案返信**と**提案アクション**ボタンを含めるオプションが利用できます。
    - **提案返信**は、ユーザーがクリックしてテキスト入力欄に事前入力できる提案応答を含むボタンです。制約された選択肢を提供することで、応答を考える手間を省きます。
    - **提案アクション**は、ユーザーのデバイスでアクションを開始するボタンです。通常、1〜2語の説明文と視覚的なアイコンで構成され、ボタンの機能をユーザーが理解するのに役立ちます。Brazeは現在、OpenURL 提案アクションをサポートしています。これは URL と同様に機能し、ボタンを選択したユーザーはWebページまたはその他の URL で特定される場所にリダイレクトされます。

![トレンドファッションスタイルを宣伝する RCS メッセージの3つの提案アクションのGIF：「フェアリーテイルロイヤリティ」「エッジーアカデミア」「他のスタイルを見せて」。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_suggested_actions.gif %}){: style="max-width:70%;"}

#### 考慮事項 {#considerations}

- テキストの文字数制限について、テキストのみ（基本）の RCS メッセージでは最大160文字、リッチ（シングル）の RCS メッセージでは最大3072文字まで入力できます。
- ボタンの制限について、1メッセージにつき最大5つのボタンを追加できます。これらのボタンには、提案アクションまたは提案返信を設定できます。
- 長いテキストブロックやボタンが多すぎるとユーザーにストレスを与える可能性があるため、可能な限りシンプルにすることを推奨します。
- 場合によっては、長いテキストのみのメッセージを SMS ではなく RCS で送信する方がコスト効率が良いことがあります。これは、長い SMS メッセージが複数のセグメントに分割され、それぞれが課金対象となるのに対し、RCS メッセージはメッセージ単位で課金されるためです。詳細やガイダンスについては、Brazeアカウントマネージャーにお問い合わせください。
{% endtab %}

{% tab メディア %}
RCS メディアメッセージでは、SMS では不可能な魅力的なメディア形式を使用できます。画像、動画、ドキュメントファイルなどがあります。これらのメディアオプションは、オーディエンスとのエンゲージメントをさらに深め、まったく新しいユースケースを実現するために用意されています。現時点では、[メディアライブラリ]({{site.baseurl}}/user_guide/messaging/design_and_edit/media_library/image_specifications)を通じた画像のアップロードのみがサポートされています。

#### 機能

- メディアメッセージタイプは、テキスト、提案返信、提案アクションなど、テキストメッセージタイプで利用可能なすべての機能をサポートしています。
- JPEG および PNG ファイル形式を含む画像ファイルをサポートしています。画像ファイルはメディアライブラリからアップロードできます。
- MP4、MPEG、MV4 ファイル形式を含む動画ファイルをサポートしています。動画ファイルはメッセージ作成画面で直接 URL を入力して追加できます。
- PDF 形式のドキュメントファイルをサポートしています。ドキュメントファイルはメッセージ作成画面で直接 URL を入力して追加できます。

![メディアファイルをアップロードするオプションが表示された RCS コンポーザー。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_media_type.png %})

#### ファイル仕様 {#file-specifications}

| ファイルタイプ | 仕様 |
| --- | --- |
| すべて | - ファイルサイズは100 MBまで <br><br>- ファイル URL は最大2048文字 |
| 画像ファイル | サポートされるファイル形式：JPG、JPEG、GIF |
| 動画ファイル | サポートされるファイル形式：H263、M4V、MP4、MPEG-4、MPEG、WEBM |
| ドキュメントファイル | サポートされるファイル形式：PDF |
{: .reset-td-br-1 .reset-td-br-2 role="presentation" }

#### 考慮事項

RCS メッセージの受信体験は、送信先の国でのキャリアカバレッジ、モバイルデバイスのハードウェア、モバイルデバイスのオペレーティングシステムなど、さまざまな要因によって若干異なる場合があります。

一般的に、RCS は Android デバイスとより自然に統合されます（この手法は主に Google が実装し、ピアツーピアの RCS メッセージングは Android コミュニティで広く普及しています）。デバイスによって、体験のレンダリング速度や品質が異なる場合があります。
{% endtab %}

{% tab リッチカード %}

{% alert important %}
リッチカードは早期アクセス段階です。この早期アクセスへの参加にご興味がある場合は、Brazeカスタマーサクセスマネージャーにお問い合わせください。
{% endalert %}

リッチカードは、メディア、テキスト、ボタンを1つのメッセージに組み合わせ、顧客にとってより直感的で魅力的な体験を作成します。リッチカードには、テキストとメディアの2つのサブタイプを作成できます。

{% subtabs %}
{% subtab テキスト %}
テキストリッチカードは、テキストに焦点を当てた簡潔なメッセージです。以下の要素を含める必要があります：

- **タイトル:** 最大200文字。Liquidでパーソナライズできます。
- **説明:** 最大2,000文字。Liquidでパーソナライズできます。
- **ボタン:** 少なくとも1つのボタンが必要です。**提案返信**または **Open web URL** アクションで最大4つのボタンを追加できます。

{% endsubtab %}
{% subtab メディア %}

メディアリッチカードは、画像または動画を含むビジュアルメッセージです。以下の要素を含める必要があります：

- **メディア:** 画像、GIF、または動画。
    - カスタム動画サムネイルは早期アクセスではサポートされていません。早期アクセスでは、画像ファイルと動画ファイルの両方で縦長レイアウトと高いメディア高さのみがサポートされています。
- **ボタン:** 少なくとも1つのボタンが必要です。**提案返信**または **Open web URL** アクションで最大4つのボタンを追加できます。

{% endsubtab %}
{% endsubtabs %}

### 機能
- **カードボタン**と**サジェスチョン:** リッチカードの下部（ボタン）またはメッセージ画面の下部（サジェスチョン）に、最大4つのボタンと5つのサジェスチョン（各最大25文字）を追加できます。ユーザーはこれらのクリック・タップオプションを選択して、特定の応答を送信したり、特定のアクションを実行したりできます。
- **パーソナライゼーション:** Liquidを使用して、タイトル、説明、メディア、ボタンなど、リッチカードのすべての要素をパーソナライズできます。
- **課金:** リッチカードは、1つのリッチ（「シングル」）RCS メッセージとして課金されます。
- **URL に関するガイダンス:** タイトルや説明にプレーンテキストとして入力された URL はクリックできません。ユーザーをWebサイトに誘導するには、**OpenURL ボタン**を使用する必要があります。

![メディアまたはテキストのリッチカードを選択するオプションが表示されたパネル。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_media_text.png %}){: style="max-width:65%;"}

{% endtab %}
{% endtabs %}

### ステップ3:RCS メッセージを作成する {#step-3-compose-your-rcs-message}

必要に応じて、言語やパーソナライゼーション（[Liquid]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid)、[Connected Content]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content)、絵文字）を使用してメッセージを作成します。超過料金が発生する可能性を減らすため、メッセージのコピー制限に従ってください。

{% alert important %}
先に進む前に、[RCS メッセージ制限に関するガイドライン](#step-2-select-your-rcs-message-type)をお読みください。RCS メッセージは[メッセージ単位で課金される]({{site.baseurl}}/sms_rcs_billing_calculators)ため、各タイプの RCS メッセージに含められる内容のニュアンスを理解しておくことが大切です。
{% endalert %}

### ステップ4:メッセージをプレビューしてテストする {#step-4-preview-and-test-your-message}

Brazeでは、送信前にメッセージのプレビューとテストを常に推奨しています。**テスト** タブに移動して、コンテンツテストグループまたは個々のユーザーにテスト RCS を送信するか、Braze内で直接ユーザーとしてメッセージをプレビューします。

### ステップ5:キャンペーンまたはキャンバスの残りの部分を構築する {#step-5-build-the-remainder-of-your-campaign-or-canvas}

次に、キャンペーンまたはキャンバスの残りの部分を構築します。RCS メッセージを構築するためのツールの最適な使用方法の詳細については、以下のセクションを参照してください。

#### ステップ5.1:配信スケジュールまたはトリガーを選択する {#step-51-choose-delivery-schedule-or-trigger}

RCS メッセージは、スケジュールされた時間、アクション、または API トリガーに基づいて配信できます。詳細については、[キャンペーンのスケジュール]({{site.baseurl}}/user_guide/messaging/campaigns/schedule_your_campaign)を参照してください。

アクションベースの配信の場合、キャンペーンの期間とサイレント時間を設定することもできます。

ユーザーがキャンペーンを再度受信できるようにしたり、フリークエンシーキャップルールを有効にしたりするなど、配信コントロールを指定します。

#### ステップ5.2:ターゲットユーザーを選択する {#step-52-choose-users-to-target}

セグメントやフィルターを選択してオーディエンスを絞り込み、ユーザーをターゲティングします。購読グループはすでに選択されているはずで、これによりユーザーはコミュニケーションのレベルやカテゴリーで絞り込まれます。

{% multi_lang_include audience/target_audiences.md %}

次に、セグメントからより大きなオーディエンスを選択し、オプションの[フィルター]({{site.baseurl}}/user_guide/audience/segments/segmentation_filters)でさらに絞り込みます。おおよそのセグメント集団が現在どのように見えるかのプレビューが自動的に表示されます。正確なセグメントメンバーシップは、メッセージの送信直前に常に計算されることにご留意ください。

{% alert tip %}
SMS および RCS のインタラクションに基づいてユーザーをターゲティングする RCS リターゲティングにご興味がありますか？[リターゲティング]({{site.baseurl}}/sms_mms_rcs_user_retargeting)を参照してください。
{% endalert %}

#### ステップ5.3:コンバージョンイベントを選択する {#step-53-choose-conversion-events}

Brazeでは、キャンペーンを受信した後にユーザーが特定のアクション（コンバージョンイベント）を実行する頻度をトラッキングできます。ユーザーが指定されたアクションを実行した場合にコンバージョンがカウントされる最大30日間のウィンドウを設定できます。

コンバージョンイベントは、キャンペーンの成功を測定するのに役立ちます。例：
- ジオターゲティングを使用して、ユーザーの購入を最終目標とする RCS メッセージをトリガーする場合、コンバージョンイベントを**購入**に設定します。
- ユーザーをアプリに誘導しようとしている場合、コンバージョンイベントを**セッション開始**に設定します。

特定のユースケースに基づいて、カスタムコンバージョンイベントを設定することもできます。キャンペーンの成功を真に測定する方法を工夫してください。

### ステップ6:確認してデプロイする {#step-6-review-and-deploy}

キャンペーンまたはキャンバスの構築が完了したら、詳細を確認し、テストしてから送信してください！

次に、[SMS、MMS、RCS のレポーティング]({{site.baseurl}}/sms_mms_rcs_reporting)を参照して、RCS キャンペーンの結果にアクセスする方法を確認してください。

## 分析とレポート {#analytics-and-reporting}

キャンペーンまたはキャンバスの分析には、以下が含まれます。

- ボタンクリック、おすすめの返信やアクションなど、リッチカードとのすべてのインタラクションを含む「_合計クリック数_」統計。
- これらのインタラクションの詳細なビューを提供する内訳テーブル。

{% alert note %}
早期アクセスには、ユーザーレベルのクリックトラッキングは含まれていません。_合計クリック数_は、ボタンがクリックされるたびに増加します。例えば、ユーザーが同じボタンを3回クリックした場合、クリック数は3つ増加します。
{% endalert %}

## ヒント {#tips}

### Liquid を使用したメッセージのパーソナライゼーション {#using-liquid-for-message-personalization}

Liquid を使用する場合は、選択したパーソナライゼーションにデフォルト値を含めるようにしてください。受信者のユーザープロファイルが不完全な場合に、名前や文章の代わりに空白のプレースホルダー`Hi, !`が表示されることを防げます。

### AI コピーの生成 {#generating-ai-copy}

魅力的なコピーの作成にお困りですか？[AI コピーライティングアシスタント]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#generate-copy)をお試しください。商品名や説明を入力すると、AIがメッセージングで使用できる人間らしいマーケティングコピーを生成します。

![AI コピーライティングアシスタントを開くアイコンが表示されたメッセージ作成画面。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_ai_copywriter.png %}){: style="max-width:70%;"}
