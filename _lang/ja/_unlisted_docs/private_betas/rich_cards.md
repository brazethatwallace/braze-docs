# RCS メッセージの作成 {#creating-an-rcs-message}

> RCS Campaignsは、顧客に直接リーチし、プログラムで会話するのに最適です。Liquidやその他のダイナミックコンテンツを使用して、ユーザーとのパーソナルな体験を作り出し、ブランドとの控えめなユーザー体験を促進・向上させる環境を構築できます。

## RCS メッセージの作成

### ステップ 1:メッセージの作成場所を選択する {#step-1-choose-where-to-build-your-message}

メッセージをCampaignで送信するか、Canvasで送信するか迷っていますか？Campaignsは単一のシンプルなメッセージングに適しており、Canvasesは複数ステップのユーザージャーニーに適しています。

{% tabs %}
{% tab Campaign %}
1. **メッセージング** > **Campaigns**に移動し、**キャンペーンを作成**を選択します。
2. **SMS/MMS/RCS**を選択するか、複数チャネルをターゲットとするCampaignsの場合は**マルチチャネル**を選択します。
3. Campaignにわかりやすく意味のある名前を付けます。
4. 必要に応じて[チーム]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/teams)と[タグ]({{site.baseurl}}/user_guide/administrative/app_settings/tags)を追加します。
   * タグを使うと、Campaignsの検索やレポートの作成が容易になります。たとえば、[レポートビルダー]({{site.baseurl}}/user_guide/analytics/reporting/report_builder)を使用する際に、特定のタグでフィルタリングできます。

{: start="5"}
5. Campaignに必要な数のバリアントを追加して名前を付けます。追加した各バリアントに対して、異なるプラットフォーム、メッセージタイプ、レイアウトを選択できます。このトピックの詳細については、[多変量テストとABテスト]({{site.baseurl}}/user_guide/engagement_tools/testing/multivariant_testing)を参照してください。
- **SMSとRCSのバリアントテスト**:Brazeでは、単一のCampaign内にSMSとRCSの両方のバリアントを含めることができ、それぞれのパフォーマンスを比較できます。メッセージ作成の最初のステップで、SMSとRCSのバリアントを追加できます。

{: start="6"}
6. RCS対応の[サブスクリプショングループ]({{site.baseurl}}/sms_rcs_subscription_groups)を選択します。サブスクリプショングループを選択すると、Brazeは自動的にセグメンテーションフィルターを追加し、購読中のユーザーのみがCampaignを受信するようにします。そのサブスクリプショングループに属するロングコードとショートコードのみが、ターゲットユーザーへのSMS送信に使用されます。
- **SMSフォールバック**:Brazeは、RCS送信者を含むすべてのサブスクリプショングループに、フォールバック用のSMSコードを少なくとも1つ含めることを強く推奨します。これは、RCSメッセージの配信に失敗した場合の到達性にとって重要です。失敗の理由としては、ユーザーのデバイスの非互換性や、特定の国や地域でのキャリアカバレッジの不完全さなどが考えられます。SMSフォールバックを有効にすることで、メッセージは引き続きユーザーに配信され、ユーザーとつながる機会を逃すことがなくなります。

{: start="7"}
7. SMSとRCSのどちらかを選択します。RCSメッセージを作成する前に、送信するチャネルを選択します。一般的に、RCSにはSMSよりも大きなユーザーエンゲージメントのメリットがあるため、可能な限りRCSの使用を推奨します。ただし、最大限の柔軟性とコントロールを確保するために、SMSでの送信オプションも常に提供しています。

![RCSまたはSMS/MMSメッセージタイプを選択するオプション。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_message_type.png %}){: style="max-width:65%;"}

{% alert tip %}
Campaign内のすべてのメッセージが類似している、または同じコンテンツを持つ場合は、追加のバリアントを追加する前にメッセージを作成してください。その後、**バリアントを追加**ドロップダウンから**バリアントからコピー**を選択できます。
{% endalert %}

{% endtab %}
{% tab Canvas %}
1. Canvasコンポーザーを使用して[Canvasを作成]({{site.baseurl}}/user_guide/engagement_tools/canvas/create_a_canvas/create_a_canvas)します。
2. Canvasの設定が完了したら、Canvasビルダーで**SMS/MMS/RCS**メッセージステップを追加します。
3. ステップにわかりやすく意味のある名前を付けます。
4. RCS対応の[サブスクリプショングループ]({{site.baseurl}}/sms_rcs_subscription_groups)を選択します。サブスクリプショングループを選択すると、Brazeは自動的にセグメンテーションフィルターを追加し、購読中のユーザーのみがCampaignを受信するようにします。そのサブスクリプショングループに属するロングコードとショートコードのみが、ターゲットユーザーへの送信に使用されます。

{: start="5"}
5. SMSとRCSのどちらかを選択します。RCSメッセージを作成する前に、送信するチャネルを選択します。一般的に、RCSにはSMSよりも大きなユーザーエンゲージメントのメリットがあるため、可能な限りRCSの使用を推奨します。ただし、最大限の柔軟性とコントロールを確保するために、SMSでの送信オプションも常に提供しています。

### ステップ 2:RCS メッセージタイプを選択する {#step-2-select-your-rcs-message-type}

CampaignおよびCanvasの作成時に、3つのRCSメッセージタイプ（テキスト、メディア、リッチカード）から選択して、目標に最適なメッセージを設定します。

![テキスト、メディア、またはカードメッセージタイプを選択するオプション。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_text_media.png %}){: style="max-width:65%;"}

{% tabs local %}
{% tab テキスト %}
名前の通り、RCSテキストメッセージはテキストを媒体としたメッセージです。160文字以内で入力した場合、RCSメッセージはテキストのみ（「ベーシック」）メッセージとして課金されます。160文字を超えるか、リッチ要素を使用した場合、メッセージはリッチ（「シングル」）RCSメッセージとして課金されます（文字数の上限は3072文字に増加します）。

#### 機能 {#features}

- テキストメッセージタイプには、すべてのSMS機能が含まれます。URLクリックトラッキングには高度なトラッキングのみが利用可能で、ユーザーレベルのレポート粒度を提供します。
- さらに、ランディングページへのアクセスや注文の実行など、高エンゲージメントのユーザーアクションを促進する魅力的な**候補返信**と**候補アクション**ボタンを含めるオプションが追加されました。
    - **候補返信**は、ユーザーがクリックしてテキスト入力に事前入力できる候補応答を含むボタンです。制約された選択肢のセットを提供することで、応答を考える手間を省きます。
    - **候補アクション**は、ユーザーのデバイス上でアクションを開始するボタンです。通常、1〜2つの説明的な単語と、ボタンの機能をユーザーが理解するのに役立つビジュアルアイコンで構成されます。Brazeは現在、OpenURL候補アクションをサポートしています。これはURLと同様に機能し、ボタンを選択したユーザーはWebページまたはその他のURLで識別される場所にリダイレクトされます。

![トレンドファッションスタイルを宣伝するRCSメッセージの3つの候補アクションのGIF：「Fairytale royalty」、「Edgy academia」、「Show me your other styles」。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_suggested_actions.gif %}){: style="max-width:70%;"}

#### 考慮事項 {#considerations}

- テキストの文字数制限について、テキストのみ（ベーシック）RCSメッセージでは最大160文字、リッチ（シングル）RCSメッセージでは最大3072文字まで入力できます。
- ボタンの制限について、1メッセージあたり最大5つのボタンを追加できます。これらのボタンは、候補アクションまたは候補返信のいずれかにできます。
- 長いテキストブロックやボタンが多すぎると、ユーザーのフラストレーションにつながる可能性があるため、可能な限りシンプルさを重視することを推奨します。
- 場合によっては、SMSよりもRCSで長いテキストのみのメッセージを送信する方がコスト効率が良いことがあります。これは、長いSMSメッセージは複数のセグメントに分割され、それぞれが課金対象となるのに対し、RCSメッセージはメッセージ単位で課金されるためです。詳細とガイダンスについては、Brazeアカウントマネージャーにお問い合わせください。
{% endtab %}

{% tab メディア %}
RCSメディアメッセージでは、SMSでは不可能な魅力的なメディア形式を使用できます。これには、画像、動画、ドキュメントファイルが含まれます。これらのメディアオプションは、オーディエンスとのエンゲージメントをさらに深め、まったく新しいユースケースを可能にするために存在します。現時点では、[メディアライブラリ]({{site.baseurl}}/user_guide/engagement_tools/templates_and_media/media_library)を通じた画像のアップロードのみがサポートされています。

#### 機能

- メディアメッセージタイプは、テキストメッセージタイプで利用可能なすべての機能（テキスト、候補返信、候補アクションを含む）をサポートしています。
- JPEGおよびPNGファイル形式を含む画像ファイルをサポートしています。画像ファイルはメディアライブラリからのアップロードで利用できます。
- MP4、MPEG、MV4ファイル形式を含む動画ファイルをサポートしています。動画ファイルはメッセージ作成画面でURLを直接入力して追加できます。
- PDF形式のドキュメントファイルをサポートしています。ドキュメントファイルはメッセージ作成画面でURLを直接入力して追加できます。

![メディアファイルをアップロードするオプション付きのRCSコンポーザー。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_media_type.png %})

#### ファイル仕様 {#file-specifications}

| ファイルタイプ | 仕様 |
| --- | --- |
| すべて | - ファイルサイズは100 MBまで <br><br>- ファイルURLは最大2048文字 |
| 画像ファイル | サポートされるファイル形式：JPG、JPEG、GIF |
| 動画ファイル | サポートされるファイル形式：H263、M4V、MP4、MPEG-4、MPEG、WEBM |
| ドキュメントファイル | サポートされるファイル形式：PDF |
{: .reset-td-br-1 .reset-td-br-2 role="presentation" }

#### 考慮事項

RCSメッセージの受信時のユーザー体験は、送信先の国でのキャリアカバレッジ、モバイルデバイスのハードウェア、モバイルデバイスのオペレーティングシステムなど、さまざまな要因によって若干異なる場合があります。

一般的に、RCSはAndroidデバイスとより自然に統合されます（この方式は主にGoogleによって実装され、ピアツーピアのRCSメッセージングはAndroidコミュニティで広く採用されています）。デバイスによって、体験のレンダリング速度や品質が異なる場合があります。
{% endtab %}

{% tab リッチカード %}

{% alert important %}
リッチカードは早期アクセス段階です。この早期アクセスへの参加に興味がある場合は、Brazeカスタマーサクセスマネージャーにお問い合わせください。
{% endalert %}

リッチカードは、メディア、テキスト、ボタンを1つのメッセージに組み合わせ、顧客にとってより直感的で魅力的な体験を作り出します。リッチカードには、テキストとメディアの2つのサブタイプを作成できます。

{% subtabs %}
{% subtab テキスト %}
テキストリッチカードは、テキストに焦点を当てた簡潔なメッセージです。以下の要素を含める必要があります：

- **タイトル:**最大200文字。Liquidでパーソナライズできます。
- **説明:**最大2,000文字。Liquidでパーソナライズできます。
- **ボタン:**少なくとも1つのボタンが必要です。**候補返信**または**Web URLを開く**アクションで最大4つのボタンを追加できます。

{% endsubtab %}
{% subtab メディア %}

メディアリッチカードは、画像または動画を含むビジュアルメッセージです。以下の要素を含める必要があります：

- **メディア:**画像、GIF、または動画。
    - カスタム動画サムネイルは早期アクセスではサポートされていません。早期アクセスでは、画像ファイルと動画ファイルの両方で、メディアの高さが大きい縦型レイアウトのみがサポートされています。
- **ボタン:**少なくとも1つのボタンが必要です。**候補返信**または**Web URLを開く**アクションで最大4つのボタンを追加できます。

{% endsubtab %}
{% endsubtabs %}

### 機能
- **カードボタン**と**候補:**リッチカードの下部（ボタン）またはメッセージ画面の下部（候補）に、最大4つのボタンと5つの候補（各最大25文字）を追加できます。ユーザーはこれらのクリック・タップオプションを選択して、特定の応答を送信したり、特定のアクションを実行したりできます。
- **パーソナライゼーション:**Liquidを使用して、タイトル、説明、メディア、ボタンなど、すべてのリッチカード要素をパーソナライズできます。
- **課金:**リッチカードは、1つのリッチ（「シングル」）RCSメッセージとして課金されます。
- **URLガイダンス:**タイトルまたは説明にプレーンテキストとして入力されたURLはクリックできません。ユーザーをWebサイトに誘導するには、**OpenURLボタン**を使用する必要があります。

![メディアまたはテキストリッチカードを選択するオプション付きのパネル。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_media_text.png %}){: style="max-width:65%;"}

{% endtab %}
{% endtabs %}

### ステップ 3:RCS メッセージを作成する {#step-3-compose-your-rcs-message}

必要に応じて、言語とパーソナライゼーション（[Liquid]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/liquid)、[コネクテッドコンテンツ]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/connected_content)、絵文字）を使用してメッセージを作成します。超過料金の可能性を減らすために、メッセージのコピー制限を必ず遵守してください。

{% alert important %}
先に進む前に、[RCSメッセージ制限のガイドライン](#step-2-select-your-rcs-message-type)をお読みください。RCSメッセージは[メッセージ単位で課金]({{site.baseurl}}/sms_rcs_billing_calculators)されるため、各タイプのRCSメッセージに含められる内容のニュアンスを理解しておくことをお勧めします。
{% endalert %}

### ステップ 4:メッセージをプレビューしてテストする {#step-4-preview-and-test-your-message}

Brazeでは、送信前にメッセージをプレビューしてテストすることを常に推奨しています。**テスト**タブに移動して、コンテンツテストグループまたは個々のユーザーにテストRCSを送信するか、Braze内でユーザーとしてメッセージを直接プレビューします。

### ステップ 5:CampaignまたはCanvasの残りの部分を構築する {#step-5-build-the-remainder-of-your-campaign-or-canvas}

次に、CampaignまたはCanvasの残りの部分を構築します。RCSメッセージを構築するためのツールの最適な使用方法の詳細については、以下のセクションを参照してください。

#### ステップ 5.1:配信スケジュールまたはトリガーを選択する {#step-51-choose-delivery-schedule-or-trigger}

RCSメッセージは、スケジュールされた時間、アクション、またはAPIトリガーに基づいて配信できます。詳細については、[Campaignのスケジュール設定]({{site.baseurl}}/user_guide/engagement_tools/campaigns/building_campaigns/delivery_types)を参照してください。

アクションベースの配信では、Campaignの期間とサイレント時間も設定できます。

ユーザーがCampaignを再度受信できるようにする、またはフリークエンシーキャップルールを有効にするなど、配信コントロールを指定します。

#### ステップ 5.2:ターゲットユーザーを選択する {#step-52-choose-users-to-target}

Segmentsまたはフィルターを選択して、オーディエンスを絞り込むことでユーザーをターゲットにします。サブスクリプショングループはすでに選択されているはずで、これによりユーザーは希望するコミュニケーションのレベルやカテゴリで絞り込まれます。

{% multi_lang_include audience/target_audiences.md %}

次に、Segmentsからより大きなオーディエンスを選択し、オプションの[フィルター]({{site.baseurl}}/user_guide/engagement_tools/segments/segmentation_filters)でそのSegmentをさらに絞り込みます。現在のおおよそのSegment人口のプレビューが自動的に表示されます。正確なSegmentメンバーシップは、メッセージが送信される直前に常に計算されることに留意してください。

{% alert tip %}
SMSおよびRCSのインタラクションに基づいてユーザーをターゲットにするRCSリターゲティングに興味がありますか？[リターゲティング]({{site.baseurl}}/sms_mms_rcs_user_retargeting)を参照してください。
{% endalert %}

#### ステップ 5.3:コンバージョンイベントを選択する {#step-53-choose-conversion-events}

Brazeでは、Campaignを受信した後にユーザーが特定のアクション（コンバージョンイベント）を実行する頻度を追跡できます。ユーザーが指定されたアクションを実行した場合にコンバージョンがカウントされる最大30日間の期間を設定できます。

コンバージョンイベントは、Campaignの成功を測定するのに役立ちます。例：
- ジオターゲティングを使用して、ユーザーの購入を最終目標とするRCSメッセージをトリガーする場合、コンバージョンイベントを**購入**に設定します。
- ユーザーをアプリに誘導しようとしている場合、コンバージョンイベントを**セッション開始**に設定します。

特定のユースケースに基づいて、カスタムコンバージョンイベントを設定することもできます。Campaignの成功を真に測定する方法について、クリエイティブに考えてみてください。

### ステップ 6:確認してデプロイする {#step-6-review-and-deploy}

CampaignまたはCanvasの構築が完了したら、詳細を確認し、テストしてから送信してください。

次に、[SMS、MMS、RCSのレポート]({{site.baseurl}}/sms_mms_rcs_reporting)を参照して、RCS Campaignsの結果にアクセスする方法を確認してください。

## 分析とレポート {#analytics-and-reporting}

CampaignまたはCanvasの分析には以下が含まれます：

- ボタンクリック、候補返信、候補アクションなど、リッチカードとのすべてのインタラクションを含む*合計クリック数*の統計。
- これらのインタラクションのより詳細なビューを提供する内訳テーブル。

{% alert note %}
早期アクセスでは、ユーザーレベルのクリックトラッキングは含まれていません。*合計クリック数*は、ボタンがクリックされるたびに増加します。たとえば、ユーザーが同じボタンを3回クリックした場合、クリック数は3増加します。
{% endalert %}

## ヒント {#tips}

### メッセージのパーソナライゼーションにLiquidを使用する {#using-liquid-for-message-personalization}

Liquidを使用する予定がある場合は、選択したパーソナライゼーションにデフォルト値を含めるようにしてください。受信者のユーザープロファイルが不完全な場合、名前や一貫した文章の代わりに空白のプレースホルダー `Hi, !` が表示されないようにするためです。

### AIコピーの生成 {#generating-ai-copy}

魅力的なコピーの作成にお困りですか？[AIコピーライティングアシスタント]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#generate-copy)を使用してみてください。製品名や説明を入力すると、AIがメッセージングで使用できる人間のようなマーケティングコピーを生成します。
