# RCS メッセージの作成 {#creating-an-rcs-message}

> RCS キャンペーンは、顧客に直接リーチし、プログラムで会話するのに最適です。Liquidやその他のダイナミックコンテンツを使用して、ユーザーとのパーソナルな体験を作り出し、ブランドとの控えめなユーザー体験を促進・向上させる環境を構築できます。

## RCS メッセージの作成

### ステップ1:メッセージの作成場所を選択する {#step-1-choose-where-to-build-your-message}

メッセージをキャンペーンとキャンバスのどちらで送信するかお悩みですか？キャンペーンは単発のシンプルなメッセージングに適しており、キャンバスは複数ステップのユーザージャーニーに適しています。

{% tabs %}
{% tab キャンペーン %}
1. **メッセージング** > **キャンペーン** に移動し、**キャンペーンを作成** を選択します。
2. **SMS/MMS/RCS** を選択するか、複数のチャネルを対象とするキャンペーンの場合は **マルチチャネル** を選択します。
3. キャンペーンにわかりやすく意味のある名前を付けます。
4. 必要に応じて[チーム]({{site.baseurl}}/user_guide/administer/global/user_management/teams)と[タグ]({{site.baseurl}}/user_guide/administer/global/workspace_settings/tags)を追加します。
   * タグを使用すると、キャンペーンの検索やレポートの作成が容易になります。たとえば、[レポートビルダー]({{site.baseurl}}/user_guide/analytics/reports/report_builder)では、特定のタグでフィルタリングできます。

{: start="5"}
5. キャンペーンに必要な数のバリアントを追加して名前を付けます。追加したバリアントごとに、異なるプラットフォーム、メッセージタイプ、レイアウトを選択できます。このトピックの詳細については、[多変量テストとABテスト]({{site.baseurl}}/user_guide/messaging/ab_testing)を参照してください。
- **SMSとRCSのバリアントテスト**: Brazeでは、1つのキャンペーン内にSMSとRCSの両方のバリアントを含めることができ、それぞれのパフォーマンスを比較できます。メッセージ作成の最初のステップで、SMSとRCSのバリアントを追加できます。

{: start="6"}
6. RCS対応の[購読グループ]({{site.baseurl}}/sms_rcs_subscription_groups)を選択します。購読グループを選択すると、Brazeはセグメンテーションフィルターを自動的に追加し、購読しているユーザーのみがキャンペーンを受信できるようにします。その購読グループに属するロングコードとショートコードのみが、ターゲットユーザーへのSMS送信に使用されます。
- **SMSフォールバック**: RCS送信者を含む購読グループには、フォールバック用のSMSコードを少なくとも1つ含めることを強くお勧めします。これは、RCSメッセージの配信に失敗した場合の到達性において重要です。その理由として、ユーザーデバイスの非互換性や、特定の国・地域でのキャリアカバレッジの不完全さなどが挙げられます。SMSフォールバックを有効にすることで、メッセージはユーザーに引き続き配信され、ユーザーとの接点を逃すことがなくなります。

{: start="7"}
7. SMSとRCSのどちらかを選択します。RCSメッセージを作成する前に、送信に使用するチャネルを選択してください。一般的にはRCSをできる限り使用することをお勧めします。SMSと比較して優れたユーザーエンゲージメントが期待できるためです。ただし、最大限の柔軟性とコントロールを提供するために、SMSでの送信オプションも常に用意しています。

![RCSまたはSMS/MMSメッセージタイプを選択するオプション。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_message_type.png %}){: style="max-width:65%;"}

{% alert tip %}
キャンペーン内のすべてのメッセージが同様または同じ内容になる場合は、追加のバリアントを作成する前にメッセージを作成してください。その後、**バリアントを追加** ドロップダウンから **バリアントからコピー** を選択できます。
{% endalert %}

{% endtab %}
{% tab キャンバス %}
1. キャンバスコンポーザーを使用して[キャンバスを作成]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas)します。
2. キャンバスの設定が完了したら、キャンバスビルダーで **SMS/MMS/RCS** メッセージステップを追加します。
3. ステップにわかりやすく意味のある名前を付けます。
4. RCS対応の[購読グループ]({{site.baseurl}}/sms_rcs_subscription_groups)を選択します。購読グループを選択すると、Brazeはセグメンテーションフィルターを自動的に追加し、購読しているユーザーのみがキャンペーンを受信できるようにします。その購読グループに属するロングコードとショートコードのみが、ターゲットユーザーへの送信に使用されます。

{: start="5"}
5. SMSとRCSのどちらかを選択します。RCSメッセージを作成する前に、送信に使用するチャネルを選択してください。一般的にはRCSをできる限り使用することをお勧めします。SMSと比較して優れたユーザーエンゲージメントが期待できるためです。ただし、最大限の柔軟性とコントロールを提供するために、SMSでの送信オプションも常に用意しています。

### ステップ2:RCSメッセージタイプを選択する {#step-2-select-your-rcs-message-type}

キャンペーンおよびキャンバスの作成時に、3つのRCSメッセージタイプ（テキスト、メディア、リッチカード）から選択して、目標に最適なメッセージを設定できます。

![テキスト、メディア、またはカードのメッセージタイプを選択するオプション。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_text_media.png %}){: style="max-width:65%;"}

{% tabs local %}
{% tab テキスト %}
名前が示すとおり、RCSテキストメッセージはテキストを媒体としたメッセージです。160文字以内で入力した場合、RCSメッセージはテキストのみ（「ベーシック」）のメッセージとして課金されます。160文字を超えたり、リッチ要素を使用したりした場合は、リッチ（「シングル」）RCSメッセージとして課金されます（文字数制限は3072文字に増加します）。

#### 機能 {#features}

- テキストメッセージタイプには、すべてのSMS機能が含まれます。URLクリックトラッキングには高度なトラッキングのみ利用可能で、ユーザーレベルのレポート精度が提供されます。
- さらに、高エンゲージメントのユーザーアクション（ランディングページへの訪問や注文など）を促進する、魅力的な**候補の返信**と**候補のアクション**ボタンを含めるオプションが利用可能です。
    - **候補の返信**は、ユーザーがクリックしてテキスト入力欄に事前入力できる候補応答を含むボタンです。限定された選択肢を提供することで、応答を考える手間を省きます。
    - **候補のアクション**は、ユーザーのデバイスでアクションを開始するボタンです。通常、1～2語の説明テキストとボタンの機能を理解するための視覚的アイコンで構成されます。Brazeは現在、OpenURL候補のアクションをサポートしています。これはURLと同様に機能し、ボタンを選択したユーザーはWebページやその他のURL指定の場所にリダイレクトされます。

![トレンドファッションスタイルを宣伝するRCSメッセージの3つの候補アクションのGIF：「おとぎ話のロイヤリティ」、「エッジーアカデミア」、「他のスタイルを見せて」。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_suggested_actions.gif %}){: style="max-width:70%;"}

#### 考慮事項 {#considerations}

- テキストの文字数制限については、テキストのみ（ベーシック）のRCSメッセージは最大160文字、リッチ（シングル）RCSメッセージは最大3072文字まで記述できます。
- ボタンの制限については、メッセージあたり最大5つのボタンを追加できます。これらのボタンは、候補のアクションまたは候補の返信のいずれかにできます。
- テキストが長すぎたりボタンが多すぎたりするとユーザーの不満につながる可能性があるため、できるだけシンプルにすることをお勧めします。
- 場合によっては、長いテキストのみのメッセージをSMSではなくRCS経由で送信する方がコスト効率が高いことがあります。これは、長いSMSメッセージは複数のセグメントに分割され、それぞれが課金対象となるのに対し、RCSメッセージはメッセージ単位で課金されるためです。詳細やガイダンスについては、Brazeアカウントマネージャーにお問い合わせください。
{% endtab %}

{% tab メディア %}
RCSメディアメッセージでは、SMSでは不可能な魅力的なメディア形式を使用できます。これには、画像、動画、ドキュメントファイルが含まれます。これらのメディアオプションは、オーディエンスとのエンゲージメントをさらに深め、まったく新しいユースケースを実現するために存在します。現時点では、[メディアライブラリ]({{site.baseurl}}/user_guide/messaging/design_and_edit/media_library/image_specifications)を通じた画像のアップロードのみがサポートされています。

#### 機能

- メディアメッセージタイプは、テキストメッセージタイプで利用可能なすべての機能（テキスト、候補の返信、候補のアクション）をサポートしています。
- JPEGおよびPNGファイル形式を含む画像ファイルをサポートしています。画像ファイルはメディアライブラリからアップロードできます。
- MP4、MPEG、MV4ファイル形式を含む動画ファイルをサポートしています。動画ファイルはメッセージ作成画面で直接URLを指定して追加できます。
- PDF形式のドキュメントファイルをサポートしています。ドキュメントファイルはメッセージ作成画面で直接URLを指定して追加できます。

![メディアファイルをアップロードするオプションを備えたRCSコンポーザー。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_media_type.png %})

#### ファイル仕様 {#file-specifications}

| ファイルタイプ | 仕様 |
| --- | --- |
| すべて | - ファイルサイズは100 MBまで <br><br>- ファイルURLは最大2048文字 |
| 画像ファイル | サポートされるファイル形式: JPG、JPEG、GIF |
| 動画ファイル | サポートされるファイル形式: H263、M4V、MP4、MPEG-4、MPEG、WEBM |
| ドキュメントファイル | サポートされるファイル形式: PDF |
{: .reset-td-br-1 .reset-td-br-2 role="presentation" }

#### 考慮事項

RCSメッセージの受信時のユーザー体験は、送信先の国でのキャリアカバレッジ、モバイルデバイスのハードウェア、モバイルデバイスのオペレーティングシステムなど、さまざまな要因に基づいてわずかに異なる場合があります。

一般的に、RCSはAndroidデバイスとより自然に統合されます（この方式は主にGoogleによって実装され、ピアツーピアのRCSメッセージングはAndroidコミュニティで広く採用されています）。デバイスによって、体験のレンダリング速度や品質が異なる場合があります。
{% endtab %}

{% tab リッチカード %}

{% alert important %}
リッチカードは早期アクセス段階です。この早期アクセスへの参加に興味がある場合は、Brazeカスタマーサクセスマネージャーにお問い合わせください。
{% endalert %}

リッチカードは、メディア、テキスト、ボタンを1つのメッセージに組み合わせ、顧客にとってより直感的で魅力的な体験を生み出します。リッチカードには、テキストとメディアの2つのサブタイプを作成できます。

{% subtabs %}
{% subtab テキスト %}
テキストリッチカードは、テキストに焦点を当てた簡潔なメッセージです。以下の要素を含める必要があります。

- **タイトル:** 最大200文字。Liquidでパーソナライズできます。
- **説明:** 最大2,000文字。Liquidでパーソナライズできます。
- **ボタン:** 少なくとも1つのボタンが必要です。**候補の返信**または**WebURLを開く**アクションで最大4つのボタンを追加できます。

{% endsubtab %}
{% subtab メディア %}

メディアリッチカードは、画像または動画を含むビジュアルメッセージです。以下の要素を含める必要があります。

- **メディア:** 画像、GIF、または動画。
    - カスタム動画サムネイルは早期アクセスではサポートされていません。早期アクセスでは、画像と動画ファイルの両方について、高い高さのメディアを持つ縦型レイアウトのみサポートしています。
- **ボタン:** 少なくとも1つのボタンが必要です。**候補の返信**または**WebURLを開く**アクションで最大4つのボタンを追加できます。

{% alert note %}
iOSでは、リッチカード内のGIFは静止画像として表示されます。Androidでは、期待どおりにアニメーションします。アニメーションコンテンツをiOSに送信するには、RCSの**メディア**メッセージを使用するか、リッチカードに動画を含めてください。GIFはBrazeのプレビューではアニメーションする場合がありますので、iOSデバイスにテスト送信してください。
{% endalert %}

{% endsubtab %}
{% endsubtabs %}

### 機能
- **カードボタン**と**候補:** リッチカードの下部（ボタン）またはメッセージ画面の下部（候補）に、最大4つのボタンと5つの候補（それぞれ最大25文字）を追加できます。ユーザーはこれらのクリック・タップオプションを選択して、特定の応答を送信したり、特定のアクションを実行したりできます。
- **パーソナライゼーション:** Liquidを使用して、タイトル、説明、メディア、ボタンなど、すべてのリッチカード要素をパーソナライズできます。
- **課金:** リッチカードは1つのリッチ（「シングル」）RCSメッセージとして課金されます。
- **URLガイダンス:** タイトルまたは説明にプレーンテキストとして入力されたURLはクリックできません。ユーザーをWebサイトに誘導するには、**OpenURLボタン**を使用する必要があります。

![メディアまたはテキストのリッチカードを選択するオプションのパネル。]({% image_buster /assets/unlisted_docs/img/rcs/rcs_media_text.png %}){: style="max-width:65%;"}

{% endtab %}

### ステップ3:RCSメッセージを作成する {#step-3-compose-your-rcs-message}

必要に応じて、言語やパーソナライゼーション（[Liquid]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid)、[Connected Content]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content)、絵文字）を使用してメッセージを作成します。超過料金の発生を抑えるために、メッセージのコピー制限を遵守してください。

{% alert important %}
先に進む前に、[RCSメッセージ制限のガイドライン](#step-2-select-your-rcs-message-type)をお読みください。RCSメッセージは[メッセージ単位で課金]({{site.baseurl}}/sms_rcs_billing_calculators)されるため、各RCSメッセージタイプに含められるものの詳細を理解しておくことをお勧めします。
{% endalert %}

### ステップ4:メッセージをプレビューしてテストする {#step-4-preview-and-test-your-message}

Brazeでは、メッセージを送信する前にプレビューとテストを行うことを常にお勧めしています。**テスト** タブに移動して、コンテンツテストグループまたは個々のユーザーにテストRCSを送信するか、Brazeで直接ユーザーとしてメッセージをプレビューします。

### ステップ5:キャンペーンまたはキャンバスの残りの部分を構築する {#step-5-build-the-remainder-of-your-campaign-or-canvas}

次に、キャンペーンまたはキャンバスの残りの部分を構築します。RCSメッセージを構築するためのツールの最適な使い方については、以下のセクションを参照してください。

#### ステップ5.1:配信スケジュールまたはトリガーを選択する {#step-51-choose-delivery-schedule-or-trigger}

RCSメッセージは、スケジュールされた時刻、アクション、またはAPIトリガーに基づいて配信できます。詳細については、[キャンペーンのスケジュール]({{site.baseurl}}/user_guide/messaging/campaigns/schedule_your_campaign)を参照してください。

アクションベースの配信では、キャンペーンの期間とサイレント時間も設定できます。

ユーザーがキャンペーンの再受信資格を得られるようにしたり、フリークエンシーキャップルールを有効にしたりするなど、配信コントロールを指定します。

#### ステップ5.2:ターゲットユーザーを選択する {#step-52-choose-users-to-target}

セグメントまたはフィルターを選択して、オーディエンスを絞り込むことでユーザーをターゲットにします。すでに購読グループを選択しているはずです。これにより、ユーザーが希望するコミュニケーションのレベルやカテゴリーで絞り込まれます。

{% multi_lang_include audience/target_audiences.md %}

次に、セグメントからより大きなオーディエンスを選択し、オプションの[フィルター]({{site.baseurl}}/user_guide/audience/segments/segmentation_filters)でそのセグメントをさらに絞り込みます。現在のおおよそのセグメント母集団のプレビューが自動的に表示されます。正確なセグメントメンバーシップは、メッセージ送信の直前に常に計算される点にご留意ください。

{% alert tip %}
SMSおよびRCSのインタラクションに基づいてユーザーをターゲティングするRCSリターゲティングに興味がありますか？[リターゲティング]({{site.baseurl}}/sms_mms_rcs_user_retargeting)を参照してください。
{% endalert %}

#### ステップ5.3:コンバージョンイベントを選択する {#step-53-choose-conversion-events}

Brazeでは、キャンペーンを受信した後にユーザーが特定のアクション（コンバージョンイベント）を実行する頻度を追跡できます。ユーザーが指定されたアクションを実行した場合にコンバージョンがカウントされる最大30日間のウィンドウを設定できます。

コンバージョンイベントは、キャンペーンの成功を測定するのに役立ちます。例えば:
- ジオターゲティングを使用して、ユーザーの購入を最終目標とするRCSメッセージをトリガーしている場合は、コンバージョンイベントを **購入** に設定します。
- ユーザーをアプリに誘導しようとしている場合は、コンバージョンイベントを **セッション開始** に設定します。

特定のユースケースに基づいて、カスタムコンバージョンイベントを設定することもできます。キャンペーンの成功をどのように測定するかについて、クリエイティブに考えてみてください。

### ステップ6:確認してデプロイする {#step-6-review-and-deploy}

キャンペーンまたはキャンバスの構築が完了したら、詳細を確認し、テストしてから送信してください。

次に、[SMS、MMS、およびRCSのレポート]({{site.baseurl}}/sms_mms_rcs_reporting)を参照して、RCSキャンペーンの結果にアクセスする方法を確認してください。

## 分析とレポート {#analytics-and-reporting}

キャンペーンまたはキャンバスの分析には、以下が含まれます。

- ボタンのクリックや候補の返信またはアクションなど、リッチカードとのすべてのインタラクションを含む「_合計クリック数_」の統計。
- これらのインタラクションのより詳細なビューを提供する内訳テーブル。

{% alert note %}
早期アクセスには、ユーザーレベルのクリックトラッキングは含まれていません。_合計クリック数_は、ボタンがクリックされるたびに増加します。例えば、ユーザーが同じボタンを3回クリックした場合、クリック数は3増加します。

## ヒント {#tips}

### Liquid を使ったメッセージのパーソナライゼーション {#using-liquid-for-message-personalization}

Liquid を使用する予定がある場合は、選択したパーソナライゼーションにデフォルト値を必ず含めてください。受信者のユーザープロファイルが不完全な場合、名前や意味のある文章の代わりに空白のプレースホルダー `Hi, !` が表示されることを防ぐことができます。

### AI によるコピーの生成 {#generating-ai-copy}

魅力的なコピーの作成にお困りですか？[AI コピーライティングアシスタント]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#generate-copy)をお試しください。製品名や説明を入力すると、AI がメッセージングに使用できる人間らしいマーケティングコピーを生成します。
