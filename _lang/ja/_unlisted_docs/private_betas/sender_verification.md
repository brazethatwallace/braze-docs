# 送信者の検証 {#sender-verification}

> このページでは、独自のサブドメインをBrazeに委任する方法について説明します。送信者の検証を使用して、専用の送信サブドメインの制御をBrazeに設定・委任することで、Fromドメインとトラッキングリンクを同じサブドメインの下に配置し、ブランドの一貫性を強化できます。

{% alert important %}
この機能はベータ版であり、Braze内部チームのみが利用できます。
{% endalert %}

## 送信者の検証の仕組み {#how-sender-verification-works}

ドメイン委任は、特定の送信サブドメインの制御をBrazeに委任できるDNS設定オプションです。たとえば、「marketing.example.com」をサブドメインとして使用する場合、Brazeはメールなどのメッセージング機能に必要なDNSレコードを管理します。

### メリット {#benefits}

送信者の検証を使用すると、設定とメンテナンスが簡素化されます。Brazeが必要なものを作成・更新するため、DNSの設定ミスが発生する可能性が低くなります。

### 考慮事項 {#considerations}

- 専用のサブドメインを選択してください。
- ドメイン委任が完了すると、Brazeは委任されたサブドメインのDNSレコードを管理します。
- 複数のブランドやBrazeワークスペースがある場合、ブランドごとに1つの委任サブドメインを選択できます。
- 送信者の検証には、送信ドメイン50個とトラッキングドメイン50個の制限があります。追加が必要な場合は、Brazeサポートチームにお問い合わせください。

## ステップ 1: 前提条件を完了する {#step-1-complete-prerequisites}

Brazeダッシュボードで、**設定** > **会社の設定**の下にある**送信者の検証**に移動し、オンボーディングマネージャーと協力して以下の前提条件を完了してください：

- IPプールを追加する
- IPアドレスを追加する
- 委任ドメインを追加し、NSレコードを検証する

## ステップ 2: 送信サブドメインを追加する {#step-2-add-your-sending-subdomain}

1. **送信ドメイン**セクションで、**送信ドメインを追加**を選択します。
2. IPプールの送信サブドメインを使用して、**Mail from**と**送信ドメイン**フィールドに入力します。例：「marketing.mail.example.com」
3. ドロップダウンから委任ドメインを選択します。
4. 次に、**送信**を選択します。

![Mail fromアドレスと送信ドメインのフィールド、委任ドメインのドロップダウン、送信ボタンが表示されたフォーム。]({% image_buster /assets/unlisted_docs/img/sender_verification/sending_subdomain.png %}){: style="max-width:85%;"}

DNSレコードが伝播するまで5〜10分かかります。完了すると、ドメインが使用可能になったことを知らせる通知メールが届きます。

{% alert important %}
ドメインは送信後に変更できません。Brazeは検証と認証のためのDNSレコードを作成し、DNS設定に追加します。
{% endalert %}

## ステップ 3: トラッキングサブドメインを追加する {#step-3-add-your-tracking-subdomain}

サブドメインを作成し、検証が完了した後：

1. **トラッキングドメインを追加**を選択します。
2. トラッキングサブドメインを入力します。たとえば、トラッキングサブドメインが「click」の場合、サブドメインは「click.marketing.mail.example.com」になります。
3. ドロップダウンから関連する送信ドメインを選択します。
4. 次に、**送信**を選択します。

![追加するトラッキングドメインの例。]({% image_buster /assets/unlisted_docs/img/sender_verification/tracking_domain.png %}){: style="max-width:85%;"}

これらのDNSレコードが伝播するまで最大24時間かかる場合がありますが、通常はそれより短い時間で完了します。完了すると、ドメインが使用可能になったことを知らせる通知メールが届きます。

{% alert important %}
適切なDNS委任のために、トラッキングドメインは送信ドメインのサブドメインである必要があります。
{% endalert %}

## ステップ 4: ワークスペースを選択する {#step-4-select-the-workspaces}

次に、ドメインにアクセスできるワークスペースを選択し、**確認**を選択します。オプションとして、新しいワークスペースが作成されたときに送信ドメインを自動的に追加することもできます。

![ワークスペース選択のチェックボックスと、新しいワークスペースに送信ドメインを自動的に追加するオプション、確認ボタンが表示されたダイアログ。]({% image_buster /assets/unlisted_docs/img/sender_verification/select_workspaces_domain.png %}){: style="max-width:85%;"}

## ステップ 5: メール送信をテストする {#step-5-test-your-email-sending}

送信ドメインとトラッキングドメインのステータスが**使用可能**になったら、以下の手順でメール送信をテストできます：

1. ワークスペースで、**設定** > **メール設定**に移動します。
2. **表示名アドレス**セクションに新しい送信ドメインが表示されていることを確認します。
3. 新しいドメインを使用したメールアドレスを追加します（例：「marketing@marketing.mail.example.com」）。
4. **保存**を選択します。
5. 次に、テスト用のメールCampaignを作成し、自分宛にメールを送信して以下を確認します：
- メールが正常に配信されたこと。
- Fromアドレスが正しいこと。
- クリックトラッキングリンクがトラッキングドメインを使用していること。
- メールヘッダーが正しく表示されていること。
