# レポートビルダーでのセグメントレポート {#segment-reporting-in-report-builder}

> この記事では、レポートビルダーでセグメントをレポートディメンションとして使用する方法について説明します。セグメントに関するレポート作成方法、セグメント別の分析、サポートされている組み合わせなどを取り上げます。

{% multi_lang_include alerts/early_access_beta_alert.md feature='セグメント reporting' contact='customer success manager' %}

レポートビルダーでは、行およびドリルダウンオプションとして**セグメント**がサポートされており、セグメントのパフォーマンスを確認したり、キャンペーンやキャンバスのパフォーマンスをセグメントメンバーシップ別に分析したりできます。**行**または**ドリルダウン**のドロップダウンに**セグメント**が表示されない場合、この機能はアカウントで有効になっていません。

次のような質問に答えることができます。

- 特定のセグメントの経時的なパフォーマンスはどうか？
- 特定のセグメントをターゲットにしているキャンペーンやキャンバスはどれか、それぞれのパフォーマンスはどうか？
- 1つのキャンペーンやキャンバスにおいて、セグメント間でエンゲージメントはどのように比較されるか？

{% alert note %}
セグメントレポートは、[分析トラッキング]({{site.baseurl}}/user_guide/analytics/tracking/segment_analytics_tracking)が有効になっているセグメントでのみ利用できます。**行**ドロップダウンで**セグメント**を選択するには、ワークスペースレベルの[「ダッシュボードレポートの表示」権限]({{site.baseurl}}/user_guide/administer/global/user_management/permissions)が必要です。
{% endalert %}

## セグメントに関するレポート作成 {#report-on-segments}

セグメントに関するレポートを直接作成するには：

1. **Analytics** > **レポートビルダー (New)** に移動します。
2. **Create New Report** をクリックします。
3. **行**ドロップダウンで**セグメント**を選択します。
4. （オプション）**ドリルダウンを追加**を選択して、セグメントデータをさらに分析します。
   - **キャンペーンとキャンバス：** セグメントをターゲットにしたキャンペーンやキャンバスと、それぞれのパフォーマンスを確認します。
   - **日付：** セグメントのサイズやパフォーマンスの経時的なトレンドを確認します。折れ線グラフと組み合わせてトレンドを可視化できます。
5. **レポートコンテンツ**で**セグメント**ドロップダウンを開き、レポートに追加するセグメントを選択します。
6. **列** > **指標をカスタマイズ**で指標を選択し、**レポートコンテンツ**で日付範囲を設定します。
7. **キャンペーンとキャンバス**のドリルダウンを追加した場合は、レポートに含めるキャンペーンとキャンバスを追加します。
8. **保存して実行**をクリックします。

レポートビルダーの完全なワークフローについては、[レポートの作成]({{site.baseurl}}/user_guide/analytics/reports/report_builder#creating-a-report)を参照してください。

## セグメント別のドリルダウン {#drill-down-by-segment}

キャンペーン、キャンバス、またはチャネルレポートをセグメント別にドリルダウンするには：

1. **行**ドロップダウンで**キャンペーン**、**キャンバス**、または**キャンペーンとキャンバス**を選択します。
2. **ドリルダウンを追加**を選択し、**セグメント**を選択します。
3. **レポートコンテンツ**で**セグメント**ドロップダウンを開き、レポートに追加するセグメントを選択します。
4. **列** > **指標をカスタマイズ**で指標を選択し、**レポートコンテンツ**で日付範囲を設定します。
5. レポートに含めるキャンペーンまたはキャンバスを追加します。
6. **保存して実行**をクリックすると、キャンペーンやキャンバスがターゲットにした各セグメント別のパフォーマンスが表示されます。

これは、同じキャンペーンやキャンバスを複数のセグメントに送信しているワークスペースで特に便利です。セグメントメンバーシップとキャンペーンのパフォーマンスを手動でクロスリファレンスすることなく、各セグメントの反応を確認できます。

## サポートされている組み合わせ {#supported-combinations}

セグメントレポートでは、以下の**行**と**ドリルダウン**の組み合わせがサポートされています。

| 行 | ドリルダウン |
| ----- | ----- |
| セグメント | キャンペーンとキャンバス |
| セグメント | 日付 |
| キャンペーン | セグメント |
| キャンペーン | バリアント |
| キャンバス | セグメント |
| キャンペーンとキャンバス | セグメント |
{: .reset-td-br-1 .reset-td-br-2 aria-label="サポートされている行とドリルダウンの組み合わせ"}

{% alert note %}
レポートビルダーでは、一度に1つのドリルダウンがサポートされています。**行**ドロップダウンで**キャンペーン**を選択した場合、**バリアント**または**セグメント**でドリルダウンできますが、同じレポートで両方を使用することはできません。
{% endalert %}

## 指標の利用可否 {#metrics-availability}

セグメントに関するレポートを作成する場合、レポートビルダーのすべての指標が利用できるわけではありません。選択できる指標は、**セグメント**が**行**にあるか**ドリルダウン**にあるか、またレポートにキャンペーンやキャンバスのディメンションが含まれているかどうかによっても異なります。

| 指標 | 利用可否 |
| ----- | ----- |
| チャネルおよび一般的なメッセージング指標 | サポートされている行とドリルダウンの組み合わせで利用可能です。 |
| コンバージョン数（コンバージョンA〜D）およびコンバージョンイベント名 | セグメントとキャンペーンまたはキャンバスのディメンションが一緒に表示される場合に利用可能です。行に**セグメント**を使用し、**キャンペーンとキャンバス**のドリルダウンを設定するか、行に**キャンペーン**、**キャンバス**、または**キャンペーンとキャンバス**を使用し、**セグメント**のドリルダウンを設定します。 |
| 収益およびコンバージョン率 | セグメントディメンションのレポートでは利用できません。 |
| セグメント購入収益および件数 | **セグメント**が行にある場合のみ利用可能です。 |
{: .reset-td-br-1 .reset-td-br-2 aria-label="セグメントレポートの指標の利用可否"}

行とドリルダウンの選択が指標にどのように影響するかについて詳しくは、レポートビルダーの[指標の利用可否]({{site.baseurl}}/user_guide/analytics/reports/report_builder#metrics-availability)を参照してください。
