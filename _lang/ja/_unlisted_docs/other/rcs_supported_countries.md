# RCS対応送信国とキャリアカバレッジ {#rcs-supported-sending-countries-and-carrier-coverage}

> RCSカバレッジとは、ブランドが特定のオーディエンスに対してRCSとして配信されることが期待できるメッセージの割合です。

RCSカバレッジには2つの要因が影響します。

- **デバイスレベルのカバレッジ:** RCSはほぼ100%のAndroidデバイスで有効になっています。RCSはiOS 18.1以降を搭載したiOSデバイスで利用可能です。2024年10月時点で、約68%のiOSデバイスが更新済みです（つまり、iOS 18.1以降を使用しています）。
- **携帯キャリアのカバレッジ:** RCSは新しいチャネルであるため、携帯キャリアはまだプロトコルのサポートに取り組んでおり、国によってカバレッジに差があります。
