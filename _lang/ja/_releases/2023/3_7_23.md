# 2023年3月7日リリース {#march-7-2023-release}

## オリジナルキャンバスエクスペリエンスの複製サポートの終了 {#removing-support-for-duplicating-original-experience-canvases}

2023年2月28日をもって、オリジナルのキャンバスエクスペリエンスを使用したキャンバスの作成や複製はできなくなりました。Brazeでは、オリジナルのキャンバスエクスペリエンスを使用しているお客様に、キャンバスフローへの移行をお勧めしています。キャンバスフローは、キャンバスの構築と管理をより効率的に行うための改善された編集エクスペリエンスです。詳しくは、[キャンバスをキャンバスフローにクローンする]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/cloning_canvases)方法をご覧ください。

## iOSのライブアクティビティ（早期アクセス） {#live-activities-for-ios-early-access}

[ライブアクティビティ]({{site.baseurl}}/developer_guide/push_notifications/live_notifications/?sdktab=swift)は、ロック画面に表示される永続的でインタラクティブな通知で、リアルタイムで状況を把握できます。ロック画面に表示されるため、ライブアクティビティは通知を見逃すことがありません。永続的であるため、ユーザーがスマートフォンのロックを解除しなくても、最新のコンテンツを表示できます。

## Content Cardsのカード作成 {#card-creation-for-content-cards}

新しいContent Cardsキャンペーンにおいて、Brazeがオーディエンスの適格性とパーソナライゼーションを評価するタイミングを、カードの作成時期を指定することで選択できるようになりました。

以下のオプションが利用可能です。

- **キャンペーン開始時:** Content Cardsの以前のデフォルト動作です。Brazeはキャンペーン開始時にオーディエンスの適格性とパーソナライゼーションを計算し、カードを作成してユーザーがアプリを開くまで保存します。
- **最初のインプレッション時:** ユーザーが次にアプリを開いた（つまり新しいセッションを開始した）とき、BrazeはそのユーザーがどのContent Cardsの対象であるかを判定し、LiquidやConnected Contentなどのパーソナライゼーションをテンプレート処理してから、カードを作成します。

詳細については、[カード作成]({{site.baseurl}}/user_guide/channels/content_cards/create_a_content_card/card_creation)を参照してください。

## アプリ内メッセージのドラッグ＆ドロップエディターのスタイルリセット {#reset-styles-for-in-app-message-drag-drop-editor}

アプリ内メッセージのドラッグ＆ドロップエディターで、変更を加えた後にスタイルをデフォルトのスタイルにすばやくリセットできるようになりました。詳細については、[スタイルをデフォルトにリセットする]({{site.baseurl}}/user_guide/channels/in_app_messages/customize/style_settings#reset-styles-to-default)を参照してください。

## リンク短縮用のカスタムドメイン {#custom-domains-for-link-shortening}

リンク短縮では、独自のドメインを使用して短縮URLの外観をパーソナライズすることもでき、一貫したブランドイメージを表現するのに役立ちます。設定が完了すると、[カスタムドメイン]({{site.baseurl}}/user_guide/message_building_by_channel/sms/campaign/link_shortening#custom-domains)を1つまたは複数のSMS購読グループに割り当てることができます。

## Safari モバイル Web プッシュ {#safari-mobile-web-push}

Safari v16.4 はモバイル Web プッシュをサポートしており、iOS および iPadOS でプッシュ通知を使用してモバイルユーザーをリエンゲージできるようになりました。iOS および iPadOS の Safari で [Web プッシュをサポートする]({{site.baseurl}}/developer_guide/push_notifications/?sdktab=safari)手順については、専用ガイドに従ってください。

## User Updateコンポーネントのユースケース {#user-update-component-use-cases}

キャンバスのUser Updateコンポーネントを使用すると、JSONコンポーザーでユーザーの属性、イベント、購入を更新できます。しかし、この機能を最大限に活用する方法がよくわからないという方もいるのではないでしょうか。アイデアのヒントとなるよう、[3つのユースケース例]({{site.baseurl}}/user_guide/engagement_tools/canvas/canvas_components/user_update#use-cases)を追加しました。

## ユーザー検索 {#user-lookup}

この新しい記事では、[ユーザー検索]({{site.baseurl}}/user_guide/audience/segments/creating_a_segment)を使用して、コンポーザーから直接特定のユーザーを検索し、フィルターやセグメントが正しく設定されているかどうかをテストする方法について説明しています。これは、キャンペーンやキャンバスが期待どおりに送信されない場合（たとえば、ユーザーが受信すべきメッセージを受信していない場合など）のトラブルシューティングにも役立ちます。

ユーザー検索は以下の場合に利用できます。

- セグメントの作成時
- キャンペーンまたはキャンバスのオーディエンス設定時
- オーディエンスパスステップの設定時

## カスタムデータのブロックリスト登録または削除 {#blocklisting-or-deleting-custom-data}

この新しい記事では、[カスタムデータのブロックリスト登録または削除]({{site.baseurl}}/user_guide/data/activation/custom_data/blocklist_custom_data)によってカスタムデータオブジェクトを廃止する方法について説明しています。

カスタム属性、カスタムイベント、または購入イベントが、データポイントを過剰に消費している、マーケティング戦略にとって不要になった、あるいは誤って記録されたと判明する場合があります。このデータがBrazeに送信されるのを停止するために、開発チームがアプリやWebサイトのバックエンドからデータを削除する作業を行っている間、カスタムデータオブジェクトをブロックリストに登録できます。

## Brazeの新しいパートナーシップ {#new-braze-partnerships}

### Sisu Data - ビジネスインテリジェンス {#sisu-data-business-intelligence}

[Sisu Data]({{site.baseurl}}/partners)とBrazeの統合により、すべてのキャンペーンまたはキャンペーンレベルで、指標（開封率、クリックスルー率、コンバージョン率など）が変化している理由や、最も最適な結果を生み出す要因を理解できます。これらのセグメントが特定されると、企業ユーザーはデータウェアハウスに出力を具体化するか、Sisuから直接Brazeに送信してユーザーのリターゲティングや再エンゲージメントを行うことができます。

### Loplat - 文脈に応じたロケーション {#loplat-contextual-location}

Brazeと[loplat]({{site.baseurl}}/partners/message_personalization/location/loplat)の統合により、loplatのロケーションサービス（店舗POIおよびカスタムジオフェンス）を使用して、地理的コンテキストに基づくマーケティングキャンペーンをトリガーし、オフラインセグメンテーションを使用してカスタムイベントを作成できます。ユーザーがloplat Xで設定したターゲットロケーションを訪問すると、キャンペーンとロケーション情報が即座にBrazeに送信されます。

### ActionIQ - 顧客データプラットフォーム {#actioniq-customer-data-platform}

Brazeと[ActionIQ]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/actioniq)の統合により、ブランドはActionIQデータをBrazeに直接同期およびマッピングでき、顧客データの全範囲に基づいた卓越した顧客体験の提供を実現します。この統合により、ユーザーは以下のことが可能になります。

- ActionIQから直接Brazeにオーディエンスセグメントまたはカスタム属性をマッピングする
- ActionIQで追跡されたイベントをリアルタイムでBrazeに転送し、パーソナライズされたターゲットキャンペーンをトリガーする

### Komo - ダイナミックコンテンツ {#komo-dynamic-content}

Brazeと[Komo]({{site.baseurl}}/partners/additional_channels_and_extensions/extensions/landing_pages/komo)の統合により、Komoエンゲージメントハブを通じてファーストパーティおよびゼロパーティデータを収集できます。これらのハブは、インタラクティブなコンテンツやゲーミフィケーション機能を提供するダイナミックなマイクロサイトです。これらのハブから収集されたユーザーデータは、Braze APIに送信されます。

### Phrase - ローカライゼーション {#phrase-localization}

[Phrase]({{site.baseurl}}/partners/message_personalization/localization/phrase)とBrazeの統合により、Brazeインターフェイスを離れることなくメールテンプレートやContent Blocksを翻訳できます。BrazeのPhrase TMS統合を使用すると、シームレスなローカライゼーションにより顧客エンゲージメントを高め、新しい市場への成長を促進できます。

### Nift - ロイヤルティ {#nift-loyalty}

Brazeと[Nift]({{site.baseurl}}/partners/additional_channels_and_extensions/extensions/rewards/nift)の統合により、カスタマーライフサイクルの重要な瞬間にNiftギフトを含む「お礼」を自動的にトリガーし、どの顧客がギフトを使用したかを特定できます。Niftギフトカードは、Niftのマッチメイキングテクノロジーを活用して新規顧客を費用対効果の高い方法で大規模に獲得するブランドが提供する製品やサービスへのアクセスに使用できます。

### Sageflo - メッセージテンプレート {#sageflo-message-templates}

Brazeと[Sageflo]({{site.baseurl}}/partners/message_orchestration/templates/sageflo)の統合により、ローカルチームはBrazeとのAPI統合を通じて、マーケティング承認済みのテンプレート、画像、オーディエンスセグメントを使用して独自のメールを簡単に送信できます。

### Airbyte - ワークフローオートメーション {#airbyte-workflow-automation}

Brazeと[Airbyte]({{site.baseurl}}/partners/data_and_analytics/workflow_automation/airbyte)の統合により、すべてのアプリケーションとデータベースを中央のウェアハウスに接続してBrazeデータを収集・分析するデータパイプラインを作成できます。中央のウェアハウスにデータが収集されると、データチームは好みのビジネスインテリジェンスツールを使用してBrazeデータを効果的に探索できます。

### GrowthLoop - ワークフローオートメーション {#growthloop-workflow-automation}

Brazeと[GrowthLoop]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/growthloop)の統合により、データウェアハウスから直接顧客データをセグメント化してBrazeに送信できます。これにより、ユーザーは信頼できる唯一の情報源と連携しながらBrazeの豊富な機能セットを最適化できます。顧客セグメンテーションとアクティベーションのマーケティング活動を効率化し、セグメント化、ローンチ、テスト、およびBrazeに送信されたターゲットキャンペーンの結果測定にかかる時間を短縮します。
