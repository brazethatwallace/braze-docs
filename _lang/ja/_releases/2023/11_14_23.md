# 2023年11月14日リリース {#november-14-2023-release}

## Brazeを始めよう {#getting-started-with-braze}

嬉しいお知らせです！Brazeの[マーケター]({{site.baseurl}}/user_guide/get_started)と[開発者]({{site.baseurl}}/developer_guide/getting_started)それぞれに合わせた2つの「はじめに」セクションを導入しました。これらのセクションは、必要なツールとガイダンスをすべて提供し、Brazeをすぐに使い始められるように設計されています。ぜひアクセスして、Brazeの機能を体験してみてください。

## 新しいBrazeダッシュボードインスタンス {#new-braze-dashboard-instance}

Brazeは、ダッシュボードとRESTエンドポイント用に複数の異なるインスタンスを管理しています。新しいダッシュボードインスタンス`US-07`が追加されました。詳細については、[API概要]({{site.baseurl}}/api/basics)を参照してください。

## 堅牢なチャネル {#robust-channels}

### アプリ内メッセージ用のカスタムドラッグ＆ドロップテンプレート {#custom-drag-and-drop-templates-for-in-app-messages}

{% multi_lang_include release_type.md release="General availability" %}

[アプリ内メッセージ用のカスタムドラッグ＆ドロップテンプレート]({{site.baseurl}}/user_guide/channels/in_app_messages/drag_and_drop)を使用して、ドラッグ＆ドロップエディターでアプリ内メッセージのデザインを開始できるようになりました。

### SMSダブルオプトイン {#sms-double-opt-in}

{% multi_lang_include release_type.md release="General availability" %}

[SMSダブルオプトイン]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/keyword_processing/double_opt_in)では、ユーザーがSMSメッセージを受信する前に、オプトインの意思を明示的に確認することを要求できます。これにより、SMSに対してエンゲージメントが高い、または今後エンゲージメントが期待できるユーザーに焦点を絞ることができます。

### メールレポートの推定実開封率 {#estimated-real-open-rate-for-email-reporting}

{% multi_lang_include release_type.md release="General availability" %}

[推定実開封率]({{site.baseurl}}/user_guide/channels/email/reporting#estimated-real-open-rate)は、Brazeが独自に作成した分析モデルを使用して、機械による開封が存在しなかった場合のキャンペーンのユニーク開封率の推定値を再構築します。Brazeは各キャンペーンのクリックデータを使用して、実際のユーザーがメッセージを開封した割合を推測します。これにより、AppleのMPPを含むさまざまな機械開封メカニズムを補正します。

### キャンバスのパーソナライズされたパス {#personalized-paths-for-canvas}

{% multi_lang_include release_type.md release="Beta" %}

[パーソナライズされたパス]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step/personalized_paths)を使用すると、キャンペーンのパーソナライズされたバリアントと同様に、コンバージョンの可能性に基づいて個々のユーザーに合わせてキャンバスジャーニー全体をパーソナライズできます。パーソナライズされたパスを実験パスステップと組み合わせて使用し、Brazeが残りのパスを相互にテストする間、一部のユーザーを遅延グループに保持します。

## データの柔軟性 {#data-flexibility}

### Brazeダッシュボードの検索 {#searching-your-braze-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

[検索バー]({{site.baseurl}}/user_guide/administer/personal/the_braze_dashboard)を使用して、Brazeダッシュボード内で作業内容やその他の情報を検索できます。検索バーはBrazeダッシュボードの上部にあります。

### カスタム属性とイベントのブロックリスト登録 {#blocklisting-custom-attributes-and-events}

{% multi_lang_include release_type.md release="General availability" %}

一度に最大10個のカスタム属性またはカスタムイベントをブロックリストに登録できるようになりました。詳細については、[カスタムイベントと属性の管理]({{site.baseurl}}/user_guide/data/activation/custom_data/managing_custom_data)を参照してください。

### 新しいヘルプ記事：ユニバーサルリンクとアプリリンク {#new-help-article-universal-links-and-app-links}

Appleのユニバーサルリンクと Android のアプリリンクは、Webコンテンツとモバイルアプリ間のシームレスな遷移を提供するために考案されたメカニズムです。ユニバーサルリンクはiOS固有のものですが、AndroidアプリリンクはAndroidアプリケーションに対して同じ目的を果たします。

このトピックの詳細については、専用の[ユニバーサルリンクとアプリリンク]({{site.baseurl}}/user_guide/channels/email/customize/universal_links_and_app_links)の記事をご覧ください。

## Brazeの新しいパートナーシップ {#new-braze-partnerships}

### Olo – チャネル拡張 {#olo-channel-extensions}

Brazeと[Olo]({{site.baseurl}}/partners/ecommerce/ordering_payments_subscription/olo)の連携により、Brazeのユーザープロファイルを更新してOloのユーザープロファイルとの整合性を保つことができます。また、Oloのイベントに基づいてBrazeから適切なメッセージングを送信することもできます。

### Typeform – 顧客データプラットフォーム {#typeform-customer-data-platform}

Brazeと[Typeform]({{site.baseurl}}/partners/additional_channels_and_extensions/extensions/surveys/typeform)の連携により、Typeformの回答から収集したデータでBrazeのユーザープロファイルを更新したり、ユーザーのTypeformへのエンゲージメントに基づいてBrazeでメッセージングをトリガーしたり、ユーザーのTypeformの回答に基づいてBrazeのメッセージングをパーソナライズしたりできます。

## SDKの更新 {#sdk-updates}

最新のSDK更新がリリースされました。破壊的な更新はSDK更新セクションに記載されています。その他のすべての更新は、対応するSDKの変更ログに記載されています。

- [Web SDK v4.10.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [Web SDK v5.0.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [Android SDK 29.0.1](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [SWIFT SDK 7.1.0-7.2.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - `Braze.Configuration.DeviceProperty.pushDisplayOptions`は非推奨になりました。この値を指定しても効果はありません。
- [React Native SDK 8.0.0-8.1.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
    - ネイティブAndroidブリッジをBraze Android SDK 27.0.1から29.0.0に更新しました。
    - ネイティブiOSブリッジをBraze SWIFT SDK 6.6.0から7.0.0に更新しました。
    - `Banner` Content Cardsタイプの名前をImageOnlyに変更しました：
        - `BannerContentCard`を`ImageOnlyContentCard`に変更
        - `ContentCardTypes.BANNER`を`ContentCardTypes.IMAGE_ONLY`に変更
    - Androidでは、プロジェクト内のXMLファイルにContent Cards用の`banner`という単語が含まれている場合、`image_only`に置き換える必要があります。
    - `Braze.getFeatureFlag(id)`は、フィーチャーフラグが存在しない場合に`null`を返すようになりました。
    - `Braze.Events.FEATURE_FLAGS_UPDATED`は、更新リクエストが成功または失敗で完了した場合、および現在のセッションからキャッシュされたデータが以前に存在していた場合の初回購読時にのみトリガーされます。
