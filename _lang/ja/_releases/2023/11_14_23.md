# 2023年11月14日リリース {#november-14-2023-release}

## Brazeを使い始める {#getting-started-with-braze}

エキサイティングなニュースです！Brazeの[マーケター]({{site.baseurl}}/user_guide/get_started)と[開発者]({{site.baseurl}}/developer_guide/getting_started)向けに特別に作られた2つの入門セクションを紹介します。これらのセクションは、必要なツールとガイダンスをすべて提供し、Brazeをすぐに使い始められるように設計されています。ぜひご覧ください。

## 新しいBrazeダッシュボードインスタンス {#new-braze-dashboard-instance}

Brazeは、ダッシュボードとRESTエンドポイント用にさまざまなインスタンスを管理しています。新しいダッシュボードインスタンス`US-07`を追加しました。詳細については、[APIの概要]({{site.baseurl}}/api/basics)を参照してください。

## 強力なチャネル {#robust-channels}

### アプリ内メッセージ用のカスタムドラッグ＆ドロップテンプレート {#custom-drag-and-drop-templates-for-in-app-messages}

{% multi_lang_include release_type.md release="General availability" %}

[アプリ内メッセージ用のカスタムドラッグ＆ドロップテンプレート]({{site.baseurl}}/user_guide/channels/in_app_messages/drag_and_drop)を使用して、ドラッグ＆ドロップエディターでアプリ内メッセージのデザインを開始できるようになりました。

### SMSダブルオプトイン {#sms-double-opt-in}

{% multi_lang_include release_type.md release="General availability" %}

[SMSダブルオプトイン]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/keyword_processing/double_opt_in)では、ユーザーがSMSメッセージを受信する前にオプトインの意思を明示的に確認することを要求できます。これにより、SMSに関心を持ちそうなユーザーや、すでにSMSに関心を持っているユーザーに焦点を合わせることができます。

### メールレポート用の推定実質開封率 {#estimated-real-open-rate-for-email-reporting}

{% multi_lang_include release_type.md release="General availability" %}

[推定実質開封率]({{site.baseurl}}/user_guide/message_building_by_channel/email/reporting_and_analytics/email_reporting#estimated-real-open-rate)は、Brazeが独自に作成した分析モデルを使用して、機械開封が存在しないかのようにキャンペーンのユニーク開封率の推定値を再構築します。Brazeは各キャンペーンのクリックデータを使用して、実際の人間がメッセージを開封した割合を推測します。これにより、AppleのMPPを含むさまざまな機械開封メカニズムが補正されます。

### キャンバス用のパーソナライズドパス {#personalized-paths-for-canvas}

{% multi_lang_include release_type.md release="Beta" %}

[パーソナライズドパス]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step/personalized_paths)では、キャンペーンのパーソナライズドバリアントと同様に、コンバージョンの可能性に基づいて個々のユーザーに対してキャンバスジャーニー全体をパーソナライズできます。Brazeが残りのパスを互いにテストしている間、ユーザーの一部を遅延グループに保持するために、実験パスステップでパーソナライズドパスを使用します。

## データの柔軟性 {#data-flexibility}

### Brazeダッシュボードの検索 {#searching-your-braze-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

[検索バー]({{site.baseurl}}/user_guide/administer/personal/the_braze_dashboard)を使用して、Brazeダッシュボード内で自分の作業やその他の情報を見つけることができます。検索バーはBrazeダッシュボードの最上部にあります。

### カスタム属性とイベントのブロックリスト化 {#blocklisting-custom-attributes-and-events}

{% multi_lang_include release_type.md release="General availability" %}

一度に最大10個のカスタム属性またはイベントをブロックリストに追加できるようになりました。詳細については、[カスタムイベントと属性の管理]({{site.baseurl}}/user_guide/data/activation/custom_data/managing_custom_data)を参照してください。

### 新しいヘルプ記事：ユニバーサルリンクとアプリリンク {#new-help-article-universal-links-and-app-links}

AppleユニバーサルリンクとAndroidアプリリンクは、Webコンテンツとモバイルアプリ間のシームレスな移行を実現するために考案されたメカニズムです。ユニバーサルリンクはiOSに固有のものですが、AndroidアプリリンクはAndroidアプリケーションで同じ役割を果たします。

このトピックの詳細については、専用の[ユニバーサルリンクとアプリリンク]({{site.baseurl}}/user_guide/channels/email/customize/universal_links_and_app_links)の記事を参照してください。

## 新しいBrazeパートナーシップ {#new-braze-partnerships}

### Olo — チャネル拡張 {#olo-channel-extensions}

Brazeと[Olo]({{site.baseurl}}/partners/ecommerce/ordering_payments_subscription/olo)の統合により、BrazeのユーザープロファイルをOloのユーザープロファイルと一貫性を保つように更新できます。また、Oloのイベントに基づいてBrazeから適切なメッセージを送信することもできます。

### Typeform — 顧客データプラットフォーム {#typeform-customer-data-platform}

Brazeと[Typeform]({{site.baseurl}}/partners/additional_channels_and_extensions/extensions/surveys/typeform)の統合により、Typeformの回答から収集されたデータを使用してBrazeのユーザープロファイルを更新したり、Typeformでのユーザーのエンゲージメントに基づいてBrazeでメッセージングをトリガーしたり、ユーザーのTypeform回答に基づいてBrazeメッセージをパーソナライズしたりできます。

## SDKのアップデート {#sdk-updates}

以下のSDKアップデートがリリースされました。破壊的な更新は下記のとおりです。その他すべての更新は、対応するSDKの変更ログをご確認ください。

- [Web SDK v4.10.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [Web SDK v5.0.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [Android SDK 29.0.1](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [Swift SDK 7.1.0-7.2.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - `Braze.Configuration.DeviceProperty.pushDisplayOptions`は非推奨になりました。この値を指定しても効果はありません。
- [React Native SDK 8.0.0-8.1.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
    - ネイティブAndroidブリッジをBraze Android SDK 27.0.1から29.0.0に更新しました。
    - ネイティブiOSブリッジをBraze Swift SDK 6.6.0から7.0.0に更新しました。
    - `Banner` Content Cardsタイプの名前をImageOnlyに変更しました：
        - `BannerContentCard`を`ImageOnlyContentCard`に変更
        - `ContentCardTypes.BANNER`を`ContentCardTypes.IMAGE_ONLY`に変更
    - Androidでは、プロジェクトのXMLファイルにContent Cardsの`banner`という単語が含まれている場合、`image_only`に置き換える必要があります。
    - `Braze.getFeatureFlag(id)`は、フィーチャーフラグが存在しない場合に`null`を返すようになりました。
    - `Braze.Events.FEATURE_FLAGS_UPDATED`は、更新リクエストが成功または失敗で完了したとき、および現在のセッションから以前にキャッシュされたデータがあった場合の初回購読時にのみトリガーされます。
