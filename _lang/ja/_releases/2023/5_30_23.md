# 2023年5月30日リリース {#may-30-2023-release}

## Braze ナビゲーションのリニューアル

Braze のナビゲーションを更新し、コンテンツの作成やアクセスをより迅速かつ効率的に行えるようにしました。各機能は、Braze でのマーケターのワークフローに馴染みがあり、関連性の高い直感的なカテゴリに整理されています。今後数か月間は、旧ナビゲーションと新ナビゲーションを自由に切り替えることができます。変更点の詳細については、[Braze ナビゲーション]({{site.baseurl}}/user_guide/administer/personal/the_braze_dashboard)を参照してください。

## 新しいCurrentsイベント

以下のWhatsApp Currentsイベントが最近リリースされ、[メッセージエンゲージメントイベント]({{site.baseurl}}/user_guide/data/distribution/braze_currents/event_glossary/message_engagement_events)の用語集に追加されました。

メッセージ中止イベント:
- `users.messages.whatsapp.Send`
- `users.messages.whatsapp.Abort`
- `users.messages.whatsapp.Delivery`
- `users.messages.whatsapp.Failure`
- `users.messages.whatsapp.Read`
- `users.messages.whatsapp.InboundReceive`

## ブラウザ内カタログ編集とカタログセレクション

カタログでは、ブラウザ内編集と[セレクション]({{site.baseurl}}/user_guide/data/activation/catalogs/selections)がサポートされるようになりました。セレクションとは、キャンペーン内の各ユーザーに合わせてメッセージをパーソナライズするために使用できるデータのグループです。[カタログ]({{site.baseurl}}/user_guide/data/activation/catalogs)を作成した後、Brazeキャンペーンにセレクションを組み込むことで、このデータをさらに参照できます。

[`message_extras` Liquidタグ]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/advanced_filters/message_extras)を使用すると、Connected Content、カタログ、カスタム属性（言語、国など）、キャンバスエントリプロパティ、その他のデータソースからのダイナミックなデータで送信イベントにアノテーションを付け、追加データをCurrentsまたはSnowflakeデータシェアリングに送信できます。

## Brazeの新しいパートナーシップ

### Tangerine - ローカライゼーション
Brazeと[Tangerine]({{site.baseurl}}/partners/ecommerce/analytics_workflow/tangerine)の統合により、Brazeからのキャンペーンおよびインプレッションの生データをSnowflakeセキュアデータシェアリングを通じてStore360に統合できます。ブランドはこれらのキャンペーンが実店舗への来店や店内エンゲージメントに与える影響を測定できるようになります。

### Personalize.AI - ダイナミックコンテンツ
Brazeと[Personalize.AI]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize)の統合により、Personalize.AIからBrazeプラットフォームにデータをエクスポートし、メッセージのパーソナライゼーションやターゲティングに活用できます。

### Regal - メッセージング
[Regal]({{site.baseurl}}/partners/additional_channels_and_extensions/additional_channels/instant_chat/regal)とBrazeを統合することで、すべての顧客タッチポイントにわたってより一貫性のあるパーソナライズされた体験を構築できます。
- Regalでの電話の会話内容に基づいて、Brazeから最適な次のメールまたはプッシュ通知を送信します。
- 価値の高い顧客がBrazeからのマーケティングメールをクリックしたがコンバージョンしなかった場合に、Regalでの通話をトリガーします。

### Sendbird - メッセージング
Brazeと[Sendbird]({{site.baseurl}}/partners/additional_channels_and_extensions/additional_channels/instant_chat/sendbird)の統合により、企業ユーザーは以下のことが可能になります。
{% multi_lang_include partners/instant_chat/sendbird_integration_bullets.md %}

### Fresh Relevance - ダイナミックコンテンツ
Brazeと[Fresh Relevance]({{site.baseurl}}/partners/home)の統合により、トリガーメールにパーソナライズされたコンテンツを含めることができます。顧客が閲覧した商品や同じカテゴリのアイテムに基づく商品レコメンデーション、価格低下、再入荷、多段階ブラウジング、カート放棄メッセージなどの高度なトリガーメールキャンペーンの送信が可能です。

### Smartling - ローカライゼーション
Brazeと[Smartling]({{site.baseurl}}/partners/message_personalization/localization/smartling)の統合により、メールテンプレートやContent Blocksを翻訳できます。Smartlingは翻訳中に言語専門家にビジュアルコンテキストを提供することで、エラーを減らし品質を維持します。

### SalesWings - 分析
Brazeと[SalesWings]({{site.baseurl}}/partners/data_and_analytics/analytics/saleswings)の統合により、2つのプラットフォーム間でデータを柔軟に同期し、リードスコアリングやリードグレーディング機能でリードを評価できます。

### Kognitiv Inspire - ロイヤルティ
Brazeと[Kognitiv]({{site.baseurl}}/partners/data_and_analytics/loyalty/kognitiv)の統合により、ロイヤルティ戦略を実装・評価でき、革新的な機能やカスタマイズされた会員コミュニケーションを提供してプログラムの効果を向上させます。

### OneTrust - データプライバシー
Brazeと[OneTrust]({{site.baseurl}}/partners/data_and_analytics/data_privacy/onetrust)の統合により、OneTrustのワークフロービルダーを使用してプロダクトのセキュリティワークフローを作成できます。

### Stylitics - ダイナミックコンテンツ
Brazeと[Stylitics]({{site.baseurl}}/partners/message_personalization/dynamic_content/visual_and_interactive_content/stylitics)の統合により、既存のメールキャンペーンを魅力的で関連性の高いバンドルコンテンツで強化し、パーソナライズされた顧客体験を実現できます。

## SDKの更新

最新のSDK更新がリリースされました。破壊的な更新はSDK更新セクションに記載されています。その他のすべての更新は、対応するSDKの変更ログに記載されています。

- [Swift SDK 6.1.0-6.2.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#620)
- [Web SDK 4.7.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md#471)
- [React Native SDK 5.0.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md#500)
  - ネイティブiOSブリッジをBraze Swift SDK 5.13.0から6.2.0に更新しました。
  - バージョン2.0.0から何も実行しなくなった`setSDKFlavor`と`setMetadata`を削除しました。
  - iOSでは、SDK初期化時に`Braze.Configuration`オブジェクトを使用してこれらのフィールドを設定する必要があります。
  - Androidでは、braze.xmlファイルを使用してこれらのフィールドを設定する必要があります。
- [Cordova SDK 4.0.0-5.0.0](https://github.com/braze-inc/braze-cordova-sdk/blob/master/CHANGELOG.md#500)
  - **Cordova SDK 4.0.0**
		- AppboyのインスタンスをBrazeに名称変更しました。
			- プロジェクトが新しい命名規則に適切に移行されるようにするには、プロジェクト内の以下のインスタンスを確認して置換してください:
				- プラグインの名前が`cordova-plonugin-appboy`から`cordova-plugin-braze`に変更されました。
					- Cordovaプラグインを実行し、`cordova-plugin-appboy`を削除してから、[README](https://github.com/braze-inc/braze-cordova-sdk/blob/master/README.md)の手順に従ってプラグインを再追加してください。
				- このGitHubリポジトリは https://github.com/braze-inc/braze-cordova-sdk に移動しました。
				- プロジェクトのconfig.xmlファイルで、各設定プロパティキーのcom.appboyをcom.brazeに名称変更してください。
				- JavaScriptクラスインターフェイス`AppboyPlugin`は`BrazePlugin`に名称変更されました。
		- Braze Android SDK 25.0.0に更新しました。
		- Braze Swift SDK 5.13.0に更新しました。
			- この更新は、Content Cardsのクリックを記録する際にバージョン2.33.0で導入されたiOSの動作を修正します。`logContentCardClicked`を呼び出すと、クリックイベントを送信して関連するURLフィールドにリダイレクトする代わりに、メトリクス用のクリックイベントのみを送信するようになりました。
  - **Cordova SDK 5.0.0**
		- これらのフィーチャーフラグメソッドがコールバックパラメーターを使用する代わりにPromiseを返すように更新しました
			- `getAllFeatureFlags()`
			- `getFeatureFlag(id)`
			- `getFeatureFlagBooleanProperty(id, key)`
			- `getFeatureFlagStringProperty(id, key)`
			- `getFeatureFlagNumberProperty(id, key)`
- [Unreal SDK 2.5.0](https://github.com/braze-inc/braze-unreal-sdk/blob/master/CHANGELOG.md#250)
- [Unity SDK 4.1.0](https://github.com/braze-inc/braze-unity-sdk/blob/master/CHANGELOG.md#410)
