# 2023年12月12日リリース {#december-12-2023-release}

## Android プッシュ連携の更新 {#updates-to-android-push-integration}

2023年6月20日、Google はAndroid アプリにプッシュ通知を送信するための Cloud Messaging API を廃止しました。[標準的な Android プッシュ連携]({{site.baseurl}}/developer_guide/push_notifications?sdktab=android)では、代わりに Google の Firebase Cloud Messaging API を設定する方法を説明しています。

Google の Cloud Messaging API の廃止に関する詳細については、[Firebase FAQ](https://firebase.google.com/support/faq#fcm-23-deprecation) を参照してください。

## 堅牢なチャネル {#robust-channels}

### WhatsApp レスポンスメッセージング {#whatsapp-response-messaging}

{% multi_lang_include release_type.md release="General availability" %}

キャンペーンまたはキャンバスで [WhatsApp メッセージを作成する]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/create#response-messages)際に、24時間以内にユーザーのWhatsAppメッセージに返信するレスポンスメッセージを作成できます。レスポンスメッセージングは、オプトインキャンペーンなど、ブランドとユーザー間のインタラクションを促進するキャンバスで特に役立ちます。

### WhatsApp フリークエンシーキャップ {#whatsapp-frequency-capping}

{% multi_lang_include release_type.md release="General availability" %}

WhatsAppに対して[フリークエンシーキャップルール]({{site.baseurl}}/user_guide/engagement_tools/campaigns/building_campaigns/rate-limiting#frequency-capping)を設定できるようになりました。フリークエンシーキャップはキャンペーンまたはキャンバスコンポーネントの送信レベルで適用され、各ワークスペースから**設定** > **フリークエンシーキャップルール**で設定できます。

## データの柔軟性 {#data-flexibility}

### コンバージョンダッシュボード {#conversions-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

[コンバージョンダッシュボード]({{site.baseurl}}/user_guide/analytics/dashboards/conversions)では、さまざまなアトリビューション方法を使用して、キャンペーン、キャンバス、チャネル全体のコンバージョンを分析できます。コンバージョンを測定する際に、期間、コンバージョンイベント、コンバージョンウィンドウを指定できます。

### メールインサイトレポート {#email-insights-reports}

{% multi_lang_include release_type.md release="General availability" %}

[メールパフォーマンスダッシュボード]({{site.baseurl}}/user_guide/data_and_analytics/analytics/email_performance_dashboard#email-insights-dashboard)内に、2つの新しいレポートを含む新しいタブ「メールインサイト」が追加されました。

- **メールボックスプロバイダー別エンゲージメント：** メールボックスプロバイダー別のクリック数と開封数を表示します。メールボックスプロバイダーを選択して、特定の受信ドメインにドリルダウンできます。
- **曜日別エンゲージメント：** ユーザーがメールにエンゲージしているタイミングを表示します。

### 購読グループ時系列グラフの更新 {#update-to-subscription-group-timeseries-graph}

{% multi_lang_include release_type.md release="General availability" %}

**購読グループ**ページに表示される**購読グループ時系列**グラフに、メールアドレスや電話番号ごとではなく、ユーザーごとの購読数が表示されるようになりました。これにより、ダッシュボードの他の領域でBrazeが統計を計算する方法との整合性が向上しています。

## AI & ML オートメーション {#ai-ml-automation}

### AI アイテムレコメンデーション {#ai-item-recommendations}

{% multi_lang_include release_type.md release="General availability" %}

[AI アイテムレコメンデーション]({{site.baseurl}}/user_guide/brazeai/item_recommendations/creating_recommendations/ai)は、ディープラーニングベースの商品レコメンデーションエンジンで、ユーザーの集合的な購買行動を活用してアイテムをレコメンドします。AI アイテムレコメンデーションを使用すると、最も人気のある商品を計算したり、特定のカタログに対してパーソナライズされた AI レコメンデーションを作成したりできます。レコメンデーションを作成した後、パーソナライゼーションを使用してそれらの商品をメッセージに挿入できます。

## Brazeの新しいパートナーシップ {#new-braze-partnerships}

### Facebook Lead Ads via Zapier – リードキャプチャ {#facebook-lead-ads-via-zapier-leads-capture}

[Facebook Lead Ads integration via Zapier]({{site.baseurl}}/partners/data_and_analytics/leads_capture/facebook_via_zapier)を使用すると、FacebookからBrazeにリードをインポートし、リードがキャプチャされたときにカスタムイベントを追跡できます。

### SmarterSends – メッセージテンプレート {#smartersends-message-templates}

Brazeと[SmarterSends]({{site.baseurl}}/partners/message_orchestration/templates/smartersends)のパートナーシップにより、Brazeの機能と分散ユーザーが所有するハイパーローカライズされたコンテンツを組み合わせて、マーケティングキャンペーンを強化できます。

### Recurly – 決済 {#recurly-payments}

[Recurly]({{site.baseurl}}/partners/ecommerce/ordering_payments_subscription/recurly)とBrazeの統合により、購読データをBrazeと共有するプロセスが簡素化され、顧客へのターゲットコミュニケーションが可能になります。

## SDKの更新 {#sdk-updates}

最新のSDK更新がリリースされました。破壊的な更新はSDK更新セクションに記載されています。その他の更新はすべて、対応するSDKチェンジログに記載されています。

- [Flutter SDK 8.0.0-8.1.0](https://pub.dev/packages/braze_plugin/changelog)
  - ネイティブAndroidブリッジをBraze Android SDK 27.0.1から29.0.1に更新しました。
  - ネイティブiOSブリッジをBraze Swift SDK 6.6.1から7.2.0に更新しました。
  - フィーチャーフラグメソッドの動作を変更しました。
    - `BrazePlugin.getFeatureFlagByID(String id)` は、フィーチャーフラグが存在しない場合に `null` を返すようになりました。
    - `BrazePlugin.subscribeToFeatureFlags(void Function(List<BrazeFeatureFlag>) onEvent))` は、以下の状況でのみトリガーされます：
      - リフレッシュリクエストが成功または失敗で完了した場合。
      - 現在のセッションから以前にキャッシュされたデータがある場合の初回サブスクリプション時。
  - サポートされるAndroid SDKの最小バージョンは21です。
