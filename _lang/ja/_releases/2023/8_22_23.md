# 2023年8月22日リリース {#august-22-2023-release}

## Shopifyカタログ {#shopify-catalogs}

Shopifyカタログを使用すると、ShopifyストアからBrazeカタログに製品をインポートでき、製品データを取り込むプロセスを自動化してメッセージのパーソナライゼーションを深めることができます。最新の製品の詳細と情報を使用して、カート放棄や注文確認などを強化できます。

## メールによるユーザーの統合 {#merging-users-by-email}

`/users/merge`エンドポイントを使用して、[メールでユーザーを統合]({{site.baseurl}}/api/endpoints/user_data/post_users_merge/#merging-users-by-email)できるようになりました。

{% multi_lang_include alerts/early_access_beta_alert.md feature='メールによってユーザーを統合し、識別子が不一致の場合に`/users/merge`エンドポイントを使用する機能' %}

## WhatsAppのベストプラクティス {#best-practices-for-whatsapp}

WhatsAppメッセージを送信する前に、推奨される[ベストプラクティス]({{site.baseurl}}/user_guide/channels/whatsapp/best_practices/)を参照して、電話品質の高評価を維持し、ブロックやレポートを回避し、ユーザーのオプトインおよびオプトアウトを管理できます。

## ドメインレピュテーション {#domain-reputation}

配信到達性センターで、スパムフォルダーへのフィルタリングを回避するために[ドメインレピュテーション]({{site.baseurl}}/user_guide/data_and_analytics/analytics/deliverability_center/#domain-reputation)を表示および監視できるようになりました。

## カスタマイズガイド {#customization-guides}

Developer Portalの再編成をお知らせします。[Content Cards]({{site.baseurl}}/developer_guide/content_cards/)を皮切りに、SDKのカスタマイズオプションが専用のカスタマイズガイドに統合されました。この変更により、詳細な手順へのアクセスが効率化され、特定のニーズに合わせた体験を簡単にカスタマイズできるようになります。

## キャンバスでのカード作成 {#card-creation-in-canvas}

カードが作成されるタイミングを指定することで、Brazeが新しいContent Cards キャンペーンおよびキャンバスステップのオーディエンス適格性とパーソナライゼーションを評価するタイミングを選択できます。

{% multi_lang_include alerts/early_access_beta_alert.md feature="Control over card creation in Canvas steps" %}

## ワークスペースへのコピー {#copying-to-workspaces}

[ワークスペース間でキャンペーンをコピー]({{site.baseurl}}/copying_to_workspaces/)すると、別のワークスペースにあるキャンペーンのコピーを利用して、メッセージの作成をすぐに開始できます。このコピーは、編集して起動するまで下書きとして残り、成功したメッセージング戦略を維持し、さらに発展させるのに役立ちます。

{% multi_lang_include alerts/early_access_beta_alert.md feature='Copying campaigns across workspaces' %}

## Push Max

[Push Max]({{site.baseurl}}/user_guide/channels/push/platform_specific_resources/android/push_max/)は、Androidプッシュ通知を増幅し、失敗したプッシュ通知を追跡して、ユーザーが受信しやすいタイミングで再送信します。Push Maxについて学び、この機能を使用してAndroidプッシュ通知の[中国のOEMデバイス]({{site.baseurl}}/user_guide/channels/push/best_practices/chinese_push_deliverability/)への配信到達性を向上させる方法をご確認ください。

{% multi_lang_include alerts/early_access_beta_alert.md feature='Push Max' %}
