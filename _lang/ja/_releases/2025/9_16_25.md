# 2025年9月16日リリース {#september-16-2025-release}

## データの柔軟性 {#data-flexibility}

### Braze データプラットフォーム {#braze-data-platform}

Braze データプラットフォームは、カスタマーライフサイクル全体でパーソナライズされたインパクトのあるエクスペリエンスを創造するための、包括的でコンポーザブルなデータ機能とパートナー連携のセットです。データに関する3つのジョブについて詳しくご覧ください：

- [データの統一]({{site.baseurl}}/user_guide/data/unification)
- [データの活用]({{site.baseurl}}/user_guide/data/activation)
- [データの配信]({{site.baseurl}}/user_guide/data/distribution)

### カスタムバナープロパティ {#custom-banner-properties}

{% multi_lang_include release_type.md release="Early access" %}

バナーキャンペーンのカスタムプロパティを使用して、SDKを通じてキーバリューデータを取得し、アプリの動作や外観を変更できます。詳しくは、[カスタムバナープロパティ]({{site.baseurl}}/developer_guide/banners/placements#custom-properties)を参照してください。

### トークン認証 {#token-authentication}

{% multi_lang_include release_type.md release="General availability" %}

BrazeのConnected Contentを使用する場合、特定のAPIではユーザー名とパスワードの代わりにトークンが必要になることがあります。Brazeは、[トークン認証ヘッダー値]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/connected_content/making_an_api_call#using-token-authentication)を保持する認証情報を保存できます。

### プロモーションコード {#promotion-codes}

ユーザー更新ステップを通じて、プロモーションコードをユーザープロファイルに保存できます。詳細については、[ユーザープロファイルへのプロモーションコードの保存]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/sources/promotion_codes#save-to-profile)を参照してください。

## 創造性を引き出す {#unlocking-creativity}

### Braze Pilot

[Braze Pilot]({{site.baseurl}}/user_guide/get_started/braze_pilot)は、AndroidとiOS向けに公開されているアプリで、Brazeダッシュボードからスマートフォンにメッセージを送信できます。アプリのダウンロード、Brazeダッシュボードへの接続の初期化、設定の完了までのウォークスルーについては、[Braze Pilotを始める]({{site.baseurl}}/user_guide/get_started/braze_pilot/getting_started)をご覧ください。

## 新しいBrazeパートナーシップ {#new-braze-partnerships}

### Blings - ビジュアル＆インタラクティブコンテンツ {#blings-visual-and-interactive-content}

[Blings]({{site.baseurl}}/partners/blings)は、次世代のパーソナライズド動画プラットフォームであり、リアルタイム、インタラクティブ、データドリブン型の動画体験をチャネル横断で大規模に提供することを可能にします。

### Shopify標準連携とサードパーティツール {#shopify-standard-integration-with-third-party-tool}

Shopifyオンラインストアの場合は、Brazeの標準的な連携方法を使用して、サイトでBraze SDKをサポートすることを推奨します。

ただし、Google Tag Managerのようなサードパーティツールを使用したい場合もあるかと思いますので、その方法についてのガイドをご用意しました。始めるには、[Shopify：サードパーティタギング]({{site.baseurl}}/shopify_standard_integration_third_party_tagging)を参照してください。

## SDKのアップデート {#sdk-updates}

以下のSDKアップデートがリリースされました。破壊的な更新は下記のとおりです。その他すべての更新は、対応するSDKの変更ログをご確認ください。

- [Braze Flutter SDK 15.0.0](https://github.com/braze-inc/braze-flutter-sdk/blob/main/CHANGELOG.md#1500)
    - ネイティブAndroidブリッジをBraze Android SDK `36.0.0`から`39.0.0`に更新しました。
    - ネイティブiOSブリッジをBraze Swift SDK `12.0.0`から`13.2.0`に更新しました。これにはXcode 26のサポートが含まれます。

- [Braze Swift SDK 7.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1300)
  - `13.0.0+` SemVer仕様のリリースを必要とするようにBraze Swift SDKバインディングを更新しました。これにより、Braze SDKの`13.0.0`から`14.0.0`未満までのあらゆるバージョンとの互換性が確保されます。
