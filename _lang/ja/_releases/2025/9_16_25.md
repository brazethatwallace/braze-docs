# 2025年9月16日リリース {#september-16-2025-release}

## データの柔軟性 {#data-flexibility}

### Braze Data Platform

Braze Data Platformは、包括的で構成可能なデータ機能とパートナー連携のセットであり、カスタマーライフサイクル全体にわたってパーソナライズされたインパクトのある体験を構築できるようにします。データに関連する3つのジョブについて詳しくは、以下をご覧ください。

- [データ統合]({{site.baseurl}}/user_guide/data/unification)
- [データアクティベーション]({{site.baseurl}}/user_guide/data/activation)
- [データ配信]({{site.baseurl}}/user_guide/data/distribution)

### カスタムバナープロパティ {#custom-banner-properties}

{% multi_lang_include release_type.md release="Early access" %}

バナーキャンペーンのカスタムプロパティを使用して、SDKを通じてキーと値のデータを取得し、アプリの動作や外観を変更できます。詳しくは、[カスタムバナープロパティ]({{site.baseurl}}/developer_guide/banners/placements#custom-properties)を参照してください。

### トークン認証 {#token-authentication}

{% multi_lang_include release_type.md release="General availability" %}

Braze Connected Contentを使用する際、一部のAPIではユーザー名とパスワードの代わりにトークンが必要になる場合があります。Brazeは[トークン認証ヘッダー値]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content/making_an_api_call#using-token-authentication)を保持する認証情報を保存できます。

### プロモーションコード {#promotion-codes}

ユーザー更新ステップを通じて、プロモーションコードをユーザープロファイルに保存できます。詳しくは、[プロモーションコードをユーザープロファイルに保存する]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/sources/promotion_codes/manage#save-to-profile)を参照してください。

## 創造性を引き出す {#unlocking-creativity}

### Braze Pilot

[Braze Pilot]({{site.baseurl}}/user_guide/get_started/braze_pilot)は、AndroidとiOS向けに公開されているアプリで、Brazeダッシュボードからスマートフォンにメッセージを送信できます。アプリのダウンロード、Brazeダッシュボードへの接続の初期化、設定の完了については、[Braze Pilotを始める]({{site.baseurl}}/user_guide/get_started/braze_pilot/getting_started)をご覧ください。

## Brazeの新しいパートナーシップ {#new-braze-partnerships}

### Blings - ビジュアル＆インタラクティブコンテンツ {#blings-visual-and-interactive-content}

[Blings]({{site.baseurl}}/partners/blings)は、次世代のパーソナライズド動画プラットフォームであり、リアルタイムでインタラクティブかつデータドリブン型の動画体験を、大規模にチャネル横断で提供できます。

### Shopifyスタンダード連携とサードパーティツール {#shopify-standard-integration-with-third-party-tool}

Shopifyオンラインストアの場合、サイトでBraze SDKをサポートするために、Brazeのスタンダード連携方法を使用することを推奨します。

ただし、Google Tag Managerなどのサードパーティツールの使用を希望する場合もあるかと思いますので、その方法に関するガイドをまとめました。詳しくは、[Shopify：サードパーティタグ設定]({{site.baseurl}}/shopify_standard_integration_third_party_tagging)を参照してください。

## SDKの更新 {#sdk-updates}

最新のSDK更新がリリースされました。破壊的な更新はSDK更新セクションに記載されています。その他すべての更新は、対応するSDKの変更ログに記載されています。

- [Braze Flutter SDK 15.0.0](https://github.com/braze-inc/braze-flutter-sdk/blob/main/CHANGELOG.md#1500)
    - ネイティブAndroidブリッジをBraze Android SDK `36.0.0`から`39.0.0`に更新しました。
    - ネイティブiOSブリッジをBraze Swift SDK `12.0.0`から`13.2.0`に更新しました。これにはXcode 26のサポートが含まれています。

- [Braze Swift SDK 7.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1300)
  - Braze Swift SDKバインディングを更新し、`13.0.0+` SemVerの範囲からのリリースを必須としました。これにより、`13.0.0`から`14.0.0`未満までの任意のバージョンのBraze SDKとの互換性が確保されます。
