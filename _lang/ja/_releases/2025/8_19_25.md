# 2025年8月19日リリース {#august-19-2025-release}

## キャンバスコンテキストへのタイムゾーン一貫性の標準化 {#time-zone-consistency-standardization-to-canvas-context}

{% multi_lang_include release_type.md release="Early access" %}

[キャンバスコンテキストステップの早期アクセス]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/context)に参加している場合、アクションベースのキャンバスにおけるトリガーイベントプロパティからの日時型のすべてのタイムスタンプは、常に [UTC](https://en.wikipedia.org/wiki/Coordinated_Universal_Time) に正規化されます。詳細については、[タイムゾーン一貫性の標準化]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/context#time-zone-consistency-standardization)を参照してください。

## データの柔軟性 {#data-flexibility}

### セルフサーブカスタムドメイン {#self-serve-custom-domains}

{% multi_lang_include release_type.md release="General access" %}

[セルフサーブカスタムドメイン]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/custom_domains)を使用すると、SMS、RCS、WhatsApp用の独自のカスタムドメインをBrazeダッシュボードから直接設定・管理できます。最大10個のカスタムドメインを1か所で簡単に追加、監視、管理できます。

### セグメントファネル統計 {#segment-funnel-statistics}

[ファネル統計を表示]({{site.baseurl}}/user_guide/engagement_tools/segments/creating_a_segment#viewing-funnel-statistics)を選択すると、そのフィルターグループの統計情報が表示され、追加した各フィルターがセグメント統計に与える影響を確認できます。その時点までのすべてのフィルターでターゲットされているユーザーの推定数と割合が表示されます。フィルターグループの統計が表示された後は、フィルターを変更するたびに自動的に更新されます。

### プッシュ通知向け `/campaigns/details` エンドポイントの新しいレスポンスフィールド {#new-response-fields-for-campaignsdetails-endpoint-for-push-notifications}

プッシュ通知の `messages` レスポンスに、2つの新しいフィールドが追加されました。

- `image_url`: Android通知画像、iOS通知画像、またはWebプッシュアイコン画像の画像URLです。
- `large_image_url`: Android ChromeおよびWindows Webプッシュアクション用のWeb通知画像URLです。

### PIIフィールドの定義 {#defining-pii-fields}

特定のフィールドを選択して[PIIフィールドとして定義]({{site.baseurl}}/user_guide/administer/global/admin_settings/security_settings#view-pii)することは、Brazeダッシュボード上でユーザーが閲覧できる内容にのみ影響し、PIIフィールド内のエンドユーザーデータの処理方法には影響しません。

法務チームに相談し、[データ保持]({{site.baseurl}}/api/data_retention)に関する規制を含め、貴社に適用されるプライバシー規制やポリシーとダッシュボードの設定を整合させてください。

### レポートビルダーのダウンロードリンクの共有 {#sharing-a-report-builder-download-link}

**共有**を選択し、**リンクを共有**または**メールを送信またはスケジュール**を選択することで、レポートへの[ダッシュボードリンクを共有]({{site.baseurl}}/user_guide/analytics/reporting/report_builder#sharing-a-report)できます。

## クリエイティビティを引き出す {#unlocking-creativity}

### ドラッグ＆ドロップメールのカスタムヘッドタグ {#custom-head-tags-for-drag-and-drop-emails}

`<head>` タグを使用して、メールメッセージにCSSやメタデータを追加できます。たとえば、これらのタグを使用してスタイルシートやファビコンを追加できます。`<head>` タグではLiquidがサポートされています。

## 堅牢なチャネル {#robust-channels}

### あいまいなオプトアウトのベストプラクティス {#fuzzy-out-out-best-practices}

あいまいなオプトアウトメッセージを慎重に設定し、購読者にとって明確でコンプライアンスに準拠したポジティブな体験を作成するための[ベストプラクティスセクション]({{site.baseurl}})を追加しました。

### WhatsApp Flows

{% multi_lang_include release_type.md release="Early access" %}

[WhatsApp Flows]({{site.baseurl}}/whatsapp_flows)は、既存のWhatsAppチャネルの拡張機能であり、インタラクティブでダイナミックなメッセージング体験を作成できます。

### WhatsApp受信製品質問 {#whatsapp-inbound-product-questions}

ユーザーは、製品またはカタログメッセージに対して[製品に関する質問]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/product_messages#receiving-inbound-product-questions)で応答できます。これらは受信メッセージとして届き、アクションパスで分類できます。

さらに、Brazeはこれらの質問から製品IDとカタログIDを抽出するため、応答を自動化したり、質問を別のチーム（カスタマーサポートなど）に送信したりする場合に、それらの詳細を含めることができます。

## AIとML オートメーション {#ai-and-ml-automation}

### 新しいBrazeAI<sup>TM</sup>ユースケース記事 {#new-brazeai-use-case-articles}

BrazeAI<sup>TM</sup>を最大限に活用するための新しいユースケース記事を追加しました。これらのガイドでは、AIをエンゲージメント戦略に適用する実践的な方法を紹介しています。

- [解約予測]({{site.baseurl}}/user_guide/brazeai/predictive_suite/predictive_churn/use_case): 解約リスクのある顧客を特定し、早期にアクションを起こします。
- [予測イベント]({{site.baseurl}}/user_guide/brazeai/predictive_suite/predictive_events/use_case): 主要なユーザーアクションを予測し、リアルタイムで体験を形成します。
- [レコメンデーション]({{site.baseurl}}/user_guide/brazeai/item_recommendations/use_case): 顧客行動に基づいて、より関連性の高いコンテンツや製品を提供します。

### MCPサーバー {#mcp-server}

{% multi_lang_include release_type.md release="Beta" %}

[Braze MCPサーバー]({{site.baseurl}}/user_guide/brazeai/mcp_server)は、安全で読み取り専用の接続であり、ClaudeやCursorなどのAIツールが非PIIのBrazeデータにアクセスして、質問への回答、トレンドの分析、インサイトの提供を、データを変更することなく行えるようにします。

## SDKの更新 {#sdk-updates}

最新のSDK更新がリリースされました。破壊的な更新はSDK更新セクションに記載されています。その他の更新については、対応するSDKの変更履歴をご確認ください。

- [Swift SDK 13.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - `BrazeSDKAuthDelegate.braze(_:sdkAuthenticationFailedWithError:)`の機能を拡張し、「Optional」認証エラーでもトリガーされるようになりました。
        - デリゲートメソッド`BrazeSDKAuthDelegate.braze(_:sdkAuthenticationFailedWithError:)`は、「Required」と「Optional」の両方の認証エラーでトリガーされるようになりました。
        - 「Required」のSDK認証エラーのみを処理したい場合は、このデリゲートメソッドの実装内で`BrazeSDKAuthError.optional`がfalseであることを確認するチェックを追加してください。
    - `Braze.Configuration.sdkAuthentication`の使用方法を修正し、有効化された際に正しく反映されるようにしました。
        - 以前は、この設定値はSDKによって使用されず、トークンが存在する場合は常にリクエストに付与されていました。
        - 現在は、この設定が有効な場合にのみ、SDKは送信ネットワークリクエストにSDK認証トークンを付与します。
    - `Braze.FeatureFlag`のすべてのプロパティおよび`Braze.Banner`のすべてのプロパティのセッターが`private`に変更されました。これらのクラスのプロパティは読み取り専用になりました。
    - バージョン`11.4.0`で非推奨となった`Braze.Banner.id`プロパティが削除されました。
        - 代わりに、`Braze.Banner.trackingId`を使用してバナーのキャンペーントラッキングIDを取得してください。
- [React Native SDK 16.0.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
    - ネイティブAndroid SDKのバージョンバインディングを[Braze Android SDK 36.0.0から37.0.0](https://github.com/braze-inc/braze-android-sdk/compare/v36.0.0...v37.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed)に更新しました。
    - ネイティブSwift SDKのバージョンバインディングを[Braze Swift SDK 12.0.0から13.0.0](https://github.com/braze-inc/braze-swift-sdk/compare/12.0.0...13.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed)に更新しました。
        - `sdkAuthenticationError`イベントは、「Required」と「Optional」の両方の認証エラーでトリガーされるようになりました。
- [Xamarin SDK 7.0.0](https://github.com/braze-inc/braze-xamarin-sdk/blob/7.0.0/CHANGELOG.md)
    - iOSおよびAndroidバインディングに.NET 9.0のサポートを追加しました。
        - これにより、.NET 8.0のサポートが削除されました。
        - [iOSの最小バージョン12.2](https://learn.microsoft.com/en-us/dotnet/maui/whats-new/dotnet-9?view=net-maui-9.0)が必要です。
    - Androidバインディングを[Braze Android 32.0.0から37.0.0](https://github.com/braze-inc/braze-android-sdk/compare/v32.0.0...v37.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed)に更新しました。
    - iOSバインディングを[Braze Swift SDK 10.0.0から12.1.0](https://github.com/braze-inc/braze-swift-sdk/compare/10.0.0...12.1.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed)に更新しました。
    - このリリースにはバナー機能のAPIが含まれていますが、現時点ではこのSDKで完全にはサポートされていません。.NET MAUIアプリでバナーを使用する場合は、アプリケーションに統合する前にカスタマーサポートマネージャーにお問い合わせください。
- [Cordova SDK 13.0.0](https://github.com/braze-inc/braze-cordova-sdk/blob/master/CHANGELOG.md#1300)
    - `enableSdk`メソッドの内部iOS実装を、Swift SDKで非推奨となった`_requestEnableSDKOnNextAppRun`の代わりに`setEnabled`を使用するよう更新しました。
    - このメソッドの呼び出しで、効果を反映するためにアプリの再起動が不要になりました。SDKは、このメソッドが実行されるとすぐに有効化されます。
    - ネイティブAndroidブリッジを[Braze Android SDK `36.0.0`から`37.0.0`](https://github.com/braze-inc/braze-android-sdk/compare/v36.0.0...v37.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed)に更新しました。
