# 2025年2月4日リリース {#february-4-2025-release}

## Braze ドキュメントの改善 {#braze-docs-improvements}

### データ＆分析の刷新 {#data-and-analytics-revamp}
お探しの情報を見つけやすくするため、以前は「データ＆分析」の下にまとめられていた記事を[データ]({{site.baseurl}}/user_guide/data/)と[分析]({{site.baseurl}}/user_guide/analytics/)に分離しました。

### 開発者ガイド {#developer-guide}
[Braze 開発者ガイド]({{site.baseurl}}/developer_guide/home/)の全ドキュメントを大幅にクリーンアップし、複数のページに分散していた「ハウツー」記事を1つのページに統合しました。

また、新しい[SDKリファレンスページ]({{site.baseurl}}/developer_guide/references/)では、各Braze SDKのすべてのリファレンスドキュメントとリポジトリが一覧で確認できます。

#### Unreal Engine Braze SDK
Unreal Engine Braze SDKのGitHubリポジトリのREADMEからすべてのコンテンツを[Braze Docsの専用セクション]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=unreal%20engine)に移行し、書き直しました。

## データの柔軟性 {#data-flexibility}

### API使用状況ダッシュボード {#api-usage-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

[API使用状況ダッシュボード]({{site.baseurl}}/user_guide/analytics/dashboards/api_usage/)を使用すると、Brazeへの受信REST APIトラフィックを監視して、REST APIの使用傾向を把握し、潜在的な問題をトラブルシューティングできます。

### カスタム属性にタグを追加する {#adding-tags-to-custom-attributes}

{% multi_lang_include release_type.md release="General availability" %}

「Manage Events, Attributes, Purchases」権限があれば、カスタム属性の作成後に[タグを追加]({{site.baseurl}}/user_guide/data/custom_data/custom_attributes/#adding-tags)できます。追加したタグを使用して、属性のリストをフィルタリングできます。

### カタログセレクションと非同期カタログフィールドエンドポイント {#catalog-selections-and-async-catalog-fields-endpoints}

{% multi_lang_include release_type.md release="General availability" %}

以下のエンドポイントが一般提供になりました。
* [POST: カタログフィールドの作成]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/post_create_catalog_fields/)
* [DELETE: カタログフィールドの削除]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/delete_catalog_field/)
* [DELETE: カタログセレクションの削除]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/delete_catalog_selection/)
* [POST: カタログセレクションの作成]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/post_create_catalog_selections/)

### メールアドレスを使用してキャンペーンやキャンバスをトリガーする {#using-an-email-address-to-trigger-campaigns-or-canvases}

{% multi_lang_include release_type.md release="General availability" %}

[キャンペーン]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/target_users/)や[キャンバス]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas/#step-13-set-your-target-entry-audience)をトリガーする際に、メールアドレスで受信者を指定できるようになりました。

### 電話番号を使用してAPI経由でユーザーを識別する {#using-a-phone-number-to-identify-a-user-via-the-api}

{% multi_lang_include release_type.md release="General availability" %}

[`/users/identify` APIエンドポイント]({{site.baseurl}}/api/endpoints/user_data/post_user_identify/)を通じてユーザーを識別する際に、エイリアスやメールアドレスに加えて電話番号も使用できるようになりました。

### SAMLトレースを取得する {#getting-a-saml-trace}
サポートチームとSAML SSOに関する問題をより効率的に解決できるように、[SAMLトレースの取得手順]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/saml_sso_setup/#obtaining-a-saml-trace)を追加しました。

### 地域別データセンター {#region-specific-data-centers}
Brazeが新しい地域へのサービス提供を拡大するのに伴い、運用アプローチを明確にするための[Brazeデータセンターに関する記事]({{site.baseurl}}/user_guide/data/infrastructure/data_centers/)を追加しました。


## 創造性を引き出す {#unlocking-creativity}

### 値下げ通知と再入荷通知 {#price-drop-notifications-and-back-in-stock-notifications}

{% multi_lang_include release_type.md release="General availability" %}

キャンバスとカタログで[再入荷通知]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/back_in_stock_notifications/)を設定することで、商品の再入荷を顧客に通知できるようになりました。

また、カタログとキャンバスで[値下げ通知]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/price_drop_notifications/)を設定して、商品の価格が下がったときに顧客に通知することもできます。

### セレクションのプレビュー {#preview-for-selection}

{% multi_lang_include release_type.md release="General availability" %}

セレクションを作成した後、ランダムなユーザーまたは特定のユーザーに対して[セレクションが返す結果を確認]({{site.baseurl}}/user_guide/data/activation/catalogs/selections/#test-and-preview)できます。

### Liquidを含むカタログアイテムのテンプレート化 {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="General availability" %}

[Liquidを含むカタログアイテムをテンプレート化]({{site.baseurl}}/user_guide/data/activation/catalogs/using_catalogs/#using-liquid)できます。

### キャンバステンプレート {#canvas-templates}
[好みの調査によるユーザーのオンボーディング]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/preference_survey/)と、[ダブルオプトインによるメール登録の作成]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/email_signup/)のための新しいキャンバステンプレートを追加しました。

### B2B向けSalesforce Sales Cloudによるリード管理 {#managing-leads-with-salesforce-sales-cloud-for-b2b}
B2BマーケターがBrazeを活用する方法の1つとして、Salesforce Sales Cloudとの統合があります。この[ユースケース]({{site.baseurl}}/user_guide/get_started/b2b_use_cases/b2b_salesforce_sales_cloud/)の実装方法について詳しくご覧ください。

## 強力なチャネル {#robust-channels}

### 抑制リスト {#suppression-lists}

{% multi_lang_include release_type.md release="Beta" %}

[抑制リスト]({{site.baseurl}}/user_guide/audience/suppression_lists/)は、メッセージを一切受信しないユーザーグループを指定します。管理者は、セグメンテーションと同様にセグメントフィルターを使用して抑制リストを作成し、ユーザーグループを絞り込むことができます。

## 新しいBrazeパートナーシップ {#new-braze-partnerships}

### Constructor - ダイナミックコンテンツ {#constructor-dynamic-content}
[Constructor]({{site.baseurl}}/partners/ecommerce/product_search_recommendations/constructor/)は、AIと機械学習を活用して、eコマースおよび小売のWebサイト向けにパーソナライズされた検索、おすすめ、ブラウジング体験を提供する検索・商品発見プラットフォームです。

### Trustpilot - ダイナミックコンテンツ {#trustpilot-dynamic-content}
[Trustpilot]({{site.baseurl}}/partners/trustpilot/)は、顧客がフィードバックを共有でき、レビューの管理や返信が行えるオンラインレビュープラットフォームです。
