# 2025年2月4日リリース {#february-4-2025-release}

## Braze Docs の改善 {#braze-docs-improvements}

### データ＆分析のリニューアル {#data-and-analytics-revamp}
お探しの情報を見つけやすくするために、以前「データ＆分析」の下にまとめられていた記事を[データ]({{site.baseurl}}/user_guide/data)と[分析]({{site.baseurl}}/user_guide/analytics)に分割しました。

### 開発者ガイド {#developer-guide}
[Braze 開発者ガイド]({{site.baseurl}}/developer_guide/home)全体のドキュメントを大規模にクリーンアップしました。これには、複数のページに分かれていた「ハウツー」記事を1つのページに統合する作業も含まれています。

また、各 Braze SDKのリファレンスドキュメントとリポジトリをすべてまとめた新しい [SDK リファレンスページ]({{site.baseurl}}/developer_guide/references)も追加されました。

#### Unreal Engine Braze SDK
Unreal Engine Braze SDK GitHub リポジトリの README からすべてのコンテンツを移行・書き直し、[Braze Docs の専用セクション]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=unreal%20engine)に掲載しました。

## データの柔軟性 {#data-flexibility}

### API 使用状況ダッシュボード {#api-usage-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

[API 使用状況ダッシュボード]({{site.baseurl}}/user_guide/analytics/dashboards/api_usage)では、Brazeへの受信 REST API トラフィックを監視して、REST APIの使用状況のトレンドを把握し、潜在的な問題のトラブルシューティングを行うことができます。

### カスタム属性へのタグの追加 {#adding-tags-to-custom-attributes}

{% multi_lang_include release_type.md release="General availability" %}

「イベント、属性、購入の管理」権限がある場合、カスタム属性の作成後に[タグを追加]({{site.baseurl}}/user_guide/data/activation/attributes/custom_attributes#add-tags)できます。タグを使用して属性のリストをフィルターできます。

### カタログセレクションおよび非同期カタログフィールドエンドポイント {#catalog-selections-and-async-catalog-fields-endpoints}

{% multi_lang_include release_type.md release="General availability" %}

以下のエンドポイントが一般提供になりました。
* [POST: カタログフィールドの作成]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/post_create_catalog_fields)
* [DELETE: カタログフィールドの削除]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/delete_catalog_field)
* [DELETE: カタログセレクションの削除]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/delete_catalog_selection)
* [POST: カタログセレクションの作成]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/post_create_catalog_selections)

### メールアドレスを使用したキャンペーンまたはキャンバスのトリガー {#using-an-email-address-to-trigger-campaigns-or-canvases}

{% multi_lang_include release_type.md release="General availability" %}

メールアドレスで受信者を指定して、[キャンペーン]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/target_users)や[キャンバス]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas#step-13-set-your-target-entry-audience)をトリガーできるようになりました。

### 電話番号を使用した API によるユーザーの識別 {#using-a-phone-number-to-identify-a-user-via-the-api}

{% multi_lang_include release_type.md release="General availability" %}

エイリアスやメールアドレスに加えて、電話番号を使用して [`/users/identify` API エンドポイント]({{site.baseurl}}/api/endpoints/user_data/post_user_identify)でユーザーを識別できるようになりました。

### SAML トレースの取得 {#getting-a-saml-trace}
[SAML トレースを取得する手順]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/saml_sso_setup#obtaining-a-saml-trace)を追加しました。これにより、SAML SSO に関する問題をサポートチームとより効率的に解決できます。

### リージョン固有のデータセンター {#region-specific-data-centers}
Brazeは新しい地域へのサービス提供を拡大しているため、運用アプローチを明確にする[Braze データセンターに関する記事]({{site.baseurl}}/user_guide/data/infrastructure/data_centers)を追加しました。

## クリエイティビティの解放 {#unlocking-creativity}

### 価格低下通知と再入荷通知 {#price-drop-notifications-and-back-in-stock-notifications}

{% multi_lang_include release_type.md release="General availability" %}

キャンバスとカタログを使用して[再入荷通知]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/back_in_stock_notifications)を設定することで、商品が再入荷した際に顧客に通知できるようになりました。

また、カタログとキャンバスで価格低下通知を設定することで、商品の価格が下がった際に顧客に通知する[価格低下通知]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/price_drop_notifications)を作成することもできます。

### セレクションのプレビュー {#preview-for-selection}

{% multi_lang_include release_type.md release="General availability" %}

セレクションを作成した後、ランダムなユーザーまたは特定のユーザーに対して[セレクションが返す内容を確認]({{site.baseurl}}/user_guide/data/activation/catalogs/selections#test-and-preview)できます。

### Liquid を含むカタログアイテムのテンプレート化 {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="General availability" %}

[Liquid を含むカタログアイテムをテンプレート化]({{site.baseurl}}/user_guide/data/activation/catalogs/using_catalogs#using-liquid)できます。

### キャンバステンプレート {#canvas-templates}
新しいキャンバステンプレートとして、[好みの調査によるユーザーオンボーディング]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/preference_survey)と[ダブルオプトインによるメール登録の作成]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/email_signup)を追加しました。

### B2B 向け Salesforce Sales Cloud によるリード管理 {#managing-leads-with-salesforce-sales-cloud-for-b2b}
B2B マーケターが Braze を活用する方法の1つとして、Salesforce Sales Cloud との連携があります。この[ユースケース]({{site.baseurl}}/user_guide/get_started/b2b_use_cases/b2b_salesforce_sales_cloud)の実装方法について詳しくご覧ください。

## 堅牢なチャネル {#robust-channels}

### 抑制リスト {#suppression-lists}

{% multi_lang_include release_type.md release="Beta" %}

[抑制リスト]({{site.baseurl}}/user_guide/audience/suppression_lists)は、メッセージを一切受信しないユーザーのグループを指定します。管理者はセグメントフィルターを使用して抑制リストを作成し、セグメンテーションと同じ方法でユーザーグループを絞り込むことができます。

## Brazeの新しいパートナーシップ {#new-braze-partnerships}

### Constructor - ダイナミックコンテンツ {#constructor-dynamic-content}
[Constructor]({{site.baseurl}}/partners/ecommerce/product_search_recommendations/constructor) は、AIと機械学習を活用して、eコマースおよび小売Webサイト向けにパーソナライズされた検索、レコメンデーション、ブラウジング体験を提供する検索・商品発見プラットフォームです。

### Trustpilot - ダイナミックコンテンツ {#trustpilot-dynamic-content}
[Trustpilot]({{site.baseurl}}/partners/trustpilot) は、顧客がフィードバックを共有でき、レビューの管理や返信が可能なオンラインレビュープラットフォームです。
