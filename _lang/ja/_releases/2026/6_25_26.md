# 2026年6月25日リリース {#june-25-2026-release}

## データとレポート {#data-reporting}

### Content Cardsと Banners の指標名の更新 {#metric-name-update-for-content-cards-and-banners}

Content Cardsと Banners の _ユニーク受信者_ 指標が _ユニークデイリーインプレッション_ に名称変更されました。_ユニークデイリーインプレッション_ は Braze から受信した数値を指し、`user_id` に基づいています。ユニークデイリーインプレッションは、キャンペーンまたはキャンバスステップのレベルでカウントされます。詳しくは、[指標用語集]({{site.baseurl}}/user_guide/analytics/metrics_glossary)を参照してください。

### ユーザーの削除 {#user-deletion}

{% multi_lang_include release_type.md release="General availability" %}

[ユーザーの削除]({{site.baseurl}}/user_guide/audience/manage_audience/user_profiles/delete_users)を使用すると、不要になったプロファイル、誤って作成されたプロファイル、またはコンプライアンス（GDPR や CCPA など）のために削除が必要なプロファイルを削除してデータベースを管理できます。

### データポイントの除外 {#data-point-exclusions}

{% multi_lang_include release_type.md release="General availability" %}

[eコマース推奨イベント]({{site.baseurl}}/user_guide/data/activation/events/recommended_events/ecommerce_events)は、請求対象のデータポイントとしてカウントされなくなりました。Braze eコマースイベント（`ecommerce.product_viewed`、`ecommerce.cart_updated`、`ecommerce.checkout_started`、`ecommerce.order_placed`、`ecommerce.order_cancelled`、`ecommerce.order_refunded`）をデータポイントの消費なしで導入できます。

### イベント履歴タブ {#event-history-tab}

{% multi_lang_include release_type.md release="General availability" %}

[ユーザープロファイル]({{site.baseurl}}/user_guide/audience/manage_audience/user_profiles)の**イベント履歴**タブには、過去30日間のユーザーのカスタムイベントと購入履歴（直近100件まで）が表示されます。このタブを使用して、SDK または API の連携が期待どおりにイベントを送信しているかどうかの確認、ユーザーがイベントトリガーのキャンペーンやキャンバスに入った（または入らなかった）理由のデバッグ、特定のユーザーに関するサポートエスカレーションの調査を行うことができます。

### 到達性センターで Amazon SES 顧客向けに Microsoft SNDS データを表示 {#deliverability-center-surfaces-microsoft-snds-data-for-amazon-ses-customers}

Amazon SES 経由でメールを送信するワークスペースでは、[到達性センター]({{site.baseurl}}/deliverability_center)が専用送信 IP に対する Microsoft SNDS の指標を表示します。この機能がワークスペースで有効になると、Braze は最大90日間の SNDS 過去データをバックフィルします。

### Operatorによるキャンペーンの作成と編集のサポート {#operator-support-for-campaign-creation-and-editing}

[Operator]({{site.baseurl}}/user_guide/brazeai/operator)は、メッセージの作成だけでなく、キャンペーン全体の作成と編集ができるようになりました。単一の自然言語プロンプトまたはキャンペーンブリーフから、Operatorはレビュー可能なキャンペーンをエンドツーエンドで構築します。メッセージの作成、配信のスケジュール設定、オーディエンスのターゲティング、コンバージョンイベントの割り当てを行い、レビューステップで構築内容を要約します。以前、Operatorはメッセージの作成（キャンペーン作成の5つのステップのうちの1つ）のみが可能でしたが、残りのスケジュール、ターゲット、割り当て、レビューのステップも可視化および制御できるようになりました。

## チャネル＆タッチポイント {#channels-touchpoints}

### バナーのユーザー非表示機能 {#user-dismissals-for-banners}

{% multi_lang_include release_type.md release="General availability" %}

非表示動作を構成する際に**バナーを非表示にできる**を選択すると、ユーザーがバナーを手動で非表示にできるようになります。このオプションは、すべてのアプリユーザーに期間限定セールを宣伝したいが、興味がない場合はメッセージを非表示にできるようにしたいシナリオで役立ちます。

非表示の有効化と非表示ボタンのカスタマイズの詳細については、[非表示動作の構成]({{site.baseurl}}/user_guide/channels/banners/create_a_banner#dismiss-behavior)を参照してください。

### バナーのカスタムクリックトラッキング {#custom-click-tracking-for-banners}

{% multi_lang_include release_type.md release="General availability" %}

バナーのより詳細なクリックトラッキングを行うために、プロパティパネルの**レポート用識別子**フィールドを使用して、各インタラクティブ要素に[カスタム識別子を割り当てる]({{site.baseurl}}/user_guide/channels/banners/create_a_banner#step-32-define-on-click-behavior-optional)ことができます。

### バナーの再適格性 {#re-eligibility-for-banners}

バナーキャンペーンで再適格性が有効になっている場合、バナーを非表示にしたユーザーは、非表示時点から開始する設定可能なクールダウン期間の後に再び適格になることができます。再適格性がオンになっていない場合、非表示にしたユーザーは適格外のままになります。再適格性を構成するには、[再適格性の構成]({{site.baseurl}}/user_guide/channels/banners/create_a_banner#re-eligibility)を参照してください。なお、キャンバスのバナーステップでは、代わりにキャンバスの再エントリ設定が使用されます。

### クイックプッシュ AB テスト {#quick-push-ab-testing}

{% multi_lang_include release_type.md release="General availability" %}

クイックプッシュ AB テストは、バリアントグループを通じてマルチプラットフォームのプッシュキャンペーンとキャンバスステップをサポートするようになりました。これにより、iOS と Android のメッセージバリエーションを1つのワークフローでテストできます。詳細については、[マルチプラットフォームプッシュメッセージ]({{site.baseurl}}/user_guide/channels/push/create_a_push_message/multiple_platform_push#use-cases)を参照してください。

### BrazeAI<sup>TM</sup> で最適化 {#optimize-with-brazeai}

{% multi_lang_include release_type.md release="Early access" %}

**BrazeAI<sup>TM</sup> で最適化**は、複数のプッシュバリアントを追加すると自動的にオンになり、推奨される実験デフォルトを適用し、最もパフォーマンスの高いバリアントに向けて最適化します。すぐに送信する必要がある場合はオフにすることができます。詳細については、[BrazeAIによる AB テストの最適化]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/variant_selection)を参照してください。

### WhatsApp テスト送信結果 {#whatsapp-test-send-results}

WhatsApp のテストメッセージを送信した後、メッセージ作成画面で直接[詳細な配信レポート]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#step-4-view-test-send-results)を確認できます。これにより、メッセージが意図した受信者に届いたことを確認し、配信前に失敗をトラブルシュートできます。

## パートナーシップ {#partnerships}

### Convercus - データと分析 - ロイヤルティ {#convercus-data-and-analytics-loyalty}

[Convercus]({{site.baseurl}}/partners/data_and_analytics/loyalty/convercus) は、オムニチャネルのロイヤルティプログラムやパーソナライズされたクーポンキャンペーンを通じて、ブランドや小売店の顧客来店頻度、バスケット単価、リピート購入率の向上を支援する SaaS 型ロイヤルティ＆クーポンプラットフォームです。

### Copy Pastd - メッセージオーケストレーション - テンプレート {#copy-pastd-message-orchestration-templates}

[Copy Pastd]({{site.baseurl}}/partners/copy_pastd) Building Blocks は、Liquid を活用した Content Blocks や完全なテンプレートを Braze ワークスペースに直接プッシュできるドラッグ＆ドロップ式のメールビルダーです。一度デザインすれば Braze に同期でき、毎回 HTML を再構築することなく、キャンペーン、キャンバス、トリガーフローで同じコンポーネントを再利用できます。

### Databricks Mosaic - AI モデルプロバイダー {#databricks-mosaic-ai-model-providers}

[Databricks Mosaic]({{site.baseurl}}/partners/databricks_mosaic) は、Databricks Data Intelligence Platform 上で AI および機械学習モデルの構築、デプロイ、管理を大規模に行うための Databricks の統合プラットフォームです。

### DinMo - データと分析 - リバース ETL {#dinmo-data-and-analytics-reverse-etl}

[DinMo]({{site.baseurl}}/partners/dinmo) は、リバース ETL（Extract, Transform, Load）を通じてクラウドデータウェアハウスと Braze を接続するコンポーザブルな顧客データプラットフォーム（CDP）です。マーケティングチームはウェアハウスデータからオーディエンスセグメントを構築し、ユーザー属性やイベントを Braze に同期し、CSV のアップロードや開発サポートなしに購読ステータスを最新の状態に保つことができます。

### EmailShepherd - メッセージオーケストレーション - テンプレート {#emailshepherd-message-orchestration-templates}

[EmailShepherd]({{site.baseurl}}/partners/emailshepherd) は、メールデザインシステムをベースに構築されたエージェント型メール作成プラットフォームで、マーケティングチーム全体と AI エージェントが、ボトルネックなしにブランドに沿った本番対応メールを作成できるようにします。Braze との連携により、承認済みメールが Braze ワークスペースに直接公開されるため、マーケターはブランドの一貫性を損なうことなく Braze でのメール制作をスケールできます。

### Talkable - メッセージパーソナライゼーション - リファーラル {#talkable-message-personalization-referrals}

[Talkable]({{site.baseurl}}/partners/talkable) は、消費者ブランドが満足した顧客をスケーラブルなリファーラルチャネルに変えることを支援します。Braze との連携により、Talkable のリファーラルキャンペーンで取得されたマーケティングメールのオプトインがリアルタイムで Braze に流れ込み、新しいアドボケイトや紹介された友人を歓迎し、セグメント化し、エンゲージするために必要な同意、コンテキスト、キャンペーンデータをチームに提供します。
