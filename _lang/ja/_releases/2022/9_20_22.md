# 2022年9月20日リリース {#september-20-2022-release}

## APIガイド {#api-guide}
[Braze APIガイド]({{site.baseurl}}/api/home/)をチェックして、エンドポイントの種類に基づいてエンドポイントを検索し、用語集を絞り込むのに役立ててください。

## パーソナライズ済みバリアント {#personalized-variants}
ターゲットセグメント内の各ユーザーに、最もエンゲージする可能性が高いバリアントを送信するには、[パーソナライズ済みバリアント]({{site.baseurl}}/user_guide/messaging/ab_testing/optimizations/)を使用します。

## キャンバスのテスト {#testing-canvases}
キャンバスを作成した後、オーディエンスのサイズやセグメンテーションフィルターの数などの詳細に応じて、起動前にいくつかの事項を確認することをお勧めします。ヒントについては、[テストキャンバスの送信]({{site.baseurl}}/user_guide/messaging/canvas/testing_canvases/sending_test_canvases/)をご確認ください。

## Liquid 5
既存の会社ユーザー向けに、Liquid 5が一般提供されています。[Liquid 5の新機能]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/liquid/#whats-new-with-liquid-5)について詳しくはこちらをご覧ください。

## 新しいBrazeパートナーシップ {#new-braze-partnerships}

### Shopify
Brazeと[Shopify]({{site.baseurl}}/partners/shopify/)の連携により、Shopifyストアでキャプチャされたリード、サインアップ、およびアカウント登録について、Brazeで既存のユーザープロファイルを更新したり、新しいプロファイルを作成したりできます。

## SDKのアップデート {#sdk-updates}

以下のSDKアップデートがリリースされました。破壊的な更新は下記のとおりです。その他すべての更新は、対応するSDKの変更ログをご確認ください。

- [Android SDK 23.1.0–23.12](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [React Native SDK v1.38.0–v1.38.1](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
	- ネイティブAndroidブリッジをBraze Android SDK 23.0.1に更新しました。
	- ネイティブiOSブリッジをBraze iOS SDK 4.5.0に更新しました。
	- Braze React Native Android SDKでは、コンパイルにKotlinが直接必要になりました。
- [Braze Expoプラグイン0.4.0](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
	- プロップ`fcmSenderID`の名前を`firebaseCloudMessagingSenderId`に変更しました。
- [Unity 3.9.0](https://github.com/Appboy/appboy-unity-sdk/blob/master/CHANGELOG.md)
	- AndroidプラグインをBraze Android SDK 23.1.0を使用するように更新しました。
	- `Appboy.AppboyBinding.PromptUserForPushPermissions(false)`を介してAndroid 13以降のデバイスでプッシュ通知の権限をリクエストする機能を追加しました。
- [Swift SDK 5.3.0–5.4.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#540)
