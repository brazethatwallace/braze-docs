# 2022年9月20日リリース {#september-20-2022-release}

## APIガイド {#api-guide}
[Braze APIガイド]({{site.baseurl}}/api/home)を参照して、エンドポイントタイプに基づいてエンドポイントを検索し、用語集を絞り込むことができます。

## パーソナライズされたバリアント {#personalized-variants}
[パーソナライズされたバリアント]({{site.baseurl}}/user_guide/messaging/ab_testing/optimizations)を使用すると、ターゲットセグメント内の各ユーザーに、最もエンゲージメントが高いと予測されるバリアントを送信できます。

## キャンバスのテスト {#testing-canvases}
キャンバスを作成した後、オーディエンスのサイズやセグメンテーションフィルターの数などの詳細に応じて、起動前にいくつかのチェックを実行することをお勧めします。ヒントについては、[テストキャンバスの送信]({{site.baseurl}}/user_guide/messaging/canvas/testing_canvases/sending_test_canvases)をご確認ください。

## Liquid 5
既存の会社ユーザー向けに、Liquid 5が一般提供されています。[Liquid 5の新機能]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid#liquid-5-support)について詳しくはこちらをご覧ください。

## Brazeの新しいパートナーシップ {#new-braze-partnerships}

### Shopify
Brazeと[Shopify]({{site.baseurl}}/partners/shopify)の連携により、Shopifyストアで取得したリード、サインアップ、アカウント登録に対して、Brazeの既存のユーザープロファイルを更新したり、新しいプロファイルを作成したりできます。

## SDKの更新 {#sdk-updates}

最新のSDK更新がリリースされました。破壊的な更新はSDK更新セクションに記載されています。その他すべての更新は、対応するSDKチェンジログに記載されています。

- [Android SDK 23.1.0-23.12](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [React Native SDK v1.38.0–v1.38.1](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - ネイティブAndroidブリッジをBraze Android SDK 23.0.1に更新しました。
  - ネイティブiOSブリッジをBraze iOS SDK 4.5.0に更新しました。
  - Braze React Native Android SDKのコンパイルに、Kotlinが直接必要になりました。
- [Braze Expo Plugin 0.4.0](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - プロパティ`fcmSenderID`を`firebaseCloudMessagingSenderId`に名前変更しました。
- [Unity 3.9.0](https://github.com/Appboy/appboy-unity-sdk/blob/master/CHANGELOG.md)
  - AndroidプラグインをBraze Android SDK 23.1.0を使用するように更新しました。
  - `Appboy.AppboyBinding.PromptUserForPushPermissions(false)`を使用して、Android 13以降のデバイスでプッシュ通知の権限をリクエストする機能を追加しました。
- [Swift SDK 5.3.0-5.4.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#540)
