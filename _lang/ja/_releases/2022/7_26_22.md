# 2022年7月26日リリース {#july-26-2022-release}

## キャンバスフロー {#canvas-flow}
キャンバス製品の最新バージョンである[キャンバスフロー]({{site.baseurl}}/user_guide/engagement_tools/canvas/create_a_canvas/create_a_canvas#editing-a-step)がリリースされました。キャンバスフローでは、軽量な[キャンバスコンポーネント]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/about)、[永続的エントリプロパティ]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas/context_and_event_properties/canvas_persistent_entry_properties)、および[ローンチ後の編集]({{site.baseurl}}/post-launch_edits)にアクセスできます。

![軽量コンポーネントと分岐フローを示すキャンバスフローの視覚的な概要。]({% image_buster /assets/img/canvas_flow.png %})

## オブジェクト配列 {#array-of-objects}
[オブジェクト配列]({{site.baseurl}}/user_guide/data/activation/attributes/array_of_objects)を使用して、関連する属性をグループ化します。たとえば、ペットオブジェクト、曲オブジェクト、アカウントオブジェクトのグループがあり、それらがすべて1人のユーザーに属している場合があります。これらのオブジェクト配列は、Liquidを使用してメッセージングをパーソナライズしたり、オブジェクト内のいずれかの要素が条件に一致する場合にオーディエンスセグメントを作成したりするために使用できます。

## パートナー連携の更新 {#updated-partner-integrations}
[Amplitude Recommend]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/amplitude/amplitude_audiences) と [mParticle]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/mparticle/mparticle) の連携手順が更新されました。これらのパートナーをご利用の場合は、各ドキュメントにアクセスして、最新の設定手順に従っていることをご確認ください。

## Shopifyの要件 {#shopify-requirements}
- [前提条件]({{site.baseurl}}/partners/message_orchestration/channel_extensions/ecommerce/shopify/shopify#prerequisites)に記載されている必要なユーザー権限が更新されました。
- `price`、`total_price`、`total_discounts`、`amount`プロパティを含むShopifyの[ペイロード]({{site.baseurl}}/partners/message_orchestration/channel_extensions/ecommerce/shopify/shopify#supported-shopify-events)の例が更新され、これらのプロパティが文字列ではなく数値としてフォーマットされるようになりました。

## 予測の更新 {#prediction-updates}
解約予測と購入予測の最大時間ウィンドウが14日から60日に延長されました。

## SDKの更新 {#sdk-updates}
以下のSDKの更新がリリースされました。破壊的な更新はこのセクションに記載されています。その他すべての更新は、対応するSDKの変更ログを確認してください。
- [Web SDK 4.1.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md#410)
- [Cordova SDK 2.30.1](https://github.com/Appboy/appboy-cordova-sdk/blob/master/CHANGELOG.md#2301)
- [Unity SDK 3.8.1](https://github.com/Appboy/appboy-unity-sdk/blob/master/CHANGELOG.md#381)
- [Swift SDK 5.0.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#501)
- [Roku SDK 0.1.2](https://github.com/braze-inc/braze-roku-sdk/blob/main/CHANGELOG.md#012)
- [React Native SDK 1.37.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md#1370)
  - Braze React Native SDKは、デフォルトオブジェクトをESモジュールとしてエクスポートするようになりました。現在`require()`を使用してSDKをインポートしている場合は、標準のESモジュールとしてインポートする必要があります（例: import Braze from "`@braze/react-native-sdk`"）。
- [Android SDK 22.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2200)
  - `Appboy.java`は`Braze.kt`に変更されました。Kotlinクライアントは、必要に応じてBrazeシングルトンでKotlinプロパティの使用をサポートするようにコードを更新する必要があります。
    - `Braze.registerPushToken()`/`Braze.getRegisteredPushToken()`は`Braze.setRegisteredPushToken()/Braze.getRegisteredPushToken()`に変更されました。Kotlinを使用している場合は、プロパティ`Braze.registeredPushToken`を使用してください。
    - `Braze.getDeviceId`は、Kotlinでは`Braze.deviceId`に変更されました。
    - `Braze.enableMockNetworkAppboyRequestsAndDropEventsMode`は`Braze.enableMockNetworkRequestsAndDropEventsMode()`に変更されました。
    - `Appboy.java`は削除されました。例えば、`Appboy.getInstance()`のような呼び出しは、今後`Braze.getInstance()`にする必要があります。
    - `setCustomAppboyNotificationFactory()`は`setCustomBrazeNotificationFactory()` / `customBrazeNotificationFactory`に置き換えられました。
    - `enableMockAppboyNetworkRequestsAndDropEventsMode`は`enableMockNetworkRequestsAndDropEventsMode`に名前が変更されました。
  - `com.appboy.IBrazeEndpointProvider`は`com.braze.IBrazeEndpointProvider`に移動されました。
  - `com.braze.events.IEventSubscriber`は`com.braze.events.IEventSubscriber`に名前が変更されました。
  - `Appboy.registerAppboyPushMessages()` / `Appboy.getAppboyPushMessageRegistrationId()`は削除されました。`getRegisteredPushToken()` / `setRegisteredPushToken()`に置き換えられました。
  - `IAppboyNotificationFactory`は`IBrazeNotificationFactory`に置き換えられました。
  - `com.appboy.ui.inappmessage.listeners.IHtmlInAppMessageActionListener`は削除されました。代わりに`com.braze.ui.inappmessage.listeners.IHtmlInAppMessageActionListener`を使用してください。
