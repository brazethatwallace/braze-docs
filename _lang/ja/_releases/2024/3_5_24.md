# 2024年3月5日リリース {#march-5-2024-release}

## Google EU ユーザー同意ポリシー {#google-eu-user-consent-policy}

Googleは、2024年3月6日に施行された[デジタル市場法（DMA）](https://ads-developers.googleblog.com/2023/10/updates-to-customer-match-conversion.html)の変更に対応して、[EU ユーザー同意ポリシー](https://www.google.com/about/company/user-consent-policy/)を更新しています。この新しい変更により、広告主はEEAおよび英国のエンドユーザーに対して特定の情報を開示し、必要な同意を取得することが求められます。今後の変更の一環として、[Brazeでカスタム属性として両方の同意シグナルを収集する]({{site.baseurl}}/partners/canvas_steps/google_audience_sync#collecting-consent-for-eea-and-uk-end-users)ことができます。Brazeは、これらのカスタム属性のデータをGoogleの適切な同意フィールドに同期します。

## データの柔軟性 {#data-flexibility}

### 重複ユーザーの統合 {#merge-duplicate-users}

{% multi_lang_include release_type.md release="Early access" %}

Brazeダッシュボードで、キャンペーンやキャンバスの効果を最大化するために、[重複ユーザーを検索して統合]({{site.baseurl}}/user_guide/audience/manage_audience/merge_duplicate_users)できるようになりました。ユーザープロファイルを個別に統合することも、一括統合を実行することもできます。一括統合では、一致する識別子を持つすべてのプロファイルが、最も最近更新されたユーザープロファイルに統合されます。

### アーカイブされたコンテンツの検索 {#search-for-archived-content}

Brazeダッシュボードで、**アーカイブされたコンテンツを表示**を選択することにより、[検索結果にアーカイブされたコンテンツを含める]({{site.baseurl}}/user_guide/administrative/access_braze/global_search#filter-for-archived-content)ことができるようになりました。

### AWS S3およびGoogle Cloud Storageのメッセージアーカイブサポート {#message-archiving-support-for-aws-s3-and-google-cloud-storage}

[メッセージアーカイブ]({{site.baseurl}}/user_guide/data/distribution/export_braze_data/message_archiving)を使用して、アーカイブまたはコンプライアンスの目的で、ユーザーに送信されたメッセージのコピーをAWS S3バケット、Azure Blob Storageコンテナ、またはGoogle Cloud Storageバケットに保存できます。

### SQLテーブルリファレンス {#sql-table-reference}

[SQLテーブルリファレンス]({{site.baseurl}}/user_guide/audience/segments/segment_extension/sql_segments/sql_segments_tables)にアクセスして、クエリビルダーやSQLセグメントエクステンションの生成時にクエリ可能なテーブルとカラムを確認してください。

## クリエイティビティの解放 {#unlocking-creativity}

### AIコピーライティングのトーンコントロール {#tone-control-for-ai-copywriting}

AIコピーライティングアシスタントで生成されるコピーのスタイルを決定する[メッセージトーン]({{site.baseurl}}/user_guide/brazeai/generative_ai/ai_copywriting#steps)を選択できるようになりました。

## 堅牢なチャネル {#robust-channels}

### カード作成 {#card-creation}

新しいContent Cardsキャンペーンやキャンバスステップにおいて、Brazeがオーディエンスの適格性とパーソナライゼーションを評価するタイミングを、カードの[作成]({{site.baseurl}}/user_guide/channels/content_cards/create_a_content_card/card_creation)時期を指定することで選択できます。

### ユーザーパスのプレビュー {#preview-user-paths}

{% multi_lang_include release_type.md release="General availability" %}

ユーザー向けに作成したキャンバスジャーニーを体験できます。タイミングやユーザーが受け取るメッセージのプレビューも含まれます。これらの[テスト実行]({{site.baseurl}}/preview_user_paths)は、キャンバスを送信する前に、メッセージが適切なオーディエンスに送信されることを確認する品質保証として機能します。

### クイックプッシュキャンペーン {#quick-push-campaigns}

{% multi_lang_include release_type.md release="General availability" %}

Brazeでプッシュキャンペーンを作成する際、複数のプラットフォームとデバイスを選択し、[クイックプッシュ]({{site.baseurl}}/user_guide/channels/push/create_a_push_message/multiple_platform_push)と呼ばれる単一の編集体験ですべてのプラットフォーム向けに1つのメッセージを作成できます。この機能はキャンペーンでのみ利用可能です。

### カスタムリスト配信停止ヘッダー {#custom-list-unsubscribe-header}

{% multi_lang_include release_type.md release="General availability" %}

メールメッセージングに[カスタムリスト配信停止ヘッダー]({{site.baseurl}}/user_guide/administrative/app_settings/email_settings#custom-list-unsubscribe-header)を追加すると、受信者がオプトアウトできるようになります。これにより、独自に設定したワンクリック購読解除エンドポイントとオプションの「mailto:」を追加できます。Brazeでは、カスタムリスト配信停止ヘッダーをサポートするためにURL入力が必要です。これは、ワンクリック購読解除HTTPがYahooおよびGmailの一括送信者に対する要件であるためです。

### アプリ内メッセージの複数ページ {#multiple-pages-for-in-app-messages}

{% multi_lang_include release_type.md release="Early access" %}

[アプリ内メッセージにページを追加する]({{site.baseurl}}/user_guide/message_building_by_channel/in-app_messages/drag_and_drop/create#multi-page)ことで、オンボーディングフローやウェルカムジャーニーのようなシーケンシャルフローにユーザーを導くことができます。ページは**ビルド**タブの**ページ**セクションから管理できます。

### 実験パスのパスをランダム化 {#randomize-paths-for-an-experiment-path}

実験パスステップで常に[パスの割り当てをランダム化]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step)するには、ステップで**実験パスのランダム化されたパス**を選択します。このオプションは、勝利パスまたはパーソナライズされたパスのいずれかを使用している場合は利用できません。

### メールキャプチャフォーム {#email-capture-form}

[メールキャプチャメッセージ]({{site.baseurl}}/user_guide/channels/in_app_messages/message_types/email_capture_form)を使用すると、サイトのユーザーにメールアドレスの送信を簡単に促すことができます。送信されたメールアドレスはユーザープロファイルで利用可能になり、すべてのメッセージングキャンペーンで使用できます。
