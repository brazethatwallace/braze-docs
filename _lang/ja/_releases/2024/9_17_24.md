# 2024年9月17日リリース {#september-17-2024-release}

## データの柔軟性 {#data-flexibility}

### S3向けBraze Cloud Data Ingestion {#braze-cloud-data-ingestion-for-s3}

[S3向けCloud Data Ingestion (CDI)]({{site.baseurl}}/user_guide/data_and_analytics/cloud_ingestion/file_storage_integrations#aws-definitions)を使用して、AWSアカウント内の1つ以上のS3バケットをBrazeと直接統合できます。新しいファイルがS3に公開されると、SQSにメッセージが送信され、Braze Cloud Data Ingestionがその新しいファイルを取り込みます。

### 月間アクティブユーザー CY 24-25 {#monthly-active-users-cy-24-25}

月間アクティブユーザー - CY 24-25を購入した顧客に対して、Brazeは`/users/track`エンドポイントに異なるレート制限を適用します。詳細については、[POST: ユーザーを追跡]({{site.baseurl}}/api/endpoints/user_data/post_user_track#monthly-active-users-cy-24-25-universal-mau-web-mau-and-mobile-mau)を参照してください。

## クリエイティビティを引き出す {#unlocking-creativity}

### Liquidを含むカタログアイテムのテンプレート化 {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="Early access" %}

Liquidタグの`:rerender`フラグを使用して、[カタログアイテムのLiquidコンテンツをレンダリング]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog#using-liquid)できます。例えば、以下のLiquidコンテンツをレンダリングした場合：

{% raw %}
```liquid
Hi ${first_name}
{% catalog_items Messages greet_msg :rerender %}
{{ items[0].Welcome_Message }}
```
{% endraw %}

次のように表示されます：

{% raw %}
```
Hi Peter,
Welcome to our store, Peter!
```
{% endraw %}

## 堅牢なチャネル {#robust-channels}

### WhatsApp応答メッセージ {#whatsapp-response-messages}

{% multi_lang_include release_type.md release="General availability" %}

[応答メッセージ]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#response-messages)を使用して、ユーザーからの受信WhatsAppメッセージに返信できます。これらのメッセージはBrazeのアプリ内でメッセージ作成中に構築され、いつでも編集できます。Liquidを使用して、応答メッセージの言語を適切なユーザーに合わせることができます。

### キャンバステンプレート {#canvas-templates}

{% multi_lang_include release_type.md release="General availability" %}

[キャンバステンプレート]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates)を作成して、キャンバス全体で特定の目標に合わせて簡単にカスタマイズできる一貫したフレームワークを構築し、メッセージングを洗練させましょう。

### ランディングページ {#landing-pages}

{% multi_lang_include release_type.md release="Beta" %}

Brazeの[ランディングページ]({{site.baseurl}}/user_guide/messaging/landing_pages)は、ユーザー獲得とエンゲージメント戦略を推進できるスタンドアロンのWebページです。

### 前回の閲覧以降の変更 {#changes-since-last-viewed}

チームの他のメンバーによる[キャンバス]({{site.baseurl}}/user_guide/engagement_tools/canvas/testing_canvases/measuring_and_testing_with_canvas_analytics#changes-since-last-viewed)、キャンペーン、[セグメント]({{site.baseurl}}/user_guide/engagement_tools/segments/managing_segments#changes-since-last-viewed)の更新数は、それぞれの概要ページ（[メールキャンペーン]({{site.baseurl}}/user_guide/channels/email/reporting#changes-since-last-viewed)の概要ページなど）の*Changes Since Last Viewed*指標を参照して確認できます。

### Webhookおよび Connected Contentリクエストのトラブルシューティング {#troubleshooting-webhook-and-connected-content-requests}

[WebhookおよびConnected Contentリクエストのトラブルシューティング]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content/troubleshooting_webhooks_and_connected_content)では、WebhookおよびConnected Contentのエラーコードのトラブルシューティング方法について、エラーの内容と解決手順を含めて説明しています。

## Brazeの新しいパートナーシップ {#new-braze-partnerships}

### Inbox Monster - 分析 {#inbox-monster-analytics}

[Inbox Monster]({{site.baseurl}}/partners/data_and_analytics/analytics/inbox_monster)は、エンタープライズブランドがすべての送信を確実に届けるための受信トレイシグナルプラットフォームです。到達性、クリエイティブレンダリング、SMS監視のための統合ソリューションスイートであり、最新のカスタマーリレーションシップマネジメント（CRM）チームを支援し、送信に関する不安を解消します。

### SessionM - ロイヤルティ {#sessionm-loyalty}

[SessionM]({{site.baseurl}}/partners/data_and_analytics/loyalty/sessionm)は、カスタマーエンゲージメントおよびロイヤルティプラットフォームであり、キャンペーン管理機能とロイヤルティ管理ソリューションを提供して、マーケターがターゲットを絞ったアウトリーチを推進し、エンゲージメントと収益性を向上させることを支援します。

## AIとML自動化 {#ai-and-ml-automation}

### トレンドアイテムレコメンデーション {#trending-item-recommendations}

「AIパーソナライズド」モデルに加えて、[AIアイテムレコメンデーション]({{site.baseurl}}/user_guide/sage_ai/recommendations/about_item_recommendations#trending)機能には「トレンド」のレコメンデーションモデルも含まれています。このモデルでは、最近のユーザーインタラクションにおいて最もポジティブな勢いのあったアイテムが表示されます。

## 設定 {#settings}

### ロール {#roles}

{% multi_lang_include release_type.md release="General availability" %}

[ロール]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/user_permissions#creating-a-role)を使用すると、個々のカスタム権限とワークスペースのアクセス制御をまとめてバンドルすることで、より構造化された管理が可能になります。これは、1つのダッシュボードに多くのブランドやリージョンのワークスペースがある場合に特に便利です。ロールを使用すると、ダッシュボードユーザーを適切なワークスペースに追加し、関連する権限を直接付与できます。

### セキュリティイベントレポート {#security-event-report}

ダウンロードしたセキュリティレポートイベントに表示される可能性のある[セキュリティイベント]({{site.baseurl}}/user_guide/administrative/app_settings/company_settings/security_settings#downloading-a-security-event-report)の完全なリストを追加しました。

### メッセージ使用状況レポート {#message-usage-report}

{% multi_lang_include release_type.md release="Early access" %}

[クレジット使用状況ダッシュボード]({{site.baseurl}}/credits_usage_dashboard)は、契約割り当てと比較した過去および現在の使用状況を包括的に把握できるよう、クレジット使用状況に関するセルフサービスのインサイトを提供します。これらのインサイトにより、疑問点を解消し、超過料金のリスクを防ぐための調整を行うことができます。

## SDK

### Braze Swift SDKの遅延初期化 {#delayed-initialization-for-the-braze-swift-sdk}

Braze Swift SDKを非同期に初期化しながらプッシュ通知の処理を保持するように[遅延初期化]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=swift#step-2-set-up-delayed-initialization-optional)を設定できます。これは、サーバーからの設定データの取得やユーザーの同意の待機など、SDKを初期化する前に他のサービスをセットアップする必要がある場合に便利です。
