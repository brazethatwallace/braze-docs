# 2024年9月17日リリース {#september-17-2024-release}

## データの柔軟性 {#data-flexibility}

### S3用Brazeクラウドデータ取り込み {#braze-cloud-data-ingestion-for-s3}

[S3用のクラウドデータ取り込み（CDI）]({{site.baseurl}}/user_guide/data_and_analytics/cloud_ingestion/file_storage_integrations/#aws-definitions)を使用して、AWSアカウントの1つ以上のS3バケットをBrazeと直接統合できます。新しいファイルがS3にパブリッシュされると、メッセージがSQSに投稿され、Brazeクラウドデータ取り込みがそれらの新しいファイルを取り込みます。

### 月間アクティブユーザー数 CY 24-25 {#monthly-active-users-cy-24-25}

月間アクティブユーザー数 - CY 24-25を購入したお客様の場合、Brazeは`/users/track`エンドポイントで異なるレート制限を管理します。詳細については、[POST: ユーザーの追跡]({{site.baseurl}}/api/endpoints/user_data/post_user_track/#monthly-active-users-cy-24-25)を参照してください。

## 創造性を引き出す {#unlocking-creativity}

### Liquidを含むカタログアイテムのテンプレート化 {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="Early access" %}

Liquidタグで`:rerender`フラグを使用して、[カタログアイテムのLiquidコンテンツをレンダリング]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog/#using-liquid)できます。たとえば、次のLiquidコンテンツをレンダリングするとします。

{% raw %}
```liquid
Hi ${first_name}
{% catalog_items Messages greet_msg :rerender %}
{{ items[0].Welcome_Message }}
```
{% endraw %}

次のように表示されます。

{% raw %}
```
Hi Peter,
Welcome to our store, Peter!
```
{% endraw %}

## 強力なチャネル {#robust-channels}

### WhatsApp応答メッセージ {#whatsapp-response-messages}

{% multi_lang_include release_type.md release="General availability" %}

[応答メッセージ]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/create/#response-messages)を使用して、ユーザーからの受信WhatsAppメッセージに返信できます。これらのメッセージは、作成中にBrazeのアプリ内で構築され、いつでも編集できます。Liquidを使えば、応答メッセージの言語を適切なユーザーに合わせることができます。

### キャンバステンプレート {#canvas-templates}

{% multi_lang_include release_type.md release="General availability" %}

[キャンバステンプレート]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/)を作成して、Canvases全体の特定の目標に合わせて簡単にカスタマイズできる一貫したフレームワークを構築し、メッセージングを洗練させましょう。

### ランディングページ {#landing-pages}

{% multi_lang_include release_type.md release="Beta" %}

Brazeの[ランディングページ]({{site.baseurl}}/user_guide/messaging/landing_pages/)は、ユーザー獲得とエンゲージメント戦略を推進できるスタンドアロンのWebページです。

### 最後に表示してからの変更 {#changes-since-last-viewed}

各概要ページ（[メールCampaign]({{site.baseurl}}/user_guide/message_building_by_channel/email/reporting_and_analytics/email_reporting/#changes-since-last-viewed)の概要ページなど）の*最後に表示してからの変更*指標を参照することで、チームの他のメンバーによる[Canvases]({{site.baseurl}}/user_guide/engagement_tools/canvas/testing_canvases/measuring_and_testing_with_canvas_analytics/#changes-since-last-viewed)、Campaigns、および[Segments]({{site.baseurl}}/user_guide/engagement_tools/segments/managing_segments/#changes-since-last-viewed)への更新数を確認できます。

### Webhookおよびコネクテッドコンテンツリクエストのトラブルシューティング {#troubleshooting-webhook-and-connected-content-requests}

[Webhookおよびコネクテッドコンテンツリクエストのトラブルシューティング]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content/troubleshooting_webhooks_and_connected_content/)では、Webhookおよびコネクテッドコンテンツのエラーコードのトラブルシューティング方法（エラーの内容やそれらを解決する手順を含む）について説明しています。

## 新しいBrazeパートナーシップ {#new-braze-partnerships}

### Inbox Monster - 分析 {#inbox-monster-analytics}

[Inbox Monster]({{site.baseurl}}/partners/data_and_analytics/analytics/inbox_monster/)は、企業ブランドがすべての送信を確実に届けるためのインボックスシグナルプラットフォームです。配信到達性、クリエイティブレンダリング、SMS監視のための統合ソリューションスイートで、最新の顧客関係管理（CRM）チームを強化し、送信に関する不安を解消します。

### SessionM - ロイヤルティ {#sessionm-loyalty}

[SessionM]({{site.baseurl}}/partners/data_and_analytics/loyalty/sessionm/)は、Campaign管理機能とロイヤルティ管理ソリューションを提供するカスタマーエンゲージメントおよびロイヤルティプラットフォームで、マーケターがターゲットを絞ったアウトリーチを推進してエンゲージメントと収益性を向上させるのを支援します。

## AIとMLのオートメーション {#ai-and-ml-automation}

### トレンドアイテムのレコメンデーション {#trending-item-recommendations}

「AIパーソナライズ」モデルに加えて、[AI項目のレコメンデーション]({{site.baseurl}}/user_guide/sage_ai/recommendations/about_item_recommendations/#trending)機能には、最近のユーザーインタラクションで最もポジティブな勢いのあったアイテムを特集する「トレンド」レコメンデーションモデルも含まれています。

## 設定 {#settings}

### ロール {#roles}

{% multi_lang_include release_type.md release="General availability" %}

[ロール]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/user_permissions/#creating-a-role)では、個別のカスタム権限をワークスペースアクセスコントロールとバンドルすることで、より体系的な管理を実現できます。これは、1つのダッシュボードに多数のブランドまたは地域ワークスペースがある場合に特に便利です。ロールを使用して、適切なワークスペースにダッシュボードユーザーを追加し、関連する権限を直接付与できます。

### セキュリティイベントレポート {#security-event-report}

ダウンロードしたセキュリティレポートイベントに表示される可能性のある[セキュリティイベント]({{site.baseurl}}/user_guide/administrative/app_settings/company_settings/security_settings/#downloading-a-security-event-report)の完全なリストを追加しました。

### メッセージ使用状況レポート {#message-usage-report}

{% multi_lang_include release_type.md release="Early access" %}

[クレジット使用状況ダッシュボード]({{site.baseurl}}/credits_usage_dashboard/)では、クレジット使用状況に関するセルフサービスのインサイトを提供し、契約割当てと比較した過去と現在の使用状況を包括的に確認できます。これらのインサイトにより、混乱を減らし、超過料金のリスクを防ぐための調整に役立てることができます。

## SDK

### Braze Swift SDKの遅延初期化 {#delayed-initialization-for-the-braze-swift-sdk}

Braze Swift SDKを非同期に初期化しながらプッシュ通知の処理を保持するように[遅延初期化]({{site.baseurl}}/developer_guide/sdk_initalization/?sdktab=swift)を設定できます。これは、サーバーからの設定データの取得やユーザーの同意の待機など、SDKを初期化する前に他のサービスをセットアップする必要がある場合に便利です。
