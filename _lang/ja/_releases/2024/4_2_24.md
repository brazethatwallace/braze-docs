# 2024年4月2日リリース {#april-2-2024-release}

## WhatsApp

### 複数のビジネスアカウント {#multiple-business-accounts}

複数のWhatsApp Businessアカウントとサブスクリプショングループを各ワークスペースに追加できるようになりました。詳細な手順については、「[複数のWhatsApp Businessアカウントと電話番号]({{site.baseurl}}/user_guide/channels/whatsapp/whatsapp_setup/multiple_business_accounts/)」を参照してください。

### 既読率 {#read-rates}

WhatsAppでは、企業のマーケティング会話でより価値の高い体験を創出し、エンゲージメントを最大化する新しいアプローチのテストが、インドの消費者を対象に開始されました。これには、ある特定の期間に、ある企業から受け取るマーケティング会話の数を制限することも含まれます。これは、読まれにくい少数の会話から始まります。詳細については、[Metaリソース]({{site.baseurl}}/user_guide/channels/whatsapp/meta_resources/)を参照してください。

## データの柔軟性 {#data-flexibility}

### Amazon S3バケットをBrazeに同期する {#sync-amazon-s3-buckets-to-braze}

{% multi_lang_include release_type.md release="Early access" %}

S3用のクラウドデータ取り込みを使用して、AWSアカウントの1つ以上のS3バケットをBrazeと直接連携できるようになりました。新規ファイルがS3にパブリッシュされると、メッセージがSQSに投稿され、Brazeのクラウドデータ取り込みがそれらの新規ファイルを取り込みます。詳細については、[ファイルストレージの統合]({{site.baseurl}}/user_guide/data/unification/cloud_ingestion/file_storage_integrations/)を参照してください。

### Shopify OAuth

{% multi_lang_include release_type.md release="General availability" %}

Shopifyは、あらゆる規模の小売事業を開始、成長、マーケティング、管理するための信頼できるツールを提供する世界的な大手商業企業です。BrazeのShopifyを設定する際に、[ワークスペースに対してOAuthを有効にする]({{site.baseurl}}/partners/message_orchestration/channel_extensions/ecommerce/shopify/setting_up_shopify/)ことができます。

### iOSプッシュ通知にExpoを使用する {#use-expo-for-ios-push-notifications}

React NativeでExpoを使用して、リッチプッシュ通知とPush StoriesをiOSアプリに統合するための[手順を追加]({{site.baseurl}}/developer_guide/platform_integration_guides/react_native/push_notifications/?tab=expo)しました。

### iOSライブアクティビティのリモート起動 {#remote-start-ios-live-activities}

[`/messages/live_activity/start`エンドポイント]({{site.baseurl}}/api/endpoints/messaging/live_activity/start/)を使用して、iOSでライブアクティビティをリモートで起動できるようになりました。詳細な手順については、「[ライブアクティビティ:アクティビティを開始する]({{site.baseurl}}/developer_guide/platform_integration_guides/swift/live_activities/live_activities/#step-2-start-the-activity)」を参照してください。

## AIとMLのオートメーション {#ai-and-ml-automation}

### アイテムのおすすめ {#item-recommendations}

{% multi_lang_include release_type.md release="Early access" %}

BrazeAI<sup>TM</sup>を使用すると、最も人気のある製品を計算したり、特定のカタログのパーソナライズされたAIレコメンデーションを作成したりできます。詳細については、[アイテムのおすすめについて]({{site.baseurl}}/user_guide/brazeai/item_recommendations/)を参照してください。

### アプリ内メッセージコンテンツのQA {#qa-in-app-message-content}

{% multi_lang_include release_type.md release="General availability" %}

以前は、BrazeダッシュボードでBrazeAI<sup>TM</sup>を使用してSMSおよびプッシュ通知コンテンツの品質保証を実行できました。[アプリ内メッセージコンテンツのQA]({{site.baseurl}}/user_guide/brazeai/operator/capabilities/#review-content-quality)も実行できるようになりました。

## 新しいBrazeパートナーシップ {#new-braze-partnerships}

### Census - コホートインポート {#census-cohort-import}

[コホートユーザーをBrazeからCensus]({{site.baseurl}}/partners/data_and_analytics/reverse_etl/census/census_cohort_import/)にインポートできるようになりました。Censusは、SnowflakeやBigQueryなどのクラウドデータウェアハウスをBrazeに接続するデータアクティベーションプラットフォームです。マーケティングチームは、ファーストパーティデータの力を解き放ち、ダイナミックなオーディエンスセグメントを構築し、顧客属性を同期してキャンペーンをパーソナライズし、Braze内のすべてのデータを最新の状態に保つことができます。
