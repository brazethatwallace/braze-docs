# 2024年8月20日リリース {#august-20-2024-release}

## 新しいユースケース {#new-use-cases}

### カタログ {#catalogs}

カタログにはあらゆる種類のデータを取り込むことができます。通常、このデータは商品、割引、プロモーション、イベントなど、提供物に関するメタデータです。[ユースケース]({{site.baseurl}}/user_guide/data/activation/catalogs)を読んで、このデータを活用してユーザーに関連性の高いメッセージングをターゲティングする方法をご確認ください。

### インテリジェンススイート {#intelligence-suite}

インテリジェンススイートは、ユーザー履歴やキャンペーン、キャンバスのパフォーマンスを分析し、エンゲージメント、閲覧数、コンバージョンを向上させるための自動調整を行う強力な機能を提供します。これらの機能がさまざまな業界にどのように役立つかについて、いくつかの例を[ユースケース]({{site.baseurl}}/user_guide/brazeai/intelligence_suite)でご確認ください。

## ホームダッシュボードの更新 {#home-dashboard-update}

Brazeダッシュボードでは、最近編集または作成したファイルに簡単にアクセスして、[前回の続きから再開]({{site.baseurl}}/user_guide/data_and_analytics/analytics/home_dashboard#pick-up-where-you-left-off)できます。このセクションは、Brazeダッシュボードの**ホーム**ページの上部に表示されます。

## データの柔軟性 {#data-flexibility}

### Data Transformationのテンプレートと新しい送信先 {#data-transformation-templates-and-new-destination}

{% multi_lang_include release_type.md release="General availability" %}

専用の[テンプレートライブラリ]({{site.baseurl}}/user_guide/data/unification/data_transformation/creating_a_transformation#step-2-create-a-transformation)を使用してData Transformationを構築すると、デフォルトのコードの代わりに、特定の外部プラットフォームとの連携を簡単に始めることができます。送信先として**POST: Send messages immediately via API Only**を選択し、ソースプラットフォームからのwebhookを変換してユーザーに即時メッセージを送信できるようになりました。

### ユーザーの一括マージ {#merge-users-in-bulk}

{% multi_lang_include release_type.md release="General availability" %}

重複するユーザープロファイルが見つかった場合、これらのユーザーを[一括マージ]({{site.baseurl}}/user_guide/audience/manage_audience/merge_duplicate_users#bulk-merging)して、データを効率化できます。

### カスタム属性のエクスポート {#export-custom-attributes}

{% multi_lang_include release_type.md release="General availability" %}

**カスタム属性**ページで**Export all**を選択すると、[カスタム属性のリストをCSVファイルとしてエクスポート]({{site.baseurl}}/user_guide/data_and_analytics/custom_data/custom_attributes#exporting-data)できます。CSVファイルが生成され、ダウンロードリンクがメールで送信されます。

### CurrentsのIP許可リスト {#currents-ip-allowlisting}

Brazeは、リストされたIPからCurrentsデータを送信します。これらのIPは、[許可リスト]({{site.baseurl}}/user_guide/data/distribution/braze_currents/setting_up_currents)にオプトインされたAPIキーに自動的かつ動的に追加されます。

## 堅牢なチャネル {#robust-channels}

### 新しいセグメントビルダー体験 {#new-segment-builder-experience}

{% multi_lang_include release_type.md release="General availability" %}

[更新された体験]({{site.baseurl}}/user_guide/audience/segments/creating_a_segment)を使用してセグメントを構築できます。セグメントはデータの変化に応じてリアルタイムに更新され、ターゲティングやメッセージングの目的に合わせて必要な数だけセグメントを作成できます。

### セグメント別の指標 {#metrics-by-segments}

[クエリビルダー]({{site.baseurl}}/user_guide/analytics/reports/query_builder)のレポートテンプレートを使用して、キャンペーン、キャンバス、バリアント、およびステップのパフォーマンス指標をセグメント別に分析できます。

### 電話番号の取得 {#phone-number-acquisition}

WhatsAppメッセージングチャネルを使用するには、WhatsAppの[Cloud API](https://developers.facebook.com/docs/whatsapp/cloud-api/phone-numbers)または[On-Premises API](https://developers.facebook.com/docs/whatsapp/on-premises/phone-numbers)の要件を満たす電話番号が必要です。

Brazeが電話番号をプロビジョニングすることはないため、ご自身で電話番号を取得する必要があります。ビジネス向け電話プロバイダーを通じてSIMカード付きの物理的な電話を購入するか、パートナーであるTwilioまたはInfobipを利用できます。**TwilioまたはInfobipのアカウントはご自身でご用意いただく必要があります。Brazeを通じてこの手続きを行うことはできません。**

## Brazeの新しいパートナーシップ {#new-braze-partnerships}

### Zendesk Chat - インスタントチャット {#zendesk-chat-instant-chat}

Brazeと[Zendesk Chat]({{site.baseurl}}/partners/zendesk_chat)の連携では、各プラットフォームのwebhookを使用して双方向のSMS会話を設定します。ユーザーがサポートをリクエストすると、Zendeskにチケットが作成されます。エージェントの応答はAPIトリガーのSMSキャンペーンを通じてBrazeに転送され、ユーザーの返信はZendeskに送り返されます。

## SDKの更新 {#sdk-updates}

最新のSDK更新がリリースされました。破壊的な更新はSDK更新セクションに記載されています。その他すべての更新は、対応するSDKの変更ログで確認できます。

- [Swift SDK 10.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - [`Braze.Notifications.subscribeToUpdates(payloadTypes:_:)`](https://braze-inc.github.io/braze-swift-sdk/documentation/brazekit/braze/notifications-swift.class/subscribetoupdates(payloadtypes:_:))でプッシュイベントを購読する際に、以下の変更が行われました。
        - `update`クロージャは、デフォルトで「Push Opened」と「Push Received」の両方のイベントによってトリガーされるようになりました。以前は、「Push Opened」イベントによってのみトリガーされていました。
            - 引き続き「Push Opened」イベントのみを購読するには、`payloadTypes`パラメーターに`[.opened]`を渡してください。あるいは、`update`クロージャを実装して、`Braze.Notifications.Payload`の`type`が`.opened`であるかを確認することもできます。
        - `content-available: true`を含むプッシュ通知を受信した場合、[`Braze.Notifications.Payload.type`](https://braze-inc.github.io/braze-swift-sdk/documentation/brazekit/braze/notifications-swift.class/payload/type)は`.opened`ではなく`.received`になります。
