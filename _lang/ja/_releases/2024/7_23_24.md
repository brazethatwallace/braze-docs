# 2024年7月23日リリース {#july-23-2024-release}

## Braze Docsの更新 {#braze-docs-updates}

### DiátaxisとBraze Docs {#ditaxis-and-braze-docs}

現在、[Diátaxis](https://diataxis.fr/)と呼ばれるフレームワークを使用して、ドキュメントの標準化を進めています。これにより、チュートリアル、ハウツーガイド、リファレンス、説明といった目的別にコンテンツを整理し、必要な情報をより迅速に見つけられるようになります。

## データの柔軟性 {#data-flexibility}

### カスタムイベントと属性のエクスポート {#export-custom-events-and-attributes}

{% multi_lang_include release_type.md release="General availability" %}

[`/custom_attributes`]({{site.baseurl}}/api/endpoints/export/custom_attributes/get_custom_attributes) および [`/events`]({{site.baseurl}}/api/endpoints/export/custom_events/get_custom_events_data) エンドポイントを使用して、カスタムイベントとカスタム属性をエクスポートできるようになりました。

### ユーザー向けの新しいCurrents権限 {#new-currents-permissions-for-users}

ユーザー向けに2つの新しい権限設定が追加されました：**View Currents Integrations** と **Edit Currents Integrations** です。[ユーザー権限]({{site.baseurl}}/user_guide/administer/global/user_management/permissions)の詳細をご覧ください。

### Snowflakeデータ保持ポリシーの更新 {#update-to-snowflake-data-retention-policy}

2024年8月27日より、2年以上前のすべてのSnowflake Secure Data Sharingイベントデータから個人を特定できる情報（PII）が削除されます。Snowflakeを使用している場合は、保持ポリシーが適用される前にSnowflakeアカウントにコピーを保存することで、環境内に完全なイベントデータを保持することができます。[Snowflakeデータ保持]({{site.baseurl}}/partners/data_and_analytics/data_warehouses/snowflake/data_retention)の詳細をご覧ください。

## 複数のWhatsApp Businessアカウント {#multiple-whatsapp-business-accounts}

{% multi_lang_include release_type.md release="General availability" %}

各ワークスペースに複数のWhatsApp Businessアカウントと購読グループ（および電話番号）を追加できるようになりました。詳細については、[複数のWhatsApp Businessアカウント]({{site.baseurl}}/user_guide/channels/whatsapp/whatsapp_setup/multiple_business_accounts)を参照してください。

### SMS地理的許可 {#sms-geographic-permissions}

SMS地理的許可は、SMSメッセージを送信できる国に対する制御を実施することで、セキュリティを強化し、不正なSMSトラフィックから保護します。SMSメッセージが承認された地域にのみ送信されるように国の許可リストを指定する方法については、[SMS国別許可リストの設定]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_setup/subscription_groups/geographic_permissions#selecting-countries)を参照してください。

### LINEとBraze {#line-and-braze}

{% multi_lang_include release_type.md release="Beta" %}

[LINE](https://www.lycbiz.com/sites/default/files/media/jp/download/LINE%20Business%20Guide_202310-202403.pdf)は、月間9,500万人以上のアクティブユーザーを持つ日本で最も人気のあるメッセージングアプリです。LINEアカウントをBrazeと統合することで、ゼロパーティおよびファーストパーティの顧客データを活用し、顧客の好み、行動、クロスチャネルのインタラクションに基づいて、適切な顧客に魅力的なLINEメッセージを送信できます。始めるには、[LINE]({{site.baseurl}}/user_guide/channels/line)を参照してください。

### Shopify：値下げと再入荷 {#shopify-price-drops-and-back-in-stock}

{% multi_lang_include release_type.md release="Early access" %}

Shopifyとの連携により、[値下げ]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/price_drop_notifications)や[再入荷商品]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/back_in_stock_notifications)のカスタム通知を作成できるようになりました。

## AIとMLのオートメーション {#ai-and-ml-automation}

### 重複ユーザーのルールベースのマージ {#rules-based-merging-for-duplicate-users}

以前は、Brazeで重複ユーザーを個別にまたは一括で検索してマージすることができました。現在は、重複がどのように解決されるかを制御するルールを作成できるため、最も関連性の高いユーザーが保持されます。詳しくは、[ルールベースのマージ]({{site.baseurl}}/user_guide/engagement_tools/segments/user_profiles/duplicate_users#rules-based-merging)を参照してください。

### AI Liquidアシスタント {#ai-liquid-assistant}

{% multi_lang_include release_type.md release="Beta" %}

AI LiquidアシスタントはBrazeAI<sup>TM</sup>を搭載したチャットアシスタントで、メッセージコンテンツをパーソナライズするために必要なLiquidの生成を支援します。テンプレートからLiquidを生成したり、パーソナライズされたLiquidの提案を受けたり、BrazeAI<sup>TM</sup>のサポートで既存のLiquidを最適化したりできます。AI Liquidアシスタントは、使用されているLiquidを説明するアノテーションも提供するため、Liquidの理解を深め、自分で書けるようになります。

始めるには、[AI Liquidアシスタント]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#generate-liquid)を参照してください。
