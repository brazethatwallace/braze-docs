# 2024年7月23日リリース {#july-23-2024-release}

## Braze Docsのアップデート {#braze-docs-updates}

### DiátaxisとBraze Docs {#ditaxis-and-braze-docs}

私たちは、[Diátaxis](https://diataxis.fr/)と呼ばれるフレームワークを使ってドキュメントの標準化を進めています。これにより、チュートリアル、ハウツーガイド、リファレンス、説明といった目的別にコンテンツを整理し、必要な情報をより素早く見つけられるようになります。

## データの柔軟性 {#data-flexibility}

### カスタムイベントとカスタム属性のエクスポート {#export-custom-events-and-attributes}

{% multi_lang_include release_type.md release="General availability" %}

[`/custom_attributes`]({{site.baseurl}}/api/endpoints/export/custom_attributes/get_custom_attributes/)および[`/events`]({{site.baseurl}}/api/endpoints/export/custom_events/get_custom_events_data/)エンドポイントを使用して、カスタムイベントやカスタム属性をエクスポートできるようになりました。

### ユーザー向けの新しいCurrents権限 {#new-currents-permissions-for-users}

ユーザーに2つの新しい権限設定が追加されました。**View Currents Integrations**と**Edit Currents Integrations**です。詳細については、[ユーザー権限]({{site.baseurl}}/user_guide/administer/global/user_management/permissions/)を参照してください。

### Snowflakeデータリテンションポリシーの更新 {#update-to-snowflake-data-retention-policy}

2024年8月27日より、個人を特定できる情報（PII）は、作成から2年を超えたすべてのSnowflake Secure Data Sharingイベントデータから削除されます。Snowflakeを使用している場合、リテンションポリシーが適用される前にSnowflakeアカウントにコピーを保存することで、完全なイベントデータを環境に保持できます。詳細については、[Snowflakeデータリテンション]({{site.baseurl}}/partners/data_and_analytics/data_warehouses/snowflake/data_retention/)を参照してください。

## 強力なチャネル {#robust-channels}

### 複数のWhatsAppビジネスアカウント {#multiple-whatsapp-business-accounts}

{% multi_lang_include release_type.md release="General availability" %}

各ワークスペースに複数のWhatsApp Businessアカウントとサブスクリプショングループ（および電話番号）を追加できるようになりました。詳しくは、[複数のWhatsAppビジネスアカウント]({{site.baseurl}}/user_guide/channels/whatsapp/whatsapp_setup/multiple_business_accounts/)を参照してください。

### SMSの地理的権限 {#sms-geographic-permissions}

SMS Geographic Permissionsは、SMSメッセージを送信できる国をコントロールすることで、セキュリティを強化し、不正なSMSトラフィックから保護します。SMSメッセージが承認された地域にのみ送信されるように国の許可リストを指定する方法については、[SMS国の許可リストの設定]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_setup/subscription_groups/geographic_permissions/#selecting-countries)を参照してください。

### LINEとBraze {#line-and-braze}

{% multi_lang_include release_type.md release="Beta" %}

[LINE](https://www.lycbiz.com/sites/default/files/media/jp/download/LINE%20Business%20Guide_202310-202403.pdf)は、月間アクティブユーザー数が9,500万人を超える日本で最も人気のあるメッセージングアプリです。LINEアカウントをBrazeと統合することで、ゼロパーティおよびファーストパーティの顧客データを活用し、顧客の嗜好、行動、クロスチャネルのインタラクションに基づいて、適切な顧客に魅力的なLINEメッセージを送信できます。開始するには、[LINE]({{site.baseurl}}/line/)を参照してください。

### Shopify：値下げと再入荷 {#shopify-price-drops-and-back-in-stock}

{% multi_lang_include release_type.md release="Early access" %}

Shopifyでは、[値下げ]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/price_drop_notifications/)や[再入荷商品]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/back_in_stock_notifications/)のカスタム通知を作成できるようになりました。

## AIとMLのオートメーション {#ai-and-ml-automation}

### 重複ユーザーのルールベースのマージ {#rules-based-merging-for-duplicate-users}

以前は、Brazeで重複するユーザーを個別または一括で検索してマージできました。今後は、重複の解決方法をコントロールするルールを作成できるようになり、最も関連性の高いユーザーが保持されます。詳細については、[ルールベースのマージ]({{site.baseurl}}/user_guide/engagement_tools/segments/user_profiles/duplicate_users/#rules-based-merging)を参照してください。

### AI Liquidアシスタント {#ai-liquid-assistant}

{% multi_lang_include release_type.md release="Beta" %}

AI Liquidアシスタントは、BrazeAI<sup>TM</sup>を搭載したチャットアシスタントで、メッセージコンテンツをパーソナライズするために必要なLiquidの生成を支援します。テンプレートからのLiquidの生成、パーソナライズされたLiquidの提案の受け取り、BrazeAI<sup>TM</sup>のサポートによる既存のLiquidの最適化が可能です。AI Liquidアシスタントには、使用されているLiquidを説明する注釈も用意されているため、Liquidの理解を深めたり、自分で書く方法を学んだりできます。

開始するには、[AI Liquidアシスタント]({{site.baseurl}}/user_guide/brazeai/generative_ai/liquid/)を参照してください。
