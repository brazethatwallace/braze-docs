## データの柔軟性 {#data-flexibility}

### APIトリガーキャンペーンの添付ファイル {#attachments-for-api-triggered-campaigns}

{% multi_lang_include release_type.md release="General availability" %}

[`/campaigns/trigger/send`エンドポイント]({{site.baseurl}}/api/endpoints/messaging/send_messages/post_send_triggered_campaigns)で、添付ファイルがサポートされるようになりました（`/messages/send`エンドポイントがメールの添付ファイルをサポートしているのと同様です）。

### データウェアハウスの追加サポート {#additional-data-warehouse-support}

{% multi_lang_include release_type.md release="Early access" %}

Brazeの[クラウドデータインジェスト（CDI）]({{site.baseurl}}/user_guide/data/unification/cloud_ingestion/connected_sources)で、BigQuery、Databricks、Redshift、Snowflakeがサポートされるようになりました。

### WhatsApp電話番号の移行 {#whatsapp-phone-number-migration}

MetaのEmbedded Signupを使用して、WhatsApp Businessアカウント間でWhatsApp電話番号を移行できます。詳しくは[WhatsApp Businessアカウント間の移行]({{site.baseurl}}/user_guide/channels/whatsapp/whatsapp_setup/whatsapp_phone_numbers/migrate_a_phone_number#migrate-between-whatsapp-business-accounts)をご覧ください。

## 創造性の解放 {#unlocking-creativity}

### デバイス別エンゲージメント {#engagement-by-device}

{% multi_lang_include release_type.md release="General availability" %}

新しい**デバイス別エンゲージメント**レポートでは、ユーザーがメールのエンゲージメントにどのデバイスを使用しているかの内訳を確認できます。このデータは、モバイル、デスクトップ、タブレット、その他のデバイスタイプ全体でのメールエンゲージメントを追跡します。[レポートとメールパフォーマンスダッシュボード]({{site.baseurl}}/user_guide/analytics/dashboards/channel_performance)の詳細をご覧ください。

### キャンバスフローでのWhatsAppおよびSMS Liquidプロパティ {#whatsapp-and-sms-liquid-properties-in-canvas-flow}

{% multi_lang_include release_type.md release="General availability" %}

[キャンバスフローでのWhatsAppおよびSMS Liquidプロパティ]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas/context_and_event_properties)のサポートが追加されました。アクションパスステップに「SMS受信メッセージを送信」または「WhatsApp受信メッセージを送信」トリガーが含まれている場合、後続のキャンバスステップにSMSまたはWhatsApp Liquidプロパティを含めることができます。これはキャンバスでのイベントプロパティの動作と同様です。これにより、メッセージを活用してファーストパーティデータをユーザープロファイルや会話型メッセージングに保存・参照できます。

### 繰り返しキャンバスでのパーソナライズされたパス {#personalized-paths-in-recurring-canvases}

{% multi_lang_include release_type.md release="Early access" %}

キャンバスのパーソナライズされたパスを使用すると、コンバージョンの可能性に基づいて、キャンバスジャーニーの任意のポイントを個々のユーザー向けにパーソナライズできます。パーソナライズされたパスが繰り返しキャンバスでも利用可能になりました。[パーソナライズされたバリアント]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step/personalized_paths)の詳細をご覧ください。

### セグメントのトラブルシューティング {#segments-troubleshooting}

セグメントを使用していますか？覚えておくべき[トラブルシューティングの手順と考慮事項]({{site.baseurl}}/user_guide/audience/segments/troubleshooting)をご確認ください。

### Liquidのハイライト表示 {#liquid-highlighting}

アクセシビリティガイドラインをより適切にサポートするために、[Liquidで使用されるカラーコーディング]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid)を改善しました。

## 堅牢なチャネル {#robust-channels}

### SMS地理的権限 {#sms-geographic-permissions}

{% multi_lang_include release_type.md release="Early access" %}

SMS地理的権限は、SMSメッセージを送信できる国に対する制御を適用することで、セキュリティを強化し、不正なSMSトラフィックから保護します。管理者は、SMSメッセージが承認された地域にのみ送信されるように、国の許可リストを指定できるようになりました。詳細については、[SMS地理的権限]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_setup/subscription_groups/geographic_permissions)を参照してください。

![最も一般的な国が上部に表示されている「国の許可リスト」ドロップダウン。]({% image_buster /assets/img/sms/allowlist_dropdown.png %}){: style="max-width:80%;"}

### SMS/MMSのベストプラクティス {#best-practices-for-smsmms}

Brazeでの[SMS/MMSのベストプラクティス]({{site.baseurl}}/sms_mms_rcs_best_practices)について、オプトアウト監視やトラフィックポンピングに関する推奨事項を含めて詳しくご覧ください。

### プッシュ購読解除のトラッキング {#tracking-push-unsubscribes}

プッシュ購読解除をトラッキングするためのヒントについては、新しい[ヘルプ記事]({{site.baseurl}}/user_guide/channels/push/reporting#push-performance)をご覧ください。

### Shopifyの`checkout.liquid`廃止 {#shopify-checkoutliquid-deprecation}

Shopifyの`checkout.liquid`のサポートは2024年8月に廃止が開始され、2025年8月に完了する予定です。Brazeがこの[移行をどのように処理するか]({{site.baseurl}}/releases/deprecations/shopify_checkout)について詳しくお読みください。

## SDKの更新 {#sdk-updates}

最新のSDK更新がリリースされました。破壊的な更新はSDK更新セクションに記載されています。その他すべての更新は、対応するSDKの変更ログで確認できます。

- [SWIFT SDK 9.3.0](https://github.com/braze-inc/braze-swift-sdk/releases/tag/9.3.0)
    - 既存のフィーチャーフラグAPIを非推奨とし、将来のバージョンで削除される予定です：
        - `Braze.FeatureFlag.jsonStringProperty(key:)` は非推奨になりました。
        - `Braze.FeatureFlag.jsonObjectProperty(key:)` は非推奨となり、代わりに `Braze.FeatureFlag.jsonProperty(key:)` を使用してください。
- [Roku SDK 2.2.0](https://github.com/braze-inc/braze-roku-sdk/blob/main/CHANGELOG.md)
- [Braze Expo Plugin 2.1.2](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
