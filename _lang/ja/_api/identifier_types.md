# API識別子タイプ {#api-identifier-types}

> このリファレンスガイドでは、Brazeダッシュボード内で見つけることができるさまざまな種類のAPI識別子、それらの目的、それらを見つける場所、およびそれらが通常どのように使用されるかについて説明します。REST APIキーまたはワークスペースAPIキーに関する情報については、[API概要]({{site.baseurl}}/api/basics)を参照してください。

次の識別子を使用して、Braze外部APIからテンプレート、キャンバス、キャンペーン、またはセグメントにアクセスできます。すべてのメッセージは[UTF-8](https://en.wikipedia.org/wiki/UTF-8)エンコーディングに従う必要があります。

## アプリ識別子 {#app-identifier}

アプリ識別子（`app_id`）は、ワークスペース内の特定のアプリにアクティビティを関連付けるためのパラメーターです。ワークスペース内のどのアプリとやり取りしているかを指定します。例えば、iOSアプリ用の`app_id`、Androidアプリ用の`app_id`、Web連携用の`app_id`がそれぞれあることがわかります。Brazeでは、Brazeがサポートするさまざまなプラットフォームタイプにまたがって、同じプラットフォーム用に複数のアプリが存在する場合があります。

### どこで確認できますか？ {#where-can-i-find-it}

`app_id`を確認するには2つの方法があります。

{% tabs local %}
{% tab アプリ識別子 %}
**設定** > **APIと識別子** > **アプリ識別子**に移動します。各アプリのAPIキーは**識別子**列に表示されます。
{% endtab %}

{% tab アプリの設定 %}
**設定** > **アプリの設定**に移動します。APIキーは設定セクションの**APIキー**フィールドの横に表示されます。

{% endtab %}
{% endtabs %}

### 何に使用できますか？ {#what-can-it-be-used-for}

Brazeのアプリ識別子は、SDKの連携時に使用されるほか、REST API呼び出しで特定のアプリを参照するためにも使用されます。`app_id`を使用すると、特定のアプリで発生したカスタムイベントのデータ取得、アンインストール統計、新規ユーザー統計、DAU統計、セッション開始統計の取得など、さまざまなことが可能です。

{% alert tip %}
`app_id`の入力を求められても、アプリを扱っていない場合があります。これは特定のプラットフォームに固有のレガシーフィールドであるため、この必須パラメーターのプレースホルダーとして任意の文字列を含めることで、このフィールドを省略できます。
{% endalert %}

### 複数のアプリ識別子 {#multiple-app-identifiers}

SDKのセットアップ時に、複数のアプリ識別子の最も一般的なユースケースは、デバッグビルドとリリースビルドのバリアントでそれぞれ識別子を分けることです。

ビルドで複数のアプリ識別子を簡単に切り替えるには、関連する[ビルドバリアント](https://developer.android.com/studio/build/build-variants.html)ごとに個別の`braze.xml`ファイルを作成することをお勧めします。ビルドバリアントは、ビルドタイプとプロダクトフレーバーの組み合わせです。デフォルトでは、新しいAndroidプロジェクトは`debug`と`release`のビルドタイプで構成され、プロダクトフレーバーはありません。

関連するビルドバリアントごとに、`src/<build variant name>/res/values/`に新しい`braze.xml`を作成します。

```xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
<string name="com_braze_api_key">{YOUR_BUILD_VARIANT_API_KEY}</string>
</resources>
```
ビルドバリアントがコンパイルされると、新しい識別子が使用されます。

## テンプレート識別子 {#template-identifier}

[テンプレート]({{site.baseurl}}/api/endpoints/templates)識別子またはテンプレートIDは、ダッシュボード内の特定のテンプレートに対してBrazeが生成するランダムなキーです。テンプレートIDは各テンプレートに固有であり、APIを通じてテンプレートを参照するために使用できます。

テンプレートは、キャンペーン用のHTMLデザインを外部に委託している場合に非常に便利です。テンプレートが作成されると、特定のキャンペーンに限定されず、ニュースレターのように一連のキャンペーンに適用できるテンプレートが手に入ります。

### どこで確認できますか？

テンプレートIDは次の2つの方法で確認できます。

{% tabs local %}
{% tab テンプレート %}
**テンプレート**に移動し、テンプレートページを選択してから、既存のテンプレートを選択します。目的のテンプレートがまだ存在しない場合は、新規作成して保存してください。個別のテンプレートページの下部に、テンプレート識別子が表示されます。
{% endtab %}

{% tab APIキー %}
**設定** > **APIと識別子**に移動します。ここでは、Brazeが**追加のAPI識別子**検索を提供しており、特定の識別子を検索できます。

{% endtab %}
{% endtabs %}

### 何に使用できますか？

- APIを使用してテンプレートを更新する
- 特定のテンプレートに関する情報を取得する

## キャンバス識別子 {#canvas-identifier}

[キャンバス]({{site.baseurl}}/user_guide/messaging/canvas)識別子またはキャンバスIDは、ダッシュボード内の特定のキャンバスに対してBrazeが生成するランダムなキーです。キャンバスIDは各キャンバスに固有であり、APIを通じてキャンバスを参照するために使用できます。

バリアントを持つキャンバスがある場合、全体のキャンバスIDに加えて、メインキャンバスの下にネストされた個別のバリアントキャンバスIDも存在することに留意してください。

### どこで確認できますか？

キャンバスIDはダッシュボードで確認できます。**メッセージング** > **キャンバス**に移動し、既存のキャンバスを選択します。目的のキャンバスがまだ存在しない場合は、作成して保存してください。個別のキャンバスページの下部で、**Analyze Variants**をクリックします。ウィンドウが表示され、下部にキャンバスAPI識別子が表示されます。

### 何に使用できますか？

- 特定のメッセージの分析を追跡する
- キャンバスのパフォーマンスに関する高レベルの集計統計を取得する
- 特定のキャンバスの詳細を取得する
- Currentsと組み合わせて、キャンバスに対する「全体像」アプローチとしてユーザーレベルのデータを取り込む
- APIトリガー配信と組み合わせて、トランザクションメッセージの統計を収集する

## キャンペーン識別子 {#campaign-identifier}

[キャンペーン]({{site.baseurl}}/user_guide/messaging/campaigns)識別子またはキャンペーンIDは、ダッシュボード内の特定のキャンペーンに対してBrazeが生成するランダムなキーです。キャンペーンIDは各キャンペーンに固有であり、APIを通じてキャンペーンを参照するために使用できます。

バリアントを持つキャンペーンがある場合、全体のキャンペーンIDと、メインキャンペーンの下にネストされた個別のバリアントキャンペーンIDの両方が存在することに注意してください。

### どこで確認できますか？

キャンペーンIDは次の2つの方法で確認できます。

{% tabs local %}
{% tab キャンペーン %}
**メッセージング** > **キャンペーン**に移動し、既存のキャンペーンを選択します。目的のキャンペーンがまだ存在しない場合は、作成して保存してください。個別のキャンペーンページの下部に、**キャンペーン API Identifier**が表示されます。

{% endtab %}

{% tab APIキー %}
**設定** > **APIと識別子**に移動します。ここでは、Brazeが**Additional API Identifiers**検索を提供しており、特定の識別子を検索できます。

{% endtab %}
{% endtabs %}

### 何に使用できますか？

- 特定のメッセージの分析をトラッキングする
- キャンペーンパフォーマンスに関する高レベルの集計統計を取得する
- 特定のキャンペーンの詳細を取得する
- Currentsと組み合わせて、キャンペーンに対する「全体像」アプローチのためのユーザーレベルのデータを取り込む
- APIトリガー配信と組み合わせて、トランザクションメッセージの統計を収集する
- **キャンペーン**ページでフィルター `api_id:YOUR_API_ID` を使用して[特定のキャンペーンを検索する]({{site.baseurl}}/user_guide/messaging/campaigns/manage_campaigns/search_campaigns)

## セグメント識別子 {#segment-identifier}

[セグメント]({{site.baseurl}}/user_guide/audience/segments)識別子またはセグメントIDは、ダッシュボード内の特定のセグメントに対してBrazeが生成するランダムなキーです。セグメントIDは各セグメントに固有であり、APIを通じてセグメントを参照するために使用できます。

### どこで確認できますか？

セグメントIDは、以下の2つの方法で確認できます。

{% tabs local %}
{% tab Segments %}
**オーディエンス** > **セグメント**に移動し、既存のセグメントを選択します。目的のセグメントがまだ存在しない場合は、新しく作成して保存してください。個別のセグメントページの下部に、セグメント識別子が表示されます。

{% endtab %}

{% tab API Keys %}
**設定** > **APIと識別子**に移動します。ここでBrazeは**追加のAPI識別子**検索を提供しており、特定の識別子を検索できます。

{% endtab %}
{% endtabs %}

### 何に使用できますか？

- 特定のセグメントの詳細を取得する
- 特定のセグメントの分析を取得する
- 特定のセグメントでカスタムイベントが記録された回数を取得する
- APIからセグメントのメンバーに対してキャンペーンを指定して送信する

## 送信識別子 {#send-identifier}

送信識別子（送信ID）は、特定のメッセージ送信に対して分析を追跡するために、Brazeによって生成されるか、ユーザー自身が作成するキーです。送信識別子を使用すると、[`/sends/data_series` エンドポイント]({{site.baseurl}}/api/endpoints/export/campaigns/get_send_analytics)を通じて、特定のキャンペーン送信インスタンスの分析データを取得できます。

### どこで確認できますか？

ブロードキャストとして送信されるAPIおよびAPIトリガーキャンペーンは、送信識別子が指定されていない場合、自動的に送信識別子を生成します。独自の送信識別子を指定する場合は、まず[`/sends/id/create` エンドポイント]({{site.baseurl}}/api/endpoints/messaging/send_messages/post_create_send_ids)を使用して作成する必要があります。識別子はすべてASCII文字で、最大64文字までです。同じキャンペーンの複数の送信の分析をグループ化する場合は、それらの送信間で送信識別子を再利用できます。

### 何に使用できますか？
送信ごとにキャンペーンを作成することなく、プログラムによってメッセージのパフォーマンスを送信および追跡できます。

## 購読グループ識別子 {#subscription-group-identifier}

購読グループ識別子（購読グループID）は、特定の購読グループに対してBrazeが生成するキーです。IDは各購読グループに固有であり、APIを通じて購読グループを参照するために使用できます。

### どこで確認できますか？

**オーディエンス** > **サブスクリプション**に移動し、該当する購読グループの横にあるIDをコピーします。

### 何に使用できますか？

- ユーザーの購読グループを一覧表示する
- ユーザーの購読グループステータスを取得する
- ユーザーの購読グループステータスを更新する
