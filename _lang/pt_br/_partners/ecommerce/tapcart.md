# Tapcart

> A [Tapcart](https://www.tapcart.com/) é uma plataforma líder de comércio móvel para marcas com tecnologia Shopify, que permite aos comerciantes criar apps móveis personalizados que proporcionam experiências de compra personalizadas e envolventes que seus clientes adoram.

_Essa integração é mantida pela Tapcart._

## Pré-requisitos {#prerequisites}

| Requisito              | Descrição                                                                                                                                         |
|--------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| Conta Tapcart Enterprise | A integração está disponível apenas para **clientes do Tapcart Enterprise**.                                                                              |
| Chave de API do app da Braze         | A [chave de API do identificador do app da Braze](https://www.braze.com/docs/api/identifier_types) é obrigatória. Cada plataforma (como iOS ou Android) tem seu próprio identificador de app. No dashboard da Braze, acesse **Configurações** > **APIs e identificadores** > **App Identifiers**. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Pré-requisitos" }

## Sobre a integração {#about-the-integration}

Para saber como integrar o Tapcart à Braze, consulte o [guia de integração do Tapcart](https://help.tapcart.com/hc/en-us/articles/36413383526675-Braze-Integration) diretamente no site deles. Após a integração, você poderá aproveitar os seguintes recursos do Tapcart na Braze:

- Integração básica de SDK
- Notificações por push para iOS e Android
- Mensagens push avançadas
- Rastreamento e segmentação da jornada do usuário

Os seguintes recursos não são suportados no momento: Push Stories, push para a web, personalização de mensagens no app.
