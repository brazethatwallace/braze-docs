# OpenAI

> A [OpenAI](https://openai.com/) cria modelos avançados de IA, como o GPT, que possibilitam a compreensão e a geração de linguagem natural, capacitando as marcas a criar e escalar interações significativas com os clientes.

{% multi_lang_include alerts/important_alerts.md alert='Braze Agents' %}

_Essa integração é mantida pela OpenAI._

## Sobre a integração {#about-the-integration}

A integração entre a Braze e a OpenAI permite conectar sua chave de API or interface de programação do aplicativo (API) da OpenAI à Braze para que você possa usar os modelos da OpenAI ao criar agentes de IA personalizados. Com essa integração, seus agentes podem gerar textos personalizados, tomar decisões em tempo real ou atualizar campos do catálogo usando os grandes modelos de linguagem da OpenAI.

## Pré-requisitos {#prerequisites}

| Requisitos | Descrição |
|---|---|
| Conta OpenAI com chave de API or interface de programação do aplicativo (API) | Uma conta OpenAI com uma chave de API or interface de programação do aplicativo (API). Entre em contato com o administrador ou com o [suporte da OpenAI](https://help.openai.com/) em caso de problemas ou dúvidas. |
| Instância da Braze | Você pode encontrar sua instância da Braze na [página de visão geral da API or interface de programação do aplicativo (API)]({{site.baseurl}}/api/basics/#endpoints) ou com seu gerente de integração da Braze. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Pré-requisitos" }

## Integração {#integration}

Para conectar sua chave de API or interface de programação do aplicativo (API) da OpenAI à Braze:

1. Acesse **Integrações de parceiros** > **Parceiros de tecnologia** no dashboard da Braze e encontre a OpenAI.
2. Digite sua chave de API or interface de programação do aplicativo (API) da OpenAI.
3. Selecione **Salvar**.

Depois de salvar, você pode selecionar modelos da OpenAI ao [criar um agente personalizado]({{site.baseurl}}/user_guide/brazeai/agents/creating_agents/) no Console do agente.

Entre em contato com o [suporte da OpenAI](https://help.openai.com/) em caso de problemas ou dúvidas sobre sua integração.
