# Lançamento em 6 de fevereiro de 2024 {#february-6-2024-release}

## Manifesto de privacidade da Braze {#braze-privacy-manifest}

A Braze lançou seu próprio manifesto de privacidade, juntamente com novas APIs flexíveis que redirecionam automaticamente os dados de rastreamento declarados para endpoints dedicados `-tracking`. Para saber mais, consulte o [manifesto de privacidade da Braze]({{site.baseurl}}/developer_guide/analytics/managing_data_collection/?sdktab=swift#swift_privacy-manifest).

## Política de consentimento do usuário da UE do Google {#google-eu-user-consent-policy}

O Google está atualizando sua [Política de consentimento do usuário da UE](https://www.google.com/about/company/user-consent-policy/) em resposta às alterações na [Lei de Mercados Digitais (DMA)](https://ads-developers.googleblog.com/2023/10/updates-to-customer-match-conversion.html), que entra em vigor em 6 de março de 2024. Essa nova alteração exige que os anunciantes divulguem determinadas informações aos seus usuários finais do EEE e do Reino Unido, bem como obtenham deles os consentimentos necessários. Como parte dessa mudança futura, você pode [coletar ambos os sinais de consentimento na Braze como atributos personalizados]({{site.baseurl}}/partners/canvas_steps/google_audience_sync/#collecting-consent-for-eea-and-uk-end-users). A Braze sincronizará os dados desses atributos personalizados com os campos de consentimento apropriados no Google.

O novo artigo de ajuda [Reduzir o tamanho da carga útil de notificações por push]({{site.baseurl}}/user_guide/channels/push/best_practices/#reduce-push-notification-payload-size) fornece algumas dicas para reduzir o tamanho da carga útil de suas notificações por push caso você não consiga lançar uma Campaign ou etapa do Canvas devido aos limites de tamanho da carga útil de push.

### Adicionar endereços BCC à sua Campaign ou ao Canvas {#add-bcc-addresses-to-your-campaign-or-canvas}

{% multi_lang_include release_type.md release="General availability" %}

Você pode anexar um [endereço BCC]({{site.baseurl}}/user_guide/administrative/app_settings/email_settings/?tab=bcc%20address#outbound-email-settings) a uma mensagem de e-mail. Isso enviará uma cópia idêntica da mensagem que o usuário receber para a sua caixa de entrada BCC. Dessa forma, você pode reter cópias das mensagens enviadas aos usuários para atender a requisitos de conformidade ou questões de suporte ao cliente.

### Links de cancelamento de inscrição com um clique para e-mails {#one-click-unsubscribe-links-for-emails}

O uso de um [cabeçalho list-unsubscribe]({{site.baseurl}}/user_guide/administrative/app_settings/email_settings/#list-unsubscribe-header) permite que os destinatários cancelem a inscrição de e-mails de marketing com um clique, exibindo um botão **Cancelar inscrição** na interface da caixa de correio, e não no corpo da mensagem.

## Novas parcerias Braze {#new-braze-partnerships}

### Criteo - Sincronização de público no Canvas {#criteo-canvas-audience-sync}

Usando a [sincronização de público da Braze com a Criteo]({{site.baseurl}}/partners/canvas_audience_sync/criteo_audience_sync/), as marcas podem optar por adicionar dados de usuários da sua própria integração da Braze às listas de clientes da Criteo para veicular anúncios com base em gatilhos comportamentais, segmentação e muito mais. Qualquer critério que você normalmente usaria para disparar uma mensagem (push, e-mail, SMS, webhook etc.) em um Canvas da Braze com base nos dados do seu usuário agora pode ser usado para disparar um anúncio para esse usuário nas suas listas de clientes da Criteo.

### Movable Ink - Conteúdo dinâmico {#movable-ink-dynamic-content}

A integração da API de dados do cliente do [Movable Ink]({{site.baseurl}}/partners/message_personalization/dynamic_content/movable_ink/#movable-ink) permite que os profissionais de marketing ativem os dados de eventos de clientes armazenados na Braze para gerar conteúdo personalizado no Movable Ink.

### Scuba Analytics - Análise de dados {#scuba-analytics-analytics}

O [Scuba Analytics]({{site.baseurl}}/partners/data_and_infrastructure_agility/analytics/scuba/#scuba-analytics) é uma plataforma de colaboração de dados full-stack, com machine learning, projetada para dados de séries temporais de alta velocidade. O Scuba permite exportar usuários (também chamados de atores) de forma seletiva e carregá-los na plataforma Braze. No Scuba, as propriedades de atores personalizados são usadas para analisar tendências comportamentais, ativar seus dados em várias plataformas e realizar modelagem preditiva usando machine learning.

## Atualizações do SDK {#sdk-updates}

As seguintes atualizações do SDK foram lançadas. As atualizações com breaking changes estão listadas abaixo; todas as outras atualizações podem ser encontradas verificando os changelogs correspondentes do SDK.

- [Plug-in Expo 2.0.0](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
    - Aumenta a versão mínima da plataforma iOS para `13.4`, de acordo com os [requisitos do Expo SDK 50](https://expo.dev/changelog/2024/01-18-sdk-50).
    - Esta versão requer a versão [8.3.0+](https://github.com/braze-inc/braze-react-native-sdk/releases/tag/8.3.0) do SDK React Native da Braze para oferecer suporte total ao Expo SDK 50.
- [React Native SDK 8.3.0](https://github.com/braze-inc/braze-react-native-sdk/blob/8.3.0/CHANGELOG.md)
- [Unity SDK 5.1.0](https://github.com/braze-inc/braze-unity-sdk/blob/master/CHANGELOG.md)
- [Android SDK 30.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
    - As WebViews usadas para In-App Messages foram atualizadas para usar o `WebViewAssetLoader`.
        - `WebSettings.allowFileAccess` agora está definido como false em `InAppMessageHtmlBaseView` e `BrazeWebViewActivity`.
        - Se estiver usando seu próprio `InAppMessageWebViewClient` ou `InAppMessageHtmlBaseView`, compare-os com as classes originais para garantir que sua implementação esteja carregando corretamente os ativos.
        - Se você não estiver usando classes personalizadas, tudo funcionará como antes.
- [Braze Swift SDK 6.6.2](https://github.com/braze-inc/braze-swift-sdk/blob/6.6.2/CHANGELOG.md)
- [Braze Swift SDK 7.6.0](https://github.com/braze-inc/braze-swift-sdk/releases/tag/7.6.0)
- [Xamarin SDK Versão 3.0.0](https://github.com/braze-inc/braze-xamarin-sdk/blob/master/CHANGELOG.md)
    - O pacote NuGet foi renomeado de `AppboyPlatformXamariniOSBinding` para [`BrazePlatform.BrazeiOSBinding`](https://www.nuget.org/packages/BrazePlatform.BrazeiOSBinding/).
        - Para usar o pacote atualizado, substitua todas as instâncias de `AppboyPlatformXamariniOSBinding;` por: using Braze;
    - Essa versão requer o uso do .NET 6+ e remove o suporte a projetos que usam o framework Xamarin. Consulte [a política da Microsoft](https://dotnet.microsoft.com/en-us/platform/support/policy/xamarin) sobre o fim do suporte para o Xamarin.
    - Atualização da vinculação do Android do [SDK da Braze para Android 26.3.2 para 29.0.1](https://github.com/braze-inc/braze-android-sdk/compare/v26.3.1...v29.0.1#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
- [Xamarin SDK 4.0.0](https://github.com/braze-inc/braze-xamarin-sdk/blob/master/CHANGELOG.md)
    - Esta versão atualiza a vinculação do iOS para usar o [Braze Swift SDK](https://github.com/braze-inc/braze-swift-sdk/). A maioria das APIs públicas do iOS foi alterada. Consulte nosso [guia de migração](https://braze-inc.github.io/braze-swift-sdk/documentation/braze/appboy-migration-guide/) (Swift) para obter orientação sobre as substituições a serem usadas. Oferecemos vinculações de compatibilidade para continuar usando as APIs públicas antigas.
        - A vinculação do iOS agora é composta de vários módulos:
            - **BrazeKit:** Biblioteca principal do SDK que oferece suporte a análise de dados e notificações por push (nuget: [Braze.iOS.BrazeKit](https://www.nuget.org/packages/Braze.iOS.BrazeKit)).
            - BrazeUI: Biblioteca de interface de usuário fornecida pela Braze para In-App Messages e Content Cards (nuget: [Braze.iOS.BrazeUI](https://www.nuget.org/packages/Braze.iOS.BrazeUI)).
            - BrazeLocation: Biblioteca de localização que fornece suporte para análise de dados de local e monitoramento de geofence (nuget: [Braze.iOS.BrazeLocation](https://www.nuget.org/packages/Braze.iOS.BrazeLocation)).
            - BrazeKitCompat: Biblioteca de compatibilidade com suporte para APIs anteriores à versão 4.0.0 (nuget: [Braze.iOS.BrazeKitCompat](https://www.nuget.org/packages/Braze.iOS.BrazeKitCompat)).
            - BrazeUICompat: Biblioteca de compatibilidade com suporte para APIs de interface do usuário anteriores à versão 4.0.0 (nuget: [Braze.iOS.BrazeUICompat](https://www.nuget.org/packages/Braze.iOS.BrazeUICompat)).
        - Consulte o BrazeiOSMauiSampleApp para ver a nova integração e o BrazeiOSMauiCompatSampleApp para ver o uso dos módulos de compatibilidade.
    - Atualização da vinculação do iOS para o [Braze Swift SDK 7.6.0](https://github.com/braze-inc/braze-swift-sdk/releases/tag/7.6.0).
    - A vinculação do iOS requer o uso do .NET 7 para compatibilidade com o Xcode 15.
- [Xamarin SDK 4.0.1](https://github.com/braze-inc/braze-xamarin-sdk/blob/master/CHANGELOG.md)
