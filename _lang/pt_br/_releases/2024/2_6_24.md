# Lançamento em 6 de fevereiro de 2024 {#february-6-2024-release}

## Manifesto de privacidade da Braze {#braze-privacy-manifest}

A Braze lançou seu próprio manifesto de privacidade, junto com novas APIs flexíveis que redirecionam automaticamente os dados de rastreamento declarados para endpoints dedicados `-tracking`. Para saber mais, consulte [Manifesto de privacidade da Braze]({{site.baseurl}}/developer_guide/analytics/managing_data_collection/?sdktab=swift#swift_privacy-manifest).

## Política de Consentimento de Usuários da UE do Google {#google-eu-user-consent-policy}

O Google está atualizando sua [Política de Consentimento de Usuários da UE](https://www.google.com/about/company/user-consent-policy/) em resposta às mudanças na [Lei dos Mercados Digitais (DMA)](https://ads-developers.googleblog.com/2023/10/updates-to-customer-match-conversion.html), que entra em vigor em 6 de março de 2024. Essa nova mudança exige que os anunciantes divulguem certas informações aos seus usuários finais do EEE e do Reino Unido, além de obter os consentimentos necessários deles. Como parte dessa mudança, você pode [coletar ambos os sinais de consentimento na Braze como atributos personalizados]({{site.baseurl}}/partners/canvas_steps/google_audience_sync#collecting-consent-for-eea-and-uk-end-users). A Braze sincronizará os dados desses atributos personalizados com os campos de consentimento apropriados no Google.

### Blocos de código personalizado {#custom-code-blocks}

Os [blocos de código personalizado]({{site.baseurl}}/user_guide/message_building_by_channel/in-app_messages/drag_and_drop/editor_blocks#custom-code) permitem adicionar, editar ou excluir HTML, CSS e JavaScript de uma mensagem no app.

### Reduzir o tamanho da carga útil das notificações por push {#reduce-payload-size-of-push-notifications}

O novo artigo de ajuda [Reduzir o tamanho da carga útil das notificações por push]({{site.baseurl}}/user_guide/channels/push/best_practices#reduce-push-notification-payload-size) fornece algumas dicas para reduzir o tamanho da carga útil das suas notificações por push caso você não consiga lançar uma Campaign ou etapa do Canvas devido aos limites de tamanho da carga útil de push.

### Adicionar endereços BCC à sua Campaign ou Canvas {#add-bcc-addresses-to-your-campaign-or-canvas}

{% multi_lang_include release_type.md release="General availability" %}

Você pode anexar um [endereço BCC]({{site.baseurl}}/user_guide/administrative/app_settings/email_settings/?tab=bcc%20address#outbound-email-settings) a uma mensagem de e-mail. Isso enviará uma cópia idêntica da mensagem que o usuário recebe para a sua caixa de entrada BCC. Dessa forma, você pode manter cópias das mensagens enviadas aos seus usuários para fins de conformidade ou questões de suporte ao cliente.

### Links de cancelamento de inscrição com um clique para e-mails {#one-click-unsubscribe-links-for-emails}

O uso de um [cabeçalho list-unsubscribe]({{site.baseurl}}/user_guide/administrative/app_settings/email_settings#list-unsubscribe-header) permite que os destinatários cancelem a inscrição com um clique de e-mails de marketing, exibindo um botão **Cancelar inscrição** na interface da caixa de entrada, e não no corpo da mensagem.

## Novas parcerias da Braze {#new-braze-partnerships}

### Criteo - Canvas Audience Sync

Usando o [Braze Audience Sync para Criteo]({{site.baseurl}}/partners/canvas_audience_sync/criteo_audience_sync), as marcas podem optar por adicionar dados de usuários de sua própria integração com a Braze às listas de clientes do Criteo para veicular anúncios com base em disparadores comportamentais, segmentação e muito mais. Qualquer critério que você normalmente usaria para disparar uma mensagem (push, e-mail, SMS, webhook, etc.) em um BRAZE CANVAS com base nos seus dados de usuários agora pode ser usado para disparar um anúncio para esse usuário nas suas listas de clientes do Criteo.

### Movable Ink - Conteúdo dinâmico {#movable-ink-dynamic-content}

A integração da [Movable Ink]({{site.baseurl}}/partners/message_personalization/dynamic_content/visual_and_interactive_content/movable_ink) com a API de Dados de Clientes permite que profissionais de marketing ativem dados de eventos de clientes armazenados na Braze para gerar conteúdo personalizado dentro da Movable Ink.

### Scuba Analytics - Análise de dados {#scuba-analytics-analytics}

O [Scuba Analytics]({{site.baseurl}}/partners/data_and_analytics) é uma plataforma de colaboração de dados full-stack, com tecnologia de machine learning, projetada para dados de séries temporais de alta velocidade. O Scuba permite que você exporte seletivamente usuários (também chamados de atores) e os carregue na sua plataforma Braze. No Scuba, propriedades personalizadas de atores são usadas para analisar tendências comportamentais, ativar seus dados em diversas plataformas e realizar modelagem preditiva usando machine learning.

As atualizações mais recentes do SDK foram lançadas. Atualizações com mudanças significativas estão listadas na seção de atualizações do SDK; todas as outras atualizações podem ser encontradas nos changelogs correspondentes de cada SDK.

    - Eleva a versão mínima da plataforma iOS para `13.4`, conforme os [requisitos do Expo SDK 50](https://expo.dev/changelog/2024/01-18-sdk-50).
    - Esta versão requer a versão [8.3.0+](https://github.com/braze-inc/braze-react-native-sdk/releases/tag/8.3.0) do Braze React Native SDK para suporte completo ao Expo SDK 50.
- [React Native SDK 8.3.0](https://github.com/braze-inc/braze-react-native-sdk/blob/8.3.0/CHANGELOG.md)
- [Unity SDK 5.1.0](https://github.com/braze-inc/braze-unity-sdk/blob/master/CHANGELOG.md)
- [Android SDK 30.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
    - As WebViews usadas para In-App Messages foram atualizadas para usar `WebViewAssetLoader`.
        - `WebSettings.allowFileAccess` agora está definido como false em `InAppMessageHtmlBaseView` e `BrazeWebViewActivity`.
        - Se você está usando seu próprio `InAppMessageWebViewClient` ou `InAppMessageHtmlBaseView`, compare-os com as classes originais para garantir que sua implementação está carregando os ativos corretamente.
        - Se você não está usando classes personalizadas, tudo funcionará como antes.
- [Braze Swift SDK 6.6.2](https://github.com/braze-inc/braze-swift-sdk/blob/6.6.2/CHANGELOG.md)
- [Braze Swift SDK 7.6.0](https://github.com/braze-inc/braze-swift-sdk/releases/tag/7.6.0)
- [Xamarin SDK Versão 3.0.0](https://github.com/braze-inc/braze-xamarin-sdk/blob/master/CHANGELOG.md)
    - O pacote NuGet foi renomeado de `AppboyPlatformXamariniOSBinding` para [`BrazePlatform.BrazeiOSBinding`](https://www.nuget.org/packages/BrazePlatform.BrazeiOSBinding/).
        - Para usar o pacote atualizado, substitua todas as instâncias de using `AppboyPlatformXamariniOSBinding;` por: using Braze;

    - Atualização do binding Android do [Braze Android SDK 26.3.2 para 29.0.1](https://github.com/braze-inc/braze-android-sdk/compare/v26.3.1...v29.0.1#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).

    - Esta versão atualiza o binding iOS para usar o [Braze Swift SDK](https://github.com/braze-inc/braze-swift-sdk/). A maioria das APIs públicas do iOS mudou. Consulte nosso [guia de migração](https://braze-inc.github.io/braze-swift-sdk/documentation/braze/appboy-migration-guide/) (Swift) para orientações sobre as substituições a serem feitas. Fornecemos bindings de compatibilidade para continuar usando as APIs públicas antigas.
        - O binding iOS agora é composto por múltiplos módulos:
            - **BrazeKit:** Biblioteca principal do SDK com suporte para análise de dados e notificações por push (nuget: [Braze.iOS.BrazeKit](https://www.nuget.org/packages/Braze.iOS.BrazeKit)).
            - BrazeUI: Biblioteca de interface de usuário fornecida pela Braze para In-App Messages e Content Cards (nuget: [Braze.iOS.BrazeUI](https://www.nuget.org/packages/Braze.iOS.BrazeUI)).

            - BrazeUICompat: Biblioteca de compatibilidade com suporte para APIs de UI anteriores à versão 4.0.0 (nuget: [Braze.iOS.BrazeUICompat](https://www.nuget.org/packages/Braze.iOS.BrazeUICompat)).
