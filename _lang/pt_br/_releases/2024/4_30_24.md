# Lançamento em 30 de abril de 2024 {#april-30-2024-release}

## Permissões para criar ou atualizar listas de códigos promocionais {#permissions-to-create-or-update-promotion-code-lists}

A partir de abril de 2024, os usuários precisarão da permissão "Access Campaigns, Canvases, Cards, Segments, Media Library" para criar ou atualizar listas de códigos promocionais. Consulte [Gerenciar permissões de funções limitadas e de equipe]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/user_permissions/#managing-limited-and-team-role-permissions) para obter uma lista de nomes de permissões e suas descrições.

## Flexibilidade de dados {#data-flexibility}

### Provisionamento SAML just-in-time {#saml-just-in-time-provisioning}

{% multi_lang_include release_type.md release="Early access" %}

[O provisionamento just-in-time]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/saml_just_in_time_provisioning/) funciona com o SAML SSO para permitir que novos usuários da empresa criem uma conta na Braze em seu primeiro login. Isso elimina a necessidade de os administradores criarem manualmente uma conta para um novo usuário da empresa, escolherem suas permissões, atribuírem a ele um espaço de trabalho e esperarem que ele ative sua conta.

### Conjuntos de permissões e funções {#permission-sets-and-roles}

Use [conjuntos de permissões]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/user_permissions/#permission-sets-and-roles) para agrupar permissões relacionadas a áreas temáticas ou ações específicas. Esses conjuntos de permissões podem ser aplicados aos usuários do dashboard que precisam do mesmo acesso em diferentes espaços de trabalho.

### Segments de Ingestão de dados na nuvem {#cloud-data-ingestion-segments}

Os [Segments de Ingestão de dados na nuvem]({{site.baseurl}}/user_guide/audience/segments/segment_extension/cdi_segments/) da Braze permitem que você escreva SQL que consulte diretamente seu próprio data warehouse usando dados disponibilizados por meio de suas conexões CDI e crie um grupo de usuários que podem ser direcionados na Braze.

## Liberando a criatividade {#unlocking-creativity}

### Modelos do Criador de consultas {#query-builder-templates}

{% multi_lang_include release_type.md release="General availability" %}

Usando os modelos do Criador de consultas, você pode criar relatórios usando dados da Braze do Snowflake. Para acessar os modelos do [Criador de consultas]({{site.baseurl}}/user_guide/analytics/reports/query_builder/), selecione **Query Template** ao criar um relatório. Todos os modelos apresentam dados de até os últimos 60 dias, mas você pode editar diretamente esse e outros valores no editor.

### Dados de desempenho por segmento {#performance-data-by-segment}

{% multi_lang_include release_type.md release="General availability" %}

Você pode detalhar os [dados de desempenho por segmento]({{site.baseurl}}/user_guide/data_and_analytics/reporting/viewing_and_understanding_segment_data/#performance-data-by-segment) nos modelos de relatório do Criador de consultas para Campaigns, variantes, Canvas e etapas do Canvas por segmentos.

## Canais robustos {#robust-channels}

### Encurtamento automático de links para envio de mensagens SMS {#automatic-link-shortening-for-sms-messaging}

{% multi_lang_include release_type.md release="General availability" %}

Use o [encurtamento automático de links]({{site.baseurl}}/user_guide/message_building_by_channel/sms/keywords/keyword_handling/?tab=manage%20responses#managing-keywords-and-auto-responses) para encurtar automaticamente os URLs estáticos em sua resposta. Isso pode ajudar a formatar sua resposta, pois o contador de caracteres será atualizado para mostrar o tamanho esperado do URL encurtado.

## Novas parcerias Braze {#new-braze-partnerships}

### Friendbuy - Fidelidade {#friendbuy-loyalty}

Aproveite a integração entre a Braze e a [Friendbuy]({{site.baseurl}}/partners/message_personalization/referrals/friendbuy/) para expandir seus recursos de e-mail e SMS e, ao mesmo tempo, automatizar sem esforço as comunicações do seu programa de indicação e fidelidade. A Braze gerará perfis de clientes para todos os números de telefone com opt-in coletados via Friendbuy.

### NiftyImages - Conteúdo dinâmico {#niftyimages-dynamic-content}

A parceria entre a Braze e a [NiftyImages]({{site.baseurl}}/partners/message_personalization/dynamic_content/visual_and_interactive_content/niftyimages/) permite que você crie imagens dinâmicas e personalizadas para suas campanhas de e-mail, mapeando suas tags de personalização existentes da Braze para seus URLs da NiftyImages.

## Atualizações do SDK {#sdk-updates}

As seguintes atualizações do SDK foram lançadas. As atualizações com breaking changes estão listadas abaixo; todas as outras atualizações podem ser encontradas verificando os changelogs correspondentes do SDK.

- [Android SDK 30.4.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [Plug-in Swift do Braze Segment 2.4.0](https://github.com/braze-inc/braze-segment-swift/blob/main/CHANGELOG.md#240)
- [Flutter SDK 9.0.0](https://pub.dev/packages/braze_plugin/changelog)
    - Atualiza a ponte nativa do iOS do [Braze Swift SDK 7.7.0 para o 8.4.0](https://github.com/braze-inc/braze-swift-sdk/compare/7.7.0...8.4.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
        - O alvo mínimo de implantação do iOS foi atualizado para 12.0.
    - Atualiza a ponte nativa do Android do [Braze Android SDK 29.0.1 para o 30.3.0](https://github.com/braze-inc/braze-android-sdk/compare/v29.0.1...v30.3.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
    - A versão mínima compatível do Dart é a 2.15.0.
- [React Native SDK 9.2.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
- [Swift SDK 8.3.0-8.4.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
- [Swift SDK 9.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - Remove os domínios de rastreamento de privacidade padrão do manifesto de privacidade do BrazeKit.
        - Se estiver usando os [recursos de rastreamento de dados]({{site.baseurl}}/developer_guide/analytics/managing_data_collection/?sdktab=swift#swift_privacy-manifest) da Braze, será necessário adicionar manualmente o endpoint de rastreamento ao manifesto de privacidade no nível do app.
        - Consulte o [tutorial](https://braze-inc.github.io/braze-swift-sdk/tutorials/braze/e1-privacy-tracking) atualizado para obter orientações sobre integração.
    - Remove o método descontinuado `BrazeDelegate.braze(_:sdkAuthenticationFailedWithError) method in favor of BrazeSDKAuthDelegate.braze(_:sdkAuthenticationFailedWithError)`.
        - Esse método foi originalmente descontinuado na [versão 5.14.0](https://github.com/braze-inc/braze-swift-sdk/releases/tag/5.14.0).
        - A falha na mudança para o novo método delegado não disparará um erro do compilador; em vez disso, o método `BrazeDelegate.braze(_:sdkAuthenticationFailedWithError)` que você definir simplesmente não será chamado.
- [Xamarin SDK versão 4.0.3](https://github.com/braze-inc/braze-xamarin-sdk/blob/master/CHANGELOG.md#403)
