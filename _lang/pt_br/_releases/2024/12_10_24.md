# Lançamento em 10 de dezembro de 2024 {#december-10-2024-release}

## Localização do usuário do SDK por endereço IP {#sdk-user-location-by-ip-address}

A partir de 26 de novembro de 2024, a Braze detectará a localização dos usuários a partir do país geolocalizado usando o endereço IP do início da primeira sessão do SDK. A Braze usará o endereço IP para definir o valor do país nos perfis de usuário criados por meio do SDK, e essa configuração de país baseada em IP estará disponível durante e após a primeira sessão. Consulte [Monitoramento de localização]({{site.baseurl}}/user_guide/audience/locations_and_geofences/location_tracking/) para mais detalhes.

## Configuração de acesso elevado {#elevated-access-setting}

O [Acesso elevado]({{site.baseurl}}/user_guide/administrative/app_settings/company_settings/security_settings/#elevated-access) adiciona uma camada extra de segurança para ações sensíveis no seu dashboard da Braze. Quando ativo, os usuários precisam verificar novamente sua conta antes de exportar um segmento ou visualizar uma chave de API. Para usar o acesso elevado, acesse **Settings** > **Admin Settings** > **Security Settings** e ative-o.

## Permissão para visualizar informações de identificação pessoal (IPI) {#permission-for-viewing-personally-identifiable-information-pii}

Para administradores, é possível [permitir que os usuários visualizem IPI]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/user_permissions/#list-of-permissions) conforme definido pela sua empresa no dashboard em pré-visualizações de mensagens que usam variáveis Liquid para acessar propriedades do usuário.

Para espaços de trabalho, é possível permitir que os usuários visualizem IPI conforme definido pela sua empresa no dashboard, ou visualizem perfis de usuário, mas com a redação dos campos que sua empresa identificou como IPI.

## Flexibilidade de dados {#data-flexibility}

### Esquemas de data lake {#data-lake-schemas}

Os seguintes esquemas foram adicionados aos esquemas de tabelas brutas:
- `USERS_CANVASSTEP_PROGRESSION_SHARED`: Eventos de progressão de um usuário em um Canvas
- `CHANGELOGS_GLOBALCONTROLGROUP_SHARED`: Identifica quais números de bucket aleatórios estão no Grupo de controle global atual e anterior
- `USERS_MESSAGES_FEATUREFLAG_IMPRESSION_SHARED`: Eventos de impressão para quando um usuário visualiza uma Feature Flag

### Segmentação baseada em contas {#account-based-segmentation}

Você pode fazer a [segmentação baseada em contas B2B (business-to-business)]({{site.baseurl}}/user_guide/get_started/b2b_use_cases/account_based_segmentation/) de duas maneiras, dependendo de como você configurou seu modelo de dados B2B:

- Ao usar catálogos para seus objetos de negócios
- Ao usar fontes conectadas para seus objetos de negócios

### Filtros de segmentação {#segmentation-filters}

Consulte [Filtros de segmentação]({{site.baseurl}}/user_guide/audience/segments/segmentation_filters/) para a lista completa de filtros de segmentação e suas descrições.

#### Perfil de usuário criado em {#user-profile-created-at}

Segmente seus usuários pela data de criação do perfil de usuário. Se um usuário foi adicionado por CSV ou API, esse filtro reflete a data em que ele foi adicionado. Se o usuário não foi adicionado por CSV ou API e teve sua primeira sessão rastreada pelo SDK, esse filtro reflete a data dessa primeira sessão.

#### Número de telefone de envio {#sending-phone-number}

Segmente seus usuários pelo campo de número de telefone e.164. Você pode usar expressões regulares com esse filtro para segmentar por números de telefone com um código de país específico.

## Novas parcerias Braze {#new-braze-partnerships}

### Narvar - eCommerce

A integração da Braze com a [Narvar](https://corp.narvar.com/) permite que as marcas aproveitem os eventos de notificação da Narvar para disparar mensagens diretamente da Braze, mantendo os clientes informados com atualizações oportunas.

### Zeotap para Currents - Plataforma de dados do cliente {#zeotap-for-currents-customer-data-platform}

A integração da Braze com o [Zeotap](https://zeotap.com/) permite que você amplie a escala e o alcance das suas campanhas sincronizando os segmentos de clientes do Zeotap com os perfis de usuários da Braze. Com o [Currents]({{site.baseurl}}/user_guide/data/distribution/braze_currents/), você também pode conectar dados ao Zeotap para torná-los acionáveis em todo o growth stack.

### Notify - Conteúdo dinâmico {#notify-dynamic-content}

A integração da Braze com o [Notify](https://notifyai.io/) permite que profissionais de marketing promovam efetivamente o engajamento em várias plataformas. Em vez de depender de métodos tradicionais de marketing, uma Campaign disparada por API da Braze pode aproveitar os recursos do Notify para entregar mensagens personalizadas por meio de vários canais, incluindo e-mail, SMS, notificações por push e muito mais.

### Contentful - Conteúdo dinâmico {#contentful-dynamic-content}

A integração da Braze com o [Contentful](https://www.contentful.com/) permite que você use dinamicamente o Conteúdo conectado para extrair conteúdo do Contentful para suas Campaigns na Braze.

### Outgrow - Captura de leads {#outgrow-leads-capture}

A integração da Braze com o [Outgrow](https://outgrow.co/) permite transferir automaticamente os dados de usuários do Outgrow para a Braze, possibilitando campanhas altamente personalizadas e direcionadas.
