# Lançamento em 2 de abril de 2024 {#april-2-2024-release}

## WhatsApp

### Várias contas comerciais {#multiple-business-accounts}

Agora você pode adicionar várias contas do WhatsApp Business e grupos de inscrições a cada espaço de trabalho. Para obter um passo a passo completo, consulte [Várias contas e números de telefone do WhatsApp Business]({{site.baseurl}}/user_guide/channels/whatsapp/whatsapp_setup/multiple_business_accounts).

### Taxas de leitura {#read-rates}

O WhatsApp está testando novas abordagens, começando com os consumidores na Índia, para criar experiências mais valiosas e maximizar o engajamento com as conversas de marketing das empresas. Isso pode incluir a limitação do número de conversas de marketing que uma pessoa recebe de qualquer empresa em um determinado período, começando com um pequeno número de conversas que têm menos probabilidade de serem lidas. Para saber mais, consulte [Recursos Meta]({{site.baseurl}}/user_guide/channels/whatsapp/meta_resources).

## Flexibilidade de dados {#data-flexibility}

### Sincronizar buckets S3 da Amazon com a Braze {#sync-amazon-s3-buckets-to-braze}

{% multi_lang_include release_type.md release="Early access" %}

Agora você pode usar a ingestão de dados na nuvem para S3 para integrar diretamente um ou mais buckets S3 na sua conta da AWS com a Braze. Quando novos arquivos são publicados no S3, uma mensagem é postada no SQS, e a ingestão de dados na nuvem da Braze recebe esses novos arquivos. Para saber mais, consulte [Integrações de armazenamento de arquivos]({{site.baseurl}}/user_guide/data/unification/cloud_ingestion/file_storage_integrations).

### Shopify OAuth

{% multi_lang_include release_type.md release="General availability" %}

A Shopify é uma empresa líder em comércio global que fornece ferramentas confiáveis para iniciar, expandir, comercializar e gerenciar um negócio de varejo de qualquer tamanho. Agora, quando você configurar o Shopify para a Braze, poderá [ativar o OAuth para seu espaço de trabalho]({{site.baseurl}}/partners/message_orchestration/channel_extensions/ecommerce/shopify/setting_up_shopify).

### Use a Expo para notificações por push do iOS {#use-expo-for-ios-push-notifications}

[Adicionamos instruções]({{site.baseurl}}/developer_guide/platform_integration_guides/react_native/push_notifications/?tab=expo) para integrar notificações por push avançadas e Push Stories no seu app para iOS usando Expo com React Native.

### Início remoto das atividades ao vivo do iOS {#remote-start-ios-live-activities}

Agora você pode iniciar remotamente suas atividades ao vivo no iOS usando o [endpoint `/messages/live_activity/start`]({{site.baseurl}}/api/endpoints/messaging/live_activity/start). Para obter um passo a passo completo, consulte [Atividades ao vivo: iniciar uma atividade]({{site.baseurl}}/developer_guide/platform_integration_guides/swift/live_activities/live_activities#step-2-start-the-activity).

## Automação de IA e ML {#ai-and-ml-automation}

### Recomendações de itens {#item-recommendations}

{% multi_lang_include release_type.md release="Early access" %}

Com o BrazeAI<sup>TM</sup>, agora você pode calcular os produtos mais populares ou criar recomendações personalizadas de IA para um catálogo específico. Para saber mais, consulte [Sobre recomendações de itens]({{site.baseurl}}/user_guide/brazeai/item_recommendations).

### Controle de qualidade do conteúdo das mensagens no app {#qa-in-app-message-content}

{% multi_lang_include release_type.md release="General availability" %}

Anteriormente, você podia realizar a garantia de qualidade do conteúdo de SMS e notificações por push usando o BrazeAI<sup>TM</sup> no dashboard da Braze. Agora, você também pode fazer o [controle de qualidade do conteúdo das mensagens no app]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#review-content-quality).

## Novas parcerias da Braze {#new-braze-partnerships}

### Census - Importação de coortes {#census-cohort-import}

Agora é possível [importar usuários de coorte da Braze para o Census]({{site.baseurl}}/partners/data_and_analytics/reverse_etl/census/census_cohort_import), uma plataforma de ativação de dados que conecta data warehouses em nuvem como Snowflake e BigQuery à Braze. Suas equipes de marketing podem liberar o poder dos dados primários para criar segmentos dinâmicos de público, sincronizar atributos de clientes para personalizar campanhas e manter todos os dados na Braze atualizados.

As seguintes atualizações do SDK foram lançadas. As atualizações com mudanças significativas estão listadas na seção de atualizações do SDK; todas as outras atualizações podem ser encontradas verificando os changelogs correspondentes do SDK.

- [React Native 9.1.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
  - Atualizada a versão mínima do React Native para 0.71.0.
  - Atualizada a versão mínima do iOS para 12.0.
  - Atualizados os bindings do iOS para usar o Braze Swift SDK 8.1.0.
  - Atualizados os bindings do Android para usar o Braze Android SDK 30.1.1.
