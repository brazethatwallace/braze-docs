# Lançamento em 20 de agosto de 2024 {#august-20-2024-release}

## Novos casos de uso {#new-use-cases}

### Catálogos {#catalogs}

Você pode trazer qualquer tipo de dados para um catálogo. Normalmente, os dados são metadados sobre ofertas, como produtos, descontos, promoções, eventos e similares. Leia nossos [casos de uso]({{site.baseurl}}/user_guide/data/activation/catalogs) e saiba como você pode usar esses dados para direcionar usuários com mensagens altamente relevantes.

### Intelligence Suite

O Intelligence Suite oferece recursos poderosos para analisar o histórico do usuário e o desempenho de Campaigns e Canvas, e então fazer ajustes automáticos para melhorar o engajamento, a visualização e as conversões. Para alguns exemplos de como esses recursos podem beneficiar diferentes setores, confira nossos [casos de uso]({{site.baseurl}}/user_guide/brazeai/intelligence_suite).

## Atualização do dashboard inicial {#home-dashboard-update}

Você pode [retomar de onde parou]({{site.baseurl}}/user_guide/data_and_analytics/analytics/home_dashboard#pick-up-where-you-left-off) no dashboard da Braze com acesso fácil aos arquivos que você editou ou criou recentemente. Essa seção aparece no topo da página **Home** do dashboard da Braze.

## Flexibilidade de dados {#data-flexibility}

### Templates de Data Transformation e novo destino {#data-transformation-templates-and-new-destination}

{% multi_lang_include release_type.md release="General availability" %}

Crie sua Data Transformation usando nossa [biblioteca de templates]({{site.baseurl}}/user_guide/data/unification/data_transformation/creating_a_transformation#step-2-create-a-transformation) dedicada para ajudar você a começar com determinadas plataformas externas, em vez de usar o código padrão. Agora você pode selecionar **POST: Send messages immediately via API or interface de programação do aplicativo (API) Only** como destino para transformar webhooks de uma plataforma de origem e enviar mensagens imediatas aos seus usuários.

### Mesclar usuários em massa {#merge-users-in-bulk}

{% multi_lang_include release_type.md release="General availability" %}

Se você encontrar perfis de usuário duplicados, poderá [mesclar em massa]({{site.baseurl}}/user_guide/audience/manage_audience/merge_duplicate_users#bulk-merging) esses usuários para ajudar a simplificar seus dados.

### Exportar atributos personalizados {#export-custom-attributes}

{% multi_lang_include release_type.md release="General availability" %}

Você pode [exportar a lista de atributos personalizados]({{site.baseurl}}/user_guide/data_and_analytics/custom_data/custom_attributes#exporting-data) como um arquivo CSV selecionando **Export all** na página **Custom Attributes**. O arquivo CSV será gerado e um link para download será enviado para o seu e-mail.

### Lista de permissão de IPs do Currents {#currents-ip-allowlisting}

A Braze enviará dados do Currents a partir dos IPs listados, que são adicionados de forma automática e dinâmica a todas as chaves de API or interface de programação do aplicativo (API) que foram habilitadas para a [lista de permissão]({{site.baseurl}}/user_guide/data/distribution/braze_currents/setting_up_currents).

## Canais robustos {#robust-channels}

### Nova experiência do criador de segmentos {#new-segment-builder-experience}

{% multi_lang_include release_type.md release="General availability" %}

Crie um Segment or segmento or segmento usando nossa [experiência atualizada]({{site.baseurl}}/user_guide/audience/segments/creating_a_segment). Os Segments são atualizados em tempo real conforme os dados mudam, e você pode criar quantos Segments forem necessários para suas finalidades de direcionamento e envio de mensagens.

### Métricas por Segments {#metrics-by-segments}

Use os modelos de relatório do [Query Builder]({{site.baseurl}}/user_guide/analytics/reports/query_builder) para detalhar métricas de desempenho de Campaigns, Canvas, variantes e etapas por Segments.

### Aquisição de número de telefone {#phone-number-acquisition}

Para usar o canal de envio de mensagens do WhatsApp, você precisará de um número de telefone que atenda aos requisitos do WhatsApp para sua [API or interface de programação do aplicativo (API) Cloud](https://developers.facebook.com/docs/whatsapp/cloud-api/phone-numbers) ou [API or interface de programação do aplicativo (API) On-Premises](https://developers.facebook.com/docs/whatsapp/on-premises/phone-numbers).

Você deve adquirir seu número de telefone por conta própria, pois a Braze não fará o provisionamento do número para você. Você pode comprar um telefone físico com chip SIM por meio do seu provedor de telefonia empresarial ou usar um de nossos parceiros: Twilio ou Infobip. **Você deve ter sua própria conta da Twilio ou da Infobip, pois isso não pode ser feito pela Braze.**

## Novas parcerias da Braze {#new-braze-partnerships}

### Zendesk Chat - Chat instantâneo {#zendesk-chat-instant-chat}

A integração da Braze com o [Zendesk Chat]({{site.baseurl}}/partners/zendesk_chat) usa webhooks de cada plataforma para configurar uma conversa bidirecional por SMS. Quando um usuário solicita suporte, um ticket é criado no Zendesk. As respostas dos agentes são encaminhadas para a Braze por meio de uma Campaign de SMS disparada por API or interface de programação do aplicativo (API), e as respostas dos usuários são enviadas de volta ao Zendesk.

As alterações que causam quebra de compatibilidade estão listadas na seção de atualizações do SDK or kit de desenvolvimento de software; todas as outras atualizações podem ser encontradas nos changelogs correspondentes de cada SDK or kit de desenvolvimento de software.

- [Android SDK or kit de desenvolvimento de software 32.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [Swift SDK or kit de desenvolvimento de software 10.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - As seguintes alterações foram feitas ao assinar eventos de push com [`Braze.Notifications.subscribeToUpdates(payloadTypes:_:)`](https://braze-inc.github.io/braze-swift-sdk/documentation/brazekit/braze/notifications-swift.class/subscribetoupdates(payloadtypes:_:)):
        - O closure `update` agora será acionado tanto por eventos "Push Opened" quanto "Push Received" por padrão. Anteriormente, ele era acionado apenas por eventos "Push Opened".
            - Para continuar assinando apenas eventos "Push Opened", passe `[.opened]` para o parâmetro `payloadTypes`. Como alternativa, implemente seu closure `update` para verificar se o `type` do `Braze.Notifications.Payload` é `.opened`.
        - Ao receber uma notificação por push com `content-available: true`, o [`Braze.Notifications.Payload.type`](https://braze-inc.github.io/braze-swift-sdk/documentation/brazekit/braze/notifications-swift.class/payload/type) agora será `.received` em vez de `.opened`.
    - Marca as seguintes APIs descontinuadas como indisponíveis:

        - `Braze.InAppMessage.Themes.default`
        - `Braze.deviceId(queue:completion:)`
        - `Braze._objc_deviceId(completion:)`
        - `Braze.deviceId()`
        - `Braze.User.setCustomAttributeArray(key:array:fileID:line:)`
        - `Braze.User.addToCustomAttributeArray(key:value:fileID:line:)`
        - `Braze.User.removeFromCustomAttributeArray(key:value:fileID:line:)`
        - `Braze.User._objc_addToCustomAttributeArray(key:value:)`
