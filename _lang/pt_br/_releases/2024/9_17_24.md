# Versão de 17 de setembro de 2024 {#september-17-2024-release}

## Flexibilidade de dados {#data-flexibility}

### Braze Cloud Data Ingestion para S3 {#braze-cloud-data-ingestion-for-s3}

Você pode usar o [Cloud Data Ingestion (CDI) para S3]({{site.baseurl}}/user_guide/data_and_analytics/cloud_ingestion/file_storage_integrations#aws-definitions) para integrar diretamente um ou mais buckets S3 da sua conta AWS com a Braze. Quando novos arquivos são publicados no S3, uma mensagem é enviada ao SQS, e o Braze Cloud Data Ingestion processa esses novos arquivos.

### Usuários ativos mensais CY 24-25 {#monthly-active-users-cy-24-25}

Para clientes que adquiriram Monthly Active Users - CY 24-25, a Braze gerencia limites de frequência diferentes no endpoint `/users/track`. Para saber mais, consulte [POST: Rastrear usuários]({{site.baseurl}}/api/endpoints/user_data/post_user_track#monthly-active-users-cy-24-25-universal-mau-web-mau-and-mobile-mau).

## Desbloqueando a criatividade {#unlocking-creativity}

### Usando modelos de itens de catálogo com Liquid {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="Early access" %}

Use a flag `:rerender` em uma Liquid tag para [renderizar o conteúdo Liquid de um item de catálogo]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog#using-liquid). Por exemplo, se você renderizar o seguinte conteúdo Liquid:

{% raw %}
```liquid
Hi ${first_name}
{% catalog_items Messages greet_msg :rerender %}
{{ items[0].Welcome_Message }}
```
{% endraw %}

O resultado será exibido da seguinte forma:

{% raw %}
```
Hi Peter,
Welcome to our store, Peter!
```
{% endraw %}

## Canais robustos {#robust-channels}

### Mensagens de resposta do WhatsApp {#whatsapp-response-messages}

{% multi_lang_include release_type.md release="General availability" %}

Você pode usar [mensagens de resposta]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#response-messages) para responder a mensagens recebidas do WhatsApp dos seus usuários. Essas mensagens são criadas no app da Braze durante a experiência de composição e podem ser editadas a qualquer momento. Você pode usar Liquid para combinar o idioma da mensagem de resposta com os usuários apropriados.

### Modelos de Canvas {#canvas-templates}

{% multi_lang_include release_type.md release="General availability" %}

Crie [modelos de Canvas]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates) para refinar seu envio de mensagens criando uma estrutura consistente que pode ser facilmente personalizada para atender aos seus objetivos específicos em seus Canvas.

### Landing pages

{% multi_lang_include release_type.md release="Beta" %}

As [landing pages]({{site.baseurl}}/user_guide/messaging/landing_pages) da Braze são páginas web independentes que podem impulsionar sua estratégia de aquisição e engajamento de usuários.

### Alterações desde a última visualização {#changes-since-last-viewed}

Você pode visualizar o número de atualizações nos seus [Canvas]({{site.baseurl}}/user_guide/engagement_tools/canvas/testing_canvases/measuring_and_testing_with_canvas_analytics#changes-since-last-viewed), Campaigns e [Segments]({{site.baseurl}}/user_guide/engagement_tools/segments/managing_segments#changes-since-last-viewed) feitas por outros membros da sua equipe consultando a métrica *Alterações desde a última visualização* nas respectivas páginas de visão geral (como a página de visão geral de uma [campanha de e-mail]({{site.baseurl}}/user_guide/channels/email/reporting#changes-since-last-viewed)).

### Solução de problemas de requisições de webhook e Connected Content {#troubleshooting-webhook-and-connected-content-requests}

## Novas parcerias da Braze {#new-braze-partnerships}

### Inbox Monster - Análise de dados {#inbox-monster-analytics}

O [Inbox Monster]({{site.baseurl}}/partners/data_and_analytics/analytics/inbox_monster) é uma plataforma de sinais de caixa de entrada que ajuda marcas corporativas a garantir a entrega de cada envio. É um pacote integrado de soluções para entregabilidade, renderização criativa e monitoramento de SMS, que capacita equipes modernas de gestão de relacionamento com o cliente (CRM) e elimina as preocupações com o envio.

### SessionM - Fidelidade {#sessionm-loyalty}

O [SessionM]({{site.baseurl}}/partners/data_and_analytics/loyalty/sessionm) é uma plataforma de engajamento do cliente e fidelidade que oferece recursos de gerenciamento de Campaigns e soluções de gestão de fidelidade para ajudar profissionais de marketing a impulsionar a comunicação direcionada, aumentando o engajamento e a lucratividade.

## Automação com IA e ML {#ai-and-ml-automation}

### Recomendações de itens em alta {#trending-item-recommendations}

Além do modelo "Personalizado por IA", o recurso de [recomendações de itens por IA]({{site.baseurl}}/user_guide/sage_ai/recommendations/about_item_recommendations#trending) também inclui um modelo de recomendação para "Em alta", que destaca itens com maior impulso positivo em relação às interações recentes dos usuários.

## Configurações {#settings}

### Funções {#roles}

{% multi_lang_include release_type.md release="General availability" %}

As [funções]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/user_permissions#creating-a-role) permitem mais estrutura ao agrupar suas permissões personalizadas individuais com controles de acesso ao espaço de trabalho. Isso é especialmente útil se você tem muitas marcas ou espaços de trabalho regionais em um único dashboard. Com as funções, você pode adicionar usuários do dashboard aos espaços de trabalho apropriados e conceder diretamente as permissões associadas.

### Relatório de eventos de segurança {#security-event-report}

Adicionamos uma lista completa dos [eventos de segurança]({{site.baseurl}}/user_guide/administrative/app_settings/company_settings/security_settings#downloading-a-security-event-report) que podem aparecer no relatório de eventos de segurança baixado.

### Relatório de uso de mensagens {#message-usage-report}

{% multi_lang_include release_type.md release="Early access" %}

O [dashboard de uso de créditos]({{site.baseurl}}/credits_usage_dashboard) oferece insights de autoatendimento sobre o uso de créditos, proporcionando uma visão abrangente do uso histórico e atual em comparação com as alocações do contrato. Esses insights podem reduzir dúvidas e ajudar você a fazer ajustes para evitar riscos de excedente.

## SDK or kit de desenvolvimento de software

### Inicialização postergada do Braze Swift SDK or kit de desenvolvimento de software {#delayed-initialization-for-the-braze-swift-sdk}

Configure a [inicialização postergada]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=swift#step-2-set-up-delayed-initialization-optional) para inicializar o Braze Swift SDK or kit de desenvolvimento de software de forma assíncrona e, ao mesmo tempo, garantir que o tratamento das notificações por push seja preservado. Isso pode ser útil quando for necessário configurar outros serviços antes de inicializar o SDK or kit de desenvolvimento de software, como buscar dados de configuração de um servidor ou aguardar o consentimento do usuário.
