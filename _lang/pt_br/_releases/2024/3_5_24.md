# Lançamento em 5 de março de 2024 {#march-5-2024-release}

## Política de consentimento do usuário da UE do Google {#google-eu-user-consent-policy}

O Google está atualizando sua [Política de consentimento do usuário da UE](https://www.google.com/about/company/user-consent-policy/) em resposta às alterações na [Lei de Mercados Digitais (DMA)](https://ads-developers.googleblog.com/2023/10/updates-to-customer-match-conversion.html), que está em vigor desde 6 de março de 2024. Essa nova alteração exige que os anunciantes divulguem determinadas informações aos seus usuários finais do EEE e do Reino Unido, bem como obtenham deles os consentimentos necessários. Como parte dessa mudança, você pode [coletar ambos os sinais de consentimento na Braze como atributos personalizados]({{site.baseurl}}/partners/canvas_steps/google_audience_sync/#collecting-consent-for-eea-and-uk-end-users). A Braze sincronizará os dados desses atributos personalizados com os campos de consentimento apropriados no Google.

## Flexibilidade de dados {#data-flexibility}

### Mesclar usuários duplicados {#merge-duplicate-users}

{% multi_lang_include release_type.md release="Early access" %}

No dashboard da Braze, agora é possível [pesquisar e mesclar usuários duplicados]({{site.baseurl}}/user_guide/audience/manage_audience/merge_duplicate_users/) para maximizar a eficácia das suas Campaigns e Canvas. Você pode mesclar perfis de usuário individualmente ou realizar uma mesclagem em massa, que mescla todos os perfis com identificadores correspondentes no perfil de usuário atualizado mais recentemente.

### Pesquisar conteúdo arquivado {#search-for-archived-content}

No dashboard da Braze, agora você pode incluir [conteúdo arquivado nos seus resultados de pesquisa]({{site.baseurl}}/user_guide/administrative/access_braze/global_search/#filter-for-archived-content) selecionando **Show Archived Content**.

### Suporte ao arquivamento de mensagens para AWS S3 e Google Cloud Storage {#message-archiving-support-for-aws-s3-and-google-cloud-storage}

Você pode usar o [arquivamento de mensagens]({{site.baseurl}}/user_guide/data/distribution/export_braze_data/message_archiving/) para salvar uma cópia das mensagens enviadas aos usuários para fins de arquivamento ou conformidade no seu bucket S3 da AWS, no contêiner do Azure Blob Storage ou no bucket do Google Cloud Storage.

### Referência de tabela SQL {#sql-table-reference}

Visite a [referência de tabela SQL]({{site.baseurl}}/user_guide/audience/segments/segment_extension/sql_segments/sql_segments_tables/) para ver as tabelas e colunas disponíveis para consulta no Criador de consultas ou ao gerar extensões de segmento SQL.

### Controle de tom para redação com IA {#tone-control-for-ai-copywriting}

Agora você pode escolher um [tom de mensagem]({{site.baseurl}}/user_guide/brazeai/generative_ai/ai_copywriting/#steps) para determinar o estilo do texto gerado com o Assistente de Copywriting com IA.

## Canais robustos {#robust-channels}

### Criação de cartões {#card-creation}

Você pode escolher quando a Braze avalia a elegibilidade do público e a personalização para novas Campaigns de Content Cards e etapas do Canvas, especificando quando o cartão é [criado]({{site.baseurl}}/user_guide/channels/content_cards/create_a_content_card/card_creation/).

### Pré-visualização das jornadas do usuário {#preview-user-paths}

{% multi_lang_include release_type.md release="General availability" %}

Experimente a jornada do Canvas que você criou para seus usuários, incluindo a pré-visualização do tempo e das mensagens que eles receberão. Essas [execuções de teste]({{site.baseurl}}/preview_user_paths/) funcionam como garantia de qualidade de que suas mensagens são enviadas para o público certo, tudo isso antes do envio do Canvas.

### Campaigns de push rápido {#quick-push-campaigns}

{% multi_lang_include release_type.md release="General availability" %}

Ao criar uma Campaign de push na Braze, você pode selecionar várias plataformas e dispositivos para criar uma mensagem para todas as plataformas em uma única experiência de edição chamada [quick push]({{site.baseurl}}/user_guide/channels/push/create_a_push_message/quick_push_messages/). Esse recurso está disponível apenas para Campaigns.

### Cabeçalho personalizado de cancelamento de inscrição em lista {#custom-list-unsubscribe-header}

{% multi_lang_include release_type.md release="General availability" %}

Adicionar um [cabeçalho personalizado de cancelamento de inscrição em lista]({{site.baseurl}}/user_guide/administrative/app_settings/email_settings/#custom-list-unsubscribe-header) ao seu envio de e-mail permite que os destinatários façam o descadastramento. Dessa forma, você pode adicionar seu próprio endpoint de cancelamento de inscrição com um clique e um "mailto:" opcional. A Braze requer uma entrada de URL para suportar um cabeçalho personalizado de cancelamento de inscrição em lista, pois o cancelamento de inscrição com um clique via HTTP é um requisito do Yahoo e do Gmail para remetentes em massa.

### Várias páginas para mensagens no app {#multiple-pages-for-in-app-messages}

{% multi_lang_include release_type.md release="Early access" %}

[Adicionar páginas à sua mensagem no app]({{site.baseurl}}/user_guide/message_building_by_channel/in-app_messages/drag_and_drop/create/#multi-page) permite orientar os usuários por meio de um fluxo sequencial, como um fluxo de integração ou uma jornada de boas-vindas. Você pode gerenciar páginas na seção **Pages** da guia **Build**.

### Randomizar jornadas para uma jornada experimental {#randomize-paths-for-an-experiment-path}

Para sempre [randomizar a atribuição de jornadas]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step/) em uma etapa de jornada experimental, selecione **Randomized Paths in Experiment Paths** na etapa. Essa opção não está disponível ao usar jornadas vencedoras ou personalizadas.

### Formulário de captura de e-mail {#email-capture-form}

As [mensagens de captura de e-mail]({{site.baseurl}}/user_guide/channels/in_app_messages/message_types/email_capture_form/) permitem solicitar facilmente que os usuários do seu site enviem o endereço de e-mail, que ficará disponível no perfil do usuário para uso em todas as suas campanhas de envio de mensagens.

## Atualizações do SDK {#sdk-updates}

As seguintes atualizações do SDK foram lançadas. As atualizações com breaking changes estão listadas abaixo; todas as outras atualizações podem ser encontradas verificando os changelogs correspondentes do SDK.

- [AppboyKit iOS SDK 4.7.0](https://github.com/Appboy/appboy-ios-sdk/releases/tag/4.7.0)
    - Esta será a versão final do SDK Objective-C antes do fim da vida útil em 1º de março de 2024 (em favor do uso do [Swift SDK](https://github.com/braze-inc/braze-swift-sdk/)).
    - Atualiza a versão mínima necessária do SDWebImage de 5.8.2 para 5.18.7. Esta versão inclui o manifesto de privacidade para SDWebImage, que aparece na [lista de SDKs que afetam a privacidade](https://developer.apple.com/support/third-party-SDK-requirements/).
- [Flutter SDK 8.1.0](https://pub.dev/packages/braze_plugin/changelog)
- [Unity 5.2.0](https://github.com/braze-inc/braze-unity-sdk/blob/master/CHANGELOG.md)
- [React Native SDK 8.4.0](https://github.com/braze-inc/braze-react-native-sdk/blob/8.4.0/CHANGELOG.md)
- [Xamarin SDK versão 4.0.2](https://github.com/braze-inc/braze-xamarin-sdk/blob/master/CHANGELOG.md)
- [Swift SDK 7.7.0-8.0.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#801)
- [Android SDK 30.1.0-30.2.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [Web SDK 5.1.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [Cordova SDK 8.0.0-Cordova SDK 8.1.0](https://github.com/braze-inc/braze-cordova-sdk/blob/master/CHANGELOG.md)
    - Atualizada a ponte nativa do Android [do SDK da Braze para Android 27.0.1 para o 30.0.0](https://github.com/braze-inc/braze-android-sdk/compare/v27.0.0...v30.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
    - Atualizada a ponte nativa do iOS [do SDK Swift da Braze 6.6.0 para o 7.6.0](https://github.com/braze-inc/braze-swift-sdk/compare/6.6.0...7.6.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
    - Renomeado o tipo de Content Card `Banner` para `ImageOnly`:
        - `ContentCardTypes.BANNER` para `ContentCardTypes.IMAGE_ONLY`
        - No Android, se os arquivos XML no seu projeto contiverem a palavra banner para Content Cards, ela deverá ser substituída por `image_only`.
    - `BrazePlugin.getFeatureFlag(id)` agora retornará `null` se a Feature Flag não existir.
    - `BrazePlugin.subscribeToFeatureFlagsUpdates(function)` só será disparado quando uma solicitação de atualização for concluída com sucesso ou falha, e na inscrição inicial, se houver dados em cache anteriores da sessão atual.
    - Removido o método obsoleto `registerAppboyPushMessages`. Em vez disso, use `setRegisteredPushToken`.
