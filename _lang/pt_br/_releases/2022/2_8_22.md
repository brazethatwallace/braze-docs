# Lançamento em 8 de fevereiro de 2022 {#february-8-2022-release}

## Jornadas de ação do Canvas {#canvas-action-paths}

As [jornadas de ação]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/action_paths) permitem que você classifique seus usuários com base em suas ações. Usando as jornadas de ação, você pode:
- Personalizar os caminhos do usuário com base em uma ação específica.
- Manter os usuários por um determinado período para priorizar sua próxima jornada com base em suas ações durante esse período de avaliação.

O acesso às jornadas de ação será implementado gradualmente para todas as instâncias da Braze. Entre em contato com o gerente da sua conta Braze para saber mais.

Procurando uma página de referência rápida de todos os endpoints disponíveis da Braze? Visite nosso [índice de endpoints da API or interface de programação do aplicativo (API)]({{site.baseurl}}/api/endpoints).

## Descontinuação da API or interface de programação do aplicativo (API) Transifex v2 e v2.5 {#transifex-v2-and-v25-api-deprecation}
A partir de 7 de abril de 2022, o [Transifex]({{site.baseurl}}/partners/message_personalization/localization/transifex) estará descontinuando suas versões de API or interface de programação do aplicativo (API) 2 e 2.5 para abrir caminho para a versão 3. Após essa data, as versões v2 e v2.5 não estarão mais operacionais, e as solicitações relacionadas falharão. Os usuários dessa integração com parceiros devem atualizar sua versão da API or interface de programação do aplicativo (API) antes dessa data.

## Tipos de dados de atributos personalizados disponíveis {#available-custom-attribute-data-types}
