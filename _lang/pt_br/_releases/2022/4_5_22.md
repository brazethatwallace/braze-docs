# Lançamento em 5 de abril de 2022 {#april-5-2022-release}

## Filtrar por atribuição de Campaign ou Canvas {#filter-by-campaign-or-canvas-attribution}
Agora é possível filtrar os usuários que responderam a uma Campaign de SMS específica ou a uma etapa do Canvas, categoria de palavra-chave ou tag. Para saber mais, consulte [Redirecionamento de SMS]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/user_retargeting/).

## Dashboard de performance de e-mail {#email-performance-dashboard}
Com o [dashboard de performance de e-mail]({{site.baseurl}}/user_guide/analytics/dashboards/), você pode visualizar as métricas de desempenho agregadas de todo o seu canal de e-mail, tanto de Campaigns quanto de Canvas, para o intervalo de datas selecionado.

Para saber mais sobre os dashboards de análise de dados disponíveis na Braze, consulte a seção [Seus dashboards de análise de dados]({{site.baseurl}}/user_guide/analytics/dashboards/home/).

## Configurações globais de estilo {#global-style-settings}

Apresentamos as [configurações de estilo global]({{site.baseurl}}/user_guide/channels/email/customize/email_global_style_settings/) para o editor de arrastar e soltar! Agora, você pode personalizar facilmente a aparência das suas Campaigns de e-mail e Canvas adicionando um tema padrão, definindo o estilo básico do texto e muito mais.

## Webhooks da Braze para a Braze {#braze-to-braze-webhooks}
Com um webhook da Braze para a Braze, você pode usar webhooks para se comunicar com a REST or transferir estado representacional API or interface de programação do aplicativo (API) da Braze, fazendo tudo o que nossa API or interface de programação do aplicativo (API) permite. Essencialmente, esse é um webhook que está se comunicando da Braze para a Braze. Para saber mais, consulte nosso artigo sobre [webhooks da Braze para a Braze]({{site.baseurl}}/user_guide/channels/webhooks/use_case_create_a_braze_to_braze_webhook/).

## Descontinuações {#deprecations}

### SDK or kit de desenvolvimento de software do Windows {#windows-sdk}
Desde 24 de março de 2022, o [SDK or kit de desenvolvimento de software da Braze para Windows]({{site.baseurl}}/developer_guide/sdk_integration/initialization/?sdktab=web/) está obsoleto, e nenhum novo app para Windows pode ser criado no dashboard da Braze.

### Integração com o Baidu push {#baidu-push-integration}
Desde 24 de março de 2022, a [integração de push da Braze com o Baidu]({{site.baseurl}}/developer_guide/platform_integration_guides/android/push_notifications/?tab=android) foi descontinuada, e nenhum novo app Baidu pode ser criado no dashboard da Braze.

## Novas parcerias da Braze {#new-braze-partnerships}

### Tealium para Currents {#tealium-for-currents}

A integração da Braze com o [Tealium]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/tealium/tealium_for_currents/) permite que você controle perfeitamente o fluxo de informações entre os dois sistemas. Agora, com o Currents, você também pode conectar dados ao Tealium para torná-los acionáveis em toda a growth stack.
