# Lançamento em 8 de março de 2022 {#march-8-2022-release}

## Mensagens no app para Roku {#in-app-messages-for-roku}

A Braze agora oferece suporte ao envio de mensagens no app para seus usuários em dispositivos Roku! Observe que isso requer configuração adicional do SDK e não está disponível por padrão. Para saber mais sobre a integração de mensagens no app para Roku, consulte [Mensagens no app para Roku]({{site.baseurl}}/developer_guide/in_app_messages/?sdktab=roku).

## Modo de filtro completo para previsões de churn e previsões de compra {#full-filter-mode-for-churn-predictions-and-purchase-predictions}

Para criar uma nova previsão imediatamente, apenas um subconjunto dos filtros de segmentação da Braze é aceito por padrão. Agora você pode ativar o modo de filtro completo para habilitar todos os filtros de segmentação. No entanto, esse modo limita você a um período ao criar a previsão. Para saber mais, consulte os seguintes artigos:

- [Criando uma previsão de churn]({{site.baseurl}}/user_guide/predictive_suite/predictive_churn/creating_a_churn_prediction/#full-filter-mode)
- [Criando uma previsão de compra]({{site.baseurl}}/user_guide/predictive_suite/predictive_purchases/creating_a_purchase_prediction/#full-filter-mode)

## Opção de redirecionamento para respostas de palavras-chave {#retargeting-option-for-keyword-responses}

Ao visualizar a análise de dados de uma campanha de SMS, agora você pode criar facilmente um Segment para redirecionamento com base nos usuários que responderam com uma categoria de palavra-chave específica. Para saber mais, consulte [Respostas de palavras-chave]({{site.baseurl}}/user_guide/message_building_by_channel/sms/sms_campaign_analytics/#keyword-responses) nos relatórios de SMS.

## Práticas recomendadas de coleta de dados {#data-collection-best-practices}

Você já se perguntou quando e como deve coletar dados de usuários ao lidar com usuários conhecidos e desconhecidos? Sabemos que o ciclo de vida de um perfil de usuário na Braze pode ser um pouco confuso, então reunimos algumas [práticas recomendadas de coleta de dados]({{site.baseurl}}/user_guide/data/unification/user_data/best_practices/) para ajudar a esclarecer diferentes métodos e melhores práticas para coletar dados de usuários novos e existentes.

## Descontinuação da API do Transifex {#transifex-api-deprecation}

A partir de 7 de abril de 2022, a Transifex está descontinuando suas versões de API 2 e 2.5 para abrir caminho para a versão 3. Após essa data, as versões v2 e v2.5 não estarão mais operacionais, e as solicitações relevantes falharão. Se você estiver utilizando a API do Transifex, atualize suas chamadas de Conteúdo conectado de acordo. Para saber mais, consulte [Transifex]({{site.baseurl}}/partners/message_personalization/localization/transifex/).

## Novas parcerias Braze {#new-braze-partnerships}

### Toovio - CDP {#toovio-customer-data-platform}

A parceria entre a Braze e a [Toovio]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/toovio/) oferece disparo de mensagens em quase tempo real, ferramentas para impulsionar o desempenho incremental e acesso às ferramentas avançadas de medição de campanhas da Toovio.

### Snowplow - Análise de dados {#snowplow-analytics}

A integração entre a Braze e o [Snowplow]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/snowplow/) permite que os usuários encaminhem eventos do Snowplow para a Braze por meio da marcação server-side do Google Tag Manager. A tag Braze do Snowplow permite que você envie eventos para a Braze com flexibilidade e controle adicionais:

- Visibilidade total de todas as transformações nos dados
- Capacidade de evoluir a sofisticação ao longo do tempo
- Todos os dados permanecem em sua nuvem privada até que você escolha encaminhá-los
- Facilidade de configuração graças às ricas bibliotecas de tags e à interface familiar do Google Tag Manager

Aproveite os ricos dados comportamentais do Snowplow para impulsionar interações poderosas centradas no cliente na Braze e entregar mensagens personalizadas em tempo real.

### Clarisights - Análise de dados {#clarisights-analytics}

A integração entre a Braze e a [Clarisights]({{site.baseurl}}/partners/data_and_analytics/business_intelligence/clarisights/) permite importar dados de Campaigns e Canvas da Braze para alcançar uma interface de relatórios unificada de desempenho e marketing de CRM/retenção.

### Wyng - Conteúdo dinâmico {#wyng-dynamic-content}

A integração entre a Braze e a [Wyng]({{site.baseurl}}/partners/wyng/) permite que você aproveite as experiências Wyng para oferecer personalização em Campaigns e Canvas da Braze. A Wyng também inclui um portal de preferências do cliente para que os usuários possam controlar os dados e preferências que compartilham com uma marca.

### Grouparoo - Automação de fluxo de trabalho {#grouparoo-workflow-automation}

A integração entre a Braze e o [Grouparoo]({{site.baseurl}}/releases/deprecations/grouparoo/) sincroniza os dados do warehouse com a Braze. As programações de sincronização automática mantêm as comunicações com os clientes atualizadas com informações em tempo real.

### Lexer - CDP {#lexer-customer-data-platform}

A integração entre a Braze e a [Lexer]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/lexer/) permite sincronizar dados entre as duas plataformas. Use seus dados do Lexer para criar segmentos valiosos na Braze ou importe os existentes para o Lexer para desbloquear insights.

### Knak - Orquestração de e-mail {#knak-email-orchestration}

A integração entre a Braze e a [Knak]({{site.baseurl}}/partners/knak/) permite que você crie e-mails totalmente responsivos em minutos ou horas, em vez de dias ou semanas, e os exporte como modelos prontos para uso na Braze. A Knak é feita para profissionais de marketing que desejam aprimorar a criação de e-mails para campanhas gerenciadas na Braze, sem a necessidade de agências externas ou codificação manual.
