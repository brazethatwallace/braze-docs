# Lançamento em 18 de outubro de 2022 {#october-18-2022-release}

## Histórico de mensagens do perfil de usuário {#user-profile-messaging-history}

A guia **Histórico de mensagens** do perfil de usuário mostra eventos recentes relacionados ao envio de mensagens (cerca de 40) para um usuário individual nos últimos 30 dias. Esses eventos incluem as mensagens que o usuário recebeu, com as quais interagiu, e muito mais. Consulte [Perfis de usuário]({{site.baseurl}}/user_guide/engagement_tools/segments/user_profiles#messaging-history-tab) para saber mais.

## Content Blocks para o editor de arrastar e soltar {#content-blocks-for-drag-drop-editor}

Os [Content Blocks]({{site.baseurl}}/user_guide/messaging/design_and_edit/content_blocks) usados exclusivamente no editor de arrastar e soltar são semelhantes em funcionalidade aos Content Blocks usados em diferentes canais. Eles são um local centralizado para armazenar informações que podem ser referenciadas em várias Campaigns de e-mail. Isso pode incluir o agrupamento de cabeçalhos de e-mail, chamadas promocionais e muito mais, tudo em uma única linha reutilizável.

## Shopify ScriptTag

A [integração da Braze com o Shopify]({{site.baseurl}}/partners/shopify) agora permite que você incorpore nossa integração do Web SDK or kit de desenvolvimento de software via ScriptTag em sua loja do Shopify. A incorporação do nosso Web SDK or kit de desenvolvimento de software via ScriptTag permite o rastreamento do seguinte:
- Rastreamento de usuários anônimos para monitorar a atividade dos visitantes em sua loja
- Rastreamento mensal de usuários ativos, pois o Web SDK or kit de desenvolvimento de software é capaz de rastrear os dados de sessão dos visitantes da sua loja
- Opção para coletar usuários de atividades no site do Shopify, que contarão para o seu consumo de pontos de dados
- Opção para ativar o envio de mensagens no navegador como um canal em sua loja do Shopify

## Opt-outs imprecisos de SMS {#sms-fuzzy-opt-outs}

O [opt-out impreciso]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/keyword_processing/fuzzy_opt_out) tenta reconhecer quando uma mensagem SMS recebida não corresponde a uma palavra-chave de opt-out, mas indica intenção de cancelamento. Se o opt-out impreciso estiver ativado e uma resposta de palavra-chave recebida for considerada "imprecisa", a Braze responderá automaticamente pedindo que o usuário confirme sua intenção.
