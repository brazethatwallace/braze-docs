# Lançamento em 18 de outubro de 2022 {#october-18-2022-release}

## Histórico de mensagens do perfil de usuário {#user-profile-messaging-history}

A guia **Histórico de mensagens** do perfil de usuário mostra eventos recentes relacionados a envio de mensagens (cerca de 40) para um usuário individual nos últimos 30 dias. Esses eventos incluem as mensagens que o usuário enviou, recebeu, com as quais interagiu e muito mais. Consulte [Perfis de usuário]({{site.baseurl}}/user_guide/engagement_tools/segments/user_profiles/#messaging-history-tab) para saber mais.

## Content Blocks para o editor de arrastar e soltar {#content-blocks-for-drag-drop-editor}

Os [Content Blocks]({{site.baseurl}}/user_guide/messaging/design_and_edit/content_blocks/) usados exclusivamente no editor de arrastar e soltar são semelhantes em funcionalidade aos Content Blocks usados em diferentes canais. Eles são um local centralizado para armazenar informações que podem ser referenciadas em várias Campaigns de e-mail. Isso pode incluir o agrupamento de cabeçalhos de e-mail, chamadas promocionais e muito mais, tudo em uma linha reutilizável.

## Shopify ScriptTag

A [integração da Braze com o Shopify]({{site.baseurl}}/partners/shopify/) agora permite que você incorpore nossa integração de SDK da Web via ScriptTag em sua loja do Shopify. A incorporação do nosso Web SDK via ScriptTag permite o rastreamento do seguinte:
- Rastreamento de usuários anônimos para monitorar a atividade dos visitantes em sua loja
- Rastreamento mensal de usuários ativos, pois o Web SDK é capaz de rastrear os dados de sessão dos visitantes da sua loja
- Opção para coletar usuários de atividades no site do Shopify, que contarão para o seu consumo de pontos de dados
- Opção para ativar o envio de mensagens no navegador como um canal em sua loja do Shopify

Use os seguintes endpoints SCIM da Braze para gerenciar o provisionamento automatizado de usuários:

- [GET: Procurar uma conta de usuário existente no dashboard]({{site.baseurl}}/api/endpoints/scim/get_see_user_account_information/)
- [POST: Criar nova conta de usuário do dashboard]({{site.baseurl}}/api/endpoints/scim/post_create_user_account/)
- [PUT: Atualizar conta de usuário do dashboard]({{site.baseurl}}/api/endpoints/scim/put_update_existing_user_account/)

## Descadastramento flexível por SMS {#sms-fuzzy-opt-outs}

O [descadastramento flexível]({{site.baseurl}}/user_guide/message_building_by_channel/sms/keywords/fuzzy_opt_out/#fuzzy-opt-out) tenta reconhecer quando uma mensagem SMS recebida não corresponde a uma palavra-chave de descadastramento, mas indica a intenção de cancelamento. Se o descadastramento flexível estiver ativado e uma resposta de palavra-chave recebida for considerada "fuzzy", a Braze responderá automaticamente solicitando que o usuário confirme sua intenção.
