# Lançamento em 20 de setembro de 2022 {#september-20-2022-release}

## Guia de API {#api-guide}
Confira o [Guia de API da Braze]({{site.baseurl}}/api/home) para pesquisar endpoints com base nos tipos de endpoint, ajudando você a refinar o glossário.

## Variantes personalizadas {#personalized-variants}
Use [Variantes personalizadas]({{site.baseurl}}/user_guide/messaging/ab_testing/optimizations) para enviar a cada usuário no seu Segment-alvo a variante com a qual ele tem mais probabilidade de interagir.

## Testando Canvas {#testing-canvases}
Depois de criar seu Canvas, existem várias verificações que você pode querer realizar antes do lançamento, dependendo de detalhes como o tamanho do seu público ou o número de filtros de segmentação. Confira [Enviando Canvas de teste]({{site.baseurl}}/user_guide/messaging/canvas/testing_canvases/sending_test_canvases) para dicas.

## Liquid 5
Para os usuários existentes da empresa, o Liquid 5 está disponível de forma geral. Saiba mais sobre [as novidades do Liquid 5]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid#liquid-5-support).

## Novas parcerias da Braze {#new-braze-partnerships}

### Shopify
A integração entre a Braze e o [Shopify]({{site.baseurl}}/partners/shopify) permite atualizar perfis de usuário existentes ou criar novos na Braze para leads, inscrições e registros de conta capturados na sua loja Shopify.

## Atualizações do SDK {#sdk-updates}

As atualizações mais recentes do SDK foram lançadas. Atualizações com mudanças significativas estão listadas na seção de atualizações do SDK; todas as outras atualizações podem ser encontradas nos changelogs correspondentes do SDK.

- [Android SDK 23.1.0-23.12](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [React Native SDK v1.38.0–v1.38.1](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - Atualizada a ponte nativa do Android para o Braze Android SDK 23.0.1.
  - Atualizada a ponte nativa do iOS para o Braze iOS SDK 4.5.0.
  - O Braze React Native Android SDK agora requer Kotlin diretamente para compilação.
- [Braze Expo Plugin 0.4.0](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - Renomeada a prop `fcmSenderID` para `firebaseCloudMessagingSenderId`.
- [Unity 3.9.0](https://github.com/Appboy/appboy-unity-sdk/blob/master/CHANGELOG.md)
  - Atualizado o plugin do Android para usar o Braze Android SDK 23.1.0.
  - Adicionada a capacidade de solicitar permissões de notificação por push em dispositivos Android 13+ via `Appboy.AppboyBinding.PromptUserForPushPermissions(false)`.
- [SWIFT SDK 5.3.0-5.4.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#540)
