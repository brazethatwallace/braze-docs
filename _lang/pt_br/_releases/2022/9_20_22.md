# Lançamento em 20 de setembro de 2022 {#september-20-2022-release}

## Guia da API {#api-guide}
Confira o [Guia da API da Braze]({{site.baseurl}}/api/home) para pesquisar endpoints com base nos tipos de endpoints, ajudando você a refinar o glossário.

## Variantes personalizadas {#personalized-variants}
Use [Variantes personalizadas]({{site.baseurl}}/user_guide/messaging/ab_testing/optimizations) para enviar a cada usuário do seu segmento de direcionamento a variante com a qual ele tem maior probabilidade de engajamento.

## Teste de Canvas {#testing-canvases}
Depois de criar seu Canvas, há várias verificações que você pode querer realizar antes do lançamento, dependendo de detalhes como o tamanho do público ou o número de filtros de segmentação. Confira [Enviando Canvas de teste]({{site.baseurl}}/user_guide/messaging/canvas/testing_canvases/sending_test_canvases) para obter dicas.

## Liquid 5
Para os usuários existentes da empresa, o Liquid 5 está disponível de forma geral. Saiba mais sobre [as novidades do Liquid 5]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/liquid#whats-new-with-liquid-5).

## Novas parcerias da Braze {#new-braze-partnerships}

### Shopify
A integração entre a Braze e o [Shopify]({{site.baseurl}}/partners/shopify) permite atualizar perfis de usuários existentes ou criar novos perfis na Braze para leads, inscrições e registros de contas capturados na sua loja Shopify.

## Atualizações do SDK {#sdk-updates}

As seguintes atualizações do SDK foram lançadas. As atualizações com mudanças significativas estão listadas na seção de atualizações do SDK; todas as outras atualizações podem ser encontradas nos changelogs correspondentes do SDK.

- [Android SDK 23.1.0-23.12](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [React Native SDK v1.38.0–v1.38.1](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - Atualizada a ponte nativa do Android para o SDK da Braze para Android 23.0.1.
  - Atualizada a ponte nativa do iOS para o SDK da Braze para iOS 4.5.0.
  - O SDK React Native da Braze para Android agora requer Kotlin diretamente para compilação.
- [Braze Expo Plugin 0.4.0](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - Renomeada a prop `fcmSenderID` para `firebaseCloudMessagingSenderId`.
- [Unity 3.9.0](https://github.com/Appboy/appboy-unity-sdk/blob/master/CHANGELOG.md)
  - Atualizado o plugin do Android para usar o SDK da Braze para Android 23.1.0.
  - Adicionada a capacidade de solicitar permissões de notificação por push em dispositivos Android 13+ via `Appboy.AppboyBinding.PromptUserForPushPermissions(false)`.
- [Swift SDK 5.3.0-5.4.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#540)
