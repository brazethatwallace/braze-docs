# Julho de 2021 {#july-2021}

## Pesquisa simples em mensagem no app {#simple-survey-in-app-message}

Use o [modelo de mensagem no app de pesquisa simples]({{site.baseurl}}/user_guide/channels/in_app_messages/message_types/simple_survey) para coletar atributos, insights e preferências do usuário que impulsionam sua estratégia de campanha. Por exemplo, você pode perguntar aos usuários como eles gostariam de usar seu app, saber mais sobre suas preferências pessoais ou até mesmo perguntar sobre sua satisfação com um determinado recurso. Esse modelo de pesquisa é compatível tanto com apps móveis quanto com navegadores web.

Está se perguntando como fazer algo com o Liquid? Está apenas buscando inspiração? Confira nossa [biblioteca de casos de uso do Liquid]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/liquid_use_cases) para obter uma coleção de casos de uso que variam de aniversários e datas de nascimento a direcionamento de plataforma e muito mais.

## Rastreamento de e-mail {#email-tracking}

O rastreamento de pixel de abertura e o rastreamento de cliques agora podem ser desativados por perfil de usuário. Essa flexibilidade ajuda os clientes a cumprir as leis de privacidade regionais, em que um perfil de usuário individual pode indicar que não deseja mais ser rastreado. Consulte [Pixel de abertura e rastreamento de cliques]({{site.baseurl}}/user_guide/channels/email/email_setup/open_pixel_and_click_tracking) para saber mais.

## Endpoints da API or interface de programação do aplicativo (API) de perfil de usuário do Amplitude {#amplitude-user-profile-api-endpoints}

A API or interface de programação do aplicativo (API) de perfil de usuário do Amplitude atende aos perfis de usuário do Amplitude. Isso inclui propriedades do usuário, propriedades computadas do usuário, uma lista de IDs de coortes que incluem o usuário e recomendações. Consulte os [endpoints da API or interface de programação do aplicativo (API) de perfil de usuário do Amplitude]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/amplitude/amplitude_user_profile_api) para saber mais.

## Endpoint de detalhes da campanha {#campaign-details-endpoint}

O [endpoint `/campaigns/details`]({{site.baseurl}}/api/endpoints/export/campaigns/get_campaign_details) adicionou uma resposta `message` dedicada para o canal de mensagem no app. A documentação sobre isso pode ser encontrada em [Mensagens por canal]({{site.baseurl}}/api/endpoints/export/campaigns/get_campaign_details#messages-by-channel).
