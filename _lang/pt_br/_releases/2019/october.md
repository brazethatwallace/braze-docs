# Outubro de 2019 {#october-2019}

## Análise aprimorada da variante do Canvas {#improved-canvas-variant-analytics}

O Canvas tem análises de dados novas e aprimoradas para visualizar o desempenho de cada uma de suas variantes. Há novas métricas, especialmente em relação a eventos de conversão e intervalo de confiança, e novos recursos como cópia de células, IDs de API e download de um `.csv` dos resultados. Leia mais sobre a [análise aprimorada da variante do Canvas]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/change_your_canvas_after_launch#canvas-details).

## SMS

A Braze agora oferece SMS com Campaigns, Canvas e [Currents]({{site.baseurl}}/user_guide/data/distribution/braze_currents/event_glossary/message_engagement_events)! Confira nosso [guia de configuração]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs) para começar e nosso [guia de envio de SMS]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs) para saber mais!

## Melhorias no bloco de conteúdo {#content-block-improvements}

O ID da API de um bloco de conteúdo agora será exibido na página do bloco de conteúdo selecionado no dashboard. Além disso, mostraremos onde os blocos de conteúdo estão sendo usados.

## Criação e identificação de usuários somente com alias por meio da API {#alias-only-user-creation-and-identification-via-the-api}

Agora é possível [usar uma solicitação de API]({{site.baseurl}}/api/objects_filters/user_attributes_object) com qualquer campo no objeto Attributes para criar ou atualizar um atributo desse nome com o valor fornecido no perfil de usuário especificado.
