# Março de 2019 {#march-2019}

## Mensagens no app - Geração 3 {#in-app-messages-generation-3}

A Braze tem o orgulho de anunciar que fizemos melhorias na aparência das nossas mensagens no app para aderir às melhores práticas de UX e UI mais recentes. Nas mensagens no app mais recentes, você pode esperar que seus usuários interajam com mensagens com:
- Tamanhos de fonte maiores
- Espaçamento refinado
- Um novo ativo de fechar `x`
- Comportamento responsivo aprimorado para todos os tipos de mensagens, ajustando-se melhor aos viewports
- Bordas de botões para criar contrastes personalizados entre botões

Nossas [novas mensagens no app]({{site.baseurl}}/user_guide/channels/in_app_messages/) levarão suas interações com seus usuários de boas para incríveis!

![Comportamento de tela inteira]({% image_buster /assets/img/full-screen-behavior.gif %}){: style="border:0px;"}

### O que você precisa fazer {#what-you-need-to-do}

Recomendamos fortemente a atualização para as versões mais recentes dos SDKs da Braze para [Web]({{site.baseurl}}/developer_guide/platform_integration_guides/web/initial_sdk_setup/#upgrading-the-sdk), [iOS]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=swift) e [Android]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=android).

Depois disso, você estará com tudo pronto!

O [Google Cloud Storage]({{site.baseurl}}/partners/data_and_analytics/cloud_storage/google_cloud_storage_for_currents/) não está mais em versão beta!
