## Flexibilidade de dados {#data-flexibility}

### Dashboard de uso da API {#api-usage-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

O [dashboard de uso da API]({{site.baseurl}}/user_guide/analytics/dashboards/api_usage) permite monitorar o tráfego de entrada da REST API na Braze para entender as tendências de uso das nossas REST APIs e solucionar possíveis problemas.

### Adição de tags a atributos personalizados {#adding-tags-to-custom-attributes}

{% multi_lang_include release_type.md release="General availability" %}

Você pode [adicionar tags a um atributo personalizado]({{site.baseurl}}/user_guide/data/custom_data/custom_attributes#adding-tags) depois que ele for criado, se tiver a permissão "Manage Events, Attributes, Purchases". As tags podem então ser usadas para filtrar a lista de atributos.

### Endpoints de seleções de catálogo e campos de catálogo assíncronos {#catalog-selections-and-async-catalog-fields-endpoints}

{% multi_lang_include release_type.md release="General availability" %}

Os seguintes endpoints já estão disponíveis de forma geral:
* [POST: Criar campos de catálogo]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/post_create_catalog_fields)
* [DELETE: Excluir campo de catálogo]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/delete_catalog_field)
* [DELETE: Excluir seleção de catálogo]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/delete_catalog_selection)
* [POST: Criar seleção de catálogo]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/post_create_catalog_selections)

### Uso de um endereço de e-mail para disparar Campaigns ou Canvas {#using-an-email-address-to-trigger-campaigns-or-canvases}

{% multi_lang_include release_type.md release="General availability" %}

Agora você pode especificar um destinatário por endereço de e-mail para disparar suas [Campaigns]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/target_users) e [Canvas]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas#step-13-set-your-target-entry-audience).

### Uso de um número de telefone para identificar um usuário por meio da API {#using-a-phone-number-to-identify-a-user-via-the-api}

{% multi_lang_include release_type.md release="General availability" %}

Agora você pode usar um número de telefone, além de um alias e endereço de e-mail, para identificar um usuário por meio do [endpoint da API `/users/identify`]({{site.baseurl}}/api/endpoints/user_data/post_user_identify)

### Obtendo um rastreamento SAML {#getting-a-saml-trace}
Adicionamos [etapas sobre como obter um rastreamento SAML]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/saml_sso_setup#obtaining-a-saml-trace), o que ajuda a resolver problemas sobre o SAML SSO com o Suporte de forma mais eficiente.

### Data centers específicos da região {#region-specific-data-centers}
Como a Braze está crescendo para atender a novas áreas, adicionamos um [artigo sobre os data centers da Braze]({{site.baseurl}}/user_guide/data/infrastructure/data_centers) para esclarecer nossa abordagem operacional.


## Liberando a criatividade {#unlocking-creativity}

### Notificações de queda de preço e notificações de volta ao estoque {#price-drop-notifications-and-back-in-stock-notifications}

{% multi_lang_include release_type.md release="General availability" %}

Agora você pode notificar os clientes quando um item estiver de volta ao estoque, configurando [notificações de volta ao estoque]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/back_in_stock_notifications) por meio de um Canvas e de um catálogo.

Você também pode criar [notificações de queda de preço]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/price_drop_notifications) para notificar os clientes quando o preço de um item diminuir, configurando notificações de queda de preço em um catálogo e Canvas.

### Prévia para seleção {#preview-for-selection}

{% multi_lang_include release_type.md release="General availability" %}

Depois de criar uma seleção, você pode [ver o que uma seleção retornaria]({{site.baseurl}}/user_guide/data/activation/catalogs/selections#test-and-preview) para um usuário aleatório ou um usuário específico.

### Uso de modelos em itens de catálogo com Liquid {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="General availability" %}

Você pode [usar modelos em itens de catálogo que incluam Liquid]({{site.baseurl}}/user_guide/data/activation/catalogs/using_catalogs#using-liquid).

### Modelos de Canvas {#canvas-templates}
Adicionamos novos modelos de Canvas para [integração de usuários com uma pesquisa de preferências]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/preference_survey) e [criação de uma inscrição por e-mail com duplo opt-in]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/email_signup).

### Gerenciamento de leads com o Salesforce Sales Cloud para B2B {#managing-leads-with-salesforce-sales-cloud-for-b2b}
Uma das maneiras pelas quais os profissionais de marketing B2B podem usar a Braze é por meio de uma integração com o Salesforce Sales Cloud. Leia mais sobre como implementar esse [caso de uso]({{site.baseurl}}/user_guide/get_started/b2b_use_cases/b2b_salesforce_sales_cloud).

## Canais robustos {#robust-channels}

### Listas de supressão {#suppression-lists}

{% multi_lang_include release_type.md release="Beta" %}

As [listas de supressão]({{site.baseurl}}/user_guide/audience/suppression_lists) especificam grupos de usuários que nunca receberão mensagens. Os administradores podem criar listas de supressão com filtros de segmento para restringir um grupo de usuários da mesma forma que você faria para a segmentação.

## Novas parcerias da Braze {#new-braze-partnerships}

### Constructor - Conteúdo dinâmico {#constructor-dynamic-content}
O [Constructor]({{site.baseurl}}/partners/ecommerce/product_search_recommendations/constructor) é uma plataforma de pesquisa e descoberta de produtos que usa IA e machine learning para oferecer pesquisa personalizada, recomendações e experiências de navegação para sites de comércio eletrônico e varejo.

### Trustpilot - Conteúdo dinâmico {#trustpilot-dynamic-content}
A [Trustpilot]({{site.baseurl}}/partners/trustpilot) é uma plataforma de avaliação on-line que permite que seus clientes compartilhem feedback e que você gerencie e responda às avaliações.
