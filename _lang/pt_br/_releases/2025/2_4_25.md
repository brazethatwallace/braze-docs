# Lançamento de 4 de fevereiro de 2025 {#february-4-2025-release}

## Melhorias na documentação da Braze {#braze-docs-improvements}

Para facilitar a busca pelo que você precisa, separamos os artigos que antes estavam agrupados em "Dados e Análises" em [Dados]({{site.baseurl}}/user_guide/data) e [Analytics]({{site.baseurl}}/user_guide/analytics).

### Guia do desenvolvedor {#developer-guide}
Fizemos uma grande reorganização de toda a documentação do [Guia do Desenvolvedor da Braze]({{site.baseurl}}/developer_guide/home), incluindo a unificação de tutoriais que estavam divididos em várias páginas em uma única página.

Também há uma nova [página de referência do SDK]({{site.baseurl}}/developer_guide/references) que lista toda a documentação de referência e os repositórios de cada SDK da Braze.

#### SDK da Braze para Unreal Engine {#unreal-engine-braze-sdk}
Migramos e reescrevemos todo o conteúdo do README do repositório GitHub do SDK da Braze para Unreal Engine em sua [seção dedicada na documentação da Braze]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=unreal%20engine).

## Flexibilidade de dados {#data-flexibility}

### Dashboard de uso de API {#api-usage-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

O [dashboard de uso de API]({{site.baseurl}}/user_guide/analytics/dashboards/api_usage) permite monitorar o tráfego de entrada da REST API na Braze para entender as tendências de uso das nossas REST APIs e solucionar possíveis problemas.

### Adicionando tags a atributos personalizados {#adding-tags-to-custom-attributes}

{% multi_lang_include release_type.md release="General availability" %}

Você pode [adicionar tags a um atributo personalizado]({{site.baseurl}}/user_guide/data/activation/attributes/custom_attributes#add-tags) após ele ser criado, desde que tenha a permissão "Manage Events, Attributes, Purchases". As tags podem então ser usadas para filtrar a lista de atributos.

### Endpoints de seleções de catálogo e campos assíncronos de catálogo {#catalog-selections-and-async-catalog-fields-endpoints}

{% multi_lang_include release_type.md release="General availability" %}

Os seguintes endpoints agora estão disponíveis de forma geral:
* [POST: Criar campos de catálogo]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/post_create_catalog_fields)
* [DELETE: Excluir campo de catálogo]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/delete_catalog_field)
* [DELETE: Excluir seleção de catálogo]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/delete_catalog_selection)
* [POST: Criar seleção de catálogo]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/post_create_catalog_selections)

### Usando um endereço de e-mail para disparar Campaigns ou Canvas {#using-an-email-address-to-trigger-campaigns-or-canvases}

{% multi_lang_include release_type.md release="General availability" %}

Agora você pode especificar um destinatário por endereço de e-mail para disparar suas [Campaigns]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/target_users) e [Canvas]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas#step-13-set-your-target-entry-audience).

### Usando um número de telefone para identificar um usuário via API {#using-a-phone-number-to-identify-a-user-via-the-api}

{% multi_lang_include release_type.md release="General availability" %}

Agora você pode usar um número de telefone, além de alias e endereço de e-mail, para identificar um usuário por meio do [endpoint de API `/users/identify`]({{site.baseurl}}/api/endpoints/user_data/post_user_identify).

### Obtendo um rastreamento SAML {#getting-a-saml-trace}
Adicionamos [etapas sobre como obter um rastreamento SAML]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/saml_sso_setup#obtaining-a-saml-trace), o que ajuda a resolver problemas de SAML SSO com o Suporte de forma mais eficiente.

### Data centers regionais {#region-specific-data-centers}
À medida que a Braze cresce para atender novas regiões, adicionamos um [artigo sobre os data centers da Braze]({{site.baseurl}}/user_guide/data/infrastructure/data_centers) para esclarecer nossa abordagem operacional.

## Desbloqueando a criatividade {#unlocking-creativity}

### Notificações de queda de preço e notificações de volta ao estoque {#price-drop-notifications-and-back-in-stock-notifications}

{% multi_lang_include release_type.md release="General availability" %}

Agora você pode notificar os clientes quando um item estiver de volta ao estoque, configurando [notificações de volta ao estoque]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/back_in_stock_notifications) por meio de um Canvas e catálogo.

Você também pode criar [notificações de queda de preço]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/price_drop_notifications) para notificar os clientes quando o preço de um item diminuir, configurando notificações de queda de preço em um catálogo e Canvas.

### Prévia para seleção {#preview-for-selection}

{% multi_lang_include release_type.md release="General availability" %}

Após criar uma seleção, você pode [visualizar o que uma seleção retornaria]({{site.baseurl}}/user_guide/data/activation/catalogs/selections#test-and-preview) para um usuário aleatório ou um usuário específico.

### Modelagem de itens de catálogo incluindo Liquid {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="General availability" %}

Você pode [modelar itens de catálogo que incluem Liquid]({{site.baseurl}}/user_guide/data/activation/catalogs/using_catalogs#using-liquid).

### Modelos de Canvas {#canvas-templates}
Adicionamos novos modelos de Canvas para [integração de usuários com uma pesquisa de preferências]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/preference_survey) e [criação de inscrição por e-mail com dupla aceitação]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/email_signup).

### Gerenciando leads com o Salesforce Sales Cloud para B2B {#managing-leads-with-salesforce-sales-cloud-for-b2b}
Uma das formas como profissionais de marketing B2B podem usar a Braze é por meio de uma integração com o Salesforce Sales Cloud. Leia mais sobre como implementar esse [caso de uso]({{site.baseurl}}/user_guide/get_started/b2b_use_cases/b2b_salesforce_sales_cloud).

## Canais robustos {#robust-channels}

### Listas de supressão {#suppression-lists}

{% multi_lang_include release_type.md release="Beta" %}

[Listas de supressão]({{site.baseurl}}/user_guide/audience/suppression_lists) especificam grupos de usuários que nunca receberão mensagens. Os administradores podem criar listas de supressão com filtros de Segment para restringir um grupo de usuários da mesma forma que fariam para segmentação.

## Novas parcerias da Braze {#new-braze-partnerships}

### Constructor - Conteúdo dinâmico {#constructor-dynamic-content}
[Constructor]({{site.baseurl}}/partners/ecommerce/product_search_recommendations/constructor) é uma plataforma de busca e descoberta de produtos que usa IA e machine learning para oferecer experiências personalizadas de busca, recomendações e navegação para websites de e-commerce e varejo.

### Trustpilot - Conteúdo dinâmico {#trustpilot-dynamic-content}
[Trustpilot]({{site.baseurl}}/partners/trustpilot) é uma plataforma de avaliações online que permite que seus clientes compartilhem feedback e que você gerencie e responda às avaliações.
