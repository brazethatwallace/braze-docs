# Lançamento de 4 de março de 2025 {#march-4-2025-release}

## Reorganização do Guia do Desenvolvedor {#developer-guide-detangle}

Conteúdos idênticos compartilhados entre vários SDKs estão começando a ser unificados usando o novo recurso de abas de SDK or kit de desenvolvimento de software do site de documentação. Este mês, [integração SDK or kit de desenvolvimento de software]({{site.baseurl}}/developer_guide/sdk_integration), [inicialização do SDK or kit de desenvolvimento de software]({{site.baseurl}}/developer_guide/sdk_integration) e [Content Cards]({{site.baseurl}}/developer_guide/content_cards) foram combinados. Fique de olho para mais atualizações nos próximos meses.

## Flexibilidade de dados {#data-flexibility}

### Braze IDs para perfis de usuário {#braze-ids-for-user-profiles}

Um perfil de usuário agora inclui um [Braze ID]({{site.baseurl}}/user_guide/audience/manage_audience/user_profiles). Você pode usar isso ao buscar perfis de usuário.

### Adiamentos {#deferrals}

A Braze atualizou a definição do que é um soft bounce e está enviando um novo evento chamado [adiamentos]({{site.baseurl}}/user_guide/channels/email/reporting#email-performance), que ocorre quando um e-mail não foi entregue imediatamente, mas a Braze tentará reenviar o e-mail por até 72 horas após essa falha temporária de entrega para maximizar as chances de entrega bem-sucedida antes que as tentativas para essa Campaign específica sejam interrompidas.

### Relacionamentos de entidades no Snowflake {#snowflake-entity-relationships}

Mapeamos os [esquemas de tabelas brutas](/docs/assets/download_file/data-sharing-raw-table-schemas.txt) para os relacionamentos de entidades do Snowflake e da Braze em uma nova [página de documentação fácil de usar]({{site.baseurl}}/partners/data_and_analytics/data_warehouses/snowflake/entity_relationships). Ela inclui um detalhamento das tabelas `USER_MESSAGES` pertencentes a cada canal, além de descrições das chaves primárias, estrangeiras e nativas de cada tabela.

### Gerenciamento de identidade para IDs externos {#identity-management-for-external-ids}

Usar um endereço de e-mail ou um endereço de e-mail com hash como seu ID externo da Braze pode simplificar o gerenciamento de identidade em todas as suas fontes de dados. No entanto, é importante considerar os [riscos potenciais]({{site.baseurl}}/user_guide/data/user_data_collection/user_profile_lifecycle#identified-user-profiles) à privacidade do usuário e à segurança dos dados.

### Etapas de contexto para Canvas {#context-steps-for-canvas}

{% multi_lang_include release_type.md release="Early access" %}

Use [etapas de contexto]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/context) para criar ou atualizar um conjunto de variáveis que representam o contexto de um usuário (ou insights sobre o comportamento desse usuário) à medida que ele avança por um Canvas.

### Postergação personalizada {#personalized-delay}

{% multi_lang_include release_type.md release="Early access" %}

Você pode configurar uma [postergação personalizada]({{site.baseurl}}/user_guide/engagement_tools/canvas/canvas_components/delay_step#personalized-delays) para seus usuários selecionando o botão de alternância **Personalize delay** na sua etapa de postergação. É possível usar isso com uma etapa de contexto para selecionar uma variável de contexto como base para a postergação.

Ao configurar uma etapa de postergação na jornada do usuário no Canvas, agora é possível criar uma postergação de até 2 anos.

### Revertendo a sincronização automática {#reverting-automatic-synchronization}

Ao [compor uma mensagem de e-mail]({{site.baseurl}}/user_guide/message_building_by_channel/email/html_editor#step-3-compose-your-email), você pode reverter para a sincronização automática na guia Texto simples selecionando o ícone Regenerar a partir do HTML, que aparece apenas se o texto simples não estiver sincronizando.

## Canais robustos {#robust-channels}

### Android Live Updates

Embora as Live Updates não estejam oficialmente disponíveis até o [Android 16](https://android-developers.googleblog.com/2025/01/first-beta-android16.html), nossa página [Live Updates para Android]({{site.baseurl}}/developer_guide/push_notifications/live_notifications/?sdktab=android&tab=local) mostra como emular esse comportamento, para que você possa exibir notificações interativas na tela de bloqueio, semelhantes às [Live Activities para o Swift Braze SDK or kit de desenvolvimento de software]({{site.baseurl}}/developer_guide/push_notifications/live_notifications/?sdktab=swift). Diferente das Live Updates oficiais, essa funcionalidade pode ser implementada em versões mais antigas do Android.

### Copiando Campaigns com Feature Flags entre espaços de trabalho {#copying-campaigns-with-feature-flags-across-workspaces}

Agora você pode [copiar Campaigns com Feature Flags entre espaços de trabalho]({{site.baseurl}}/user_guide/engagement_tools/campaigns/managing_campaigns/copying_to_workspace#copying-campaigns-with-feature-flags). Para isso, certifique-se de que o espaço de trabalho de destino tenha um experimento de Feature Flag configurado com um ID que corresponda à Feature Flag referenciada na Campaign original.

### Novos tipos de mensagens WhatsApp compatíveis {#new-whatsapp-message-types-supported}

As mensagens do WhatsApp agora são compatíveis com [mensagens de saída em vídeo, áudio e documento]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#outbound-messages). Entre em contato com o gerente de conta da Braze se tiver interesse em participar do acesso antecipado.

### Mensagens da direita para a esquerda {#right-to-left-messages}

[Criação de mensagens da direita para a esquerda]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/localization/right_to_left_messages) aborda as práticas recomendadas para criar mensagens em idiomas que são lidos da direita para a esquerda, para que suas mensagens sejam exibidas da forma mais precisa possível.

## Automação de IA e ML {#ai-and-ml-automation}

### Recomendação de itens {#item-recommendations}

[Usando recomendação de itens no envio de mensagens]({{site.baseurl}}/user_guide/brazeai/item_recommendations/using_recommendations) aborda o objeto Liquid `product_recommendation` e inclui um tutorial para ajudar você a colocar esse conhecimento em prática.

## Novas parcerias da Braze {#new-braze-partnerships}

### Email Love - Extensões de canal {#email-love-channel-extensions}

A parceria entre a Braze e o [Email Love]({{site.baseurl}}/partners/message_orchestration) aproveita o recurso Export to Braze do Email Love e a API or interface de programação do aplicativo (API) da Braze para fazer o upload dos seus modelos de e-mail para a Braze de forma integrada.

### VWO - Testes A/B {#vwo-ab-testing}

A integração entre a Braze e o [VWO]({{site.baseurl}}/partners/data_and_analytics/ab_testing/vwo) permite que você aproveite os dados de experimentos do VWO para criar Segments direcionados e entregar Campaigns personalizadas.
