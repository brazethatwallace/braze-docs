# Lançamento de 4 de março de 2025 {#march-4-2025-release}

## Guia do desenvolvedor descomplicado {#developer-guide-detangle}

Conteúdo idêntico compartilhado entre vários SDKs está começando a ser mesclado usando o novo recurso de abas de SDK do site de documentação. Este mês, [integração de SDK]({{site.baseurl}}/developer_guide/sdk_integration), [inicialização de SDK]({{site.baseurl}}/developer_guide/sdk_initialization) e [Content Cards]({{site.baseurl}}/developer_guide/content_cards) foram combinados. Fique atento para mais atualizações nos próximos meses.

## Flexibilidade de dados {#data-flexibility}

### IDs da Braze para perfis de usuário {#braze-ids-for-user-profiles}

Um perfil de usuário agora inclui um [ID da Braze]({{site.baseurl}}/user_guide/engagement_tools/segments/user_profiles#user-profiles). Você pode usar isso ao pesquisar perfis de usuário.

### Adiamentos {#deferrals}

A Braze atualizou a definição do que é um soft bounce e está enviando um novo evento chamado [adiamentos]({{site.baseurl}}/user_guide/message_building_by_channel/email/reporting_and_analytics/email_reporting#email-performance), que ocorre quando um e-mail não é entregue imediatamente, mas a Braze tentará reenviar o e-mail por até 72 horas após essa falha temporária de entrega para maximizar as chances de entrega bem-sucedida antes que as tentativas para essa Campaign específica sejam interrompidas.

### Relacionamentos de entidades do Snowflake {#snowflake-entity-relationships}

Mapeamos os [esquemas de tabela bruta](/docs/assets/download_file/data-sharing-raw-table-schemas.txt) para relacionamentos de entidades do Snowflake e da Braze em uma nova [página de documentação amigável]({{site.baseurl}}/partners/data_and_analytics/data_warehouses/snowflake/entity_relationships). Ela inclui um detalhamento das tabelas `USER_MESSAGES` pertencentes a cada canal, bem como descrições das chaves primárias, estrangeiras e nativas de cada tabela.

### Gerenciamento de identidade para IDs externos {#identity-management-for-external-ids}

Usar um endereço de e-mail ou um endereço de e-mail com hash como seu ID externo da Braze pode simplificar o gerenciamento de identidade em todas as suas fontes de dados; no entanto, é importante considerar os [riscos potenciais]({{site.baseurl}}/user_guide/data/user_data_collection/user_profile_lifecycle#identified-user-profiles) à privacidade do usuário e à segurança dos dados.

### Etapas de contexto para Canvas {#context-steps-for-canvas}

{% multi_lang_include release_type.md release="Early access" %}

Use as [etapas de contexto]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/context) para criar ou atualizar um conjunto de variáveis que representam o contexto de um usuário (ou insights sobre o comportamento desse usuário) à medida que ele se move pelo Canvas.

### Postergação personalizada {#personalized-delay}

{% multi_lang_include release_type.md release="Early access" %}

Você pode configurar uma [postergação personalizada]({{site.baseurl}}/user_guide/engagement_tools/canvas/canvas_components/delay_step#personalized-delays) para seus usuários selecionando o toggle **Personalizar postergação** na sua etapa de postergação. Você pode usar isso com uma etapa de contexto para selecionar uma variável de contexto para a postergação.

Ao configurar uma etapa de postergação na jornada do usuário do Canvas, agora você pode criar uma postergação de até 2 anos.

### Revertendo a sincronização automática {#reverting-automatic-synchronization}

Ao [compor uma mensagem de e-mail]({{site.baseurl}}/user_guide/message_building_by_channel/email/html_editor#step-3-compose-your-email), você pode reverter para a sincronização automática na guia Texto simples selecionando o ícone Regenerar a partir do HTML, que só aparece se o texto simples não estiver sincronizando.

## Canais robustos {#robust-channels}

### Live Updates para Android {#android-live-updates}

Embora as Live Updates não estejam oficialmente disponíveis até o [Android 16](https://android-developers.googleblog.com/2025/01/first-beta-android16.html), nossa página [Live Updates para Android]({{site.baseurl}}/developer_guide/push_notifications/live_notifications/?sdktab=android&tab=local) mostra como emular seu comportamento, para que você possa exibir notificações interativas na tela de bloqueio semelhantes às [Live Activities para o SDK Swift da Braze]({{site.baseurl}}/developer_guide/push_notifications/live_notifications/?sdktab=swift). Diferente das Live Updates oficiais, essa funcionalidade pode ser implementada para versões mais antigas do Android.

### Copiando Campaigns com Feature Flags entre espaços de trabalho {#copying-campaigns-with-feature-flags-across-workspaces}

Agora você pode [copiar Campaigns com Feature Flags entre espaços de trabalho]({{site.baseurl}}/user_guide/engagement_tools/campaigns/managing_campaigns/copying_to_workspace#copying-campaigns-with-feature-flags). Para isso, certifique-se de que o espaço de trabalho de destino tenha um experimento de Feature Flag configurado com um ID que corresponda ao Feature Flag referenciado na Campaign original.

### Novos tipos de mensagens do WhatsApp suportados {#new-whatsapp-message-types-supported}

Mensagens do WhatsApp agora suportam [mensagens de saída de vídeo, áudio e documento]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/create#outbound-messages). Entre em contato com seu gerente de conta da Braze se estiver interessado em participar do acesso antecipado.

### Mensagens da direita para a esquerda {#right-to-left-messages}

[Criação de mensagens da direita para a esquerda]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/localization/right_to_left_messages) abrange as melhores práticas para elaborar mensagens em idiomas que leem da direita para a esquerda, para que suas mensagens sejam exibidas com a maior precisão possível.

### Recomendações de itens {#item-recommendations}

[Usando recomendações de itens em mensagens]({{site.baseurl}}/user_guide/brazeai/item_recommendations/using_recommendations) abrange o objeto Liquid `product_recommendation` e inclui um tutorial para ajudar você a colocar esse conhecimento em prática.

## Novas parcerias da Braze {#new-braze-partnerships}

### Email Love — Extensões de canal {#email-love-channel-extensions}

A parceria entre a Braze e o [Email Love]({{site.baseurl}}/partners/message_orchestration) aproveita o recurso Export to Braze do Email Love e a API da Braze para fazer upload dos seus modelos de e-mail para a Braze de forma integrada.

### VWO — Testes A/B {#vwo-ab-testing}

A integração entre a Braze e o [VWO]({{site.baseurl}}/partners/data_and_analytics/ab_testing/vwo) permite que você aproveite os dados de experimentos do VWO para criar segmentos direcionados e entregar Campaigns personalizadas.

    - Atualiza as ligações da versão nativa do iOS do [Braze Swift SDK 7.5.0 para 8.1.0](https://github.com/braze-inc/braze-swift-sdk/compare/7.5.0...8.1.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
