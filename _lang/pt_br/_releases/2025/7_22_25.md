# Versão de 22 de julho de 2025 {#july-22-2025-release}

## Exportação de eventos de segurança com Amazon S3 {#security-events-export-with-amazon-s3}

Você pode [exportar eventos de segurança automaticamente para o Amazon S3]({{site.baseurl}}/user_guide/administer/global/admin_settings/security_settings/security_export_s3), um provedor de armazenamento em nuvem, com um trabalho diário executado à meia-noite UTC. Uma vez configurado, você não precisa exportar manualmente os eventos de segurança pelo dashboard.

## Flexibilidade de dados {#data-flexibility}

### Importação de CSV {#csv-import}

{% multi_lang_include release_type.md release="General availability" %}

Você pode usar a importação de CSV para registrar e atualizar atributos de usuários e eventos personalizados na Braze, como `first_name`, `last_destination_searched` e `trip_booked`. Para começar, consulte [Importação de CSV]({{site.baseurl}}/user_guide/audience/manage_audience/import_users/csv_import).

### Alertas de uso da API {#api-usage-alerts}

{% multi_lang_include release_type.md release="General availability" %}

Os alertas de uso da API fornecem visibilidade crítica sobre o uso da sua API, permitindo que você detecte proativamente tráfego inesperado. Ao configurar esses alertas para rastrear volumes de solicitações de API importantes, você pode receber notificações em tempo real e resolver problemas antes que eles impactem suas campanhas de marketing.

### Limites de taxa da API do espaço de trabalho {#workspace-api-rate-limits}

Com os limites de taxa da API do espaço de trabalho, você pode definir um número máximo de solicitações de API que um espaço de trabalho pode fazer para um endpoint de ingestão específico, como `/users/track` ou dados do SDK. Você também pode aplicar limites de taxa a um grupo de espaços de trabalho, o que significa que o limite é compartilhado entre todos os espaços de trabalho desse grupo.

### Intervalo de tempo padrão para análise de dados de Campaign {#default-time-range-for-campaign-analytics}

Por padrão, o intervalo de tempo para [**Campaign Analytics**]({{site.baseurl}}/user_guide/analytics/reports/campaign_analytics) exibirá os últimos 90 dias a partir do momento atual. Isso significa que, se a Campaign foi lançada há mais de 90 dias, a análise de dados será exibida como "0" para o intervalo de tempo informado. Para visualizar toda a análise de dados de Campaigns mais antigas, ajuste o intervalo de tempo do relatório.

### Comportamento atualizado para a etapa da jornada experimental do Canvas {#updated-behavior-for-canvas-experiment-paths-step}

Se o seu Canvas tiver um Caminho Vencedor ou Caminho Personalizado com [experimento]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step) ativo ou em andamento e você atualizar o Canvas ativo, independentemente de atualizar a etapa da jornada experimental em si, o experimento em andamento será encerrado e a etapa do experimento não determinará um caminho vencedor ou caminhos personalizados. Para reiniciar o experimento, você pode desconectar a jornada experimental existente e lançar uma nova, ou duplicar o Canvas e lançar um novo Canvas. Caso contrário, os usuários seguirão a jornada experimental como se nenhum método de otimização tivesse sido selecionado.

Para saber mais, consulte [Editar Canvas após o lançamento]({{site.baseurl}}/post-launch_edits).

### Limite de taxa mais rápido disponível para o endpoint `/users/export/ids` {#faster-rate-limit-available-for-usersexportids-endpoint}

Você também pode aumentar o [limite de taxa para o endpoint /users/export/ids]({{site.baseurl}}/api/endpoints/export/user_data/post_users_identifier#rate-limit) para 40 solicitações por segundo atendendo aos seguintes requisitos:

- Seu espaço de trabalho tem o limite de taxa padrão (250 solicitações por minuto) ativado. Entre em contato com seu gerente de conta da Braze para obter mais assistência na remoção de qualquer limite de taxa pré-existente que você possa ter.
- Sua solicitação inclui o parâmetro fields_to_export para listar todos os campos que você deseja receber.

## Liberando a criatividade {#unlocking-creativity}

### Landing pages

Você pode tornar sua landing page [responsiva ao tamanho do dispositivo do usuário]({{site.baseurl}}/user_guide/engagement_tools/landing_pages/creating_pages#step-3-customize-the-page) empilhando colunas verticalmente em telas menores. Para ativar isso, adicione uma coluna na linha que você deseja tornar responsiva e, em seguida, ative **Vertically stack on smaller screens** na seção **Customize columns**.

## Canais robustos {#robust-channels}

### Filtragem de bots para e-mails {#bot-filtering-for-emails}

{% multi_lang_include release_type.md release="General availability" %}

Configure a filtragem de bots nas suas [Preferências de e-mail]({{site.baseurl}}/user_guide/administer/global/workspace_settings/email_preferences) para excluir todos os cliques suspeitos de máquinas ou bots. Um "clique de bot" em e-mail refere-se a um clique em hiperlinks dentro de um e-mail gerado por um programa automatizado. Ao filtrar esses cliques de bot, você pode intencionalmente disparar e entregar mensagens a destinatários que estão engajados.

### Blocos de produtos no editor de arrastar e soltar {#drag-and-drop-product-blocks}

{% multi_lang_include release_type.md release="Early access" %}

O [editor de arrastar e soltar]({{site.baseurl}}/dnd_product_blocks) permite que você adicione e configure rapidamente blocos de produtos nas suas mensagens para exibições de produtos integradas, sem a necessidade de criar código Liquid personalizado. O recurso de bloco de produto no editor de arrastar e soltar está atualmente disponível apenas para e-mail.

### Texto span para landing pages e mensagens no app {#span-text-for-landing-pages-and-in-app-messages}

O texto span permite que você aplique estilos específicos a blocos de texto sem código personalizado para suas [landing pages]({{site.baseurl}}/user_guide/engagement_tools/landing_pages/creating_pages#step-3-customize-the-page) e [mensagens no app]({{site.baseurl}}/user_guide/channels/in_app_messages/customize/style_settings#blocks). Para fazer isso, destaque o texto que você deseja estilizar e selecione **Wrap with span for style**.

### Clique no anúncio para WhatsApp {#ad-click-to-whatsapp}

[Anúncios que direcionam para o WhatsApp]({{site.baseurl}}/whatsapp_use_cases) são uma maneira eficiente de trazer clientes novos e existentes a partir de anúncios do Meta no Facebook, Instagram ou outras plataformas. Use esses anúncios para promover seus produtos e serviços enquanto torna os usuários cientes da sua presença no WhatsApp.

## Novas parcerias Braze {#new-braze-partnerships}

### API de visitantes do Shopify — eCommerce {#shopify-visitory-api-ecommerce}

A Braze coleta informações de visitantes, como endereços de e-mail e números de telefone, por meio de mensagens no navegador. Essas informações são então enviadas para o Shopify. Esses dados ajudam os comerciantes a reconhecer visitantes em sua loja e criar uma experiência de compra mais personalizada.

### Okendo — eCommerce

A integração da Braze com a [Okendo]({{site.baseurl}}/partners/okendo) funciona em vários produtos na plataforma da Okendo, incluindo Avaliações, Fidelidade, Indicações, Pesquisas e Questionários. A Okendo envia eventos personalizados e atributos de usuário para a Braze, que podem ser usados para personalizar e disparar mensagens.

### Lemnisk — Plataforma de dados do cliente {#lemnisk-customer-data-platform}

A integração da Braze com a [Lemnisk]({{site.baseurl}}/partners/lemnisk) permite que marcas e empresas desbloqueiem todo o potencial da Braze, atuando como uma camada de inteligência liderada por CDP que unifica dados de usuários em várias plataformas em tempo real e envia as informações e comportamentos coletados do usuário para a Braze em tempo real.

## Atualizações do SDK {#sdk-updates}

As seguintes atualizações do SDK foram lançadas. As atualizações com mudanças significativas estão listadas abaixo; todas as outras atualizações podem ser encontradas verificando os changelogs correspondentes do SDK.

- [Web SDK 6.0.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
    - Removidas a propriedade `Banner.html` e os métodos `logBannerClick` e `logBannerImpressions`. Em vez disso, use [`insertBanner`](https://js.appboycdn.com/web-sdk/latest/doc/modules/braze.html#insertbanner), que lida automaticamente com o rastreamento de impressões e cliques.
    - Removido o suporte para o recurso legado do News Feed. Isso inclui a remoção da classe Feed e seus métodos associados.
    - Os campos created e categories que eram usados por cartões legados do News Feed foram removidos das subclasses de [`Card`](https://js.appboycdn.com/web-sdk/latest/doc/classes/braze.card.html).
    - O campo linkText também foi removido da subclasse Card [`ImageOnly`](https://js.appboycdn.com/web-sdk/latest/doc/classes/braze.imageonly.html) e de seu construtor.
    - Definições foram esclarecidas e tipos atualizados para indicar que certos métodos do SDK retornam explicitamente undefined quando o SDK não está inicializado, alinhando as tipagens com o comportamento real em tempo de execução. Isso pode introduzir novos erros de TypeScript em projetos que dependiam das tipagens anteriores (incompletas).
    - As imagens de mensagens no app com `cropType` de `CENTER_CROP` (como `FullScreenMessage` por padrão) agora são renderizadas via uma tag `<img>` em vez de `<span>` para melhorar a acessibilidade. Isso pode quebrar personalizações CSS existentes para a classe `.ab-center-cropped-img` ou seus filhos.
- [Cordova SDK 13.0.0](https://github.com/braze-inc/braze-cordova-sdk/blob/master/CHANGELOG.md#1300)
    - Atualizada a implementação interna do iOS do método `enableSdk` para usar setEnabled: em vez de `_requestEnableSDKOnNextAppRun`, que foi descontinuado no Swift SDK.
        - Chamar este método não requer mais que o app seja reiniciado para ter efeito. O SDK agora será ativado assim que este método for executado.
    - Atualizada a ponte nativa do Android [do Braze Android SDK 36.0.0 para o 37.0.0](https://github.com/braze-inc/braze-android-sdk/compare/v36.0.0...v37.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
- [Android SDK 37.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [Swift SDK 12.0.1-12.1.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
