# Versão de 22 de julho de 2025 {#july-22-2025-release}

## Exportação de eventos de segurança com Amazon S3 {#security-events-export-with-amazon-s3}

Você pode [exportar automaticamente Eventos de Segurança para o Amazon S3]({{site.baseurl}}/user_guide/administer/global/admin_settings/security_settings/security_export_s3), um provedor de armazenamento em nuvem, com um job diário executado à meia-noite UTC. Após a configuração, não é necessário exportar manualmente os Eventos de Segurança pelo dashboard.

## Flexibilidade de dados {#data-flexibility}

### Importação de CSV {#csv-import}

{% multi_lang_include release_type.md release="General availability" %}

Você pode usar a importação de CSV para registrar e atualizar atributos de usuários e eventos personalizados na Braze, como `first_name`, `last_destination_searched` e `trip_booked`. Para começar, consulte [Importação de CSV]({{site.baseurl}}/user_guide/audience/manage_audience/import_users/csv_import).

### Alertas de uso de API {#api-usage-alerts}

{% multi_lang_include release_type.md release="General availability" %}

Os alertas de uso de API fornecem visibilidade crítica sobre o uso da sua API, permitindo que você detecte proativamente tráfego inesperado. Ao configurar esses alertas para rastrear volumes de solicitações de API importantes, você pode receber notificações em tempo real e resolver problemas antes que eles afetem suas campanhas de marketing.

### Limites de frequência de API do espaço de trabalho {#workspace-api-rate-limits}

Com os limites de frequência de API do espaço de trabalho, você pode definir um número máximo de solicitações de API que um espaço de trabalho pode fazer para um endpoint de ingestão específico, como `/users/track` ou dados do SDK. Você também pode aplicar limites de frequência a um grupo de espaços de trabalho, o que significa que o limite é compartilhado entre todos os espaços de trabalho desse grupo.

### Intervalo de tempo padrão para análise de dados de Campaigns {#default-time-range-for-campaign-analytics}

Por padrão, o intervalo de tempo para [**Campaign Analytics**]({{site.baseurl}}/user_guide/analytics/reports/campaign_analytics) exibirá os últimos 90 dias a partir do momento atual. Isso significa que, se a Campaign foi lançada há mais de 90 dias, a análise de dados será exibida como "0" para o intervalo de tempo selecionado. Para visualizar todos os dados de análise de Campaigns mais antigas, ajuste o intervalo de tempo do relatório.

### Comportamento atualizado para a etapa da jornada experimental do Canvas {#updated-behavior-for-canvas-experiment-paths-step}

Se o seu Canvas tiver uma Winning jornada ou Personalized jornada ativa ou em andamento em um [experimento]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step) e você atualizar o Canvas ativo, independentemente de atualizar a etapa da jornada experimental em si, o experimento em andamento será encerrado e a etapa do experimento não determinará uma jornada vencedora ou jornadas personalizadas. Para reiniciar o experimento, você pode desconectar a jornada experimental existente e lançar uma nova, ou duplicar o Canvas e lançar um novo Canvas. Caso contrário, os usuários seguirão pela jornada experimental como se nenhum método de otimização tivesse sido selecionado.

Para saber mais, consulte [Editando Canvas após o lançamento]({{site.baseurl}}/post-launch_edits).

### Limite de frequência mais rápido disponível para o endpoint `/users/export/ids` {#faster-rate-limit-available-for-usersexportids-endpoint}

Você também pode aumentar o [limite de frequência para o endpoint /users/export/ids]({{site.baseurl}}/api/endpoints/export/user_data/post_users_identifier#rate-limit) para 40 solicitações por segundo atendendo aos seguintes requisitos:

- Seu espaço de trabalho tem o limite de frequência padrão (250 solicitações por minuto) ativado. Entre em contato com o gerente de conta da Braze para obter mais assistência com a remoção de qualquer limite de frequência pré-existente que você possa ter.
- Sua solicitação inclui o parâmetro fields_to_export para listar todos os campos que você deseja receber.

## Desbloqueando a criatividade {#unlocking-creativity}

### Landing pages

Você pode tornar sua landing page [responsiva ao tamanho do dispositivo do usuário]({{site.baseurl}}/user_guide/messaging/landing_pages/create_landing_pages#step-3-customize-the-page) empilhando colunas verticalmente em telas menores. ## Canais robustos {#robust-channels}

### Filtragem de bots para e-mails {#bot-filtering-for-emails}

{% multi_lang_include release_type.md release="General availability" %}

Configure a filtragem de bots nas suas [Preferências de E-mail]({{site.baseurl}}/user_guide/administer/global/workspace_settings/email_preferences) para excluir todos os cliques suspeitos de máquinas ou bots. Um "clique de bot" em e-mail refere-se a um clique em hiperlinks dentro de um e-mail gerado por um programa automatizado. Ao filtrar esses cliques de bots, você pode disparar e entregar mensagens intencionalmente para destinatários que estão engajados.

### Blocos de produto de arrastar e soltar {#drag-and-drop-product-blocks}

{% multi_lang_include release_type.md release="Early access" %}

O [editor de arrastar e soltar]({{site.baseurl}}/dnd_product_blocks) permite que você adicione e configure rapidamente blocos de produto nas suas mensagens para exibições de produtos integradas, sem a necessidade de criar código Liquid personalizado. O recurso de bloco de produto de arrastar e soltar está disponível atualmente apenas para e-mail.

### Texto span para landing pages e mensagens no app {#span-text-for-landing-pages-and-in-app-messages}

O texto span permite aplicar estilos específicos a blocos de texto sem código personalizado nas suas [landing pages]({{site.baseurl}}/user_guide/engagement_tools/landing_pages/creating_pages#step-3-customize-the-page) e [mensagens no app]({{site.baseurl}}/user_guide/channels/in_app_messages/customize/style_settings#blocks). Para isso, destaque o texto que deseja estilizar e selecione **Wrap with span for style**.

### Clique em anúncio para WhatsApp {#ad-click-to-whatsapp}

[Anúncios que direcionam para o WhatsApp]({{site.baseurl}}/whatsapp_use_cases) são uma maneira eficiente de trazer clientes novos e existentes a partir de anúncios da Meta no Facebook, Instagram ou outras plataformas. Use esses anúncios para promover seus produtos e serviços enquanto informa os usuários sobre sua presença no WhatsApp.

## Novas parcerias da Braze {#new-braze-partnerships}

### Shopify Visitory API — eCommerce

A Braze coleta informações de visitantes, como endereços de e-mail e números de telefone, por meio de mensagens no navegador. Essas informações são então enviadas para a Shopify. Esses dados ajudam os comerciantes a reconhecer visitantes em suas lojas e criar uma experiência de compra mais personalizada.

### Okendo — eCommerce

A integração entre a Braze e a [Okendo]({{site.baseurl}}/partners/okendo) funciona com múltiplos produtos na plataforma da Okendo, incluindo Reviews, Loyalty, Referrals, Surveys e Quizzes. A Okendo envia eventos personalizados e atributos de usuário para a Braze, que podem ser usados para personalizar e disparar mensagens.

### Lemnisk — CDP {#lemnisk-customer-data-platform}

A integração entre a Braze e a [Lemnisk]({{site.baseurl}}/partners/lemnisk) permite que marcas e empresas desbloqueiem todo o potencial da Braze ao atuar como uma camada de inteligência orientada por CDP que unifica dados de usuários entre plataformas em tempo real, enviando as informações e comportamentos coletados dos usuários para a Braze em tempo real.

## Atualizações do SDK {#sdk-updates}

As atualizações mais recentes do SDK foram lançadas. As alterações significativas estão listadas na seção de atualizações do SDK; todas as outras atualizações podem ser encontradas nos changelogs correspondentes de cada SDK.

- [Web SDK 6.0.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
    - Removidas a propriedade `Banner.html`, e os métodos `logBannerClick` e `logBannerImpressions`. Em vez disso, use [`insertBanner`](https://js.appboycdn.com/web-sdk/latest/doc/modules/braze.html#insertbanner), que gerencia automaticamente o rastreamento de impressões e cliques.
    - Removido o suporte ao recurso legado do News Feed. Isso inclui a remoção da classe Feed e seus métodos associados.
    - Os campos created e categories que eram usados pelos cartões legados do News Feed foram removidos das subclasses de [`Card`](https://js.appboycdn.com/web-sdk/latest/doc/classes/braze.card.html).
    - O campo linkText também foi removido da subclasse [`ImageOnly`](https://js.appboycdn.com/web-sdk/latest/doc/classes/braze.imageonly.html) de Card e de seu construtor.
    - Definições foram esclarecidas e tipos foram atualizados para indicar que certos métodos do SDK retornam explicitamente undefined quando o SDK não está inicializado, alinhando as tipagens com o comportamento real em tempo de execução. Isso pode introduzir novos erros de TypeScript em projetos que dependiam das tipagens anteriores (incompletas).
    - As imagens de mensagens no app com `cropType` do tipo `CENTER_CROP` (como `FullScreenMessage` por padrão) agora são renderizadas por meio de uma tag `<img>` em vez de `<span>`, para melhorar a acessibilidade. Isso pode afetar personalizações de CSS existentes para a classe `.ab-center-cropped-img` ou seus elementos filhos.
- [Cordova SDK 13.0.0](https://github.com/braze-inc/braze-cordova-sdk/blob/master/CHANGELOG.md#1300)
    - Atualizada a implementação interna do método `enableSdk` no iOS para usar setEnabled: em vez de `_requestEnableSDKOnNextAppRun`, que foi descontinuado no Swift SDK.
        - Chamar esse método não exige mais que o app seja reiniciado para entrar em vigor. O SDK agora será ativado assim que o método for executado.
    - Atualizada a bridge nativa do Android [da Braze Android SDK 36.0.0 para a 37.0.0](https://github.com/braze-inc/braze-android-sdk/compare/v36.0.0...v37.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed).
- [Android SDK 37.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [Swift SDK 12.0.1-12.1.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
