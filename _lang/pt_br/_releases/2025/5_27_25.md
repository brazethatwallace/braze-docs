# Versão de 27 de maio de 2025 {#may-27-2025-release}

## Flexibilidade de dados {#data-flexibility}

### Cópia de Canvas entre espaços de trabalho {#copying-canvases-across-workspaces}

{% multi_lang_include release_type.md release="General availability" %}

Agora você pode copiar Canvas entre espaços de trabalho. Isso permite que você agilize a composição de mensagens começando com uma cópia de um Canvas em um espaço de trabalho diferente. Para saber mais sobre o que é copiado, consulte [Cópia de Campaigns e Canvas entre espaços de trabalho]({{site.baseurl}}/copying_to_workspaces).

### Regras de mensagens para o fluxo de aprovação {#messaging-rules-for-approval-workflow}

{% multi_lang_include release_type.md release="General availability" %}

Use [regras de mensagens]({{site.baseurl}}/user_guide/messaging/governance/approvals/messaging_rules) no seu fluxo de aprovação para limitar o número de usuários contatáveis antes que uma aprovação adicional seja necessária — dessa forma, você pode revisar suas Campaigns e Canvas antes de atingir um público maior.

### Diagramas de relacionamento de entidades para Snowflake e Braze {#entity-relationship-diagrams-for-snowflake-and-braze}

No início deste ano, criamos tabelas de relacionamento de entidades para dados compartilhados entre o Snowflake e a Braze. Neste mês, adicionamos [novos diagramas interativos]({{site.baseurl}}/partners/data_and_analytics/data_warehouses/snowflake/entity_relationships) nos quais você pode navegar, arrastar e ampliar os detalhes de cada tabela, tendo uma ideia melhor de como seus dados interagem com a Braze.

## Liberando a criatividade {#unlocking-creativity}

### Eventos recomendados {#recommended-events}

{% multi_lang_include release_type.md release="Early access" %}

[Os eventos recomendados]({{site.baseurl}}/user_guide/data/activation/events/recommended_events) são mapeados para os casos de uso mais comuns de e-commerce. Ao usar os eventos recomendados, você pode desbloquear modelos pré-construídos de Canvas, dashboards de relatórios que mapeiam o ciclo de vida do cliente e muito mais.

## Canais robustos {#robust-channels}

### Canal de Banners {#banners-channel}

{% multi_lang_include release_type.md release="General availability" %}

Com os [Banners]({{site.baseurl}}/user_guide/channels/banners), você pode criar mensagens personalizadas para seus usuários, ao mesmo tempo em que amplia o alcance de seus outros canais, como e-mail ou notificações por push. Você pode incorporar Banners diretamente no seu app ou website, o que permite interagir com os usuários por meio de uma experiência que parece natural.

### Canal de Rich Communication Services (RCS) {#rich-communication-services-rcs-channel}

{% multi_lang_include release_type.md release="General availability" %}

O [Rich Communication Services (RCS)]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs) aprimora o SMS tradicional, permitindo que as marcas enviem mensagens não apenas informativas, mas também muito mais envolventes. Agora com suporte para Android e iOS, o RCS traz recursos como mídia de alta qualidade, botões interativos e perfis de remetente com marca diretamente para os apps de mensagens pré-instalados dos usuários, eliminando a necessidade de baixar um app separado.

### Página de configurações de push {#push-settings-page}

{% multi_lang_include release_type.md release="General availability" %}

Use a página [**Push Settings**]({{site.baseurl}}/user_guide/administer/global/workspace_settings/push_settings) para definir as principais configurações das suas notificações por push, incluindo o Push Time to Live (TTL) e a prioridade FCM padrão para Campaigns do Android. Essas configurações ajudam a otimizar a entrega e a eficácia das suas notificações por push, garantindo uma melhor experiência para os usuários.

### Códigos de promoção para Campaigns de mensagens no app {#promotion-codes-for-in-app-message-campaigns}

{% multi_lang_include release_type.md release="Early access" %}

Você pode usar [códigos de promoção]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/sources/promotion_codes) em Campaigns de mensagens no app inserindo um [snippet de lista de códigos de promoção]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/sources/promotion_codes/create#create) no corpo da mensagem da sua Campaign de mensagem no app.

### Tratamento de erros de webhook e limite de frequência {#handling-webhook-errors-and-rate-limiting}

[Sobre webhooks]({{site.baseurl}}/user_guide/message_building_by_channel/webhooks/understanding_webhooks#webhook-error-handling-and-rate-limiting) tem uma nova seção que descreve como a Braze lida com erros de webhook e limite de frequência.

### Locais de mensagens no app {#in-app-message-locales}

Depois de [adicionar locais]({{site.baseurl}}/locales_in_messages) ao seu espaço de trabalho, você pode segmentar usuários em diferentes idiomas em uma única mensagem no app.

### Amazon SES como provedor de serviços de e-mail (ESP) {#amazon-ses-as-an-email-sending-provider-esp}

Agora você pode usar o Amazon SES como um ESP, da mesma forma que usaria o SendGrid e o SparkPost. Consulte [SSL na Braze]({{site.baseurl}}/user_guide/message_building_by_channel/email/email_setup/ssl#what-is-a-cdn-and-why-do-i-need-it) e [Universal Links e App Links]({{site.baseurl}}/user_guide/message_building_by_channel/email/universal_links#turning-off-click-tracking-on-a-link-to-link-basis) para conhecer as nuances da configuração de SSL e do rastreamento de cliques link a link.

## Novas parcerias Braze {#new-braze-partnerships}

### Eagle Eye - Fidelidade {#eagle-eye-loyalty}

A integração bidirecional entre a Braze e a [Eagle Eye]({{site.baseurl}}/partners/eagle_eye) permite que você ative dados de fidelidade e promocionais diretamente na Braze, permitindo que os profissionais de marketing personalizem o engajamento do cliente usando dados em tempo real, como saldos de pontos, promoções e atividades de recompensa.

### Eppo - Testes A/B {#eppo-ab-testing}

A integração entre a Braze e o [Eppo]({{site.baseurl}}/partners/eppo) permite que você configure testes A/B na Braze e analise os resultados no Eppo para descobrir insights e vincular o desempenho da mensagem a métricas de negócios de longo prazo, como receita ou retenção.

### Mention Me - Indicações {#mention-me-referrals}

Juntos, o [Mention Me](https://www.mention-me.com/) e a Braze podem ser sua porta de entrada para atrair clientes premium e promover uma fidelidade inabalável à marca. Ao integrar perfeitamente os dados de indicação primários na Braze, você pode oferecer experiências omnicanal altamente personalizadas direcionadas aos fãs da sua marca. Para começar, consulte [Parceiros de tecnologia: Mention Me]({{site.baseurl}}/partners/mention_me).

### Shopify - eCommerce

[Conecte vários domínios de lojas da Shopify]({{site.baseurl}}/shopify_connecting_multiple_stores) a um único espaço de trabalho para ter uma visão holística dos seus clientes em todos os mercados. Crie e lance programas e jornadas de automação em um único espaço de trabalho sem duplicar esforços em lojas regionais.

## Atualizações do SDK {#sdk-updates}

As seguintes atualizações do SDK foram lançadas. As atualizações com mudanças significativas estão listadas na seção de atualizações do SDK; todas as outras atualizações podem ser encontradas verificando os changelogs correspondentes do SDK.

- [Android SDK 36.0.0](https://pub.dev/packages/braze_plugin/changelog)
    - Esta versão reverte o aumento da versão mínima do Android SDK da Braze Android SDK de API 21 para API 25 introduzido na versão 34.0.0. Isso permite que o SDK seja novamente compilado em apps compatíveis a partir da API 21. Observe que, embora estejamos reintroduzindo a capacidade de compilação, não estamos reintroduzindo o suporte formal para < API 25 e não podemos garantir que o SDK funcionará como esperado em dispositivos executando essas versões.
    - Se o seu app for compatível com essas versões, você deve:
        - Validar que sua integração do SDK funciona como esperado em dispositivos físicos (não apenas emuladores) para essas versões de API.
        - Se não for possível validar o comportamento esperado, você deve chamar [disableSDK](https://braze-inc.github.io/braze-android-sdk/kdoc/braze-android-sdk/com.braze/-braze/-companion/disable-sdk.html) ou não inicializar o SDK nessas versões. Caso contrário, poderá causar efeitos colaterais não intencionais ou degradar o desempenho nos dispositivos dos seus usuários finais.
    - Corrigido um problema em que mensagens no app causavam uma leitura na thread principal.
    `BrazeInAppMessageManager.displayInAppMessage` agora é uma função de suspensão do Kotlin.
        - Se você não chamar essa função diretamente, não precisará fazer nenhuma alteração.
    - BOM do AndroidX Compose atualizado para 2025.04.01 para lidar com atualizações nas APIs do Jetpack Compose.
- [React Native SDK 15.0.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
    - Atualiza a ponte nativa do Android da Braze Android SDK 35.0.0 para 36.0.0.
    - Atualiza as ligações da versão nativa do iOS da Braze Swift SDK 11.9.0 para 12.0.0.
    - Atualiza a representação da unidade de PushNotificationEvent.timestamp para milissegundos no iOS.
        - Anteriormente, esse valor era representado em segundos no iOS. Agora ele corresponderá à implementação existente do Android.
- [Web SDK 5.9.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [Flutter SDK 14.0.0 5.9.0](https://pub.dev/packages/braze_plugin/changelog)
    - Esta versão reverte o aumento da versão mínima do Android SDK da Braze Android SDK de API 21 para API 25 introduzido na versão 34.0.0. Isso permite que o SDK seja novamente compilado em apps compatíveis a partir da API 21. No entanto, não estamos reintroduzindo o suporte formal para < API 25. Leia a [entrada do changelog da Braze Android SDK](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#3600).
    - Atualiza a ponte nativa do Android da Braze Android SDK 35.0.0 para 36.0.0.
    - Atualiza a ponte nativa do iOS da Braze Swift SDK 11.9.0 para 12.0.0.
