# Versão de 27 de maio de 2025 {#may-27-2025-release}

## Flexibilidade de dados {#data-flexibility}

### Copiando Canvas entre espaços de trabalho {#copying-canvases-across-workspaces}

{% multi_lang_include release_type.md release="General availability" %}

Agora você pode copiar Canvas entre espaços de trabalho. Isso permite acelerar a composição de mensagens começando com uma cópia de um Canvas em um espaço de trabalho diferente. Para saber mais sobre o que é copiado, consulte [Copiando Campaigns e Canvas entre espaços de trabalho]({{site.baseurl}}/copying_to_workspaces).

### Regras de envio de mensagens para fluxo de aprovação {#messaging-rules-for-approval-workflow}

{% multi_lang_include release_type.md release="General availability" %}

Use [regras de envio de mensagens]({{site.baseurl}}/user_guide/messaging/governance/approvals/messaging_rules) no seu fluxo de aprovação para limitar o número de usuários contatáveis antes que uma aprovação adicional seja necessária. Dessa forma, você pode revisar suas Campaigns e Canvas antes de segmentar um público maior.

### Diagramas de relacionamento de entidades para Snowflake e Braze {#entity-relationship-diagrams-for-snowflake-and-braze}

No início deste ano, criamos tabelas de relacionamento de entidades para dados compartilhados entre Snowflake e Braze. Neste mês, adicionamos [novos diagramas interativos]({{site.baseurl}}/partners/data_and_analytics/data_warehouses/snowflake/entity_relationships) onde você pode navegar, arrastar e ampliar os detalhes de cada tabela, proporcionando uma ideia melhor de como seus dados interagem com a Braze.

## Canais robustos {#robust-channels}

### Canal de Banners {#banners-channel}

{% multi_lang_include release_type.md release="General availability" %}

Com os [Banners]({{site.baseurl}}/user_guide/channels/banners), você pode criar mensagens personalizadas para seus usuários, ampliando o alcance de outros canais, como e-mail ou notificações por push. Você pode incorporar Banners diretamente no seu app ou website, o que permite engajar os usuários por meio de uma experiência que parece natural.

### Canal Rich Communication Services (RCS) {#rich-communication-services-rcs-channel}

{% multi_lang_include release_type.md release="General availability" %}

O [Rich Communication Services (RCS)]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs) aprimora o SMS tradicional, permitindo que as marcas entreguem mensagens que não são apenas informativas, mas também muito mais envolventes. Agora com suporte no Android e no iOS, o RCS traz recursos como mídia de alta qualidade, botões interativos e perfis de remetente com identidade de marca diretamente nos apps de mensagens pré-instalados dos usuários, eliminando a necessidade de baixar um app separado.

### Página de configurações de push {#push-settings-page}

{% multi_lang_include release_type.md release="General availability" %}

Use a [página **Push Settings**]({{site.baseurl}}/user_guide/administer/global/workspace_settings/push_settings) para configurar os parâmetros principais das suas notificações por push, incluindo o Push Time to Live (TTL) e a prioridade FCM padrão para Campaigns no Android. Essas configurações ajudam a otimizar a entrega e a eficácia das suas notificações por push, garantindo uma experiência melhor para os seus usuários.

### Códigos de promoção para campanhas de mensagens no app {#promotion-codes-for-in-app-message-campaigns}

{% multi_lang_include release_type.md release="Early access" %}

Você pode usar [códigos de promoção]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/sources/promotion_codes) em campanhas de mensagens no app inserindo um [snippet de lista de códigos de promoção]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/sources/promotion_codes/create#create) no corpo da mensagem da sua campanha de mensagem no app.

### Tratamento de erros de webhook e limite de frequência {#handling-webhook-errors-and-rate-limiting}

A página [Sobre webhooks]({{site.baseurl}}/user_guide/message_building_by_channel/webhooks/understanding_webhooks#webhook-error-handling-and-rate-limiting) possui uma nova seção que descreve como a Braze lida com erros de webhook e limite de frequência.

### Locais para mensagens no app {#in-app-message-locales}

Após [adicionar locais]({{site.baseurl}}/locales_in_messages) ao seu espaço de trabalho, você pode direcionar usuários em diferentes idiomas dentro de uma única mensagem no app.

### Amazon SES como provedor de serviços de e-mail (ESP) {#amazon-ses-as-an-email-sending-provider-esp}

Agora você pode usar o Amazon SES como ESP, de forma semelhante a como você usaria o SendGrid e o SparkPost. Consulte [SSL na Braze]({{site.baseurl}}/user_guide/channels/email/email_setup/ssl#what-is-a-cdn-and-why-do-i-need-it) e [Universal Links e App Links]({{site.baseurl}}/user_guide/channels/email/customize/universal_links_and_app_links#turning-off-click-tracking-on-a-link-to-link-basis) para detalhes sobre a configuração de SSL e rastreamento de cliques link a link.

## Novas parcerias da Braze {#new-braze-partnerships}

### Eagle Eye - Fidelidade {#eagle-eye-loyalty}

A integração bidirecional entre a Braze e a [Eagle Eye]({{site.baseurl}}/partners/eagle_eye) permite ativar dados de fidelidade e promoções diretamente na Braze, possibilitando que profissionais de marketing personalizem o engajamento do cliente usando dados em tempo real, como saldos de pontos, promoções e atividades de recompensa.

### Eppo - Testes A/B {#eppo-ab-testing}

A integração entre a Braze e a [Eppo]({{site.baseurl}}/partners/eppo) permite configurar testes A/B na Braze e analisar os resultados na Eppo para descobrir insights e vincular o desempenho das mensagens a métricas de negócio de longo prazo, como receita ou retenção.

### Mention Me - Indicações {#mention-me-referrals}

Juntas, a [Mention Me](https://www.mention-me.com/) e a Braze podem ser a porta de entrada para atrair clientes premium e cultivar uma fidelidade inabalável à marca. Ao integrar dados de indicação primários na Braze de forma transparente, você pode oferecer experiências omnicanal altamente personalizadas direcionadas aos fãs da sua marca. Para começar, consulte [Parceiros de tecnologia: Mention Me]({{site.baseurl}}/partners/mention_me).

### Shopify - eCommerce

[Conecte vários domínios de lojas Shopify]({{site.baseurl}}/shopify_connecting_multiple_stores) a um único espaço de trabalho para ter uma visão holística dos seus clientes em todos os mercados. Crie e lance programas de automação e jornadas em um único espaço de trabalho sem duplicar esforços entre lojas regionais.

## Atualizações do SDK {#sdk-updates}

As atualizações mais recentes do SDK foram lançadas. Alterações incompatíveis estão listadas na seção de atualizações do SDK; todas as outras atualizações podem ser encontradas nos changelogs correspondentes do SDK.

- [Android SDK 36.0.0](https://pub.dev/packages/braze_plugin/changelog)
    - Esta versão reverte o aumento da versão mínima do Android SDK do Braze Android SDK da API 21 para a API 25, introduzido na versão 34.0.0. Isso permite que o SDK seja novamente compilado em apps com suporte a partir da API 21. Embora estejamos reintroduzindo a capacidade de compilação, não estamos reintroduzindo o suporte formal para versões anteriores à API 25, e não podemos garantir que o SDK funcionará conforme esperado em dispositivos com essas versões.
    - Se o seu app oferece suporte a essas versões, você deve:
        - Validar que a integração do SDK funciona conforme esperado em dispositivos físicos (não apenas emuladores) para essas versões de API.
        - Se não for possível validar o comportamento esperado, você deve chamar [disableSDK](https://braze-inc.github.io/braze-android-sdk/kdoc/braze-android-sdk/com.braze/-braze/-companion/disable-sdk.html) ou não inicializar o SDK nessas versões. Caso contrário, você pode causar efeitos colaterais indesejados ou desempenho degradado nos dispositivos dos seus usuários finais.
    - Corrigido um problema em que mensagens no app causavam uma leitura na thread principal.
    `BrazeInAppMessageManager.displayInAppMessage` agora é uma função Kotlin suspend.
        - Se você não chama essa função diretamente, não precisa fazer nenhuma alteração.
    - AndroidX Compose BOM atualizado para 2025.04.01 para lidar com atualizações nas APIs do Jetpack Compose.
- [React Native SDK 15.0.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
    - Atualiza a bridge nativa do Android do Braze Android SDK 35.0.0 para 36.0.0.
    - Atualiza os bindings da versão nativa do iOS do Braze Swift SDK 11.9.0 para 12.0.0.
    - Atualiza a representação de unidade de PushNotificationEvent.timestamp para milissegundos no iOS.
        - Anteriormente, esse valor era representado em segundos no iOS. Agora ele corresponderá à implementação existente no Android.
- [Web SDK 5.9.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [Flutter SDK 14.0.0 5.9.0](https://pub.dev/packages/braze_plugin/changelog)
    - Esta versão reverte o aumento da versão mínima do Android SDK do Braze Android SDK da API 21 para a API 25, introduzido na versão 34.0.0. Isso permite que o SDK seja novamente compilado em apps com suporte a partir da API 21. No entanto, não estamos reintroduzindo o suporte formal para versões anteriores à API 25. Leia a [entrada do changelog do Braze Android SDK](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#3600).
    - Atualiza a bridge nativa do Android do Braze Android SDK 35.0.0 para 36.0.0.
    - Atualiza a bridge nativa do iOS do Braze Swift SDK 11.9.0 para 12.0.0.
