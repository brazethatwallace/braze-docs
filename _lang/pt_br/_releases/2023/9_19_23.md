# Versão de 19 de setembro de 2023 {#september-19-2023-release}

## BigQuery para ingestão de dados na nuvem {#bigquery-for-cloud-data-ingestion}

Agora você pode criar integrações de ingestão de dados na nuvem com o [BigQuery](https://cloud.google.com/bigquery), um data warehouse empresarial sem servidor. Para saber mais, consulte [Integrações de ingestão de dados na nuvem]({{site.baseurl}}/user_guide/data_and_analytics/cloud_ingestion/integrations/?tab=bigquery).

## Braze Data Transformation

A [Braze Data Transformation]({{site.baseurl}}/user_guide/data/unification/data_transformation) permite criar e gerenciar integrações de webhook para automatizar o fluxo de dados de plataformas externas para perfis de usuário da Braze. Esses dados de usuário recém-integrados podem então potencializar casos de uso de marketing ainda mais sofisticados.

## Comentários no Canvas {#commenting-in-canvas}

[Comentários em Canvas]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas/canvas_comments) podem ser um ótimo espaço colaborativo para sua equipe de marketing identificar, discutir e revisar os detalhes mais específicos dos seus Canvas. Conforme você desenvolve um Canvas, é possível criar e gerenciar comentários para identificar as áreas que podem precisar de feedback adicional dos seus colegas.

## Central de Entregabilidade {#deliverability-center}

A [Central de Entregabilidade]({{site.baseurl}}/user_guide/analytics/dashboards/deliverability_center) fornece mais insight sobre o desempenho do seu e-mail, oferecendo suporte ao uso do Gmail Postmaster Tools para rastrear dados sobre e-mails enviados e coletar dados sobre o seu domínio de envio.

A entregabilidade de e-mail é a base do sucesso de uma campanha. Usando a Central de Entregabilidade no dashboard da Braze, você pode visualizar seus domínios por reputação de IP ou erros de entrega para descobrir e solucionar possíveis problemas com a entregabilidade de e-mail.

## Editor de arrastar e soltar para mensagens no app {#drag-and-drop-editor-for-in-app-messages}

Esses recursos adicionais foram incluídos no [editor de arrastar e soltar para mensagens no app]({{site.baseurl}}/user_guide/channels/in_app_messages/drag_and_drop):

- Links de texto que não dispensam a mensagem
- Ação de botão para solicitar push primer
- Bloco de editor de código personalizado

Para aproveitar todos os recursos disponíveis no editor de arrastar e soltar, atualize seus SDKs para as versões recomendadas do SDK.

### Salvar modelos personalizados (acesso antecipado) {#save-custom-templates-early-access}

No editor de arrastar e soltar para mensagens no app, os participantes do acesso antecipado podem criar e salvar modelos personalizados de mensagens no app usando o botão **Salvar como modelo**, disponível após sair do editor. Antes de salvá-lo como modelo, primeiro é necessário lançar a campanha OU salvá-la como rascunho.

Você também pode criar e salvar modelos de mensagens no app acessando **Modelos** > **Modelos de mensagens no app**.

## Desativando o modo escuro para mensagens no app {#disabling-dark-mode-for-in-app-messages}

Os desenvolvedores podem impedir que as mensagens no app adotem o estilo do modo escuro quando o dispositivo do usuário está com o modo escuro ativado. Para saber como implementar isso, consulte a documentação a seguir por plataforma:

- [Swift]({{site.baseurl}}/developer_guide/platform_integration_guides/swift/in-app_messaging/customization/setting_delegates#disabling-dark-mode)
- [Objective-C]({{site.baseurl}}/developer_guide/platform_integration_guides/ios/in-app_messaging/customization/handling_in_app_display#disabling-dark-mode)

## Novos campos para arquivamento de mensagens {#new-fields-for-message-archiving}

O [arquivamento de mensagens]({{site.baseurl}}/user_guide/data/distribution/export_braze_data/message_archiving) permite salvar uma cópia das mensagens enviadas aos usuários para fins de arquivamento ou conformidade no seu bucket S3. Os seguintes campos foram adicionados à carga útil JSON entregue ao seu bucket S3 cada vez que uma mensagem é enviada:

- `user_id`
- `campaign_name`
- `canvas_name`
- `canvas_step_name`

## Novas tags de personalização Liquid {#new-liquid-personalization-tags}

Para mensagens no app, você pode usar os seguintes atributos de app no Liquid. Os valores são baseados na chave de API SDK que seus apps usam para solicitar o envio de mensagens:

- {% raw %}`{{app.${api_id}}}`{% endraw %}
- {% raw %}`{{app.${name}}}`{% endraw %}

Para saber mais, consulte [Tags de personalização compatíveis]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/supported_personalization_tags#targeted-app-information).

## Novas parcerias da Braze {#new-braze-partnerships}

### Antavo Loyalty Cloud – Extensões de canal {#antavo-loyalty-cloud-channel-extensions}

A integração entre [Antavo]({{site.baseurl}}/partners/data_and_analytics/loyalty/antavo) e Braze permite que você use dados relacionados a programas de fidelidade para criar campanhas personalizadas que aprimoram a experiência do cliente. O Antavo oferece suporte à sincronização de dados de fidelidade entre as duas plataformas — essa sincronização é unidirecional, apenas do Antavo para a Braze.

### Ketch – CDP {#ketch-customer-data-platform}

A integração entre a Braze e o [Ketch]({{site.baseurl}}/partners/data_and_analytics/data_privacy/ketch) permite que você controle as preferências de comunicação dos clientes dentro da central de preferências do Ketch e propague automaticamente essas alterações para a Braze.

### Redpoint – CDP {#redpoint-customer-data-platform}

O Redpoint é uma plataforma de tecnologia que oferece aos profissionais de marketing uma plataforma de orquestração de campanhas totalmente integrada. A integração entre a Braze e o [Redpoint]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/redpoint) permite que você crie Segments na Braze com base nos dados do seu CDP Redpoint.

### Simon Data – CDP {#simon-data-customer-data-platform}

Use a integração entre a Braze e o [Simon Data]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/simonai) para criar e sincronizar públicos sofisticados com a Braze para orquestração em tempo real e sem código. Com essa integração, você pode alavancar o melhor dos recursos de priorização de campanhas e correspondência de identidade do Simon, suporte a agregações complexas e muito mais para elevar o desempenho das suas Campaigns na Braze.

## Atualizações do SDK {#sdk-updates}

As atualizações mais recentes do SDK foram lançadas. As atualizações com mudanças significativas estão listadas na seção de atualizações do SDK; todas as outras atualizações podem ser encontradas nos changelogs correspondentes de cada SDK.

- [Swift SDK 6.6.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#661)
- [Web SDK 4.9.0](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md#490)
- [Android SDK 28.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2800)
    - Versão mínima do SDK atualizada para 21 (Lollipop).
    - As funções de Feature Flags foram modificadas.
    - `Braze.getFeatureFlag(id)` agora retornará null se o Feature Flag não existir.
    - `Braze.subscribeToFeatureFlagsUpdates()` só executará o retorno de chamada quando uma solicitação de atualização for concluída e, inicialmente, se dados em cache existirem previamente. Também será chamado com feature flags em cache em caso de falhas de atualização.
        - Se você quiser o valor em cache imediatamente na inicialização do app, use `Braze.getFeatureFlag(id)`.
    - Refatoração de `DefaultInAppMessageViewWrapper.createButtonClickListener()` para `DefaultInAppMessageViewWrapper.createButtonClickListeners()`.
- [React Native SDK 7.0.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md#700)
    - Atualiza a bridge nativa do Android de [Braze Android SDK 26.3.2 para 27.0.1](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2701).
- [Cordova SDK 7.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2800)
    - Atualiza a bridge nativa do Android de [Braze Android SDK 26.3.2 para 27.0.1](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#2701).
- [Roku SDK 2.0.0](https://github.com/braze-inc/braze-roku-sdk/blob/main/CHANGELOG.md#200)
    - `getFeatureFlag` retornará invalid quando o flag não existir.
    - `BrazeTask` agora observa `BrazeFeatureFlagsUpdated` para saber quando as atualizações de feature flags são bem-sucedidas ou falham. Os valores dos dados podem nem sempre ser diferentes.
