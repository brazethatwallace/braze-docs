# Lançamento em 12 de dezembro de 2023 {#december-12-2023-release}

## Atualizações na integração com push para Android {#updates-to-android-push-integration}

Em 20 de junho de 2023, o Google descontinuou a API Cloud Messaging para o envio de notificações por push para apps Android. A [integração push padrão do Android]({{site.baseurl}}/developer_guide/platform_integration_guides/android/push_notifications/android/integration/standard_integration/) agora mostra como configurar a API Firebase Cloud Messaging do Google.

Para saber mais sobre a descontinuação da API Cloud Messaging do Google, consulte as [Perguntas frequentes do Firebase](https://firebase.google.com/support/faq#fcm-23-deprecation).

## Canais robustos {#robust-channels}

### Mensagens de resposta do WhatsApp {#whatsapp-response-messaging}

{% multi_lang_include release_type.md release="General availability" %}

Ao [criar uma mensagem do WhatsApp]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/create/#response-messages) em uma Campaign ou Canvas, você pode criar mensagens de resposta para responder às mensagens do WhatsApp do usuário dentro de um período de 24 horas. As mensagens de resposta podem ser particularmente úteis em Canvas que incentivam interações entre sua marca e seus usuários, como campanhas de opt-in.

### Limite de frequência do WhatsApp {#whatsapp-frequency-capping}

{% multi_lang_include release_type.md release="General availability" %}

Agora você pode configurar [regras de limite de frequência]({{site.baseurl}}/user_guide/engagement_tools/campaigns/building_campaigns/rate-limiting/#frequency-capping) para o WhatsApp. O limite de frequência é aplicado no nível de envio da Campaign ou do componente do Canvas e pode ser configurado para cada espaço de trabalho em **Configurações** > **Regras do limite de frequência**.

## Flexibilidade de dados {#data-flexibility}

### Dashboard de conversões {#conversions-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

O [dashboard de conversões]({{site.baseurl}}/user_guide/analytics/dashboards/conversions/) permite que você analise as conversões em Campaigns, Canvas e canais, usando diferentes métodos de atribuição. Ao medir suas conversões, você pode especificar o período de tempo, o evento de conversão e a janela de conversão.

### Relatórios de Email Insights {#email-insights-reports}

{% multi_lang_include release_type.md release="General availability" %}

Há uma nova guia, Email Insights, localizada no [dashboard de Performance de e-mail]({{site.baseurl}}/user_guide/data_and_analytics/analytics/email_performance_dashboard/#email-insights-dashboard), que contém dois novos relatórios:

- **Engagement by Mailbox Providers:** Mostra o número de cliques e aberturas por provedor de caixa de e-mail. Você pode selecionar um provedor de caixa de e-mail e detalhar domínios de recebimento específicos.
- **Engagement by Day of Week:** Mostra quando os usuários estão interagindo com seus e-mails.

### Atualização do gráfico de séries temporais do grupo de inscrições {#update-to-subscription-group-timeseries-graph}

{% multi_lang_include release_type.md release="General availability" %}

O gráfico **Subscription Group Timeseries** que aparece na página **Grupos de inscrições** agora mostra a contagem de inscrições por usuário em vez de por e-mail ou número de telefone. Isso se alinha melhor com a forma como a Braze calcula as estatísticas em outras áreas do dashboard.

## Automação de IA e ML {#ai-ml-automation}

### Recomendação de item de IA {#ai-item-recommendations}

{% multi_lang_include release_type.md release="General availability" %}

A [Recomendação de item de IA]({{site.baseurl}}/ai_item_recommendations/) é um mecanismo de recomendação de produto baseado em deep learning que usa o comportamento coletivo de compra dos usuários para recomendar itens. Você pode usar a Recomendação de item de IA para calcular os produtos mais populares ou criar recomendações de IA personalizadas para um catálogo específico. Após criar sua recomendação, você pode usar a personalização para inserir esses produtos nas suas mensagens.

## Novas parcerias da Braze {#new-braze-partnerships}

### Facebook Lead Ads via Zapier — Captura de leads {#facebook-lead-ads-via-zapier-leads-capture}

Com a [integração do Facebook Lead Ads via Zapier]({{site.baseurl}}/partners/data_and_analytics/leads_capture/facebook_via_zapier/), você pode importar seus leads do Facebook para a Braze e rastrear um evento personalizado quando os leads forem capturados.

### SmarterSends — Modelos de mensagens {#smartersends-message-templates}

A parceria entre a Braze e a [SmarterSends]({{site.baseurl}}/partners/message_orchestration/templates/smartersends/) permite combinar o poder da Braze com o conteúdo hiperlocalizado de propriedade dos seus usuários distribuídos para elevar suas campanhas de marketing.

### Recurly — Pagamentos {#recurly-payments}

A integração entre a [Recurly]({{site.baseurl}}/partners/ecommerce/ordering_payments_subscription/recurly/) e a Braze simplifica o processo de compartilhamento de dados de inscrição com a Braze, possibilitando a comunicação direcionada com os clientes.

## Atualizações do SDK {#sdk-updates}

As seguintes atualizações do SDK foram lançadas. As atualizações com breaking changes estão listadas abaixo; todas as outras atualizações podem ser encontradas verificando os changelogs correspondentes do SDK.

- [Flutter SDK 8.0.0-8.1.0](https://pub.dev/packages/braze_plugin/changelog)
  - Atualiza a ponte nativa do Android do SDK da Braze para Android 27.0.1 para o 29.0.1.
  - Atualiza a ponte nativa do iOS do SDK Swift da Braze 6.6.1 para o 7.2.0.
  - Modifica o comportamento dos métodos de Feature Flags.
    - `BrazePlugin.getFeatureFlagByID(String id)` agora retornará `null` se a feature flag não existir.
    - `BrazePlugin.subscribeToFeatureFlags(void Function(List<BrazeFeatureFlag>) onEvent))` só será disparado nas seguintes situações:
      - Quando uma solicitação de atualização é concluída com sucesso ou falha.
      - Na inscrição inicial, se houver dados previamente armazenados em cache da sessão atual.
  - A versão mínima aceita do Android SDK é a 21.
- [React Native SDK 8.2.0](https://github.com/braze-inc/braze-react-native-sdk/blob/8.2.0/CHANGELOG.md)
- [Swift SDK 7.3.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
- [Plugin Braze Segment Swift 2.2.0](https://github.com/braze-inc/braze-segment-swift/blob/main/CHANGELOG.md)
- [Plugin Braze Expo 1.2.0](https://github.com/braze-inc/braze-react-native-sdk/blob/8.2.0/CHANGELOG.md)
