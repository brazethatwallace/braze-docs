# Lançamento em 12 de dezembro de 2023 {#december-12-2023-release}

## Atualizações na integração de push para Android {#updates-to-android-push-integration}

Em 20 de junho de 2023, o Google descontinuou sua API or interface de programação do aplicativo (API) Cloud Messaging para envio de notificações por push para apps Android. A [integração padrão de push para Android]({{site.baseurl}}/developer_guide/push_notifications?sdktab=android) agora mostra como configurar a API or interface de programação do aplicativo (API) Firebase Cloud Messaging do Google.

Para saber mais sobre a descontinuação da API or interface de programação do aplicativo (API) Cloud Messaging do Google, consulte as [Perguntas frequentes do Firebase](https://firebase.google.com/support/faq#fcm-23-deprecation).

## Canais robustos {#robust-channels}

### Mensagens de resposta do WhatsApp {#whatsapp-response-messaging}

{% multi_lang_include release_type.md release="General availability" %}

Ao [criar uma mensagem de WhatsApp]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/create#response-messages) em uma campanha ou Canvas, você pode criar mensagens de resposta para responder às mensagens de WhatsApp dos usuários dentro de uma janela de 24 horas. As mensagens de resposta podem ser especialmente úteis em Canvas que incentivam interações entre sua marca e seus usuários, como campanhas de aceitação.

### Limite de frequência do WhatsApp {#whatsapp-frequency-capping}

{% multi_lang_include release_type.md release="General availability" %}

Agora você pode configurar [regras de limite de frequência]({{site.baseurl}}/user_guide/engagement_tools/campaigns/building_campaigns/rate-limiting#frequency-capping) para o WhatsApp. O limite de frequência é aplicado no nível de envio do componente de campanha ou Canvas e pode ser configurado para cada espaço de trabalho em **Configurações** > **Regras de limite de frequência**.

## Flexibilidade de dados {#data-flexibility}

### Dashboard de conversões {#conversions-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

O [dashboard de conversões]({{site.baseurl}}/user_guide/analytics/dashboards/conversions) permite que você analise conversões em Campaigns, Canvas e canais, usando diferentes métodos de atribuição. Ao medir suas conversões, você pode especificar o período, o evento de conversão e a janela de conversão.

### Relatórios de Email Insights {#email-insights-reports}

{% multi_lang_include release_type.md release="General availability" %}

Há uma nova guia, Email Insights, localizada no [dashboard de desempenho de e-mail]({{site.baseurl}}/user_guide/data_and_analytics/analytics/email_performance_dashboard#email-insights-dashboard), que contém dois novos relatórios:

- **Engajamento por provedores de caixa de entrada:** mostra o número de cliques e aberturas por provedor de caixa de entrada. Você pode selecionar um provedor de caixa de entrada e detalhar domínios de recebimento específicos.
- **Engajamento por dia da semana:** mostra quando os usuários estão interagindo com seus e-mails.

### Atualização no gráfico de série temporal de grupos de inscrições {#update-to-subscription-group-timeseries-graph}

{% multi_lang_include release_type.md release="General availability" %}

O gráfico **Série temporal de grupos de inscrições** que aparece na página **Grupos de inscrições** agora mostra a contagem de inscrições por usuário, em vez de por e-mail ou número de telefone. Isso está mais alinhado com a forma como a Braze calcula estatísticas em outras áreas do dashboard.

## Automação de IA e ML {#ai-ml-automation}

### Recomendações de itens com IA {#ai-item-recommendations}

{% multi_lang_include release_type.md release="General availability" %}

[Recomendações de itens com IA]({{site.baseurl}}/user_guide/brazeai/item_recommendations/creating_recommendations/ai) é um mecanismo de recomendação de produtos baseado em deep learning que usa o comportamento coletivo de compras dos usuários para recomendar itens. Você pode usar as recomendações de itens com IA para calcular os produtos mais populares ou criar recomendações de IA personalizadas para um catálogo específico. Depois de criar sua recomendação, você pode usar a personalização para inserir esses produtos nas suas mensagens.

## Novas parcerias da Braze {#new-braze-partnerships}

### Facebook Lead Ads via Zapier – Captura de leads {#facebook-lead-ads-via-zapier-leads-capture}

Com a [integração do Facebook Lead Ads via Zapier]({{site.baseurl}}/partners/data_and_analytics/leads_capture/facebook_via_zapier), você pode importar seus leads do Facebook para a Braze e rastrear um evento personalizado quando os leads são capturados.

### SmarterSends – Modelos de mensagens {#smartersends-message-templates}

A parceria entre a Braze e a [SmarterSends]({{site.baseurl}}/partners/message_orchestration/templates/smartersends) permite combinar o poder da Braze com o conteúdo hiperlocalizado gerenciado pelos seus usuários distribuídos para elevar suas campanhas de marketing.

### Recurly – Pagamentos {#recurly-payments}

A integração entre a [Recurly]({{site.baseurl}}/partners/ecommerce/ordering_payments_subscription/recurly) e a Braze simplifica o processo de compartilhamento de dados de inscrição com a Braze, possibilitando uma comunicação direcionada com os clientes.

## Atualizações do SDK or kit de desenvolvimento de software {#sdk-updates}

As atualizações mais recentes do SDK or kit de desenvolvimento de software foram lançadas. Alterações importantes estão listadas na seção de atualizações do SDK or kit de desenvolvimento de software; todas as outras atualizações podem ser encontradas nos changelogs correspondentes de cada SDK or kit de desenvolvimento de software.

- [Flutter SDK or kit de desenvolvimento de software 8.0.0-8.1.0](https://pub.dev/packages/braze_plugin/changelog)
  - Atualiza a ponte nativa do Android do Braze Android SDK or kit de desenvolvimento de software 27.0.1 para 29.0.1.
  - Atualiza a ponte nativa do iOS do Braze Swift SDK or kit de desenvolvimento de software 6.6.1 para 7.2.0.
  - Modifica o comportamento dos métodos de Feature Flags.
    - `BrazePlugin.getFeatureFlagByID(String id)` agora retornará `null` se a Feature Flag não existir.
    - `BrazePlugin.subscribeToFeatureFlags(void Function(List<BrazeFeatureFlag>) onEvent))` será disparado apenas nas seguintes situações:
      - Quando uma solicitação de atualização for concluída com sucesso ou falha.
      - Na inscrição inicial, se houver dados previamente armazenados em cache da sessão atual.
  - A versão mínima suportada do Android SDK or kit de desenvolvimento de software é 21.
