# Lançamento em 2 de maio de 2023 {#may-2-2023-release}

## UI/UX da Braze redesenhada {#redesigned-braze-uiux}

_Disponível para todos em 16 de maio de 2023_

Economize tempo e encontre exatamente o que você precisa com a UI/UX e a arquitetura de informações recém-redesenhadas. Navegue rapidamente pela plataforma, conclua tarefas e descubra novos recursos com facilidade. Para facilitar essa transição para você e sua equipe, confira nosso [guia de navegação]({{site.baseurl}}/user_guide/administer/personal/the_braze_dashboard/) dedicado para saber o que mudou e o que você pode esperar a seguir.

## Criador de consultas {#query-builder}

Com o [Criador de consultas]({{site.baseurl}}/user_guide/analytics/reports/query_builder/), você pode gerar relatórios usando dados da Braze no Snowflake. O Criador de consultas vem com modelos de consultas de SQL pré-construídos para você começar, ou você pode escrever suas próprias consultas de SQL personalizadas para desbloquear ainda mais insights.

## Histórico de versões do Canvas {#canvas-version-history}

O [histórico de versões]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/canvas_version_history/) permite visualizar e acessar a análise de dados do Canvas e as jornadas do usuário para qualquer versão anterior do seu Canvas. Consultar o histórico de versões do Canvas pode ser especialmente útil para manter um registro da evolução de um Canvas.

## Atualização incremental para SQL Segments {#incremental-refresh-for-sql-segments}

Agora você pode criar [extensões de segmento SQL]({{site.baseurl}}/user_guide/audience/segments/segment_extension/sql_segments/) que usam atualização incremental, que atualiza apenas os dados dos últimos dois dias. Isso é mais econômico e usa menos créditos de SQL Segment cada vez que a associação ao segmento é atualizada. Ao contrário das extensões de atualização completa, você pode definir extensões de atualização incremental para regenerar automaticamente a associação diariamente.

## Centro de entregabilidade para e-mail {#deliverability-center-for-email}

O [Centro de entregabilidade]({{site.baseurl}}/user_guide/data_and_analytics/analytics/deliverability_center/#deliverability-center) fornece mais insights sobre a performance do seu e-mail, apoiando o uso das Ferramentas do Postmaster do Gmail para rastrear dados sobre e-mails enviados e coletar dados sobre seu domínio de envio.

{% alert important %}
O Centro de entregabilidade está atualmente em acesso antecipado. Entre em contato com seu gerente de sucesso do cliente da Braze se tiver interesse em participar do acesso antecipado.
{% endalert %}

## Atualização para limitações do catálogo {#update-for-catalog-limitations}

A partir de 1º de maio de 2023, houve atualizações para os [limites de armazenamento de catálogos]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog/#limits). Para solicitar um upgrade para o armazenamento de catálogos, entre em contato com seu gerente de conta da Braze.

## Novo artigo sobre endpoints de API e SDK {#new-api-and-sdk-endpoints-article}

A Braze gerencia várias instâncias diferentes do nosso dashboard, SDK e endpoints REST, que chamamos de "clusters". Confira [Endpoints de API e SDK]({{site.baseurl}}/user_guide/administer/personal/sdk_endpoints/) para obter uma lista de URLs de dashboard, endpoints de API e endpoints de SDK para instâncias disponíveis da Braze.

## Descontinuação do SDK do iOS - Swift {#ios-sdk-deprecation-swift}

O SDK legado da Braze para iOS está sendo descontinuado em favor do novo SDK Swift. Ele traz desempenho aprimorado, novos recursos e muitas melhorias, incluindo [uma nova documentação]({{site.baseurl}}/developer_guide/platform_integration_guides/swift/initial_sdk_setup/overview/)!

Está pensando em fazer upgrade? Consulte nosso [guia de migração](https://braze-inc.github.io/braze-swift-sdk/documentation/braze/appboy-migration-guide/) para obter detalhes.
