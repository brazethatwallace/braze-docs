# Lançamento em 2 de maio de 2023 {#may-2-2023-release}

## UI/UX da Braze redesenhado {#redesigned-braze-uiux}

_Disponível para todos a partir de 16 de maio de 2023_

Economize tempo e encontre exatamente o que precisa com a UI/UX e a arquitetura de informações recém-redesenhadas. Navegue rapidamente pela plataforma, conclua tarefas e descubra novos recursos com facilidade. Para facilitar essa transição para você e sua equipe, confira nosso [guia de navegação]({{site.baseurl}}/user_guide/administer/personal/the_braze_dashboard) dedicado para saber o que mudou e o que esperar a seguir.

## Query builder

Com o [query builder]({{site.baseurl}}/user_guide/analytics/reports/query_builder), você pode gerar relatórios usando dados da Braze no Snowflake. O query builder vem com modelos de consultas SQL pré-criados para você começar, ou você pode escrever suas próprias consultas SQL personalizadas para obter ainda mais insights.

## Histórico de versões do Canvas {#canvas-version-history}

O [Histórico de versões]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/canvas_version_history) permite que você visualize e acesse a análise de dados do Canvas e as jornadas de usuários de qualquer versão anterior do seu Canvas. Consultar o histórico de versões do Canvas pode ser especialmente útil para manter um registro da evolução de um Canvas.

## Atualização incremental para SQL Segments {#incremental-refresh-for-sql-segments}

Agora você pode criar [extensões de segmento SQL]({{site.baseurl}}/user_guide/audience/segments/segment_extension/sql_segments) que usam atualização incremental, que atualiza apenas os últimos 2 dias de dados. Isso é mais eficiente em termos de custo e consome menos créditos de SQL Segment a cada vez que a associação do segmento é atualizada. Diferentemente das extensões com atualização completa, você pode configurar extensões com atualização incremental para regenerar automaticamente a associação diariamente.

## Central de Entregabilidade para e-mail {#deliverability-center-for-email}

A [Central de Entregabilidade]({{site.baseurl}}/user_guide/data_and_analytics/analytics/deliverability_center#deliverability-center) oferece mais insights sobre o desempenho do seu e-mail, permitindo o uso do Gmail Postmaster Tools para rastrear dados sobre e-mails enviados e coletar dados sobre o seu domínio de envio.

{% alert important %}
A Central de Entregabilidade está atualmente em acesso antecipado. Entre em contato com o seu gerente de sucesso do cliente da Braze se tiver interesse em participar do acesso antecipado.
{% endalert %}

## Descontinuação do SDK para iOS - Swift {#ios-sdk-deprecation-swift}

O SDK legado da Braze para iOS está sendo descontinuado em favor do novo SDK Swift. Isso traz melhorias de performance, novos recursos e diversas melhorias—incluindo [nova documentação]({{site.baseurl}}/developer_guide/sdk_integration?sdktab=swift)!

Quer fazer upgrade? Confira nosso [guia de migração](https://braze-inc.github.io/braze-swift-sdk/documentation/braze/appboy-migration-guide/) para mais detalhes.
