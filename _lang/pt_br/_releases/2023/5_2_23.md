# Lançamento em 2 de maio de 2023 {#may-2-2023-release}

## UI/UX da Braze redesenhado {#redesigned-braze-uiux}

_Disponível para todos a partir de 16 de maio de 2023_

Economize tempo e encontre exatamente o que você precisa com a UI/UX e a arquitetura de informação recém-redesenhadas. Navegue rapidamente pela plataforma, conclua tarefas e descubra novos recursos com facilidade. Para facilitar essa transição para você e sua equipe, confira nosso [guia de navegação]({{site.baseurl}}/user_guide/administer/personal/the_braze_dashboard) dedicado para saber o que mudou e o que esperar a seguir.

## Query builder

Com o [query builder]({{site.baseurl}}/user_guide/analytics/reports/query_builder), você pode gerar relatórios usando dados da Braze no Snowflake. O query builder vem com modelos de consultas SQL pré-criados para você começar, ou você pode escrever suas próprias consultas SQL personalizadas para obter ainda mais insights.

## Histórico de versões do Canvas {#canvas-version-history}

O [Histórico de versões]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/canvas_version_history) permite que você visualize e acesse a análise de dados do Canvas e as jornadas de usuários de qualquer versão anterior do seu Canvas. Consultar o histórico de versões do Canvas pode ser especialmente útil para manter um registro da evolução de um Canvas.

## Atualização incremental para SQL Segments {#incremental-refresh-for-sql-segments}

Agora é possível criar [extensões de Segment or segmento or segmento SQL]({{site.baseurl}}/user_guide/audience/segments/segment_extension/sql_segments) que usam atualização incremental, que atualiza apenas os dados dos últimos 2 dias. Isso é mais econômico e consome menos créditos de SQL Segment or segmento a cada vez que a associação do Segment or segmento or segmento é atualizada. Diferente das extensões com atualização completa, você pode configurar as extensões de atualização incremental para regenerar automaticamente a associação diariamente.

## Deliverability Center para e-mail {#deliverability-center-for-email}

O [Deliverability Center]({{site.baseurl}}/user_guide/analytics/dashboards/deliverability_center) oferece mais insights sobre o desempenho do seu e-mail ao integrar o uso do Gmail Postmaster Tools para rastrear dados sobre e-mails enviados e coletar dados sobre o seu domínio de envio.

{% alert important %}
O Deliverability Center está atualmente em acesso antecipado. Entre em contato com o seu gerente de sucesso do cliente da Braze se tiver interesse em participar do acesso antecipado.
{% endalert %}

## Descontinuação do SDK or kit de desenvolvimento de software para iOS - Swift {#ios-sdk-deprecation-swift}

O SDK or kit de desenvolvimento de software legado para iOS da Braze está sendo descontinuado em favor do novo SDK or kit de desenvolvimento de software Swift. Isso traz melhor performance, novos recursos e muitas melhorias, incluindo uma [nova documentação]({{site.baseurl}}/developer_guide/sdk_integration?sdktab=swift)!

Quer fazer upgrade? Confira nosso [guia de migração](https://braze-inc.github.io/braze-swift-sdk/documentation/braze/appboy-migration-guide/) para mais detalhes.
