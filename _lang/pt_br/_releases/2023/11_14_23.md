# Lançamento em 14 de novembro de 2023 {#november-14-2023-release}

## Começando com a Braze {#getting-started-with-braze}

Novidades empolgantes! Estamos apresentando duas seções de Primeiros Passos feitas especialmente para nossos [profissionais de marketing]({{site.baseurl}}/user_guide/get_started) e [desenvolvedores]({{site.baseurl}}/developer_guide/getting_started) da Braze. Essas seções foram criadas para ajudar você a começar com tudo na Braze, oferecendo todas as ferramentas e orientações necessárias. Mergulhe e comece a explorar.

## Nova instância do dashboard da Braze {#new-braze-dashboard-instance}

A Braze gerencia diversas instâncias diferentes para nosso dashboard e endpoints REST. Adicionamos uma nova instância de dashboard `US-07`. Para saber mais, consulte [Visão geral da API]({{site.baseurl}}/api/basics).

## Canais robustos {#robust-channels}

### Modelos personalizados de arrastar e soltar para mensagens no app {#custom-drag-and-drop-templates-for-in-app-messages}

{% multi_lang_include release_type.md release="General availability" %}

Agora você pode usar [modelos personalizados de arrastar e soltar para mensagens no app]({{site.baseurl}}/user_guide/channels/in_app_messages/drag_and_drop) para começar a criar sua mensagem no app no editor de arrastar e soltar.

### Dupla aceitação de SMS {#sms-double-opt-in}

{% multi_lang_include release_type.md release="General availability" %}

A [dupla aceitação de SMS]({{site.baseurl}}/user_guide/channels/sms_mms_and_rcs/message_features_and_optimization/keyword_processing/double_opt_in) permite que você exija que os usuários confirmem explicitamente a intenção de aceitação antes de poderem receber mensagens SMS. Isso ajuda a direcionar seu foco para usuários que provavelmente estão ou já estão engajados com SMS.

### Taxa de abertura real estimada para relatórios de e-mail {#estimated-real-open-rate-for-email-reporting}

{% multi_lang_include release_type.md release="General availability" %}

A [taxa de abertura real estimada]({{site.baseurl}}/user_guide/channels/email/reporting#estimated-real-open-rate) usa um modelo analítico proprietário criado pela Braze para reconstruir uma estimativa da taxa de abertura única da Campaign como se as aberturas por máquina não existissem. A Braze usa dados de cliques de cada Campaign para inferir a taxa na qual humanos reais abriram a mensagem. Isso compensa vários mecanismos de abertura por máquina, incluindo o MPP da Apple.

### Jornadas personalizadas para Canvas {#personalized-paths-for-canvas}

{% multi_lang_include release_type.md release="Beta" %}

Com as [jornadas personalizadas]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step/personalized_paths), você pode personalizar jornadas inteiras do Canvas para usuários individuais com base na probabilidade de conversão, semelhante às variantes personalizadas em Campaigns. Use as jornadas personalizadas com uma etapa de jornada experimental para manter uma parte dos usuários em um grupo de postergação enquanto a Braze testa as jornadas restantes entre si.

### Novo artigo de ajuda: Links universais e App Links {#new-help-article-universal-links-and-app-links}

Os links universais da Apple e os Android App Links são mecanismos criados para fornecer uma transição perfeita entre conteúdo web e apps móveis. Enquanto os links universais são específicos do iOS, os Android App Links servem ao mesmo propósito para aplicativos Android.

Saiba mais sobre esse tópico em nosso artigo dedicado [Links universais e App Links]({{site.baseurl}}/user_guide/channels/email/customize/universal_links_and_app_links).

## Novas parcerias da Braze {#new-braze-partnerships}

### Olo – Extensões de canal {#olo-channel-extensions}

A integração da Braze com o [Olo]({{site.baseurl}}/partners/ecommerce/ordering_payments_subscription/olo) permite que você atualize perfis de usuário na Braze para mantê-los consistentes com os perfis de usuário do Olo. Você também pode enviar as mensagens certas a partir da Braze com base em eventos do Olo.

### Typeform – CDP {#typeform-customer-data-platform}

A integração da Braze com o [Typeform]({{site.baseurl}}/partners/additional_channels_and_extensions/extensions/surveys/typeform) permite que você atualize perfis de usuário na Braze com dados coletados das respostas do Typeform, dispare envio de mensagens na Braze com base no engajamento de um usuário com um typeform e personalize as mensagens da Braze com base nas respostas do Typeform de um usuário.

## Atualizações do SDK {#sdk-updates}

As atualizações mais recentes do SDK foram lançadas. As atualizações com breaking changes estão listadas na seção de atualizações do SDK; todas as outras atualizações podem ser encontradas nos changelogs correspondentes do SDK.

- [Web SDK v4.10.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [Web SDK v5.0.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [Android SDK 29.0.1](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [SWIFT SDK 7.1.0-7.2.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - `Braze.Configuration.DeviceProperty.pushDisplayOptions` foi descontinuado. Fornecer esse valor não tem mais efeito.
- [React Native SDK 8.0.0-8.1.0](https://github.com/braze-inc/braze-react-native-sdk/blob/master/CHANGELOG.md)
    - Atualiza a bridge nativa do Android do Braze Android SDK 27.0.1 para 29.0.0.
    - Atualiza a bridge nativa do iOS do Braze SWIFT SDK 6.6.0 para 7.0.0.
    - Renomeia o tipo de cartão de conteúdo `Banner` para ImageOnly:
        - `BannerContentCard` para `ImageOnlyContentCard`
        - `ContentCardTypes.BANNER` para `ContentCardTypes.IMAGE_ONLY`
    - No Android, se os arquivos XML do seu projeto contiverem a palavra `banner` para Content Cards, ela deve ser substituída por `image_only`.
    - `Braze.getFeatureFlag(id)` agora retornará `null` se a Feature Flag não existir.
    - `Braze.Events.FEATURE_FLAGS_UPDATED` será disparado apenas quando uma solicitação de atualização for concluída com sucesso ou falha, e na inscrição inicial se houver dados em cache da sessão atual.
