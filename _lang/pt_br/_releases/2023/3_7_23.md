# Lançamento em 7 de março de 2023 {#march-7-2023-release}

## Remoção do suporte para duplicação de Canvas na experiência original {#removing-support-for-duplicating-original-experience-canvases}

A partir de 28 de fevereiro de 2023, não é mais possível criar ou duplicar Canvas usando a experiência original do Canvas. A Braze recomenda que os clientes que usam a experiência original do Canvas migrem para o Canvas Flow. É uma experiência de edição aprimorada para criar e gerenciar Canvas de forma mais eficiente. Saiba mais sobre [clonar seus Canvas para o Canvas Flow]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/cloning_canvases).

## Live Activities para iOS (acesso antecipado) {#live-activities-for-ios-early-access}

[Live Activities]({{site.baseurl}}/developer_guide/push_notifications/live_notifications/?sdktab=swift) são notificações persistentes e interativas exibidas na tela de bloqueio, permitindo que você acompanhe as coisas em tempo real. Como aparecem na tela de bloqueio, as Live Activities garantem que suas notificações não passem despercebidas. Por serem persistentes, você pode exibir conteúdo atualizado para seus usuários sem que eles precisem desbloquear o telefone.

## Criação de cartões para Content Cards {#card-creation-for-content-cards}

Agora você pode escolher quando a Braze avalia a elegibilidade do público e a personalização para novas campanhas de Content Cards, especificando quando o cartão é criado.

As seguintes opções estão disponíveis:

- **No lançamento da campanha:** O comportamento padrão anterior para Content Cards. A Braze calcula a elegibilidade do público e a personalização quando a campanha é lançada, depois cria o cartão e o armazena até que o usuário abra seu app.
- **Na primeira impressão:** Quando o usuário abre seu app pela próxima vez (ou seja, inicia uma nova sessão), a Braze determina para quais Content Cards o usuário é elegível, processa qualquer personalização como Liquid ou Connected Content e então cria o cartão.

Para saber mais, consulte [criação de cartões]({{site.baseurl}}/user_guide/channels/content_cards/create_a_content_card/card_creation).

## Redefinir estilos no editor de arrastar e soltar para mensagens no app {#reset-styles-for-in-app-message-drag-drop-editor}

No editor de arrastar e soltar para mensagens no app, agora você pode redefinir rapidamente os estilos para o padrão após fazer alterações. Para saber mais, consulte [redefinir estilos para o padrão]({{site.baseurl}}/user_guide/channels/in_app_messages/customize/style_settings#reset-styles-to-default).

## Domínios personalizados para encurtamento de links {#custom-domains-for-link-shortening}

O encurtamento de links também permite que você use seu próprio domínio para personalizar a aparência das suas URLs encurtadas, ajudando a transmitir uma imagem de marca consistente. Depois de configurados, os [domínios personalizados]({{site.baseurl}}/user_guide/message_building_by_channel/sms/campaign/link_shortening#custom-domains) podem ser atribuídos a um ou mais grupos de inscrições de SMS.

## Push web para dispositivos móveis no Safari {#safari-mobile-web-push}

O Safari v16.4 oferece suporte a push web para dispositivos móveis, o que significa que agora você pode reengajar usuários móveis com notificações por push no iOS e iPadOS. Siga nosso guia dedicado para ver as etapas de como oferecer suporte a [push web no Safari para iOS e iPadOS]({{site.baseurl}}/developer_guide/push_notifications/?sdktab=safari).

## Pesquisa de usuários {#user-lookup}

Este novo artigo descreve como usar a [pesquisa de usuários]({{site.baseurl}}/user_guide/audience/segments/creating_a_segment) para buscar um usuário específico diretamente no criador, a fim de testar se seus filtros e segmentos estão configurados corretamente. Isso também pode ser útil ao solucionar problemas de uma Campaign ou Canvas que não está enviando conforme o esperado — por exemplo, se os usuários não estão recebendo uma mensagem quando deveriam.

A pesquisa de usuários está disponível ao:

- Criar um Segment
- Configurar o público de uma Campaign ou Canvas
- Configurar uma etapa de jornada do público

## Bloqueio ou exclusão de dados personalizados {#blocklisting-or-deleting-custom-data}

Este novo artigo descreve como descontinuar um objeto de dados personalizados por meio do [bloqueio ou exclusão de dados personalizados]({{site.baseurl}}/user_guide/data/activation/custom_data/blocklist_custom_data).

Ocasionalmente, você pode identificar atributos personalizados, eventos personalizados ou eventos de compra que estão consumindo muitos pontos de dados, não são mais úteis para sua estratégia de marketing ou foram registrados por engano. Para impedir que esses dados sejam enviados para a Braze, você pode bloquear um objeto de dados personalizados enquanto sua equipe de engenharia trabalha para removê-lo do backend do seu app ou website.

## Novas parcerias da Braze {#new-braze-partnerships}

### Sisu Data - Business intelligence

A integração entre [Sisu Data]({{site.baseurl}}/partners) e a Braze permite que você entenda, em todas as campanhas ou no nível de uma campanha específica, por que as métricas (por exemplo, taxa de abertura, taxa de cliques, taxa de conversão, etc.) estão mudando e o que gera os resultados mais otimizados. Depois que esses segmentos são identificados, os usuários da empresa podem materializar os resultados em seu data warehouse ou enviá-los diretamente do Sisu para a Braze para redirecionar e reengajar usuários.

### Loplat - Localização contextual {#loplat-contextual-location}

A integração entre a Braze e o [loplat]({{site.baseurl}}/partners/message_personalization/location/loplat) permite que você use os serviços de localização do loplat (POI de lojas e geofence personalizado) para disparar campanhas de marketing geocontextuais e criar eventos personalizados usando segmentação offline. Quando os usuários visitam o local definido no loplat X, as informações da campanha e da localização são enviadas imediatamente para a Braze.

### ActionIQ - CDP {#actioniq-customer-data-platform}

A integração entre a Braze e o [ActionIQ]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/actioniq) permite que as marcas sincronizem e mapeiem seus dados do ActionIQ diretamente para a Braze, possibilitando a entrega de experiências extraordinárias ao cliente com base na totalidade dos dados de clientes. A integração permite que os usuários:

- Mapeiem segmentos de público ou atributos personalizados para a Braze diretamente do ActionIQ
- Encaminhem os eventos rastreados pelo ActionIQ para a Braze em tempo real para disparar campanhas personalizadas e direcionadas

### Komo - Conteúdo dinâmico {#komo-dynamic-content}

A integração entre a Braze e o [Komo]({{site.baseurl}}/partners/additional_channels_and_extensions/extensions/landing_pages/komo) permite que você colete dados voluntários e de primeira parte por meio dos Komo Engagement Hubs. Esses hubs são microsites dinâmicos que oferecem conteúdo interativo e recursos de gamificação. Os dados de usuários coletados nesses hubs são então transmitidos para a API da Braze.

### Phrase - Localização {#phrase-localization}

A integração entre o [Phrase]({{site.baseurl}}/partners/message_personalization/localization/phrase) e a Braze permite que você traduza modelos de e-mail e Content Blocks sem sair da interface da Braze. Com a integração do Phrase TMS para a Braze, você pode aumentar o engajamento do cliente e impulsionar o crescimento em novos mercados com uma localização integrada.

### Nift - Fidelidade {#nift-loyalty}

A integração entre a Braze e o [Nift]({{site.baseurl}}/partners/additional_channels_and_extensions/extensions/rewards/nift) permite que você dispare automaticamente agradecimentos contendo presentes Nift em momentos-chave do ciclo de vida do cliente e identifique quais clientes usaram seu presente. Os cartões-presente Nift podem ser usados para acessar produtos e serviços fornecidos por marcas que utilizam a tecnologia de matchmaking da Nift para adquirir novos clientes de forma econômica e em escala.

### Sageflo - Modelos de mensagem {#sageflo-message-templates}

A integração entre a Braze e o [Sageflo]({{site.baseurl}}/partners/message_orchestration/templates/sageflo) capacita equipes locais a enviar facilmente seus próprios e-mails usando modelos, imagens e segmentos de público aprovados pelo marketing por meio de integrações de API com a Braze.

### Airbyte - Automação de fluxo de trabalho {#airbyte-workflow-automation}

A integração entre a Braze e o [Airbyte]({{site.baseurl}}/partners/data_and_analytics/workflow_automation/airbyte) permite que os usuários criem um pipeline de dados para coletar e analisar dados da Braze conectando todos os seus aplicativos e bancos de dados a um data warehouse central. Depois que os dados são coletados no data warehouse central, as equipes de dados podem explorar os dados da Braze de forma eficaz usando suas ferramentas de business intelligence preferidas.

### GrowthLoop - Automação de fluxo de trabalho {#growthloop-workflow-automation}

A integração entre a Braze e o [GrowthLoop]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/growthloop) permite que você segmente dados de clientes diretamente do data warehouse e os envie para a Braze, garantindo que os usuários possam otimizar o conjunto avançado de recursos da Braze em conjunto com sua fonte única de verdade. Simplifique os esforços de marketing para segmentação e ativação de clientes, reduzindo o tempo necessário para segmentar, lançar, testar e medir os resultados de campanhas direcionadas enviadas para a Braze.
