# Versão de 10 de janeiro de 2023 {#january-10-2023-release}

## Componente de Atualização de usuário para o Canvas Flow {#user-update-component-for-canvas-flow}

O componente [User Update]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/user_update/) permite atualizar os atributos, eventos e compras de um usuário em um criador de JSON, sem a necessidade de incluir informações confidenciais, como chaves de API.

## Configuração de grupos de inscrições via API {#setting-subscription-groups-via-api}

Ao criar novos usuários por meio do [endpoint `/users/track`]({{site.baseurl}}/api/endpoints/user_data/post_user_track/), é possível definir grupos de inscrições no objeto de atributos do usuário, o que permite criar um usuário e definir o estado do grupo de inscrições em uma única chamada de API.

## Acesso antecipado ao dashboard de conversões {#conversions-dashboard-early-access}

O [dashboard de conversões]({{site.baseurl}}/user_guide/analytics/dashboards/conversions/) permite analisar conversões em Campaigns, Canvas e canais, usando diferentes métodos de atribuição. Você pode rastrear especificamente estes métodos de atribuição:

- **Conversões por abertura:** conversões que ocorreram depois que um usuário abriu a mensagem
- **Conversões por clique:** conversões que ocorreram depois que um usuário clicou na mensagem
- **Conversões por recebimento:** conversões que ocorreram depois que um usuário recebeu a mensagem
- **Conversões por último clique:** conversões que ocorreram depois que um usuário clicou na mensagem, caso ela tenha sido a mais recente em que o usuário clicou (esse recurso está sendo testado atualmente em um pequeno subconjunto de clientes com acesso antecipado)

Esse recurso está atualmente em acesso antecipado. Se você tiver interesse em participar do acesso antecipado, entre em contato com o seu gerente de sucesso do cliente.

## Eventos de saída do Canvas para o Braze Currents {#canvas-exit-events-for-braze-currents}

Agora é possível rastrear quando os usuários saem de um Canvas, seja ao realizar um evento ou ao corresponder a um público. Consulte a seção [Eventos de engajamento com mensagens]({{site.baseurl}}/user_guide/data/distribution/braze_currents/event_glossary/message_engagement_events/) no glossário de eventos do Currents para saber mais.

## Atualizações do SDK {#sdk-updates}

As seguintes atualizações do SDK foram lançadas. As atualizações com mudanças significativas estão listadas abaixo; todas as outras atualizações podem ser encontradas nos changelogs correspondentes do SDK.

- [Web SDK 4.5.1](https://github.com/braze-inc/braze-web-sdk/blob/master/CHANGELOG.md)
- [AppboyKit iOS SDK 4.5.2](https://github.com/Appboy/appboy-ios-sdk/releases/tag/4.5.2)
- [Swift SDK 5.8.0-5.8.1](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#580)
  - Renomeia a classe `BrazeLocation` para `BrazeLocationProvider` para evitar o sombreamento do módulo com o mesmo nome.
- [Flutter SDK 3.0.1](https://pub.dev/packages/braze_plugin/changelog)
- [Android SDK 24.0.0](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
  - A funcionalidade de local e geofence foi movida para um novo módulo chamado `com.braze:android-sdk-location`.
  - As classes e os arquivos do Appboy foram migrados integralmente para a Braze.
  - Alterado o comportamento padrão do `DefaultContentCardsUpdateHandler` para usar a hora de criação em vez da hora da última atualização ao classificar os Content Cards.
  - Removidos BrazeUser.setFacebookData() e BrazeUser.setTwitterData().
