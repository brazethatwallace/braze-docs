# Geofences {#geofences}

> Aprenda como configurar geofences para o SDK or kit de desenvolvimento de software da Braze. Um [geofence]({{site.baseurl}}/user_guide/audience/locations_and_geofences) é uma área geográfica virtual que forma um círculo ao redor de uma posição global específica, representada pela combinação de latitude, longitude e um raio.
