# BrazeAI Decisioning Studio™ Go

> Saiba como configurar e integrar o BrazeAI Decisioning Studio™ Go na Braze.

{% alert important %}
Em meados de 2026, uma nova versão do Decisioning Studio™ Go será lançada como self-service a partir do dashboard da Braze. O artigo a seguir se aplica à versão legada, que eventualmente será descontinuada.
{% endalert %}

## Sobre o Decisioning Studio Go {#about-decisioning-studio-go}

O Decisioning Studio Go inclui configuração criativa self-service com um banco de ações limitado, apenas recursos de cliente baseados em engajamento, otimização por cliques e é compatível apenas com as seguintes plataformas de engajamento com clientes (CEPs):

* Braze
* Salesforce Marketing Cloud

Para saber mais sobre as diferenças entre o Decisioning Studio Go e o Decisioning Studio Pro, consulte [Decisioning Studio Go versus Decisioning Studio Pro]({{site.baseurl}}/user_guide/brazeai/decisioning_studio/#decisioning-studio-go-vs-decisioning-studio-pro).
