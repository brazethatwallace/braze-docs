# O Intelligence Suite {#the-intelligence-suite}

> O Braze Intelligence Suite automatiza a tomada de decisões com insights baseados em dados. Do tempo de entrega à seleção de canal, você pode usar esses recursos para criar experiências dinâmicas e mensagens integradas entre canais que otimizam em escala. O Intelligence Suite inclui o Intelligent Timing e o Canal Inteligente.

## Casos de uso {#use-cases}

O Intelligence Suite oferece recursos poderosos para analisar o histórico do usuário e o desempenho de Campaigns e Canvas, e então fazer ajustes automáticos para melhorar engajamento, visualizações e conversões. Para alguns exemplos de como esses recursos podem beneficiar diferentes setores, veja os casos de uso a seguir.

### eCommerce {#ecommerce}

- **Promoção relâmpago:** Use o [filtro Canal Inteligente]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_channel) para estudar o histórico do usuário e identificar os usuários que são mais responsivos a notificações por push do que a e-mails, e então envie notificações por push e e-mails para os respectivos usuários. Opcionalmente, selecione um canal específico para usuários que não possuem dados suficientes para determinar o canal preferido.

### Viagens {#travel}

- **Ofertas de viagem:** Use o filtro Canal Inteligente para enviar ofertas de viagem personalizadas pelo canal mais ativo do usuário, como e-mail ou SMS, maximizando a probabilidade de engajamento com o envio de mensagens.

### Entretenimento {#entertainment}

- **Promoção de novo conteúdo:** Use o [Intelligent Timing]({{site.baseurl}}/user_guide/brazeai/intelligence_suite/intelligent_timing) para enviar notificações sobre novos filmes, séries, músicas e outros tipos de conteúdo quando os usuários têm mais probabilidade de abrir suas mensagens.
