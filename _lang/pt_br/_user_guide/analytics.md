Use **Dashboards** para monitorar o desempenho em uma visão geral, **Relatórios** para análises mais aprofundadas de campanhas e Canvas, e **Rastreamento** para configurar como a Braze captura as ações dos usuários. Se você não tem certeza do que uma métrica específica significa, consulte o **Glossário de métricas**.
