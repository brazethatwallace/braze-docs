Use **Dashboards** para monitorar o desempenho em uma visão geral, **Relatórios** para análises mais aprofundadas de Campaigns e Canvas, e **Rastreamento** para configurar como a Braze captura as ações dos usuários. Se você não tem certeza do que uma métrica específica significa, consulte o **Glossário de métricas**.

## Perguntas frequentes {#frequently-asked-questions}

### Quais dashboards de análise de dados estão disponíveis na Braze? {#what-analytics-dashboards-are-available-in-braze}

A Braze inclui dashboards pré-construídos e personalizáveis para desempenho de Campaign, Canvas e canais. Consulte [Dashboards]({{site.baseurl}}/user_guide/analytics/dashboards) para ver as visualizações disponíveis e as etapas de configuração.

### Como faço para exportar dados de análise da Braze? {#how-do-i-export-braze-analytics-data}

Use relatórios no dashboard, exportações agendadas ou [Currents]({{site.baseurl}}/user_guide/data/distribution/braze_currents) para transmitir dados de eventos para seu data warehouse ou ferramentas de BI.

### Onde posso encontrar definições das métricas da Braze? {#where-can-i-find-definitions-for-braze-metrics}

Consulte o [Glossário de métricas]({{site.baseurl}}/user_guide/analytics/metrics_glossary) para ver as definições das métricas comuns de Campaign e engajamento.
