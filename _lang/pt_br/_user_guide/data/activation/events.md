Para rastrear ações únicas dos usuários, como iniciar um tutorial ou adicionar um item à lista de desejos, você pode definir eventos personalizados. Para setores comuns como eCommerce, os eventos recomendados oferecem esquemas pré-definidos e estruturas de dados com boas práticas para ajudar você a começar mais rápido. Você também pode registrar transações com dados de receita usando eventos de compra. <br><br>Juntos, esses eventos permitem que você analise tendências ao longo do tempo e acione engajamentos oportunos e relevantes."
