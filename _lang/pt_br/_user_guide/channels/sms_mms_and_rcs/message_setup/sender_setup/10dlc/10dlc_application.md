# Informações necessárias para a aplicação 10DLC {#required-information-for-10dlc-application}

> Este artigo aborda as informações da empresa e da campanha de SMS que a Braze precisa se você está trabalhando com a Braze para registrar seu 10DLC.

Se você adquiriu o suporte da Braze para registrar seu 10DLC, será necessário enviar todas as informações obrigatórias listadas para o e-mail abaixo, conforme acordado em seu contrato conosco.

Inclua quaisquer capturas de tela e anexos relevantes e envie tudo para [smsapplications@braze.com](mailto:smsapplications@braze.com). Se você tiver alguma dúvida sobre 10DLC, consulte o [guia de SMS 10DLC da Braze]({{site.baseurl}}/assets/pdf/SMS_10DLC_Guide.pdf) ou entre em contato com seu gerente de sucesso do cliente da Braze.

## Informações da campanha de SMS {#sms-campaign-information}

Precisaremos registrar cada grupo de inscrições de SMS que contenha um long code dos EUA com sua própria Campaign A2P 10DLC (às vezes chamada de caso de uso). Forneça as informações abaixo uma vez para cada um dos seus grupos de inscrições de SMS que contenham um long code dos EUA.

| Campo | Opções (se aplicável) | Descrição |
| ------ | ------------------------ | --------------- |
| Caso de uso da Campaign (escolha o que melhor se aplica) | {::nomarkdown} <ul><li>Marketing</li><li>Account Notifications</li><li>Delivery Notifications</li><li>Customer Care</li><li>Security Alert</li><li>Fraud Alert Messaging</li><li>Higher Education</li><li>Mixed</li><li>Polling and Voting</li><li>Public Service Announcement</li></ul>{:/} | Nota: Se você planeja usar um caso de uso "Mixed" para um grupo de inscrições, consulte seu gerente de sucesso do cliente ou gerente de integração para obter detalhes importantes antes de prosseguir |
| Nome da Campaign | | {::nomarkdown}<p>O nome da campanha de SMS precisa ser exibido de forma consistente em suas mensagens, nos Termos de Serviço e em qualquer lugar onde seus usuários se inscrevam no seu programa.</p><p>Exemplos:</p><ul><li>Braze Marking Alerts</li><li>Braze Account Notifications</li><li>Braze Cart Reminders</li></ul>{:/} |
| Descrição da Campaign | | Esta campanha envia mensagens de marketing e promocionais para usuários que optaram por receber SMS, incluindo ofertas especiais/cupons e notificações de lembrete de carrinho. |
| Endereço de e-mail do suporte ao cliente | | Onde os usuários finais podem entrar em contato por e-mail para obter ajuda e suporte |
| Número de telefone do suporte ao cliente | | Onde os usuários finais podem entrar em contato por telefone para obter ajuda e suporte |
| URL dos termos e condições de SMS | | {::nomarkdown} <p>Para concluir o registro US A2P 10DLC, sua página de termos de SMS deve incluir o seguinte:</p><ol><li>Nome do programa (marca)</li><li>Divulgação consistente do produto no site e no fluxo de mensagens</li><li>Frequência de mensagens (consistente com o fluxo de mensagens)</li><li>Aviso de "Taxas de mensagem e dados podem ser aplicadas"</li><li>Instruções de HELP/STOP OU informações de contato do atendimento ao cliente</li></ol><p>Se esta página não estiver ativa ou se alguma das divulgações obrigatórias estiver faltando, será necessário um rascunho dos termos de SMS junto com a data prevista de implementação na sua página ativa para concluir o processo de registro.</p>{:/} |
| Como os usuários finais fazem opt-in na sua campanha de SMS? (Compartilhe como os usuários finais podem aderir ao seu programa de SMS, como podem dar consentimento para receber suas mensagens SMS. Se vários métodos de opt-in forem usados, todos devem ser listados aqui.) | | {::nomarkdown}<p>Exemplos:</p><ul><li>Os usuários finais fazem opt-in enviando START para XXXXXXXXXX.</li><li>Os usuários finais fazem opt-in visitando o site e adicionando seu número de celular. Em seguida, marcam uma caixa concordando em receber SMS.</li><li>Se o método de opt-in escolhido ainda não estiver ativo, forneça um mockup/captura de tela do método de opt-in.</li></ul>{:/} |
| Palavras-chave de opt-in | | {::nomarkdown} <p>Se os usuários finais podem enviar uma palavra-chave para começar a receber SMS desta campanha, essas palavras-chave devem ser fornecidas. Por padrão, a Braze configura as seguintes palavras-chave:</p><ul><li>START</li><li>UNSTOP</li><li>YES</li></ul><p>Informe-nos se deseja adicionar alguma palavra-chave.</p> {:/} |
| Mensagem de confirmação de opt-in | | A mensagem de resposta automática enviada aos usuários finais para confirmar o opt-in deve ser fornecida. A resposta de opt-in deve incluir o nome da marca, confirmação da inscrição em uma campanha de mensagens recorrentes, como obter ajuda e uma descrição clara de como fazer o descadastramento. (por exemplo, Obrigado por se juntar ao Braze Marketing Alerts! A frequência de mensagens varia. Taxas de mensagem e dados podem ser aplicadas. Responda HELP para ajuda ou STOP para cancelar.) |
| Palavras-chave de descadastramento | | {::nomarkdown} <p>Os usuários finais devem poder enviar uma palavra-chave para parar de receber mensagens desta campanha. Por padrão, a Braze configura as seguintes palavras-chave:</p><ul>  <li>STOP</li><li>STOPALL</li><li>UNSUBSCRIBE</li><li>CANCEL</li><li>END</li><li>QUIT</li></ul><p>Informe-nos se deseja adicionar alguma palavra-chave.</p>{:/} |
| Mensagem de descadastramento | | Ao receber as palavras-chave de descadastramento dos usuários finais, as operadoras esperam uma resposta gerada automaticamente, que deve fornecer o reconhecimento da solicitação de descadastramento e a confirmação de que nenhuma mensagem adicional será enviada. Também é recomendado que essas mensagens de descadastramento incluam o nome da marca (por exemplo, Braze Marketing Alerts: Você cancelou a inscrição de todas as mensagens. Responda HELP para ajuda.) <br><br>Máximo de 320 caracteres|
| Palavras-chave de ajuda | | Os usuários finais devem poder enviar uma palavra-chave para receber ajuda. Por padrão, a Braze configura as seguintes palavras-chave: -HELP -INFO Informe-nos se deseja adicionar alguma palavra-chave. |
| Mensagem de ajuda | | Ao receber as palavras-chave de ajuda dos usuários finais, as operadoras esperam uma resposta gerada automaticamente, que pode incluir o nome da marca e informações adicionais de contato de suporte (por exemplo, Braze Marketing Alerts: Para ajuda ligue 555-555-555. Taxas de msg e dados podem ser aplicadas. A freq de msg pode variar. Envie STOP para cancelar)<br><br>Máximo de 320 caracteres|
| Mensagem de exemplo 1 de 2 | | Customer/Brand Updates: Olá e bem-vindo ao Customer Brand Updates. Visite nosso site em www.customerwebsite.com. Digite HELP para ajuda ou STOP para cancelar. |
| Mensagem de exemplo 2 de 2 | | Customer/Brand Updates: Confira nossa última promoção de feriado com 20% de desconto em todos os itens até segunda-feira. Visite nosso site em www.customerwebsite.com. Digite HELP para ajuda ou STOP para cancelar. |
| Volume diário estimado | | Indique o número médio estimado de mensagens enviadas por dia para este caso de uso/grupo de inscrições específico, por exemplo, 10.000. |
| Checklist de chamada para ação | | {::nomarkdown} <p>A chamada para ação deve incluir o seguinte:</p><ol><li>Descrição do produto</li><li>Divulgação da frequência de mensagens</li><li>Link para os termos e condições completos</li><li>Link para a política de privacidade completa</li><li>Instruções da palavra-chave STOP</li><li>Instruções da palavra-chave HELP</li><li>Aviso de "Taxas de mensagem e dados podem ser aplicadas"</li></ol> {:/} |
