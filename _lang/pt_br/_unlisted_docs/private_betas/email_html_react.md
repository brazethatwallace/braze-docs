# Editor de HTML atualizado para e-mail {#updated-html-editor-for-email}

> O editor de HTML atualizado para e-mail traz uma série de melhorias na interface, incluindo uma experiência aprimorada de edição de código.

## Benefícios {#benefits}

O editor de HTML atualizado cria uma experiência consistente com nossos editores em outros canais de envio de mensagens. Você pode alternar facilmente entre os editores (HTML, clássico, texto simples e AMP) usando a navegação superior do editor. Essas opções ficavam anteriormente ocultas em um menu suspenso no antigo editor de HTML.

Os benefícios também incluem suporte aprimorado à sintaxe Liquid e [suporte a configurações de vários idiomas]({{site.baseurl}}/user_guide/administrative/app_settings/multi_language_settings/).

O gerenciamento de links também é compatível com o editor de HTML atualizado, mesmo que você não tenha o [link aliasing]({{site.baseurl}}/user_guide/message_building_by_channel/email/templates/link_aliasing/) ativado.
