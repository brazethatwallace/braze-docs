# Gerações de mensagens no app {#in-app-messages-generations}

A Braze possui atualmente três gerações de mensagens no app. Cada uma conta com seu próprio nível de suporte. Para aproveitar os recursos mais recentes das nossas mensagens no app, recomendamos atualizar para os SDKs mais recentes de [web]({{site.baseurl}}/developer_guide/platform_integration_guides/web/initial_sdk_setup/#upgrading-the-sdk), iOS e Android.

Este gráfico destaca os recursos e tipos de mensagem que estão disponíveis atualmente e quando foram introduzidos em cada geração. O gráfico também indica explicitamente o que não é suportado em uma determinada geração.

| Geração | Novos recursos | Recursos não suportados |
|---|---|---|
| **Geração 1** | • Tipos de mensagem Tela cheia, Modal e slideup disparados no app | Mensagens HTML personalizadas <br> • Formulário de captura de e-mail para web <br> • Modal para web com CSS personalizado |
| **Geração 2** | • Controles de alinhamento de texto <br> • Sobreposição atrás do Modal <br> • Zona segura de imagem na janela de pré-visualização | Borda do botão |
| **Geração 3** | • Borda do botão <br> • Aparência refinada para todos os tipos de mensagem <br> • Conceito de Gerações 1, 2 e 3 <br> • Novo ativo de fechar (X) <br> • Acessibilidade aprimorada na web <br> • Suporte aprimorado em dispositivos com entalhe | (A geração mais recente sempre tem suporte completo a todos os recursos!) |
