# Repository-Leitfäden {#repository-guides}

> Diese Seiten spiegeln die öffentlichen README-Dateien aus den Braze SDK or Software-Development-Kit-Repositorys wider. Sie werden wöchentlich automatisch synchronisiert, und jede Seite verlinkt auf das Quell-Repository für Beispielprojekte und zusätzlichen Kontext.
