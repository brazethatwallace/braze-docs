# Veröffentlichung am 16. September 2025 {#september-16-2025-release}

## Datenflexibilität {#data-flexibility}

### Braze Data Platform

Braze Data Platform ist ein umfassendes, modulares Set von Datenfunktionen und Partnerintegrationen, mit dem Sie personalisierte, wirkungsvolle Erlebnisse über den gesamten Kundenlebenszyklus hinweg schaffen können. Erfahren Sie mehr über die drei datenbezogenen Aufgabenbereiche:

- [Datenvereinheitlichung]({{site.baseurl}}/user_guide/data/unification)
- [Datenaktivierung]({{site.baseurl}}/user_guide/data/activation)
- [Datenverteilung]({{site.baseurl}}/user_guide/data/distribution)

### Angepasste Banner-Eigenschaften {#custom-banner-properties}

{% multi_lang_include release_type.md release="Early access" %}

Sie können angepasste Eigenschaften aus Ihrer Banner-Campaign verwenden, um Schlüssel-Wert-Daten über das SDK abzurufen und das Verhalten oder Erscheinungsbild Ihrer App zu ändern. Weitere Informationen finden Sie unter [Angepasste Banner-Eigenschaften]({{site.baseurl}}/developer_guide/banners/placements#custom-properties).

### Token-Authentifizierung {#token-authentication}

{% multi_lang_include release_type.md release="General availability" %}

Wenn Sie Connected-Content von Braze verwenden, stellen Sie möglicherweise fest, dass bestimmte APIs anstelle eines Benutzernamens und Passworts ein Token erfordern. Braze kann Zugangsdaten speichern, die [Token-Authentifizierungs-Header-Werte]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content/making_an_api_call#using-token-authentication) enthalten.

### Aktionscodes {#promotion-codes}

Sie können Aktionscodes über einen Nutzer:innen-Update-Schritt im Nutzerprofil speichern. Weitere Informationen finden Sie unter [Aktionscodes in Nutzerprofilen speichern]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/sources/promotion_codes/manage#save-to-profile).

## Kreativität freisetzen {#unlocking-creativity}

### Braze Pilot

[Braze Pilot]({{site.baseurl}}/user_guide/get_started/braze_pilot) ist eine öffentlich verfügbare App für Android und iOS, mit der Sie Nachrichten von Ihrem Braze-Dashboard an Ihr Telefon senden können. Sehen Sie sich [Erste Schritte mit Braze Pilot]({{site.baseurl}}/user_guide/get_started/braze_pilot/getting_started) an, um eine Schritt-für-Schritt-Anleitung zum Herunterladen der App, zum Herstellen der Verbindung mit Ihrem Braze-Dashboard und zum Abschließen der Einrichtung zu erhalten.

## Neue Braze-Partnerschaften {#new-braze-partnerships}

### Blings – Visueller und interaktiver Content {#blings-visual-and-interactive-content}

[Blings]({{site.baseurl}}/partners/blings) ist eine Personalisierte-Video-Plattform der nächsten Generation, mit der Sie Realtime-, interaktive und datengestützte Video-Erlebnisse kanalübergreifend und in großem Umfang bereitstellen können.

### Shopify-Standardintegration mit Drittanbieter-Tool {#shopify-standard-integration-with-third-party-tool}

Für Shopify-Onlineshops empfehlen wir die Standardintegrationsmethode von Braze, um die Braze-SDKs auf Ihrer Website zu unterstützen.

Wir wissen jedoch, dass Sie möglicherweise ein Drittanbieter-Tool wie Google Tag Manager bevorzugen, und haben daher eine Anleitung zusammengestellt, wie Sie dabei vorgehen können. Informationen zum Einstieg finden Sie unter [Shopify: Drittanbieter-Tagging]({{site.baseurl}}/shopify_standard_integration_third_party_tagging).

## SDK-Updates

Die neuesten SDK-Updates wurden veröffentlicht. Wichtige Änderungen sind im Abschnitt SDK-Updates aufgeführt; alle weiteren Updates finden Sie in den entsprechenden SDK-Changelogs.

- [Braze Flutter SDK 15.0.0](https://github.com/braze-inc/braze-flutter-sdk/blob/main/CHANGELOG.md#1500)
    - Aktualisiert die native Android-Bridge vom Braze Android SDK `36.0.0` auf `39.0.0`.
    - Aktualisiert die native iOS-Bridge vom Braze Swift SDK `12.0.0` auf `13.2.0`. Dies umfasst Xcode 26-Unterstützung.

- [Braze Swift SDK 7.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1300)
  - Aktualisiert die Braze Swift SDK-Bindings, sodass Releases ab der SemVer-Bezeichnung `13.0.0+` erforderlich sind. Dies ermöglicht die Kompatibilität mit jeder Version des Braze SDK ab `13.0.0` bis, aber nicht einschließlich, `14.0.0`.
