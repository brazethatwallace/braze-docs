# Release vom 4. Februar 2025 {#february-4-2025-release}

## Verbesserungen der Braze-Dokumentation {#braze-docs-improvements}

### Überarbeitung von Daten und Analytics {#data-and-analytics-revamp}
Damit Sie leichter finden, wonach Sie suchen, haben wir die Artikel, die zuvor unter „Daten und Analytics“ zusammengefasst waren, in [Daten]({{site.baseurl}}/user_guide/data) und [Analytics]({{site.baseurl}}/user_guide/analytics) aufgeteilt.

### Entwickler:innen-Leitfaden {#developer-guide}
Wir haben eine umfassende Bereinigung aller Dokumente im [Braze-Entwickler:innen-Leitfaden]({{site.baseurl}}/developer_guide/home) durchgeführt, einschließlich der Zusammenführung von „How-tos“, die über mehrere Seiten verteilt waren, auf jeweils eine einzelne Seite.

Außerdem gibt es eine neue [SDK-Referenzseite]({{site.baseurl}}/developer_guide/references), die alle Referenzdokumentationen und Repositories für jedes Braze SDK auflistet.

#### Unreal Engine Braze SDK
Wir haben alle Inhalte aus der README des Unreal Engine Braze SDK GitHub-Repositorys migriert und neu verfasst und in einen [eigenen Bereich in der Braze-Dokumentation]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=unreal%20engine) überführt.

## Datenflexibilität {#data-flexibility}

### Dashboard zur API-Nutzung {#api-usage-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

Das [Dashboard zur API-Nutzung]({{site.baseurl}}/user_guide/analytics/dashboards/api_usage) ermöglicht es Ihnen, Ihren eingehenden REST-API-Traffic in Braze zu überwachen, Trends in Ihrer Nutzung unserer REST APIs zu verstehen und potenzielle Probleme zu beheben.

### Tags zu angepassten Attributen hinzufügen {#adding-tags-to-custom-attributes}

{% multi_lang_include release_type.md release="General availability" %}

Sie können [Tags zu einem angepassten Attribut hinzufügen]({{site.baseurl}}/user_guide/data/activation/attributes/custom_attributes#add-tags), nachdem es erstellt wurde, wenn Sie die Berechtigung „Manage Events, Attributes, Purchases“ haben. Die Tags können dann verwendet werden, um die Liste der Attribute zu filtern.

### Katalogauswahlen und asynchrone Katalogfeld-Endpunkte {#catalog-selections-and-async-catalog-fields-endpoints}

{% multi_lang_include release_type.md release="General availability" %}

Die folgenden Endpunkte sind jetzt allgemein verfügbar:
* [POST: Katalogfelder erstellen]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/post_create_catalog_fields)
* [DELETE: Katalogfeld löschen]({{site.baseurl}}/api/endpoints/catalogs/catalog_fields/asynchronous/delete_catalog_field)
* [DELETE: Katalogauswahl löschen]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/delete_catalog_selection)
* [POST: Katalogauswahl erstellen]({{site.baseurl}}/api/endpoints/catalogs/catalog_selections/asynchronous/post_create_catalog_selections)

### Eine E-Mail-Adresse zum Triggern von Campaigns oder Canvases verwenden {#using-an-email-address-to-trigger-campaigns-or-canvases}

{% multi_lang_include release_type.md release="General availability" %}

Sie können jetzt eine Empfänger:in per E-Mail-Adresse angeben, um Ihre [Campaigns]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/target_users) und [Canvases]({{site.baseurl}}/user_guide/messaging/canvas/create_a_canvas#step-13-set-your-target-entry-audience) zu triggern.

### Eine Telefonnummer zur Identifizierung von Nutzer:innen über die API verwenden {#using-a-phone-number-to-identify-a-user-via-the-api}

{% multi_lang_include release_type.md release="General availability" %}

Sie können jetzt eine Telefonnummer zusätzlich zu einem Alias und einer E-Mail-Adresse verwenden, um Nutzer:innen über den [`/users/identify`-API-Endpunkt]({{site.baseurl}}/api/endpoints/user_data/post_user_identify) zu identifizieren.

### Einen SAML-Trace erhalten {#getting-a-saml-trace}
Wir haben [Schritte zum Erhalten eines SAML-Trace]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/saml_sso_setup#obtaining-a-saml-trace) hinzugefügt, die Ihnen helfen, Probleme mit SAML Single Sign-on effizienter mit dem Support zu lösen.

### Regionsspezifische Rechenzentren {#region-specific-data-centers}
Da Braze wächst und neue Regionen bedient, haben wir einen [Artikel über Braze-Rechenzentren]({{site.baseurl}}/user_guide/data/infrastructure/data_centers) hinzugefügt, um unseren operativen Ansatz zu erläutern.

## Kreativität freisetzen {#unlocking-creativity}

### Preisdrop-Benachrichtigungen und Wieder-auf-Lager-Benachrichtigungen {#price-drop-notifications-and-back-in-stock-notifications}

{% multi_lang_include release_type.md release="General availability" %}

Sie können Kund:innen jetzt benachrichtigen, wenn ein Artikel wieder auf Lager ist, indem Sie [Wieder-auf-Lager-Benachrichtigungen]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/back_in_stock_notifications) über einen Canvas und einen Katalog einrichten.

Sie können auch [Preisdrop-Benachrichtigungen]({{site.baseurl}}/user_guide/data/activation/catalogs/catalog_triggers/price_drop_notifications) erstellen, um Kund:innen zu benachrichtigen, wenn der Preis eines Artikels gesunken ist, indem Sie Preisdrop-Benachrichtigungen in einem Katalog und Canvas einrichten.

### Vorschau für Auswahl {#preview-for-selection}

{% multi_lang_include release_type.md release="General availability" %}

Nach dem Erstellen einer Auswahl können Sie sich [ansehen, was eine Auswahl zurückgeben würde]({{site.baseurl}}/user_guide/data/activation/catalogs/selections#test-and-preview) – entweder für eine:n zufällige:n Nutzer:in oder eine:n bestimmte:n Nutzer:in.

### Templating von Katalogartikeln mit Liquid {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="General availability" %}

Sie können [Katalogartikel, die Liquid enthalten, als Template verwenden]({{site.baseurl}}/user_guide/data/activation/catalogs/using_catalogs#using-liquid).

### Canvas-Templates
Wir haben neue Canvas-Templates hinzugefügt: für das [Onboarding von Nutzer:innen mit einer Präferenzumfrage]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/preference_survey) und für das [Erstellen einer E-Mail-Registrierung mit Double-Opt-in]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates/braze_templates/email_signup).

### Leads mit Salesforce Sales Cloud für B2B verwalten {#managing-leads-with-salesforce-sales-cloud-for-b2b}
Eine Möglichkeit für B2B-Marketer, Braze zu nutzen, ist eine Integration mit der Salesforce Sales Cloud. Erfahren Sie mehr darüber, wie Sie diesen [Anwendungsfall]({{site.baseurl}}/user_guide/get_started/b2b_use_cases/b2b_salesforce_sales_cloud) implementieren können.

## Robuste Kanäle {#robust-channels}

### Unterdrückungslisten {#suppression-lists}

{% multi_lang_include release_type.md release="Beta" %}

[Unterdrückungslisten]({{site.baseurl}}/user_guide/audience/suppression_lists) legen Gruppen von Nutzer:innen fest, die niemals Nachrichten erhalten werden. Admins können Unterdrückungslisten mit Segmentfiltern erstellen, um eine Nutzer:innengruppe einzugrenzen – genauso wie bei der Segmentierung.

## Neue Braze-Partnerschaften {#new-braze-partnerships}

### Constructor – Dynamischer Content {#constructor-dynamic-content}
[Constructor]({{site.baseurl}}/partners/ecommerce/product_search_recommendations/constructor) ist eine Such- und Produktentdeckungsplattform, die KI und maschinelles Lernen nutzt, um personalisierte Such-, Empfehlungs- und Browsing-Erlebnisse für E-Commerce- und Einzelhandels-Websites bereitzustellen.

### Trustpilot – Dynamischer Content {#trustpilot-dynamic-content}
[Trustpilot]({{site.baseurl}}/partners/trustpilot) ist eine Online-Bewertungsplattform, die es Ihren Kund:innen ermöglicht, Feedback zu teilen, und Ihnen erlaubt, Bewertungen zu verwalten und darauf zu antworten.
