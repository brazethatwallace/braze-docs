# Veröffentlichung am 11. November 2025 {#november-11-2025-release}

## Datenflexibilität {#data-flexibility}

### Segmentierungsfilter `Live Activities Push to Start Registered for App` {#live-activities-push-to-start-registered-for-app-segmentation-filter}

Der Filter [`Live Activities Push to Start Registered for App`]({{site.baseurl}}/user_guide/audience/segments/segmentation_filters#live-activities-push-to-start-registered-for-app) segmentiert Ihre Nutzer:innen danach, ob sie registriert sind, eine Live Activity über iOS-Push-Benachrichtigungen für eine bestimmte App zu starten.

### RFM-SQL-Segmenterweiterung {#rfm-sql-segment-extension}

Sie können eine [RFM-Segmenterweiterung (Recency, Frequency, Monetary)]({{site.baseurl}}/rfm_segments) erstellen, um Ihre besten Nutzer:innen gezielt anzusprechen, indem Sie deren Kaufgewohnheiten messen.

Die RFM-Analyse ist eine Marketingtechnik, die Ihre besten Nutzer:innen identifiziert, indem sie auf einer Skala von 0 bis 3 für jede Kategorie (Recency, Frequency, Monetary) bewertet werden, wobei 3 die beste und 0 die schlechteste Bewertung ist. Die Werte für Recency, Frequency und Monetary basieren alle auf Daten aus einem bestimmten Zeitraum Ihrer Wahl.

### Angepasste Attribute – Werte {#custom-attributes-values}

Wenn Sie einen Nutzungsbericht anzeigen, wählen Sie den [Tab **Werte**]({{site.baseurl}}/user_guide/data/activation/custom_data/custom_attributes#values-tab) aus, um die häufigsten Werte der ausgewählten angepassten Attribute basierend auf einer Stichprobe von etwa 250.000 Nutzer:innen anzuzeigen.

### Sync-Protokolle und Beobachtbarkeit für Cloud-Datenaufnahme {#sync-logs-and-observability-for-cloud-data-ingestion}

{% multi_lang_include release_type.md release="General availability" %}

Das [Sync-Log-Dashboard]({{site.baseurl}}/user_guide/data/unification/cloud_ingestion/sync_logs) der Cloud-Datenaufnahme (CDI) ermöglicht es Ihnen, alle von CDI verarbeiteten Daten zu überwachen, zu überprüfen, ob Daten erfolgreich synchronisiert wurden, und etwaige Probleme mit „fehlerhaften“ oder fehlenden Daten zu diagnostizieren.

### Feature-Flag-Rollouts mit mehreren Regeln {#multi-rule-feature-flag-rollouts}

Verwenden Sie [Feature-Flag-Rollouts mit mehreren Regeln]({{site.baseurl}}/developer_guide/feature_flags/create#multi-rule-feature-flag-rollouts), um eine Abfolge von Regeln zur Auswertung von Nutzer:innen zu definieren. Dies ermöglicht eine präzise Segmentierung und kontrollierte Feature-Releases. Diese Methode ist ideal, um dasselbe Feature an unterschiedliche Zielgruppen auszuliefern.

### Zuordnung zu Katalogfeldern für Drag-and-drop-Produktblöcke {#mapping-to-catalog-fields-for-drag-and-drop-product-blocks}

In Ihren Katalogeinstellungen können Sie den Toggle **Produktblöcke** auswählen, um [bestimmte Felder zuzuordnen]({{site.baseurl}}/user_guide/messaging/design_and_edit/product_blocks#catalog-setup) und Informationen in Ihrem Katalog zu verwenden. So können Sie festlegen, welche Felder als Produkttitel, Produkt-URL und Bild-URL verwendet werden sollen.

### Frequency-Capping-Abbruchereignisse in Currents {#frequency-capping-abort-events-in-currents}

Bei der Verwendung von Currents können Sie jetzt `abort_type` in den Kanal-Abbruchereignissen referenzieren. Dies zeigt an, dass eine Nachricht aufgrund von Frequency-Capping abgebrochen wurde, und gibt an, welche Frequency-Capping-Regel den Abbruch verursacht hat. Diese Information hilft Ihnen bei der Einrichtung Ihrer Frequency-Capping-Regeln. Einzelheiten zu spezifischen Currents-Ereignissen finden Sie unter [Nachrichten-Engagement-Ereignisse]({{site.baseurl}}/user_guide/data/distribution/braze_currents/event_glossary/message_engagement_events).

## Robuste Kanäle {#robust-channels}

### Hintergrundbilder für Zeilen {#background-row-images}

{% multi_lang_include release_type.md release="General availability" %}

Sie können [ein Hintergrundbild für eine Zeile hinzufügen]({{site.baseurl}}/user_guide/channels/in_app_messages/customize/style_settings#background-image), um es in einer In-App-Nachricht oder Landing-Page im Panel **Zeileneigenschaften** zu verwenden. Schalten Sie **Hintergrundbild** ein und geben Sie dann eine Bild-URL ein oder wählen Sie ein Bild aus der [Medienbibliothek]({{site.baseurl}}/user_guide/messaging/design_and_edit/media_library) aus. Konfigurieren Sie abschließend Ihren Alternativtext, die Größe, die Position und ob das Bild wiederholt wird, um Muster über die gesamte Zeile zu erstellen.

![Ein Zeilen-Hintergrundbild einer Pizza mit einem horizontalen Wiederholungsmuster.]({% image_buster /assets/img_archive/background_row.png %})

### Vorschau-Link kopieren {#copy-preview-link}

Verwenden Sie **Vorschau-Link kopieren** in Ihren [Bannern]({{site.baseurl}}/user_guide/channels/banners/create_a_banner#step-5-test-your-message-optional), [benutzerdefinierten E-Mail-Fußzeilen]({{site.baseurl}}/user_guide/channels/email/customize/custom_email_footer#create-your-custom-footer) und [E-Mail-Opt-in- und Abmeldeseiten]({{site.baseurl}}/user_guide/administer/global/workspace_settings/email_preferences/?tab=custom%20footer#subscription-pages-and-footers), um einen teilbaren Link zu generieren, der zeigt, wie Ihr Content für zufällige Nutzer:innen aussieht.

### WhatsApp-Nachrichten mit optimierter Zustellung {#whatsapp-messages-with-optimized-delivery}

Nutzen Sie die fortschrittlichen KI-Systeme von Meta, um Ihre Marketing-Nachrichten an mehr Nutzer:innen zu senden, die am wahrscheinlichsten mit ihnen interagieren werden, und steigern Sie so die Zustellbarkeit und das Nachrichten-Engagement erheblich.

[WhatsApp-Nachrichten mit optimierter Zustellung]({{site.baseurl}}/user_guide/channels/whatsapp/message_features_and_optimization/optimized_delivery) werden über Metas neue [Marketing Messages Lite API](https://developers.facebook.com/docs/whatsapp/marketing-messages-lite-api/) gesendet, die im Vergleich zur herkömmlichen Cloud API eine überlegene Performance bietet. Diese neue Sende-Pipeline hilft Ihnen, Nutzer:innen besser zu erreichen, die Ihre Nachrichten schätzen und empfangen möchten.

### WhatsApp Flows

Wenn Sie eine WhatsApp-Flow-Nachricht in ein Braze-Canvas oder eine Campaign einbinden, möchten Sie möglicherweise bestimmte Informationen erfassen und nutzen, die Nutzer:innen über den Flow übermitteln. Braze benötigt zusätzliche Informationen über die Struktur der Nutzerantwort, insbesondere die erwartete Form der JSON-Antwort, um das erforderliche Schema für verschachtelte angepasste Attribute (NCA) zu generieren.

Jetzt können Sie Braze die Informationen über die Antwortstruktur bereitstellen, indem Sie [die Flow-Antwort als angepasstes Attribut speichern]({{site.baseurl}}/user_guide/channels/whatsapp/message_features_and_optimization/whatsapp_flows/?tab=recommended%20method#step-1-generate-the-flow-custom-attribute) und einen Testversand durchführen.

### Bearbeitbare Nutzervorschau {#editable-user-preview}

Sie können [einzelne Felder eines zufälligen oder bestehenden Nutzers bzw. einer Nutzerin bearbeiten]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/sending_test_messages/?tab=webhook#customizing-an-existing-user), um dynamischen Content innerhalb Ihrer Nachricht zu testen. Wählen Sie **Bearbeiten**, um die ausgewählte Person in eine benutzerdefinierte Person umzuwandeln, die Sie ändern können.

## Neue Braze-Partnerschaften {#new-braze-partnerships}

### StackAdapt – Werbung {#stackadapt-advertising}

[StackAdapt]({{site.baseurl}}/partners/stackadapt) ist eine KI-gestützte Marketing-Plattform, die zielgerichtete, Performance-orientierte Werbung ermöglicht. Sie können damit Nutzerprofildaten aus Braze mit dem StackAdapt Data Hub synchronisieren. Durch die Verbindung der beiden Plattformen erhalten Sie eine einheitliche Sicht auf Ihre Kund:innen und können First-Party-Daten aktivieren, um die Werbewirkung zu verbessern.

### Cloudinary – Dynamischer Content {#cloudinary-dynamic-content}

[Cloudinary]({{site.baseurl}}/partners/cloudinary) ist eine Bild- und Video-Plattform, mit der Sie Bilder und Videos in großem Umfang verwalten, bearbeiten, optimieren und über beliebige Campaigns, Kanäle und Customer Journeys hinweg bereitstellen können. Wenn Cloudinary integriert und aktiviert ist, unterstützt das Medienmanagement die dynamische, kontextuelle und personalisierte Bereitstellung von Assets für Ihre Braze-Campaigns und Canvases.

### Kameleoon – A/B-Tests {#kameleoon-ab-testing}

[Kameleoon]({{site.baseurl}}/partners/kameleoon) ist eine Optimierungslösung mit Funktionen für Experimente, KI-gestützte Personalisierung und Feature-Management – vereint auf einer einzigen Plattform.

## SDK-Aktualisierungen {#sdk-updates}

Die neuesten SDK-Aktualisierungen wurden veröffentlicht. Wichtige Änderungen sind im Abschnitt SDK-Aktualisierungen aufgeführt; alle weiteren Aktualisierungen finden Sie in den entsprechenden SDK-Changelogs.

- [React Native SDK 18.0.0](https://github.com/braze-inc/braze-react-native-sdk/blob/16.1.0/CHANGELOG.md)
    - Behebt den Typescript-Typ für den Callback von `subscribeToInAppMessage` und `addListener` für `Braze.Events.IN_APP_MESSAGE_RECEIVED`.
        - Diese Listener geben jetzt ordnungsgemäß einen Callback mit dem neuen Typ `InAppMessageEvent` zurück. Zuvor waren die Methoden so annotiert, dass sie einen `BrazeInAppMessage`-Typ zurückgaben, aber tatsächlich wurde ein `String` zurückgegeben.
         - Wenn Sie eine der Abo-APIs verwenden, stellen Sie sicher, dass das Verhalten Ihrer In-App-Nachrichten nach dem Update auf diese Version unverändert bleibt. Sehen Sie sich unseren Beispielcode in `BrazeProject.tsx` an.
    - Die APIs `logInAppMessageClicked`, `logInAppMessageImpression` und `logInAppMessageButtonClicked` akzeptieren jetzt nur noch ein `BrazeInAppMessage`-Objekt, um der bestehenden öffentlichen Schnittstelle zu entsprechen.
        - Zuvor wurden sowohl ein `BrazeInAppMessage`-Objekt als auch ein `String` akzeptiert.
    - `BrazeInAppMessage.toString()` gibt jetzt einen lesbaren String anstelle der JSON-String-Darstellung zurück.
        - Um die JSON-String-Darstellung einer In-App-Nachricht zu erhalten, verwenden Sie `BrazeInAppMessage.inAppMessageJsonString`.
    - Unter iOS wurde `[[BrazeReactUtils sharedInstance] formatPushPayload:withLaunchOptions:]` nach `[BrazeReactDataTranslator formatPushPayload:withLaunchOptions:]` verschoben.
        - Diese neue Methode ist jetzt eine Klassenmethode statt einer Instanzmethode.
    - Fügt Nullability-Annotationen zu `BrazeReactUtils`-Methoden hinzu.
    - Entfernt die folgenden veralteten Methoden und Eigenschaften aus der API:
        - `getInstallTrackingId(callback:)` zugunsten von `getDeviceId`.
        - `registerAndroidPushToken(token:)` zugunsten von `registerPushToken`.
        - `setGoogleAdvertisingId(googleAdvertisingId:adTrackingEnabled:)` zugunsten von `setAdTrackingEnabled`.
        - `PushNotificationEvent.push_event_type` zugunsten von `payload_type`.
        - `PushNotificationEvent.deeplink` zugunsten von `url`.
        - `PushNotificationEvent.content_text` zugunsten von `body`.
        - `PushNotificationEvent.raw_android_push_data` zugunsten von `android`.
        - `PushNotificationEvent.kvp_data` zugunsten von `braze_properties`.
