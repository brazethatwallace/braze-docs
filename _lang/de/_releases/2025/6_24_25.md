## Flexibilität der Daten {#data-flexibility}

### SAML Just-in-Time-Bereitstellung {#saml-just-in-time-provisioning}

{% multi_lang_include release_type.md release="General availability" %}

Verwenden Sie die [SAML Just-in-Time-Bereitstellung]({{site.baseurl}}/user_guide/administer/global/saml_single_sign_on/saml_just_in_time_provisioning), damit neue Unternehmensnutzer:innen bei ihrer ersten Anmeldung ein Braze-Konto erstellen können. Dadurch müssen Administratoren nicht mehr manuell ein Konto für neue Unternehmensnutzer:innen erstellen, deren Berechtigungen auswählen, sie einem Workspace zuweisen und darauf warten, dass sie ihr Konto aktivieren.

### Filter pro Auswahl {#filters-per-selection}

Sie können jetzt bis zu 10 Filter pro [Auswahl]({{site.baseurl}}/user_guide/data/activation/catalogs/selections) hinzufügen.

### Katalogspeicher {#catalog-storage}

Die Speichergröße für die kostenlose Version der [Kataloge]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog#catalog-storage) beträgt bis zu 100&nbsp;MB. Sie können eine unbegrenzte Anzahl von Artikeln haben, solange sie unter 100&nbsp;MB bleiben.

### Anzahl der mit der Cloud-Datenaufnahme synchronisierten Zeilen {#number-of-rows-synced-with-cloud-data-ingestion}

Standardmäßig können bei der Cloud-Datenaufnahme pro Lauf bis zu 500 Millionen Zeilen synchronisiert werden. Alle Synchronisierungen mit mehr als 500 Millionen neuen Zeilen werden gestoppt.

Weitere Informationen finden Sie unter [Produkteinschränkungen der Cloud-Datenaufnahme]({{site.baseurl}}/user_guide/data/cloud_ingestion/overview#product-limitations).

## Robuste Kanäle {#robust-channels}

### Barrierefreiheitstests in Inbox Vision {#accessibility-testing-in-inbox-vision}

{% multi_lang_include release_type.md release="General availability" %}

Verwenden Sie die [Barrierefreiheitstests]({{site.baseurl}}/user_guide/message_building_by_channel/email/inbox_vision#accessibility-testing) in Inbox Vision, um Barrierefreiheitsprobleme in Ihren E-Mails aufzuzeigen.

Bei den Barrierefreiheitstests wird Ihr E-Mail-Inhalt anhand einiger Anforderungen der [Web Content Accessibility Guidelines](https://www.w3.org/WAI/standards-guidelines/wcag/) (WCAG) 2.2 AA analysiert. Dies kann Insights darüber liefern, welche Elemente nicht den Barrierefreiheitsstandards entsprechen.

### Klick-Tracking für WhatsApp {#click-tracking-for-whatsapp}

{% multi_lang_include release_type.md release="General availability" %}

Sie können das [Klick-Tracking]({{site.baseurl}}/user_guide/channels/whatsapp/message_features_and_optimization/click_tracking) sowohl in Antwort- als auch in Template-Nachrichten aktivieren, um Klickdaten in Ihren WhatsApp-Performance-Berichten zu sehen und Nutzer:innen danach segmentieren zu können, worauf sie geklickt haben.

### Videos für WhatsApp {#videos-for-whatsapp}

{% multi_lang_include release_type.md release="General availability" %}

Sie können [Videos einbetten]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/create#supported-whatsapp-features), die im Textkörper ausgehender WhatsApp-Nachrichten angezeigt werden. Diese Dateien müssen über eine URL oder in der [Braze-Medienbibliothek]({{site.baseurl}}/user_guide/messaging/design_and_edit/media_library/image_specifications) gehostet werden.
