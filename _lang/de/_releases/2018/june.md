# Juni 2018 {#june-2018}

## Passwortwiederverwendung {#password-reusability}

Administratoren können jetzt die Mindestanzahl neuer, eindeutiger Passwörter festlegen, die andere Unternehmensnutzer:innen in ihrem Unternehmen verwenden müssen, bevor sie ein früheres Passwort wieder verwenden können. Dies kann über das Panel [Authentifizierungsregeln]({{site.baseurl}}/user_guide/onboarding/platform_administrative_features/#authentication-rules) in den **Unternehmenseinstellungen** auf dem Tab **Sicherheitseinstellungen** gesteuert werden.

## Uninstall-Tracking für Canvas-Schritte {#uninstall-tracking-for-canvas-steps}

Deinstallationen pro Canvas-Schritt werden jetzt getrackt und können in den Canvas-Analysen als Kennzahl eingesehen werden.
