# Release vom 20. August 2026 {#august-20-2026-release}

## Daten und Berichterstattung {#data-reporting}

### Cloud-Datenaufnahme – SQL-Editor {#cloud-data-ingestion-sql-editor}

{% multi_lang_include release_type.md release="General availability" %}

Mit dem [SQL-Editor]({{site.baseurl}}/user_guide/data/unification/cloud_ingestion/sql_editor) können Sie Cloud-Datenaufnahme-Syncs (CDI-Syncs) erstellen und bearbeiten, indem Sie eine SQL-Abfrage gegen eine beliebige Tabelle oder Ansicht in Ihrem Data Warehouse schreiben – anstatt eine dedizierte Braze-spezifische Tabelle zu erstellen und zu pflegen. Er ist für alle Sync-Datentypen über alle CDI-Data-Warehouse-Quellen hinweg verfügbar: Snowflake, Redshift, BigQuery, Databricks und Fabric.

### Cloud-Datenaufnahme – visueller Mapper {#cloud-data-ingestion-visual-mapper}

{% multi_lang_include release_type.md release="Beta" %}

Mit dem [visuellen Mapper]({{site.baseurl}}/user_guide/data/unification/cloud_ingestion/visual_mapper) können Sie einen Cloud-Datenaufnahme-Sync (CDI-Sync) erstellen, indem Sie die Spalten einer vorhandenen Data-Warehouse-Tabelle direkt im Dashboard Braze-Feldern zuordnen – ohne SQL oder eine dedizierte Tabelle. Diese Beta-Version unterstützt Nutzerattribut-Syncs über alle CDI-Data-Warehouse-Quellen hinweg. Der visuelle Mapper und der SQL-Editor ergänzen sich: Verwenden Sie den visuellen Mapper für die direkte Spalte-zu-Feld-Zuordnung und den SQL-Editor für fortgeschrittene Fälle wie Transformationen, Joins und bedingte Logik.

### Cloud-Datenaufnahme für Google Cloud Storage und Azure Blob Storage {#cloud-data-ingestion-for-google-cloud-storage-and-azure-blob-storage}

{% multi_lang_include release_type.md release="General availability" %}

Die Cloud-Datenaufnahme (CDI) unterstützt zwei neue Dateispeicherquellen: Google Cloud Storage, ab sofort allgemein verfügbar, und Azure Blob Storage, verfügbar ab der Woche vom 31. August 2026. Beide Quellen funktionieren wie die bestehende Amazon-S3-Quelle – Braze nimmt Dateien auf, sobald sie in den Bucket oder Container geschrieben werden – sodass Kund:innen auf Google Cloud oder Azure die gleiche Geschwindigkeit und Zuverlässigkeit erhalten, ohne Dateien nach S3 zu replizieren oder eine benutzerdefinierte Integration zu erstellen.

### Cloud-Datenaufnahme für BrazeAI Decisioning Studio {#cloud-data-ingestion-to-brazeai-decisioning-studio}

{% multi_lang_include release_type.md release="Early access" %}

Die Cloud-Datenaufnahme (CDI) kann jetzt Data-Warehouse-Daten direkt mit BrazeAI Decisioning Studio synchronisieren – für Kund:innen, die beide Produkte nutzen. So können Sie Daten über Ihren Braze-Workspace hinaus für Reinforcement Learning und KI-gestützte Entscheidungsfindung einbringen, ohne benutzerdefinierte ETL-Jobs erstellen zu müssen. Diese Early-Access-Version unterstützt Snowflake-Quellen; weitere Data-Warehouse-Quellen folgen in Kürze.

## BrazeAI<sup>TM</sup>

### Operator kann für Sie im Dashboard navigieren {#operator-can-navigate-the-dashboard-for-you}

{% multi_lang_include release_type.md release="General availability" %}

[Operator]({{site.baseurl}}/user_guide/brazeai/operator/capabilities#navigate-the-dashboard) kann zu einer anderen Dashboard-Seite navigieren, um Ihre Anfrage zu bearbeiten. Wenn ein Prompt einen anderen Bereich des Dashboards erfordert, identifiziert Operator das Ziel, schlägt die Navigation vor und bringt Sie dorthin, bevor er seine Arbeit fortsetzt.

So kann Operator mehrstufige Aufgaben aus einem einzigen Prompt heraus verketten. Wenn Sie Operator beispielsweise von der Startseite aus bitten, Ihre Drag-and-Drop-Editor-Einstellungen an Ihre Markenrichtlinien anzupassen, navigiert er Sie zu den entsprechenden E-Mail-Einstellungen und hilft Ihnen von dort aus weiter.

Standardmäßig bittet Operator Sie, eine vorgeschlagene Navigation zu genehmigen, bevor er Sie auf eine neue Seite bringt. Um Operator ohne jedes Mal Ihre Genehmigung abzuwarten navigieren zu lassen, aktivieren Sie [Aktionen automatisch genehmigen]({{site.baseurl}}/user_guide/brazeai/operator/reviewing_actions#auto-approve-actions).

### Operator kann auf weiteren Dashboard-Seiten agieren {#operator-can-act-on-more-dashboard-pages}

{% multi_lang_include release_type.md release="General availability" %}

[Operator]({{site.baseurl}}/user_guide/brazeai/operator/capabilities) kann Aufgaben auf zusätzlichen Dashboard-Seiten erledigen, wenn Sie das gewünschte Ergebnis in natürlicher Sprache beschreiben. Beispiele umfassen das Erstellen von Berichten und Dashboards, das Arbeiten mit E-Mail-Template- und Content-Block-Listenseiten, das Importieren oder Verwalten von Nutzer:innen, das Erstellen von Prognosen sowie das Aktualisieren weiterer Admin- und Einstellungsoberflächen.

Bitten Sie Operator beispielsweise auf der Berichts-Builder-Seite, einen Bericht zu erstellen, der das SMS-Engagement des Workspace über die letzten 30 Tage zeigt.

Eine repräsentative Übersicht finden Sie unter [Was Sie mit Operator tun können]({{site.baseurl}}/user_guide/brazeai/operator/capabilities). Fragen Sie Operator auf der Seite, auf der Sie sich befinden, für die aktuellste Antwort.

### Operator kann Canvases erstellen und bearbeiten {#operator-can-create-and-edit-canvases}

{% multi_lang_include release_type.md release="General availability" %}

[Operator]({{site.baseurl}}/user_guide/brazeai/operator/capabilities) kann einen Canvas-Entwurf aus einer Beschreibung in natürlicher Sprache erstellen und einen bestehenden Canvas auf die gleiche Weise bearbeiten. Beschreiben Sie die gewünschte Journey – Eintrittskriterien, Verzögerungen und Nachrichten – und Operator erstellt einen Entwurf, den Sie überprüfen und verfeinern, bevor Sie ihn starten.

Bitten Sie Operator beispielsweise, eine Warenkorb-Abbruch-Journey zu erstellen, die eine Stunde nach dem Warenkorb-Abbruch wartet, eine E-Mail-Erinnerung sendet und dann nach 24 Stunden eine Push-Benachrichtigung, falls die Nutzer:innen noch nicht gekauft haben.

Informationen zu unterstützten Schritten und Einschränkungen finden Sie unter [Was Sie mit Operator tun können]({{site.baseurl}}/user_guide/brazeai/operator/capabilities).

### Aktualisierungen des Content-Optimizer-Schritts {#content-optimizer-step-updates}

{% multi_lang_include release_type.md release="Beta" %}

Der [Content-Optimizer]({{site.baseurl}}/user_guide/brazeai/content_optimizer)-Schritt enthält die folgenden Aktualisierungen:

- **Schrittstatus:** Content-Optimizer-Schritte zeigen an, ob sie sich im Status **Learning**, **Optimizing** oder **Action Recommended** befinden, sodass Sie den Stand jedes Schritts sehen können.
- **Prüfungen vor dem Start:** Der Content-Optimizer prüft während der Entwurfsphase auf wichtige Fehlkonfigurationen, damit Sie Probleme erkennen können, bevor Sie starten.
- **Nachverfolgen, welche Kombination jede:r Nutzer:in erhalten hat:** Ein neuer Liquid-Tag und die Sichtbarkeit im Nutzerprofil ermöglichen es Ihnen, durchgängig nachzuverfolgen, welche Variantenkombination jede:r Nutzer:in erhalten hat.
- **Neue Currents-Daten:** Drei neue Ereignistypen ermöglichen es Ihnen, Content-Optimizer-Daten in Ihr Warehouse zu übertragen: `users.canvas.costep.Send`, `users.canvas.costep.Conversion` und `contentoptimizer.ComponentStore`.

Einzelheiten zur Einrichtung finden Sie unter [Content-Optimizer-Schritt]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/content_optimizer_step).

## Orchestrierung {#orchestration}

### Workspace-Ruhezeiten {#workspace-quiet-hours}

{% multi_lang_include release_type.md release="Early access" %}

[Workspace-Ruhezeiten]({{site.baseurl}}/user_guide/messaging/messaging_fundamentals/quiet_hours/workspace_quiet_hours) ermöglichen es Ihnen, ein Standard-Ruhezeitfenster für einen Messaging-Kanal über Ihren gesamten Workspace hinweg festzulegen. Jede Campaign und jeder Canvas auf diesem Kanal respektiert das Fenster in der jeweiligen Ortszeit der Empfänger:innen. Sie können den Workspace-Standard beibehalten oder sich abmelden und stattdessen ein Campaign- oder Canvas-spezifisches Fenster anwenden.

Nachrichten, die während des Fensters gesendet würden, werden für eine spätere Zustellung zurückgehalten oder abgebrochen, je nach Campaign-Typ. Workspace-Ruhezeiten ändern niemals den Nachrichteninhalt.

### Canvas-Schwellenwert-Benachrichtigungen {#canvas-threshold-alerts}

{% multi_lang_include release_type.md release="Early access" %}

[Canvas-Schwellenwert-Benachrichtigungen]({{site.baseurl}}/user_guide/messaging/canvas/managing_canvases/canvas_threshold_alerts) informieren Sie, wenn Nutzereintritte oder gesendete Nachrichten außerhalb des erwarteten Volumens liegen. Legen Sie einen Schwellenwert fest, wählen Sie, wie oft Braze ihn prüft (alle 3 bis 12 Stunden oder alle 24 Stunden), und lassen Sie sich per E-Mail, Webhook oder beidem benachrichtigen, wenn eine Regel erfüllt ist. Sie können mehrere Benachrichtigungen für denselben Canvas erstellen, auch für Entwürfe – die Benachrichtigung beginnt mit der Prüfung, nachdem der Canvas gestartet wurde.

### Automatische Team-Zuweisung {#automatic-team-assignment}

{% multi_lang_include release_type.md release="General availability" %}

Für Nutzer:innen mit ausschließlich Team-Berechtigungen kann Braze ein [Team]({{site.baseurl}}/user_guide/administer/global/user_management/teams#automatic-team-assignment) während der Objekterstellung automatisch zuweisen.

## Kanäle und Touchpoints {#channels-touchpoints}

### Connected-Content-Debugger

{% multi_lang_include release_type.md release="Early access" %}

Der [Connected-Content-Debugger]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content/debugger) zeigt die Live-Anfrage und -Antwort für jeden Connected-Content-Aufruf in **Vorschau und Test** an, sodass Sie Ihren Endpunkt, Header und Liquid-Tags überprüfen können, bevor Sie eine Campaign oder einen Canvas starten. Öffnen Sie **Details anzeigen**, um URL, Methode, Statuscode, Anfrage- und Antwort-Header, Payload, Dauer und ob die Antwort aus dem Cache bereitgestellt wurde, zu inspizieren.

Während des Early Access ist der Debugger für Content Cards, E-Mail, In-App Messages, Push, SMS/MMS/RCS, Webhooks und WhatsApp verfügbar.

### Verbesserungen am WhatsApp-Template-Builder {#whatsapp-template-builder-improvements}

{% multi_lang_include release_type.md release="General availability" %}

Der [WhatsApp-Template-Builder]({{site.baseurl}}/user_guide/channels/whatsapp/message_features_and_optimization/template_builder) unterstützt mehr Erstellungspfade und Template-Optionen:

- **Templates beim Erstellen von Campaigns und Canvases anlegen:** Erstellen Sie ein neues WhatsApp-Template direkt im Composer, anstatt nur vorhandene Templates aus dem Content-Bereich auszuwählen.
- **Karussell-Antwortnachrichten:** Erstellen Sie Karussell-Layouts als Antwortnachrichten, nicht nur als ausgehende Templates.
- **Neue Template-Typen: Utility und Flow:** Der Template-Builder unterstützt Utility-Templates und Flow-Templates, auch wenn Sie Templates aus Campaigns, Canvases oder der eigenständigen Content-Templates-Oberfläche erstellen.

## Partnerschaften {#partnerships}

### Audience Sync: Google Data Manager API

{% multi_lang_include release_type.md release="Early access" %}

### Amazon Bedrock – KI-Modellanbieter {#amazon-bedrock-ai-model-provider}

[Amazon Bedrock](https://aws.amazon.com/bedrock/) ist ein vollständig verwalteter AWS-Dienst, der über eine einheitliche API Zugang zu Foundation-Modellen führender KI-Unternehmen bietet, sodass Marken generative KI-Anwendungen auf AWS erstellen und skalieren können.

Weitere Informationen finden Sie unter [Amazon Bedrock]({{site.baseurl}}/partners/amazon_bedrock).

### Bynder – Nachrichtenorchestrierung – CMS und DAM {#bynder-message-orchestration-cms-and-dam}

[Bynder](https://www.bynder.com) ist eine Digital-Asset-Management-Plattform (DAM), die Kund:innen dabei hilft, genehmigte digitale Assets (Bilder, Videos und andere Kreativmaterialien) aus einer einzigen Quelle der Wahrheit zu erstellen, zu verwalten, zu finden und zu verteilen. In Kombination mit Braze ermöglicht die Universal Compact View (UCV) Google-Chrome-Erweiterung von Bynder Marketern, Bynder-Assets zu suchen und auszuwählen, ohne das Braze-Dashboard zu verlassen. Fügen Sie Links zu diesen Assets direkt in Campaigns und Canvases ein.

Weitere Informationen finden Sie unter [Bynder]({{site.baseurl}}/partners/bynder).

### Multiplied Media – Nachrichtenpersonalisierung – visuelle und interaktive Inhalte {#multiplied-media-message-personalization-visual-and-interactive-content}

[Multiplied Media](https://multiplied.media) ist ein Kreativ- und Automatisierungsstudio, das Ihre CRM-Daten nutzt, um personalisierte Bilder, GIFs und Videos zu erstellen – ein einzigartiges Asset für jede:n Kund:in. Die Integration von Multiplied Media und Braze ermöglicht es Ihnen, diese Medien über E-Mail, Push-Benachrichtigungen, In-App-Nachrichten, Content Cards und WhatsApp zu versenden.

Weitere Informationen finden Sie unter [Multiplied Media]({{site.baseurl}}/partners/multiplied_media).
