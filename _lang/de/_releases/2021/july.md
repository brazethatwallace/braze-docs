# Juli 2021 {#july-2021}

## Einfache Umfrage als In-App-Nachricht {#simple-survey-in-app-message}

Nutzen Sie das [Template für einfache Umfragen in In-App-Nachrichten]({{site.baseurl}}/user_guide/channels/in_app_messages/message_types/simple_survey), um Nutzer:innen-Attribute, Insights und Präferenzen zu sammeln, die Ihre Campaign-Strategie unterstützen. Sie können die Nutzer:innen zum Beispiel fragen, wie sie Ihre App nutzen möchten, mehr über ihre persönlichen Vorlieben erfahren oder sogar nach ihrer Zufriedenheit mit einem bestimmten Feature fragen. Dieses Umfrage-Template wird sowohl für mobile Apps als auch für Webbrowser unterstützt.

## Liquid-Bibliothek für Anwendungsfälle {#liquid-use-case-library}

Sie fragen sich, wie Sie diese eine Sache mit Liquid erledigen können? Suchen Sie einfach nur nach Inspiration? In unserer [Liquid-Bibliothek für Anwendungsfälle]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid/liquid_use_cases) finden Sie eine Sammlung von Anwendungsfällen, die von Jahrestagen und Geburtstagen bis hin zum Plattform-Targeting und mehr reichen.

## E-Mail-Tracking {#email-tracking}

Das Open-Pixel-Tracking und das Klick-Tracking kann jetzt pro Kundenprofil deaktiviert werden. Diese Flexibilität hilft Kund:innen, regionale Datenschutzgesetze einzuhalten, bei denen ein individuelles Kundenprofil angeben kann, dass es nicht mehr getrackt werden möchte. Lesen Sie unseren Artikel über [Open-Pixel- und Klick-Tracking]({{site.baseurl}}/user_guide/channels/email/email_setup/open_pixel_and_click_tracking), um mehr zu erfahren.

## Amplitude-Kundenprofil-API-Endpunkte {#amplitude-user-profile-api-endpoints}

Die Kundenprofil API von Amplitude stellt Amplitude-Nutzer:innen-Profile bereit. Dazu gehören Nutzereigenschaften, berechnete Nutzereigenschaften, eine Liste der Kohorten-IDs von Kohorten, die die Nutzer:innen enthalten, und Empfehlungen. Weitere Informationen finden Sie unter [Amplitude-Kundenprofil-API-Endpunkte]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/amplitude/amplitude_user_profile_api).

## Endpunkt für Campaign-Details {#campaign-details-endpoint}

Der [Endpunkt `/campaigns/details`]({{site.baseurl}}/api/endpoints/export/campaigns/get_campaign_details) enthält jetzt eine eigene `message`-Antwort für den In-App-Nachricht-Kanal. Die Dokumentation dazu finden Sie unter [Nachrichten nach Kanal]({{site.baseurl}}/api/endpoints/export/campaigns/get_campaign_details#messages-by-channel).
