# Veröffentlichung 20. September 2022 {#september-20-2022-release}

## API-Leitfaden {#api-guide}
Schauen Sie sich den [Braze API Guide]({{site.baseurl}}/api/home) an, um nach Endpunkten auf der Grundlage von Endpunkttypen zu suchen und so das Glossar einzugrenzen.

## Personalisierte Varianten {#personalized-variants}
Verwenden Sie [personalisierte Varianten]({{site.baseurl}}/user_guide/messaging/ab_testing/optimizations), um allen Nutzer:innen in Ihrem Zielsegment die Variante zu senden, mit der sie sich am ehesten beschäftigen werden.

## Canvases testen {#testing-canvases}
Nachdem Sie Ihr Canvas erstellt haben, gibt es mehrere Überprüfungen, die Sie vor dem Start durchführen sollten – abhängig von Details wie der Größe Ihrer Zielgruppe oder der Anzahl der Segmentierungs-Filter. Tipps finden Sie unter [Test-Canvases versenden]({{site.baseurl}}/user_guide/messaging/canvas/testing_canvases/sending_test_canvases).

## Liquid 5
Für bestehende Unternehmensnutzer:innen ist Liquid 5 allgemein verfügbar. Erfahren Sie mehr über die [Neuerungen in Liquid 5]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/liquid#whats-new-with-liquid-5).

## Neue Braze-Partnerschaften {#new-braze-partnerships}

### Shopify
Die Integration von Braze und [Shopify]({{site.baseurl}}/partners/shopify) ermöglicht es Ihnen, bestehende Nutzerprofile zu aktualisieren oder neue Profile in Braze zu erstellen – für Leads, Registrierungen und Kontoerstellungen, die in Ihrem Shopify-Shop erfasst werden.

## SDK-Updates

Die folgenden SDK-Updates wurden veröffentlicht. Wichtige Änderungen sind im Abschnitt „SDK-Updates“ aufgeführt; alle weiteren Updates finden Sie in den entsprechenden SDK-Changelogs.

- [Android SDK 23.1.0–23.12](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [React Native SDK v1.38.0–v1.38.1](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - Die native Android-Bridge wurde auf Braze Android SDK 23.0.1 aktualisiert.
  - Die native iOS-Bridge wurde auf Braze iOS SDK 4.5.0 aktualisiert.
  - Das Braze React Native Android SDK benötigt jetzt Kotlin direkt zur Kompilierung.
- [Braze Expo Plugin 0.4.0](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - Die Eigenschaft `fcmSenderID` wurde in `firebaseCloudMessagingSenderId` umbenannt.
- [Unity 3.9.0](https://github.com/Appboy/appboy-unity-sdk/blob/master/CHANGELOG.md)
  - Das Android-Plugin wurde auf Braze Android SDK 23.1.0 aktualisiert.
  - Es wurde die Möglichkeit hinzugefügt, Push-Benachrichtigungsberechtigungen auf Android-13+-Geräten über `Appboy.AppboyBinding.PromptUserForPushPermissions(false)` anzufordern.
- [Swift SDK 5.3.0–5.4.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#540)
