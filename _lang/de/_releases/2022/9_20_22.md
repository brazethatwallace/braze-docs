# Veröffentlichung 20. September 2022 {#september-20-2022-release}

## API-Leitfaden {#api-guide}
Sehen Sie sich den [Braze API-Leitfaden]({{site.baseurl}}/api/home) an, um Endpunkte nach Endpunkttypen zu durchsuchen und so die Übersicht gezielt einzugrenzen.

## Personalisierte Varianten {#personalized-variants}
Verwenden Sie [Personalisierte Varianten]({{site.baseurl}}/user_guide/messaging/ab_testing/optimizations), um jeder Nutzer:in in Ihrem Zielsegment die Variante zu senden, mit der sie sich am wahrscheinlichsten beschäftigen wird.

## Canvases testen {#testing-canvases}
Nachdem Sie Ihren Canvas erstellt haben, sollten Sie vor dem Start je nach Details wie Ihrer Zielgruppengröße oder der Anzahl der Segmentierungsfilter verschiedene Prüfungen durchführen. Tipps finden Sie unter [Test-Canvases senden]({{site.baseurl}}/user_guide/messaging/canvas/testing_canvases/sending_test_canvases).

## Liquid 5
Für bestehende Unternehmensnutzer:innen ist Liquid 5 allgemein verfügbar. Erfahren Sie mehr über die [Neuerungen in Liquid 5]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/liquid#liquid-5-support).

## Neue Braze-Partnerschaften {#new-braze-partnerships}

### Shopify
Die Integration von Braze und [Shopify]({{site.baseurl}}/partners/shopify) ermöglicht es Ihnen, bestehende Nutzerprofile in Braze zu aktualisieren oder neue zu erstellen – für Leads, Registrierungen und Kontoanmeldungen, die in Ihrem Shopify-Shop erfasst werden.

## SDK-Aktualisierungen {#sdk-updates}

Die neuesten SDK-Aktualisierungen wurden veröffentlicht. Nicht abwärtskompatible Änderungen sind im Abschnitt SDK-Aktualisierungen aufgeführt; alle weiteren Aktualisierungen finden Sie in den entsprechenden SDK-Changelogs.

- [Android SDK 23.1.0–23.12](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md)
- [React Native SDK v1.38.0–v1.38.1](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - Die native Android-Bridge wurde auf Braze Android SDK 23.0.1 aktualisiert.
  - Die native iOS-Bridge wurde auf Braze iOS SDK 4.5.0 aktualisiert.
  - Das Braze React Native Android SDK erfordert jetzt Kotlin direkt für die Kompilierung.
- [Braze Expo Plugin 0.4.0](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
  - Die Eigenschaft `fcmSenderID` wurde in `firebaseCloudMessagingSenderId` umbenannt.
- [Unity 3.9.0](https://github.com/Appboy/appboy-unity-sdk/blob/master/CHANGELOG.md)
  - Das Android-Plugin wurde aktualisiert, um Braze Android SDK 23.1.0 zu verwenden.
  - Die Möglichkeit wurde hinzugefügt, Push-Benachrichtigungsberechtigungen auf Android-13+-Geräten über `Appboy.AppboyBinding.PromptUserForPushPermissions(false)` anzufordern.
- [SWIFT SDK 5.3.0–5.4.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#540)
