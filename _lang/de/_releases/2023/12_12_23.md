# Release vom 12. Dezember 2023 {#december-12-2023-release}

## Aktualisierungen der Android-Push-Integration {#updates-to-android-push-integration}

Am 20. Juni 2023 hat Google seine Cloud Messaging API zum Senden von Push-Benachrichtigungen an Android-Apps eingestellt. Die [Standard-Android-Push-Integration]({{site.baseurl}}/developer_guide/push_notifications?sdktab=android) zeigt Ihnen jetzt, wie Sie stattdessen Googles Firebase Cloud Messaging API einrichten.

Weitere Informationen zur Einstellung der Cloud Messaging API von Google finden Sie in den [Firebase FAQ](https://firebase.google.com/support/faq#fcm-23-deprecation).

## Robuste Kanäle {#robust-channels}

### WhatsApp-Antwortnachrichten {#whatsapp-response-messaging}

{% multi_lang_include release_type.md release="General availability" %}

Wenn Sie eine [WhatsApp-Nachricht erstellen]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/create#response-messages) in einer Campaign oder einem Canvas, können Sie Antwortnachrichten einrichten, um innerhalb eines 24-Stunden-Fensters auf WhatsApp-Nachrichten von Nutzer:innen zu reagieren. Antwortnachrichten können besonders hilfreich in Canvases sein, die Interaktionen zwischen Ihrer Marke und ihren Nutzer:innen fördern, z. B. bei Opt-in-Campaigns.

### WhatsApp-Frequency-Capping

{% multi_lang_include release_type.md release="General availability" %}

Sie können jetzt [Frequency-Capping-Regeln]({{site.baseurl}}/user_guide/engagement_tools/campaigns/building_campaigns/rate-limiting#frequency-capping) für WhatsApp einrichten. Frequency-Capping wird auf der Sendeebene von Campaigns oder Canvas-Komponenten angewendet und kann für jeden Workspace unter **Einstellungen** > **Frequency-Capping-Regeln** konfiguriert werden.

## Datenflexibilität {#data-flexibility}

### Konversions-Dashboard {#conversions-dashboard}

{% multi_lang_include release_type.md release="General availability" %}

Das [Konversions-Dashboard]({{site.baseurl}}/user_guide/analytics/dashboards/conversions) ermöglicht es Ihnen, Konversionen über Campaigns, Canvases und Kanäle hinweg mithilfe verschiedener Attributionsmethoden zu analysieren. Bei der Messung Ihrer Konversionen können Sie den Zeitrahmen, das Konversions-Event und das Konversionsfenster festlegen.

### E-Mail-Insights-Berichte {#email-insights-reports}

{% multi_lang_include release_type.md release="General availability" %}

Es gibt einen neuen Tab „E-Mail-Insights“ im [E-Mail-Performance-Dashboard]({{site.baseurl}}/user_guide/data_and_analytics/analytics/email_performance_dashboard#email-insights-dashboard), der zwei neue Berichte enthält:

- **Engagement nach E-Mail-Anbietern:** Zeigt die Anzahl der Klicks und Öffnungen nach E-Mail-Anbieter an. Sie können einen E-Mail-Anbieter auswählen und die Aufschlüsselung nach bestimmten Empfangsdomains vornehmen.
- **Engagement nach Wochentag:** Zeigt, wann Nutzer:innen mit ihren E-Mails interagieren.

### Aktualisierung der Abo-Gruppen-Zeitreihengrafik {#update-to-subscription-group-timeseries-graph}

{% multi_lang_include release_type.md release="General availability" %}

Die Grafik **Abo-Gruppen-Zeitreihen**, die auf der Seite **Abo-Gruppen** angezeigt wird, zeigt jetzt die Abo-Anzahl pro Nutzer:in statt pro E-Mail oder Telefonnummer an. Dies entspricht besser der Art und Weise, wie Braze Statistiken in anderen Bereichen des Dashboards berechnet.

## KI- und ML-Automatisierung {#ai-ml-automation}

### KI-Artikelempfehlungen {#ai-item-recommendations}

{% multi_lang_include release_type.md release="General availability" %}

[KI-Artikelempfehlungen]({{site.baseurl}}/user_guide/brazeai/item_recommendations/creating_recommendations/ai) ist ein auf Deep Learning basierendes Produktempfehlungssystem, das das kollektive Kaufverhalten von Nutzer:innen nutzt, um Artikel zu empfehlen. Sie können KI-Artikelempfehlungen verwenden, um die beliebtesten Produkte zu berechnen oder personalisierte KI-Empfehlungen für einen bestimmten Katalog zu erstellen. Nachdem Sie Ihre Empfehlung erstellt haben, können Sie mithilfe von Personalisierung diese Produkte in Ihre Nachrichten einfügen.

## Neue Braze-Partnerschaften {#new-braze-partnerships}

### Facebook Lead Ads über Zapier – Leads Capture {#facebook-lead-ads-via-zapier-leads-capture}

Mit der [Facebook Lead Ads-Integration über Zapier]({{site.baseurl}}/partners/data_and_analytics/leads_capture/facebook_via_zapier) können Sie Ihre Leads aus Facebook in Braze importieren und ein angepasstes Event tracken, wenn Leads erfasst werden.

### SmarterSends – Nachrichten-Templates {#smartersends-message-templates}

Die Partnerschaft zwischen Braze und [SmarterSends]({{site.baseurl}}/partners/message_orchestration/templates/smartersends) ermöglicht es Ihnen, die Leistungsfähigkeit von Braze mit den hyperlokalisierten Inhalten Ihrer verteilten Nutzer:innen zu kombinieren, um Ihre Marketing-Campaigns auf ein neues Niveau zu heben.

### Recurly – Zahlungen {#recurly-payments}

Die Integration von [Recurly]({{site.baseurl}}/partners/ecommerce/ordering_payments_subscription/recurly) und Braze vereinfacht den Prozess der gemeinsamen Nutzung von Abo-Daten mit Braze und ermöglicht eine gezielte Kommunikation mit Kund:innen.

## SDK-Updates

Die neuesten SDK-Updates wurden veröffentlicht. Wichtige Änderungen sind im Abschnitt „SDK-Updates“ aufgeführt; alle weiteren Updates finden Sie in den entsprechenden SDK-Changelogs.

- [Flutter SDK 8.0.0–8.1.0](https://pub.dev/packages/braze_plugin/changelog)
  - Aktualisiert die native Android-Bridge von Braze Android SDK 27.0.1 auf 29.0.1.
  - Aktualisiert die native iOS-Bridge von Braze SWIFT SDK 6.6.1 auf 7.2.0.
  - Ändert das Verhalten der Feature-Flag-Methoden.
    - `BrazePlugin.getFeatureFlagByID(String id)` gibt jetzt `null` zurück, wenn das Feature-Flag nicht existiert.
    - `BrazePlugin.subscribeToFeatureFlags(void Function(List<BrazeFeatureFlag>) onEvent))` wird nur in den folgenden Situationen ausgelöst:
      - Wenn eine Aktualisierungsanfrage erfolgreich oder mit einem Fehler abgeschlossen wird.
      - Bei der erstmaligen registrieren, wenn zuvor zwischengespeicherte Daten aus der aktuellen Sitzung vorhanden waren.
  - Die minimal unterstützte Android-SDK-Version ist 21.
