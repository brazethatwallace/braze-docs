# Veröffentlichung am 17. September 2024 {#september-17-2024-release}

## Datenflexibilität {#data-flexibility}

### Braze Cloud-Datenaufnahme für S3 {#braze-cloud-data-ingestion-for-s3}

Sie können die [Cloud-Datenaufnahme (CDI) für S3]({{site.baseurl}}/user_guide/data_and_analytics/cloud_ingestion/file_storage_integrations#aws-definitions) nutzen, um einen oder mehrere S3-Buckets in Ihrem AWS-Konto direkt mit Braze zu integrieren. Wenn neue Dateien in S3 veröffentlicht werden, wird eine Nachricht an SQS gesendet, und die Braze Cloud-Datenaufnahme nimmt diese neuen Dateien auf.

### Monatlich aktive Nutzer:innen CY 24-25 {#monthly-active-users-cy-24-25}

Für Kund:innen, die „Monthly Active Users - CY 24-25“ erworben haben, verwaltet Braze andere Rate-Limits für den `/users/track`-Endpunkt. Weitere Informationen finden Sie unter [POST: Nutzer:innen tracken]({{site.baseurl}}/api/endpoints/user_data/post_user_track#monthly-active-users-cy-24-25-universal-mau-web-mau-and-mobile-mau).

## Kreativität freisetzen {#unlocking-creativity}

### Katalog-Artikel mit Liquid als Template verwenden {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="Early access" %}

Verwenden Sie das `:rerender`-Flag in einem Liquid-Tag, um den [Liquid-Inhalt eines Katalog-Artikels zu rendern]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog#using-liquid). Wenn Sie beispielsweise den folgenden Liquid-Inhalt rendern:

{% raw %}
```liquid
Hi ${first_name}
{% catalog_items Messages greet_msg :rerender %}
{{ items[0].Welcome_Message }}
```
{% endraw %}

Wird Folgendes angezeigt:

{% raw %}
```
Hi Peter,
Welcome to our store, Peter!
```
{% endraw %}

## Robuste Kanäle {#robust-channels}

### WhatsApp-Antwortnachrichten {#whatsapp-response-messages}

{% multi_lang_include release_type.md release="General availability" %}

Sie können [Antwortnachrichten]({{site.baseurl}}/user_guide/channels/whatsapp/create_a_whatsapp_message#response-messages) verwenden, um auf eingehende WhatsApp-Nachrichten Ihrer Nutzer:innen zu antworten. Diese Nachrichten werden in der App auf Braze während Ihres Erstellungsprozesses erstellt und können jederzeit bearbeitet werden. Sie können Liquid verwenden, um die Sprache der Antwortnachricht den entsprechenden Nutzer:innen anzupassen.

### Canvas-Templates

{% multi_lang_include release_type.md release="General availability" %}

Erstellen Sie [Canvas-Templates]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates), um Ihr Messaging zu verfeinern, indem Sie ein konsistentes Framework erstellen, das leicht angepasst werden kann, um Ihre spezifischen Ziele über Ihre Canvase hinweg zu erreichen.

### Landing-Pages

{% multi_lang_include release_type.md release="Beta" %}

Braze [Landing-Pages]({{site.baseurl}}/user_guide/messaging/landing_pages) sind eigenständige Webseiten, die Ihre Strategie zur Nutzer:innengewinnung und zum Engagement vorantreiben können.

### Änderungen seit der letzten Ansicht {#changes-since-last-viewed}

Sie können die Anzahl der Aktualisierungen Ihrer [Canvase]({{site.baseurl}}/user_guide/engagement_tools/canvas/testing_canvases/measuring_and_testing_with_canvas_analytics#changes-since-last-viewed), Campaigns und [Segmente]({{site.baseurl}}/user_guide/engagement_tools/segments/managing_segments#changes-since-last-viewed) durch andere Mitglieder Ihres Teams einsehen, indem Sie sich auf die Metrik *Änderungen seit der letzten Ansicht* auf den jeweiligen Übersichtsseiten beziehen (z. B. die Übersichtsseite für eine [E-Mail-Campaign]({{site.baseurl}}/user_guide/channels/email/reporting#changes-since-last-viewed)).

### Fehlerbehebung bei Webhook- und Connected-Content-Anfragen {#troubleshooting-webhook-and-connected-content-requests}

[Fehlerbehebung bei Webhook- und Connected-Content-Anfragen]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content/troubleshooting_webhooks_and_connected_content) behandelt die Fehlerbehebung bei Webhook- und Connected-Content-Fehlercodes, einschließlich der Beschreibung der Fehler und der Schritte zu deren Behebung.

## Neue Braze-Partnerschaften {#new-braze-partnerships}

### Inbox Monster – Analytics

[Inbox Monster]({{site.baseurl}}/partners/data_and_analytics/analytics/inbox_monster) ist eine Inbox-Signals-Plattform, die Unternehmensmarken dabei unterstützt, bei jedem Versand den Posteingang zu erreichen. Es handelt sich um eine integrierte Suite von Lösungen für Zustellbarkeit, kreatives Rendering und Kurzmitteilungsdienst or SMS-Monitoring, die moderne CRM or Customer-Relationship-Management [-System] (CRM)-Teams unterstützt und Versandsorgen ein Ende bereitet.

### SessionM – Kundenbindung {#sessionm-loyalty}

[SessionM]({{site.baseurl}}/partners/data_and_analytics/loyalty/sessionm) ist eine Plattform für Customer-Engagement und Kundenbindung, die Features für das Campaign-Management und Lösungen für das Loyalty-Management bietet, um Marketer bei der gezielten Ansprache zu unterstützen und Engagement sowie Gewinn zu steigern.

## KI or künstliche Intelligenz- und ML-Automatisierung {#ai-and-ml-automation}

### Empfehlungen für Trend-Artikel {#trending-item-recommendations}

Zusätzlich zum Modell „KI or künstliche Intelligenz-personalisiert“ umfasst das Feature [KI or künstliche Intelligenz-Artikelempfehlungen]({{site.baseurl}}/user_guide/sage_ai/recommendations/about_item_recommendations#trending) auch ein Empfehlungsmodell für „Trending“, das Artikel hervorhebt, die bei den jüngsten Nutzer:innen-Interaktionen die stärkste positive Dynamik aufwiesen.

## Einstellungen {#settings}

### Rollen {#roles}

{% multi_lang_include release_type.md release="General availability" %}

[Rollen]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/user_permissions#creating-a-role) ermöglichen mehr Struktur, indem sie Ihre individuellen benutzerdefinierten Berechtigungen mit Workspace-Zugriffskontrollen bündeln. Dies ist besonders nützlich, wenn Sie viele Marken oder regionale Workspaces in einem Dashboard haben. Mit Rollen können Sie Dashboard-Nutzer:innen den entsprechenden Workspaces hinzufügen und ihnen direkt die zugehörigen Berechtigungen gewähren.

### Sicherheitsereignisbericht {#security-event-report}

Wir haben eine vollständige Liste der [Sicherheitsereignisse]({{site.baseurl}}/user_guide/administrative/app_settings/company_settings/security_settings#downloading-a-security-event-report) hinzugefügt, die in Ihrem heruntergeladenen Sicherheitsbericht erscheinen können.

### Nachrichtennutzungsbericht {#message-usage-report}

{% multi_lang_include release_type.md release="Early access" %}

Das [Credits-Usage-Dashboard]({{site.baseurl}}/credits_usage_dashboard) bietet Self-Service-Einblicke in Ihre Credit-Nutzung mit einer umfassenden Übersicht über die historische und aktuelle Nutzung im Vergleich zu Ihren vertraglichen Kontingenten. Diese Insights können Unklarheiten reduzieren und Ihnen helfen, Anpassungen vorzunehmen, um Überschreitungsrisiken zu vermeiden.

## SDK or Software-Development-Kit

### Verzögerte Initialisierung für das Braze Swift SDK or Software-Development-Kit {#delayed-initialization-for-the-braze-swift-sdk}

Richten Sie eine [verzögerte Initialisierung]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=swift#step-2-set-up-delayed-initialization-optional) ein, um Ihr Braze Swift SDK or Software-Development-Kit asynchron zu initialisieren und gleichzeitig sicherzustellen, dass die Verarbeitung von Push-Benachrichtigungen erhalten bleibt. Dies kann nützlich sein, wenn Sie vor der Initialisierung des SDK or Software-Development-Kit andere Dienste einrichten müssen, z. B. das Abrufen von Konfigurationsdaten von einem Server oder das Warten auf die Zustimmung der Nutzer:innen.
