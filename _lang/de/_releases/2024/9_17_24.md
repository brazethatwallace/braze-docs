# Veröffentlichung am 17. September 2024 {#september-17-2024-release}

## Flexibilität der Daten {#data-flexibility}

### Braze Cloud-Datenaufnahme für S3 {#braze-cloud-data-ingestion-for-s3}

Sie können die [Cloud-Datenaufnahme (CDI) für S3]({{site.baseurl}}/user_guide/data_and_analytics/cloud_ingestion/file_storage_integrations#aws-definitions) verwenden, um einen oder mehrere S3-Buckets in Ihrem AWS-Konto direkt mit Braze zu integrieren. Wenn neue Dateien in S3 veröffentlicht werden, wird eine Nachricht an SQS gesendet, und die Braze Cloud-Datenaufnahme nimmt diese neuen Dateien auf.

### Monatlich aktive Nutzer:innen CY 24-25 {#monthly-active-users-cy-24-25}

Für Kund:innen, die „Monatlich aktive Nutzer:innen – CY 24-25“ erworben haben, verwaltet Braze verschiedene Rate-Limits auf seinem Endpunkt `/users/track`. Einzelheiten finden Sie unter [POST: Nutzer:innen tracken]({{site.baseurl}}/api/endpoints/user_data/post_user_track#monthly-active-users-cy-24-25-universal-mau-web-mau-and-mobile-mau).

## Kreativität entfesseln {#unlocking-creativity}

### Templates für Katalogartikel einschließlich Liquid {#templating-catalog-items-including-liquid}

{% multi_lang_include release_type.md release="Early access" %}

Verwenden Sie das Flag `:rerender` in einem Liquid-Tag, um [den Liquid-Inhalt eines Katalogartikels darzustellen]({{site.baseurl}}/user_guide/personalization_and_dynamic_content/catalogs/catalog#using-liquid). Wenn Sie zum Beispiel den folgenden Liquid-Inhalt rendern:

{% raw %}
```liquid
Hi ${first_name}
{% catalog_items Messages greet_msg :rerender %}
{{ items[0].Welcome_Message }}
```
{% endraw %}

Wird dies wie folgt angezeigt:

{% raw %}
```
Hi Peter,
Welcome to our store, Peter!
```
{% endraw %}

## Robuste Kanäle {#robust-channels}

### WhatsApp-Antwortnachrichten {#whatsapp-response-messages}

{% multi_lang_include release_type.md release="General availability" %}

Sie können [Antwortnachrichten]({{site.baseurl}}/user_guide/message_building_by_channel/whatsapp/whatsapp_campaign/create#response-messages) verwenden, um auf eingehende WhatsApp-Nachrichten Ihrer Nutzer:innen zu antworten. Diese Nachrichten werden in der App in Braze während der Erstellung erstellt und können jederzeit bearbeitet werden. Sie können Liquid verwenden, um die Sprache der Antwortnachricht an die entsprechenden Nutzer:innen anzupassen.

### Canvas-Templates

{% multi_lang_include release_type.md release="General availability" %}

Erstellen Sie [Canvas-Templates]({{site.baseurl}}/user_guide/messaging/templates/canvas_templates), um Ihr Messaging zu verfeinern, indem Sie einen konsistenten Rahmen schaffen, der sich leicht an Ihre spezifischen Ziele in Ihren Canvases anpassen lässt.

### Landing-Pages

{% multi_lang_include release_type.md release="Beta" %}

Braze [Landing-Pages]({{site.baseurl}}/user_guide/messaging/landing_pages) sind eigenständige Webseiten, die Ihre Strategie zur Nutzer:innengewinnung und zum Engagement vorantreiben können.

### Änderungen seit der letzten Ansicht {#changes-since-last-viewed}

Sie können die Anzahl der Aktualisierungen an Ihren [Canvases]({{site.baseurl}}/user_guide/engagement_tools/canvas/testing_canvases/measuring_and_testing_with_canvas_analytics#changes-since-last-viewed), Campaigns und [Segmenten]({{site.baseurl}}/user_guide/engagement_tools/segments/managing_segments#changes-since-last-viewed) durch andere Mitglieder Ihres Teams einsehen, indem Sie die Metrik *Änderungen seit der letzten Ansicht* auf den jeweiligen Übersichtsseiten aufrufen (z. B. auf der Übersichtsseite für eine [E-Mail-Campaign]({{site.baseurl}}/user_guide/message_building_by_channel/email/reporting_and_analytics/email_reporting#changes-since-last-viewed)).

### Fehlerbehebung bei Webhook- und Connected-Content-Anfragen {#troubleshooting-webhook-and-connected-content-requests}

[Fehlerbehebung bei Webhook- und Connected-Content-Anfragen]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content/troubleshooting_webhooks_and_connected_content) behandelt die Fehlerbehebung von Fehlercodes bei Webhooks und Connected Content – einschließlich einer Erklärung der Fehler und der Schritte zu deren Behebung.

## Neue Braze-Partnerschaften {#new-braze-partnerships}

### Inbox Monster – Analytics

[Inbox Monster]({{site.baseurl}}/partners/data_and_analytics/analytics/inbox_monster) ist eine Plattform für Posteingangssignale, die Unternehmensmarken dabei hilft, jeden Versand erfolgreich zuzustellen. Es handelt sich um eine integrierte Suite von Lösungen für Zustellbarkeit, kreatives Rendering und SMS-Überwachung, die moderne CRM-Teams befähigt und die Angst vor dem Versand beendet.

### SessionM – Loyalty

[SessionM]({{site.baseurl}}/partners/data_and_analytics/loyalty/sessionm) ist eine Plattform für Customer-Engagement und Kundentreue, die Features für das Campaign-Management und Lösungen für das Loyalty-Management bereitstellt, um Marketern gezielte Ansprache zu ermöglichen und so Engagement und Gewinn zu steigern.

## KI- und ML-Automatisierung {#ai-and-ml-automation}

### Empfehlungen zu Trend-Artikeln {#trending-item-recommendations}

Zusätzlich zum Modell „KI-Personalisierung“ umfasst die Funktion [KI-Artikelempfehlungen]({{site.baseurl}}/user_guide/sage_ai/recommendations/about_item_recommendations#trending) auch ein Empfehlungsmodell für „Trending“, das Artikel mit der positivsten Dynamik in Bezug auf die jüngsten Interaktionen der Nutzer:innen anzeigt.

## Einstellungen {#settings}

### Rollen {#roles}

{% multi_lang_include release_type.md release="General availability" %}

[Rollen]({{site.baseurl}}/user_guide/administrative/app_settings/manage_your_braze_users/user_permissions#creating-a-role) ermöglichen eine bessere Strukturierung, indem sie Ihre individuell angepassten Berechtigungen mit den Zugriffskontrollen für den Workspace bündeln. Das ist besonders nützlich, wenn Sie viele Marken oder regionale Workspaces in einem Dashboard haben. Mit Rollen können Sie Dashboard-Nutzer:innen zu den richtigen Workspaces hinzufügen und ihnen direkt die entsprechenden Berechtigungen erteilen.

### Bericht über Sicherheitsereignisse {#security-event-report}

Wir haben eine vollständige Liste der [Sicherheitsereignisse]({{site.baseurl}}/user_guide/administrative/app_settings/company_settings/security_settings#downloading-a-security-event-report) hinzugefügt, die in Ihrem heruntergeladenen Sicherheitsbericht erscheinen können.

### Bericht über die Nachrichtennutzung {#message-usage-report}

{% multi_lang_include release_type.md release="Early access" %}

Das [Dashboard für die Guthabennutzung]({{site.baseurl}}/credits_usage_dashboard) bietet Ihnen Self-Service-Insights über Ihre Guthabennutzung und verschafft Ihnen einen umfassenden Überblick über die historische und aktuelle Nutzung im Vergleich zu den vertraglich festgelegten Kontingenten. Diese Insights können Unklarheiten ausräumen und Ihnen helfen, Anpassungen vorzunehmen, um Überschreitungsrisiken zu vermeiden.

## SDK

### Verzögerte Initialisierung für das Braze Swift SDK {#delayed-initialization-for-the-braze-swift-sdk}

Richten Sie eine [verzögerte Initialisierung]({{site.baseurl}}/developer_guide/sdk_integration/?sdktab=swift#step-2-set-up-delayed-initialization-optional) ein, um Ihr Braze Swift SDK asynchron zu initialisieren und gleichzeitig sicherzustellen, dass die Verarbeitung von Push-Benachrichtigungen erhalten bleibt. Dies kann nützlich sein, wenn Sie vor der Initialisierung des SDK andere Dienste einrichten müssen, z. B. das Abrufen von Konfigurationsdaten von einem Server oder das Warten auf die Zustimmung der Nutzer:innen.
