# Veröffentlichung am 28. Mai 2024 {#may-28-2024-release}

## Visuelle Updates der Dokumentationsseite {#visual-updates-to-documentation-site}

Vielleicht haben Sie schon bemerkt, dass unsere Dokumentationswebsite ein schickes neues Aussehen hat! Wir haben sie überarbeitet, um die neue, lebendige Markenidentität von Braze widerzuspiegeln. Wenn Sie einen Blick hinter die Kulissen unserer neuen Marke werfen möchten, lesen Sie mehr unter [Unveiling Our New Brand: A Conversation with Braze Executive Creative Director Greg Erdelyi](https://www.braze.com/resources/articles/unveiling-our-new-brand-a-conversation-with-braze-executive-creative-director-greg-erdelyi).

## Unterstützung für Portugiesisch und Spanisch {#support-for-portuguese-and-spanish}

{% multi_lang_include release_type.md release="General availability" %}

Braze ist jetzt sowohl auf Portugiesisch als auch auf Spanisch verfügbar. Um die Sprache zu ändern, in der das Braze-Dashboard angezeigt wird, lesen Sie den Abschnitt [Spracheinstellungen]({{site.baseurl}}/user_guide/administer/personal/language_settings/).

## Robuste Kanäle {#robust-channels}

### Mehrsprachige Einstellungen {#multi-language-settings}

{% multi_lang_include release_type.md release="General availability" %}

Durch Anpassen der [mehrsprachigen Einstellungen]({{site.baseurl}}/multi_language_support/) können Sie Nutzer:innen in verschiedenen Sprachen und an verschiedenen Standorten mit unterschiedlichen Nachrichten innerhalb einer einzigen E-Mail-Nachricht ansprechen. Um die Unterstützung mehrerer Sprachen zu bearbeiten und zu verwalten, benötigen Sie die Nutzerberechtigung „Einstellungen für mehrere Sprachen verwalten“. Um das Gebietsschema zu einer Nachricht hinzuzufügen, benötigen Sie Berechtigungen zum Bearbeiten von Campaigns.

### Kopfzeile zum Abmelden von der Liste auf Nachrichtenebene mit einem Klick {#message-level-one-click-list-unsubscribe-header}

{% multi_lang_include release_type.md release="General availability" %}

Die Ein-Klick-Abmeldung für den List-Unsubscribe-Header ([RFC 8058](https://datatracker.ietf.org/doc/html/rfc8058)) bietet Empfänger:innen eine einfache Möglichkeit, sich von E-Mails abzumelden. Sie können diese Kopfzeileneinstellung so anpassen, dass sie in Ihren E-Mails auf Nachrichtenebene angewendet wird. Weitere Informationen zu dieser Einstellung finden Sie unter [Kopfzeile für das Abmelden von E-Mails in Workspaces]({{site.baseurl}}/user_guide/administrative/app_settings/email_settings/#email-unsubscribe-header-in-workspaces).

### Über die Bereinigung von E-Mails {#about-email-sanitization}

Besuchen Sie unseren neuen Artikel zur [Bereinigung]({{site.baseurl}}/user_guide/channels/email/best_practices/), um mehr über den Prozess zu erfahren, der abläuft, wenn Braze eine bestimmte Art von JavaScript in Ihrer E-Mail-Nachricht erkennt. Sein Hauptzweck besteht darin, böswillige Akteure daran zu hindern, auf die Sitzungsdaten anderer Nutzer:innen des Braze-Dashboards zuzugreifen.

### Anzahl der Einbindungen für Content Blocks {#inclusion-count-for-content-blocks}

Nachdem Sie einen Content-Block in einer aktiven Campaign oder einem Canvas hinzugefügt haben, können Sie [eine Vorschau dieses Content-Blocks]({{site.baseurl}}/user_guide/messaging/design_and_edit/content_blocks/) aus der Content-Block-Bibliothek anzeigen, indem Sie den Mauszeiger über den Content-Block bewegen und das Symbol <i class="fa fa-eye preview-icon"></i> **Vorschau** auswählen.

### Canvas-Status {#canvas-statuses}

Auf dem Braze-Dashboard sind Ihre Canvases nach ihrem Status gruppiert. Informieren Sie sich über die verschiedenen [Canvas-Status und deren Beschreibungen]({{site.baseurl}}/user_guide/messaging/governance/statuses/), um zu erfahren, was sie bedeuten.

## KI- und ML-Automatisierung {#ai-and-ml-automation}

### Markenrichtlinien für Operator {#brand-guidelines-for-operator}

{% multi_lang_include release_type.md release="General availability" %}

Sie können jetzt [Markenrichtlinien]({{site.baseurl}}/user_guide/administer/global/workspace_settings/brand_guidelines/) erstellen und anwenden, um den Stil der von Operator generierten Texte an die Stimme Ihrer Marke anzupassen. Richten Sie mehrere Richtlinien für verschiedene Szenarien ein, um sicherzustellen, dass Ihr Ton immer zum jeweiligen Kontext passt.

## Neue Braze-Partnerschaften {#new-braze-partnerships}

### Adikteev – Analytics

Die Integration von Braze und [Adikteev]({{site.baseurl}}/partners/message_orchestration/retargeting/adikteev/) ermöglicht es Ihnen, die Nutzerbindung zu steigern, indem Sie die Churn-Prognosetechnologie von Adikteev innerhalb von Braze-CRM-Campaigns nutzen, um vorrangig risikoreiche Nutzersegmente anzusprechen.

### Celebrus – Analytics

Die Integration von Braze und [Celebrus]({{site.baseurl}}/partners/data_and_analytics/customer_data_platform/celebrus/) erfolgt nahtlos mit dem Braze SDK über Web- und mobile App-Kanäle und erleichtert die Bestückung von Braze mit Kanal-Aktivitätsdaten. Dazu gehören umfassende Insights über den Besucherverkehr bei digitalen Assets über bestimmte Zeiträume.

### IAM Studio – Nachrichten-Templates {#iam-studio-message-templates}

Mit der Integration von Braze und [IAM Studio]({{site.baseurl}}/partners/message_orchestration/templates/iam_studio/) können Sie ganz einfach anpassbare In-App-Nachrichtentemplates in Ihre Braze In-App Messages einfügen. Sie bieten Bildersatz, Textänderung, Deeplink-Einstellungen, angepasste Attribute und Ereigniseinstellungen. Mit IAM Studio können Sie die Produktionszeit für Nachrichten reduzieren und mehr Zeit für die Planung von Inhalten aufwenden.

### Regal – Sofortiger Chat {#regal-instant-chat}

Durch die Integration von Braze und [Regal]({{site.baseurl}}/partners/additional_channels_and_extensions/additional_channels/instant_chat/regal/) können Sie ein konsistenteres und personalisierteres Erlebnis an allen Ihren Kunden-Touchpoints schaffen.

### Treasure Data – Kohortenimport {#treasure-data-cohort-import}

Mit der Integration von Braze und [Treasure Data]({{site.baseurl}}/partners/data_and_analytics/cohort_import/treasuredata/) können Sie Nutzerkohorten aus Treasure Data in Braze importieren, um gezielte Campaigns auf der Grundlage von Daten zu versenden, die möglicherweise nur in Ihrem Warehouse vorhanden sind.

### Zapier – Workflow-Automatisierung {#zapier-workflow-automation}

Die Partnerschaft von Braze und [Zapier]({{site.baseurl}}/partners/data_and_analytics/workflow_automation/zapier/) nutzt die Braze API und Braze-Webhooks, um sich mit Drittanbieter-Anwendungen zu verbinden und verschiedene Aktionen zu automatisieren.
