# Veröffentlichung am 2. April 2024 {#april-2-2024-release}

## WhatsApp

### Mehrere Geschäftskonten {#multiple-business-accounts}

Jetzt können Sie mehrere WhatsApp Business-Konten und Abo-Gruppen zu jedem Workspace hinzufügen. Eine vollständige Anleitung finden Sie unter [Mehrere WhatsApp Business-Konten und Telefonnummern]({{site.baseurl}}/user_guide/channels/whatsapp/whatsapp_setup/multiple_business_accounts/).

### Leseraten {#read-rates}

WhatsApp testet neue Ansätze, beginnend mit Verbraucher:innen in Indien, um wertvollere Erfahrungen zu schaffen und das Engagement bei Marketingkonversationen von Unternehmen zu maximieren. Dazu kann es gehören, die Anzahl der Marketinggespräche, die eine Person in einem bestimmten Zeitraum von einem Unternehmen erhält, zu begrenzen und mit einer kleinen Anzahl von Gesprächen zu beginnen, die weniger wahrscheinlich gelesen werden. Weitere Informationen finden Sie unter [Meta-Ressourcen]({{site.baseurl}}/user_guide/channels/whatsapp/meta_resources/).

## Flexibilität der Daten {#data-flexibility}

### Amazon S3-Buckets mit Braze synchronisieren {#sync-amazon-s3-buckets-to-braze}

{% multi_lang_include release_type.md release="Early access" %}

Sie können jetzt Cloud-Datenaufnahme für S3 verwenden, um einen oder mehrere S3-Buckets in Ihrem AWS-Konto direkt in Braze zu integrieren. Wenn neue Dateien in S3 veröffentlicht werden, wird eine Nachricht an SQS gesendet, und die Braze Cloud-Datenaufnahme nimmt diese neuen Dateien auf. Weitere Informationen finden Sie unter [Dateispeicher-Integrationen]({{site.baseurl}}/user_guide/data/unification/cloud_ingestion/file_storage_integrations/).

### Shopify OAuth

{% multi_lang_include release_type.md release="General availability" %}

Shopify ist ein weltweit führendes Handelsunternehmen, das zuverlässige Tools für die Gründung, das Wachstum, das Marketing und die Verwaltung von Einzelhandelsgeschäften jeder Größe bereitstellt. Wenn Sie nun Shopify für Braze einrichten, können Sie [OAuth für Ihren Workspace aktivieren]({{site.baseurl}}/partners/message_orchestration/channel_extensions/ecommerce/shopify/setting_up_shopify/).

### Expo für iOS-Push-Benachrichtigungen verwenden {#use-expo-for-ios-push-notifications}

Wir haben eine [Anleitung]({{site.baseurl}}/developer_guide/platform_integration_guides/react_native/push_notifications/?tab=expo) für die Integration von Rich-Push-Benachrichtigungen und Push Stories in Ihre iOS-App mit Expo und React Native hinzugefügt.

### Fernstart von iOS-Live-Aktivitäten {#remote-start-ios-live-activities}

Jetzt können Sie Ihre Live-Aktivitäten auf iOS über den [`/messages/live_activity/start`-Endpunkt]({{site.baseurl}}/api/endpoints/messaging/live_activity/start/) aus der Ferne starten. Eine vollständige Anleitung finden Sie unter [Live-Aktivitäten: Eine Aktivität starten]({{site.baseurl}}/developer_guide/platform_integration_guides/swift/live_activities/live_activities/#step-2-start-the-activity).

## KI- und ML-Automatisierung {#ai-and-ml-automation}

### Artikelempfehlungen {#item-recommendations}

{% multi_lang_include release_type.md release="Early access" %}

Mit BrazeAI<sup>TM</sup> können Sie jetzt die beliebtesten Produkte berechnen oder personalisierte KI-Empfehlungen für einen bestimmten Katalog erstellen. Weitere Informationen finden Sie unter [Über Artikelempfehlungen]({{site.baseurl}}/user_guide/brazeai/item_recommendations/).

### QA für In-App-Nachrichteninhalte {#qa-in-app-message-content}

{% multi_lang_include release_type.md release="General availability" %}

Bisher konnten Sie mit BrazeAI<sup>TM</sup> im Braze-Dashboard eine Qualitätssicherung Ihrer SMS- und Push-Benachrichtigungsinhalte durchführen. Jetzt können Sie auch [Inhalte von In-App-Nachrichten überprüfen]({{site.baseurl}}/user_guide/brazeai/operator/capabilities/#review-content-quality).

## Neue Braze-Partnerschaften {#new-braze-partnerships}

### Census – Kohortenimport {#census-cohort-import}

Sie können jetzt [Kohorten-Nutzer:innen von Braze in Census importieren]({{site.baseurl}}/partners/data_and_analytics/reverse_etl/census/census_cohort_import/), einer Datenaktivierungsplattform, die Cloud Data Warehouses wie Snowflake und BigQuery mit Braze verbindet. Ihre Marketing-Teams können die Leistungsfähigkeit ihrer First-Party-Daten nutzen, um dynamische Zielgruppen-Segmente zu erstellen, Nutzerattribute zur Personalisierung von Campaigns zu synchronisieren und alle Daten in Braze auf dem neuesten Stand zu halten.
