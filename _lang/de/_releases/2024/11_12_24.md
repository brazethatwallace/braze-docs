### LINE

{% multi_lang_include release_type.md release="General availability" %}

## SDK or Software-Development-Kit-Updates

Die folgenden SDK or Software-Development-Kit-Updates wurden veröffentlicht. Die wichtigsten Updates sind unten aufgeführt; alle anderen Updates finden Sie in den entsprechenden SDK or Software-Development-Kit-Changelogs.

- [Expo Plugin 3.0.0](https://github.com/braze-inc/braze-expo-plugin/blob/main/CHANGELOG.md)
    - Diese Version erfordert 13.1.0 des Braze React Native SDK or Software-Development-Kit.
    - Ersetzt den iOS-BrazeAppDelegate-Methodenaufruf von BrazeReactUtils.populateInitialUrl durch BrazeReactUtils.populateInitialPayload.
        - Dieses Update or aktualisieren behebt ein Problem, bei dem Push-Öffnungs-Ereignisse nicht ausgelöst wurden, wenn auf eine Benachrichtigung geklickt wurde, während sich die Anwendung in einem beendeten Zustand befand.
        - Um dieses Update or aktualisieren vollständig zu nutzen, ersetzen Sie in Ihrem JavaScript-Code alle Aufrufe von Braze.getInitialURL durch Braze.getInitialPushPayload. Auf die ursprüngliche URL kann nun über die Eigenschaft url der ursprünglichen Push-Nutzlast zugegriffen werden.
- [Braze Segment Swift Plugin 5.0.0](https://github.com/braze-inc/braze-segment-swift/blob/main/CHANGELOG.md)
    - Aktualisiert die Braze Swift SDK or Software-Development-Kit-Bindungen, um Versionen ab der SemVer-Bezeichnung 11.1.1+ zu erfordern.
    - Dies ermöglicht die Kompatibilität mit jeder Version des Braze SDK or Software-Development-Kit von 11.1.1 bis, aber nicht einschließlich, 12.0.0.
    - Weitere Informationen zu möglichen Breaking Changes finden Sie im Changelog-Eintrag für 11.1.1.
