# Veröffentlichung am 5. März 2024 {#march-5-2024-release}

## Google EU-Richtlinie zur Zustimmung der Nutzer:innen {#google-eu-user-consent-policy}

Google aktualisiert seine [EU-Zustimmungsrichtlinie](https://www.google.com/about/company/user-consent-policy/) als Reaktion auf die Änderungen des [Digital Markets Act (DMA)](https://ads-developers.googleblog.com/2023/10/updates-to-customer-match-conversion.html), der ab dem 6. März 2024 in Kraft tritt. Diese neue Änderung verlangt von den Werbetreibenden, dass sie ihren Endnutzer:innen aus dem EWR und Großbritannien bestimmte Informationen offenlegen und die erforderlichen Einwilligungen von ihnen einholen. Im Rahmen dieser bevorstehenden Änderung können Sie [beide Zustimmungssignale in Braze als angepasste Attribute erfassen]({{site.baseurl}}/partners/canvas_steps/google_audience_sync#collecting-consent-for-eea-and-uk-end-users). Braze wird die Daten aus diesen angepassten Attributen mit den entsprechenden Einwilligungsfeldern in Google synchronisieren.

## Flexibilität der Daten {#data-flexibility}

### Doppelte Nutzer:innen zusammenführen {#merge-duplicate-users}

{% multi_lang_include release_type.md release="Early access" %}

Im Braze-Dashboard können Sie jetzt [nach doppelten Nutzer:innen suchen und diese zusammenführen]({{site.baseurl}}/user_guide/audience/manage_audience/merge_duplicate_users), um die Effektivität Ihrer Kampagnen und Canvases zu maximieren. Sie können Nutzerprofile einzeln zusammenführen oder eine Massenzusammenführung durchführen, bei der alle Profile mit übereinstimmenden Bezeichnern zum zuletzt aktualisierten Nutzerprofil zusammengeführt werden.

### Suche nach archivierten Inhalten {#search-for-archived-content}

Im Braze-Dashboard können Sie jetzt [archivierte Inhalte in Ihre Suchergebnisse]({{site.baseurl}}/user_guide/administrative/access_braze/global_search#filter-for-archived-content) aufnehmen, indem Sie **Show Archived Content** auswählen.

### Unterstützung der Nachrichtenarchivierung für AWS S3 und Google Cloud Storage {#message-archiving-support-for-aws-s3-and-google-cloud-storage}

Mit der [Nachrichtenarchivierung]({{site.baseurl}}/user_guide/data/distribution/export_braze_data/message_archiving) können Sie eine Kopie Ihrer an Nutzer:innen gesendeten Nachrichten zu Archivierungs- oder Compliance-Zwecken in Ihrem AWS S3-Bucket, Azure Blob Storage-Container oder Google Cloud Storage-Bucket speichern.

### SQL-Tabellenreferenz {#sql-table-reference}

Besuchen Sie die [SQL-Tabellenreferenz]({{site.baseurl}}/user_guide/audience/segments/segment_extension/sql_segments/sql_segments_tables), um die Tabellen und Spalten zu sehen, die im Abfrage-Builder oder beim Erstellen von SQL-Segmenterweiterungen abgefragt werden können.

## Kreativität entfesseln {#unlocking-creativity}

### Tonsteuerung für KI-Texte {#tone-control-for-ai-copywriting}

Sie können jetzt einen [Nachrichtenton]({{site.baseurl}}/user_guide/brazeai/generative_ai/ai_copywriting#steps) wählen, um den Stil der mit dem KI-Texterstellungsassistenten generierten Texte zu bestimmen.

## Robuste Kanäle {#robust-channels}

### Kartenerstellung {#card-creation}

Sie können wählen, wann Braze die Eignung der Zielgruppe und die Personalisierung für neue Content-Card-Kampagnen und Canvas-Schritte bewertet, indem Sie angeben, wann die Karte [erstellt]({{site.baseurl}}/user_guide/channels/content_cards/create_a_content_card/card_creation) wird.

### Vorschau der Nutzerpfade {#preview-user-paths}

{% multi_lang_include release_type.md release="General availability" %}

Erleben Sie die Canvas-Journey, die Sie für Ihre Nutzer:innen erstellt haben, einschließlich einer Vorschau auf das Timing und die Nachrichten, die sie erhalten werden. Diese [Testläufe]({{site.baseurl}}/preview_user_paths) dienen der Qualitätssicherung, um sicherzustellen, dass Ihre Nachrichten an die richtige Zielgruppe gesendet werden, und zwar bevor Sie das Canvas versenden.

### Schnelle Push-Kampagnen {#quick-push-campaigns}

{% multi_lang_include release_type.md release="General availability" %}

Wenn Sie eine Push-Kampagne in Braze erstellen, können Sie mehrere Plattformen und Geräte auswählen, um eine Nachricht für alle Plattformen in einem einzigen Bearbeitungsvorgang, dem sogenannten [Quick Push]({{site.baseurl}}/user_guide/channels/push/create_a_push_message/quick_push_messages), zu erstellen. Dieses Feature ist nur für Campaigns verfügbar.

### Angepasster List-Unsubscribe-Header {#custom-list-unsubscribe-header}

{% multi_lang_include release_type.md release="General availability" %}

Wenn Sie Ihrem E-Mail-Messaging einen [angepassten List-Unsubscribe-Header]({{site.baseurl}}/user_guide/administrative/app_settings/email_settings#custom-list-unsubscribe-header) hinzufügen, können sich Ihre Empfänger:innen abmelden. Auf diese Weise können Sie Ihren eigenen konfigurierten Endpunkt für das Abmelden mit einem Klick und ein optionales „mailto:“ hinzufügen. Braze erfordert eine Eingabe für die URL, um einen angepassten List-Unsubscribe-Header zu unterstützen, da die HTTP-Funktion zum Abmelden mit einem Klick eine Anforderung von Yahoo und Gmail für Massenabsender ist.

### Mehrere Seiten für In-App-Nachrichten {#multiple-pages-for-in-app-messages}

{% multi_lang_include release_type.md release="Early access" %}

[Durch das Hinzufügen von Seiten zu Ihrer In-App-Nachricht]({{site.baseurl}}/user_guide/message_building_by_channel/in-app_messages/drag_and_drop/create#multi-page) können Sie Nutzer:innen durch einen sequentiellen Ablauf leiten, z. B. ein Onboarding oder eine Willkommens-Journey. Sie können Seiten im Bereich **Pages** des Tabs **Build** verwalten.

### Pfade für einen Experimentpfad randomisieren {#randomize-paths-for-an-experiment-path}

Um immer eine [zufällige Pfadzuweisung]({{site.baseurl}}/user_guide/messaging/canvas/canvas_components/experiment_step) für einen Experimentpfad-Schritt durchzuführen, wählen Sie in dem Schritt **Randomized Paths in Experiment Paths** aus. Diese Option ist nicht verfügbar, wenn Sie entweder den Gewinnerpfad oder personalisierte Pfade verwenden.

### Formular zur Erfassung von E-Mails {#email-capture-form}

Mit [Nachrichten zur Erfassung von E-Mails]({{site.baseurl}}/user_guide/channels/in_app_messages/message_types/email_capture_form) können Sie die Nutzer:innen Ihrer Website auf einfache Weise auffordern, ihre E-Mail-Adresse zu übermitteln, die dann in ihrem Nutzerprofil für alle Ihre Messaging-Kampagnen zur Verfügung steht.
