- [Xamarin SDK 9.0.0](https://github.com/braze-inc/braze-xamarin-sdk/blob/master/CHANGELOG.md)
    - Das Android-Binding wurde von [Braze Android SDK 37.0.0 auf 41.0.0](https://github.com/braze-inc/braze-android-sdk/compare/v37.0.0...v41.0.0#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed) aktualisiert.
    - Das iOS-Binding wurde von [Braze Swift SDK 13.3.0 auf 14.0.1](https://github.com/braze-inc/braze-swift-sdk/compare/13.3.0...14.0.1#diff-06572a96a58dc510037d5efa622f9bec8519bc1beab13c9f251e97e657a9d4ed) aktualisiert.
    - Neue transitive NuGet-Abhängigkeiten wurden hinzugefügt, die vom Braze Android SDK benötigt werden:
        - Xamarin.AndroidX.DataStore.Preferences (1.1.7.1)
        - Xamarin.KotlinX.Serialization.Json.Jvm (1.9.0.2)
        - Xamarin.Kotlin.StdLib wurde von 2.0.21.3 auf 2.3.0.1 aktualisiert. Wenn Ihr Projekt dieses Paket explizit auf eine ältere Version festlegt, müssen Sie es aktualisieren, um Wiederherstellungsfehler zu vermeiden.
    - Das News-Feed-Feature wurde entfernt.
        - Dieses Feature wurde im nativen Android SDK in Version [38.0.0](https://github.com/braze-inc/braze-android-sdk/releases/tag/v38.0.0) entfernt.
        - Dieses Feature wurde im nativen Swift SDK in Version [14.0.0](https://github.com/braze-inc/braze-swift-sdk/releases/tag/14.0.0) entfernt.
    - Der enum-Fall BRZInAppMessageDismissalReason.BRZInAppMessageDismissalReasonWipeData wurde in BRZInAppMessageDismissalReason.WipeData umbenannt.
- [Expo Plugin 4.0.0](https://github.com/braze-inc/braze-expo-plugin/releases/tag/4.0.0)
    - Diese Version erfordert Version 19.0.0 des Braze React Native SDK.
    - (Android) Ein Speicherleck in der Datenpersistenzschicht wurde behoben.
    - (Android) Unterstützung für Braze.getInitialPushPayload() wurde hinzugefügt, um Push-Benachrichtigungs-Deeplinks zu verarbeiten, wenn die App aus einem beendeten Zustand gestartet wird. Dies behebt ein Problem, bei dem Deeplinks aus Push-Benachrichtigungen auf Android nicht verarbeitet wurden, wenn die App kalt gestartet wurde.
- [React Native SDK 19.0.0](https://github.com/braze-inc/braze-react-native-sdk/releases/tag/19.0.0)
    - Die nativen Swift-SDK-Versionsbindungen wurden von Braze Swift SDK 13.3.0 auf 14.0.1 aktualisiert.
    - Die nativen Android-SDK-Versionsbindungen wurden von Braze Android SDK 40.0.2 auf 41.0.0 aktualisiert.
