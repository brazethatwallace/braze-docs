- [Swift SDK 15.0.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - Banner: `onDismiss` empfängt jetzt `Braze/BannerDismissalEvent` anstelle von `Braze/Banner`.
    - Erhöht die Xcode-Version auf 26.0 (17A324).
    - Erhöht das minimale Mac-Catalyst-Deployment-Target von iOS 13 (macOS 10.15 Catalina) auf iOS 16 (macOS 13 Ventura).
        - Mac-Catalyst-Nutzer:innen unter macOS 12 Monterey oder älter werden nicht mehr unterstützt.
    - Entfernt die Möglichkeit zu steuern, ob das SDK in bestimmten Grenzfällen die Anzeige von In-App-Nachrichten für verschiedene Nutzer:innen verhindert.
        - Entfernt die Option zur Konfiguration über `Braze.Configuration.preventInAppMessageDisplayForDifferentUser`.
        - Das SDK verhält sich jetzt immer so, als wäre diese Konfigurationsoption auf „true“ gesetzt.
    - Aktualisiert die Initialisierung von `Braze.WebViewBridge.ScriptMessageHandler` und `Braze.WebViewBridge.SchemeHandler`, sodass der Parameter `channel` nicht mehr optional ist.
- [Android SDK 42.3.1](https://github.com/braze-inc/braze-android-sdk/blob/master/CHANGELOG.md#4231)
    - Unterstützung für neue E-Commerce-Event-Methoden hinzugefügt.
    - Banner-Dismissal-Methoden für angepasste UI-Implementierungen hinzugefügt.
    - Fehlerbehebungen für HTML-In-App-Nachrichten enthalten.

- [React Native 21.0.0](https://www.npmjs.com/package/@braze/react-native-sdk/v/21.0.0)

- [Swift SDK 15.1.0](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md)
    - Unterstützung für neue E-Commerce-Event-Methoden hinzugefügt.
    - Banner-Dismissal-Methoden für angepasste UI-Implementierungen hinzugefügt.
    - Beispielimplementierungen zum Erstellen angepasster UI mit Bannern hinzugefügt.
    - Pass-through-Observability für Live Activities hinzugefügt, sodass Fehler und Update-Ereignisse mit mehr Präzision und Granularität verfolgt werden können.
    - Asynchrone Callback-basierte Getter für Content Cards hinzugefügt und ältere Getter als veraltet markiert.
    - Stabilität der Zustandsverwaltung verbessert.
- [Segment Swift 9.0.0](https://github.com/braze-inc/braze-segment-swift/releases/tag/9.0.0)
    - Aktualisiert die Braze Swift SDK-Bindungen, sodass Releases ab der SemVer-Bezeichnung `15.0.0+` erforderlich sind.
        - Dies ermöglicht die Kompatibilität mit jeder Version des Braze SDK ab `15.0.0` bis, aber nicht einschließlich, `16.0.0`.
        - Erhöht die Xcode-Version auf 26.0 (17A324).
        - Weitere Informationen zu möglichen Breaking Changes finden Sie im Changelog-Eintrag für [`15.0.0`](https://github.com/braze-inc/braze-swift-sdk/blob/main/CHANGELOG.md#1500).
