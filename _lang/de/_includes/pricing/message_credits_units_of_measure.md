{% alert note %}
Verschiedene Produkte verwenden unterschiedliche Maßeinheiten im Reporting.

- **Agent Console:** Invocations
- **SMS:** Segments
- **MMS:** Sends
- **WhatsApp:** Zugestellte Nachrichten
- **RCS:** Zugestellte Segments, zugestellte Sends
- **LINE:** Sends
- **KakaoTalk:** Sends

Carrier-Gebühren für SMS, MMS und RCS werden separat (nachträglich) abgerechnet und sind nicht Teil dieser Message Credits SKU.
{% endalert %}
