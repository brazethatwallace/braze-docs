## E-Mail-Editor-Blöcke {#email-editor-blocks}

Editor-Blöcke befinden sich im Bereich **Content** für E-Mail-Nachrichten. Ziehen Sie einen Block in eine Spalte im **Drag-And-Drop-Editor**; er passt sich automatisch an die Spaltenbreite an.

Weitere Informationen zum Erstellen von E-Mails im **Drag-And-Drop-Editor** finden Sie unter [E-Mail per Drag-and-Drop erstellen]({{site.baseurl}}/user_guide/channels/email/drag_and_drop) und <a href="{{site.baseurl}}/user_guide/channels/email/drag_and_drop/#other-customizations">Weitere Anpassungen</a> in diesem Artikel.

{% alert tip %}
Sie können auch [angepasste Attribute]({{site.baseurl}}/user_guide/data/activation/custom_data/data_types) zu jeder URL innerhalb der Editor-Blöcke `Image`, `Button` oder `Text` hinzufügen.
{% endalert %}

Fügt ein Bild aus der [Medienbibliothek]({{site.baseurl}}/user_guide/messaging/design_and_edit/media_library) ein. Für dynamische Bilder (Bilder mit Liquid oder Connected-Content) müssen Sie ein Fallback-Bild festlegen, um die automatischen Breiteneinstellungen zu verwenden. Bildspezifikationen finden Sie unter [E-Mail-Bildspezifikationen]({{site.baseurl}}/user_guide/messaging/design_and_edit/media_library/image_specifications#email).

{% multi_lang_include alerts/important_alerts.md alert='dynamic image URL' %}

| Eigenschaft | Beschreibung |
|---|---|
| Automatische Breite | Ändert die Breite des Bildes in Pixeln. |
| Ausrichtung | Setzt die Bildausrichtung innerhalb des Blocks auf links, zentriert oder rechts. |
| Bild mit Liquid | Verwenden Sie [Liquid]({{site.baseurl}}/liquid)-Logik, um innerhalb desselben Content-Blocks dynamisch verschiedene Bilder festzulegen. |
| URL | Legen Sie ein Bild über die Adresse fest, unter der es gehostet wird. |
| Alternativtext | Eine kurze Beschreibung des Bildes, die Nutzer:innen dieselben Informationen vermittelt, die im Bild gezeigt werden. Unverzichtbar für die Barrierefreiheit bei Screenreadern oder wenn das Bild nicht geladen werden kann. |
| Bild mit abgerundeten Ecken | Rendert das Bild mit abgerundeten Ecken. Standardmäßig werden Bilder mit eckigen Kanten gerendert. |
| Aktion | Löst eine Aktion aus, wenn Nutzer:innen auf das Bild klicken. |
| Blockoptionen | Legt Padding rund um den Bildblock fest. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Bild" }

{% alert tip %}
Bei **Automatische Breite** wählt die automatische Bildgrößenanpassung die beste Größe für das Bild basierend auf einer Kombination aus Bildbreite und verfügbarem Platz im Layout:
- Bilder, die breiter als der verfügbare Platz sind, werden auf 100 % Breite gesetzt und behalten dieses Verhältnis auf Mobilgeräten bei, wobei die gesamte Bildschirmbreite des Geräts genutzt wird.
- Bilder, die kleiner als der verfügbare Platz sind, verwenden die natürliche Bildgröße, um Verzerrungseffekte oder unscharfe Bilder zu vermeiden.
{% endalert %}

#### Gmail-Download-Button-Verhalten {#gmail-download-button-behavior}

Gmail fügt automatisch einen Download-Button zu Bildern hinzu, denen kein Hyperlink (`href`) zugeordnet ist. Wenn das Seitenverhältnis des Bildes jedoch 299 × 524 px oder kleiner ist, zeigt Gmail den Download-Button nicht an.

Um den Download-Button bei größeren Bildern zu verhindern, können Sie den „#“-Link-Workaround anwenden:

1. Wählen Sie den Block **Image** aus.
2. Navigieren Sie im Panel **Block Options** zum Abschnitt **Link**.
3. Setzen Sie den **Linktyp** auf **Webseite öffnen**.
4. Geben Sie ein Rautezeichen (`#`) in das Eingabefeld **URL** ein.

Das Hinzufügen dieses Links verhindert, dass Gmail den Download-Button anzeigt, ohne das Nutzererlebnis zu beeinträchtigen.

{% alert tip %}
Videos, die bei Vimeo gehostet werden, funktionieren nur, wenn sie als öffentlich eingestellt sind. Alle anderen in Vimeo verfügbaren Sicherheitseinstellungen (z. ## Personalisierung {#personalization}

Sie können Ihre E-Mail mithilfe von Liquid oder Connected-Content personalisieren.

- **Liquid:** Wählen Sie unter **Content** > **Personalization** ein Attribut aus, kopieren Sie das Snippet und fügen Sie es in einen Titel-, Absatz- oder Listenblock (einfaches Liquid) oder einen HTML-Block (erweitertes Liquid) ein. Grundsätzlich können Sie einfaches Liquid zwar in Titel-, Absatz- und Listenblöcken verwenden, wir empfehlen jedoch für komplexere Logik die Verwendung von HTML-Blöcken, um Layoutprobleme zu vermeiden. Beachten Sie, dass Liquid in Bildblöcken oder in Button-URL-Feldern nicht unterstützt wird.
- **[Connected-Content]({{site.baseurl}}/user_guide/messaging/design_and_edit/personalize/connected_content):** Fügen Sie einen **HTML**-Block hinzu und platzieren Sie dort Ihren {% raw %}`{% connected_content %}`{% endraw %}-Aufruf.
