guide_top_header: "Externe ID-Migration"
guide_top_text: "Mit der API für die externe ID-Migration können Sie bestehende externe IDs umbenennen (indem Sie eine neue primäre ID erstellen und die bestehende ID als veraltet markieren) und veraltete IDs nach der Migration entfernen. <br><br> Wir haben diese Lösung so konzipiert, dass sie mehrere externe IDs zulässt, um eine Migrationsphase zu unterstützen, in der ältere Versionen Ihrer Apps, die noch im Umlauf sind und das vorherige Namensschema für externe IDs verwenden, nicht kaputt gehen. Wir empfehlen dringend, veraltete externe IDs zu entfernen, wenn Ihr altes Namensschema nicht mehr verwendet wird."
