# Automatisches Speichern von Campaigns {#autosaving-campaigns}

> Wenn Sie Ihre Campaigns in Braze erstellen, werden Ihre Änderungen jetzt automatisch gespeichert. So können Sie sich darauf konzentrieren, Ihre Campaign-Details zu optimieren – mit der Gewissheit, dass Ihr Fortschritt erhalten bleibt.

{% alert important %}
Das automatische Speichern befindet sich derzeit in der Betaphase und ist nur für Campaigns verfügbar. Kontaktieren Sie Ihren CSM, wenn Sie an dieser Beta teilnehmen möchten.
{% endalert %}

{% alert warning %}
Wenn Sie eine Nachricht in einem Vollbild-Editor bearbeiten, z. B. für E-Mail oder In-App-Nachrichten, werden Änderungen an der Nachricht nicht automatisch gespeichert. Wenn Sie **Done** auswählen, um den Editor zu verlassen und zur Campaign zurückzukehren, werden die Änderungen an der Nachricht beim nächsten automatischen Speichern gesichert. Sie können Ihre Nachricht auch manuell speichern, um auf Nummer sicher zu gehen.
{% endalert %}

## So funktioniert es {#how-it-works}

![][1]{: style="float:right;max-width:40%;margin-left:15px;"}

Ihre Campaigns werden automatisch und regelmäßig gespeichert, während Sie im Campaign-Editor Änderungen vornehmen und zwischen Tabs wechseln.

Änderungen werden sowohl für Entwürfe als auch für aktive Campaigns als Entwurf gespeichert. Bei gestoppten Campaigns werden Ihre Änderungen gespeichert, die Campaign bleibt jedoch gestoppt.

Wenn Sie und eine andere Person gleichzeitig Änderungen an einer Campaign vornehmen, wird der erste Satz von Änderungen gespeichert. Wenn Sie die zweite Person sind, die Änderungen speichert, müssen Sie die Seite aktualisieren, um die neuesten Änderungen an der Campaign zu sehen.
