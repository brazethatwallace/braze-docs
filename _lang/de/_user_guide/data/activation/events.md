guide_top_text: "Events erfassen das Verhalten von Nutzer:innen und speichern diese Informationen in ihren <a href='/docs/user_guide/data/unification/user_data/user_profile_lifecycle'>Nutzerprofilen</a>. <br><br>Verwenden Sie Standard-Events für Aktionen, die automatisch vom <a href='/docs/user_guide/data/unification/user_data/sdk_data_collection'>Braze SDK or Software-Development-Kit</a> erfasst werden, wie z. B. App-Starts und Sitzungsbeginn. Um individuelle Nutzeraktionen wie das Starten eines Tutorials oder das Hinzufügen eines Wunschlistenartikels zu erfassen, können Sie angepasste Events definieren. Für gängige Branchen wie E-Commerce bieten empfohlene Events vorgefertigte Schemata und Best-Practice-Datenstrukturen, die Ihnen einen schnelleren Einstieg ermöglichen. Sie können auch Transaktionen mit Umsatzdaten mithilfe von Kauf-Events aufzeichnen. <br><br>Zusammen ermöglichen Ihnen diese Events, Trends im Zeitverlauf zu analysieren und zeitnahes, relevantes Engagement auszulösen."
