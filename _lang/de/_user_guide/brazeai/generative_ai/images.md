# Bilder mit BrazeAI generieren {#generate-images-with-brazeai}

> {% multi_lang_include brazeai/generative_ai/about_images.md %}

## Über die Medienbibliothek {#about-the-media-library}

Die Medienbibliothek ermöglicht es Ihnen, Ihre Assets an einem einzigen, zentralen Ort zu verwalten. Um auf Ihre Braze-Medienbibliothek zuzugreifen, gehen Sie zu **Content** > **Media Library**. Ausführlichere Informationen finden Sie unter [Medienbibliothek]({{site.baseurl}}/user_guide/messaging/design_and_edit/media_library/).

## Ein Bild generieren {#generating-an-image}

1. Öffnen Sie Ihre Medienbibliothek und wählen Sie <i class="fas fa-wand-magic-sparkles"></i> **AI Image Generator**.
2. Geben Sie eine Beschreibung des Bildes ein, das Sie generieren möchten (bis zu 300 Zeichen). Je detaillierter die Beschreibung, desto besser das Ergebnis. Dieses Feature unterstützt nur Texteingaben – das Hochladen eines Bildes als Referenz ist nicht möglich.
3. Wählen Sie **Generate Images**. Es kann etwa eine Minute dauern, bis die Bilder generiert sind.
4. Wählen Sie <i class="fas fa-download" title="Bild zur Medienbibliothek hinzufügen"></i> bei den Bildern, die Sie zu Ihrer Medienbibliothek hinzufügen möchten.
