# BrazeAI Decisioning Studio™ Go

> Erfahren Sie, wie Sie BrazeAI Decisioning Studio™ Go einrichten und in Braze integrieren.

{% alert important %}
Mitte 2026 wird eine neue Version von Decisioning Studio™ Go als Self-Service-Lösung über das Braze-Dashboard verfügbar sein. Der folgende Artikel bezieht sich auf die Legacy-Version, die zu einem späteren Zeitpunkt eingestellt wird.
{% endalert %}

## Über Decisioning Studio Go {#about-decisioning-studio-go}

Decisioning Studio Go umfasst eine Self-Service-Konfiguration kreativer Inhalte mit einer begrenzten Aktionsbank, ausschließlich engagementbasierte Kund:innen-Features, Optimierung anhand von Klicks und ist nur mit den folgenden Customer-Engagement-Plattformen (CEPs) kompatibel:

* Braze
* Salesforce Marketing Cloud

Weitere Informationen zu den Unterschieden zwischen Decisioning Studio Go und Decisioning Studio Pro finden Sie unter [Decisioning Studio Go im Vergleich zu Decisioning Studio Pro]({{site.baseurl}}/user_guide/brazeai/decisioning_studio/#decisioning-studio-go-vs-decisioning-studio-pro).
