  - name: Active User

  - name: A/B Multivariate Testing

    description: "App-Instanzen beziehen sich auf die verschiedenen Websites und Apps, die in einem Workspace gesammelt werden."
  - name: Alloys
    description: "Alloys sind unsere <a href=\"https://www.braze.com/docs/partners/home/\">Technologie-Partner</a>."
  - name: Anonymous Users
    description: "Wenn ein Nutzerprofil über das SDK erkannt wird, wird ein anonymes Nutzerprofil mit der zugehörigen <a href=\"https://www.braze.com/docs/api/basics/#user-ids\">Braze-Nutzer-ID</a> erstellt."
  - name: Application Program Interface (API)
    description: "Die <a href=\"https://www.braze.com/docs/api/basics/#api-overview\">Braze API</a> bietet einen Webdienst, mit dem Sie die Aktionen Ihrer Nutzer:innen direkt über HTTP aufzeichnen können, anstatt über die mobilen SDKs. So können Sie zum Beispiel Nutzerdaten an Braze weitergeben, die in Ihrer App oder Website nicht erfasst werden."
  - name: Braze (The Product)
    description: "Dieses Produkt, das manchmal auch als Dashboard bezeichnet wird, steuert alle Daten und Interaktionen, die das Herzstück der Braze-Plattform bilden. Braze-Kund:innen verwenden es, um Benachrichtigungen zu verwalten, gezielte Messaging-Kampagnen einzurichten und Analytics einzusehen. Entwickler:innen verwalten damit Einstellungen für die Integration von Apps, wie API-Schlüssel und Zugangsdaten für Push-Benachrichtigungen."
  - name: Braze Engagement Tools
    description: "Braze bietet zahlreiche <a href=\"https://www.braze.com/docs/user_guide/messaging\">Engagement-Tools</a>, um Ihre Kund:innen und Nutzer:innen mit unseren Campaigns, Canvas-Tools zu erreichen. Außerdem können Sie mit unseren Templates und Medien-Tools die Konsistenz optimieren (und Bilder und andere Inhalte hochladen). Von dort aus können Sie Segmente und Geofences erstellen, um Ihre Zielgruppe nach Standorten oder anderen Attributen zu adressieren."
  - name: Braze Teams
    description: "Braze-Administrator:innen können eine Teilmenge der Dashboard-Nutzer:innen in <a href=\"https://www.braze.com/docs/user_guide/administer/global/user_management/teams\">Teams</a> mit unterschiedlichen Rollen und Berechtigungen einteilen. Dies erlaubt es Braze-Administrator:innen, den Zugriff auf bestimmte Features nach Gruppenmitgliedschaft einzuschränken."
  - name: Campaigns
    description: "Campaigns sind anpassbare Messaging-Methoden, um Ihren Kund:innen eine personalisierte Antwort zu liefern. Sie können über verschiedene Messaging-Kanäle <a href=\"https://www.braze.com/docs/user_guide/messaging/campaigns\">Campaigns erstellen</a>, um Ihre individuellen Nachrichten zu versenden."
  - name: Canvas
    description: "<a href=\"https://www.braze.com/docs/user_guide/messaging/canvas\">Canvas</a> ist eine einheitliche Schnittstelle, auf der Marketer Campaigns mit mehreren Nachrichten und Schritten einrichten können, um eine zusammenhängende Journey zu gestalten. Canvas erlaubt es Ihnen, diese Erfahrungen zu vergleichen und zu optimieren, indem Sie umfassende Analytics für das gesamte Nutzererlebnis nutzen."
  - name: Connected Content
    description: "<a href=\"https://www.braze.com/docs/user_guide/messaging/design_and_edit/personalize/connected_content\">Connected-Content</a> erweitert die Personalisierung des Marketings, um das Customer-Engagement und die Conversions zu steigern. Sie können alle über API zugänglichen Informationen direkt in Nachrichten einfügen, die Sie an Nutzer:innen senden. Mit Connected-Content können Sie Inhalte entweder direkt von Ihrem Webserver oder über öffentlich zugängliche APIs beziehen."
  - name: Content Cards
    description: "Mit <a href=\"https://www.braze.com/docs/user_guide/channels/content_cards\">Content Cards</a> können Sie Ihren Kund:innen direkt in den Apps, die sie lieben, einen gezielten, dynamischen Strom reichhaltiger Inhalte senden, ohne deren Erlebnis zu unterbrechen. Content Cards können an iOS-, Android- und Web-Nutzer:innen gesendet werden."
  - name: Currents
    description: "<a href=\"https://www.braze.com/docs/user_guide/data/distribution/braze_currents\">Currents</a>, unser Daten-Streaming-Export, ist in bestimmten Braze-Paketen enthalten. Braze-Currents ermöglicht Ihnen die Integration durch Datenspeicherung unter Verwendung von Flat Files oder durch unsere Partner für Verhaltensanalysen und Kundendaten unter Verwendung von gebündelten JSON-Payloads an einen bestimmten Endpunkt."
  - name: Custom Attributes
    description: "<a href=\"https://www.braze.com/docs/user_guide/data/activation/attributes/custom_attributes\">Angepasste Attribute</a> sind eine Sammlung der einzigartigen Eigenschaften Ihrer Nutzer:innen. Sie eignen sich am besten zum Speichern von Attributen über Ihre Nutzer:innen oder von Informationen über geringwertige Aktionen innerhalb Ihrer Anwendung. Sie können Nutzer:innen innerhalb des Dashboards angepasste Attribute zuweisen. Sie können Ihre Nutzer:innen nach diesen Attributen filtern und segmentieren, sowohl für <a href=\"https://www.braze.com/docs/developer_guide/platforms/swift/analytics/setting_custom_attributes/\">iOS-</a> als auch für <a href=\"https://www.braze.com/docs/developer_guide/platforms/android/analytics/setting_custom_attributes/\">Android</a>-Campaigns."
  - name: Custom Events
    description: "<a href=\"https://www.braze.com/docs/user_guide/data/activation/events/custom_events\">Angepasste Events</a> sind Aktionen, die von Ihren Nutzer:innen ausgeführt werden. Sie eignen sich am besten für das Tracking hochwertiger Nutzer:innen-Interaktionen mit Ihrer Anwendung."
  - name: Data Point
    description: "Ein Datenpunkt wird gezählt, wenn ein <a href=\"https://www.braze.com/docs/user_guide/data/activation/attributes/custom_attributes\">angepasstes Attribut</a> gesetzt oder aktualisiert wird (auch wenn Sie es mit demselben Wert aktualisieren), ein <a href=\"https://www.braze.com/docs/user_guide/data/activation/events/custom_events\">angepasstes Event</a> oder Kauf-Event protokolliert wird, beliebige Standarddaten (z. B. <code>email</code>, <code>first_name</code>, <code>last_name</code>, <code>country</code> oder <code>home_city</code>) protokolliert werden, wenn eine Sitzung beginnt und wenn eine Sitzung endet."
  - name: Deep Linking
    description: "<a href=\"https://www.braze.com/docs/user_guide/messaging/design_and_edit/personalize/actions_and_media_urls/\">Deeplinks</a> werden verwendet, um Kund:innen zu ihrer nächsten Aktion oder ihrem nächsten Engagement zu führen. Mit Deeplinks können Sie eine Nachricht mit einem gezielten Inhalt auf einer Website oder in einer mobilen App verbinden."
  - name: Dormant Users
    description: "Ein:e Nutzer:in gilt als <a href=\"https://www.braze.com/docs/user_archival/#dormant-users\">inaktiv</a>, wenn in den letzten zwölf Monaten keine Aktivität stattgefunden hat."
  - name: Endpoint
    description: "Ein Endpunkt eines Kommunikationskanals, der auch als API-<a href=\"https://www.braze.com/docs/api/endpoints/\">Endpunkt</a> bezeichnet wird, wird innerhalb der Messaging-API von Braze zum Senden und Planen von Nachrichten verwendet."
  - name: Exception Events
    description: "<a href=\"https://www.braze.com/docs/user_guide/messaging/canvas/create_a_canvas/exit_criteria#exception-events\">Ausnahme-Events</a> treten auf, wenn ein:e Nutzer:in das gewünschte Ziel erreicht hat und keine getriggerte Nachricht erhält. Auf diese Weise ist die getriggerte Nachricht für die:den Nutzer:in weiterhin relevant."
  - name: Frequency Capping
    description: "<a href=\"https://www.braze.com/docs/user_guide/messaging/messaging_fundamentals/frequency_capping#frequency-capping\">Frequency-Capping</a> ermöglicht es Ihnen, die Kommunikation zu steuern, ohne Ihre Zielgruppe zu überfordern. Es handelt sich um eine automatische Begrenzung der Nachrichten, um zu verhindern, dass Nutzer:innen zu viele Nachrichten in kurzer Zeit erhalten."
  - name: HIPAA
    description: "HIPAA ist eine Abkürzung für Health Insurance Portability and Accountability Act (US-Gesetz zum Schutz medizinischer Daten). Braze ist <a href=\"https://www.braze.com/docs/developer_guide/disclosures/security_qualifications/#hipaa\">HIPAA-konform</a>. Die HIPAA-Anforderungen umfassen administrative, physische und technische Sicherheit."
  - name: In-App Messages
    description: "<a href=\"https://www.braze.com/docs/user_guide/channels/in_app_messages\">In-App-Nachrichten</a> sind mobile Nachrichten, die innerhalb Ihrer Anwendung erscheinen. Sie helfen Ihnen, Inhalte an Ihre Nutzer:innen zu übermitteln, ohne sie mit einer Push-Benachrichtigung zu unterbrechen. Angepasste und maßgeschneiderte In-App-Nachrichten verbessern das Nutzererlebnis und helfen Ihrer Zielgruppe, den größten Nutzen aus Ihrer App zu ziehen."
  - name: Inactive Users
    description: "Ein:e Nutzer:in gilt als <a href=\"https://www.braze.com/docs/user_archival/#inactive-users\">inaktiv</a>, wenn bestimmte Kriterien erfüllt sind, z. B. keine E-Mails oder Push-Nachrichten mehr empfangen werden und seit mehr als sechs Monaten keine Aktivität stattgefunden hat."
  - name: IP Warming
    description: "<a href=\"https://www.braze.com/docs/user_guide/channels/email/email_setup/ip_warming\">IP-Warming</a> bezeichnet die schrittweise Erhöhung der Menge an E-Mails, die von einer bestimmten IP-Adresse aus gesendet werden. Dies trägt dazu bei, einen guten Ruf bei Internet-Providern aufzubauen und die Wahrscheinlichkeit zu minimieren, dass Ihre Nachrichten markiert werden."
  - name: Key-Value Pairs
    description: "<a href=\"http://www.braze.com/docs/user_guide/messaging/design_and_edit/personalize/sources/key_value_pairs\">Schlüssel-Wert-Paare</a> sind verknüpfte Datenobjekte, bei denen der Schlüssel ein eindeutiger Bezeichner und der Wert der Inhalt ist. Sie können verwendet werden, um zusätzliche Daten-Payloads an Nutzer:innen-Geräte zu senden."
  - name: Liquid
    description: "Liquid ist eine weit verbreitete, von Shopify entwickelte und in Ruby geschriebene Template-Sprache. <a href=\"https://www.braze.com/docs/user_guide/messaging/design_and_edit/personalize/liquid\">Liquid</a> wird zum Laden und Abrufen dynamischer Inhalte verwendet. Liquid erlaubt Ihnen die Verwendung von Objekten, Tags und Filtern, um <a href=\"http://www.braze.com/docs/user_guide/messaging/design_and_edit/personalize/liquid/supported_personalization_tags\">eine persönliche Anpassung vorzunehmen</a>."
  - name: Messaging Channel
    description: "<a href=\"https://www.braze.com/docs/user_guide/channels/\">Messaging-Kanäle</a> bieten Ihnen die Möglichkeit, virtuell mit Ihren Kund:innen zu kommunizieren – über Push-Benachrichtigungen auf dem Telefon oder im Webbrowser, E-Mails, In-App-Nachrichten und vieles mehr!"
  - name: Monthly Active User (MAU)

  - name: Multichannel Messaging

  - name: Multivariate Testing
    description: "Mit <a href=\"https://www.braze.com/docs/user_guide/messaging/ab_testing#multivariate-test\">multivariaten Tests</a> können Sie mehrere Variablen testen, indem Sie zwei oder mehr Versionen einer Nachricht vergleichen, um festzustellen, welche Variante am besten abschneidet."
  - name: New User
    description: "Braze betrachtet neue Nutzer:innen als Personen, die Ihre App neu installiert haben. Alternativ können neue Nutzer:innen auch als Personen mit einer Nutzer-ID definiert werden, die in Braze noch nicht bekannt ist."
  - name: Personalization
    description: "Einsatz von Technologie, um die individuellen Vorlieben und Tendenzen jeder:jedes Nutzer:in bei der Kommunikation zu berücksichtigen. <a href=\"https://www.braze.com/docs/user_guide/messaging/design_and_edit/personalize\">Personalisiertes Messaging</a> hilft, wertvolle Kundenerlebnisse zu schaffen, indem es an die Präferenzen der Kund:innen angepasst wird."
  - name: Push Messages
    description: "Eine <a href=\"https://www.braze.com/docs/user_guide/channels/push\">Push-Nachricht</a> oder Push-Benachrichtigung ist eine Benachrichtigung, die von einer mobilen Anwendung angezeigt wird. Push-Benachrichtigungen erscheinen oft als Popup-Dialoge und Banner für iOS und Android."
  - name: Push Token
    description: "Ein Push-Token ist ein eindeutiger Schlüssel, der von Apple oder Google erstellt und zugewiesen wird, um eine Verbindung zwischen einer App und einem iOS-, Android- oder Web-Gerät herzustellen. Die <a href=\"https://www.braze.com/docs/api/objects_filters/user_attributes_object/#migrating-push-tokens\">Push-Token-Migration</a> ist das Importieren dieser bereits generierten Schlüssel in Braze."
  - name: Push Time to Live
    description: "Die auch als <a href=\"https://www.braze.com/docs/user_guide/administer/global/workspace_settings/push_settings\">Push TTL</a> bezeichnete Time-to-Live bezieht sich auf den Zeitraum, in dem Campaigns weiterhin versuchen, einer:einem Offline-Nutzer:in zugestellt zu werden."
  - name: Race Condition
    description: "Eine <a href=\"http://www.braze.com/docs/user_guide/messaging/ab_testing/concepts/race_conditions\">Race-Condition</a> ist ein Konzept aus der Softwaretechnik, das eine unerwünschte Situation beschreibt, die auftritt, wenn ein System versucht, mehrere Operationen gleichzeitig auszuführen. Aufgrund der Beschaffenheit des Systems müssen die Operationen jedoch in der richtigen Reihenfolge ausgeführt werden, um korrekt zu funktionieren. <br><br>In der Braze-Plattform kann die Segmentierung einer getriggerten Campaign anhand von Nutzerdaten, die zum Zeitpunkt des Events aufgezeichnet wurden, eine Race-Condition verursachen. Dies geschieht, wenn eine Änderung des Nutzerattributs, auf dessen Grundlage die Campaign segmentiert wird, zum Zeitpunkt der Bestimmung der Segmentzugehörigkeit und des Versands der Campaign noch nicht für die:den Nutzer:in verarbeitet wurde, was dazu führen kann, dass die:der Nutzer:in die Campaign nicht erhält."
  - name: Rate Limiting
    description: "<a href=\"https://www.braze.com/docs/user_guide/messaging/messaging_fundamentals/frequency_capping\">Rate-Limiting</a> ist der Prozess der Begrenzung der Anzahl gesendeter Nachrichten innerhalb eines bestimmten Zeitraums, um eine Überlastung Ihrer Zielgruppe zu vermeiden."
  - name: Tags
    description: "<a href=\"https://www.braze.com/docs/user_guide/administer/global/workspace_settings/tags\">Tags</a> sind ein Werkzeug, mit dem Sie Ihr Engagement über eine oder mehrere Campaigns hinweg kategorisieren, organisieren und sortieren können."
  - name: Segmentation
    description: "Mit der Dashboard-<a href=\"https://www.braze.com/docs/user_guide/audience/segments\">Segmentierung</a> können Sie Gruppen oder Erweiterungen von Nutzer:innen auf der Grundlage leistungsstarker Filter für deren In-App-Verhalten, demografische Daten und mehr erstellen."
  - name: Software Development Kit (SDK)
    description: "<a href=\"https://www.braze.com/docs/developer_guide/getting_started/sdk_overview/\">SDKs</a> werden in iOS- und Android-Anwendungen integriert und bieten leistungsstarke Marketing-, Kundensupport- und Analysetools. Braze bietet SDK-Integration sowohl für <a href=\"https://www.braze.com/docs/developer_guide/platforms/swift/sdk_integration/#integrating-the-sdk/\">iOS</a> als auch für <a href=\"https://www.braze.com/docs/developer_guide/platforms/android/sdk_integration/#step-1-configure-brazexml\">Android</a>."
  - name: Sunsetting
    description: "Sunsetting bezieht sich auf den Prozess der Identifizierung von Nutzer:innen, die sich nicht mehr engagieren, und die Beendigung der aktiven Nachrichtenübermittlung an diese Nutzer:innen, ohne dass diese etwas unternehmen müssen. Die Erstellung von Sunset-Richtlinien für Ihre <a href=\"https://www.braze.com/docs/user_guide/channels/email/best_practices/sunset_policies/\">E-Mails</a> und <a href=\"https://www.braze.com/docs/user_guide/channels/push/best_practices/#implement-a-sunset-policy-for-unresponsive-users\">Push-Nachrichten</a> kann dazu beitragen, die Auswirkungen auf Ihre Öffnungsraten einzudämmen."
  - name: User Archival
    description: "<a href=\"https://www.braze.com/docs/user_archival/\">Nutzerarchivierung</a> bezieht sich auf Nutzer:innen, die archiviert wurden. Bei Braze umfasst dies sowohl inaktive als auch ruhende Nutzer:innen."
  - name: Webhooks
    description: "Mit <a href=\"https://www.braze.com/docs/user_guide/channels/webhooks\">Webhooks</a> können Sie Nicht-App-Aktionen wie den Versand von SMS-Nachrichten auslösen. Sie können Webhooks verwenden, um anderen Systemen und Anwendungen Realtime-Informationen zur Verfügung zu stellen. Die Flexibilität dieses Features erlaubt es Ihnen, Informationen an jeden beliebigen Endpunkt zu senden."
