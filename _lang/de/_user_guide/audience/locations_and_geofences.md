## Über Standorte und Geofences {#about-locations-and-geofences}

Mit Braze können Sie Beziehungen zu Ihren Nutzer:innen auf Basis ihres Standorts in der realen Welt aufbauen und vertiefen und so eine leistungsstarke Reihe eng vernetzter Interaktionen ermöglichen:

- Laden Sie die Standorte aller stationären Geschäfte Ihrer Marke hoch und senden Sie Push-Benachrichtigungen an treue Nutzer:innen, um sie über Aktionen im Shop zu informieren, wenn sie in der Nähe vorbeikommen.
- Laden Sie den Standort eines bevorstehenden Konzerts hoch und senden Sie Nutzer:innen eine Nachricht, in der Sie ihnen mitteilen, wo sie sich anmelden können, wenn sie den Veranstaltungsort erreichen. Senden Sie anschließend eine Dankesnachricht eine Stunde nach ihrem Verlassen des Veranstaltungsorts.

Sie können Standortdaten von Nutzer:innen auf verschiedene Weisen erfassen und nutzen:

- Wenn Nutzer:innen Ihre App öffnen, erfasst das Standort-Tracking ihren letzten Standort mithilfe von GPS-Standortdaten. So können Sie sehen, wo sich Ihre Nutzer:innen aufgehalten haben, und auf Basis dieser Daten segmentieren.
- Geofences sind definierte virtuelle geografische Bereiche. Wenn Nutzer:innen das Standort-Tracking im Hintergrund aktiviert haben, können Sie Geofences verwenden, um Campaigns in Realtime auszulösen, wenn sich Nutzer:innen in einem Geofence befinden.
