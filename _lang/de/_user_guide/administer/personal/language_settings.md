# Spracheinstellungen {#language-settings}

> Dieser Artikel beschreibt, wie Sie die Sprache ändern, in der das Braze-Dashboard angezeigt wird.

## Sprache des Dashboards ändern {#change-your-dashboard-language-settings}

Das Braze-Dashboard ist in [mehreren Sprachen](#supported-languages) verfügbar. Sie können die Anzeigesprache jederzeit auf Ihre bevorzugte Sprache umstellen.

1. Wählen Sie in der globalen Kopfzeile <i class="fa-solid fa-globe" aria-label="Sprache auswählen"></i> aus.
2. Wählen Sie Ihre Sprache aus der Liste.

![Englisch als Sprache für das Braze-Dashboard ausgewählt.]({% image_buster /assets/img_archive/language_dashboard.png %}){: style="max-width:40%"}

Es kann einen Moment dauern, bis das Dashboard neu geladen wird.

### Unterstützte Sprachen {#supported-languages}

Sie können aus den folgenden unterstützten Sprachen wählen:

- Deutsch (Deutsch)
- Englisch (English)
- Spanisch (Espa&ntilde;ol)
- Französisch (Français)
- Japanisch (日本語)
- Koreanisch (한국어)
- Portugiesisch (Brasil)
