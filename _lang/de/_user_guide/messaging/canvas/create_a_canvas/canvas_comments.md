# Kommentare in Canvas {#comments-in-canvas}

> Kommentare in Canvases können ein hervorragender kollaborativer Bereich für Ihr Marketing-Team sein, um die Details Ihrer Canvases zu identifizieren, zu besprechen und zu überprüfen. Während Sie ein Canvas aufbauen, können Sie Kommentare erstellen und verwalten, um Bereiche zu kennzeichnen, die möglicherweise zusätzliches Feedback von Ihren Kolleg:innen erfordern.

![Canvas-Builder mit der Kommentar-Seitenleiste, die offene Kommentar-Threads anzeigt.]({% image_buster /assets/img_archive/canvas_comments.png %}){: style="float:right;max-width:70%;margin-left:15px;"}

## Vorteile {#benefits}

Einige Vorteile des Kommentierens in Ihrem Canvas sind:
- Alle Details und Diskussionen über ein Canvas innerhalb des Canvas aufbewahren
- Änderungen an einem Canvas überprüfen und einen Freigabeprozess für diese Änderungen fördern
- In Realtime zusammenarbeiten, indem Sie andere Nutzer:innen taggen und ihnen antworten
- Detaillierte Aspekte eines Canvas identifizieren, wie z. B. spezifische Segmentierung, einschließlich Eigenschaften und Attribute, die für ein Canvas eindeutig sind

## So kommentieren Sie {#how-to-comment}

Standardmäßig zeigt die Seitenleiste offene Kommentare an. Sie können zwischen offenen Kommentaren, gelösten Kommentaren und allen Kommentaren umschalten, indem Sie das <i class="fa-solid fa-sliders"></i> Filter-Symbol verwenden. Sie können auch zur Ansicht „Für Sie“ umschalten, die Threads anzeigt, in denen Sie getaggt sind.

Um einen Kommentar zu hinterlassen, klicken Sie auf das <i class="fas fa-comment"></i> Kommentar-Symbol oben im Canvas. Dadurch verwandelt sich Ihr Cursor in ein Kommentar-Symbol. Klicken Sie auf den Schritt, den Sie kommentieren möchten. Um Ihren Cursor zurückzusetzen, drücken Sie die **Esc**-Taste oder klicken Sie erneut auf das Kommentar-Symbol.

### Tastenkombinationen {#keyboard-shortcuts}

Sie können auch Tastenkombinationen verwenden, um Kommentare hinzuzufügen:

| Mac | Windows |
| --- | --- |
| <kbd>⌘</kbd> + <kbd>Enter</kbd> | <kbd>Ctrl</kbd> + <kbd>Enter</kbd>|
| <kbd>Tab</kbd> + <kbd>Enter</kbd> | <kbd>Tab</kbd> + <kbd>Enter</kbd> |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Tastenkombinationen" }

Um einen bestehenden Kommentar anzuzeigen, öffnen Sie die Seitenleiste oder wählen Sie das <i class="fas fa-comment"></i> Kommentar-Symbol neben dem Schrittnamen aus. Sie können auch auf bestehende Kommentare in einem Thread antworten.

## Kommentare verwalten {#managing-comments}

Sie können Kommentare und Threads, die Sie erstellt haben, löschen, indem Sie auf das <i class="fa-solid fa-ellipsis-vertical"></i> Menü-Symbol in Ihrem Kommentar klicken. Wenn ein roter Kreis neben einem Kommentar erscheint, bedeutet dies, dass der Kommentar ungelesen ist.

Sie können keine Kommentare oder Threads anderer Nutzer:innen löschen. Allerdings kann jede Person einen Kommentar lösen, indem sie **Thread lösen** auswählt.

## Benachrichtigungen verwalten {#managing-notifications}

![Canvas-Benachrichtigungseinstellungen für Kommentar-Benachrichtigungen.]({% image_buster /assets/img_archive/canvas_notifications.png %}){: style="float:right;max-width:70%;margin-left:15px;"}

Um E-Mail-Benachrichtigungen für ein Canvas zu verwalten, öffnen Sie die Seitenleiste und klicken Sie auf <i class="fa-solid fa-bell"></i> **Benachrichtigungen**. Hier können Sie Ihre Benachrichtigungspräferenzen auswählen.

Wenn Sie **Alle neuen Kommentare** auswählen, werden Sie über neue Threads benachrichtigt, die in einem Canvas gestartet werden – das schließt auch ein, wenn Kommentare gelöst oder erneut geöffnet werden. Wenn Sie **Erwähnungen oder Antworten** auswählen, werden Sie über neue Kommentare benachrichtigt, in denen Sie getaggt sind, oder über Threads, an denen Sie teilnehmen.

Um Kommentar-Benachrichtigungen für ein Canvas zu deaktivieren, wählen Sie **Keine** aus. Standardmäßig ist die erstellende Person eines Canvas für Benachrichtigungen über alle neuen Kommentare angemeldet, und andere Nutzer:innen sind für Benachrichtigungen über Erwähnungen oder Antworten angemeldet.

Beachten Sie, dass der Schalter **Kommentare in Canvases** unter diesen Benachrichtigungspräferenzen steuert, ob Sie für Benachrichtigungen über alle Canvases hinweg angemeldet oder abgemeldet sind. Wenn Sie diese Einstellung deaktivieren, erhalten Sie keine E-Mail-Benachrichtigungen über Kommentar-Aktionen.
