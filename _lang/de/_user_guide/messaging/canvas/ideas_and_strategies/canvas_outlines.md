### Onboarding {#onboarding}

Nehmen wir an, Ihr Restaurant möchte Nutzer:innen beim Onboarding unterstützen, damit sie ihre erste Reservierung vornehmen. Da dieses Canvas nur für das Onboarding gedacht ist, wäre ein idealer Startzeitpunkt der Sitzungsbeginn für alle neuen Kund:innen. Für eine schnelle und effektive Möglichkeit, Ihre Gäste zu erreichen, können Sie den SMS-Messaging-Kanal nutzen.

![]({% image_buster /assets/img_archive/canvas_outline_onboarding.png %}){: style="max-width:90%;"}

### Upselling {#upsell}

Auch das Upgraden Ihrer Abos kann durch das Erstellen und Versenden effektiver Canvases gefördert werden. Wenn Sie beispielsweise aktive Nutzer:innen upgraden möchten, die eine kostenlose Version Ihrer App nutzen, können Sie ein aktionsbasiertes Canvas erstellen, das getriggert wird, wenn ein:e Kund:in das angepasste Event „3 Stunden gestreamt“ erreicht hat. Mit einem Nachrichten-Schritt können Sie diese Kund:innen dazu auffordern, sich für Ihre Premium-Abos anzumelden.

![]({% image_buster /assets/img_archive/canvas_outline_upsell.png %}){: style="max-width:90%;"}

### Warenkorb-Abbrüche {#abandoned-carts}

Einzelhandelsunternehmen müssen Kund:innen häufig an unvollständige Käufe erinnern. Mit einem aktionsbasierten Canvas können Sie eine Erinnerung an alle registrierten Kund:innen senden, die Artikel in ihrem abgebrochenen Warenkorb zu kaufen. Sie können außerdem testen, wie empfänglich Ihre Kund:innen für Ihr Messaging sind, indem Sie verschiedene Verzögerungszeiten verwenden.

![]({% image_buster /assets/img_archive/canvas_outline_cart.png %}){: style="max-width:90%;"}

### Ressourcen für Kund:innen {#customer-resources}

Sie können Canvases nutzen, um Kund:innen über Ressourcen zu informieren. Für Fluggesellschaften können Sie beispielsweise ein Canvas erstellen, das Kund:innen, die eine Reise in drei Tagen gebucht haben, vorbereitet, indem Sie eine wöchentliche E-Mail mit ihren Fluginformationen und zugehörigen Flughafen-FAQ planen.

![]({% image_buster /assets/img_archive/canvas_outline_resource.png %}){: style="max-width:90%;"}
