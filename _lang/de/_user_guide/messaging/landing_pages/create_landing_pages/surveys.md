# Landing-Page-Umfragen {#landing-page-surveys}

> Braze-Umfragen erfassen Feedback auf Landing-Pages, das Sie analysieren und in Folge-Nachrichten nutzen können. Umfragen werden im [Drag-and-Drop-Editor für Landing-Pages]({{site.baseurl}}/user_guide/messaging/landing_pages/create_landing_pages) erstellt.
