# Öffentliche APIs für Connected-Content verwenden {#use-public-apis-for-connected-content}

> Es gibt eine Vielzahl öffentlich verfügbarer APIs, die für Connected-Content genutzt werden können. Öffentliche APIs ermöglichen es Ihnen, angepasste Daten in Nachrichten einzufügen. Diese Seite stellt eine Liste öffentlicher APIs zusammen, die für Connected-Content verwendet werden könnten. Es gibt jedoch noch viele weitere APIs, die eine breite Palette potenzieller Connected-Content-Anwendungen bieten.

Kontaktieren Sie uns unter [success@braze.com](mailto:success@braze.com), um uns mitzuteilen, wenn Sie eine API zum Teilen haben!

{% alert note %}
Öffentliche APIs können Nutzungsbeschränkungen und Rate-Limiting unterliegen. Lesen Sie unbedingt die API-Dokumentation durch und kontaktieren Sie die API-Anbieter bezüglich Ihrer beabsichtigten Nutzung.
{% endalert %}

## Nachrichten und Informationen {#news-and-information}

|	 API 	| Beschreibung |
| --------- | --- |
| [OpenWeatherMap](http://openweathermap.org/api) | Stellt aktuelle Wetterdaten, 5- und 16-Tage-Vorhersagen sowie historische Daten bereit. |
| [NYT Article Search](https://developer.nytimes.com/docs/articlesearch-product/1/overview) | Stellt NYT-Artikeldaten bereit, darunter Überschrift, Thema, URL, Datum, Zusammenfassung usw. |
| [The Guardian API](http://open-platform.theguardian.com/documentation/) | Stellt Guardian-Artikeldaten bereit, darunter Überschrift, Thema, URL, Datum, Zusammenfassung usw. |
