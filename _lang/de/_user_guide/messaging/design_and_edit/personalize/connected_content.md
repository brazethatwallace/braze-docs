guide_top_text: "Braze Connected-Content erweitert die Personalisierung im Marketing, um Customer-Engagement und Conversions zu steigern. Dieses Feature ermöglicht es Ihnen, beliebige über eine API zugängliche Informationen direkt in Nachrichten einzufügen, die Sie an Nutzer:innen senden. Connected-Content ermöglicht das Abrufen von Inhalten entweder direkt von Ihrem Webserver oder von öffentlich zugänglichen APIs. Sie können unsere Connected-Content-Funktionen auch mit unseren Technologie-Partnern nutzen, wie <b><a href='/docs/partners/data_augmentation/contextual_location/accuweather/'>AccuWeather</a></b> und <b><a href='/docs/partners/channel_extensions/localization/transifex/'>Transifex</a></b>.<br><br>Zusätzlich zu den folgenden aufgeführten Artikeln empfehlen wir Ihnen unseren <b><a href='https://learning.braze.com/connected-content'>Connected-Content</a></b>-Braze-Lernkurs."
