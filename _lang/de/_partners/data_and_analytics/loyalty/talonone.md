# Talon.One

> [Talon.One](https://talon.one/) bietet personalisierte Anreize für Ihr Mobile-Marketing-CRM or Customer-Relationship-Management [-System] (CRM) und erlaubt es Ihnen, kontextuelle 1-zu-1-Gutschein-, Empfehlungs-, Rabatt- und Kundenbindungs-Kampagnen schnell und effizient zu starten.

_Diese Integration wird von Talon.One gepflegt._

## Über die Integration {#about-the-integration}

Mit der Integration von Braze und Talon.One können Sie Ihr Kundenbindungs- oder Coupon-Programm auf die nächste Stufe heben, indem Sie von Talon.One generierte Codes über Braze Connected-Content an Ihre Zielgruppe senden.


## Voraussetzungen {#prerequisites}

| Anforderung | Beschreibung |
| ----------- | ----------- |
| Talon.One-Konto | Um die Vorteile dieser Partnerschaft zu nutzen, benötigen Sie ein Talon.One-Konto. |
| Talon.One-API-Schlüssel | Erstellen Sie in Talon.One unter **Settings** > **Developer Settings** einen Braze-3rd-Party-API-Schlüssel für die Integration. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Prerequisites" }

{% alert warning %}
Talon.One **_erfordert_** ein Rate-Limit von maximal 2.500 Nachrichten pro Minute. Dieses Rate-Limit kann im Braze-Dashboard [geändert]({{site.baseurl}}/user_guide/engagement_tools/campaigns/testing_and_more/rate-limiting/#delivery-speed-rate-limiting) werden.
{% endalert %}
