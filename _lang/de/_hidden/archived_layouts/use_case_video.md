## So erstellen Sie diese Campaign/dieses Canvas {#how-to-build-this-campaigncanvas}

Wenn Sie diesen Teil des Artikels schreiben, gliedern Sie die Aufgaben nach Strategie und Schritt. Sie können dies deutlich machen, indem Sie die Schritte wie folgt benennen. Schreiben Sie die Schritte nicht explizit aus (d. h. klicken Sie auf diesen Button; klicken Sie auf jenen Button). Leiten Sie die Leser:innen stattdessen an, indem Sie Schritte beschreiben, die die Ziele des Anwendungsfalls erreichen.

### 1. Schritt: Richten Sie Ihr Canvas für passive Nutzer:innen ein (Hinweise zur Zielgruppe) {#step-1-set-up-your-canvas-for-lapsing-users-advise-on-audience}

Wenn Sie über die Zielgruppe sprechen, müssen Sie nicht erklären, wie man Segmente oder Filter verwendet. Zeigen Sie stattdessen, wie die Zielgruppe auf passive Nutzer:innen eingegrenzt werden kann und wie sichergestellt wird, dass die Nachricht nicht an andere Personen geht – und warum das wichtig ist. Zum Beispiel: „Sie können Ihre passiven Nutzer:innen auf verschiedene Weise eingrenzen – z. B. indem Sie Nutzer:innen auswählen, die die App seit einigen Tagen nicht mehr benutzt haben, oder eine E-Mail geöffnet haben, wenn Sie das möchten. Stellen Sie sicher, dass Sie einen Filter anwenden, wenn Sie Personen ausschließen möchten, die schon so lange nicht mehr in der App waren, dass sie die Datenpunkte nicht mehr wert sind.“


### Code-Beispiel {#code-sample}

Wenn Sie ein technisches Konzept erklären, vermerken Sie das hier und zeigen Sie ein Code-Beispiel.

### 2. Schritt: Senden Sie Ihre Nachricht zum richtigen Zeitpunkt {#step-2-send-your-message-at-the-right-time}

Sprechen Sie darüber, wann Sie Ihre Nachricht senden sollten, sofern das wichtig ist. Vielleicht ist es das nicht! Lassen Sie die Leser:innen zumindest wissen, dass das Senden in Ortszeit möglich ist. Oder erklären Sie, wie diese spezielle Situation per API getriggert werden kann, oder ob es bei einem Canvas besser ist, den Schritt auf Basis einer Aktion zu triggern (z. B. eine E-Mail öffnen und mindestens einen Tag lang nicht klicken).
