# Preview drag-and-drop editor Content Blocks

After creating your [Content Blocks for your drag-and-drop email campaigns]({{site.baseurl}}/user_guide/messaging/design_and_edit/content_blocks?tab=drag-and-drop), you can view your library of these Content Blocks in the drag-and-drop editor.

{% alert important %}
This preview feature for the drag-and-drop Content Blocks is currently in early access. Contact your Braze account manager if you're interested in participating in the early access.
{% endalert %}

To preview your Content Blocks, go to the **Content** section > **Design and Build**. Select the **Rows** tab, and select **Content Blocks** in the dropdown. Here, you can see your drag-and-drop Content Blocks display as they would in your email campaign. 

{% alert note %}
Only Content Blocks used exclusively in the drag-and-drop editor are viewable under the **Rows** tab.
{% endalert %}

Once you've dragged and dropped the Content Block into your email campaign, you can make changes to any and all content in the Content Block. Note that if a Content Block contains Liquid, you'll see the Liquid in the **Preview & Test** section.
