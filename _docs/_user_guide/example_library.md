## What you find here

Each example walks through a practical pattern: the goal it solves, what to consider before you build, and how to set it up in Braze. Examples are organized by topic, so you can find patterns that match the outcome you're working toward.

These articles complement the feature reference articles. When you need the full product details for a channel, Canvas component, or data tool used in an example, follow the related article links on that page.

## How to use these examples

1. **Start with your goal:** Identify the outcome you want (for example, validating personalized Liquid in preview, or orchestrating a multi-step journey).
2. **Adapt the pattern:** Treat each example as a starting point. Swap in your events, attributes, segments, and creative.
3. **Verify against your workspace:** Confirm prerequisites such as data availability, channel setup, and permissions before you launch.
4. **Deepen with featured resources:** Use the related articles on each example page when you need fuller reference guidance for a Braze capability.
