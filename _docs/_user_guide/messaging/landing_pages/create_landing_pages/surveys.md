# Landing page surveys

> Braze surveys collect feedback on landing pages that you can analyze and use in follow-up messaging. Surveys are built in the [landing page drag-and-drop editor]({{site.baseurl}}/user_guide/messaging/landing_pages/create_landing_pages).
