The calculations for different metrics in the {{ include.channel }} performance dashboard are the same as those on an individual message level (such as campaign analytics). On this dashboard, the metrics are aggregated across all campaigns and Canvases for the date range you've selected. {% if include.channel == "email" %}To learn more about these definitions, refer to [Email metrics]({{site.baseurl}}/user_guide/channels/email/reporting/analytics_glossary/#email-metrics).{% elsif include.channel == "SMS" %}To learn more about these definitions, refer to [SMS metrics]({{site.baseurl}}/sms_mms_rcs_reporting/).{% elsif include.channel == "push" %}For metric definitions, refer to [Report Metrics Glossary]({{site.baseurl}}/user_guide/data/report_metrics/) and filter by Push. For more information about influenced opens, see [Influenced opens]({{site.baseurl}}/user_guide/analytics/tracking/influenced_opens/).{% endif %}

{% if include.channel == "email" %}Each tile shows the rate metric first, followed by the count metric (with the exception of *Sends*, which displays the count metric followed by the average per day). For example, the unique clicks tile contains the *Unique click rate* from your selected time period and the count of the total number of unique clicks from that time period.{% elsif include.channel == "SMS" %}Each tile shows the rate metric first, followed by the count metric (with the exception of _Sends_, which displays the count metric followed by the average per day).{% elsif include.channel == "push" %}Each tile shows the rate metric first, followed by the count metric (with the exception of _Sends_, which displays the count metric only).{% endif %} Each tile also shows the [comparison to the last period](#comparing-time-periods).
